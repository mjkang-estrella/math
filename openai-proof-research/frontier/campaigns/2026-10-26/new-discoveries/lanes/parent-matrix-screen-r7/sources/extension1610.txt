                                                  Abstract. We extend an operator Pólya–Szegö type inequality involving the
                                                  operator geometric mean to any arbitrary operator mean under some mild condi-
                                                  tions. Utilizing the Mond–Pečarić method, we present some other related operator
                                                  inequalities as well.



                                                                               1. Introduction

                                             Let B(H) denote the C ∗ -algebra of all bounded linear operators on a complex
                                           Hilbert space (H, h·, ·i) equipped with the operator norm k · k. Throughout the
                                           paper, a capital letter means an operator in B(H). We identify a scalar with the
                                           identity operator I multiplied by this scalar. An operator A is called positive if
                                           hAx, xi ≥ 0 for all x ∈ H, and we then write A ≥ 0. We denote by A > 0 if it is a
                                           positive invertible operator. For self-adjoint operators A, B ∈ B(H), we say B ≥ A
                                           if B − A ≥ 0. A linear map Φ : B(H) → B(K) is called positive if A ≥ 0 implies
                                           Φ(A) ≥ 0. It is said to be unital if Φ preserves the identity operator.
                                             The axiomatic theory for operator means of positive invertible operators have
                                           been developed by Kubo and Ando [9], in particular an operator mean σ has the
                                           monotonicity property if A ≤ C and B ≤ D imply AσB ≤ CσD. A continuous real
                                           valued function h defined on an interval J is called operator monotone if A ≥ B
                                           implies that h(A) ≥ h(B) for all self-adjoint operators A, B with spectra in J.
                                           There exists an affine order isomorphism between the class of operator means σ
                                           and the class of positive operator monotone functions h defined on (0, ∞) with

all strictly positive operators A, B. The operator monotone function h is called
the representing function of σ. Using a standard limit argument, this notion can
be extended for positive operators A, B. The operator mean corresponding to the
operator monotone functions h(t) = tǫ (0 < ǫ < 1) is called the weighted operator
geometric mean, which is indeed A♯ǫ B = A1/2 (A−1/2 BA−1/2 )ǫ A1/2 . The case where
ǫ = 1/2 gives rise to the usual operator geometric mean ♯.
    Ando [1] proved the property Φ(A♯B) ≤ Φ(A)♯Φ(B) for any positive linear map
Φ (not neccessarily unital). Further, it is well-known that Ando’s proof can work
not only for # but also for every operator mean σ. As a complementary to Ando’s
inequality, Seo [16] obtained some additive and multiplicative types of reverses of
Ando’s inequality. Reverses of this inequality are known as operator Pólya–Szegö
type inequalities in the literature. Moslehian et al. [13, Theorem 2.1] presented an
operator Pólya–Szegö inequality (see also [10] for a proof for matrices) as follows:

Theorem 1.1. Let Φ be a positive linear map. If 0 < m ≤ A, B ≤ M for some
positive real numbers m ≤ M, then
                                     M +m
(1.1)                    Φ(A)♯Φ(B) ≤ √    Φ(A♯B) .
                                    2 Mm
    It is well known that t2 is not operator monotone. However, Fujii et al. [6,
Theorem 6] applied the Kantrovich inequality to show that t2 is order preserving in
a certain sense. Lin [11] reduced the study of squared operator inequalities to that
of some norm inequalities. Hoa, Toan and Binh [8] studied some reverse inequalities
for arbitrary pair of operator means. Recently, Fu and Hoa [5] extended this result
for any power greater than 1, see also [14].
    This note intends to extend the operator Pólya–Szegö inequality (1.1) for any
arbitrary operator mean. Our results provide some general reverses of the Ando
inequality under some mild conditions.

Remark 2.2. The positive linear maps Φ and Ψ in Theorem 2.1 must be unital. If
not, the conclusion doesn’t hold in general. For example, Let f (x) = g(x) = x,
Φ(A) = kA, Ψ(A) = lA, where k, l > 0. Obviously, the conclusion doesn’t hold in
Theorem 2.1 when we choose the appropriate positive numbers k and l.
    Notice that if g is an operator monotone function on [0, ∞), then from the general
Ando inequality Ψ(A)τ Ψ(B) ≥ Ψ(Aτ B) we have

                            g(Ψ(A)τ Ψ(B)) ≥ g(Ψ(Aτ B)).

Without the condition of operator monotonicity on g the last inequality can be false.

    When f : [0, ∞) → [0, ∞) is a monotone increasing function, we know that f p is
also a monotone increasing function for p > 0. Then we have the following corollary.

Corollary 2.3. Let Φ, Ψ be positive linear maps, σ, τ be operator means, 0 < m ≤
A, B ≤ M for some positive real numbers m ≤ M and f, g : [0, ∞) → [0, ∞)
monotone increasing functions. Then

                f p (Φ(A)σΦ(B)) ≤ f p (M)g p (m−1 )g p (Ψ(A)τ Ψ(B)),

                 f p (Φ(A)σΦ(B)) ≤ f p (M)g p (m−1 )g p(Ψ(Aτ B)),

                 f p (Φ(AσB)) ≤ f p (M)g p (m−1 )g p(Ψ(A)τ Ψ(B)),

and

                   f p (Φ(AσB)) ≤ f p (M)g p (m−1 )g p (Ψ(Aτ B)),

where, p > 0.

    In the case when f = g is a nonzero operator monotone function on [0, ∞), we
have the following theorem.

Theorem 2.12. Let Φ be a positive linear map, f a nonzero operator monotone
function on [0, ∞), τ, σ operator means between arithmetic and harmonic means,
and 0 < m ≤ M. Then for any positive matrices 0 < m ≤ A, B ≤ M,

                      f (Φ(A))τ f (Φ(B)) ≤ K(M, m)f (Φ(AσB)).

Proof. It is well-known (see, for example [8]) that if Φ is unital, then

(2.6)                       K(M, m)Φ(AσB) ≥ Φ(A)∇Φ(B).

There is a standard argument in dealing with operator inequalities in which we may
consider positive linear maps instead of unital positive linear maps. In fact, by
passing to Φ + ε id we can assume that Φ(I) > 0 and then we can define Ψ(A) =
Φ(I)−1/2 Φ(A)Φ(I)−1/2 as a unital positive linear map. Using a limit argument, we
get (3).

                              3. Concluding remark

  From Theorem 2.12 for any p ∈ [0, 1] and for any positive matrices 0 < m ≤
A, B ≤ M,

(3.1)                         Ap ∇B p ≤ K(M, m)(A♯B)p .

At the same time, inequality (3.1) is failed when p = 2. Indeed, it is easy to construct
some matrices A and B that do not satisfy (3.1). For example, with m = 0.4, M = 3

                   f (A♯B) ≤ f (A∇B) and f (A∇B) ≤ f (A)♯f (B)

characterize operator monotone (decreasing, respectively) functions on [0, ∞). It
was also proved in [7] that an additive reverse inequality

                                       1
                     f (A∇B) ≤ f (A♯B + A1/2 |I − A−1/2 BA−1/2 |A1/2 )
                                       2

characterizes operator monotonicity.
     So, it is natural to ask the following question: Does the multiplicative reverse
inequality (3) characterize operator monotone functions? In particular, suppose that

                                f (A)∇f (B) ≤ K(M, m)f (A♯B)

holds for any positive matrices 0 < m ≤ A, B ≤ M (where m < M are the given
positive numbers). Is it true that the function f is operator monotone on [m, M]?
