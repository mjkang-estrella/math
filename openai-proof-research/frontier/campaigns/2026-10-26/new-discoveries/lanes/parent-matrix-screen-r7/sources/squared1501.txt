                                                                                  1. Introduction

                                             Let B(H ) denote the C ∗ -algebra of all bounded linear operators on a complex Hilbert
                                           space (H , h·, ·i). Throughout the paper, a capital letter means an operator in B(H ).
                                           If dim H = n, then B(H ) can be identified with the space Mn of all n × n complex
                                           matrices. We identify a scalar with the identity operator I multiplied by this scalar.
                                           An operator A is called positive if hAx, xi ≥ 0 for all x ∈ H , and we then write
                                           A ≥ 0. An operator A is said to be strictly positive (denoted by A > 0) if it is a
                                           positive invertible operator. For self-adjoint operators A, B ∈ B(H ), we say B ≥ A
                                           if B − A ≥ 0. For strictly positive operators, A2 ≤ k 2 B 2 for some constant k if and
                                           only if (AB −1 )∗ (AB −1 ) ≤ k 2 and this occurs if and only if kAB −1 k ≤ k. A linear map
                                           Φ : B(H ) → B(K ) is called positive if A ≥ 0 implies Φ(A) ≥ 0. If this implication
                                           holds for > instead of ≥, we say that Φ is strictly positive. It is said to be unital if Φ
                                           preserves the identity operator. The operator norm is denoted by k · k. For A, B > 0,
