                                                  is investigated, via some convex ordering properties for related random variables. In particular,
                                                  it is shown that the mapping α 7→ Eα (xα ) decreases on (0, 2) for all x > 0, that the mapping

                                                                 1. Introduction and presentation of the results

                                            Introduced in [16], the classical Mittag-Leffler function
                                                                                           X       xn
                                                                                Eα (x) =
                                                                                               Γ(1 + nα)
                                                                                                n≥0
                                          with parameter α > 0, is one of the simplest special functions. In the case when α is rational, this
                                          function has a hypergeometric character and solves a certain linear ordinary differential equation.
                                          In general, the Mittag-Leffler function solves an Abelian integral equation with a fractional kernel
                                          and for this reason, it has been the object of many studies in the literature on fractional calculus.
                                          See the recent monographs [2, 12] for comprehensive accounts. Meanwhile, some basic properties of
                                          these functions are still unsettled.
                                            In this paper, we wish to study some monotonicity properties of the Mittag-Leffler function with
                                          respect to the fractional parameter α. This problem is classical for the usual special functions,
                                          in relationship with various comparison inequalities for the involved differential equations. As an
                                          instance, let us refer to our previous paper [9] for such comparison inequalities in the framework
                                          of confluent hypergeometric functions. For the Mittag-Leffler functions, the second author had
                                          obtained in [22] various stochastic ordering results for related random variables, leading to the
                                          hyperbolic bounds
                                                                                 1                       1
                                                                                         ≤ Eα (−x) ≤        x                                            (1)
                                                                           1 + Γ(1 − α)x             1 + Γ(1+α)
                                          for all α ∈ (0, 1) and x ≥ 0. These bounds, which were later on generalized in [6] for the two
                                          parameter Mittag-Leffler functions and the more general Kilbas-Saigo functions - can then be used
                                          for several problems such as Van der Corput estimates [20], inverse problems for subdiffusions [13]
                                          or boundedness properties for fractional differential equations [8].

    The purpose of this paper is to apply the notion of convex ordering for studying the monotonicity
of the mapping α 7→ Eα , in various contexts. Let us first recall that for two real random variables
X and Y, the convex ordering relationship

                                                X ≺cx Y

means that E[φ(X)] ≤ E[φ(Y )] for all convex functions such that the two expectations exist. By
the convexity of the exponential function, this property has an immediate application for comparing
Laplace transforms or moment generating functions, which is a known feature of several Mittag-
Leffler functions or transformations thereof - see [23] for an account. The methodology we use to
obtain convex orderings in this paper is classical, and makes an extensive use of single and double
intersection properties, as displayed in the standard reference [21] on the topic. Considering the
sometimes technical arguments and the specificity of some statements in [22], our proofs will be more
transparent and our findings will also have a simpler character. Our first result is the following.

Theorem A. For every x > 0, the mapping α 7→ Eα (xα ) decreases on (0, 2).

    The proof of the above result is different according as α ∈ (0, 1) or α ∈ (1, 2). In case α ∈ (0, 1),
the function Eα (xα ) is the difference of two Laplace transforms and we can apply a complete
monotonicity result of [1], which basically amounts to a non-intersection property for the kernels in
one Laplace transform. In case α ∈ (1, 2), the function Eα (xα ) is the moment generating function
of a centered random variable with an atom, and we show a double intersection property with the
help of the generalized Descartes’ rule of signs. If we consider the two-parameter Mittag-Leffler
function
                                                    X        xn
