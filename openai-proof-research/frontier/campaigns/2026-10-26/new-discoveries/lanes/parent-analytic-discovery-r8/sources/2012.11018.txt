                                                  REMARK ON A MITTAG-LEFFLER FUNCTION OF LE ROY TYPE

                                                                                          THOMAS SIMON




arXiv:2012.11018v2 [math.CA] 25 Mar 2021
                                                   Abstract. We give some necessary and some sufficient conditions for the complete monotonicity
                                                   on the negative half-line of a Mittag-Leffler function of Le Roy type. It is conjectured that the
                                                   underlying positive random variable, when it exists, must be logarithmically infinitely divisible.

                                           We will consider here the classical problem of the complete monotonicity on the negative half-line.
                                           It has been shown in [12] that x 7→ Eα,β (−x) is completely monotone (CM) on (0, ∞) iff α ∈ [0, 1]

                                           G−function. Throughout, the CM property of a given function will be implicitly meant on (0, ∞).
                                           Our contribution in this note is the

                                           Theorem. For every α, β, γ > 0, the following holds.
                                                                                   (γ)
                                             (a) If γ ≤ 1, the function x 7→ Fα,β (−x) is CM iff αγ ≤ 1 and β ≥ α.

                                                                                                 (γ)
                                             (c) If γ > 1 and αγ = 1, the function x 7→ Fα,β (−x) is CM iff β ≥ (1 + α)/2.

    The connection between the Stieltjes moment problem and the CM property is mentioned in the
conclusion of [7]. We follow this approach here in a continuous way, with the help of Carlson’s
theorem which implies an equivalence between the CM property and the existence of certain Mellin
transforms. We then appeal to some classical considerations on infinite divisibility and the Gamma
function. The situation {γ > 1, αγ < 1, β ∈ (α, (α + 1)/2)} remains however open. A plausible,
albeit non explicit, conjecture in this respect is formulated in Section 3.

Remark. Consider the following function
                                                      (Γ(Ax + a))α
                                      V (x) = θ −x
                                                      (Γ(Bx + b))β
on (0, ∞), where all the parameters are positive. With the notation of the recent paper [2] for
logarithmic completely monotone (LCM) functions, the proof of parts (a) and (c) of the theorem
can be easily adapted to show that the following characterization holds:

                                   V (x) is CM   ⇐⇒      V (x) is LCM,

and that this property is equivalent to the following set of conditions on the parameters:

                αA = βB, Ab ≥ Ba, B Bβ θ ≥ AAα and β(2b − 1) ≥ α(2a − 1).

This also implies that the necessary conditions given in Corollary 3.3 of [2] for the LCM property of
V (x) are actually sufficient in the case p = s = 1, with the notation therein. The latter equivalence
is also an extension of Theorem 3.13 in [2]. In particular, the function
                                               X                               

                   ψ(Ax + a) − ψ(Bx + b) =                        −
                                                     Bx + b + n      Ax + a + n
                                                 n≥0

is Bernstein on (0, ∞) if and only if a ≥ b and 2(Ab − Ba) ≥ A − B ≥ 0. We leave the details,
which are available upon request, to the interested reader. See Section 3 in [2] and the references
therein for further results on the LCM property for more general ratios of powers of the Gamma
function.


                                        3. An open problem

  The above proof shows that
                                                                   
    (γ)                                                   n!
   Fα,β (−x) is CM       ⇐⇒ Mα,β,γ holds ⇐⇒                             is a Stieltjes moment sequence
                                                     (Γ(αn + β))γ
and that this is ensured by z + γ(z β−α − z β ) ≤ 1 for all z ∈ (0, 1). The latter criterion was also
shown to be necessary for γ ≤ 1 or {γ > 1, αγ = 1}. We believe that this necessity is true in
general.

Conjecture. For every α, β, γ > 0, one has
                   (γ)
                 Fα,β (−x) is CM     ⇐⇒     z + γ(z β−α − z β ) ≤ 1       for all z ∈ (0, 1).

  In general, it does not seem that the criterion on the right-hand side can be expressed explicitly
in terms of α, β, γ, save for γ ≤ 1 or {γ > 1, αγ = 1} by part (a) resp. part (c) of the theorem. If
we fix γ > 1 and set

            β(α) = inf{β > 0, z + γ(z β−α − z β ) ≤ 1 for all z ∈ (0, 1)} ∈ (α, α(1 + γ)/2)

for all α ∈ (0, 1/γ), it is not difficult to prove that α 7→ β(α)/α is non-decreasing. We also believe
that α 7→ β(α) is convex, but this fact still eludes us.

In the remaining situation {γ > 1, αγ < 1}, the puzzling point is that for β ∈ (α, α(1 + γ)/2) the
function z 7→ z + γ(z β−α − z β ) − 1 may vanish twice and be negative then positive then negative
on (0, 1), which implies that there exists x2 > x1 > 0 such that ϕα,β,γ (x) < 0 for x ∈ (x1 , x2 ) and
ϕα,β,γ (x) > 0 for x ∈ (0, x1 ) ∪ (x2 , ∞). In this case, the absolute continuity counterargument used
at the end of Section 2 does not hold anymore. Besides, there exist real random variables having
