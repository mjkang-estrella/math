 Abstract. 
    
 P. V. Chung showed that there are many multiplicative functions  f f  which satisfy  f ⁡ ( m 2 + n 2 ) = f ⁡ ( m 2 ) + f ⁡ ( n 2 ) f(m^{2}+n^{2})=f(m^{2})+f(n^{2})  for all positive integers  m m  and  n n . In this article, we show that if more than  2 2  squares in the additive condition are involved, then such  f f  is uniquely determined. That is, if a multiplicative function  f f  satisfies 
    
 

 
 
 f ⁡ ( a 1 2 + a 2 2 + ⋯ + a k 2 ) = f ⁡ ( a 1 2 ) + f ⁡ ( a 2 2 ) + ⋯ + f ⁡ ( a k 2 ) f(a_{1}^{2}+a_{2}^{2}+\dotsb+a_{k}^{2})=f(a_{1}^{2})+f(a_{2}^{2})+\dotsb+f(a_{k}^{2}) 
 
 
    
 for arbitrary positive integers  a i a_{i} , then  f f  is the identity function. In this sense, we call the set of all posotive squares a  k k -additive uniqueness set  for multiplicative functions. 
  
 
 
 Key words and phrases:  multiplicative function,  k k -additive uniqueness set, functional equation
 
 
 1.  Introduction 

 
 In 1992, Claudia Spiro  [ 9 ]  called a set  E E  an  additive uniqueness set  for a set  S S  of arithmetic functions if  f ∈ S f\in S  is determined uniquely to be the identity function by the additive condition  f ⁡ ( m + n ) = f ⁡ ( m ) + f ⁡ ( n ) f(m+n)=f(m)+f(n)  for arbitrary  m , n ∈ E m,n\in E . She proved that the set of primes is an additive uniqueness set for the set of multiplicative functions which do not vanish at some prime. 
 
 
 Many mathematicians have generalized her theorem. Fang  [ 5 ]  showed that the additive condition for primes can be changed to three primes. Also, Dubickas and Šarka  [ 3 ]  extended the result to the arbitrary many primes. That is, the condition can be changed to 
 

 
 
 f ⁡ ( p 1 + p 2 + ⋯ + p k ) = f ⁡ ( p 1 ) + f ⁡ ( p 2 ) + ⋯ + f ⁡ ( p k ) f(p_{1}+p_{2}+\dotsb+p_{k})=f(p_{1})+f(p_{2})+\dotsb+f(p_{k}) 
 
 
 for all primes  p i p_{i} ’s when  k ≥ 2 k\geq 2 . In their result, let us call the additive condition  k k -additivity  and the set of primes a  k k -additive uniqueness set . 
 
 
 Some mathematicians have studied other additive uniqueness sets. Chung classified all multiplicative functions which are  2 2 -additive on positive squares  [ 2 ] . If  S S  is the set of completely multiplicative nonnegative functions, then the set of positive squares is a  2 2 -additive uniqueness set for  S S . But, it is not a  2 2 -additive uniqueness set for the set of multiplicative functions. Similarly, Bašić classified all arithmetic functions  f f  satisfying  f ⁡ ( m 2 + n 2 ) = f ​ ( m ) 2 + f ​ ( n ) 2 f(m^{2}+n^{2})=f(m)^{2}+f(n)^{2}   [ 1 ] . He showed that there exists a function  2 2 -additive on positive squares other than the identity function although the functions are restricted to multiplicative functions. The author generalized Basšić’s result to 
 

 
 
 f ⁡ ( a 1 2 + a 2 2 + ⋯ + a k 2 ) = f ​ ( a 1 ) 2 + f ​ ( a 2 ) 2 + ⋯ + f ​ ( a k ) 2 f(a_{1}^{2}+a_{2}^{2}+\dotsb+a_{k}^{2})=f(a_{1})^{2}+f(a_{2})^{2}+\dotsb+f(a_{k})^{2} 
 
 
 for all positive integers  a i a_{i} ’s and showed that such  f f  is determined uniquely to be the identity function when  k ≥ 3 k\geq 3   [ 8 ] . 
 
 
 In this article, we show that the set of positive squares is  k k -additive uniqueness set for multiplicative functions when  k ≥ 3 k\geq 3 : 
 
 
 Theorem 1 . 
 
 Fix  k ≥ 3 k\geq 3 . The set of positive squares is the  k k -additive uniqueness set for multiplicative functions. That is, if a multiplicative function  f f  satisfies 
 

 
 
 f ⁡ ( a 1 2 + a 2 2 + ⋯ + a k 2 ) = f ⁡ ( a 1 2 ) + f ⁡ ( a 2 2 ) + ⋯ + f ⁡ ( a k 2 ) f(a_{1}^{2}+a_{2}^{2}+\dotsb+a_{k}^{2})=f(a_{1}^{2})+f(a_{2}^{2})+\dotsb+f(a_{k}^{2}) 
 
 
 for arbitrary positive integers  a i a_{i} , then  f f  is the identity function. 
 
 
 
 This is the first example that a  3 3 -additive uniqueness set is not a  2 2 -additive uniqueness set. 
 
 
 The proof is similar to that of the author’s generalization  [ 8 ]  of Bašić. But, since the  k k -additivity condition in Theorem 1 produces relations about  f ⁡ ( n 2 ) f(n^{2})  instead of  f ​ ( n ) 2 f(n)^{2} , the proof is more difficult. It is known that the numbers inexpressible as sums of  k k  positive squares are infinite when  k = 3 , 4 k=3,4  and are finite when  k ≥ 5 k\geq 5 . 
 
 
 We divide the proof into four sections: §2 for  k = 3 k=3 , §3 for  k = 4 k=4 , §4 for  k = 5 k=5 , and §5 for  k ≥ 6 k\geq 6 .
