# Artifact boundary

The packet is a research screen, not a manuscript or publication release. Files in `public/` are original exposition/code. Bodies in `private/upstream/` and `private/primary/` retain the upstream authors' and publishers' original rights; no relicensing or permission to republish those bodies is asserted. They are deliberately separate from the original public notes. No upload or outside communication occurred.

`manifest.json` records every payload file and every directory, excluding only itself. Its SHA256 is reported **outside** the packet. Run `public/verify.py` with `--root`, `--finalhash` and optionally `--tree` pointing to the complete canonical tree. The verifier requires the detached hash; there is no internal default anchor. With `--tree`, it hashes and checks all13,223 canonical entries before comparing the20 retained source entries. Without that option, it checks the retained canonical records and authenticated body blobs but does not independently open the external full tree.

The verifier reads only and prints a receipt. It checks exact membership, byte sizes, SHA256, symlinks/nonregular entries, duplicate JSON keys, source pin and raw-URL consistency, Git blob identities, primary PDF/text identities, and the screen-only disposition. It does not execute mathematical evidence, validate a proof, authenticate the remote Git commit cryptographically, or decide contribution. The detached hash and trusted interpreter/verifier must be obtained through a trusted channel. Concurrent filesystem mutation is outside the threat model.

`public/integrity_controls.py` is a separate **writing** control runner, never invoked by the read-only verifier. It requires an outer work directory beside the packet, copies only this small packet one case at a time, and deletes each disposable copy. It retains a receipt outside the packet. The12 cases cover pristine replay, wrong/missing external anchor, modified/missing/extra payloads, an extra empty directory, file/directory symlinks, changed manifest, changed verifier and a wrong external tree. Both pristine packet and tested copy are inventoried before/after each verifier invocation. These are bounded integrity controls, not mathematical or acceptance gates.

No Lean support, mathematical numerical tests, candidate formal package, or full manuscript was prepared. No author certification of substantiality is supplied.
