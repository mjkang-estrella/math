# A superquadratic sensitivity separation for transitive Boolean functions

Myeongjin Kang, no affiliation. All four independent internal review gates are adopted. This release package does not itself award campaign acceptance or perform publication; those are separate parent actions.

The full target remains: for every C>0 a nonconstant total Boolean function invariant under a group transitive on all raw input coordinates, with f(0)=0 and bs(f,0)>C s(f)^2 for ordinary all-input sensitivity; also one fixed alpha>2 and a sequence of such functions with bs(F_m,0)>=s(F_m)^alpha and diverging zero-input block sensitivity.

The pinned OpenAI source provides the nested-predicate construction, ordinary/joint sensitivity architecture, zero blocks, balancing and composition. The new compatible-label operation simultaneously supplies a constant head-pattern exclusion bound, an alphabet small relative to the square root of the row count, and full affine covariance on row-position pairs. The manuscript credits earlier Paley/cyclotomic symmetry and transitivity-preserving composition. Bounded primary comparison is not a worldwide priority claim.
