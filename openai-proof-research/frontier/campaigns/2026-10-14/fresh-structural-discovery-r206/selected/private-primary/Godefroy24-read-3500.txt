Non-linear geometry of Banach spaces as it was in 2000 is displayed in [3]. The book

    Our reference on approximation properties of Banach spaces is [8]. A Banach space
X has the approximation property (A.P.) if I d X belongs to the closure of the space of
finite rank operators for the topology τ K of uniform convergence on compact subsets
of X . The λ-bounded approximation property (in short, λ-B.A.P. or simply B.A.P.
when λ does not matter) means that I d X is in the τ K -closure of the set of finite rank
operators of norm at most λ. The 1-B.A.P. is called the metric approximation property
(M.A.P.). A separable Banach space X has the (commuting) bounded approximation
property if there exist a (commuting) sequence (Rn ) ⊂ L(X ) of finite rank operators
such that lim n x − Rn (x) = 0 for all x ∈ X . If I d X belongs to the τ K -closure of
the set of finite rank linear projections of norm at most λ, we say that X has the (πλ )-
property (or (π ) if λ does not matter). A separable space X has a finite-dimensional
decomposition (F.D.D.) if there exists a sequence (E k ) of finite dimensional subspaces
of X such that for every x ∈ X , there exists a unique sequence (xk ) such that xk ∈ E k
for all k and moreover

    If every E k is one dimensional, the F.D.D. is called a Schauder basis. It is shown
in [9] that a separable Banach space has an F.D.D. if and only if it has the commuting

the approximation property with a sequence of contractions.

 2 Lipschitz-free spaces nearly have the ()-property

 We recall that a pointed metric space M is a metric space equipped with a distinguished
 point called 0, and Li p0 (M) is the Banach space of Lipschitz functions on M which
 vanish at 0. The space F(M) is the closed linear span of the set of Dirac measures
 in Li p0 (M)∗ , and it is an isometric predual of Li p0 (M), hence F(M)∗ = Li p0 (M).
 The space F(M) is separable when M is separable. Let us recall some basic facts (see
 e.g. [23]): if M and N are pointed metric spaces and f : M → N is a Lipschitz map
 such that f (0) = 0, there exists a unique linear operator fˆ : F(M) → F(N ) such
 that fˆ ◦ δ M = δ N ◦ f , where δ denotes the Dirac maps. If 0 ∈ N ⊂ M and i : N → M
 is the canonical injection, then î : F(N ) → F(M) is an isometric embedding and
 thus we may identify F(N ) with a subspace of F(M). If X is a Banach space, the
 canonical inclusion i : X ∗ → Li p0 (X ) satisfies i = β X∗ , where β X : F(X ) → X is
 called the barycenter map. This map β X is a quotient map and if f : M → X is a
 Lipschitz map such that f (0) = 0, then f = β X ◦ fˆ : F(M) → X is a linear operator
 such that f ◦ δ M = f , whose norm is equal to the Lipschitz norm of f . Moreover, the
 map f → f is an isometric linear isomorphism between Li p0 (M, X ) and the space
 L(F(M), X ) of bounded linear operators from F(M) to X .
     Warning: In what follows, metric spaces are always pointed with a distinguished
 point 0, Lipschitz maps f always satisfy f (0) = 0, subsets always contain the dis-
 tinguished point, and the spaces Li p0 (M) are always equipped with the Lipschitz
 norm. Since the space F(M) is isometrically independent of the choice of the dis-
 tinguished point and since the corresponding restrictions are essentially formal, they
 will be ommitted for the sake of shortness, and for instance Li p0 (M) will simply be
 denoted Li p(M).

3 Lipschitz-free spaces with or without the ()-property

The following general result states what happens when good extension operators are
available.
Proposition 3.1 Let M be a metric space. If there exists λ ∈ R such that ae(S) ≤ λ
for every finite subset S ⊂ M, then F(M) has the (πλ )-property. If moreover M is
separable and F(M) has the commuting bounded approximation property, for instance
if F(M) has the metric approximation property, then F(M) has a finite-dimensional
decomposition.
Proof We proceed as in the proof of Proposition 2.1. For any finite subset S ⊂ M,
there exists a Lipschitz map g : M → F(S) extending δ S with g L ≤ λ, and then
g : F(M) → F(S) is a projection with g ≤ λ. Since the union of the subspaces
F(S) where S runs through the finite subsets of M is dense in the Banach space F(M),
the (πλ )-property follows for F(M). If moreover F(M) has the commuting B.A.P.
then by [9] F(M) has an F.D.D. By the main result of [10], any separable space with
M.A.P. has commuting B.A.P. This concludes the proof.
