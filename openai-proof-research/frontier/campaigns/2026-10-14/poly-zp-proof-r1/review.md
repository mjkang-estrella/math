## 2. Line-by-line audit of Lemma 1

Conventions: G = N ⋊_α Z_p with (n,λ)(n',λ') = (n·α_λ(n'), λ+λ'), and T = (1,1),
so T n T^-1 = α(n). G is a profinite group because the action map Z_p × N → N is
jointly continuous. This is what "continuous action" must mean (Optional O3).

1. **Index formula.** Let H be open in G. Its projection π(H) is open in Z_p, so
   π(H) = p^a Z_p for a unique a >= 0. Put V = H ∩ N, an open subgroup of N.
   Then [G:H] = [G:HN][HN:H] = p^a [N:V]. Checked.
2. **Necessity of (3).** V is normal in H because N is normal in G. Every
   x = gT^(p^a) in H therefore normalizes V, which gives
   g α^(p^a)(V) g^-1 = V. Checked.
3. **The fiber over p^a is one coset.** Let x ∈ H lie over p^a. Then
   H ∩ π^-1(p^a) = Vx = (Vg)T^(p^a). It is a right coset in the usual
   convention, although the candidate calls it a "left coset" (O1).
   Condition (3) depends only on the coset, since replacing g by vg conjugates
   by v ∈ V. Checked.
4. **Converse construction and the zero-kernel point.** Let C be the closed
   subgroup generated by x = gT^(p^a). It is procyclic pro-p, and π(C) is a
   closed subgroup of Z_p containing p^a and contained in p^a Z_p, so
   π(C) = p^a Z_p. An infinite procyclic pro-p group is Z_p. A continuous
   surjection Z_p → p^a Z_p ≅ Z_p has kernel 0 or p^k Z_p, and a nonzero
   kernel would give a finite image. Hence C ∩ N = 1.

   The normalizer N_G(V) is closed, because V is closed. It contains x, so it
   contains C. Therefore VC is a subgroup. It is compact as the image of V × C,
   hence closed. If vc ∈ N, then c ∈ N ∩ C = 1, so VC ∩ N = V. Also
   π(VC) = p^a Z_p, so [G:VC] = p^(a+b), and VC is open. The unique element of
   C over p^a is x, so the fiber of VC over p^a is exactly Vx.

   For injectivity, take H with data (V, Vx). Then H ⊇ VC, and the two groups
   have the same intersection with N and the same projection, so H = VC.
   The candidate's sentence "modulo V in the normalizer ... maps isomorphically"
   compresses this argument correctly. I recommend spelling out C ∩ N = 1 ⇒
   VC ∩ N = V (O2). There is no gap.
5. **Weights.** If g0 solves (3), the full solution set is N_N(V)·g0. That set is
   a union of [N_N(V):V] right V-cosets. The class of V has [N:N_N(V)] members,
   and each member has the same normalizer index. Each fixed class therefore
   contributes [N:N_N(V)][N_N(V):V] = p^b. Solutions exist iff α^(p^a)
   maps V into its own N-conjugacy class. This proves (2) exactly, as an
   identity between integers.
6. **p-power orbits and continuity.** N is finitely generated, so it has only
   finitely many continuous homomorphisms to Sym(p^b). The intersection O of
   their kernels is open and characteristic, and every core of an index-p^b
   subgroup contains O. The map λ ↦ (induced automorphism of N/O) is locally
   constant on Z_p, hence continuous. Its image is a finite quotient of Z_p,
   which is a cyclic p-group. Every orbit of α on S_b therefore has length
   p^e. Such an orbit is fixed pointwise by α^(p^a) iff e <= a. So
   k_b − f_b(p^a) is a sum of orbit lengths p^e with e >= a+1. Checked.
7. **Conclusion.** (4) − (2) = Σ_(a+b=h) p^b (k_b − f_b(p^a)). Every term has
   valuation at least b + a + 1 = h + 1. Checked for every p, including p = 2;
   no step uses p odd.

**Attack on the kernel class.** Lemma 1 uses only two facts: N is finitely
generated, so S_b is finite, and N is pro-p, so G is pro-p and its indices
are powers of p. Torsion, nonsolubility, infinite rank and non-normal V cause
no difficulty. My checks include non-normal V, torsion, and an infinite kernel
with torsion (Section 6).

## 3. Theorem A and the remaining claims

- **Splitting.** The argument matches the source's `lem:profinite-elementary`(ii)
  and is reproved in the candidate. The bijective continuous map
  K_i × C → K_(i-1) between compact Hausdorff spaces is a homeomorphism,
  so the semidirect decomposition is topological.
- **Iteration with direct factors.** E_i = K_i × Z_p^i and K_i = K_(i+1) ⋊ ⟨x_i⟩.
  This gives E_i ≅ (K_(i+1) × Z_p^i) ⋊ Z_p, where Z_p acts by conjugation by
  x_i on K_(i+1) and trivially on Z_p^i. The action is jointly continuous, being
  a restriction of conjugation. N = K_(i+1) × Z_p^i is finitely generated
  because K_(i+1) is poly-Z_p, by induction from K_t = 1. Lemma 1 gives
  a_h(E_i) ≡ a_h(E_(i+1)) mod p^(h+1), with the same modulus at every step.
  E_t = Z_p^t. Checked.
- **Lattice count and generating function.** By (4) with abelian N = Z_p^(t-1),
  k_b = A_b(t-1). With G_t(z) = Σ A_h(t) z^h, this gives
  G_t(z) = (1−z)^-1 G_(t−1)(pz), and therefore the product
  Π_(i<t)(1−p^i z)^-1. Checked. This step is credited to Tamanoi and to the
  source's `lem:lattice-limit`.
- **Tail.** The coefficient b_j of Π_(i=1)^(t-1)(1−p^i z)^-1 is a sum of
  p^(Σ i m_i) with Σ m_i = j, so p^j | b_j. Products of convergent p-adic
  series converge to the product of their sums, so Σ b_j = c_t, and the tail
  beyond h is divisible by p^(h+1). Checked. For t = 1, c_1 = 1 = A_h(1).
- **Open U.** U ∩ K_(i-1) is open in K_(i-1). Its image in K_(i-1)/K_i ≅ Z_p
  is compact, open and nonzero, hence isomorphic to Z_p. The kernel of that
  image is U ∩ K_i. So U has length exactly t. Checked.
- **Closed J.** Each factor image is a closed subgroup of Z_p, so it is 0 or
  ≅ Z_p. A zero image means J ∩ K_(i-1) = J ∩ K_i, so the repeated term can be
  deleted. If every image is zero, then J = 1. Checked.
- **(SC).** Fix a coset xW. The subgroups V of index p^h that fix it are the
  subgroups of xWx^-1 of index p^(h−m), and there are a_(h−m)(W) of them.
  There are p^m cosets, which proves (5). For h < m, the difference
  −p^m a_h(U) has m >= h+1. For h >= m, both counts are ≡ c_t, with moduli
  p^(h−m+1) and p^(h+1), so (6) is divisible by p^(h+1). Stabilizers are open
  and indices are powers of p, so any finite continuous U-set decomposes into
  transitive pieces. The empty set gives 0. Checked.
- **Limit and length.** c_(t+1) − c_t = c_t p^t/(1−p^t), which has valuation
  exactly t. For s > t the ultrametric minimum is attained uniquely at the first
  step, so v_p(c_s − c_t) = t. I checked this numerically for
  p ∈ {2,3,5,7}, 1 <= t < s <= 9. The limits also differ from the limit 0
  for J = 1, since c_t is a unit. Length uniqueness follows. Checked.
- **Allp2, empty X, h = 0, r = 0.** At p = 2, every 1 − 2^i is odd. At h = 0,
  a_0 = A_0 = 1 and c_t ≡ 1 mod p. Empty X and J = 1 are handled explicitly.
  All checked.

**Sharpness (R1, required wording).** Heisenberg: a_1 = p + 1 and
A_1(3) = 1 + p + p^2, so v_p(a_1 − A_1(3)) = 2 for every p. Correct. For
the c_t congruence, however,

a_1 − c_3 = (p^4 − 2p^2)/((1−p)(1−p^2)),

so v_p(a_1 − c_3) = 2 + v_p(2 − p^2). This equals 2 for odd p but **3 for
p = 2**: a_1 = 3 ≡ 1/3 = c_3 mod 8. At p = 2 the Heisenberg example therefore
satisfies the c_t congruence modulo p^(h+2) at h = 1. My checker confirms this
(`heisenberg_h1_sharpness`).

The sentence in Theorem A is true if "(A) with h+2" means the conjunction,
or the A_h(t) line. Read separately for the c_t line, it is false at p = 2.
The fix is easy, and it is stronger than the current statement: Z_p^2 has
A_h(2) − c_2 = −p^(h+1)/(1−p), with valuation exactly h+1 for **every** h
and p. That is checked in closed form for p <= 11 and h < 12. So the c_t
congruence is sharp at every h through an abelian example, and the Heisenberg
group is needed only for the A_h(t) congruence.

Required change: state which congruence each example witnesses. Optionally,
add that the A_h(t) congruence is an equality for abelian groups, which is why
a nonabelian witness is needed.

## 5. Finite/profinite bridge and the candidate's checker

**Principle.** A coset action of a pro-p group of degree p^h has image a finite
p-group in Sym(p^h). Its elements have order at most p^h, the largest p-power
cycle length. Let M be a closed normal subgroup generated by p^B-th powers.
Then M lies in the core of every subgroup of index p^h when h <= B, so the
open subgroups of index p^h in E correspond bijectively to the subgroups of
index p^h in E/M. Section 5 of the candidate states this correctly.

- **Finite-kernel tests (C2^2 shear, C4 inversion, D8 order 4).** The
  quotient is by ⟨T^(p^L)⟩. That subgroup is central because the checker
  asserts α^(p^L) = id, and it consists of p^L-th powers. The tested range is
  h <= L. Valid.
- **Heisenberg mod p^L.** The coordinate kernel is normal and consists of
  products of p^L-th powers: (p^L a, p^L b, p^L c') =
  X^(p^L a) Y^(p^L b) Z^(p^L(c' − p^L ab)). Valid for h <= L.

  Caution (O5): at p = 2 this kernel is **not** the verbal subgroup E^(2^L)
  and is not stable under every automorphism. For example,
  (XY)^4 = (4, 4, 10) ≡ (0, 0, 2) mod 4, so X ↦ X, Y ↦ XY does not preserve
  it. The candidate applies no automorphism to a Heisenberg kernel, so its
  check is unaffected. My checker records this negative fact and uses
  E^4 = {x, y ≡ 0 mod 4, z ≡ 0 mod 2} instead.
- **Z2^2 ⋊ diag(3,1) mod 4, with T^4.** M = (4Z_2)^2·⟨T^4⟩ is normal because
  3^4 ≡ 1 mod 16, and it is generated by 4th powers. Valid for h <= 2. The map
  λ ↦ 3^λ is continuous on Z_2 because Z_2^× is pro-2.
- **Fixed-coset and residue checks.** The depth bounds keep every index
  inside the bridge. The abelian residues use exact modular inverses. The
  mutation tests reject what they claim to reject.

**Coverage limits (not errors).** The candidate's checks use only p ∈ {2,3},
h <= 3, no torsion-free kernel with non-normal V, no c_t check on nonabelian
groups, and no residue checks on proper open U. My independent checks cover
these gaps. As the candidate itself says, the finite checks prove nothing
universal.

## 6. Independent adversarial checks (`checks/adversarial.py`)

The checker shares no code with the candidate's `checks.py`. It enumerates
subgroups by **maximal-subgroup descent through Frattini quotients**: Φ is
computed as the normal closure of p-th powers and commutators of a generating
set, and maximal subgroups are hyperplane preimages. The candidate instead
grows subgroups by adding generators. The receipt is `checks/adversarial.json`
(SHA256 `23b56c28a90b2270be4f13f9003fde696d303bd64b55e1d139566eb93e32d8be`).
A run takes about 11 s.

1. **Lemma 1, every p-power-order automorphism** of five kernels: D16 (32
   automorphisms), C4⋊C4 (32), Q8 (16), Heis(F_3) (81) and C9⋊C3 (27). That
   is 188 cases, with h <= 3 at p = 2 and h <= 2 at p = 3. In each case:
   - the actual descent count equals formula (2), using N-classes and
     α^(p^a);
   - the direct product equals (4);
   - the difference is divisible by p^(h+1);
   - all 1448 instances of k_b − f_b(p^a) ≡ 0 mod p^(a+1) hold.

   For 9077 subgroups, the coset parametrization was checked directly: the
   projection is p^a, V = H ∩ N, the fiber is one V-coset Vg,
   g α^(p^a)(V) g^-1 = V, the map H ↦ (a, V, Vg) is injective, and the
   admissible pairs number Σ[N_N(V):V], counted by brute force over g.

   Classes moved by α: 16/32, 24/32, 12/16, 72/81 and 18/27. Non-normal
   subgroups are present in four of the five kernels. The D16 cases are also
   exact quotients of the infinite pro-2 dihedral kernel Z_2 ⋊ C_2, because
   every automorphism of D16 lifts and 8Z_2 consists of 8th powers.
2. **p = 5**: three shears of C5^2, with h <= 2. **Infinite torsion kernels**:
   Z_p × C_p with α(x,c) = (x, c + x mod p), for p = 2 (h <= 3) and p = 3
   (h <= 2). All pass. The Lemma 1 difference has valuation exactly h+1 at
   h = 1, so p^(h+1) is attained even for Lemma 1.
3. **Theorem A on torsion-free poly-Z_p quotients** (seven groups):
   - Z_2^2 ⋊ {swap, [[−1,1],[0,1]], diag(3,1)}, mod 8, bridge 3;
   - Z_3^2 ⋊ [[4,1],[3,1]] (non-unipotent, α of order 9 mod 9), bridge 2;
   - Heis(Z_2) ⋊ {X ↦ X, Y ↦ XY} and ⋊ {X ↔ Y}, length 4, bridge 2,
     modulo the characteristic subgroup E^4;
   - Z_2^3 ⋊ J_3, length 4, bridge 2.

   Each group satisfies (2), a_h ≡ A_h(t), and a_h ≡ c_t mod p^(h+1). There
   are also 104 checks of a_j(U) ≡ c_t and ≡ A_j(t) on every proper open U
   inside the bridge range, including non-normal U, and 3704 transitive (SC)
   checks. The fixed-point test uses V ⊆ xWx^-1 directly, not identity (5).
4. **Sharpness table** for p = 2, 3, 5, 7: v_p(a_1 − A_1(3)) = 2 in every
   case, and v_p(a_1 − c_3) = 3, 2, 2, 2. This supports R1. Z_p^2 gives the
   exact valuation h+1 for the c_t congruence.
5. **Bridge-necessity control.** For D16 ⋊ C_2 (truncation L = 1), the finite
   counts at h = 2, 3 are 5 and 9, while the profinite formula (2) gives 11
   and 27. This shows that the zero-kernel/procyclic step and the condition
   h <= L are both essential, and that finite truncations are not proofs.
6. **Mutations rejected:** using α^(p^(a+1)) (267 rejections), counting
   α-fixed actual subgroups instead of classes (188), the modulus p^(h+2) in
   Lemma 1 (259), and the modulus p^(h+2) for c_t (13).

These are finite diagnostics within the bridge range only. They do not
replace the proof audit above.

## 7. Literature lead: Frankel's dissertation (relevant; required to add for the contribution package)

(supervisor T. Chinburg). The PDF is 37 pages, 266205 bytes, SHA256

with server filename `Frankel_upenngdas_0175C_12183.pdf` (see
`retrieval-literature.json`). I read Chapter 4
completely (printed pp. 23–29) and the abstract and introduction (pp. v and 5).

- **Theorem 13 / Proposition 17.** For every topologically finitely generated
  profinite Γ, every semidirect product Γ ⋊ Z_p, and every finite G,
  v_p(#Hom(Γ ⋊ Z_p, G)/|G|) >= 0. The proof decomposes Hom(Γ ⋊ Z_p, G) over
  G-orbits of restrictions φ, counts the extensions g in a coset C_φ g_φ of
  the centralizer, restricts to p-power-order elements, and uses a
  Frobenius-type lemma (Lemma 16) for p-divisibility.
- **Lemma 18 / Proposition 19.** The converse: integrality implies a Ẑ_S
  quotient, and every surjection onto Ẑ_S has a closed section.

**Relevance.** This is a direct *profinite* antecedent of three things:

1. the splitting fact;
2. the source's first-quotient step (hom-integrality ⇒ Z_p quotient, with
   S = all primes ≠ p, so S^-1 Z = Z_(p));
3. the general mechanism of counting extensions over a semidirect product
   with Z_p, with an arbitrary continuous action, by cosets of a
   normalizer/centralizer.

It does **not** count subgroups. It does not compare an action with the
trivial action, does not work at precision p^(h+1), and does not identify
poly-Z_p residues. It therefore does not affect the proof verdict.

It does strengthen the contribution objection. A profinite version of the
GRV torsor count for Γ ⋊ Z_p predates the candidate (2016), and the
candidate's `literature.md` cites only discrete GRV. **Required for the
literature/contribution package (not the proof):** cite Frankel 2016,
Chapter 4, and pass it to the contribution review. I make no judgment on
substantiality.

## 8. Findings summary

**Required (editorial or dependency; no mathematical gap):**

  A_h(t) congruence at h = 1 for every p. It does **not** witness sharpness of
  the c_t congruence at p = 2, where a_1 = 3 ≡ c_3 mod 8. Use Z_p^2, which has
  exact valuation h+1 at every h, for the c_t congruence.
- **R2.** Theorem B's dependency statement must include
  `lem:profinite-elementary`(i), or reprove it. "Precisely two lemmas" is
  inaccurate.
- **R3 (literature package only).** Add Frankel 2016, Chapter 4, as a profinite
  GRV antecedent and forward it to the contribution review.

**Optional:**

- **O1.** The coset Vg is a *right* coset in the usual convention.
- **O2.** Spell out C ∩ N = 1 ⇒ VC ∩ N = V, and closedness of N_G(V), in Lemma 1.
- **O3.** State that "continuous action" means joint continuity of
  Z_p × N → N, which is what makes N ⋊ Z_p a profinite group.
- **O4.** Note that the Lemma 1 modulus p^(h+1) is itself attained (for
  example, C5^2 shear at h = 1).
- **O5.** Record the p = 2 caveat: the Heisenberg coordinate kernel is not
  stable under all automorphisms, which matters for any future checks.
- **O6.** Note that the t in Theorem B(3) equals the length in (1).

**Counterexamples found:** none.

**Contribution:** not assessed here. It remains unresolved and is separately
assigned. The broad quantifiers of Theorem A are fully supported by the proof,
but supported breadth is not, by itself, evidence of substantiality.
