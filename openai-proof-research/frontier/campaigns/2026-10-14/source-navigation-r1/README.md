# Source-family navigation, not an eligibility audit

This map covers the372 catalogue families and2819 tracked public frontier Markdown documents at commit777bcb46. It matches canonical manuscript-folder tokens ending in a year and the expressions `family/source/families` followed by a three-digit number. Input copies, private bodies, temporary/rebuild copies and source-cache directories are excluded. The catalogue hash and pin are recorded in lexical-map.json.

The first direct all-family/all-document scan completed successfully but was slow; a single-pass number/folder-token scan then produced the retained navigation map. A termination attempt after the first process had already finished had no effect. No process remains running from this screen.

**Low or zero matches do not establish freshness.** Known false-low examples include families152,186 and366, with prior work described using other terminology. Spelling, abbreviated citations, generic operation names, untracked live work and filtered copies can hide relevant history. Positive matches can be incidental. This is not a classification of developed versus undeveloped families, a literature search or an absence certificate.

The three live Astra discovery agents received subject-relevant low-hit leads with the explicit requirement to search concepts and operations and read actual earlier reports before acquiring or nominating a target. The purpose is to reduce repeated catalogue screens. No theorem, proof, contribution gate or count change follows from the map.
