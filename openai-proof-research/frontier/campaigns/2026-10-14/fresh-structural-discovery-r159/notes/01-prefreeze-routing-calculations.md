# Prefreeze feasibility: prescribed branch vertices in a biclique

No theorem is frozen. The graph-rigidity screen yielded no matching pinned family; the second and final family is graph immersion. Neither screen found a matching pinned source. Generic lexical matches were geometric rather than graph-theoretic and were not developed. Thus there is no pinned theorem/operative proof premise in the following elementary calculations, and the required pinned-source development gate has NOT been met. No extended author-proof nominee will be drafted on that basis.

Let the host be K_{a,b}, with prescribed branch sets X,Y of sizes x,y, t=x+y. Put p=a-x and q=b-y for nonbranch counts. A strong clique immersion must avoid X union Y internally. Every branch-to-branch host edge can only occur as its own one-edge demand path. Therefore all cross demands may WLOG use the direct edges: replace a longer path by its unused direct edge, releasing its other edges. This is compatible with the entire immersion, unlike a naive independent same-side calculation.

The remaining demands are cliques on X and Y. Length-two paths are proper edge colorings of K_x by q right nonbranches and K_y by p left nonbranches. The familiar bound uses chi'(K_n)=n-1 for even n, n for odd n>1. Primary DDFMMS11 Lemma2.1 already supplies this exact matching/splitting operation. DY15 explicitly credits the unrooted K_{t-1,t-1} strong K_t, and Lemmas5–6 supply list/common-neighbor and multipartite extensions. No unrooted improvement is a nominee.

In the degree-tight host a=b=t-1 and x,y>0, we have p=y-1,q=x-1. Both x,y even is immediate by one-factorization. If x odd and y even>=2, use a near-one-factorization of K_x in x colors. Delete one color class, a matching of size (x-1)/2. Assign the other x-1 color classes to the right nonbranches. Their unmatched vertices run bijectively through all X except the unmatched vertex of the deleted class. For each deleted pair, its two unused terminal-to-nonbranch edges can be joined through one left nonbranch, giving a length-four path. This uses every incident core edge of that helper exactly once. The even Y side uses length-two paths and no core edge. This pays that parity repair by a classical factorization plus one extra hub.

If x odd>1,y=1, there is no left nonbranch. The remaining graph is K_{x,x-1}; every right nonbranch can pair at most (x-1)/2 terminal stubs, insufficient to serve all x(x-1)/2 demands. Thus branch degrees alone do not characterize prescribed strong immersion. This is an elementary parity cut, not substantial evidence.

If x,y both odd, repairing each side through a single opposite helper conflicts at one core edge. That PARTICULAR construction failure is not an unpaid theorem operation by itself. Need strongest integrated routing, not two separately inconsistent hub repairs. Every terminal-to-core edge is used in the degree-tight case; at a core vertex the odd number of terminal stubs forces odd used degree in the bipartite core K_{p,q}. If p=2, each right core vertex has odd core degree<=2, so degree1. No core component joins both left core vertices. Each left vertex has an odd number y of Y stubs; they cannot all pair internally, and any departing path ends among X stubs. Cross demands have already been shortened to direct edges. This is impossible. Symmetrically q=2 is impossible. For p,q>=4 even, investigate a joint core routing of same-side pairs of residual stubs. This is still prefreeze and not a novelty claim.
