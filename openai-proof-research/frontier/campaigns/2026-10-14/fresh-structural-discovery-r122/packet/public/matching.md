## Zero-error expectation is a compatible classical reduction

The strongest classical verifier was checked rather than assuming that finding a matching certifies maximal cardinality. In [Vazirani2012.03582v1](https://arxiv.org/pdf/2012.03582v1), Sections3–4 initialize a phase from the unmatched vertices of the **current matching**. Section4's phase finds a maximal set of vertex-disjoint shortest augmenting paths, or exhausts the search when there is none. Lemma8.5 proves the maximal-family assertion. Theorem8.6's actual proof charges a constant number of scans per edge per phase; the bud-star union structure costs O(m alpha(m,n)) on the pointer model, or O(m) on RAM. Vertex initialization/isolates add O(n). The phase interface is not restricted to an empty current matching; emptiness only initializes the full multistage algorithm.

A prefreeze transfer is therefore immediate at the exact interface. Run the source algorithm with fresh independent random bits. Check that its proposed output is a matching in the input graph. If malformed, discard it. If valid, perform one classical phase: accept it only when there is no augmenting path. Berge's criterion then certifies maximal cardinality; an augmentable output is discarded. Every successful source run is accepted, so the conditional chance of stopping in each new trial is at least2/3. The probability of more than j trials is at most(1/3)^j, the expected number of trials is at most3/2, and termination is almost sure. The expected total cost remains almost-linear. No false optimum is returned.

This does **not** preserve a deterministic work cap on every random tape. It gives expected time and zero error by a classical verifier/restart operation. For f-factor decision, run this construction on the actual source gadget: a verified maximum matching determines whether the gadget has a perfect matching, and the source decoder supplies the factor when it does. This uses the stronger actual reduction and detects genuine NO cases; merely checking a returned factor would not validate NO.

The per-phase argument and the geometric calculation leave no identified compatibility issue for this transfer. It is not nominated, and the round assigns no contribution rating or correctness gate. The entire MV structural proof chain was not independently re-proved: the phase definitions and final correctness/time proof interfaces were read, with intermediate blossom lemmas used as credited classical results.
