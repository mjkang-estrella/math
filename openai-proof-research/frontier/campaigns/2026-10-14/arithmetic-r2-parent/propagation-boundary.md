# Least-totient-preimage propagation: parent boundary check

Myeongjin Kang; no affiliation. Original prose CC BY 4.0. Supporting
observation, not an accepted result or a proof of unbounded least preimages.

The pinned family024 companion's full-fiber propagation lemma supplies,
for each fixed seed totient d, values v=d phi(b) with

    phi^{-1}(v) = {b d_i : phi(d_i)=d}.

It follows exactly that ell(v)/v = [b/phi(b)] ell(d)/d. The source gives
no lower bound greater than one for the factor that is uniform in d.
Thus iterating its existential statement does not prove unbounded ratios.
Even strict multiplicative improvement at every stage is insufficient:
the abstract product of factors 1+2^{-j} is bounded, since its logarithm
is at most sum 2^{-j}. This example is a logical warning about inference,
not an assertion about the actual attainable arithmetic factors.

There is also a necessary restriction on every propagation multiplier.
For positive integers u,b, prime-by-prime evaluation of Euler's function
gives, with g=gcd(u,b),

    phi(ub) = phi(u) phi(b) g/phi(g).

For a shared prime p, the ratio is p/(p-1); for an unshared prime it is
one, proving the formula including prime powers. Therefore the equality
phi(b d_i)=d phi(b) forces g/phi(g)=1, equivalently gcd(b,d_i)=1,
for EVERY original preimage d_i. A multiplier cannot simply reuse a
small prime that divides any existing preimage. This is not a global
impossibility theorem for support forcing or for unbounded ell(d)/d.

The current arithmetic agent was sent both observations. Its actual new
work must exclude alternate inverse supports or establish controlled new
multiplier support; mere positive-density propagation and a growing b
do not pay that operation. The source's ratio-tightness lemma is compatible
with unbounded ratios on an exceptional set, so it does not refute the target.
