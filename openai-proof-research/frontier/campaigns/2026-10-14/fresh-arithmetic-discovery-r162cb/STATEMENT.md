# R162CB — frozen author statement

There is an integer s_0 >= 7 such that, for every prime s >= s_0 with s congruent to 2 modulo 3, there is an integer n_0(s) >= 3 such that the following holds for every odd integer n >= n_0(s).

Put q=s^n and r=q+1. There exists a finite simple hypergraph H with a partition of its vertex set into r pairwise disjoint parts V_1,...,V_r such that:

1. Every edge contains exactly one vertex from each part.
2. Each part has exactly r vertices, and every vertex belongs to an edge.
3. Every two distinct edges e,f satisfy 1 <= |e intersection f| <= 2.
4. The minimum cardinality tau(H) of a vertex set meeting every edge is exactly r.

The constants and thresholds are existential. The theorem makes no algorithmic, effective-threshold, fractional-cover, matching-polytope, all-rank, or linear-hypergraph assertion.
