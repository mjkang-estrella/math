# Rights and archive selection

Author: Myeongjin Kang, no affiliation. Original prose is CC BY 4.0; original
Python and Lean code is MIT. License texts are included in the manuscript and
formal directories. Third-party works and dependencies retain their own rights.

The explicit selection contains original paper/code and original audit reports,
not publisher PDFs, fetched manuscript bodies, web extracts, the pinned upstream
paper, mathlib sources or dependency objects. Historical `.olean` files belonging
to this project's own formal sources are retained as audit evidence; fresh
reproduction ignores them. Input manifests identify external reading materials
by hash and reference only. A reference does not grant redistribution rights.

`payload-selection.json` fixes the pre-gate payload. The actual final gate adds
only named independent revision evidence. No recursive workspace packaging is
used. Local Zenodo/MathDB metadata are unsubmitted drafts; no account credentials,
public URL, DOI or external endorsement is claimed.
