# One integral mapping-class orbit in every rank

Myeongjin Kang; no affiliation. Original article source and prose: CC BY4. Original build script: MIT.

Theorem1.1: for every g≥2 and r≥2, one actual representation π1(Σ_g)→SL_r(O_L) over a number field has a Zariski-dense orientation-preserving mapping-class orbit in the entire complex SL_r character variety. Rank2 is credited to Coccia–Litt; the higher-rank construction is presented as new to this project, without worldwide priority claim.

Build this directory, including its sections/, from any copied location:

    python3 -B build.py --tectonic /path/to/tectonic --output /absolute/NEW/output-directory

The output must be new and outside the copied source directory. Tectonic0.17.0 was used. The command uses --only-cached and --untrusted, so the required TeX bundle must already be cached; it does not download missing packages. The receipt pins source hashes, engine version, epoch, output hash and warnings. The TeX bundle is a trusted build dependency, not supplied here. SOURCE_DATE_EPOCH=1792281600 and TZ=UTC produce the recorded PDF on the verified toolchain. No third-party paper bodies belong in this public directory.

Article source: article.tex, references.tex, sections/01-context.tex through08-scope.tex. The final PDF is in the surrounding manuscript packet's output/pdf/article.pdf. Scoped formal support is external to this directory; AppendixA.1 and the packet's proof-scope.md describe its strict limits. This source bundle alone does not include a full formal proof or an acceptance decision.
