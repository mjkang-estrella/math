# Reproduction and limits

From the preparation directory run `python3 -B verify_preparation.py` and `python3 -B release_checks.py`. The latter creates disposable /var/tmp copies only and verifies rejection reasons. It creates no ZIP and runs no compiler. The current preparatory anchor must separately come from the parent/external message; self-computed hashes are not an external trust source.

After parent adoption of manuscript-v2 and the actual final manuscript-r2 review, use `python3 -B assemble.py --gate /path/FINAL-GATE.json --gate-sha256 EXTERNAL_GATE_HASH --output /path/NEW.zip`. Then use `python3 -B verify_bundle.py /path/NEW.zip --manifest-sha256 EXTERNAL_MANIFEST_HASH --gate-sha256 EXTERNAL_GATE_HASH`, and repeat against a clean extraction. These future steps are guarded and have not been performed. Exact membership, directory membership, duplicate JSON keys, unsafe paths, hashes, symlinks, hardlinks and nonregular nodes are checked; hashes do not establish theorem validity.
