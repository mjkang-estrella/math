## 2. Candidate plumbing and the exact finite obstruction

Fix q>=3. Use plumbing types (s,c,k) with 1<=s<q, 1<=c<=q, 1<=k<=5. A type has two ports, each colored c; its plumbing generator has height s. Nine extra generators have height zero. On a bottom punctured torus put two dyadic branches. Each branch is a comb with exactly q terminal tips, once in each color in the order 1,...,q. Install every ordered choice of distinct ports with two of each color, placing one in each branch; use every independent source conjugator and sign choice. This is finite for each q.

For a cyclic cover of degree d>=q the plumbing graph has vertices Z/d and an edge (v,s,c,k) from v to v+s. It is loopless, even if some underlying undirected pairs occur twice. Ports at a vertex are distinct incident edges. Suppose its endpoint assignment avoids every set containing two edges of each color. At every vertex v there is a color c for which v receives at most one c edge. Let D(v) be ALL such deficient colors. If vertices u,v differ by s in 1,...,q-1, five parallel edges of each color join them; a shared deficient color would allow at most two of those five edges to be assigned. Therefore D(u) and D(v) are disjoint. Every q consecutive vertices are a clique. There are q nonempty pairwise disjoint subsets D(v) of a q-element set in such a clique, so they are singletons exhausting the colors. Overlapping cliques imply D(v+q)=D(v). Combined with d-periodicity, the color sequence has period gcd(d,q). Injectivity on each block of q forces gcd(d,q)=q, i.e. q divides d.

Conversely, if q divides d, color v by v mod q. Across an edge of height s, endpoint colors differ. Assign each edge to an endpoint whose vertex color differs from its edge color, which is always possible. Each vertex then receives zero edges of its own color, so it receives no complete law. This proves an exact assignment spectrum, not just a counting obstruction. Its realization as marked chamber fillings remains to be supplied in the full proof.
