# Reproduction

Use this lane as working directory. All Python/helper operations run through the absolute helper_guard.py bound in run.sh with OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1. That guard fixes helper address space and process-group RSS at 512MiB, CPU210s and wall230s. No limit is raised for helper work.

`sh run.sh` serially compiles 24 mathematical modules then runs StandaloneAudit.lean. Its per-invocation runner checks compiler SHA256 e8baaa71855a616dc351028f3ad2200051b0671f423a1696a100e809302d5550 and uses the specifically authorized Lean exception: -j1 -M2700, group RSS2800MiB, CPU210s, wall230s, warningAsError=true and autoImplicit=false. Package search paths come only from the pinned 2026-10-14 formal package tree. pins.json records all nine revisions, including mathlib d13f23b723b8a846827a245b89c10fc7d3f11612. Revision checks read pin metadata without git commands.

Using the same guard prefix, run `python certify.py pack`, `python certify.py replay`, `python certify.py manifest`, then a SEPARATE invocation `python certify.py verify`. The pack command checks originals/copies, all 23 inherited module bytes, pins, and the completed audit. It creates a deterministic zip with fixed timestamps, explicit file modes and a source hash inventory. No compiled object is archived. Replay extracts to a new empty replay/fresh directory and compiles only its extracted source serially, then repeats the audit and compares all declaration inventories/axioms. It removes compiled objects after success. Manifest excludes itself and verification-receipt.json. Final verification independently rehashes every manifest member, every frozen original/copy, all nine pins, the archive and replay audit, and checks absence of compiled objects.

StandaloneAudit uses Lean module-origin Names, including private/generated declarations, and traverses every owned type and opaque body transitively. It hard-fails unsafe OR partial declarations at origins and dependencies and allows only propext, Classical.choice, Quot.sound as axioms. It audits all 24 mathematical modules. Audit instrumentation is a separate safe executable, not a premise of any theorem.

All local compiler failures and their exact input snapshots and resource receipts remain in attempt-* files. Frozen earlier failures/receipts remain historical evidence. No failed operation is treated as successful verification. The first run's audit is intentionally separate from the fresh extracted replay audit. Root's independent replay and acceptance review remain outstanding even after worker receipts PASS.
