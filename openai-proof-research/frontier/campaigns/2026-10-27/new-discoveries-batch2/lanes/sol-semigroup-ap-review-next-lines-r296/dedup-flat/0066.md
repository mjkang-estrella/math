## Ranked survivors

1. **Exact finite sequence-covering existence.** Gentle–Horsley–Wanless, [2411.17145v1](https://arxiv.org/pdf/2411.17145v1), pp1–3, Theorems1–2 and the excess-coverage argument: does an SCA(7!;7,9) exist? A set of5040 permutations of9 symbols must cover every ordered7-tuple exactly once as a subsequence. Theorem1 only excludes v>=10; its CAX(42;2,5,6) uniqueness theorem does NOT exclude v9, whose derived array has4 columns. Levenshtein's original universal claim already has a known t4,v6 exception; do not nominate that universal wording. **Mechanism:** exact cover followed by a small combinatorial obstruction or a complete checkable construction. **Decisive calculation:** the literal system has362880 binary variables and181440 exact-one equations,36 ones per column, requiring5040 selected permutations. Relabeling permits fixing identity. A derived CAX(42;2,4,6) has each symbol7 times in every column, each same-symbol ordered pair twice and each unequal pair once. An obstruction must also enforce the stronger sequence-lifting constraints; bare CAX feasibility is insufficient. **Closest classical construction:** Gentle [2209.15234v1](https://arxiv.org/pdf/2209.15234v1), Theorem1.1 pp2–3 bounds minimum multiplicity polynomially; it does not construct multiplicity1 at(9,7). **Objection:** a huge solver run is not a proof mechanism under these caps, and the four-column necessary conditions may be far too weak. No SAT run claimed. No identifier/Levenshtein/covering alias hit in the1596 bound history references. Current exact-title search returned no later sequence-covering paper; mixed keyword search was noisy. Bounded, not complete, clearance.

2. **Coprime BHR, support-three survivor.** Ağırseven–Ollis, [2412.05750v2](https://arxiv.org/pdf/2412.05750v2), Conjecture1.3 p2: for v>=1 and a multiset L of size v-1, entries in1..floor(v/2), all coprime to v, there is a Hamiltonian path on Z/v with precisely those CYCLIC edge lengths. The focused survivor is its entire support-three subcase, not a new arbitrary fixed support. **Closest actual theorem:** Theorem3.6 p16 gives thresholds f(x,y) in the three unit-normalized supports; it does not cover all multiplicities. Later [2502.00164v1](https://arxiv.org/pdf/2502.00164v1), Theorems1.4–1.9 and core constructions in Section3, improves y-k supports, especially k<=2, but retains the general question. **Mechanism:** splice the source's core perfect two-length realizations with grid paths while keeping endpoint states, rather than attempting unqualified greedy insertion. **Decisive calculation:** v97,support{1,10,13} has equivalent normalized supports{1,11,29},{1,15,44}; Theorem3.6 thresholds are21,39,58. Exactly210 positive exponent triples a+b+c=96 remain below all three thresholds. This only falsifies the threshold-only shortcut, not other source constructions. A universal connector lemma must handle those residual regions uniformly in v,x,y. **Objection:** source already makes this reduction; finite leftover instances or one support are not a full conjecture resolution. [2507.00059v4](https://arxiv.org/pdf/2507.00059v4), Sections2–3 actual code/methodology, gives bounded searches and heuristics, not a universal inductive proof. Its reported counts were not independently replayed and are not imported as certified truth. No BHR/Buratti/identifier hit in bounded history. Current keyword query returns the above later bodies; no proof-absence claim.

3. **Rainbow arborescence.** Bérczi–Király–Yamaguchi–Yokoi, [2412.15457v2](https://arxiv.org/pdf/2412.15457v2), Conjecture1.1 p1: n-1 arc-disjoint spanning out-arborescences on the SAME n vertices (parallel arcs of different colors allowed) admit a spanning arborescence using exactly one arc of each color. Roots are unrestricted. **Closest actual results:** Section4 proves path/star inputs, at most two multi-roots, common-tree orientations and the underlying-cycle case (Theorems4.3–4.9); Section5 supplies the cycle proof. The interval symmetric-difference corollary is therefore already solved, not a new target. **Mechanism:** contract maximal rainbow branchings and track root/color obstructions; seek an augmentation lemma that chooses the root dynamically. **Decisive reduction:** the first source-computationally-unchecked order is9, with8 input roots; any unresolved root multiset has at least three multi-roots. Its multiplicity partitions are(4,2,2),(3,3,2),(3,2,2,1),(2,2,2,2),(2,2,2,1,1). This is a search reduction only. **Objection:** prescribed-root existence is NP-complete even with two input roots (Theorem2.1); a fixed-root exchange proof is unjustified. The cycle proof is already nontrivial and does not cover arbitrary underlying graphs. No exact identifier/arborescence history hit. Current title query found companion [2511.04953v2](https://arxiv.org/pdf/2511.04953v2), but its PDF returned404; parked without retry. Main v2 explicitly states and proves the same cycle endpoint, so no main-conjecture solution was inferred from that metadata.
