    We introduce a variant of k in a row: On a given board, each of play-
ers claims a position in turns until there is a k in a row among all claimed
positions. The difference to the original k in a row is that, in this variant, a
player no longer needs to claim a full k in a row by themself to win the game;
instead, claiming the last remaining position of a k in a row is sufficient.

    We are curious about how long a game can last, or, equivalently, how
dense a final board configuration can be. Likewise, we concern how sparse a
configuration can be. We ask the same questions for various boards, say the
infinite plane board and the hypercubes [k]d for every d ∈ N. To answer it,
we give bounds on the maximum and minimum densities configurations.

1.1     Monochromatic k in a row


1.1.1    Five in a Row


      Five in a Row, also called “Gomoku”, is a strategy board game played on a 15 × 15
grid board (or a 19 × 19 go board). Two players take turns claiming positions by placing
a stone of their color on the board. The winner is the first player to form a consecutive
line of length five or more of their color. Once the board is completely filled and no one
could claim winning, the game ends in a draw. In different settings, it is possible to require
the length of this line to be exactly five, six or more is not allowed. In here, we always
allow a longer line. Monochromatic Five in a Row is as the same as the original Five in
a Row, but all players are using stones of the same color, which means that one can claim
a win if their last move forms a line of length five or more on the board. A significant
difference to the original game is that this variant never draws. Given k, t, d ∈ N and
{ℓi }di=1 ⊆ N, an obvious generalization can be obtained: There are t players claiming,
                                                                  Q
in turns, an unclaimed position from a d-dimensional gird board di=1 [ℓi ]. The game
continues until a player wins or the board is filled. A player wins if there is a k in a row
among all claimed positions after their latest claiming. At the end of the game, if no player
wins, the board must be filled, then the game is a draw. (It happens when the board is too
small to have a k in a row.) We call this game a t-player monochromatic k in a row played
             Q
on the board di=1 [ℓi ]. In this thesis, the winning strategy and the extreme density of stones
on the board of 2-player monochromatic variant will be discussed.

1.1.3      Infinite Plane Board

       If we play the monochromatic k in a row on the infinite plane grid board instead.
What can we say? Compare to the normal k in a row on infinite plane board Z2 . When
k = 8 or 9, we can find a pairing strategy for the second player, hence it is a draw (see p.
159-161 in [1]), while it is unknown when k = 6 or 7.

       However, the result for the monochromatic ones is worlds apart. Note that you can
always claim a position at least 2k far from every claimed position, and another player
cannot force you to drop this strategy unless creating a win for you. Therefore, it is a trivial
draw for the monochromatic game played on infinite board. The statement holds for all

1.1.4    Biased Game

     The biased monochromatic k in a row involves two parameters p, q ∈ N. It is the
same as the monochromatic k in a row, except the first player claims p positions per
move, and the second player claims q positions per move, respectively. Denote it the
biased (p : q) monochromatic k in a row. The weak biased (p : q) game can be defined
in a similar manner, by allowing players to claim lesser positions but forbidding skipping
(claiming no position). First, if p ≥ k, then the first player wins without doubt. Similarly,
if p < k ≤ q, then the second player wins. Now we assume that both of p and q are
strictly lesser than k. Suppose p > q, the weak (p : q) k-game is a first player win.
The following is a possible winning strategy for the first player: (1) Track the minimum
number of positions needed to form a k in a row based on current board state, call this
number N . (2) When it is the first player’s turn, if N ≤ p, then the first player can claim
N positions to win; otherwise, they claims a position that decreases N by one. If the
second player wins under this scenario, let S be the board state just before the second
player claims their last move. On S, by the definition, the latest move of the first player
is a single position x such that N (S) = N (S\{x}) − 1. As N (S) ≤ q < p, we know that
N (S\{x}) = N (S) + 1 ≤ p. Therefore, the first player could win at the spot. Besides,
note that N (∅) = k and the parameter N decreases every other steps, it will eventually
become not greater than p in a finite steps. In other words, the game ends in a finite time
even if the board is infinite. Similarly, by using the same strategy, when p < q, the second
player wins the weak (p : q) game. It turns the weak biased game is less interested unless
p = q.

     A remark is that, as long as the board is huge enough, the same results hold for the

strong versions as well. In a huge board, during the early game, players can claim a number
of “dummy” positions that are at least k far from each other claimed position, which makes
almost no difference between strong and weak versions. Then the winning strategy above
works, still.



1.2      Nikodym & Kakeya Problem

1.2.1     Nikodym Set

      The following is a short introduction to Nikodym set and its variant.

Definition 1.2.1. Given a space A with a line structure L(A) ⊆ 2A . A subset N ⊆ A is
called a Nikodym set if, for every x ∈ A\N , there is a line L ∈ L(A) such that x ∈ L
and |L\N | = 1, i.e., the only missing point on the line L is x.


      Trivially, A itself is a Nikodym set. For every x ∈ A, the one-point-missing subset
A\{x} is also a Nikodym set. Note that the smaller a subset is, the harder it is to be
a Nikodym set. Therefore, the goal should be to find a Nikodym set that is as small as
                                                                              
possible. Li [4] showed that every Nikodym set in Fnq has size at least q+n−2
                                                                          n
                                                                                . Especially,
                                2
the bound can be raised to 2q3 + O(q) when n = 2. Lund, Saraf, and Wolf [6] showed
that, for a sufficiently large q, every Nikodym set in F3q has size at least 0.38q 3 .

      Later, we will see the connection between the monochromatic k in a row problem
and the Nikodym set problem. Roughly speaking, a “finished board state” can be regard
as a sort of Nikodym set if we replace “full line” with “line segment of length k” in the
definition of Nikodym set. Fortunately, the replacement is needless once every full line,
in the definition of Nikodym set, consists of k points. This happens when there is a finite
field of size k and the space A = Fdk . Thus the corresponding games, the monochromatic k
in a row played on torus boards, are concerned. In fact, the connection we had is between
the final board state and the 2-Nikodym set, which is a type of generalized Nikodym set
defined below.

1.2.2      Kakeya Set

      The Kakeya set is a related concept to the Nikodym set, and the core problems in the
field are the same, asking about how small can a Kakeya set be. There are two types of
Kakeya set, that are mainly discussed, based on different underlying spaces. The first one,
the classic one, is defined on the real spaces Rn .

Definition 1.2.3 (Kakeya sets in reals). A compact subset K ⊆ Rn is Kakeya if, for every
direction d ∈ S n−1 , there is a point x ∈ Rn such that x + [0, 1]d ⊆ K, i.e., it contains a
unit line segment in each direction.


      The main conjecture, as known as Kakeya set conjecture, about this type asserts that
“every Kakeya set in Rn has Minkowski and Hausdorff dimension n.” Recently, Wang
and Zahl [7] proved that the conjecture is true on R3 . The second one is defined on the
finite fields. In the finite fields, a Kakeya set is required to contain a full line, instead of a
unit line segment, in each direction.

Definition 1.2.4 (Kakeya sets in finite fields). Let Fq be a finite field of size q. A subset
K ⊆ Fnq is Kakeya if, for every direction d ∈ Fnq \{0}, there is a point x ∈ Fnq such that
x + (Fq )d ⊆ K, i.e., it contains a line in each direction.


      Bukh and Chao [2] proved that the size of every Kakeya set K ⊆ Fnq satisfies |K| ≥
(2 − 1q )−(n−1) q n .

Outline

     In the following, we focus on determining the game length and the winner for various
settings. For the former, we want results in form of bounds on density of final board states.
For the latter, the construction or existence of a winning strategy is needed.

     The second chapter consists of the formal definitions (of boards, games, and strate-
gies), handful properties, and problems we are interested in. Notably, the relation between
the final board state and the 2-Nikodym set is explained in this chapter. The third chap-
ter is proving main results, including bounds for maximum and minimum densities on
two types of boards and a construction of winning strategy for a specific type of boards.
Also, some results involving torus board are included. In the final chapter, we give a
generalized version of the result mentioned in Section 1.2.1. Besides, we propose several
possible extensions from the original problem in different direction and list conjectures
we are concerned about.

4.2.1      Multiplayer Games

      A t-player monochromatic k in a row played on the board B is denoted by (k, B, t).
Each player, in turns, claims a position from the board until a k-line is created. The defi-

                                                                                  doi:10.6342/NTU202501210
nition of the game sequence remains the same. Given a game sequence S = {si }i∈[n] , for
each i ∈ [t], the i-th player’s j-th move is s(j−1)t+(i−1) . Then here comes a natural ques-
tion: Given a (k, B, t)-game, who will win the game? It seems the current two assump-
tions imposing on players are not sufficient to determine the winner under some games.
For instance, take (3, [3]2 , 3)-game, there are five saturated configurations of (3, [3]2 )-
game. There are only two types of them up to rotation and reflection.

      It means the length of any game sequence is either 3 or 5; in either cases, the first
player can not win. However, the first player can “choose” which one will win. If the
first move is (2, 2), then the winner is the third player. If the first move is not (2, 2), then
the winner is the second player. Either moves are legal under our assumptions, which
causes that the winner is undetermined before the first move is made. Still, we can try to
determine the set of all possible winners instead of the winner. Let W(k, B, t) ⊆ [t] be
the set of all possible winner of (k, B, t)-game.
