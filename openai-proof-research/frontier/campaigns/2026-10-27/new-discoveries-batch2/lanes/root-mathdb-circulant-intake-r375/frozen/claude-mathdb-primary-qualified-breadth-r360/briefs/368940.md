# Brief 368940: centroid-preserving triangle center is unique

Section 32.7 ("Ask about uniqueness") states Conjecture 1:

> Let ABCD be an arbitrary quadrilateral. Let X denote a triangle center. Let E, F,
> G, and H be the X-points of △BCD, △CDA, △DAB, and △ABC, respectively. Then the
> centroid of ABCD coincides with the centroid of EFGH if and only if X = X2.

The source motivates it with a question: is m[ABCD] = m[EFGH] true only for n = 2
"because we only searched the first 1000 values of n?" Here m is the vertex
centroid (QA-P1, Table 2). The "if" direction is the source's Theorem 6.4.

## Exact reading of the quantifiers

P(X) means: for every quadrilateral ABCD (four points, no three collinear), the four
X-points are finite and (E+F+G+H)/4 = (A+B+C+D)/4.

The conjecture says P(X) ⇔ X = X2.

The pointwise reading ("for a given ABCD, coincidence ⇔ X = X2") is false.
- In a parallelogram, BCD and DAB are swapped by the point reflection in the center
  O, and so are CDA and ABC.
- So X(BCD) + X(DAB) = X(CDA) + X(ABC) = 2O for every center X.
- Every center therefore preserves the centroid of every parallelogram.

The universal reading matches "arbitrary quadrilateral" and the source's
"general quadrilateral" tables.

"Centroid" must mean the vertex centroid. EFGH (with X = X2) is the image of ABCD
under the homothety of ratio −1/3 about the vertex centroid M. Under the
area-centroid reading, X2 itself would fail whenever the area centroid differs from
M.

## Theorem (proved here)

Let X be any rule assigning a point X(T) ∈ R² to each non-degenerate triangle T,
depending only on the unordered vertex set. Every Kimberling triangle center that
is finite on all triangles qualifies, because its center function is bisymmetric.

Suppose (E+F+G+H) = (A+B+C+D) for every convex cyclic quadrilateral ABCD. Then
X(T) is the centroid of T for every triangle T.

In particular P(X) ⇒ X = X2, and P(X2) holds (source Theorem 6.4). So Conjecture 1
holds in its universal reading. The proof uses no continuity, homogeneity or ETC
data. It needs the hypothesis only for convex cyclic quadrilaterals.

## Proof

1. Set Φ(T) = X(T) − G(T), where G is the centroid.
   - Each vertex of a 4-set Q lies in three of its four 3-subsets.
   - So Σ_{T⊂Q, |T|=3} G(T) = (1/3)·3·Σ_{v∈Q} v = Σ_{v∈Q} v.
   - Hence the hypothesis is equivalent to S(Q) := Σ_{T⊂Q} Φ(T) = 0 for every
     admissible 4-set Q.
2. Fix a triangle T0 = {P1, P2, P3} with circumcircle Γ. Choose four more distinct
   points P4, …, P7 on Γ.
   - No three points of Γ are collinear, so every 3-subset is a non-degenerate
     triangle.
   - Every 4-subset, in circular order, is a convex cyclic quadrilateral.
   - So S(Q) = 0 for all 35 four-subsets Q of {P1, …, P7}.
3. Define c3 = 1/4, c2 = −1/12, c1 = 1/12, c0 = −1/4. Claim: for any function Φ on
   the 3-subsets of a 7-set,
   Φ(T0) = Σ_Q c_{|Q∩T0|} S(Q).
   Proof of the claim:
   - Let T be a 3-subset with j = |T ∩ T0|. The coefficient of Φ(T) on the right is
     Σ_{Q⊃T} c_{|Q∩T0|}.
   - Write Q = T ∪ {x}. There are 3 − j choices of x in T0 \ T, each giving
     |Q∩T0| = j+1. The other 4 − (3 − j) = 1 + j choices give |Q∩T0| = j.
   - So the coefficient is (3−j)c_{j+1} + (1+j)c_j:
     - j = 3: 4·(1/4) = 1.
     - j = 2: 1/4 − 3/12 = 0.
     - j = 1: −2/12 + 2/12 = 0.
     - j = 0: 3/12 − 1/4 = 0.
4. Each S(Q) = 0, so Φ(T0) = 0, that is X(T0) = G(T0). T0 was arbitrary. ∎

Remark. Step 3 is the explicit inverse of the inclusion matrix W_{3,4}(7), which is
35×35 and nonsingular (Gottlieb–Kantor full-rank theorem with t = 3, k = 4, n = 7).

## Scope caveats for the reviewer

- Centers that are points at infinity for some triangles (for example X30) fail P
  outright, because the X-points must be finite. If such centers should instead be
  judged only "where defined", the theorem still covers every triangle T0 that lies
  in a 7-point concyclic configuration all of whose triangles are in the domain.
  The fully general partial-domain variant is not claimed.
- This is a uniqueness/characterization result about the hypothesis class. It does
  not touch the source's other tables. The source's equidiagonal-orthodiagonal
  entry X489 concerns a restricted class with no 7-point cyclic configurations, so
  there is no conflict. Only entries for general quadrilaterals are covered.
