# Generic graph-potential soundness component

Complete Lean component for the already eligible C57 candidate. Credit **0**; counts remain **5/30 additional, 35/60 total**. This is supporting formalization, with no new discovery, novelty, acceptance, table-verification, geometry, or full source-endpoint claim.

`GraphPotential.soundness` proves the unconditional implication requested: given a finite connected vertex set T, a root z in T, a nonempty finite label mask M, witnesses in T for every label, and the three local certificate inequalities, `L M z ≤ T.card`. Vertex and label types are arbitrary types with decidable equality. Neither type must itself be finite. The finite domain D contains T; certificate inequalities apply only to vertices in D and nonempty masks contained in M. Taking D=T gives the formulation with inequalities restricted to T itself. The theorem even permits a directed relation with the stated all-pairs restricted-path connectivity, so symmetric adjacency needs no additional transfer premise.

`GraphPotential.excludes_small` gives `¬ T.card ≤ 11` from `12 ≤ L M z` at every vertex in D. `Polyomino57.potential_soundness` and `Polyomino57.potential_excludes_eleven` are closed grid specializations, taking precisely the frozen `EdgeConnected P`, `P ⊆ D`, and the certificate/hitting premises. The connection equivalence is definitionally reflexive. No vertex outside P enters a path: each path edge explicitly requires both endpoints in P. `Grid.lean` is copied byte-identically from the frozen source-formal-r1 lane.

## Mathematical proof

`Rooted` describes singleton rooted trees, extension by a fresh root connected to the old root, and union of two rooted trees sharing exactly their root. `Rooted.graft` proves by structural induction that a fresh leaf can be attached at any existing vertex while retaining the original root. For unions the leaf is grafted into one containing branch, and freshness preserves the intersection condition. For edge extension the graft recurses into the child, except when the attachment vertex is the root, where a new two-vertex branch is merged at the root.

`boundary` proves that every proper nonempty subset of a connected finite set has an outward edge inside that set: induct along a literal restricted path to a vertex outside the subset. `rooted_complete` starts at the chosen singleton root and repeatedly uses this boundary edge and grafting, inducting on the remaining cardinality. Thus no rooted decomposition is a residual hypothesis of soundness.

`split_hits` partitions each finite mask by the existence of a witness on the first side. It assigns all labels witnessed there to that side and the remaining labels to the second side. The masks are disjoint even when group memberships overlap. `rooted_bound` inducts on the constructed tree. Singleton masks at a vertex use base. An edge extension splits between labels assigned to the new root and labels assigned below it; it handles either part being empty separately, then applies edge and, when both are nonempty, merge. For a union of two rooted trees, both nonempty masks use merge and the exact identity `card(S ∪ T)+1=card S+card T`, since their intersection is the singleton root. If one mask is empty, only the other branch's bound is used, followed by cardinal monotonicity.

No empty-mask value, mask monotonicity, optimizer property, group disjointness, or label assignment premise is used. All arithmetic uses natural addition; there is no truncated subtraction in certificate merge or bound combination. Consequently **no positivity hypothesis is needed**. This proves a slightly stronger implication than the suggested interface with positivity. A singleton-label/singleton-vertex example is included in Bridge.lean; the empty-root-label case is handled explicitly in the edge induction.

## Validation and replay

The source-only deterministic archive is `source-only-component.zip`. Extract into a new directory and run `python3 replay.py`. The archive includes no compiled objects. Replay verifies source hashes, pinned Lean SHA/version, and all package revisions by read-only repository metadata; compiles Grid, Potential, Bridge, and the audits serially with warningAsError=true and autoImplicit=false; and consumes only newly built component objects plus the pinned package cache.

Every build uses the byte-identical frozen run.py resource wrapper: process-group RSS sampled at 45 ms, kill at 2800 MiB or 230 seconds, Lean -j1. The origin audit exhausts all declarations belonging to the three proof modules, prints their types, recursively checks the axiom whitelist, and rejects unsafe, partial, and new axiom declarations. Replay then generates and executes literal #check and #print axioms commands for every audited declaration. Logs, declaration inventory, dependency list, source manifest, and the fresh receipt remain in extracted-replay/. Replay receipt is copied to REPLAY-RECEIPT.json. Only propext, Classical.choice, and Quot.sound are allowed.

Failed development attempts are retained as attempt logs and source snapshots. Initial failures were deprecated Symmetric, an unavailable Finset disjointness name, an unused symmetry binder, and an unnecessary tactic sequencing linter warning; these are corrected in the final sources. A first extracted replay compiled and audited all proof modules but its Python audit parser unpacked five fields into four variables; the parser is corrected and the failed extraction is preserved as extracted-replay-attempt01/. A second extracted replay passed proof-module compilation and origin audits, then failed because the generated exhaustive commands deliberately name an auxiliary declaration, triggering linter.auxLemma. Only the generated audit command file disables that naming linter; all builds retain warningAsError=true. The second failed extraction is retained as extracted-replay-attempt02/. No proof gaps remain in this component. The generic soundness proof and the independently reviewed ordinary C57 certificate remain distinct from full source endpoint integration.
