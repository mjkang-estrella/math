 Abstract. 
    
 Every symmetric polynomial  h ⁡ ( x ) h(x)  with center of symmetry  n / 2 n/2  can be expressed as a linear combination in the basis  x i ​ ( 1 + x ) n − 2 ​ i x^{i}(1+x)^{n-2i} . The  γ \gamma -polynomial of  h ⁡ ( x ) h(x) , which we denote  γ h ​ ( x ) \gamma_{h}(x) , records the coefficients of this linear combination. Two decades ago, Brändén and Gal independently showed that if  γ h ​ ( x ) \gamma_{h}(x)  has nonpositive real roots only, then so does  h ⁡ ( x ) h(x) . More recently, Brändén, Ferroni, and Jochemko proved using Lorentzian polynomials that if  γ h ​ ( x ) \gamma_{h}(x)  is ultra log-concave, then so is  h ⁡ ( x ) h(x) , and they raised the question of whether a similar statement can be proved for the usual notion of log-concavity. The purpose of this article is to show that the answer to the question of Brändén, Ferroni, and Jochemko is affirmative. One of the crucial ingredients of the proof is an inequality involving binomial numbers that we establish via a path-counting argument. 
  
 
 
 Key words and phrases:  Log-concave polynomials,  γ \gamma -positivity, binomial identities
 
 2020 Mathematics Subject Classification 05A15, 05A19, 05A20
 
 
 1.  Introduction 

 
 A recurring endeavor in combinatorics consists in proving that special polynomials satisfy the properties of being unimodal or log-concave. Precisely, a polynomial  h ⁡ ( x ) := h 0 + h 1 ​ x + ⋯ + h n ​ x n h(x):=h_{0}+h_{1}\,x+\cdots+h_{n}\,x^{n}  with nonnegative coefficients is said to be  unimodal  if there exists some index  i i  such that 
 

 
 
 h 0 ≤ ⋯ ≤ h i − 1 ≤ h i ≥ h i + 1 ≥ ⋯ ≥ h n , h_{0}\leq\cdots\leq h_{i-1}\leq h_{i}\geq h_{i+1}\geq\cdots\geq h_{n}, 
 
 
 whereas it is said to be  log-concave  if, for each  0 < i < n 0<i<n , the inequalities  h i 2 ≥ h i − 1 ​ h i + 1 h_{i}^{2}\geq h_{i-1}\,h_{i+1}  hold true. If the sequence  h 0 , … , h n h_{0},\ldots,h_{n}  has no internal zeros, i.e., if  h i ​ h j ≠ 0 h_{i}h_{j}\neq 0  for  i < j i<j  implies that  h k ≠ 0 h_{k}\neq 0  for  i ≤ k ≤ j i\leq k\leq j , then the property of being log-concave implies that of being unimodal. For detailed surveys on unimodality and log-concavity, we refer to  [ Sta89 ,  Bre94 ,  Brä15 ] . 
 
 
 If the polynomial  h ⁡ ( x ) h(x)  satisfies the conditions  h i = h n − i h_{i}=h_{n-i}  for each  i i , then we say that  h h  is  symmetric  with center of symmetry  n / 2 n/2 . We note that no assumptions on the degree of  h ⁡ ( x ) h(x)  have been made, thus in particular one is allowed to have  h n = 0 h_{n}=0 . Also, notice that the center of symmetry of a symmetric polynomial is unique. 
 
 
 An important tool to prove that such a symmetric polynomial is unimodal consists of proving that it is  γ \gamma -positive. Precisely, symmetric polynomials with center of symmetry  n / 2 n/2  can be rewritten as follows: 
 

 
 
 h ⁡ ( x ) = ∑ i = 0 ⌊ n / 2 ⌋ γ i ​ x i ​ ( 1 + x ) n − 2 ​ i , h(x)=\sum_{i=0}^{\lfloor n/2\rfloor}\gamma_{i}\,x^{i}(1+x)^{n-2i}, 
 
 
 where  γ 0 , … ​ γ ⌊ n / 2 ⌋ \gamma_{0},\ldots\gamma_{\lfloor n/2\rfloor}  are uniquely determined.
Whenever all the coefficients  γ i \gamma_{i}  are nonnegative, then  h ⁡ ( x ) h(x)  is said to be  γ \gamma -positive . The  γ \gamma -polynomial  associated to  h ⁡ ( x ) h(x)  is defined by  γ h ​ ( x ) := γ 0 + γ 1 ​ x + ⋯ + γ ⌊ n / 2 ⌋ ​ x ⌊ n / 2 ⌋ \gamma_{h}(x):=\gamma_{0}+\gamma_{1}x+\cdots+\gamma_{\lfloor n/2\rfloor}x^{\lfloor n/2\rfloor} . It is not difficult to show that  γ \gamma -positivity implies unimodality. For a thorough exposition on  γ \gamma -positivity, we refer the reader to  [ Ath18 ] . 
 
 
 Two decades ago, Brändén  [ Brä06 ]  and Gal  [ Gal05 ]  showed independently the following result. 
 
 
 Theorem 1.1   ( [ Brä06 ,  Gal05 ] ) 
 
 Let  h ⁡ ( x ) h(x)  be a symmetric polynomial. The polynomial  γ h ​ ( x ) \gamma_{h}(x)  has only nonpositive real zeros if and only if so does  h ⁡ ( x ) h(x) . 
 
 
 
 The proof of the above result resorts to basic manipulations of (complex) univariate polynomials. This has been used extensively throughout the literature to approach various problems on unimodality, log-concavity, and real-rootedness. 
 
 
 More recently, Brändén, Ferroni, and Jochemko  [ BFJ24 , Theorem 3.3]  proved a version of the above statement, for ultra log-concavity instead. Specifically, the polynomial  h ⁡ ( x ) = h 0 + ⋯ + h n ​ x n h(x)=h_{0}+\cdots+h_{n}\,x^{n}  is said to be  ultra log-concave of order  m ≥ n m\geq n  if the sequence 
 

 
 
 h 0 ( m 0 ) , h 1 ( m 1 ) , … , h n ( m n ) \frac{h_{0}}{\binom{m}{0}},\frac{h_{1}}{\binom{m}{1}},\ldots,\frac{h_{n}}{\binom{m}{n}} 
 
 
 is log-concave. Their result can be reformulated as follows. 
 
 
 Theorem 1.2   ( [ BFJ24 ] ) 
 
 Let  h ⁡ ( x ) h(x)  be a symmetric polynomial with center of symmetry  n / 2 n/2 . If  γ h ​ ( x ) \gamma_{h}(x)  is ultra log-concave of order  ⌊ n / 2 ⌋ \lfloor n/2\rfloor  with no internal zeros, then  h ⁡ ( x ) h(x)  is ultra log-concave of order  n n  with no internal zeros. 
 
 
 
 In contrast to Theorem  1.1 , in the last theorem the converse is false, see  [ BFJ24 , Example 3.4] . The proof of Theorem  1.2  relies on properties of the class of Lorentzian polynomials introduced by Brändén and Huh  [ BH20 ] . A question raised by Brändén, Ferroni, and Jochemko in their work is whether it was possible to prove a similar property but for the weaker notion of log-concavity. We show that the answer to their question is affirmative. The main result of this article is the following. 
 
 
 Theorem 1.3 
 
 Let  h ⁡ ( x ) h(x)  be a symmetric polynomial. If  γ h ​ ( x ) \gamma_{h}(x)  is log-concave and has no internal zeros, then  h ⁡ ( x ) h(x)  is log-concave and has no internal zeros. 
 
 
 
 Once again, and via the same example of Brändén, Ferroni, and Jochemko  [ BFJ24 , Example 3.4] , the converse is not true. 
 
 
 A reformulation of Theorem  1.2  is that the operator on bivariate homogeneous polynomials appearing in  [ BFJ24 , Lemma 3.2]  preserves the Lorentzian property. Lorentzian polynomials generalize the notion of ultra log-concavity whilst  denormalized  Lorentzian polynomials generalize the notion of log-concavity. In particular, Theorem  1.3  says that the aforementioned operator preserves the denormalized Lorentzian property too. As it is the case in the present situation, proving the preservation of the denormalized Lorentzian property is often considerably harder. One reason is that Lorentzian polynomials satisfy much better properties than denormalized Lorentzian—for example, nonnegative linear changes of variables preserve the Lorentzian property but often fail to preserve the denormalized Lorentzian property (see  [ BH20 , Theorem 2.10]  and  [ BFJ24 , Section 6] ). In particular, in order to prove a result like Theorem  1.3 , some ad-hoc strategy needs to be applied. In the present article, the proof of Theorem  1.3  is essentially elementary, but relies on certain technical combinatorial identities and inequalities involving binomial coefficients and injections on lattice paths (see  Lemma   3.3  and  Theorem   4.3 ). 
 
 
 
 2.  The set up

As mentioned earlier, we do not require  h n ≠ 0 h_{n}\neq 0 , so that the degree of  h ⁡ ( x ) h(x)  is allowed to be less than  n n . Correspondingly, we will denote  γ h ​ ( x ) = γ 0 + γ 1 ​ x + ⋯ + γ ⌊ n / 2 ⌋ ​ x ⌊ n / 2 ⌋ \gamma_{h}(x)=\gamma_{0}+\gamma_{1}\,x+\cdots+\gamma_{\lfloor n/2\rfloor}\,x^{\lfloor n/2\rfloor}  the  γ \gamma -polynomial associated to  h ⁡ ( x ) h(x) . 
 
 
 The identity  h ⁡ ( x ) = ∑ j = 0 ⌊ n / 2 ⌋ γ j ​ x j ​ ( 1 + x ) n − 2 ​ j h(x)=\sum_{j=0}^{\lfloor n/2\rfloor}\gamma_{j}\,x^{j}(1+x)^{n-2j}  allows us to establish a relation between the  h i h_{i} ’s in terms of the  γ j \gamma_{j} ’s. More precisely, we have:
