                                                                                             Abstract
                                                  A real matrix is said to be positive if its every entry is positive, and a real square matrix A is
                                                  algebraically positive if there exists a real polynomial f such that f (A) is a positive matrix.
                                                  A sign pattern matrix A is said to require a property if all matrices having sign pattern as A
                                                  have that property. In this paper, we characterize all sign pattern matrices associated with
                                                  cycle graphs that require algebraic positivity.
                                           Keywords: Algebraically positive, Sign pattern, Require algebraic positivity, Sign non-singular.
                                           AMS Subject Classifications: 15B35, 15B48, 05C50.

                                           1    Introduction

                                           A real matrix is said to be positive if its every entry is positive. Positive matrices has applications
                                           in population models, Markov chains, economic model, low-dimensional topology, epidemiology
                                           etc. (see [9]). A generalization of positive matrices was given by Kirkland, Qiao, and Zhan as
                                           algebraically positive matrices. A real square matrix A is algebraically positive if there exists a
                                           real polynomial f such that f (A) is a positive matrix. The characterization of algebraically positive
                                           matrices was given by the following result.
                                           Theorem 1.1 ([7]). A real square matrix is algebraically positive if and only if it has a simple real
                                           eigenvalue and corresponding left and right positive eigenvectors.
                                               We are interested in answering the problem of identifying an algebraically positive matrix from
                                           the signs its entries. A sign pattern matrix is a matrix whose every entry is a symbol from the
                                           set {+, −, 0}. The qualitative class of a matrix A, denoted by Q(A), is defined by the set of all
                                           real matrices obtained from A by replacing ‘+’ by some positive number, ‘−’ by some negative
                                           number and ‘0’ by the zero number. A sign pattern matrix A allows a property P if at least one
                                           matrix in Q(A) has the property P , and requires property P if all matrices in Q(A) have the
                                           property P . For our convenience, we use the symbols +0 , −0 , # in sign pattern matrices. Any
                                           entry associated +0 , −0 , # will be considered as a nonnegative, a non-positive, and an arbitrary
                                           real number, respectively.

                                           [2, 6] that the digraph of a sign pattern matrix A of order n, denoted by D(A), is defined by a

      Characterization of sign patterns allowing algebraic positivity is still not solved completely, but
many results to identify those patterns can be observed in [1, 3, 4, 7]. The problem of identifying
sign patterns requiring algebraically positivity is widely open. Path and star sign patterns requiring
algebraic positivity are described in [4], and list of all 3-by-3 sign patterns requiring algebraic
positivity are presented in [1]. The graphs of 3-by-3 tree sign pattern matrices are either stars
or paths. For any other 3-by-3 irreducible sign pattern matrix, the underlying undirected graph
is a cycle. In this paper, we attempt to generalize the problem of requiring algebraic positivity
for cycle graphs. In the process, we also give some results in identifying matrices which are not
algebraically positive and whose underlying graph is an arbitrary graph.
      In Section 2, we provide some necessary conditions for a sign pattern matrix to require algebraic
positivity. In Section 3, we identify all sign patterns having cycle graphs that require algebraic
positivity. Finally, we summerize all main results in Section 4.
      Throughout this paper, R denotes the set of all real numbers, Rn is the n-dimensional Euclidean
space, and AT is the transpose of the matrix A. A vector in Rn is denoted by x̄ and its i-th entry
is denoted by xi . A zero vector is denoted by 0̄ and an identity matrix is denoted by I, whose sizes
will be clear from the context. We denote the adjugate of a square matrix A by adj(A).

2    Identifying sign patterns that does not require algebraic positivity

The following lemma from [5, pp. 78-80] gives a relation between left and right eigenvectors
corresponding to two distinct eigenvalues of a matrix.
Lemma 2.1 ([5]). Let A be a real square matrix and x̄, ȳ ∈ Rn \ {0̄} such that Ax̄ = λx̄ and
ȳ T A = µȳ T for some λ, µ ∈ R.
    1. If λ ̸= µ, then ȳ T x̄ = 0.
    2. If λ = µ and λ has geometric multiplicity 1, then its algebraic multiplicity is 1 if and only if
       ȳ T x̄ ̸= 0.

    The following lemma shows that any non-negative left or right eigenvector of an algebraically
positive matrix must be a scalar multiple of its left or right positive eigenvector, whose existence
is given by Theorem 1.1.
Lemma 2.2. If a matrix A has a non-negative left or right eigenvector x̄ with some xi = 0, then
A is not algebraically positive.

Proof. Suppose that Ax̄ = λx̄, where x̄ is non-negative right eigenvector of A with some xi = 0. If
A is algebraically positive, then by Theorem 1.1, it has a simple eigenvalue µ such that Az̄ = µz̄
and ȳ T A = µȳ T for some positive vectors ȳ and z̄. Since x̄ and z̄ are independent, and µ is simple
eigenvalue, λ ̸= µ. But ȳ T x̄ ̸= 0, a contradiction to Lemma 2.1.1. Therefore A is not algebraically
positive. Similarly, if A has a non-negative left eigenvector x̄ with some xi = 0, then A is not
algebraically positive.

Lemma 2.6 ([7]). The following statements are equivalent for a square matrix A.

  1. A is algebraically positive.
  2. −A is algebraically positive.
  3. P T AP is algebraically positive for every permutation matrix P .

  4. A − αI is algebraically positive for every real number α.
    A matrix is said to be stable (semi-stable) if all its eigenvalues have negative (non-positive)
real part. A sign pattern matrix is potentially stable (semi-stable) if its qualitative class contains
a stable (semi-stable) matrix.
Proposition 2.7. Let A be a sign pattern matrix such that it has either a row containing no −
or a column containing no −. If A is potentially semi-stable, then it does not require algebraic
positivity.
Proof. Suppose that A requires algebraic positivity. Since A has either a row containing no − or a
column containing no −, by Theorem 1.1, every matrix in Q(A) has a simple positive eigenvalue.
But it contradicts the assumption that A is potentially semi-stable.

Proposition 2.8. A real skew-symmetric matrix of even order cannot be algebraically positive.
Proof. Eigenvalues of a real skew-symmetric matrix are either 0 or purely imaginary. So an even
order real skew-symmetric matrix cannot have a simple real eigenvalue. Therefore, by Theorem
1.1, a real skew-symmetric matrix of even order cannot be algebraically positive.

3.1   Cycles with loops and negative 2-cycles only
The following lemma gives a necessary condition for a sign pattern matrix associated with cycle
graphs to require algebraic positivity if no diagonal entries are positive and no 2-cycles are positive.
Lemma 3.10. Let A be a sign pattern matrix of order n of the form (1) such that aii = −0 for all
i and all directed 2-cycles in D(A) are negative. Let D(A+ ) contains a directed n-cycle, D(A− )
does not contain a directed n-cycle and aij aji = − for some i ̸= j. If A is not SNS and A requires
algebraic positivity, then aii = − and ajj = − whenever aij = + and aji = 0 for some i ̸= j.
Proof. Since D(A+ ) contains a directed n-cycle, let aij = + for all i, j with j = i + 1 mod n.
Since D(A− ) does not contain a directed n-cycle, assume that a1n = 0.
    Now D(A) has no directed k-cycle for 2 < k < n and only one directed n-cycle with sign
+. The standard determinant expansion of every matrix in Q(A) has a term with sign (−)n−1
corresponding to the n-cycle. Since A is not SNS, the standard determinant expansion of every
matrix in Q(A) has a term with sign (−)n . So we can choose B ∈ Q(A) such that det B = (−1)n .
Moreover, all 2-cycles in D(A) are negative. So the coefficients of xi in the characteristic polynomial
of B are non-negative for i = 1, 2, . . . , n. Consequently, the characteristic equation p(B) = 0 has
no positive real root, by Descartes’ rule of signs. Thus all real eigenvalues of B are negative, as
det B ̸= 0. Since A requires algebraic positivity, by Theorem 1.1, B has positive left and right
eigenvectors corresponding to a negative eigenvalue.
    If ann = 0, then for any λ < 0, the n-th column of B − λI is a nonzero, non-negative vector
so that B − λI does not have a positive left eigenvector. Similarly, if a11 = 0, then for any λ < 0,
the first row of B − λI is a nonzero, non-negative vector so that B − λI does not have a positive
right eigenvector. Thus if either a11 = 0 or ann = 0, then B is not algebraically positive so that A
does not require algebraic positivity, a contradiction. Therefore a11 = − and ann = −. Hence the
result follows.
    The following result is a necessary condition for a sign pattern of the form (1) to require
algebraic positivity when there is no positive directed 2-cycle in its digraph.
Lemma 3.11. Let A be a sign pattern matrix of order n of the form (1) and all directed 2-cycles
in D(A) are negative. Let D(A+ ) contains a directed n-cycle, aij aji = − for some i ̸= j, and A
requires algebraic positivity.
  1. If D(A− ) does not contain an n-cycle and aii = −0 for all i, then A is SNS.
  2. If D(A− ) contains an n-cycle, then n is odd and aii = 0 for all i.
Proof. Assume that A requires algebraic positivity. Since D(A+ ) contains a directed n-cycle, let
aij = + for all i, j with j = i + 1 mod n.
  1. Suppose that A is not SNS. Since aij aji = − for some i ̸= j and D(A− ) does not contain a
     directed n-cycle, assume that a21 = − and a1n = 0. Further, by Lemma 3.10, aii = − and
     ajj = − provided that aji = 0 for some j = i + 1 mod n. So for every k-th column of A,
     either akk = − or ak+1,k = − for 1 ≤ k ≤ n − 1, and ann = −.
      Now we can choose B ∈ Q(A) and λ < 0 such that the second column of (B − λI)(1, :) is
      zero vector or has both + and −, and all other columns of (B − λI)(t, :) has both + and −.
      So by Proposition 2.3, A does not require algebraic positivity, a contradiction. Therefore A

4   Summary

As we have considered that G(A) is a cycle, there are no directed k-cycles in D(A) for 2 < k < n
and A is of the form (1). Lemma 3.2 shows that a sign pattern matrix of the form (1) must have
a directed n-cycle with positive arcs only for A to require algebraic positivity. If all directed 2-
cycles are positive, then A is irreducible and all nonzero off-diagonal entries are positive so that A
requires algebraic positivity. If there are no loops, then sign patterns requiring algebraic positivity
is given by Theorem 3.15. If there are some loops and all directed 2-cycles are negative, then the
characterization of sign pattern requiring algebraic positivity is described by Theorem 3.14. If
we have both positive and negative directed 2-cycles, then the characterization for A to require
algebraic positivity is described by Theorem 3.18. Thus Theorem 3.15, 3.14 and 3.18 together
describes all sign pattern matrices with cycle graphs that require algebraic positivity.
