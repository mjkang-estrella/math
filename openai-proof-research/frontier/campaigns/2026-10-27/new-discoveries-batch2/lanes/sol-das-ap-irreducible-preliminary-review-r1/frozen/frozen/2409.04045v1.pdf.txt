                                                                                Abstract
                                                       Let D denote the set of directions determined by the graph of a
                                                  polynomial f of Fq [x], where q is a power of the prime p. If D is
                                                  contained in a multiplicative subgroup M of F×  q , then by a result of
                                                                                                   k
                                                  Carlitz and McConnel it follows that f (x) = axp + b for some k ∈ N.
                                                  Of course, if D ⊆ M , then 0 ∈/ D and hence f is a permutation. If we
                                                  assume the weaker condition D ⊆ M ∪ {0}, then f is not necessarily a
                                                                                                        k
                                                  permutation, but Sziklai conjectured that f (x) = axp + b follows also
                                                  in this case. When q is odd, and the index of M is even, then a result
                                                  of Ball, Blokhuis, Brouwer, Storme and Szőnyi combined with a result
                                                  of McGuire and Göloğlu proves the conjecture. Assume deg f ≥ 1.
                                                  We prove that if the size of D −1 D = {d−1 d′ : d ∈ D \ {0}, d′ ∈ D}
                                                  is less than q − deg f + 2, then f is a permutation of Fq . We use this
                                                  result to verify the conjecture of Sziklai.


                                          1       Introduction
                                          Let Fq denote the finite field of q = pn elements, where p is a prime. If f is
                                          an Fq → Fq function then the affine q-set {(x, f (x)) : x ∈ Fq } ⊆ AG(2, q) is
                                          called the graph of f , the subset Df := {(f (x)−f (y))/(x−y) : x, y ∈ Fq , x 6=
                                          y} of Fq is called the set of directions, or slopes, determined by (the graph
                                          of) f . Each Fq → Fq function can be uniquely represented by a polynomial
                                          of Fq [x] and of degree at most q − 1, so we will consider polynomials instead
                                          of function. For a subset A of Fq we will denote A \ {0} by A∗ .

The following result was proved first by Carlitz in the case of d = 2 [5] and
then generalised by McConnel for other divisors d of q − 1 [6].

Result 1.1. If Df ⊆ Md , then f is of the form f (x) = a + bxp .

    There are several generalisations and different proofs of this result, due
to Bruen and Levinger [3], Grundhöfer [8], Lenstra [4], see [9, Section 9] for
a survey on these results and their relation with the Paley graph.
    Since 0 ∈ / Df yields f (x) 6= f (y) for each x 6= y, it is obvious that
only permutations can satisfy the condition D ⊆ Md . This is not the case
anymore if we allow D ⊆ Md ∪ {0}. In [10, pg. 114] Sziklai conjectured
                  k
that f (x) = axp + b holds also when one replaces Md with Md ∪ {0} in the
statement of Result 1.1. To present what is known regarding this conjecture,
we need to recall some definitions. An Fq → Fq function f is called additive
if f (a + b) = f (a) + f (b) for each a, b ∈ Fq . Such functions correspond to
                                           n−1
polynomials a0 x + a1 xp + . . . + an−1 xp     ∈ Fq [x]. If f is additive and α ∈ Fq ,
then we we will call f + α an affine polynomial. An important result on
directions is the following, due to Ball, Blokhuis, Brouwer, Storme, Szőnyi
[2] and Ball [1].

Result 1.2. If |Df | ≤ (q + 1)/2, then f is an affine polynomial.

    If f is additive, then for the affine polynomial g = f + α it holds that
Dg = {f (x)/x : x ∈ F∗q } = Df . The following result is due to McGuire and
Göloğlu [7].
                                                                                    k
Result 1.3. If q is odd, f is additive and Df ⊆ M2 ∪ {0}, then f (x) = axp .

    If Dg ⊆ M2 ∪{0}, then |Dg | ≤ (q +1)/2 and hence by Result 1.2 g = f +α
for some additive f with Df = Dg , thus Result 1.3 proves Sziklai’s conjecture
in case of odd q and even d. In [7] the authors used Kloosterman sums and
it seems to be that their technique cannot be used to prove the conjecture
when d is odd.
   Our key result is Theorem 2.1. It’s proof was inspired by the recent
manuscript [11] of C. H. Yip who used Result 1.2 in a clever way to strengthen
Result 1.1. In Corollary 2.5 we extend Yip’s result to polynomials which are

Theorem 2.2. Let f ∈ Fq [x] be a polynomial of degree k for some 0 < k < q.
If |Df−1 Df | < q − k + 2, then f is a permutation of Fq .
Proof. If k = 1, then f is a permutation. Assume k > 1. If f was not a
permutation, then there would be a line with slope 0 meeting Uf in at least
two and at most k points (since f (x) = c has at most deg f roots for each
c ∈ Fq ). By Theorem 2.1 it follows that |Df−1 Df | ≥ q − k + 2, contradicting
the assumption.
Corollary 2.3. If |Df−1 Df | ≤ (q+1)/2 holds for some Fq → Fq non-constant
function f , then f permutes Fq .

∅ and |Df | ≤ |Df−1 Df |. By Result 1.2 f can be represented by an affine
polynomial of degree at most q/p ≤ q/2. Then

Corollary 2.4. If Df ⊆ Md ∪ {0}, then f (x) = axp + b.

Proof. Df−1 Df ⊆ Md−1 (Md ∪{0}) = Md ∪{0} and hence |Df−1Df | ≤ |Md |+1 ≤
(q + 1)/2. By Corollary 2.3 f is a constant function (that is, a = 0), or it is
a permutation and hence 0 ∈/ Df . The assertion follows from Result 1.1.
   The next result weakens the condition on f from [11, Theorem 1.2], since
we do not require f to be a permutation.

Corollary 2.5. If for some Fq → Fq function f it holds that |Df−1Df Df−1 | ≤
                           k
(q + 1)/2, then f (x) = axp + b.

Proof. If f is the constant function then the result trivially holds. If it is
not, then Df−1 6= ∅ and hence |Df−1 Df | ≤ |Df−1 Df Df−1 | ≤ (q + 1)/2, thus f is
a permutation by Corollary 2.3. Then the result follows from [11, Theorem
1.2] and from the fact that 1 ∈ Df−1 Df and hence Df−1 ⊆ Df−1 Df Df−1 , thus
Df−1 ∪ Df−1 Df Df−1 = Df−1 Df Df−1 .
