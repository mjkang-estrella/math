                                                                                               Abstract
                                                   We study the trace set of the commutator subgroup of Γ(2), a type of Local-Global prob-
                                               lem about thin groups. We determine the local obstructions and then use the correspondence
                                               between binary quadratic forms and hyperbolic matrices to find some global obstructions. We
                                               then develop a probabilistic argument for the existence of sufficiently large admissible traces by
                                               modeling the elements as non-backtracking random walks in a 2-dimensional lattice via their
                                               homology class and word length. Finally, we investigate the number of commutators needed to
                                               represent matrices in the commutator subgroup. This is done using an algorithm of Goldstein
                                               and Turner along with utilizing properties of level k-Markoff type surfaces. We conjecture that
                                               any trace in the commutator subgroup of Γ(2) can be represented with either 1 or 2 commutators.

    Conjecture 1.4 would then imply McMullen’s Conjecture 1.1 (see [BK18]). Despite this
reformulation of the problem, relatively little progress has been made. In this paper we consider
a related problem in a particular group that has more structure. The group is defined as follows.
    Take Γ(2) := {γ ∈ SL2 (Z) | γ ≡ I mod 2}, the level-2 principal congruence subgroup
of the modular group SL2 (Z), and let Γ(2)0 be its commutator subgroup. Our main objective,
analogous to McMullen’s conjecture, is to study the trace set of Γ(2)0 . This is interesting since
the trace is related to the length of closed geodesics in the trivial homology. First, we determine
the admissible values.

Theorem 1.5 (Admissibility Theorem). The set of admissible values for the trace set of Γ(2)0
are all t such that t mod 256 ∈ {2, 18, 66, 146} and t mod 9 ∈ {0, 2, 3, 6, 7}.

Conjecture 1.6. For all sufficiently large admissible t, there exists γ ∈ Γ(2)0 such that Tr(γ) = t.

    This conjecture asks for less than the what Conjecture 1.4 would ask in the analogous setting
since we are only asking if matrices with trace t exist, and not about multiplicity. We are not
able to fully solve this and so in these pages we will prove some theorems about the structure of
the group and give both empirical and probabilistic arguments toward the conjecture.
    It is not even known that a positive proportion of the traces arise. One’s first instinct may
be to use the relationships between level structures of the Markoff surface and 1-commutators,
elements of the form [X, Y] with X, Y ∈ Γ(2) (see Section 7), as studied by Ghosh and Sarnak
[GS17]. That is, perhaps the traces of 1-commutators already produce a positive proportion.
However, this direction seems just as, if not more, difficult since one would need to exhibit
matrices in Γ(2) with very special properties. This question about 1-commutators then opens an
auxiliary direction of inquiry where one asks, for γ in the commutator subgroup of Γ(2)0 , what
is the commutator width of γ? I.e. the minimal number of commutators needed to represent
γ. There are cases of different groups where such a question is undecidable [BBN59], however
Wicks showed that it is possible to compute the width in free groups [Wic62]. We use the
algorithm of Goldstein and Turner [GT79] to do so effectively and study the distribution of
widths which lead to the formulation of Conjecture 1.14.
    Another question one might ask is, are there admissible values that do not arise as traces?
We explain a constructive algorithm (Section 5) that will tell us if a given value is or is not a trace
of a matrix in the commutator subgroup of Γ(2) modeling Gauss’s reduction theory of Binary
Quadratic Forms. In doing this, we identify what the failures are in this context and it seems
reasonable to believe that these are all of them.

Lemma 1.7. The only admissible values, t, such that |t| < 106 and t is not the trace of an element
in Γ(2)0 is when t ∈ {−1006, −1726, −2558, −4718}.

Conjecture 1.8. The only admissible values, t, such that t is not the trace of an element in Γ(2)0

      7     Commutator Width
      We might ask ourselves if g ∈ Γ(2)0 can it be written as a 1-commutator. We can further general-
      ize this question to ask, what is the minimal number of commutators needed to write g ∈ Γ(2)0 .
      We call this value the commutator width of g. Given that γ[h, k]γ−1 = [γhγ−1 , γkγ−1 ], it is clear
      that g has the same width as any other element in its SL2 (Z) conjugacy class. So the question
      reduces, as usual, to answering the question in ∆ ∩ Γ(2)0 .
          For certain g, this question is not hard to answer as can be seen in Lemma 7.1 below.

       7.1    Algorithm for finding the width of an element in Γ(2)0
       The algorithm by Goldstein and Turner [GT79] tells us not only if a conjugacy class can be
       written as a 1-commutator, but the minimum number of commutators we need to write it. The
       implementation of this algorithm can be found in the repository. 4
           A sketch of an Algorithm for finding the commutator width of an element in ∆ ∩ Γ(2)0
         1. Given g ∈ ∆ ∩ Γ(2)0
         2. Write g = Am1 Bn1 · · · Amk Bnk
         3. Convert into a list of a’s, b’s, c’s, d’s where A → a, B → b, A−1 → c, B−1 → d
         4. Pair the a’s and c’s together
         5. Pair the b’s and d’s together
         6. Assign labels to all of the pairings in order from left to right.
         7. Plot the points, in order they appear, on a circle and connect two points via a line segment
            if they were matched above.
         8. Create a matrix that at position (i, j) is 1 if the line associated with label i intersects with
            line associated with label j and 0 else.
         9. Calculate the rank of the matrix in Z/2Z and divide it by 2.
        10. The minimum of these values is the width of g.
           For g ∈ ∆ ∩ Γ(2)0 , we can begin by searching for a mapping that has width 1. If we find
       one, then we can stop because we already hit the best case scenario. However, if g has no width
       1 mappings we must check every single mapping since we don’t yet know if we can do better.
       Given that `(g) > log(|t|/2), as the trace gets larger, this algorithm, obviously, becomes less
       helpful.

Also, [Tho61] gives us that g ∈ SL3 (Z/pZ)0 is a 1-commutator. It is then conjectured that all
g ∈ SL3 (Z) are 1-commutators. From previous theorems in Section 3 and, again, [Tho61], it is
easy to see that, for our case, g ∈ Γ(2)0 mod p is a 1-commutator for prime p , 3 and from the
examples in this section we see that there do exist g ∈ SL2 (Z)0 such that the commutator width
is greater than 1.
Definition 7.3. For an admissible value, t, the minimal width of t is the smallest commutator
width of the conjugacy classes with that trace.
    Now how do we find the minimal width of t? We start by taking each representatives of the
SL2 (Z) conjugacy classes with trace t (in ∆ ∩ Γ(2)0 ). If a representative has narrow length 2 or
3 then we know it is a one commutator and can stop. Else, we loop through each representative
searching for a mapping that has commutator width 1 and regardless we always take the smallest.
If we find one, we are done. We can ignore some relations like transposes of representatives
(since if one is a 1-commutator so is the other). To attempt to speed up this search, we sort the
matrices (which are already the representatives with the smallest lengths), in increasing order by
length, in the hopes that the smallest ones might have a 1-commutator before having to go on to
the bigger ones. In the next section we will discuss how to optimize this further.
    Summary of some search results:
   • First trace that has a class that is not a 1-commutator: 322
   • First trace that has no classes that are 1-commutators: 322
   • First trace that has some that are not 1-commutators and some that are: 1170
   • Traces that have a 1-commutator width representative versus those that have a commutator
     width 2 representative: up to |t| < 25000, 267 had a 1-commutator representative, 160 had
     a 2 commutator representative.
   • First trace that has a 3-commutator: 1298
   • For |t| < 150000, the admissible traces (that aren’t failures) have commutator width no
     more than 2.
Conjecture 7.4. For admissible values t with h(t) > 0, the minimal width of t is either 1 or 2.


7.2    Connection to the Markoff Equation
Now, one might ask why we are interested in the commutator width. This interest stemmed
from the fact that there is a relationship between 1-commutators and solutions to the level k
Markoff-type equations. We will change the wording of some of the theorems stated in Ghosh
and Sarnak’s paper to fit our purposes. For more information on this topic we recommend
[GS17].
    Take the Markoff-type equation for fixed k, x12 + x22 + x32 − x1 x2 x3 = k and let Mk be the set
of integer solutions to this equation. Such things tie together with 1-commutators using Fricke’s
Identity:
                Tr(A)2 + Tr(B)2 + Tr(AB)2 − Tr(A) Tr(B) Tr(AB) = Tr([A, B]) + 2.                 (5)
    We already know that not all of the commutators are 1-commutators (see the summary of
the search results) and the algorithm discussed in the previous section by Goldstein and Turner
[GT79] appears to find a representative pretty quickly with commutator width 2 (which was the
inspiration for Conjecture 7.4). The goal of this section is to be able to improve the algorithm
by using facts about level k Markoff-type solutions to speed up differentiating between 1 and
greater than 1 commutator widths.
