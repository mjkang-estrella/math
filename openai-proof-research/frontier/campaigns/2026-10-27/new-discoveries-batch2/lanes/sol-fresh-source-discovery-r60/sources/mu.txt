  Abstract. 
    
 For a polynomial      f  ⁡   (  t  )    =   1  +    f  0   ​  t   +  ⋯  +    f   d  −  1    ​   t  d      f(t)=1+f_{0}t+\cdots+f_{d-1}t^{d}    with positive integer
coefficients Bell and Skandera [Discrete Math, 307 (2007), pp. 668-682] ask if real-rootedness of
    f  ⁡   (  t  )    f(t)    implies that there is a simplicial complex with
   f  f   -vector     (  1  ,   f  0   ,  …  ,   f   d  −  1    )   (1,f_{0},\ldots,f_{d-1})    or equivalently a simplicial complex with    f  f   -polynomial     f  ⁡   (  t  )    f(t)   . In this paper we
discover properties implied by the
real-rootedness of     f  ⁡   (  t  )    f(t)    in terms
of the
binomial representation      f  i   =   (    x   i  +  1     i  +  1    )    f_{i}=\binom{x_{i+1}}{i+1}   ,     i  ≥  0   i\geq 0   . We use these to partially answer the question by Bell and Skandera. We also describe two further approaches to the question and use one to verify that some well studied real-rooted classical polynomials are    f  f   -polynomials. 
    
 Finally, we provide a series of results showing that the set of    f  f   -vectors of simplicial complexes is closed under constructions also preserving real-rootedness
of their generating polynomials. 
  
 
 
  1.  Introduction 

 
 The results of this paper are motivated by a question of Bell and Skandera. 
 
 
   Question 1.0     (Bell and Skandera, Question 1.1 in  [ 2 ] ) .  
 
 Let      f  ⁡   (  t  )    =   1  +    f  0   ​  t   +  ⋯  +    f   d  −  1    ​   t  d      f(t)=1+f_{0}t+\cdots+f_{d-1}t^{d}    be a polynomial with positive integer coefficients. If     f  ⁡   (  t  )    f(t)    is real-rooted, is     (  1  ,   f  0   ,  …  ,   f   d  −  1    )   (1,f_{0},\ldots,f_{d-1})    the
   f  f   -vector     (   f   −  1   Δ   ,  …  ,   f   d  −  1   Δ   )   (f_{-1}^{\Delta},\ldots,f_{d-1}^{\Delta})    of a simplicial complex    Δ  \Delta   ? 
 
 
 
 Recall that for a simplicial complex    Δ  \Delta    the entries     f  i  Δ   f_{i}^{\Delta}    of the    f  f   -vector are the number of    i  i   -dimensional faces of    Δ  \Delta   .
Thus in other words the conclusion of   Question 1.0   is that
     f  ​   (  t  )    =    f  Δ   ​   (  t  )     f(t)=f^{\Delta}(t)    is the    f  f   -polynomial of a simplicial complex    Δ  \Delta   .
We develop three approaches to this question,
which may be of independent
interest, and collect further
evidence for a positive answer to the question.
The main results of the paper are. 
 
  •  
 
 For a real-rooted polynomial      f  ⁡   (  t  )    =   1  +    f  0   ​  t   +  ⋯  +    f   d  −  1    ​   t  d      f(t)=1+f_{0}t+\cdots+f_{d-1}t^{d}    with positive integer coefficients and real
numbers      x  i   ≥  i   x_{i}\geq i    such that
     f  ⁡   (  t  )    =   1  +    (    x  1   1   )   ​  t   +  ⋯  +    (    x  d   d   )   ​   t  d      f(t)=1+\binom{x_{1}}{1}t+\cdots+\binom{x_{d}}{d}t^{d}    we have
     x  1   ≥  ⋯  ≥   x  d    x_{1}\geq\cdots\geq x_{d}    (  Theorem 3.0  ). As a consequence
we provide in   Corollary 3.0   a new proof of  [ 2 , Theorem 4.2]  showing that
real-rootedness of     f  ⁡   (  t  )    f(t)    implies that the coefficient sequence is the    f  f   -vector
of a multicomplex or equivalently the    h  h   -vector of a Cohen-Macaulay simplicial complex. 
  
  •  
 
 If      f  ⁡   (  t  )    =   1  +    (    x  1   1   )   ​  t   +  ⋯  +    (    x  d   d   )   ​   t  d      f(t)=1+\binom{x_{1}}{1}t+\cdots+\binom{x_{d}}{d}t^{d}    is a
real-rooted polynomial
with positive integer coefficients, and
     x  i   ≥   ⌈   x   i  +  1    ⌉    x_{i}\geq\lceil x_{i+1}\rceil    then there is a simplicial complex
   Δ  \Delta    such that     f  ⁡   (  t  )    f(t)    is the    f  f   -polynomial of    Δ  \Delta    (  Theorem 3.0  ). 
  
  •  
 
 A method based on Murai’s
 [ 16 ]  admissible vectors which can be
used to demonstrate that classical real-rooted
polynomials (Eulerian, Stirling, derangement)
are    f  f   -polynomials of simplicial complexes.
For Eulerian polynomials this is a known result (see  [ 10 ,  7 ] ). 
  
  •  
 
 Proofs that classical constructions preserving real-rootedness
applied to    f  f   -polynomials      f  Δ   ​   (  t  )    f^{\Delta}(t)    of simplicial complexes yield the    f  f   -polynomial of another
simplicial complex (see   Section 4  ). 
  
 
 
 
 
  2.  Notation, definitions and basic results 

 
 For a finite set    Ω  \Omega   ,  a simplicial complex  over ground set    Ω  \Omega    is
a set of subsets of    Ω  \Omega    such that     σ  ⊆  τ  ∈  Δ   \sigma\subseteq\tau\in\Delta   
implies     σ  ∈  Δ   \sigma\in\Delta   .
We call a     σ  ∈  Δ   \sigma\in\Delta     a face  of    Δ  \Delta   
and  the dimension of a face     σ  \sigma    is      dim   (  σ  )    =    #  ​  σ   −  1    \dim(\sigma)=\#\sigma-1   .
 The dimension of    Δ  \Delta     is     max  ⁡    dim     σ  ∈  Δ      ⁡   (  σ  )     \max_{\sigma\in\Delta}\dim(\sigma)   .
If    Δ  \Delta    is a    d  d   -dimensional simplicial complex then the
vector      f  Δ   =   (   f   −  1   Δ   ,  …  ,   f  d  Δ   )    f^{\Delta}=(f_{-1}^{\Delta},\ldots,f_{d}^{\Delta})    where
     f  i  Δ   =   #  ⁡   {   σ  ∈  Δ   |    dim   (  σ  )    =  i   }     f_{i}^{\Delta}=\#\big\{\,\sigma\in\Delta~\big|~\dim(\sigma)=i\,\big\}   
is called the    f  f    -vector  of    Δ  \Delta   
and       f  Δ   ​   (  t  )    =    f   −  1   Δ   +    f  0  Δ   ​  t   +  ⋯  +    f  d  Δ   ​   t   d  +  1       f^{\Delta}(t)=f_{-1}^{\Delta}+f_{0}^{\Delta}t+\cdots+f_{d}^{\Delta}t^{d+1}    is called the    f  f    -polynomial  of    Δ  \Delta   .

with coefficient sequence      h  Δ   =   (   h  0  Δ   ,  …  ,   h   d  +  1   Δ   )    h^{\Delta}=(h_{0}^{\Delta},\ldots,h_{d+1}^{\Delta})     the    h  h   -vector  of    Δ  \Delta   .
For a face     F  ∈  Δ   F\in\Delta   , denote by      lk  Δ    (  F  )   =   {  G  :  F  ∪  G  ∈  Δ  ,  F  ∩  G  =  ∅  }    \mathrm{lk}_{\Delta}(F)=\big\{\,G\,:\,F\cup G\in\Delta,F\cap G=\emptyset\,\big\}     the link  of    F  F    in    Δ  \Delta   . 
 
 
 It is well-known that the    f  f   -vector of a simplicial complex can be characterized in terms of functions based upon the following expression of a positive integer
   m  m    as a sum of binomial coefficients.
Given a positive integer    i  i   , there exists a unique representation of    m  m    in the form 
 

  
  
      m  =    (    a  i   i   )   +   (    a   i  −  1     i  −  1    )   +  ⋯  +   (    a  j   j   )     ,   m=\binom{a_{i}}{i}+\binom{a_{i-1}}{i-1}+\cdots+\binom{a_{j}}{j},    
    
 
 where      a  i   >   a   i  −  1    >  ⋯  >   a  j   ≥  j  ≥  1   a_{i}>a_{i-1}>\cdots>a_{j}\geq j\geq 1   .
We refer to this representation of    m  m    as the    i  i     th    binomial expansion  of    m  m   .
Since the binomial representation of    m  m    is unique it follows that 
 
 
 

  
  (1)  
  
     m  =    (     a  i   i    )   +   (     a   i  −  1     i  −  1     )   +  ⋯  +   (     a  j   j    )     \displaystyle m=\binom{a_{i}}{i}+\binom{a_{i-1}}{i-1}+\cdots+\binom{a_{j}}{j}    
        <   (      a  i   +  1   i    )    .   \displaystyle<\binom{a_{i}+1}{i}.    
    
 
 
 
 Define the functions      (   μ  i   )    i  ≥  1    (\mu_{i})_{i\geq 1}    and      (   κ  i   )    i  ≥  1    (\kappa_{i})_{i\geq 1}    on    ℕ  \mathbb{N}    by 
 

  
  
       μ  i   ​   (  m  )    =    (    a  i    i  −  1    )   +   (    a   i  −  1     i  −  2    )   +  ⋯  +   (    a  j    j  −  1    )     \mu_{i}(m)=\binom{a_{i}}{i-1}+\binom{a_{i-1}}{i-2}+\cdots+\binom{a_{j}}{j-1}    
    
 
 and 
 

  
  
        κ  i   ​   (  m  )    =    (     a  i   −  1    i  −  1    )   +   (     a   i  −  1    −  1    i  −  2    )   +  ⋯  +   (     a  j   −  1    j  −  1    )     .   \kappa_{i}(m)=\binom{a_{i}-1}{i-1}+\binom{a_{i-1}-1}{i-2}+\cdots+\binom{a_{j}-1}{j-1}.    
    
 
 The characterization of    f  f   - and    h  h   -vectors of simplicial complexes are due to Kruskal  [ 13 ] , Katona  [ 12 ]  independently and Macaulay  [ 15 ]  respectively. Note that in combinatorial terms Macaulay’s result characterizes    f  f   -vectors of multicomplexes which is equivalent to being the    h  h   -vector of a Cohen-Macaulay simplicial complex, see e.g.  [ 18 ]  for
the equivalence and the definition of Cohen-Macaulay simplicial complexes. 
 
 
   Theorem 2.0     (Kruskal-Katona, Macaulay) .  
 
  Let     f  =   (  1  ,   f  0   ,  …  ,   f   d  −  1    )    f=(1,f_{0},\dots,f_{d-1})    be a vector of positive integers. Then  
 
  •  
 
    f  f     is an     f  f    -vector of a simplicial complex if and only if        μ   i  +  1    ​   (   f  i   )    ≤   f   i  −  1     \mu_{i+1}(f_{i})\leq f_{i-1}     for      0  ≤  i  ≤   d  −  1    0\leq i\leq d-1    .  
  
  •  
 
    f  f     is an     h  h    -vector of a Cohen-Macaulay simplicial complex if and only if        κ   i  +  1    ​   (   f  i   )    ≤   f   i  −  1     \kappa_{i+1}(f_{i})\leq f_{i-1}     for      0  ≤  i  ≤   d  −  1    0\leq i\leq d-1    .  
  
 
 
 
 
 As usual, for example in the contexts of Newton’s generalized binomial
formula, we consider the binomial coefficient     (   n  k   )   \binom{n}{k}    as
a polynomial function in    n  n   , so that for     x  ∈  ℝ   x\in\mathbb{R}    we have 
 

  
  
       (   x  k   )   =    x  (  x  −  1  )  ⋯  (  x  −  k  +  1  )    k  !     .   \binom{x}{k}=\frac{x(x-1)\cdots(x-k+1)}{k!}.    
    
 
 We also write      (  x  )   k   (x)_{k}    for the numerator     x   (  x  −  1  )   ⋯   (  x  −  k  +  1  )    x(x-1)\cdots(x-k+1)   .
The following lemma recalls some well known facts about binomial coefficients. 
 
 
   Lemma 2.1   .  
 
 
  (i)  
 
  For any      x  ∈  ℝ   x\in\mathbb{R}     and any      0  <  k  ∈  ℕ   0<k\in\mathbb{N}     we have
       (   x  k   )   +   (   x   k  −  1    )    =   (    x  +  1   k   )    \binom{x}{k}+\binom{x}{k-1}=\binom{x+1}{k}    .  
  
  (ii)  
 
  For any      0  ≤  y  ∈  ℝ   0\leq y\in\mathbb{R}     and any      0  <  k  ∈  ℕ   0<k\in\mathbb{N}     there is
a unique      x  ≥   k  −  1    x\geq k-1     such that      y  =   (   x  k   )    y=\binom{x}{k}    .  
  
 
 
 
 
 Proof. 
 
  Part (i) is a trivial calculation. The second assertion follows
from the fact that     k  −  1   k-1    is the largest root of the
   k  k    real roots of     (   x  k   )   \binom{x}{k}   . Hence     (   x  k   )   \binom{x}{k}    is strictly
monotone for     x  ≥   k  −  1    x\geq k-1    with limit     +  ∞   +\infty   .
∎  
 
 
 
 By   Lemma 2.1   any polynomial      f  ⁡   (  t  )    =   1  +    y  1   ​  t   +  ⋯  +    y  d   ​   t  d      f(t)=1+y_{1}t+\cdots+y_{d}t^{d}    with coefficients      y  i   ≥  0   y_{i}\geq 0    there
are uniquely defined real numbers      x  i   ≥   i  −  1    x_{i}\geq i-1    such that such that
     f  ⁡   (  t  )    =   1  +    (    x  1   1   )   ​  t   +  ⋯  +    (    x  d   d   )   ​   t  d      f(t)=1+\binom{x_{1}}{1}t+\cdots+\binom{x_{d}}{d}t^{d}   . We call     (   x  1   ,  …  ,   x  d   )   (x_{1},\ldots,x_{d})    the  binomial
expansion  of     f  ⁡   (  t  )    f(t)    or of its  coefficient sequence . 
 
 
 
  3.  Real-rooted polynomials with positive integer coefficients 

 
 While   Question 1.0   remains open, we provide three different approaches to advancing our ability to answer it. 
 
 
  3.1.  First approach 

 
 We answer a special case of   Question 1.0   by describing a subset of real-rooted polynomials in     ℕ  ⁡   [  t  ]    \mathbb{N}[t]    which are provably    f  f   -polynomials of simplicial complexes. 
 
 
 Before we can formulate our first main results we recall the following definition. We say that a polynomial
     a  0   +    a  1   ​  t   +  ⋯  +    a  d   ​   t  d     a_{0}+a_{1}t+\cdots+a_{d}t^{d}    of degree    d  d    is  ultra log-concave  if 
 

  
  
       [    a  i    (   d  i   )    ]   2   ≥     a   i  −  1    ​   a   i  +  1       (   d   i  −  1    )   ​   (   d   i  +  1    )      \Big[\,\frac{a_{i}}{\binom{d}{i}}\,\Big]^{2}\geq\frac{a_{i-1}a_{i+1}}{\binom{d}{i-1}\binom{d}{i+1}}    
    
 
 for     1  ≤  i  ≤   d  −  1    1\leq i\leq d-1   . This concept is motivated by Newton’s result showing that
any real-rooted polynomial with non-negative coefficients has an
ultra log-concave coefficient sequence (see for example  [ 3 , Lemma 7.1.1] ). 
 
 
   Theorem 3.0   .  
 
  Let      f  ⁡   (  t  )    =   1  +    (    x  1   1   )   ​  t   +  ⋯  +    (    x  d   d   )   ​   t  d      f(t)=1+\binom{x_{1}}{1}t+\cdots+\binom{x_{d}}{d}t^{d}    in      ℝ     ≥  0    ​   [  t  ]    \mathbb{R}_{\geq 0}[t]    with      x  d   ≥  d   x_{d}\geq d    be an ultra log-concave polynomial.
Then
     x  1   ≥   x  2   ≥  ⋯  ≥   x  d    x_{1}\geq x_{2}\geq\cdots\geq x_{d}   .  
 
 
 
 Proof. 
 
  By ultra log-concavity we have  
 

  
  (2)  
  
       [     (    x  i   i   )    (   d  i   )     ]   2   ≥      (    x   i  −  1     i  −  1    )    (   d   i  −  1    )     ​     (    x   i  +  1     i  +  1    )    (   d   i  +  1    )     ​   for   ​  2   ≤  i  ≤   d  −  1    \displaystyle\left[\frac{\binom{x_{i}}{i}}{\binom{d}{i}}\right]^{2}\geq\frac{\binom{x_{i-1}}{i-1}}{\binom{d}{i-1}}\frac{\binom{x_{i+1}}{i+1}}{\binom{d}{i+1}}\text{ for }2\leq i\leq d-1    
    
 
  and  
 

  
  (3)  
  
        [     (    x  1   1   )    (   d  1   )     ]   2   ≥     (    x  2   2   )    (   d  2   )      .   \displaystyle\left[\frac{\binom{x_{1}}{1}}{\binom{d}{1}}\right]^{2}\geq\frac{\binom{x_{2}}{2}}{\binom{d}{2}}.    
    
 
 
 
  Claim:  For integers     1  ≤  i  ≤   d  −  1    1\leq i\leq d-1    we have 
 

  
  
         (    x  i   i   )    (   d  i   )    i   ≥     (    x  i   i   )    (   d  i   )     i  +  1     .   \sqrt[i]{\frac{\binom{x_{i}}{i}}{\binom{d}{i}}}\geq\sqrt[i+1]{\frac{\binom{x_{i}}{i}}{\binom{d}{i}}}.    
    
 
 
 
  We prove the claim be induction on    i  i   . For     i  =  1   i=1    the assertion follows
immediately from (  3  ). Now let     i  >  1   i>1   .
Using (  2  ) and the induction hypothesis for     i  −  1   i-1    we get  
 

  
  
        [     (    x  i   i   )    (   d  i   )     ]   2   ​   ≥   (    2    )    ​     (    x   i  −  1     i  −  1    )    (   d   i  −  1    )     ​     (    x   i  +  1     i  +  1    )    (   d   i  +  1    )     ​   ≥  Induction   ​    [     (    x  i   i   )    (   d  i   )     ]     i  −  1   i    ​     (    x   i  +  1     i  +  1    )    (   d   i  +  1    )      .   \displaystyle\left[\frac{\binom{x_{i}}{i}}{\binom{d}{i}}\right]^{2}\overset{\text{\eqref{NI}}}{\geq}\frac{\binom{x_{i-1}}{i-1}}{\binom{d}{i-1}}\frac{\binom{x_{i+1}}{i+1}}{\binom{d}{i+1}}\overset{\text{Induction}}{\geq}\left[\frac{\binom{x_{i}}{i}}{\binom{d}{i}}\right]^{\frac{i-1}{i}}\frac{\binom{x_{i+1}}{i+1}}{\binom{d}{i+1}}.    
    
 
  Now cancelling      (    x  i   i   )    (   d  i   )    \frac{\binom{x_{i}}{i}}{\binom{d}{i}}    in the left and right terms and taking the     (   i  −  1   )   (i-1)    st  root yields the claim.  
 
 
  The claim immediately implies the following inequalities
