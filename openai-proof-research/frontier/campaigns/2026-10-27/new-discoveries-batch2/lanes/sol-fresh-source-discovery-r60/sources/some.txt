  Abstract. 
    
 The    n  n   -dimensional lattice polytopes
    𝒬   n  ,  k    \mathcal{Q}_{n,k}   
obtained by intersecting the    n  n   th dilate of the
standard    n  n   -dimensional simplex in     ℝ  n   \mathbb{R}^{n}   
with the half-spaces      x  i   ≤  1   x_{i}\leq 1    for     1  ≤  i  ≤  k   1\leq i\leq k   
form an interesting special case of Chapoton’s arbor
polytopes. They interpolate between the    n  n   th
dilate of the standard    n  n   -dimensional simplex and
the standard    n  n   -dimensional cube in     ℝ  n   \mathbb{R}^{n}   .
This paper provides an
explicit combinatorial interpretation of the
    h  ∗   h^{\ast}   -polynomial of     𝒬   n  ,  k    \mathcal{Q}_{n,k}   , as
the ascent enumerator of certain words, and partly
confirms some of Chapoton’s conjectures on the
lattice point enumeration of arbor polytopes in
this special case. More specifically, the Ehrhart
polynomial of     𝒬   n  ,  k    \mathcal{Q}_{n,k}    is shown to be
magic positive, by means of a new combinatorial
parking model for cars, and the real-rootedness
of its     h  ∗   h^{\ast}   -polynomial is deduced. The
polynomial whose coefficients count the lattice
points of     𝒬   n  ,  k    \mathcal{Q}_{n,k}    by the number of
their nonzero coordinates is shown to be
gamma-positive and a combinatorial
interpretation of the     h  ∗   h^{\ast}   -polynomial of
any arbor polytope is conjectured. 
  
 
 
  1.  Introduction 

 
 Given a positive integer    n  n    and     k  ∈   {   0  ,  1  ,  …  ,  n   }    k\in\{0,1,\dots,n\}   , we will be primarily interested in
the polytope     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    in     ℝ  n   {\mathbb{R}}^{n}    defined by the
inequalities 
 

  
  (1)  
  
 
 
 
 
      x  i   ≥  0   x_{i}\geq 0     for     1  ≤  i  ≤  n   1\leq i\leq n   ,   
 
      x  i   ≤  1   x_{i}\leq 1     for     1  ≤  i  ≤  k   1\leq i\leq k   ,
and   
 
       x  1   +   x  2   +  ⋯  +   x  n    ≤  n   x_{1}+x_{2}+\cdots+x_{n}\leq n    ,   
 
  
    
 
 where      x  1   ,   x  2   ,  …  ,   x  n    x_{1},x_{2},\dots,x_{n}    are the standard
coordinates of     ℝ  n   {\mathbb{R}}^{n}   . This    n  n   -dimensional
lattice polytope specializes to the    n  n   th dilate
of the standard    n  n   -dimensional simplex and to
the standard    n  n   -dimensional cube in     ℝ  n   {\mathbb{R}}^{n}   
for     k  =  0   k=0    and     k  =  n   k=n   , respectively. 
 
 
 The polytopes     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    belong to the class of
arbor polytopes, introduced and studied by
Chapoton  [ 8 ] . Let us recall their
definition. An  arbor  on the ground set      [  n  ]   :=   {   1  ,  2  ,  …  ,  n   }    [n]:=\{1,2,\dots,n\}    is a rooted tree with vertices
the blocks of a partition of     [  n  ]   [n]   . We call    n  n   
the  size  of the arbor. Given such an arbor
   τ  \tau   , the polytope     𝒬  τ   {\mathcal{Q}}_{\tau}    in     ℝ  n   {\mathbb{R}}^{n}    is
defined by the inequalities      x  i   ≥  0   x_{i}\geq 0    for     i  ∈   [  n  ]    i\in[n]    and 
 

  
  
       ∑   i  ∈   𝒟  ⁡   (  v  )       x  i    ≤   |   𝒟  ⁡   (  v  )    |    \sum_{i\in{\mathcal{D}}(v)}x_{i}\leq|{\mathcal{D}}(v)|    
    
 
 for all vertices    v  v    of    τ  \tau   , where     𝒟  ⁡   (  v  )    {\mathcal{D}}(v)    is
the union of all vertices which are descendants of
   v  v    in    τ  \tau    (including    v  v    itself). Thus,       x  1   +   x  2   +  ⋯  +   x  n    ≤  n   x_{1}+x_{2}+\cdots+x_{n}\leq n    is the inequality
which corresponds to the root of    τ  \tau   . It was
verified in  [ 8 , Section 1]  that
    𝒬  τ   {\mathcal{Q}}_{\tau}    is an    n  n   -dimensional lattice polytope
(all vertices of     𝒬  τ   {\mathcal{Q}}_{\tau}    belong to     ℕ  n   {\mathbb{N}}^{n}   )
which is simple (every vertex is an endpoint of
exactly    n  n    edges of     𝒬  τ   {\mathcal{Q}}_{\tau}   ). 
 
 
 Chapoton  [ 8 ]  formulated a number of
intriguing conjectures on the lattice point
enumeration of arbor polytopes. The first of
these concerns the vector      h  ⁡   (  τ  )    =    (    h  i   ​   (  τ  )    )    0  ≤  i  ≤  n     h(\tau)=(h_{i}(\tau))_{0\leq i\leq n}   , where      h  i   ​   (  τ  )    h_{i}(\tau)   
is the number of points in      𝒬  τ   ∩   ℕ  n    {\mathcal{Q}}_{\tau}\cap{\mathbb{N}}^{n}   
which have exactly    i  i    nonzero coordinates. 
 
 
   Conjecture 1.1   .  
 
 ( [ 8 , Conjecture 0.1] ) 

The vector     h  ⁡   (  τ  )    h(\tau)    is equal to the    h  h   -vector of
an    n  n   -dimensional simplicial polytope for every
arbor    τ  \tau    of size    n  n   . In particular,     h  ⁡   (  τ  )    h(\tau)   
is palindromic and unimodal.  
 
 
 
 The palindromicity of     h  ⁡   (  τ  )    h(\tau)    (meaning, the
statement that       h  i   ​   (  τ  )    =    h   n  −  i    ​   (  τ  )     h_{i}(\tau)=h_{n-i}(\tau)    for
    0  ≤  i  ≤  n   0\leq i\leq n   ) is by itself nontrivial. It
would imply that the generating polynomial
     h  ⁡   (  τ  ,  t  )    =    ∑   i  =  0   n     h  i   ​   (  τ  )   ​   t  i      h(\tau,t)=\sum_{i=0}^{n}h_{i}(\tau)t^{i}    of
    h  ⁡   (  τ  )    h(\tau)    can be written uniquely in the form 
 

  
  (2)  
  
      h  ⁡   (  τ  ,  t  )    =    ∑   i  =  0    ⌊   n  /  2   ⌋      γ  i   ​   (  τ  )   ​   t  i   ​    (   1  +  t   )    n  −   2  ​  i        h(\tau,t)=\sum_{i=0}^{\lfloor n/2\rfloor}\gamma_{i}(\tau)t^{i}(1+t)^{n-2i}    
    
 
 for some integers       γ  0   ​   (  τ  )    ,    γ  1   ​   (  τ  )   ​  …   ,    γ   ⌊   n  /  2   ⌋    ​   (  τ  )     \gamma_{0}(\tau),\gamma_{1}(\tau)\dots,\gamma_{\lfloor n/2\rfloor}(\tau)   .
The nonnegativity of these numbers, known as
    γ  \gamma   -positivity  (see  [ 1 ] 
for a survey of this important notion), is
stronger than the palindromicity and unimodality
of     h  ⁡   (  τ  ,  t  )    h(\tau,t)   . The    γ  \gamma   -positivity of
    h  ⁡   (  τ  ,  t  )    h(\tau,t)    was implicitly conjectured in
 [ 8 , Section 0.1]  as well. 
 
 
 The second main conjecture of  [ 8 ] 
concerns the Ehrhart polynomials of arbor
polytopes. We recall from
 [ 15 , Section 4.6]  (see also  [ 9 ] 
and references therein) that the  Ehrhart
polynomial  of a lattice polytope     𝒬  ⊂   ℝ     ≥  0   n    {\mathcal{Q}}\subset{\mathbb{R}}_{\geq 0}^{n}    is the unique polynomial
    Ehr  ⁡   (  𝒬  ,  t  )    {\rm Ehr}({\mathcal{Q}},t)    with the property that
     Ehr  ⁡   (  𝒬  ,  m  )    =   #  ⁡   (    m  ​  𝒬   ∩   ℕ  n    )     {\rm Ehr}({\mathcal{Q}},m)=\#(m{\mathcal{Q}}\cap{\mathbb{N}}^{n})    for every
    m  ∈  ℕ   m\in{\mathbb{N}}   . The      h  ∗   h^{\ast}   -polynomial 
     h  ∗   ​   (  𝒬  ,  t  )    h^{\ast}({\mathcal{Q}},t)    of    𝒬  {\mathcal{Q}}    is defined by the
equation 
 

  
  (3)  
  
        ∑   m  ≥  0      Ehr  ⁡   (  𝒬  ,  m  )    ​   t  m     =     h  ∗   ​   (  𝒬  ,  t  )      (   1  −  t   )    d  +  1      ,   \sum_{m\geq 0}{\rm Ehr}({\mathcal{Q}},m)t^{m}=\frac{h^{\ast}({\mathcal{Q}},t)}{(1-t)^{d+1}},    
    
 
 where     d  =   dim   (  𝒬  )     d=\dim({\mathcal{Q}})   . The     h  ∗   h^{\ast}   -polynomial
always has nonnegative coefficients, a property
which may fail for the Ehrhart polynomial; see,
for instance,  [ 9 , Section 4] . An old
theorem of Brenti  [ 7 , Theorem 4.4.4] 
implies that if all roots of     Ehr  ⁡   (  𝒬  ,  t  )    {\rm Ehr}({\mathcal{Q}},t)    are
real and lie in the interval     [    −  1   ,  0   ]   [-1,0]   , then all
roots of      h  ∗   ​   (  𝒬  ,  t  )    h^{\ast}({\mathcal{Q}},t)    are real as well. 
 
 
   Conjecture 1.2   .  
 
 ( [ 8 , Conjecture 2.2] ) 

For every arbor    τ  \tau   , all roots of the
Ehrhart polynomial of     𝒬  τ   {\mathcal{Q}}_{\tau}    are real and lie
in the interval     [    −  1   ,  0   ]   [-1,0]   . In particular, the
    h  ∗   h^{\ast}   -polynomial of     𝒬  τ   {\mathcal{Q}}_{\tau}    has only real
roots.  
 
 
 
 The real-rootedness of      h  ∗   ​   (   𝒬  τ   ,  t  )    h^{\ast}({\mathcal{Q}}_{\tau},t)    is
implied by a weaker property of the Ehrhart
polynomial. One may express this polynomial as 
 

  
  (4)  
  
       n  !   ​  Ehr  ​   (   𝒬  τ   ,  t  )    =    ∑   i  =  0   n     c  i   ​   (  τ  )   ​   t  i   ​    (   1  +  t   )    n  −  i       n!\,{\rm Ehr}({\mathcal{Q}}_{\tau},t)=\sum_{i=0}^{n}c_{i}(\tau)t^{i}(1+t)^{n-i}    
    
 
 for some integers       c  0   ​   (  τ  )    ,    c  1   ​   (  τ  )    ,  …  ,    c  n   ​   (  τ  )     c_{0}(\tau),c_{1}(\tau),\dots,c_{n}(\tau)   . Following  [ 9 ] ,
we call     Ehr  ⁡   (   𝒬  τ   ,  t  )    {\rm Ehr}({\mathcal{Q}}_{\tau},t)     magic positive 
if these integers are nonnegative. A theorem of
Brändén  [ 6 , Theorem 4.2]  implies in
this situation that      h  ∗   ​   (   𝒬  τ   ,  t  )    h^{\ast}({\mathcal{Q}}_{\tau},t)    has
only real roots. Thus, one may attempt to prove
the real-rootedness of the     h  ∗   h^{\ast}   -polynomial of
    𝒬  τ   {\mathcal{Q}}_{\tau}    by providing a combinatorial
interpretation of these integers. 
 
 
 Conjecture   1.1   and the
   γ  \gamma   -positivity of     h  ⁡   (  τ  ,  t  )    h(\tau,t)    were
verified in the special case of linear arbors
in  [ 2 ] . The aim of this paper is to
address these questions for the polytopes
    𝒬   n  ,  k    {\mathcal{Q}}_{n,k}   . This polytope is simply the arbor
polytope associated to the arbor     τ   n  ,  k    \tau_{n,k}   
which has the     (   n  −  k   )   (n-k)   -element set
    {    k  +  1   ,   k  +  2   ,  …  ,  n   }   \{k+1,k+2,\dots,n\}    as its root and the
singletons     {  i  }   \{i\}    for     i  ∈   [  k  ]    i\in[k]    as the leaves
of the root (one may call such an arbor an
 octopus ). Here are two of our main
results for     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}   . 
 
 
   Theorem 1.3   .  
 
  The polynomial     h  ⁡   (   τ   n  ,  k    ,  t  )    h(\tau_{n,k},t)    is
   γ  \gamma   -positive and, in particular, palindromic
and unimodal, for all     n  ,  k   n,k   .  
 
 
 
   Theorem 1.4   .  
 
  We have  
 

  
  (5)  
  
       n  !   ​  Ehr  ​   (   𝒬   n  ,  k    ,  t  )    =    ∑   i  =  0   n     c  i   ​   t  i   ​    (   1  +  t   )    n  −  i       n!\,{\rm Ehr}({\mathcal{Q}}_{n,k},t)=\sum_{i=0}^{n}c_{i}t^{i}(1+t)^{n-i}    
    
 
  for some nonnegative integers      c  0   ,   c  1   ,  …  ,   c  n    c_{0},c_{1},\dots,c_{n}   . In particular, the
    h  ∗   h^{\ast}   -polynomial of     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    has only real
roots.  
 
 
 
 Our third main result for     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    is an
explicit combinatorial interpretation of its
    h  ∗   h^{\ast}   -polynomial. The sum of the coefficients
of this polynomial is known to equal the
normalized volume of     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    (defined as the
volume of     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    multiplied by     n  !   n!   ). One
can easily verify (for example, as a
consequence of Equation (  8  ) in
Section   3  ) that the normalized
volume of     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    is equal to the number of
maps     f  :    [  n  ]   →   [  n  ]     f:[n]\rightarrow[n]    which contain the set     [  k  ]   [k]   
in their image (this is a reason to expect apriori
that     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    may have interesting lattice point
enumerative properties). The following statement
is a natural refinement of this observation. We
recall that     des  ⁡   (  w  )    {\rm des}(w)    denotes the number of
descents of a word     w  =   (   w  1   ,   w  2   ,  …  ,   w  n   )   ∈    [  n  ]   n    w=(w_{1},w_{2},\dots,w_{n})\in[n]^{n}   , meaning indices     i  ∈   [   n  −  1   ]    i\in[n-1]    such that
     w  i   >   w   i  +  1     w_{i}>w_{i+1}   . 
 
 
   Theorem 1.5   .  
 
  We have  
 

  
  (6)  
  
        h  ∗   ​   (   𝒬   n  ,  k    ,  t  )    =    ∑   w  ∈   𝒲   n  ,  k       t   n  −  1  −   des  ⁡   (  w  )        ,   h^{\ast}({\mathcal{Q}}_{n,k},t)=\sum_{w\in{\mathcal{W}}_{n,k}}t^{n-1-{\rm des}(w)},    
    
 
  where     𝒲   n  ,  k    {\mathcal{W}}_{n,k}    is the set of words     w  ∈    [  n  ]   n    w\in[n]^{n}    in which each of     1  ,  2  ,  …  ,  k   1,2,\dots,k    appears
at least once.  
 
 
  In particular, the right-hand
side of (  6  ) has only real roots
for all     n  ,  k   n,k   .

Section   2   by means of an explicit

Proposition   2.2  ) for the
coefficients      γ  i   ​   (   τ   n  ,  k    )    \gamma_{i}(\tau_{n,k})    of

Theorems   1.4   and   1.5

  2.  Gamma-positivity 

 
 This section proves Theorem   1.3  .
That result is a consequence of the explicit
formula of Proposition   2.2  . The
proof is rather computational; we leave the task
to find a bijective proof as an interesting
open problem. 
 
 
 The following lemma is a direct consequence
of the definition of     h  ⁡   (   τ   n  ,  k    ,  t  )    h(\tau_{n,k},t)   . 
 
 
   Lemma 2.1   .  
 
  For every positive integer    n  n    and every     k  ∈   {   0  ,  1  ,  …  ,  n   }    k\in\{0,1,\dots,n\}   ,  
 

  
  
        t  n   ​  h  ​   (   τ   n  ,  k    ,   1  /  t   )    =    ∑   j  =  0   n     ∑   i  =  0    n  −  k      (    n  −  k   i   )   ​   (   k   j  −  i    )   ​   (      n  −  k   +  j   −  i   j   )   ​   t  j       .   t^{n}h(\tau_{n,k},1/t)=\sum_{j=0}^{n}\sum_{i=0}^{n-k}{n-k\choose i}{k\choose j-i}{n-k+j-i\choose j}t^{j}.    
    
 
 
 
 
 Proof. 
 
  The lattice points in     𝒬   n  ,  k    {\mathcal{Q}}_{n,k}    are the vectors
    x  =   (   x  1   ,   x  2   ,  …  ,   x  n   )   ∈   ℕ  n    x=(x_{1},x_{2},\dots,x_{n})\in{\mathbb{N}}^{n}    which satisfy
(  1  ). Given     j  ∈   {   0  ,  1  ,  …  ,  n   }    j\in\{0,1,\dots,n\}   ,
we need to show that the number of these vectors
which have exactly    j  j    zero coordinates is equal
to  
 

  
  
       ∑   i  =  0    n  −  k      (    n  −  k   i   )   ​   (   k   j  −  i    )   ​   (      n  −  k   +  j   −  i   j   )     .   \sum_{i=0}^{n-k}{n-k\choose i}{k\choose j-i}{n-k+j-i\choose j}.    
    
 
  To enumerate these elements, let    i  i    be the
number of zero coordinates among      x   k  +  1    ,  …  ,   x  n    x_{k+1},\dots,x_{n}   .
There are     (    n  −  k   i   )   {n-k\choose i}    ways to choose these
coordinates and     (   k   j  −  i    )   {k\choose j-i}    ways to choose
the remaining zero coordinates of    x  x   . The      k  −  j   +  i   k-j+i   
nonzero coordinates among      x  1   ,   x  2   ,  …  ,   x  k    x_{1},x_{2},\dots,x_{k}    must
all be equal to 1. The remaining     n  −  k  −  i   n-k-i    nonzero
coordinates of    x  x    have sum no larger than       n  −  k   +  j   −  i   n-k+j-i   . Thus, they can be chosen in     (      n  −  k   +  j   −  i   j   )   {n-k+j-i\choose j}    ways and the proof follows.
∎  
 
 
 
   Proposition 2.2   .  
 
  We have  
 

  
  
      h  ⁡   (   τ   n  ,  k    ,  t  )    =    ∑   i  =  0    ⌊   n  /  2   ⌋      (    n  −  k   i   )   ​   (    n  −  i   i   )   ​   t  i   ​    (   1  +  t   )    n  −   2  ​  i        h(\tau_{n,k},t)=\sum_{i=0}^{\lfloor n/2\rfloor}{n-k\choose i}{n-i\choose i}t^{i}(1+t)^{n-2i}    
    
 
  for all     n  ,  k   n,k   . In particular,     h  ⁡   (   τ   n  ,  k    ,  t  )    h(\tau_{n,k},t)    is
   γ  \gamma   -positive, and hence palindromic and unimodal.

appear a total of at least     |   𝒟  ⁡   (  v  )    |   |{\mathcal{D}}(v)|    times in
   w  w   .  
 
 
 
 The validity of this statement is unclear even
for linear arbors, studied in  [ 2 ] . An
even more general conjecture will appear
in  [ 3 ] .
