                                                                                                  Abstract
                                                   A block graph is a graph in which every block is a complete graph (clique). Let G be a block graph and
                                               let A(G) be its (0,1)-adjacency matrix. Graph G is called nonsingular (singular) if A(G) is nonsingular
                                               (singular). Characterizing nonsingular block graphs, other than trees, is an interesting open problem. In
                                               this article, we give some classes of nonsingular and singular block graphs and related conjectures.
                                         Key words. block, block graph, nonsingular graph, nullity
                                         AMS Subject Classifications. 15A15, 05C05.


                                         1     Introduction
                                         Let G = (V (G), E(G)) be a simple graph with the vertex set V (G) and the edge set E(G). Let the cardinality
                                         |V (G)| (also called as the order of G) be equal to n. The adjacency matrix A(G) = (aij ) of G is the square
                                         matrix of order n defined by
                                                                           (
                                                                             1 if the vertices i, j are connected by an edge,
                                                                     aij =
                                                                             0 if i = j or i, j are not connected by an edge,

                                         where 1 ≤ i, j ≤ n. Graph G is called nonsingular (singular) if A(G) is nonsingular (singular). Rank of G,
                                         denoted by r(G) is the rank of the adjacency matrix A(G). If G is full rank, that is, r(G) = n, then G is
                                         nonsingular, otherwise, singular. The nullity of G is equal to the number of zero eigenvalue of A(G). A block
                                         in a graph is a maximal connected subgraph that has no cut-vertex ([16], p.15). Note that if a connected
                                         graph has no cut-vertex, then it itself is a block. A block in a graph G is called a pendant block if it has at
                                         most one cut-vertex of G. A complete graph (clique) on n vertices is denoted Kn . If every block of a graph
                                         is a complete graph then it is called a block graph. Except Figure 2b, all the graphs in the figures of this
                                         paper are block graphs. For more graph theoretic preliminaries see [16, 1]. For more details on the block
                                         graphs see ([1], Chapter 7).
                                             In 1957, Collatz and Sinogowitz proposed a well-known problem, to characterize graphs with positive
                                         nullity [15]. A zero nullity of a graph G implies that it is nonsingular while a positive nullity implies that it
                                         is singular. Nullity of graphs is applicable in various branches of science, in particular, quantum chemistry,
                                         Hückel molecular orbital theory [7, 10] and social network theory [11]. There has been significant work on the
                                         nullity of the undirected graphs like trees, unicyclic graphs and bicyclic graphs etc [5, 6, 8, 9, 12, 9, 2, 4, 17].
                                         We extend this study to block graphs. The combinatorial formulae for the determinant of the block graphs

    We frequently use the mathematical induction and elementary row or column operations to get the results.
It is to be noted that elementary operations on the adjacency matrix A(G), equivalently can be seen as the
change of weights on the edges and addition of loops on the vertices in G. Thus, during the proofs, we
frequently encounter graphs with some possible loops on the vertices. A positive (negative) loop is a loop
with positive (negative) weight on it. Also, on reordering of the vertices of G or of the graph resulting after
the elementary transformation keeps the determinant of G unchanged.
    Consider the complete graph Kn . If we add loops of nonpositive weights on r vertices, we denote the
resulting graph by Knr . That is, in Knr , there can be at most r vertices with negative loops. Although a loop
of zero weight is equivalent to no loop, still we use the notation Knr to maintain the generality throughout
the proofs. The matrix A(Knr ) is the resulting matrix on replacing the corresponding r diagonal entries in
A(Kn ) by nonpositive weights, we call it adjacency matrix of Knr . J, j, O, o denote the all-one matrix, all-one
column vector, zero matrix, zero column vector of suitable order, respectively. w denotes a (0, 1)-column
vector of suitable size, and wT denotes its transpose. Adding a connected graph G1 to another connected
graph G2 means coalescing vertices v1 and v2 , v1 ∈ G1 , v2 ∈ G2 , that is, in resulting graph v1 and v2 are the
same vertex which becomes a cut-vertex. If Q is a subgraph of G, then G \ Q denotes the induced subgraph
of G on the vertex subset V (G) \ V (Q). Here, V (G) \ V (Q) is the standard set-theoretic subtraction of vertex
sets.
    Rest of the paper is organised as the follows. In section 2 we consider the block graph which have no

Finally, in section 4 we consider some miscellaneous families of block graphs. Notations and classes of the
block graphs are defined in the respective sections.

                                       r(G) = r(G \ (B1 , B2 , . . . , Bt+1 )) + 2(t + 1).

     vertex Bt+1 \ v. Thus, G \ (B1 , B2 , . . . , Bt ) is singular which makes the rank of G less than the number
     of vertices in G, hence it is a singular graph.
  3. When m = t, notice that G \ (B1 , B2 , . . . , Bt ) is the disjoint union of the subgraphs B̆i , i = t + 1, . . . , k.
     Hence, the result follows.
  4. Notice that the t pendant edges B1 , B2 , . . . , Bt gives the total rank 2t, which makes their union nonsin-
     gular. These edges are vertex disjoint to the subgraph G\(B1 , B2 , . . . , Bt ). Hence, G will be nonsingular

4                Miscellaneous
In this section we consider singular and nonsingular block graphs which are mix of K2 forbidden and K2
allowed block graphs. In particular using B13 -block graph, (n, m, k)-block graphs and p1 -block graphs we can
generate different classes of singular and nonsingular block graphs.
Theorem 4.1. Let G be a p1 -block graph. If at some or all the cut-vertex of G, B13 -block graphs, nonsingular
(n, m, k)-block graphs or p1 -block graphs are added via edges then the resulting graph is nonsingular.
Proof. As B13 -block graphs, p1 -block graphs are nonsingular the proof follows using Theorem 3.8.
   Note that in general it is not necessary that if we add an edge between two nonsingular graphs then the
resulting graph is also nonsingular. The following lemma makes it clear.
Lemma 4.2. Let G1 and G2 be two nonsingular graphs (not necessarily block graphs). If we add an edge
between vertices v1 and v2 , v1 ∈ G1 , v2 ∈ G2 , then the resulting graph is singular if and only if

                                                                    det(G1 ) det(G2 ) = det(G1 \ v1 ) det(G2 \ v2 ).

Proof. Let G be the resulting graph. Then recursively using [14] (Lemma 2.3), at v1 and v2 ,

                                                               det(G) = det(G1 ) det(G2 ) + det(G1 \ v1 ) det(v1 ) det(G2 )
                                                   + det(G1 ) det(v2 ) det(G2 \ v2 ) + det(G1 \ v1 ) det(ev1 v2 ) det(G2 \ v2 ),

where, ev1 v2 is the edge between the vertices v1 and v2 . As det(ev1 v2 ) = −1, and the determinant of the
single vertex graph is zero,

                                                               det(G) = det(G1 ) det(G2 ) − det(G1 \ v1 ) det(G2 \ v2 ).


                                                                                            9
Now, as G1 and G2 are singular, G is nonsingular if and only if

                                      det(G1 ) det(G2 ) = det(G1 \ v1 ) det(G2 \ v2 ).

This completes the proof.
