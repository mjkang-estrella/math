Remark. Let us consider the problem of ﬁnding a complex solution of a polynomial
system with n variables and integer coeﬃcients. This problem reduces to the problem
of ﬁnding a real solution of some polynomial system with 2n variables and integer
coeﬃcients. Therefore, the problem of consistency over C of a polynomial system
with n variables and integer coeﬃcients reduces to the problem of consistency over R
of some polynomial system with 2n variables and integer coeﬃcients.

    Let us note three facts:

 (4) There is a ﬁnite number of non-empty subsets of En .

 (5) There is an algorithm for quantiﬁer elimination for (R, +, ·, 0, 1, =, ≤) (A. Tarski
       and A. Seidenberg, and later G. E. Collins with his cylindrical algebraic decom-
       position algorithm, see [1]). In particular, there is an algorithm checking the
       consistency over R of each ﬁnite system of polynomial equations with integer
       coeﬃcients.

 (6) Applying the cylindrical algebraic decomposition algorithm, for each consistent
       ﬁnite system of polynomial equations with n variables and integer coeﬃcients,
       we can determine a > 0 such that [−a, a]n contains a solution.

By the Remark and facts (4), (5), (6), we can ﬁnd computable γ and θ.
