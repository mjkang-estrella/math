                                                                                   1. Introduction
                                             Let K be a field and let L ⊆ K be finite. Following Bukh [2], an L-matrix is a square
                                           matrix over K whose diagonal entries are zero and whose off-diagonal entries belong to L.
                                           Matrices with prescribed entries arise naturally in linear algebraic methods in extremal
                                           combinatorics. For 0 ∈
                                                                / L and an integer r ≥ 0, Bukh studies the extremal function
                                                                
                                            NK (r, L) := max n ≥ 1 : there exists an n × n L-matrix over K of rank at most r .
                                           This function measures the largest possible order of an L-matrix subject to a rank
                                           constraint. Bukh investigates it using polynomial bounds and constructions from finite
                                           geometry. If 0 ∈ L, the possible orders are unbounded, since the zero matrix is an
                                           L-matrix of every order.
                                             For a three-element set L ⊆ K \ {0}, a standard polynomial argument gives a lower
                                           bound of order n1/3 for the rank of an n × n L-matrix. Bukh asks in [1, Problem 7]
                                           whether this order of magnitude can always be attained over Fp : for every prime p and
                                           every three-element set L ⊆ Fp , do there exist n × n L-matrices of rank Op,L (n1/3 ) for
                                           every n ≥ 1? In particular, he identifies L = {1, 4, 6} ⊆ F19 as the simplest open case.
                                             We answer this question for every prime p for which 2 generates the multiplicative
                                           group F×p.

Theorem 1.3. Let p be a prime such that 2 is a primitive root modulo p, and let L ⊆ Fp
be a three-element set. Then there exist a three-element set L′ ⊆ Z with L′ mod p = L
and a constant Cp,L > 0 such that, for every integer n ≥ 1, there exists a symmetric
L′ -matrix Mn ∈ Matn (Z) satisfying
                                   rkQ (Mn ) ≤ Cp,L n1/3 .

                                   NQ (r, L′ ) = Ωp,L (r3 ).

Outline of the proof. The proof uses two finite fields with different roles. An auxiliary
field Fq of characteristic two provides a set S ⊆ F3q of size D := (h − 1)q + h, where h
and q are powers of two. Its intersections with proper linear subspaces of F3q have sizes
in {0, 1, h}. We prove the required properties directly in Section 3.
   For an integer k ≥ 1, we set Q := q k and regard S as a subset of F3Q . We form the
incidence matrix with rows indexed by x ∈ F3Q , columns indexed by (v, t) ∈ S × FQ , and
entries recording whether v · x = t. Its entries are taken in Fp . Multiplying this matrix
by its transpose gives a square matrix with diagonal entries D mod p, off-diagonal entries
in {0, 1, h mod p}, and rank at most DQ. The primitive root hypothesis allows us to
choose h and q so that an affine transformation maps these three possible off-diagonal
values to the prescribed set L and sends D mod p to 0. Taking principal submatrices
then yields matrices of every order.
