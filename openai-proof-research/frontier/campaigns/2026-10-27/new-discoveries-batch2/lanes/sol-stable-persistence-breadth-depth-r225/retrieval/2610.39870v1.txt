                                                                                                 Abstract

                                                  We complete the determination of the minimum possible length of eight-dimensional binary
                                                  self-orthogonal codes with given minimum distance. For dimension nine we give exact
                                                  values and bounds for minimum distance at most 64. By exploiting the geometric reformu-
                                                  lation of linear codes as multisets of points, we fully redo the classification for dimension
                                                  at most seven in a simplified and computer-free manner. As a by-product we prove the
                                                  non-existence of [93, 9, 44]2 codes and show several divisibility results for putative optimal
                                                  nine-dimensional binary codes.
                                                  Keywords: self-orthogonal codes · linear codes · Griesmer bound · Galois geometry
                                                  2020 Mathematics Subject Classification: Primary 94B05; Secondary 51E21, 94B27, 94B65



                                           1     Introduction
                                           A linear code is called self-orthogonal if it is contained in its dual code w.r.t. the standard inner
                                           product. They have been studied since the theory of error-correcting codes transitioned from
                                           an engineering tool into a mathematical discipline, see e.g. [62]. There are e.g. connections to
                                           lattices [73], designs [2, 71], groups [20, 42], DNA codes [65, Section 8], and quantum error-
                                           correcting codes [15]. We call a linear [n, k, d]q code (length) optimal if there does not exist a
                                           linear [n′ , k, d]q with n′ < n. By nq (k, d) we denote the minimum possible length of an [n, k, d]q
                                           code. The function n2 (k, ·) is completely known for all k ≤ 8 [9]. The majority of the current
                                           knowledge on nq (k, d) can be looked up in the online table [32]. If we additionally require that
                                           the linear code has to be self-orthogonal we use the notation ñq (k, d) for the minimum possible
                                           length. In terms of distance optimality, ñ2 (4, ·) was completely determined in [57]. In a sequence
                                           of papers this was extended to ñ2 (k, ·) for all k ≤ 7, see [63] and the references cited therein.
                                           Here we completely determine ñ2 (8, ·), cf. [52] where the optimal parameters of 8-dimensional

2    Preliminaries
In this section we introduce the basic notation and first auxiliary results. We start with the
coding theoretic formulation in Subsection 2.1. The well-known reformulation of linear codes
as multisets of points in projective geometries, see e.g. [72, §1.1.2] or [26], is briefly outlined in
Subsection 2.2. For the reader’s sake we provide proofs whenever they are short, instructive, or
we did not find our precise formulation in the literature, see e.g. the characterization results for
binary self-orthogonal codes in Proposition 1 and Lemma 4. However, we claim no priority at
all. It is well known that the minimum possible length of a linear code with given dimension,
field size, and minimum distance d is given by the so-called Griesmer bound, see Inequality (1)
for all sufficiently large d and attained by the Solomon–Stiffler construction [33, 69]. If we
additionally require the linear codes to be self-orthogonal, we have to slightly modify the
Griesmer bound, see Inequality (5), and the attaining construction, see Subsection 2.2. In order
to make the paper self-contained we provide more technical details on the Griesmer bound and
the Solomon–Stiffler construction in Subsection 2.3.

Proposition 1. Let C be an [n, k]2 code, where k ≥ 2. Then, the following statements are equivalent:

 (A) C is SO.
 (B) C is even and the doubly-even codewords form a subcode of dimension k − 1 or k.
 (C) All residual codes are even.
 (D) The rows of a generator matrix G have even weights and are pairwise orthogonal.

Proof. Let us first assume that C is SO, i.e. property (A). Since ⟨c, c⟩ = 0 for every codeword
we have wt(c) ≡ 0 (mod 2), i.e. C is even. For two different codewords ⟨c, c′ ⟩ = 0 implies
| supp(c) ∩ supp(c′ )| = wt(c ⋆ c′ ) ≡ 0 (mod 2). Using Equation (2) we conclude that the sum
of two doubly-even codewords and the sum of two singly-even codewords is always doubly-
even, i.e. the set of doubly-even codewords forms a subcode of dimension at least k − 1. For a
codeword c′r ∈ Res(C, c) corresponding to c′ ∈ C Equation (4) gives wt(c′r ) ≡ 0 (mod 2), i.e., the
residual code is even.
    Now let us assume that C satisfies (B). Since C is even we have ⟨c, c⟩ = 0. For each pair of
different codewords c, c′ ∈ C property (B) implies that the number of singly-even codewords of
{c, c′ , c′ + c} is either zero or two. Thus, Equation (2) implies | supp(c) ∩ supp(c′ )| = wt(c ⋆ c′ ) ≡ 0
(mod 2), i.e. ⟨c, c′ ⟩ = 0.
    Let us now assume that C satisfies (C). Due to Equation (4) it suffices to show that C is even
in order to conclude that C is SO. From Equation (4) we conclude wt(c′ ) ≡ wt(c ⋆ c′ ) ≡ wt(c)
(mod 2) for all pairs of different codewords c, c′ ∈ C\{0}, i.e. the non-zero weights are either all
even or all odd. The latter case is impossible for k ≥ 2 due to Equation (2).
    The implication (D) ⇒ (A) follows from the bilinearity of the scalar product. The other
direction is obvious.

Property (B) is a refinement of the commonly stated implications that each SO binary code is
even and that each doubly-even binary code is SO. Similarly, for each binary code Equation (2)
implies that the set of even codewords forms a subcode of dimension at least k − 1 in each
binary [n, k]2 code. The implication (A) ⇒ (B) is e.g. mentioned in [19, Section II]. For the other
direction see e.g. [55, Proposition 3.2]. Lemma 1 and property (C) directly imply the following
improvement of Lemma 1 for binary SO codes.

2.2    Geometric notation
The set of all subspaces of Frq , ordered by the incidence relation ⊆, is called (r − 1)-dimensional
projective geometry over Fq and denoted by PG(r − 1, q). Employing this algebraic notion of
dimension instead of the geometric one, we will use the term i-space to denote an i-dimensional
subspace of Frq . To highlight the important geometric interpretation of subspaces we will call
1-, 2-, and (r − 1)-spaces points, lines, and hyperplanes, respectively. For two subspaces S and
S′ we write S ≤ S′ if S is contained in S′ . Moreover, we say that S and S′ are incident iff S ≤ S′ or
                       qi −1
S ≥ S′ . Let [i]q := q−1 denote the number of points of an arbitrary i-space in PG(r − 1, q) where
r ≥ i. A premultiset of points M of PG(r − 1, q) is a mapping from the set of points of PG(r − 1, q)
to Z. The value M(P) is called the multiplicity of M. We extend this notation additively to each
subspace S via M(S) = P≤S M(P). So, the cardinality of M equals M(V), where V denotes
                        P

the ambient space. For a hyperplane H the number of points of M in H is given by M(H). If

M(P) ∈ N for each point P, we say that M is a multiset of points. For each subspace S we denote
its characteristic function by χS , i.e. χS (P) = 1 if P ≤ S and χS (P) = 0 otherwise.
   Starting from a generator matrix G ∈ Fk×n
                                         q   of an [n, k, d]q code C we can associate a multiset
of points M in PG(k − 1, q) by considering the spans of the columns of G. The cardinality
of M is #M = n iff C is of full length. For the other direction we can build up a generator
matrix G of C by taking M(P) copies of a representing vector for every point P. We call M in
PG(r − 1, q) spanning if the points with positive multiplicity, called the support, span the entire
ambient space. The dimension of the associated linear code equals r iff M is spanning. Let C
be a full length [n, k]q code and M in PG(k − 1, q) its associated spanning multiset of points. We
remark that the ambiguities in these constructions result in equivalent linear codes or multisets
of points, see e.g. [72, §1.1.2] or [26] for more details. As an example we mention that Sq (k) and
RMq (1, k − 1) correspond to χV and χV − χH , where V denotes the ambient space PG(k − 1, q)
and H is a hyperplane. Each non-zero codeword c corresponds to a hyperplane H and we have
wt(c) = n − M(H). For the other direction, each hyperplane corresponds to the q − 1 multiples of
a non-zero codeword. A multiset of points M is called m-arc if M(H) ≤ m for every hyperplane
H. I.e. a full-length [n, k, d]q code corresponds to a spanning (n − d)-arc. Similarly, a multiset of
points M is called m-minihyper (or m-fold blocking set w.r.t. hyperplanes) if M(H) ≥ m for every
hyperplane H. If M is a spanning m-arc and M′ is an m′ -minihyper in PG(k − 1, q), then M − M′
is a spanning (m − m′ )-arc iff it is a spanning multiset of points. In coding theoretic terms the
deletion of M′ is called puncturing. For a multiset of points M we denote the maximum point
multiplicity by γ(M), so that e.g. γ(M) = 1 iff the corresponding linear code C is projective. If
K is some subspace not equal to the ambient space V, then the projection MK of M through K is
the multiset of points in the factor geometry V/K with multiplicity MK (S/K) = M(S) − M(K) for
every subspace K ⊆ S ⊆ V. The dimension of the ambient space drops by i and the cardinality
drops by M(K), while the m-arc property is preserved. In coding theory terms MK corresponds
to a codimension i subcode of C when M corresponds to C and projection is called truncation
or shortening. If M, M′ are spanning m- and spanning m′ -arcs in PG(k − 1, q), respectively, then
M + M′ is a spanning (m + m′ )-arc in PG(k − 1, q). If M′ spans a (k − 1)-space we can choose a
hyperplane H for the embedding, so that M + M′ is a spanning (≤ max{m + m′ , M(H) + #M′ })-
arc in PG(k − 1, q). In terms of corresponding generator matrices G, G′ this corresponds to the
                    
juxtaposition G|G̃′ where G̃′ is obtained from G′ by suitably padding one row. An example is
given by the unique [38, 6, 18]2 Griesmer code that can be obtained in this way from a [32, 6, 16]2
and a [6, 5, 2]2 code.
   We call a multiset of points M ∆-divisible iff its corresponding linear code is, i.e. if we have
M(H) ≡ #M (mod ∆) for every hyperplane H. Similarly, we call a multiset of points in PG(k, 2)
self-orthogonal (SO) if its corresponding linear code is. Clearly, projection preserves divisibility
and self-orthogonality.

attained with equality if d is sufficiently large. For d ≡ 0 (mod 4) any [g2 (k, d), k, d]2 Griesmer

4     Optimal binary self-orthogonal codes with dimension 8
In this section we completely determine ñ2 (8, ·), see Theorem 2. The existence of a linear code
with a prescribed minimum distance and a prescribed subgroup of the automorphism group,
can be formulated as a system of Diophantine linear equations, see e.g. [13]. Here we use the
fact that each doubly-even binary linear code is self-orthogonal and solve the corresponding
systems with integer linear programming.
