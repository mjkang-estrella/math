# Strict reproduction

Run from this lane (or the extracted source archive) with `sh run.sh`. Each helper is run through the externally bound helper_guard.py with OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1. Helpers have AS and group RSS 512MiB, CPU210s, wall230s. The separately authorized Lean launcher uses serial j1, M2700, group RSS2800MiB, CPU210s, wall230s, warningAsError=true and autoImplicit=false. No cap was increased. The inherited launcher removes the helper AS restriction only for the explicitly authorized Lean child and supervises its separate process group.

Compilation order: Literal Terminal Law Cells Product Prefix Marks Boards Injection Abundance Tail Concentration Assembly, then Inventory and Audit. Inventory enumerates every declaration by actual module origin, including private/generated names; BOTH unsafe and partial flags hard-fail for every owned declaration and all transitive type/body dependencies. Audit runs #print axioms for every enumerated declaration; certify.py checks name-set equality and permits only propext, Classical.choice, Quot.sound.

Through the fixed guard invoke `python certify.py pack`, then separately `python certify.py replay`. The deterministic ZIP uses fixed timestamps, permissions and order and contains source only. Replay extracts into a fresh directory, verifies every archived file hash, recompiles serially, repeats both audits and compares exact declaration names/axioms. It then removes all compiled artifacts. `python close.py` records implementation metrics. Finally invoke `python certify.py manifest` and, in a separate guarded invocation after all writes, `python certify.py verify`. The manifest excludes itself and verification-receipt.json. freeze.json is the scientific source binding; administrative originals are not treated as immutable.
