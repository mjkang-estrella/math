# P2 — MathDB 339564: proof of Conjecture 4.4 of arXiv:1806.06821v2 (Mohamed–Williams)

Screening-stage brief. No credit. Needs independent hypothesis review, a registry/prior check (see limits) and formalization.

## Source and literal quantifiers
- Source: arXiv:1806.06821v2 (12 Aug 2019), retained. The presentation is P_n(k,l) = ⟨x_0..x_{n−1} | x_i x_{i+k} x_{i+l}⟩ (eq. (2)). d(G) is the minimum number of generators (line ~403). The exponent-sum polynomial is f(t), with g(t) = t^n − 1 (Section 4).
- Conjecture 4.4: suppose (n,6) = 2 and n ≥ 8. Then d(Γ_n(1,n/2−1)^ab) is 1 if (n,16) = 2, is 2 if (n,16) ∈ {4,16}, and is 3 if (n,16) = 8.
- Source-internal results read: Theorem 4.1 (Betti number), Theorem 4.2 (order), Corollary 3.11(b) (d ≥ 3 when (n,16) = 8). The proof below does not use Theorem 4.2 or Corollary 3.11.

## Setup
Write n = 2m. Then (n,6) = 2 means 3 ∤ m, and n ≥ 8 means m ≥ 4. Also (n,16) = 2, 4, 8, 16 exactly when m is odd, m ≡ 2 (mod 4), m ≡ 4 (mod 8), m ≡ 0 (mod 8) respectively. Set f(t) = 1 + t + t^{m−1} and g(t) = t^n − 1.

Standard facts:
- **(F1)** A := Γ^ab ≅ Z[t]/(g,f) as abelian groups. The relation lattice of the cyclic presentation is the circulant generated by f in Z[t]/(t^n−1) ≅ Z^n.
- **(F2)** A is finite (source Theorem 4.1, since 3 ∤ n). Hence d(A) = max_p dim_{F_p} A/pA.
- **(F3)** A/pA ≅ F_p[t]/(g,f) = F_p[t]/(h_p) with h_p = gcd_{F_p[t]}(g,f). So dim = deg h_p = Σ_{ζ∈F̄_p} min(μ_ζ(g), μ_ζ(f)), where μ denotes root multiplicity.

Let q(x) = x² + x − 1.

## Lemma 1 (common roots)
Let ζ ∈ F̄_p with g(ζ) = f(ζ) = 0. Then ε := ζ^m satisfies ε² = 1 and ζ^{m−1} = ε ζ^{−1}, so 0 = ζ f(ζ) = ζ² + ζ + ε.
- If ε = 1, then ζ² + ζ + 1 = 0 and ζ^m = 1.
  - For p ≠ 3, ζ ≠ 1, so ζ has order 3 and 3 | m, which is a contradiction.
  - For p = 3, ζ² + ζ + 1 = (ζ−1)², so ζ = 1.
- If p = 2, then ε = 1 necessarily, so there is no common root: h_2 = 1.
- If p is odd and ε = −1, then q(ζ) = 0 and ζ^m = −1.

Conversely, ζ = 1 is a common root for p = 3, since f(1) = 3. Any root ζ of q with ζ^m = −1 is a common root, since ζ f(ζ) = q(ζ).

## Lemma 2 (pairing)
For p odd, the roots ζ_1, ζ_2 of q satisfy ζ_1 ζ_2 = −1. If ζ_1^m = −1, then ζ_2^m = (−1)^m ζ_1^{−m} = (−1)^{m+1}.
- For m odd, at most one root of q satisfies ζ^m = −1.
- For m even, either both roots satisfy it or neither does.

## Lemma 3 (multiplicities)
μ_ζ(g) = p^a, where p^a ‖ n.

Let p ∉ {2,5} and let ζ be a root of q with ζ^m = −1.
- If p ∤ n, then μ_ζ(g) = 1.
- If p | n, then p | m. If also f'(ζ) = 1 + (m−1)ζ^{m−2} = 1 + ζ^{−2} were 0, then ζ² = −1 = 1 − ζ, so ζ = 2 and q(2) = 5 ≡ 0, i.e. p = 5. This is excluded.

In both cases the root contributes exactly 1 to deg h_p.

For p = 3: ζ = 1 is simple in g (3 ∤ n) and in f (f'(1) = m ≢ 0).

For p = 5: q = (x−2)², and 2 has order 4 in F_5^*, so 2^m = −1 iff m ≡ 2 (mod 4).
- If 5 ∤ m, the contribution is ≤ 1.
- If 5 | m and m ≡ 2 (mod 4), then f'(2) = 1 − 2^{m−2} = 0 and f''(2) = (m−1)(m−2)2^{m−3} = 2^{m−2} ≠ 0. So μ_2(f) = 2 ≤ 5 ≤ μ_2(g), and deg h_5 = 2.

## Lemma 4 (p = 3)
Over F_3, q = x² + x + 2 is irreducible. Its roots satisfy ζ^4 = N(ζ) = 2 = −1, so they have order 8. Hence ζ^m = −1 iff m ≡ 4 (mod 8), and then both roots qualify. Therefore deg h_3 = 3 if m ≡ 4 (mod 8), and deg h_3 = 1 otherwise.

## Lemma 5 (existence of a degree-2 prime, m even, m ≢ 4 mod 8)
Let ζ_1, ζ_2 be the roots of q in F̄_p, with p ∤ 10. The power sums s_j = ζ_1^j + ζ_2^j satisfy s_j = −s_{j−1} + s_{j−2}, s_0 = 2, s_1 = −1, so s_j = (−1)^j L_j (Lucas numbers). For m even, (ζ_1^m+1)(ζ_2^m+1) = 1 + L_m + 1 = L_m + 2 in F_p. If p | L_m + 2, some root has ζ^m = −1, so by Lemmas 2–3, deg h_p = 2.

**Case m ≡ 0 (mod 8).** Put k = m/2 ≡ 0 (mod 4), so k ≥ 4. Then L_m + 2 = L_k² (from L_{2k} = L_k² − 2(−1)^k).
- L_k is odd, since 3 ∤ k (L is even iff 3 | index).
- 3 ∤ L_k, since 3 | L_j iff j ≡ 2 (mod 4).
- 5 ∤ L_j for every j.
- L_k ≥ L_4 = 7.

So some prime p ≥ 7 divides L_m + 2.

**Case m ≡ 2 (mod 4).** Put k = m/2, which is odd. Then L_m + 2 = L_k² + 4 = 5F_k² (from L_k² − 5F_k² = 4(−1)^k). Here m ≥ 10, because m = 6 is excluded by 3 ∤ m, so k ≥ 5.
- If 5 | k, then 5 | m and deg h_5 = 2 (Lemma 3).
- Otherwise k ≥ 7 and k is odd with 3 ∤ k. Then F_k ≥ 13 and gcd(F_k, 30) = 1, because 2 | F_k iff 3 | k, 3 | F_k iff 4 | k, and 5 | F_k iff 5 | k. So some prime p ≥ 7 divides L_m + 2.

## Conclusion
In all cases deg h_2 = 0, and deg h_p ≤ 2 for every p ≥ 5 (Lemma 3). For p ≥ 7 with m odd, deg h_p ≤ 1 (Lemma 2). For p = 5 with m odd, deg h_5 = 0.
- **m odd:** d = max(1, ≤1) = 1. The lower bound comes from h_3.
- **m ≡ 4 (mod 8):** d = 3, from h_3.
- **m ≡ 2 (mod 4) or m ≡ 0 (mod 8):** deg h_3 = 1, every other prime gives ≤ 2, and Lemma 5 supplies a prime with 2. So d = 2.

This is exactly Conjecture 4.4. ∎

## Side finding (source-internal defect, not a credit item)
Printed Theorem 4.2 gives |Γ^ab| = 3(L_m − 1 − (−1)^m). For m even this is wrong. For n = 8 it gives 15, while the source itself states Γ_8(1,3)^ab ≅ Z_3³, of order 27. The value 3(L_m + 1 + (−1)^m) matches all 52 SNF cases.

## Decisive check (run)
`scripts/abel_snf.py`: an exact integer Smith normal form of the n×n relation matrix, independent of the proof. Over all admissible n in [8,160] (52 values), d agrees with the conjecture. Runs: `runs/abel_snf.8-64.r1.txt`, `runs/abel_snf.65-160.r1.txt`. The source reports GAP checks for n ≤ 500.
