1     Introduction
    All graphs considered are assumed to be simple and connected. Let G
be such a graph with vertex set V (G) and edge set E(G). The degree dv
of a vertex v ∈ V (G) is the number of vertices adjacent to v in G. Let Tn
be the set of all trees of order n. Sn and Pn denote the star and the path
of order n, respectively.

3       Main result
Theorem 3.1. Let f (x, y) be one of the three functions x + y, xy, and
x2 + y 2 . Then for any T ∈ Tn ,

    T If (Pn ) + RT If (Pn ) ≤ T If (T ) + RT If (T ) ≤ T If (Sn ) + RT If (Sn ).

The left equality holds if and only if T ∼
                                         = Pn , and the right equality holds
                 ∼
if and only if T = Sn .

Proof. Let T ∈ Tn . If T ̸= Sn , then T has at least one non-pendent edge.
By Lemma 2.2, there is a tree T ′ ∈ Tn such that T If (T ) + RT If (T ) <
T If (T ′ ) + RT If (T ′ ). Thus the upper bound holds.
      If T ̸= Pn , then by Lemmas 2.3, 2.4 and 2.5, there is a tree T ′ ∈ Tn
such that T If (T ) + RT If (T ) > T If (T ′ ) + RT If (T ′ ). The lower bound
holds.

      Note that for each topological index mentioned in this article, the star
Sn and path Pn reach their maximum and minimum values among all
trees of Tn , respectively. For their reciprocal indies, the results are just
the opposite. So we believe that the following conjecture is true.

Conjecture 4.1.        If T If (Pn ) ≤ T If (T ) ≤ T If (Sn ) and RT If (Sn ) ≤
RT If (T ) ≤ RT If (Pn ) for any T ∈ Tn , then

  T If (Pn ) + RT If (Pn ) ≤ T If (T ) + RT If (T ) ≤ T If (Sn ) + RT If (Sn ).
