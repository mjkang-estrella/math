1     Main results
1.1    Some notation and transforms
In what follows, F (x) denotes a distribution function (d.f.) defined on [0, ∞)
with F (0) = 0, and F (x) = 1 − F (x) denotes its tail. The α–th       moment
of F (x) is denoted by m(α). It is said that f (x) ∼ g(x) if f (x) g(x) → 1
as x → ∞. The case f (x) ∼ 0 will be understood as f (x) → 0 as x →
∞. The class of regularly varying functions with index α, denoted by RVα ,
consists of functions f (x) satisfying, for any t > 0, f (tx) ∼ tα f (x). If the
index α = 0, f (x) is said slowly varying. If L ∈ RV0 , then the de Haan
class, denoted by Πβ (L), consists of functions f (x) satisfying, for any t > 1,
(f (tx) − f (x)) L(x) ∼ β log t.
