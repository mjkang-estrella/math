  the set N [x] = {x} ∪ N (x). For a subset S of V (G), let G[S] be the induced subgraph of

  G on the vertex set S, and we use G − S to denote G[V (G) − S]. If S = {x}, we write
  G − x instead of G − {x}. An independent (or stable) set in G is a set of pairwise non-

  independent set. An independent set of the largest size is a maximum independent set;
  its cardinality is denoted α(G) and called the independence number (or stability number)
  of G.

       A matching in a graph G is a set of pairwise non-incident edges. Let A and B be two

  Berge established the following useful characterization of maximum independent sets.

  Theorem 1.1 ([3]). In a graph G, an independent set S is maximum if and only if every
  independent set disjoint from S can be matched into S.
