# Accepted-family exclusion index

Use accepted-exclusions.json before allocating a MathDB hypothesis attempt. It contains all 39 accepted families, their recorded scopes, all 30 first-batch publication records, and structured MathDB ID associations. Related IDs remain explicitly distinct from exact-scope associations. A matching ID flags scope comparison; it does not prove that every question in the record is solved.

historical-dispositions.json supplies cached exclusion and hold leads. It is not an exhaustive campaign-history inventory, a new adjudication, or current priority clearance. In particular, current evidence may refine an old hold.

The two administrative originals were copied before this derivation. No accepted record, first-thirty publication link, external database or shared count was changed. The index is for orchestration and deduplication only. Mathematical review and solving remain delegated.
