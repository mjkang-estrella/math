The combinatorial depth of Golomb’s sequence has recently been made explicit by Claes and Miyamoto [ 6 ] , who define the golombic operator Γ \Gamma : given a sequence a a , Γ ⁡ ( a ) \Gamma(a) is the sequence whose n n -th run has length a ⁡ ( n ) a(n) (that is, value n n is repeated a ⁡ ( n ) a(n) times). They show that Golomb’s sequence is the unique fixed point of Γ \Gamma in the class of nondecreasing sequences, establishing a rich algebraic structure. Our almost Golomb sequences occupy a different regime. They are not fixed points of Γ \Gamma , but their run lengths are bounded (depending on r r ) and the corresponding run-length sequence is r r -automatic. For r = 2 r=2 in particular the run lengths lie in { 1 , 2 } \{1,2\} (Proposition 7.3 ). Golomb’s global rule forces a smooth, sublinear growth governed by an irrational exponent. The finite-window rule instead imposes linear growth accompanied by discrete, r r -automatic oscillations. The sequence transitions from the realm of analytic power laws into the realm of automatic sequences. A sequence is r r -regular (in the sense of Allouche and Shallit [ 2 ] ) if all its subsequences of the form ( f ⁡ ( r i ​ n + j ) ) n ≥ 0 (f(r^{i}n+j))_{n\geq 0} lie in a finitely generated ℤ \mathbb{Z} -module. Informally, its values along arithmetic progressions in base r r satisfy linear recurrences. This framework is well adapted to sequences defined by divide-and-conquer rules.
