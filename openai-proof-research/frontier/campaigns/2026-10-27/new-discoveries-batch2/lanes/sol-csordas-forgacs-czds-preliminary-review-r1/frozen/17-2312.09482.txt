                                          An open problem and a conjecture on binary linear
                                                   complementary pairs of codes∗

                                                                        Shitao Li, Minjia Shi†, San Ling‡

                                                                                         Abstract
                                                     The existence of q-ary linear complementary pairs (LCPs) of codes with q > 2
                                                 has been completely characterized so far. This paper gives a characterization for the
                                                 existence of binary LCPs of codes. As a result, we solve an open problem proposed
                                                 by Carlet et al. (IEEE Trans. Inf. Theory 65(3): 1694-1704, 2019) and a conjecture
                                                 proposed by Choi et al. (Cryptogr. Commun. 15(2): 469-486, 2023).

                                         Keywords: Linear complementary pair of code, linear ℓ-intersection pair, the security
                                         parameter

complementary dual (LCD). This notion was introduced by Massey [28] in order to provide
an optimum linear coding solution for the two-user binary adder channel.
    LCPs of codes have been used in the framework of direct sum masking, which was
proposed as a countermeasure against side channel attacks (SCAs) and fault injection
attacks (FIAs) [10, 11]. If an LCP of codes (C1 , C2 ) is used in this framework, then
the minimum distance d(C1 ) of C1 measures the protection against FIAs, whereas the
minimum distance d(C2⊥ ) of the dual code of C2 measures the protection against SCAs.
It has been shown that the level of resistance against both SCA and FIA depends on
min{d(C1), d(C2⊥ )}, which is referred to as the security parameter of the LCP of codes.
Note that for an LCD code C, (C, C ⊥ ) is an LCP of codes. Then the security parameter
of (C, C ⊥ ) is simply d(C), which has been studied extensively (see [2–5, 9, 14, 16–18, 21,
22, 26, 27]). Hence we can define the optimal security parameter of [n, k] LCPs of codes
for given n and k as follows:
      dLCP (n, k) = max{min{d(C1 ), d(C2⊥ )} | (C1 , C2) is an [n, k]q LCP of codes}.
Let dL (n, k) denote the largest minimum distance among linear [n, k]q codes. Then we
clearly have dLCP (n, k) ≤ dL (n, k).
    Carlet et al. [13] showed that for any q-ary linear code C with q > 2, there is a
monomial transformation σ on Fnq such that (C, (σ(C))⊥ ) is an LCP of codes. They
proposed an open problem for the existence of q-ary LCPs of codes: is there a monomial
transformation σ on Fnq such that (C1 , (σ(C2 ))⊥ ) is an LCP of codes for any two q-
ary linear [n, k] codes C1 and C2 with q > 2? This open problem has been settled by
Anderson et al. [1]. This means that the problems of the existence and the optimal security
parameters of q-ary LCPs of codes have been settled for q > 2. For the binary case, the
same article [13] showed that for any binary linear code C, there is a linear transformation
σ on Fn+1
        2    such that ({0} × C, (σ({0} × C))⊥ ) is an LCP of codes. They also proposed
a similar open problem for the existence of binary LCPs of codes. Moreover, their result
also yields that dLCP (n, k) ≥ dL (n, k) − 1. Hence an interesting topic is to study the best
security parameter problem for binary LCPs of codes. For this topic, Choi et al. [15]
determined the best security parameters of binary [n, k] LCPs of codes for n ≤ 18 or
k ≤ 4. Further, they also described a sufficient condition for dLCP (n, k) = dL (n, k) − 1,
and gave a conjecture on its necessary condition. Very recently, Güneri [20] constructed
an infinite family of optimal binary LCPs of codes from Solomon-Stiffler codes.
    In this paper, we study the problems of the existence and the optimal security param-
eters of binary LCPs of codes. We show that for two binary linear [n, k] codes C1 and C2 ,
there is a linear transformation σ on Fn+1
                                         2   such that ({0} × C1 , (σ({0} × C2))⊥ ) is an LCP
of codes. This solves an open problem proposed by Carlet et al. [13]. Further, we present
a more general sufficient condition for dLCP (n, k) = dL (n, k) − 1 than that given by Choi
et al. [15], and show a conjecture proposed in the same paper. As a result, we construct
an infinite family of optimal binary LCPs of codes from Solomon-Stiffler codes, whose
parameters cover those constructed by Güneri [20]. Further, these results also imply that
the conjecture proposed by Guenda et al. [19] is not valid for the binary case.

Conjecture 4.5. [15, Conjecture 10] Let n > k ≥ 1. Then, there exists a unique binary

every binary optimal [n, k, dL (n, k)] code is even-like and contains 1.
Theorem 4.6. Let n > k ≥ 1. Then, dLCP (n, k) = dL (n, k) − 1 if and only if every
binary optimal [n, k, dL (n, k)] code is even-like and contains 1.
Proof. (⇐=) Suppose that dLCP (n, k) = dL (n, k), then there exists a binary [n, k] LCP
of codes (C, D) with security parameter dL (n, k). Hence C ∩ D = {0}, C and D ⊥ have
parameters [n, k, dL (n, k)]. By hypothesis, every binary optimal [n, k, dL (n, k)] code is
even-like and contains 1. This implies that both C and D ⊥ are even-like and contain 1.
Since D ⊥ is even-like, we have 1 ∈ D. Then 1 ∈ C ∩ D. This contradicts the condition
that C ∩D = {0}. Hence, dLCP (n, k) ≤ dL (n, k)−1. On the other hand, by [13, Corollary
9], we have dLCP (n, k) ≥ dL (n, k) − 1. Therefore, dLCP (n, k) = dL (n, k) − 1.
    (=⇒) Suppose that dLCP (n, k) = dL (n, k) − 1. If there exists a binary linear
[n, k, dL (n, k)] code C such that C is odd-like or does not contain 1, then both cases
imply that 1 ∈    / Hull(C). By Lemma 4.3, there exists a mapping σ ∈ PAut(Fn2 ) such
that (C, (σ(C))⊥ ) is an LCP of codes. This implies that dLCP (n, k) = dL (n, k), which
contradicts the condition that dLCP (n, k) = dL (n, k) − 1.
Corollary 4.7. If there exists a binary linear [n, k, d] code C with 1 ∈
                                                                       / Hull(C), then
there exists a binary [n, k] LCP of codes with security parameter d.
Proof. By Lemma 4.3, there exists a mapping σ ∈ PAut(Fn2 ) such that (C, (σ(C))⊥ )
is a binary [n, k] LCP of codes. The security parameter of (C, (σ(C))⊥) is equal to
min{d(C), d(σ(C))}. Together with the fact that d(σ(C)) = d(C), the result holds.

5   Conclusion
In this paper, we have pushed further the study of the characterization of binary LCPs of
codes. We have characterized the existence of binary LCPs of codes. As a consequence,
an open problem proposed by Carlet et al. in [13] has been solved. We have also settled
the best parameter problem of binary LCPs of codes. As a result, a conjecture proposed
by Choi et al. in [15] has been solved. Further, we have constructed an infinite family of
optimal binary LCPs of codes with more general parameters, which cover the parameters
constructed by Güneri in [20]. Further, these results also imply that the conjecture
proposed by Guenda et al. in [19] does not always hold for the binary case.
