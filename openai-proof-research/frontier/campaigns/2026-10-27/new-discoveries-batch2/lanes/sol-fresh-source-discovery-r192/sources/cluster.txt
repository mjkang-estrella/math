                                                                                    1. Introduction
                                              Clustering reduces a finite configuration to a simpler one by merging nearby points. Its
                                           Lipschitz version asks that small perturbations of the input produce controlled perturbations
                                           of the output. We study retractions that reduce an n-point configuration to at most k
                                           representatives, where 1 ≤ k < n, and fix configurations already having at most k points.
                                           Allowing fewer than k representatives accommodates simultaneous mergers. Our main setting
                                           is that of normed spaces, with estimates independent of dimension.
                                              For a metric space X and an integer n ≥ 1, write X(n) = {A ⊂ X : 1 ≤ |A| ≤ n}, with
                                           the Hausdorff metric

the classical hierarchical clustering obtained from a minimum spanning tree [7, 9]. Carlsson

theorem for flat clustering [10], and proved that it is stable under perturbations of the metric.

as fast as the input points. Lipschitz continuity of algorithms has recently been studied
systematically in theoretical computer science, for example for minimum spanning trees [13].

  All Lipschitz constants between finite subset spaces refer to the Hausdorff metric. For
labeled configurations we use the maximum of the distances between corresponding points.
Section 2 gives efficient and explicit retractions between finite subset spaces of ℓ∞ ; unfortu-

Section 5 concerns the applications of Theorems 1.1 and 1.2 to metric spaces. Section 6
presents results for absolute Lipschitz retracts, lower bounds, and open questions.

                             2. Warm-up: clustering in ℓ∞
  In this section we construct an explicit (2n − 1)-Lipschitz retraction V (n) → V (k) for every
1 ≤ k < n, where V = ℓ∞ (Γ) and Γ is an arbitrary nonempty index set. The construction is
simpler than the one in Section 3 and shares some elements with it, such as the following
definition.

(2.1)             sk (A) = min{s ≥ 0 : Gs (A) has at most k components}.

  If d is a metric, then sk (A) = 0 exactly when |A| ≤ k.

            6. Absolute retracts, lower bounds, and open questions
  The existence of retractions between finite subset spaces is inherited by Lipschitz retracts.

Lemma 6.1 ([2, Lemma 3.3]). Let g : X → Z and f : Z → X be Lipschitz maps with
f ◦ g = idX . Then

                      Λn,k (X) ≤ Lip(f ) Lip(g) Λn,k (Z)    (1 ≤ k < n).

Proof. Apply maps to finite sets pointwise. If R : Z(n) → Z(k) is a retraction, then f ◦ R ◦ g
is a retraction X(n) → X(k), and its Lipschitz constant is at most Lip(f ) Lip(R) Lip(g). □

Definition 6.2. A metric space X is an absolute λ-Lipschitz retract if every isometric copy
of X in a metric space is the image of a λ-Lipschitz retraction.

  For example, ℓ∞ (Γ) is an absolute 1-Lipschitz retract.

Corollary 6.3. Every absolute λ-Lipschitz retract X satisfies Λn,k (X) ≤ λ(2n − 1) for
1 ≤ k < n.

Proof. For a fixed o ∈ X, the map x 7→ d(x, ·) − d(o, ·) embeds X isometrically into ℓ∞ (X),
so X is a λ-Lipschitz retract of ℓ∞ (X). Apply Theorem 2.3 and Lemma 6.1.                 □

  The constants in Theorems 1.1, 1.2, and 2.3 grow with n, and some growth is unavoidable.

Proposition 6.4. Let X contain an isometric copy of a nondegenerate interval. Then
Λn (X) ≥ n − 3 for all n ≥ 2.

Proof. For an interval [0, L], this is [2, Theorem 5.1]. Let c : [0, L] → X be an isometry. The
map f (x) = min{L, d(x, c(0))} is 1-Lipschitz and satisfies f ◦ c = id, so Lemma 6.1 gives
Λn ([0, L]) ≤ Λn (X).                                                                        □

Question 6.5. Is Λn (X) = O(n) for every normed space X?

Question 6.6. Is sup1≤k<n Λn,k (X) = O(n) for every normed space X?

  For normed spaces of dimension at least two, the lower bound also grows with the size of
the target: Λn,k (X) ≥ k/(2π) − 1/2 by [2, Theorem 1.1].
