L30: Conjecture: a(n) = (n^2 - n + 6)/2 for n >= 4, with a(n) = 2n - 1 for n in {1, 2, 3}. Equivalently a(n) = 【13†A000217】(n-1) + 3 for n >= 4. Predicts a(10) = 48.
L31: At n = 7 every minimum container has a single 1-cell interior hole. A wider 8 X 8 search at k = 23 returns UNSAT (LRAT certified).
L32: The hole is therefore a structural feature of a(7), distinguishing this sequence geometrically from the purely numerical match 【14†A350660】. For n in {1, 2, 3, 4, 5, 6, 8, 9} the optimal container is simply connected.

L10: # The L n-omino instance sequence
L11: ## Problem
L12: 
L13: D. M. Condon, E. B. Dugan, L. M. Goldman and E. R. Williams,
L14: *Polyomino Density*, arXiv:2608.29231v1, Section 6.3, p. 28:
L15: 
L16: > We believe S(5, 1, 2) is the same as the instance sequence for [L pentomino], and we suspect that the instance sequence for the L n-omino is S(n, 1, 2) in general.
L17: The bracketed label represents the inline L pentomino diagram. For every
L18: integer n >= 3, the L n-omino has n-1 left-aligned bottom-row cells and
L19: one top-row cell. Instances are translated copies, as in Section 2.1.
L20: For every N >= 1, its instance minimum is the least cardinality of a
L21: nonempty edge-connected finite board containing at least N instances.
L22: The sequence S(n,1,2) starts at n, then increases by one at position k
L23: if k appears before position k, and by two otherwise.
L24: ## Motivation
L25: 
L26: The source's Theorem 4.9 supplies a closed form for the instance minimum.
L27: Identifying this geometric minimum with the independently specified
L28: self-referential recursion resolves the general suspicion and its
L29: explicitly mentioned pentomino case. The frozen result is
L30: `D5/S3/Combinatorics/Polyomino/LPolyominoSkippedSequence.result`.
L31: ## Gap
L32: Issue #12562 preregisters the exact universal statement and a tier-1
L33: classification before the Lean probe. The bounded literature check covers
L34: the source's v1, Benoit Cloitre's *A study of self-referential sequences*,
L35: arXiv:2506.18103v2, Theorems 5.1-5.3, OEIS A080353, MathDB and the
L36: formal-conjectures corpus. Cloitre describes x=3,4,5, with the algebraic
L37: proof for x=5 omitted; this does not establish the general polyomino
L38: identification. No resolution of the exact general statement was found in
L39: that searched scope. Citing works were not exhaustively audited because
L40: the citation API returned HTTP 429. This is not a priority claim.
L41: ## Route
L42: 
L43: Put d=n-2 and H_d(K)=sum_{0 <= i < K} floor(i/d). For an arbitrary finite
L44: integer-cell board P, give cell (x,y) weight x+d*y. The top and right-most
L45: cells of each L instance share a weight. The other bottom cells give
L46: injective maps into each of the preceding d layers. In an occupied layer,
L47: the maximum-x cell cannot be an instance's top cell. Write s_k for the
L48: layer size, e_k for its top-cell count, and delta_k=s_k-e_k. Then
L49: 
L50: d*e_k <= sum_{l<k} delta_l.
L51: The cumulative deficits at occupied layers are distinct integers below
L52: D=|P|-I, where I is the instance count. Summing their quotient capacities
L53: gives I <= H_d(D). This argument uses neither connectivity nor compression.
L54: Let K be least with N <= H_d(K+1), and q=N-H_d(K). Retain every
L55: nonnegative cell of weight less than K, and the weight-K cells with
L56: height at most q. This trimmed down-set is edge-connected, contains
L57: exactly N instances, and has N+K+1 cells. The lower bound proves
L58: that the genuine at-least-N minimum is N+K+1.
L59: The identity H_d(K+d)=H_d(K)+K places these minimum values between
L60: successive jump thresholds. It also constructs an earlier index for every
L61: non-jump value. Consequently the increment is two exactly when the index
L62: is missing from the earlier range, and one otherwise. The initial value
L63: is n. Strong induction identifies the minimum with the literal S(n,1,2)
L64: recursion. All these arguments occur inside the proof of `result`.
L65: ## Falsifier
L66: 
L67: A source discrepancy in the L orientation, translation-only convention,
L68: positive sequence indices, edge connectivity, at-least-N condition or
L69: skipped-number recursion would invalidate this interpretation. The formal
L70: claim retains all these conditions. A genuine counterexample to the
L71: universal equality would contradict the kernel-checked result within its
L72: stated definitions and axiom boundary.

L92: ### What the settlement shows
L93: - **Proved in this module:** the universal equality for every n >= 3 and
L94:   N >= 1, by `result`. Its live proof constructs the weighted-layer
L95:   injection, the cumulative-deficit bound I <= H_d(|P|-I), connected
L96:   sharp trimmed down-sets, and the jump-set/missing-set identification.
L97:   These mechanisms are internal proof terms rather than separately
L98:   exported companion theorems.
L99: - **Proved in this module:** the geometric lower bound holds for all

L106:   Theorem 4.9. Comparing that evaluated expression syntactically with

L110:   1, 2, 6, 19, 63, 216, 760, 2725, 9910, 36446, 135268, 505861,

L119: - **Proved consequence for the source:** its L instance-minimum formula
L120:   is now identified with S(n,1,2), including the explicitly conjectured
L121:   pentomino case. The source's other density results need no additional
L122:   hypothesis from this identification.
L123: - **Open:** transferring the weighted-layer argument to the P n-ominoes
