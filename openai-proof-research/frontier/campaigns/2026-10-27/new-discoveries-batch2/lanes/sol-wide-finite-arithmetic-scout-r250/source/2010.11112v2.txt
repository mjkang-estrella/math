                                            UNIQUE MAXIMUM INDEPENDENT SETS IN GRAPHS
                                                 ON MONOMIALS OF A FIXED DEGREE




arXiv:2010.11112v2 [math.CO] 14 Mar 2021
                                                                            JOHN MACHACEK


                                                   Abstract. We consider graphs on monomials in n variables of a fixed
                                                   degree d where two monomials are adjacent if and only if their least
                                                   common multiple has degree d + 1. We prove that when n = 3 and d is
                                                   divisible by 3 as well as when n = 4 and d is even that these graphs have
                                                   a unique maximum independent set. Domination in these graphs is also
                                                   considered, and we conjecture that there is equality of the domination
                                                   number and independent domination number in all cases.




                                                                            1. Introduction
                                              An independent set (also known as a stable set) in a graph is a set of
                                           vertices such that there is no edge between any two vertices in the set. A
                                           maximum independent set in a graph is an independent set of vertices of
                                           maximum possible size. Finding and understanding maximum independent
                                           sets is an important problem from both graph theoretic and algorithmic
                                           perspectives. Our main focus will be on demonstrating certain graphs have
                                           a unique maximum independent set. We will also look at domination and
                                           independent domination. In particular, we show some triangular grid graphs
                                           and tetrahedral grid graphs have a unique maximum independent set. What
                                           we call triangular grid graphs and tetrahedral grid graphs are part of a larger
                                           family of graphs defined on monomials of a given degree in a polynomial ring.
                                           We also conjecture for these graphs that the domination and independent
                                           domination number are equal. Previous study of independence and dom-
                                           ination in these graphs has been done from perspectives of commutative
                                           algebra [GGR86] and hexagon chess [DT13, Wag14].
                                              In this introduction we define this family of graphs that include triangular
                                           grid graphs and tetrahedral grid graphs. Section 2 contains our main result
                                           of triangular grid graphs, and in Section 3 we prove our main result on
                                           tetrahedral grid graphs. We conclude with Section 4 which discusses some
                                           connections to other work, domination, open problems, and directions for
                                           future research.

of an independent set. Thus a maximum independent set of G is precisely
an independent set of size α(G). Let G be a graph with vertex set V and
edge set E. For X ⊆ V we use G|X to denote the graph with vertex set
X and edge set {{a, b} ∈ E : a, b ∈ X}. We also use G \ X to denote G|X
where X is the complement of X in V .
   Let αn (d) = α(Gn (d)) denote the independence number of the graph
Gn (d). We will be interested in the quantity an (d) which we define to be the
number of maximum independent sets of Gn (d). The numbers αn (d) were
studied by Geramita, Gregory, and Roberts in the context of monomial
ideals [GGR86]. Work on computing the numbers αn (d) by constructing
simplicial complexes has been done by Carlini, Hà, and Van Tuyl [CHVT01].
A connection between the numbers α4 (d) and sequence A053307 in Sloane’s
OEIS [OEI] which involves certain 2 × 2 integer matrices has been found by
Babcock and Van Tuyl [BVT13].

how much a collection of monomials in Sn (d) can “spread” in Sn (d+1) when
each monomial is multiplied by each variable x1 , x2 , . . . , xn . That is, αn (d)
is the largest possible size of a subset A ⊆ Sn (d) such that n|A| = |Sn (1) · A|

                          4. Concluding remarks
4.1. Periodicity and larger values of n. We now give two conjectures
in the spirit of Conjecture 1.1 , Theorem 2.1, and Theorem 3.1. The first
conjecture deals with unique maximum independent sets. The second con-
jecture deals with periodicity of the sequences {an (d)}d≥0 .
Conjecture 4.1. For any n ≥ 1 there exists some N ≥ 0 such that an (d) =
1 whenever d ≡ 0 (mod n) and d ≥ N .
Conjecture 4.2. For any n ≥ 1 there exists some N ≥ 0 such that the
sequence {an (d)}d≥N is n-periodic.
   It is easy to see Conjecture 4.1 and Conjecture 4.2 both hold when n = 1
and n = 2. Since G1 (d) is always just a single point we find that a1 (d) = 1 for
all d ≥ 0. We see that a2 (2k) = 1 and a2 (2k+1) = 2 for all k ≥ 0 since G2 (d)

   The sequence {a4 (d)}d≥0 begins

4.2. Domination. We now discuss the relationship of our work with domi-
nation. A k-dominating set is a set vertices D such that every vertex not in
the set is adjacent to at least k vertices in D. A usual dominating set is then
a 1-dominating set. Hopkins and Stanton [HS85] characterized trees with
a unique maximum independent set as well as graphs with a unique maxi-
mum independent set for which complement of this maximum independent
set is also an independent set. Further work in this direction was done by
Siemes, Topp, and Volkmann [STV94] by considering k-independent sets for
any k which are independent sets I such that any independent set I ′ with
                     UNIQUE MAXIMAL INDEPENDENT SETS                            11

|I ′ | ≥ |I| − (k − 1) is must be a subset of I. Hence, the notion of a unique
maximum independent is recovered for k = 1. Certainly any maximal inde-
pendent set will be a dominating set, but it is known that any k-independent
set is actually a (k + 1)-dominating set [STV94, Corollary 2]. So, we obtain
the following corollary.
Corollary 4.4. The unique maximal independent sets constructed in the
proofs of Theorem 2.1 and Theorem 3.1 are 2-dominating sets.
   It can be seen from Figure 3 and Figure 4 that the independent sets from
Theorem 2.1 and Theorem 3.1 are not 3-dominating, and hence also they
are not 2-independent. Volkmann [Vol04] has studied further connections
between unique maximum independent sets and 2-dominating sets.
