Abstract
Fix n≥2. A set A={a0<a1<⋯<an−1} of n residues in
ℤN is valid mod N if the all-ones multiset is the only
size-n multiset drawn from A whose sum is p:=∑iai(modN). For the
super-increasing set A={2k−1:0≤k≤n−1} we determine the least
valid modulus exactly:
Nmin​(n)=2n−2⌊log2⁡n⌋ for all n≥2.
Both directions of the proof are elementary, resting on a sharp
minimal-digit-sum estimate for representations by binary coins, and the full
theorem has been machine-checked in Lean 4/Mathlib for all n
(https://github.com/jarfo/min-modulus). We conjecture
that no size-n residue set admits a smaller valid modulus.
This validity condition is exactly what makes the permanent of an n×n
matrix equal to a single coefficient of a row-product polynomial modulo
xN−1, extractable by a size-N discrete Fourier (or number-theoretic)
transform; the theorem thus identifies the smallest transform, N≈2n,
for which this evaluation is exact. That application — and the resulting common
framework for the classical formulas of Ryser and Glynn and this transform —
is developed in a companion paper [2].
Keywords: multiset sums, distinct sums, minimum modulus,
super-increasing sequence, permanent, formal verification.
MSC 2020: 11B13 (primary); 68V20 (secondary).
1 Introduction
The permanent of an n×n matrix,
per⁡B=∑σ∈Sn∏i=1nbi​σ​(i), is a classical
hard object — computing it exactly is #P-complete even for 0–1 matrices
[10]. This paper grew out of a transform-based route to it. A
standard generating-function identity expresses per⁡B as a single coefficient
of the row-product polynomial
∏i(∑jbi​j​xaj)mod(xN−1), which a size-N
discrete Fourier transform (over ℂ, or a number-theoretic transform over a
finite field for exact integer arithmetic) extracts exactly — provided
no size-n multiset of the exponents aj other than the all-ones one reaches
the target p=∑jaj modulo N. Since the cost is governed by N, one
wants the smallest modulus for which some exponent set has this property.
That transform view of the permanent, and its relation to the classical formulas
of Ryser and Glynn, is developed in the companion paper
[2].
This motivates the following combinatorial question, which we call the
unique multiset-sum problem and which seems natural independently of the
application. Call a set A={a0<⋯<an−1}⊆ℤN
valid mod N if the only size-n multiset with elements from A
summing to p=∑iai(modN) is the multiset containing each element
exactly once. How small can N be?
For the super-increasing set
A={ 2k−1:0≤k≤n−1}={0,1,3,7,…,2n−1−1},
we answer the question exactly.
Main Theorem.
For every n≥2, the least modulus at which the super-increasing set is
valid is
Nmin​(n)= 2n−2⌊log2⁡n⌋.
The first values, for n=2,3,…,13, are
2, 6, 12, 28, 60, 124, 248, 504, 1016, 2040, 4088, 8184.
The proof has two independent halves. The upper bound
(Theorem A): the set is valid at N=2n−2m,
m=⌊log2⁡n⌋. After a change of variables, a collision is a
representation of a shifted target by binary coins {20,…,2n−1}
with digit sum exactly n; a single step estimate (Lemma 4) shows each
additional multiple of N forces the minimal digit sum up by at least one, and
an induction kills all multiples at once — no case analysis on n, no bound
on the multiple. The lower bound
(Theorem B): every smaller modulus admits an
explicit collision, produced by a complete achievability criterion for the
values of the collision map (Proposition 1). The boundary case is sharp
from both sides in a satisfying way: at gap 2t with t>m a
negative multiple of the modulus provides the collision, and at t=m
that witness misses by exactly one unit — the definition of
m=⌊log2⁡n⌋ enters the two halves through the two sides of
the same inequality 2m≤n≤2m+1−1.
Beyond the pencil-and-paper proof, the full statement — both bounds, all n
— has been formalized and kernel-checked in Lean 4 with Mathlib
[1, 9], with no unproven assumptions
(Section 7).
We conjecture that the super-increasing set is presumably not just convenient but optimal:
Conjecture 1.
For every n≥2 and every N<2n−2⌊log2⁡n⌋, no
set of n residues is valid mod N; that is, the super-increasing set attains
the least valid modulus over all size-n sets.
Related work.
The condition studied here is a single-target, multiset, modular relative of
several classical uniqueness conditions on sumsets. Sets all of whose
subset sums are distinct (Erdős’s problem; see
[4, Problem C8]) and Bh/Sidon-type sets, where all h-fold sums
are distinct [6], both demand far more — distinctness at
every target — and correspondingly force larger ranges. Validity asks
for uniqueness at the single target p only, which is what allows a modulus
below 2n despite the (2​n−1n) candidate multisets.
Super-increasing sequences are familiar from knapsack cryptosystems
[5], where they make subset-sum decoding easy; here the
closely related set {2k−1} is extremal for a different, multiset
uniqueness property. On the application side, exact permanent algorithms
descend from Ryser [8] and Glynn [3]; the companion
paper [2] shows that these and the transform used here
are three instances of one framework — orthogonal evaluation schemes that
isolate the permanent as a single coefficient — with the present
minimum-modulus result identifying the smallest cyclic instance.
Organization.
Section 2 fixes notation and states the results.
Sections 3 and 4 reduce validity to a digit-sum question and
solve the latter. Section 5 proves the upper bound (Theorem A),
Section 6 the matching lower bound (Theorem B).
Section 7 reports the machine certification, and
Section 8 collects open problems.
2 The problem and the main results
Fix n≥2. For a set A={a0<a1<⋯<an−1} of n residues
in ℤN, write p:=∑iaimodN. A size-n multiset with elements
from A is encoded by its multiplicity vector
k=(k0,…,kn−1)∈ℤ≥0n with ∑iki=n.
Definition.
A is valid mod N if the only k≥0 with ∑iki=n and
∑iki​ai≡p(modN) is k=(1,1,…,1).
We study the super-increasing set A={2k−1:0≤k≤n−1} and
Nmin​(n)=min⁡{N≥2:A​ is valid mod ​N}.
Throughout, put
m=⌊log2n⌋,so 2m≤n≤2m+1−1,andN= 2n−2m.
The Main Theorem asserts Nmin​(n)=N; it splits into Theorem A
(Nmin​(n)≤N: the set is valid at N; Section 5) and Theorem B
(Nmin​(n)≥N: every smaller modulus admits a collision;
Section 6).

4 The digit-sum lemma
For a target M≥0 and coins {20,21,…,2n−1}, let
smin​(M) denote the minimal digit sum ∑iki over all representations
ki≥0, ∑iki​2i=M. Write popcount⁡(x) for the number of ones in the
binary expansion of x≥0.
Lemma 3 (digit sum).
With Mmod2n−1 the remainder and ⌊⋅⌋ the quotient,
smin​(M)=⌊M/2n−1⌋+popcount⁡(Mmod2n−1),
and the set of achievable digit sums for target M is exactly the
integer interval [smin​(M),M].
Proof.
Minimality. The greedy representation —
⌊M/2n−1⌋ top coins plus the binary expansion of the
remainder — attains the stated value. Any representation with some
ki≥2, i≤n−2, admits a carry
(ki,ki+1)→(ki−2,ki+1+1), lowering the digit sum by 1;
iterating terminates, and a carry-free representation (ki≤1 below the
top coin) is determined by its value — it is the greedy one. So every
representation descends to greedy through digit-sum-lowering moves: greedy is
minimal, and it is the unique representation attaining the minimum.
Contiguity, upward. Start from greedy, with digit sum smin​(M). While
the current digit sum s is <M, some ki≥1 with i≥1 exists —
otherwise all mass sits at index 0 and s=k0=M — and the split
(ki,ki−1)→(ki−1,ki−1+2) raises the digit sum by exactly
1. Hence the achievable digit sums are exactly [smin​(M),M].
∎
Remark 1.
Only the minimality half of Lemma 3 is used in
Section 5, and only the contiguity half in Section 6.
5 Validity: the upper bound
Theorem A.
For every n≥2, the super-increasing set is valid mod
N=2n−2m. Equivalently,
Nmin​(n)≤2n−2⌊log2⁡n⌋.
The proof is an induction on the multiple j​N, powered by a single step
estimate. We state the estimate for a general power-of-two gap, since
Section 6 reuses it at gaps other than 2m.
Lemma 4 (step).
Let 0≤t≤n−1 and Nt:=2n−2t. Then for every M≥0,
smin​(M+Nt)≥smin​(M)+1.
Proof.
Write Nt=2⋅2n−1−2t and M=q⋅2n−1+R with
0≤R<2n−1; by Lemma 3, smin​(M)=q+popcount⁡(R). Two cases
on R.
If R≥2t: then M+Nt=(q+2)⋅2n−1+(R−2t) with
0≤R−2t<2n−1, so
smin​(M+Nt)−smin​(M)= 2+popcount⁡(R−2t)−popcount⁡(R).
Subtracting a power of two costs at most one bit: if bit t of R is set, the
popcount drops by exactly 1; if not, the borrow clears the lowest set bit of
R above t — say bit u — and sets bits t,…,u−1, a net change
of (u−t)−1≥0. Either way the difference is ≥2−1=1.
If R<2t: then
M+Nt=(q+1)⋅2n−1+(R+(2n−1−2t)), and the new
remainder is <2n−1. The mask 2n−1−2t occupies bits
t,…,n−2, disjoint from R<2t, so its n−1−t bits add: the
difference is 1+(n−1−t)≥1.
∎

6 Optimality: the lower bound
We must show every N′ with 2≤N′<2n−2m is invalid: some
balanced c has N′|V⁡(c). Unlike at N itself — where the trivial
bound n≤M of Section 3 rules out negative multiples — a
smaller modulus may (and in one case must) be hit by a negative
multiple, so we work with signed V throughout.

Sharpness of the bound.
The boundary is exactly t=m, from both sides:
•
t≥m+1 ⟹ 2t−1≥n: the n units of digit sum fit

7 Machine certification
The results are supported by machine at two independent levels: a Lean
formalization of the full Main Theorem, and exact CP certificates for
Conjecture 1.
Lean formalization (all n).
The Main Theorem — Theorems A and B, for every n≥2 — is formalized
and kernel-checked in Lean 4 [1] with Mathlib
[9]: the statement nmin_eq asserts that
2n−2⌊log2⁡n⌋ is the least element of
{N≥2:A​ valid mod ​N}, with no unproven assumptions (the only
axioms are Mathlib’s standard propext, Classical.choice,
Quot.sound). The development mirrors the paper proof: the greedy digit
sum is defined by a one-bit-peeling recursion, Lemma 4 is
gmin_step, and the induction on j is slack — with, as in
Section 5, no range restriction on j and no small-n cases.
Theorem B constructs the four witnesses of Section 6 directly.
The full development is available at
https://github.com/jarfo/min-modulus.
Evidence for Conjecture 1.
Validity of a pair (A,N) is decidable exactly — without enumerating the
(2​n−1n) multisets — by proving a small integer feasibility model
infeasible (n bounded integer variables ki with ∑ki=n,
∑ki​ai≡p(modN), and k≠𝟏). Leaving the set A
free as well (its n residues become variables), CP-SAT [7]
certifies, for each modulus N′<2n−2m, that no
size-n set is valid mod N′ — one infeasibility certificate per modulus.
This certifies Conjecture 1 outright for n≤7; the number of moduli
roughly doubles per increment of n and the certificates harden, so beyond
that the conjecture rests on search: for n≤13, extensive solver- and
GPU-search finds valid sets at N=2n−2m and none below, and every
minimal-modulus solution found canonicalizes, under translation and unit
scaling, to the super-increasing set.
8 Open problems
1.
Global optimality (Conjecture 1): prove that no size-n
residue set is valid below 2n−2⌊log2⁡n⌋. The case
analysis of Section 6 uses the binary structure of the fixed set
throughout; a set-free argument would need a different mechanism. Even an
exponential lower bound Nmin≥cn valid for all sets appears to be open.
2.
Structure of minimal sets: for n≤13 every minimal-modulus
valid set found canonicalizes to the super-increasing one. Is the minimal-
modulus solution unique up to translation and unit scaling for all n?
3.
Weighted and rectangular variants: the validity condition fixes
∑iki=n with all rows sharing one exponent set. Permanents of
rectangular matrices, or mixed row supports, lead to variants of the validity
condition whose minimal moduli are unexplored.
4.
Beyond cyclic groups: validity mod N is the case G=ℤN of a
property of finite abelian groups. Say that n elements g0,…,gn−1
of a finite abelian group G, with sum t=∑jgj, have unique
multiset sums if the all-ones multiset is the only size-n multiset drawn from
them that sums to t; the companion paper [2]
realizes every such family as an exact permanent evaluator by a transform of
length |G|, the cyclic case G=ℤN being validity mod N. The Main
Theorem gives the least modulus among cyclic groups, but over all finite
abelian groups the least order is strictly smaller: the elementary abelian group
(ℤ2)n−1, of order 2n−1<2n−2⌊log2⁡n⌋ for
n≥3, already carries a size-n family with unique multiset sums
[2], so no cyclic group is optimal. Whether 2n−1
is the least order over all finite abelian groups for every n — it is
for n≤6 by exhaustive search — is open; as a first step,
Proposition 2 settles it within the elementary abelian 2-groups, the
family underlying Glynn’s scheme.
For the elementary abelian 2-groups Problem 4 has an elementary
answer: 2n−1 is optimal for every n, by a rank count over 𝔽2.
Proposition 2 (optimality among elementary abelian 2-groups).
If g0,…,gn−1∈(ℤ2)k have unique multiset sums, then k≥n−1.
Hence among elementary abelian 2-groups the least order admitting a size-n
embedding with unique multiset sums is exactly 2n−1, attained by
(ℤ2)n−1 with g=(0,e1,…,en−1).
Proof.
Write G=𝔽2k and let Λ:𝔽2n→𝔽2k be the 𝔽2-linear map
Λ⁡(x)=∑jxj​gj, so that t=∑jgj=Λ⁡(𝟏).
Since 2​g=0 in G, the sum ∑jkj​gj depends only on the parities
k¯j=kjmod2, and ∑jkj​gj=t holds iff
u:=k¯+𝟏∈ker⁡Λ (over 𝔽2, −1=1); note
supp⁡u={j:kj​ even}. We claim the embedding has
unique multiset sums iff ker⁡Λ contains no nonzero vector of even Hamming
weight. If some u∈ker⁡Λ is nonzero with wt⁡(u)=2​m,
form k by setting kj=1 off supp⁡u and, on the 2​m
coordinates of supp⁡u, setting m of them to 2 and the other
m to 0: then k¯+𝟏=u, so ∑jkj​gj=t, while
∑jkj=(n−2​m)+2​m=n and k≠𝟏 — a genuine rival.
Conversely a rival k≠𝟏 yields u=k¯+𝟏∈ker⁡Λ
with u≠0 (else every kj is odd, hence, being positive with sum n, equal
to 1) and wt⁡(u)=n−wt⁡(k¯)≡0(mod2),
since ∑jkj=n forces wt⁡(k¯)≡n. This proves the
claim.
The even-weight vectors form the parity hyperplane
H={x∈𝔽2n:wt⁡(x)≡0}, of codimension 1, so
ker⁡Λ∩H={0} forces dimker⁡Λ≤1; then
rank⁡Λ=n−dimker⁡Λ≥n−1, and
im⁡Λ⊆𝔽2k gives k≥n−1, i.e. |G|=2k≥2n−1. Equality holds for (ℤ2)n−1 with
g=(0,e1,…,en−1): there Λ⁡(x)=(x1,…,xn−1) has
kernel ⟨e0⟩, spanned by a weight-one vector, so the sums are unique
at order 2n−1.
∎
