## 0. Statements

Notation: `[r] = {1,...,r}`; for a field `K`, `K^x = K \ {0}`; for
`x_1,...,x_n` in `K` and nonempty `J ⊆ [n]`, `FS_J = Σ_{i∈J} x_i` and
`FP_J = Π_{i∈J} x_i`.

**Theorem F.** Let `K` be an infinite field (of any characteristic). Let
`r, n ≥ 1` and let `χ: K^x → [r]` be any map. Then there exist pairwise
distinct `x_1,...,x_n ∈ K^x` such that

1. `FS_J ≠ 0` for every nonempty `J ⊆ [n]`, and
2. `χ` is constant on `{FS_J} ∪ {FP_J}` (`J` ranging over nonempty subsets
   of `[n]`).

**Corollary G.** For every prime `p` and all `r, n ≥ 1` there is `d ≥ 1`
such that for every `m` divisible by `d` and every `χ: F_{p^m}^x → [r]` there
exist pairwise distinct `x_1,...,x_n ∈ F_{p^m}^x` satisfying 1 and 2.

The characteristic-zero case of Theorem F is known (Alweiss, Theorem 1.3 over
`Q`, restricted to the prime field, with Hunter's Remark 1.1 for
distinctness). The proof below does not use that case; it is uniform in the
characteristic.

## 1. External inputs (used as stated)

**(BL) Bergelson–Leibman, Annals of Math. 150 (1999), Corollary 7.11.**
Let `n, t ∈ N`, let `G` be an infinite ring, let `P: G^n → G^t` be a
polynomial mapping over `G` with `P(0) = 0`, and let `F` be a finite
configuration in `G^n`. For any finite colouring of `G^t` there are `h ∈ G^t`
and a nonzero `x ∈ G` such that `h + P(xF)` is monochromatic.
(Read in arXiv:math/9907201v1, §7.9–7.11; no restriction on the
characteristic. A conventional polynomial mapping is polynomial in their
sense by §8.7.)

**(R) Finite Ramsey theorem.** For all `k, M, c ≥ 1` there is `R_k(M; c)`
such that every `c`-colouring of the `k`-subsets of a set of size at least
`R_k(M; c)` has a subset of size `M` all of whose `k`-subsets have one colour.

**(Fo) Folkman's finite sums theorem.** For all `n, c ≥ 1` there is
`F = F(n, c)` such that every `c`-colouring of `[F]` admits positive integers
`a_1,...,a_n` (not necessarily distinct) with every nonempty subset sum in
`[F]` and all these subset sums of one colour. (This is the form stated in the
pinned source, `02_framework.tex`, "A finite combinatorial selection".)

**(T) Compactness.** For a countable set `X` and finite `C`, the product
space `C^X` is compact; sets defined by finitely many coordinates are clopen.

## 2. Reduction to countable fields and two colourings

**Lemma 1.** It suffices to prove Theorem F for countable `K`.

*Proof.* An infinite field `K` contains a countably infinite subset `A`; the
subfield `K_0` generated by `A` consists of rational expressions in finitely
many elements of `A` with coefficients in the prime field, so it is countable,
and it is infinite. Apply the countable case to `K_0` and `χ|_{K_0^x}`. Sums
and products of elements of `K_0` are the same in `K`. ∎

From now on `K` is a countably infinite field.

**Lemma 2 (ψ).** If `char K ≠ 2` there is `ψ: K^x → {0,1,2}` with
`ψ(2z) ≠ ψ(z)` for every `z ∈ K^x`.

*Proof.* `τ(z) = 2z` is a permutation of `K^x` with no fixed point (`2z = z`
forces `z = 0`). Fix an enumeration of `K`; in each `⟨τ⟩`-orbit let `z_0` be
its first element. If the orbit is infinite its elements are the distinct
`τ^j z_0`, `j ∈ Z`; put `ψ(τ^j z_0) = j mod 2`. If it is finite of size
`L ≥ 2`, its elements are `τ^j z_0`, `0 ≤ j < L`; put `ψ(τ^j z_0) = j mod 2`
for `j < L−1` and `ψ(τ^{L−1} z_0) = 2` if `L` is odd, `= 1` if `L` is even.
Consecutive elements receive different values in every case (for odd `L` the
element coloured 2 has neighbours coloured `(L−2) mod 2 = 1` and `0`). ∎

## 3. Finite polynomial recurrence over `K`

**Lemma 3.** Let `E` be a finite nonempty set, `(d_e)_{e∈E}` positive
integers, `L ⊂ K` finite with `0 ∈ L`, and `R ≥ 1`. There is a finite set
`Φ = Φ(E, d, L, R) ⊂ K^E × K^x` such that for every map `c: K^E → [R]` there
is `(u, k) ∈ Φ` with

    c(u + (ℓ_e k^{d_e})_{e∈E}) = c(u)   for all ℓ ∈ L^E.

*Proof.* Existence for one `c`: apply (BL) with `G = K`, `n = 1 + |E|`,
`t = |E|`, `P(w_0, (w_e)_e) = (w_e w_0^{d_e − 1})_{e∈E}`. Each coordinate is
a monomial of degree `d_e ≥ 1`, so `P(0) = 0`. Put
`F = {(1, ℓ) : ℓ ∈ L^E}`. Then `P(x(1, ℓ)) = (ℓ_e x^{d_e})_e`. (BL) gives
`h` and `x ≠ 0` with `c` constant on `h + P(xF)`; `ℓ = 0` gives the value
`c(h)`. So `(h, x)` works.

Uniformity: let `Ω = [R]^{K^E}` (compact by (T), since `K^E` is countable).
For `(u, k) ∈ K^E × K^x` let `O_{u,k}` be the set of `c` satisfying the
display. It depends on finitely many coordinates, so it is open. The first
paragraph shows the countably many `O_{u,k}` cover `Ω`. A finite subcover
gives `Φ`. ∎

`Φ` depends only on `(E, d, L, R)`, not on any colouring.

## 4. The field version of Alweiss's Proposition 4.1

Fix a map `χ: K → C` into a finite set `C` with `|C| = r`.

Notation.
- `y_j = 2^j` for `j ≥ 1`; for a finite `J ⊂ N`, `s_J = Σ_{j∈J} 2^j`
  (`s_∅ = 0`). For `J ⊆ [n−1]`, `0 ≤ s_J ≤ 2^n − 2`.
- For finite sets `S, T ⊂ N`, `S > T` means every element of `S` exceeds
  every element of `T` (vacuous if `T = ∅`).
- If `∅ ≠ S > T` then `s_T ≤ 2^{max S} − 2 < 2^{max S} ≤ s_S`, so
  `σ(S,T) := s_S − s_T ≥ 2`.
- For `i ≥ 1` and `T ⊆ [i−1]`, `𝒮(i,T) = {S : ∅ ≠ S ⊆ [i−1], S > T}`.
- `E_n = {(S,T) : ∅ ≠ S ⊆ [n−1], T ⊆ [n−1], S > T}`; write `σ_e = σ(S,T)`
  for `e = (S,T)`.
- For `x ∈ K^n` and `J ⊆ [n]`, `x^J = Π_{j∈J} x_j` (`x^∅ = 1`). If
  `x_1,...,x_{n−1} ≠ 0` and `e = (S,T) ∈ E_n`, `μ_e(x) = x^S / x^T`.
- For finite `Λ ⊂ K^x`, `χ^Λ(z) = (χ(λz))_{λ∈Λ} ∈ C^Λ`.

**Definition.** Let `Λ ⊂ K^x` and `L ⊂ K` be finite and `x ∈ K^n`.
- For `i ∈ [n]`, `T ⊆ [i−1]`: `(i,T)` is *`(Λ,L)`-secured at `x`* if for all
  `λ ∈ Λ` and all `ℓ ∈ L^{𝒮(i,T)}`,
  `χ(λ(x_i x^T + Σ_{S∈𝒮(i,T)} ℓ_S x^S)) = χ(λ x_i x^T)`.
- `x` is *`(Λ,L)`-good* if every `(i,T)` with `i ∈ [n]`, `T ⊆ [i−1]` is
  `(Λ,L)`-secured at `x`.
- If `x_1,...,x_{n−1} ≠ 0` and `U ⊆ [n−1]`: `U` is *`(Λ,L)`-handled at `x`* if
  for all `λ ∈ Λ`, `ℓ ∈ L^{E_n}`,
  `χ(λ(x_n + Σ_{e∈E_n} ℓ_e μ_e(x)) x^U) = χ(λ x_n x^U)`.

Both notions are monotone: they persist when `Λ, L` are replaced by subsets.
Whether `(i,T)` is secured depends only on `x_1,...,x_i`.

**Fact H.** If `0 ∈ L` and `U` is `(Λ,L)`-handled at `x`, then `(n,U)` is
`(Λ,L)`-secured at `x`.

*Proof.* `(S,U) ∈ E_n` iff `S ∈ 𝒮(n,U)`, and `μ_{(S,U)}(x) x^U = x^S`. Given
`ℓ ∈ L^{𝒮(n,U)}` put `ℓ'_{(S,U)} = ℓ_S` and `ℓ'_e = 0` for the other
`e ∈ E_n`. Then `(x_n + Σ_e ℓ'_e μ_e(x)) x^U = x_n x^U + Σ_S ℓ_S x^S`. ∎

**Lemma 4 (update identities).** Let `n ≥ 2`, `x ∈ K^n` with
`x_1,...,x_{n−1} ≠ 0`, `U ⊆ [n−1]`, `u ∈ K^{E_n}`, `k ∈ K^x`. Define
`x̃ = Upd_{U,u,k}(x)` by

    x̃_j = k^{y_j} x_j  (j < n),    x̃_n = k^{−s_U} (x_n + Σ_{e∈E_n} u_e μ_e(x)).

Then `x̃_1,...,x̃_{n−1} ≠ 0` and:
1. `x̃^J = k^{s_J} x^J` for `J ⊆ [n−1]`, and `μ_e(x̃) = k^{σ_e} μ_e(x)`.
2. For every `U_1 ⊆ [n−1]` and `ℓ ∈ K^{E_n}`:
   `(x̃_n + Σ_e ℓ_e μ_e(x̃)) x̃^{U_1} = k^{s_{U_1} − s_U} (x_n + Σ_e (u_e + ℓ_e k^{σ_e + s_U}) μ_e(x)) x^{U_1}`.
3. For `i ≤ n−1`, `T ⊆ [i−1]`, `ℓ ∈ K^{𝒮(i,T)}`, with `a = s_{T∪{i}}`:
   `x̃_i x̃^T + Σ_S ℓ_S x̃^S = k^a (x_i x^T + Σ_S ℓ_S k^{s_S − a} x^S)`.

*Proof.* (1) is immediate from `x̃_j = k^{2^j} x_j`. For (2):
`x̃_n x̃^{U_1} = k^{s_{U_1} − s_U}(x_n + Σ u_e μ_e(x)) x^{U_1}` and
`ℓ_e μ_e(x̃) x̃^{U_1} = ℓ_e k^{σ_e + s_{U_1}} μ_e(x) x^{U_1}
 = k^{s_{U_1} − s_U} · ℓ_e k^{σ_e + s_U} μ_e(x) x^{U_1}`; add.
For (3): `x̃_i x̃^T = k^{a} x_i x^T` and `x̃^S = k^{s_S} x^S`. ∎

These identities were also checked by random evaluation (see
`packet/code/identity_check.py`); that check is not a proof.

**Lemma 5 (one handling step).** Let `n ≥ 2`, `x ∈ K^n` with
`x_1,...,x_{n−1} ≠ 0`, `U ⊆ [n−1]`, `Λ ⊂ K^x` and `L ⊂ K` finite with
`0 ∈ L`. Let `Φ = Φ(E_n, (σ_e + s_U)_e, L, r^{|Λ|})` (Lemma 3). Then some
`(u,k) ∈ Φ` makes `U` `(Λ,L)`-handled at `Upd_{U,u,k}(x)`.

*Proof.* Identify `C^Λ` with a set of size `r^{|Λ|}` and define
`c(q) = χ^Λ((x_n + Σ_e q_e μ_e(x)) x^U)` for `q ∈ K^{E_n}`. Lemma 3 gives
`(u,k) ∈ Φ` with `c(u + (ℓ_e k^{σ_e + s_U})_e) = c(u)` for all `ℓ ∈ L^{E_n}`.
By Lemma 4(2) with `U_1 = U`, the left side is
`χ^Λ((x̃_n + Σ ℓ_e μ_e(x̃)) x̃^U)` and the right side (`ℓ = 0`) is
`χ^Λ(x̃_n x̃^U)`. Reading off coordinate `λ` gives the claim. ∎

**Lemma 6 (preservation).** Let `n ≥ 2`, `U ⊆ [n−1]`, `(u,k) ∈ K^{E_n} × K^x`,
and finite `Λ' ⊂ K^x`, `L' ⊂ K` with `0 ∈ L'`. Put `Z = 2^{n+1}` and

    Λ^♯ = {λ k^z : λ ∈ Λ', z ∈ Z, |z| ≤ Z},
    L^♯ = {ℓ k^z, u_e + ℓ k^z : ℓ ∈ L', e ∈ E_n, z ∈ Z, |z| ≤ Z}.

They are finite, `Λ' ⊆ Λ^♯`, `L' ⊆ L^♯`. Let `x` have `x_1,...,x_{n−1} ≠ 0`
and `x̃ = Upd_{U,u,k}(x)`.
- (a) If `U_1 ⊆ [n−1]` is `(Λ^♯, L^♯)`-handled at `x`, it is
  `(Λ', L')`-handled at `x̃`.
- (b) If `i ≤ n−1`, `T ⊆ [i−1]` and `(i,T)` is `(Λ^♯, L^♯)`-secured at `x`,
  it is `(Λ', L')`-secured at `x̃`.

*Proof.* Exponent bounds: `|s_{U_1} − s_U| ≤ 2^n`, `1 ≤ σ_e + s_U ≤ 2^{n+1}`,
`0 ≤ a ≤ 2^n`, `|s_S − a| ≤ 2^n`; all are at most `Z`.
(a) Let `λ ∈ Λ'`, `ℓ ∈ L'^{E_n}`. Put `λ_1 = λ k^{s_{U_1} − s_U} ∈ Λ^♯`,
`ℓ^1_e = u_e + ℓ_e k^{σ_e + s_U} ∈ L^♯`, and `ℓ^0_e = u_e ∈ L^♯` (use
`0 ∈ L'`). By Lemma 4(2),
`λ(x̃_n + Σ ℓ_e μ_e(x̃)) x̃^{U_1} = λ_1(x_n + Σ ℓ^1_e μ_e(x)) x^{U_1}` and
`λ x̃_n x̃^{U_1} = λ_1(x_n + Σ ℓ^0_e μ_e(x)) x^{U_1}`. Handledness at `x`
gives both the colour `χ(λ_1 x_n x^{U_1})`.
(b) By Lemma 4(3), `λ(x̃_i x̃^T + Σ ℓ_S x̃^S) = λ k^a(x_i x^T + Σ ℓ_S k^{s_S−a} x^S)`
with `λ k^a ∈ Λ^♯` and `ℓ_S k^{s_S − a} ∈ L^♯`. Securedness at `x` gives
colour `χ(λ k^a x_i x^T) = χ(λ x̃_i x̃^T)`. ∎

**Proposition 7.** Assume `χ(z) = χ(0)` implies `z = 0`. For every `n ≥ 1`
and finite `Λ ⊂ K^x`, `L ⊂ K` with `1 ∈ Λ` and `{0,1} ⊆ L`, there is a
`(Λ,L)`-good `x ∈ (K^x)^n`.

*Proof.* Induction on `n`. For `n = 1`, `x_1 = 1` works because
`𝒮(1,∅) = ∅`.

Let `n ≥ 2`. List the subsets of `[n−1]` as `U_1,...,U_q`, `q = 2^{n−1}`.

*Backward choice of finite data.* Put `(Λ_q, L_q) = (Λ, L)`. For
`t = q, q−1, ..., 1` let `Φ_t = Φ(E_n, (σ_e + s_{U_t})_e, L_t, r^{|Λ_t|})`
and let `(Λ_{t−1}, L_{t−1})` be the union over `(u,k) ∈ Φ_t` of the sets
`(Λ_t^♯, L_t^♯)` of Lemma 6 built from `(Λ_t, L_t)`, `U_t` and `(u,k)`.
These are finite, contain `(Λ_t, L_t)`, hence `1 ∈ Λ_{t−1}` and
`{0,1} ⊆ L_{t−1}`. None of this depends on any variable.

*Start.* By the induction hypothesis there is a `(Λ_0, L_0)`-good
`x' ∈ (K^x)^{n−1}`. Put `x^{(0)} = (x'_1, ..., x'_{n−1}, 0)`.

*Forward steps.* For `t = 1, ..., q` apply Lemma 5 to `x^{(t−1)}`, `U_t`,
`(Λ_t, L_t)` and `Φ_t`; it yields `(u^{(t)}, k^{(t)}) ∈ Φ_t`; put
`x^{(t)} = Upd_{U_t, u^{(t)}, k^{(t)}}(x^{(t−1)})`.

*Invariant J_t:* `x^{(t)}_1, ..., x^{(t)}_{n−1} ≠ 0`; every `(i,T)` with
`i ≤ n−1` is `(Λ_t, L_t)`-secured at `x^{(t)}`; and `U_1,...,U_t` are
`(Λ_t, L_t)`-handled at `x^{(t)}`.

`J_0` holds because securedness for `i ≤ n−1` involves only `x'`. Assume
`J_{t−1}`. Nonvanishing persists by Lemma 4. Since `(u^{(t)}, k^{(t)}) ∈ Φ_t`,
`Λ_{t−1} ⊇ Λ_t^♯` and `L_{t−1} ⊇ L_t^♯` for this pair; by monotonicity the
items in `J_{t−1}` hold with `(Λ_t^♯, L_t^♯)`, and Lemma 6 transfers them to
`(Λ_t, L_t)` at `x^{(t)}`. Lemma 5 adds `U_t`. So `J_t` holds.

At `t = q`, every `U ⊆ [n−1]` is `(Λ, L)`-handled at `x = x^{(q)}`; by Fact H
every `(n, U)` is secured; with `J_q`, `x` is `(Λ, L)`-good.

Finally `x_n ≠ 0`: `{1} ∈ 𝒮(n, ∅)`, so taking `λ = 1`, `ℓ_{{1}} = 1` and the
other coefficients `0` gives `χ(x_n + x_1) = χ(x_n)`. If `x_n = 0` then
`χ(x_1) = χ(0)`, so `x_1 = 0`, a contradiction. ∎

## 5. Proof of Theorem F

By Lemma 1, `K` is countable. If `n = 1`, take any `x_1 ∈ K^x`. Let `n ≥ 2`.

*Step 0 (refined colouring).* Let `ψ` be as in Lemma 2 if `char K ≠ 2` and
`ψ ≡ 0` if `char K = 2`. Define `χ̃: K → C̃ = ([r] × {0,1,2}) ∪ {★}` by
`χ̃(0) = ★` and `χ̃(z) = (χ(z), ψ(z))` for `z ≠ 0`. Then `r̃ = |C̃| = 3r + 1`
and `χ̃` isolates `0`.

*Step 1 (parameters).* `F = F(n, r̃)` from (Fo); `N_1 = F + n`;
`M_{N_1} = N_1` and `M_{k−1} = R_k(M_k; r̃)` for `k = N_1, ..., 1`;
`N_0 = M_0`.

*Step 2 (Proposition 7).* Apply Proposition 7 to `χ̃` with `n = N_0`,
`Λ = {1}`, `L = {0,1}`. We get `x ∈ (K^x)^{N_0}` such that for every
`i ∈ [N_0]`, `T ⊆ [i−1]` and every subfamily `𝒢 ⊆ 𝒮(i,T)`:

    (P1)   χ̃(x_i x^T + Σ_{S∈𝒢} x^S) = χ̃(x_i x^T).

*Step 3 (Ramsey).* Colour each `J ⊆ [N_0]` with `1 ≤ |J| ≤ N_1` by
`χ̃(x^J)`. Successively choose `[N_0] = I_0 ⊇ I_1 ⊇ ... ⊇ I_{N_1}` with
`|I_k| ≥ M_k` and all `k`-subsets of `I_k` of one colour (possible by (R),
since `|I_{k−1}| ≥ M_{k−1} = R_k(M_k; r̃)`). Let `I ⊆ I_{N_1}` have `N_1`
elements `ι_1 < ... < ι_{N_1}`. There is `κ: [N_1] → C̃` with
`χ̃(x^J) = κ(|J|)` for all `J ⊆ I`, `1 ≤ |J| ≤ N_1`.

*Step 4 (Folkman).* Apply (Fo) to `κ` restricted to `[F]` (`F ≤ N_1`): there
are `a_1, ..., a_n ≥ 1` with every nonempty subset sum in `[F]` and
`κ(Σ_{i∈Q} a_i) = ρ` for all nonempty `Q ⊆ [n]`.

*Step 5 (blocks).* Put `b_0 = 0`, `b_i = Σ_{h≤i}(a_h − 1)`; `b_n ≤ F − n`.
Let `B_i = {ι_j : b_{i−1} < j ≤ b_i}` (size `a_i − 1`, possibly empty) and
`π_i = ι_{F+n+1−i}`. Then `π_1 > π_2 > ... > π_n ≥ ι_{F+1}`, every pivot
exceeds every element of every block, and `B_i < B_{i'}` elementwise for
`i < i'`. Let `D_i = {π_i} ∪ B_i` (pairwise disjoint, `|D_i| = a_i`) and
`X_i = x^{D_i} = x_{π_i} x^{B_i}`.

*Products.* For nonempty `Q ⊆ [n]`, `Π_{i∈Q} X_i = x^{D_Q}` with
`D_Q = ∪_{i∈Q} D_i ⊆ I` and `|D_Q| = Σ_{i∈Q} a_i ∈ [F]`. So
`χ̃(Π_Q X_i) = κ(Σ_Q a_i) = ρ`.

*Sums.* For nonempty `Q`, let `i_0 = min Q`. For `i ∈ Q \ {i_0}`: `D_i` is
nonempty; `D_i ⊆ [π_{i_0} − 1]` because `π_i < π_{i_0}` and blocks lie below
all pivots; and `D_i > B_{i_0}` because `B_i > B_{i_0}` and `π_i` exceeds
every block element. Thus `𝒢 = {D_i : i ∈ Q \ {i_0}} ⊆ 𝒮(π_{i_0}, B_{i_0})`,
with distinct members, and `B_{i_0} ⊆ [π_{i_0} − 1]`. By (P1),

    χ̃(Σ_{i∈Q} X_i) = χ̃(x_{π_{i_0}} x^{B_{i_0}} + Σ_{S∈𝒢} x^S) = χ̃(X_{i_0}) = κ(a_{i_0}) = ρ.

*Step 6 (nondegeneracy).* Each `X_i` is a product of nonzero elements, so
`X_i ≠ 0` and `ρ = χ̃(X_1) ≠ ★`. Every subset sum has colour `ρ ≠ ★`, so is
nonzero. If `X_i = X_j` with `i ≠ j`, then `2X_i = X_i + X_j` has colour `ρ`.
In characteristic 2, `2X_i = 0` has colour `★ ≠ ρ`. Otherwise the second
coordinates give `ψ(2X_i) = ψ(X_i)`, contradicting Lemma 2. So the `X_i` are
pairwise distinct, all lie in `K^x`, all subset sums are nonzero, and the
first coordinate of `χ̃` shows that `χ` is constant on all subset sums and
products. Take `x_i := X_i`. ∎

## 6. Proof of Corollary G

Fix `p, r, n`. Inside an algebraic closure `Ω` of `F_p` let `F_j` be the
subfield with `p^{j!}` elements. Then `F_1 ⊆ F_2 ⊆ ...` and `∪_j F_j = Ω`,
an infinite field. Call `c: F_j^x → [r]` *bad* if no pairwise distinct
`x_1,...,x_n ∈ F_j^x` satisfy 1 and 2 for `c` in `F_j`. A configuration in
`F_i` is one in `F_j` for `i ≤ j`, so restrictions of bad colourings are
bad.

Suppose every `F_j` has a bad colouring. For `j ≥ i` let `R_{i,j}` be the set
of restrictions to `F_i^x` of bad colourings of `F_j^x`. These sets are
nonempty, finite, consist of bad colourings, and decrease in `j` (a bad
colouring of `F_{j+1}^x` restricts to a bad colouring of `F_j^x`). Hence
`B_i = ∩_{j≥i} R_{i,j}` is nonempty. Every `c ∈ B_i` extends to some
`c' ∈ B_{i+1}`: for each `j ≥ i+1` pick a bad colouring of `F_j^x` restricting
to `c`; among their (finitely many possible) restrictions to `F_{i+1}^x` one,
`c'`, occurs for infinitely many `j`, and then `c' ∈ R_{i+1,j}` for every
`j ≥ i+1` by the monotonicity just noted. Choose
`c_i ∈ B_i` with `c_{i+1}|_{F_i^x} = c_i` and let `c: Ω^x → [r]` be their
union. Theorem F for `Ω` gives a configuration; its finitely many elements and
sums lie in some `F_i`, so `c_i` is not bad. Contradiction.

So some `j_0` has no bad colouring; put `d = j_0!`. If `d | m`, then `F_{p^m}`
contains a subfield with `p^d` elements, isomorphic to `F_{j_0}`. Restrict
`χ: F_{p^m}^x → [r]` to it and transport along the isomorphism; the
configuration obtained there works in `F_{p^m}`. ∎

## 7. What is used from where

- Mechanism of §4 (shift of the top variable by bounded combinations of
  `x^S/x^T`, compensating dilations `x_j ← k^{2^j} x_j`, `x_n ← k^{−s_U} x_n`,
  handling the tails `U` one at a time, backward choice of finite budgets):
  Alweiss arXiv:2307.08901v6, §3–§4 (Proposition 4.1 and its proof). Here it
  is re-derived with finite sets of multipliers/coefficients in place of
  Alweiss's height `s(·)`.
- Recurrence input: Bergelson–Leibman Corollary 7.11 in place of Alweiss's
  Theorem 2.4 (integer polynomial van der Waerden scaled to `Q`); the finite
  set `Φ` from topological compactness of colourings of `K^E` in place of
  Alweiss's "u and n bounded by a function of the number of colours" and
  Hunter's "D is finite since N has characteristic zero".
- Selection (§5 Steps 3–5): Alweiss §5 Steps II–IV; the pinned source's
  `lem:chain-selection` uses the same argument over `N`.
- Distinctness: the `C(q) ≠ C(2q)` device of Hunter arXiv:2308.10749v1
  Remark 1.1, with the characteristic-2 case handled by the isolated zero
  colour.
- Corollary G: König-type compactness over the chain `F_{p^{j!}}`.

No step uses characteristic zero, an order, or a height.

## 8. Limitations

- The proof transports Alweiss's argument; the new ingredients are the
  characteristic-free recurrence input with finite-set bookkeeping, and the
  nondegeneracy argument. Whether this is a substantial contribution is for
  the separate contribution review; this document makes no such claim.
- Novelty search was limited (see `reading-limits.md`). Neither Bergelson–
  Leibman–McCutcheon (2005) nor other function-field Ramsey literature was
  read; a published characteristic-p statement may exist.
- Corollary G is only for `m` divisible by `d`; it says nothing about, e.g.,
  `F_{2^m}` with `m` prime. No bounds are given.
