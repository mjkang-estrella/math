                                                      On the boundary of pq-parameter space one encounters existing theorems and conjectures,

                                                                                       0. Introduction
                                             What shape experiences the greatest change in Riesz capacity when the exponent p in
                                           the interaction energy |x − y|−p increases or decreases? Specifically, consider the shape
                                           optimization problem of maximizing the Riesz capacity ratio
                                                                                            Capq (K)
                                                                                            Capp (K)
                                           for fixed Riesz exponents p ̸= q, as K varies over all compact sets in Rn . The ratio is scale
                                           and translation invariant and so the size or location of K does not matter, only its shape.
                                              This family of maximization problems connects naturally to geometric quantities, because
                                           Riesz p-capacity with p → −∞ gives diameter while as p → n it yields volume. Thus special
                                           cases of the family yield known results and open problems, including: Watanabe’s theorem
                                           on minimizing Riesz capacity for given volume, Pólya and Szegő’s conjecture on maximizing
                                           the ratio of Newtonian over logarithmic capacity for planar sets, the classical isodiametric
                                           theorem that maximizes volume for given diameter, the isodiametric theorem maximizing
                                           Newtonian capacity for given diameter (which follows from capacitary Brunn–Minkowski),
                                           and the still-open isodiametric conjecture for Riesz capacity.

  The optimal set in each of these special cases is known or conjectured to be the ball.
But this perfect symmetry is known to break in some regions of the pq-parameter plane,
in particular when p = −∞ (diameter) for certain q values by recent work of Burchard,
Choksi and Hess-Childs [8]. What are the maximizing shapes for the capacity ratio in the
symmetry-breaking transition region and beyond?

Overview. Motivated by these questions, we develop a wide-ranging shape optimization
program for Capq (K)/ Capp (K), summarized in the next sections by Figure 1, Figure 2 and
Figure 3 for dimensions 1, 2 and ≥ 3, respectively.
  The figures show in which regions of the pq-parameter plane we can conjecture or prove
maximality of the capacity ratio for the ball, regular (n + 1)-point set (vertices of a regular
simplex), or endpoints of an interval. Those parameter regions are separated by a “terra
incognita” transition region where symmetry breaks and the shape of maximizers is unclear.
  Progress is strongest in low dimensions, where our theorems cover substantial interior
regions in Figure 1 for 1 dimension and Figure 2 for the 2-dimensional case. In these figures,
a two-point set means the endpoints of a segment and a regular three-point set means
the vertices of an equilateral triangle. Results in Section 1 and Section 2 are:
     • (1-dim) interval maximizes when q = 1: Watanabe’s theorem for −∞ < p < 1
       (Theorem 2),
     • (1-dim) interval is maximizer when p ≤ −1 < q < 1 (Proposition 3),
     • (1-dim) two-point set is maximal when −1 < p < 0, q ≤ −1 (Proposition 5),
     • (2-dim) disk is not maximal in a certain region where p < −2, −2 < q < −0.86
       (Theorem 7),
     • (2-dim) regular three-point set is maximal when p < q ≤ −2 (Theorem 10),
     • (2-dim) two-point set is maximal when q < p < 0 and q ≤ −2 (Theorem 10).
Minimization results follow too, by simply interchanging p and q.
  Restricting temporarily to the class of planar three-point sets (vertices of a triangle),
Theorem 8 evaluates the p-capacity explicitly for negative p and Theorem 9 solves the ratio
maximization problem completely for p and q both negative.
  Existence of a maximizing set when p is negative is proved in Theorem 11, in all dimensions.
We have not found an existence result when p ≥ 0.
  Regarding the nature of the maximizing set in higher dimensions, Section 3 shows:
     • (n-dim) ball is maximal when −∞ ≤ p ≤ −2, q ∈ {n − 2, n − 1, n} (Theorem 13),
     • (n-dim) regular (n + 1)-point set is maximal when p = −∞, q ≤ −2 (Proposition 16),
     • (n-dim) two-point set is maximizer when p < 0, q = −∞ (Lemma 18).
Here Riesz capacity with parameter −∞ means the diameter of the set. The first of these
three results is Szegő’s isodiametric theorem for Newtonian capacity (q = n−2), and includes
the classical isodiametric theorem for volume (q = n). The second and third results provide
isodiametral maximization and minimization for Riesz capacity with parameters q ≤ −2 and
p < 0, respectively.
   Much remains unknown in higher dimensions. Perhaps the most difficult question in
the paper is Conjecture 12, which asserts that the ball maximizes the capacity ratio when
0 ≤ p < q. Pólya and Szegő’s Conjecture 6 is the case (p, q, n) = (0, 1, 2), and Watanabe’s
theorem is the limiting case with n − 2 < p < n and q ↗ n. The conjectures are confirmed
in Section 4 for some families of explicit examples.

k-point sets. By a k-point set we mean a finite set in Euclidean space containing exactly
k elements. The set is regular if its points form the vertices of a regular simplex. The
p-equilibrium measure on a regular k-point set is equidistributed with measure 1/k at each
point, when p < 0, and the set has p-capacity ((k − 1)/k)−1/p d where d is the diameter. See
the regular and nonregular examples in Section 6.

Related literature. The ratio of Riesz capacities studied in this paper resembles an attraction–
repulsion energy, in some respects. Recent work by Carrillo, Figalli, and Patacchini [10] and
Frank and Lieb [16] can serve as an introduction to that area. There the goal is to minimize
                             MAXIMIZING RIESZ CAPACITY RATIOS                                    5

an energy whose kernel encourages short-range repulsion and long-range attraction of parti-
cles. A “difference of power laws” kernel |x − y|α /α − |x − y|β /β where α > β > −n is a key
model example.
   The rich theory of that model has been explored in particular by Lim and McCann [22],
later joined by Davies [14, 15]. Those papers establish in certain regions of the αβ-parameter
plane that the minimizer is the uniform measure on either a sphere or the vertices of a regular
simplex — the same extremal shapes expected in the current paper. The link is direct when
α → ∞ (the “hard confinement limit”), for then the long-range potential imposes a diameter
constraint that corresponds in this paper to the limit p → −∞.
   A crucial difference, though, is that extremizing the attractive–repulsive energy involves
optimizing with respect only to a single measure, whereas in this paper, extremizing the
ratio of q-capacity to p-capacity requires simultaneous treatment of different measures in the
numerator and denominator.
   Other papers that have indirectly inspired the current research include Jerison’s solution
of the Minkowski problem for Newtonian capacity [19], which relies on Borell’s capacitary
Brunn–Minkowski inequality [5], Xiao’s result [40] on the Pólya–Szegő double-disk conjec-
ture for minimizing Newtonian capacity among convex sets of given surface area, Laugesen’s
extremal result for Riesz capacity under linear transformations [21], and Solynin and Zal-
galler’s beautiful theorem that among N -gons of given area, the regular N -gon minimizes
logarithmic capacity [32].

  Building on the last result, we prove the regular three-point set conjecture and some of
the two-point conjecture. That is, Conjecture 15 from the next section holds in the planar

Theorem 10 (p < 0 and q ≤ −2). Consider compact sets K ⊂ R2 containing more than
one point.
  (a) If p < q ≤ −2 then Capq (K)/ Capp (K) is maximal for K a regular three-point set,
with the maximal value being (2/3)1/p−1/q .
  (b) If q < p < 0 and q ≤ −2, then Capq (K)/ Capp (K) is maximal for K a two-point set,
with maximal value 21/q−1/p .
   The proof of the theorem is in Section 8. A key ingredient is a result of Björck [4, Theorem
12] which states for p < −2 that the equilibrium measure of K ⊂ Rn is supported on at most
n + 1 extreme points of the convex hull of K. Thus in the planar case we may reduce to
an arbitrary three-point set whose p-capacity we get from Theorem 8, and that result with
Theorem 9 helps prove Theorem 10.
   A word of caution is warranted, because the regular three-point set and the two-point set
are not the only maximizers for Theorem 10. For instance, when p < q < −2, any subset of
the equilateral triangle that contains its vertices will have the same p and q-capacities, and
will therefore also maximize the ratio in part (a) of the theorem. Similarly, for part (b), a
ball and almost-degenerate triangle will (for many parameters) have the same capacity and
equilibrium measure as a two-point set, by [7, Theorem 4.6.6] and Theorem 8, and so can
also be maximizing sets.
   Although the maximizing sets differ in these examples, the underlying equilibrium mea-
sures are admittedly the same. Surprisingly, even the measures can differ. In Section 8
we construct a maximizing set for the capacity ratio when q < p < −2 that supports two
different p-equilibrium measures. One of those equilibrium measures is supported not on a
2-point subset of the maximizer but rather on a 3-point subset.

                  3. Higher dimensions: results and open problems
 In all dimensions n ≥ 1, we start by showing the ratio of Riesz capacities achieves a
maximum, when p < 0.
Theorem 11 (Maximizer exists when p < 0). Let n ≥ 1 and q < n.
  If p < 0 then the ratio Capq (K)/ Capp (K) has a maximizer among the family of compact
sets K ⊂ Rn with positive p-capacity.
  If p < 0 and q < −2 then the maximizer can be taken to be a finite set consisting of
between 2 and n + 1 points, each of which is an extreme point for the convex hull of the set.
  If p < −1 then the maximizer can be taken to be convex.

   10. Proof of Theorem 13: capacitary Brunn–Minkowski and isodiametric

   The Brunn–Minkowski inequality for capacity is the key ingredient for proving Theorem 13.
It is known for p = n − 2 and p = n − 1:
Theorem 21 (Brunn–Minkowski for Riesz capacity; Borell [5, 6], Novaga–Ruffini [26], Pom-

cases, p = n − 2. For p = n − 1 the theorem was proved by Novaga and Ruffini [26].

Remark on equality cases. When p = n − 2, equality holds for convex bodies A and B if and
only if they are homothetic, by work of Caffarelli, Jerison and Lieb [9]. When p = n − 1,
Muratov, Novaga and Ruffini [25, Lemma 3.7] proved the equality case for n = 2, by an
argument that Qin and Zhang [30] observed extends easily to the case n ≥ 2. We will not
need these equality cases.

Remark on variational capacities. Colesanti and Salani [13] proved Brunn–Minkowski for
the family of variational capacities, which are not the same as Riesz capacities except in the
Newtonian case. An endpoint limit by Colesanti and Cuoghi [12] extends this approach to a
“variational logarithmic capacity”, which is not the same as the logarithmic capacity in this
paper.

                        Appendix A. Potential theoretic facts
   A set Z ⊂ Rn is said to have inner p-capacity zero if Capp (Z ′ ) = 0 for every compact
Z ′ ⊂ Z.
Lemma 23 (Inner p-capacity zero implies measure zero). Let 0 ≤ p < n. If Z ⊂ Rn is a
measurable set with inner p-capacity zero then Voln (Z) = 0.
Proof. We establish the contrapositive. If Voln (Z) > 0 then Voln (Z ′ ) > 0 for some compact
subset Z ′ ⊂ Z by inner regularity, and so Capp (Z ′ ) > 0 by using normalized Lebesgue
measure on Z ′ as a trial measure for the energy. Hence Z does not have inner p-capacity
zero.                                                                                      □
Lemma 24 (Inner p-capacity zero does not alter capacity). Let p ≥ 0 and n ≥ 1. Suppose
K, Z ⊂ Rn and that K and K ∪ Z are compact. If Z has inner p-capacity zero then
                                 Capp (K) = Capp (K ∪ Z).

Proof. We may suppose K and Z are disjoint, by replacing Z with the smaller set Z \ K. It
suffices to show Capp (K ∪ Z) ≤ Capp (K), since the other direction is immediate. We may
suppose Capp (K ∪ Z) is positive.

measure on K ∪ Z with finite p-energy. We claim µ(Z) = 0. Suppose µ(Z) > 0, so that
µ(Rn \ K) > 0 and hence the open set Rn \ K contains some compact subset Ze with positive
