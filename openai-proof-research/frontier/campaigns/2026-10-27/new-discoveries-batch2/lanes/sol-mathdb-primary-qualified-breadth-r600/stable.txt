Abstract.
We discuss the dynamics of nn-expansive homeomorphisms with the shadowing property defined on compact metric spaces. For every n∈ℕn\in\mathbb{N}, we exhibit an nn-expansive homeomorphism, which is not (n−1)(n-1)-expansive, has the shadowing property and admits an infinite number of chain-recurrent classes. We discuss some properties of the local stable (unstable) sets of nn-expansive homeomorphisms with the shadowing property and use them to prove that some types of the limit shadowing property are present. This deals some direction to the problem of non-existence of topologically mixing nn-expansive homeomorphisms that are not expansive.
Key words and phrases: Expansive, nn-expansive, shadowing, transitive, limit shadowing.
Bernardo Carvalho, Welington Cordeiro
1. Introduction and Statement of Results
The dynamics of expansive homeomorphisms with the shadowing property may be very complicated but it is quite well understood (see Aoki and Hiraide’s monograph [2]). It is known that these systems admit only a finite number of chain recurrent classes and that other pseudo-orbit tracing properties are present, such as the limit shadowing property (see Section 2 for definitions). A generalization of the expansiveness property that has been given attention recently is the nn-expansive property (see [3], [4], [10], [12]).
Definition 1.1.
We say that a homeomorphism ff, defined in a metric space (X,d)(X,d), is n-expansive (n∈ℕ)(n\in\mathbb{N}) if there exists c>0c>0 such that for every x∈Xx\in X the set
Γ⁡(x,c):={y∈X;d⁡(fn​(x),fn​(y))≤c,n∈ℤ}\Gamma(x,c):=\{y\in X\,\,\,;\,\,\,d(f^{n}(x),f^{n}(y))\leq c,\,\,\,n\in\mathbb{Z}\}
contains at most nn different points of XX. The number cc is called the nn-expansivity constant of ff.
The expansive homeomorphisms are exactly the 11-expansive ones. Roughly speaking, the nn-expansive homeomorphisms may admit nn different orbits ‘moving together’ but cannot admit n+1n+1. In this paper, we analyze the dynamics of nn-expansive homeomorphisms with the shadowing property defined on compact metric spaces. The first result that does not hold in this scenario is the Spectral Decomposition Theorem (Theorem 3.1.11 in [2]).
Theorem A.
For every n∈ℕn\in\mathbb{N}, there is an nn-expansive homeomorphism, defined in a compact metric space, that is not (n−1)(n-1)-expansive, has the shadowing property and admits an infinite number of chain recurrent classes.
This example also enlightens an important difference between the expansive homeomorphisms and the nn-expansive ones: for expansive homeomorphisms there is some number ε>0\varepsilon>0 such that for every x∈Xx\in X, the local stable set of xx of size ε\varepsilon (Wεs​(x)W^{s}_{\varepsilon}(x)) is contained in the stable set of xx (Ws​(x)W^{s}(x)) (see [11] for a proof), while for nn-expansive homeomorphisms such number does not exist (even when the shadowing property is present). However, we are able to prove some similar property: the existence of such number in a uniform way along the orbits.
Theorem B.
If an nn-expansive homeomorphism ff, defined in a compact metric space XX, has the shadowing property, then for each x∈Xx\in X there exists εx>0\varepsilon_{x}>0 such that
Wεxs​(fm​(x))⊂Ws​(fm​(x))W^{s}_{\varepsilon_{x}}(f^{m}(x))\subset W^{s}(f^{m}(x))
for every m∈ℤm\in\mathbb{Z}.
Using this Theorem we are able to prove that some types of limit shadowing are still present (precise definitions are given in Section 2).
Theorem C.
If an nn-expansive homeomorphism has the shadowing property then it has the limit shadowing property. If, in addition, it is topologically mixing, then it has the two-sided limit shadowing property.
These results generalize Theorems C and D in [8] to the nn-expansive scenario and gives some direction to the following question:
Question 1.
Does there exist a topologically mixing nn-expansive homeomorphism that is not expansive?
The two-sided limit shadowing property is known to be one of the strongest notions of pseudo-orbit tracing properties since it implies many of them (it implies even the specification property, see [8]). Its importance relies on its relation with hyperbolicity and transitivity, as one can see in [6] and [7]. Thought there are examples of non-expansive homeomorphisms with the two-sided limit shadowing property [8], the only known examples of homeomorphisms defined on compact and connected finite dimensional manifolds satisfying it are topologically conjugated to a transitive Anosov diffeomorphism, being, in particular, expansive. It is expected that, in this scenario, these are the only ones (see [5]). If this happens to be true, then Theorem C would answer Question 1 negatively for homeomorphisms defined on compact and connected finite dimensional manifolds and admitting the shadowing property.
The paper is organized as follows: in Section 2 we state some necessary definitions, in Section 3 we prove Theorem A, in Section 4 we prove Theorem B and in Section 5 we prove Theorem C.
2. Definitions
In this section we state all definitions that will be necessary in the proofs of our results. During this section ff denotes a homeomorphism defined in a compact metric space (X,d)(X,d). The first definition is the (standard) shadowing property.
Definition 2.1.
We say that a sequence (xk)k∈ℤ⊂X(x_{k})_{k\in\mathbb{Z}}\subset X is a δ\delta-pseudo-orbit if
it satisfies
d⁡(f⁡(xk),xk+1)<δ,k∈ℤ.d(f(x_{k}),x_{k+1})<\delta,\,\,\,\,\,\,k\in\mathbb{Z}.
A sequence (xk)k∈ℤ⊂X(x_{k})_{k\in\mathbb{Z}}\subset X is ε\varepsilon-shadowed if there exists y∈Xy\in X satisfying
d⁡(fk​(y),xk)<ε,k∈ℤ.d(f^{k}(y),x_{k})<\varepsilon,\,\,\,\,\,\,k\in\mathbb{Z}.
We say that ff has the shadowing property if for every ε>0\varepsilon>0 there exists δ>0\delta>0 such that every two-sided δ\delta-pseudo-orbit is
ε\varepsilon-shadowed.
This property was extensively studied due to its relation to the hyperbolic and stability thoeries (see [2], [14]). Now we define the limit shadowing property.
Definition 2.2.
We say that (xk)k∈ℕ(x_{k})_{k\in\mathbb{N}} is a limit pseudo-orbit if it
satisfies
d⁡(f⁡(xk),xk+1)→0,k→∞.d(f(x_{k}),x_{k+1})\rightarrow 0,\,\,\,\,\,\,k\rightarrow\infty.
A sequence {xk}k∈ℕ0\{x_{k}\}_{k\in\mathbb{N}_{0}} is limit-shadowed if there exists y∈Xy\in X such that
d⁡(fk​(y),xk)→0,k→∞.d(f^{k}(y),x_{k})\rightarrow 0,\,\,\,\,\,\,k\rightarrow\infty.
We say that ff has the limit shadowing property if every limit pseudo-orbit is limit-shadowed.
This property was introduced by T. Eirola, O. Nevanlinna, S. Pilyugin in [9] and further studied by S. Pilyugin in [13]. The first author of this paper proved (Lemma 2.1 in [6]) that any expansive homeomorphism, defined in a compact metric space, with the shadowing property has the limit shadowing property. This gives many examples of homeomorphisms with the limit shadowing property. If we consider bilateral sequences of XX we can define a property called two-sided limit shadowing.
Definition 2.3.
We say that a sequence (xk)k∈ℤ(x_{k})_{k\in\mathbb{Z}} of points of a metric space (X,d)(X,d) is a two-sided limit pseudo-orbit if it satisfies
d⁡(f⁡(xk),xk+1)→0,|k|→∞.d(f(x_{k}),x_{k+1})\rightarrow 0,\,\,\,\,\,\,|k|\rightarrow\infty.

d⁡(fk​(y),xk)→0,|k|→∞.d(f^{k}(y),x_{k})\rightarrow 0,\,\,\,\,\,\,|k|\rightarrow\infty.
In this situation, we also say that yy two-sided limit shadows (xk)k∈ℤ(x_{k})_{k\in\mathbb{Z}}. We say that
ff has the two-sided limit shadowing property if every two-sided limit pseudo-orbit is two-sided limit shadowed.
Tough this property is very similar to define, it is very different from the limit shadowing property. The first author studies this property in detail in [5], [6], [7] and [8]. Among many results, it is proved that this property implies the shadowing property, the limit shadowing property, the average shadowing property, the assymptotic average shadowing property and even the specification property, being one of the strongest known notions of pseudo-orbit tracing properties. Now the specification property is defined.

Every continuous map with the specification property is topologically mixing.
Definition 2.5.
We say that ff is transitive if for any pair (U,V)(U,V) of non-empty open subsets of XX there is k∈ℕk\in\mathbb{N} such that fk​(U)∩V≠∅f^{k}(U)\cap V\neq\emptyset. We say that ff is totally transitive if all its iterates fkf^{k}, k∈ℕk\in\mathbb{N}, are transitive. We say that ff is topologically mixing if for any pair (U,V)(U,V) of non-empty open subsets of XX there is k∈ℕk\in\mathbb{N} such that fj​(U)∩V≠∅f^{j}(U)\cap V\neq\emptyset for every j≥kj\geq k.
It is known that the topologically mixing property implies the totally transitive property, which, in turn, implies the transitive property. In the non-transitive scenario, the notion of a chain-recurrent class is important.
Definition 2.6.
The chain-recurrent class of a point x∈Xx\in X is the set of all points y∈Xy\in X such that for every ε>0\varepsilon>0 there exist a finite ε\varepsilon-pseudo orbit starting at xx and ending at yy and another finite ε\varepsilon-pseudo orbit starting at yy and ending at xx.
It is easy to see that transitive homeomorphisms admit only one chain recurrent class, while the example we exhibit in Theorem A admits an infinite number of such classes. A generalization of the notion of nn-expansivity is the finite expansivity and we define it as follows.
Definition 2.7.
We say that ff is finite expansive if there exists c>0c>0 such that for every x∈Xx\in X the set
Γ⁡(x,c):={y∈X;d⁡(fn​(x),fn​(y))≤c,n∈ℤ}\Gamma(x,c):=\{y\in X\,\,\,;\,\,\,d(f^{n}(x),f^{n}(y))\leq c,\,\,\,n\in\mathbb{Z}\}
is finite. The number cc is called the finite-expansivity constant of ff.
There are finite expansive homeomorphisms that are not nn-expansive for any n∈ℕn\in\mathbb{N} (see Remark 3.2) even when the shadowing property is present. We finish this section with the definitions of the stable and unstable sets of ff (also the local ones).
Definition 2.8.
The stable set of x∈Xx\in X is the set
Ws(x)={y∈X;d(fk(y),fk(x))→0,ifk→∞}.W^{s}(x)=\{y\in X;\,\,\,d(f^{k}(y),f^{k}(x))\rightarrow 0,\,\,\,\textrm{if}\,\,\,k\rightarrow\infty\}.
The unstable set of x∈Xx\in X is the set
Wu(x)={y∈X;d(f−k(y),f−k(x))→0,ifk→∞}.W^{u}(x)=\{y\in X;\,\,\,d(f^{-k}(y),f^{-k}(x))\rightarrow 0,\,\,\,\textrm{if}\,\,\,k\rightarrow\infty\}.
For some number ε>0\varepsilon>0, we define the ε\varepsilon-stable set of x∈Xx\in X as the set
Wεs​(x)={y∈X;d⁡(fk​(y),fk​(x))≤ε,k∈ℕ},W_{\varepsilon}^{s}(x)=\{y\in X;\,\,\,d(f^{k}(y),f^{k}(x))\leq\varepsilon,\,\,\,k\in\mathbb{N}\},
and define the ε\varepsilon-unstable set of x∈Xx\in X as the set
Wεu​(x)={y∈X;d⁡(f−k​(y),f−k​(x))≤ε,k∈ℕ}.W_{\varepsilon}^{u}(x)=\{y\in X;\,\,\,d(f^{-k}(y),f^{-k}(x))\leq\varepsilon,\,\,\,k\in\mathbb{N}\}.

4. Local stable sets
The example of Theorem A also shows that there is no number ε>0\varepsilon>0 such that Wεs​(x)⊂Ws​(x)W_{\varepsilon}^{s}(x)\subset W^{s}(x) and Wεu​(x)⊂Wu​(x)W_{\varepsilon}^{u}(x)\subset W^{u}(x) for every x∈Xx\in X. Indeed, for every ε>0\varepsilon>0 one can consider k∈ℕk\in\mathbb{N} such that 1k<ε\frac{1}{k}<\varepsilon and note that all the periodic points q⁡(i,k,j)q(i,k,j), with i∈{1,…,n−1}i\in\{1,\dots,n-1\}, belong to Wεs​(pk)W_{\varepsilon}^{s}(p_{k}) and Wεu​(pk)W_{\varepsilon}^{u}(p_{k}) but do not belong to Ws​(pk)W^{s}(p_{k}) nor Wu​(pk)W^{u}(p_{k}).
