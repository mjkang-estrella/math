                                                      Descents and inversions in powers of permutations
                                                                               Stijn Cambie ∗                Jun Yan†

                                                                                               Abstract
                                                      In this paper, we generalise several recent results by Archer and Geary on descents in powers
                                                  of permutations, and confirm all their conjectures. Specifically, for all k ∈ Z+ , we prove explicit
                                                  formulas for the expected numbers of descents and inversions in the k-th powers of permutations
                                                  in Sn for all n ≥ 2k +1. We also compute the number of Grassmanian permutations in Sn whose
                                                  k-th powers remain Grassmanian, and the number of permutations in Sn whose k-th powers
                                                  have the maximum number of descents.


                                           1      Introduction
                                               Given a permutation π ∈ Sn , a descent in π is an index i ∈ [n − 1] satisfying π(i) > π(i + 1),
                                           while an inversion in π is a pair i < j of indices in [n] satisfying π(i) > π(j). The number of descents
                                           and the number of inversions in π are denoted by des(π) and inv(π), respectively.
                                               It is easy to show that the expected number of descents in a random permutation π ∈ Sn is n−1    2 ,
                                           as for each i ∈ [n − 1], the events π(i) > π(i + 1) and π(i) < π(i + 1) are equally likely. A similar
                                           argument shows that the expected number of inversions in a permutation π ∈ Sn is n(n−1)     4   .

                                           have a fixed small number of descents, Archer and Geary conjectured that for all but the first few

π k (j) = y is independent of the choice of x and y.

{i, i + 1}, half of them satisfy π k (i) > π k (i + 1) and half of them satisfy π k (i) < π k (i + 1).
Proof. By Lemma 2.1, it suffices to consider those π ∈ Sn such that exactly one of π k (i), π k (i + 1)

direct bijective proof here.
    For every x ∈ [n] \ {i, i + 1}, switching the labels i and i + 1 gives a bijection between π ∈ Sn for
which (π k (i), π k (i + 1)) = (i, x) and those satisfying (π k (i), π k (i + 1)) = (x, i + 1), and and a bijection
between those satisfying (π k (i), π k (i + 1)) = (x, i) and those with (π k (i), π k (i + 1)) = (i + 1, x). Since
x > i if and only if i + 1 < x under our assumption on x, these two bijections swaps whether π k has
an ascent or descent at position i, implying that there are equally many of them having each.

3     On Grassmanian permutations π with des(π k ) ∈ {0, 1}
    In this section, we show that a permutation being Grassmanian is so rare, that both π and
π k being so implies a lot of structure, and so we can count the number of them precisely. By [1,
Lem. 2.2], it is sufficient to determine the number of such permutations for which π(1) 6= 1 or
π(n) 6= n, as those satisfying π(1) = 1 or π(n) = n can be counted recursively.
    We begin with a technical lemma that we will use shortly to prove Theorem 1.3.
Lemma 3.1. Let k ≥ 3, i, j ∈ [n − 1]. Suppose π, π k are both Grassmanian permutations with
π(i) = π k (j) = n, π(i + 1) = π k (j + 1) = 1. If there exists some 0 ≤ t ≤ i − 1, such that
π(i − ℓ) = π k (j − ℓ) = n − ℓ for all ℓ ∈ [t], and π(n) = π k (n) = n − t − 1, then i = j and π k−1 = id.
Proof. Since π(n) = π k (n) = n − t − 1, we have π k−1 (n) = n. Thus, π k−2 (n) = i as π(i) = n, and
so π k−1 (i) = i. However, we also have π k−1 (j) = i as π k (j) = n. Hence, we must have i = j.
    We now use induction to show that π k−1 (n − ℓ) = n − ℓ for all 0 ≤ ℓ ≤ n − 1, or equivalently
π (n − ℓ) = π −k (n − ℓ). The case ℓ = 0 follows from above. For all ℓ ∈ [t], since i = j, from
  −1

assumption we have π(i − ℓ) = π k (i − ℓ) = n − ℓ, and so π k−1 (n − ℓ) = n − ℓ. The case ℓ = t + 1
follows similarly from π(n) = π k (n) = n − t − 1. Now assume r > t + 1 and π k−1 (n − ℓ) = n − ℓ for
all 0 ≤ ℓ ≤ r − 1.
    Let x, y be such that π(x) = π k (y) = n − r. From induction hypothesis, π −1 (n − ℓ) = π −k (n − ℓ)
for all 0 ≤ ℓ ≤ r − 1. Let x1 be the smallest index such that π(x1 ) ∈ {n − r + 1, . . . , n} and let x2 be
the smallest index larger than i + 1 such that π(x2 ) ∈ {n − r + 1, . . . , n}. Since the unique descent
of π is at i, we must have x, y ∈ {x1 − 1, x2 − 1}. If x = y, then π k−1 (n − r) = n − r and we are
done. Otherwise, x = x2 − 1 or y = x2 − 1. Since x2 > i + 1, we have π(x2 ) < · · · < π(n) = n − t − 1,
which implies n − r + 1 ≤ π(x2 ) ≤ x2 − t − 1, and so x2 − 1 ≥ n − r + 1 + t ≥ n − r + 1. If x = x2 − 1,
then from induction hypothesis, π k−1 (x) = π k−1 (x2 − 1) = x2 − 1 = x, so n − r = π(x) = π k (x) and
π k−1 (n − r) = n − r, as required. If y = x2 − 1, then similarly, n − r = π k (y) = π(π k−1 (y)) = π(y)
and so π k−1 (n − r) = n − r as well. This completes the induction and the proof that π k−1 = id.

Lemma 3.5. Let α ∈ Sr , β ∈ Ss be Grassmanian permutations with no fixed point. Then, there
exists a Grassmanian permutation π ∈ Sr+s with a partition [r+s] = A∪B, such that the restrictions
of π to A and B are permutations isomorphic to α and β, respectively.
Proof. To distinguish it from α, we view β as a permutation on the set [s] = {1, 2, . . . , s}. For
notational convenience, define f : [r] ∪ [s] → [r] ∪ [s] by f (i) = α(i) for i ∈ [r] and f (i) = β(i) for
i ∈ [s]. Suppose α(t) = r, α(t + 1) = 1 and β(m) = s, β(m + 1) = 1.
      After relabelling each xi to i, the desired permutation π is equivalent to an ordering x1 ≺ x2 ≺
· · · ≺ xr+s of the elements in [r] ∪ [s], such that the elements in [r] and the elements in [s] are still
ordered in the usual way, and the sequence f (x1 ), f (x2 ), . . . , f (xr+s ) has exactly one descent in this
ordering ≺. Note that as t ≺ t + 1 and f (t + 1) = α(t + 1) ≺ α(t) = f (t), there must be a descent
somewhere between t and t + 1. Similarly, there is a descent between m and m + 1. Hence, for
f (x1 ), f (x2 ), . . . , f (xr+s ) to have at most one descent, we must have t ≺ m + 1 and m ≺ t + 1, and
that the unique descent is at xt+m . It follows that the smallest t + m elements under ≺ must be
[t] ∪ [m], and we call them the first part of ≺. The largest r + s − t − m elements under ≺ are called
the second part of ≺.
      We construct such an ordering with the following process. Start with the ordering 1 ≺ 2 ≺ · · · ≺
t ≺ 1 ≺ 2 ≺ · · · ≺ m ≺ t + 1 ≺ · · · ≺ r ≺ m + 1 ≺ · · · ≺ s. In every step, if within the same part of
≺ there is some i immediately preceding some j, but f (i) ≻ f (j), then we swap the order of i and
j in ≺. Since elements in [r] are only ever moved up in the ordering ≺, if at some point during the
process we have i ≻ j, then this is true from then on. Also, if within the same part we have i ≻ j
at some point, then i must have been swapped with j in some previous step, so from that point on
we have f (i) ≻ f (j).
      This process must terminate. If it ends with 1 ≺ 2 ≺ · · · ≺ m ≺ 1 ≺ 2 ≺ · · · ≺ t ≺ m + 1 ≺
· · · ≺ s ≺ t + 1 ≺ · · · ≺ r, then from the observation above f (x1 ), f (x2 ), . . . , f (xr+s ) has exactly one
descent. If the process ends earlier because no further swap is needed, then from the definition of
swaps, f is increasing within both parts, and thus has exactly one descent.

Lemma 3.7. Given distinct Grassmanian cycles α, β of length at least two, there is at most one
Grassmanian permutation which decomposes exactly into two cycles isomorphic to α and β.
Proof. We use the same notations as in the proof of Lemma 3.5. Suppose ≺1 , ≺2 are two differ-
ent orderings that would produce two distinct Grassmanian permutations satisfying the required
conditions. As proved before, ≺1 , ≺2 have the same first part and the same second part.
     Suppose i ∈ [r] is the index that maximises v2 − v1 , where v1 is the number of elements in [s]
that i is greater than under ≺1 , or equivalently the unique element such that v1 ≺1 i ≺1 v1 + 1, and
similarly for v2 . Let j be this maximum, and note we can assume without loss of generality that
j ≥ 1, which means that i surpasses j additional elements of [s] when we go from ≺1 to ≺2 . Since i
is in the same part of ≺1 and ≺2 and f is increasing in that part, it follows that α(i) also surpasses
at least j elements of [s], and thus exactly j by maximality. Repeating the argument, since α is a
cycle, αk (i) attains all values of α, so each i ∈ [r] surpasses exactly j elements of [s] going from ≺1
to ≺2 . By symmetry, there is some j ′ ≥ 1 such that each i ∈ [s] is surpassed by j ′ elements of [r].
     It follows that ≺1 , ≺2 both consists of groups of j + j ′ elements, where in ≺1 each group begins
with a block of j ′ elements in [r] and ends with a block of j elements in [s], and in ≺2 the two blocks
in each group of ≺1 are swapped. Since these are the only order swaps, α must send each block of
j ′ elements in [r] to another block of j ′ elements in [r]. As α is increasing in each block, it follows
that if i is the ℓ-th element in a block, then so is α(i). Repeating this argument shows that for every
ℓ ∈ [j ′ ], α only sends the ℓ-th elements in these block to each other, contradicting α is a cycle if
j ′ > 1. Similarly, j > 1 would contradict that β is a cycle. Therefore, we must have j = j ′ = 1, and
so r = s. We show that α is isomorphic to β, which is a contradiction. Indeed, for every i ∈ [r], the
groups containing i is just i and i. Going from ≺1 to ≺2 , i swapped with i, so α(i) swapped with
β(i), implying that they are in the same group and hence α(i) = β(i).
Example 3.8. A situation where j = 1, j ′ = 2 could be 3 ≺1 4 ≺1 2 ≺1 5 ≺1 6 ≺1 3 ≺1 1 ≺1 2 ≺1 1
and 2 ≺2 3 ≺2 4 ≺2 3 ≺2 5 ≺2 6 ≺2 1 ≺2 1 ≺2 2. It follows that α must send 3, 5, 1 to each other
and 4, 6, 2 to each other, and thus is not a 6-cycle.
