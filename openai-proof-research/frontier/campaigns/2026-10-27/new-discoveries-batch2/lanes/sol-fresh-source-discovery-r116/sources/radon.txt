 Abstract. 
    
 Consider the (almost surely) unique Radon partition of a set of  n n  random Gaussian vectors in  ℝ n − 2 \mathbb{R}^{n-2} ; choose one of the two parts of this partition uniformly at random, and for  0 ≤ k ≤ n 0\leq k\leq n , let  p k p_{k}  denote the probability that it has size  k k . In this paper, we prove strong unimodality results for the distribution  ( p 0 , … , p n ) (p_{0},\dots,p_{n}) . 
  
 
 2010 Mathematics Subject Classification Primary 05A20; Secondary 05E05, 15A15, 58K05
 
 
 1.  Introduction 

 
 In 1921, Radon proved  [ 29 ]  that any set  X X  of  n n  points in  ℝ n − 2 \mathbb{R}^{n-2}  can be partitioned — such a partition is called a  Radon partition of  X X  — into two sets whose convex hulls intersect, and that if the points are in general position (as will be the case in what follows), then this partition is unique. Radon’s theorem is a foundational result in convex geometry  [ 2 ,  15 ,  16 ] , and was, for instance, used by Radon to give one of the early proofs of Helly’s theorem. 
 
 
 In this paper, we explore the behaviour of the Radon partition of a random set of  n n  points in  ℝ n − 2 \mathbb{R}^{n-2} , specifically, of a set of  n n  independent Gaussian vectors. For such a random set  X X  and for  0 ≤ k ≤ n 0\leq k\leq n , let  p k = p k ( n ) p_{k}=p_{k}^{(n)}  denote the probability that a randomly chosen part of its (almost surely) unique Radon partition has  k k  elements, and note that  p 0 = p n = 0 p_{0}=p_{n}=0 . Our goal in this paper is to understand this probability distribution  𝐩 n = ( p 0 , … , p n ) \mathbf{p}_{n}=(p_{0},\dots,p_{n}) , and to demonstrate in particular that  𝐩 n \mathbf{p}_{n}  has some strong unimodality properties. 
 
 
 The motivation to study this distribution  𝐩 n \mathbf{p}_{n}  is related to Sylvester’s ‘four-point question’ from 1864 that asks for the probability that four random planar points are in convex position. For Gaussian planar vectors, the answer —  ( p 2 ) ( 4 ) (p_{2})^{(4)}  in our notation — was given by Maehara  [ 24 ] . The distribution  𝐩 n \mathbf{p}_{n}  arises naturally when studying higher-dimensional analogues of Sylvester’s question, and the problem of understanding this distribution was recently raised by Frick, Newman, and Pegden  [ 17 ]  and by White  [ 38 ]  in precisely this context. While an exact description of the distribution  𝐩 n \mathbf{p}_{n}  seems out of reach, we shall nevertheless establish a number of nontrivial properties of this distribution. 
 
 
 Main results 

 
 Let  X = { 𝐗 1 , … , 𝐗 n } ⊂ ℝ n − 2 X=\{\Xb_{1},\dots,\Xb_{n}\}\subset\mathbb{R}^{n-2}  be a set of  n n  independent standard normal random vectors. Note that these points are in general position almost surely, so they almost surely admit a unique Radon partition; we denote this partition by  { 𝒜 n , ℬ n } \{\mathcal{A}_{n},\mathcal{B}_{n}\} . From these two sets, we choose one uniformly at random, which we call  𝒮 n \cS_{n} , and we write  S n = | 𝒮 n | S_{n}=|\cS_{n}| . For  n ≥ 3 n\geq 3  and  0 ≤ k ≤ n 0\leq k\leq n , let 
 

 
 (1.1) 
 
 p k = p k ( n ) = ℙ [ S n = k ] p_{k}=p_{k}^{(n)}=\Pb[S_{n}=k] 
 
 
 be the probability that a randomly chosen part of the Radon partition of  X X  has size  k k . Writing  [ n ] [n]  for the set  { 1 , … , n } \{1,\dots,n\} , our main result is the following theorem. 
 
 
 Theorem 1.1   (Ultra log-concavity) . 
 
 For each  n ≥ 3 n\geq 3 , the distribution  𝐩 n = ( p 0 , … , p n ) \mathbf{p}_{n}=(p_{0},\dots,p_{n})  is ultra log-concave, i.e., we have 
 

 
 
 ( p k ( n k ) ) 2 ≥ p k + 1 ( n k + 1 ) ​ p k − 1 ( n k − 1 ) \left(\frac{p_{k}}{\binom{n}{k}}\right)^{2}\geq\frac{p_{k+1}}{\binom{n}{k+1}}\frac{p_{k-1}}{\binom{n}{k-1}} 
 
 
 for each  k ∈ [ n − 1 ] k\in[n-1] . 
 
 
 
 We prove Theorem  1.1  in Section  5 .
The following consequence of Theorem  1.1  establishes a conjecture of White  [ 38 ]  asserting that the more balanced a partition is, the more likely it is to occur as the Radon partition of a Gaussian random set of points. 
 
 
 Corollary 1.2   (Unimodality) . 
 
 For each  n ≥ 3 n\geq 3 , the distribution  𝐩 n = ( p 0 , … , p n ) \mathbf{p}_{n}=(p_{0},\dots,p_{n})  is unimodal, i.e., 
 

 
 
 p 0 ≤ p 1 ≤ ⋯ ≤ p ⌊ n 2 ⌋ = p ⌈ n 2 ⌉ ≥ ⋯ ≥ p n − 1 ≥ p n . p_{0}\leq p_{1}\leq\dots\leq p_{\lfloor\frac{n}{2}\rfloor}=p_{\lceil\frac{n}{2}\rceil}\geq\dots\geq p_{n-1}\geq p_{n}. 
 
 
 
 
 
 We prove Theorem  1.1  by reducing it to a problem involving the log-concavity of sequences arising from the behaviour of percentiles of normal random variables. This is a problem of some independent interest and we shall say more about it below.
We also note that it remains an open problem to determine whether unimodality still holds when  𝐗 1 , … , 𝐗 n \Xb_{1},\ldots,\Xb_{n}  are sampled uniformly from a bounded convex set  K K , see Problem  7.1 . 
 
 
 
 Log-concavity of Youden’s demon sequence 

 
 Let  Y 1 , … , Y n Y_{1},\dots,Y_{n}  be a set of  n n  independent standard normal random variables, and let  Y ¯ = ( Y 1 + ⋯ + Y n ) / n \overline{Y}=({Y_{1}+\cdots+Y_{n}})/{n}  denote their  sample mean . For  k ∈ [ n ] k\in[n] , we write 
 

 
 (1.2) 
 
 q k = q k ( n ) = ℙ [ { Y 1 , … , Y k ≤ Y ¯ ≤ Y k + 1 , … , Y n } ] q_{k}=q_{k}^{(n)}=\Pb\left[\{Y_{1},\dots,Y_{k}\leq\overline{Y}\leq Y_{k+1},\dots,Y_{n}\}\right] 
 
 
 for the probability that the sample mean is greater than the first  k k  samples and less than the last  n − k n-k  samples. The determination of these probabilities — this is the problem of  Youden’s demon  — has been the subject of extensive work in mathematical statistics; see  [ 39 ,  20 ,  14 ,  17 ] , for examples. 
 
 
 We shall deduce our main result, Theorem  1.1 , from the following result about Youden’s demon problem. 
 
 
 Theorem 1.3   (Log-concavity) . 
 
 For each  n ≥ 3 n\geq 3 , the distribution  𝐪 n = ( q 0 , … , q n ) \mathbf{q}_{n}=(q_{0},\dots,q_{n})  is log-concave, i.e., we have 
 

 
 (1.3) 
 
 q k 2 ≥ q k + 1 ​ q k − 1 q_{k}^{2}\geq q_{k+1}q_{k-1} 
 
 
 for each  k ∈ [ n − 1 ] k\in[n-1] . 
 
 
 
 We prove Theorem  1.3  in Section  4 .
We note that the assumption that  Y 1 , … , Y n Y_{1},\ldots,Y_{n}  are normally distributed is essential here (as we shall see in Section  6 ).
The reduction of Theorem  1.1  to Theorem  1.3  (see Lemma  5.1 ) more or less follows from the work of Frick, Newman, and Pegden  [ 17 ]  and White  [ 38 ]  who, in turn, rely on a general result by Baryshnikov and Vitale  [ 12 ] . 
 
 
 Let us also note that the assumption of normality cannot be dropped from Theorem  1.3 ; we shall exhibit an i.i.d. collection of non-normal random variables for which the corresponding sequence  q 0 , … , q n q_{0},\dots,q_{n}  is not unimodal, and therefore not log-concave. 
 
 
 
 Conditional associations 

 
 We will prove Theorem  1.3  as a consequence of a more general phenomenon about  conditional associations , but to state the precise result driving this, we need some notation. 
 
 
 Two events  A A  and  B B  in a probability space are said to be  positively associated  if  ℙ ⁡ [ A ∩ B ] ≥ ℙ ⁡ [ A ] ​ ℙ ⁡ [ B ] \Pb[A\cap B]\geq\Pb[A]\Pb[B] , and we write  A ↑ B A\uparrow B  to denote positive association. Analogously, we say that two real-valued random variables  X X  and  Y Y  are  positively associated  if 
 

 
 
 { X ≥ s } ↑ { Y ≥ t } \{X\geq s\}\uparrow\{Y\geq t\} 
 
 
 for all  s , t ∈ ℝ s,t\in\mathbb{R} , or equivalently if 
 

 
 
 𝔼 ⁡ [ f ⁡ ( X ) ​ g ​ ( Y ) ] ≥ 𝔼 ⁡ [ f ⁡ ( X ) ] ​ 𝔼 ​ [ g ⁡ ( Y ) ] \Eb[f(X)g(Y)]\geq\Eb[f(X)]\Eb[g(Y)] 
 
 
 for all increasing functions  f , g : ℝ → ℝ f,g:\mathbb{R}\to\mathbb{R} ; again, we write  X ↑ Y X\uparrow Y  to denote positive association (though we note that this differs slightly from the usage of this terminology in  [ 21 ] ). Finally, for a collection of events  𝒞 \cC , we say that  X X  and  Y Y  are  positively associated given  𝒞 \cC  if  X ↑ Y X\uparrow Y  conditional on any event in  𝒞 \cC , i.e., if 
 

 
 
 ℙ [ X ≥ s , Y ≥ t | C ] ≥ ℙ [ X ≥ s | C ] ℙ [ Y ≥ t | C ] \Pb\left[X\geq s,Y\geq t\,|\,C\right]\geq\Pb\left[X\geq s\,|\,C\right]\Pb\left[Y\geq t\,|\,C\right] 
 
 
 for all  s , t ∈ ℝ s,t\in\mathbb{R}  and  C ∈ 𝒞 C\in\cC . 
 
 
 A sequence of random variables  Z 1 , … , Z m Z_{1},\dots,Z_{m}  is  jointly normal  if there exist independent normal random variables  Y 1 , … , Y n Y_{1},\dots,Y_{n}  such that each  Z i Z_{i}  is a linear combination of the  Y j Y_{j} ’s. An important property that we will use throughout this paper is that for any pair of random variables  X , Y X,Y  that is jointly normal,  X X  is independent of  Y Y  if and only if  Cov ⁡ ( X , Y ) = 𝔼 ⁡ [ XY ] − 𝔼 ⁡ [ X ] ​ 𝔼 ​ [ Y ] = 0 \Cov(X,Y)=\Eb[XY]-\Eb[X]\Eb[Y]=0 ; see e.g.  [ 5 ] , for a proof. 
 
 
 We shall study jointly normal random variables  Z 1 , … , Z m Z_{1},\dots,Z_{m}  with the following properties: 
 
 (1)  
 
 𝔼 ⁡ [ Z i ] = 0 \Eb[Z_{i}]=0  for all  i ∈ [ m ] i\in[m] ,  𝔼 ⁡ [ Z i ​ Z j ] ≤ 0 \Eb[Z_{i}Z_{j}]\leq 0  for all distinct  i , j ∈ [ m ] i,j\in[m] , and 
 
 (2)  
 
 𝔼 ⁡ [ Z i ​ ( Z 1 + ⋯ + Z m ) ] ≥ 0 \Eb[Z_{i}(Z_{1}+\dots+Z_{m})]\geq 0  for all  i ∈ [ m ] i\in[m] . 
 
 
 Note that  1  says that the covariance matrix of  Z 1 , … , Z m Z_{1},\dots,Z_{m}  is a  Stieltjes matrix  (see  [ 22 ] , for more details on this subject), while  2  tells us that each  Z i Z_{i}  has nonnegative covariance with the sample mean  Z ¯ \overline{Z} . We call such a collection of random variables a  repulsive–cooperative Gaussian ensemble . 
 
 
 With the convention that  − ∞ ≤ a ≤ b ≤ ∞ -\infty\leq a\leq b\leq\infty  whenever we refer to a closed interval  [ a , b ] [a,b] , we have the following theorem about conditional associations of repulsive–cooperative Gaussian ensembles. 
 
 
 Theorem 1.4 . 
 
 Let  Z 1 , … , Z m Z_{1},\dots,Z_{m}  be a repulsive–cooperative Gaussian ensemble, and let  𝒞 \cC  be the collection of events of the form 
 

 
 (1.4) 
 
 ⋂ i ∈ [ m ] { Z i ∈ [ a i , b i ] } . \bigcap_{i\in[m]}\left\{Z_{i}\in[a_{i},b_{i}]\right\}. 
 
 
 Then, for all  i ∈ [ m ] i\in[m] ,  Z ¯ \overline{Z}  and  Z i Z_{i}  are positively associated given  𝒞 \cC . 
 
 
 
 We prove Theorem  1.4  in Section  3 .
Let us note that the positive association of  Z ¯ \overline{Z}  and  Z i Z_{i}  without conditioning is a consequence of  2 ; see  [ 28 ]  for a proof. However, conditioning on  𝒞 \cC  does not in general preserve positive associations (as we shall see in Section  6 ), so we need a more involved argument that exploits  1 .

 2.  Background 

 
 In this section, we provide some background and historical context for the various problems discussed in Section  1 . 
 
 
 Around Radon’s theorem 

 
 Recall that Radon’s theorem states that any set of  n n  points in  ℝ d \mathbb{R}^{d} , where  n ≥ d + 2 n\geq d+2 , can be partitioned into two sets whose convex hulls intersect. This theorem was first proved by Radon  [ 29 ]  in 1921, and it has since become a cornerstone of convex geometry. Radon’s theorem was used by Radon to give a proof of Helly’s theorem that asserts that if a finite family of convex sets in  ℝ d \mathbb{R}^{d}  (with at least  d + 1 d+1  members) has the property that every  d + 1 d+1  sets in the family have a point in common, then there is a point in common to all sets in the family. In 1966, Tverberg  [ 35 ]  published a far-reaching extension of Radon’s theorem conjectured a few years earlier by Birch. 
 
 
 Theorem 2.1 . 
 
 Any  ( r − 1 ) ​ ( d + 1 ) + 1 (r-1)(d+1)+1  points in  ℝ d \mathbb{R}^{d}  can be partitioned into  r r  sets whose convex hulls intersect. 
 
 
 
 Any partition that satisfies the conditions of Theorem  2.1  is referred to as a  Tverberg partition of order  r r . It would be interesting to investigate analogues of our results for Tverberg partitions in place of Radon partitions, a topic about which we will say more later in Section  7 . For more background on these results, see  [ 2 ,  15 ,  16 ,  31 ,  11 ,  6 ] . 
 
 
 
 Around Sylvester’s four-point question 

 
 In 1864, Sylvester asked for the probability that four random points in the plane are in convex position  [ 34 ] . He proposed that the answer is 1/4 if the points are “taken at random in an indefinite plane”, and also asked what happens when the points are taken at random from a set  K ⊂ ℝ 2 K\subset\mathbb{R}^{2} . When the points are taken at random from the Gaussian distribution, then this probability is equal to  p 2 ( 4 ) p_{2}^{(4)}  (as defined in ( 1.1 )), and understanding the distribution of the Radon partition of  n n  random points in  ℝ n − 2 \mathbb{R}^{n-2}  is a natural higher-dimensional extension of Sylvester’s problem. For more on Sylvester’s four-point problem, involving extensions both to more points and to higher dimensions, see  [ 34 ,  27 ,  1 ,  36 ] . 
 
 
 For four Gaussian points in the plane, Sylvester’s problem has a nice answer going back to Maehara  [ 24 ]  (see also  [ 7 ] ). 
 
 
 Theorem 2.2 . 
 
 The probability that four random Gaussian points in  ℝ 2 \mathbb{R}^{2}  are in convex position is 
 

 
 
 6 π ​ arcsin ⁡ ( 1 3 ) ≈ 0.649 . \frac{6}{\pi}\arcsin(\frac{1}{3})\approx 0.649. 
 
 
 
 
 
 The study of Radon partitions of a set of higher-dimensional Gaussian vectors is a natural extension of Sylvester’s question that was recently studied by Frick, Newman, and Pegden  [ 17 ]  and by White  [ 38 ] . For more historical context and relevant background, see White’s thesis  [ 38 ]  and the references therein. 
 
 
 
 Around unimodality and log-concavity 

 
 Unimodality is a very natural property that mathematicians perceive in a number of places, leading to a surge of conjectures about settings where this property may arise. In trying to demonstrate unimodality, it is quite natural to (attempt to) demonstrate log-concavity instead, since it is the more robust of the two properties. For instance, the convolution of two log-concave sequences remains log-concave, whereas unimodality is not preserved under such operations; see  [ 23 ] , for example. In this vein, our proof (Corollary  1.2 ) of White’s conjecture through Theorem  1.1  adheres to this general approach. 
 
 
 We point the reader to the surveys  [ 9 ,  10 ,  33 ]  for an overview of classical unimodality and
log-concavity results. It is worth mentioning that more recently, Huh and his collaborators have advanced an algebraic-geometric approach that has resolved a number of longstanding conjectures about log-concavity; see  [ 19 ]  for a survey,
and  [ 13 ]  for a more combinatorial perspective on this direction. However, our proof of Theorem  1.1  relies on a different approach, and is inspired by the work such as  [ 25 ,  4 ,  21 ]  that link log-concavity with negative association. 
 
 
 
 Around central limit theorems 

 
 One consequence of Theorem  1.1  is that the scaling limit of the distributions  𝐩 n = ( p 0 , … , p n ) \mathbf{p}_{n}=(p_{0},\dots,p_{n})  as  n → ∞ n\to\infty , if it exists, must be a log-concave distribution. It is therefore natural to inquire what this limiting distribution is; this is addressed by the following central limit theorem. 
 
 
 Theorem 2.3   (Central limit theorem) . 
 
 As  n → ∞ n\to\infty , we have 
 

 
 
 S n − n / 2 σ ​ n → dist 𝒩 ⁡ ( 0 , 1 ) , \frac{S_{n}-n/2}{\sigma\sqrt{n}}\xrightarrow[\mathrm{dist}]{}\mathcal{N}(0,1), 
 
 
 where  S n S_{n}  is sampled from  𝐩 n \mathbf{p}_{n} , and  σ 2 = 1 / 4 − 1 / ( 2 ​ π ) \sigma^{2}={1}/{4}-{1}/{(2\pi)} . 
 
 
 
 It is possible to prove Theorem  2.3  by reducing the problem to an analogous central limit theorem for Youden’s demon, a version of which was established by Dmitrienko and Govindarajulu  [ 14 , Thm3.1]  using the Bahadur representation of quantiles (see, e.g.,  [ 18 ] ).
To keep the exposition self-contained, we include a more direct proof of Theorem  2.3  in Appendix  A , using the second-moment method. 
 
 
 
 
 3.  Conditional associations 

 
 Our goal in this section is to prove Theorem  1.4 . We start with the following standard lemma; we include the proof for completeness. 
 
 
 Lemma 3.1 . 
 
 Let  W W  be a real-valued random variable, and let  [ a , b ] [a,b]  and  [ c , d ] [c,d]  be intervals of  ℝ \mathbb{R}  such that  a < c a<c  and  b < d b<d .
Let  U U  and  V V  be random variables such that 
 

 
 (3.1) 
 
 U  is equal in distribution to  W  conditioned on  W ∈ [ a , b ] , and V  is equal in distribution to  W  conditioned on  W ∈ [ c , d ] . \displaystyle\begin{split}&\text{$U$ is equal in distribution to $W$ conditioned on $W\in[a,b]$, and}\\
&\text{$V$ is equal in distribution to $W$ conditioned on $W\in[c,d]$.}\end{split} 
 
 
 Then there exists a coupling of  U U  and  V V  such that  U ≤ V U\leq V . That is, there exists a probability space  Ω \Omega , a probability measure  μ : Ω → [ 0 , 1 ] \mu:\Omega\to[0,1] , and measurable functions  U , V : Ω → ℝ U,V:\Omega\to\mathbb{R}  such that  U U  and  V V  satisfy ( 3.1 ) and  U ⁡ ( ω ) ≤ V ⁡ ( ω ) U(\omega)\leq V(\omega)  for all  ω ∈ Ω \omega\in\Omega .

 The lemma is straightforward if  b ≤ c b\leq c , so we assume that  b > c b>c . It suffices to show, for all  s ∈ ℝ s\in\mathbb{R} , that 
 

 
 
 ℙ ⁡ [ W ≥ s ∣ W ∈ [ a , b ] ] ≤ ℙ ⁡ [ W ≥ s ∣ W ∈ [ c , d ] ] . \Pb\left[W\geq s\mid W\in[a,b]\right]\leq\Pb\left[W\geq s\mid W\in[c,d]\right]. 
 
 
 
 
 Let  W ′ W^{\prime}  be the random variable  W W  conditioned on  W ∈ [ a , b ] W\in[a,b] . Notice that the events  { W ′ ≥ s } \{W^{\prime}\geq s\}  and  { W ′ ≥ c } \{W^{\prime}\geq c\}  are positively associated. Indeed, we clearly have 
 

 
 (3.2) 
 
 ℙ [ W ′ ≥ s , W ′ ≥ c ] = ℙ [ W ′ ≥ max { s , c } ] ≥ ℙ [ W ′ ≥ s ] ℙ [ W ′ ≥ c ] . \displaystyle\Pb\left[W^{\prime}\geq s,W^{\prime}\geq c\right]=\Pb\left[W^{\prime}\geq\max\{s,c\}\right]\geq\Pb\left[W^{\prime}\geq s\right]\Pb\left[W^{\prime}\geq c\right].

 7.  Further directions 

 
 Here, we discuss a number of directions for further research related to the results of this paper. 
 
 
 Random points in a prescribed set 

 
 The Gaussian model adopted in this paper is convenient for the analytic and empirical study of high-dimensional extensions for the Sylvester four-point question. However, it would be quite interesting to investigate the arguably more common setting for Sylvester’s question. 
 
 
 Problem 7.1 . 
 
 Extend Theorem  1.1  (or its weaker corollaries) to the model of points drawn uniformly at random from a fixed  d d -dimensional convex set  K K . 
 
 
 
 It would also be interesting to prove a central limit theorem (like Theorem  2.3 ) for this model.

 For fixed integers  d , n ∈ ℕ d,n\in\mathbb{N} , consider the probabilities  p k ′ ​ ( n , d ) p^{\prime}_{k}(n,d)  that, for a sequence of  n n  random Gaussian points  𝐗 1 , … , 𝐗 n \Xb_{1},\dots,\Xb_{n}  in  ℝ d \mathbb{R}^{d} , we have

 Note that, when  n = d + 2 n=d+2 , we have 
 

 
 
 p k = p k ′ ​ ( n , d ) 2 ​ ( n k ) , p_{k}=\frac{p^{\prime}_{k}(n,d)}{2\binom{n}{k}},

 Recall that Tverberg’s theorem asserts that any  ( d + 1 ) ​ ( r − 1 ) + 1 (d+1)(r-1)+1  points in  ℝ d \mathbb{R}^{d}  can be partitioned into  r r  sets whose convex hulls intersect; such a partition is called a  Tverberg partition  of order  r r .
A long-standing conjecture due to Sierksma  [ 32 ]  on the minimal number of Tverberg partitions asserts the following. 
 
 
 Conjecture 7.3 .

 We note that there are quite a few different configurations for which this minimum is attained; see  [ 37 ,  8 ] , for example. 
 
 
 We can also ask about configurations with the maximum number of Tverberg partitions, though now, we need to assume that the points are  generic . We raise the following two closely related problems. 
 
 
 Problem 7.4 .

Nevertheless, our belief is guided by the following intuition. Let  𝐗 1 , … , 𝐗 m ∈ ℝ d + 1 \Xb_{1},\dots,\Xb_{m}\in\mathbb{R}^{d+1}  be a set of  m = ( d + 1 ) ​ ( r − 1 ) + 1 m=(d+1)(r-1)+1  points with the maximum number  P ⁡ ( d + 1 , r ) P(d+1,r)  of conic Tverberg partitions, and suppose that the origin is  not contained  in the convex hull of  𝐗 1 , … , 𝐗 m {\Xb_{1},\dots,\Xb_{m}} . Then there exists a hyperplane such that all these points lie on the right of this hyperplane. Projecting  𝐗 1 , … , 𝐗 m {\Xb_{1},\dots,\Xb_{m}}  onto this hyperplane gives us a  d d -dimensional set  𝐗 1 ′ , ⋯ , 𝐗 m ′ {\Xb_{1}^{\prime},\cdots,\Xb_{m}^{\prime}} ,
and note that any conic Tverberg  r r -partition of  𝐗 1 , … , 𝐗 m \Xb_{1},\ldots,\Xb_{m}  corresponds to a Tverberg  r r -partition of  𝐗 1 ′ , … , 𝐗 m ′ \Xb_{1}^{\prime},\ldots,\Xb_{m}^{\prime} .
This implies that  P ⁡ ( d + 1 , r ) ≤ M ⁡ ( d , r ) P(d+1,r)\leq M(d,r)  provided there exists a set with the right number of conic Tverberg partitions that does not contain the origin in its convex hull. 
 
 
 If it is in fact the case that  P ⁡ ( d + 1 , r ) ≲ M ⁡ ( d , r ) P(d+1,r)\lesssim M(d,r) , then this would imply that  M ⁡ ( d , r ) ≳ ( r / 2 ) m / r ! M(d,r)\gtrsim{(r/2)^{m}}/{r!} , where  m = ( d + 1 ) ​ ( r − 1 ) + 1 m=(d+1)(r-1)+1 , which should be contrasted with the bound of  m ⁡ ( d , r ) ≲ ( r / e ) m m(d,r)\lesssim(r/e)^{m}  implied by Sierksma’s Conjecture (and Stirling’s formula).

 In the context of counting Tverberg partitions, some numerical results are worth mentioning. We used simulation with Gaussian random points to study the possible Tverberg partitions of order three for seven points in generic position in the plane. The (potentially exhaustive) list of eleven configurations that we found is summarised in Figure  7.1 . In these simulations, the minimum number of Tverberg partitions that we encountered was four (in agreement with Sierksma’s conjecture), and the maximum was seven (as seen by the vertices of a regular 7-gon). 
 
 
 
 Reay’s Conjecture 

 
 Micha Perles  [ 26 ]  proposed using the probabilistic method to show that,
for fixed  r ∈ ℕ r\in\mathbb{N}  and  d d  large enough, every set of  2 ​ d + 2 2d+2  points in  ℝ d \mathbb{R}^{d}  can be partitioned into  r r  sets — such a partition is called a  Reay partition  — whose convex hulls  pairwise  intersect. If true, this would refute a conjecture of Reay  [ 30 ] . Some modest evidence for such a claim comes from simulations in  [ 38 ]  which suggest that for six random Gaussian points in the plane, the probability that a Reay partition exists is  ≈ 0.427 \approx 0.427 .
