                                                                                           Abstract
                                                       The column number question asks for the maximal number of columns of an
                                                    integer matrix with the property that all its rank size minors are bounded by a
                                                    fixed parameter ∆ in absolute value. Polynomial upper bounds have been proved
                                                    in various settings in recent years, with consequences for algorithmic questions in
                                                    integer linear programming and matroid theory. In this paper, we focus on the exact
                                                    determination of the maximal column number of such matrices with two rows and
                                                    no vanishing 2-minors. We prove that for large enough ∆, this number is a quasi-
                                                    linear function, non-decreasing and always even. Such basic structural properties of
                                                    column number functions are barely known, but expected to hold in other settings
                                                    as well. Moreover, our results identify the unique excluded (co)rank two minors for
                                                    the class of matroids that are representable as a ∆-submodular matrix.


                                           1 Introduction
                                           A fundamental insight in integer linear programming is that the underlying polyhedron
                                           of a linear program of the form

                                                                               max {c⊺ x : Bx ≤ d, x ∈ Rr } ,

                                           for B ∈ Zn×r , c ∈ Zr and d ∈ Zn has only integral vertices, if B is a totally unimodular
                                           matrix, that is, every minor of any size of B equals either −1, 0, or 1. This means,
                                           that for such a program optimizing over integral solutions x ∈ Zr only can be done
                                           simply by linear programming techniques, and thus in polynomial time (see, e.g. [25]).
                                           In general however, the decision problem behind integer linear programming is NP-
                                           hard. In an attempt to parametrize integer linear programming with the goal to achieve
                                           efficient algorithms, the following notions have received considerable interest in the recent
                                           literature (see, e.g. [3, 4, 5, 10, 15, 22]):

     For an integer matrix A ∈ Zr×n with full row rank rk(A) = r, we denote by
                      ∆(A) = max{|det B| : B is an r × r submatrix of A} .
We call A a ∆-submodular matrix if ∆(A) ≤ ∆ and call it ∆-modular if ∆(A) = ∆.1
The prevailing conjecture in the optimization community is that, for fixed ∆ ∈ Z>0 ,
integer linear programs with ∆-modular constraint matrices can be solved in polynomial
time (see [26]). Motivated by this approach, there is ongoing interest in studying the
combinatorics of ∆-modular integer programs, and in particular, in studying the maximal
size of ∆-modular matrices. We refer to [3, 16] for thorough introductions to this topic.
   In this paper, we contribute to this so-called column number problem and determine
the maximal size of generic ∆-modular matrices with two rows, if ∆ is sufficiently large.
In order to make this precise and give an account of the state of the art, we say that
an integer matrix A ∈ Zr×n is generic, if any r columns of A are linearly independent;
we say that A is simple, if A has only non-zero and pairwise non-parallel columns. We
always assume all matrices A ∈ Zr×n to have pairwise distinct columns, allowing us to
consider A ⊆ Zr as a subset of integer vectors of cardinality n.
   The notion of genericity is motivated by the paper of Jiang & Basu [15], who showed
that for generic ∆-modular integer programs the vertices of the integer hull of the un-
derlying polyhedron can be enumerated in polynomial time. The notion of simplicity
is closely related to matroid theory and the growth rate question for minor-closed ma-
troid classes (see, e.g. [11]). In fact, our results have implications to excluded minor
characterizations for (co)rank-2 ∆-submodular matroids, as we discuss further below.
   Now, the relevant counting functions can be formulated as
     g(∆, r) = max{n : there is a generic ∆-modular matrix A ∈ Zr×n with rk(A) = r}
      s(∆, r) = max{n : there is a simple ∆-modular matrix A ∈ Zr×n with rk(A) = r}
     h(∆, r) = max{n : there is a ∆-modular matrix A ∈ Zr×n with rk(A) = r} .
Clearly, we have g(∆, r) ≤ s(∆, r) ≤ h(∆, r) for all ∆, r ∈ Z>0 . Over recent years strong
polynomial upper bounds on these functions have been obtained in terms of either of
the parameters ∆ and r. The best bounds to date are

   All these results point to a phenomenon that seems common to all the three column
number functions g(∆, r), s(∆, r), h(∆, r): For ∆ or r fixed, and small values of the
other parameter, the function values show quite an erratic behavior and do not seem to
fit into a common uniform description. However, if ∆ or r is taken large enough with
respect to the other parameter, uniform bounds or exact uniform descriptions can be
given. To the best of our knowledge, there is no good explanation for this phenomenon
available to date, and more data seems to be needed in order to develop understanding.
   With this goal in mind, our starting point is our earlier paper [16] in which we present
an algorithm to compute g(∆, r), and where we compute the values g(∆, 2), for every

conjectured that this uniform description carries over asymptotically, that is, for every

Theorem 1.1 then follows from the inequalities

The first and last inequality (see [16]) hold unconditionally on ∆. The inequality in
the middle is the difficult step and is based on two key observations. First, we show in
Proposition 3.4 that for every ∆ there is a very well-structured ∆-submodular matrix
M (a, b) with the maximal number g′ (∆, 2) of columns. This uses arguments from the
geometry of numbers. Secondly, in Proposition 3.7, we prove an upper bound on the
number of columns of these matrices M (a, b) in terms of the optimal value of a suitable
linear program whose objective function is highly number theoretical. Estimating the
optimal value of said linear program and applying some estimates from analytical number
theory then finishes the proof. The threshold ∆0 = 108 in Theorem 1.1 is imposed by
the quality of both of these estimates. Although we did not optimize the threshold as
much as possible, it is clear that without significantly new ideas we will not be able to
sufficiently lower the value for ∆0 in order for the computer to compute g(∆, 2), for the
remaining ∆ ≤ ∆0 (see Section 6).
   As a final remark on the proof of Theorem 1.1, we point out that the condition
that we impose on the matrices M (a, b) (see Definition 3.1) is conceptually much closer
to simplicity than to genericity. In particular, it might be possible to generalize our
approach for g(∆, 2) = s(∆, 2) in order to determine s(∆, r) asymptotically for r ≥ 3.
   Theorem 1.1 has a number of structural consequences for the function g(∆, 2). We
say that a property of a function ∆ 7→ f (∆) holds eventually, if it holds for all ∆ ≥ ∆0 ,
for some threshold ∆0 ∈ Z>0 . First of all and somewhat curiously, Theorem 1.1 shows
that g(∆, 2) is eventually even. Note that this is not true for all ∆. For instance, g(∆, 2)
is an odd number for ∆ ∈ {19, 23, 33, 47, 53, 54, 384} (see [16, Table 2]).
   Second, the first representation in Theorem 1.1 in terms of the floor function shows
that g(∆, 2) is eventually a non-decreasing function. The data on g(∆, r), for r ∈
{3, 4, 5}, obtained in [16] suggests that this also holds for g(∆, r) for any fixed r ≥ 2.

   Finally, the second representation shows that g(∆, 2) is eventually a quasi-linear func-
tion, more precisely, ∆ 7→ g(∆, 2) is linear when restricted to values of ∆ in a fixed
residue class modulo 6. Quasi-polynomiality of counting functions motivated by geomet-
ric questions is a reoccurring phenomenon. We refer to the overview paper of Woods [29]
for more information on this matter. It would be desirable to develop a structural un-
derstanding for this property, and see whether other column number functions exhibit
eventual quasi-polynomiality for any of the two parameters ∆ or r as well. In [16,
Thm. 1.4] it is shown that for fixed r ≥ 3, the function ∆ 7→ g(∆, r) is upper bounded
by a sublinear function (see (1.1)), so it does not exhibit eventual (quasi-)polynomial
behavior for more than two rows. However, the following questions may be posed
Question 1.2.
  (i) Is any of the counting functions g(∆, r), s(∆, r), or h(∆, r) eventually non-decrea-
      sing, for any fixed r ?
 (ii) Is any of the functions s(∆, r) or h(∆, r) eventually a (quasi-)polynomial, for any
      fixed r ≥ 3 or any fixed ∆ ?
The discussion above shows that for g(∆, 2) = s(∆, 2), h(∆, 2), s(2, r), h(2, r), and
g(∆, r) for every fixed ∆ ≥ 2, both of these questions have an affirmative answer.
Monotonicity of s(∆, r) and h(∆, r) for fixed ∆ is clear, as in a (simple) ∆-modular
rank r matrix with the maximal number of columns, one may add an all-ones-row and
then the column (0, . . . , 0, 1)⊺ ∈ Zr+1 and obtain a (simple) ∆-modular matrix with
full row-rank r + 1 and one more column. Thus, both s(∆, r) and h(∆, r) are strictly
increasing as functions of r.
   As we hinted at before, Theorem 1.1 has implications on excluded minor characteri-
zations in matroid theory. To this end, let M∆ denote the class of matroids that have
a representation over R as a ∆-submodular matrix, and let Ur,n be the rank r uniform
matroid on n elements. An excluded minor characterization of the class M1 is known.
A list of excluded minors for M2 has been identified, but it is open whether this list
is complete (see [22, Sect. 4]). For ∆ ≥ 3 much less is known, and an excluded mi-
nor characterization of M∆ is one of the challenging open problems in matroid theory.
Oxley & Walsh [22, Prob. 4.5] thus propose to first focus on rank two excluded minors
for M∆ . As they discuss in [22, Sect. 4 & Thm. 4.2], the uniform matroid U2,g(∆,2)+1 is
the unique rank two excluded minor for M∆ , and M∆ is closed under duality. In view
of these connections, Theorem 1.1 and the computations done in [16] solve their problem
for small enough and large enough ∆ as follows:
Corollary 1.3. For every ∆ ∈ Z>0 with ∆ ≤ 1 550 or ∆ ≥ 108 , the sizes of the unique
rank two excluded minor U2,g(∆,2)+1 for M∆ and the unique corank two excluded minor
Ug(∆,2)−1,g(∆,2)+1 for M∆ are determined by Theorem 1.1 and [16, Sect. 4.4].

3 A reduction to a class of well-structured matrices
In this section we study a special family of matrices which we call matrices M (a, b) of
type m. These matrices have been introduced in [16] to give lower bound constructions
for certain values of g(∆, 2), see Example 3.2. We show that every generic ∆-modular
matrix can, in some sense, be reduced to such a matrix M (a, b). We then proceed to
bound the number of columns of M (a, b) by associating the matrix to a certain linear
program, which we study further in Sections 4 and 5.

   The reason that we can focus our study on matrices M (a, b) is that roughly speaking

   For a non-zero vector v ∈ Rr \ {0} the width of a convex body K ⊆ Rr in direction v
is defined as
                              ω(K, v) = max x⊺ v − min x⊺ v .
                                         x∈K           x∈K
Minimizing the width over all non-zero lattice directions yields the lattice-width

                               ωL (K) =     min       ω(K, v) .

If K is a lattice polytope, meaning that K = conv(S), for a finite set S ⊆ Zr , then for

follows: ω(K, v) + 1 is the number of parallel lattice-planes orthogonal to v and which
have a non-empty intersection with K.

5 Closing the gap and proof of Theorem 1.1
Here we show that we also have zm ≤ 0.999 in the range 4 ≤ m ≤ 3257, which is the final
ingredient for the proof of Theorem 1.1. To this end, we employ a computer to solve the
relevant linear programs. We use GLPK from GNU [12] implemented in sagemath [27].
   While for small values of m the LP (3.1) or its dual (Dm ) can be easily solved, this is
no longer the case for bigger m. Note that in the primal problem we have m variables
and m2 constraints while in the dual problem we have m2 variables and m constraints,
which makes the linear program too large for a computer to quickly solve it. Hence for
larger values of m we will only give an upper bound for the optimal value zm .
   Just as in Section 4, our approach is based on the observation that the optimal so-
lutions Y of (Dm ), for small values of m, satisfy Yk,ℓ ̸= 0 only for index pairs (k, ℓ)
with k 2 + ℓ2 ≈ m2 . Hence, we hope that we can still get a good enough approximation
zm ≤ ẑm ≤ 0.999 by setting Yk,ℓ = 0 for other indices (k, ℓ), which is effectively achieved
by not including those variables in the linear program. More precisely, we only include
variables Yk,ℓ for the pairs (k, ℓ) in the following set:

6 Improvements and limitations of our approach
As mentioned in the introduction, the constant ∆0 = 108 in Theorem 1.1 is not optimal.
In this last section, we discuss possible improvements in our proof that would reduce
the value of ∆0 . At the same time, we point to the limitations of the approach, showing
that without significantly new ideas, it is not possible to reduce ∆0 far enough to be
able to compute g(∆, 2) for all ∆ ≤ ∆0 with a computer in a reasonable timeframe.
  The proof of Theorem 1.1 shows that ∆0 is essentially determined by the inequality

we do not expect significant improvements on c1 or said error term, we only discuss
possibilities to reduce w.
   We have shown zm ≤ 0.999, for m ≥ 4 in two steps. A theoretical argument covered
all m ≥ m0 = 3257, and we used a computer for the range 4 ≤ m ≤ m0 .
   For the first step, we presented a feasible solution Y to (Dm ) based on approximating
the quarter circle shown in Fig. 1 by p = 3 rectangles. This gave us two conditions
for the constant C, one of the form C ≥ g(β, γ, ε) to satisfy the constraints and one of
the form C ≤ h(β, γ, ε, w) to satisfy zm ∗ ≤ w, for some functions g, h. These conditions

could then be rearranged to a form w ≥ k(β, γ, ε) (although we have not done so). In
our case we got a function monotonically increasing in ε > 0, meaning a smaller ε gives
a smaller w. However, decreasing ε comes at the cost of increasing the value x0 (ε) in
Lemma 2.1. This implies an increase of m0 , because it needs to satisfy βm0 ≥ x0 (ε).
   We may improve the approximation of the quarter circle  p usingp p ≥ 4 rectangles and a
sequence 0 <β1 < β2 < . . . < βp−1 < 1 instead of 0 < 1/3 < 2/3 < 1, for example
βi = tan pi π2 . This would presumably allow for a better bound w. However, it again
comes at the cost of increasing m0 , due to the constraint β1 m0 ≥ x0 (ε).
   For the second step, we used a computer to solve the approximate linear programs (D̂m )
to show zm ≤ ẑm ≤ w, for all 4 ≤ m ≤ m0 , with the help of Lemma 5.1 for a speed
up. Of course, lowering w or increasing m0 leads to a higher computational effort. More
importantly, there will be values of m ≥ 4 for which the inequality zm ≤ w does not
hold. A concrete example is z5 = 119/120 = 0.9916 and any w < 119/120. Any such
value of m needs to be dealt with individually. This could come in the form of a proof
similar to the proofs of Claims 3.9 and 3.10 for m = 2, 3, however it is not obvious how
to generalize these proofs without ending up with too many cases to check. Another
approach is to compute the error term of Proposition 3.7 explicitly. As an example, for
m = 5 we have |M (a, b)| ≤ 119                           119
                              120 ∆ + 7. The inequality 120 ∆ + 7 ≤ ∆ + 2 then gives that
for ∆ ≥ 600 no matrix M (a, b) of type 5 could give a generic ∆-modular matrix with
more columns than a matrix of type 1, 2 or 3, meaning we only have to check ∆ ≤ 600.
While for m = 5 this is doable, for bigger m it quickly becomes unfeasible.
   Furthermore, the value of w can likely not be reduced further than w ≈ 0.955. Based
on our numerical data it seems that zm converges to a value near 0.955. Even if we could
prove that indeed zm ≤ 0.955, for m large enough, then using w = 0.955 in the relevant
inequality of the proof of Theorem 1.1 gives ∆0 ≈ 65000. While this is certainly a huge
improvement over ∆0 = 108 , it is still not feasible to compute g(∆, 2) for all ∆ ≤ ∆0
and thus determine g(∆, 2) completely.
