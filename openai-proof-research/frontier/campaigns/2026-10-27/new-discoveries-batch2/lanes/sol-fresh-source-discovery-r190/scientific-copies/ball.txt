                                                                                      1. Introduction

                                              The uniform inner ball condition is a classical geometric characterization of C 1,1 regu-
                                           larity for convex bodies. In particular, a convex body K has C 1,1 boundary if and only if
                                           for some r > 0, the set K is the union of closed balls of radius r contained in K as stated
                                           in [9, Proposition 2.4.3]; see also [1, 2]. This condition is closely related to the theory of
                                           positive reach, applied to the boundary of convex bodies, initiated by Federer [6] and the
                                           regularity of the distance function [13]. Related formulations involving Lipschitz normals
                                           and two-sided rolling ball conditions for general domains appear in [15, 16, 23].
                                              If one wishes to identify a similar characterization for convex bodies whose boundary
                                           has C 1,α regularity, with 0 < α < 1, then the ability to find a uniform inner ball condition
                                           is not possible in general. For example, the epigraph of the function xn = |x′ |1+α has no
                                           tangent interior ball at the origin. Yet, it is possible to characterize C 1,α convex bodies
                                           by use of an approximate inner ball condition, where for each point on the boundary of K
                                           we can identify closed balls contained in K at a distance of at most ε > 0 whose radius is
                                           some fixed constant times ε(1−α)/(1+α) .
                                             For a closed convex set K ⊂ Rn and r > 0 we define
                                           (1.1)             Kr := {z ∈ K : B(z, r) ⊂ K} and K(r) := Kr + B(0, r).
                                           The set Kr is the inner parallel body of K and K(r) is the union of closed balls of radius
                                           r contained in K. We say that K satisfies AIB(r, ε) if Kr ̸= ∅ and
                                           (1.2)                                    sup dist(x, K(r)) ≤ ε.

The function fx combined with the sets C(0, en , R, M ) ∩ ∂U and C(0, en , R, M ) ∩ U are
called the charts of ∂U . Simply put, the boundary of a domain is a hypersurface when its
boundary can be represented locally as the graph of a function. If fx is convex for each
x ∈ ∂U , then we say ∂U is a convex hypersurface. If fx ∈ C 1 for each x ∈ ∂U , then ∂U
is a C 1 hypersurface. If fx ∈ C 1,α for 0 < α ≤ 1 and for all x ∈ ∂U , then ∂U is a C 1,α
hypersurface. For convex bodies (or closed convex domains) we say the boundary is of
class C 1,α if the boundary is a C 1,α hypersurface.

                  7. Regularity of the Sum of Convex Domains

  The approximate inner ball condition is inherited by the Minkowski sum, and hence the
proof of Theorem 1.4 follows almost immediately from Theorem 1.1.

Proof of Theorem 1.4. Let β := (1 − α)/(1 + α). As A is a convex body and B is convex
and closed, A+B is a closed convex domain. By Theorem 1.1, there are constants C, ε0 > 0
such that every point a ∈ A lies within an ε distance of a closed ball B(h, Cεβ ) ⊂ A for
all 0 < ε ≤ ε0 . Take any z = a + b ∈ A + B. Translating B(h, Cεβ ) by the point b yields
B(h + b, Cεβ ) ⊂ A + B, and
                       dist(z, B(h + b, Cεβ )) = dist(a, B(h, Cεβ )) ≤ ε.
Therefore A + B satisfies AIB(Cεβ , ε) for every 0 < ε ≤ ε0 and applying Theorem 1.1
concludes the proof.                                                              □
