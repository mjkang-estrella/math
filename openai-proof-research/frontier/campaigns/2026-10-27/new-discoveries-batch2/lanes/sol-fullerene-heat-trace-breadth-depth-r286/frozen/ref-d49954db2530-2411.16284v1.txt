                                                    Abstract. A semigroup conjugacy is an equivalence relation that equals group
                                                    conjugacy when the semigroup is a group. In this note, we answer five open
                                                    problems related to semigroup conjugacy. (Problem One) We say a conju-
                                                    gacy ∼ is partition-covering if for every set X and every partition of the set,
                                                    there exists a semigroup with universe X such that the partition gives the ∼-
                                                    conjugacy classes of the semigroup. We prove that six well-studied conjugacy
                                                    relations – ∼o , ∼c , ∼n , ∼p , ∼p∗ , and ∼tr – are all partition-covering. (Prob-
                                                    lem Two) For two semigroup elements a, b ∈ S, we say a ∼p b if there exists
                                                    u, v ∈ S such that a = uv and b = vu. We give an example of a semigroup
                                                    that is embeddable in a group for which ∼p is not transitive. (Problem Three)
                                                    We construct an infinite chain of first-order definable semigroup conjugacies.
                                                    (Problem Four) We construct a semigroup for which ∼o is a congruence and
                                                    S/ ∼o is not cancellative. (Problem Five) We construct a semigroup for which
                                                    ∼p is not transitive while, for each of the semigroup’s variants, ∼p is transitive.

that a = uv and b = vu. This relation is not always transitive, but it is equal to
group conjugacy when the semigroup is a group, We know that ∼p is transitive

for a semigroup if it is transitive for all of the semigroup’s variants. We give a
counterexample and thus give a negative answer to the problem.
    Problem 6.16 from [3] is concerned with the following relation. For a semigroup
S and any two elements a, b ∈ S, a ∼o b iff there exists u, b ∈ S such that au = ub
and va = bv. The problem asks if there is a semigroup for which ∼o is a congruence
and S/ ∼o is not cancellative. We define such an example that has infinite size and
we leave as an open question whether a finite example exists.
    Conjugacies can be partially ordered by inclusion, which gives rise to a lattice
of conjugacies. Problem 6.21 from [3] asks whether there exists an infinite set of
first-order definable conjugacies that forms: (1) a chain ordered by inclusion or
(2) an anti-chain ordered by inclusion. We give a partial answer by constructing
an infinite chain of first-order definable conjugacies. We also extend the definition
of ∼p to define an infinite chain of first-order definable relations, each of which is
equal to group conjugacy when the semigroup is a group. From this, we define a
new class of L-complete problems in which we are given two elements and we are
asked whether they are ∼p related.

                                 2. Preliminaries
    Define the semigroup relation ∼g to be reflexive and, for any distinct semigroup
elements a, b ∈ S, a ∼g b iff there is a subgroup G ⊆ S containing a and b such
that, for some g ∈ G, gag −1 = b. A semigroup relation ∼ is a conjugacy relation
iff, for any semigroup S that is also a group, ∼ = ∼g . We now present several
approaches for generalizing group conjugacy to semigroups. Note that, for groups,
the condition for ∼g could equivalently be written as ag = gb. In [13], Otto defined
semigroup conjugacy in a similar fashion:
           ∀a, b ∈ S (a ∼o b ⇔ ag = gb and bh = ha for some g, h ∈ S).
   This is an equivalence relation, but it suffers the unfortunate drawback of being
the universal equivalence relation for any semigroup S that has a zero element, 0,
satisfying 0s = s0 = 0 for every s ∈ S. Araújo, Konieczny, and Malheiro avoided
this by restricting the set from which g and h can be chosen. For a semigroup S
with zero element 0 and any nonzero a ∈ S \ {0}, they defined P(a) := {g ∈ S :
(ma)g 6= 0 for any ma ∈ S 1 a \ {0}}. If S has no zero element, then P(a) := S.
Finally, P1 (a) := P(a) ∪ {1} with 1 being the identity element of S 1 . They then

              ∀a, b ∈ S (a ∼p b ⇔ a = uv and b = vu for some u, v ∈ S).

                        3. Partition-Covering Problem
   Problem 6.10 from [3] asks whether ∼o , ∼p , and ∼tr are partition-covering.
Brute force calculation using the GAP package Smallsemi [5] proves that ∼o and
∼p are partition-covering for any |X| ≤ 6 [3]. We will now prove that ∼o , ∼c ,
∼n , ∼p , ∼p∗ , and ∼tr are partition-covering for any set. We start by defining the
following relations. For any a, b ∈ S:
                            a ∼ℓ b ⇔ (ab = a and ba = b)
                          a ∼r b ⇔ (ab = b and ba = a).
In other words, a ∼ℓ b (a ∼r b) iff {a, b} is a left-(right-)zero subsemigroup of S.
Lemma 3.1. For any band S, ∼ℓ and ∼r are both equivalence relations and both
are contained in ∼n .
Proof. These relations are clearly symmetric. Let a, b, c ∈ S such that a ∼ℓ b and
b ∼ℓ c, then ac = abc = ab = a and ca = cba = cb = c, proving that ∼ℓ is transitive.
The argument for ∼r is similar. Also, aa = a implies a ∼ℓ a and a ∼r a, so these
relations are equivalence relations for bands. Finally, for bands, a ∼ℓ b (a ∼r b)
implies a ∼n b by picking g = a (g = b) and h = b (h = a) in Konieczny’s definition
for ∼n as stated above.                                                           
  A normal band is a semigroup S such that, for all elements a, b, c ∈ S: (1) aa = a
and (2) abca = acba.

Lemma 3.2. A conjugacy relation ∼ is partition-covering if ∼ℓ ⊆ ∼ ⊆ ∼tr or ∼r
⊆ ∼ ⊆ ∼tr for normal bands.
Proof. Suppose ∼ℓ ⊆ ∼ ⊆ ∼tr for all normal bands. Let X be any set and P (X) =
{Xi }i∈I be any partition of X. We will use Von Neumann’s definition of an ordinal
as a well-ordered set of all smaller ordinals. Using the axiom of choice, every set
Xi can be well-ordered and is then order isomorphic to some ordinal αi . So, we
can identify Xi with the set {(i, j) : j ∈ αi } and we will refer to the elements of
Xi by these pairs. Let (P (X), <) be a total order such that Xi < Xj whenever
αi ( αj . We will not be concerned about how sets of equal cardinality are ordered.
For every i, j ∈ I, let maxP (i, j) = j if Xi < Xj and maxP (i, j) = i otherwise. To
define a semigroup whose ∼-conjugacy classes are P (X), we define the following
multiplication on X: (a, b)(c, d) = (maxP (a, c), b).
   To verify that (X, ·) is a semigroup, we need to check that, for every (a, b), (c, d) ∈
X, (a, b)(c, d) ∈ X and that the defined multiplication is associative. If maxP (a, c) =
a, then (a, b)(c, d) = (a, b) ∈ Xa . Notably, each (Xi , ·) is a left-zero subsemigroup.
If maxP (a, c) = c, then αa ⊆ αc , ensuring that (c, b) ∈ Xc . The multiplication is
associative since (X, ·) is a semilattice of left-zero subsemigroups. For this same
reason, the semigroup is also a normal band.
   We now want to show that, for any (a, b), (c, d) ∈ X, the following are equivalent:
      (1) a = c;
      (2) (a, b) ∼ℓ (c, d); and
      (3) (a, b) ∼tr (c, d).
   (1) ⇒ (2): By definition, (a, b)(c, d) = (a, b) and (c, d)(a, b) = (c, d).
   (2) ⇒ (3): ∼ℓ ⊆∼n by Lemma 3.1 and ∼n ⊆∼tr by (2.1).
   (3) ⇒ (1): Because (a, b) ∼tr (c, d), there exists (g1 , g2 ), (h1 , h2 ) ∈ X such that
(g1 , g2 )(h1 , h2 ) = (a, b) and (h1 , h2 )(g1 , g2 ) = (c, d). Because (P (X), <) is a total
order, then maxP (g1 , h1 ) = maxP (h1 , g1 ) and thus a = c.

   Consequently, for the constructed semigroup, ∼ℓ = ∼ = ∼tr and the ∼-conjugacy
classes are given by P (X). By similar argument, if ∼r ⊆ ∼ ⊆ ∼tr , then we can show
∼ is partition-covering by defining (a, b)(c, d) = (maxP (a, c), d).              
Theorem 3.3. ∼o , ∼c , ∼n , ∼p , ∼p∗ , and ∼tr are partition-covering.
Proof. Since ∼ℓ ⊆ ∼n , then ∼n , ∼p , ∼p∗ , and ∼tr are all partition-covering by
Lemma 3.2. We need a different construction for ∼o and ∼c .
    As with the proof of Lemma 3.2, let X be any set, P (X) = {Xi }i∈I be any
partition of X, and {(i, j) : j ∈ αi } be the elements of Xi . For any cardinal,
there exists a commutative group whose number of elements equals that cardinal.
Let (I, ·) be one such commutative group with identity element 1I . To define a
semigroup whose o-conjugacy classes are {Xi }i∈I , we define the following binary
operation on X: (a, b)(c, d) = (a · c, 0). For any (a, b), (c, d) ∈ X, (a · c, 0) ∈ X, since

(c, d) iff a = c. Suppose there exists (e, f ) ∈ X such that (a, b)(e, f ) = (e, f )(c, d).
Then (a · e, 0) = (e · c, 0). Because (I, ·) is a commutative group, a = c. Conversely,
for any (a, b), (a, d) ∈ Xa , (a, 0) = (a, b)(1I , 0) = (1I , 0)(a, d) = (1I , 0)(a, b) =
(a, d)(1I , 0).

                   4. Non-Partition Covering Conjugacies
    A natural question to ask at this stage is whether there are any semigroup
conjugacies that are not partition-covering. Indeed there are. Consider the first
relation we defined, ∼g . The smallest semigroup that has distinct elements a and
b such that a ∼g b is the symmetric group S3 . But there is another well-studied
conjugacy that is not partition-covering.
    Let U (S) be the group of units for a semigroup S. Then for any a, b ∈ S,
we define a ∼u b iff there exists u ∈ U (S) such that u−1 au = b and ubu−1 = a
[9]. Kudryavtseva and Mazorchuk note that, for transformation semigroups, this
notion of conjugacy has a nice connection to graph isomorphisms. Let Tn be the
full transformation semigroup over the points {1, . . . , n}. For a ∈ Tn , define the
graph Γ(a) to have vertices {1, . . . , n} and edges {(i, j) : ia = j}. Then for any
a, b ∈ Tn , a ∼u b iff Γ(a) ∼
                            = Γ(b) [9, Prop 6].

the identity element. Since the identity element will always be in its own conjugacy
class, ∼u cannot be partition-covering for any set with more than one element.
