                                                                                                   1. Introduction
                                              Let N be the set of non negative integers. A numerical semigroup is a submonoid S of N having finite
                                           complement in it. This notion is widely studied in literature, also with connections in different fields of
                                           mathematics, as commutative algebra, algebraic geometry or coding theory. For a good overview we refer to
                                           [1] and [20]. In [15], a straightforward generalization of numerical semigroups is provided for submonoids
                                           in Nd , with d a positive integer. In particular, the authors introduce the concept of generalized numerical
                                           semigroup (GNS), that is a submonoid S of Nd such that the set H(S ) = Nd \ S is finite. The set H(S ) is
                                           called the set of gaps (or holes) of S and its cardinality g(S ) = | H(S )| is called the genus of S . Generalized
                                           numerical semigroups and some generalizations of them are studied in several recent papers (see for instance
                                           [2, 3, 4, 5, 8, 9, 12]). In [15] Failla et al. develop an algorithm, inspired by [6, 7], that leads to the construction
                                           of a tree, that we denote by Td, , having as set of vertices the set S d of all generalized numerical semigroups
                                           in Nd . In particular, if g is a positive integer and Sg,d is the set of GNSs in Nd having genus g, the construction
                                           allows to produce all semigroups in Sg+1,d from all semigroups in Sg,d . Moreover, the behavior of the values
                                           ng,d = |S g,d | is analyzed for low values of d and g. A first implementation of this procedure in a software is
                                           considered in [18]. New algorithms to deal with GNSs are introduced in [10]. To be precise, it is shown how
                                           to compute the set Sg,d , the set of gaps from a minimal generating set of a GNS and the set of minimal set
                                           of generators of a GNS, once its gaps are known. In particular, the set Sg,d is computed by using a different
                                           procedure of [15], and it is performed by the construction of a different tree, that we denote by Tg,d,    ′   , having

                                          2. Preliminaries and notations
   A generalized numerical semigroup (GNS) is a submonoid S of Nd with finite complement in Nd . The set
H(S ) is called the set of gaps (or holes) of S and its cardinality g(S ) = | H(S )| is called the genus of S . This
notion has been introduced in [15] as a generalization of the well known concept of numerical semigroup.
By known results, every submonoid S of Nd admits a unique minimal set of generators A(S ), that is, every
element in S is a linear combination of element in A(S ) with coefficient in N and no proper subset of A(S )
has this property. In particular, A(S ) = S ∗ \ (S ∗ + S ∗ ), where S ∗ = S \ {0}. It is known that if S is a GNS,
then A(S ) is finite and we denote e(S ) = | A(S )|, called embedding dimension of S .
Recall that the natural partial order ≤ in Nd is defined by a ≤ b if b − a ∈ Nd . As usual, when we define an
order relation  on a set A, which is a total order, and we consider x, y ∈ A, the notation x ≺ y means that
x  y and x , y. In the following definition we provide a class of total orders in Nd , introduced in [15], that
will be useful in this work.

   We briefly recall some useful notions on oriented graphs, that we will use in this work. An oriented
(or direct) graph is a structure G = (V, E) such that V is a nonempty set, called the set of vertices, and
E ⊆ V × V, called the set of edges. If x, y ∈ V, a path from x to y of length n is a sequence of distinct
vertices x0 , x2 , . . . , xn such that x0 = x, xn = y and (xi−1 , xi ) ∈ E for all i ∈ {1, . . . , n}. An oriented graph is
called a tree if there exists a vertex v, called root, such that for every vertex x there exists a unique path from
x to v. In this case, the length of the unique path from x to v is called the depth of x and if (x, y) is an edge,
we say that x is a child of y. A vertex in a tree is a leaf if it has no children. In the context of numerical
semigroups and GNSs, some procedures are related to some constructions of tree oriented graphs.

                                  3. Permutations and isomorphisms between GNSs
   If S , T are monoids, we recall that a map f : S → T is an homomorphism (of monoid) if for all a, b ∈ S
then f (a + b) = f (a) + f (b). Moreover f is an isomorphism if it is also a bijective map. Obviously if f is
an isomorphism then it is invertible and f −1 : T → S is also an isomorphism. As usual, if f : S → S is an
isomorphism of S in itself then f is also called an automorphism of S .

properties of these semigroups.

Proposition 4.2. Let S ⊆ Nd be an equivariant GNS. Then the following hold:
   (1) If x is a minimal generator of S then σ(x) is a minimal generators of S for all σ ∈ Pd .

Therefore σ(x) ∈ SG(S ).

   Finally, we conclude with some possible developments that arises from this work. In the context of
numerical semigroups and affine semigroups there are different graph-tree constructions to produce families
of semigroups with prescribed properties. For instance, we mention the following in the context of affine
semigroups:
      • In [3], the authors introduce the notion of corner element in the context of GNSs, as a generalization
        of the concept of conductor of a numerical semigroup. The authors also provide a procedure to
        generate all GNSs with a given corner element.
      • In [17, 19], the authors consider the notion of C-semigroup, that is a an affine semigroup having
        finite complement in a integer cone C. A GNS can be seen as a C-semigroup with C = Nd . In
        these articles it is shown, respectively, a procedure to compute all irreducible C-semigroups of given
        Frobenius element and how to arrange the set of the so called I(S)-semigroups in a rooted tree.
      • Another construction is given in [13], in order to produce all almost symmetric GNSs with a given
        Frobenius element.
   A question that arises, is if it is possible to refine these procedures in order to generated the prescribed
families of semigroups, in such a way that only one semigroup in each isomorphism equivalence class is
produced.
