 Abstract. 
    
 Let  f ⁡ ( n ) f(n)  be the maximum, over all graphs  G G  on  n n  vertices, of the ratio  χ ⁡ ( G ) ω ⁡ ( G ) \frac{\chi(G)}{\omega(G)} , where  χ ⁡ ( G ) \chi(G)  denotes the chromatic number of  G G  and  ω ⁡ ( G ) \omega(G)  the clique number of  G G . In 1967, Erdős showed that 
    
 

 
 
 ( 1 4 + o ⁡ ( 1 ) ) ​ n ( log 2 ⁡ n ) 2 ⩽ f ⁡ ( n ) ⩽ ( 4 + o ⁡ ( 1 ) ) ​ n ( log 2 ⁡ n ) 2 . \Big(\frac{1}{4}+o(1)\Big)\frac{n}{(\log_{2}n)^{2}}\leqslant f(n)\leqslant\big(4+o(1)\big)\frac{n}{(\log_{2}n)^{2}}. 
 
 
    
 We show that 
    
 

 
 
 f ⁡ ( n ) ⩽ ( c + o ⁡ ( 1 ) ) ​ n ( log 2 ⁡ n ) 2 f(n)\leqslant\big(c+o(1)\big)\frac{n}{(\log_{2}n)^{2}} 
 
 
    
 for some  c < 3.72 c<3.72 .
This follows from recent improvements in the asymptotics of Ramsey numbers and is the first improvement in the asymptotics of  f ⁡ ( n ) f(n)  established by Erdős. 
  
 
 
 1.  Introduction 

 
 Ramsey Theory is a fundamental area of Graph Theory concerned with the existence of unavoidable structures in large graphs. The  Ramsey number   R ⁡ ( s , t ) R(s,t)  is the minimum  n n  such that every red/blue edge-coloring of the complete graph on  n n  vertices contains either a clique on  s s  vertices colored red or a clique on  t t  vertices colored blue. 
 
 
 While Ramsey  [ 9 ]  proved in 1930 that Ramsey numbers are finite, the first explicit upper bound was obtained by Erdős and Szekeres  [ 3 ]  in 1935, who showed that 
 

 
 (1) 
 
 R ⁡ ( s , t ) ⩽ ( s + t − 2 s − 1 ) . R(s,t)\leqslant\binom{s+t-2}{s-1}. 
 
 
 Note that in the  diagonal  case, this shows that  R ⁡ ( k , k ) ⩽ 4 k + o ⁡ ( k ) R(k,k)\leqslant 4^{k+o(k)} .
On the other hand, Erdős  [ 4 ]  established the lower bound  R ⁡ ( k , k ) ⩾ 2 k / 2 + o ⁡ ( k ) R(k,k)\geqslant 2^{k/2+o(k)}  in 1947 in one of the first uses of the probabilistic method. Subsequent improvements on the lower bound have only refined it by a constant multiplicative factor (see, e.g., Spencer’s bound obtained via the Lovász Local Lemma  [ 10 ] ). Since then, one of the major problems in modern combinatorics has been to determine the correct asymptotic behavior of the diagonal Ramsey number  R ⁡ ( k , k ) R(k,k) . More specifically, one could ask whether the limit 
 

 
 (2) 
 
 lim k → ∞ log ⁡ ( R ⁡ ( k , k ) ) k \lim_{k\to\infty}\frac{\log(R(k,k))}{k} 
 
 
 exists and, if so, what is its value 1 1

          This question appears as Problem 1 in  [ 2 ] , as Problem 77 in  https://www.erdosproblems.com/77 , and on the webpage  https://mathweb.ucsd.edu/~erdosproblems/ . . 
 
 
 In 1967, Erdős  [ 5 ]  asked a seemingly unrelated question. Define  f ⁡ ( n ) f(n)  to be the maximum, over all graphs  G G  on  n n  vertices, of the ratio  χ ⁡ ( G ) ω ⁡ ( G ) \frac{\chi(G)}{\omega(G)} , where  χ ⁡ ( G ) \chi(G)  denotes the chromatic number of  G G  and  ω ⁡ ( G ) \omega(G)  the clique number of  G G . Formally, we have 
 

 
 
 f ⁡ ( n ) ≔ max ⁡ { χ ⁡ ( G ) ω ⁡ ( G ) : G ​  is a graph on  ​ n ​  vertices  } . f(n)\coloneq\max\Big\{\ \frac{\chi(G)}{\omega(G)}\ :\ G\text{ is a graph on }n\text{ vertices }\Big\}.

 (3) 
 
 lim n → ∞ f ⁡ ( n ) n / ( log ⁡ n ) 2 . \lim_{n\to\infty}\frac{f(n)}{n/(\log n)^{2}}. 
 
 
 In this note, we establish a connection between these two problems.
The upper bound on  f ⁡ ( n ) f(n)  from  [ 5 ]  combines ( 1 ) with the observation that, if  ( s + t t ) ⩾ n \binom{s+t}{t}\geqslant n , then

This motivates Conjecture  1.1  below as a natural bridge to extend Erdős’ proof.

 For every  s , t , k ∈ ℕ s,t,k\in{\mathbb{N}}  such that  s ​ t ⩽ k 2 st\leqslant k^{2}  we have that

 The function  f ⁡ ( n ) f(n)  satisfies

 1.1.  Conjecture  1.1  and the Diagonal Conjecture 

 
 We note that Conjecture  1.1  is closely related to the following conjecture, which is named the  Diagonal Conjecture  in  [ 8 ] . 
 
 
 Conjecture 1.4   (Diagonal Conjecture (DC)) . 
 
 For every  s 1 ⩽ s 2 ⩽ t 2 ⩽ t 1 s_{1}\leqslant s_{2}\leqslant t_{2}\leqslant t_{1}  such that  s 1 + t 1 ⩽ s 2 + t 2 s_{1}+t_{1}\leqslant s_{2}+t_{2}  we have that 
 

 
 
 R ⁡ ( s 1 , t 1 ) ⩽ R ⁡ ( s 2 , t 2 ) . R(s_{1},t_{1})\leqslant R(s_{2},t_{2}). 
 
 
 
 
 
 It is widely believed that the Diagonal Conjecture is very difficult to prove. Even in the case  R ⁡ ( t − 1 , t + 1 ) ⩽ R ⁡ ( t , t ) R(t-1,t+1)\leqslant R(t,t) , there is no relevant progress. Observe that Conjecture  1.1  can be stated as a weak version of the following conjecture. 
 
 
 Conjecture 1.5   (Multiplicative form of DC) . 
 
 For every  s 1 ⩽ s 2 ⩽ t 2 ⩽ t 1 s_{1}\leqslant s_{2}\leqslant t_{2}\leqslant t_{1}  such that  s 1 ​ t 1 ⩽ s 2 ​ t 2 s_{1}t_{1}\leqslant s_{2}t_{2}  we have that 
 

 
 
 R ⁡ ( s 1 , t 1 ) ⩽ R ⁡ ( s 2 , t 2 ) . R(s_{1},t_{1})\leqslant R(s_{2},t_{2}). 
 
 
 
 
 
 It is easy to see that if  s 1 ⩽ s 2 ⩽ t 2 ⩽ t 1 s_{1}\leqslant s_{2}\leqslant t_{2}\leqslant t_{1}  and  s 1 ​ t 1 ⩽ s 2 ​ t 2 s_{1}t_{1}\leqslant s_{2}t_{2} , then  s 1 + t 1 ⩽ s 2 + t 2 s_{1}+t_{1}\leqslant s_{2}+t_{2}  and therefore Conjecture  1.5  implies Conjecture  1.4 .
