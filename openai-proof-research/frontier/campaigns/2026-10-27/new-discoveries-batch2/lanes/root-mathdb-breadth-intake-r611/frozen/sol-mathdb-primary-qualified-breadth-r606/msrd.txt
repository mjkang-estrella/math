Abstract
    

This paper investigates the theory of sum-rank metric codes for which the individual matrix blocks may have different sizes. Various bounds on
the cardinality of a code are derived, along with their asymptotic extensions.
The duality theory of sum-rank metric codes is also explored,
showing that MSRD codes (the sum-rank analogue of MDS codes) dualize to MSRD codes only if all matrix blocks have the
same number of columns. In the latter case, duality considerations lead to an upper bound on the number of blocks for MSRD codes.
The paper also contains various constructions of sum-rank metric codes for variable block sizes, illustrating the possible behaviours of these objects with respect to bounds, existence, and duality properties.
  




1 Introduction




It is well known that codes with the rank metric offer a solution to the problem of error amplification in linear
network coding, both in the one-shot and multi-shot regime; see [22, 19, 6]. In the latter scenario however, using codes with the
sum-rank metric can significantly reduce the size of the network alphabet [15], which is particularly handy in fast-evolving systems.
The sum-rank metric itself occurred already earlier in space-time coding [2, 8, 21].
Besides applications in multi-shot linear network coding (see also [13]) and space-time coding,
sum-rank metric codes can also be utilized for distributed storage [14].
Furthermore, convolutional codes endowed with the sum-rank metric have been considered in, for instance, [9] in order to address network streaming problems.




The theory of sum-rank metric codes is still in its beginnings and
to date only a few constructions are known.
A general construction of MSRD codes (the analogue of MDS codes) up to a certain length, along with a Welch-Berlekamp sum-rank decoding algorithm, can be found in [11] (see also [14]).
These codes are linearized Reed-Solomon codes, i.e., a hybrid between Reed-Solomon codes and Gabidulin codes, and their
duals are again linearized Reed-Solomon codes [13].
Furthermore, in [14] sum-rank alternant codes are introduced, and sum-rank BCH codes have been introduced in [10].
Finally, a generic decoding algorithm for sum-rank metric codes is presented in [16].
In all the above mentioned results, the sum-rank metric codes considered can be viewed as linear spaces over an extension field, which in particular requires that all matrix blocks have the same number of columns.




Our Contribution.




In this paper, we study the fundamental properties of codes in the sum-rank metric
with respect to bounds, their asymptotics, duality, and existence/optimality.
We do not require that
all blocks have the same number of columns.
In particular, we only assume that the codes are linear over \mathbb{F}_{q}, and so do not necessarily have a representation as a block code over an extension field (cf. Definition 2.1).
As we will see, removing these restrictions makes the theory of sum-rank metric codes, and in particular of maximum sum-rank metric codes (MSRD codes), significantly richer from a mathematical viewpoint.




After setting up the preliminaries, in Section 3 we derive several bounds.
We start by showing that any bound for codes in the Hamming metric yields a bound for sum-rank
metric codes, which we call the corresponding induced bound.
We then establish additional bounds for the parameters of a sum-rank metric code and
show that these are in general not comparable with each other, i.e., each bound is the unique best bound
for a specific class of parameters.
We also provide examples of codes meeting these bounds.
While the induced bounds only take into account the maximum number of columns over all blocks,
the additional bounds depend on all block dimensions; this refinement is evident in the sharpness of the latter bounds compared to those induced from the known Hamming metric bounds.




In Section 4 we turn to the theory of asymptotic bounds for sum-rank metric codes by letting the number of blocks in the
ambient space grow (imposing natural constraints on the block sizes) and describing the behaviour of the rate of an optimal code.
This results in the asymptotic version of the bounds mentioned above.




Next, we concentrate on the duality theory of sum-rank metric codes and their MacWilliams identities.
We introduce the notions of
sum-rank, rank-list and support distributions of a sum-rank metric code.
While the first one does not obey a MacWilliams identity in general, we prove that the latter two do, and
give a closed formula for the corresponding MacWilliams transformations using a combinatorial approach.
This generalizes the MacWilliams identities for both the Hamming-metric and the rank-metric.




A substantive part of the paper is devoted to the study of MSRD codes, i.e., those sum-rank metric codes
that attain the sum-rank metric analogue of the Singleton Bound.
We show that when the blocks of the ambient space all have the same number of columns,
the dual of an MSRD code is again MSRD.
Interestingly, this duality result is not true in general: if the ambient space supports variable block sizes, then
the duality result does not necessarily hold.
Moreover, under the assumption that all blocks have the same number of columns, we explicitly compute
the support distribution of an MSRD code.
We also investigate for which parameters MSRD codes exist (which extends the problem for which parameter sets MDS codes exist).
Our contribution is this direction is twofold.
We first provide a non-existence criterion with the aid of the support distribution, which
allows us to rule out MSRD codes for certain parameters even if none of our bounds rules them out.
Secondly, we use a modification of the sphere-packing bound to establish an upper bound
on the number of blocks of an MSRD code.
As simple corollaries, we recover classical upper bounds on the length of an MDS code.




We conclude the paper with a section on constructions of optimal codes. We first provide several constructions of MSRD
codes for specific families of parameters.
Although our techniques do not extend to arbitrary parameter sets, to our best knowledge they produce the only known
constructions of MSRD codes for ambient spaces where the blocks have different numbers of columns.
Finally, we present a lifting construction that produces a sum-rank metric code combining a Hamming-metric and a rank-metric code. As an application, we obtain a class of sum-rank metric codes that attain the induced Plotkin bound with equality.






2 Sum-Rank Metric Codes




Throughout this paper, let \mathbb{N}=\{1,2,...\} and \mathbb{N}_{0}=\mathbb{N}\cup\{0\}.
For a\in\mathbb{N}, denote by [a] the set \{1,...,a\}.
Let q denote a prime power and t,n_{1},...,n_{t},m_{1},...,m_{t}\geq 1 be integers such that



(2.1)

n_{i}\leq m_{i}\ \text{ for all }\ i\in[t]\ \text{ and }\ m_{1}\geq\cdots\geq m_{t}.



We consider the product of t matrix spaces



(2.2)

\Pi:=\Pi_{q}(n_{1}\times m_{1}\mid\cdots\mid n_{t}\times m_{t}):=\bigoplus_{i=1}^{t}\mathbb{F}_{q}^{n_{i}\times m_{i}}



and define the sum-rank of an element X=(X_{1},...,X_{t})\in\Pi as







\textnormal{srk}(X):=\sum_{i=1}^{t}\textnormal{rk}(X_{i}).



It is easy to see that the sum-rank induces a metric on \Pi via (X,Y)\longmapsto\textnormal{srk}(X-Y).



Definition 2.1.



A (sum-rank metric) code is an \mathbb{F}_{q}-linear subspace of the metric space \Pi.
The minimum (sum-rank) distance of a non-zero code C\leq\Pi is defined as usual via
\textnormal{srk}(C):=\min\{\textnormal{srk}(X)\mid X\in C,\;X\neq 0\}.
We say that a code C\leq\Pi is trivial when C=\{0\} or C=\Pi.
For a codeword (X_{1},\ldots,X_{t}) we call the matrix X_{i} the i-th block.





Obviously, the definition reduces to rank-metric codes in the case where t=1 and to block codes of length t with the
Hamming metric in the case where m_{i}=n_{i}=1 for all i\in[t].



Remark 2.2.



A special class of sum-rank metric codes arises in the case where m_{i}=m for all i\in[t].
In this case \Pi\cong\mathbb{F}_{q^{m}}^{N}, where N=\sum_{i=1}^{t}n_{i}, and we may consider sum-rank-metric codes as vector codes in \mathbb{F}_{q^{m}}^{N}.
In this case the codes may be \mathbb{F}_{q}-linear or even \mathbb{F}_{q^{m}}-linear.
The latter class of codes has been studied in [11, 12, 13, 14].
In [15, Thm. 1] it has been shown that a code in \mathbb{F}_{q^{m}}^{N} with sum-rank distance d can correct \alpha errors
and \beta erasures whenever 2\alpha+\beta<d.
In [13, Thm. 1] the converse has been established: any code with \alpha-error-\beta-erasure correction capability must
have sum-rank distance at least 2\alpha+\beta.





Sum-rank metric codes may also be considered as rank-metric codes consisting of matrices supported on a particular profile.
More precisely, let



(2.3)

N=n_{1}+\cdots+n_{t}\quad\text{ and }\quad M=m_{1}+\cdots+m_{t}.



For any subset \mathcal{P}\subseteq[N]\times[M] define \mathbb{F}_{q}^{N\times M}[\mathcal{P}] as the space of
N\times M matrices over \mathbb{F}_{q} supported on \mathcal{P} (i.e., whose nonzero entries have indices in \mathcal{P}).
Setting now



(2.4)

\mathcal{P}:=\bigcup_{i=1}^{t}\Big(\Big\{\sum_{j=0}^{i-1}n_{j}+1,\ldots,\sum_{j=0}^{i}n_{j}\Big\}\times\Big\{\sum_{j=0}^{i-1}m_{j}+1,\ldots,\sum_{j=0}^{i}m_{j}\Big\}\Big),



where n_{0}=m_{0}=0, we obtain an \mathbb{F}_{q}-isomorphism



(2.5)

\psi:\Pi\longrightarrow\mathbb{F}_{q}^{N\times M}[\mathcal{P}],\quad(X_{1},\ldots,X_{t})\longmapsto\begin{pmatrix}X_{1}&&\\
&\ddots&\\
&&X_{t}\end{pmatrix},



satisfying \textnormal{rk}(\psi(X))=\textnormal{srk}(X) for all X\in\Pi(n_{1}\times m_{1}\mid\cdots\mid n_{t}\times m_{t}).
In other words, \psi is an isometry between the metric spaces (\Pi,\textnormal{srk}) and (\mathbb{F}_{q}^{N\times M}[\mathcal{P}],\textnormal{rk}).
Occasionally, it will be helpful to consider sum-rank metric codes as rank-metric codes in \mathbb{F}_{q}^{N\times M}[\mathcal{P}].
When we do so, we will make this explicit.




In order to define the support of elements in \Pi, we need the following.



Definition 2.3.



For i\in[t] let \mathcal{L}_{i} be the lattice of subspaces of \mathbb{F}_{q}^{n_{i}} partially ordered by inclusion.
Let \mathcal{L} be the product lattice, that is, \mathcal{L}:=\mathcal{L}_{1}\times\cdots\times\mathcal{L}_{t} endowed with the product order, which we denote
by \subseteq.
The rank function on \mathcal{L} is given by
\textnormal{rk}_{\mathcal{L}}(\bm{U})=\sum_{i=1}^{t}\dim(U_{i}) for all \bm{U}=(U_{1},...,U_{t})\in\mathcal{L}.
We also set \dim(\bm{U}):=(\dim(U_{1}),...,\dim(U_{t})) for \bm{U}\in\mathcal{L}.
Finally, the Möbius function of \mathcal{L} is given by




\mu_{\mathcal{L}}(\bm{U},\bm{V})=\prod_{i=1}^{t}(-1)^{\dim(V_{i})-\dim(U_{i})}q^{\binom{\dim(V_{i})-\dim(U_{i})}{2}}\quad\text{ for }\bm{U}\subseteq\bm{V}.







We refer the reader to [23] for more details.




The following definitions of support and shortening are straightforward extensions of the rank-metric case;
see [18, Ex. 39].



Definition 2.4.



For a matrix M\in\mathbb{F}^{a\times b} let \textnormal{colsp}(M)\leq\mathbb{F}^{a} denote its column space.
We define the support as




\sigma:\Pi\longrightarrow\mathcal{L},\quad(X_{1},\ldots,X_{t})\longmapsto(\textnormal{colsp}(X_{1}),...,\textnormal{colsp}(X_{t})).



Note that \textnormal{srk}(X)=\textnormal{rk}_{\mathcal{L}}(\sigma(X)) for all X\in\Pi, that is, the sum-rank weight is the composition of \sigma with the rank function of \mathcal{L}.




Definition 2.5.



For a code C\leq\Pi and \bm{U}\in\mathcal{L} we define the shortening of C on \bm{U} as




C(\bm{U}):=\{X\in C\mid\sigma(X)\subseteq\bm{U}\}\leq\Pi.






Remark 2.6.



Let \bm{U}=(U_{1},\ldots,U_{t}) and C=\Pi as in (2.2). Then
\Pi(\bm{U}) is a code in \Pi of dimension \sum_{i=1}^{t}m_{i}\dim(U_{i}). Moreover, every X\in\Pi(\bm{U}) satisfies
\textnormal{srk}(X)\leq\sum_{i=1}^{t}\dim(U_{i})=\textnormal{rk}_{\mathcal{L}}(\bm{U}).





The next result easily follows from the definitions.



Proposition 2.7.



Let \Pi be as in (2.2). For a non-zero code C\leq\Pi and 1\leq d\leq N=n_{1}+\cdots+n_{t} the following are equivalent:


(1)  



\textnormal{srk}(C)\geq d;


(2)  



|C(\bm{U})|=1 for all \bm{U}\in\mathcal{L} with \textnormal{rk}_{\mathcal{L}}(\bm{U})\leq d-1;


(3)  



|C(\bm{U})|=1 for all \bm{U}\in\mathcal{L} with \textnormal{rk}_{\mathcal{L}}(\bm{U})=d-1.







We close this preliminary section by introducing three partition enumerators of codes in \Pi,
which will be studied later on in the paper.



Definition 2.8.



Let C\leq\Pi be a code. For r\in\mathbb{N}_{0}, \bm{r}=(r_{1},...,r_{t})\in\mathbb{N}_{0}^{t} and \bm{U}\in\mathcal{L}
let




\displaystyle W_{r}(C)
\displaystyle:=\big|\{X\in C\mid\textnormal{srk}(X)=r\}\big|,



\displaystyle W_{\bm{r}}(C)
\displaystyle:=\big|\{X\in C\mid\textnormal{rk}(X_{i})=r_{i}\mbox{ for all $i\in[t]$}\}\big|,



\displaystyle W_{\bm{U}}(C)
\displaystyle:=\big|\{X\in C\mid\sigma(X)=\bm{U}\}\big|.



We call the lists \big(W_{r}(C)\big)_{r\in\mathbb{N}_{0}},\ \big(W_{\bm{r}}(C)\big)_{\bm{r}\in\mathbb{N}_{0}^{t}}, and
\big(W_{\bm{U}}(C)\big)_{\bm{U}\in\mathcal{L}} the sum-rank, rank-list and
support distributions of C, respectively.





Note that



(2.6)

|C(\bm{U})|=\sum_{\bm{V}\leq\bm{U}}W_{\bm{V}}(C).







3 Bounds for Sum-Rank Metric Codes




In this and the following section we will deviate from Definition 2.1 and consider general (that is, not necessarily \mathbb{F}_{q}-linear) codes.
We will establish various bounds for the cardinality of a sum-rank metric code as a function of its parameters.
To our knowledge, the only bound for sum-rank metric codes established so far is the Singleton Bound for
the case where m_{1}=\cdots=m_{t}; see [14, Cor. 2].
As before, we will not make this assumption on m_{1},\ldots,m_{t}.




For ease of exposition, we first present all bounds and relegate the proofs to Subsection 3.1.
We compare the bounds with each other in Subsection 3.2.




A simple method to obtain bounds for the dimension of a sum-rank metric code C\subseteq\Pi
is to use bounds for non-linear codes in the Hamming metric.
Denote by \mathcal{A}_{Q}(n,d) the largest cardinality of a (possibly non-linear) code over an alphabet of
size Q with length n and minimum Hamming distance at least d.
We set \mathcal{A}_{Q}(n,d):=1 if such a code does not exist.
The following result shows how any bound for a non-linear Hamming-metric code yields a bound for
sum-rank metric codes. We call these bounds “induced”.
For details see Section 3.1.




Throughout we assume \mathbb{F}=\mathbb{F}_{q} and \Pi=\Pi_{q}(n_{1}\times m_{1}\mid\cdots\mid n_{t}\times m_{t}) with the specifications as is (2.1)–(2.3).
In particular, N=n_{1}+\ldots+n_{t}.



Theorem 3.1.



Let m=\max\{m_{1},...,m_{t}\} and let C\subseteq\Pi be sum-rank metric code with |C|\geq 2 and \textnormal{srk}(C)=d.
Then
|C|\leq\mathcal{A}_{q^{m}}(N,d), which leads to the following bounds.






Induced Singleton Bound:


|C|\leq q^{m(N-d+1)},


Induced Hamming Bound:


{\displaystyle|C|\leq\bigg\lfloor\frac{q^{mN}}{\sum_{s=0}^{\lfloor(d-1)/2\rfloor}\binom{N}{s}(q^{m}-1)^{s}}}\bigg\rfloor,


Induced Plotkin Bound:


{\displaystyle|C|\leq\Big\lfloor\frac{q^{m}d}{q^{m}d-(q^{m}-1)N}\Big\rfloor,\>\>\text{ if }d>(q^{m}-1)N/q^{m}},


Induced Elias Bound:


{\displaystyle|C|\leq\Big\lfloor\frac{Nd(q^{m}-1)}{q^{m}w^{2}-2Nw(q^{m}-1)+(q^{m}-1)Nd}\cdot\frac{q^{mN}}{V_{w}(\mathbb{F}_{q^{m}}^{N})}}\Big\rfloor,





where in the Induced Elias bound, w is any integer in the interval [0,\,N(q^{m}-1)/q^{m}] such that the denominator is
positive and V_{w}(\mathbb{F}_{q^{m}}^{N}) is the volume of any sphere of radius w in \mathbb{F}_{q^{m}}^{N} with respect to the Hamming distance, that is V_{w}(\mathbb{F}_{q^{m}}^{N})=\sum_{i=0}^{w}\binom{N}{i}(q^{m}-1)^{i}.





The next bound is obtained from a projection argument and can be regarded as the sum-rank analogue of the Singleton Bound.
It generalizes [14, Cor. 2].



Theorem 3.2 (Singleton Bound).



Let C\subseteq\Pi be a code with |C|\geq 2 and \textnormal{srk}(C)=d.
Let j and \delta be the unique integers satisfying d-1=\sum_{i=1}^{j-1}n_{i}+\delta and 0\leq\delta\leq n_{j}-1.
Then




|C|\leq q^{\sum_{i=j}^{t}m_{i}n_{i}-m_{j}\delta}.



In the special case where m_{1}=\cdots=m_{t}=:m, the upper bound simplifies to
|C|\leq q^{m(N-d+1)}, which agrees with the Induced Singleton Bound in Theorem 3.1.




Definition 3.3.



A code C\subseteq\Pi is called MSRD (maximum sum-rank distance) if its cardinality attains the
Singleton Bound of Theorem 3.2, or if |C|=1.





Our next bounds require us to give the cardinality of a sum-rank sphere.



Definition 3.4.



For r\in\mathbb{N} we define




V_{r}(\Pi):=\sum_{s=0}^{r}\ \sum_{\begin{subarray}{c}(s_{1},...,s_{t})\in\mathbb{N}_{0}^{t}\\
s_{1}+\cdots+s_{t}=s\end{subarray}}\ \prod_{i=1}^{t}\left[\begin{matrix}n_{i}\\
s_{i}\end{matrix}\right]_{q}\prod_{j=0}^{s_{i}-1}(q^{m_{i}}-q^{j}).







It is not hard to see that V_{r}(\Pi) is the volume of any sphere in \Pi of sum-rank radius r.



Lemma 3.5.



For all r\in\mathbb{N} we have V_{r}(\Pi)=|\{(X_{1},...,X_{t})\in\Pi\mid\textnormal{srk}(X_{1},...,X_{t})\leq r\}|.





We next apply a sphere-packing argument in the metric space (\Pi,\textnormal{srk}).



Theorem 3.6 (Sphere-Packing Bound).



A code C\subseteq\Pi with |C|\geq 2 and \textnormal{srk}(C)=d satisfies




|C|\leq\bigg\lfloor\frac{|\Pi|}{V_{r}(\Pi)}\bigg\rfloor,\ \text{ where }r=\lfloor(d-1)/2\rfloor.







The sphere-packing bound can be combined with projection arguments to obtain other bounds for the cardinality of a sum-rank metric
code. We include one of these results.
In Section 6, we will make use of it to obtain non-existence criteria for MSRD codes.



Theorem 3.7 (Projective Sphere-Packing Bound).



Let C\subseteq\Pi be a code with |C|\geq 2 and minimum distance 3\leq d\leq N.
Let \ell\in[t-1] and \delta\in[n_{\ell+1}-1] be the unique integers such that
d-3=\sum_{j=1}^{\ell}n_{j}+\delta.
Define \Pi^{\prime}:=\Pi_{q}((n_{\ell+1}-\delta)\times m_{\ell+1}\mid n_{\ell+2}\times m_{\ell+2}\mid\cdots\mid n_{t}\times m_{t}).
Then




|C|\leq\bigg\lfloor\frac{|\Pi^{\prime}|}{V_{1}(\Pi^{\prime})}\bigg\rfloor.







Estimating for a given code C\subseteq\Pi the sum of the sum-rank distances between its codewords (the total distance), we arrive
at our final bound.
Even though its proof in the next section suggests that it is a very coarse bound,
it turns out to be often the best among all bounds; see Section 3.2.



Theorem 3.8 (Total-Distance Bound).



Let C\subseteq\Pi be a code with |C|\geq 2 and sum-rank distance d. Let Q=\sum_{i=1}^{t}q^{-m_{i}}.
Then




d\leq N+\frac{t-|C|Q}{|C|-1}.



In particular, if d>N-Q, then




|C|\leq\frac{d-N+t}{d-N+Q}.







As a corollary of Theorem 3.8,
we obtain an upper bound for the length t of a sufficiently large sum-rank metric code.
The proof follows from using |C|\sum_{i=1}^{t}q^{-m_{i}}\leq t|C|q^{-m} in the first inequality above.



Corollary 3.9.



Let m:=\max\{m_{1},...,m_{t}\} and let C\subseteq\Pi be a sum-rank metric code
with cardinality |C|>q^{m} and sum-rank distance d. Then




t\leq(N-d)q^{m}\frac{|C|-1}{|C|-q^{m}}.







In Section 6 we will improve the upper bound of Corollary 3.9
for the class of MSRD codes and some parameter sets; see Theorem 6.12.




All of the above bounds apply to general (not necessarily \mathbb{F}_{q}-linear) codes.
Since an \mathbb{F}_{q}-linear code with cardinality b clearly has dimension \log_{q}(b),
we propose the following expressions.



Definition 3.10.



If b is the value of any of the above bounds, we call \lfloor\log_{q}(b)\rfloor the
\mathbb{F}_{q}-linear version of the bound.
We say that a linear code C\leq\Pi attains the linear version of the bound if \dim(C)=\lfloor\log_{q}(b)\rfloor.





We conclude this part with the sum-rank analogue of the Gilbert bound, which follows by the application of the standard sphere-covering argument, i.e. that the union of the spheres of sum-rank radius d-1 centered at each codeword of a code of minimum sum-rank distance d is the entire ambient space \Pi.



Theorem 3.11 (Sphere-Covering Bound).



Let 1\leq d\leq N be an integer. Denote by k the smallest integer such that




q^{k}\geq\left\lceil\frac{|\Pi|}{V_{d-1}(\Pi)}\right\rceil,



where V_{d-1}(\Pi) is as in Theorem 3.6.
Then there exists a linear code C\leq\Pi of dimension k and sum-rank distance at least d.





3.1 Proofs of the Bounds




In this subsection we present the proofs of the various bounds.



Proof of Theorem 3.1.



Fix an ordered basis \{\gamma_{1},...,\gamma_{m}\} of \mathbb{F}_{q^{m}} over
\mathbb{F}_{q}.
For all i\in[t] define the map f^{i}:\mathbb{F}_{q}^{n_{i}\times m_{i}}\longrightarrow\mathbb{F}_{q^{m}}^{n_{i}}
as f^{i}(X)_{j}:=\sum_{\ell=1}^{m_{i}}X_{j,\ell}\,\gamma_{\ell},
for all X\in\mathbb{F}_{q}^{n_{i}\times m_{i}} and j\in[n_{i}].
This gives rise to a map



(3.1)

f:\Pi\longrightarrow\mathbb{F}_{q^{m}}^{N},\quad(X_{1},...,X_{t})\longmapsto(f^{1}(X_{1}),...,f^{t}(X_{t})).



Observe that for all i and all X,X^{\prime}\in\mathbb{F}_{q}^{n_{i}\times m_{i}} the Hamming weight
of f^{i}(X)-f^{i}(X^{\prime}) equals the number of nonzero rows of X-X^{\prime} and thus is
at least the rank of X-X^{\prime}. Therefore, for X,X^{\prime}\in\Pi, the Hamming distance between
f(X) and f(X^{\prime}) is at least the sum-rank distance between X and X^{\prime}. In particular, f is injective
(and bijective when m_{1}=\cdots=m_{t}).




All of this shows that the image f(C) of C is a code
in \mathbb{F}_{q^{m}}^{N} with the same cardinality as C and whose minimum Hamming distance is at least d.
Thus |C|\leq\mathcal{A}_{q^{m}}(N,d), as claimed.
The specific bounds are well known, see e.g. [5, Ch. 2].
∎





For the proof of Theorem 3.2 we need the following lemma.



Lemma 3.12.



Let 0\leq r<N and \mathcal{U}_{r}=\{(u_{1},\ldots,u_{t})\in\mathbb{N}_{0}^{t}\mid 0\leq u_{i}\leq n_{i},\,\sum_{i=1}^{t}u_{i}=r\}. Set K:=\max\{\sum_{i=1}^{t}m_{i}u_{i}\mid(u_{1},\ldots,u_{t})\in\mathcal{U}_{r}\}.
Let j\in[t] and \delta\in[n_{j}-1] be the unique integers such that r=\sum_{i=1}^{j-1}n_{i}+\delta.
Then




K=\sum_{i=1}^{j-1}m_{i}n_{i}+m_{j}\delta.






Proof.



First of all, u=(n_{1},\ldots,n_{j-1},\delta,0,\ldots,0) is in \mathcal{U}_{r} and thus K\geq\tilde{K}:=\sum_{i=1}^{j-1}m_{i}n_{i}+m_{j}\delta.
For the converse we proceed as follows. Let (u_{1},\ldots,u_{t})\in\mathcal{U}_{r} and set \alpha_{i}=n_{i}-u_{i} for i\in[t]. Then \alpha_{i}\geq 0 and \sum_{i=1}^{t}u_{i}=r=\sum_{i=1}^{j-1}n_{i}+\delta implies
\delta=\sum_{i=j}^{t}n_{i}-\sum_{i=1}^{t}\alpha_{i}. Using m_{1}\geq\ldots\geq m_{t} we obtain




\displaystyle\sum_{i=1}^{t}m_{i}u_{i}
\displaystyle=\sum_{i=1}^{j-1}m_{i}n_{i}-\sum_{i=1}^{j-1}m_{i}\alpha_{i}+\sum_{i=j}^{t}m_{i}u_{i}\leq\tilde{K}-m_{j}\delta-m_{j}\sum_{i=1}^{j-1}\alpha_{i}+m_{j}\sum_{i=j}^{t}u_{i}




\displaystyle=\tilde{K}-m_{j}\left(\sum_{i=j}^{t}n_{i}-\sum_{i=1}^{t}\alpha_{i}+\sum_{i=1}^{j-1}\alpha_{i}-\sum_{i=j}^{t}u_{i}\right)=\tilde{K}.



This shows K\leq\tilde{K}.
∎




Proof of Theorem 3.2.



Fix any (u_{1},...,u_{t})\in\mathbb{N}_{0}^{t} with 0\leq u_{i}\leq n_{i} and \sum_{i=1}^{t}u_{i}=d-1.
For each i\in\{1,...,t\} choose u_{i} coordinates of \{1,...,n_{i}\}
and delete the corresponding rows from the matrices in \mathbb{F}_{q}^{n_{i}\times m_{i}}.
This provides us with a projection




\tau:\Pi\longrightarrow\hat{\Pi}:=\Pi_{q}\big((n_{1}-u_{1})\times m_{1}\mid\cdots\mid(n_{t}-u_{t})\times m_{t}\big).



Consider now a code C\subseteq\Pi with sum-rank distance d.
Its image is \tau(C)\subseteq\hat{\Pi}.
For any distinct X,Y\in C we have \textnormal{srk}(X-Y)\geq d and therefore \textnormal{srk}(\tau(X),\tau(Y))\geq 1.
This shows that \tau is injective and hence
|C|=|\tau(C)|\leq|\hat{\Pi}|=q^{\sum_{i=1}^{t}(n_{i}-u_{i})m_{i}}.
The best bound arises by maximizing \sum_{i=1}^{t}u_{i}m_{i} subject to the above conditions on (u_{1},\ldots,u_{t}).
Hence Theorem 3.2 follows from Lemma 3.12.
∎




Proof of Lemma 3.5.



Fix any X\in\Pi and an integer r\geq 0.
The bijection on \Pi given by the shift Y\longmapsto X-Y implies that




\big|\{Y\in\Pi\mid\textnormal{srk}(X-Y)\leq r\}\big|=\big|\{Y\in\Pi\mid\textnormal{srk}(Y)\leq r\}\big|,



and thus it remains to compute the right hand side.
Using the well-known formula for the number of (n_{i}\times m_{i})-matrices of rank s_{i} we easily obtain




\displaystyle\big|\{Y\in\Pi\mid\textnormal{srk}(Y)\leq r\}\big|
\displaystyle=\sum_{s=0}^{r}\ \sum_{\begin{subarray}{c}(s_{1},...,s_{t})\in\mathbb{N}_{0}^{t}\\
s_{1}+\cdots+s_{t}=s\end{subarray}}\big|\{(Y_{1},...,Y_{t})\in\Pi\mid\textnormal{rk}(Y_{i})=s_{i}\mbox{ for all $i$}\}\big|




\displaystyle=\sum_{s=0}^{r}\ \sum_{\begin{subarray}{c}(s_{1},...,s_{t})\in\mathbb{N}_{0}^{t}\\
s_{1}+\cdots+s_{t}=s\end{subarray}}\ \prod_{i=1}^{t}\left[\begin{matrix}n_{i}\\
s_{i}\end{matrix}\right]_{q}\prod_{j=0}^{s_{i}-1}(q^{m_{i}}-q^{j}).\qed






Proof of Theorem 3.7.



Consider the code C given in Theorem 3.7 and recall the isomorphism \psi from (2.5).
Deleting from all matrices in \psi(C) the first d-3 rows provides us with a code \tilde{C}\subseteq\mathbb{F}_{q}^{(N-d+3)\times M}.
In terms of matrix tuples (X_{1},\ldots,X_{t})\in C, this means that we delete a total of d-3 rows of the individual matrices
starting from the left.
As a result X_{1},\ldots,X_{\ell} are entirely deleted and the topmost n_{\ell+1}-\delta rows of X_{\ell+1} are deleted, where \ell
and \delta are as in Theorem 3.7.
Thus C^{\prime}:=\psi^{-1}(\tilde{C}) is a sum-rank metric code in the space
\Pi^{\prime}:=\Pi_{q}((n_{\ell+1}-\delta)\times m_{\ell+1}\mid\cdots\mid n_{t}\times m_{t}).




Since the code C has sum-rank distance d, the map C\longrightarrow C^{\prime} is injective and thus
|C^{\prime}|=|C|.
Moreover, \textnormal{srk}(C^{\prime})\geq 3 because deleting one row in one block causes a drop of at most one in the sum-rank distance.
We can therefore apply the sphere-packing bound of Theorem 3.6 to C^{\prime} with distance 3 and arrive at the desired bound




|C|=|C^{\prime}|\leq\frac{|\Pi^{\prime}|}{V_{1}(\Pi^{\prime})}=\frac{q^{\sum_{i=\ell+1}^{t}n_{i}m_{i}-\delta m_{\ell+1}}}{1+\sum_{i=\ell+2}^{t}(q^{n_{i}}-1)\Big[\textstyle{\begin{matrix}m_{i}\\
1\end{matrix}}\Big]_{q}+(q^{n_{\ell+1}-\delta}-1)\Big[\textstyle{\begin{matrix}m_{\ell+1}\\
1\end{matrix}}\Big]_{q}}.\qed






Proof of Theorem 3.8.



Define the total distance of C, that is,




S:=\sum_{\begin{subarray}{c}X,Y\in C\\
X\neq Y\end{subarray}}\textnormal{srk}(X-Y)=\sum_{i=1}^{t}\,\sum_{\begin{subarray}{c}X,Y\in C\\
X\neq Y\end{subarray}}\textnormal{rk}(X_{i}-Y_{i}).



We have S\geq d|C|(|C|-1).
In order to derive an upper bound for S let




\displaystyle K_{i,1}
\displaystyle:=|\{(X,Y)\in C^{2}\mid\textnormal{rk}(X_{i}-Y_{i})=n_{i}\}|,



\displaystyle K_{i,2}
\displaystyle:=|\{(X,Y)\in C^{2}\mid X\neq Y,\,\textnormal{rk}(X_{i}-Y_{i})\leq n_{i}-1\}|.



Then K_{i,1}+K_{i,2}=|C|(|C|-1) for each i\in[t].
Furthermore,



(3.2)

S\leq\sum_{i=1}^{t}(n_{i}K_{i,1}+(n_{i}-1)K_{i,2})=\sum_{i=1}^{t}\big(n_{i}|C|(|C|-1)-K_{i,2}\big)=N|C|(|C|-1)-\sum_{i=1}^{t}K_{i,2}.



For our goal to derive a lower bound on K_{i,2} we need the following notation.
For X=(X_{1},...,X_{t}) write X_{i}^{1} for the first row of X_{i}.
Then distinct X,Y\in C clearly satisfy \textnormal{rk}(X_{i}-Y_{i})\leq n_{i}-1 whenever X_{i}^{1}=Y_{i}^{1}.
Therefore, the number of pairs of distinct X,Y\in C such that X_{i}^{1}=Y_{i}^{1} is a lower
bound for the number of such pairs satisfying \textnormal{rk}(X_{i}-Y_{i})\leq n_{i}-1.
Setting for A\in\mathbb{F}_{q}^{1\times m_{i}}




N_{i,A}:=|\{X\in C\mid X_{i}^{1}=A\}|,



we arrive at




\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}=|C|\ \text{ and }\ K_{i,2}\geq\displaystyle\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}(N_{i,A}-1).



Together with (3.2) this gives us




\displaystyle d|C|(|C|-1)\leq S(C)
\displaystyle\leq
\displaystyle N|C|(|C|-1)-\sum_{i=1}^{t}K_{i,2}




\displaystyle\leq
\displaystyle N|C|(|C|-1)-\sum_{i=1}^{t}\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}(N_{i,A}-1),




\displaystyle=
\displaystyle N|C|(|C|-1)-\sum_{i=1}^{t}\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}^{2}+\sum_{i=1}^{t}\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A},




\displaystyle=
\displaystyle N|C|(|C|-1)+t|C|-\sum_{i=1}^{t}\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}^{2},




\displaystyle\leq
\displaystyle N|C|(|C|-1)+t|C|-\sum_{i=1}^{t}q^{-m_{i}}\bigg(\sum_{A\in\mathbb{F}_{q}^{1\times m_{i}}}N_{i,A}\bigg)^{2},




\displaystyle=
\displaystyle N|C|(|C|-1)+t|C|-|C|^{2}Q,



where the penultimate step follows from the Cauchy-Schwarz inequality.
Thus we have d(|C|-1)\leq N(|C|-1)+t-|C|Q,
which in turn yields




|C|\leq\frac{d-N+t}{d-N+Q},



as long as d>N-Q.
∎




Proof of Theorem 3.11.



Towards a contradiction, suppose that the largest dimension, k, of a linear code C\leq\Pi with sum-rank distance d
satisfies




q^{k}<\frac{|\Pi|}{V_{d-1}(\Pi)}.



Then there must exist X\in\Pi such that \textnormal{srk}(X-Y)\geq d for all Y\in C.
It is easy to see that C\oplus\langle X\rangle\leq\Pi is a code of sum-rank distance d that strictly contains C.
This contradicts the maximality of C.
∎






3.2 Comparisons




In this subsection we provide for each of the bounds, except for the Induced Hamming Bound, an
example of an ambient space \Pi and a distance d for which that bound is superior to all other bounds.
This is true for linear as well as general sum-rank metric codes.
In the case where m=m_{1}=\cdots=m_{t}, the Induced Hamming Bound (Theorem 3.1) is clearly inferior
to the sphere-packing bound (Theorem 3.6) because the Hamming sphere of radius r in \mathbb{F}_{q^{m}}^{N} is contained in
the sum-rank sphere of the same radius in \Pi, where we identify \mathbb{F}_{q^{m}}^{N} and \Pi via the map f defined in (3.1).
For the case of general m_{i}, the embedding f and subsequent comparison between the Hamming weight and sum-rank weight
suggests that in fact the Sphere-Packing Bound is always superior to the Induced Hamming Bound.




The examples below show, in contrast to MRD codes, that MSRD codes do not exist for all possible parameter
sets.
This is not surprising because the sum-rank is a hybrid of the Hamming distance and the rank distance and thus,
just like MDS codes, MSRD codes may not exist over arbitrary fields.

4 Asymptotic Bounds




In this section we derive asymptotic versions for the bounds presented in Section 3
as t\rightarrow\infty, where as usual, t is the number of blocks.
As the reader will see, the Singleton Bound of Theorem 3.2, the Projective Sphere-Packing Bound of Theorem 3.7 and the Induced Singleton Bound of Theorem 3.1 are all asymptotically the same. The Sphere-Packing Bound of Theorem 3.2 and the Total-Distance Bound of Theorem 3.8 are asymptotically the best upper bounds currently known.




Recall from (2.1) that we always assume that m_{i}\geq m_{i+1}.
As a consequence, we will now impose that (m_{i}) is a non-increasing sequence of positive integers, which in turn
implies that the sequence stabilizes.




Throughout this section we fix the following notation.



Notation 4.1.



Let (m_{i})_{i\in\mathbb{N}},\,(n_{i})_{i\in\mathbb{N}} be sequences with the following properties and further data.


(i)  



1\leq n_{i}\leq m_{i} and n_{i},\,m_{i}\in\mathbb{N} for all i\in\mathbb{N}.


(ii)  



The sequence (m_{i}) is monotonically non-increasing.


(iii)  



Let s\in\mathbb{N} be the least integer such that m_{i}=m_{s} for all i>s. We write \hat{m}:=m_{s}.


(iv)  



Set n^{\ast}=\max\{n_{i}\mid i>s\} and n_{\ast}=\min\{n_{i}\mid i>s\}.


(v)  



For any t\in\mathbb{N} we define \Pi^{(t)}=\Pi_{q}(n_{1}\times m_{1}\mid\cdots\mid n_{t}\times m_{t}) and




N_{t}=\sum_{i=1}^{t}n_{i},\quad D_{t}=\dim(\Pi^{(t)})=\sum_{i=1}^{t}n_{i}m_{i}.








Definition 4.2.



Let d\in\mathbb{R}_{\geq 0}. We define




A_{q}(d):=A_{q}\big(t,(n_{i}),(m_{i}),d\big):=\max\big\{|C|\,\big|\,C\subseteq\Pi^{(t)},\,|C|\geq 2,\,\textnormal{srk}(C)\geq d\big\},



where the maximum over the empty set is taken to be 1.
Furthermore, for any \eta\in[0,1] we define




\alpha_{q}(\eta):=\limsup_{t\rightarrow\infty}\frac{\log_{q}\big(A_{q}(\eta N_{t})\big)}{D_{t}}.



The quantity \frac{\log_{q}(A_{q}(d))}{D_{t}} is the rate of an optimal code C\subseteq\Pi^{(t)} with sum-rank distance at least d, provided that such a code exists (and is zero otherwise).





Clearly, the induced bounds from Theorem 3.1 lead to the asymptotic bounds as known for the Hamming metric;
see for instance [5, Sec. 2.10].
For the sake of comparison, and the convenience of the reader, we summarize these below.



Remark 4.3.



In applying the asymptotic induced upper bounds on the rate of a code for the sum-rank distance, the parameter m that appears in the bounds denotes the maximal value of the m_{i} (which given the assumptions that the m_{i} are non-increasing, is m_{1}.) Recall that we identify a code in \Pi^{t} with one in \mathbb{F}_{q^{m}}^{N_{t}}, as outlined in the proof of Theorem 3.1. Therefore, in applying the asymptotic versions of the induced bounds we use only the datum m_{1} provided by the sequences (m_{i}) and (n_{i}).





First recall that for any prime power Q, we denote by h_{Q}(x) the Hilbert entropy function defined on [0,1] by




h_{Q}(x)=\left\{\begin{array}[]{ll}0&\text{ if }x=0,\\
x\log_{Q}(Q-1)-x\log_{Q}(x)-(1-x)\log_{Q}(1-x)&\text{ if }0<x<1-Q^{-1}.\end{array}\right.



It is well-known [5, Lem. 2.10.3] that
h_{Q}(x)=\lim_{t\rightarrow\infty}t^{-1}V_{xt}(\mathbb{F}_{Q}^{t}), where V_{xt}(\mathbb{F}_{Q}^{t}) is the volume of the Hamming sphere (defined in Theorem 3.1).



Theorem 4.4 (Asymptotic Induced Bounds).



Let m=m_{1} and \eta\in[0,1]. We have the following upper bounds on \alpha_{q}(\eta).






Induced Singleton Bound:


\alpha_{q}(\eta)\leq 1-\eta.


Induced Hamming Bound:


\alpha_{q}(\eta)\leq 1-h_{q^{m}}(\eta/2) for \eta\in(0,1-q^{-m}).


Induced Plotkin Bound:


\alpha_{q}(\eta)\leq\left\{\begin{array}[]{ll}1-\eta(1-q^{-m})^{-1}&\text{ if }\eta\in[0,1-q^{-m}],\\
0&\text{ otherwise. }\end{array}\right.


Induced Elias Bound:


\alpha_{q}(\eta)\leq 1-h_{q^{m}}\big(r-\sqrt{r(r-\eta)}\,\big) for \eta\in(0,r) where r=1-q^{-m}.








We now focus on the other bounds of Section 3 and derive asymptotic versions.




It would appear, intuitively, that the asymptotic bounds we derive shortly do not depend on the parameters of the first s blocks, where s is as in Notation 4.1 (iii),
and therefore we should be able to assume that (m_{i})_{i\in\mathbb{N}} is a constant sequence.
However, while it is straightforward to puncture on columns and retain information about the distance, the converse process is not obvious.
Therefore, we will start with the general setup of Notation 4.1, and the independence of the asymptotic bounds on the first s
blocks will become clear only a posteriori.




Note that for any t\geq s we have



(4.1)


\displaystyle D_{s}+\hat{m}n^{\ast}(t-s)\geq D_{t}=D_{s}+\hat{m}(N_{t}-N_{s})\geq D_{s}+\hat{m}n_{\ast}(t-s),


(4.2)


\displaystyle N_{s}+n^{\ast}(t-s)\geq N_{t}\geq N_{s}+n_{\ast}(t-s).



Using that D_{s} and N_{s} are constant, we thus have the following limits:



(4.3)


\displaystyle\lim_{t\rightarrow\infty}\frac{D_{t}}{N_{t}}=\hat{m},


(4.4)


\displaystyle\frac{1}{\hat{m}n^{\ast}}\leq\liminf_{t\rightarrow\infty}\frac{t}{D_{t}}\leq\limsup_{t\rightarrow\infty}\frac{t}{D_{t}}\leq\frac{1}{\hat{m}n_{\ast}},


(4.5)


\displaystyle\frac{1}{n^{\ast}}\leq\liminf_{t\rightarrow\infty}\frac{t}{N_{t}}\leq\limsup_{t\rightarrow\infty}\frac{t}{N_{t}}\leq\frac{1}{n_{\ast}}.






We are now ready to present the Asymptotic Singleton Bound.



Theorem 4.5 (Asymptotic Singleton Bound).



Let \eta\in[0,1]. Then




\alpha_{q}(\eta)\leq 1-\eta.






Proof.



Let \eta>0.
We apply the Singleton Bound (Theorem 3.2) to codes C\subseteq\Pi^{(t)} with \textnormal{srk}(C)\geq d=\lceil\eta N_{t}\rceil for any t.
Let j(t)\in\mathbb{N}_{0} be the unique integer satisfying



(4.6)

\lceil\eta N_{t}\rceil-1\in[N_{j(t)-1},N_{j(t)}).



Then Theorem 3.2 implies \log_{q}(|C|)\leq\sum_{i=j(t)}^{t}m_{i}n_{i}.
Since \lim_{t\rightarrow\infty}\eta N_{t}=\infty, we also have \lim_{t\rightarrow\infty}j(t)=\infty.
Clearly, j(t)\leq t.
Consider now t large enough so that j(t)>s.
With the aid of (4.6) we arrive at




\displaystyle\log_{q}(|C|)
\displaystyle\leq\sum_{i=j(t)}^{t}m_{i}n_{i}=\hat{m}(N_{t}-N_{j(t)}+n_{j(t)})




\displaystyle\leq\hat{m}(N_{t}-N_{j(t)}+\hat{m})\leq\hat{m}(N_{t}-\eta N_{t}+1+\hat{m}).



Hence, applying (4.3), we have:




\alpha_{q}(\eta)\leq\limsup_{t\rightarrow\infty}\frac{\hat{m}(N_{t}-\eta N_{t}+1+\hat{m})}{D_{t}}=\limsup_{t\rightarrow\infty}\Big(\hat{m}(1-\eta)\frac{N_{t}}{D_{t}}+\frac{\hat{m}(1+\hat{m})}{D_{t}}\Big)=1-\eta.\qed







We now turn to the Asymptotic Total-Distance Bound. We need the following lemma.
Recall Notation 4.1.



Lemma 4.6.



Let Q_{t}:=\sum_{i=1}^{t}q^{-m_{i}}.
Then




\frac{1}{n^{\ast}q^{\hat{m}}}\leq\liminf_{t\rightarrow\infty}\frac{Q_{t}}{N_{t}}\leq\limsup_{t\rightarrow\infty}\frac{Q_{t}}{N_{t}}\leq\frac{1}{n_{\ast}q^{\hat{m}}}.



Furthermore, if there exist s^{\prime}\in\mathbb{N} and \hat{n}\in\mathbb{N} such that n_{i}=\hat{n} for all i>s^{\prime}, then
\lim_{t\rightarrow\infty}\frac{Q_{t}}{N_{t}}=\frac{1}{\hat{n}q^{\hat{m}}}.




Proof.



Using Q_{t}=Q_{s}+q^{-\hat{m}}(t-s) and (4.2)
we obtain



(4.7)

\frac{Q_{s}+q^{-\hat{m}}(t-s)}{N_{s}+n^{\ast}(t-s)}\leq\frac{Q_{t}}{N_{t}}\leq\frac{Q_{s}+q^{-\hat{m}}(t-s)}{N_{s}+n_{\ast}(t-s)}.



Since Q_{s} and N_{s} are constant, this leads to the desired result.
Finally, if n_{i}=\hat{n} for i\geq s^{\prime}, the above proof with s^{\prime} and \hat{n} in place of s and n_{\ast} (or n^{\ast}), respectively,
leads to equalities in (4.7) and the stated result follows.
∎




Theorem 4.7 (Asymptotic Total-Distance Bound).



Let \eta\in[0,1]. Then


(a)  



If \eta>1-\frac{1}{n^{\ast}q^{\hat{m}}}, then \alpha_{q}(\eta)=0.


(b)  



If \eta\leq 1-\frac{1}{n^{\ast}q^{\hat{m}}}, then
\alpha_{q}(\eta)\leq 1-\eta\big(1-\frac{1}{n^{*}q^{\hat{m}}}\big)^{-1}.


(c)  



Suppose there exists s^{\prime}\in\mathbb{N} such that n_{i}=\hat{n} for all i>s^{\prime}. Then




\alpha_{q}(\eta)\leq 1-\eta\big(1-\frac{1}{\hat{n}q^{\hat{m}}}\big)^{-1}\text{ for all }\eta\leq 1-\frac{1}{\hat{n}q^{\hat{m}}}\ \ \text{ and }\ \ \alpha_{q}(\eta)=0\text{ otherwise.}








Proof.



(a) Let \eta>1-\frac{1}{n^{\ast}q^{\hat{m}}} and let Q_{t}:=\sum_{i=1}^{t}q^{-m_{i}}.
Then \eta>1-\frac{Q_{t}}{N_{t}} for sufficiently large t thanks to Lemma 4.6,
and so \eta N_{t}>N_{t}-Q_{t}.
Therefore, we can apply Theorem 3.8 to a code C\subseteq\Pi^{(t)} with minimum sum-rank distance at least
\eta N_{t} to obtain:




|C|\leq\frac{\eta N_{t}-N_{t}+t}{\eta N_{t}-N_{t}+Q_{t}}=\frac{\eta-1+t/N_{t}}{\eta-1+Q_{t}/N_{t}}.



Now \limsup_{t\rightarrow\infty}|C|\leq\frac{\eta-1+n_{\ast}^{-1}}{\eta-1+(n^{\ast}q^{\hat{m}})^{-1}} follows from
Lemma 4.6 and (4.5).
Thus, \limsup_{t\rightarrow\infty}A_{q}(\eta N_{t}) is finite and hence \alpha_{q}(\eta)=0.




(b) Now suppose that \eta\leq 1-\frac{1}{n^{\ast}q^{\hat{m}}}.
Let C\subseteq\Pi^{(t)} have \textnormal{srk}(C)\geq\eta N_{t} and |C|=A_{q}(\eta N_{t}).
We proceed in several steps.
We first derive a general form of puncturing that will allow us to apply the Total-Distance Bound.
In a second step we specify the parameters for the puncturing such that the asymptotics of the bound can be determined.
The final computation is carried out in Sept 3.




Step 1: Deriving a Punctured Code:
For given t choose any integers r_{1},\ldots,r_{t} such that 0\leq r_{i}\leq n_{i} and



(4.8)

\sum_{i=1}^{t}(n_{i}-r_{i})-\sum_{i:r_{i}<n_{i}}q^{-m_{i}}+1\leq\eta N_{t}.



In this step we will puncture a subset the code C by removing r_{i} rows from block i.
The specific choice of the parameters r_{i}, depending on t, will be made in Step 2 of this proof.
For our general choice subject to (4.8) define the index sets (which depend on t)




\mathcal{I}_{1}=\{i\in[t]\mid r_{i}>0\}\ \text{ and }\ \mathcal{I}_{2}=\{i\in[t]\mid r_{i}<n_{i}\}



and the spaces




\Pi_{1}^{(t)}=\bigoplus_{i\in\mathcal{I}_{1}}\mathbb{F}_{q}^{r_{i}\times m_{i}}\ \text{ and }\ \Pi_{2}^{(t)}=\bigoplus_{i\in\mathcal{I}_{2}}\mathbb{F}_{q}^{(n_{i}-r_{i})\times m_{i}}.



Clearly, \Pi_{1}^{(t)}\oplus\Pi_{2}^{(t)}\cong\Pi^{(t)}.
Set L_{1}=\sum_{i\in\mathcal{I}_{1}}r_{i}m_{i}.
Consider the projections




\displaystyle f_{1}:
\displaystyle\Pi^{(t)}\longrightarrow\Pi_{1}^{(t)},\quad(X_{1},\ldots,X_{t})\longmapsto(X^{\prime}_{i}\mid i\in\mathcal{I}_{1}),



\displaystyle f_{2}:
\displaystyle\Pi^{(t)}\longrightarrow\Pi_{2}^{(t)},\quad(X_{1},\ldots,X_{t})\longmapsto(X^{\prime\prime}_{i}\mid i\in\mathcal{I}_{2}),



where X^{\prime}_{i} consists of the first r_{i} rows of X_{i} and X^{\prime\prime}_{i} consists of the last n_{i}-r_{i} rows of X_{i}.
Since |\Pi_{1}^{(t)}|=q^{L_{1}}, there exists a matrix tuple Y\in\Pi_{1}^{(t)} such that
C_{Y}:=\{X\in C\mid f_{1}(X)=Y\} has cardinality at least |C|/q^{L_{1}}.
Set




C^{\prime}:=f_{2}(C_{Y})\subseteq\Pi_{2}^{(t)}.



Then |C^{\prime}|=|C_{Y}|\geq|C|/q^{L_{1}} and \textnormal{srk}(C^{\prime})\geq\eta N_{t}.
Note that the code C^{\prime} has length |\mathcal{I}_{2}| (and all blocks have a positive number of rows).
Write N_{2,t}=\sum_{i\in\mathcal{I}_{2}}n_{i},\,R_{2,t}=\sum_{i\in\mathcal{I}_{2}}r_{i}, and Q_{2,t}=\sum_{i\in\mathcal{I}_{2}}q^{-m_{i}}.
Then (4.8) reads as N_{2,t}-R_{2,t}-Q_{2,t}+1\leq\eta N_{t}, which means
we can apply Theorem 3.8 to C^{\prime}.
We obtain



(4.9)

|C|\leq|C^{\prime}|q^{L_{1}}\leq q^{L_{1}}\frac{\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|}{\eta N_{t}-(N_{2,t}-R_{2,t})+Q_{2,t}}\leq q^{L_{1}}\big(\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|\big),



where the last step follows from the fact that the denominator in the previous term is at least 1 thanks to (4.8).
Setting R_{t}=\sum_{i=1}^{t}r_{i}, we have N_{2,t}-R_{2,t}=N_{t}-R_{t} and thus




\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|\leq(\eta-1)N_{t}+R_{t}+t\leq(\eta-1)N_{t}+N_{t}+t\leq\eta N_{t}+t.



With the aid of (4.3) and (4.4) we arrive at




\limsup_{t\rightarrow\infty}\frac{\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|}{D_{t}}\leq\limsup_{t\rightarrow\infty}\frac{\eta N_{t}+t}{D_{t}}\leq\frac{1}{\hat{m}}\Big(\eta+\frac{1}{n_{\ast}}\Big),



which in turn yields \limsup_{t\rightarrow\infty}\frac{\log_{q}(\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|)}{D_{t}}=0.
Together with (4.9) all of this shows that




\displaystyle\alpha_{q}(\eta)
\displaystyle=\limsup_{t\rightarrow\infty}\frac{\log_{q}(|C|)}{D_{t}}\leq\limsup_{t\rightarrow\infty}\frac{\sum_{i\in\mathcal{I}_{1}}^{t}r_{i}m_{i}+\log_{q}(\eta N_{t}-(N_{2,t}-R_{2,t})+|\mathcal{I}_{2}|)}{D_{t}}


(4.10)


\displaystyle=\limsup_{t\rightarrow\infty}\frac{\sum_{i=1}^{t}r_{i}m_{i}}{D_{t}}.






Step 2: Determining Suitable Parameters r_{i}:
We seek values for r_{i} satisfying (4.8) and such that \sum_{i=1}^{t}r_{i}m_{i} in (4.10)
can be evaluated asymptotically.
At the same time we want r_{i} such that the sum is small.
Since (m_{i}) is non-increasing, this means to put more weight on r_{i} for large value of i.
(Note that actually minimizing \sum_{i=1}^{t}r_{i}m_{i} subject to the constraint (4.8) would be an instance of linear programming,
which is much harder and may lead to results that cannot be evaluated asymptotically.)
We proceed as follows.
First set T\in\mathbb{N} such that \eta N_{t}\geq 1 for all t\geq T.
Define, as before, Q_{t}=\sum_{i=1}^{t}q^{-m_{i}}.
Since the sequence (N_{t}-Q_{t}) is strictly increasing, there exist, for all t\geq T, a maximal index z(t)\in[t]
such that



(4.11)

N_{z(t)-1}-Q_{z(t)-1}+1\leq\eta N_{t}



(and where we set N_{0}=Q_{0}=0).
The maximality of z(t) implies that \lim_{t\rightarrow\infty}z(t)\rightarrow\infty.
Observe that (4.11) forms an instance of (4.8). Indeed, it corresponds to the choice



(4.12)

r_{i}=\begin{cases}0,&\text{for }i=1,\ldots,z(t)-1,\\
n_{i},&\text{for }i=z(t)+1,\ldots,t,\end{cases}



for which we have \mathcal{I}_{2}=[z(t)-1] and thus Q_{2,t}=Q_{z(t)-1}, as desired.




In preparation of the final part of the proof we need the lower bound



(4.13)

\liminf_{t\rightarrow\infty}\frac{N_{z(t)}}{N_{t}}\geq\eta\Big(1-\frac{1}{n^{*}q^{\hat{m}}}\Big)^{-1}.



To establish this, note first that our assumption on \eta implies \eta\big(1-(n^{*}q^{\hat{m}})^{-1}\big)^{-1}\leq 1, which
covers the case z(t)=t in above inequality.
Let now \mathcal{T}=\{t\geq T\mid z(t)<t\} and suppose |\mathcal{T}|=\infty.
Then for t\in\mathcal{T} the maximality of z(t) subject to (4.11) implies
\eta N_{t}<N_{z(t)}-Q_{z(t)}+1.
With the aid of Lemma 4.6 this yields




\liminf_{t\in\mathcal{T},\,t\rightarrow\infty}\frac{N_{z(t)}}{N_{t}}\geq\eta+\liminf_{t\in\mathcal{T},\,t\rightarrow\infty}\frac{Q_{z(t)}}{N_{t}}=\eta+\liminf_{t\in\mathcal{T},\,t\rightarrow\infty}\frac{Q_{z(t)}}{N_{z(t)}}\frac{N_{z(t)}}{N_{t}}\geq\eta+\frac{1}{n^{*}q^{\hat{m}}}\liminf_{t\in\mathcal{T},\,t\rightarrow\infty}\frac{N_{z(t)}}{N_{t}},



from which




\liminf_{t\in\mathcal{T},\,t\rightarrow\infty}\frac{N_{z(t)}}{N_{t}}\geq\eta\big(1-(n^{*}q^{\hat{m}})^{-1}\big)^{-1}



follows.
All of this establishes (4.13).




Step 3: Determining the Asymptotics:
With the choice of r_{1},\ldots,r_{t} in (4.12) we now return to (4.10).
For sufficiently large t we have
\sum_{i=1}^{t}r_{i}m_{i}=\sum_{i=z(t)+1}^{t}n_{i}m_{i}=\hat{m}(N_{t}-N_{z(t)}),
and therefore (4.10) turns into




\displaystyle\alpha_{q}(\eta)
\displaystyle\leq\limsup_{t\rightarrow\infty}\frac{\hat{m}(N_{t}-N_{z(t)})}{D_{t}}=\limsup_{t\rightarrow\infty}\frac{N_{t}-N_{z(t)}}{N_{t}}




\displaystyle=1-\liminf_{t\rightarrow\infty}\frac{N_{z(t)}}{N_{t}}\leq 1-\eta\Big(1-\frac{1}{n^{*}q^{\hat{m}}}\Big)^{-1},



where the second step follows from (4.3) and the last one from (4.13).




(c) Let now n_{i}=\hat{n} for all i>s^{\prime}.
Then in (4.4) and (4.5) we have \lim_{t\rightarrow\infty}(t/D_{t})=(\hat{m}\hat{n})^{-1} and
\lim_{t\rightarrow\infty}(t/N_{t})=(\hat{n})^{-1}.
Thus if \eta\geq 1-\frac{1}{\hat{n}q^{\hat{m}}}, the proof of (a) with \hat{n} instead of n^{\ast} and n_{\ast}
results in \alpha_{q}(\eta)=0, and if \eta<1-\frac{1}{\hat{n}q^{\hat{m}}} the proof of (b) with \hat{n} instead of
n^{\ast} results in \alpha_{q}(\eta)\leq 1-\eta\big(1-(\hat{n}q^{\hat{m}})^{-1}\big)^{-1}, as desired.
∎





Next, we show that the Projective Sphere-Packing Bound provides the same asymptotic bound as the Singleton Bound.



Theorem 4.8 (Asymptotic Projective Sphere-Packing Bound).



Let \eta\in[0,1]. Then




\alpha_{q}(\eta)\leq 1-\eta.






Proof.



Let C\subseteq\Pi^{(t)} have \textnormal{srk}(C)\geq\eta N_{t} and |C|=A_{q}(\eta N_{t}).
Consider t sufficiently large so that \eta N_{t}\geq 3.
For these t let \ell(t)\in\mathbb{Z} and \delta(t)\in[0,n_{\ell(t)+1}-1] be the unique integers satisfying



(4.14)

\lceil\eta N_{t}\rceil-3=\sum_{j=1}^{\ell(t)}n_{j}+\delta(t)=N_{\ell(t)}+\delta(t).



Clearly, \ell(t)\leq t and \lim_{t\rightarrow\infty}\ell(t)=\infty.
By Theorem 3.7, we have



(4.15)

\left.\begin{split}\log_{q}(|C|)&\leq\sum_{j=\ell(t)+1}^{t}n_{j}m_{j}-\delta(t)m_{\ell(t)+1}\\[3.01385pt]
&\quad-\log_{q}\bigg(1+\sum_{i=\ell(t)+2}^{t}(q^{n_{i}}-1)\frac{q^{m_{i}}-1}{q-1}+(q^{n_{\ell(t)+1}-\delta(t)}-1)\frac{q^{m_{\ell(t)+1}}-1}{q-1}\bigg).\end{split}\quad\right\}



We compute \limsup\log_{q}(|C|)/D_{t} by considering the two terms individually. First,




\displaystyle\limsup_{t\rightarrow\infty}\frac{\sum_{j=\ell(t)+1}^{t}n_{j}m_{j}-\delta(t)m_{\ell(t)+1}}{D_{t}}
\displaystyle=\limsup_{t\rightarrow\infty}\frac{D_{t}-D_{\ell(t)}-\delta(t)m_{\ell(t)+1}}{D_{t}},


(4.16)


\displaystyle=1-\liminf_{t\rightarrow\infty}\frac{D_{\ell(t)}}{D_{t}}=1-\liminf_{t\rightarrow\infty}\frac{N_{\ell(t)}}{N_{t}}


(4.17)


\displaystyle\leq 1-\liminf_{t\rightarrow\infty}\frac{\eta N_{t}-3-\delta(t)}{N_{t}}=1-\eta,



where the third step follows from (4.3) and the last two from (4.14) and the fact that \delta(t) is bounded.
As for the second term we first note that for sufficiently large t



(4.18)

\sum_{i=\ell(t)+2}^{t}(q^{n_{i}}-1)\frac{q^{m_{i}}-1}{q-1}+(q^{n_{\ell(t)+1}-\delta(t)}-1)\frac{q^{m_{\ell(t)+1}}-1}{q-1}\geq\frac{q^{\hat{m}}-1}{q-1}\big((q^{n_{\ast}}-1)(t-\ell(t)-1)\big)



since n_{\ell(t)+1}-\delta(t)\geq 0.
The only term in the rightmost part depending on t is t-\ell(t).
We show now that the sequence (\frac{t-\ell(t)}{D_{t}})_{t\in\mathbb{N}} is bounded.
Using N_{\ell(t)}\leq N_{s}+n^{\ast}(\ell(t)-s) we obtain from (4.14)




\ell(t)\geq\frac{\eta N_{t}-3-N_{s}-\delta(t)}{n^{\ast}}+s.



Therefore,




\limsup_{t\rightarrow\infty}\frac{t-\ell(t)}{D_{t}}\leq\limsup_{t\rightarrow\infty}\frac{t}{D_{t}}-\liminf_{t\rightarrow\infty}\bigg(\frac{\eta N_{t}-3-N_{s}-\delta(t)}{n^{\ast}D_{t}}+\frac{s}{D_{t}}\bigg)\leq\frac{1}{n_{\ast}\hat{m}}-\frac{\eta}{n^{\ast}\hat{m}},



thanks to (4.4) and (4.3).
All of this shows that \liminf_{t\rightarrow\infty}\frac{\log_{q}(t-\ell(t))}{D_{t}}=0, and together
with (4.15) – (4.18) this establishes \alpha_{q}(\eta)\leq 1-\eta, as stated.
∎





As the proof has shown, the first term in (4.15) fully determines the asymptotic bound, see also (4.17), and the second
term does not provide an improvement.
This explains why the Asymptotic Sphere-Packing Bound is identical to the Asymptotic Singleton Bound.




We now turn to the Asymptotic Sphere-Packing and Sphere-Covering Bound.
For this we need an asymptotic estimate for the cardinality of the spheres of sum-rank radius t\rho as t\longrightarrow\infty; see
Theorem 3.6.
This has been established in the literature for more general alphabets and applies to our case if all matrix blocks have the same size.
Therefore we assume for the remainder of this section that m_{i}=m and n_{i}=n for all i\in\mathbb{N}
and furthermore set \pi:=\mathbb{F}_{q}^{n\times m}. Thus \Pi=\pi^{t}.
In [7] the author considers a general alphabet {\mathcal{A}} and a weight function w on {\mathcal{A}} that extends to a weight function on {\mathcal{A}}^{t} via w(u_{1},...,u_{t})=\sum_{i=1}^{t}w(u_{i}).
In the setting of this paper, we have {\mathcal{A}}=\pi with the rank as weight function, and the induced weight function on {\mathcal{A}}^{t} is
precisely the sum-rank.




Now we are ready to state the following sum-rank adaptation of [7] (see also [4, Theorem 4.1]).



Theorem 4.9.



Define the generating function




f(z):=\sum_{A\in\pi}z^{\textnormal{rk}(A)}=\sum_{i=0}^{n}\left[\begin{matrix}n\\
i\end{matrix}\right]_{q}\prod_{j=0}^{i-1}(q^{m}-q^{j})z^{i}



and the average rank weight \epsilon:=\frac{1}{|\pi|}\sum_{A\in\pi}\textnormal{rk}(A).
Then for all \rho\in(0,\epsilon] we have




\lim_{t\longrightarrow\infty}\frac{1}{t}\log_{|\pi|}\Big(V_{t\rho}(\pi^{t})\Big)=\min_{z\in(0,1]}\log_{|\pi|}\Big(\frac{f(z)}{z^{\rho}}\Big).







An entropy function for the sum-rank is hence defined as




H(\rho):=\min_{z\in(0,1]}\log_{|\pi|}\Big(\frac{f(z)}{z^{\rho}}\Big)=\min_{z\in(0,1]}\frac{1}{mn}\log_{q}\Big(\frac{f(z)}{z^{\rho}}\Big).



The asymptotic bounds follow now easily.



Corollary 4.10 (Asymptotic Sphere-Packing Bound & Sphere-Covering Bound).



Let \eta\in(0,\frac{\epsilon}{n}], where
\epsilon is as in Theorem 4.9. Then




1-H(\eta n)\leq\alpha(\eta)\leq 1-H\left(\frac{\eta n}{2}\right).






Proof.



The bounds are immediate consequences of Theorem 3.6 and Theorem 3.11:




1-H(\eta n)\!=\!\lim_{t\rightarrow\infty}\frac{mnt-\log_{q}\big({V_{\eta nt-1}(\pi^{t})}\big)}{mnt}\leq\alpha_{q}(\eta)\leq\lim_{t\rightarrow\infty}\frac{mnt-\log_{q}\big(V_{\frac{\eta nt}{2}}(\pi^{t})\big)}{mnt}\!=\!1-H\left(\frac{\eta n}{2}\right).\qed

5 Duality and MacWilliams Identities




For the rest of the paper we again focus on \mathbb{F}_{q}-linear sum-rank metric codes.
In this section we will investigate the distributions introduced in Definition 2.8 under duality.
We show that the sum-rank distribution does not obey a MacWilliams identity, while both the rank-list distribution and the support distribution do.
Moreover, we give explicit formulas
for the corresponding MacWilliams transformations. We follow the notation of Section 2; recall in particular
(2.1), (2.2) and (2.3) and Definition 2.3.



Definition 5.1.



The dual of a code C\leq\Pi is defined as




C^{\perp}:=\bigg\{(Y_{1},...,Y_{t})\in\Pi\,\bigg|\,\sum_{i=1}^{t}\mbox{$\langle{X_{i},Y_{i}}\rangle$}=0\mbox{ for all $(X_{1},...,X_{t})\in C$}\bigg\}\leq\Pi,



where \langle{\,\cdot,\cdot\,}\rangle denotes the trace-product.
Furthermore, the dual of \bm{U}\in\mathcal{L} is \bm{U}^{\perp}:=(U_{1}^{\perp},...,U_{t}^{\perp}), where
U_{i}^{\perp} is the orthogonal of U_{i} with respect to the standard inner product of
\mathbb{F}_{q}^{n_{i}}.





One easily observes that \Pi({\bm{U}}^{\perp})=\Pi({\bm{U}})^{\perp}, where \Pi({\bm{U}}) is as in Definition 2.5.
Furthermore, using the isomorphism \psi from (2.5)
and the ordinary trace dual on \mathbb{F}_{q}^{N\times M} we obtain \psi(C^{\perp})=\psi(C)^{\perp}\cap\mathbb{F}_{q}^{N\times M}[\mathcal{P}].




Our first observation, shown in the following example, illustrates that the sum-rank distributions of a code C and its dual C^{\perp} do not satisfy
a MacWilliams identity.



Example 5.2.



The sum-rank distribution of a code does not determine the sum-rank distribution of its dual code.
Consider e.g. the 1-dimensional codes C_{1} and C_{2} in \Pi=\mathbb{F}_{2}^{2\times 2}\times\mathbb{F}_{2}^{2\times 2}
generated by the matrix tuples




\left(\begin{pmatrix}1&0\\
0&1\end{pmatrix},\begin{pmatrix}0&0\\
0&0\end{pmatrix}\right)\ \text{ and }\ \left(\begin{pmatrix}1&0\\
0&0\end{pmatrix},\begin{pmatrix}1&0\\
0&0\end{pmatrix}\right),



respectively. Then C_{1} and C_{2} have the same sum-rank distribution. However, C_{1}^{\perp} has
12 elements of sum-rank 1 and C_{2}^{\perp} has 10.





On the positive side, the rank-list distribution and the support distribution of sum-rank metric codes
do satisfy MacWilliams identities.
We establish these results using a combinatorial technique
that gives an explicit formula for the transformation between the distributions.
In order to do so, we need the following observation, which can be thought of as a sum-rank version of the duality between puncturing and shortening. It extends [17, Lem. 28] from rank-metric codes to sum-rank metric codes.



Proposition 5.3.



Let C\leq\Pi and \bm{U}=(U_{1},\ldots,U_{t})\in\mathcal{L}. Let u_{i}:=\dim(U_{i}) for i\in[t]. Then




|C(\bm{U})|=\frac{|C|}{|\Pi({\bm{U}})^{\perp}|}|C^{\perp}(\bm{U}^{\perp})|=\frac{|C|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-u_{i})}}|C^{\perp}(\bm{U}^{\perp})|.






Proof.



Let C,A\leq\Pi be linear subspaces.
Then




\dim(C\cap A)=\dim(C)-\dim(A^{\perp})+\dim(C^{\perp}\cap A^{\perp}),



which can be seen by taking dimensions in the identity
(C\cap A)^{\perp}=C^{\perp}+A^{\perp} and using the dimension formula for the sum of vector spaces.
Specializing to A=\Pi(\bm{U}), using A^{\perp}=\Pi({\bm{U}}^{\perp}) and applying Remark 2.6, we obtain the desired result.
∎





Now we turn to the support distribution.
Define the partial order \leq on \mathbb{N}_{0}^{t} by



(5.1)

\bm{v}\leq\bm{u}:\Longleftrightarrow v_{i}\leq u_{i}\text{ for all }i\in[t],



for any {\bm{u}}=(u_{1},\ldots,u_{t}),\,{\bm{v}}=(v_{1},\ldots,v_{t})\in\mathbb{N}_{0}^{t}.
The following result shows that the support distribution of C^{\perp} is fully determined by the support distribution of C.



Theorem 5.4.



Let C\leq\Pi.
Moreover, let \bm{U}=(U_{1},\ldots,U_{t})\in\mathcal{L} and \dim(\bm{U})=\bm{u}=(u_{1},\ldots,u_{t}). Then




W_{\bm{U}}(C^{\perp})=\frac{1}{|C|}\sum_{\bm{H}\in\mathcal{L}}W_{\bm{H}}(C)\sum_{\bm{v}\leq\bm{u}}q^{\sum_{i=1}^{t}m_{i}v_{i}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\genfrac{[}{]}{0.0pt}{0}{\dim(H_i^\perp\cap U_i)}{v_i}_{q}.



In particular, the support distribution of C^{\perp} is uniquely determined by the support distribution of C via an invertible linear transformation.




Proof.



We follow/extend the approach of [18] based on combinatorics.
Fix \bm{U}\in\mathcal{L} as in the theorem.
Identity (2.6) applied to C^{\perp} along with Möbius inversion in the lattice \mathcal{L} yields




W_{\bm{U}}(C^{\perp})\ =\ \sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\end{subarray}}|C^{\perp}(\bm{V})|\,\mu_{\mathcal{L}}(\bm{V},\bm{U}).



Using Proposition 5.3 and the explicit expression for the Möbius function in Definition 2.3
we obtain



(5.2)

W_{\bm{U}}(C^{\perp})=\sum_{\bm{v}\leq\bm{u}}\;\frac{|C^{\perp}|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-v_{i})}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V}^{\perp})|.



Fix \bm{v}\leq\bm{u} and consider the set




\{(\bm{V},X)\in\mathcal{L}\times C\mid\bm{V}\leq\bm{U},\,\dim(\bm{V})=\bm{v},\,\sigma(X)\leq\bm{V}^{\perp}\}.



Counting its elements in two ways, we obtain




\displaystyle\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V}^{\perp})|
\displaystyle=\sum_{\bm{H}\in\mathcal{L}}\sum_{\begin{subarray}{c}X\in C\\
\sigma(X)=\bm{H}\end{subarray}}\big|\{\bm{V}\in\mathcal{L}\mid\dim(\bm{V})=\bm{v},\,\bm{V}\leq\bm{H}^{\perp}\cap\bm{U}\}\big|




\displaystyle=\sum_{\bm{H}\in\mathcal{L}}W_{\bm{H}}(C)\prod_{i=1}^{t}\genfrac{[}{]}{0.0pt}{0}{\dim(H_i^\perp\cap U_i)}{v_i}_{q}.



Combining this with (5.2) and using |C^{\perp}|=|\Pi|/|C|=q^{\sum_{i=1}^{t}m_{i}n_{i}}/|C|, we arrive at




W_{\bm{U}}(C^{\perp})=\frac{1}{|C|}\sum_{\bm{H}\in\mathcal{L}}W_{\bm{H}}(C)\sum_{\bm{v}\leq\bm{u}}\;q^{\sum_{i=1}^{t}m_{i}v_{i}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\left[\begin{matrix}\dim(H_{i}^{\perp}\cap U_{i})\\
v_{i}\end{matrix}\right]_{q},



as desired.
∎





Similarly, we obtain a MacWilliams duality for the rank-list distribution.



Theorem 5.5.



Let C\leq\Pi and \bm{u}\in\mathbb{N}_{0}^{t}. Then




W_{\bm{u}}(C^{\perp})=\frac{1}{|C|}\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\sum_{\bm{v}\leq\bm{u}}q^{\sum_{i=1}^{t}m_{i}v_{i}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\left[\begin{matrix}n_{i}-h_{i}\\
v_{i}\end{matrix}\right]_{q}\left[\begin{matrix}n_{i}-v_{i}\\
u_{i}-v_{i}\end{matrix}\right]_{q}.






Proof.



Starting from (5.2) and summing over all \bm{U}\in\mathcal{L} with
\dim(\bm{U})=\bm{u}, we obtain



(5.3)

W_{\bm{u}}(C^{\perp})=\sum_{\bm{v}\leq\bm{u}}\;\frac{|C^{\perp}|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-v_{i})}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V}^{\perp})|.



Fix \bm{v}\leq\bm{u} and consider the set




S=\{(\bm{U},\bm{V},X)\in\mathcal{L}\times\mathcal{L}\times C\mid\dim(\bm{U})=\bm{u},\,\dim(\bm{V})=\bm{v},\,\bm{V}\leq\bm{U},\,\sigma(X)\leq\bm{V}^{\perp}\}.



On the one hand,




|S|=\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V}^{\perp})|,



and on the other hand,




\displaystyle|S|
\displaystyle=\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}\ \sum_{\begin{subarray}{c}X\in C\\
\dim(\sigma(X))=\bm{h}\end{subarray}}\ \sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\dim(\bm{V})=\bm{v}\\
\bm{V}\leq\sigma(X)^{\perp}\end{subarray}}\big|\{\bm{U}\in\mathcal{L}\mid\dim(\bm{U})=\bm{u},\,\bm{V}\leq\bm{U}\}\big|




\displaystyle=\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\prod_{i=1}^{t}\left[\begin{matrix}n_{i}-h_{i}\\
v_{i}\end{matrix}\right]_{q}\left[\begin{matrix}n_{i}-v_{i}\\
u_{i}-v_{i}\end{matrix}\right]_{q}.



Therefore




\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V}^{\perp})|=\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\prod_{i=1}^{t}\left[\begin{matrix}n_{i}-h_{i}\\
v_{i}\end{matrix}\right]_{q}\left[\begin{matrix}n_{i}-v_{i}\\
u_{i}-v_{i}\end{matrix}\right]_{q}.



Combining this with (5.3) we obtain




W_{\bm{u}}(C^{\perp})=\frac{1}{|C|}\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\sum_{\bm{v}\leq\bm{u}}\;q^{\sum_{i=1}^{t}m_{i}v_{i}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\left[\begin{matrix}n_{i}-h_{i}\\
v_{i}\end{matrix}\right]_{q}\left[\begin{matrix}n_{i}-v_{i}\\
u_{i}-v_{i}\end{matrix}\right]_{q},



concluding the proof.
∎





We conclude this section with the sum-rank metric analogue of the binomial moments of the MacWilliams identities.



Theorem 5.6.



Let C\leq\Pi.
For all \bm{u}=(u_{1},...,u_{t})\in\mathbb{N}_{0}^{t} we have




\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\prod_{i=1}^{t}\left[\begin{matrix}n_{i}-h_{i}\\
u_{i}-h_{i}\end{matrix}\right]_{q}=\frac{|C|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-u_{i})}}\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C^{\perp})\prod_{i=1}^{t}\left[\begin{matrix}n_{i}-h_{i}\\
u_{i}\end{matrix}\right]_{q}.






Proof.



Fix any tuple \bm{u}\in\mathbb{N}_{0}^{t}. We start from Proposition 5.3 and sum over all \bm{U}\in\mathcal{L}
with \dim(\bm{U})=\bm{u}, obtaining



(5.4)

\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}|C(\bm{U})|=\frac{|C|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-u_{i})}}\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}|C^{\perp}(\bm{U}^{\perp})|.



The map \bm{U}\longmapsto\bm{U}^{\perp} induces a bijection between the tuples
\bm{U}\in\mathcal{L} with \dim(\bm{U})=\bm{u} and those with
\dim(\bm{U})=\bm{n}-\bm{u}, where \bm{n}=(n_{1},\ldots,n_{t}).
Therefore (5.4) can be re-written as



(5.5)

\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{u}\end{subarray}}|C(\bm{U})|=\frac{|C|}{q^{\sum_{i=1}^{t}m_{i}(n_{i}-u_{i})}}\sum_{\begin{subarray}{c}\bm{U}\in\mathcal{L}\\
\dim(\bm{U})=\bm{n}-\bm{u}\end{subarray}}|C^{\perp}(\bm{U})|.



Finally, observe that for all \bm{v}\in\mathbb{N}_{0}^{t} one has




\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\dim(\bm{V})=\bm{v}\end{subarray}}|C(\bm{V})|=\sum_{X\in C}|\{\bm{V}\in\mathcal{L}\mid\dim(\bm{V})=\bm{v},\,\bm{V}\geq\sigma(X)\}|=\sum_{\bm{h}\in\mathbb{N}_{0}^{t}}W_{\bm{h}}(C)\prod_{i=1}^{t}\left[\begin{matrix}n_{i}-h_{i}\\
v_{i}-h_{i}\end{matrix}\right]_{q}.



Using this fact twice in (5.5)
yields the desired result.
∎




Remark 5.7.



Theorem 5.6 implies
the binomial moments of the MacWilliams identities for both the Hamming and the rank metric, as in
[5, eq. (M1), p. 257] and [17, Theorem 31] respectively.
Indeed, the binomial moments for the rank-metric are easily obtained by setting t=1 in Theorem 5.6.
To recover the binomial moments for the Hamming metric,
let (n_{1},...,n_{t})=(m_{1},...,m_{t})=(1,..,1) and
fix 0\leq\nu\leq t.
Consider the identity in Theorem 5.6 and sum
over all \bm{u}\in\{0,1\}^{t}
with |\bm{u}|=t-\nu.
This results in




\sum_{\begin{subarray}{c}\bm{u}\in\{0,1\}^{t}\\
|\bm{u}|=t-\nu\end{subarray}}\ \sum_{\begin{subarray}{c}\bm{h}\in\{0,1\}^{t}\\
\bm{h}\leq\bm{u}\end{subarray}}W_{\bm{h}}(C)=\frac{|C|}{q^{\nu}}\sum_{\begin{subarray}{c}\bm{u}\in\{0,1\}^{t}\\
|\bm{u}|=t-\nu\end{subarray}}\ \sum_{\begin{subarray}{c}\bm{h}\in\{0,1\}^{t}\\
\bm{h}\leq(1,...,1)-\bm{u}\end{subarray}}W_{\bm{h}}(C^{\perp}).



The latter identity can be re-written as




\sum_{i=0}^{t-\nu}W_{i}(C)\binom{t-i}{\nu}=\frac{|C|}{q^{\nu}}\sum_{i=0}^{\nu}W_{i}(C^{\perp})\binom{t-i}{t-\nu},



where W_{i}(C) and W_{i}(C^{\perp}) denote the number of codewords of Hamming weight i in C and C^{\perp}, respectively. This is precisely [5, eq. (M1) on page 257].






6 Linear MSRD Codes




In this section we investigate the structural properties of linear MSRD codes, i.e., the sum-rank metric codes that meet the Singleton Bound
of Theorem 3.2; see also Definition 3.3.
We first study duality of MSRD codes.
We show that if m_{1}=m_{2}=\cdots=m_{t}, the MSRD property is invariant under dualization, while this is not true for general
m_{1},\ldots,m_{t}.
Next, the duality result for the case m_{1}=m_{2}=\cdots=m_{t} allows us to explicitly determine the support distribution of MSRD codes
(and hence the rank-list and sum-rank distributions).
This in turn leads to necessary conditions for the existence of MSRD codes.
In some cases they turn out to be more powerful than the bounds of Section 3.
Finally, we provide an upper bound on the length t of an MSRD code for the case where n_{1}=\ldots=n_{t} and m_{1}=\ldots=m_{t}, improving on Corollary 3.9 for certain classes of parameters.
We close the section with discussing puncturing and shortening of MSRD codes.
We will see that doing so in a suitable way results in an MSRD code again.




We start with the invariance of the MSRD property under dualization for the case where m_{1}=\ldots=m_{t}.
For \mathbb{F}_{q^{m}}-linear MSRD codes (see Remark 2.2) this result has been derived earlier in [12, Thm. 5].
Recall the notation C^{\perp} and {\bm{U}}^{\perp} from Definition 5.1 and \textnormal{srk}(C) from Definition 2.1.



Theorem 6.1.



Suppose m_{1}=\cdots=m_{t}=m. If C\leq\Pi is MSRD, then
C^{\perp} is
MSRD as well. Moreover, if C is a non-trivial MSRD code, then
\textnormal{srk}(C^{\perp})=N-\textnormal{srk}(C)+2.




Proof.



The result is immediate if C is trivial.
We henceforth assume that C is MSRD with sum-rank distance d\geq 2, and hence has
dimension m(N-d+1).
We show that C^{\perp} is MSRD of minimum distance N-d+2. Observe that \dim(C^{\perp})=mN-\dim(C)=m(d-1). By Theorem 3.2 we then have
m(d-1)\leq m(N-d^{\perp}+1), where d^{\perp} is the minimum distance of C^{\perp}.
In particular, d^{\perp}\leq N-d+2. Therefore it suffices to show that d^{\perp}\geq N-d+2.
We will use the criterion in Proposition 2.7 and the notation from Definition 2.3.
Let \bm{U}\in\mathcal{L} be arbitrary with
\textnormal{rk}_{\mathcal{L}}(\bm{U})=N-d+1. Then \textnormal{rk}_{\mathcal{L}}({\bm{U}}^{\perp})=d-1 and thus
|\mathcal{C}(\bm{U}^{\perp})|=1.
By Proposition 5.3 we have




1=|C(\bm{U}^{\perp})|=\frac{|C|}{q^{m(N-d+1)}}|C^{\perp}(\bm{U})|=|C^{\perp}(\bm{U})|.



Since \bm{U} was arbitrary with \textnormal{rk}_{\mathcal{L}}(U)=N-d+1, Proposition 2.7 implies d^{\perp}\geq N-d+2
as desired.
∎





If m_{i}\neq m_{j} for some i,j with i\neq j, Theorem 6.1 is false in general,
as the following example shows.



Example 6.2.



Let \Pi=\Pi_{q}(n\times n\mid 1\times 1), where n\geq 2 and d=2.
Then the Singleton Bound in Theorem 3.2 is n^{2}-n+1.
An MSRD code can be constructed as follows.
Let C_{1}\leq\mathbb{F}^{n\times n} be an MRD code with rank distance 2, and let Z\in\mathbb{F}_{q}^{n\times n} be a matrix of rank 1.
Set




C=\{(A,\,0)\mid A\in C_{1}\}+\{\lambda(Z,\,1)\mid\lambda\in\mathbb{F}_{q}\}.



Then \textnormal{srk}(C)\geq 2 thanks to \textnormal{rk}(A+\lambda Z)\geq 1 for all A\in C_{1} and \lambda\in\mathbb{F}_{q}^{*}.
Since \dim(C)=n(n-1)+1, the code C is MSRD.
The dual code is given by




C^{\perp}=\{(B,-\mbox{$\langle{B,Z}\rangle$})\mid B\in C_{1}^{\perp}\}.



Indeed, the right hand side is clearly contained in C^{\perp} and has dimension equal to \dim(C_{1}^{\perp})=n=\dim(\Pi)-\dim(C).
In order to determine \textnormal{srk}(C^{\perp}), consider the map C_{1}^{\perp}\longrightarrow\mathbb{F}_{q},\ B\longmapsto\mbox{$\langle{B,Z}\rangle$}.
It is linear, surjective (because Z\not\in C_{1}) and thus has an (n-1)-dimensional kernel. This shows that the sum-rank distance of C^{\perp} equals the rank distance of C_{1}^{\perp}, which is n.
But for that distance, the Singleton Bound in Theorem 3.2 is n+1, and thus C^{\perp} is not MSRD.





Let us return to the case where m_{1}=\cdots=m_{t}.
Theorem 6.1 allows us to give a closed formula for the support distribution of any MSRD code.
We need the following simple lemma.
Recall the lattice \mathcal{L} and the accompanying notation from Definition 2.3.



Corollary 6.3.



Suppose m_{1}=\cdots=m_{t}=m. Let C\leq\Pi be a non-zero MSRD code of minimum distance d. For all
\bm{U}\in\mathcal{L} with \textnormal{rk}_{\mathcal{L}}(\bm{U})=u we have




|C(\bm{U})|=\left\{\begin{array}[]{ll}1&\mbox{if $u<d$,}\\
q^{m(u-d+1)}&\mbox{otherwise.}\end{array}\right.






Proof.



The statement is clear for u<d. Thus let u\geq d.
Then \textnormal{rk}_{\mathcal{L}}(\bm{U}^{\perp})=N-u\leq N-d while \textnormal{srk}(C^{\perp})=N-d+2 thanks to Theorem 6.1.
Hence |C^{\perp}(U^{\perp})|=1, and the result follows from Proposition 5.3.
∎





In order to determine the support distribution, we introduce the following notation.
Recall the partial order on \mathbb{N}_{0}^{t} in (5.1).



Notation 6.4.



Let \ell\in\mathbb{N}_{0} and \bm{U}\in\mathcal{L}. We define




f_{\ell}(\bm{u})=\sum_{\begin{subarray}{c}\bm{v}\leq\bm{u}\\
|\bm{v}|=\ell\end{subarray}}\prod_{i=1}^{t}(-1)^{u_{i}-v_{i}}q^{\binom{u_{i}-v_{i}}{2}}\left[\begin{matrix}u_{i}\\
v_{i}\end{matrix}\right]_{q}.







Then



(6.1)

f_{\ell}(\bm{u})=0\text{ if }\ell>|\bm{u}|,\quad f_{|\bm{u}|}(\bm{u})=1,\quad f_{|\bm{u}|-1}(\bm{u})=-\sum_{i=1}^{t}\genfrac{[}{]}{0.0pt}{0}{u_i}{1}_{q}=-\frac{\sum_{i=1}^{t}q^{u_{i}}-t}{q-1}.






Now we are ready to present the support distribution of an MSRD code (recall Definition 2.8).



Theorem 6.5.



Suppose m_{1}=\cdots=m_{t}=m.
Let C\leq\Pi be a non-zero MSRD code of minimum distance d, and let
\bm{U}\in\mathcal{L}\setminus 0 with \dim(\bm{U})=\bm{u}. Then




W_{\bm{U}}(C)=\sum_{\ell=d}^{|\bm{u}|}\big(q^{m(\ell-d+1)}-1\big)f_{\ell}(\bm{u}).



In particular, W_{\bm{U}}(C) only depends on \bm{u}=\dim(\bm{U}), but not on the subspace \bm{U} itself.




Proof.



Set \mathcal{V}_{\ell}(\bm{U})=\{\bm{V}\in\mathcal{L}\mid\bm{V}\leq\bm{U},\textnormal{rk}_{\mathcal{L}}(\bm{V})=\ell\}.
Applying Möbius inversion to (2.6) and using Corollary 6.3, we obtain




\displaystyle W_{\bm{U}}(C)
\displaystyle=
\displaystyle\sum_{\begin{subarray}{c}\bm{V}\in\mathcal{L}\\
\bm{V}\leq\bm{U}\end{subarray}}|C(\bm{V})|\,\mu_{\mathcal{L}}(\bm{V},\bm{U})




\displaystyle=
\displaystyle\sum_{\ell=0}^{d-1}\sum_{\bm{V}\in\mathcal{V}_{\ell}(U)}\mu_{\mathcal{L}}(\bm{V},\bm{U})\ +\sum_{\ell=d}^{|\bm{u}|}\sum_{\bm{V}\in\mathcal{V}_{\ell}(U)}q^{m(\ell-d+1)}\mu_{\mathcal{L}}(\bm{V},\bm{U})




\displaystyle=
\displaystyle\sum_{\ell=d}^{|\bm{u}|}\big(q^{m(\ell-d+1)}-1\big)\sum_{\bm{V}\in\mathcal{V}_{\ell}(\bm{U})}\mbox{$\mu_{\mathcal{L}}$}(\bm{V},\bm{U}),



where the last identity follows from \sum_{\bm{V}\leq\bm{U}}\mbox{$\mu_{\mathcal{L}}$}(\bm{V},\bm{U})=0 since \bm{U}\neq 0.
Finally, one easily observes that
\sum_{\bm{V}\in\mathcal{V}_{\ell}(\bm{U})}\mbox{$\mu_{\mathcal{L}}$}(\bm{V},\bm{U})=f_{\ell}(\bm{u}), and this proves the stated identity.
∎





We remark that examples show that Theorem 6.5 does not necessarily hold if we remove the constraint that the m_{i} are all equal.




Now we arrive at the following non-existence criterion for MSRD codes.
It is an immediate consequence of Theorem 6.5.



Corollary 6.6.



Consider the space \Pi=\Pi(n_{1}\times m\mid\cdots\mid n_{t}\times m) and define the index set
\mathcal{I}_{(n_{1},\ldots,n_{t})}=\{(u_{1},\ldots,u_{t})\in\mathbb{N}_{0}^{t}\mid u_{i}\leq n_{i}\text{ for all }i\in[t]\}.
Suppose there exists an MSRD code C\leq\Pi of sum- rank distance d.
Then



(6.2)

\omega(\bm{u}):=\sum_{\ell=d}^{|\bm{u}|}(q^{m(\ell-d+1)}-1)f_{\ell}(\bm{u})\geq 0\ \text{ for all }\bm{u}\in\mathcal{I}_{(n_{1},\ldots,n_{t})}\setminus\{(0,\ldots,0)\}.







This criterion is indeed quite powerful.



Example 6.7.



Consider \Pi=\Pi_{3}(3\times 3\mid 3\times 3\mid 2\times 3) and d=7.
Then the linear version of the Singleton Bound provides a strictly smaller value than all other bounds.
In other words, no known bound excludes the existence of an MSRD code.
However, applying the above non-existence criterion
leads to \omega(3,3,2)=-52, and thus an MSRD code does not exist.
This example shows that MSRD codes of length t=q do not exist in general, not even for fixed column size.
On the other hand, for certain parameters such codes do exist,
as Example 3.16 has shown.
In this context we also wish to remind of [11, Thm. 4] where it has been shown that (even \mathbb{F}_{q^{m}}-linear) MSRD codes always
exist for length t up to q-1.





It is a simple consequence of (6.1) that \omega(\bm{u})=0 if |\bm{u}|<d and
\omega(\bm{u})=q^{m}-1 if |\bm{u}|=d+1.
Hence it suffices to consider |\bm{u}|\geq d+1.
The criterion is obviously conclusive only in the case where \omega(\bm{u})<0 for some \bm{u}\in\mathcal{I}_{(n_{1},\ldots,n_{t})},
but such a \bm{u} may be hard to find within the, generally large, set \mathcal{I}_{(n_{1},\ldots,n_{t})}, even with the restriction
|\bm{u}|\geq d+1.
However, an abundance of examples leads us to the following conjecture.
It tells us that the tests in (6.2) can be replaced by a single test.



Conjecture 6.8.



Let (n_{1},\ldots,n_{t})\in\mathbb{N}_{0}^{t} and, without loss of generality, n_{1}\geq\ldots\geq n_{t}.
Fix d<N and let s\in[t] and \delta\in[n_{s+1}-1] be such that
\tilde{\bm{u}}:=(n_{1},\ldots,n_{s},\delta,0,\ldots,0)\in\mathcal{I}_{(n_{1},\ldots,n_{t})} satisfies |\tilde{\bm{u}}|=d+1.
In other words, \tilde{\bm{u}} is the minimum in \mathcal{I}_{(n_{1},\ldots,n_{t})}
with respect to the graded reverse lexicographic order and such that |\tilde{\bm{u}}|\geq d+1.
Then \omega(\tilde{\bm{u}})=q^{2m}-1-(q^{m}-1)/(q-1)\big(\sum_{i=1}^{t}q^{\tilde{u}_{i}}-t\big) and the conjecture is




\omega(\tilde{\bm{u}})\geq 0\Longrightarrow\omega(\bm{u})\geq 0\text{ for all }\bm{u}\in\mathcal{I}_{(n_{1},\ldots,n_{t})}.



This tells us that the much faster test \omega(\tilde{\bm{u}})\geq 0 appears to be as strong as the laborious test in Corollary 6.6.




Example 6.9.



Let \mathbb{F}=\mathbb{F}_{2} and \Pi=\Pi_{2}(n\times n\mid n\times n). Then there exists no MSRD code of distance
d=n+1. Indeed, in this case \tilde{\bm{u}}=(n,2) and \omega(\tilde{\bm{u}})=1-2^{n}.





Let us return to Corollary 6.6.
Applying the same line of reasoning to the dual code, which is also MSRD by
Theorem 6.1, we obtain an additional non-existence criterion for MSRD codes.



Corollary 6.10.



Consider \Pi=\Pi(n_{1}\times m\mid\cdots\mid n_{t}\times m) and let N=\sum_{i=1}^{t}n_{i}.
Suppose there exists an MSRD code C\leq\Pi of minimum distance d.
Then



(6.3)

\hat{\omega}(\bm{u}):=\sum_{\ell=N-d+2}^{|\bm{u}|}(q^{m(\ell-N+d-1)}-1)f_{\ell}(\bm{u})\geq 0\text{ for all }\bm{u}\in\mathcal{I}_{(n_{1},\ldots,n_{t})}\setminus\{(0,\ldots,0)\}.







The same comment as in Conjecture 6.8 applies: assuming n_{1}\geq\ldots\geq n_{t} we believe that
it suffices to test \hat{\omega}(\tilde{\bm{v}})\geq 0 for \tilde{\bm{v}}=(n_{1},\ldots,n_{s^{\prime}},\delta^{\prime},0,\ldots,0) where
|\tilde{\bm{v}}|=N-d+3.
It is not hard to find examples where one of Corollary 6.6 and Corollary 6.10
excludes an MSRD code, but not the other one.



Remark 6.11.



The above results lead immediately to explicit formulas for the sum-rank distribution
and the rank-list distribution; see Definition 2.8.
Indeed, W_{r}(C)=\sum_{\bm{U}\in\mathcal{L},\,\textnormal{rk}_{\mathcal{L}}(\bm{U})=r}W_{\bm{U}}(C) for any r\in\mathbb{N}_{0} and W_{\bm{u}}(C)=\sum_{\bm{U}\in\mathcal{L},\,\dim(\bm{U})=\bm{u}}W_{\bm{U}}(C) for any \bm{u}\in\mathbb{N}_{0}^{t}.
Thus, Theorem 6.5 generalizes accordingly.





We now turn to the length t of an MSRD code.
Recall that Corollary 3.9 gives an upper bound
for t that applies to an arbitrary sum-rank metric code.
In this section we restrict to MSRD codes and obtain a much
stronger bound for the case where n_{1}=\ldots=n_{t} and m_{1}=\ldots=m_{t}.
The proof uses the projective sphere-packing bound of Theorem 3.7.



Theorem 6.12.



Suppose n=n_{1}=\cdots=n_{t} and m=m_{1}=\cdots=m_{t}, and suppose there exists an MSRD code C\leq\Pi
of minimum distance d\geq 3. Then




t\leq\Big\lfloor\frac{d-3}{n}\Big\rfloor+\Big\lfloor\frac{q^{n}-q^{n\lfloor(d-3)/n\rfloor+n-d+3}+(q-1)(q^{m}+1)}{q^{n}-1}\Big\rfloor\leq\Big\lfloor\frac{d-3}{n}\Big\rfloor+1+\Big\lfloor\frac{q^{m}(q-1)}{q^{n}-1}\Big\rfloor.



In particular, we have the following cases.


(a)  



If n\mid(d-3), then




t\leq\frac{d-3}{n}+\Big\lfloor\frac{(q-1)(q^{m}+1)}{q^{n}-1}\Big\rfloor.




(b)  



If d\leq n+2, then




t\leq\Big\lfloor\frac{q^{n}-q^{n-d+3}+(q-1)(q^{m}+1)}{q^{n}-1}\Big\rfloor\leq 1+\Big\lfloor\frac{q^{m}(q-1)}{q^{n}-1}\Big\rfloor.



If in addition n=m, then this implies t\leq(q^{n+1}-1)/(q^{n}-1)\leq q+1 and even t\leq q if n=m\geq 2.






Proof.



We apply the projective sphere-packing bound of Theorem 3.7.
Write d-3=\ell n+\delta with 0\leq\delta<n.
Thus \ell=\lfloor(d-3)/n\rfloor and t^{\prime}=t-\ell.
Moreover,
n_{1}^{\prime}=n-\delta,\,m_{1}^{\prime}=m, and (n_{i}^{\prime},m_{i}^{\prime})=(n,m) for 2\leq i\leq t^{\prime}.
Since C is MSRD, the Singleton Bound (Theorem 3.2) tells us that |C|=q^{m(tn-d+1)}.
Therefore Theorem 3.7 reads as




q^{m(tn-d+1)}\Big(1+\frac{q^{m}-1}{q-1}\big((t^{\prime}-1)(q^{n}-1)+q^{n-\delta}-1\big)\Big)\leq q^{m(tn-d+3)},



which in turn is equivalent to




t\leq\frac{(q-1)(q^{m}+1)-q^{n-\delta}+1}{q^{n}-1}+\ell+1=\ell+\frac{(q-1)(q^{m}+1)+q^{n}-q^{n-\delta}}{q^{n}-1}



Using \ell=\lfloor(d-3)/n\rfloor and \delta=d-3-\ell n, we arrive at the first inequality.
The second one follows from n-\delta\geq 1, hence q^{n}-q^{n-\delta}\leq q^{n}-q.
The special cases follow easily from the first inequality.
∎




Remark 6.13.



Suppose n=n_{1}=\cdots=n_{t} and m=m_{1}=\cdots=m_{t}, as in Theorem 6.12.


(a)  



For n=m=1, the upper bound in Theorem 6.12 reads as t\leq q+d-2, which is a well-known
upper bound on the length of an MDS code C\leq\mathbb{F}_{q}^{t} of minimum distance d\geq 3; see e.g. [5, Cor. 7.4.3(ii)].
For n=1<m this generalizes to t\leq q^{m}+d-2 by Part (a) above.
As we will spell out in Example 7.1, it is a consequence of the MDS conjecture that actually t\leq q^{m}+1.


(b)  



The MDS conjecture states that N\leq q^{m}+1 for an \mathbb{F}_{q^{m}}-linear MDS code in \mathbb{F}_{q^{m}}^{N} of minimum distance d
(minus some exceptional cases); see  [5, p. 265].
For an MSRD code this results in t\leq(q^{m}+1)/n.
It is straightforward to show that the first bound in Theorem 6.12 yields a tighter bound for t
if d\leq q^{m}\big(1-n(q-1)/(q^{n}-1)\big)+4-n.
In the special case where n=m and d\leq n+2, Theorem 6.12(b) even provides the much better estimate t\leq q+1.







For relatively small length, MSRD codes do exist for large classes of parameters.
In [11, Thm. 4] a construction of \mathbb{F}_{q^{m}}-linear MSRD codes in \mathbb{F}_{q^{m}}^{N} is given for the case where
m:=m_{1}=\ldots=m_{t} and where the length satisfies t\leq q-1 (and thus N\leq q^{m}+1, in accordance with the MDS conjecture).
Example 6.9 shows that for t=q MSRD codes may not exist.
On the other hand, in Examples 3.15 and 3.16 we have seen examples of MSRD codes with t>q;
even for the case where m_{1}=\cdots=m_{t}.
In the next section we present a few more classes of MSRD codes.




We close this section with a discussion of specific shortening and puncturing of MSRD codes.
A few details are needed in order to specify where to puncture or shorten.
We set up the following notation.




Let \Pi be as in (2.1) and (2.2) and let C\leq\Pi be a linear MSRD code of sum-rank distance d.
As in Theorem 3.2 let



(6.4)

j\in[t] and \delta\in\{0,\ldots,n_{j}-1\} be the unique integers such that d-1=\sum_{i=1}^{j-1}n_{i}+\delta.



Set



(6.5)

n_{i}^{\prime}=\begin{cases}n_{i},&\text{if }i\neq j,\\
n_{j}-\delta,&\text{if }i=j,\end{cases}



and define the space \Pi^{\prime}=\Pi(n_{j}^{\prime}\times m_{j}\mid\cdots\mid n_{t}^{\prime}\times m_{t}).
Thanks to the Singleton Bound we have \dim(C)=\sum_{i=j}^{t}n_{i}^{\prime}m_{i} and
the map




\tau:C\longrightarrow\Pi^{\prime},\quad(X_{1},\ldots,X_{t})\longmapsto(\hat{X}_{j},X_{j+1},\ldots,X_{t})\quad\left\{\begin{array}[]{l}\text{where $\hat{X}_{j}\in\mathbb{F}^{(n_{j}-\delta)\times m_{j}}$ consists}\\
\text{of the first $n_{j}-\delta$ rows of~$X_{j}$.}\end{array}\right.



is an isomorphism.
Indeed, \tau is injective by (6.4) and thus bijective since \dim(C)=\dim(\Pi^{\prime}).
As a consequence, C has a basis of the form




\{B_{a,b}^{(j)}\mid a=1,\ldots,n_{j}-\delta,\,b=1,\ldots,m_{j}\}\cup\{B_{a,b}^{(i)}\mid i=j+1,\ldots,t,\,a=1,\ldots,n_{i},\,b=1,\ldots,m_{i}\}



where



(6.6)

\left.\begin{array}[]{ccll}B_{a,b}^{(j)}&\!\!=&\Big(\ \ast,\ \ldots,\ast,\mbox{\small{$\begin{pmatrix}{\!E_{a,b}^{(j)}\!}\\
{\ast}\end{pmatrix}$}},\quad 0,\ \ldots\ldots,\,0,\ 0\ \Big)&\text{for }a\in[n_{j}^{\prime}],\,b\in[m_{j}],\\[8.61108pt]
B_{a,b}^{(j+1)}&\!\!=&\Big(\ \ast,\ \ldots,\ast,\mbox{\small{$\begin{pmatrix}{\ 0\ }\\
{\ast}\end{pmatrix}$}},\ E_{a,b}^{(j+1)},\ \ldots,\,0,\ 0\ \Big)&\text{for }a\in[n_{j+1}^{\prime}],\,b\in[m_{j+1}],\\
\vdots&&\qquad\vdots\\
B_{a,b}^{(t)}&\!\!=&\Big(\underbrace{\ast,\ \ldots,\ \ast}_{j-1\text{ blocks}},\mbox{\small{$\begin{pmatrix}{\ 0\ }\\
{\ast}\end{pmatrix}$}},\quad 0,\ \ldots\ldots,\,0,E_{a,b}^{(t)}\Big)&\text{for }a\in[n_{t}^{\prime}],\,b\in[m_{t}],\end{array}\ \right\}



where E_{a,b}^{(i)} denote the standard basis matrices in \mathbb{F}^{n_{i}^{\prime}\times m_{i}} and \ast denote suitable matrices in the respective matrix space.
We define index sets




\displaystyle\textnormal{tail}(C)
\displaystyle=\{(i,a,b)\mid i=j,\ldots,t,\,a\in[n_{i}^{\prime}],\,b\in[m_{i}]\},



\displaystyle\textnormal{head}(C)
\displaystyle=\{(i,a,b)\mid i\in[j-1],\,a\in[n_{i}^{\prime}],\,b\in[m_{i}]\}\cup\{(j,a,b)\mid a=n_{j}^{\prime}+1,\ldots,n_{j},\,b\in[m_{j}]\}.






Note that |\textnormal{tail}(C)|=\dim(C).
Furthermore, the above means that \textnormal{tail}(C) forms an information set for C in the usual sense.
Note that the MSRD codes in Examples 3.15 and 3.16 are given in form of a basis as in (6.6); in both cases \delta=0.




The above provides us with many options to shorten an MSRD code without compromising the MSRD property.
It should be noted that the shortening in (a) below is a special case of shortening as introduced in
Definition 2.5 – up to isomorphism (which consists of the actual deletion of a row).
On the other hand, shortening on a column as considered in (b) is not an instance of Definition 2.5.



Theorem 6.14 (Shortening an MSRD Code on a Row or Column).



Suppose there exists a linear MSRD code C\leq\Pi of sum-rank distance d and with data as
in (6.4) – (6.6).


(a)  



Choose s\in\{j,\ldots,t\} and set




\tilde{n}_{i}=\begin{cases}n_{i},&\text{if }i\neq s,\\
n_{s}-1,&\text{if }i=s.\end{cases}



Then there exists an MSRD code in \tilde{\Pi}:=\Pi(\tilde{n}_{1}\times m_{1}\mid\cdots\mid\tilde{n}_{t}\times m_{t}) with sum-rank distance d.
It is obtained by shortening C on a row with indices in the tail of C.


(b)  



Choose s\in\{j+1,\ldots,t\} and set




\tilde{m}_{i}=\begin{cases}m_{i},&\text{if }i\neq s,\\
m_{s}-1,&\text{if }i=s.\end{cases}



Then there exists an MSRD code in \tilde{\Pi}:=\Pi(n_{1}\times\tilde{m}_{1}\mid\cdots\mid n_{t}\times\tilde{m}_{t}) with sum-rank distance d.
It is obtained by shortening C on a column with indices in the tail of C, but not in the j-th block.






Proof.



(a) Choose any a\in[n_{s}^{\prime}], where n_{i}^{\prime} is as in (6.5).
Consider the basis B from (6.6) and set




B^{\prime}=B\setminus\{B_{a,b}^{(s)}\mid b=1,\ldots,m_{s}\}.



Let C^{\prime}=\mbox{$\langle{B^{\prime}}\rangle$}.
Then clearly \textnormal{srk}(C^{\prime})\geq\textnormal{srk}(C) and \dim(C^{\prime})=\dim(C)-m_{s}=\sum_{i=j}^{t}\tilde{n}_{i}m_{i}-m_{j}\delta.
Since all matrix tuples in C^{\prime} have a zero row in the s-th block at position a, deleting that row
results in a code \tilde{C} in \tilde{\Pi} of the same sum-rank distance and dimension as C^{\prime}.
Since d-1=\sum_{i=1}^{j-1}\tilde{n}_{i}+\delta, the code \tilde{C} is MSRD.

(b) Choose any b\in[m_{s}] and set
B^{\prime}=B\setminus\{B_{a,b}^{(s)}\mid a=1,\ldots,n_{s}\}.
Let C^{\prime}=\mbox{$\langle{B^{\prime}}\rangle$}.
Then clearly \textnormal{srk}(C^{\prime})\geq\textnormal{srk}(C) and \dim(C^{\prime})=\dim(C)-n_{s}=\sum_{i=j}^{t}n_{i}\tilde{m}_{i}-m_{j}\delta.
Deleting column b in the s-th block results in
an MSRD code \tilde{C} in \tilde{\Pi} of the same sum-rank distance and dimension as C^{\prime}.
∎





We now turn to puncturing. In this case only puncturing of rows leads to an MSRD code in general.



Theorem 6.15 (Puncturing an MSRD Code on a Row).



Suppose there exists a linear MSRD code C\leq\Pi of sum-rank distance d and with data as
in (6.4) – (6.6).
If \delta>0 choose s\in[j] and if \delta=0 choose s\in[j-1]. Set




\tilde{n}_{i}=\begin{cases}n_{i},&\text{if }i\neq s,\\
n_{s}-1,&\text{if }i=s.\end{cases}



Then there exists an MSRD code in \tilde{\Pi}:=\Pi(\tilde{n}_{1}\times m_{1}\mid\cdots\mid\tilde{n}_{t}\times m_{t}) with sum-rank distance d-1.
It is obtained by puncturing C on a row with indices in the head of C.




Proof.



Consider the map
\pi:C\longrightarrow\Pi,\ (X_{1},\ldots,X_{t})\longmapsto(X_{1},\ldots,\hat{X}_{s},\ldots,X_{t}),
where \hat{X}_{s}\in\mathbb{F}^{(n_{s}-1)\times m_{s}} is obtained from X_{s} be removing the last row.
Note that if s=j, then \delta>0 and therefore this last row belongs to the head of C.
Since \textnormal{srk}(C)\geq 2, the map \pi is injective.
Set C^{\prime}=\pi(C). Then \textnormal{srk}(C^{\prime})\geq d-1.
If s<j, we have




d-2=\sum_{i=1}^{j-1}n_{i}+\delta-1=\sum_{i=1}^{j-1}\tilde{n}_{i}+\delta\ \text{ and }\ \dim(C^{\prime})=\dim(C)=\sum_{i=j}^{t}\tilde{n}_{i}m_{i}-m_{j}\delta,



and thus C^{\prime} is MSRD.
For s=j we have \delta>0 and with \delta^{\prime}=\delta-1 we obtain




d-2=\sum_{i=1}^{j-1}n_{i}+\delta^{\prime}\ \text{ and }\ \dim(C^{\prime})=\dim(C)=\sum_{i=j}^{t}n_{i}m_{i}-m_{j}\delta=\sum_{i=j}^{t}\tilde{n}_{i}m_{i}-\delta^{\prime}m_{j},



and again C^{\prime} is MSRD.
∎




Remark 6.16.



Let us briefly consider the situation where m_{1}=\ldots=m_{t}=:m.
In this case we may consider (6.4) for any ordering of the blocks.
This implies that shortening on a row as in Theorem 6.14 and puncturing as in
Theorem 6.15 can be applied to any row in \Pi and always leads to an MSRD code.
This agrees with [12, Cor. 7], where shortening and puncturing (called restriction) are
defined more generally, but only applied to \mathbb{F}_{q^{m}}-linear codes.






7 Constructions of Optimal Codes




In this section we concentrate on constructions of optimal codes. The main focus is
on MSRD codes, which we construct in various ad-hoc ways for several parameter sets.
Note that while a general construction of (even \mathbb{F}_{q^{m}}-linear) MSRD codes exists for t\leq q-1
if m:=m_{1}=...=m_{t}, see [11, Thm. 4], some of our constructions
provide examples of significantly longer MSRD codes if we allow the blocks to have variable number of columns.
Our constructions show that for sum-rank distance equal to 2 or N, MSRD codes exist for all parameters while this is not true for other distances.
Thereafter we will establish the existence of MSRD codes for certain other sum-rank distances in the case that there are
sufficiently many 1\times 1-blocks involved.




We conclude the section with presenting a lifting construction that produces a sum-rank metric code
by combining a Hamming-metric and a rank-metric code.
As an application, we obtain a family of codes that meet the Induced Plotkin Bound of Theorem 3.1.




7.1 MSRD Codes




We start with the following simple example showing that MSRD codes of length t\leq q^{m}+1 in
\Pi_{q}(1\times m\mid\cdots\mid 1\times m) exist for all distances d\leq t.
They are, up to an isomorphism \mathbb{F}_{q^{m}}\cong\mathbb{F}_{q}^{1\times m}, simply the \mathbb{F}_{q}-linear MDS codes in \mathbb{F}_{q^{m}}^{t}.



Construction 7.1.



Fix a field \mathbb{F}_{q} and consider \Pi=\Pi_{q}(1\times m\mid\cdots\mid 1\times m) with t blocks.
Let d\leq t. If t\leq q^{m}+1, there exists an (\mathbb{F}_{q^{m}}-linear) MDS code C\leq\mathbb{F}_{q^{m}}^{t} of Hamming distance d.
Thus \dim_{\mathbb{F}_{q}}(C)=m(t-d+1).
Let \phi:\mathbb{F}_{q^{m}}\longrightarrow\mathbb{F}_{q}^{1\times m} be an \mathbb{F}_{q}-isomorphism and extend it entrywise to an isomorphism
\phi:\mathbb{F}_{q^{m}}^{t}\longrightarrow\Pi.
Then the sum-rank metric code \tilde{C}=\phi(C)\leq\Pi is MSRD with sum-rank distance d.
Since conversely every linear MSRD code in \Pi induces an \mathbb{F}_{q}-linear MDS code in \mathbb{F}_{q^{m}}^{t}, the MDS conjecture (for nonlinear codes) implies that such an MSRD code with distance not in \{1,2,t\} exists iff t\leq q^{m}+1.





The next example shows that MSRD codes with sum-rank distance d=2 exist for all parameters.
We proceed in two steps.
The construction makes use of MRD codes in the rank metric; see [1, 3, 20] among many others.
Recall that for n\leq m an [n\times m;d]_{q}-MRD code is a linear rank-metric code in \mathbb{F}_{q}^{n\times m} of rank
distance d and dimension m(n-d+1). If possible we skip the subscript q.



Construction 7.2.




(a)  



Let \Pi=\Pi(n_{1}\times m\mid\cdots\mid n_{t}\times m). Without loss of generality let n_{1}\geq\ldots\geq n_{t}.
We will construct MSRD codes with distance d=2.
Let \hat{C} be an [n_{1}\times m;2]-MRD code, thus \dim(\hat{C})=m(n_{1}-1).
Consider the map \phi_{i}:\mathbb{F}_{q}^{n_{i}\times m}\longrightarrow\mathbb{F}_{q}^{n_{1}\times m} defined by adding n_{1}-n_{i} zero
rows to the given matrix. Then \phi_{i} is rank-preserving and linear.
Define the sum-rank metric code




C=\Big\{\Big(A-\sum_{i=2}^{t}\phi_{i}(A_{i}),A_{2},\ldots,A_{t}\Big)\,\Big|\,A_{i}\in\mathbb{F}_{q}^{n_{i}\times m},A\in\hat{C}\Big\}.



Then \dim(C)=m\sum_{i=2}^{t}n_{i}+m(n_{1}-1)=m(N-1), which is the Singleton bound (Theorem 3.2) for distance 2.
It remains to see that \textnormal{srk}(A-\sum_{i=2}^{t}\phi_{i}(A_{i}),A_{2},\ldots,A_{t},)\geq 2 for all nonzero elements in C.
This is clear if either \textnormal{srk}(A_{2},\ldots,A_{t})\geq 2 or if (A_{2},\ldots,A_{t})=0.
Thus let \textnormal{srk}(A_{2},\ldots,A_{t})=1. That means \textnormal{rk}(A_{\ell})=1 for some \ell and A_{i}=0 for i\neq\ell.
In this case A-\sum_{i=2}^{t}\phi_{i}(A_{i})=A-\phi_{\ell}(A_{\ell}), and this matrix is not zero because \textnormal{rk}(A)\neq 1.
All of this shows that C is an MSRD code with distance 2.
The dual code is given by C^{\perp}=\{(B,\psi_{2}(B),\ldots,\psi_{t}(B))\mid B\in\hat{C}^{\perp}\}, where
\psi_{i}:\mathbb{F}^{n_{1}\times m}\longrightarrow\mathbb{F}^{n_{i}\times m} is the projection onto the first n_{i} rows.
This follows from the simple identity \mbox{$\langle{\psi_{i}(B),A_{i}}\rangle$}=\mbox{$\langle{B,\phi_{i}(A_{i})}\rangle$} along with \dim(C^{\perp})=m=\dim\hat{C}^{\perp}.
Using that \hat{C}^{\perp} has rank distance n_{1}, we conclude that C^{\perp} has sum-rank distance N and thus is MSRD,
in agreement with Theorem 6.1.
If n_{i}=n_{1} for all i, then C^{\perp} is just the repetition code \{(B,\ldots,B)\mid B\in\hat{C}^{\perp}\}.


(b)  



The previous construction can be generalized to arbitrary ambient spaces. Let \Pi be as in(2.1)– (2.2).
Define \hat{\Pi}=\Pi(n_{1}\times m_{1}\mid\cdots\mid n_{t}\times m_{1}) and identify \Pi with the subspace of \hat{\Pi} consisting of the
matrix tuples for which the last m_{1}-m_{i} columns in the ith block are zero for all i\in[t].
By (a) there exists an MSRD code \hat{C}\leq\hat{\Pi} with distance d=2.
Hence \dim(\hat{C})=m_{1}(N-1).
Note that the projection
\rho:\hat{C}\longrightarrow\Pi_{q}\big((n_{1}-1)\times m_{1}\mid n_{2}\times m_{1}\mid\cdots\mid n_{t}\times m_{1}\big),
obtained by deleting the first row in the first block is an isomorphism because \textnormal{srk}(\hat{C})>1.
Consider now C:=\hat{C}\cap\Pi. Clearly \textnormal{srk}(C)\geq 2.
In order to determine its dimension, consider the map




\tau:\hat{C}\longrightarrow\Pi_{q}\big(n_{2}\times(m_{1}-m_{2})\mid\cdots\mid n_{t}\times(m_{1}-m_{t})\big),



where we project onto the last m_{1}-m_{i} columns of each matrix.
Then clearly \ker(\tau)=C and the surjectivity of \rho implies the surjectivity of \tau.
This implies \dim(C)=\sum_{i=2}^{t}m_{i}n_{i}+m_{1}(n_{1}-1), which is the Singleton Bound in Theorem 3.2 for d=2.







We now turn to the other extreme and consider distance d=N and d=N-1.
As we will show, MSRD codes with sum-rank distance d=N exist for all parameters, while for d=N-1 this is not the case.



Construction 7.3.




(a)  



Consider \Pi as in (2.1)–(2.2). We show that there exists an MSRD code with sum-rank
distance N=\sum_{i=1}^{t}n_{i}.
For each i let C_{i} be an [n_{i}\times m_{i};n_{i}]_{q}-MRD code, thus \dim(C_{i})=m_{i}. Let
A_{i,1},\ldots,A_{i,m_{i}} be a basis of C_{i}.
Using that m_{t}\leq m_{i} for all i, we may construct the code




C=\big\langle(A_{1,1},\ldots,A_{t,1}),\ldots,(A_{1,m_{t}},\ldots,A_{t,m_{t}})\big\rangle.



Then clearly every nonzero element of C has sum-rank weight N and \dim(C)=m_{t}, which is the Singleton Bound for d=N;
see Theorem 3.2.
Thus, C is an MSRD code.


(b)  



In some cases the previous construction can be generalized to distance d=N-1.
For instance, suppose n_{t}\geq 2 and 2m_{t}\leq m_{t-1}.
For d=N-1 the Singleton Bound in Theorem 3.2 reads as \dim(C)\leq 2m_{t}.
Choose now [n_{i}\times m_{i};n_{i}]-MRD codes C_{i} for i=1,\ldots,t-1 and an [n_{t}\times m_{t};n_{t}-1]-MRD code C_{t}.
Then \dim(C_{i})=m_{i} for i=1,\ldots,t-1 and \dim(C_{t})=2m_{t}.
Now we can mimic the construction from (a) to obtain an MSRD code with distance N-1.
The construction generalizes further to distance d=N-\alpha, but needs the stronger assumptions n_{t}\geq\alpha+1
and (\alpha+1)m_{t}\leq m_{t-1}


(c)  



Let us consider again d=N-1 in (b). Then MSRD codes do not exist for all ambient spaces \Pi.
For instance, for m:=m_{1}=\ldots=m_{t} and n_{1}\geq\ldots\geq n_{t} one can apply Corollary 6.6 to rule
out, for many cases, the existence of an MSRD code with sum-rank distance d=N-1.
With the aid of (6.1) one obtains
\omega(\tilde{u})=q^{2m}-q^{m}\sum_{i=1}^{t}(q^{n_{i}}-1)/(q-1) for \tilde{u}=(n_{1},\ldots,n_{t}).
Thus, for instance, \omega(\tilde{u})<q^{2m}-q^{(n_{1}-1)m}, and hence \omega(\tilde{u})<0 whenever n_{1}\geq 3.







The above examples can be extended as follows.



Construction 7.4.



Let \mathbb{F}=\mathbb{F}_{q} and consider




\Pi=\Pi_{q}\big(n_{1}\times m_{1}\mid\cdots\mid n_{t_{1}}\times m_{t_{1}}\mid\underbrace{1\times 1\mid\cdots\mid 1\times 1}_{t_{2}\text{ blocks}}\big),



with the usual assumption m_{1}\geq\ldots\geq m_{t_{1}} and n_{j}\leq m_{j}.
Assume furthermore that t_{2}\geq m_{t_{1}}.
For each j\in[t_{1}] let C_{j} be an [n_{j}\times m_{j};n_{j}]_{q}-MRD code and let A_{j,1},\ldots,A_{j,m_{j}} be a basis of C_{j}.
Furthermore, let G=(g_{ij})\in\mathbb{F}^{m_{t_{1}}\times t_{2}} be the generator matrix of an MDS code.
Define the sum-rank metric code C\leq\Pi generated by




\big(A_{1,i},\ldots,A_{t_{1},i},(g_{i1}),\ldots,(g_{it_{2}})\big)\ \text{ for }i=1,\ldots,m_{t_{1}}.



Clearly \dim(C)=m_{t_{1}} and \textnormal{srk}(C)=\sum_{j=1}^{t_{1}}n_{j}+t_{2}-m_{t_{1}}+1.
Thus Theorem 3.2 implies that C is an MSRD.
If the MDS code is non-trivial, this construction requires t_{2}\leq q+1 (up to some exceptions in the MDS conjecture),
while the trivial MDS codes of length t_{2}=m_{t_{1}} or t_{2}=m_{t_{1}}+1 work for every field.
For instance, the 2-dimensional code




C=\big\langle\big((1,0),\ldots,(1,0),\,(1),\,(1),\,(0)\big),\ \big((0,1),\ldots,(0,1),\,(0),\,(1),\,(1)\big)\big\rangle



in \Pi(1\times 2\mid\cdots\mid 1\times 2\mid 1\times 1\mid 1\times 1\mid 1\times 1)
is MSRD with sum-rank distance t_{1}+2 and exists over any finite field \mathbb{F}.




Construction 7.5.



We can also combine the constructions of Examples 7.1 and 7.4:
Consider the data from Example 7.4 and assume m_{t_{1}} can be factored as m_{t_{1}}=\hat{m}a, where a\leq t_{2}.
Choose an MDS code in \mathbb{F}_{q^{\hat{m}}}^{t_{2}} of Hamming distance t_{2}-a+1.
Hence its \mathbb{F}_{q}-dimension is m_{t_{1}}.
Then combining Examples 7.1 and 7.4 we can construct a code
C\leq\bigoplus_{j=1}^{t_{1}}\mathbb{F}^{n_{j}\times m_{j}}\oplus\bigoplus_{j=1}^{t_{2}}\mathbb{F}^{1\times\hat{m}} of dimension m_{t_{1}} and sum-rank distance \sum_{j=1}^{t_{1}}n_{j}+t_{2}-a+1.
Again, the Singleton Bound shows that the code is MSRD.





In the special case where \mathbb{F}^{n_{j}\times m_{j}}=\mathbb{F}^{1\times m} for all j, Example 7.4 can be extended further into a different direction.



Construction 7.6.



Consider Example 7.4.
Set s=t_{1} and let n_{j}=1 for all j\in[s], m:=m_{1}=\ldots=m_{s}, and
t_{2}=m.
Hence \textnormal{srk}(C)=s+1.
We may choose the same [1\times m;1]_{q}-MRD codes \hat{C} for the components.
Let A_{1},\ldots,A_{m} be a basis of \hat{C} (e.g., the standard basis vectors).
Choosing G=I_{m} as a generator matrix of the trivial [m,m]-MDS code, the code C from Example 7.4 reads as




C=\Big\langle\big(\underbrace{A_{j},\ldots,A_{j}}_{s\text{ entries}},\,(0),\ldots,(0),(1),(0),\ldots,(0)\big)\,\Big|\,j\in[m]\Big\rangle\leq\bigoplus_{j=1}^{s}\mathbb{F}^{1\times m}\oplus\bigoplus_{j=1}^{m}\mathbb{F}^{1\times 1},



and where (1) is at the jth position.
Assume now s\leq m+\binom{m}{2}+1.
We will now extend C to an MSRD code \tilde{C}\leq\Pi^{\prime}:=\bigoplus_{j=1}^{s+1}\mathbb{F}^{1\times m}\oplus\bigoplus_{j=1}^{m+1}\mathbb{F}^{1\times 1}
of sum-rank distance s+2. It thus has dimension m+1.
If s>m, choose s-m-1 distinct 2-subsets \{\alpha_{k},\beta_{k}\} of [m].
This is possible thanks to s\leq m+\binom{m}{2}+1.
Set B_{k}=A_{\alpha_{k}}+A_{\beta_{k}} for k\in[s-m-1].
Then B_{1},\ldots,B_{s-m-1} are distinct.
Define




\displaystyle Z_{j}
\displaystyle=\big(A_{1},A_{j},\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots,A_{j}\,,\,(0),\ldots,(0),(1),(0),\ldots,(0),(0)\big)\ \text{ for }j\in[m],



\displaystyle Z_{m+1}
\displaystyle=\big(A_{2},A_{1},\ldots,A_{m},B_{1},B_{1},B_{2},\ldots,B_{s-m-1},(0),\ldots,(0),(0),(0),\ldots,(0),(1)\big),



where again (1) is at the jth position.
Note that in  Z_{m+1} the block (A_{1},\ldots,A_{m},B_{1},B_{1},B_{2},\ldots, B_{s-m-1}) is of length s.
If s\leq m, only the matrices A_{1},\ldots,A_{s} occur.
If s>m+1, then B_{1} occurs twice whereas all other B_{k} occur once.
Let \tilde{C}=\langle Z_{1},\ldots,Z_{m+1}\rangle. Then \tilde{C}\leq\Pi^{\prime} and \dim(\tilde{C})=m+1.
We show that \tilde{C} has sum-rank distance s+2.
This is clearly the case for the subcode \langle Z_{1},\ldots,Z_{m}\rangle.
Furthermore \textnormal{srk}(Z_{m+2})=s+2.
Hence it remains to consider an arbitrary linear combination X=Z_{m+1}+\sum_{j=1}^{m}x_{j}Z_{j}, where x_{j}\in\mathbb{F} are not all zero.
It is of the form




X=(X_{1},\ldots,X_{s+1},(x_{1}),\ldots,(x_{m}),(1)).



In the following we restrict ourselves to the case where s\geq m.
The other case is similar, and actually much simpler.
Note first that X_{1}\neq 0.
For the other components we consider the following cases.

Case 1: (B_{1},B_{1}) is eliminated by the linear combination \sum_{j=1}^{m}x_{j}Z_{j}.
In this case x_{j}\neq 0 for at least two values of j.
Furthermore, none of the entries A_{1},\ldots,A_{m} of Z_{m+1} is cancelled and likewise no B_{k},\,k>1, is cancelled.
All of this leads to \textnormal{srk}(X)\geq 1+m+(s-m-2)+3=s+2.

Case 2: There exists k>1 such that B_{k} is cancelled.
Again, x_{j}\neq 0 for at least two values of j and no A_{1},\ldots,A_{m} and likewise no B_{j},\,j\neq k, is cancelled.
Thus \textnormal{srk}(X)\geq 1+m+(s-m-1)+3=s+3.

Case 3: There exists j such that A_{j} is cancelled.
Then no B_{k} is cancelled and moreover x_{j}\neq 0. Thus \textnormal{srk}(X)\geq 1+(m-1)+(s-m)+2=s+2.

The case where no cancellation occurs is obvious.
We conclude that \tilde{C} has sum-rank distance s+2 and therefore is MSRD due to the Singleton Bound.
The code in Example 3.15 is a special instance of the above construction.






7.2 Lifting Construction




Finally, we present a construction of sum-rank metric codes that combines a Hamming-metric and a rank-metric code
with each other. We call this the lifting construction because the Hamming-metric code serves
to lift the rank-metric code to a sum-rank metric code.



Theorem 7.7 (Lifting Construction).



Consider \Pi as in (2.2), (2.1).
For i\in[t] choose integers \delta_{i}\in[n_{i}] and [n_{i}\times m_{i};\delta_{i}]_{q}-MRD codes \mathcal{C}_{i}.
Let h be an integer with 1\leq h\leq\min\{m_{i}(n_{i}-\delta_{i}+1)\mid i\in[t]\} and let
H\leq\mathbb{F}_{q^{h}}^{t} be a nonzero \mathbb{F}_{q}-linear code of minimum Hamming distance \Delta.
Fix \mathbb{F}_{q}-linear injections \varphi_{i}:\mathbb{F}_{q^{h}}\longrightarrow\mathcal{C}_{i}, i\in[t], and let




C:=\{(\varphi_{1}(\alpha_{1}),...,\varphi_{t}(\alpha_{t}))\mid(\alpha_{1},...,\alpha_{t})\in H\}.



Then C is a linear sum-rank metric code in \Pi with




\dim(C)=\dim_{\mathbb{F}_{q}}(H)\ \text{ and }\ \textnormal{srk}(C)\geq\min\Big\{\sum_{i\in I}\delta_{i}\,\Big|\,I\subseteq[t],\,|I|=\Delta\Big\}.






Proof.



The map H\longrightarrow C given by (\alpha_{1},...,\alpha_{t})\longmapsto(\varphi(\alpha_{1}),...,\varphi(\alpha_{t})) is \mathbb{F}_{q}-linear and injective, which shows that C
and H have the same dimension over \mathbb{F}_{q}.
Now fix a nonzero codeword (\varphi(\alpha_{1}),...,\varphi(\alpha_{t}))\in C. Since \varphi_{1},...,\varphi_{t} are injections,
we have either \textnormal{rk}(\varphi_{i}(\alpha_{i}))\geq\delta_{i} or \alpha_{i}=0.
Since C has minimum Hamming distance \Delta, this gives the desired lower bound
on \textnormal{srk}(C).
∎





Note that the construction of Theorem 7.7 generalizes Example 7.1.
Indeed, let m_{i}=m and n_{i}=\delta_{i}=1 for all i\in[t], and hence C_{i}=\mathbb{F}_{q}^{m} for i\in[t].
Then we may choose h=m so that H is an MDS code in \mathbb{F}_{q^{m}}^{t} with Hamming distance \Delta.
Then the above construction returns the MSRD code from Example 7.1.



Remark 7.8.



We can use Theorem 7.7 to construct sum-rank metric codes meeting the Induced Plotkin Bound of Theorem 3.1.
Let m_{i}=m and n_{i}=\delta_{i}=n for all i\in[t].
Let H\leq\mathbb{F}_{q^{m}}^{t} be an \mathbb{F}_{q}-linear code of minimum distance \Delta
meeting the Plotkin bound for the Hamming metric, i.e.,




q^{m}\Delta>(q^{m}-1)t\qquad\mbox{and}\qquad|H|=\Big\lfloor\frac{q^{m}\Delta}{q^{m}\Delta-(q^{m}-1)t}\Big\rfloor.



Choosing [n\times m;n]-MRD codes \mathcal{C}_{i} and injections \varphi_{i} as in Theorem 7.7
we obtain a code C\leq\Pi of cardinality |H| and sum-rank distance n\Delta.
Since q^{m}\Delta>(q^{m}-1)t, we have q^{m}n\Delta>(q^{m}-1)nt=(q^{m}-1)N.
Therefore the Induced Plotkin Bound from Theorem 3.1 reads as




|C|\leq\Big\lfloor\frac{q^{m}n\Delta}{q^{m}n\Delta-(q^{m}-1)N}\Big\rfloor=\Big\lfloor\frac{q^{m}\Delta}{q^{m}\Delta-(q^{m}-1)t}\Big\rfloor



and is met with equality.
We illustrate this more explicitly in the following example, where we lift the simplex code.




Example 7.9.



Let q=2, m=4 and n=3. Let r=3 and t=(16^{3}-1)/15=273.
Let H\leq\mathbb{F}_{16}^{273} be the simplex code of dimension r over \mathbb{F}_{16}.
The code is linear over \mathbb{F}_{16}, but we only need its linearity over \mathbb{F}_{2}.
The minimum distance of H is \Delta=16^{2}=256.
Therefore Theorem 7.7 gives us a code
C with sum-rank distance at least
256\cdot 3=768 (in fact, exactly 768).
The code meets the Induced Plotkin Bound with equality, as
|C|=|H|=16^{3}=\textnormal{4,096}=q^{m}\Delta/(q^{m}\Delta-(q^{m}-1)t).







Summary




We have investigated the fundamental properties of sum-rank metric codes with respect to
bounds, their asymptotic versions, duality, and existence/optimality.
In contrast to the previous literature, we consider codes with possibly variable block sizes, which therefore do not necessarily have a representation as a linear code over an extension field.




We have seen that the theory of sum-rank metric codes touches aspects of both rank-metric and Hamming-metric codes.
Our approach has led us to various new bounds for sum-rank metric codes.
In our asymptotic analysis of these bounds, we have considered the case that the number of blocks t goes to infinity and have observed
a behaviour that reverts to the case of all block lengths m_{i} being equal.




With respect to duality considerations, we have shown that MacWilliams identities hold for the support and rank-list distributions,
but not for the sum-rank distribution of a code: two codes with the same sum-rank distribution may have dual codes whose sum-rank distributions are different.




A substantial part of the paper is devoted to MSRD codes, the sum-rank analogues of MDS and MRD codes.
We have shown however, unlike their Hamming and rank-metric counterparts, that the MSRD property is not an invariant of
duality, except in the case that all blocks have the same number of columns.
In that case, we have derived an existence criterion for MSRD codes via duality considerations.
An interesting question on MSRD codes relates to the maximum number of blocks t that such a code can have.
In the instance that all block sizes are equal, we have derived an upper bound on this value.




Finally, we have provided some constructions of optimal codes for certain sets of parameters, illustrating the possible behaviours of these objects.




There are many aspects of sum-rank metric codes that are currently open for further research.
The most obvious of these are general constructions of families of optimal and extremal codes.
