                                                                                Abstract
                                           For a polynomial u = u(x) in Z[x] and r ∈ Z, we consider the orbit of u at r denoted
                                           and defined by Ou (r) := {u(r), u(u(r)), . . .}. We ask two questions here: (i) what
                                           are the polynomials u for which 0 ∈ Ou (r), and (ii) what are the polynomials for
                                           which 0 6∈ Ou (r) but, modulo every prime p, 0 ∈ Ou (r)? In this paper, we give a
                                           complete classification of the polynomials for which (ii) holds for a given r. We also
                                           present some results for some special values of r where (i) can be answered.

Reduction of polynomials.
Let r ∈ N and u = u(x) ∈ Z[x] such that r|u(0). Define v = v(x) := r1 u(rx).
Note that v is a polynomial over Z of the same degree as u and rv(1) = u(r).

at 1. Thus we can reduce any polynomial u(x) in Ldr,∅ with the extra condition that
r|u(0) to a polynomial v(x) in Ld1,P (r) . We will call this the reduction of u(x) to
v(x), where, of course, u and v are as above.

6. Some open problems

For u(x), a non-constant polynomial over Z, let

              N (u) := {r ∈ Z | u ∈ Nr }, LN (u) := {r ∈ Z | u ∈ Lr,∅ }.

Then one can look at the following questions:

 Q1. Describe all u′ s such that N (u) is finite.
INTEGERS: 23 (2023)                                                                             16

 Q2. Describe all u′ s such that LN (u) is finite.

 Q3. Given r ∈ Z, describe all u′ s such that r ∈ LN (u).

   Few words about the open problems. The methods used in the paper are
actually useful for linear polynomials and due to Fact 1.1 we were able to achieve
our goal by studying the linear polynomials only. It is clear that if u is assumed
to be linear, then N (u) is finite for every u except for the polynomials of the form
±x± c, c ∈ Z\ {0}. This answers Q1 for linear polynomials u(x). It should be noted
that LN (u) = N (u) ∪ {r ∈ Z | u ∈ Sr }. So for Q2, due to Fact 1.1 again, if the
degree of u is greater than or equal to 2 then LN (u) is finite so that N (u) is finite.
For linear polynomials of the form ±x± c, c ∈ Z\ {0}, N (u) is infinite and so LN (u)
                                                                           n
is infinite. If u = ax + b with a 6= 1, then we know that u(n) (r) = a (r−a−b)+b
                                                                              1−a      .
               b       k
Note that a+b−r = a , for some k ∈ Z can only be true for finitely many values
of r. So it follows from Lemma 3.2 that P \ ∪n∈N P ((r − a − b)an + b) is finite for
only finitely many values of r. Thus for these polynomials, LN (u) is indeed finite.
In this paper we have fully classified Sr , for every integer r. Also given an r, using
the linear iteration formula it should be easy enough to describe the linear u′ s such
that r ∈ N (u). So we have a partial answer for Q3 here. Thus if one knows enough
about the form of the nilpotent polynomials of degree higher than or equal to 2, one
should potentially be able to answer all of the questions above. This is a work in
progress and it is of course important enough to be considered as a separate work.
