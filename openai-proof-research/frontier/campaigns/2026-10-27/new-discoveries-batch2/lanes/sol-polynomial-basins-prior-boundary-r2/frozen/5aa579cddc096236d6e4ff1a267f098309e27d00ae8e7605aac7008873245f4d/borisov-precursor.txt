                                         SOME INTERESTING INTEGER POLYNOMIAL MAPS

                                                                   ALEXANDER BORISOV




arXiv:1301.0517v1 [math.NT] 3 Jan 2013
                                                Abstract. We introduce three simple polynomial maps with inte-
                                                ger coefficients that have interesting dynamical properties modulo
                                                primes.


                                           The first map is the simplest, and was discovered while woriking with
                                         Mark Sapir on [BS].


                                         Example 1. (Additive Trap) Define Fat (x, y) = (u, v), where


                                                                  (u, v) = (x2 y, x2 y + xy 2 )


                                           Note that modulo any prime p the p-th iteration of Fat sends every-
                                         thing to (0, 0). Indeed, if x 6= 0, then uv = xy + 1. So after no more
                                         than p − 1 iterations, we get y = 0, which forces x and y to become
                                         zero at the next step and forever afterwards. Note that this attractor
                                         property of (0, 0) does not hold for extensions of Z/(pZ) or over Z or
                                         C. Indeed, the map Fat is dominant, so by [BS] its periodic orbits over
                                         an algebraic closure of any finite field are Zariski dense.

                                                             (u, v) = (x2 y(x − y), 2xy 2(x − y))

Example 3. (Power Trap) Define Fpt (x, y) = (u, v), where

                      (u, v) = (x3 y(x − y), xy 3(x − y))

    Note that modulo any prime p if x 6= 0 and xy 6= 1, then uv = ( xy )2 . If
p = 2k + 1, then k + 1 iterations of this map send everything to (0, 0).
For general p a high enough iteration of Fpt sends to (0, 0) all pairs
(x, y) with one of the coordinates zero or xy having 2-primary order in
(Z/pZ)∗ .
    Obviously, with more variables one can create more complicated
maps, but it is unclear how much can be actually “programed” us-
ing integer polynomial maps. The following question is very natural in
this respect.
    Question. Does there exist an integer polynomial map with two
different fixed points such modulo every prime its sufficiently high it-
eration will send any initial point to one of the fixed points, depending
on whether or not the initial first coordinate is zero?
