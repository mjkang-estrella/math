Let A , B be infinite sets of non-negative integers with n ∈ A + B for all sufficiently large integers n . We prove that if A ⁡ ( x ) ​ B ​ ( x ) − x does not tend to infinity, then lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x ∈ [ 3 2 , 2 ] . The lower bound is sharp, and confirms a conjecture of Chen. Our proof is based on the weak limits and the convolution factorization theorem of Gabardo and Lai. A discrete proof of the same bound was also given by Zhang. Motivated by the known spectrum of perfect additive complements, we conjecture that the interval ( 3 / 2 , 8 / 5 ) is also excluded for almost perfect additive complements. Introduction Let A , B be two subsets of non-negative integers, and A ⁡ ( x ) , B ⁡ ( x ) be the corresponding counting functions defined by A ⁡ ( x ) := ∑ a ∈ A 0 ⩽ a ⩽ x 1 , B ⁡ ( x ) := ∑ b ∈ B 0 ⩽ b ⩽ x 1 . • A , B are called infinite , if A , B are both infinite sets. • A , B are called additive complements , if each sufficiently large integer n can be written as n = a + b for a ∈ A , b ∈ B . • Additive complements A , B are called almost perfect , if A ⁡ ( x ) ​ B ​ ( x ) − x ↛ ∞ . • Additive complements A , B are called perfect , if the expression n = a + b is unique for all n ∈ ℤ ⩾ 0 . For infinite additive complements, Sárközy and Szemerédi [ 12 ] proved Danzer’s conjecture [ 6 ] : lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x ⩽ 1 ⟹ A ⁡ ( x ) ​ B ​ ( x ) − x → ∞ . The problems were studied by many authors [ 6 , 7 , 11 , 12 ] . Chen and Fang [ 2 , 3 , 4 , 5 ] extended the result to show that for infinite almost perfect additive complements A , B , lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x ∈ [ 3 − 3 , 2 ] . Yang and Zhao [ 14 ] improved the lower bound to 4 / 3 recently. Chen conjectured that the lower bound of the interval should be 3 / 2 , which is a sharp bound. In this paper, we confirm Chen’s conjecture. The proof is shown in Section 3 . Theorem 1.1 (Chen’s conjecture) . If A , B are infinite almost perfect additive complements, then lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x ∈ [ 3 2 , 2 ] .
