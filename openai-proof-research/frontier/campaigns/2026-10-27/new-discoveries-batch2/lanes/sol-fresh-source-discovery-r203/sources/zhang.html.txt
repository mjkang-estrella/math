Let A and B be infinite sets of nonnegative integers whose sum contains all sufficiently large integers, and let A ⁡ ( x ) and B ⁡ ( x ) be their counting functions. We give a discrete proof of the sharp implication lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x < 3 2 ⟹ A ⁡ ( x ) ​ B ​ ( x ) − x ⟶ + ∞ . The constant 3 / 2 is best possible. Using finite convolution sums, we show that a long gap in one set forces a gap in the other. We then compare the counting functions before and after the gap to obtain the sharp bound. Key words and phrases: Additive complements, counting functions, representation functions, convolution 2020 Mathematics Subject Classification Primary 11B13. Secondary 11B34 1. Introduction We write ℕ 0 = { 0 , 1 , 2 , … } . Two infinite sets A , B ⊆ ℕ 0 are called additive complements if A + B contains all sufficiently large integers. For real x ≥ 0 , put A ⁡ ( x ) = # ⁡ ( A ∩ [ 0 , x ] ) , B ⁡ ( x ) = # ⁡ ( B ∩ [ 0 , x ] ) . Every sufficiently large integer at most x has a representation using elements at most x , so A ⁡ ( x ) ​ B ​ ( x ) ≥ x − O ⁡ ( 1 ) . Hanani asked whether every pair of infinite additive complements satisfies lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x > 1 . Erdős recorded this question in [ 3 , Problem 12, p. 295] . Danzer [ 2 ] answered it negatively by constructing complements for which (1.1) A ⁡ ( x ) ​ B ​ ( x ) x ⟶ 1 . Following Ruzsa [ 8 , Section 1] , such pairs are called exact additive complements. This terminology refers to the counting functions and does not require unique representations. Danzer also asked whether ( 1.1 ) forces (1.2) A ⁡ ( x ) ​ B ​ ( x ) − x ⟶ + ∞ . Sárközy and Szemerédi [ 9 ] proved that it does. Ruzsa [ 8 , Theorem 1.3] later showed that the excess can grow arbitrarily slowly along a sequence: for any function tending to infinity, there are exact complements whose excess is smaller than that function at arbitrarily large arguments. Fang and Chen [ 4 ] proved ( 1.2 ) under the weaker assumption lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x < 5 4 . They replaced 5 / 4 by 3 − 3 in [ 5 , Theorem 1.1] , and Yang and Zhao [ 11 , Theorem 1.1] obtained 4 / 3 . Chen and Fang [ 1 ] also constructed complements with upper limit 3 / 2 and excess equal to 1 at infinitely many integers. Thus 3 / 2 is the largest possible threshold. A measure-theoretic proof of the sharp 3 / 2 bound was announced by van Doorn, Liu and Tang on 5 August 2026 in the discussion of Erdős Problem 785 [ 10 ] . The announcement credits GPT-5.6 Sol with obtaining the proof. The accompanying note takes weak limits of normalized counting measures and uses Gabardo and Lai’s characterization [ 6 ] of probability measures whose convolution is Lebesgue measure on [ 0 , 1 ] . However, they think the proof by is too surprising that they are working now to find a human-generated version. We give a proof of the same conclusion using elementary counting and finite convolutions. Theorem 1.1 . Let A and B be infinite additive complements in ℕ 0 . If (1.3) lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x < 3 2 , then A ⁡ ( x ) ​ B ​ ( x ) − x ⟶ + ∞ . The proof begins with a standard observation: if the excess stays bounded along a sequence, then every sufficiently large integer has a unique representation as a sum. This reduction was already used in [ 9 , p. 238] and [ 5 , p. 85] . The upper limit assumption then gives consecutive elements x < y of one set with y ≥ 3 ​ x + n 0 , where n 0 is fixed. Our use of these gaps is motivated by the 3 / 2 example of Chen and Fang [ 1 ] , discussed in Section 6 . We prove, uniformly for integers 0 ≤ t ≤ x , that A ⁡ ( y + t ) = A ⁡ ( x ) + A ⁡ ( t ) + O ⁡ ( 1 ) , A ⁡ ( x ) ​ B ​ ( y + t ) = y + O ⁡ ( 1 ) . The first estimate describes how A grows after the gap; the second controls B on the same interval. At t = x , they give A ⁡ ( y + x ) ​ B ​ ( y + x ) y + x ≥ ( 2 − o ⁡ ( 1 ) ) ​ y y + x ≥ 3 2 − o ⁡ ( 1 ) along the sequence of gaps. The reflected convolution identity used below also appears in [ 11 , Lemma 3.1] . The longer gap lets us show that certain coefficients vanish exactly, which yields both counting estimates. Section 2 collects the basic lemmas. Sections 3 and 4 give the gaps and the two counting estimates. We finish the proof in Section 5 and verify sharpness in Section 6 . 2. Sharpness We recall a digit example and verify the endpoint by direct counting. It is a special case of Ma’s construction [ 7 , Lemma 2.1 and equation (3.1)] ; the existence of examples at 3 / 2 was proved earlier by Chen and Fang [ 1 ] . Let (6.1) A = { ∑ i ≥ 0 ε i 4 i | ε i ∈ { 0 , 1 } , only finitely many ε i ≠ 0 } , B = 2 A . Every base- 4 digit is uniquely the sum of a digit in { 0 , 1 } and one in { 0 , 2 } , with no carries. Thus every nonnegative integer has exactly one representation in A + B . At X k = 4 k − 1 , counting the first k digits gives (6.2) A ⁡ ( X k ) = B ⁡ ( X k ) = 2 k , A ⁡ ( X k ) ​ B ​ ( X k ) − X k = 1 . To bound the product ratio, write v = ∑ i ε i ​ 2 i and put a v = ∑ i ε i ​ 4 i . These a v list A in increasing order. Since ∑ j < i ε j ​ 2 j ≤ 2 i − 1 , (6.3) v 2 = ∑ i ε i ​ 4 i + 2 ​ ∑ i ε i ​ 2 i ​ ∑ j < i ε j ​ 2 j ≤ ∑ i ε i ​ 4 i + 2 ​ ∑ i ε i ​ 2 i ​ ( 2 i − 1 ) ≤ 3 ​ a v . Fix k ≥ 0 and put H = 2 k . In [ 4 k , 4 k + 1 ) , the elements of A are 4 k + a v , and those of B are 2 ​ ( 4 k + a v ) , with 0 ≤ v < H . As a v ≤ ( 4 k − 1 ) / 3 , the A block ends before the B block begins. Between consecutive elements of A ∪ B , the numerator is constant and the denominator increases. The same bound therefore holds throughout [ 4 k , 4 k + 1 ) , giving (6.4) lim sup x → ∞ A ⁡ ( x ) ​ B ​ ( x ) x ≤ 3 2 . For the reverse inequality, take z k = 2 ​ ( 4 k − 1 ) / 3 , the largest element of B using the first k digits. Then A ⁡ ( z k ) = B ⁡ ( z k ) = 2 k , so A ⁡ ( z k ) ​ B ​ ( z k ) z k = 3 ⋅ 4 k 2 ​ ( 4 k − 1 ) ⟶ 3 2 . Together with ( 6.2 ), this proves that the constant 3 / 2 is best possible and that the strict inequality in Theorem 1.1 is necessary.
