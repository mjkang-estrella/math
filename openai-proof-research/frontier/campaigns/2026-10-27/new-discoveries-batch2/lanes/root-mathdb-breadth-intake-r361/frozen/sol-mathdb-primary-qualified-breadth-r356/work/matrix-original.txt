                                                  Abstract. Motivated by complexity questions in integer programming, this paper aims
                                                  to contribute to the understanding of combinatorial properties of integer matrices of row
                                                  rank r and with bounded subdeterminants. In particular, we study the column number
                                                  question for integer matrices whose every r × r minor is non-zero and bounded by a fixed
                                                  constant ∆ in absolute value. Approaching the problem in two different ways, one that
                                                  uses results from coding theory, and the other from the geometry of numbers, we obtain

                                                  linear and asymptotically sublinear upper bounds on the maximal number of columns of

                                                  matching the linear upper bound for r = 2, and a discussion of a computational approach

                                                                                   1. Introduction
                                            This paper contributes to the understanding of combinatorial properties of integer pro-
                                          grams, parametrized by the maximal absolute value of a subdeterminant of their constraint
                                          matrices. An integer program is an optimization problem of the form
                                                                             max {c⊺ x : Bx ≤ d, x ∈ Zr } ,                                   (IP)
                                          where B ∈ Zn×r is the constraint matrix, c ∈ Zr the cost function, and d ∈ Zn the right
                                          hand side. The underlying polyhedron of this integer program is defined as
                                                                            P (B, d) := {x ∈ Rr : Bx ≤ d} ,
                                          that is, as the set of all solutions of the linear inequality system b⊺1 x ≤ d1 , . . . , b⊺n x ≤ dn
                                          with b1 , . . . , bn ∈ Zr denoting the rows of B, which we compactly write as Bx ≤ d.
                                             Solving a general integer program is computationally expensive. Indeed the associated
                                          decision problem that asks whether P (B, d) ∩ Zr ̸= ∅ is among Karp’s [17] famous early
                                          list of NP-complete problems. The most efficient algorithm for solving a general instance
                                          of the integer program (IP) was very recently proposed in [25], and has a running time of
                                          log(2r)O(r) multiplied with a polynomial in the encoding length of B, d, and c. We refer
                                          to that paper [25] for a detailed discussion of the history of such complexity results. The
                                          question whether (IP) can be solved in single exponential time is one of the major research
                                          problems in the area.
                                             Given the computational hardness of integer programming, there is an extensive amount
                                          of research about investigating integer programs with additional structure. The most basic
                                          assumption that implies efficient algorithms is that the constraint matrix B in (IP) is
                                          totally unimodular, which means that all its minors, that is, the determinants of square
                                          submatrices, are in {−1, 0, 1}. As a consequence, the polyhedron P (B, d) has only integral
                                          vertices and thus (IP) can be solved in polynomial time, for instance, by linear programming
                                          techniques (see [26, Ch. 19]).
                                             This observation suggests to parametrize integer programs by maximal determinants of
                                          the submatrices of the constraint matrix. More precisely, given an integer ∆ ∈ Z>0 , we say
                                          that a rational matrix A ∈ Qr×n of rank rk(A) is ∆-submodular, if all its rk(A) × rk(A)
                                          minors are bounded by ∆ in absolute value. Further, we say that A is ∆-modular, if it
                                          is ∆-submodular and there is a rk(A) × rk(A) minor equal to ∆ or −∆. If the minors
                                                                                             1
2           BJÖRN KRIEPKE, GOHAR M. KYUREGHYAN, AND MATTHIAS SCHYMURA

of every size are bounded by ∆ in absolute value, we call A totally ∆-(sub)modular. An
integer program (IP) with a ∆-modular constraint matrix B is called a ∆-modular integer
program. Note that this definition is independent of the right hand side d ∈ Zn .
   As discussed above, totally unimodular (∆ = 1) integer programs are efficiently solvable.
This is relevant for problems that can be formulated by network matrices, for instance
(see [26, Ch. 19]), but at the same time it is a very restrictive assumption. Extending
our understanding of ∆-modular integer programs beyond the totally unimodular case
is a prevailing and currently very active research direction in the community. The main
conjecture in the field is that efficient algorithms exist, whenever ∆ is not part of the input:
Conjecture 1.1. Let ∆ ∈ Z>0 be fixed. Then, there is a polynomial time algorithm to
solve any integer program of the form (IP) with a ∆-modular constraint matrix.
   The origin of this conjecture is hard to trace, but [14] attribute it to [27]; it might
be much older than that though. Despite the fact that Conjecture 1.1 is far from being
resolved in whole generality, there is a list of pertinent results supporting it and which
cover different variations and specializations of the problem. In fact, polynomial time
algorithms have been devised for 2-modular integer programs [3], for totally ∆-modular
integer programs with at most two non-zeros per row [11], and for ∆ ≤ 4 for so-called
strictly ∆-modular integer programs [21].
   Additionally, the class of generic ∆-modular integer programs is well understood from
a computational point of view. A matrix A ∈ Zr×n is called generic, if all its rk(A) ×
rk(A) minors are non-zero, that is, every set of rk(A) columns or rows of A is linearly
independent. Generic ∆-modular integer programming, for arbitrary but fixed ∆ ∈ Z>0 ,
is known to be polynomial time solvable due to [2] (the case of generic 2-modular constraint
matrices was known before [30]). More strongly, all the potentially relevant feasible points
in the underlying polyhedron of a generic ∆-modular integer program can be enumerated
efficiently:
Theorem 1.2 ([16, Thm. 2.1]). Let ∆ ∈ Z>0 be fixed. Then, for every generic ∆-modular
matrix B ∈ Zn×r and every d ∈ Zn , one can enumerate the vertices of the convex hull of
P (B, d) ∩ Zr in polynomial time.
   In this paper, we continue the study of generic ∆-modular integer programs and their
combinatorial properties. Our aim is to underpin the algorithmic results for this class of
optimization problems by corresponding strong combinatorial obstructions. More precisely,
we are interested in the maximum number of irredundant inequality constraints that a
generic ∆-modular integer program can have. After interchanging rows and columns (which
is more convenient for our analysis) this corresponds to bounding the number of columns
of a generic ∆-modular integer matrix for a fixed number r of rows. We may also assume
that the considered matrices have no repeating columns, and we will do so for the rest of
the paper without further mention. By this assumption we can identify a matrix A ∈ Zr×n
with its set of columns and then consider it as a subset of Zr of cardinality n.
   The combinatorial question described above is the so-called column number question for
generic ∆-modular integer matrices and is made precise by the function
          g(∆, r) := max n : ∃ a generic ∆-modular A ∈ Zr×n with rk(A) = r .

   Our main results on the behavior of the function g(∆, r) substantiate the fact that
generic ∆-modular integer programs are quite restrictive. They are summarized as follows:
Theorem 1.3. Let r and ∆ be positive integers with r ≥ 2, and let p be the smallest prime
number with ∆ < p. Then,
                                 g(∆, r) ≤ max{r, p} + 1.                               (1.2)
Furthermore, if r, ∆ ≥ 2, then g(∆, r) ≤ 2∆, and if r ≥ 2∆ − 1, then g(∆, r) = r + 1.

g(∆, r) = r + 1, if r is large enough compared to ∆, was established before in [2, Lem. 7],
albeit with the much stronger assumption that r is at least doubly exponential in ∆. A
direct consequence of (1.2) is that g(∆, r) is at most linear in both parameters ∆ and r.
The previous state of the art was given by the inequality g(∆, r) ≤ r + ∆2 , established
in [22, Lem. 8] (cf. [12, Proof of Lem. 1] for a similar bound). The authors of [22] show
how bounds on g(∆, r) have consequences on what they term the integrality number of the
corresponding integer programs.

   Of course, the column number question has been investigated also for general, not nec-
essarily generic, ∆-modular integer matrices. The corresponding counting function is
              h(∆, r) := max n : ∃ a ∆-modular A ∈ Zr×n with rk(A) = r .

Note that in contrast to g(∆, r) this allows linear dependencies among sets of r columns
in the considered matrices, and in particular, it allows for parallel columns. We shortly
mention the best-known bounds on this parameter and refer to the cited papers for more
background and literature.
   A construction of a ∆-modular matrix with many columns in [19] shows that
                   r2 + r + 1 + 2r(∆ − 1) ≤ h(∆, r), for all ∆, r ∈ Z>0 .               (1.3)

Notations. Here, we fix some notations that we use throughout the following sections.
For a positive integer r, we write [r] = {1, 2, . . . , r}. If M ⊆ Rr is a Lebesgue-measurable
set, then we denote its Lebesgue measure, or volume, by vol(M ), and its normalized volume
by Vol(M ) = r! vol(M ). The symbol conv(S) stands for the convex hull of a set S ⊆ Rr ,
and if S is finite then |S| denotes its cardinality. For a matrix A, we let rk(A) denote its
rank, as used already above. Finally, an integer matrix U ∈ Zr×r with determinant equal
to 1 or −1 is called a unimodular matrix.

                                  2. Upper bounds on g(∆, r)
2.1. A linear upper bound using finite fields. A generic ∆-modular matrix implying
the lower bound g(∆, r) ≥ r + 1 has columns e1 , . . . , er , (∆, . . . , ∆)⊺ . In this part we aim
to prove Theorem 1.3, which implies that this lower bound is best possible, if r ≥ 2∆ − 1.
   Our proof of Theorem 1.3 relies on a connection of generic ∆-modularity with so-called
MDS-codes. The famous MDS conjecture describes possible parameters of an optimal
family of codes over the finite field with q elements, denoted here by Fq . It was first stated
by Segre in the 1950s in terms of arcs in finite geometry. For q = p prime the MDS
conjecture was proven by Ball [7]:
Theorem 2.1 (Ball [7, Cor. 11.1]). Let p be a prime and let A ∈ Fr×n  p   be a matrix
with rk(A) = r ≥ 2 such that any set of r columns of A is linearly independent. Then
n ≤ max{r, p} + 1.

2.2. A sublinear upper bound for fixed r ≥ 3 using geometry of numbers. In this
part, we prove Theorem 1.4. The main idea of our argument is the following: Given a
generic ∆-modular matrix A ∈ Zr×n , considered as a subset of Zr with cardinality n, we
upper bound n by counting the points in A by containment in a family of parallel affine
hyperplanes. The subsets of A in each of these hyperplanes are points in general position
and that satisfy a volume condition in terms of the parameter ∆. These point sets in r − 1
dimensions again can be counted by containment in a family of parallel hyperplanes, only
that now at most r − 1 of the points can be contained in a given such hyperplane by the
general position condition. For the envisioned bound, we need to find a family of parallel
hyperplanes of small cardinality and that covers the points in A. This is achieved by using
the ∆-modularity in form of a volume-width-principle from the geometry of numbers.
   The sketched argument can be implemented in a series of lemmas. First of all, let S ⊆ Zr
be a finite set of lattice points.
      • S is in general position, if no r + 1 of its points are contained in a common affine
        hyperplane, and
      • S has simplex-volume at most ∆, if for every r + 1 points in S the lattice simplex
        spanned by those points has normalized volume at most ∆.
With this notation we define the constant
   gv(∆, r) := max {|S| : S ⊆ Zr in general position with simplex-volume at most ∆} .

                4. A computational approach for small parameters
   Complementing the theoretical results on g(∆, r) concerning upper bounds in Section 2
and lower bounds in Section 3, we discuss in the following a computational approach to
algorithmically determine the precise values of g(∆, r) for small parameters ∆ and r. A
related yet different computational approach for the “non-generic” numbers h(∆, r) has
been described in [5] (see the discussion in Section 4.4.3).
   We begin the section with some elementary properties of generic ∆-modular matrices
that take the symmetries of the problem into account, in particular its invariance under
unimodular transformations. Based on these properties we describe our algorithm in Sec-
tion 4.2 and investigate simple reductions that speed up the implementation considerably.
Finally, in Section 4.4, we report on the numerical results of our computations and we aim
to explain the findings at least for the rank two case as best as possible.

Definition 4.2. Let A ∈ Qr×n be a rational matrix with rk(A) = r. We call A
  (i) ∆-bound, if for 1 ≤ m ≤ r every m × m-minor is bounded by ∆m in absolute value,
 (ii) totally generic, if for 1 ≤ m ≤ r every m × m-minor is non-zero.
If A is a totally generic ∆-bound matrix, then in particular all entries of A are non-zero
and bounded by ∆ in absolute value. An equivalent condition to being ∆-bound is that
A/∆ is totally 1-submodular. As a sidenote, by Hadamard’s inequality we have that if the
absolute value of the entries of any matrix are bounded by β, then each m × m-minor of
that matrix is bounded by mm/2 β m in absolute value. So if A is ∆-bound this then gets
rid of the factor mm/2 .

submodularity and genericity, respectively, if we amend a matrix with the identity matrix.

   It relies on the notion of a normal form for integer matrices under unimodular transfor-

normal form of A (see [10, Ch. 2] for more background and computational approaches to
efficiently compute H from a given matrix A).

4.2. An algorithm to compute g(∆, r). Lemma 4.4 and its proof suggest an algorithm
for finding a generic ∆-modular matrix of size r × (r + L) with maximal L.
Step 1: Construct all integer matrices A ∈ Zr×r in Hermite normal form with determinant
         det(A) = ∆.
Step 2: Find all solutions x ∈ Zr∆ of Ax = 0 mod ∆. For each such solution x calculate
         all possible representatives in Zr with nonzero entries bounded by ∆ in absolute
         value. We can assume that the first entry is positive.
Step 3: Find a largest possible totally generic ∆-bound matrix with the columns obtained
         in Step 2.
Step 4: Let C ∈ Zr×L be the totally generic ∆-bound matrix found in Step 3. Then,
         D = (A, AC/∆) is a generic ∆-modular matrix of size r × (r + L).
Pseudocode for this algorithmic approach is given as Algorithm 1. Correctness of the
algorithm follows directly from Lemma 4.4, so that in the remainder of this subsection we
will be concerned with describing how we can implement the various steps in an efficient
manner.

Algorithm 1 Compute g(∆, r)
Require: ∆, r ∈ Z>0
Ensure: g(∆, r), generic ∆-modular matrix D ∈ Zr×g(∆,r)
 1: g ← 0
 2: D ← 0
 3: H ← list of all relevant Hermite normal forms
 4: for all A ∈ H do
 5:    X ← relevant integer solutions to Ax = 0 mod ∆
 6:    C ← largest possible totally generic ∆-bound matrix with columns in X
 7:    if r + number-of-columns(C) > g then
 8:        g ← r + number-of-columns(C)
 9:        D ← (A, AC/∆)
10:    end if
11: end for

   Note that Step 3 above, respectively Line 6 in Algorithm 1, is by far the most compu-
tationally expensive step. Therefore, we first investigate whether we actually need to run
through all the Hermite normal forms in Step 1, and likewise through all integer solutions
to the linear system in Step 2. It turns out that we can reduce the possibilities quite a bit
and only need to consider the relevant of these objects as is hinted at in the description of
Algorithm 1 in Lines 3 and 5. Let us start with the Hermite normal forms.
4.2.1. Relevant Hermite normal forms. Among any pair A1 and A2 of integer matrices in
Hermite normal form that give equivalent results, we need to iterate only over one of them.
Let us make more precise what we consider as equivalent results:
Definition 4.5. Let D1 , D2 ∈ Zr×n . We say that D1 is equivalent to D2 , in symbols
D1 ≃ D2 , if there exists a unimodular matrix S ∈ Zr×r , a diagonal matrix D ∈ Zn×n with
diagonal entries ±1, and a permutation matrix P ∈ Zn×n such that D2 = SD1 DP .
   Hence, D1 ≃ D2 , if D2 can be obtained from D1 by applying integer row operations,
rearranging columns and multiplying columns by −1. Note that both ∆-modularity and
genericity are preserved under this notion of equivalence.
   Let D1 = (A1 , U1 ) be a generic ∆-modular matrix with A1 in Hermite normal form and
let A2 be a matrix in Hermite normal form and which is equivalent to A1 , i.e. A2 = SA1 DP
for suitable matrices S, D, and P as in Definition 4.5. Then D2 = (SA1 DP, SU1 ) =
      SIZE OF INTEGER PROGRAMS WITH BOUNDED NON-VANISHING SUBDETERMINANTS                                15

(A2 , SU1 ) is also generic ∆-modular and will be found by the algorithm. In particular,
during the algorithm we do not have to run through the for loop for both A1 and A2 .
However, even if D1 = (A1 , U1 ), D2 = (A2 , U2 ) are matrices with A1 , A2 in Hermite normal
form and such that D1 ≃ D2 , then A1 and A2 need not be equivalent. There can be a
submatrix Ã1 of U1 which is equivalent to A2 . Therefore, even if we restrict the equivalence
to the Hermite normal forms that we investigate, and for each equivalence class we test only
one matrix, we might still find resulting matrices during the algorithm that are equivalent.
   This problem is related to finding a canonical form under the equivalence relation ≃.
We are not aware of any work in the literature solving this problem, but we discuss two
operations below that can be used to reduce the amount of Hermite normal forms that
have to be checked. Note that a slightly different notion of equivalence has been studied
by Paolini [24]. He says that two matrices D, D′ ∈ Zr×n are equivalent, if there is a
permutation matrix P ∈ Zn×n and an affine unimodular equivalence φ : Zr → Zr , that is
φ(x) = Ax + b, for some unimodular A ∈ Zr×r and some b ∈ Zr , such that D′ = φ(D)P .
Paolini defines a canonical form for this notion and devises an efficient algorithm to compute
it. The question on whether his approach can be adapted to our notion of equivalence will
be left for future work.

Operation 1: Sorting the diagonal. Let A ∈ Zr×r be a matrix in Hermite normal form with
diagonal (a1 , . . . , ar ). We claim that we can apply suitable column and row operations to

such that a′1 ≤ . . . ≤ a′r . To see this it suffices to show how we may “swap” two adjacent
diagonal entries, that is, if A has diagonal (a1 , . . . , ai−1 , ai , ai+1 , ai+2 , . . . , ar ) with ai >
ai+1 , then we can obtain an equivalent matrix A′ in Hermite normal form with the diagonal
(a1 , . . . , ai−1 , a′i+1 , a′i , ai+2 , . . . , ar ) and a′i+1 ≤ a′i . This can be achieved by following a

(1) Write b for the entry of A at position (i, i + 1) and exchange columns i and i + 1 of A.

(4) Use rows i + 1, . . . , r to restore the Hermite normal form condition for (i + 1)-st row.

4.2.2. Relevant integer solutions. Now, we investigate the relevant solutions to the equa-
tion in Line 5 of Algorithm 1. For a matrix A ∈ Zr×r in Hermite normal form and with
det(A) = ∆, we therefore consider the linear system Ax = 0 mod ∆.
   Since A is in Hermite normal form, this system can be solved by backwards substitution,
but as det(A) = ∆, the matrix A is not invertible over Z∆ . Thus, there will be multiple
solutions in Zr∆ and for each of those there might be several integer representatives.
   As a first step, we determine the number of solutions of the linear system above in Zr∆ .
For this, we need the Smith normal form of an integer matrix (cf. Cohen [10, Ch. 2]).
Theorem 4.7. Let A ∈ Zr×r have non-zero determinant. Then, there exist unimodular
matrices Q, P ∈ Zr×r such that P AQ = diag(α1 , . . . , αr ), where the integers α1 , . . . , αr are
the elementary divisors of A satisfying 0 ≤ αi |αi+1 , for all 1 ≤ i ≤ r − 1.
  The matrix S := P AQ in this theorem is uniquely determined and is called the Smith
normal form of A. By definition, we have |det(A)| = det(S) = α1 · . . . · αr .
Lemma 4.8. Let a, b, ∆ ∈ Z be integers with ∆ > 0 and let A ∈ Zr×r have determinant
det(A) = ∆.
  (i) The equation ax = b mod ∆ has either 0 or gcd(a, ∆) solutions in Z∆ .
 (ii) There are exactly ∆ solutions to Ax = 0 mod ∆ in Zr∆ .
Proof. (i): By linearity we only need to consider b = 0. If ax = 0 mod ∆, then ax = k∆
for some integer k. Let d = gcd(a, ∆) and a = ds, ∆ = dt be with gcd(s, t) = 1. Plugging
in, we obtain dsx = kdt, or equivalently sx = kt. As s divides sx = kt, but gcd(s, t) = 1,
we have x = (k/s)t, where k/s = m is an integer. It is easy to check that indeed for
any integer m the number x = mt is a solution. We now need to check that these give d
distinct solutions in Z∆ .
   To this end, let m1 , m2 ∈ Z be with m1 t = m2 t mod ∆. Then, (m1 − m2 )t = k∆ = kdt
for some integer k. Therefore, m1 − m2 = kd = 0 mod d and m1 = m2 mod d. Hence, each
0 ≤ m < d gives a distinct solution and this proves the claim.
   (ii): Let S = P AQ be the Smith normal form of A. Since as integer matrices |det(P )| =
|det(Q)| = 1, both matrices Q, P are invertible over Zr∆ . Further, we have α1 · . . . · αr = ∆
for the diagonal elements of S.
   Multiplying Ax = 0 mod ∆ from the left by P gives us
                         P Ax = P AQQ−1 x = S(Q−1 x) = 0 mod ∆.
As P and Q are invertible, the number of solutions to Ax = 0 mod ∆ and Sy = 0 mod ∆
with y = Q−1 x are the same. The i-th row of the system Sy = 0 mod ∆ is given by
αi yi = 0 mod ∆, which by part (i) has exactly αi solutions in Z∆ , since αi is a divisor
of ∆. Combining these solutions for each row, we obtain exactly α1 · . . . · αr = ∆ solutions
of Ax = 0 mod ∆ over Zr∆ .                                                                 □

   Now, as the second step, for each of the ∆ solutions x ∈ Zr∆ to Ax = 0 mod ∆, we want
to find all the integer representatives in x + ∆Zr that are relevant for the computation of
g(∆, r) by Algorithm 1. Since we want to build a totally generic ∆-bound matrix out of
these vectors, in particular each of the entries of such a representative needs to be non-zero
and bounded by ∆ in absolute value. Further, if we find a matrix using the representative v,
then we will also find an equivalent matrix using the representative −v, and no matrix can
contain both of v and −v because this would create a vanishing minor. Therefore, we only
need to take one of v and −v, which we can achieve, for example, by fixing the first entry
of each representative to be positive.

   In summary, if x ∈ Zr∆ is a solution and v ∈ x+∆Zr a representative under the discussed
conditions, we have that if xi = 0, for some index i, then vi ∈ {∆, −∆}, and if xi = k ̸= 0,
then vi ∈ {k, k − ∆}. This gives 2 options for each entry of v, except for the first entry,
which must be positive. Hence, that leaves us with 2r−1 relevant representatives of x. The
list X in Line 5 of Algorithm 1 will therefore in total have 2r−1 ∆ vectors.
   For particular matrices A, we may further remove irrelavant representatives. Indeed,
if v and ℓv are elements in the list X, for some ℓ > 1, and we find a matrix using the
column ℓv, then we will also find a matrix using the column v. This means that we only
need to take v, and can neglect ℓv.
Remark 4.9. The previous observations show that the matrices C that are constructed
in Algorithm 1 have at most 2r−1 ∆ columns, which means that the generic ∆-modular
matrices (A, AC/∆) have at most r + 2r−1 ∆ columns. This proves g(∆, r) ∈ O(∆), for
fixed values of r, without using the theory of finite fields employed in Section 2.1. However,
here the implied constant depends exponentially on r instead of being constant. Also, as
discussed after Theorem 2.1, the linear bound g(∆, r) ≤ r + p − 1 is not very involved, and
in particular is independent of Ball’s result Theorem 2.1.
   A similar argument was carried out in [5, Rem. 1], showing the bound h(∆, r) ≤ 3r ∆ for
the maximal column number of not necessarily generic ∆-modular matrices with r rows.
4.3. Finding a totally generic ∆-bound matrix with the most columns. After the
previous reductions have been carried out and, for a given Hermite normal from A, the
candidate set X has been computed, how can we now find a largest possible totally generic
∆-bound matrix C with columns in X? We solve this problem by translating it into a
clique problem in a suitably defined (hyper-)graph.
   Recall that a clique in a simple graph G = (V, E) is a collection of vertices K ⊆ V , so
that for every i, j ∈ K with i ̸= j, we have {i, j} ∈ E. A clique is called maximal if it
is not a proper subset of another clique, and it is called maximum if there is no clique of
larger cardinality in G. Now, let H = (V, H) be a simple hypergraph, where H ⊆ 2V is the
set of hyperedges. For k ≥ 2, a k-hyperclique in H is a set K ⊆ V of vertices so that every
subset I ⊆ K of size 1 < |I| ≤ k is a hyperedge. Maximal and maximum k-hypercliques
are defined analogously to maximal and maximum cliques in graphs, respectively.
   Now, assume we are given a list X = {v1 , . . . , vn } of vectors with n ≤ 2r−1 ∆ generated
in Line 5 of Algorithm 1, and we want to build a maximum totally generic ∆-bound
matrix C with columns from X. We define the hypergraph Hr = ([n], Hr ), where I ⊆ [n]
is a hyperedge, if and only if 1 < |I| ≤ r and the matrix (vi : i ∈ I) is totally generic
∆-bound. Note that the hypergraph Hr is downward-closed, because if a matrix M is
totally generic ∆-bound, then so is any submatrix of M obtained by removing columns.
The problem of finding the matrix C above is now equivalent to finding a maximum r-
hyperclique in Hr .
   Let us first consider the case r = 2, in which the hypergraph H2 is just a simple graph.
For the maximum clique problem in graphs there are various software implementations
available. We used the Sagemath [28] implementation sage.graphs.cliquer.max_clique.
For r ≥ 3, we implemented an algorithm for the hypergraph clique problem in C++, based
on hClique described in [29].

4.4.3. Non-generic setting. With only slight modifications the ideas behind Algorithm 1 are
also applicable in the non-generic setting. More precisely, we are interested in determining
the maximum number of columns that a ∆-modular matrix A with r = rk(A) rows can
have. Compared to the generic case, this means that we allow vanishing minors of size
r × r. The following lemma is the “non-generic” version of Lemma 4.4 and can be proved
analogously.
Lemma 4.13. Let D ∈ Zr×(r+L) be a ∆-modular matrix with rk(D) = r. Then, there
exists a ∆-bound matrix C ∈ Zr×L . Further, each column of C is a solution to a linear
system of equations Ax = 0 mod ∆ for an integer matrix A ∈ Zr×r in Hermite normal
form satisfying det(A) = ∆.

a zero-column and also both v and −v, for reasons of efficiency, we implemented the
corresponding algorithm in a way that both of these are not allowed. This reduces the size
of the hypergraphs roughly by a factor of two and therefore improves the runtime of the
algorithm considerably. However, the hypergraphs still end up very large and also happen

An interesting observation is that there are several hypergraphs for which there are a lot
of maximum cliques. Therefore it takes a lot of time to go through the search tree of all
cliques and the hClique algorithm takes considerably longer for these hypergraphs. In
our implementation of Algorithm 1 we parallelized the for loop in Line 4. In the generic
setting this works well, as most hypergraphs have roughly the same size. However, in the
non-generic setting most of the time will be spent waiting on a single thread corresponding
to one such large hypergraph. Therefore it might be fruitful to instead parallelize the
algorithm hClique itself.
