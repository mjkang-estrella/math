Abstract.
Lazy burning is a recently introduced variation of burning where only one set of vertices is chosen to burn in the first round. In hypergraphs, lazy burning spreads when all but one vertex in a hyperedge is burned. The lazy burning number is the minimum number of initially burned vertices that eventually burns all vertices. We give several equivalent characterizations of lazy burning on hypergraphs using matchings and zero forcing, and then apply these to give new bounds and complexity results.
We prove that the lazy burning number of a hypergraph HH equals its order minus the maximum cardinality of a certain matching on its incidence graph. Using this characterization, we give a formula for the lazy burning number of a dual hypergraph and give new bounds on the lazy burning number based on various hypergraph parameters. We show that the lazy burning number of a hypergraph may be characterized by a maximal subhypergraph that results from iteratively deleting vertices in singleton hyperedges.
We prove that lazy burning on a hypergraph is equivalent to zero forcing on its incidence graph and show an equivalence between skew zero forcing on a graph and lazy burning on its neighborhood hypergraph. As a result, we show that finding an upper bound on the lazy burning number of a hypergraph is NP-complete, which resolves a conjecture from [7]. By applying lazy burning, we show that computing an upper bound on the skew zero forcing number for bipartite graphs is NP-complete. We finish with open problems.
Key words and phrases: hypergraphs, burning, matchings, zero forcing

1. Introduction
Graph burning is a simplified model for the spread of influence in a network. Associated with the process is a parameter introduced in [7, 8], the burning number, which quantifies the speed at which the influence spreads to every vertex. Given a graph GG, the burning process on GG is a discrete-time process. At the beginning of the first round, all vertices are unburned. In each round, first, all unburned vertices that have a burned neighbor become burned, and then one new unburned vertex is chosen to burn if such a vertex is available. If at the end of round kk every vertex of GG is burned, then GG is kk-burnable. The burning number of G,G, written b⁡(G),b(G), is the least kk such that GG is kk-burnable. For further background on graph burning, see the survey [5] and the book [6].
Hypergraph burning was introduced in [12, 18] as a natural variant of graph burning. The rules for hypergraph burning are identical to those of burning graphs, except for how burning propagates within a hyperedge. Recall that in a hypergraph, a singleton edge contains exactly one vertex. In hypergraphs, the burning spreads to a vertex vv in round rr if and only if there is a non-singleton hyperedge {v,u1,…,uk}\{v,u_{1},\ldots,u_{k}\} such that vv was not burned and each of u1,u2,…,uku_{1},u_{2},\ldots,u_{k} was burned at the end of round r−1r-1. In particular, a vertex becomes burned if it is the only unburned vertex in a hyperedge. A natural variation of burning that is our principal focus here is lazy hypergraph burning, where a set of vertices is chosen to burn in the first round only; no other vertices are chosen to burn in later rounds. The lazy burning number of HH, denoted bL​(H)b_{L}(H), is the minimum cardinality of a set of vertices burned in the first round that eventually burn all vertices. Note that for a hypergraph H,H, we have that bL​(H)≤b​(H).b_{L}(H)\leq b(H). We refer to the set of vertices chosen to burn in the first round as a lazy burning set. A lazy burning set SS such that |S|=bL​(H)|S|=b_{L}(H) is called optimal. If a vertex is burned and not part of a lazy burning set, then we say it is burned by propagation; all rounds other than the first where a lazy burning set is chosen are called propagation rounds.
We note that we consider a slightly modified rule for lazy burning than the one given in [12], which simplifies our discussion. If a hyperedge hh contains exactly one unburned vertex vv, then vv burns. The only difference between this rule and the original one is that now singleton hyperedges spontaneously burn in the sense that they cause the vertices they contain to burn immediately. Note that this cannot increase the lazy burning number. Further, no optimal lazy burning set will contain a vertex belonging to a singleton edge, and various bounds (such as |V⁡(H)|−|E⁡(H)|≤bL​(H)|V(H)|-|E(H)|\leq b_{L}(H) from [12]) remain unchanged with only minor variations in their proof.
In the zero forcing coloring process, a vertex subset of a graph GG is initially chosen to be black, while the remaining vertices are white (some authors alternatively refer to the colors as blue and white, respectively). Consider the following zero forcing color change rule: a black vertex uu can change the color of a white vertex vv if vv is the only white neighbor of uu; we say that uu forces vv or that vv is forced, and write u→v.u\rightarrow v.
A zero forcing set of GG is a set Z⊆V⁡(G)Z\subseteq V(G) of vertices such that if the vertices of ZZ are black and the rest are white, then every vertex eventually becomes black after repeated applications of the zero forcing color change rule. The minimum cardinality of a zero forcing set for a graph is known as the zero forcing number z⁡(G)z(G) of the graph GG. The skew zero forcing color change rule requires that if a vertex uu has exactly one white neighbor vv, then uu forces vv. The only difference between the two processes is that in skew zero forcing, a vertex does not need to be black to force one of its neighbors. A skew zero forcing set and the skew zero forcing number z0​(G)z_{0}(G) are defined analogously. As shown in [17], we have that z0​(G)≤z​(G)z_{0}(G)\leq z(G). For more background on these coloring processes, see [2, 15, 16, 17].
The paper is organized as follows. In Section 2, we define chronological lists of lazy burning on a hypergraph, which leads to the notion of a CC-matching. In Corollary 3, we prove that bL​(H)=|V⁡(H)|−m⁡(H)b_{L}(H)=|V(H)|-m(H), where m⁡(H)m(H) is the maximum cardinality of a CC-matching on the incidence graph of HH. This provides a formula for the lazy burning number of the dual hypergraph in Corollary 6 and provides various new lower and upper bounds on the lazy burning number. For example, Corollary 12 gives that in a linear hypergraph with minimum degree δ\delta with at least δ\delta hyperedges, bL​(H)≥|V⁡(H)|−|E⁡(H)|+(δ2)b_{L}(H)\geq|V(H)|-|E(H)|+\binom{\delta}{2}, while Theorem 15 shows that bL​(H)≤|V⁡(H)|−⌈|E⁡(H)|Δ⌉,b_{L}(H)\leq|V(H)|-\left\lceil\frac{|E(H)|}{\Delta}\right\rceil, where Δ\Delta is the maximum vertex degree. In Section 3, we characterize the lazy burning number of a hypergraph using its core, which is the hypergraph that results by iteratively deleting vertices in singleton hyperedges; see Theorem 21. Section 4 focuses on connections with zero forcing, and Theorem 25 shows that lazy burning is equivalent to zero forcing on incidence graphs. We prove in Theorem 27 that skew zero forcing on a graph is equivalent to lazy burning on its neighborhood hypergraph. Using this result, we prove that computing an upper bound on the lazy burning number of a hypergraph is NP-complete, which answers Problem 11 from [12]. In Theorem 35, we find applications of lazy burning to skew zero forcing and show the skew zero forcing problem on bipartite graphs is NP-complete. The final section lists open problems.
For more background on hypergraphs, see [3, 4, 10], and for more background on graph theory, see [19].
2. Chronological Lists and CC-Matchings
A concept gaining in popularity in the literature is a chronological list of zero forcing. Given an initial zero forcing set S0S_{0}, a list of forces (u1→v1,u2→v2,…,uk→vk)(u_{1}\rightarrow v_{1},u_{2}\rightarrow v_{2},\ldots,u_{k}\rightarrow v_{k}) is defined so that the list of sets S0,S1,S2,…,SkS_{0},S_{1},S_{2},\ldots,S_{k} with Si+1=Si∪{vi+1}S_{i+1}=S_{i}\cup\{v_{i+1}\} satisfies N⁡[ui]∖{vi}⊆Si−1N[u_{i}]\setminus\{v_{i}\}\subseteq S_{i-1}. Intuitively, if the set Si−1S_{i-1} is a subset of the black vertices at any time during the zero forcing process, then the vertex uiu_{i} will force the vertex viv_{i} in the next round if viv_{i} is not already black. It follows that SiS_{i} will be a subset of the black vertices at some time in the process. We note that we may have two vertices viv_{i} and vjv_{j}, with viv_{i} occurring earlier than vjv_{j} in the chronological list, but where vertex vjv_{j} would be forced by some black vertex in the zero forcing process in an earlier round than viv_{i}. A chronological list of skew zero forces may be defined analogously. If the context is clear, then we abbreviate the lists of either type as a chronological list of forces.
We illustrate chronological lists in Figure 1, where two adjacent black vertices, aa and bb, are initially chosen as our zero forcing set.
In the first zero forcing propagation round, cc and dd are forced by aa and b,b, respectively. In the second round, ee is forced by either cc or dd.
However, one possible chronological list of forces is (b→d,d→e,e→c)(b\rightarrow d,d\rightarrow e,e\rightarrow c), so cc is the last to be forced in the chronological list of forces, even though cc is forced before ee in the zero forcing process.

We note that, if Bk=V⁡(H)B_{k}=V(H), then B0B_{0} is a burning set for HH and k=n−|B0|k=n-|B_{0}|.
In the case that we take B0B_{0} to be a lazy burning set, if Bi−1B_{i-1} is burned at any time during the lazy burning process, then each vertex in hi∖{vi}h_{i}\setminus\{v_{i}\} is burned. Lemma 1.
If ({h1,v1},{h2,v2},…,{hk,vk})(\{h_{1},v_{1}\},\{h_{2},v_{2}\},\ldots,\{h_{k},v_{k}\}) is a chronological list of lazy burnings of HH, then

A matching in a graph is a set of edges such that no two edges in the set share a common vertex.

2.2. Upper Bounds
By decomposing a CC-matching into the set of vertices or the set of edges that are contained in the matching, we find that we have a vertex cover or edge cover of HH, respectively. This also provides us with a number of upper bounds on the lazy burning number of HH.
Lemma 13.
If HH is a hypergraph, then we have that any maximum CC-matching has cardinality at least that of a minimum vertex cover.
Proof.
Let M=(v1​h1,v2​h2,…,vk​hk)M=(v_{1}h_{1},v_{2}h_{2},\ldots,v_{k}h_{k}) be a CC-matching of the maximum possible length k=|V⁡(H)|−bL​(H)k=|V(H)|-b_{L}(H).
We will show that the set of vertices given by MV={v1,v2,…,vk}M_{V}=\{v_{1},v_{2},\ldots,v_{k}\} forms a vertex cover of HH.
Suppose for contradiction that MVM_{V} does not form a vertex cover. There must then be some hyperedge hh with none of its vertices in MVM_{V}.
For any vertex v∈hv\in h, the matched pair v​hvh may be appended to the CC-matching to form a longer CC-matching, contradicting maximality.
∎
The proof to show that the cardinality of a maximum CC-matching has at least that of the cardinality of a minimum edge cover of HH is analogous with dual terms interchanged. An isolated vertex is not in any hyperedge.
Lemma 14.
If HH is a hypergraph with no isolated vertices, then any maximum CC-matching has a cardinality at least the cardinality of a minimum edge cover of HH.
There are straightforward upper bounds on the minimum size of a vertex cover and an edge cover in terms of the maximum degree Δ⁡(H)\Delta(H) and maximum hyperedge cardinality Δ¯​(H)\overline{\Delta}(H), respectively.
Theorem 15.
If HH is a hypergraph with maximum vertex degree Δ\Delta, then
bL​(H)≤|V⁡(H)|−⌈|E⁡(H)|Δ⌉.b_{L}(H)\leq|V(H)|-\left\lceil\frac{|E(H)|}{\Delta}\right\rceil.
Proof.
We find a lower bound on the size of a vertex cover of HH, which combines with Lemma 14 to complete the proof.
If a vertex cover of HH contains tt vertices, then since each vertex is contained in at most Δ\Delta hyperedges, at most t​Δt\Delta hyperedges contain vertices from the vertex cover.
Since each hyperedge of E⁡(H)E(H) contains a vertex in the cover, we then have |E⁡(H)|≤t​Δ|E(H)|\leq t\Delta.
We then have that bL​(H)=|V⁡(H)|−m⁡(H)≤|V⁡(H)|−tb_{L}(H)=|V(H)|-m(H)\leq|V(H)|-t, and the result follows.
∎
In an analogous fashion, the hyperedges from a CC-matching form an edge cover of HH, from which we derive the following result using an edge cover instead of a vertex cover.
Theorem 16.
If HH is a hypergraph with maximum hyperedge cardinality Δ¯\overline{\Delta} that contains no isolated vertices, then
bL​(H)≤|V⁡(H)|−⌈|V⁡(H)|Δ¯⌉.b_{L}(H)\leq|V(H)|-\left\lceil\frac{|V(H)|}{\overline{\Delta}}\right\rceil.
In the above two results, we found that the set of vertices (respectively, edges) contained within a CC-matching formed a vertex (respectively, edge) cover of HH.
Instead, if we consider the ordered list of vertices (v1,v2,…,vk)(v_{1},v_{2},\ldots,v_{k}) coming from the restriction of a maximum CC-matching to just its vertices, then we arrive at a topic previously studied by the present authors in the context of burning Latin square hypergraphs; see [9].
An nn-uniform Latin square hypergraph, written HLH_{L}, has vertex set as the entries of the Latin square LL and hyperedges containing all vertices that share a given row, a given column, or a given symbol.
A cover-sequence of HLH_{L} is a sequence of vertices v1,v2,…,vkv_{1},v_{2},\ldots,v_{k} such that {v1,v2,…,vk}\{v_{1},v_{2},\ldots,v_{k}\} is a vertex cover of HLH_{L} and each viv_{i} does not share all three of its incident hyperedges with vertices that proceeded it in the sequence.
It is straightforward to see that the restriction of a CC-matching to its vertices satisfies these conditions.
Further, if we match a vertex viv_{i} to a hyperedge hih_{i} such that hih_{i} does not contain a vertex earlier in the sequence, then the constructed sequence of vertex-edge pairs forms a CC-matching on IG⁡(HL)\mathrm{IG}(H_{L}).
As such, CC-matchings of IG⁡(HL)\mathrm{IG}(H_{L}) are equivalent to cover-sequences of Latin squares, and so results in this section generalize results on the lazy burning of Latin squares in [9].
3. Hypergraph Cores
We introduce another characterization of lazy burning sets in terms of certain induced subhypergraphs. We are interested in the maximum induced subhypergraph so that every hyperedge is of cardinality greater than one. In the literature, this would correspond to the so-called 2-core of the dual hypergraph. For ease of notation, we refer to this simply as the core of HH, written core⁡(H)\mathrm{core}(H) (this is not to be confused with the core of a graph as used in graph homomorphism theory). The core can be obtained by continually deleting every hyperedge with cardinality one, along with the vertex it contains, until all remaining hyperedges have cardinality greater than one.
Let HH be a hypergraph and U⊆V⁡(H)U\subseteq V(H).
The subhypergraph of HH weakly induced by UU, denoted H⁡[U]H[U], is the hypergraph with V⁡(H⁡[U])=UV(H[U])=U and
E⁡(H⁡[U])={h∩U:h∈E⁡(H)​ and ​h∩U≠∅}.E(H[U])=\{h\cap U:h\in E(H)\text{ and }h\cap U\neq\emptyset\}.
This is also not to be confused with the strongly induced subhypergraphs; in the following, we mean an induced subhypergraph as a weakly induced subhypergraph since it is the only type of subhypergraph we are concerned with in this paper. We define the subhypergraph formed by vertex removal as H∖U=H⁡[V⁡(H)∖U]H\setminus U=H[V(H)\setminus U].

We provide another characterization of lazy burning in the following, which is the main result of the section.

The next result reduces the burning number of a hypergraph to the burning number of its core.
Theorem 22.

As an immediate corollary, we have the following.
Corollary 23.
For any hypergraph HH, bL​(H)=bL​(core⁡(H))b_{L}(H)=b_{L}(\mathrm{core}(H)).
By applying hypergraph cores, we show the monotonicity of lazy burning numbers with respect to vertex removal.
The following theorem contrasts with zero forcing, which is not monotone.
Theorem 24.
The lazy burning number is monotone under vertex removal; that is, for any vertex v∈V⁡(H)v\in V(H), bL​(H)−1≤bL​(H∖{v})≤bL​(H).b_{L}(H)-1\leq b_{L}(H\setminus\{v\})\leq b_{L}(H).

For the upper bound, let BB be an optimal lazy burning set for HH.
Suppose first that v∉Bv\notin B. Observe that B∪{v}B\cup\{v\} is a lazy burning set for HH, so H∖(B∪{v})H\setminus(B\cup\{v\}) is degenerate by Theorem 21. Also note that H∖(B∪{v})=(H∖{v})∖BH\setminus(B\cup\{v\})=(H\setminus\{v\})\setminus B and B⊆V⁡(H∖{v})B\subseteq V(H\setminus\{v\}), so we have that BB is a lazy burning set for H∖{v}H\setminus\{v\} by Theorem 21. We can therefore conclude that bL​(H∖{v})≤|B|=bL​(H)b_{L}(H\setminus\{v\})\leq|B|=b_{L}(H) in this case.
Now, suppose v∈Bv\in B. Observe that H∖B=(H∖{v})∖(B∖{v})H\setminus B=(H\setminus\{v\})\setminus(B\setminus\{v\}), and hence, they have the same core. 4. Complexity via Zero Forcing
The principal goal of this section is to show that computing an upper bound on the lazy burning number is NP-complete, which answers a conjecture in [12]. We first provide another characterization of lazy burning sets in hypergraphs via zero forcing sets in their incidence graphs.
Theorem 25.
For a hypergraph HH, a subset B⊆V⁡(H)B\subseteq V(H) is a lazy burning set for HH if and only if B∪E⁡(H)B\cup E(H) is a zero forcing set for IG⁡(H)\mathrm{IG}(H).
Proof.
For the forward direction, suppose that BB is a lazy burning set for HH.
Let k=|V⁡(H)|−|B|k=|V(H)|-|B| and consider a chronological list of lazy burning of S=({v1,h1},{v2,h2},…,{vk,hk})S=(\{v_{1},h_{1}\},\{v_{2},h_{2}\},\dots,\{v_{k},h_{k}\}) with the corresponding list of burned vertices B=B0,B1,…,Bk=V⁡(H)B=B_{0},B_{1},\dots,B_{k}=V(H).
For 0≤i≤k0\leq i\leq k, define Bi′=Bi∪E⁡(H)⊆V⁡(IG⁡(H))B_{i}^{\prime}=B_{i}\cup E(H)\subseteq V(\mathrm{IG}(H)).
For 1≤i≤k1\leq i\leq k, we have that hi∖{vi}⊆Bi−1h_{i}\setminus\{v_{i}\}\subseteq B_{i-1}.
It follows that NIG⁡(H)​(hi)∖{vi}⊆Bi−1⊆Bi−1′N_{\mathrm{IG}(H)}(h_{i})\setminus\{v_{i}\}\subseteq B_{i-1}\subseteq B_{i-1}^{\prime} in IG⁡(H)\mathrm{IG}(H), and hence, the list (h1→v1,h1→v2,…,hk→vk)(h_{1}\to v_{1},h_{1}\to v_{2},\dots,h_{k}\to v_{k}) is a chronological list of zero forcing in IG⁡(H)\mathrm{IG}(H), where B0′,B1′,…,Bk′B_{0}^{\prime},B_{1}^{\prime},\dots,B_{k}^{\prime} is the corresponding list of black vertices.
We may conclude that B∪E⁡(H)B\cup E(H) is a zero forcing set for IG⁡(H)\mathrm{IG}(H).
The reverse direction follows analogously by reversing the implications in the forward direction above.
∎
We note that Theorem 25 gives the new inequality
z⁡(IG⁡(H))≤bL​(H)+|E⁡(H)|.z(\mathrm{IG}(H))\leq b_{L}(H)+|E(H)|.
Denote the lazy burning number as defined in [18], where singleton hyperedges do not spontaneously burn, by bLo​(H)b_{L}^{o}(H). Consider the following decision problems.
PROBLEM: Lazy burning 
INSTANCE: A hypergraph HH and a positive integer k≤|V⁡(H)|k\leq|V(H)|.
QUESTION: Is bL​(H)≤kb_{L}(H)\leq k?
PROBLEM: Lazy burning without spontaneous burning 
INSTANCE: A hypergraph HH and a positive integer k≤|V⁡(H)|k\leq|V(H)|.

To show the NP-completeness of the two problems, we need the following theorem.
Theorem 26.
For every hypergraph HH, if HH contains no singleton hyperedge, then bLo​(H)=bL​(H)b_{L}^{o}(H)=b_{L}(H). Further, bLo​(core⁡(H))=bL​(H)b_{L}^{o}(\mathrm{core}(H))=b_{L}(H).
Proof.
For the first statement, if a list is a chronological list of lazy burning in one process, then it is also a chronological list of lazy burning in the other one. For the second statement, we have that bLo​(core⁡(H))=bL​(core⁡(H))=bL​(H)b_{L}^{o}(\mathrm{core}(H))=b_{L}(\mathrm{core}(H))=b_{L}(H), where the first equality holds since the core of a hypergraph contains no singleton hyperedge, and the second equality holds by Corollary 23.
∎
The symmetric and skew zero forcing decision problems are as follows.
PROBLEM: Zero forcing 
INSTANCE: A graph GG and a positive integer k≤|V⁡(G)|k\leq|V(G)|.
QUESTION: Is z⁡(G)≤kz(G)\leq k?
PROBLEM: Skew zero forcing 
INSTANCE: A graph GG and a positive integer k≤|V⁡(G)|k\leq|V(G)|.
QUESTION: Is z0​(G)≤kz_{0}(G)\leq k?
Let GG be a graph and N​(v)=NG​(v)N(v)=N_{G}(v) be the neighborhood of v∈V⁡(G)v\in V(G).
The open neighborhood hypergraph 𝒩⁡(G){\mathcal{N}}(G) is a hypergraph with V⁡(𝒩⁡(G))=V⁡(G)V({\mathcal{N}}(G))=V(G) and E⁡(𝒩⁡(G))={NG​(v):v∈V⁡(G)}E(\mathcal{N}(G))=\{N_{G}(v):v\in V(G)\}.
The closed neighborhood hypergraph 𝒩⁡[G]{\mathcal{N}}[G] is defined analogously with the hyperedge set consisting of the closed neighborhood N⁡[v]=NG​[v]=N⁡(v)∪{v}N[v]=N_{G}[v]=N(v)\cup\{v\} of each vertex in GG.
The following theorem characterizes skew zero forcing as lazy burning on the open neighborhood hypergraph.
Theorem 27.
Let GG be a graph and B⊆V⁡(G)B\subseteq V(G). The set BB is a skew zero forcing set for GG if and only if BB is a lazy burning set for 𝒩⁡(G)\mathcal{N}(G). In particular, z0​(G)=bL​(𝒩⁡(G))z_{0}(G)=b_{L}(\mathcal{N}(G)).
Proof.
Let ℬ=(B=B0,B1,…,Bk=V⁡(G))\mathcal{B}=(B=B_{0},B_{1},\dots,B_{k}=V(G)) be a list of vertex subsets, where k=|V⁡(H)|−|B|k=|V(H)|-|B|, and V⁡(H)∖B={v1,v2,…,vk}V(H)\setminus B=\{v_{1},v_{2},\dots,v_{k}\} is indexed so that Bi=Bi−1∪{vi}B_{i}=B_{i-1}\cup\{v_{i}\} for 1≤i≤k1\leq i\leq k.
Suppose that ℬ\mathcal{B} is the corresponding list of black vertices of a chronological list of skew zero forces of BB, say S=(u1→v1,u2→v2,…,uk→vk)S=(u_{1}\to v_{1},u_{2}\to v_{2},\dots,u_{k}\to v_{k}).
For 1≤i≤k1\leq i\leq k, we have that N⁡(ui)∖{vi}⊆Bi−1N(u_{i})\setminus\{v_{i}\}\subseteq B_{i-1}.
Hence, SS is a chronological list of skew zero forcing if and only if the list
({v1,N⁡(u1)},{v2,N⁡(u2)},…,{vk,N⁡(uk)})(\{v_{1},N(u_{1})\},\{v_{2},N(u_{2})\},\dots,\{v_{k},N(u_{k})\})
is a chronological list of lazy burning of BB on 𝒩⁡(G)\mathcal{N}(G).
∎
An analogous and so omitted argument proves the following.
Theorem 28.
Let GG be a graph and B⊆V⁡(G)B\subseteq V(G).
If BB is a zero forcing set for GG, then BB is a lazy burning set for 𝒩⁡[G]\mathcal{N}[G].
In particular, bL​(𝒩⁡[G])≤z⁡(G)b_{L}(\mathcal{N}[G])\leq z(G).
The converse of Theorem 28 does not hold. Let K1,jK_{1,j} be the star graph, where V⁡(K1,j)={v,u1,u2,…,uj}V(K_{1,j})=\{v,u_{1},u_{2},\dots,u_{j}\} and vv is the universal vertex.
Note that NK1,j​[v]=V⁡(K1,j)N_{K_{1,j}}[v]=V(K_{1,j}) and NK1,j​[ui]={v,ui}N_{K_{1,j}}[u_{i}]=\{v,u_{i}\} for each leaf uiu_{i}. We then have that
E⁡(𝒩⁡[K1,j])={V⁡(K1,j),v​u1,v​u2,…,v​uj}.E(\mathcal{N}[K_{1,j}])=\{V(K_{1,j}),vu_{1},vu_{2},\dots,vu_{j}\}.
The set {v}\{v\} is a lazy burning set for 𝒩⁡[K1,j]{\mathcal{N}}[K_{1,j}] since burning spreads via each edge v​ui∈E⁡(𝒩⁡[K1,j])vu_{i}\in E({\mathcal{N}}[K_{1,j}]).
Meanwhile, the zero forcing number of a star graph is j−1j-1 by initially forcing all leaves except one.
For completeness, we restate results on the complexity of skew zero forcing from [13]. We first need some terminology introduced there. For a graph GG, let T⁡(G)T(G) denote the graph obtained by “gluing a triangle” to each vertex of GG.
More precisely, V⁡(T⁡(G))=V⁡(G)×{1,2,3}V(T(G))=V(G)\times\{1,2,3\} and
E⁡(T⁡(G))={e×{1}:e∈E⁡(G)}∪{(v,i)(v,j):v∈V(G),i,j∈{1,2,3},i≠j}.\begin{split}E(T(G))=&\ \{e\times\{1\}:e\in E(G)\}\ \cup\\
&\ \{(v,i)(v,j):v\in V(G),i,j\in\{1,2,3\},i\neq j\}.\end{split}
In particular, the induced subgraph T​(G)​[V​(G)×{1}]T(G)[V(G)\times\{1\}] is isomorphic to GG using a canonical map such that (v,1)↦v(v,1)\mapsto v, for v∈V⁡(G)v\in V(G).
Theorem 29 ([13, Theorem 3.7]).
For a graph GG and B⊆V⁡(G)B\subseteq V(G), BB is a zero forcing set if and only if B×{1}B\times\{1\} is a skew zero forcing set for T⁡(G)T(G). Further, BB is optimal if and only if B×{1}B\times\{1\} is optimal; that is z⁡(G)=z0​(T⁡(G))z(G)=z_{0}(T(G)).
By Theorem 29, the skew zero forcing problem is at least as hard as the zero forcing problem, which is shown to be NP-complete in [1, 20]. We then have the following result.
Theorem 30 ([13, Corollary 3.8]).
The skew zero forcing problem is NP-complete.
We now state the main result of this section.
Theorem 31.
The lazy burning problem is NP-complete.
Proof.
Given a hypergraph HH and a vertex set B⊆V⁡(H)B\subseteq V(H), determining whether or not BB is a lazy burning set for HH takes polynomial time by determining whether or not H∖BH\setminus B is degenerate,
as in Theorem 21.
Theorem 18 states that Algorithm 1 can verify it in polynomial time. Hence, the lazy burning problem is in NP.
By Theorem 27, we know that 𝒩⁡(⋅)\mathcal{N}(\cdot) is a transformation from the skew zero forcing problem to the lazy burning problem. That is, if a vertex set B⊆V⁡(G)B\subseteq V(G) is a skew forcing a set of a graph GG, then B⊆V⁡(𝒩⁡(G))=V⁡(G)B\subseteq V(\mathcal{N}(G))=V(G) is a lazy burning set for the hypergraph 𝒩⁡(G)\mathcal{N}(G).
Note that 𝒩⁡(⋅)\mathcal{N}(\cdot) is a polynomial-time transformation.
Therefore, the lazy burning problem is NP-hard by Theorem 30, and hence, is NP-complete.
∎
We also derive the following.
Theorem 32.
The lazy burning problem without spontaneous burning is NP-complete.
Proof.
Given a hypergraph HH and a vertex subset BB, we first show that verifying whether or not BB is a lazy burning set can take polynomial time. This can be done by considering first taking another hypergraph H′H^{\prime} with V⁡(H′)=V⁡(H)V(H^{\prime})=V(H) and E⁡(H′)=E⁡(H)∖{e∈E⁡(H):|e|=1}E(H^{\prime})=E(H)\setminus\{e\in E(H):|e|=1\}. We know that BB is a lazy burning set without spontaneous burning if and only if H′∖BH^{\prime}\setminus B is degenerate. The first step takes O⁡(m)O(m)-time, and the second step takes O⁡(n​m)O(nm)-time by Theorem 18. In particular, the lazy burning problem without spontaneous burning is in NP.
The function core⁡(⋅)\mathrm{core}(\cdot) is a transformation from the lazy burning problem with spontaneous burning to the lazy burning problem without spontaneous burning, which is proved in Theorem 26. Hence, the lazy burning problem without spontaneous burning is NP-hard and, hence, is NP-complete.
∎
We may use the complexity results from lazy burning to analyze the complexity of the skew zero forcing numbers of bipartite graphs.
Given a bipartite graph G=(X∪Y,I)G=(X\cup Y,I), we may construct two hypergraphs H1H_{1} and H2H_{2}, where V⁡(H1)=XV(H_{1})=X, E⁡(H1)={NG​(y):y∈Y}E(H_{1})=\{N_{G}(y):y\in Y\}, and H2=H1∗H_{2}=H_{1}^{*}; that is, we may view every bipartite graph as a hypergraph H=(V,E)H=(V,E) by considering V=XV=X and E={NG​(y):y∈Y}E=\{N_{G}(y):y\in Y\}.
Note that the hyperedge set E=E⁡(H1)E=E(H_{1}) may be a multiset, and lazy burning performs identically on hypergraphs whenever E⁡(H1)E(H_{1}) is a set or a multiset.
Theorem 33.
Let HH be a hypergraph. We then have that BB is a lazy burning set for HH and B∗B^{*} is a lazy burning set for H∗H^{*} if and only if B∪B∗B\cup B^{*} is a skew zero forcing set for IG⁡(H)\mathrm{IG}(H).
In particular,
z0​(IG⁡(H))=bL​(H)+bL​(H∗).z_{0}(\mathrm{IG}(H))=b_{L}(H)+b_{L}(H^{*}).
Proof.
The proof is straightforward by considering that the neighborhood hypergraph of an incidence graph G=IG⁡(H)G=\mathrm{IG}(H) is precisely the disjoint union of H∪H∗H\cup H^{*}.
The statement follows by Theorem 27.
∎
We have the following by the alternative form of Corollary 6.
Corollary 34.
For any hypergraph HH,
z0​(IG⁡(H))=2​bL​(H)+|E⁡(H)|−|V⁡(H)|z_{0}(\mathrm{IG}(H))=2b_{L}(H)+|E(H)|-|V(H)|.
PROBLEM: Skew zero forcing on bipartite graphs
INSTANCE: A bipartite graph GG and an integer k≤|V⁡(G)|k\leq|V(G)|. 
QUESTION: Is z0​(G)≤kz_{0}(G)\leq k?
We arrive at the following new result on skew zero forcing. The results in [14] also give a similar characterization of skew zero forcing on bipartite graphs using special matchings, but our technique is essentially different.
Theorem 35.
The skew zero forcing problem on bipartite graphs is NP-complete.
Proof.
For a hypergraph HH, it takes polynomial time to generate the bipartite graph IG⁡(H)\mathrm{IG}(H). By Corollary 3, from a lazy burning set BB for HH, we obtain a CC-matching by performing the lazy burning process and then obtain a lazy burning set for H∗H^{*}.
Since verifying if a set of vertices is a skew zero forcing set for a graph takes polynomial time, and the lazy burning problem is NP-complete by Theorem 31, we have that the skew zero forcing problem on bipartite graphs is NP-complete.
∎
5. Further Directions
We presented several characterizations of lazy burning on hypergraphs via matchings and zero forcing. It would be interesting to see what new insights can be provided by these connections, especially in the case of zero forcing on graphs. The lazy burning of hypergraphs associated with Steiner Triple Systems was shown to equal their dimension; see
[11]. One question is to determine if there are relationships between the lazy burning number of hypergraphs associated with other designs, such as balanced incomplete block designs, and a natural notion of dimension.
A hypergraph is critical kk-burnable if bL​(H)=kb_{L}(H)=k, and removing any vertex results in the decrease of its lazy burning number. It would be interesting to characterize critical kk-burnable hypergraphs.
