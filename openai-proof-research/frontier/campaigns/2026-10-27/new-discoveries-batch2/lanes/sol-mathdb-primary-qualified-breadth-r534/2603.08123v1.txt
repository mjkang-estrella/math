A note on hyperseparating set systems



Dániel Gerbner

Note: HUN-REN Alfréd Rényi Institute of Mathematics, E-mail: gerbner@renyi.hu.



Abstract
    

We say that a set system  ${\mathcal{F}}$  is  $k$ -completely hyperseparating if for any vertex  $v$ , there are at most  $k$  sets in  ${\mathcal{F}}$  with intersection  $\{v\}$ . We determine the minimum size of such set systems on an  $n$ -element underlying set, generalizing a very recent result for  $k=2$  by Batíková, Kepka, and Nemĕc.
    

We say that  ${\mathcal{F}}$  is  $k$ -hyperseparating if for any vertex  $v$ , there are at most  $k$  sets in  ${\mathcal{F}}$  such that no other vertex is contained by exactly the same sets out of these  $k$  sets. We determine the minimum size of  $2$ -hyperseparating set systems on an  $n$ -element underlying set.
  




1 Introduction




A set system  ${\mathcal{F}}$  on an underlying set  $V$  is called separating if for any elements  $v\neq v^{\prime}$  of  $V$ , there is a set in  ${\mathcal{F}}$  that contains exactly one of them. This is a central object in the topic Search Theory/Group Testing (see [3] for a monograph), which seeks to find one (or more) hidden elements (usually called defective) in  $V$  by asking queries of the following form for some  $F\subset V$ : “Is the defective element contained in  $F$ ”? Asking all the sets in a family  ${\mathcal{F}}$  always finds the defective element if and only if  ${\mathcal{F}}$  is separating. Therefore, the goal is to minimize the size of separating set systems.




It is well-known and easy to see that if  $|V|=n$ , then the smallest size of a separating set system is  $\lceil\log_{2}n\rceil$ . Indeed, a simple construction is obtained by mapping the elements to  $\{1,\dots,n\}$  and taking the sets  $V_{i}:=\{j\leq n:\text{the $i$th digit of $j$ is 1}\}$ . On the other hand, if we list the sets that contain a given  $v\in V$ , we obtain a different list for different elements. There are  $2^{|{\mathcal{F}}|}$  possible lists, thus  $2^{|{\mathcal{F}}|}\geq n$ .




A natural variant is the so-called completely separating set system, where for any elements  $v\neq v^{\prime}$  of  $V$ , there is a set in  ${\mathcal{F}}$  that contains  $v$  but not  $v^{\prime}$  (note that there is also a set that contains  $v^{\prime}$  but not  $v$  by exchanging the role of  $v$  and  $v^{\prime}$ ). This notion was introduced by Dickson [2]. Spencer [6] proved that the smallest size of a separating set system is  $\min\{m:\binom{m}{\lfloor m/2\rfloor}\geq n\}$ . Note that completely separating set systems did not originally have a motivation from Search Theory, but later they also appeared in that area [5, 4].




Very recently, Batíková, Kepka and Nemĕc [1] introduced hypercompletely separating systems. They are set systems with the property that for every element  $v$  of the underlying set  $V$ , there are sets  $A,B$  in the set system with  $A\cap B=\{v\}$ . Note that  $A$  and  $B$  are not necessarily distinct. Batíková, Kepka and Nemĕc [1] determined the minimum size of a hypercompletely separating system on an  $n$ -element underlying set.




In this note, we consider two generalizations. We say that a set system  ${\mathcal{F}}\subset 2^{V}$  is  $k$ -hypercompletely separating if for any element  $v\in V$ , there are (not necessarily distinct) sets  $A_{1},\dots,A_{k}\in{\mathcal{F}}$  such that  $A_{1}\cap A_{2}\cap\dots\cap A_{k}=\{v\}$ . Note that the case  $k=2$  gives back the hypercompletely separating systems from [1].




One can rephrase the definition of completely separating set systems in the following way. For any element  $v\in V$ , the intersection of sets containing  $v$  is  $v$ . In other words, there are some sets in  ${\mathcal{F}}$  such that their intersection is  $v$ . Here, we assume that there are  $k$  or fewer sets in  ${\mathcal{F}}$  such that their intersection is  $v$ .




We determine the smallest size of a  $k$ -hypercompletely separating set system for every  $k$ . Let  $k^{\prime}=k^{\prime}(m)$  be  $k$  if  $m\geq 2k-1$  and  $\lfloor m/2\rfloor$  if  $m\leq 2k-1$ .



Proposition 1.1.



The smallest size of a  $k$ -hypercompletely separating set system on an  $n$ -element underlying set is  $\min\{m:\binom{m}{k^{\prime}}\geq n\}$ .





We also consider the analogous restriction for separating set systems. Observe that one can rephrase the definition of completely separating set systems the following way. For any element  $v\in V$ , there are some sets in  ${\mathcal{F}}$  such that knowing which ones of those sets contain  $v$  completely determines  $v$ .




We say that a set system  ${\mathcal{F}}\subset 2^{V}$  is  $k$ -hyperseparating if for any element  $v\in V$ , there are sets  $A_{1},\dots,A_{k}\in{\mathcal{F}}$  such that  $v\in A_{1},\dots,A_{i}$ ,  $v\not\in A_{i+1},\dots,A_{k}$ , and no other element of the underlying set satisfies this property.




Looking at the search theory motivation, we can assume that we want to determine the defective element, and then we want to provide at most  $k$  sets as witnesses. This can happen if witnesses are important but have a high cost.
Let  $f(n,k)$  denote the smallest size of a  $k$ -hyperseparating set system on an  $n$ -element underlying set.



Proposition 1.2.



If  $n>\binom{2k-1}{k}$ , then we have  $\min\{m:2^{k}\binom{m}{k}\geq n\}\leq f(n,k)\leq\min\{m:\binom{m}{k}\geq n\}$ .





We conjecture that the upper bound is sharp for large  $n$ , i.e., there is no smaller construction than the construction for  $k$ -hypercompletely separating sets systems.



Conjecture 1.3.



For any  $k$ , if  $n$  is sufficiently large, then
we have  $f(n,k)=\min\{m:\binom{m}{k}\geq n\}$ .





We can prove this conjecture for  $k=2$ .



Theorem 1.4.



We have




 $f(n,2)=\left\{\begin{array}[]{l l}\min\{m:\binom{m}{2}\geq n\}&\textrm{if\/ $n\geq 10$},\\
\lceil n/2\rceil&\textrm{if\/ $n\leq 10$}.\\
\end{array}\right.$ 








2 Proofs




Given a set system  ${\mathcal{F}}$  on  $V$  with  $|{\mathcal{F}}|=m$ , the dual (multi)set system  ${\mathcal{F}}^{\prime}$  is defined on the underlying set  ${\mathcal{F}}$ . Each  $v\in V$  defines a set  $F_{v}:=\{F\in{\mathcal{F}}:v\in F\}$  in  ${\mathcal{F}}^{\prime}$ , thus  ${\mathcal{F}}^{\prime}$  consists of  $n$  sets on an  $m$ -element underlying set. Observe that the dual of the dual system is isomorphic to the original set system.




A standard method in this area is to study what properties of  ${\mathcal{F}}^{\prime}$  are implied by the properties of  ${\mathcal{F}}$ . For example,  ${\mathcal{F}}$  is separating if and only if for any two vertices, there is a set that contains exactly one of them. This is equivalent to the property that in  ${\mathcal{F}}^{\prime}$ , for any two sets, there is an element that is contained in exactly one of them. This means that the sets are distinct, i.e., there are no multisets. In particular, there are at most  $2^{m}$  sets in  ${\mathcal{F}}^{\prime}$ , i.e.,  $n\leq 2^{m}$ , hence  $m\geq\lceil\log n\rceil$ . Since the  $2^{m}$  upper bound is sharp, the  $m\geq\lceil\log n\rceil$  lower bound is also sharp. In general, determining the minimum size of set systems satisfying some properties is equivalent to determining the maximum size of the dual set systems.




Similarly,  ${\mathcal{F}}$  is completely separating if and only if in  ${\mathcal{F}}^{\prime}$ , for every two sets  $A,B$  there are elements in  $A\setminus B$  and in  $B\setminus A$ . In other words, no set in  ${\mathcal{F}}^{\prime}$  contains another set in  ${\mathcal{F}}^{\prime}$ . Set systems with this property are called Sperner or antichain, and their maximum size was determined by Sperner [7].




Similarly,  ${\mathcal{F}}$  is  $k$ -hypercompletely separating if and only if for every set  $F\in{\mathcal{F}}^{\prime}$  there is a set  $S$  of size at most  $k$  that is a subset of  $F$ , but not a subset of any other member of  ${\mathcal{F}}^{\prime}$ . Moreover,  ${\mathcal{F}}$  is  $k$ -hyperseparating if and only if for every set  $F\in{\mathcal{F}}^{\prime}$  there is a set  $S$  of size at most  $k$  such that  $F\cap S\neq S\cap F^{\prime}$  for any  $F^{\prime}\in{\mathcal{F}}^{\prime}$  with  $F^{\prime}\neq F$ . In both cases, the set  $S$  is called a separator. Let  $S^{\prime}=S^{\prime}(F)=S\cap F$ . We call  $S^{\prime}$  the key of  $F$ .




Let us start with the proof of Proposition 1.1. It states that the smallest size of a  $k$ -hypercompletely separating set system on an  $n$ -element underlying set is  $\min\{m:\binom{m}{k^{\prime}}\geq n\}$ .



Proof of Proposition 1.1.



Consider the dual set system  ${\mathcal{F}}^{\prime}$  of a  $k$ -hypercompletely separating set system  ${\mathcal{F}}$ . Our goal is now to determine the largest size of such set systems.




If  $F\in{\mathcal{F}}^{\prime}$  has size larger than  $k$ , then we can replace  $F$  by  $S$ . Clearly,  $S$  was not in  ${\mathcal{F}}^{\prime}$ , since  $F$  is the only member of  ${\mathcal{F}}^{\prime}$  that contains  $S$ . Therefore, the size of  ${\mathcal{F}}^{\prime}$  does not change by this replacement, and for the new set  $S$ ,  $S$  will be a separator. Therefore, we can assume that each set in  ${\mathcal{F}}^{\prime}$  has size at most  $k$ . Also,  ${\mathcal{F}}^{\prime}$  must be a Sperner family, since a subset of  $F$  does not have any unique subgraph  $S$ . If  $m\leq 2k-1$ , then Sperner’s theorem [7] shows that  $|{\mathcal{F}}^{\prime}|\leq\binom{m}{k^{\prime}}$ . If  $m\geq 2k-1$ , then it is well-known that a Sperner family consisting of sets of size at most  $k$  has at most  $\binom{m}{k}$  sets.




This can be seen, for example, by the following argument. If there is a set of size less than  $k$  in  ${\mathcal{F}}^{\prime}$ , then we consider the subfamily  ${\mathcal{G}}$  of  ${\mathcal{F}}^{\prime}$  consisting of the sets of the smallest size  $\ell$ . Let  ${\mathcal{G}}^{\prime}$  consist of all the  $\ell+1$ -element subsets of the underlying set that contain at least one member of  ${\mathcal{G}}$ . Each set in  ${\mathcal{G}}$  is contained in  $m-\ell$  sets of  ${\mathcal{G}}^{\prime}$ , and each set in  ${\mathcal{G}}^{\prime}$  contains at most  $\ell+1<n-\ell$  sets of  ${\mathcal{G}}$ , thus  $|{\mathcal{G}}^{\prime}|>|{\mathcal{G}}|$ . We delete  ${\mathcal{G}}$  and add  ${\mathcal{G}}^{\prime}$  to  ${\mathcal{F}}^{\prime}$  in order to obtain a family  ${\mathcal{F}}^{\prime\prime}$ . Each set in  ${\mathcal{F}}^{\prime\prime}$  has size at most  $k$ , and  ${\mathcal{F}}^{\prime\prime}$  is a Sperner family. Indeed, the new sets of  ${\mathcal{F}}^{\prime\prime}$  do not contain any other set of  ${\mathcal{F}}^{\prime\prime}$ , since they have the smallest size in  ${\mathcal{F}}^{\prime\prime}$ . If  $G\in{\mathcal{G}}^{\prime}$  is contained in  $F\in{\mathcal{F}}^{\prime\prime}$ , then  $|F|>|G|$ , thus  $F\not\in{\mathcal{G}}^{\prime}$ . This implies that  $F\in{\mathcal{F}}^{\prime}$ . But  $F$  contains a set in  ${\mathcal{G}}^{\prime}$ , which contains a set in  ${\mathcal{G}}$ , thus  ${\mathcal{F}}^{\prime}$  is not a Sperner family, a contradiction. Therefore,  ${\mathcal{G}}^{\prime\prime}$  is indeed a Sperner family consisting of sets of size at most  $k$ , and is larger than  ${\mathcal{F}}$ , a contradiction.




We obtained that  $n=|{\mathcal{F}}^{\prime}|\leq\binom{m}{k^{\prime}}$ . This bound is sharp, as shown by the set system consisting of all the  $k^{\prime}$ -element sets. To obtain the bound on  $|{\mathcal{F}}|$ , observe that we showed that  $\binom{m}{k^{\prime}}\geq n$ . We can pick the smallest  $m$  satisfying this inequality, take the  $k^{\prime}$ -element sets on an  $m$ -element underlying set, and take its dual to obtain a  $k$ -hyperseparating family of the desired size.
∎





Let us continue with the proof of Proposition 1.2 that states that  $\min\{m:2^{k}\binom{m}{k}\geq n\}\leq f(n,k)\leq\min\{m:\binom{m}{k}\geq n\}$ .



Proof of Proposition 1.2.



Consider a  $k$ -hyperseparating set system  ${\mathcal{F}}$  on an  $n$ -element set  $V$ , and its dual  ${\mathcal{F}}^{\prime}$ .
Then  ${\mathcal{F}}^{\prime}$  has the property that for any set  $F\in{\mathcal{F}}^{\prime}$ , there is a set  $S$  of size at most  $k$  such that  $F\cap S\neq S\cap F^{\prime}$  for any  $F^{\prime}\in{\mathcal{F}}^{\prime}$  with  $F^{\prime}\neq F$ .




The upper bound follows from Proposition 1.1. For the lower bound, observe first that a set of size  $i$  can be the separator of at most  $2^{i}$  sets. This shows that  $|{\mathcal{F}}^{\prime}|\leq\sum_{i=0}^{k}2^{i}\binom{n}{i}$ .




Now, we are given a family  ${\mathcal{H}}$  of pairs  $(S,S^{\prime})$  of separators and keys, where  $|S|\leq k$  and  $S^{\prime}\subset S$ . Furthermore, we claim that for any pairs with the same key, i.e.,  $(S_{1},S^{\prime})$  and  $(S_{2},S^{\prime})$ , we have that  $S_{1}$  is not a subset of  $S_{2}$ . Indeed, otherwise let  $(S_{i},S^{\prime})$  belong to the set  ${\mathcal{F}}_{i}\in{\mathcal{F}}^{\prime}$ , i.e.,  $F_{i}\cap S_{i}=S^{\prime}$  and  $F_{i}$  is the only member of  ${\mathcal{F}}^{\prime}$  with this property. Then  $S^{\prime}\subseteq F_{1}\cup S_{1}\subseteq F_{2}\cap S_{1}\subseteq F_{2}\cap S_{2}=S^{\prime}$ . This shows that  $F_{1}$  is not the only set in  ${\mathcal{F}}^{\prime}$  that intersects  $S_{1}$  in  $S^{\prime}$ , a contradiction.




Consider now families  ${\mathcal{H}}$  of pairs  $(S,S^{\prime})$  on an  $m$ -element underlying set, where  $|S|\leq k$  and  $S^{\prime}\subset S$ , such that for each  $S^{\prime}$ , the the sets  $S$  with  $(S,S^{\prime})\in{\mathcal{H}}$  form a Sperner family. We claim that such families consist of at most  $2^{k}\binom{m}{k}$  pairs. To emphasize that we are dealing with abstract families satisfying the above conditions, instead of separator and key, we say that  $S$  is the large set of the pair and  $S^{\prime}$  is the small set.




Assume that  ${\mathcal{H}}$  has the maximum number of pairs. If all the large sets form a Sperner family, then there are at most  $\binom{n}{k}$  large sets by an argument inside the proof of Proposition 1.1, which implies the desired upper bound  $2^{k}\binom{n}{k}$ . This is not the property we have here, but we can use a similar argument. Note that the threshold on  $n$  means that  $m\geq 2k$ .




If there is a large set of size less than  $k$ , then we consider the subfamily  ${\mathcal{G}}$  of  ${\mathcal{H}}$  consisting of the large sets of the smallest size  $\ell$ , together with the corresponding small sets. Let  ${\mathcal{G}}^{\prime}$  consist of all the  $\ell+1$ -element subsets of the underlying set that contain at least one member of  ${\mathcal{G}}$ . Each set in  ${\mathcal{G}}$  is contained in  $m-\ell$  sets of  ${\mathcal{G}}^{\prime}$ , and each set in  ${\mathcal{G}}^{\prime}$  contains at most  $\ell+1<m-\ell$  sets of  ${\mathcal{G}}$ , thus  $|{\mathcal{G}}^{\prime}|>|{\mathcal{G}}|$ . For each set in  ${\mathcal{G}}^{\prime}$ , we add each  $S^{\prime}$  as a small set if  $S^{\prime}$  is the small set of a member of  ${\mathcal{G}}$ . Then  ${\mathcal{G}}^{\prime}$  is disjoint from  ${\mathcal{H}}$  and  ${\mathcal{G}}^{\prime}$  contains more pairs than  ${\mathcal{G}}$ . We delete  ${\mathcal{G}}$  and add  ${\mathcal{G}}^{\prime}$  to  ${\mathcal{H}}$  in order to obtain a family  ${\mathcal{H}}^{\prime}$ .




Each set in  ${\mathcal{H}}^{\prime}$  has size at most  $k$ . Indeed, the new sets in  ${\mathcal{H}}^{\prime}$  do not contain any other set of  ${\mathcal{H}}^{\prime}$ , since they have the smallest size in  ${\mathcal{H}}^{\prime}$ . We have to show that for each small set  $S^{\prime}$ , the corresponding large sets form a Sperner family. Indeed, a new large set  $S$  cannot be the subset of a new large set, since they have the same size, and cannot be the subset of an old large set  $S_{1}$  where  $S_{1},S^{\prime}$  is in  ${\mathcal{H}}$ .  $S$  also cannot contain any member of  ${\mathcal{H}}^{\prime}$ , since  $S$  has the smallest size in  ${\mathcal{H}}^{\prime}$ .




We obtained that  ${\mathcal{H}}^{\prime}$  satisfies our assumptions on the family, thus  ${\mathcal{H}}$  did not contain the largest number of pairs, a contradiction, completing the proof.
∎





Let us continue with the proof of Theorem 1.4, which states that  $f(n,2)$  is the smaller of  $\min\{m:\binom{m}{2}\geq n\}$  and  $n/2$ .



Proof of Theorem 1.4.



Consider a  $2$ -hyperseparating set system  ${\mathcal{F}}$  on an  $n$ -element set  $V$ , and its dual  ${\mathcal{F}}^{\prime}$ .
Then  ${\mathcal{F}}^{\prime}$  has the property that for any set  $F\in{\mathcal{F}}^{\prime}$ , there is a set  $S$  of size at most 2 such that  $F\cap S\neq S\cap F^{\prime}$  for any  $F^{\prime}\in{\mathcal{F}}^{\prime}$  with  $F^{\prime}\neq F$ . We call such families nice.
Our goal is to determine the largest size of nice families on an  $m$ -element underlying set, which we denote by  $g(m)$ . We need to show that  $g(m)$  is at most the larger of  $\binom{m}{2}$  and  $2m$ .




Given a family  ${\mathcal{F}}^{\prime}$  and an element  $v$ , we say that we switch  $v$  if we remove it from the sets in  ${\mathcal{F}}^{\prime}$  that contain  $v$  and add it to those that do not contain  $v$ . In other words, we obtain the family
 $\{F\cup\{v\}:v\not\in F,\,F\in{\mathcal{F}}^{\prime}\}\cup\{F\setminus\{v\}:v\in F\in{\mathcal{F}}^{\prime}\}$ .
Observe that for a nice family  ${\mathcal{F}}^{\prime}$ , we can switch any element to obtain another nice family. Indeed, the same  $S$  will be a separator.




Let us consider two vertices  $x,y$  with the property that  $\{x,y\}$  is the separator for at least two sets  $F,F^{\prime}\in{\mathcal{F}}^{\prime}$ . There are two cases, either  $S^{\prime}(F)$  and  $S^{\prime}(F^{\prime})$  differ by one element or by two elements. By switching elements, we can assume that either  $S^{\prime}(F)=\{x,y\}$  and  $S^{\prime}(F^{\prime})=\{x\}$ , or  $S^{\prime}(F)=\{x,y\}$  and  $S^{\prime}(F^{\prime})=\emptyset$ .




In the first case, among the sets that contain  $x$ , only one contains  $y$ , and only one does not contain  $y$ . Let us delete  $x,F,F^{\prime}$ . Then the resulting set system  ${\mathcal{G}}$  on  $m-1$  vertices has the property that for any set, we have a separator of size 2. Note that the separator here could contain  $x$ , hence it is not obvious that  ${\mathcal{G}}$  is a nice family on  $m-1$  vertices. However, in this particular case, it is easy to see that  $x$  does not actually separate sets in  ${\mathcal{G}}$ , i.e., we could delete  $x$  from any separator to obtain another separator in  ${\mathcal{G}}$ . This shows that  ${\mathcal{G}}$  is nice, thus  ${\mathcal{F}}^{\prime}$  has size at most  $g(m-1)+2$ .




In the second case, we delete  $x,y,F,F^{\prime}$  and add a new element  $z$ . We add  $z$  to each set that contains  $x$  but not  $y$ . Let  ${\mathcal{G}}$  denote the resulting set system. We show that  ${\mathcal{G}}$  is nice. Consider  $G\in{\mathcal{G}}$ . By switching, we can assume that  $G$  does not contain  $z$ , i.e.,  $G\in{\mathcal{F}}^{\prime}$ ,  $x\not\in G$  and  $y\in G$ . Consider the separator  $S(G)$  in  ${\mathcal{F}}^{\prime}$  (note that  $G$  may have a different separator in  ${\mathcal{G}}$ ). If  $x,y\not\in S(G)$ , then  $S(G)$  is still a separator in  ${\mathcal{G}}$ .




If  $S(G)=\{x,w\}$  for some  $w\neq y$ , that means that  $G$  is the only set in  ${\mathcal{F}}^{\prime}$  that does not contain  $x$  and contains  $w$  if and only if  $w$  is in the key  $S^{\prime}(G)$ . Then  $G$  is the only set in  ${\mathcal{G}}$  that does not contain  $z$  and contains  $w$  if and only if  $v$  is in the key  $S^{\prime}(G)$ . Indeed, if  $G^{\prime}\in{\mathcal{G}}$  also does not contain  $z$  and contains  $w$  if and only if  $w$  is in the key  $S^{\prime}(G)$ , then  $G^{\prime}$  does not contain  $x$ , hence in  ${\mathcal{F}}^{\prime}$  intersects  $S(G)$  in  $S^{\prime}(G)$ , a contradiction.




If  $S(G)=\{y,w\}$  for some  $w\neq x$ , that means that  $G$  is the only set in  ${\mathcal{F}}^{\prime}$  that contains  $y$  and contains  $w$  if and only if  $w$  is in the key  $S^{\prime}(G)$ . Then  $G$  is the only set in  ${\mathcal{G}}$  that does not contain  $z$  and contains  $w$  if and only if  $v$  is in the key  $S^{\prime}(G)$ . Indeed, if  $G^{\prime}\in{\mathcal{G}}$  also does not contain  $z$  and contains  $w$  if and only if  $w$  is in the key  $S^{\prime}(G)$ , then  $G^{\prime}$  does not contain  $x$ , hence in  ${\mathcal{F}}^{\prime}$  intersects  $S(G)$  in  $S^{\prime}(G)$ , a contradiction.




Finally, if  $S(G)=\{x,y\}$ , that means that  $G$  is the only set in  ${\mathcal{F}}^{\prime}$  that does not contain  $x$  and contains  $y$ , but then we are in the first case.




We have obtained that if a 2-set is the separator for more than one member of  ${\mathcal{F}}$ , then  $g(m)\leq g(m-1)+2$ . Otherwise, each 2-set is a separator at most once, and each 1-set is a separator at most twice. Assume that a 1-set is a separator  $S$ . Let  $S=\{x\}$ , and by switching we can assume that  $S^{\prime}=S$ , i.e., exactly one set  $F\in{\mathcal{F}}^{\prime}$  contains  $x$ . Then we delete  $F$  and  $x$ , and in the rest we obtain a nice set system on  $m-1$  vertices, thus  ${\mathcal{F}}^{\prime}$  contains at most  $g(m-1)+1$  sets.




We have obtained that either  $|{\mathcal{F}}^{\prime}|\leq\binom{m}{2}$ , or  $|{\mathcal{F}}^{\prime}|\leq g(m-1)+2$ .
Clearly,  $g(1)\leq 2$  and  $g(2)\leq 4$ , thus  $g(3)\leq\max\{6,\binom{3}{2}\}=6$ ,  $g(4)\leq\max\{8,\binom{4}{2}\}=8$  and  $g(5)\leq\max\{10,\binom{5}{2}\}=10$ . This shows that  $g(5)=10$  and for  $m>5$ , we can see by induction that  $g(m)\leq\binom{m}{2}$ . Indeed, either we do have this bound immediately, or we have that  $g(m)\leq g(m-1)+2\leq\binom{m-1}{2}+2<\binom{m}{2}$ .




Let us show some constructions for  $m\leq 3$ .
For  $m=1$ , the two sets are  $\emptyset$  and the full set  $\{v\}$ , and for both of these sets  $F$  we have  $S=S^{\prime}=F$ . For  $m=2$ , we have all four sets in  ${\mathcal{F}}$ , and for each set  $F$  we have  $S=V$ ,  $S^{\prime}=F$ . For  $m=3$ , we take all the 1-element and 2-element sets. If  $|F|=2$ , then  $S=S^{\prime}=F$ , while if  $|F|=1$ , then  $S^{\prime}=\emptyset$  and  $S$  is the complement of  $F$ .




Finally, consider the case  $m=4$ . A simple construction of 8 sets was found by Claude Opus 4.6. The sets in the underlying set  $\{1,2,3,4\}$  are  $\emptyset$  with witness  $\{1,2\}$ ,  $\{1\}$  with witness  $\{1,3\}$ ,  $\{2\}$  with witness  $\{2,4\}$ ,  $\{1,3\}$  with witness  $\{3,4\}$ ,  $\{2,4\}$  with witness  $\{3,4\}$ ,  $\{1,3,4\}$  with witness  $\{2,4\}$ ,  $\{2,3,4\}$  with witness  $\{1,3\}$ , and  $\{1,2,3,4\}$  with witness  $\{1,2\}$ .
∎
