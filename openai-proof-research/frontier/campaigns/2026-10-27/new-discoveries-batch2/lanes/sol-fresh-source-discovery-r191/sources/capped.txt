                                                                                              Abstract
                                                        An ordered graph is capped if, for any four vertices a < b < c < d, the edges ac and
                                                     bd imply the edge ad. We prove that every nonempty capped graph G satisfies χ(G) ≤
                                                     min{3ω(G)−1 , 18ω(G)3 }, where χ(G) and ω(G) are its chromatic number and clique number.
                                                     This proves a conjecture of Davies, Krawczyk, McCarty and Walczak [3].

                                           Mathematics Subject Classification (2020): 05C15.
                                           Keywords: Capped graphs; ordered graphs; chromatic number; polynomial χ-boundedness.


                                           1        Introduction
                                           All graphs are finite, simple and undirected. For a graph G, write V (G) and E(G) for its vertex
                                           set and edge set. The subgraph induced by X ⊆ V (G) is G[X], and G − v = G[V (G) \ {v}].
                                           A spanning subgraph of G has vertex set V (G). The neighborhood of a vertex v is NG (v), its
                                           degree is |NG (v)|, and NG (X) = v∈X NG (v). Disjoint vertex sets are anticomplete if there is no
                                                                              S

                                           edge between them. A clique is a set of pairwise adjacent vertices, and a stable set is a set of
                                           pairwise nonadjacent vertices. The maximum size of a clique is ω(G). A triangle is a clique of
                                           size three, and a graph is triangle-free if it has no triangle. A forest has no cycle, and a bipartite
                                           graph has a partition into two stable sets. An induced path has no edges between nonconsecutive
                                           vertices.
                                               A proper coloring assigns different colors to adjacent vertices, and χ(G) is the minimum
                                           number of colors needed. A palette is the set of available colors. A color class is the set of vertices
                                           assigned a particular color. A set of colored vertices is monochromatic if all its vertices have the
                                           same color. We use the convention χ(G) = ω(G) = 0 when G has no vertices.
                                               A class of graphs is χ-bounded if there is a function f such that χ(H) ≤ f (ω(H)) for every
                                           nonempty induced subgraph H of a graph in the class. It is polynomially χ-bounded if f can
                                           be chosen to be a polynomial. For background on χ-boundedness, see the survey of Scott and
                                           Seymour [5].
                                               An ordered graph is a graph together with a fixed linear order v1 < · · · < vn on its vertices.
                                           For vertex sets X, Y , the notation X < Y means that every vertex of X precedes every vertex of
                                           Y ; the same notation is used when either set is a single vertex. Throughout, left and right refer
                                           to this vertex order. Two edges cross if their endpoints occur in the order a < b < c < d and the
                                           edges are ac, bd. An ordered graph is capped if every such pair of crossing edges has the edge ad,
                                           called its cap. All induced subgraphs carry the restricted order. Taking an induced subgraph or
                                           reversing the order preserves cappedness.

                                                                                                 1
   Capped graphs were studied by Davies, Krawczyk, McCarty and Walczak [3] in connection
with visibility graphs of polygons. The visibility graph of a simple polygon has the polygon
vertices as its vertices; two are adjacent if the segment joining them lies in the closed region
bounded by the polygon. The vertex order follows the polygon boundary.
   Capped graphs are also called terrain-like graphs; their enumeration was studied by Froese and
Renken [4]. Compact representations of these graphs were studied by Cardinal and Yuditsky [2]
and Cardinal and Sharir [1].
   Davies, Krawczyk, McCarty and Walczak [3] proved that every capped graph with clique
number w ≥ 2 has chromatic number at most 4w (w − 1). They conjectured that the class of
capped graphs is polynomially χ-bounded [3]. We prove the following bound.
Theorem 1.1. Every nonempty capped graph G satisfies χ(G) ≤ min{3ω(G)−1 , 18ω(G)3 }.
    If G has at least one edge, the proof gives the slightly stronger polynomial bound 18(ω(G)3 −
ω(G)). The exponential bound gives three colors when ω(G) = 2, and this is best possible: the
five-cycle v1 v2 v3 v4 v5 v1 , ordered as v1 < v2 < v3 < v4 < v5 , has no crossing edges and requires
three colors.
    An ordered hole is an induced cycle c1 c2 · · · ck c1 with k ≥ 4 and c1 < · · · < ck . Davies,
Krawczyk, McCarty and Walczak [3] noted that three-colorability of triangle-free capped graphs
containing no ordered hole would improve their coloring bounds. Corollary 2.3 proves three-
colorability for all triangle-free capped graphs.
    The paper is organized as follows. Section 2 proves a three-color extension lemma for triangle-
free capped graphs. In Section 3, we define edge ranks and obtain the exponential bound.
Section 4 develops the forest construction and uses it to prove the cubic bound.


2    Triangle-free capped graphs
An ordered partition L < X < B consists of three disjoint sets covering the vertex set, with all
vertices of L first, then those of X, and then those of B. We call X the interior and L, B the left
and right boundaries. A prescribed coloring of L ∪ B is proper on the induced graph on that set.
To extend it means to keep every prescribed color.
    The three-color extension lemma below requires L to be monochromatic and B to contain at
most one vertex. We first prove the following bipartiteness lemma.
Lemma 2.1. Let G be a capped ordered graph with a partition V (G) = S ∪ U . Suppose that
every vertex of S has only greater neighbors. Suppose also that, for every edge xy with x < y and
x, y ∈ U , the vertex x is the least neighbor of y in G. Then G is bipartite.
Proof. All the hypotheses are preserved under induced restriction, so we induct on |V (G)|. The
assertion is immediate if G has no vertices. If S is empty, the greatest vertex has degree at most
one: two neighbors x < y would contradict the least-neighbor condition on the edge from y to
that vertex. Delete the vertex, color the remaining graph with two colors by induction, and
restore it with an available color.
    Suppose S is nonempty, let s = max S, and let T = {v ∈ V (G) : s < v}. If G[T ] has an edge,
choose the greatest vertex y that is nonisolated in G[T ], and let x ∈ T be a neighbor of y. Then
x < y, and y has no greater neighbor in G. Since x, y ∈ U , the least neighbor of y is x > s. Thus
y has no neighbor in S. It has no second neighbor in U either, since each such neighbor would
also have to be its least neighbor. Hence y has degree one, and deletion and restoration again
complete the coloring.
    It remains to consider the case that T is stable. All neighbors of s are in T . If u < v are
neighbors of s, then NG (u) ⊆ NG (v). Indeed, any t ∈ NG (u) \ {s} is before s, and the edges
tu, sv at t < s < u < v give tv by cappedness.

   Color G − s with two colors by induction. If s is isolated, give it either color. Otherwise let
d = max NG (s). For any u ∈ NG (s) \ {d} that is not isolated in G − s, choose t ∈ NG (u) \ {s}.
The inclusion just proved gives td, so the two-edge path u, t, d in G − s forces u and d to have
the same color. Give every neighbor of s that is isolated in G − s the color of d as well. All
neighbors of s now have one color, so the other color can be assigned to s.

Lemma 2.2. Let G be a triangle-free capped ordered graph with an ordered partition L < X < B,
where L is stable and B is empty or a singleton {b}. Every proper coloring of G[L ∪ B] with a
palette of three colors, monochromatic on L, extends to a proper coloring of G with the same
palette.

Proof. We induct on |X|, for all graphs and boundary colorings in the statement. If X is empty,
there is nothing to prove.
    Let α be the prescribed color on L; if L is empty, choose any color of the palette as α. Let Q
be the other two colors, and let T = NG (L) ∩ X. Thus T is exactly the set of interior vertices
with a neighbor in L.
    If T is empty, let x be the least vertex of X. Give x a color different from the color of b when
b exists, and any color otherwise. In the induced graph G[X ∪ B], use {x} as the left boundary,
X \ {x} as the interior, and B as the right boundary. The prescribed boundary coloring is
proper, and the interior is smaller. The induction hypothesis colors this graph. Together with
the original coloring of L, this colors G: there are no edges from L to X, and the prescribed
edges from L to B are already proper.
   Assume for the rest of the proof that T is nonempty. Say that a vertex contacts a set if it
has a neighbor in that set. We need the following three facts about these contacts.
 (i) If x ∈ T , x < y with y ∈ X ∪ B, and xy ∈ E(G), then y has no neighbor z ∈ X with z < x.
     For otherwise choose an L-neighbor a of x. The order a < z < x < y and the edges ax, zy
     give ay by cappedness. Then a, x, y form a triangle.
(ii) Each component D of G[X \ T ] is contained in a single gap of T : before its first vertex,
     between two consecutive vertices of T , or after its last vertex. Moreover, D has at most one
     contact in T to its left, and that contact, if present, is the last vertex of T before the gap.
     To prove the first assertion, an edge xz of G[X \ T ] cannot satisfy x < y < z for y ∈ T .
     An L-neighbor a of y would give az from the crossing edges ay, xz, contrary to z ∈/ T. A
     path in G[X \ T ] therefore cannot pass from one gap to another. For the second assertion,
     suppose that a vertex x ∈ T contacts D and another vertex y ∈ T is between x and D.
     Choose d ∈ D adjacent to x and an L-neighbor a of y. The order a < x < y < d gives ad
     from ay, xd, contrary to d ∈
                                / T.
(iii) If b exists and has no neighbor in L, then every neighbor of b in X is at or after every vertex
      of T . Indeed, if ub is an edge with u < x for some x ∈ T , an L-neighbor a of x gives ab
      from ax, ub at a < u < x < b, a contradiction. In particular, a component D of G[X \ T ]
      contacting b is after all of T . Its contacts to the right among T ∪ B are then exactly {b}.
    To color T with the two colors in Q, retain b if it exists and its prescribed color is different
from α; otherwise omit it for the moment. Let P consist of T and the retained vertex b, if
any. Construct an ordered graph A with vertex set P ∪ {sD : D ∈ D}, where D is the set of
components of G[X \ T ]. Each sD is a new symbol placed at the position of min D in the order.
Keep every original edge with both ends in P . Join sD to t ∈ P precisely when every vertex of D
is before t and t contacts D. There are no other edges. Thus symbols have only greater neighbors,
and no two symbols are adjacent. The symbols will make all right contacts of a component
receive one color, so that induction can later be applied to that component in the reversed order.


                                                 3
    The components need not be intervals in the order, so we check cappedness of A using their
connectedness. Associate a set Cx to each vertex x of A: Cx = {x} for x ∈ P , and CsD = D for
a symbol. These sets are pairwise disjoint and each is connected in G.
    Take edges xz, yt of A with x < y < z < t. Their greater endpoints z, t are in P . Also
z ∈ T , since a retained b is the last vertex. By (ii), every vertex of Cx ∪ Cy is before z. Choose
witnessing original edges cz and dt with c ∈ Cx and d ∈ Cy . If c < d, then c < d < z < t gives ct.
If d < c, the order in A gives min Cx < min Cy ≤ d < c < z. A path in G[Cx ] from its minimum
to c has an edge ef with e < d < f < z, since d ∈ / Cx . The cap of ef and dt is et. Equality c = d
is impossible by disjointness. In both cases Cx contacts t; all of Cx is before t, so xt is an edge of
A by its definition.
    For an edge xy of A with x < y and x, y ∈ P , we have x ∈ T . There is no neighbor of y in P
before x, by (i). Nor can a symbol sD < x be adjacent to y: (ii) puts the whole of D before x,
and a witnessing edge from D to y would contradict (i). Therefore x is the least neighbor of y in
A. Lemma 2.1 applies with S the set of symbols and U = P .
    Properly color A with the two colors in Q. If b was retained, interchange the two colors on its
connected component if needed to give b its prescribed color. This is the only prescribed color in
A. Transfer the colors of the vertices of T to G and discard the symbol colors. This properly
colors G[L ∪ T ∪ B]: the colors on T are in Q, every edge within T or from T to a retained b was
colored in A, and an omitted b has color α. Edges from L to B retain their prescribed colors.
    For D ∈ D, let aD denote its possible contact in T to the left, which is unique by (ii). Let
RD be its full set of contacts in T ∪ B to the right. Each vertex of T is either wholly before or
wholly after D, so these sets account for every contact of D in T ∪ B.
    If D does not contact an omitted b, then RD = NA (sD ). All these vertices have the color
opposite to the color of sD in the two-coloring of A, and hence RD is monochromatic. It is also
stable in G: every original edge between two of its vertices was retained in A. If D contacts an
omitted b, then b has color α. Properness of the prescribed coloring on L ∪ B implies that b has
no neighbor in L. By (iii), RD = {b}. Thus in every case RD is stable and monochromatic; an
empty RD is allowed.
    Consider the induced graph on RD ∪ D ∪ {aD }, omitting aD if there is no left contact, and
reverse its order. Its left boundary is now RD , its interior is D, and its optional right boundary
is aD . Its boundary coloring is proper because all edges from aD to RD are already properly
colored in G[L ∪ T ∪ B]. The graph remains triangle-free and capped. Since T is nonempty,
|D| < |X|, so the induction hypothesis extends this boundary coloring over D.
    Do this for each component D. Different interiors are anticomplete because they are different
components of G[X \ T ]. They have no neighbors in L, by the definition of T , and all of their
contacts in T ∪ B were included in their boundaries. Every extension preserves the already
assigned colors, so the extensions combine to color all of G. If X = T , no further extension is
needed.

    Taking both boundaries empty in Lemma 2.2 gives the following consequence.

Corollary 2.3. Every triangle-free capped ordered graph is three-colorable.


3    Edge ranks and the exponential bound
Davies, Krawczyk, McCarty and Walczak [3] proved that the edges of a capped graph G with an
edge can be partitioned into ω(G) − 1 triangle-free capped subgraphs. We give a rank proof of
this decomposition; the rank inequalities will also be used in the forest construction.




                                                  4
    Fix a capped ordered graph G with an edge, and write w = ω(G) and q = w − 1. For each
original edge uv with u < v, define its rank by

                                p(uv) = ω G[{x ∈ NG (v) : x ≤ u}] .                                  (1)
                                                                     


The set in this definition contains u, so p(uv) ≥ 1. Adjoining v to a clique in that set gives a
larger clique of G, so p(uv) ≤ q. A clique attaining p(uv) will be used as a witness for the rank.
Such a clique need not contain u. For a path a < b < c, we call p(ab) and p(bc) its incoming and
outgoing ranks, respectively.

Lemma 3.1. The ranks in (1) have the following properties.
  (i) If ac, bd ∈ E(G) and a ≤ b < c ≤ d, then ad ∈ E(G) and p(ac) ≤ p(ad) ≤ p(bd).
 (ii) If a < b < c form a triangle in G, then p(bc) ≥ p(ab) + 1.

Proof. For (i), the edge ad is already one of the assumed edges if a = b or c = d. In the remaining
case it follows from cappedness. Let K be a clique witnessing p(ac), so each x ∈ K satisfies
x ≤ a and xc ∈ E(G).
    If c < d and x < b, the order x < b < c < d and the edges xc, bd give xd. The only remaining
possibility is x = b, which forces x = a = b and uses the given edge bd. If c = d, the adjacency
to d was already part of the choice of K. Thus K is contained in NG (d) ∩ {x : x ≤ a}, proving
p(ac) ≤ p(ad). The inclusion NG (d) ∩ {x : x ≤ a} ⊆ NG (d) ∩ {x : x ≤ b} proves the second
inequality.
    For (ii), take a clique K witnessing p(ab). The same transfer argument, applied to the edges
ab and ac, puts every vertex of K in NG (c). Each vertex of K is also adjacent to b and is at
most a < b. Hence K ∪ {b} is a clique in the prefix of NG (c) through b, which proves (ii).

    For 1 ≤ h ≤ q, let Gh be the spanning subgraph of G whose edges have rank exactly h. If
two edges of Gh cross, Lemma 3.1(i) forces their cap also to have rank h. Thus Gh is capped. It
is triangle-free by Lemma 3.1(ii), since a triangle a < b < c satisfies p(bc) > p(ab).
    By Corollary 2.3, fix a proper coloring φh : V (G) → {1, 2, 3} of each Gh . Give v the tuple
(φ1 (v), . . . , φq (v)). Every original edge has some rank h, and its ends receive different entries in
coordinate h. We obtain the following bound.

Proposition 3.2. Every nonempty capped ordered graph G satisfies χ(G) ≤ 3ω(G)−1 .

   The edgeless case needs one color. When this proposition is applied to a different graph, its
ranks are computed within that graph; the ranks p assigned to the edges of G remain fixed.


4     The cubic bound
4.1    Selecting forests from ordered neighborhoods
We next select forests whose edges meet certain induced paths on three vertices. Let G be a
capped ordered graph.
   Let B ⊆ V (G) be a set of potential centers. For each b ∈ B, choose sets Ab and Cb of
neighbors of b such that Ab < b < Cb ; call them its left and right shores. These sets may be
empty, and shores of different centers may overlap. A vertex in a shore may itself be a potential
center.




                                                   5
Lemma 4.1. Suppose that a graph Γ on B satisfies the following two conditions.
 (i) If b, t ∈ B and t ∈ Ab ∪ Cb , then bt ∈ E(Γ).
 (ii) If r < a < c < t, where r, t ∈ B, a ∈ At , and c ∈ Cr , then rt ∈ E(Γ).
Let W ⊆ B be stable in Γ. Each vertex v ∈ V (G) \ W makes the following selections, when the
indicated set of centers is nonempty:
 • it selects the least b ∈ W with b < v and v ∈ Cb ;
 • it selects the greatest b ∈ W with v < b and v ∈ Ab .
Let FW be the spanning subgraph of G consisting of the selected edges. Then FW is a forest.
Moreover, whenever a < b < c is an induced path in G with b ∈ W , a ∈ Ab and c ∈ Cb , at least
one of ab, bc belongs to FW .

Proof. No vertex of W belongs to a shore of another vertex of W : condition (i) would give an
edge inside the stable set W in Γ. In particular, the endpoints a, c of every path in the statement
are outside W . Each selected edge has exactly one end in W and one end outside it, and each
vertex outside W selects at most one center on either side.
    Suppose that FW has a cycle. It alternates between k distinct centers in W and k distinct
vertices outside W , for some k ≥ 2. Each outside vertex on the cycle has two selected cycle edges.
Since it selects at most one center on each side, it is strictly between its two cycle centers.
    Order the k cycle centers. Every outside vertex on the cycle is in one of the k − 1 gaps between
consecutive cycle centers. Since there are k such outside vertices, two of them, say v < w, are in
the same gap. Let r be the cycle center selected by w to its left, and let t be the cycle center
selected by v to its right. There is no cycle center between v and w, so r < v < w < t. The
selections give v ∈ At and w ∈ Cr . Condition (ii) therefore gives rt ∈ E(Γ), contrary to r, t ∈ W .
Thus FW is a forest.
    Now consider an induced path a < b < c in the statement. The center b is available for both
endpoint selections. If neither path edge were selected, then a would select a later center t > b,
by the greatest-center rule, and c would select an earlier center r < b, by the least-center rule.
We claim that t > c and r < a.
    If b < t < c, the crossing edges at, bc would give ac, contrary to inducedness; if t = c, the
selected edge at would itself be ac. Thus t > c. Similarly, if a < r < b, the crossing edges ab, rc
would give ac, and r = a would give ac directly. Thus r < a. We now have r < a < c < t with
a ∈ At and c ∈ Cr . Condition (ii) again gives an edge rt inside W , a contradiction. Hence at
least one path edge was selected.

Lemma 4.2. The graph Γ is capped and has clique number at most four. It also satisfies both
conditions of Lemma 4.1 for the shores in (2) and the ambient graph G.

Proof. Cappedness. Take edges xz, yt ∈ E(Γ) with x < y < z < t. Their cap xt is an original
edge, and if h = p(xt), then Lemma 3.1(i) gives j ≤ p(xz) ≤ h ≤ p(yt) ≤ i. If h = j or h = i, the
definition includes xt in Γ. Assume j < h < i. By (3), βx < t and x < αt . It remains to prove
αt < βx .
    First suppose y < βx . Since p(yt) ≥ h > j, the edge yt either has rank i or has a strictly

αt < βy by (4); and the observation for x < y < βx gives βy ≤ βx .
    It remains to consider βx ≤ y. We have p(xz) ≤ h < i. The rank of xz cannot be j, since
then z ∈ Cx would give z ≤ βx ≤ y, contrary to y < z. Therefore xz has a strictly intermediate
rank and satisfies (4). In particular, αz < βx ≤ y < z < t. Applying Lemma 3.1(i) to the original
edges αz z and yt gives an edge αz t and i = p(αz z) ≤ p(αz t) ≤ p(yt) ≤ i. Thus αz ∈ At and
αt ≤ αz < βx . This case includes βx = y. In both cases (4) holds for xt, so xt ∈ E(Γ).
    The clique bound. Suppose v1 < · · · < v5 form a clique in Γ. Every one of its edges is an
original edge of rank between j and i. The triangle v1 , v2 , v3 gives p(v2 v3 ) ≥ p(v1 v2 ) + 1 > j.
The triangle v3 , v4 , v5 gives p(v3 v4 ) ≤ p(v4 v5 ) − 1 < i. Using Lemma 3.1(i) with a common left or
right endpoint, we obtain j < p(v2 v3 ) ≤ p(v2 v4 ) ≤ p(v3 v4 ) < i. All three middle edges therefore
satisfy (4). The edges v2 v3 and v3 v4 give βv2 < v3 < αv4 , whereas v2 v4 gives αv4 < βv2 . This
contradiction proves ω(Γ) ≤ 4.
    The two selection conditions. If another center is in a shore of b, its edge to b has rank i or j,
