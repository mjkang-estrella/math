## Exact source realization and finite checks

Label a strictly convex n-point set counterclockwise by0,...,n-1. Two edges ab,cd with sorted endpoints cross in their interiors iff a<c<b<d or c<a<d<b: the chord ab cuts the convex polygon into two sides, and cd crosses it exactly when its endpoints are on opposite open boundary arcs. Shared endpoints do not count as interior crossings. A noncrossing set of n-1 edges is a spanning tree iff union-find detects no cycle: an acyclic n-vertex graph has n minus its number of components edges, so n-1 forces one component. These criteria depend only on cyclic order, not coordinates.

Conversely all these states are realized on a genuine strictly convex rational point set, for example (i,i²), i=0,...,n-1. Each point uniquely minimizes y-2ix on the set, because at j the value is (j-i)²-i². Thus every point is exposed; distinct parabola points have no collinear triples, and their lower chain plus the closing chord gives the cyclic order. The finite graph is therefore the literal source flip graph, not an abstract relaxation. Two masks are adjacent precisely when one edge is removed and another inserted and the result belongs to the state list; deletion/insertion crossing is intentionally NOT forbidden.

For H=T intersect U, let G_H be the induced graph of all trees containing H. A path in G_H is exactly an H-preserving path. Thus the source assertion for this pair is d_G(T,U)=d_GH(T,U), with disconnection treated as infinity. BFS computes exact unweighted graph distances. The checker enumerates every acyclic noncrossing (n-1)-subset and all valid exchanges; for each start and each nonempty subset H of it, BFS in G_H is compared with unrestricted BFS for targets having EXACT intersection H. Empty H is automatic. This handles simultaneous preservation, rather than testing each shared edge separately.
