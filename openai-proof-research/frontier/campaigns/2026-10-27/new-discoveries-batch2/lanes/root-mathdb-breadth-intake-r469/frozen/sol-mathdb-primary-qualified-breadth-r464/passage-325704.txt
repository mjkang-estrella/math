9:                                                                                   Abstract
10:                                                      Let A be a set of n positive integers. We say that a subset B of A is a
11:                                                 divisor of A, if the sum of the elements in B divides the sum of the elements
12:                                                 in A. We are interested in the following extremal problem. For each n, what
13:                                                 is the maximum number of divisors a set of n positive integers can have?
14:                                                 We determine this function exactly for all values of n. Moreover, for each
15:                                                 n we characterize all sets that achieve the maximum. We also prove results
16:                                                 for the k-subset analogue of our problem. For this variant, we determine
17:                                                 the function exactly in the special case that n = 2k. We also characterize
18:                                                 all sets that achieve this bound when n = 2k.
19: 
20:                                                 Keywords: extremal combinatorics; exact enumeration

24:                                           1     Introduction
25:                                           Let A be a finite set of positive integers and let B be a subset of A. We say that B
26:                                           is a divisor of A, if the sum of the elements in B divides the sum of the elements
27:                                           in A. We are interested in the number of divisors a set of positive integers can
28:                                           have. Toward that end, we let d(A) be the number of divisors of A and we let
29:                                           d(n) be the maximum value of d(A) over all sets A of n positive integers. We
30:                                           also study the k-subset version of this problem. That is, we define dk (A) to be
31:                                           the number of k-subset divisors of A and we let d(k, n) be the maximum value of
32:                                           dk (A) over all sets A of n positive integers.
33:                                           This work is motivated by Problem 1 of the 2011 International Mathematical
34:                                           Olympiad [1], where it is asked to determine d(2, 4).
35: 
36:                                           Problem 1.1. Determine d(2, 4). Moreover, find all sets of four positive integers
37:                                           A with exactly d(2, 4) 2-subset divisors.
38: 
39:                                           We begin by presenting the solution to Problem 1.1.
