Abstract.
    

We introduce consecutive-pattern-avoiding stack-sorting maps \operatorname{SC}_{\sigma}, which are natural generalizations of West’s stack-sorting map s and natural analogues of the classical-pattern-avoiding stack-sorting maps s_{\sigma} recently introduced by Cerbai, Claesson, and Ferrari. We characterize the patterns \sigma such that \operatorname{Sort}(\operatorname{SC}_{\sigma}), the set of permutations that are sortable via the map s\circ\operatorname{SC}_{\sigma}, is a permutation class, and we enumerate the sets \operatorname{Sort}(\operatorname{SC}_{\sigma}) for \sigma\in\{123,132,321\}. We also study the maps \operatorname{SC}_{\sigma} from a dynamical point of view, characterizing the periodic points of \operatorname{SC}_{\sigma} for all \sigma\in S_{3} and computing \max_{\pi\in S_{n}}|\operatorname{SC}_{\sigma}^{-1}(\pi)| for all \sigma\in\{132,213,231,312\}. In addition, we characterize the periodic points of the classical-pattern-avoiding stack-sorting map s_{132}, and we show that the maximum number of iterations of s_{132} needed to send a permutation in S_{n} to a periodic point is n-1. The paper ends with numerous open problems and conjectures.
  



1. Introduction



1.1. Background




Let S_{n} denote the set of permutations of the set [n]:=\{1,\ldots,n\}, which we write as words in one-line notation. The investigation of pattern avoidance in permutations began in 1968, when Knuth [28] introduced a stack-sorting machine and showed that a permutation can be sorted to the identity permutation using this machine if and only if it avoids the pattern 231 (we define pattern containment and avoidance formally below). In his 1990 Ph.D. dissertation, West [37] introduced a deterministic variant of Knuth’s machine; this variant is a function s:S_{n}\to S_{n}. As in Knuth’s case, a permutation \pi\in S_{n} satisfies s(\pi)=123\cdots n if and only if it avoids 231. More recently, Albert, Homberger, Pantone, Shar, and Vatter [2] introduced a vast generalization of Knuth’s stack-sorting machine by considering \mathcal{C}-machines. Roughly speaking, a \mathcal{C}-machine is a sorting machine that uses a stack whose entries, when read from top to bottom, must have the same relative order as an element of the permutation class \mathcal{C}. Even more recently, Cerbai, Claesson, and Ferrari [11] generalized West’s stack-sorting map in a similar manner. For each permutation pattern \sigma, they defined a map s_{\sigma}:S_{n}\to S_{n} that sends each permutation through a stack in a right-greedy manner, insisting that the contents of the stack must avoid the pattern \sigma when read from top to bottom. In this more general setup, West’s stack-sorting map is just s_{21}. Although the article [11] is quite recent, it has already spawned several subsequent papers [3, 5, 12, 10].




In this article, we introduce consecutive-pattern-avoiding stack-sorting maps \operatorname{SC}_{\sigma}. In order to define the maps s_{\sigma} and \operatorname{SC}_{\sigma} formally and simultaneously, it is helpful to define more general maps T_{\mathcal{A}} dependent on sets \mathcal{A} of permutations. Assume we are given an input permutation \pi=\pi_{1}\cdots\pi_{n}. Throughout this procedure, we consider the permutation obtained by reading the contents of a vertical stack from top to bottom. If moving the next entry in the input permutation to the top of the stack results in a stack whose contents have the same relative order as any element of \mathcal{A}, then the next entry in the input permutation is placed at the top of the stack (this operation is called a push). Otherwise, the entry at the top of the stack is annexed to the end of the growing output permutation (this operation is called a pop). This procedure stops when the output permutation has length n. We then define T_{\mathcal{A}}(\pi) to be this output permutation. When \mathcal{A} is the set of permutations that avoid \sigma, the map T_{\mathcal{A}} is s_{\sigma}. Our focus in this article is on the case in which \mathcal{A} is the set of permutations that avoid \sigma as a consecutive pattern, in which case we write T_{\mathcal{A}}=\operatorname{SC}_{\sigma}.

Our newly-defined maps \operatorname{SC}_{\sigma} serve as perfectly legitimate generalizations of West’s stack-sorting map because \operatorname{SC}_{21} is the same as s, which is also the same as s_{21} (a permutation avoids the pattern 21 classically if and only if it avoids 21 consecutively). However, when the length of \sigma is at least 3, the maps \operatorname{SC}_{\sigma} and s_{\sigma} exhibit different behaviors.




The decision to consider stacks that avoid consecutive patterns, rather than stacks that avoid classical patterns, is very natural. Indeed, when one actually works through the process of sending a permutation through a classical-21-avoiding stack, one checks at each step whether the next entry in the input permutation is greater than the entry currently sitting at the top of the stack. One does not bother checking if the next entry in the input is greater than all of the entries in the stack because the smallest number in the stack is necessarily the top entry (this is another manifestation of the simple observation that a permutation avoids 21 classically if and only if it avoids 21 consecutively). If \sigma has length k\geq 3, then when one sends a permutation through a classical-\sigma-avoiding stack, one must check all of the entries in the stack to see if the addition of the next entry produces an occurrence of the pattern \sigma. By contrast, when one sends a permutation through a consecutive-\sigma-avoiding stack, it is only necessary to compare the next entry in the input permutation with the top k-1 entries in the stack. In this way, the mechanics governing the maps \operatorname{SC}_{\sigma} are in some sense “closer” to those governing West’s stack-sorting map than those of the maps s_{\sigma} are.




Typically, researchers have approached West’s stack-sorting map from a “sorting” point of view. The usual questions concern structural and enumerative aspects of t-stack-sortable permutations, which are permutations that get sorted to the identity using at most t iterations of the map s [6, 7, 8, 13, 15, 17, 22, 37, 38]. On the other hand, there are now several articles that study the stack-sorting map from a “dynamical” point of view (see [9, 14, 19, 16, 18] and the references therein). In this approach, we view the stack-sorting map as an interesting combinatorially-defined function, without caring so much about trying to sort permutations. The typical questions concern the number of preimages of a permutation under s, which is called the fertility of the permutation. The investigation of fertilities of permutations has revealed unexpected patterns and connections with several other aspects of combinatorics [9, 14, 16, 19, 31, 33],
including a very surprising and useful link with the combinatorics of cumulants in noncommutative probability theory [18]. This dynamical approach concerning fertilities has also shed new light on the t-stack-sortable permutations studied from the sorting point of view [15, 17].




In this paper, we consider the maps \operatorname{SC}_{\sigma} from both the sorting point of view and the dynamical point of view. All of the sorting questions we consider are analogues of questions asked about the maps s_{\sigma} in [11, 12]. On the other hand, our dynamical approach is completely novel in the realm of pattern-avoiding stack-sorting maps (other than s itself). We will also see that there are several dynamical questions that one can ask about the maps \operatorname{SC}_{\sigma} that are trivial when \sigma=21 (i.e., when \operatorname{SC}_{\sigma}=s), but which become much more interesting when the length of \sigma is at least 3.




1.2. Outline and Summary of Main Results




The articles [11, 12] focus primarily on the set \operatorname{Sort}(s_{\sigma}) of permutations that get sorted to the identity using a \sigma-avoiding stack followed by a classical-21-avoiding stack. Since the set of permutations that s maps to the identity is the set \operatorname{Av}(231) of 231-avoiding permutations, we have \operatorname{Sort}(s_{\sigma})=s_{\sigma}^{-1}(\operatorname{Av}(231)). Note that \operatorname{Sort}(s_{21})=s^{-1}(\operatorname{Av}(231)) consists of the 2-stack-sortable permutations, which have received an enormous amount of attention since their inception in West’s dissertation [6, 7, 8, 15, 17, 22, 37, 38]. Let us also remark that the articles [3, 10] have studied other close variants of these sets; for example, the paper [3] explores the sets \operatorname{Sort}(s_{\sigma,\tau})=s_{\sigma,\tau}^{-1}(\operatorname{Av}(231)), where s_{\sigma,\tau} is the map that sends a permutation through a right-greedy stack whose contents avoid both \sigma and \tau (using our earlier notation, s_{\sigma,\tau}=T_{\operatorname{Av}(\sigma,\tau)}). In Section 2, we define \operatorname{Sort}(\operatorname{SC}_{\sigma})=\operatorname{SC}_{\sigma}^{-1}(\operatorname{Av}(231)), which can similarly be seen as the set of permutations that get sorted into the identity by a consecutive-\sigma-avoiding stack followed by a 21-avoiding stack. We will prove that if \sigma\in S_{k} for some k\geq 3, then \operatorname{Sort}(\operatorname{SC}_{\sigma}) is a permutation class if and only if \sigma and \widehat{\sigma} both contain the pattern 231, where \widehat{\sigma} is the permutation obtained by swapping the first 2 entries in \sigma; this is a direct analogue of one of the main results from [11].




The other main results from [11] concern the enumeration of the sets \operatorname{Sort}(s_{123}) and \operatorname{Sort}(s_{321}). Extending this work, the article [12] focuses on the enumeration of the set \operatorname{Sort}(s_{132}). In Sections 4 and 6, we give analogues of these results by characterizing and enumerating the sets \operatorname{Sort}(\operatorname{SC}_{123}), \operatorname{Sort}(\operatorname{SC}_{321}), and \operatorname{Sort}(\operatorname{SC}_{132}). More precisely, we will see that \operatorname{Sort}(\operatorname{SC}_{123}) is enumerated by the first differences of Motzkin numbers, that \operatorname{Sort}(\operatorname{SC}_{321}) is enumerated by the Motzkin numbers, and that \operatorname{Sort}(\operatorname{SC}_{132}) is enumerated by the Catalan numbers.




In Section 3, we adopt the dynamical point of view and consider the periodic points of the maps \operatorname{SC}_{\sigma}, which we view as functions from S_{n} to S_{n} for each n\geq 1. It is easy to show that the only periodic point of s:S_{n}\to S_{n} is the identity permutation 123\cdots n. By contrast, if the length of \sigma is at least 3, then \operatorname{SC}_{\sigma} has multiple periodic points. We will prove that if \sigma\in S_{3}, then the periodic points of \operatorname{SC}_{\sigma}:S_{n}\to S_{n} are precisely the permuatations in S_{n} that avoid \sigma and its reverse as consecutive patterns.




It is known that the identity permutation 123\cdots n, which has C_{n}:=\frac{1}{n+1}{2n\choose n} preimages under s, has strictly more preimages under s than every other permutation in S_{n} (see [6, Chapter 8, Exercise 23]). The analogous results for the maps \operatorname{SC}_{\sigma} are more difficult. In Section 4, we study preimages under the maps \operatorname{SC}_{132} and \operatorname{SC}_{312}, proving in particular that




\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{312}^{-1}(\pi)|={n-1\choose\left\lfloor\frac{n-1}{2}\right\rfloor}



(along the way, we obtain a simple formula for |\operatorname{SC}_{132}^{-1}(\pi)| for all reverse-layered permutations \pi). In Section 5, we prove a similar result for the maps \operatorname{SC}_{231} and \operatorname{SC}_{213}, showing that




\max_{\pi\in S_{n}}|\operatorname{SC}_{231}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{213}^{-1}(\pi)|=2^{n-2}



when n\geq 2.




Section 7 is a little different from the rest of the paper because it focuses on classical-pattern-avoiding stack-sorting maps instead of consecutive-pattern-avoiding stack-sorting maps. The purpose of this section is to prove dynamical results about the maps s_{132} and s_{312}. Such questions have not previously been considered for these maps, and we believe our results open the gate for interesting further developments. Specifically, we prove that the periodic points of s_{132} (respectively, s_{312}) are precisely the permutations that avoid 132 and 231 (respectively, 312 and 213). We also prove the the maximum number of iterations needed for s_{132} (respectively, s_{312}) to send a permutation to one of its periodic points is n-1 (these results are much more difficult than the analogous results for West’s stack-sorting map).




Finally, Section 8 collects a large number of open problems, conjectures, and other suggestions for future work.




1.3. Terminology and Notation




Recall that in this article, a permutation is an ordering of the elements of the set [n] for some n. If \pi is a sequence of n distinct integers, then the standardization of \pi is the permutation in S_{n} obtained by replacing the ith-smallest entry in \pi with i for all i. For example, the standardization of 4829 is 2314. We say two sequences have the same relative order if their standardizations are equal. We say a permutation \sigma contains a permutation \tau as a pattern if there is a (not necessarily consecutive) subsequence of \sigma that has the same relative order as \tau; otherwise, \sigma avoids \tau. We say \sigma contains \tau consecutively if \sigma has a consecutive subsequence with the same relative order as \tau; otherwise, \sigma avoids the consecutive pattern \tau. When we wish to stress that pattern containment (or avoidance) is nonconsecutive, we will sometimes call it classical pattern containment (or avoidance). We refer to the standard references [6, 20, 27, 30] for more information about classical and consecutive permutation patterns.




We denote consecutive patterns by underlining them (or referring to them as consecutive patterns). If \tau^{(1)},\tau^{(2)},\ldots is a (finite or infinite) list of classical or consecutive patterns, then we write \operatorname{Av}_{n}(\tau^{(1)},\tau^{(2)},\ldots) for the set of permutations in S_{n} that avoid \tau^{(1)},\tau^{(2)},\ldots. We also write \operatorname{Av}(\tau^{(1)},\tau^{(2)},\ldots)=\bigcup_{n\geq 0}\operatorname{Av}_{n}(\tau^{(1)},\tau^{(2)},\ldots). For example, \operatorname{Av}(231,321) is the set of permutations that avoid 231 and 321, while \operatorname{Av}(\underline{321}) is the set of permutations that avoid the consecutive pattern 321. If \tau is an arbitrary unspecified permutation, then we let \operatorname{Av}(\underline{\tau}) be the set of permutations that consecutively avoid \tau.




Given a permutation \sigma=\sigma_{1}\cdots\sigma_{k} of length k\geq 2, we let \widehat{\sigma}=\sigma_{2}\sigma_{1}\sigma_{3}\cdots\sigma_{k} denote the permutation obtained by swapping the first two entries in \sigma. We also let \operatorname{rev}(\sigma)=\sigma_{k}\cdots\sigma_{1} denote the reverse of \sigma. If \sigma\in S_{k}, then we write \operatorname{comp}(\sigma)=(k+1-\sigma_{1})\cdots(k+1-\sigma_{k}) for the complement of \sigma. A descent (respectively, ascent) of \sigma is an index i such that \sigma_{i}>\sigma_{i+1} (respectively, \sigma_{i}<\sigma_{i+1}). An ascending run of \sigma is a maximal consecutive increasing subsequence of \pi, while a descending run is a maximal consecutive decreasing subsequence. For example, the ascending runs of 7862351 are 78, 6, 235, and 1, while the descending runs of 7862351 are 7, 862, 3, and 51. We write |\tau| for the length of a sequence \tau of positive integers.




1.4. A Preliminary Lemma




Before we proceed, it will be helpful to record the following lemma, which will allow us to simplify many of our considerations. The proof of this lemma is immediate from the definitions of s_{\sigma} and \operatorname{SC}_{\sigma}.



Lemma 1.2.



If \sigma\in S_{k} for some k\geq 2, then




s_{\operatorname{comp}(\sigma)}=\operatorname{comp}\circ s_{\sigma}\circ\operatorname{comp}\quad\text{and}\quad\operatorname{SC}_{\operatorname{comp}(\sigma)}=\operatorname{comp}\circ\operatorname{SC}_{\sigma}\circ\operatorname{comp}.








2. When is \operatorname{Sort}(\operatorname{SC}_{\sigma}) a Permutation Class?




A permutation class is a set \mathcal{C} of permutations that is closed under classical pattern containment. Said differently, this means that if \sigma,\tau are permutations such that \sigma contains \tau classically and \sigma\in\mathcal{C}, then \tau\in\mathcal{C}. Equivalently, a set of permutations is a permutation class if and only if it is of the form \operatorname{Av}(\tau^{(1)},\tau^{(2)},\ldots) for some classical patterns \tau^{(1)},\tau^{(2)},\ldots.




Recall that \widehat{\sigma} is the permutation obtained by swapping the first two entries in \sigma. Furthermore, \operatorname{Sort}(s_{\sigma})=s_{\sigma}^{-1}(\operatorname{Av}(231)) is the set of permutations that get sorted into the identity by the map s\circ s_{\sigma}. The following theorem is one of the main results in [11].



Theorem 2.1 (​​[11]).



Let \sigma\in S_{k} for some k\geq 2. The set \operatorname{Sort}(s_{\sigma}) is a permutation class if and only if \sigma=12 or \widehat{\sigma} contains the pattern 231 classically.





Our goal in this section is to prove the following analogue of Theorem 2.1 for the consecutive-pattern-avoiding stack-sorting maps \operatorname{SC}_{\sigma}. Recall that \operatorname{Sort}(\operatorname{SC}_{\sigma})=\operatorname{SC}_{\sigma}^{-1}(\operatorname{Av}(231)) is the set of permutations that get sorted into the identity by the map s\circ\operatorname{SC}_{\sigma}.



Theorem 2.2.



The set \operatorname{Sort}(\operatorname{SC}_{12}) is equal to the permutation class \operatorname{Av}(213), while \operatorname{Sort}(\operatorname{SC}_{21}) is not a permutation class. If \sigma\in S_{k} for some k\geq 3, then the set \operatorname{Sort}(\operatorname{SC}_{\sigma}) is a permutation class if and only if \sigma and \widehat{\sigma} both contain the pattern 231 classically. In this case, \operatorname{Sort}(\operatorname{SC}_{\sigma})=\operatorname{Av}(132).





We will prove Theorem 2.2 via the following two lemmas. Recall that \operatorname{rev}(\sigma) denotes the reverse of the permutation \sigma.



Lemma 2.3.



Let \sigma\in S_{k} for some k\geq 3. If \widehat{\sigma} contains 231 classically, then \operatorname{Sort}(\operatorname{SC}_{\sigma}) is the set \operatorname{Av}\left(132,\underline{\operatorname{rev}(\sigma)}\right) of permutations that avoid 132 classically and avoid \operatorname{rev}(\sigma) consecutively.




Proof.



In general, it is immediate from the definition of \operatorname{SC}_{\sigma} that \operatorname{SC}_{\sigma}(\pi)=\operatorname{rev}(\pi) whenever \pi avoids \operatorname{rev}(\sigma) consecutively. Indeed, in this case, all of the entries in \pi enter the stack and then proceed to exit the stack in the reverse of the order in which they entered. It follows that if \pi avoids \operatorname{rev}(\sigma) consecutively and avoids 132 classically, then \operatorname{SC}_{\sigma}(\pi)=\operatorname{rev}(\pi)\in\operatorname{Av}(231). Furthermore, if \pi contains 132 classically and avoids \operatorname{rev}(\sigma) consecutively, then \operatorname{SC}_{\sigma}(\pi)=\operatorname{rev}(\pi) contains 231 classically. This implies that \pi\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}).




Suppose now that \pi contains \operatorname{rev}(\sigma) consecutively, and let i be the minimal index such that \pi_{i}\cdots\pi_{i+k-1} is a consecutive occurrence of the pattern \operatorname{rev}(\sigma). Consider sending \pi through a consecutive-\sigma-avoiding stack. When \pi_{i+k-1} is about to enter the stack, the top k-1 entries in the stack, read from top to bottom, are \pi_{i+k-2},\ldots,\pi_{i}. The entry \pi_{i+k-2} pops out of the stack, and the entry \pi_{i+k-1} enters the stack immediately afterward. Once all of the entries have finally exited the stack, the entries \pi_{i+k-2},\pi_{i+k-1},\pi_{i+k-3},\ldots,\pi_{i} will appear in this order in the output permutation \operatorname{SC}_{\sigma}(\pi). However, \pi_{i+k-2}\pi_{i+k-1}\pi_{i+k-3}\cdots\pi_{i} has the same relative order as \widehat{\sigma}, which in turn contains 231 classically by hypothesis. This shows that \operatorname{SC}_{\sigma}(\pi)\not\in\operatorname{Av}(231), so \pi\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}).
∎




Lemma 2.4.



If \widehat{\sigma}\in\operatorname{Av}_{k}(231) for some k\geq 3, then \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class.




Proof.



We first dispose of the case in which \sigma=231. A simple computation yields \operatorname{SC}_{231}(2413)=3142\not\in\operatorname{Av}(231) and \operatorname{SC}_{231}(25314)=54132\in\operatorname{Av}(231). This shows that 25314 is in \operatorname{Sort}(\operatorname{SC}_{231}) while 2413 is not. Since 25314 classically contains 2413, it follows that \operatorname{Sort}(\operatorname{SC}_{231}) is not a permutation class. We may now assume \sigma\neq 231. Because the length of \sigma is at least 3, we have \operatorname{SC}_{\sigma}(132)=231. This shows that 132\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}).




Let us now assume that \sigma classically contains 231 but is not equal to 231. One can easily check that \operatorname{SC}_{\sigma}(\operatorname{rev}(\sigma))=\widehat{\sigma}, and we assumed that \widehat{\sigma}\in\operatorname{Av}(231). This shows that \operatorname{rev}(\sigma)\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). Now note that \operatorname{rev}(\sigma) contains 132 classically and that 132\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). It follows that \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class in this case.




Next, assume \sigma\in\operatorname{Av}(231), \sigma_{1}<\sigma_{2}, and \sigma_{2}>2. These assumptions force \sigma_{1}=1 since, otherwise, the entries \sigma_{1},\sigma_{2},1 would form a classical 231 pattern in \sigma. Let \pi=\sigma_{k}^{\prime}\cdots\sigma_{2}^{\prime}\sigma_{1}^{\prime}\sigma_{2}, where \sigma_{i}^{\prime}=\sigma_{i} if \sigma_{i}<\sigma_{2} and \sigma_{i}^{\prime}=\sigma_{i}+1 if \sigma_{i}\geq\sigma_{2}. We will prove that \pi\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). Since the entries 2,\sigma_{2}^{\prime},\sigma_{2} form an occurrence of the classical pattern 132 in \pi and 132\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}), this will imply that \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class. One can easily compute that \operatorname{SC}_{\sigma}(\pi)=\sigma_{2}^{\prime}\sigma_{2}\sigma_{1}^{\prime}\sigma_{3}^{\prime}\cdots\sigma_{k}^{\prime}. Notice that the permutation \sigma_{2}\sigma_{1}^{\prime}\sigma_{3}^{\prime}\cdots\sigma_{k}^{\prime} has the same relative order as \widehat{\sigma}, which avoids 231 classically by hypothesis. Therefore, if \operatorname{SC}_{\sigma}(\pi) contains 231, then the first entry in the occurrence of the 231 pattern must be \sigma_{2}^{\prime}. Since \sigma_{2}^{\prime}=\sigma_{2}+1, we can replace \sigma_{2}^{\prime} with \sigma_{2} in this subsequence in order to obtain an occurrence of the pattern 231 in \operatorname{SC}_{\sigma}(\pi) that starts with the entry \sigma_{2}. However, this contradicts our earlier observation that \sigma_{2}\sigma_{1}^{\prime}\sigma_{3}^{\prime}\cdots\sigma_{k}^{\prime} avoids 231.




For our next case, we assume \sigma\in\operatorname{Av}(231), \sigma_{1}=1, and \sigma_{2}=2. Let \pi=\sigma_{k}\cdots\sigma_{3}21(k+1) be the concatenation of \operatorname{rev}(\sigma) with the entry k+1. Let \pi^{\prime}=\sigma_{k}\cdots\sigma_{3}2(k+1)1(k+2). The first 3 entries of the permutation \operatorname{SC}_{\sigma}(\pi)=2(k+1)1\sigma_{3}\cdots\sigma_{k} form a 231 pattern, so \pi\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). On the other hand, since \pi^{\prime} certainly avoids the pattern \operatorname{rev}(\sigma) consecutively, we have \operatorname{SC}_{\sigma}(\pi^{\prime})=\operatorname{rev}(\pi^{\prime})=(k+2)1(k+1)2\sigma_{3}\cdots\sigma_{k}. The assumption \sigma\in\operatorname{Av}(231) guarantees that \operatorname{SC}_{\sigma}(\pi^{\prime})\in\operatorname{Av}(231), so \pi^{\prime}\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). The permutation \pi^{\prime} contains \pi classically, so \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class in this case.




The final case we need to consider is that in which \sigma\in\operatorname{Av}(231) and \sigma_{1}>\sigma_{2}. Notice that the hypothesis \widehat{\sigma}\in\operatorname{Av}(231) forces \sigma_{2}=1 in this case. Let \pi=\sigma_{k}^{\prime}\cdots\sigma_{2}^{\prime}\sigma_{1}^{\prime}2, where \sigma_{2}^{\prime}=1 and \sigma_{i}^{\prime}=\sigma_{i}+1 for all i\neq 2. We have \operatorname{SC}_{\sigma}(\pi)=12\sigma_{1}^{\prime}\sigma_{3}^{\prime}\cdots\sigma_{k}^{\prime}; note that this permutation avoids 231 because \sigma avoids 231. Therefore, \pi\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). The entries \sigma_{2}^{\prime},\sigma_{1}^{\prime},2 form an occurrence of the pattern 132 in \pi, and we have seen that 132\not\in\operatorname{Sort}(\operatorname{SC}_{\sigma}). Therefore, \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class in this final case.
∎




Proof of Theorem 2.2.



It is straightforward to check that if \pi\in S_{n} for some n\geq 1, then the last entry in \operatorname{SC}_{12}(\pi) is 1. It follows that \operatorname{SC}_{12}(\pi) avoids 231 if and only if it avoids 12. Using Lemma 1.2, we find that




\operatorname{Sort}(\operatorname{SC}_{12})=\operatorname{SC}_{12}^{-1}(\operatorname{Av}(231))=\operatorname{SC}_{12}^{-1}(\operatorname{Av}(12))=\operatorname{comp}(\operatorname{SC}_{21}^{-1}(\operatorname{comp}(\operatorname{Av}(12))))






=\operatorname{comp}(s^{-1}(\operatorname{Av}(21)))=\operatorname{comp}(\operatorname{Av}(231))=\operatorname{Av}(213).



On the other hand, the set \operatorname{Sort}(\operatorname{SC}_{21}) is not a permutation class because it includes the permutation 35241 but not the permutation 3241.




Now assume \sigma\in S_{k} for some k\geq 3. If \sigma and \widehat{\sigma} both contain 231 classically, then it follows from Lemma 2.3 that




\operatorname{Sort}(\operatorname{SC}_{\sigma})=\operatorname{Av}\left(132,\underline{\operatorname{rev}(\sigma)}\right)=\operatorname{Av}(132).



If \widehat{\sigma}\in\operatorname{Av}(231), then Lemma 2.4 tells us that \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class. Now assume \sigma\in\operatorname{Av}(231) and \widehat{\sigma}\not\in\operatorname{Av}(231). Note that this implies that \sigma_{1}>\sigma_{2}>1. Since \operatorname{SC}_{\sigma}(\operatorname{rev}(\sigma))=\widehat{\sigma}, the permutation \operatorname{rev}(\sigma) is not in \operatorname{Sort}(\operatorname{SC}_{\sigma}). However, the permutation \pi=(\sigma_{k}+1)\cdots(\sigma_{2}+1)1(\sigma_{1}+1), which contains \operatorname{rev}(\sigma) classically, is in \operatorname{Sort}(\operatorname{SC}_{\sigma}). To see this, note that the condition \sigma_{1}>\sigma_{2}>1 guarantees that \pi avoids \operatorname{rev}(\sigma) consecutively. Therefore, \operatorname{SC}_{\sigma}(\pi)=1(\sigma_{1}+1)(\sigma_{2}+1)\cdots(\sigma_{k}+1), and this permutation avoids 231 because \sigma does. Hence, \operatorname{Sort}(\operatorname{SC}_{\sigma}) is not a permutation class.
∎





3. Periodic Points




In this section, we prove the following theorem, which completely classifies the periodic points of the consecutive-\sigma-avoiding stack-sorting map for \sigma\in S_{3}.



Theorem 3.1.



Let \sigma\in S_{3}. The periodic points of the map \operatorname{SC}_{\sigma}:S_{n}\to S_{n} are precisely the permutations in \operatorname{Av}_{n}\left(\underline{\sigma},\underline{\operatorname{rev}(\sigma)}\right). When n\geq 2, each of these periodic points has period 2.





Lemma 1.2 tells us that for each permutation pattern \sigma, the maps \operatorname{SC}_{\sigma} and \operatorname{SC}_{\operatorname{comp}(\sigma)} are topologically conjugate (with the discrete topology), with the complementation map \operatorname{comp} serving as the topological conjugacy. It follows that if Theorem 3.1 holds when \sigma is some specific pattern \tau, then it also holds when \sigma=\operatorname{comp}(\tau). Thus, we really only need to prove the theorem when \sigma\in\{123,132,231\}. We first handle the case in which \sigma\in\{132,231\}.



Proposition 3.2.



For \sigma\in\{132,231\}, the set of periodic points of the map \operatorname{SC}_{\sigma}:S_{n}\to S_{n} is the set \operatorname{Av}_{n}(\underline{132},\underline{231}) of permutations in S_{n} that avoid 132 and 231 consecutively (these permutations also avoid 132 and 231 classically). When n\geq 2, these points have period 2.




Proof.



Note that \{132,231\}=\{\sigma,\operatorname{rev}(\sigma)\}. It is clear that if \pi\in\operatorname{Av}(\underline{132},\underline{231}), then \operatorname{SC}_{\sigma}(\pi)=\operatorname{rev}(\pi)\in\operatorname{Av}(\underline{132},\underline{231}), so \operatorname{SC}_{\sigma}^{2}(\pi)=\pi. Hence, \pi is a periodic point of \operatorname{SC}_{\sigma}, and the period is 2 if n\geq 2.




We now prove that every periodic point of \operatorname{SC}_{\sigma}:S_{n}\to S_{n} is in \operatorname{Av}(\underline{132},\underline{231}). This is trivial if n\leq 2, so we may assume n\geq 3 and induct on n. Given \tau\in S_{n}, let \tau^{*} be the permutation in S_{n-1} obtained by deleting the entry 1 from \tau and then decreasing all remaining entries by 1. Observe that if the entries 1 and 2 appear consecutively in \tau, then they also appear consecutively in \operatorname{SC}_{\sigma}(\tau) and that (\operatorname{SC}_{\sigma}(\tau))^{*}=\operatorname{SC}_{\sigma}(\tau^{*}). Now fix \pi\in S_{n}. By induction, we have \operatorname{SC}_{\sigma}^{t}(\pi^{*})\in\operatorname{Av}(\underline{132},\underline{231}) for all sufficiently large t. We will prove that if t is sufficiently large, then the entries 1 and 2 appear consecutively in \operatorname{SC}_{\sigma}^{t}(\pi). It will then follow that (\operatorname{SC}_{\sigma}^{t}(\pi))^{*}=\operatorname{SC}_{\sigma}^{t}(\pi^{*})\in\operatorname{Av}(\underline{132},\underline{231}) for all sufficiently large t, which will imply that \operatorname{SC}_{\sigma}^{t}(\pi)\in\operatorname{Av}(\underline{132},\underline{231}) for all sufficiently large t.




Let D(\tau) denote the number of entries between 1 and 2 in \tau (regardless of whether 1 appears before or after 2 in \tau). First, note that neither 1 nor 2 will get popped from the stack until after all of the entries of \tau have entered the stack because neither 1 nor 2 can trigger the consecutive-\sigma-avoiding restriction when at the top of the stack. This immediately implies that D(\tau)\leq D(\operatorname{SC}_{\sigma}(\tau)). We further show that if D(\tau)>0, then D(\operatorname{SC}_{\sigma}^{2}(\tau))<D(\tau), implying that 1 and 2 are consecutive entries in \operatorname{SC}_{\sigma}^{t}(\pi) for all sufficiently large t. Let \{1,2\}=\{\tau_{i},\tau_{i+c}\} so that D(\pi)=c-1, and assume c\geq 2. The consecutive subsequence \tau_{i}\tau_{i+1}\cdots\tau_{i+c} of \tau contains a consecutive occurrence of either \sigma or \operatorname{rev}(\sigma). If it contains a consecutive occurrence of \operatorname{rev}(\sigma), then when \tau_{i+c} enters the stack, the entries between \tau_{i} and \tau_{i+c} form a strict subset of \{\tau_{i+1},\ldots,\tau_{i+c-1}\}. Moreover, these entries are precisely the entries between 1 and 2 in \operatorname{SC}_{\sigma}(\tau) since neither 1 nor 2 is popped until all entries of \tau have entered the stack. This implies that D(\operatorname{SC}_{\sigma}(\tau))<D(\tau). If there is no consecutive occurrence of \operatorname{rev}(\sigma) in the consecutive subsequence \tau_{i}\tau_{i+1}\cdots\tau_{i+c} of \tau, then \tau_{i+c}\tau_{i+c-1}\cdots\tau_{i} is a consecutive subsequence of \operatorname{SC}_{\sigma}(\tau) that contains a consecutive occurrence of \operatorname{rev}(\sigma), so the previous argument guarantees that D(\operatorname{SC}_{\sigma}^{2}(\tau))<D(\operatorname{SC}_{\sigma}(\tau))\leq D(\tau).
∎





Next, we consider the periodic points of \operatorname{SC}_{123} and \operatorname{SC}_{321}. By complementing, it suffices to just consider \operatorname{SC}_{321}. To understand this map, it helps to decompose a permutation \pi by writing \pi=a_{1}\cdots a_{k}, where the a_{i}’s are the ascending runs (maximal consecutive increasing subsequences). In addition, let a_{i}^{m} be the subsequence of a_{i} consisting of the entries that are not the first or last entries in a_{i}, and let a_{i}^{e} be the sequence obtained from a_{i} by deleting a_{i}^{m}. If |a_{i}| is 1 or 2, then a_{i}^{e}=a_{i} and a_{i}^{m} is an empty sequence. For example, the ascending runs of 4572136 are a_{1}=457, a_{2}=2, and a_{3}=136, with a_{1}^{e}=47,a_{2}^{e}=2,a_{3}^{e}=16,a_{1}^{m}=5,a_{2}^{m} empty, and a_{3}^{m}=3.



Lemma 3.3.



Keeping the notation above, let \pi=a_{1}\cdots a_{k}, where the a_{i}’s are ascending runs. Then \operatorname{SC}_{321}(\pi)=a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{1}^{e}\cdots a_{k}^{e})=a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e})\cdots\operatorname{rev}(a_{1}^{e}).




Proof.



When the ascending run a_{i} enters the consecutive-321-avoiding stack, each entry in a^{m} is popped immediately after it enters while a_{i}^{e} remains in the stack. After all entries have been pushed into the stack, the entries remaining in the stack are popped out in the reverse of the order in which they entered and thus the output is a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{1}^{e}\cdots a_{k}^{e})=a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e})\cdots\operatorname{rev}(a_{1}^{e}).
∎





To identify the periodic points of \operatorname{SC}_{321}, we analyze how the number of peaks and valleys of a permutation \pi changes as \operatorname{SC}_{321} is iteratively applied to \pi. A peak (respectively, valley) of \pi=\pi_{1}\cdots\pi_{n} is an index i\in\{2,\ldots,n-1\} such that \pi_{i-1}<\pi_{i}>\pi_{i+1} (respectively, \pi_{i-1}>\pi_{i}<\pi_{i+1}). If i is a peak (respectively, valley) of \pi, then the entry \pi_{i} is called a peak top (respectively, valley bottom) of \pi. We let g(\pi) denote the total number of indices that are either peaks or valleys of \pi.



Lemma 3.4.



Let \pi=a_{1}\cdots a_{k}\in S_{n}, where a_{1},\ldots,a_{k} are the ascending runs of \pi. We have g(\pi)\leq g(\operatorname{SC}_{321}(\pi)). Moreover, if |a_{k}|\geq 2, then this inequality is an equality if and only if a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is a decreasing sequence. If |a_{k}|=1, then g(\pi)=g(\operatorname{SC}_{321}(\pi)) if and only if a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is an increasing sequence.




Proof.



We specifically show that the peak tops and valley bottoms of \pi are still peak tops and valley bottoms in \operatorname{SC}_{321}(\pi). The key observation is that each peak top (valley bottom) of \pi is the second (first) entry of a_{j}^{e} for some ascending run a_{j} of length at least 2, and it is not the first or last entry of \pi.




Suppose the entry \pi_{i} is a peak top of \pi. Then \pi_{i} is the last entry of some ascending run a_{j} of length at least 2. We have a_{j}^{e}=\pi_{h}\pi_{i} for some \pi_{h}<\pi_{i}. Similarly, \pi_{i+1} is the first entry of the ascending run a_{j+1} and is less than \pi_{i}. By Lemma 3.3, the sequence \operatorname{rev}(a_{j+1}^{e})\operatorname{rev}(a_{j}^{e}), which itself has \pi_{i+1}\pi_{i}\pi_{h} as a consecutive subsequence, is a consecutive subsequence of \operatorname{SC}_{321}(\pi). Consequently, \pi_{i} is still a peak top of \operatorname{SC}_{321}(\pi).
A completely analogous argument shows that every valley bottom of \pi is also a valley bottom of \operatorname{SC}_{321}(\pi), so g(\pi)\leq g(\operatorname{SC}_{321}(\pi)).




For the equality cases, suppose first that a_{k} has length at least 2. Note that g(\pi)=g(\operatorname{SC}_{321}(\pi)) if and only if no entry in a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) except for the last entry is a peak top or valley bottom in \operatorname{SC}_{321}(\pi). This happens if and only if a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is an increasing or decreasing sequence. Since \operatorname{rev}(a_{k}^{e}) is a decreasing sequence, it follows that g(\pi)=g(\operatorname{SC}_{321}(\pi)) if and only if a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is a decreasing sequence.




Now suppose a_{k} has length 1. We again have g(\pi)=g(\operatorname{SC}_{321}(\pi)) if and only if no element in a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is a peak top or valley bottom in \operatorname{SC}_{321}(\pi). Note that a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is part of the consecutive subsequence a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e})\operatorname{rev}(a_{k-1}^{e}) in \operatorname{SC}_{321}(\pi). Since a_{k} has length 1, it is a single entry that is less than the entry before it in \pi; this entry before it is also the entry after it in a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e})\operatorname{rev}(a_{k-1}^{e}). Thus, no entry in a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is a peak top or valley bottom if and only if a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is an increasing sequence.
∎





By the previous lemma, it is clear that if g(\pi)<g(\operatorname{SC}_{321}(\pi)), then \pi cannot be a periodic point. We make use of this fact when proving the next few results.



Corollary 3.5.



Let \pi=a_{1}\cdots a_{k}, where the a_{i}’s denote ascending runs. If |a_{k}|\geq 3 or |a_{1}|=|a_{2}|=1, then \pi is not a periodic point of \operatorname{SC}_{321}.




Proof.



If |a_{k}|\geq 3, then a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is not a decreasing sequence, so g(\pi)<g(\operatorname{SC}_{321}(\pi)) by Lemma 3.4. Hence, \pi is not a periodic point of \operatorname{SC}_{321}. If |a_{1}|=|a_{2}|=1, then \operatorname{SC}_{321}(\pi) is a permutation ending in an ascending run of length at least 3, so it follows from the preceding argument that \operatorname{SC}_{321}(\pi) is not a periodic point of \operatorname{SC}_{321}. Hence, \pi is not a periodic point in this case either.
∎




Corollary 3.6.



Let \pi=a_{1}\cdots a_{k}\in S_{n} for some n\geq 3, where the a_{i}’s denote ascending runs. If |a_{1}|\geq 3 or |a_{k-1}|=|a_{k}|=1, then \pi is not a periodic point of \operatorname{SC}_{321}.




Proof.



Suppose \pi is a periodic point of \operatorname{SC}_{321} and |a_{1}|\geq 2. Let \ell be the period of \pi so that \operatorname{SC}_{321}^{\ell}(\pi)=\pi. Let \pi_{1} denote the first entry of \pi. By Lemma 3.4, we must have g(\pi)=g(\operatorname{SC}_{321}^{t}(\pi)) for all t\geq 1. By Lemma 3.3, the last two entries of \operatorname{SC}_{321}(\pi) form the sequence \operatorname{rev}(a_{1}^{e}); in particular, the last ascending run of \operatorname{SC}_{321}(\pi) has length 1 and is simply \pi_{1}. Since \operatorname{SC}_{321}(\pi) ends in an ascending run of length 1 and g(\pi)=g(\operatorname{SC}_{321}(\pi)), Lemma 3.4 guarantees that \operatorname{SC}_{321}^{2}(\pi) begins with an ascending run that contains \pi_{1}, so \operatorname{SC}_{321}^{2}(\pi)_{1}\leq\pi_{1}. In fact, the first ascending run of \operatorname{SC}_{321}^{2}(\pi) must actually contain a_{1}^{e}, so \operatorname{SC}_{321}^{2}(\pi) is a periodic point of \operatorname{SC}_{321} that starts with an ascending run of length at least 2. Moreover, if \operatorname{SC}_{321}(\pi) has an ascending run of length at least 3, then the first ascending run of \operatorname{SC}_{321}^{2}(\pi) actually begins with an entry that is smaller than \pi_{1}, implying that \operatorname{SC}_{321}^{2}(\pi)_{1}<\pi_{1}. Repeating this argument shows that (\operatorname{SC}_{321}^{2t}(\pi)_{1})_{t\geq 1} is a weakly decreasing sequence and is nonconstant if \operatorname{SC}_{321}^{2t-1}(\pi) contains an ascending run of length at least 3 for some t\geq 1. Since \operatorname{SC}_{321}^{k\ell}(\pi)=\pi for all integers k\geq 1, it follows that for every t\geq 1, the permutation \operatorname{SC}_{321}^{2t-1}(\pi) does not have an ascending run of length at least 3. This implies that \operatorname{SC}_{321}^{2t}(\pi)=\operatorname{rev}(\operatorname{SC}_{321}^{2t-1}(\pi)) for all t\geq 1.




Now consider \pi_{2}, the second entry of \pi. As previously stated, \operatorname{SC}_{321}(\pi) ends in \operatorname{rev}(a_{1}^{e}), so the second-to-last entry of \operatorname{SC}_{321}(\pi) is greater than or equal to \pi_{2}. This implies that the second entry of \operatorname{SC}_{321}^{2}(\pi) is greater than or equal to \pi_{2}, as \operatorname{SC}_{321}^{2}(\pi)=\operatorname{rev}(\operatorname{SC}_{321}(\pi)). Repeating this argument shows that the sequence (\operatorname{SC}_{321}^{2t}(\pi)_{2})_{t\geq 1} is weakly increasing. As \operatorname{SC}_{321}^{2k\ell}(\pi)=\pi for all k\geq 1, this sequence must actually be constant. If |a_{1}|\geq 3, then the second-to-last entry of \operatorname{SC}_{321}(\pi), which is also the second entry of \operatorname{SC}_{321}^{2}(\pi), is actually strictly greater than \pi_{2}. This is a contradiction.




Now suppose \pi is a periodic point and |a_{k-1}|=|a_{k}|=1. This means we must have g(\pi)=g(\operatorname{SC}_{321}(\pi)), so it follows from Lemma 3.4 that a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) is an increasing sequence. Notice also that the first 3 entries of the sequence \operatorname{rev}(a_{k}^{e})\operatorname{rev}(a_{k-1}^{e})\operatorname{rev}(a_{k-2}^{e}) appear in increasing order (we must have k\geq 3 since n\geq 3 and |a_{k-1}|=|a_{k}|=1). This shows that \operatorname{SC}_{321}(\pi) is a periodic point beginning with an ascending run of length at least 3, which contradicts what we found in the previous two paragraphs.
∎





The following proposition proves Theorem 3.1 for \sigma=321, thereby completing the proof of the entire theorem. Indeed, we already proved the theorem for \sigma\in\{132,213,231,312\}, and we can use Lemma 1.2 to see that the next proposition implies Theorem 3.1 for \sigma=123 as well.



Proposition 3.7.



The set of periodic points of \operatorname{SC}_{321}:S_{n}\to S_{n} is \operatorname{Av}_{n}(\underline{123},\underline{321}), the set of permutations in S_{n} that avoid 123 and 321 consecutively. When n\geq 2, these points have period 2.




Proof.



It is clear that if \pi\in\operatorname{Av}(\underline{123},\underline{321}), then \operatorname{SC}_{321}(\pi)=\operatorname{rev}(\pi)\in\operatorname{Av}(\underline{123},\underline{321}), so \operatorname{SC}_{321}^{2}(\pi)=\pi. Hence, \pi is a periodic point of \operatorname{SC}_{321}, and the period is 2 if n\geq 2.




Suppose that \pi\notin\operatorname{Av}(\underline{123},\underline{321}); we will show that \pi is not a periodic point of \operatorname{SC}_{321}. If \pi does not contain a consecutive 321 pattern but does contain a consecutive 123 pattern, then \operatorname{SC}_{321}(\pi)=\operatorname{rev}(\pi) contains a consecutive 321, so we may simply assume that \pi\notin\operatorname{Av}(\underline{321}) (otherwise, the same analysis applies to \operatorname{SC}_{321}(\pi)). Suppose instead that \pi is a periodic point, and let a_{1},\ldots,a_{k} be its ascending runs. Note that we have g(\pi)=g(\operatorname{SC}_{321}(\pi)). Furthermore, the sequence a_{1}^{m}\cdots a_{k}^{m} is nonempty because \pi contains a consecutive 321 pattern. It then follows from Lemma 3.3 that \operatorname{SC}_{321}(\pi) is a periodic point of \operatorname{SC}_{321} that begins with the sequence a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}). If |a_{k}|\geq 2, then a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e}) has length at least 3, and Lemma 3.4 tells us that this sequence is decreasing. This implies that the periodic point \operatorname{SC}_{321}(\pi) starts with a decreasing sequence of length at least 3, contradicting Corollary 3.5. Hence, we must have |a_{k}|=1. Consider \pi_{n-1}, which is last entry in a_{k-1}. We must have \pi_{n-1}>\pi_{n}, so it follows from Lemma 3.4 that a_{1}^{m}\cdots a_{k}^{m}\operatorname{rev}(a_{k}^{e})\pi_{n-1} is an increasing sequence of length at least 3. This shows that \operatorname{SC}_{321}(\pi) is a periodic point whose first ascending run has length at least 3, which contradicts Corollary 3.6.
∎





4. The Maps \operatorname{SC}_{132} and \operatorname{SC}_{312}




In this section, we explore the maps \operatorname{SC}_{132} and \operatorname{SC}_{312} from both a sorting point of view and a dynamical point of view. We do not have much to say about \operatorname{SC}_{312} from a sorting point of view because we were not able to enumerate the set \operatorname{Sort}(\operatorname{SC}_{312}). The initial values of the sequence (|\operatorname{Sort}_{n}(\operatorname{SC}_{312})|)_{n\geq 0} are




1,1,2,5,15,50,179,675,2649,10734;



this sequence appears to be new.
However, we will be able to characterize and enumerate the permutations in \operatorname{Sort}(\operatorname{SC}_{132}). Specifically, we show that they are in bijection with Dyck paths and are thus enumerated by the Catalan numbers.




From a dynamical point of view, we will be interested in the number of preimages of permutations under \operatorname{SC}_{132} and \operatorname{SC}_{312}. In this setup, it suffices to focus our attention on \operatorname{SC}_{132}. Indeed, since 312=\operatorname{comp}(132), Lemma 1.2 implies that |\operatorname{SC}_{312}^{-1}(\pi)|=|\operatorname{SC}_{132}^{-1}(\operatorname{comp}(\pi))| for all \pi\in S_{n}. Consequently, we will not need to discuss the map \operatorname{SC}_{312} directly in this section.




Let us begin with the set \operatorname{Sort}(\operatorname{SC}_{132}). Recall that a left-to-right minimum of a permutation \pi=\pi_{1}\cdots\pi_{n} is an entry \pi_{i} such that \pi_{i}<\pi_{j} for all 1\leq j<i. For example, the left-to-right minima of 4572163 are 4, 2, and 1.



Proposition 4.1.



Let \pi=a_{1}\cdots a_{k}\in S_{n}, where the subsequences a_{i} are the ascending runs of \pi. For each i, let us write a_{i}=m_{i}t_{i}, where m_{i} is the first entry of a_{i} and t_{i} is the (possibly empty) string obtained by removing m_{i} from a_{i}. Then \operatorname{SC}_{132}(\pi)\in\operatorname{Av}(231) if and only if each m_{i} is a left-to-right minimum of \pi and the concatenation \operatorname{rev}(t_{1})\cdots\operatorname{rev}(t_{k}) is a decreasing sequence.




Proof.



Let us first assume \operatorname{SC}_{132}(\pi)\in\operatorname{Av}(231). We will prove by induction that the entries m_{1},\ldots,m_{k} are all left-to-right minima of \pi. Since m_{1} is the first entry of \pi, it is trivially a left-to-right minimum. Now consider 1\leq i<k, and suppose that m_{1},\ldots,m_{i} are all left-to-right minima. Suppose by way of contradiction that m_{i+1} is not a left-to-right minimum. This implies that if we write t_{i}=b_{1}\cdots b_{j}, where j=|t_{i}|, then j\geq 1 and m_{i}<m_{i+1}<b_{j}. Let \ell be the smallest index such that b_{\ell}>m_{i+1}. When we send \pi through the consecutive-132-avoiding stack, the consecutive subsequence a_{i} will enter the stack consecutively, so \operatorname{rev}(a_{i})=b_{j}\cdots b_{1}m_{i} will be at the top of the stack when m_{i+1} is next in line to be pushed into the stack. The entries b_{j},\ldots,b_{\ell+1} will be popped, and then m_{i+1} will be pushed into the stack on top of b_{\ell}. Since b_{\ell}>m_{i+1}, the entry m_{i+1} will not get popped out of the stack until after all of the entries of \pi have entered the stack. It follows that m_{i+1},b_{\ell},m_{i} form an occurrence of the classical pattern 231 in \operatorname{SC}_{132}(\pi); this is our desired contradiction. It is straightforward to see that \operatorname{SC}_{132}(a_{1}\cdots a_{k})=\operatorname{rev}(t_{1})\cdots\operatorname{rev}(t_{k})m_{k}\cdots m_{1}, where m_{k}=1. Since we are assuming \operatorname{SC}_{132}(a_{1}\cdots a_{k}) avoids 231, the sequence \operatorname{rev}(t_{1})\cdots\operatorname{rev}(t_{k}) must be decreasing.




For the reverse direction, suppose that the entries m_{1},\ldots,m_{k} are left-to-right minima and that the sequence \operatorname{rev}(t_{1})\cdots\operatorname{rev}(t_{k}) is decreasing. As above, \operatorname{SC}_{132}(\pi)=\operatorname{rev}(t_{1})\cdots\operatorname{rev}(t_{k})m_{k}\cdots m_{1}, which is a decreasing sequence followed by an increasing sequence. Such a permutation necessarily avoids 231.
∎




Remark 4.2.



The proof of Proposition 4.1 yields the somewhat-unexpected fact that if a permutation is in the image of \operatorname{SC}_{132} and avoids the pattern 231, then it also avoids 132.





Proposition 4.1 tells us that each \pi\in\operatorname{Sort}(\operatorname{SC}_{132}) is determined by the first entries m_{i} of its ascending runs as well as the lengths |a_{1}|,\ldots,|a_{k}| of its ascending runs. Furthermore, these quantities must satisfy n+1-m_{i}\geq|a_{1}|+\cdots+|a_{i}| for all i. Indeed, the entries in t_{1} must be the |a_{1}|-1 largest elements of [n]\setminus\{m_{1},\ldots,m_{k}\}, the entries in t_{2} must be the next |a_{2}|-1 largest elements, and so on. The condition that n+1-m_{i}\geq|a_{1}|+\cdots+|a_{i}| for all i guarantees that the m_{i}’s are left-to-right minima.




A Dyck path of semilength n is a word over the alphabet \{U,D\} that contains n copies of each letter and has the additional property that each of its prefixes contains at least as many occurrences of U as occurrences of D. Let {\bf D}_{n} denote the set of Dyck paths of semilength n. It is well known that |{\bf D}_{n}|=C_{n}=\frac{1}{n+1}{2n\choose n} is the nth Catalan number. Given \pi\in S_{n} such that \operatorname{SC}_{132}(\pi)\in\operatorname{Av}(231), write \pi=a_{1}\cdots a_{k} and a_{i}=m_{i}t_{i} as in Proposition 4.1. Let \Phi(\pi) be the Dyck path U^{m_{0}-m_{1}}D^{|a_{1}|}U^{m_{1}-m_{2}}D^{|a_{2}|}\cdots U^{m_{k-1}-m_{k}}D^{|a_{k}|}, where we make the convention m_{0}=n+1.



Example 4.3.



Let \pi=589436712, and note that \operatorname{SC}_{132}(\pi)=987621345\in\operatorname{Av}(231). We have a_{1}=589, a_{2}=4, a_{3}=367, and a_{4}=12. The first entries of these ascending runs are m_{1}=5, m_{2}=4, m_{3}=3, and m_{4}=1. Therefore, \Phi(\pi)=UUUUUDDDUDUDDDUUDD.




Theorem 4.4.



The map \Phi:\operatorname{Sort}_{n}(\operatorname{SC}_{132})\to{\bf D}_{n} is a bijection. Consequently,




|\operatorname{Sort}_{n}(\operatorname{SC}_{132})|=C_{n}.






Proof.



Preserve the notation from above. The total number of occurrences of the letter U in \Phi(\pi) is (m_{0}-m_{1})+\cdots+(m_{k-1}-m_{k})=m_{0}-m_{k}=(n+1)-1=n, and the total number of occurrences of D is |a_{1}|+\cdots+|a_{k}|=n. As mentioned above, we have n+1-m_{i}\geq|a_{1}|+\cdots+|a_{i}| for all i; this guarantees that \Phi(\pi) is indeed a Dyck path of semilength n. Moreover, by the previous discussion, \Phi is injective.




To prove surjectivity, suppose we are given a Dyck path \Lambda=U^{\gamma_{1}}D^{\delta_{1}}U^{\gamma_{2}}D^{\delta_{2}}\cdots U^{\gamma_{k}}D^{\delta_{k}} for some positive integers \gamma_{1},\ldots,\gamma_{k},\delta_{1},\ldots,\delta_{k}. Define m_{i}=n+1-\gamma_{1}-\cdots-\gamma_{i}. Using the fact that \Lambda is a Dyck path, one can verify that there exists a permutation \pi\in S_{n} with ascending runs a_{1},\ldots,a_{k} satisfying the conditions in Proposition 4.1 with a_{i}=m_{i}t_{i} and |a_{i}|=\delta_{i} for all i. This permutation is in \operatorname{Sort}_{n}(\operatorname{SC}_{132}) and satisfies \Phi(\pi)=\Lambda.
∎





The next series of results determines the maximum number of preimages of permutations under \operatorname{SC}_{132} and \operatorname{SC}_{312}. As mentioned above, it is only necessary to consider \operatorname{SC}_{132}.



Lemma 4.5.



Let \pi\in S_{n}. Suppose there exists an entry i\in[n-1] that occurs before i+1 but not immediately before i+1 in \pi. Let \pi^{\prime} be the permutation obtained by swapping i and i+1 in \pi. Then,




|\operatorname{SC}_{132}^{-1}(\pi)|\leq|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|.






Proof.



Suppose \operatorname{SC}_{132}(\tau)=\pi, and let \tau^{\prime} be the permutation obtained by swapping i and i+1 in \tau. We will prove that \operatorname{SC}_{132}(\tau^{\prime})=\pi^{\prime}. To do so, it suffices to show that the sequence of “push” and “pop” operations that is used to send \tau through the consecutive-132-avoiding stack is exactly the same as the sequence used to send \tau^{\prime} through the stack.




When sending \tau through the consecutive-132-avoiding stack, the entries i and i+1 are never consecutive entries in the stack. Indeed, if they were, then i would sit on top of i+1 because i appears before i+1 in the output permutation \pi. However, if i sits on top of i+1, then these two entries will appear consecutively in the output \pi, contrary to our hypothesis. Now consider the sequences of “push” and “pop” operations that send \tau and \tau^{\prime} through the stack. Note that in each sequence, the first two operations are necessarily pushes. Now suppose the first two sequences agree in their first k operations. Suppose further that after the first k operations, the stack-sorting procedure that is being applied to \tau (respectively, \tau^{\prime}) has b (respectively, b^{\prime}) as the top entry in the stack, has c (respectively, c^{\prime}) as the second-to-top entry in the stack, and has a (respectively, a^{\prime}) as the entry next in line to enter the stack. We show that the next operation is the same as well.




If none of a, b, and c are i or i+1, then it must be that a=a^{\prime}, b=b^{\prime}, and c=c^{\prime}, so the claim is trivially true. Next, if exactly one of a, b, and c is i or i+1, then abc and a^{\prime}b^{\prime}c^{\prime} have the same relative order, so the claim is true is in this case as well. Finally, suppose exactly two of a,b,c are i or i+1. Because i and i+1 cannot appear consecutively in the stack, we cannot have \{b,c\}=\{i,i+1\}. If \{a,b\}=\{i,i+1\}, then one of the two sorting procedures (sorting \tau or \tau^{\prime}) would have i and i+1 appear consecutively in the stack, which is again impossible. Therefore, it must be that (a,c)=(i,i+1) or (a^{\prime},c^{\prime})=(i,i+1). The two cases are symmetric, so we may assume the former. Note that abc cannot have the same relative order as 132 as, otherwise, i and i+1 would end up being consecutive in the stack once b gets popped out and c=i+1 gets pushed in. Thus, the next operation for the \tau case is to push a into the stack. Likewise a^{\prime}=i+1 and c^{\prime}=i, so a^{\prime}b^{\prime}c^{\prime} cannot have the same relative order as 132. The next operation in the \tau^{\prime} case is therefore to push a^{\prime} into the stack. By induction, the sequences of operations when sending \tau and \tau^{\prime} through the consecutive-132-avoiding stack are identical.




Since the map \tau\mapsto\tau^{\prime} is one-to-one, this shows that |\operatorname{SC}_{132}^{-1}(\pi)|\leq|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|, as desired.
∎




Corollary 4.6.



For every positive integer n, we have




\max_{\pi\in\operatorname{Av}_{n}(132,213)}|\operatorname{SC}_{132}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|.






Proof.



Suppose \pi\in S_{n}. If \pi classically contains an occurrence of either 132 or 213, then there exists some i\in[n-1] such that i and i+1 are not consecutive in \pi and i occurs before i+1. Lemma 4.5 tells us that swapping these entries yields a permutation with at least as many preimages under \operatorname{SC}_{132}. By repeatedly performing such swaps, we must eventually reach a permutation in \operatorname{Av}_{n}(132,213) (the sequence of swaps must terminate because each swap decreases the number of inversions in the permutation by 1), and this permutation has at least as many preimages under \operatorname{SC}_{132} as \pi.
∎





A permutation in S_{n} is called reverse-layered if the set of entries in each of its ascending runs forms an interval of consecutive integers. For example, 5674231 is reverse-layered because the sets of entries in its ascending runs are \{5,6,7\}, \{4\}, \{2,3\}, and \{1\}. It is well known [30] that \operatorname{Av}_{n}(132,213) is precisely the set of reverse-layered permutations in S_{n}. Note that each reverse-layered permutation is uniquely determined by its set of descents, which we can encode via a word of length n over the alphabet \{A,D\} that starts with A. More precisely, the reverse-layered permutation \pi=\pi_{1}\cdots\pi_{n} corresponds to the word b_{1}\cdots b_{n}, where b_{1}=A and for 2\leq j\leq n, we have b_{j}=A if \pi_{j-1}<\pi_{j} and b_{j}=D if \pi_{j-1}>\pi_{j}. Let d_{\pi}(k) denote the number of occurrences of D in the subword b_{1}\cdots b_{k}. Let a_{\pi}(k) denote the number of occurrences of A in the word b_{k+1}\cdots b_{n} that appear to the right of an occurrence of the letter D in b_{k+1}\cdots b_{n}. For example, the reverse-layered permutation \pi=78634512 corresponds to the word AADDAADA. We have




(d_{\pi}(0),\ldots,d_{\pi}(8))=(0,0,0,1,2,2,2,3,3)\quad\text{and}\quad(a_{\pi}(0),\ldots,a_{\pi}(8))=(3,3,3,3,1,1,1,0,0).



Using this notation, we can obtain a nice formula for |\operatorname{SC}_{132}^{-1}(\pi)| when \pi is reverse-layered. The reader may find it helpful to refer to Example 4.8 while reading the following proof.



Theorem 4.7.



Let \pi\in\operatorname{Av}_{n}(132,213) be a reverse-layered permutation in S_{n}, and preserve the definitions of d_{\pi}(k) and a_{\pi}(k) from above. We have




|\operatorname{SC}_{132}^{-1}(\pi)|=\sum_{k=0}^{n}{d_{\pi}(k)+a_{\pi}(k)\choose k}.






Proof.



Let \operatorname{SC}_{132,k}^{-1}(\pi) denote the set of permutations \tau\in\operatorname{SC}_{132}^{-1}(\pi) such that when \tau is sent through the consecutive-132-avoiding stack, exactly k entries get popped out of the stack before all entries have entered the stack. We will show that




|\operatorname{SC}_{132,k}^{-1}(\pi)|={d_{\pi}(k)+a_{\pi}(k)\choose k},



which will complete the proof. Note that |\operatorname{SC}_{132,0}^{-1}(\pi)|=1 because the only element of \operatorname{SC}_{132,0}^{-1}(\pi) is \operatorname{rev}(\pi). Indeed, \operatorname{SC}_{132} does actually send \operatorname{rev}(\pi) to \pi because \pi is reverse-layered (hence, \operatorname{rev}(\pi) avoids 231). Therefore, we may assume that k\geq 1 in what follows.




Suppose \tau\in\operatorname{SC}_{132,k}^{-1}(\pi). When we send \tau through the consecutive-132-avoiding stack, the k entries popped before all entries have entered the stack must be exactly \pi_{1},\ldots,\pi_{k}, and they must be popped in that order. The other entries \pi_{k+1},\ldots,\pi_{n} get popped out of the stack later in this order, so they must appear in \tau in the order \pi_{n},\ldots,\pi_{k+1}. Thus, when constructing such a preimage \tau, we first insert each entry \pi_{i} with 1\leq i\leq k between a pair of entries \pi_{j(i)},\pi_{j(i)+1} with k+1\leq j(i)\leq n and then reverse the entire permutation. When we do so, the following conditions must be satisfied:





• 



the string \pi_{j(i)}\pi_{i}\pi_{j(i)+1} has the same relative order as 132;


• 



j(1)\geq\cdots\geq j(k);


• 



if j(i)=j(i+1), then \pi_{i}>\pi_{i+1} and \pi_{i+1}\pi_{i} is a consecutive subsequence of \tau.



The first and third conditions ensure that the entries \pi_{1},\ldots,\pi_{k} actually get popped before all entries have entered the stack; the second and third conditions ensure that they are popped in the correct order.
Moreover, each placement of the entries \pi_{1},\dots,\pi_{k} between consecutive entries in \pi_{k+1}\cdots\pi_{n} such that the three conditions are satisfied yields a unique preimage \tau\in\operatorname{SC}_{132,k}^{-1}(\pi).




To determine the number of valid placements, let \pi_{\ell} be the last entry in the ascending run of \pi that includes \pi_{k}. When we insert the entry \pi_{k} between the entries \pi_{j(k)},\pi_{j(k)+1}, the first condition above guarantees that j(k)\geq\ell+1, so it follows from the second condition that j(1)\geq\cdots\geq j(k)\geq\ell+1. Thus, for each i\in[k], the possible choices for the index j(i) are precisely the ascents counted by a_{\pi}(k).
To satisfy the third condition, note that we can have j(i)=j(i+1) only if i is a descent of \pi. In summary, this proves that the number of ways to choose a preimages \tau is equal to the number of ways to choose the indices j(1),\ldots,j(k) from among the ascents counted by a_{\pi}(k) such that j(1)\geq\cdots\geq j(k), where the inequality j(i)\geq j(i+1) is actually strict whenever i is an ascent of \pi.
If we decide that there are precisely t descents i such that j(i)=j(i+1), then there are \binom{d_{\pi}(k)}{t} choices for these descents. There are then \binom{k}{k-t} choices for the set \{j(1),\ldots,j(k)\} of values taken by the indices j(1),\ldots,j(k). These choices uniquely determine j(1),\ldots,j(k).
Together, this shows that




|\operatorname{SC}_{132,k}^{-1}(\pi)|=\sum_{t=0}^{d_{\pi}(k)}{d_{\pi}(k)\choose t}{a_{\pi}(k)\choose k-t}={d_{\pi}(k)+a_{\pi}(k)\choose k},



where the second equality is due to Vandermonde’s Identity.
∎




Example 4.8.



Let us take \pi to be the permutation 12\,13\,11\,8\,9\,10\,6\,7\,5\,1\,2\,3\,4. Suppose we want to construct a preimage \tau\in\operatorname{SC}_{132,5}^{-1}(\pi). The ascents counted by a_{\pi}(5) are 7,10,11,12, which correspond to the following blanks: 6\underline{\hskip 5.69046pt}7\,5\,1\underline{\hskip 5.69046pt}2\underline{\hskip 5.69046pt}3\underline{\hskip 5.69046pt}4. Therefore, a_{\pi}(5)=4. We need to insert the entries 12,13,11,8,9 into some of these blanks. As an example illustrating the notation from the proof of Theorem 4.7, placing the entry \pi_{2}=13 in the blank between the entries \pi_{10}=1 and \pi_{11}=2 would correspond to setting j(2)=10. The indices in \{1,\ldots,5\} that are descents of \pi are 2 and 3 (meaning d_{\pi}(5)=2), so the proof of the theorem tells us that we must choose j(1),\ldots,j(5)\in\{7,10,11,12\} such that j(1)>j(2)\geq j(3)\geq j(4)>j(5). The number of ways to make this choice is




\sum_{t=0}^{2}{2\choose t}{4\choose 5-t}={2+4\choose 5}.



For one specific choice, we can take j(1)=12, j(2)=j(3)=j(4)=10, and j(5)=7. This corresponds to inserting the entries into the blanks to produce the permutation 6\,9\,7\,5\,1\,13\,11\,8\,2\,3\,12\,4. Reversing this permutation produces \tau=4\,12\,3\,2\,8\,11\,13\,1\,5\,7\,9\,6, which is indeed in \operatorname{SC}_{132,5}^{-1}(\pi).




Lemma 4.9.



Let \pi=\pi_{1}\cdots\pi_{n}\in S_{n}\setminus\{123\cdots n\}, and let b=b_{1}\cdots b_{n} be its corresponding word over the alphabet \{A,D\} as above. Let i be the smallest positive integer such that b_{i+1}=A, and let a=a_{\pi}(i-1). Finally, let \pi^{\prime} be the permutation whose corresponding word over \{A,D\} is the following modification of b:




b^{\prime}=\begin{cases}\underbrace{AD\cdots DD}_{i+1}b_{i+2}\cdots b_{n}&\mbox{if }a\geq i;\\
\underbrace{AD\cdots D}_{i}b_{i+2}\cdots b_{n}A&\mbox{if }a<i.\end{cases}



Then |\operatorname{SC}_{132}^{-1}(\pi)|\leq|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|.




Proof.



Suppose a\geq i. Then b=\underbrace{AD\cdots DA}_{i+1}b_{i+2}\cdots b_{n} and b^{\prime}=\underbrace{AD\cdots DD}_{i+1}b_{i+2}\cdots b_{n}, with permutations \pi and \pi^{\prime} corresponding to b and b^{\prime} respectively. Note that a=a_{\pi}(i-1)=\cdots=a_{\pi}(1). Furthermore, d_{\pi}(r)=r-1 for all 1\leq r\leq i. By Theorem 4.7 and the Hockey Stick Identity,




\displaystyle|\operatorname{SC}_{132}^{-1}(\pi)|
\displaystyle=1+{a\choose 1}+\cdots+{a+i-2\choose i-1}+\sum_{r=i}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}




\displaystyle=1+{a+i-1\choose i-1}+\sum_{r=i}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}.



It is straightforward to see that d_{\pi}(i)=d_{\pi}(i+1) and a_{\pi}(i)=a_{\pi}(i+1), so by Pascal’s Identity,




|\operatorname{SC}_{132}^{-1}(\pi)|=1+{a+i-1\choose i-1}+{d_{\pi}(i+1)+a_{\pi}(i+1)+1\choose i+1}+\sum_{r=i+2}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}.






As for the preimages of \pi^{\prime}, notice that for r\geq i+1, we have d_{\pi^{\prime}}(r)=d_{\pi}(r)+1 and a_{\pi^{\prime}}(r)=a_{\pi}(r). Furthermore, we have d_{\pi^{\prime}}(r)=d_{\pi}(r)=r-1 and a_{\pi^{\prime}}(r)\geq a_{\pi}(r)-1 for all 1\leq r\leq i. Thus,




\displaystyle|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|\geq 1+
\displaystyle{a-1\choose 1}+\cdots+{a+i-3\choose i-1}+{a+i-2\choose i}




\displaystyle+{d_{\pi}(i+1)+a_{\pi}(i+1)+1\choose i+1}+\sum_{r=i+2}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}



\displaystyle=1+
\displaystyle{a+i-1\choose i}+{d_{\pi}(i+1)+a_{\pi}(i+1)+1\choose i+1}+\sum_{r=i+2}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}.



This proves that if a=a_{\pi}(i-1)\geq i, then |\operatorname{SC}_{132}^{-1}(\pi)|\leq|\operatorname{SC}_{132}^{-1}(\pi^{\prime})| as desired.




Now suppose a<i so that b=\underbrace{AD\cdots DA}_{i+1}b_{i+2}\cdots b_{n} and b^{\prime}=\underbrace{AD\cdots D}_{i}b_{i+2}\cdots b_{n}A, with permutations \pi and \pi^{\prime} corresponding to b and b^{\prime} respectively. We may suppose that b_{j}=D for some j\geq i+2 as, otherwise, b=b^{\prime} and the inequality is trivially true. Thus, a_{\pi^{\prime}}(i)=a_{\pi}(i)+1 and d_{\pi^{\prime}}(i)=d_{\pi}(i). It is straightforward to see that d_{\pi^{\prime}}(r)=d_{\pi}(r) and a_{\pi^{\prime}}(r)=a_{\pi}(r) for 1\leq r\leq i-1. Furthermore, d_{\pi}(r)=d_{\pi^{\prime}}(r-1) and a_{\pi}(r)\leq a_{\pi^{\prime}}(r-1) for r\geq i+2. Observe also that \binom{d_{\pi^{\prime}}(n)+a_{\pi^{\prime}}(n)}{n}=\binom{d_{\pi^{\prime}}(n)}{n}=0. It follows that,




\displaystyle|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|-|\operatorname{SC}_{132}^{-1}(\pi)|
\displaystyle={d_{\pi}(i)+a_{\pi}(i)+1\choose i}-{d_{\pi}(i)+a_{\pi}(i)\choose i}-{d_{\pi}(i+1)+a_{\pi}(i+1)\choose i+1}




\displaystyle\hskip 14.22636pt+\sum_{r=i+1}^{n-1}{d_{\pi^{\prime}}(r)+a_{\pi^{\prime}}(r)\choose r}-\sum_{r=i+2}^{n}{d_{\pi}(r)+a_{\pi}(r)\choose r}




\displaystyle\geq{d_{\pi}(i)+a_{\pi}(i)+1\choose i}-{d_{\pi}(i)+a_{\pi}(i)\choose i}-{d_{\pi}(i+1)+a_{\pi}(i+1)\choose i+1}




\displaystyle\hskip 14.22636pt+\sum_{r=i+2}^{n}\left[{d_{\pi}(r)+a_{\pi}(r)\choose r-1}-{d_{\pi}(r)+a_{\pi}(r)\choose r}\right].






Since a<i by assumption, a_{\pi}(r)<a<i<r for all r\geq i+2. Moreover, d_{\pi}(r)<r trivially, so it follows that 2r>d_{\pi}(r)+a_{\pi}(r) and




{d_{\pi}(r)+a_{\pi}(r)\choose r-1}\geq{d_{\pi}(r)+a_{\pi}(r)\choose r}



for all r\geq i+2. This shows that the summation in the above inequality is nonnegative.




Finally, we also have that d_{\pi}(i)=d_{\pi}(i+1)=i-1 and a_{\pi}(i)=a_{\pi}(i+1), so by Pascal’s Identity,




\displaystyle|\operatorname{SC}_{132}^{-1}(\pi^{\prime})|-|\operatorname{SC}_{132}^{-1}(\pi)|
\displaystyle\geq{d_{\pi}(i)+a_{\pi}(i)+1\choose i}-{d_{\pi}(i)+a_{\pi}(i)\choose i}-{d_{\pi}(i+1)+a_{\pi}(i+1)\choose i+1}




\displaystyle={i+a_{\pi}(i)\choose i}-{i+a_{\pi}(i)\choose i+1}\geq 0,



as desired. The last inequality follows from the fact that a_{\pi}(i)\leq a_{\pi}(i-1)=a<i.
∎





If we start with a permutation \pi\in\operatorname{Av}(132,213) whose corresponding word over \{A,D\} is not of the form AD\cdots DA\cdots A (i.e., the permutation is not simply a decreasing sequence followed by an increasing sequence), then the previous lemma allows us to alter the permutation and obtain a new permutation \pi^{\prime} with at least as many preimages under \operatorname{SC}_{132} as \pi. This is stated in the following corollary. It is well known that a permutation can be written as a decreasing sequence followed by an increasing sequence if and only if it avoids 132 and 231 classically. Therefore, the set of permutations in \operatorname{Av}(132,213) that can be written as a decreasing sequence followed by an increasing sequence is precisely \operatorname{Av}(132,213,231).



Corollary 4.10.



For every positive integer n, we have




\max_{\pi\in\operatorname{Av}_{n}(132,213,231)}|\operatorname{SC}_{132}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|.






Proof.



Let \displaystyle M=\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|. By Corollary 4.6, there is a permutation \pi\in\operatorname{Av}_{n}(132,213) such that |\operatorname{SC}_{132}^{-1}(\pi)|=M. Suppose \pi contains the pattern 231. We can alter \pi using Lemma 4.9 in order to obtain a new permutation \pi^{\prime} with |\operatorname{SC}_{132}^{-1}(\pi)|=M. Let b and b^{\prime} be the words over \{A,D\} corresponding to \pi and \pi^{\prime} respectively. Given a word w over \{A,D\}, let f_{1}(w) denote the length of the longest consecutive string of D’s in w starting in the second position of w, and let f_{2}(w) be the length of the longest suffix of w that uses only the letter A. Because \pi contains 231, it is straightforward to check (using the definition of b^{\prime} given in the proof of Lemma 4.9) that f_{1}(b)\leq f_{1}(b^{\prime}) and f_{2}(b)\leq f_{2}(b^{\prime}), where at least one of these inequalities must be strict. This shows that if we repeatedly use Lemma 4.9 to alter permutations, we must eventually reach a permutation \tau\in\operatorname{Av}_{n}(132,213,231) with |\operatorname{SC}_{132}^{-1}(\tau)|=M.
∎




Theorem 4.11.



The maximum number of preimages under \operatorname{SC}_{132} or \operatorname{SC}_{312} that a permutation in S_{n} can have is given by




\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{312}^{-1}(\pi)|={n-1\choose\left\lfloor\frac{n-1}{2}\right\rfloor}.






Proof.



By complementing, it suffices to consider only the map \operatorname{SC}_{132}. Let \displaystyle M=\max_{\pi\in S_{n}}|\operatorname{SC}_{132}^{-1}(\pi)|. By Corollary 4.10, there exists \pi\in\operatorname{Av}_{n}(132,213,231) with |\operatorname{SC}_{132}^{-1}(\pi)|=M. Since \pi avoids 132, 213, and 231, it must be of the form




n(n-1)\cdots(n-r+1)123\cdots(n-r).



The word over \{A,D\} corresponding to \pi is A\underbrace{D\cdots D}_{r}\underbrace{A\cdots A}_{n-r-1}. Observe that d_{\pi}(k)=\min(k-1,r) for all 1\leq k\leq n. Furthermore, we have a_{\pi}(k)=n-r-1 if 1\leq k\leq r and a_{\pi}(k)=0 if r+1\leq k\leq n. By Theorem 4.7 and the Hockey Stick Identity, we have




M=|\operatorname{SC}_{132}^{-1}(\pi)|=1+{n-r-1\choose 1}+{n-r\choose 2}+\cdots+{n-2\choose r}={n-1\choose r}\leq{n-1\choose\left\lfloor\frac{n-1}{2}\right\rfloor}.



Moreover, equality is achieved when r=\left\lfloor\frac{n-1}{2}\right\rfloor; this completes the proof.
∎





5. The Maps \operatorname{SC}_{213} and \operatorname{SC}_{231}




We begin this section with a brief discussion of the sets \operatorname{Sort}(\operatorname{SC}_{213}) and \operatorname{Sort}(\operatorname{SC}_{231}).
The initial terms of the sequence (|\operatorname{Sort}_{n}(\operatorname{SC}_{213})|)_{n\geq 0} are




1,1,2,5,15,50,180,686,2731,11254.



This sequence appears to be new.
On the other hand, the first 10 terms of (|\operatorname{Sort}_{n}(\operatorname{SC}_{213})|)_{n\geq 0} are




1,1,2,6,21,79,311,1265,5275,22431.



These numbers match the initial terms in the OEIS sequence A033321, which is the binomial transform of Fine’s sequence. Fine’s sequence (F_{k})_{k\geq 0} can be defined via its generating function




\sum_{k\geq 0}F_{k}x^{k}=\frac{1-\sqrt{1-4x}}{3-\sqrt{1-4x}}.





Conjecture 5.1.



For each positive integer n, we have




|\operatorname{Sort}_{n}(\operatorname{SC}_{231})|=\sum_{k=0}^{n}\binom{n}{k}F_{k+1}.







Our main focus in this section will be on the maximum number of preimages a permutation in S_{n} can have under either \operatorname{SC}_{213} or \operatorname{SC}_{231}.



Theorem 5.2.



For every n\geq 2, we have




\max_{\pi\in S_{n}}|\operatorname{SC}_{213}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{231}^{-1}(\pi)|=2^{n-2}.






Proof.



The equality \displaystyle\max_{\pi\in S_{n}}|\operatorname{SC}_{213}^{-1}(\pi)|=\max_{\pi\in S_{n}}|\operatorname{SC}_{231}^{-1}(\pi)| follows directly from Lemma 1.2, so we can focus on the map \operatorname{SC}_{231}. Now consider the process of sending a permutation \tau=\tau_{1}\cdots\tau_{n}\in S_{n} through a consecutive-231-avoiding stack. Say that the entry \tau_{j} is premature if it is popped out of the stack before all of the entries of \tau enter the stack. The effect of sending \tau through the stack is to shift all of the premature entries to the left while preserving their relative order and reverse the remaining (non-premature) entries.
More formally, if \{\tau_{j_{1}},\cdots,\tau_{j_{k}}\} are the premature entries of \tau, then \operatorname{SC}_{231}(\tau)=\tau_{j_{1}}\cdots\tau_{j_{k}}\operatorname{rev}(\tau\setminus\{\tau_{j_{1}},\cdots,\tau_{j_{k}}\}), where \tau\setminus\{\tau_{j_{1}},\cdots,\tau_{j_{k}}\} is simply the sequence \tau with the terms in \{\tau_{j_{1}},\cdots,\tau_{j_{k}}\} removed.




Now fix \pi=\pi_{1}\cdots\pi_{n}\in S_{n}, and consider a preimage \tau of \pi under \operatorname{SC}_{231}. Suppose that \tau_{j_{1}},\ldots,\tau_{j_{k}} are the premature entries of \tau (with j_{1}<\cdots<j_{k}). By the previous paragraph, \tau is obtained by inserting the entries \pi_{1},\ldots,\pi_{k} into \operatorname{rev}(\pi_{k+1}\cdots\pi_{n}) so that the entry in position j_{i} of \tau is \pi_{i} for all i\in[k]. This shows that \tau is uniquely determined by specifying \pi and the set of indices \{j_{1},\ldots,j_{k}\}. Finally, notice that the first and last entries of a permutation cannot be premature. Therefore, the positions of the premature entries of \tau must form a subset of \{2,\ldots,n-1\}. It follows that |\operatorname{SC}_{231}^{-1}(\pi)|\leq 2^{n-2}




To complete the proof, it suffices to show that |\operatorname{SC}_{231}^{-1}(n(n-1)\cdots 1)|\geq 2^{n-2}. For each set J=\{j_{1},\ldots,j_{k}\}\subseteq\{2,\ldots,n-1\} (with j_{1}<\cdots<j_{k}), let \tau^{J} be the permutation obtained by inserting the entries n,n-1,\ldots,n-k+1 into the sequence 123\cdots(n-k) so that for each i\in[k], the entry n+1-i is in position j_{i}. For example, if n=8 and J=\{2,3,5\}, then \tau^{J}=18726345. It is straightforward to check that \operatorname{SC}_{231}(\tau^{J})=n(n-1)\cdots 1 and that \tau^{J}\neq\tau^{J^{\prime}} whenever J\neq J^{\prime}. Consequently, |\operatorname{SC}_{231}^{-1}(n(n-1)\cdots 1)|\geq 2^{n-2}.
∎





6. The Maps \operatorname{SC}_{123} and \operatorname{SC}_{321}




Our goal in this section is to enumerate the sets \operatorname{Sort}(\operatorname{SC}_{123}) and \operatorname{Sort}(\operatorname{SC}_{321}), thereby proving analogues of two more of the main theorems from [11]. Our enumeration of \operatorname{Sort}(\operatorname{SC}_{321}) generalizes to \operatorname{Sort}(\operatorname{SC}_{k(k-1)\cdots 1}), so we focus on \operatorname{Sort}(\operatorname{SC}_{k(k-1)\cdots 1}) first instead.




It follows immediately from Lemma 2.3 that \operatorname{Sort}(\operatorname{SC}_{k(k-1)\cdots 1})=\operatorname{Av}(132,\underline{12\cdots k}) for k\geq 3. In Proposition 3.2 of [24] it was shown that this set is enumerated by the so-called generalized Motzkin numbers M_{k-1,n}, which can be defined via the formula




M_{k-1,n}=\frac{1}{n+1}\sum_{j=0}^{\left\lfloor n/k\right\rfloor}(-1)^{j}\binom{n+1}{j}\binom{2n-jk}{n}.



For k=3,4,5, and 6, these numbers are given by OEIS sequences A001006, A036765, A036766, and A036767 respectively [32].



Theorem 6.1 (​​[24]).



For k\geq 3, the sets \operatorname{Sort}_{n}(\operatorname{SC}_{k(k-1)\cdots 1})=\operatorname{Av}_{n}(132,\underline{12\cdots k}) are enumerated by the generalized Motzkin numbers. More precisely,




|\operatorname{Sort}_{n}(\operatorname{SC}_{k(k-1)\cdots 1})|=M_{k-1,n}.







The above theorem completes our enumeration of \operatorname{Sort}(\operatorname{SC}_{k(k-1)\cdots 1}). We remark that when k=3, the generalized Motzkin numbers M_{2,n} are the same as the classical Motzkin numbers M_{n}. These numbers will also be related to our enumeration of \operatorname{Sort}(\operatorname{SC}_{123}).



Corollary 6.2.



The set \operatorname{Sort}(\operatorname{SC}_{321}) is enumerated by the Motzkin numbers. That is,




|\operatorname{Sort}_{n}(\operatorname{SC}_{321})|=M_{n}.







The following is a well-known recurrence for the Motzkin numbers.



Lemma 6.3.



We have M_{0}=M_{1}=1 and, for n\geq 2,




M_{n}=M_{n-1}+\sum_{i=0}^{n-2}M_{i}M_{n-2-i}.







To begin enumerating \operatorname{Sort}(\operatorname{SC}_{123}), we first classify the set. In order to do this, it is helpful to use the notion of a vincular pattern. We refer the reader to [34] for a formal treatment of vincular patterns; we will only need to consider the set \operatorname{Av}(132,\underline{321}4,\underline{421}3,\underline{431}2). This is the set of permutations that avoid 132 and also do not contain any occurrences of the patterns 3214, 4213, or 4312 in which the first 3 entries in the occurrence of the pattern appear consecutively in the permutation. For example, 51324 belongs to this set of permutations because, although 5,3,2,4 form an occurrence of the pattern 4213, the entries 5,3,2 do not appear consecutively in 51324.



Theorem 6.4.



The set \operatorname{Sort}(\operatorname{SC}_{123}) consists of the permutations \pi=\pi_{1}\cdots\pi_{n}, for some positive integer n, that satisfy the following properties:


• 



\pi\in\operatorname{Av}(132)


• 



if \pi_{i}\pi_{i+1}\cdots\pi_{j} is a descending run of \pi of length at least 3, then there are no entries bigger than \pi_{j-1} to the right of \pi_{j-1} in \pi, and
the entries \pi_{i+1},...,\pi_{j-1} are consecutive integers.



Alternatively, \operatorname{Sort}(\operatorname{SC}_{123})=\operatorname{Av}(132,\underline{321}4,\underline{421}3,\underline{431}2).



Proof.



It is straightforward to check that a permutation satisfies the two listed conditions if and only if it is in \operatorname{Av}(132,\underline{321}4,\underline{421}3,\underline{431}2). The proof of the first statement is straightforward once we find an expression for \operatorname{SC}_{123}(\pi). Fortunately, this was done in Lemma 3.3 for the map \operatorname{SC}_{321}, so we may use Lemma 1.2 to find a similar expression for \operatorname{SC}_{123}(\pi) by complementing. Namely, suppose \pi=d_{1}\cdots d_{k}, where each d_{i} is a descending run. We have \operatorname{SC}_{123}(\pi)=d_{1}^{m}\cdots d_{k}^{m}\operatorname{rev}(d_{k}^{e})\cdots\operatorname{rev}(d_{1}^{e}), where d_{i}^{m} is the subsequence of d_{i} consisting of the entries that are not the first or last entries in d_{i} and d_{i}^{e} is the sequence obtained from d_{i} by deleting d_{i}^{m}.




To see that all permutations in \operatorname{Sort}(\operatorname{SC}_{123}) must satisfy the two conditions, note first that if abc forms an occurrence of the classical pattern 132 in \pi and a,b, and c are in the descending runs d_{i},d_{j}, and d_{\ell} respectively, then c, the second entry of \operatorname{rev}(d_{j}^{e}), and the first entry of \operatorname{rev}(d_{i}^{e}) form an occurrence of the classical pattern 231 in \operatorname{SC}_{123}(\pi). This shows that \operatorname{Sort}(\operatorname{SC}_{123})\subseteq\operatorname{Av}(132). For the first part of the second condition, suppose \pi_{i}\pi_{i+1}\cdots\pi_{j} is a descending run of length at least 3 and that \pi_{\ell} is an entry to the right of \pi_{j} that is also the first entry of a different descending run. Then \pi_{j-1}\pi_{\ell}\pi_{j} is a subsequence of \operatorname{SC}_{123}(\pi), and we certainly have \pi_{j}<\pi_{j-1}. It follows that if \operatorname{SC}_{123}(\pi)\in\operatorname{Av}(231), then \pi_{\ell}<\pi_{j-1}. Hence, no entry to the right of \pi_{j-1} in \pi is bigger than \pi_{j-1}. Finally, the previous two points imply the second part of the second condition. If the entries \pi_{i+1},...,\pi_{j-1} are not consecutive integers, then there is some entry \pi_{i^{\prime}} that is not part of the descending run containing these entries and that satisfies \pi_{i+1}>\pi_{i^{\prime}}>\pi_{j-1}. Then either \pi_{i^{\prime}}\pi_{i}\pi_{i+1} is a 132-subsequence or there is an entry to the right of \pi_{j-1} that is bigger than \pi_{j-1}.




To see that every permutation satisfying these conditions is indeed in \operatorname{Sort}(\operatorname{SC}_{123}), again decompose \pi into its descending runs and write \operatorname{SC}_{123}(\pi)=d_{1}^{m}\cdots d_{k}^{m}\operatorname{rev}(d_{k}^{e})\cdots\operatorname{rev}(d_{1}^{e}). The first condition ensures that \operatorname{rev}(d_{k}^{e})\cdots\operatorname{rev}(d_{1}^{e}) does not contain an occurrence of the classical pattern 231. The first part of the second condition ensures that d_{1}^{m}\cdots d_{k}^{m} is a decreasing sequence, so it also does not contain an occurrence of 231. Finally, the first condition and first part of the second condition ensure that there is no occurrence of the pattern 231 containing entries from both d_{1}^{m}\cdots d_{k}^{m} and \operatorname{rev}(d_{k}^{e})\cdots\operatorname{rev}(d_{1}^{e}). Indeed, suppose abc is an occurrence such a pattern. As d_{1}^{m}\cdots d_{k}^{m} is a decreasing sequence, the entry a must be in d_{1}^{m}\cdots d_{k}^{m} while b and c are in \operatorname{rev}(d_{k}^{e})\cdots\operatorname{rev}(d_{1}^{e}). Let i,j,\ell be the indices such that a is in d_{i}^{m}, b is in d_{j}^{e}, and c is in d_{\ell}^{e}. Since c appears to the right of b in \operatorname{SC}_{123}(\pi), we must have \ell<j. The first part of the second condition guarantees that j\leq i. However, this implies that cba is an occurrence of the classical pattern 132 in \pi, which is a contradiction.
∎






Before enumerating the permutations in \operatorname{Sort}(\operatorname{SC}_{123}), we need one more lemma that counts permutations avoiding 132 classically and 123 consecutively. We obtain this result via a bijection between \operatorname{Av}(132) and \operatorname{Av}(231). For our purposes, we only need the existence of this bijection and one of its properties. The bijection is described in detail in Lemma 4.1 of [14].



Lemma 6.5 (​​[14]).



For each n\geq 1, there exists a bijection \operatorname{swd}:\operatorname{Av}_{n}(132)\to\operatorname{Av}_{n}(231) that preserves the set of descents. That is, an index i is a descent of \pi if and only if it is a descent of \operatorname{swd}(\pi).




Corollary 6.6.



For each n\geq 1, the sets of permutations \operatorname{Av}_{n}(132,\underline{321}), \operatorname{Av}_{n}(231,\underline{321}), and \operatorname{Av}_{n}(132,\underline{123}) are in bijection. Consequently, |\operatorname{Av}_{n}(132,\underline{321})|=M_{n}.




Proof.



Using the previous lemma, we obtain a chain of bijections




\operatorname{Av}_{n}(132,\underline{321})\xrightarrow{\operatorname{swd}}\operatorname{Av}_{n}(231,\underline{321})\xrightarrow{\operatorname{rev}}\operatorname{Av}_{n}(132,\underline{123}).



By Theorem 6.2, |\operatorname{Av}_{n}(132,\underline{321})|=|\operatorname{Av}_{n}(132,\underline{123})|=M_{n}.
∎





We need one final lemma before completing the enumeration of \operatorname{Sort}(\operatorname{SC}_{123}).



Lemma 6.7.



The number of permutations in \operatorname{Sort}_{n}(\operatorname{SC}_{123}) beginning with the entry n is M_{n-1}.




Proof.



We proceed by induction on n, noting first that the lemma is trivial if n\leq 2. Assume n\geq 3. Suppose \pi\in\operatorname{Sort}_{n}(\operatorname{SC}_{123}) starts with the entry n, and let \pi^{\prime} be the permutation obtained by deleting the leading entry n from \pi. It follows from Theorem 6.4 that \pi^{\prime}\in\operatorname{Sort}_{n-1}(\operatorname{SC}_{123}) and that \pi^{\prime} either starts with the entry n-1 or starts with an ascent. On the other hand, if \tau\in\operatorname{Sort}_{n-1}(\operatorname{SC}_{123}) starts with the entry n-1 or starts with an ascent, then the permutation n\tau is in \operatorname{Sort}_{n}(\operatorname{SC}_{123}). By the induction hypothesis, there are M_{n-2} permutations in \operatorname{Sort}_{n-1}(\operatorname{SC}_{123}) that start with n-1.




We now need to determine the number of permutations \tau\in\operatorname{Sort}_{n-1}(\operatorname{SC}_{123}) that start with an ascent. Let i\in\{2,\ldots,n-1\} be such that \tau_{i}=n-1. We may write \tau as A(n-1)B, where A does not start with a descent (meaning it either starts with an ascent or consists of a single entry). Since \tau must avoid 132 by Theorem 6.4, every entry in A is greater than every entry in B, so the entries in A are n-i+2,\ldots,n-2 and the entries in B are 1,\ldots,n-i+1. Since (n-1)B has length n-i+1 and has the same relative order as (n-i+1)B, the number of possibilities for (n-1)B is the same as the number of possibilities for (n-i+1)B. Now (n-i+1)B can be any element of \operatorname{Sort}_{n-i+1}(\operatorname{SC}_{123}) that starts with n-i+1, so it follows from the induction hypothesis that the number of possibilities for (n-1)B is M_{n-i}. Next, for each possible choice of A, we can subtract n-i+1 from each entry of A. Theorem 6.4 implies that this operation yields a bijection between the set of possible choices for A and the set of permutations in \operatorname{Av}_{i-1}(132,\underline{321}) that do not start with a descent. If i\geq 3, then since A avoids 132 and starts with an ascent, the first two entries of A must be consecutive integers. As a result, removing the first entry and standardizing gives a bijection between permutations in \operatorname{Av}_{i-1}(132,\underline{321}) that do not start with a descent and permutations in \operatorname{Av}_{i-2}(132,\underline{321}). This implies that there are M_{i-2} possibilities for A by Lemma 6.6. If i=2, then it is also certainly true that the number of choices for A is M_{i-2}=M_{0}=1.




Putting this all together and invoking the Motzkin number recurrence in Lemma 6.3, we find that the number of permutations in \operatorname{Sort}_{n}(\operatorname{SC}_{123}) beginning with n is




M_{n-2}+\sum_{i=2}^{n-1}M_{i-2}M_{n-i}=M_{n-2}+\sum_{i=0}^{n-3}M_{i}M_{n-3-i}=M_{n-1}.\qed







We can now prove that \operatorname{Sort}(\operatorname{SC}_{123}) is enumerated by the first differences of Motzkin numbers, which form the OEIS sequence A002026 [32].



Theorem 6.8.



The permutations in \operatorname{Sort}(\operatorname{SC}_{123}) are counted by the first differences of Motzkin numbers. That is,




|\operatorname{Sort}_{n}(\operatorname{SC}_{123})|=M_{n+1}-M_{n}.






Proof.



Let X_{i}^{n} denote the set of permutations in \operatorname{Sort}_{n}(\operatorname{SC}_{123}) in which the ith entry is n. If \pi\in X_{i}^{n}, then we may write \pi=AnB, where A has length i-1 and B has length n-i. By Theorem 6.4, AnB avoids the pattern 132, so every entry in A is bigger than every entry in B, meaning that A is a permutation of the numbers n-i+1,\ldots,n-1 and B is a permutation of 1,\ldots,n-i. Moreover, the standardization of A can be an arbitrary element of \operatorname{Av}(132,\underline{321}), so the number of possibilities for A is M_{i-1} by Corollary 6.6. Meanwhile, the standardization of nB can be an arbitrary permutation in \operatorname{Sort}_{n-i+1}(\operatorname{SC}_{123}) that starts with n-i+1, so by Lemma 6.7, there are M_{n-i} possibilities for nB. Thus, |X_{i}^{n}|=M_{i-1}M_{n-i}, and




|\operatorname{Sort}_{n}(\operatorname{SC}_{123})|=\sum_{i=1}^{n}M_{i-1}M_{n-i}=\sum_{i=0}^{n-1}M_{i}M_{n-1-i}=M_{n+1}-M_{n}.\qed







7. Dynamics of the Maps s_{132} and s_{312}




The set \operatorname{Sort}(s_{132}) was the primary focus of the recent article [12], where it was shown that \operatorname{Sort}(s_{132}) is equal to the set of permutations avoiding the classical pattern 2314 as well as a certain mesh pattern. The same article proved that |\operatorname{Sort}_{n}(s_{132})|=\sum_{k=0}^{n-1}\binom{n-1}{k}C_{k}, where C_{k} denotes the kth Catalan number. In this section, we briefly discuss some dynamical properties of the map s_{132} and, by complementation, the map s_{312}.



Theorem 7.1.



The periodic points of the map s_{132}:S_{n}\to S_{n} are precisely the permutations in \operatorname{Av}_{n}(132,231). The periodic points of the map s_{312}:S_{n}\to S_{n} are precisely the permutations in \operatorname{Av}_{n}(213,312). When n\geq 2, each of these periodic points has period 2. Furthermore, for every permutation \pi\in S_{n}, we have s_{132}^{n-1}(\pi)\in\operatorname{Av}_{n}(132,231) and s_{312}^{n-1}(\pi)\in\operatorname{Av}_{n}(213,312).




Proof.



By Lemma 1.2, it suffices to prove the desired properties of s_{132}. Note that if we have \pi\in\operatorname{Av}(132,231), then s_{132}(\pi)=\operatorname{rev}(\pi)\in\operatorname{Av}(132,231), so s_{132}^{2}(\pi)=\pi. Hence, \pi is a periodic point of s_{132}, and the period is 2 if n\geq 2.




It remains to prove that s_{132}^{n-1}(\pi)\in\operatorname{Av}(132,231) for every \pi\in S_{n}. This is trivial if n=1, so we may assume n\geq 2 and induct on n. Consider sending a permutation \tau\in S_{n} through a classical-132-avoiding stack. When the entry 1 enters the stack, the entries below it in the stack must appear in increasing order from top to bottom. Furthermore, the entry 1 will not leave the stack until after all entries have entered the stack. This implies that the last ascending run of s_{132}(\tau) begins with the entry 1. Therefore, it suffices to prove that if \pi\in S_{n} is a permutation whose last ascending run begins with 1, then s_{132}^{n-2}(\pi)\in\operatorname{Av}(132,231). We prove this by induction on n, noting first that it is trivial if n=2. Now suppose n\geq 3.




For each \tau\in S_{n}, let \tau^{*} be the permutation in S_{n-1} obtained by deleting the entry 1 from \tau and then decreasing all remaining entries by 1. Observe that if the entries 1 and 2 appear consecutively in \tau, then they also appear consecutively in s_{132}(\tau) and that (s_{132}(\tau))^{*}=s_{132}(\tau^{*}). By induction, we have s_{132}^{n-2}(\tau^{*})\in\operatorname{Av}(132,231). If the last ascending run of \tau begins with 1, then the above analysis of the classical-132-avoiding stack shows that the entries 1 and 2 appear consecutively in s_{132}(\tau). It then follows that the entries 1 and 2 appear consecutively in s_{132}^{n-2}(\tau) and that (s_{132}^{n-2}(\tau))^{*}=s_{132}^{n-2}(\tau^{*})\in\operatorname{Av}(132,231). This implies that s_{132}^{n-2}(\tau)\in\operatorname{Av}(132,231), as desired.
∎





Whenever one is confronted with a noninvertible finite dynamical system, it is natural to ask for the maximum number of iterations of the map needed to send every point to a periodic point. For example, Knuth [29, pages 106–110] studied this problem for the classical bubble sort map. For West’s stack-sorting map s, permutations requiring close to the maximum number of iterations to get sorted into the identity were studied by West and Claesson–Dukes–Steingrímsson[13, 37]. Ungar gave a rather nontrivial argument proving that the maximum number of iterations needed to sort a permutation in S_{n} using the pop-stack-sorting map is n-1 [36], and the permutations requiring n-1 iterations were investigated further by Asinowski, Banderier, and Hackl [1]. Some other papers that have studied similar questions for other finite dynamical systems include
[35, 25, 4, 26, 21, 23].




Our second result in this section will determine the maximum number of iterations of s_{132} (equivalently, s_{312}) needed to send a permutation to a periodic point. In what follows, we let \operatorname{sd}_{132}(\pi) denote the smallest nonnegative integer t such that s_{132}^{t}(\pi)\in\operatorname{Av}(132,231). Note that \operatorname{sd}_{132}(\pi) is also the smallest nonnegative integer t such that s_{312}^{t}(\operatorname{comp}(\pi))\in\operatorname{Av}(213,312).



Theorem 7.2.



For n\geq 3, we have




\max_{\pi\in S_{n}}\operatorname{sd}_{132}(\pi)=n-1.






Proof.



Theorem 7.1 tells us that \displaystyle\max_{\pi\in S_{n}}\operatorname{sd}_{132}(\pi)\leq n-1, so it suffices to find a permutation \pi\in S_{n} such that \operatorname{sd}_{132}(\pi)\geq n-1. Let n=3m+r, where r\in\{0,1,2\}. Let \lambda_{m} denote the permutation in S_{n-r} obtained by taking the skew sum of m copies of the permutation 132. In other words, \lambda_{m}=\xi_{m}\xi_{m-1}\cdots\xi_{1}, where \xi_{j} denotes the sequence (3j-2)(3j)(3j-1). Let




\pi=\begin{cases}\lambda_{m}&\mbox{if }r=0;\\
n\lambda_{m}&\mbox{if }r=1;\\
(n-1)n\lambda_{m}&\mbox{if }r=2.\end{cases}



We claim that s_{132}^{n-2}(\pi)\not\in\operatorname{Av}(132,231); that is, \operatorname{sd}_{132}(\pi)\geq n-1. For the sake of simplicity, we will prove this in the case r=0; the proofs in the cases r=1 and r=2 are similar. Thus, n=3m and \pi=\lambda_{m}. If n=3, then we are done because s_{132}(\pi)=s_{132}(132)=231\not\in\operatorname{Av}(132,231). Therefore, we may assume n=3m\geq 6.




It will be helpful to introduce a little more notation. If k\geq 1 is odd (respectively, even), we let V_{k} denote the permutation in S_{3k} obtained by listing the odd (respectively, even) numbers in [3k+1] in decreasing order and then listing the even (respectively, odd) numbers in [3k+1] in increasing order. For example, we have V_{1}=3124, V_{2}=6421357, and V_{3}=9\,7\,5\,3\,1\,2\,4\,6\,8\,10. For i\in\{0,1,2\}, let D_{k,m}^{(i)} be the sequence obtained by writing the elements of \{3k+2,3k+3,\ldots,3m\} that are congruent to i modulo 3 in decreasing order. For example, D_{2,5}^{(0)}=15\,12\,9, D_{2,5}^{(1)}=13\,10, and D_{2,5}^{(2)}=14\,11\,8. The following two claims can be verified in a straightforward manner using nothing more than the definition of the map s_{132}; we leave this verification to the reader.




Claim 1: We have s_{132}^{4}(\lambda_{m})=D_{1,m}^{(2)}D_{1,m}^{(0)}V_{1}\operatorname{rev}\left(D_{1,m}^{(1)}\right).




Claim 2: For 1\leq k\leq m-2, we have




s_{132}^{3}\left(D_{k,m}^{(2)}D_{k,m}^{(0)}V_{k}\operatorname{rev}\left(D_{k,m}^{(1)}\right)\right)=D_{k+1,m}^{(2)}D_{k+1,m}^{(0)}V_{k+1}\operatorname{rev}\left(D_{k+1,m}^{(1)}\right).






These two claims imply that s_{132}^{n-2}(\pi)=s_{132}^{3m-2}(\lambda_{m})=D_{m-1,m}^{(2)}D_{m-1,m}^{(0)}V_{m-1}\operatorname{rev}\left(D_{m-1,m}^{(1)}\right). Note that D_{m-1,m}^{(2)} consists of the single entry 3m-1. Similarly, D_{m-1,m}^{(0)} consists of the single entry 3m. Finally, D_{m-1,m}^{(1)} is empty. Thus, s_{132}^{n-2}(\pi)=(3m-1)(3m)V_{m-1}\not\in\operatorname{Av}(132,231).
∎

In Section 7, we studied the maximum number of iterations of s_{132} (equivalently, s_{312}) needed to send a permutation to a periodic point. This line of investigation is completely open for the consecutive-pattern-avoiding stack-sorting maps. However, we do have the following conjecture, which we have verified for n\leq 9. Recall that the set of periodic points of \operatorname{SC}_{231}:S_{n}\to S_{n} is \operatorname{Av}_{n}(\underline{132},\underline{231})=\operatorname{Av}_{n}(132,231).



Conjecture 8.2.



Let n\geq 3. We have \operatorname{SC}_{231}^{2n-4}(\pi)\in\operatorname{Av}_{n}(132,231) for every \pi\in S_{n}. Furthermore, there exists a permutation \tau\in S_{n} such that \operatorname{SC}_{231}^{2n-5}(\tau)\not\in\operatorname{Av}_{n}(132,231).





In [16], the first author showed that the numbers 3,7,11,15,19,23 are infertility numbers, meaning that there does not exist a permutation \pi such that |s^{-1}(\pi)|\in\{3,7,11,15,19,23\}. By contrast, we have the following conjecture for the maps \operatorname{SC}_{\sigma} with \sigma\in S_{3}.



Conjecture 8.3.



For every \sigma\in S_{3} and every positive integer f, there exists a permutation \pi such that |\operatorname{SC}_{\sigma}^{-1}(\pi)|=f.





Section 7 contains the first theorems of a dynamical nature concerning maps of the form s_{\sigma}. It would be interesting to have other dynamical results for these maps, including analogues of Theorems 7.1 and 7.2 for the maps s_{\sigma} with \sigma\in\{123,213,231,321\}. In Theorems 7.1 and 7.2, we proved that every permutation \pi\in S_{n} satisfies s_{132}^{n-1}(\pi)\in\operatorname{Av}(132,231) and that there exists at least one permutation \tau\in S_{n} such that s_{132}^{n-2}(\tau)\not\in\operatorname{Av}(132,231). It would be interesting to obtain nontrivial information about these permutations \tau. We also have the following conjecture. If n is odd (respectively, even), let {\bf V}_{n} denote the permutation in S_{n} obtained by listing the odd (respectively, even) elements of [n] in decreasing order and then listing the even (respectively, odd) elements of [n] in increasing order. For example, {\bf V}_{6}=642135 and {\bf V}_{7}=7531246.



Conjecture 8.4.



If \tau\in S_{n} is such that s_{132}^{n-2}(\tau)\not\in\operatorname{Av}(132,231), then s_{132}^{n-1}(\tau)={\bf V}_{n}.





For example, one can check that if \tau\in S_{6} is such that s_{132}^{4}(\tau)\not\in\operatorname{Av}(132,231), then s_{132}^{5}(\tau)={\bf V}_{6}=642135.




Of course, it would also be very natural to consider the maps of the form \operatorname{SC}_{\sigma^{(1)},\ldots,\sigma^{(r)}}, where \operatorname{SC}_{\sigma^{(1)},\ldots,\sigma^{(r)}} is defined using a stack whose contents must consecutively avoid all of the patterns \sigma^{(1)},\ldots,\sigma^{(r)}. It would also be exciting to have results about the maps \operatorname{SC}_{\sigma} for patterns \sigma of length at least 4 (such as progress toward Conjecture 8.1).
