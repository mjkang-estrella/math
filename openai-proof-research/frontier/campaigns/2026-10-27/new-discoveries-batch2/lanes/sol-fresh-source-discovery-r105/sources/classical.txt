 Abstract 
    
 For a permutation  π \pi  in the symmetric group  S n S_{n}  let the
 total degree  be its valency in the Hasse diagram of the strong Bruhat order on  S n S_{n} ,
and let the  down degree  be the number of permutations which are covered by  π \pi  in
the strong Bruhat order.
The maxima of
the total degree and the down degree and their values at a random permutation
are computed. Proofs involve variants of a classical theorem of Turán from
extremal graph theory.

 2  Maximal Down Degree 

 
 In this section we compute the maximal value of the
down degree on  S n S_{n}  and find all the permutations achieving the maximum.
We prove 
 
 
 Proposition 2.1 
 
 For every positive integer  n n 
 

 
 
 max ⁡ { d − ​ ( π ) | π ∈ S n } = ⌊ n 2 / 4 ⌋ . \max\{d_{-}(\pi)|\ \pi\in S_{n}\}=\lfloor n^{2}/4\rfloor. 
 
 
 
 
 
 Remark 2.2 
 
 The same number appears as the order dimension of the strong Bruhat
poset  [ 7 ] .
An upper bound on the maximal down degree for finite Coxeter groups appears in
 [ 4 , Prop. 3.4] . 
 
 
 
 For the proof of Proposition  2.1  we need a classical theorem of Turán. 
 
 
 Definition 2.3 
 
 Let  r ≤ n r\leq n  be positive integers. The Turán graph
 T r ​ ( n ) T_{r}(n)  is the complete  r r -partite graph with  n n  vertices and
all parts as equal in size as possible, i.e., each size is
either  ⌊ n / r ⌋ \lfloor n/r\rfloor  or  ⌈ n / r ⌉ \lceil n/r\rceil .
Denote by  t r ​ ( n ) t_{r}(n)  the number of edges of  T r ​ ( n ) T_{r}(n) . 
 
 
 
 Theorem 2.4 
 
 [ 10 ]   [ 3 , IV, Theorem 8] 
 (Turán’s Theorem) 
 
 (1)  
 
 Every graph of order  n n  with more than  t r ​ ( n ) t_{r}(n)  edges
contains a complete subgraph of order  r + 1 r+1 . 
 
 (2)  
 
 T r ​ ( n ) T_{r}(n)  is
the unique graph of order  n n  with  t r ​ ( n ) t_{r}(n)  edges that does not
contain a complete subgraph of order  r + 1 r+1 . 
 
 
 
 
 
 We shall apply
the special case  r = 2 r=2  (due to Mantel) of
Turán’s theorem to the following graph. 
 
 
 Definition 2.5 
 
 The strong descent graph of  π ∈ S n \pi\in S_{n} , denoted  Γ − ​ ( π ) \Gamma_{-}(\pi) ,
is the undirected graph whose set of vertices is  { 1 , … , n } \{1,\dots,n\}  and whose
set of edges is 
 

 
 
 { { a , b } | t a , b ∈ D − ​ ( π ) } . \{\{a,b\}\,|\,t_{a,b}\in D_{-}(\pi)\}. 
 
 
 
 
 
 By definition, the number of edges in  Γ − ​ ( π ) \Gamma_{-}(\pi)  equals  d − ​ ( π ) d_{-}(\pi) . 
 
 
 Remark 2.6 
 
 Permutations for which the strong descent graph is connected are
called indecomposable. Their enumeration was studied
in  [ 5 ] ; see  [ 6 , pp. 7–8] .
The number of components in  Γ − ​ ( π ) \Gamma_{-}(\pi)  is equal to the number of
global descents in  π ​ w 0 \pi w_{0}  (where  w 0 := [ n , n − 1 , … , 1 ] w_{0}:=[n,n-1,\dots,1] ),
which were introduced and studied in  [ 1 , Corollaries 6.3 and 6.4] . 
 
 
 
 Lemma 2.7 
 
 For every  π ∈ S n \pi\in S_{n} , the strong descent graph  Γ − ​ ( π ) \Gamma_{-}(\pi)  is triangle-free. 
 
 
 
 Proof. 
Assume that  Γ − ​ ( π ) \Gamma_{-}(\pi)  contains a triangle.
Then there exist  1 ≤ a < b < c ≤ n 1\leq a<b<c\leq n 
such that  t a , b , t a , c , t b , c ∈ D − ​ ( π ) t_{a,b},t_{a,c},t_{b,c}\in D_{-}(\pi) . By Observation  1.2 , 
 

 
 
 t a , b , t b , c ∈ D − ​ ( π ) ⟹ π − 1 ​ ( c ) < π − 1 ​ ( b ) < π − 1 ​ ( a ) ⟹ t a , c ∉ D − ​ ( π ) . t_{a,b},t_{b,c}\in D_{-}(\pi)\Longrightarrow\pi^{-1}(c)<\pi^{-1}(b)<\pi^{-1}(a)\Longrightarrow t_{a,c}\not\in D_{-}(\pi). 
 
 
 This is a contradiction.

 3  Maximal Total Degree 

 
 Obviously, the maximal value of the total degree  d = d − + d + d=d_{-}+d_{+} 
cannot exceed  ( n 2 ) {n\choose 2} , the total number of transpositions in  S n S_{n} .
This is slightly better than the bound  2 ​ ⌊ n 2 / 4 ⌋ 2\lfloor n^{2}/4\rfloor 
obtainable from Proposition  2.1 .
The actual maximal value is smaller. 
 
 
 Theorem 3.1 
 
 For  n ≥ 2 n\geq 2 ,
the maximal total degree in the Hasse diagram of the
strong Bruhat order on  S n S_{n}  is 
 

 
 
 ⌊ n 2 / 4 ⌋ + n − 2 . \lfloor n^{2}/4\rfloor+n-2. 
 
 
 
 
 
 In order to prove this result, associate with each permutation  π ∈ S n \pi\in S_{n} 
a graph  Γ ⁡ ( π ) \Gamma(\pi) , whose set of vertices is  { 1 , … , n } \{1,\dots,n\}  and
whose set of edges is 
 

 
 
 { { a , b } | ℓ ⁡ ( t a , b ​ π ) − ℓ ⁡ ( π ) = ± 1 } . \{\{a,b\}\,|\,\ell(t_{a,b}\pi)-\ell(\pi)=\pm 1\}. 
 
 
 This graph has many properties; e.g., it is  K 5 K_{5} -free and is the
edge-disjoint union of two triangle-free graphs on the same set of vertices.
However, these properties are not strong enough to imply the above result.
A property which does imply it is the following bound on the minimal degree. 
 
 
 Lemma 3.2 
 
 There exists a vertex in  Γ ⁡ ( π ) \Gamma(\pi)  with degree at most  ⌊ n / 2 ⌋ + 1 \lfloor n/2\rfloor+1 . 
 
 
 
 Proof. 
Assume, on the contrary, that each vertex in  Γ ⁡ ( π ) \Gamma(\pi)  has at least
 ⌊ n / 2 ⌋ + 2 \lfloor n/2\rfloor+2  neighbors. This applies, in particular, to the vertex
 π ⁡ ( 1 ) \pi(1) .
Being the first value of  π \pi , the neighborhood of  π ⁡ ( 1 ) \pi(1)  in  Γ ⁡ ( π ) \Gamma(\pi) ,
viewed as a subsequence of  [ π ⁡ ( 2 ) , … , π ⁡ ( n ) ] [\pi(2),\ldots,\pi(n)] ,
consists of a shuffle of a decreasing sequence of numbers larger than  π ⁡ ( 1 ) \pi(1) 
and an increasing sequence of numbers smaller than  π ⁡ ( 1 ) \pi(1) .
Let  a a  be the rightmost neighbor of  π ⁡ ( 1 ) \pi(1) .
The intersection of the neighborhood of  a a  with

Corollary  5.8 .
