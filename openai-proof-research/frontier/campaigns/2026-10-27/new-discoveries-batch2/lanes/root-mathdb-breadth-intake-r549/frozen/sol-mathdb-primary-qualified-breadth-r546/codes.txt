 Abstract. 
    
 We study the  r r -th generalized minimum distance
function (gmd function for short) and the
corresponding generalized footprint function of a graded ideal in a
polynomial ring over a field. If  𝕏 \mathbb{X}  is a set of projective points over a
finite field and  I ⁡ ( 𝕏 ) I(\mathbb{X})  is its vanishing ideal, we show
that the gmd function and the Vasconcelos
function of  I ⁡ ( 𝕏 ) I(\mathbb{X})  are equal to the  r r -th
generalized Hamming weight of the corresponding Reed-Muller-type
code  C 𝕏 ​ ( d ) C_{\mathbb{X}}(d) . We show that the  r r -th generalized footprint function
of  I ⁡ ( 𝕏 ) I(\mathbb{X})  is a lower bound for the  r r -th generalized Hamming
weight of  C 𝕏 ​ ( d ) C_{\mathbb{X}}(d) . As an application to
coding theory we show an explicit formula and a combinatorial formula
for the second generalized Hamming weight of an affine cartesian code. 
  
 
 
 Key words and phrases:  Reed-Muller-type codes,
minimum distance, vanishing
ideal, degree, Hilbert function.

 The definition of  δ I ​ ( d , r ) \delta_{I}(d,r)  was motivated by the notion of
generalized Hamming weight of a linear code  [ 12 ,  23 ] . For convenience we
recall this notion. Let  K = 𝔽 q K=\mathbb{F}_{q}  be a finite field and let  C C  be a  [ m , k ] [m,k]   linear
code  of  length   m m  and  dimension   k k ,
that is,  C C  is a linear subspace of  K m K^{m}  with  k = dim K ( C ) k=\dim_{K}(C) .
Given a subcode  D D  of  C C  (that is,  D D  is a linear subspace of  C C ),
the  support  of  D D , denoted  χ ⁡ ( D ) \chi(D) , is the set of non-zero positions of  D D , that is, 
 

 
 
 χ ( D ) := { i | ∃ ( a 1 , … , a m ) ∈ D , a i ≠ 0 } . \chi(D):=\{i\,|\,\exists\,(a_{1},\ldots,a_{m})\in D,\,a_{i}\neq 0\}. 
 
 
 
 
 The  r r -th  generalized Hamming weight  of  C C , denoted
 δ r ​ ( C ) \delta_{r}(C) , is the size of the smallest support of an
 r r -dimensional subcode. Generalized Hamming weights
have received a lot of attention; see
 [ 4 ,  6 ,  9 ,  19 ,  23 ,  24 ]  and the
references therein. The study of these weights is related to
trellis coding,  t t –resilient functions, and was motivated from
some applications from cryptography  [ 23 ] . 
 
 
 The minimum distance of projective Reed-Muller-type codes has been
studied using Gröbner bases techniques; see
 [ 4 ,  9 ,  10 ,  17 ]  and the references
therein. In this work we extend these techniques to study the  r r -th
generalized Hamming weights of projective
Reed-Muller-type codes, a special type of linear codes that generalizes affine
Reed-Muller-type codes  [ 14 ] .
These projective codes are constructed
as follows. 
 
 
 Let  K = 𝔽 q K=\mathbb{F}_{q}  be a finite field with  q q  elements,
let  ℙ s − 1 \mathbb{P}^{s-1}  be a projective space over
 K K , and let  𝕏 \mathbb{X}  be a subset of
 ℙ s − 1 \mathbb{P}^{s-1} . The  vanishing ideal  of
 𝕏 \mathbb{X} , denoted  I ⁡ ( 𝕏 ) I(\mathbb{X}) , is the ideal of  S S 
generated by the homogeneous polynomials that vanish at all points of
 𝕏 \mathbb{X} . In this case the Hilbert function of  S / I ⁡ ( 𝕏 ) S/I(\mathbb{X})  is denoted by
 H 𝕏 ​ ( d ) H_{\mathbb{X}}(d) . We can write
 𝕏 = { [ P 1 ] , … , [ P m ] } ⊂ ℙ s − 1 \mathbb{X}=\{[P_{1}],\ldots,[P_{m}]\}\subset\mathbb{P}^{s-1} 
with  m = | 𝕏 | m=|\mathbb{X}| . Here we assume that  [ P 1 ] , … , [ P m ] [P_{1}],\ldots,[P_{m}]  are
written in standard form, that is, the first non-zero entry of  [ P i ] [P_{i}] 
from left to right is  1 1 . 
 
 
 Fix a degree  d ≥ 1 d\geq 1 . There is a  K K -linear map given by 
 

 
 
 ev d : S d → K m , f ↦ ( f ⁡ ( P 1 ) , … , f ⁡ ( P m ) ) . {\rm ev}_{d}\colon S_{d}\rightarrow K^{m},\ \ \ \ \ f\mapsto\left(f(P_{1}),\ldots,f(P_{m})\right). 
 
 
 
 
 The image of  S d S_{d}  under  ev d {\rm ev}_{d} , denoted by  C 𝕏 ​ ( d ) C_{\mathbb{X}}(d) , is
called a  projective Reed-Muller-type code  of
degree  d d  on  𝕏 \mathbb{X}   [ 7 ,  11 ] .
The  parameters  of the linear
code  C 𝕏 ​ ( d ) C_{\mathbb{X}}(d)  are: 
 
 (a)

paper are as follows. In Section  2  we
present some of the results and terminology that will be needed

 If  𝕏 \mathbb{X}  is a finite set of projective points over a
finite field and  I ⁡ ( 𝕏 ) I(\mathbb{X})  is its vanishing ideal, we show
that  δ I ⁡ ( 𝕏 ) ​ ( d , r ) \delta_{I(\mathbb{X})}(d,r)  is the  r r -th generalized Hamming weight
 δ 𝕏 ​ ( d , r ) \delta_{\mathbb{X}}(d,r)  of the corresponding Reed-Muller-type
code  C 𝕏 ​ ( d ) C_{\mathbb{X}}(d)  (Theorem  4.5 ). We introduce
the  Vasconcelos  function  ϑ I ​ ( d , r ) \vartheta_{I}(d,r)  of a graded ideal

function is also equal to  δ 𝕏 ​ ( d , r ) \delta_{\mathbb{X}}(d,r) 
(Theorem  4.5 ). These abstract algebraic formulations
gives us a new tool to study generalized Hamming weights in a systematic manner.
One of our results shows that the  r r -th generalized footprint function
of  I ⁡ ( 𝕏 ) I(\mathbb{X})  is a lower bound for  δ 𝕏 ​ ( d , r ) \delta_{\mathbb{X}}(d,r) 
(Theorem  4.9 ). As is seen in this paper in
certain cases the footprint function gives the exact value of
 δ 𝕏 ​ ( d , r ) \delta_{\mathbb{X}}(d,r) .

 2.  Preliminaries 

 
 In this section we
present some of the results that will be needed throughout the paper
and introduce some more notation. All results of this
section are well-known. To avoid repetitions, we continue to employ
the notations and
definitions used in Section  1 . 
 
 
 Generalized Hamming weights 

 
 Let  K = 𝔽 q K=\mathbb{F}_{q}  be a finite field and let  C C  be a  [ m , k ] [m,k]   linear
code  of  length   m m  and  dimension   k k . 
 
 
 The  r r -th  generalized Hamming weight  of  C C , denoted
 δ r ​ ( C ) \delta_{r}(C) , is the size of the smallest support of an
 r r -dimensional subcode, that is, 
 

 
 
 δ r ( C ) := min { | χ ( D ) | : D  is a linear subcode of  C  with  dim K ( D ) = r } . \delta_{r}(C):=\min\{|\chi(D)|\,\colon\,D\mbox{ is a linear subcode of
}C\mbox{ with }\dim_{K}(D)=r\}. 
 
 
 
 
 The  weight hierarchy  of  C C  is the sequence
 ( δ 1 ​ ( C ) , … , δ k ​ ( C ) ) (\delta_{1}(C),\ldots,\delta_{k}(C))  and
 δ 1 ​ ( C ) \delta_{1}(C)  is called the  minimum distance  of  C C  and is
denoted by  δ ⁡ ( C ) \delta(C) .
According to  [ 23 , Theorem 1,
Corollary 1] 
the weight hierarchy is an
increasing sequence 
 

 
 
 1 ≤ δ 1 ​ ( C ) < δ 2 ​ ( C ) < ⋯ < δ r ​ ( C ) ≤ m , 1\leq\delta_{1}(C)<\delta_{2}(C)<\cdots<\delta_{r}(C)\leq m,
