 D. Silberger
 

 Abstract 
    
 Given a groupoid   ⟨ G , ⋆ ⟩ \langle G,\star\rangle ,  and
  k ≥ 3 k\geq 3 ,  we say that  G G  is  antiassociative 
iff for all   x 1 , x 2 , x 3 ∈ G x_{1},x_{2},x_{3}\in G ,   ( x 1 ⋆ x 2 ) ⋆ x 3 (x_{1}\star x_{2})\star x_{3}   and   x 1 ⋆ ( x 2 ⋆ x 3 ) x_{1}\star(x_{2}\star x_{3})   are never equal. Generalizing this,   ⟨ G , ⋆ ⟩ \langle G,\star\rangle   is  k k -antiassociative iff for all
  x 1 , x 2 , … ​ x k ∈ G x_{1},x_{2},\ldots x_{k}\in G ,  any two distinct expressions
made by putting parentheses in
  x 1 ⋆ x 2 ⋆ x 3 ⋆ ⋯ x k x_{1}\star x_{2}\star x_{3}\star\cdots x_{k}   are never equal. 
    
 We prove that for every  k ≥ 3 k\geq 3 , there exist finite groupoids
that are  k k -antiassociative. We then generalize this, investigating when other pairs of groupoid terms can be made never equal.

 1  Introduction 

 
 Around fifteen years ago, the second two authors
started to investigate finite groupoids which were
antiassociative. Instead of obeying the associative law that   ( x 1 ⋆ x 2 ) ⋆ x 3 (x_{1}\star x_{2})\star x_{3}   and   x 1 ⋆ ( x 2 ⋆ x 3 ) x_{1}\star(x_{2}\star x_{3})   are always equal, a groupoid is  antiassociative  iff   ( x 1 ⋆ x 2 ) ⋆ x 3 (x_{1}\star x_{2})\star x_{3}   and   x 1 ⋆ ( x 2 ⋆ x 3 ) x_{1}\star(x_{2}\star x_{3})   are never equal. This is a natural change to make
to the associative law. 
 
 
 We were aided by a program written by Ming Lei Wu, which went
through all the  4 16 4^{16}  possible  4 4 -element groupoids and
returned a list of 421,560 which were antiassociative. About
97% of these antiassociative groupoids were what we called
“deranged”, and turned out to be constructible in the following way. 
 
 
 Let  G G  be any set with  2 2  or more elements. First pick a
function   f : G → G f:G\rightarrow G   with the
property that   f ⁡ ( x ) ≠ x f(x)\neq x   for all  x x 
(the “derangement”).
Then define the binary operation on  G G  by   x ⋆ y = f ⁡ ( x ) x\star y=f(x) ,  or alternatively, by   x ⋆ y = f ⁡ ( y ) x\star y=f(y) . This makes  ⟨ G , ⋆ ⟩ \langle G,\star\rangle 
a  deranged  groupoid.  When  x ⋆ y = f ⁡ ( x ) x\star y=f(x) , we have   ( x 1 ⋆ x 2 ) ⋆ x 3 = f ⁡ ( x 1 ) ⋆ x 3 = f ⁡ ( f ⁡ ( x 1 ) ) ≠ f ⁡ ( x 1 ) = x 1 ⋆ ( x 2 ⋆ x 3 ) (x_{1}\star x_{2})\star x_{3}=f(x_{1})\star x_{3}=f(f(x_{1}))\neq f(x_{1})=x_{1}\star(x_{2}\star x_{3}) ,
showing  ⟨ G , ⋆ ⟩ \langle G,\star\rangle  is antiassociative.
If  x ⋆ y = f ⁡ ( y ) x\star y=f(y) , the proof is similar. 
 
 
 Of the remaining 3% of the antiassociative groupoids
found by the program, almost all had  ⋆ \star  tables which were
within a few entries of the table of one of the deranged
groupoids. But beyond that, we found few patterns
in their construction. We conjecture that a
similar situation holds for the examples we give
in this paper. They probably will not be unique, since
it will sometimes be possible to modify them slightly
in a haphazard way. 
 
 
 Before moving on to  k k -antiassociative groupoids, we
will invest in some definitions. Using terminology from
universal algebra (see  [ 3 ] ), an
 algebra  is a set with some number of (finitary) operations on it.
A  term  of an algebra is any expression on a finite
number of variables that can be made by composing the
(basic) operations of the algebra. We will use the same
notation both for terms as formal expressions and for the
resulting functions on an algebra, since the distinction
should be clear from context. This paper will
focus on groupoids, which are algebras with a single
binary operation. We believe that many of our techniques
can be used for algebras with multiple operations of any arity,
but will not pursue this avenue here. 
 
 
 An  ordered term  on the variables   x j , x j + 1 , x j + 2 , … ​ x j + k − 1 x_{j},x_{j+1},x_{j+2},\ldots x_{j+k-1}  is a  k k -ary
term where each variable appears once, in order of
their indices. For clarity, we give an inductive
definition. Any single variable  x j x_{j}  is a  1 1 -ary
ordered term. Now suppose that  f f  is an  m m -ary
basic operation and that   t 1 , … ​ t m t_{1},\ldots t_{m}   are
ordered terms on the variables   x j , x j + 1 , … ​ x j + n − 1 x_{j},x_{j+1},\ldots x_{j+n-1}   respectively.
(That is,  t 1 t_{1}  is a  k 1 k_{1} -ary ordered term on   x j , x j + 1 , … ​ x j + k 1 − 1 x_{j},x_{j+1},\ldots x_{j+k_{1}-1} ,   t 2 t_{2}  is a
 k 2 k_{2} -ary ordered term on the next  k 2 k_{2}  variables,
and so on, where   n = k 1 + k 2 + ⋯ k m n=k_{1}+k_{2}+\cdots k_{m} .)  Then   f ⁡ ( t 1 , t 2 , … ​ t m ) f(t_{1},t_{2},\ldots t_{m})   is an  n n -ary
ordered term on the variables   x j , x j + 1 , … ​ x j + n − 1 x_{j},x_{j+1},\ldots x_{j+n-1} .  We used
ordered terms in groupoids in our earlier papers
 [ 1 ]  and  [ 2 ] 
and called them  formal products . 
 
 
 Focusing on groupoids with operation  ⋆ \star , we see
that there are exactly  5 5  different ordered terms on the
 4 4  variables   x 1 , x 2 , x 3 , x 4 x_{1},x_{2},x_{3},x_{4} . They are:
  ( ( x 1 ⋆ x 2 ) ⋆ x 3 ) ⋆ x 4 ((x_{1}\star x_{2})\star x_{3})\star x_{4} ,    ( x 1 ⋆ ( x 2 ⋆ x 3 ) ) ⋆ x 4 (x_{1}\star(x_{2}\star x_{3}))\star x_{4} ,    ( x 1 ⋆ x 2 ) ⋆ ( x 3 ⋆ x 4 ) (x_{1}\star x_{2})\star(x_{3}\star x_{4}) ,    x 1 ⋆ ( ( x 2 ⋆ x 3 ) ⋆ x 4 ) x_{1}\star((x_{2}\star x_{3})\star x_{4})   and
  x 1 ⋆ ( x 2 ⋆ ( x 3 ⋆ x 4 ) ) x_{1}\star(x_{2}\star(x_{3}\star x_{4})) .  As is well known (see  [ 10 ] ), a groupoid has   C ⁡ ( k − 1 ) = ( 2 ​ k − 2 ) ! / k ! ​ ( k − 1 ) ! C(k-1)=(2k-2)!/{k!(k-1)!}   many distinct
ordered terms on  k k  variables, where   C ⁡ ( m ) C(m)   is the  m m -th Catalan number. 
 
 
 Assume   k ≥ 3 k\geq 3 .  Let   s ⁡ ( x 1 , … ​ x k ) s(x_{1},\ldots x_{k})   and   t ⁡ ( x 1 , … ​ x k ) t(x_{1},\ldots x_{k})   be distinct terms
of some groupoid   ⟨ G , ⋆ ⟩ \langle G,\star\rangle .  If   s ⁡ ( x 1 , … ​ x k ) ≠ t ⁡ ( x 1 , … ​ x k ) s(x_{1},\ldots x_{k})\neq t(x_{1},\ldots x_{k})   for all   x 1 , x 2 , … ​ x k ∈ G x_{1},x_{2},\ldots x_{k}\in G , then we say
that  G G   separates  s s  and  t t . The groupoid   ⟨ G , ⋆ ⟩ \langle G,\star\rangle   is
 k k -antiassociative  iff it separates all the
distinct pairs of ordered terms on   x 1 , x 2 , … ​ x k x_{1},x_{2},\ldots x_{k} . 
 
 
 Two observations are in order. If  G G  is a groupoid
that separates two terms  s s  and  t t , then every
subgroupoid of  G G  also separates  s s  and  t t . Second,
suppose  G G  is a groupoid that separates  s s  and  t t ,
and let  H H  be an arbitrary groupoid (with the same
operation symbol). Then the Cartesian product   G × H G\times H   separates  s s  and  t t . 
 
 
 There are infinite groupoids that are
 k k -antiassociative for all  k k .
One example is   ⟨ F σ ; ⊙ ⟩ \langle F^{\sigma};\odot\rangle ,  the set of all
formal products under a natural operation which is
similar to concatenation. (See  [ 1 ]  for a
definition and proof.) The free groupoid
(see  [ 3 ] ) on one or more
generators is another example, as can be shown by a modification
of the proof of Theorem  3.5 .
(At the end of the proof, where Theorem  3.4 
is invoked, one argues directly instead.) 
 
 
 There are no finite groupoids
which are  k k -antiassociative for all  k k , since
the number of  k k -ary ordered terms increases without
bound. Once there are more terms than elements in
the groupoid, the Pigeonhole Principle implies that
there are terms which will not be separated in the groupoid.
This brings us to the following question, which we
posed in  [ 2 ] . 
 
 
 Question 1.1 . 
 
 For all   k ≥ 3 k\geq 3 ,  is there a finite
groupoid that is  k k –antiassociative? 
 
 
 
 By our observation above, this question may
be reduced to the following one. 
 
 
 Question 1.2 . 
 
 For each   k ≥ 3 k\geq 3   and for all distinct ordered
terms  s s  and  t t  on   x 1 , x 2 , … ​ x k x_{1},x_{2},\ldots x_{k} ,  is
there a finite groupoid that separates  s s  and  t t ? 
 
 
 
 An affirmative answer to the second question gives
an affirmative answer to the first. To see this,
assume that for all distinct ordered terms  s s  and  t t 
on   x 1 , x 2 , … ​ x k x_{1},x_{2},\ldots x_{k} ,  there is a finite groupoid
  G s , t G_{s,t}   that separates  s s  and  t t . Then the product
of these groupoids separates all the  k k -ary ordered
terms, and is  k k -antiassociative.
The other direction is immediate, so the two questions
are equivalent. 
 
 
 Note also that whenever  3 ≤ j < k 3\leq j<k , a groupoid  ⟨ G , ⋆ ⟩ \langle G,\star\rangle 
that is  k k -antiassociative is also  j j -antiassociative. For suppose  s ⁡ ( x 1 , x 2 , … ​ x j ) s(x_{1},x_{2},\dots x_{j}) 
and  t ⁡ ( x 1 , x 2 , … ​ x j ) t(x_{1},x_{2},\dots x_{j})  are  j j -ary ordered terms that are not
separated in  ⟨ G , ⋆ ⟩ \langle G,\star\rangle .
We let  r ⁡ ( x j + 1 , … ​ x k ) r(x_{j+1},\dots x_{k})  be some fixed  ( k − j ) (k-j) -ary ordered term, and form
 s ′ ​ ( x 1 , x 2 , … ​ x k ) = s ⁡ ( x 1 , x 2 , … ​ x j ) ⋆ r ⁡ ( x j + 1 , … ​ x k ) s^{\prime}(x_{1},x_{2},\dots x_{k})=s(x_{1},x_{2},\dots x_{j})\star r(x_{j+1},\dots x_{k})  and
 t ′ ​ ( x 1 , x 2 , … ​ x k ) = t ⁡ ( x 1 , x 2 , … ​ x j ) ⋆ r ⁡ ( x j + 1 , … ​ x k ) t^{\prime}(x_{1},x_{2},\dots x_{k})=t(x_{1},x_{2},\dots x_{j})\star r(x_{j+1},\dots x_{k}) . These are two
 k k -ary ordered terms that are not separated in  ⟨ G , ⋆ ⟩ \langle G,\star\rangle , a contradiction. 
 
 
 §2 will present two preliminary examples.
We will answer Question  1.2  in the affirmative in
§3, and generalize it to arbitrary groupoid terms
in §4. 
 
 
 
 2  Preliminary examples 

 
 We start with two simple constructions that often
yield groupoids separating two distinct  k k -ary
ordered terms. The first is to simply take products
of deranged operations. For example, define the
operation  L 2 \mathop{\rm L_{2}}  on the universe of  Z 2 Z_{2}  by setting
 x ​ L 2 ⁡ y = ( x + 1 ) mod 2 x\mathop{\rm L_{2}}y=(x+1)\mod 2 . Then we have

 ( ( x ​ L 2 ⁡ y ) ​ L 2 ⁡ z ) ​ L 2 ⁡ w = ( x + 3 ) mod 2 ((x\mathop{\rm L_{2}}y)\mathop{\rm L_{2}}z)\mathop{\rm L_{2}}w=(x+3)\mod 2 , and so on.
The value of a term with leftmost variable  x x  is
 ( x + n ) mod 2 (x+n)\mod 2 , where  n n  is the depth of  x x  in the term.

the value of a term with rightmost variable  z z  is
 ( z + n ) mod 3 (z+n)\mod 3 , where  n n  is the depth of  z z  in the term.

of a term only depends on the depths of its leftmost and rightmost
variables, so terms that have those two variables at the same depth can not be separated this way.

 3  Finite  k k -antiassociative groupoids 

 
 We will use a somewhat involved construction, and will require some
preliminary definitions. Recall that a  full binary tree 
is a rooted tree where every internal node has exactly two
children. (For further definitions and theorems, see  [ 8 ] 
or a recent text in discrete mathematics or data structures.) 
 
 
 When full binary trees are used as data structures, the
two nodes directly below each internal node are called
its  left  and  right  children, and the subtrees
with these children as roots are the  left  and  right subtrees 
of that node. As is well known, groupoid terms correspond
to full binary trees with leaves labeled by variables.
If  s s  is a groupoid
term, we will denote the corresponding tree by   T ⁡ ( s ) T(s) .  This correspondence may be defined recursively as follows.
If  s s  is a single variable  x i x_{i} , then   T ⁡ ( s ) T(s)   is a
tree with one node, labelled  x i x_{i} . If  s s  and  t t  are
groupoid terms, then   T ⁡ ( s ⋆ t ) T(s\star t)   is the tree with
a root that has   T ⁡ ( s ) T(s)   as its left subtree and
  T ⁡ ( t ) T(t)   as its right subtree. 
 
 
 We will also label the nodes of binary trees with strings
made from the characters ‘ l l ’ and ‘ r r ’. As is usual,
we will write the set of all such strings as   { l , r } ∗ \{l,r\}^{*} .  In dealing with
strings, we will show concatenation by simply writing
the two strings next to each other. We use  Λ \Lambda  to
denote the empty string, which is the identity for concatenation.
Our labeling may
be defined recursively as follows. 
 
 
 The root is labeled  Λ \Lambda .
If a node is labeled  a a , then its left and right
children are labeled   a ​ l al   and   a ​ r ar ,  respectively.
These labels may be thought of as directions for how to
get to a node by starting at the root and turning the
correct way at each branching. 
 
 
 Given a string  p p , an  initial substring  of  p p  is
a string  q q  so that   p = q ​ u p=qu   for some string  u u .
(Note that the empty string  Λ \Lambda  is an initial substring
of every string.)
A substring is  proper  if it is not equal to the
entire original string, and  nontrivial  if it is
not equal to  Λ \Lambda . 
 
 
 Putting these two ideas together, occurrences of variables in
a groupoid term  s s  correspond to leaves of   T ⁡ ( s ) T(s) .  The string that is the label of the leaf corresponding to an
occurrence of the variable  x i x_{i}  will be called the  path 
of that occurrence. If  x i x_{i}  only occurs once, we may also call
this the path of  x i x_{i} .
Generalizing this, for any subterm  b b  of  s s , we have that the
 path  of  b b  is also the label of the interior node of   T ⁡ ( s ) T(s)   corresponding to the root of subtree  T ⁡ ( b ) T(b) .

 If  s s  is a groupoid term, we use   Paths ( s ) \mathop{\rm Paths}(s)   for the

paths to the internal nodes of the tree   T ⁡ ( s ) T(s) ;  these

 Our long-term goal is to form a groupoid that separates
any two distinct  k k -ary ordered terms  s s  and  t t .
We will need some preliminary ideas in order to do this.
Our groupoids will have elements which are vectors
of finite length over the  2 2 -element field  𝐙 2 {\mathbf{Z}}_{2} .
We take the index set of the components of these vectors
to be the set of natural numbers
  𝐍 = { 0 , 1 , 2 , … } {\mathbf{N}}=\{0,1,2,\dots\} .   All of our vectors
will only have a finite number of components, or equivalently,
will be vectors indexed by  𝐍 {\mathbf{N}}  that are zero in all
but finitely many components. Given any finite set of
such vectors, we let  M M  be the set of all indices where any
of them have nonzero components. Then all these vectors lie in the finite
subspace consisting of vectors with all their
components outside
of  M M  equal to  0 0 . We will usually leave this final
reduction to a finite groupoid to the reader. 
 
 
 We will actually be using only the additive structure of
the field
 𝐙 2 {\mathbf{Z}}_{2} 
, and viewing it as an abelian
group. Our groupoids will all be affine endomorphism
groupoids, although the endomorphisms will be built up from
their actions on the components of vectors. One nice
consequence of this is that we will be able to add groupoid
operations pointwise. If  ⋆ 1 \star_{1}  and  ⋆ 2 \star_{2}  are two
groupoid operations on vectors over  𝐙 2 {\mathbf{Z}}_{2} , their
sum   ⋆ 1 + ⋆ 2 \star_{1}+\star_{2}   will be defined by   x → ( ⋆ 1 + ⋆ 2 ) y → = ( x → ⋆ 1 y → ) + ( x → ⋆ 2 y → ) \vec{x}\,(\star_{1}+\star_{2})\,\vec{y}=(\vec{x}\star_{1}\vec{y})+(\vec{x}\star_{2}\vec{y}) .  Since we are working over
 𝐙 2 {\mathbf{Z}}_{2} , all additions of values such as the above are
done modulo  2 2 . We will periodically note this fact, but not always. 
 
 
 We will define groupoid operations by their actions on components.

 We can generalize

 We would like to have a nice characterization of which pairs
of groupoid terms can be separated in a finite groupoid. So
we will also investigate when it is impossible to separate a
pair of terms in any groupoid. 
 
 
 We need a bit of preliminary material on free algebras. A more
detailed exposition may be found in  [ 3 ] .
We use  𝐆 \mathbf{G}  for the class of all groupoids, and let
 F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1})  denote the free groupoid
with generators  y 0 , y 1 , … ​ y n − 1 y_{0},y_{1},\ldots y_{n-1} . The key feature of
 F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1})  is that it has the
Universal Mapping Property for the class of groupoids. If  G G 
is any groupoid with elements
 g 0 , g 1 , … ​ g n − 1 g_{0},g_{1},\ldots g_{n-1} , then there is a unique homomorphism
 ϕ \phi  from  F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1})  into
 G G  where  ϕ ⁡ ( y i ) = g i \phi(y_{i})=g_{i}  for all  i i . 
 
 
 Theorem 4.3 . 
 
 Let  s s  and  t t  be groupoid terms, each on a set of variables
that is a subset of  { y 0 , y 1 , … ​ y n − 1 } \{y_{0},y_{1},\ldots y_{n-1}\} .
Then the following are equivalent. 
 
 1.  
 
 s s  and  t t  are separated in some groupoid. 
 
 2.  
 
 s s  and  t t  are separated in
 F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1}) . 
 
 3.  
 
 s s  and  t t  are separated in  F 𝐆 ​ ( x ) F_{\mathbf{G}}(x) , the free
groupoid on one variable. 
 
 
 
 
 
 Proof. 
 
 Let  s s  and  t t  be groupoid terms with all their variables
in  { y 0 , y 1 , … ​ y n − 1 } \{y_{0},y_{1},\ldots y_{n-1}\} . It is clear that
(2) implies (1). To see that (3) implies (2), suppose that
(2) fails. Then there are terms  h 0 , h 1 , … ​ h n − 1 h_{0},h_{1},\ldots h_{n-1}  in
 F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1})  with
 s ⁡ ( h 0 , h 1 , … ​ h n − 1 ) = t ⁡ ( h 0 , h 1 , … ​ h n − 1 ) s(h_{0},h_{1},\ldots h_{n-1})=t(h_{0},h_{1},\ldots h_{n-1}) .
The  h i h_{i}  are all generated from  { y 0 , … ​ y n − 1 } \{y_{0},\ldots y_{n-1}\} 
by repeatedly using the groupoid operation. Now consider
the homomorphism  ϕ \phi  from
 F 𝐆 ​ ( y 0 , y 1 , … ​ y n − 1 ) F_{\mathbf{G}}(y_{0},y_{1},\ldots y_{n-1})  into
 F 𝐆 ​ ( x ) F_{\mathbf{G}}(x)  that takes all of the  y i y_{i}  to  x x .
Denoting the image of each  h i h_{i}  by  h i ′ h^{\prime}_{i} , we have that
 s ⁡ ( h 0 ′ , h 1 ′ , … ​ h n − 1 ′ ) = t ⁡ ( h 0 ′ , h 1 ′ , … ​ h n − 1 ′ ) s(h^{\prime}_{0},h^{\prime}_{1},\ldots h^{\prime}_{n-1})=t(h^{\prime}_{0},h^{\prime}_{1},\ldots h^{\prime}_{n-1}) 
in  F 𝐆 ​ ( x ) F_{\mathbf{G}}(x) , so (3) fails. 
 
 
 To see (1) implies (3), assume that (3) fails. So we have
 f 0 , f 1 , … ​ f n − 1 ∈ F 𝐆 ​ ( x ) f_{0},f_{1},\ldots f_{n-1}\in F_{\mathbf{G}}(x)  with
 s ⁡ ( f 0 , f 1 , … ​ f n − 1 ) = t ⁡ ( f 0 , f 1 , … ​ f n − 1 ) s(f_{0},f_{1},\ldots f_{n-1})=t(f_{0},f_{1},\ldots f_{n-1}) .
Letting  G G  be any groupoid, we pick any  c ∈ G c\in G , and
consider the homomorphism  ϕ \phi  from  F 𝐆 ​ ( x ) F_{\mathbf{G}}(x)  to
 G G  that takes  x x  to  c c . Letting the image of each
 f i f_{i}  be  f i ′ f^{\prime}_{i} , we have that
 s ⁡ ( f 0 ′ , f 1 ′ , … ​ f n − 1 ′ ) = t ⁡ ( f 0 ′ , f 1 ′ , … ​ f n − 1 ′ ) s(f^{\prime}_{0},f^{\prime}_{1},\ldots f^{\prime}_{n-1})=t(f^{\prime}_{0},f^{\prime}_{1},\ldots f^{\prime}_{n-1}) 
in  G G , so (1) fails.
∎ 
 
 
 
 The free groupoid  F 𝐆 ​ ( x ) F_{\mathbf{G}}(x)  is easy to work with,
since all of its elements may be viewed as groupoid terms
in the single variable  x x . Terms  s s  and  t t  are separated
in  F 𝐆 ​ ( x ) F_{\mathbf{G}}(x)  iff there are no terms
 f 0 ​ ( x ) , f 1 ​ ( x ) , … ​ f n − 1 ​ ( x ) ∈ F 𝐆 ​ ( x ) f_{0}(x),f_{1}(x),\ldots f_{n-1}(x)\in F_{\mathbf{G}}(x) 
that can be substituted for the variables
of  s s  and  t t  to yield
 s ⁡ ( f 0 ​ ( x ) , f 1 ​ ( x ) , … ​ f n − 1 ​ ( x ) ) = t ⁡ ( f 0 ​ ( x ) , f 1 ​ ( x ) , … ​ f n − 1 ​ ( x ) ) s(f_{0}(x),f_{1}(x),\ldots f_{n-1}(x))=t(f_{0}(x),f_{1}(x),\ldots f_{n-1}(x)) . 
 
 
 This relates to the notion of  unification  of terms, which
has been extensively studied in computer science. The introduction
of the topic was by Herbrand, in  [ 5 ] .
Modern work was pioneered by Robinson, in  [ 9 ] .
Good
survey articles are by Knight (in  [ 7 ] ) and Jouannaud
and Kirchner (in  [ 6 ] ). Consider two terms  s ⁡ ( x 0 , … ​ x m − 1 ) s(x_{0},\dots x_{m-1}) 
and  t ⁡ ( y 0 , … ​ y n − 1 ) t(y_{0},\dots y_{n-1}) .
The terms are  unifiable  if there are terms
 r 0 , … ​ r m − 1 r_{0},\dots r_{m-1}  and  u 0 , … ​ u n − 1 u_{0},\dots u_{n-1}  so that substituting
the  r i r_{i}  for the  x i x_{i}  in  s s  and the  u j u_{j}  for the  y j y_{j}  in  t t 
makes the two resulting terms identical, and the corresponding
substitution is a  unification . In other words, the terms
 s s  and  t t  can be unified iff they can not be separated in a free
algebra. In view of the previous theorem, two terms can not be unified
iff there is a groupoid where they are separated. 
 
 
 Algorithms to see whether or not two terms  s s  and  t t  can be
unified are discussed in detail in  [ 7 ]  and  [ 6 ] .
An inefficient but effective method for groupoid terms
is to use the following rules for generating sets of statements,
starting with the statement  s = t s=t . In each rule,
a,b,c and d are terms, while x and y are variables. 
 
 1.  
 
 (Decompose) 
From  a ⋆ b = c ⋆ d a\star b=c\star d  deduce  a = c a=c  and  b = d b=d . 
 
 2.  
 
 (Coalesce) 
If we have  x = y x=y , deduce the results of replacing every  x x  in our set of statements with a  y y . 
 
 3.  
 
 (Check) 
From  x = a x=a , deduce  𝐅𝐚𝐥𝐬𝐞 \mathbf{False}  if  x x  occurs in the term  a a . 
 
 4.  
 
 (Eliminate) 
From  x = a x=a , deduce the results of replacing every  x x  in our set of
statements with the term  a a , provided  x x  does not occur in  a a . 
 
 
 One may simply apply all the rules repeatedly, until no more statements
are deduced. If  𝐅𝐚𝐥𝐬𝐞 \mathbf{False}  is ever deduced, the original terms
 s s  and  t t  can not be unified. Otherwise, a unifying set of substitutions
will be deduced. In practice, one may be more targeted in applying the rules
and reach  𝐅𝐚𝐥𝐬𝐞 \mathbf{False}  or unifying substitutions more rapidly. 
 
 
 For example, consider  s = ( x ⋆ y ) ⋆ ( z ⋆ y ) s=(x\star y)\star(z\star y)  and
 t = z ⋆ ( ( x ⋆ y ) ⋆ ( x ⋆ x ) ) t=z\star((x\star y)\star(x\star x)) . We will use the
algorithm to see if they can be unified. We start with  s = t s=t .
Using  Decompose , we obtain  z = x ⋆ y z=x\star y  and
 z ⋆ y = ( x ⋆ y ) ⋆ ( x ⋆ x ) z\star y=(x\star y)\star(x\star x) . Applying  Decompose 
again to the last statement, we get  z = x ⋆ y z=x\star y  (a duplicate) and
 y = x ⋆ x y=x\star x . Applying  Eliminate  using  y = x ⋆ x y=x\star x  to
 z = x ⋆ y z=x\star y , we get  z = x ⋆ ( x ⋆ x ) z=x\star(x\star x) . We have found a
set of unifying substitutions. Letting  y = x ⋆ x y=x\star x  and
 z = x ⋆ ( x ⋆ x ) z=x\star(x\star x)  in  s s  and  t t , both become
 ( x ⋆ ( x ⋆ x ) ) ⋆ ( ( x ⋆ ( x ⋆ x ) ) ⋆ ( x ⋆ x ) ) (x\star(x\star x))\star((x\star(x\star x))\star(x\star x)) . 
 
 
 Here is an example with a cycle. In view of Theorem  4.2 ,
it will be no surprise that this is an obstacle to unification.
Let  s = ( x ⋆ y ) ⋆ ( z ⋆ w ) s=(x\star y)\star(z\star w)  and let
 t = ( ( w ⋆ u ) ⋆ x ) ⋆ ( ( y ⋆ v ) ⋆ z ) t=((w\star u)\star x)\star((y\star v)\star z) .
Repeatedly applying  Decompose , we get  x = w ⋆ u x=w\star u ,
 y = x y=x ,  z = y ⋆ v z=y\star v  and  w = z w=z . Applying  Coalesce ,
we get  x = z ⋆ u x=z\star u  and  z = x ⋆ v z=x\star v . Applying  Eliminate 
gives  x = ( x ⋆ v ) ⋆ u x=(x\star v)\star u , and applying  Check  gives
 𝐅𝐚𝐥𝐬𝐞 \mathbf{False} . Our applications of  Coalesce 
and  Eliminate  acted to reduce the length of the
original cycle. Using the
notation of Theorem  4.2 , this cycle had
 y 0 u y_{0}^{u}  the  x x  in  s s ,  y 0 d y_{0}^{d}  the  w w  in  t t ,  y 1 u y_{1}^{u}  the  w w  in  s s ,
 y 1 d y_{1}^{d}  the  z z  in  t t ,  y 2 u y_{2}^{u}  the  z z  in  s s ,  y 2 d y_{2}^{d}  the  y y  in  t t ,
 y 3 u y_{3}^{u}  the  y y  in  s s , and  y 3 d y_{3}^{d}  the  x x  in  t t . 
 
 
 There are pairs of terms without a cycle which still can not be unified.
For example, let  s = ( x ⋆ y ) ⋆ ( z ⋆ y ) s=(x\star y)\star(z\star y)  and let
 t = z ⋆ ( ( y ⋆ y ) ⋆ ( x ⋆ x ) ) t=z\star((y\star y)\star(x\star x)) . Working left to right, we
see that  x x  and  y y  occur below  z z ,  y y  occurs below  z z  and  x x  occurs
below  y y . This is consistent with the ordering  x < y < z x<y<z .
Since there is a consistent ordering of the variables like this,
there are no cycles. However,  s s  and  t t  can not be unified. Applying
 Decompose  repeatedly gives  z = x ⋆ y z=x\star y ,  z = y ⋆ y z=y\star y  and
 y = x ⋆ x y=x\star x . Then applying  Eliminate  to the first two
gives  x ⋆ y = y ⋆ y x\star y=y\star y , after which  Decompose  gives
 x = y x=y . Finally,  Eliminate  gives  x = x ⋆ x x=x\star x , and
 Check  gives  𝐅𝐚𝐥𝐬𝐞 \mathbf{False} . 
 
 
 Although Theorem  4.2  does not apply to this last
example, we had no problem separating the terms using a similar
construction. Letting  ⋆ ′ = ‖ 3 , l , 0 ‖ + ‖ 3 , r l , 1 ‖ + ‖ 4 , r r , 2 ‖ + ‖ 4 , l , 3 ‖ + ‖ 4 , l , 4 ‖ ′ \star^{\prime}=\left\|3,l,0\right\|+\left\|3,rl,1\right\|+\left\|4,rr,2\right\|+\left\|4,l,3\right\|+\left\|4,l,4\right\|^{\prime} , we calculate  s ⁡ [ 0 ] + s ⁡ [ 1 ] + s ⁡ [ 2 ] = ( x ⋆ y ) ​ [ 3 ] + z ⁡ [ 3 ] + y ⁡ [ 4 ] = x ⁡ [ 4 ] + z ⁡ [ 3 ] + y ⁡ [ 4 ] s[0]+s[1]+s[2]=(x\star y)[3]+z[3]+y[4]=x[4]+z[3]+y[4] , while
 t ⁡ [ 0 ] + t ⁡ [ 1 ] + t ⁡ [ 2 ] = z ⁡ [ 3 ] + ( y ⋆ y ) ​ [ 3 ] + ( x ⋆ x ) ​ [ 4 ] = z ⁡ [ 3 ] + y ⁡ [ 4 ] + x ⁡ [ 4 ] + 1 t[0]+t[1]+t[2]=z[3]+(y\star y)[3]+(x\star x)[4]=z[3]+y[4]+x[4]+1 , which has the opposite parity. 
 
 
 Based on many examples similar to the above, we make the following
conjecture. 
 
 
 Conjecture 4.4 . 
 
 Whenever two groupoid terms can be separated in an
infinite groupoid, they can also be separated in a finite groupoid.
