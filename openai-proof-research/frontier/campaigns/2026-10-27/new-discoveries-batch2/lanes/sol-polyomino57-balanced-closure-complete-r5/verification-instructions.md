The source archive has no compiled artifacts. Extract it into a new empty directory. `python3 fresh_replay.py prepare` verifies the manifest, compiler hash/version and package revisions, and creates a work directory solely from the extracted Lean sources. For each module in modules.json, in order, run `python3 fresh_replay.py build MODULE`. Finally run `python3 fresh_replay.py finish` to validate all actual-origin inventories and produce verification/receipt.json.

Each build launches its independent Lean supervisor before taking its own512MiB hard AS cap. The Lean monitor has CPU210sec, wall220sec and45ms sampled groupRSS2800MiB kill threshold. The outer bounded build waits at most225sec. Do not place a hard512MiB AS restriction around a parent that has yet to spawn Lean. Use tool-level serial orchestration rather than an unbounded long-running Python coordinator.

No source expected-count premise is used. OriginAudit modules enumerate the actual origin declaration lists supplied by Lean, inspect their actual types, transitive axioms and unsafe/axiom flags, and reject any forbidden dependency. Inherited generated partial helpers named _unsafe_rec have actual unsafe=false and axiom=false, as the inventory records.
