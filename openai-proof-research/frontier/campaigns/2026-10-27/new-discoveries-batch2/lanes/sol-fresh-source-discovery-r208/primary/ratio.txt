                                                                                   Abstract
                                                   In this work we will introduce the concept of ratio-covariety, as a
                                                nonempty family R of numerical semigroups verifying certain properties.
                                                This concept will allow us to:
                                                   1. Describe an algorithmic process to compute R.
                                                   2. Prove the existence of the smallest element of R that contains a set
                                                      of positive integers.
                                                   3. Talk about the smallest ratio-covariety that contains a finite set of
                                                      numerical semigroups.
                                                In addition, in this paper we will apply the previous results to the study of
                                                the ratio-covariety R(F, m) = {S | S is a numerical semigroup with Fro-
                                                benius number F and multiplicity m}.
                                                   Keywords: Numerical semigroup, ratio-covariety, Frobenius number,
                                                genus, ratio, algorithm.
                                                    MSC-class: 20M14 (Primary), 11D07, 13H10 (Secondary).

we write S = hn1 , . . . , np i. We say that a system of generators of a numerical
semigroup is a minimal system of generators if none of its proper subsets gener-
ates the numerical semigroup. Every numerical semigroup has a unique minimal
system of generators, which in addition is finite (see [17, Corollary 2.8]). The
minimal system of generators of a numerical semigroup S is denoted by msg(S).
Its cardinality is called the embedding dimension and will be denoted by e(S).
Another invariant which we will use in this work is the multiplicity of S, denoted
by m(S). It is defined as the minimum of S\{0}.
    The called Frobenius problem (see [14]) for numerical semigroups is a clas-
sical mathematical problem. It lies in finding formulas to obtain the Frobenius
number and the genus of a numerical semigroup from its minimal system of
generators. This problem was solved in [19] for numerical semigroups with em-
bedding dimension two. Since then, many researchers have tried to solve this
problem for numerical semigroups with embedding dimension greater than or
equal to three. However, the problem is still open. Furthemore, in this case the
problem becomes NP-hard (see [13]).
    Looking to find a solution to the Frobenius problem, we have found common
properties that verify certain families of numerical semigroups (see for instance
[11] and [12]).
    The motivation for this work has been to try to extend the study of covari-
eties, which was initiated in [11], to families of numerical semigroup with a fixed
Frobenius number and multiplicity. That is, if m and F are positive integers
such that m < F and m does not divide F, then we denote by

   R(F, m) = {S | S is a numerical semigroup, F(S) = F and m(S) = m}.

The main aim of this paper is to study the set R(F, m). We can see the set
R(F, m) as a family of numerical semigroups which verifies some important
properties. The generalization of these properties, leads us to the notion of
ratio-covariety.
    For integers a and b, we say that a divides b if there exists an integer c such
that b = ca, and we denote this by a | b. Otherwise, a does not divide b, and
we denote this by a ∤ b. Let S be a numerical semigroup such that S 6= N, the
ratio of S is defined r(S) := min(msg(S)\{m(S)}). Note that r(S) = min{s ∈
S | m(S) ∤ s}.
    A ratio-covariety is a nonempty family R of numerical semigroups fulfilling
the following conditions:

  1) There is the minimum of R, denoted by min(R).
  2) If {S, T } ⊆ R, then S ∩ T ∈ R.
  3) If S ∈ R and S 6= min(R), then S\{r(S)} ∈ R.

that every ratio-covariety es finite and its elements can be ordered in a rooted

   Following the notation introduced in [15], an integer z is a pseudo-Frobenius
number of a numerical semigroup S if z ∈/ S and z + s ∈ S for all s ∈ S\{0}. We
denote by PF(S) the set formed by the pseudo-Frobenius numbers of S. The
cardinality of PF(S) is an important invariant of S (see [8] and [3]) called the
type of S.

Proposition 4.33].
Lemma 2.5. Let S be a numerical semigroup and x ∈ N\S. Then x ∈ SG(S)
if and only if S ∪ {x} is a numerical semigroup.

5     R-system of generators
Throughout this section R will denote a ratio-covariety. We will say that a set
X is an R-set, if it verifies the following conditions:
    1) X ∩ min(R) = ∅.
    2) There is S ∈ R such that X ⊆ S.
    If X is an R-set, then we will denote by R[X] the intersection of all elements
of R containing X. By Proposition 2.2, we know that R is a finite set and so, the
intersection of elements of R is an element of R. Therefore, we can ennounce
the following proposition.
Proposition 5.1. Let X be an R-set. Then R[X] is the smallest element of
R containing X.
    If X is an R-set and S = R[X], we will say that X is an R-system of
generators of S. Moreover, if S 6= R[Y ] for all Y ( X, then X will be called a
minimal R-system of generators of S.
    In general, the minimal R-system of generators is not unique as we can see
in the following example.
Example 5.2. Let R = {S | S is a numerical semigroup, m(S) = 8, r(S) ≥
10 and F(S) ≤ 15} ∪ {S1 = {0, 8, 9, 10, 11, 15, →}, S2 = {0, 8, 9, 13, 15, →}, S3 =
{0, 8, 9, 15, →}}.
    It is easy to see that R is a ratio-covariety, R([{9, 10}]) = R([{9, 11}]) = S1 ,
R([{9}]) = S3 , R([{10}]) = {0, 8, 10, 15, →} and R([{11}]) = {0, 8, 11, 15, →}.
Therefore, {9, 10} and {9, 11} are minimal R-system of generators of S1 .
   Our next aim in this section will be to prove that every element of R(F, m)
admits a unique minimal R(F, m)-system of generators.

R[X] = S.

We are going to see the reverse inclusion. Let T ∈ R such that X ⊆ T.
Then X ∪ min(R) ⊆ T and so msg(S) ⊆ T. Hence, S ⊆ T and consequently,

Our first goal in this section will be to show that the maximum of the set

   The following result is well known and it appears in [17, Proposition 2.10].

    A numerical semigroup S is said to have maximal embedding dimension (from
now on MED-semigroup) if e(S) = m(S).
    In the literature one can find a long list of works dealing with the study of one
dimensional analytically irreducible local domains via their value semigroups.
One of the properties studied for this kind of rings using this approach is that of
being of maximal embedding dimension (see [1],[3], [6] and [18]). The character-

gave rise to the notion of MED-semigroup.
    From [17, Corollary 3.2] we can deduce the following result.
Lemma 6.2. If S is a MED-semigroup and S 6= N, then F(S) = max(msg(S))−
m(S).
Proposition 6.3. If S ∈ R(F, m), then R(F, m)rank (S) ≤ m − 2.
Proof. By Proposition 5.4, we know that R(F, m)rank (S) is the cardinality of
the set X = {x ∈ msg(S) | x ∈ / ∆(F, m)}. As m ∈ msg(S) and m ∈ ∆(F, m),
then R(F, m)rank (S) ≤ e(S) − 1. Now, by applying Lemma 6.1, we have that
R(F, m)rank (S) ≤ m(S) − 1. To finish the proof, we will see that the case
R(F, m)rank (S) = m(S)−1 is impossible. Indeed, if R(F, m)rank (S) = m(S)−

a MED-semigroup, then by applying Lemma 6.2, we have that max(msg(S)) ∈
∆(F, m). Now, by Proposition 5.4, we have that R(F, m)rank (S) ≤ e(S) − 2 ≤
m − 2.
