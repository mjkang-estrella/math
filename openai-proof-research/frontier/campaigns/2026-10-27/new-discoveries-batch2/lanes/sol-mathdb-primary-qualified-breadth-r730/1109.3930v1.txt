Abstract: The Roman dominating function on a graph
G=(V,E)G=(V,E) is a function f:V→{0,1,2}f:V\rightarrow\{0,1,2\} such that each
vertex xx with f⁡(x)=0f(x)=0 is adjacent to at least one vertex yy with
f⁡(y)=2f(y)=2. The value f⁡(G)=∑u∈V⁡(G)f⁡(u)f(G)=\sum\limits_{u\in V(G)}f(u) is called
the weight of ff. The Roman domination number γR​(G)\gamma_{\rm R}(G)
is defined as the minimum weight of all Roman dominating functions.
This paper defines the Roman bondage number bR​(G)b_{\rm R}(G) of a
nonempty graph G=(V,E)G=(V,E) to be the cardinality among all sets of

values are determined for several classes of graphs. Moreover, the
decision problem for bR​(G)b_{\rm R}(G) is proved to be NP-hard even for
bipartite graphs.

1 Introduction
In this paper, a graph G=(V,E)G=(V,E) is considered as an undirected
graph without loops and multi-edges, where V=V⁡(G)V=V(G) is the vertex
set and E=E⁡(G)E=E(G) is the edge set. For each vertex x∈V⁡(G)x\in V(G), let
NG​(x)={y∈V⁡(G):(x,y)∈E⁡(G)}N_{G}(x)=\{y\in V(G):(x,y)\in E(G)\}, NG​[x]=NG​(x)∪{x}N_{G}[x]=N_{G}(x)\cup\{x\}.
A subset S⊆VS\subseteq V is a dominating set of GG if
NG​[x]∩S≠∅N_{G}[x]\cap S\neq\emptyset for every vertex xx in GG. The domination number of GG, denoted by γ⁡(G)\gamma(G), is the minimum
cardinality of all dominating sets of GG. The Roman dominating
function on a graph G=(V,E)G=(V,E), proposed by Cockayne et
al. [2], is a function f:V→{0,1,2}f:V\rightarrow\{0,1,2\} such that
each vertex xx with f⁡(x)=0f(x)=0 is adjacent to at least one vertex yy
with f⁡(y)=2f(y)=2. Let (V0,V1,V2)(V_{0},V_{1},V_{2}) be the ordered partition of VV
induced by ff, where Vi={v∈V|f⁡(v)=i}V_{i}=\{v\in V|f(v)=i\} for i=0,1,2i=0,1,2. It is
clear that V1∪V2V_{1}\cup V_{2} is a dominating set of GG, called the
Roman dominating set, denoted by DR=(V1,V2)D_{\rm R}=(V_{1},V_{2}). For
S⊆VS\subseteq V, let f⁡(S)=∑u∈Sf⁡(u)f(S)=\sum\limits_{u\in S}f(u). The value
f⁡(V⁡(G))f(V(G)) is called the weight of ff, denoted by f⁡(G)f(G). The
Roman domination number, denoted by γR​(G)\gamma_{\rm R}(G), is
defined as the minimum weight of all Roman dominating functions,
that is,
γR​(G)=min⁡{f⁡(G):f​is​a​Roman​dominating​function​on​G}.\gamma_{\rm R}(G)=\min\{f(G):f\ {\rm is\ a\ Roman\ dominating\ function\ on}\ G\}.
It is clear that for a Roman dominating function ff on GG and a
Roman dominating set DRD_{\rm R} of GG, f⁡(DR)=2​|V2|+|V1|f(D_{\rm R})=2|V_{2}|+|V_{1}|. If DRD_{\rm R} is a minimum Roman dominating set of graph
GG, then f⁡(DR)=γR​(G)f(D_{\rm R})=\gamma_{\rm R}(G). A Roman dominating
function ff is called a γR\gamma_{\rm R}-function if
f​(G)=γR​(G)f(G)=\gamma_{\rm R}(G). It has been showed by Cockayne et
al. [2] that for any graph GG, γ⁡(G)⩽γR​(G)⩽2​γ​(G)\gamma(G)\leqslant\gamma_{R}(G)\leqslant 2\gamma(G). A graph GG is called to be Roman if γR​(G)=2​γ​(G)\gamma_{\rm R}(G)=2\gamma(G). Roman domination numbers
have been studied, for example, in [2, 3, 5, 6, 11, 12, 13, 14, 15, 16, 20].
To measure the vulnerability or the stability of the domination in
an interconnection network under edge failure, Fink et
at. [4] proposed the concept of the bondage number in
1990. The bondage number, denoted by b⁡(G)b(G), of GG is the
minimum number of edges whose removal from GG results in a graph
with larger domination number of GG.
Analogously, we can define the Roman bondage number. The Roman
bondage number, denoted by bR​(G)b_{\rm R}(G), of a nonempty graph GG
is the minimum number of edges whose removal from GG results in a
graph with larger Roman domination number. Precisely speaking, the
Roman bondage number
bR(G)=min{|B|:B⊆E(G),γR(G−B)>γR(G)}.b_{\rm R}(G)=\min\{|B|:B\subseteq E(G),\gamma_{\rm R}(G-B)>\gamma_{\rm R}(G)\}.
An edge set BB that γR​(G−B)>γR​(G)\gamma_{\rm R}(G-B)>\gamma_{\rm R}(G) is
called the Roman bondage set and the minimum one the minimum Roman bondage set. In fact, if BB is a minimum Roman
bondage set, then γR​(G−B)=γR​(G)+1\gamma_{\rm R}(G-B)=\gamma_{\rm R}(G)+1, because
the removal of one single edge can not increase the Roman domination
number by more than one. If bR​(G)b_{\rm R}(G) does not exist we define
bR​(G)=∞b_{\rm R}(G)=\infty.
In this paper, we give an original investigation. Some bounds are
obtained for bR​(G)b_{\rm R}(G), and the exact values are determined for
several classes of graphs. Moreover, the decision problem for
bR​(G)b_{\rm R}(G) is proved to be NP-hard even for bipartite graphs.
In the proofs of our results, when a Roman dominating function of a
graph is constructed, we only give its nonzero value of some
vertices.

4 Complexity of Roman bondage number
In this section, we will show that the Roman bondage number problem
is NP-hard and the Roman domination number problem is NP-complete
even for bipartite graphs. We first state the problem as the
following decision problem.
Roman bondage number problem (RBN):
Instance: A nonempty bipartite graph GG and a positive
integer kk.
Question: Is bR​(G)≤kb_{\rm R}(G)\leq k?
Roman domination number problem (RDN):
Instance: A nonempty bipartite graph GG and a positive
integer kk.
Question: Is γR​(G)≤k\gamma_{\rm R}(G)\leq k?
Following Garey and Johnson’s techniques for proving NP-completeness
given in [7], we prove our results by describing a
polynomial transformation from the known-well NP-complete problem:
3SAT. To state 3SAT, we recall some terms.
Let UU be a set of Boolean variables. A truth assignment for
UU is a mapping t:U→{T,F}t:U\to\{T,F\}. If t⁡(u)=Tt(u)=T, then uu is said to
be “ true” under tt; If t⁡(u)=Ft(u)=F, then uu is said to be
“ false” under tt. If uu is a variable in UU, then uu and
u¯\bar{u} are literals over UU. The literal uu is true under
tt if and only if the variable uu is true under tt; the literal
u¯\bar{u} is true if and only if the variable uu is false.
A clause over UU is a set of literals over UU. It represents
the disjunction of these literals and is satisfied by a truth
assignment if and only if at least one of its members is true under
that assignment. A collection 𝒞\mathscr{C} of clauses over UU is
satisfiable if and only if there exists some truth assignment
for UU that simultaneously satisfies all the clauses in 𝒞\mathscr{C}. Such a truth assignment is called a satisfying truth
assignment for 𝒞\mathscr{C}. The 3SAT is specified as follows.
33-satisfiability problem (3SAT):
Instance: A collection
𝒞={C1,C2,…,Cm}\mathscr{C}=\{C_{1},C_{2},\ldots,C_{m}\} of clauses over a finite set
UU of variables such that |Cj|=3|C_{j}|=3 for j=1,2,…,mj=1,2,\ldots,m.
Question: Is there a truth assignment for UU
that satisfies all the clauses in 𝒞\mathscr{C}?

3SAT is NP-complete.

Let GG be a graph with γR​(G)=2​β​(G)\gamma_{\rm R}(G)=2\beta(G). Then
(1) bR​(G)≥δ⁡(G)b_{\rm R}(G)\geq\delta(G);
(2) bR​(G)≥δ⁡(G)+1b_{\rm R}(G)\geq\delta(G)+1 if GG is a vrc-graph.
Proof. Let GG be a graph with γR​(G)=2​β​(G)\gamma_{\rm R}(G)=2\beta(G).
(1) Without loss of generality, Assume δ⁡(G)≥2\delta(G)\geq 2. Let
B⊆E⁡(G)B\subseteq E(G) with |B|≤δ⁡(G)−1|B|\leq\delta(G)-1. Then δ⁡(G−B)≥1\delta(G-B)\geq 1 and so γR​(G)≤γR​(G−B)≤2​β​(G−B)≤2​β​(G)=γR​(G)\gamma_{\rm R}(G)\leq\gamma_{\rm R}(G-B)\leq 2\beta(G-B)\leq 2\beta(G)=\gamma_{\rm R}(G). Thus, BB is not a
Roman bondage set of GG, and so bR​(G)≥δ⁡(G)b_{\rm R}(G)\geq\delta(G).
(2) From the above proof, every Roman bondage set BB contains at
least all edges incident with some vertex xx, so that G−BG-B has an
isolated vertex. On the other hand, if GG is a vrc-graph, then
γR​(G−x)<γR​(G)\gamma_{\rm R}(G-x)<\gamma_{\rm R}(G) for any vertex xx, which
implies that the removal of all edges incident with xx can not
enlarge the Roman domination number. Hence bR​(G)≥δ⁡(G)+1b_{\rm R}(G)\geq\delta(G)+1.
