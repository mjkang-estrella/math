                                                                                          1. Introduction

                                             Non-transitive dice are fascinating mathematical objects that have attracted attention and have
                                           been studied by various researchers (cf. [1, 2, 3, 4, 5, 6, 7]). In this paper, we are concerned
                                           specifically with non-transitive dice which have n-many sides and can only take values from the
                                           set {1, . . . , n}. Hereafter, all dice are assumed fair and independent with regard to outcomes of
                                           competing dice tosses. A standard n-sided die is such that each face takes a value from 1 to n for
                                           some natural number n ∈ N with n ≥ 3, and each face value appears exactly once, and each face
                                           has equal probability of n1 to be a result in a die toss. We denote by [n] the set {1, . . . , n} with
                                           n ≥ 3.

                                           Definition 1. We will call a non-standard n-sided die to be a die taking face values in [n] such
                                           that face values may be repeated. Each face still possesses probability n1 to be the result of a toss.

                                             We will represent dice by n-tuples such that the coordinates are placed in non-decreasing order.

                                           Example 1. The die in ordered tuple form (1, 2, 3, 4, 5, 6) is standard and will also occur in the
                                           set of non-standard dice; whereas, the die (1, 2, 3, 3, 4, 4) is non-standard. In particular, the set of
                                           standard n-sided dice is a singleton.

                                             Given two non-standard n-sided dice, Dx := (x1 , x2 , . . . , xn ) and Dy := (y1 , y2 , . . . , yn ) for n ≥ 3,

Definition 3. A directed graph G = (V, E) with no loops is called strongly connected if for every

    Given a directed graph G = (V, E) with no loops, a maximal subset S ⊆ V is called a strongly

vertices u, v in the directed subgraph, there is a directed path from u to v and from v to u both
of which lie entirely in the subgraph induced by S. The trivial SCCs are those for which S is a

  Strong connectivity defines an equivalence relation on the vertex set V of a directed graph G.
Thus, the SCCs are the equivalence classes of this relation and partition V . Namely, for two distinct
SCCs S1 and S2 there may either be an out-edge or an in-edge but not in both directions, there
may also be no edges between them. If an SCC has at least two vertices then it possesses a directed
cycle; moreover, every directed cycle will be entirely within some SCC.

non-transitive cycle of maximum length n with uniform and minimal winning advantage.

                        3. Conjecture for n = 6 and Evidence for n > 6

Conjecture 1. n = 6 is the largest n ≥ 3 such that the set of non-standard n-sided dice admits a
non-transitive cycle of maximum length n with uniform and minimal winning advantage.

Evidence. We use a similar approach to that done for the proof of Theorem 1. We construct the
directed graphs for n = 7, 8, 9, 10 and find the SCCs of the resulting graphs.
Computer-assistance
As before we use a program written in the Julia programming language and the package Graphs.jl
(cf. Appendix F). Again by way of exhaustive search, we use the program to construct the directed
graph Gn for the given n. The construction of edges follow from using the following criteria
                             X n

This provided a speed-up in obtaining the results (cf. the Technology Disclosure below). Again,
Tarjan’s algorithm (cf. [8]) is utilized to find the SCCs. Once the SCCs are found, the program
searches each SCC with at least n + 1 vertices using a depth-first search (DFS) until it finds a
directed cycle which has length n + 1 or greater. Given the non-standard dice are represented
in non-decreasing ordered n-tuples placed in a lexicographical ordering, the program chooses the
first vertex label under this ordering that occurs in the SCC possessing at least n + 1 vertices and
performs the DFS, if no such non-transitive cycle is found it moves on to the second vertex in this
ordering, and so forth until such a non-transitive cycle is either found or not found. The program
stops as soon as a non-transitive cycle of length n + 1 or greater is found; otherwise it exhausts all
cases. If no SCC is found to contain at least n + 1 vertices then there is no directed cycle of length
at least n + 1. The output of the program is as follows
      (1) The total number of non-standard dice; thus, the number of vertices in G.

# ============================================================
# 2. Enumerate all nondecreasing n-tuples lexicographically
# ============================================================


function generate_dice(n)
       dice = Tuple[]
       x = zeros(Int, n)


       function build(pos, lower)
            if pos > n
                  push!(dice, Tuple(x))
                  return
            end


            for value in lower:n
                  x[pos] = value
      COMPUTER-ASSISTED RESULTS FOR n-SIDED NON-TRANSITIVE DICE TAKING FACE VALUES IN [n]   13

                  build(pos + 1, value)
            end
      end


      build(1, 1)
      return dice
end


dice = generate_dice(n)
N = length(dice)


# Number of multisets of size n chosen from {1,...,n}
expected_vertices = binomial(2n - 1, n)

# 3. Construct directed graph
#
#      X -> Y iff
#
#            sum_{i=1}^n sum_{j=1}^n 1{x_i > y_j}
#                  = n^2/2 + 1
# ============================================================


beatscore(X, Y) = sum(x > y for x in X for y in Y)
