From the workspace root, run the finite exact checker with the specified unchanged caps:

```bash

```

The checker uses only Python’s standard library. It deterministically writes checks.json, exhausts only the stated small graphs, and has a 200,000-node DFS budget. A separate final verification runs as follows:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python /home/mj-kang/Documents/Dev/math/openai-proof-research/frontier/campaigns/2026-10-27/new-discoveries-batch2/lanes/sol-edge-irregulator-manuscript-packet-r1/packet/helper_guard.py python /home/mj-kang/Documents/Dev/math/openai-proof-research/frontier/campaigns/2026-10-27/new-discoveries-batch2/lanes/sol-fresh-source-discovery-r206/verify.py
```

Caps are 512 MiB address space and sampled process-group RSS, 210 CPU seconds and 230 wall seconds. The guard samples RSS; unsampled transients are not ruled out. Both commands passed, with about 16.4 MiB sampled peak RSS and 1.9 seconds for the final exact checker. Verification checks raw scientific original/copy bindings, historical frozen snapshots, complete manifest inventory and cycle witness arithmetic; it is not a universal proof checker.

manifest.json excludes exactly itself and verification-receipt.json. The receipt is generated by a separate guarded command after all manifested files and the manifest have been finalized. Rebuilding history or rerunning retrieval helpers is unnecessary for replay and would intentionally change the packet. Read FAILURES.md for the missing distinct pre-read disk-check receipt.
