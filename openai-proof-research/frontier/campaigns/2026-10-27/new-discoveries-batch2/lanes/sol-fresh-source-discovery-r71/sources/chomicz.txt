The type and cardinality of minimal presentations of 
numerical semigroups with embedding dimension four 


Kazimierz Chomicz

September 2026


Abstract
    

For a numerical semigroup S with embedding dimension four, we study the relationship between its type t(S) and the cardinality of its minimal presentations \eta(S). Using an approach based on the geometry of the Apéry set, we prove that 4t(S)+5\geq\eta(S)\geq t(S)-11. This resolves a problem of Moscariello and Sammartano asking whether t(S) is bounded by a function of \eta(S), and improves the previously known bound 9t(S)+4\geq\eta(S) due to Bresinsky.
  



1 Introduction
††
        
      Keywords: numerical semigroup, embedding dimension, Apéry set, type, minimal presentation.††
        
      2020 Mathematics Subject Classification: 20M13, 20M14


Let \mathbb{N} denote the set of nonnegative integers. For k>0 and d_{0},d_{1},\dots,d_{k}\in\mathbb{N} such that \gcd(d_{0},d_{1},\dots,d_{k})=1, the set





S=\langle d_{0},d_{1},\dots,d_{k}\rangle=\{\lambda_{0}d_{0}+\lambda_{1}d_{1}+\dots+\lambda_{k}d_{k}\mid\lambda_{i}\in\mathbb{N}\},



is called a numerical semigroup generated by \{d_{0},d_{1},\dots,d_{k}\}. Equivalently, S is a submonoid of (\mathbb{N},+) such that \mathbb{N}\setminus S is finite (see [14, Lemma 2.1]). If no proper subset of \{d_{0},d_{1},\dots,d_{k}\} generates S, then we say that S is minimally generated by \{d_{0},d_{1},\dots,d_{k}\}. The cardinality of the minimal set of generators of S is called the embedding dimension of S and is denoted e(S).



The largest integer that is not in S is called the Frobenius number and is denoted F(S). An integer a\notin S is called a pseudo-Frobenius number of S if a+s\in S for all s\in S\setminus\{0\}. The set of all pseudo-Frobenius numbers of S is denoted PF(S). The cardinality of PF(S) is called the type of S and is denoted t(S).



If S is minimally generated by \{d_{0},d_{1},\dots,d_{k}\}, then we have a homomorphism \varphi:\mathbb{N}^{k+1}\to S defined by \varphi(z_{0},\dots,z_{k})=z_{0}d_{0}+\dots+z_{k}d_{k}.
The kernel congruence of \varphi is \ker(\varphi)=\{(a,b)\in\mathbb{N}^{k+1}\times\mathbb{N}^{k+1}\mid\varphi(a)=\varphi(b)\}.
It is well known that S is isomorphic to the monoid \mathbb{N}^{k+1}/\ker(\varphi). A minimal set of generators of the congruence \ker(\varphi) is called a minimal presentation of S. Minimal presentations of S are not unique, but their cardinality depends only on S and is denoted by \eta(S).



Both type and minimal presentations are central to the study of numerical semigroups (see [2, 3, 9, 13, 14]).
In the study of minimal presentations, the invariant \eta(S) has attracted considerable interest (see [8, 12, 13, 14, 16]).



A numerical semigroup S is symmetric if for every x\in\mathbb{Z}\setminus S we have F(S)-x\in S. This is equivalent to t(S)=1 [11]. It is well known that if e(S)=2, then t(S)=\eta(S)=1. The case e(S)=3 is completely settled in the following theorem.



Theorem 1.1.


[10] Let S be a numerical semigroup with e(S)=3. If S is symmetric, then \eta(S)=2 and t(S)=1. If S is not symmetric, then \eta(S)=3 and t(S)=2.




When e(S)\geq 4, the situation becomes much more complicated. Bresinsky [4] found a family of numerical semigroups with e(S)=4 whose \eta(S) can be arbitrarily large, while Backelin [9, p. 75] found a family of numerical semigroups with e(S)=4 whose t(S) can be arbitrarily large.



In this paper, we study t(S) and \eta(S) for numerical semigroups with embedding dimension four. In [6], Bresinsky established the following bound.



Theorem 1.2.


[6, Theorem 7] If S is a numerical semigroup with e(S)=4, then 9t(S)+4\geq\eta(S).




In [13], the authors, inspired by the above bound, proposed the following problem.



Problem 1.3.


[13, Problem 25] Let S be a numerical semigroup with e(S)=4. Is t(S) bounded by a function of \eta(S)?




Resolving Problem 1.3 also settles a general
problem on the boundedness of Betti numbers [13, Problem 24] in the case e(S)=4, as noted in the same paper.



The main result of this paper is the following theorem, which settles Problem 1.3 and improves the bound of Theorem 1.2.



Theorem 1.4.


If S is a numerical semigroup with e(S)=4, then 4t(S)+5\geq\eta(S)\geq t(S)-11.




The paper is organized as follows.
In Section 2, we study the geometry of the Apéry set of numerical semigroups with embedding dimension four using L-shapes [1].
In Section 3, we relate minimal presentations of numerical semigroups with embedding dimension four to an L-shape.
In Section 4, we prove Theorem 1.4 by using results of the previous sections to study t(S) and \eta(S) geometrically.
We conclude the paper with Conjecture 5.1.




2 Geometry of the Apéry set



In this section, we study the geometry of the Apéry set of numerical semigroups with e(S)=4. Subsection 2.1 introduces the notion of minimal relations and uses them to classify numerical semigroups with e(S)=4 into primary and secondary semigroups (Lemma 2.2) — a distinction that underpins our approach. Subsection 2.2 presents the geometric framework for analyzing the Apéry set (Theorem 2.4). Subsection 2.3 introduces the notion of L-shapes and examines them for primary and secondary semigroups (Propositions 2.7 and 2.8).



Let S be minimally generated by \{d_{0},d_{1},\dots,d_{k}\}. For an element s\in S, the set





\varphi^{-1}(s)=\{(z_{0},\dots,z_{k})\in\mathbb{N}^{k+1}\mid z_{0}d_{0}+\dots+z_{k}d_{k}=s\}

(1)


is called the set of factorizations of s.
For z=(z_{0},\dots,z_{k})\in\varphi^{-1}(s), the support of z is





\text{supp}(z)=\{i\in\{0,\dots,k\}\mid z_{i}>0\}.

(2)


For an element a\in S, the set





\textup{Ap}(S,a)=\{s\in S\mid s-a\notin S\}

(3)


is called the Apéry set of S with respect to a. Note that \textup{Ap}(S,a) is the set of the smallest nonnegative integers from each residue class modulo a that are in S, hence |\textup{Ap}(S,a)|=a. From [14, Proposition 2.20], we have





PF(S)=\{s-a\mid s\in\textup{Ap}(S,a),s+d_{i}\notin\textup{Ap}(S,a)\text{ for }i=0,1,\dots,k\}.

(4)


This description of pseudo-Frobenius numbers in terms of the Apéry set will provide a useful framework for our study of the type in Section 4.



2.1 Minimal relations



Let S=\langle d_{0},d_{1},d_{2},d_{3}\rangle be a numerical semigroup with embedding dimension four.



For every i\in\{0,1,2,3\}, let a_{ii} be the smallest positive integer such that there exist nonnegative integers a_{ij},a_{ik},a_{il} satisfying





a_{ii}d_{i}=a_{ij}d_{j}+a_{ik}d_{k}+a_{il}d_{l}

(5)


where \{i,j,k,l\}=\{0,1,2,3\}. We call (5) a minimal relation of d_{i}.



Fix m\in\{0,1,2,3\}. For every i\in\{0,1,2,3\}\setminus\{m\}, let b_{m,ii} be the smallest positive integer such that there exist nonnegative integers b_{m,ij},b_{m,ik},b_{m,il} satisfying





b_{m,ii}d_{i}=b_{m,ij}d_{j}+b_{m,ik}d_{k}+b_{m,il}d_{l}

(6)


where \{i,j,k,l\}=\{0,1,2,3\} and b_{m,im}>0. We call (6) a d_{m}-positive minimal relation of d_{i}.



Note that in the minimal relations a_{ii} is unique; however, each a_{ij} for i\neq j is not necessarily unique. Similarly, in the d_{m}-positive minimal relations b_{m,ii} is unique; however, each b_{m,ij} for i\neq j is not necessarily unique.



Let \varphi:\mathbb{N}^{4}\to S be the factorization morphism of S.



Lemma 2.1.


For i\in\{0,1,2,3\} and (\mu_{0},\mu_{1},\mu_{2},\mu_{3})\in\varphi^{-1}(a_{ii}d_{i}), we have either \mu_{i}=a_{ii} and \mu_{j}=0 for all j\in\{0,1,2,3\}\setminus\{i\}, or \mu_{i}=0.




Proof.


Without loss of generality, suppose i=0. We have





(a_{00}-\mu_{0})d_{0}=\mu_{1}d_{1}+\mu_{2}d_{2}+\mu_{3}d_{3}.

(7)


The right-hand side is clearly nonnegative. If (a_{00}-\mu_{0})=0, then \mu_{1}=\mu_{2}=\mu_{3}=0. If (a_{00}-\mu_{0})>0, then the minimality of a_{00} implies \mu_{0}=0.
∎




Lemma 2.2.


If there is no m\in\{0,1,2,3\} such that a_{ii}=b_{m,ii} for at least two distinct indices i\in\{0,1,2,3\}\setminus\{m\}, then there exists an arrangement \{i,j,k,l\}=\{0,1,2,3\} such that a_{ii}d_{i}=a_{jj}d_{j}\neq a_{kk}d_{k}=a_{ll}d_{l}, and \varphi^{-1}(a_{ii}d_{i})\cup\varphi^{-1}(a_{kk}d_{k})=\{(a_{00},0,0,0),(0,a_{11},0,0),(0,0,a_{22},0),(0,0,0,a_{33})\}.




Proof.


Suppose that for every m\in\{0,1,2,3\} we have a_{ii}<b_{m,ii} for at least two distinct indices i\in\{0,1,2,3\}\setminus\{m\} (note that a_{ii}\leq b_{m,ii} always holds by definition).



Suppose that there exists z\in\varphi^{-1}(a_{00}d_{0}) with |\textup{supp}(z)|\geq 2. By Lemma 2.1, 0\notin\textup{supp}(z). Without loss of generality, suppose that z=(0,a_{01},a_{02},a_{03}) where a_{01},a_{02}>0. Then, a_{00}=b_{1,00}=b_{2,00}. This implies a_{11}<b_{2,11}, a_{22}<b_{1,22}, a_{33}<b_{1,33}, and a_{33}<b_{2,33}. The last two inequalities give \varphi^{-1}(a_{33}d_{3})=\{(0,0,0,a_{33}),(a_{30},0,0,0)\}, so a_{30}>0 and hence a_{33}=b_{0,33}. This implies a_{11}<b_{0,11} and a_{22}<b_{0,22}. Now, since a_{11}<b_{0,11} and a_{11}<b_{2,11}, we have \varphi^{-1}(a_{11}d_{1})=\{(0,a_{11},0,0),(0,0,0,a_{13})\}, so a_{13}>0 and hence a_{11}=b_{3,11}. Similarly, \varphi^{-1}(a_{22}d_{2})=\{(0,0,a_{22},0),(0,0,0,a_{23})\} and a_{22}=b_{3,22}, which is a contradiction, as now there exists at most one i\in\{0,1,2\} such that a_{ii}<b_{3,ii}.



Hence, for every z\in\varphi^{-1}(a_{00}d_{0}), we have |\textup{supp}(z)|=1.
Proceeding analogously with a_{11}d_{1}, a_{22}d_{2}, and a_{33}d_{3}, we obtain that for every i\in\{0,1,2,3\} and every z\in\varphi^{-1}(a_{ii}d_{i}), we have |\textup{supp}(z)|=1.



Without loss of generality, suppose that a_{00}d_{0}=a_{01}d_{1}.
Observe that a_{01}\geq a_{11}. If a_{01}>a_{11}, then





a_{00}d_{0}=a_{01}d_{1}=(a_{01}-a_{11})d_{1}+a_{1i}d_{i}

(8)


for some i\in\{0,2,3\}. Clearly a_{1i}>0. If i=0, subtracting d_{0} from both sides of (8) contradicts the minimality of a_{00}. If i\neq 0, we get a factorization z\in\varphi^{-1}(a_{00}d_{0}) with |\textup{supp}(z)|=2, which is a contradiction.



Hence a_{01}=a_{11}, and therefore a_{00}d_{0}=a_{11}d_{1}. Analogously, we get a_{22}d_{2}=a_{ii}d_{i} for some i\in\{0,1,3\}. If i\in\{0,1\}, then a_{00}d_{0}=a_{11}d_{1}=a_{22}d_{2}, so a_{11}=b_{0,11} and a_{22}=b_{0,22}, which is contrary to our assumption. Hence a_{22}d_{2}=a_{33}d_{3}\neq a_{00}d_{0}=a_{11}d_{1}, and the claim follows.
∎




If there exists m\in\{0,1,2,3\} such that a_{ii}=b_{m,ii} for at least two distinct indices i\in\{0,1,2,3\}\setminus\{m\}, we call \langle d_{0},d_{1},d_{2},d_{3}\rangle primary. Moreover, for a primary semigroup \langle d_{0},d_{1},d_{2},d_{3}\rangle, unless stated otherwise, we always assume throughout this paper that the generators are ordered so that a_{11}=b_{0,11} and a_{22}=b_{0,22}.



Numerical semigroups with embedding dimension four that are not primary will be referred to as secondary semigroups. By Lemma 2.2, if \langle d_{0},d_{1},d_{2},d_{3}\rangle is a secondary semigroup, then there exists an arrangement \{i,j,k,l\}=\{0,1,2,3\} such that a_{ii}d_{i}=a_{jj}d_{j}\neq a_{kk}d_{k}=a_{ll}d_{l}, and \varphi^{-1}(a_{ii}d_{i})\cup\varphi^{-1}(a_{kk}d_{k})=\{(a_{00},0,0,0),(0,a_{11},0,0),(0,0,a_{22},0),(0,0,0,a_{33})\}. Moreover, for a secondary semigroup \langle d_{0},d_{1},d_{2},d_{3}\rangle, unless stated otherwise, we always assume throughout this paper that the generators are ordered so that \varphi^{-1}(a_{00}d_{0})=\varphi^{-1}(a_{11}d_{1})=\{(a_{00},0,0,0),(0,a_{11},0,0)\} and \varphi^{-1}(a_{22}d_{2})=\varphi^{-1}(a_{33}d_{3})=\{(0,0,a_{22},0),(0,0,0,a_{33})\}.



A numerical semigroup with embedding dimension four, S=\langle d_{0},d_{1},d_{2},d_{3}\rangle, is said to be ordered if its generators are arranged according to the ordering defined above — that is, the ordering assumed for primary semigroups if S is primary, and the ordering assumed for secondary semigroups if S is secondary. We adopt this convention so that certain definitions and constructions can be stated uniformly for any ordered semigroup \langle d_{0},d_{1},d_{2},d_{3}\rangle, without requiring a prior assumption on whether it is primary or secondary.




2.2 Geometric framework



From this point on, we will focus on the Apéry set of \langle d_{0},d_{1},d_{2},d_{3}\rangle with respect to d_{0}, which we henceforth refer to simply as the Apéry set. For brevity, we also write b_{0,ij}=b_{ij} for all i,j\in\{0,1,2,3\}.



Consider the unit cubes in \mathbb{R}^{3}. Each unit cube [i,i+1]\times[j,j+1]\times[k,k+1]\subset\mathbb{R}^{3} has natural coordinates (i,j,k)\in\mathbb{N}^{3} and is labeled with the value id_{1}+jd_{2}+kd_{3}. We will refer to the collection of all such labeled cubes as the initial collection of cubes. We denote the unit cube [i,i+1]\times[j,j+1]\times[k,k+1] by [[i,j,k]].
For a point P=(a,b,c)\in\mathbb{Z}^{3}, we call the region \{x>a,y>b,z>c\} the region associated to P. We write [[a,b,c]]\geq[[a^{\prime},b^{\prime},c^{\prime}]] when a\geq a^{\prime}, b\geq b^{\prime}, c\geq c^{\prime}, and [[a,b,c]]>[[a^{\prime},b^{\prime},c^{\prime}]] when [[a,b,c]]\geq[[a^{\prime},b^{\prime},c^{\prime}]] and [[a,b,c]]\neq[[a^{\prime},b^{\prime},c^{\prime}]].



Lemma 2.3.


No cube labeled with an element of the Apéry set is in the region associated to a point (\mu_{1},\mu_{2},\mu_{3})\in\mathbb{Z}^{3} satisfying \mu_{1}d_{1}+\mu_{2}d_{2}+\mu_{3}d_{3}=\mu d_{0} for some positive integer \mu.




Proof.


Recall that the Apéry set with respect to d_{0} is the set of the smallest nonnegative integers from each residue class modulo d_{0} that are in the numerical semigroup \langle d_{1},d_{2},d_{3}\rangle. Suppose to the contrary, that for some residue r\in\{0,1,\dots,d_{0}-1\} there is a cube [[\lambda_{1},\lambda_{2},\lambda_{3}]] labeled with the smallest number \lambda d_{0}+r (\lambda\in\mathbb{N}) that is in \langle d_{1},d_{2},d_{3}\rangle such that [[\lambda_{1},\lambda_{2},\lambda_{3}]]\geq[[\mu_{1},\mu_{2},\mu_{3}]]. This gives





(\lambda_{1}-\mu_{1})d_{1}+(\lambda_{2}-\mu_{2})d_{2}+(\lambda_{3}-\mu_{3})d_{3}=(\lambda-\mu)d_{0}+r

(9)


where all coefficients on the left-hand side are nonnegative. This means that the value in (9) is congruent to r modulo d_{0}, is nonnegative, is in \langle d_{1},d_{2},d_{3}\rangle, and is strictly less than \lambda d_{0}+r, which contradicts the minimality of \lambda d_{0}+r.
∎




Theorem 2.4.


Delete from the initial collection of cubes the regions \{x>b_{11}\}, \{y>b_{22}\}, and \{z>b_{33}\}.
Next, for every point (a_{01},a_{02},a_{03})\in\mathbb{N}^{3} satisfying





a_{01}d_{1}+a_{02}d_{2}+a_{03}d_{3}=a_{00}d_{0}

(10)


delete the region associated to it.
Furthermore, for all identities of the form





\lambda_{0}d_{0}+\lambda_{1}d_{1}=\lambda_{2}d_{2}+\lambda_{3}d_{3}

(11)


with \lambda_{i}\in\mathbb{Z}_{>0}, \lambda_{2}<b_{22}, and \lambda_{3}<b_{33}, delete the region associated to (-\lambda_{1},\lambda_{2},\lambda_{3}). For all identities of the form





\lambda_{0}d_{0}+\lambda_{2}d_{2}=\lambda_{1}d_{1}+\lambda_{3}d_{3}

(12)


with \lambda_{i}\in\mathbb{Z}_{>0}, \lambda_{1}<b_{11}, and \lambda_{3}<b_{33}, delete the region associated to (\lambda_{1},-\lambda_{2},\lambda_{3}). Finally, for all identities of the form





\lambda_{0}d_{0}+\lambda_{3}d_{3}=\lambda_{1}d_{1}+\lambda_{2}d_{2}

(13)


with \lambda_{i}\in\mathbb{Z}_{>0}, \lambda_{1}<b_{11}, and \lambda_{2}<b_{22}, delete the region associated to (\lambda_{1},\lambda_{2},-\lambda_{3}).
Then, the remaining collection of cubes is the set of all cubes from the initial collection of cubes that are labeled with an element of the Apéry set.




Proof.


Let R be the remaining collection of cubes.
The condition \lambda_{i}<b_{ii} ensures that only the relevant identities are considered, since we delete the regions \{x>b_{11}\}, \{y>b_{22}\}, and \{z>b_{33}\}. Moreover, by Lemma 2.3, every cube labeled with an element of the Apéry set is in R, since deleting the regions \{x>b_{11}\}, \{y>b_{22}\}, and \{z>b_{33}\} is the same as deleting the regions associated to (b_{11},-b_{12},-b_{13}), (-b_{21},b_{22},-b_{23}), and (-b_{31},-b_{32},b_{33}).



Therefore we only need to prove that R contains only cubes labeled with an element of the Apéry set. Suppose to the contrary, that for some remainder r\in\{0,1,\dots,d_{0}-1\}, \lambda d_{0}+r and \lambda^{\prime}d_{0}+r, where \lambda^{\prime}>\lambda, are labels in R. This means that





\lambda d_{0}+r=\lambda_{1}d_{1}+\lambda_{2}d_{2}+\lambda_{3}d_{3}

(14)






\lambda^{\prime}d_{0}+r=\lambda_{1}^{\prime}d_{1}+\lambda_{2}^{\prime}d_{2}+\lambda_{3}^{\prime}d_{3}

(15)


where [[\lambda_{1},\lambda_{2},\lambda_{3}]],[[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R.
Subtracting (14) from (15) we get





(\lambda^{\prime}-\lambda)d_{0}=(\lambda_{1}^{\prime}-\lambda_{1})d_{1}+(\lambda_{2}^{\prime}-\lambda_{2})d_{2}+(\lambda_{3}^{\prime}-\lambda_{3})d_{3}

(16)


where (\lambda^{\prime}-\lambda)>0. Now, we consider cases of how many coefficients on the right-hand side of (16) are positive. The left-hand side is positive; hence, at least one of the coefficients on the right-hand side is positive.



If exactly one coefficient is positive, without loss of generality, suppose that (\lambda_{1}^{\prime}-\lambda_{1}) is the one. Moving the non-positive integers to the other side gives





(\lambda^{\prime}-\lambda)d_{0}+(\lambda_{2}-\lambda_{2}^{\prime})d_{2}+(\lambda_{3}-\lambda_{3}^{\prime})d_{3}=(\lambda_{1}^{\prime}-\lambda_{1})d_{1}.

(17)


Since all the above coefficients are nonnegative and (\lambda_{1}^{\prime}-\lambda_{1}) and (\lambda^{\prime}-\lambda) are positive, the minimality of b_{11} gives b_{11}\leq(\lambda_{1}^{\prime}-\lambda_{1})\leq\lambda_{1}^{\prime}, which contradicts [[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R.



If exactly two coefficients on the right-hand side of (16) are positive, without loss of generality, suppose that (\lambda_{1}^{\prime}-\lambda_{1}) and (\lambda_{2}^{\prime}-\lambda_{2}) are the two. Moving (\lambda_{3}^{\prime}-\lambda_{3}) to the other side gives





(\lambda^{\prime}-\lambda)d_{0}+(\lambda_{3}-\lambda_{3}^{\prime})d_{3}=(\lambda_{1}^{\prime}-\lambda_{1})d_{1}+(\lambda_{2}^{\prime}-\lambda_{2})d_{2}.

(18)


The above identity satisfies the conditions of the current theorem, thus the region \{x>(\lambda_{1}^{\prime}-\lambda_{1}),y>(\lambda_{2}^{\prime}-\lambda_{2})\} was deleted. Again, this contradicts [[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R, since \lambda^{\prime}_{1}\geq(\lambda_{1}^{\prime}-\lambda_{1}) and \lambda^{\prime}_{2}\geq(\lambda_{2}^{\prime}-\lambda_{2}).



Now, the only case left is where all the coefficients in (16) are positive. We substitute \mu=(\lambda^{\prime}-\lambda)>0 and \mu_{i}=(\lambda_{i}^{\prime}-\lambda_{i})>0 for i=1,2,3. We have





\mu d_{0}=\mu_{1}d_{1}+\mu_{2}d_{2}+\mu_{3}d_{3}

(19)


and since [[\mu_{1},\mu_{2},\mu_{3}]]\leq[[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R, we have [[\mu_{1},\mu_{2},\mu_{3}]]\in R.
From the minimality of a_{00}, we get a_{00}\leq\mu. Subtracting a_{00}d_{0}=a_{01}d_{1}+a_{02}d_{2}+a_{03}d_{3} from (19) gives





(\mu-a_{00})d_{0}=(\mu_{1}-a_{01})d_{1}+(\mu_{2}-a_{02})d_{2}+(\mu_{3}-a_{03})d_{3}.

(20)




If \mu=a_{00}, then (0,\mu_{1},\mu_{2},\mu_{3})\in\varphi^{-1}(a_{00}d_{0}), hence the region associated to (\mu_{1},\mu_{2},\mu_{3}) had been deleted, which contradicts [[\mu_{1},\mu_{2},\mu_{3}]]\in R.



Hence (\mu-a_{00})>0. Now, we repeat the same case by case consideration with (20) as we did with (16), which results in all the coefficients in (20) being positive. However, this implies that the cube [[\mu_{1},\mu_{2},\mu_{3}]] is in the region associated to (a_{01},a_{02},a_{03}), which contradicts [[\mu_{1},\mu_{2},\mu_{3}]]\in R.
∎




Throughout this paper, R denotes the collection of all cubes from the initial collection of cubes that are labeled with an element of the Apéry set.
We will refer to equations of the forms (11), (12), (13) (where \lambda_{i}\in\mathbb{Z}_{>0}) as the (2,2)-type relations. In addition, we will refer to points that are constructed from the (2,2)-type relations (as in Theorem 2.4) as the (2,2)-type points.




2.3 L-shapes



Define an L-shape to be a subset of the initial collection of cubes such that:


• 


all its labels are elements of the Apéry set,


• 


every element of the Apéry set labels exactly one cube in it,


• 


if a cube [[a,b,c]], (a,b,c)\in\mathbb{N}^{3}, is not in it, then neither is any cube in the region associated to (a,b,c).



This notion is adopted from [1] and is established in the literature.



Lemma 2.5.


Delete from R one of the regions \{x>a_{11}\}, \{y>a_{22}\}, or \{z>a_{33}\}. Then every element of the Apéry set still labels some remaining cube.




Proof.


Delete the region \{x>a_{11}\} from R (the other two cases follow analogously).
If a_{11}=b_{11}, there is nothing to prove; thus, suppose a_{11}<b_{11}. Suppose to the contrary, that there is some element of the Apéry set that does not label any cube in R\cap\{x\leq a_{11}\}. By Theorem 2.4, then there exists [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in R with \lambda_{1}\geq a_{11} that is labeled with the element in question. There exists a positive integer \lambda such that a_{11}>(\lambda_{1}-\lambda a_{11})\geq 0. Using a_{11}d_{1}=a_{12}d_{2}+a_{13}d_{3}, where a_{12},a_{13}\in\mathbb{N} (recall a_{11}<b_{11}), we obtain





\lambda_{1}d_{1}+\lambda_{2}d_{2}+\lambda_{3}d_{3}=(\lambda_{1}-\lambda a_{11})d_{1}+(\lambda_{2}+\lambda a_{12})d_{2}+(\lambda_{3}+\lambda a_{13})d_{3}.

(21)


The cube [[\lambda_{1}-\lambda a_{11},\lambda_{2}+\lambda a_{12},\lambda_{3}+\lambda a_{13}]] has the same label as [[\lambda_{1},\lambda_{2},\lambda_{3}]], hence it is in R by Theorem 2.4. Since a_{11}>(\lambda_{1}-\lambda a_{11}), it is in R\cap\{x\leq a_{11}\} — contradiction.
∎




Lemma 2.6.


Delete from R the regions \{x>a_{11}\}, \{y>a_{22}\}, and \{z>a_{33}\}. Then, in the resulting collection, each element of the Apéry set labels at most one cube.




Proof.


Suppose to the contrary, that for two distinct [[\lambda_{1},\lambda_{2},\lambda_{3}]],[[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R\cap\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}, we have





\lambda_{1}d_{1}+\lambda_{2}d_{2}+\lambda_{3}d_{3}=\lambda_{1}^{\prime}d_{1}+\lambda_{2}^{\prime}d_{2}+\lambda_{3}^{\prime}d_{3}







\implies(\lambda_{1}^{\prime}-\lambda_{1})d_{1}+(\lambda_{2}^{\prime}-\lambda_{2})d_{2}+(\lambda_{3}^{\prime}-\lambda_{3})d_{3}=0.



If all coefficients above are zero, we have nothing to prove. Therefore either one or two coefficients above are positive. Regardless, without loss of generality, we can suppose that





(\lambda_{1}^{\prime}-\lambda_{1})d_{1}=(\lambda_{2}-\lambda_{2}^{\prime})d_{2}+(\lambda_{3}-\lambda_{3}^{\prime})d_{3}

(22)


where every coefficient above is nonnegative. However, (\lambda_{1}^{\prime}-\lambda_{1}) is positive, because otherwise all coefficients are zero. This implies a_{11}\leq(\lambda_{1}^{\prime}-\lambda_{1})\leq\lambda_{1}^{\prime}, which contradicts [[\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}]]\in R\cap\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}.
∎




Proposition 2.7.


If \langle d_{0},d_{1},d_{2},d_{3}\rangle is primary, then R\cap\{z\leq a_{33}\} is an L-shape.




Proof.


If a_{ii}=b_{ii} for i=1,2,3, then R=R\cap\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}, hence Lemma 2.6 yields the claim. Otherwise, we have a_{ii}<b_{ii} for exactly one i\in\{1,2,3\}. In such case, Lemmas 2.5 and 2.6 yield the claim.
∎




Proposition 2.8.


Suppose that for \langle d_{0},d_{1},d_{2},d_{3}\rangle we have a_{11}=b_{11} and a_{22}d_{2}=a_{33}d_{3}. Then there is a bijection f:R\cap\{y\geq a_{22}\}\to R\cap\{z\geq a_{33}\} sending [[\lambda_{1},\lambda_{2},\lambda_{3}]]\mapsto[[\lambda_{1},\lambda_{2}-a_{22},\lambda_{3}+a_{33}]]. Moreover, R\cap\{y\leq a_{22}\} and R\cap\{z\leq a_{33}\} are L-shapes.




Proof.


For [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in R\cap\{y\geq a_{22}\}, the cube [[\mu_{1},\mu_{2}-a_{22},\mu_{3}+a_{33}]] is in R by Theorem 2.4, because it has the same label as [[\lambda_{1},\lambda_{2},\lambda_{3}]], so it is labeled with an element of the Apéry set. Thus, the function f:[[\lambda_{1},\lambda_{2},\lambda_{3}]]\mapsto[[\lambda_{1},\lambda_{2}-a_{22},\lambda_{3}+a_{33}]] maps R\cap\{y\geq a_{22}\} to R\cap\{z\geq a_{33}\} and is also clearly injective. Similarly, we obtain the injection f^{-1}:R\cap\{z\geq a_{33}\}\to R\cap\{y\geq a_{22}\} sending [[\lambda_{1},\lambda_{2},\lambda_{3}]]\mapsto[[\lambda_{1},\lambda_{2}+a_{22},\lambda_{3}-a_{33}]], which yields that f is a bijection.



Let T=R\cap\{z\leq a_{33}\}. Since f preserves labels, every element of the Apéry set labels a cube in T. Thus, to prove that T is an L-shape we only have to prove that it has distinct labels.



Otherwise, we have





\mu_{1}d_{1}+\mu_{2}d_{2}+\mu_{3}d_{3}=\nu_{1}d_{1}+\nu_{2}d_{2}+\nu_{3}d_{3}

(23)


where [[\mu_{1},\mu_{2},\mu_{3}]] and [[\nu_{1},\nu_{2},\nu_{3}]] are two distinct cubes in T. Without loss of generality, suppose \mu_{2}\geq\nu_{2}.



If \mu_{1}\leq\nu_{1} and \mu_{3}\leq\nu_{3}, then





(\mu_{2}-\nu_{2})d_{2}=(\nu_{1}-\mu_{1})d_{1}+(\nu_{3}-\mu_{3})d_{3}

(24)


where all coefficients above are nonnegative, which implies (\mu_{2}-\nu_{2})\geq a_{22} (as [[\mu_{1},\mu_{2},\mu_{3}]]\neq[[\nu_{1},\nu_{2},\nu_{3}]]). If \nu_{3}\geq(\nu_{3}-\mu_{3})\geq a_{33}, we get a contradiction with [[\nu_{1},\nu_{2},\nu_{3}]]\in T, hence (\nu_{3}-\mu_{3})<a_{33}. This gives





(\mu_{2}-\nu_{2}-a_{22})d_{2}+(a_{33}-\nu_{3}+\mu_{3})d_{3}=(\nu_{1}-\mu_{1})d_{1}

(25)


where all coefficients above are nonnegative and (a_{33}-\nu_{3}+\mu_{3}) is positive. Hence (\nu_{1}-\mu_{1}) is also positive, which implies \nu_{1}\geq(\nu_{1}-\mu_{1})\geq a_{11}=b_{11}, contradicting [[\nu_{1},\nu_{2},\nu_{3}]]\in T.



If \mu_{1}>\nu_{1} and \mu_{3}\leq\nu_{3}, then





(\mu_{2}-\nu_{2})d_{2}+(\mu_{1}-\nu_{1})d_{1}=(\nu_{3}-\mu_{3})d_{3}

(26)


where all coefficients above are nonnegative and (\mu_{1}-\nu_{1}) is positive, which implies \nu_{3}\geq(\nu_{3}-\mu_{3})\geq a_{33}, contradicting [[\nu_{1},\nu_{2},\nu_{3}]]\in T.



Lastly, if \mu_{1}\leq\nu_{1} and \mu_{3}>\nu_{3}, then





(\mu_{2}-\nu_{2})d_{2}+(\mu_{3}-\nu_{3})d_{3}=(\nu_{1}-\mu_{1})d_{1}

(27)


where all coefficients above are nonnegative and (\mu_{3}-\nu_{3}) is positive, which implies \nu_{1}\geq(\nu_{1}-\mu_{1})\geq a_{11}=b_{11}, so again a contradiction with [[\nu_{1},\nu_{2},\nu_{3}]]\in T.



Analogously, we obtain that R\cap\{y\leq a_{22}\} is an L-shape.
∎




In particular, since secondary semigroups satisfy a_{11}=b_{11} and a_{22}d_{2}=a_{33}d_{3} by definition, Proposition 2.8 applies to all secondary semigroups.

3 Minimal presentations



In this section, we investigate the set of Betti elements for primary and secondary semigroups. We start with preliminary definitions and then proceed to the main results. Theorems 3.4 and 3.11 relate Betti elements to an L-shape for primary and secondary semigroups respectively. Lemmas 3.6 and 3.7 determine the sets of factorizations of Betti elements arising from (2,2)-type points in the primary case, while Lemmas 3.12 and 3.13 establish the analogous results for secondary semigroups. Finally, Lemma 3.8 characterizes the (2,2)-type points which do not correspond to Betti elements in the primary case, while Lemmas 3.14 and 3.15 do the same in the secondary case. This framework will be used in Section 4 to study minimal presentations from a geometric perspective.



Bresinsky’s work [6], which underlies the bound in Theorem 1.2, contains results closely related to those of this section (cf. [6, Theorem 3]). Our approach differs in two main respects. First, in the classification of numerical semigroups with e(S)=4, we distinguish primary and secondary semigroups, whereas Bresinsky introduced three families. Second, we relate Betti elements and minimal presentations to the Apéry set via an L-shape, allowing us to make use of its geometric structure, whereas Bresinsky’s approach was commutative algebra centered.



Let S be minimally generated by \{d_{0},d_{1},\dots,d_{k}\}.
Two elements z and z^{\prime} of \mathbb{N}^{k+1} are said to be \mathcal{R}-related if there exists a finite sequence z=z_{1},\dots,z_{p}=z^{\prime} in \mathbb{N}^{k+1} such that \text{supp}(z_{i})\cap\text{supp}(z_{i+1}) is nonempty for all i\in\{1,\dots,p-1\}. We write z\,\mathcal{R}\,z^{\prime} in this case. We refer to the equivalence classes of \varphi^{-1}(s) under the relation \mathcal{R} as the \mathcal{R}-classes.
An element s\in S is called a Betti element if there exist two elements of \varphi^{-1}(s) that are not \mathcal{R}-related (i.e. \varphi^{-1}(s) has at least two \mathcal{R}-classes). The set of all Betti elements of S is denoted \text{Betti}(S).



Let \mathcal{R}_{1},\dots,\mathcal{R}_{l} be all the \mathcal{R}-classes of \varphi^{-1}(b) for some b\in\text{Betti}(S). We choose v_{i}\in\mathcal{R}_{i} for each i\in\{1,\dots,l\}. Let \rho_{b} be a set of l-1 pairs of elements from \{v_{1},\dots,v_{l}\} such that the graph with vertices \{v_{1},\dots,v_{l}\}, having an edge between v_{i} and v_{j} if and only if (v_{i},v_{j}) or (v_{j},v_{i}) is in \rho_{b}, is connected.



Theorem 3.1.


[15]
The set \rho=\bigcup_{b\in\text{Betti}(S)}\rho_{b} is a minimal presentation of S and every minimal presentation of S is of this form.




For the rest of this section, let S=\langle d_{0},d_{1},d_{2},d_{3}\rangle be an ordered numerical semigroup with embedding dimension four. Let T=R\cap\{z\leq a_{33}\}. By Propositions 2.7 and 2.8, T is an L-shape.
Let V\subset\mathbb{Z}^{3} be a minimal set (with respect to inclusion) of points (x,y,z) such that xd_{1}+yd_{2}+zd_{3} is a nonnegative multiple of d_{0}, and such that removing from the initial collection of cubes the regions associated to the points of V yields T.
Define





U=\{\max\{x,0\}d_{1}+\max\{y,0\}d_{2}+\max\{z,0\}d_{3}\mid(x,y,z)\in V\}.



Note that U is independent of the choice of V. Furthermore, assume that every point (x,y,z)\in V such that





\max\{x,0\}d_{1}+\max\{y,0\}d_{2}+\max\{z,0\}d_{3}\notin\{(a_{00}d_{0},b_{11}d_{1},b_{22}d_{2},a_{33}d_{3})\}



is a (2,2)-type point. Such V exists by Theorem 2.4. Throughout this paper, we will always assume that V satisfies this.



Remark 3.2.


The above assumption may fail for certain choices of V. For example, if a_{00}d_{0}=a_{11}d_{1} and there exists (-\lambda_{1},\lambda_{2},\lambda_{3})\in V such that \lambda_{1}=\mu a_{11} for some \mu\in\mathbb{Z}_{>0}, then we could take (0,\lambda_{2},\lambda_{3}) as an element of V instead of (-\lambda_{1},\lambda_{2},\lambda_{3}), since \lambda_{2}d_{2}+\lambda_{3}d_{3}=(\lambda_{0}+\mu a_{00})d_{0}.

3.1 Primary case



Lemma 3.3.


Suppose that S is primary. If b\in\textup{Betti}(S) labels a cube in R, then b\in U.




Proof.


In this proof, it will be more convenient to drop the assumption that S is ordered — we only suppose that a_{ii}=b_{ii} for at least two distinct i\in\{1,2,3\} and that T=R\cap\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}.



Suppose that b labels a cube in R. Then b\in\textup{Ap}(S,d_{0}) by Theorem 2.4. Since T is an L-shape, b labels a cube in T. Consider the factorization z_{0}=(0,\lambda_{1},\lambda_{2},\lambda_{3})\in\varphi^{-1}(b) with [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in T. Let (\lambda_{0}^{\prime},\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}) be a different factorization of b. We have





(\lambda_{1}-\lambda_{1}^{\prime})d_{1}+(\lambda_{2}-\lambda_{2}^{\prime})d_{2}+(\lambda_{3}-\lambda_{3}^{\prime})d_{3}=\lambda_{0}^{\prime}d_{0}.

(28)




If all coefficients on the left-hand side are nonnegative, then \lambda_{0}^{\prime}>0, as the two factorizations are distinct. This contradicts [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in T by Lemma 2.3.



Suppose that exactly one coefficient on the left-hand side of (28) is nonnegative. Without loss of generality, suppose that every coefficient below is nonnegative.





(\lambda_{1}-\lambda_{1}^{\prime})d_{1}=\lambda_{0}^{\prime}d_{0}+(\lambda_{2}^{\prime}-\lambda_{2})d_{2}+(\lambda_{3}^{\prime}-\lambda_{3})d_{3}.

(29)


This gives \lambda_{1}\geq(\lambda_{1}-\lambda_{1}^{\prime})\geq a_{11}, which contradicts [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in T.



Suppose that exactly two coefficients on the left-hand side of (28) are nonnegative. Without loss of generality, suppose that every coefficient below is nonnegative.





(\lambda_{1}-\lambda_{1}^{\prime})d_{1}+(\lambda_{2}-\lambda_{2}^{\prime})d_{2}=\lambda_{0}^{\prime}d_{0}+(\lambda_{3}^{\prime}-\lambda_{3})d_{3}.

(30)


If \lambda_{0}^{\prime}>0, then by Lemma 2.3, we get a contradiction with [[\lambda_{1},\lambda_{2},\lambda_{3}]]\in T, hence \lambda_{0}^{\prime}=0. This means that for all z\in\varphi^{-1}(b) we have 0\notin\text{supp}(z), as (\lambda_{0}^{\prime},\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in\varphi^{-1}(b) was chosen arbitrarily.



Let z=(0,\mu_{1},\mu_{2},\mu_{3})\in\varphi^{-1}(b) be a factorization that is not \mathcal{R}-related to z_{0}. Repeating the same argument as for (\lambda_{0}^{\prime},\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime}), without loss of generality, we may assume \lambda_{1}\geq\mu_{1}, \lambda_{2}\geq\mu_{2}, \lambda_{3}<\mu_{3}. This forces \mu_{1}=\mu_{2}=\lambda_{3}=0, as otherwise z\,\mathcal{R}\,z_{0}. Hence





b=\lambda_{1}d_{1}+\lambda_{2}d_{2}=\mu_{3}d_{3}

(31)


where \lambda_{1},\lambda_{2},\mu_{3}>0 — if \lambda_{1}=0 or \lambda_{2}=0, we derive a contradiction as in (29).
If \mu_{3}>a_{33}, then





b=a_{30}d_{0}+a_{31}d_{1}+a_{32}d_{2}+(\mu_{3}-a_{33})d_{3}

(32)


where (a_{30},a_{31},a_{32},0)\in\varphi^{-1}(a_{33}d_{3}). We also have a_{30}=0, since 0\notin\text{supp}(z) for any z\in\varphi^{-1}(b). Hence \max\{a_{31},a_{32}\}>0, which implies z_{0}\,\mathcal{R}\,(0,a_{31},a_{32},\mu_{3}-a_{33})\,\mathcal{R}\,z, which is a contradiction. Thus \mu_{3}=a_{33}, and hence b=a_{33}d_{3}\in U.
∎




Theorem 3.4.


If S is primary, then \textup{Betti}(S)\subseteq U.




Proof.


Suppose that there exists an element b\in\text{Betti}(S) that is not in U.
There exists a factorization z_{0}=(0,\kappa_{1},\kappa_{2},\kappa_{3})\in\varphi^{-1}(b); otherwise, if every factorization z\in\varphi^{-1}(b) had 0\in\text{supp}(z), then all factorizations would be \mathcal{R}-related, which cannot happen for a Betti element. By Lemma 3.3, we have [[\kappa_{1},\kappa_{2},\kappa_{3}]]\notin T, hence [[\kappa_{1},\kappa_{2},\kappa_{3}]] is in the region associated to some point P\in V.




• 


If P=(-\lambda_{1},\lambda_{2},\lambda_{3}), where





\lambda_{0}d_{0}+\lambda_{1}d_{1}=\lambda_{2}d_{2}+\lambda_{3}d_{3}

(33)


with \lambda_{i}\in\mathbb{Z}_{>0}, we get





b=\lambda_{0}d_{0}+(\lambda_{1}+\delta_{1})d_{1}+\delta_{2}d_{2}+\delta_{3}d_{3}=\delta_{1}d_{1}+(\lambda_{2}+\delta_{2})d_{2}+(\lambda_{3}+\delta_{3})d_{3}

(34)


for some \delta_{i}\in\mathbb{N} with \max\{\delta_{1},\delta_{2},\delta_{3}\}>0. The factorizations z_{1}=(\lambda_{0},\lambda_{1}+\delta_{1},\delta_{2},\delta_{3}) and z_{2}=(0,\delta_{1},\lambda_{2}+\delta_{2},\lambda_{3}+\delta_{3}) have a nonempty intersection of supports, and hence they are \mathcal{R}-related. Moreover, we have 0,1,2,3\in\textup{supp}(z_{1})\cup\textup{supp}(z_{2}), so every factorization of b will be \mathcal{R}-related to z_{1} and z_{2}. This contradicts b\in\textup{Betti}(S), as it must have at least two distinct \mathcal{R}-classes.



The cases P=(\lambda_{1},-\lambda_{2},\lambda_{3}) and P=(\lambda_{1},\lambda_{2},-\lambda_{3}) follow analogously.


• 


If P=(a_{01},a_{02},a_{03}), where (0,a_{01},a_{02},a_{03})\in\varphi^{-1}(a_{00}d_{0}), we get





b=a_{00}d_{0}+\delta_{1}d_{1}+\delta_{2}d_{2}+\delta_{3}d_{3}=(a_{01}+\delta_{1})d_{1}+(a_{02}+\delta_{2})d_{2}+(a_{03}+\delta_{3})d_{3}

(35)


for some \delta_{i}\in\mathbb{N} with \max\{\delta_{1},\delta_{2},\delta_{3}\}>0. The factorizations z_{1}=(a_{00},\delta_{1},\delta_{2},\delta_{3}) and z_{2}=(0,a_{01}+\delta_{1},a_{02}+\delta_{2},a_{03}+\delta_{3}) have a nonempty intersection of supports, and hence they are \mathcal{R}-related. Because b\in\textup{Betti}(S), there exists a factorization z\in\varphi^{-1}(b) which is not \mathcal{R}-related to them.



In this case, as in the proof of Lemma 3.3, it will be more convenient to drop the assumption that S is ordered — we only suppose that a_{ii}=b_{ii} for at least two distinct i\in\{1,2,3\} and that T=R\cap\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}. This way, without loss of generality, we can suppose that \delta_{1}>0. As a_{00}>0, we have 0,1\notin\text{supp}(z).



First, suppose that z=(0,0,\mu_{2},\mu_{3}) where \mu_{2},\mu_{3}>0. This implies z_{1}=(a_{00},\delta_{1},0,0) and z_{2}=(0,a_{01}+\delta_{1},0,0).
If \mu_{2}\geq a_{22}, then





b=\mu_{2}d_{2}+\mu_{3}d_{3}=a_{20}d_{0}+a_{21}d_{1}+(\mu_{2}-a_{22})d_{2}+(\mu_{3}+a_{23})d_{3}

(36)


where (\mu_{2}-a_{22})\geq 0 and (a_{20},a_{21},0,a_{23})\in\varphi^{-1}(a_{22}d_{2}).
If \max\{a_{20},a_{21}\}>0, then z_{1}\,\mathcal{R}\,(a_{20},a_{21}, \mu_{2}-a_{22},\mu_{3}+a_{23})\,\mathcal{R}\,z (recall \mu_{3}>0), which is a contradiction. Hence a_{20}=a_{21}=0 and a_{22}d_{2}=a_{23}d_{3}, which implies a_{23}\geq a_{33}. Moreover, since (a_{20},a_{21},0,a_{23}) was chosen arbitrarily, the conclusion a_{20}=0 gives a_{22}<b_{22}. Now, we have





b=a_{30}d_{0}+a_{31}d_{1}+(\mu_{2}-a_{22}+a_{32})d_{2}+(\mu_{3}+a_{23}-a_{33})d_{3}

(37)


where all coefficients above are nonnegative (since a_{23}\geq a_{33}) and (a_{30},a_{31},a_{32},0)\in\varphi^{-1}(a_{33}d_{3}). As in (36), this yields a_{30}=0 and hence a_{33}<b_{33}. Since we also have a_{22}<b_{22}, we get a contradiction with the hypothesis.



If \mu_{3}\geq a_{33} we proceed analogously and get a contradiction, thus \mu_{2}<a_{22} and \mu_{3}<a_{33}.
Consider the cube [[0,\mu_{2},\mu_{3}]]. If it is in T, then b\in U by Lemma 3.3. Hence [[0,\mu_{2},\mu_{3}]] is in the region associated to a point Q\in V.
As \mu_{2}<a_{22} and \mu_{3}<a_{33}, we have Q=(-\nu_{1},\nu_{2},\nu_{3}), where





-\nu_{1}d_{1}+\nu_{2}d_{2}+\nu_{3}d_{3}=\nu_{0}d_{0}

(38)


\nu_{0},\nu_{2},\nu_{3}\in\mathbb{Z}_{>0}, \nu_{1}\in\mathbb{N} (possibly \nu_{1}=0), and \mu_{2}\geq\nu_{2}, \mu_{3}\geq\nu_{3}. We can write





b=\nu_{0}d_{0}+\nu_{1}d_{1}+(\mu_{2}-\nu_{2})d_{2}+(\mu_{3}-\nu_{3})d_{3}.

(39)


We have \max\{\mu_{2}-\nu_{2},\mu_{3}-\nu_{3}\}>0, as b\notin U, hence z\,\mathcal{R}\,(\nu_{0},\nu_{1},\mu_{2}-\nu_{2},\mu_{3}-\nu_{3})\,\mathcal{R}\,z_{1}, which is a contradiction.



Next, suppose that z=(0,0,\mu_{2},0).
If \mu_{2}=a_{22}, then b=a_{22}d_{2}\in U, so \mu_{2}>a_{22}. We can write





b=\mu_{2}d_{2}=a_{20}d_{0}+a_{21}d_{1}+(\mu_{2}-a_{22})d_{2}+a_{23}d_{3}.

(40)


where (a_{20},a_{21},0,a_{23})\in\varphi^{-1}(a_{22}d_{2}).
Because (\mu_{2}-a_{22})>0, we have z\,\mathcal{R}\,(a_{20},a_{21},\mu_{2}-a_{22},a_{23}). Since z is not \mathcal{R}-related to z_{1}, we have a_{20}=a_{21}=0 (recall a_{00},\delta_{1}>0). This gives the factorization (0,0,\mu_{2}-a_{22},a_{23})\in\varphi^{-1}(b) that has (\mu_{2}-a_{22}),a_{23}>0 and which is not \mathcal{R}-related to z_{1} nor z_{2}, as it is \mathcal{R}-related to z. Thus we reduce to the previously treated case z=(0,0,\mu_{2},\mu_{3}).

The case P=(-b_{21},b_{22},-b_{23}) follows analogously.

Lemma 3.9.

Lemma 3.10.

4 t(S) and \eta(S) 



This section is devoted to proving Theorem 1.4. We begin with a series of lemmas relating the type to the set V, culminating in Theorem 4.10. We then turn to results linking V to \eta(S), concluding with Corollary 4.17, from which Theorem 1.4 follows.



Let S=\langle d_{0},d_{1},d_{2},d_{3}\rangle be a numerical semigroup with embedding dimension four that is ordered. Let T, R, V, and U be as in the previous sections.



4.1 t(S) and V



A finite and nonempty subset F of the initial collection of cubes is called a cube figure if for every (a,b,c)\in\mathbb{N}^{3} with [[a,b,c]]\notin F, no cube in the region associated to (a,b,c) is in F. For a cube figure F, a cube [[a,b,c]]\in F is called a corner of F if [[a+1,b,c]],[[a,b+1,c]],[[a,b,c+1]]\notin F.



Recall from (4) that





PF(S)=\{s-d_{0}\mid s\in\textup{Ap}(S,d_{0}),s+d_{i}\notin\textup{Ap}(S,d_{0})\text{ for }i=1,2,3\}.

(84)


Thus, since R is the collection of all cubes labeled with an element of the Apéry set, PF(S) is the set of all labels of corners of R, and t(S) is the number of such distinct labels.



Lemma 4.1.

\displaystyle=\lambda_{1}d_{1}+\lambda_{2}d_{2},

(96)



\displaystyle a_{00}d_{0}+\lambda_{3}^{\prime}d_{3}
\displaystyle=\lambda_{1}^{\prime}d_{1}+\lambda_{2}^{\prime}d_{2},

(97)


where \lambda_{3},\lambda_{3}^{\prime}<a_{33} Since T=R\cap\{z\leq a_{33}\}, we have \lambda_{1},\lambda_{1}^{\prime}<b_{11}=a_{11}.



Without loss of generality, suppose \lambda_{3}\geq\lambda_{3}^{\prime}. Subtracting (97) and (96), we obtain





(\lambda_{3}-\lambda_{3}^{\prime})d_{3}+(\lambda_{1}^{\prime}-\lambda_{1})d_{1}=(\lambda_{2}-\lambda_{2}^{\prime})d_{2}

(98)


where all above coefficients are nonnegative, as otherwise we would get a contradiction with \lambda_{3}<a_{33} or \lambda_{1}<a_{11}. As (\lambda_{1},\lambda_{2},-\lambda_{3})\neq(\lambda_{1}^{\prime},\lambda_{2}^{\prime},-\lambda_{3}^{\prime}), we obtain \lambda_{2}>(\lambda_{2}-\lambda_{2}^{\prime})\geq a_{22}. We have





a_{00}d_{0}=\lambda_{1}d_{1}+(\lambda_{2}-a_{22})d_{2}+(a_{33}-\lambda_{3})d_{3}

(99)


where all above coefficients are positive. This contradicts \varphi^{-1}(a_{00}d_{0})=\{(a_{00},0,0,0),(0,a_{11},0,0)\}.
∎




Let





U_{0}=\{\max\{x,0\}d_{1}+\max\{y,0\}d_{2}+\max\{z,0\}d_{3}\mid(x,y,z)\in V^{*}\setminus\mathcal{N}\}.



Note that U_{0} is independent of the choice of V.



Lemma 4.13.


|U_{0}|=|V^{*}\setminus\mathcal{N}|.




Proof.


Suppose that there exist distinct (-\lambda_{1},\lambda_{2},\lambda_{3}) and (-\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}\setminus\mathcal{N} (where \lambda_{i}>0) such that \lambda_{2}d_{2}+\lambda_{3}d_{3}=\lambda_{2}^{\prime}d_{2}+\lambda_{3}^{\prime}d_{3}. Without loss of generality, suppose \lambda_{2}>\lambda_{2}^{\prime} and \lambda_{3}<\lambda_{3}^{\prime}. Now, as (\lambda_{3}^{\prime}-\lambda_{3})d_{3}=(\lambda_{2}-\lambda_{2}^{\prime})d_{2}>0, we obtain \lambda_{3}^{\prime}>(\lambda_{3}^{\prime}-\lambda_{3})\geq a_{33}. This contradicts (-\lambda_{1}^{\prime},\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}, since T=R\cap\{z\leq a_{33}\}.



If there exist distinct (\lambda_{1},-\lambda_{2},\lambda_{3}) and (\lambda_{1}^{\prime},-\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}\setminus\mathcal{N} (where \lambda_{i}>0) such that \lambda_{1}d_{1}+\lambda_{3}d_{3}=\lambda_{1}^{\prime}d_{1}+\lambda_{3}^{\prime}d_{3}, we proceed analogously as above and derive a contradiction.



Suppose that there exist distinct (\lambda_{1},\lambda_{2},-\lambda_{3}) and (\lambda_{1}^{\prime},\lambda_{2}^{\prime},-\lambda_{3}^{\prime})\in V^{*}\setminus\mathcal{N} (where \lambda_{i}>0) such that \lambda_{1}d_{1}+\lambda_{2}d_{2}=\lambda_{1}^{\prime}d_{1}+\lambda_{2}^{\prime}d_{2}. Without loss of generality, suppose \lambda_{1}>\lambda_{1}^{\prime} and \lambda_{2}<\lambda_{2}^{\prime}, which gives \lambda_{1}>(\lambda_{1}-\lambda_{1}^{\prime})\geq a_{11}=b_{11} (as S is ordered). This contradicts (\lambda_{1},\lambda_{2},-\lambda_{3})\in V^{*}, since T\subseteq R\subseteq\{x\leq b_{11},y\leq b_{22},z\leq b_{33}\}.



Suppose that S is primary and there exist (-\lambda_{1},\lambda_{2},\lambda_{3}) and (\lambda_{1}^{\prime},-\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}\setminus\mathcal{N} (where \lambda_{i}>0) such that \lambda_{2}d_{2}+\lambda_{3}d_{3}=\lambda_{1}^{\prime}d_{1}+\lambda_{3}^{\prime}d_{3}. Without loss of generality, suppose \lambda_{3}\geq\lambda_{3}^{\prime}, which gives \lambda_{1}^{\prime}\geq a_{11}, which contradicts (\lambda_{1}^{\prime},-\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}, since T\subseteq\{x\leq a_{11},y\leq a_{22},z\leq a_{33}\}. All other cases follow analogously.



Suppose that S is secondary and there exist (-\lambda_{1},\lambda_{2},\lambda_{3}) and (\lambda_{1}^{\prime},-\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}\setminus\mathcal{N} (where \lambda_{i}>0) such that \lambda_{2}d_{2}+\lambda_{3}d_{3}=\lambda_{1}^{\prime}d_{1}+\lambda_{3}^{\prime}d_{3}. Since (\lambda_{1}^{\prime},-\lambda_{2}^{\prime},\lambda_{3}^{\prime})\in V^{*}, we have \lambda_{1}^{\prime}<b_{11}=a_{11}. Thus we have





\lambda_{2}d_{2}=\lambda_{1}^{\prime}d_{1}+(\lambda_{3}^{\prime}-\lambda_{3})d_{3}

(100)


where (\lambda_{3}^{\prime}-\lambda_{3})\geq 0. This gives \lambda_{2}\geq a_{22}, hence





(\lambda_{2}-a_{22})d_{2}=\lambda_{1}^{\prime}d_{1}+(\lambda_{3}^{\prime}-\lambda_{3}-a_{33})d_{3}

(101)


where (\lambda_{2}-a_{22})\geq 0. Since a_{11}>\lambda_{1}^{\prime}>0, we have (\lambda_{3}^{\prime}-\lambda_{3}-a_{33})\geq 0, which gives (\lambda_{2}-a_{22})\geq a_{22}. This leads to an infinite descent, which is impossible.
All other cases follow analogously.
∎




Let \rho be a minimal presentation of S and let \rho^{*}=\{(a,b)\in\mathbb{N}^{4}\times\mathbb{N}^{4}\mid(a,b)\in\rho,|\textup{supp}(a)|=|\textup{supp}(b)|=2\}. To proceed, we require a result of Bresinsky [6].



Lemma 4.14.


[6, Corollary 2] There exists a minimal presentation \rho such that \eta(S)-|\rho^{*}|\leq 4.




Lemma 4.15.


If S is primary, then |U_{0}|+4\geq\eta(S)\geq|U_{0}|+3.




Proof.


By Lemma 2.1, and Theorems 2.4 and 3.4, we have





\textup{Betti}(S)=U_{0}\sqcup\{a_{00}d_{0},a_{11}d_{1},a_{22}d_{2},a_{33}d_{3}\}.

(102)


Lemma 2.1 tells us that (a_{00},0,0,0) is the only element in its \mathcal{R}-class. The same is true for (0,a_{11},0,0), (0,0,a_{22},0), and (0,0,0,a_{33}), so the sets on the right-hand side
of (102) are indeed disjoint.



If there exists a factorization in \bigcup_{i=0}^{3}\varphi^{-1}(a_{ii}d_{i}) that is distinct from the four canonical ones, then a_{00}d_{0},a_{11}d_{1},a_{22}d_{2},a_{33}d_{3} together contribute at least three elements to \rho by Lemma 2.1 and Theorem 3.1. Otherwise, since S is not secondary, we have a_{00}d_{0}=a_{11}d_{1}=a_{22}d_{2}=a_{33}d_{3}, which has four \mathcal{R}-classes by Lemma 2.1, so it contributes three elements to \rho by Theorem 3.1.



From Lemmas 3.6 and 3.7 we know that every element of U_{0} has exactly two \mathcal{R}-classes, so each contributes exactly one element to \rho, by Theorem 3.1. This, combined with the previous paragraph, gives \eta(S)\geq|U_{0}|+3.



Suppose, for contradiction, that \eta(S)-|U_{0}|>4. By (102), since U_{0} contributes exactly |U_{0}| elements to \rho, the elements a_{00}d_{0}, a_{11}d_{1}, a_{22}d_{2}, a_{33}d_{3} must together contribute more than 4 elements to \rho — and by Theorem 3.1, this holds for every minimal presentation \rho, since this count is determined only by the number of \mathcal{R}-classes.
By Lemma 2.1, there do not exist z_{1},z_{2}\in\varphi^{-1}(a_{ii}d_{i}) such that |\textup{supp}(z_{1})|=|\textup{supp}(z_{2})|=2 and \textup{supp}(z_{1})\cap\textup{supp}(z_{2})=\varnothing. Thus in every minimal presentation \rho, there will be more than 4 elements that are not in \rho^{*}. This gives a contradiction with Lemma 4.14, therefore \eta(S)\leq|U_{0}|+4.
∎




Lemma 4.16.


If S is secondary, then |U_{0}|+6\geq\eta(S)\geq|U_{0}|+2.




Proof.


By Lemma 2.1 and Theorems 2.4 and 3.11, we have





U_{0}\sqcup\{a_{00}d_{0},a_{22}d_{2}\}\subseteq\textup{Betti}(S)\subseteq U_{0}\cup\{a_{00}d_{0},a_{22}d_{2},b_{22}d_{2},b_{33}d_{3}\}.

(103)


From Lemmas 3.12 and 3.13 we know that every element of U_{0} has exactly two \mathcal{R}-classes, so it contributes exactly one element to \rho, by Theorem 3.1. We also have ((a_{00},0,0,0),(0,a_{11},0,0))\in\rho and ((0,0,a_{22},0),(0,0,0,a_{33}))\in\rho, hence \eta(S)\geq|U_{0}|+2.



We claim that b_{22}d_{2} and b_{33}d_{3} together contribute at most four elements to \rho. Otherwise, without loss of generality, suppose that b_{22}d_{2} contributes at least three elements to \rho, so it has at least four \mathcal{R}-classes. The only way for this to be possible is \varphi^{-1}(b_{22}d_{2})=\{(b_{20},0,0,0), (0,b_{21},0,0), (0,0,b_{22},0), (0,0,0,b_{23})\}. Note that b_{23}\geq b_{33}. However, if b_{23}>b_{33}, then (b_{30}, b_{31}, b_{32}, (b_{23}-b_{33}))\in\varphi^{-1}(b_{22}d_{2}), which is a contradiction, since b_{30},(b_{23}-b_{33})>0. Hence b_{23}=b_{33} and b_{22}d_{2}=b_{33}d_{3}. Therefore, in the current case, b_{22}d_{2} and b_{33}d_{3} together contribute at most three elements to \rho, by Theorem 3.1, since b_{22}d_{2}=b_{33}d_{3} has at most four \mathcal{R}-classes.



Therefore, by (103), we have \eta(S)\leq|U_{0}|+2+4=|U_{0}|+6.
∎




Corollary 4.17.


If S is primary, then 4t(S)+5\geq\eta(S)\geq t(S)-11. If S is secondary, then 2t(S)+9\geq\eta(S)\geq t(S)-4.




Proof.


Suppose that S is primary. The lower bound for \eta(S) follows from the chain of inequalities:





\eta(S)\geq|U_{0}|+3=|V^{*}\setminus\mathcal{N}|+3\geq|V^{*}|\geq t(S)-11

(104)


which are the result of Lemmas 4.15, 4.13, 4.11, and Theorem 4.10, respectively. Moreover, the upper bound for \eta(S) is due to the following chain of inequalities:





\eta(S)\leq|U_{0}|+4=|V^{*}\setminus\mathcal{N}|+4\leq|V^{*}|+4\leq 4t(S)+5

(105)


which are the result of Lemmas 4.15, 4.13, and Theorem 4.10, respectively.



Suppose that S is secondary. The lower bound for \eta(S) is due to the following chain of inequalities:





\eta(S)\geq|U_{0}|+2=|V^{*}\setminus\mathcal{N}|+2\geq|V^{*}|+1\geq t(S)-4

(106)


which are the result of Lemmas 4.16, 4.13, 4.12, and Theorem 4.10, respectively. Moreover, the upper bound for \eta(S) is due to the following chain of inequalities:





\eta(S)\leq|U_{0}|+6=|V^{*}\setminus\mathcal{N}|+6\leq|V^{*}|+6\leq 2t(S)+9

(107)


which are the result of Lemmas 4.16, 4.13, and Theorem 4.10, respectively.
∎




For t(S)\geq 2, the inequality 4t(S)+5\geq 2t(S)+9 holds, so Corollary 4.17 implies Theorem 1.4 in this case. Recall that t(S)=1 is equivalent to S being symmetric [11]. This allows us to use the following result to resolve the case t(S)=1.



Theorem 4.18.


[5] If S is symmetric with e(S)=4, then \eta(S)\in\{3,5\}.




Since 5\leq 9=4\cdot 1+5, this completes the proof of Theorem 1.4.





5 Closing remarks



The bounds of Theorem 1.4 can most likely be improved. To improve the bound \eta(S)\geq t(S)-11, we propose the following conjecture.



Conjecture 5.1.


If S is a numerical semigroup with e(S)=4, then \eta(S)\geq t(S)+1.




We expect that \eta(S)\geq t(S)+1 is the best possible bound, since no numerical semigroup with e(S)=4 and \eta(S)\leq t(S) is currently known. In contrast, the situation where \eta(S)=t(S)+1 is quite common among numerical semigroups with embedding dimension four. For example, S=\langle 77,85,89,131\rangle has e(S)=4, t(S)=3, and \eta(S)=4. Likewise, S=\langle 76,99,143,223\rangle has e(S)=4, t(S)=6, \eta(S)=7, and S=\langle 195,200,209,226\rangle has e(S)=4, t(S)=8, \eta(S)=9. The equation \eta(S)=t(S)+1 is also satisfied for all numerical semigroups with e(S)=3 (Theorem 1.1).



Remark 5.2.


In higher embedding dimension, the inequality \eta(S)\geq t(S)+1 is false in general, already for embedding dimension five. For example,
S=\langle 86,133,143,155,198\rangle has e(S)=5 and t(S)=\eta(S)=10. Likewise, S=\langle 161,177,196,207,225\rangle has e(S)=5, t(S)=18, \eta(S)=16, and (a more extreme example) S=\langle 6072,6307,7965,8702,9423\rangle has e(S)=5, t(S)=53, \eta(S)=40.




Remark 5.3.


The results of Section 2, together with the results of Section 3 concerning primary semigroups, appeared earlier in the preprint [7].
