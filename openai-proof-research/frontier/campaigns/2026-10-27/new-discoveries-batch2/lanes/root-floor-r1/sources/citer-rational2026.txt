1    Introduction

This work represents a companion to and natural continuation of the authors’ paper [1]
which considered the precise description of the ranges of certain generalized polynomials
depending on a positive parameter α, given by

                        fα (n) = α2 n − αbαnc ,
                                                
                                                          n ∈ N.

Generalized polynomials of this type arise in a natural way when considering dilated
floor functions and their commutators, which in turn are motivated by investigations of
digital straight lines; see, for example, [5] and the discussion in [1, Introduction]. While
several answers regarding the range of fα for rational and irrational parameters α were
provided in [1], a few questions remained open. The recent work of Dubickas [3] settled the
conjectures related to the irrational case, thus completing the description of Range(fα )
for every positive irrational parameter α.
    The goal of this paper is to complete the description of Range(fα ) for every positive
rational parameter α. With the exception of the sub-unitary rational parameter case

sult unifying all possible rational cases proved elusive. A nice insight into settling the
rational parameter case came from ChatGPT, but the formulations and arguments pre-
sented below are due to the authors. In fact, the essential tools required for the exact
characterization were already developed in [1].
    Throughout this paper, we will follow the notation used in [1]. By Z we denote
the set of integers, by N the set of positive integers, and by N0 = N ∪ {0} the set of
nonnegative integers. Given a real number x, bxc and dxe denote the floor and ceiling of
x, respectively; see [4, Chapter 3] for the history and properties of these functions. The
fractional part of x ∈ R is defined by

                                           x := x − bxc,

so that 0 ≤ x < 1. Here we opt, as in [2], for the notation x for the fractional part of
a real number, rather than the more common {x}, since braces are consistently used for
set notation; in particular, {x} denotes a singleton set.
    For integers p ≤ q, we write

                                 Jp, qK := {m ∈ Z : p ≤ m ≤ q}.

We will also use the following dilation and shift operations on a set: given a set A ⊂ R,
and given two scalars x, s ∈ R, we let
                                         
