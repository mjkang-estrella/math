                                         1     Introduction
                                         In the weighted matroid intersection problem, we are give two matroids M1 = (E, I1 ) and
                                         M2 = (E, I2 ) on a common ground set E, together with a weight function w : E →       PR>0 . The
                                         goal is to find a common independent set S ∈ I1 ∩ I2 that maximizes w(S) :=              e∈S w(e).
                                         Matroid intersection is one of the fundamental problems in combinatorial optimization and
                                         generalizes several classical optimization problems, including bipartite matching. The design
                                         of faster algorithms for matroid intersection has received considerable attention in recent years.
                                         A particularly important objective is to reduce the number of independence-oracle queries. An
                                         independence oracle for a matroid M = (E, I) takes a set S ⊆ E as input and determines
                                         whether S ∈ I.

                                         1.1    Previous Work
                                         Starting the work of Edmonds [Edm70, Edm79], a long line of research has developed increas-
                                         ingly efficient algorithms for matroid intersection with polynomial query complexity [AD71,
                                         Law75, Cun86, BCG86, FX95, SI95, LSW15, CQ16, HKK19, Ngu19, CLS+ 19, BvdBMN21, Bli21,
                                         Tu22, BMNT23, Qua24, BT25, Ter25, DG26].

                                             Unweighted Matroid Intersection. In the unweighted matroid intersection problem, the
                                         goal is to find a common independent set of maximum size. Edmonds [Edm70] developed
                                         the first polynomial-query algorithm by reduction to the matroid partitioning problem. This
                                         algorithm requires O(n4 ) independence oracle queries. More direct algorithms were given by
                                         Aigner–Dowling [AD71] and Lawler [Law75]. Lawler’s algorithm requires O(nr2 ) indepen-
                                         dence oracle queries, where r denotes the maximum cardinality of a common independent set.
                                         In 1986, Cunningham [Cun86] presented an O(nr3/2 )-independence-query algorithm by using
                                         a blocking flow approach, which is akin to the bipartite matching algorithm of Hopcroft–Karp

tion in the rank-oracle model [LSW15, CLS+ 19, Tu22, HK26]. A rank oracle returns the rank

matroid intersection, Huang–Kobayashi [HK26] also presented a deterministic Õε (n)-rank-
query (1 − ε)-approximation algorithm.

1.2     Our Result
Our contribution is to present a simple auction algorithm for weighted matroid intersection,
which yields the following result.

Theorem 1. Let ε > 0. For the weighted matroid intersection problem, there exists a deterministic
(1 − ε)-approximation algorithm using O(nε−2 log2 (n)) independence-oracle queries.
    Our algorithm is based on the auction algorithm of Huang–Kobayashi [HK26] for un-
weighted matroid intersection. The resulting algorithm is the first deterministic (1−ε)-approximation
algorithm for the weighted matroid intersection problem whose query complexity is nearly
linear in n and polynomial in 1/ε.
    Both the unweighted matroid intersection algorithms of Blikstad–Tu [BT25] and Huang–
Kobayashi [HK26] are inspired by the auction algorithm for the unweighted bipartite matching
problem by Assadi–Liu–Tarjan [ALT21]. This naturally raises the question of whether these
auction-based approaches can be extended to weighted matroid intersection while retaining
nearly-linear independence-oracle query complexity. Prior to our work, it was not known
whether either of these auction algorithms for unweighted matroid intersection could be di-
rectly extended to obtain a (1 − ε)-approximation for weighted matroid intersection using a
nearly linear number of independence-oracle queries. Furthermore, Dudeja–Grilnberger [DG26]
identified improving the dependence on ε from (1/ε)1/ε to poly(1/ε) as an interesting direction.

2.1   Notation

Basic Notation. Let R and R+ denote the sets of real numbers and non-negative real num-
bers, and let Z denote the set of integers. For a set X and an element e, we write X +e := X ∪{e}
and X −e := X \{e}. For two sets A and B, we will also write A+B := A∪B and A−B := A\B
when no confusion can arise.
   Throughout the paper, log denotes the natural logarithm.

Matroid. A pair M = (E, I) of a finite set E and a non-empty set family I ⊆ 2E is called a
matroid if the following properties are satisfied.

(Downward closure property) If S ∈ I and S ′ ⊆ S, then S ′ ∈ I.

(Augmentation property) If S, S ′ ∈ I and |S ′ | < |S|, then there exists v ∈ S \ S ′ such that
    S ′ + v ∈ I.

    A set S ⊆ E is called independent if S ∈ I and dependent otherwise. An element e is called
a loop if {e} ∈
              / I. An inclusion-wise maximal independent set is called a base of M. It is well
known that every base of M has the same size. It is also well known that, for any two bases B1
and B2 of M and any element e ∈ B1 \ B2 , there exists an element f ∈ B2 \ B1 such that both
B1 − e + f and B2 + e − f are bases of M; see e.g. [Sch03, Theorem 39.12]. This is known as
the simultaneous exchange property. An inclusion-wise minimal dependent set is called a circuit
of M.
    For a matroid M = (E, I), we define the rank function rankM : 2E → Z≥0 and the span
function spanM : 2E → 2E by

                      rankM (X) = max{|Y | | Y ⊆ X, Y ∈ I},
                      spanM (X) = {e ∈ E | rankM (X + e) = rankM (X)}

    For an independent set X ∈ I and an element e ∈ E \ X such that X + e ∈   / I, X + e contains
a unique circuit, denoted by CM (X, e), called the fundamental circuit e with respect of X.

Lemma 5 ( [HK26, Lemma 2.3]). Let M = (E, I) be a matroid and let w ∈ RE . A set S ∈ I is a
w-maximum independent set of M if and only if (i) w(e) ≤ 0 for any e ∈ E \ S with S + e ∈ I, (ii)

q-maximum base of M. Since e′ ∈   / Y , the base Z − e′ + e contains Y + e.
    We next show the “only if” part. Suppose that Y + e is contained in a q-maximum base
Z ′ of M. If e ∈ Z, then e′ = e satisfies the required conditions, because e ∈ Z \ Y and
Z − e + e = Z ∈ B. Suppose that e ∈       / Z. Then e ∈ Z ′ \ Z. By the simultaneous exchange

3.2   Algorithm Description
Our algorithm is presented in Algorithm 1. We call each iteration of the outer for-loop a round,
and we denote by X t the set X at the end of round t, where X 0 = ∅. In each round, X ∗ , π ∗ , p∗ ,
and q ∗ denote X, π, p, and q at the beginning of the round. They   stay fixed during the round,
whereas X, π, p, and q change. The number of rounds is T := 10 (ε−1 log(r1 (E)) + ε−2 ) .

    In a round, the algorithm scans each e ∈ E \X ∗ once, in an arbitrary order. If q(e) = q ∗ (e) >
0, that is, the utility of e is positive and has not changed since the beginning of the round, and
Y + e is contained in a q ∗ -maximum base of M1 (Line 6), then e is added to Y and π(e) is set
to the current price p(e) (Lines 7 and 8). Then, e is added to X. If X + e ∈        / I2 , an element
f ∈ C2 (X | e) − e minimizing π(f ) is removed from X at the same time (Lines 10–14).
    In the auction interpretation, a round proceeds as follows. Alice aims to buy a q ∗ -maximum
base of M1 . She buys an item e ∈ E \ X ∗ if its utility is positive, if the utility has not changed
since the beginning of the round, and if e and the items bought so far lie in a common q ∗ -
maximum base of M1 . The last condition says that buying e keeps this aim achievable. When
Alice buys e and X + e ∈     / I2 , Bob removes a cheapest item f ∈ X with X + e − f ∈ I2 .
