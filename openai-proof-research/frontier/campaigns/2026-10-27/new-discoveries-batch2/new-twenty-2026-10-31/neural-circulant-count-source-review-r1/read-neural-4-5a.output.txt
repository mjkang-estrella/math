517:    At the beginning of their paper, Curto and Youngs [6] discuss ring homomorphisms between two
518: neural rings. They proved that there is a 1-1 correspondence between code maps q : C → D and the ring
519: homomorphisms ϕ : RD → RC . The map q, associated with the ring homomorphism ϕ is denoted by qϕ .
520: Later, the authors classify all the neural ring homomorphisms using the following theorem:
521: 
522: Theorem 4.2. [6, Theorem 3.4] A map ϕ : RD → RC is a neural ring homomorphism if and only if qϕ
523: is a composition of the following elementary code maps:
524:     (1) Permutation
525:     (2) Adding a trivial neuron (or deleting a trivial neuron)
526:     (3) Duplication of a neuron (or deleting a neuron that is a duplicate of another)
527:     (4) Neuron projection (or deleting a not necessarily trivial neuron)
528:     (5) Inclusion (of one code into another)
529: Moreover, ϕ is a neural ring isomorphism if and only if qϕ is a composition of maps (1) − (3).

533:

535: surjective code map corresponding to a neural ring homomorphism. Then if C is convex (open convex),
536: D is also convex (open convex) with d(D) ≤ d(C)4.

538: Remark 4.4. We observe that the above theorem holds for closed convex codes too. The proof can be
539: obtained similar to the original version given by Curto and Youngs [6].

1028: Lemma 5.13. If C is a circulant code with support p = 2 then the total number of basis permutation
1029: maps present in NRE{RC } is 2n.
1030: 
1031: Proof. Let ϕ ∈ BPM{RC }. It is enough to see the restriction of ϕ to basis elements to determine the
1032: entire map. For this reason we now start counting where ϕ can map each ρi . We begin with ρ1 . As ρ1
1033: can map to ρi for any i ∈ [n], we get that ρ1 has n choices. Assume that ρ1 is mapped to ρj for some
1034: j ∈ [n]. Since x1 = ρ1 + ρ2 and ϕ(x1 ) ∈ {xi | i ∈ [n]} (For a map ϕ ∈ BPM{RC } we have that ϕ(xi ) and
1035: xi have same number of terms, leading to ϕ(xi ) ̸∈ {0, 1}). Therefore ϕ(x1 ) = ϕ(ρ1 + ρ2 ) = ρj + ϕ(ρ2 ).
1036: So, for ϕ(x1 ) ∈ {xi | i ∈ [n]}, we must have ϕ(ρ2 ) = ρj+1 or ρj−1 . Therefore ρ2 has 2 choices when ρ1 is
1037: fixed. On fixing ρ2 7→ ρj−1 we similarly get two choices for ρ3 i.e., ρ3 7→ ρj or ρj−2 . But as ϕ(ρ1 ) = ρj
1038: we cannot have ϕ(ρ3 ) = ρj . Also, ρ3 will still have 1 choice when ρ2 7→ ρj+1 . Therefore ρ3 has exactly
1039: one choice when ρ1 and ρ2 are fixed. So, in total we will have 2n choices. Hence the result.                             □
