3.3    Example: Maximizing K(G) for threshold graphs
A goal of this investigation is to determine the range of values of K(G) for threshold graphs.
While it is clear that the graph that minimizes K(G) is the complete graph (which is itself
a threshold graph), the threshold graph maximizing K(G) is not clear. Determining this
would shed light on more general extremal questions regarding K(G).
    The results in the previous sections provide us several advantages in pursuing this ex-
tremal question. Typically, calculation of Kemeny’s constant for a graph of order n requires
the computation of the eigenvalues of D −1 A, and thus has computational complexity on the
order of O(n3 ). An advantage to the formula given above is a massive reduction in complex-
ity, such that K(G) can be computed for a threshold graph of order n in O(n2 ) steps. This
allows us to run a comprehensive search for all threshold graphs to determine the construc-
tion code for the threshold graph of order n with maximum K(G). In particular, we have
the following conjecture, which has been confirmed by computer for threshold graphs of all
orders up to n = 30.

construction code of the form 0111..1100000...0001.
