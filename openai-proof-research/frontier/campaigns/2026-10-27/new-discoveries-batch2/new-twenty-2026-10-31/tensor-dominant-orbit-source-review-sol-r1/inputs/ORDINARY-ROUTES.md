326578: actual1310.6008v1 Section2.3 defines fast as equality of shortest instruction lengths, not generation by linear instructions. Source Conj1 explicitly has prime q. A linear instruction updates one coordinate by a linear form with nonzero own-coordinate coefficient. Arbitrary instructions are reversible one-coordinate functions. Merely Gaussian-eliminating an invertible matrix does not compare the shortest nonlinear program.

Route A, one-update schedules. Suppose a program updates each used coordinate at most once and its final map is linear. At each update the updated value must already equal its final linear target coordinate, because that register will never be updated again. Before this update, the current registers are linear forms in the initial registers by induction. Their joint map is invertible because the preceding instructions are permutations. The desired output is therefore a linear form in the current registers, and its own-register coefficient is nonzero because the new joint map is invertible. Replace this update by that linear instruction. This proves schedule-preserving linearity for these schedules (identity steps may be omitted). It does not handle shortest programs with repeated registers.

Route B, affine shadow, pays q=2,n≤2 only. Every binary reversible instruction with two registers is x_i←x_i+h(x_j), and every function h:F2→F2 is affine. Thus all intermediates are affine bijections. Replacing each affine instruction by its linear part gives the same final linear map, at no increased length; translations compose separately. This establishes the small case, with n1 immediate, not the all-n conjecture. For n≥3 h can depend nonlinearly on two other bits. Finite-field function identities such as x²=x mean that discarding higher-degree terms is not compatible with composition in the Boolean function algebra. Formal derivatives of chosen polynomial representatives therefore give no valid chain-rule shadow of arbitrary functions. For larger prime fields even unary permutations need not be affine.

Route C: model each program state as a reversible coordinate partition and seek a sequence of bases with the same update positions, ending at the prescribed linear map. This is exactly a schedule-preserving linear representability lemma; arbitrary nonlinear reversible coordinate partitions need not be linear subspaces. No replacement lemma was proved for repeated-register schedules, and no concrete full-scope nonlinear advantage certificate was found. Source permutation-matrix and almost-all-large-q results do not cover the missing schedules.
