# Independent ordinary audit for MathDB 375537

The finite certificate interface is sound with the conventions below. It is a routine reduction, not a solution or a significant new helper. No graph witness has been supplied or computed.

Use a fixed orientation and B = out minus in. A cycle means a connected 2-regular edge subgraph. For distinct conserved flows agreeing outside such a cycle, conservation at its vertices forces the difference to be epsilon times a single constant. This holds over Z/k as well as over Z, including composite k: the equations propagate equality, requiring no division. Thus a nonzero difference has full cycle support. Cranston's support-contained definition and Esperet's support-equals definition give the same edges between distinct states. Identical states can be ignored. No intermediate state may have a zero edge. A union of cycles, general Eulerian support, or closed walk with repeated vertices is not a single move. Fundamental cycles suffice as flow coordinates, but do NOT suffice as the adjacency list.

For k >= 2 and residues r in {1,...,k-1}^E with Br = 0 modulo k, exactly the bounded nonzero integer representatives are f = r - kx, x in {0,1}^E. Indeed the only integers in [-k+1,k-1] congruent to r_e are r_e and r_e-k. Conservation is equivalent to Bx = Br/k, including the sign. This is a bijection of the entire fiber, not an arbitrarily selected subset. Tutte guarantees nonemptiness; one checked lift per residue can replace this dependence in a finite witness. Fiber connectivity is already Esperet Lemma 5.5 (all versions); changing each edge-disjoint signed difference cycle by the appropriate sign of k keeps each coordinate equal to one of its endpoint values.

Let pi reduce every integer flow. Make Q have one vertex for every modular flow, and an edge between distinct residues exactly when some pair of their integer lifts is adjacent. An integer path projects to a Q walk after stationary steps are removed. Conversely a Q path lifts to a walk by joining the chosen incoming and outgoing representatives inside each fiber. Therefore pi induces a bijection of component sets of F_int and Q. Every nonstationary integer step projects to one modular cycle step, so Q is a spanning subgraph of F_mod. Isolated residues cause no exception: their entire fiber is one integer component. If there are no modular states, there are no integer states and both spaces are connected by source convention. A one-state modular space has a connected integer fiber. A nontrivial partition and a modular spanning tree require at least two states; vacuous partitions cannot refute the conjecture.

For a modular edge r -> s choose a traversal of its unique support C and t in {1,...,k-1} so that s-r = epsilon t modulo k on C. Every adjacent lift pair has difference epsilon delta with delta = t modulo k and |delta| <= 2k-2. An interval of length 4k-4 contains at most four members of any residue class modulo k: five would span at least 4k. The complete set is {t+jk : -2k+2 <= t+jk <= 2k-2}. It is contained in {t-2k,t-k,t,t+k}; filter by the bound. Testing only t and t-k is unsound. Delta is nonzero for this inter-fiber edge.

For each delta define A_e = {a in {0,1}: 0 < |r_e-ka+epsilon_e delta| < k} on C, and A_e = {0,1} elsewhere. Empty A_e proves impossibility. Otherwise A_e is exactly the binary interval [ell_e,u_e]. Any integral x with ell <= x <= u and Bx = b = Br/k gives adjacent lifts f and f+epsilon delta of r and s, and conversely every such lift pair gives x. No unverified assignment of the second representative is needed.

For S subset V, summing the conservation equations gives b(S) = x(out S)-x(in S). Consequently b(S) > u(out S)-ell(in S) is a sound infeasibility certificate. The stated sign is correct for out-minus-in; reversing B would reverse the necessary convention. All subsets S are needed. Complementation turns a violated lower inequality into a violated upper one because b(V)=0. For ordinary directed bounded circulation, these inequalities, ell <= u, integral bounds, and b(V)=0 are also sufficient by integral max-flow or incidence-matrix integrality. Loops contribute zero to B and to both cut sides, and are constrained independently. The refutation checker needs only the easy soundness direction, not a formalized optimizer or the sufficiency theorem.

Enumeration: choose a spanning forest T, with b = m-n+c chords. For each chord choose a residue in {1,...,k-1}. Solve the tree coordinates modulo k by deleting leaves, since each tree incidence coefficient is +1 or -1, a unit for every k. Check the final component-root equations and reject zero tree coordinates. Every modular flow has exactly these chord coordinates and conversely each surviving tuple yields exactly one flow. Hence there are at most (k-1)^b raw tuples. Isolates give zero equations; bridges necessarily get zero and leave an empty nowhere-zero space. Exhaustive enumeration of edge subsets that are connected and degree two supplies all cycles in a small simple graph. For a multigraph edges must have distinct identities, two parallel edges form a 2-cycle, and degree counts multiplicity. A vertex-list simple-cycle enumerator must not silently discard those cycles.

The original Esperet domain explicitly excludes graph loops. Cranston uses multigraphs and contracts/deletes loops but has no blanket loop convention located in the read introductory passages. Do not create a novelty claim from that ambiguity. If loops are admitted with the usual degree-two convention, each loop is a 1-cycle and its arbitrary nonzero values form an independent connected factor in each reconfiguration space. Removing loops preserves connectedness, also when the remaining space is empty. Edge-free graphs have one empty assignment (including k=1); graphs with any edge have no nonzero k=1 assignment. For k=2 any nonempty modular fiber is the entire integer space and is connected by Lemma 5.5. Disconnected underlying graphs give products of state spaces, with one-component-at-a-time moves; empty factors make the whole space empty. These observations prevent degenerate-domain proxy refutations.

A complete negative packet must give every modular flow, one integer lift per flow, a full cycle list, a verified modular spanning tree, a partition M=L disjoint-union R with both sides nonempty, and for EVERY modular edge crossing L/R, for EVERY allowed delta, either an empty coordinate or a cut violating the inequality. Check all cycles and all t for each state, even when deduplicating edges. Each lift provides an actual integer state in its side, and no integer path can cross. A missing Q edge alone is not a disconnection certificate; Q may have alternate paths. A disconnected modular graph is also insufficient.

Lemma 5.1 joins the two fibers of ANY half-modulus move by a path through other states; it need not create the original Q edge. It reduces modulo d=k/2, lifts with zeros preserved, writes states as W+dJ, and uses a positive-cycle decomposition of 2W-chi_C to connect the original residues while preserving nonzero values modulo d. This completes k=6 (Theorem 2.1). Lemma 4.1 bounds a failed direct c-lift by at least 2 ceil(k/(c-2)) high-residue cycle edges and a failed c-k-lift by at least 2 ceil(k/(k-c-2)) low-residue edges. Lemma 3.3 proves a dominance argument for discarding the two extreme shifts when deciding existence: c+k is impossible if the high-residue set is nonempty, and otherwise c already works; symmetrically c-2k is impossible if the low-residue set is nonempty, and otherwise c-k works.
