                                                                                         Abstract
                                                    A (v, k, t) packing of size b is a system of b subsets (blocks) of a v-element underlying
                                                set such that each block has k elements and every t-set is contained in at most one block.
                                                P (v, k, t) stands for the maximum possible b. A packing is called abundant if b > v. We
                                                give new estimates for P (v, k, t) around the critical range, slightly improving the Johnson
                                                bound and asymptotically determine the minimum v = v0 (k, t) when abundant packings
                                                exist.
                                                    For a graph G and a positive integer c, let χℓ (G, c) be the minimum value of k such
                                                that one can properly color the vertices of G from any assignment of lists L(v) such that
                                                |L(v)| = k for all v ∈ V (G) and |L(u) ∩ L(v)| ≤ c for all
                                                                                                        √ uv ∈ E(G). Kratochvı́l, Tuza and
                                                Voigt in 1998 asked to determine limn→∞ χℓ (Kn , c)/ cn (if exists). Using our bound on
                                                v0 (k, t), we prove that the limit exists and equals 1. Given c, we find the exact value of
                                                χℓ (Kn , c) for infinitely many n.


                                          1    Preliminaries on hypergraphs
                                          A hypergraph H = (V, E) consists of a set of vertices V = V (H) and a collection E of subsets of
                                          V called edges or blocks, i.e., multiple copies of edges are allowed. Often we take V (H) = [v],
                                          where [v] := {1, 2, 3, . . . , v}. The degree of a vertex x ∈ V , denoted by dH (x) or just by dx , is
                                          the number of edges containing the vertex x.

    A (v, k, t) packing of size b is a system of b subsets (blocks) of a v-element underlying set
such that each block has k-elements and every t-set is contained in at most one block. P (v, k, t)

is abundant.

     Theorem 1 allows to answer a question on list colorings of graphs. Recall that a list L for a
graph G is an assignment to every v ∈ V (G), a set L(v) of colors that may be used for coloring
v. Graph G is L-colorable, if there exists a proper coloring f of the vertices of G from L, i.e.,
if f (v) ∈ L(v) for all v ∈ V (G) and f (u) 6= f (v) for all uv ∈ E. The list chromatic number of
G, χℓ (G), is the least k such that G is L-colorable, whenever |L(v)| = k for all v ∈ V (G).

      Let F be the q-element finite field and let g be an element of order c in the multiplica-
tive group F\{0}. Set H = {1, g, g 2 , ..., g c−1 }, it is a c-element subgroup of F\{0}. For
(a, b), (a′ , b′ ) ∈ (F × F) we say that (a, b) ∼ (a′ , b′ ) if there exists an h ∈ H such that
(a′ , b′ ) = (ha, hb). This is an equivalence relation with {(0, 0)} being a 1-element class. Each
other equivalence class is a collection of c elements in (F×F)\{(0, 0)}. So there are 1+(q 2 −1)/c
equivalence classes. The equivalence class containing (a, b) is denoted by ha, bi. These equiva-
lence classes form the vertex set V of the packing P.

ax + by ∈ H implies (h′ a)x + (h′ b)y ∈ H, for all h′ ∈ H. Hence Lha, bi is a well-defined subset
of V . The next statement is a consequence of basic linear algebra.

Proof. The complete graph Kn is L-colorable if and only if the set of lists {L(v) : v ∈ [n]}
satisfy Hall’s condition (1). (This observation is due to Vizing [10].) A (k, c)-list corresponds
to a (c + 1)-packing of k-sets. So χℓ (Kn , c) > k if and only if there is an abundant (v, k, c + 1)
packing with v ≤ n. Hence

                  χℓ (Kn , c) = q + 1 ⇐⇒ v0 (q, c + 1) < n ≤ v0 (q + 1, c + 1).                 (8)

    To make (8) more clear, let us explain. If v0 (q, c + 1) < n, then there exists a (v, q, c + 1)
packing P of size v + 1 ≤ n. Assign the members of P to the first v + 1 vertices of Kn and
assign completely disjoint q-sets to the rest of the vertices. This assignment does not satisfy
Hall’s condition, so we obtain χℓ (Kn , c) > q. On the other hand, if n ≤ v0 (q + 1, c+ 1) then any
(q +1, c)-list assignment L of Kn is a (c+1)-packing of (q +1)-sets of size at most v0 (q +1, c+1).
So neither {L(v) : v ∈ [n]} is abundant, nor any part of it is abundant. Therefore, it satisfies
Hall’s condition and thus implying Kn is L-colorable.
    Finally, Theorem 6 is now a corollary of Theorem 1, (5), and (8).

    For a fixed c ≥ 1, one might be interested in knowing what is the maximum value of
χℓ (G, c) over all n-vertex graphs G. Note that if H is an induced subgraph of G, then
χℓ (H, c) ≤ χℓ (G, c), but this may not hold true for non-induced subgraphs. We have the
following conjecture.
Conjecture 7. If c, n ≥ 1 and G is an n-vertex graph, then χℓ (G, c) ≤ χℓ (Kn , c).
