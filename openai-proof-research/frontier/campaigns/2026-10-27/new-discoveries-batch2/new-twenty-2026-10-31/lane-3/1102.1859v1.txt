 Abstract 
    
 Let  G = ( V , E ) G=\left(V,E\right) . A set  S ⊆ V S\subseteq V  is  independent  if
no two vertices from  S S  are adjacent, and by  Ind ⁡ ( G ) \mathrm{Ind}(G)  we mean the
set of all independent sets of  G G . The number  d ⁡ ( X ) = d\left(X\right)= 
 | X | − | N ⁡ ( X ) | \left|X\right|-\left|N(X)\right|  is the
 difference  of  X ⊆ V X\subseteq V , and  A ∈ Ind ⁡ ( G ) A\in\mathrm{Ind}(G)  is
 critical  if 
    
 

 
 
 d ⁡ ( A ) = max ⁡ { d ⁡ ( I ) : I ∈ Ind ⁡ ( G ) } ​   [ 7 ] . d(A)=\max\{d\left(I\right):I\in\mathrm{Ind}(G)\}\text{ \cite[cite]{[\@@bibref{}{Zhang}{}{}]}}. 
 
 
    
 Let us recall the following definitions: 
    
 

 
 
 ker ( G ) = ∩ { S : S  is a critical independent
set }   [ 5 ] , \mathrm{\ker}(G)=\cap\left\{S:S\text{{ is a critical independent
set}}\right\}\text{ \cite[cite]{[\@@bibref{}{Levman2011a}{}{}]},} 
 
 
    
 

 
 
 core ( G ) = ∩ { S : S  is a maximum
independent set }   [ 4 ] . \mathrm{core}\left(G\right)=\cap\left\{S:S\text{{ is a maximum
independent set}}\right\}\text{ \cite[cite]{[\@@bibref{}{LevMan2002a}{}{}]}}. 
 
 
    
 Recently, it was established that   ker ⁡ ( G ) ⊆ core ⁡ ( G ) \mathrm{\ker}(G)\subseteq\mathrm{core}(G)  is true for every graph  [ 5 ] , while the corresponding
equality holds for bipartite graphs  [ 6 ] . 
    
 In this paper we present various structural properties of  ker ⁡ ( G ) \mathrm{\ker}(G) .
The main finding claims that 
    
 

 
 
 ker ( G ) = ∪ { S 0 : S 0  is an inclusion minimal
independent set with  d ( S 0 ) > 0 } . \mathrm{\ker}(G)=\cup\left\{S_{0}:S_{0}\text{ is an inclusion minimal
independent set with }d\left(S_{0}\right)>0\right\}. 
 
 
    
 . 
    
 Keywords:  independent set, critical set, ker, core, matching 
  
 
 
 1  Introduction 

 
 Throughout this paper  G = ( V , E ) G=(V,E)  is a simple (i.e., a finite, undirected,
loopless and without multiple edges) graph with vertex set  V = V ⁡ ( G ) V=V(G)  and edge
set  E = E ⁡ ( G ) E=E(G) . If  X ⊆ V X\subseteq V , then  G ⁡ [ X ] G[X]  is the subgraph of  G G  spanned by
 X X . By  G − W G-W  we mean either the subgraph  G ⁡ [ V − W ] G[V-W] , if  W ⊆ V ⁡ ( G ) W\subseteq V(G) , or
the partial subgraph  H = ( V , E − W ) H=(V,E-W)  of  G G , for  W ⊆ E ⁡ ( G ) W\subseteq E(G) . In either
case, we use  G − w G-w , whenever  W W   = { w } =\{w\} . 
 
 
 The  neighborhood  of a vertex  v ∈ V v\in V  is the set  N ( v ) = { w : w ∈ V N(v)=\{w:w\in V 
  and   v w ∈ E } vw\in E\} , while the  closed neighborhood  of  v ∈ V v\in V 
is  N ⁡ [ v ] = N ⁡ ( v ) ∪ { v } N[v]=N(v)\cup\{v\} ; in order to avoid ambiguity, we use also  N G ​ ( v ) N_{G}(v) 
instead of  N ⁡ ( v ) N(v) . The  neighborhood  of  A ⊆ V A\subseteq V  is 
 denoted by  N ⁡ ( A ) = N G ​ ( A ) = { v ∈ V : N ⁡ ( v ) ∩ A ≠ ∅ } N(A)=N_{G}(A)=\{v\in V:N(v)\cap A\neq\emptyset\} , and
 N ⁡ [ A ] = N ⁡ ( A ) ∪ A N[A]=N(A)\cup A . 
 
 
 A set  S ⊆ V ⁡ ( G ) S\subseteq V(G)  is  independent  if no two vertices from  S S 
are adjacent, and by  Ind ⁡ ( G ) \mathrm{Ind}(G)  we mean the set of all the independent
sets of  G G . 
 
 
 An independent set of maximum size will be referred to as a  maximum
independent set  of  G G , and the  independence number  of  G G  is
 α ⁡ ( G ) = max ⁡ { | S | : S ∈ Ind ⁡ ( G ) } \alpha(G)=\max\{\left|S\right|:S\in\mathrm{Ind}(G)\} . Let
 Ω ⁡ ( G ) \Omega(G)  denote the family of all maximum independent sets, and
 core ⁡ ( G ) = ∩ { S : S ∈ Ω ⁡ ( G ) } \mathrm{core}(G)=\cap\{S:S\in\Omega(G)\}   [ 4 ] . 
 
 
 A  matching  is a set of non-incident edges of  G G ; a matching of
maximum cardinality is a  maximum matching , and its size is denoted by
 μ ⁡ ( G ) \mu(G) . 
 
 
 The number  d ⁡ ( X ) = | X | − | N ⁡ ( X ) | d(X)=\left|X\right|-\left|N(X)\right| ,
 X ⊆ V ⁡ ( G ) X\subseteq V(G) , is called the  difference  of the set  X X . The
number  d c ​ ( G ) = max ⁡ { d ⁡ ( X ) : X ⊆ V } d_{c}(G)=\max\{d(X):X\subseteq V\}  is called the  critical
difference  of  G G , and a set  U ⊆ V ⁡ ( G ) U\subseteq V(G)  is  critical  if
 d ​ ( U ) = d c ​ ( G ) d(U)=d_{c}(G)   [ 7 ] . The number  i ​ d c ​ ( G ) = max ⁡ { d ⁡ ( I ) : I ∈ Ind ⁡ ( G ) } id_{c}(G)=\max\{d(I):I\in\mathrm{Ind}(G)\}  is called the  critical independence difference  of
 G G . If  A ⊆ V ⁡ ( G ) A\subseteq V(G)  is independent and  d ⁡ ( A ) = i ​ d c ​ ( G ) d(A)=id_{c}(G) , then  A A  is
called  critical independent  [ 7 ] . Clearly,  d c ​ ( G ) ≥ i ​ d c ​ ( G ) d_{c}(G)\geq id_{c}(G)  is true for every graph  G G . 
 
 
 Theorem 1.1 
 
 [ 7 ]  The equality  d c ​ ( G ) d_{c}(G)   = i ​ d c ​ ( G ) =id_{c}(G)  holds for
every graph  G G .

{is a critical independent set}}\right\} . It is known that
  ker ⁡ ( G ) ⊆ core ⁡ ( G ) \mathrm{\ker}(G)\subseteq\mathrm{core}(G)  is true for every graph

 It is easy to see that all pendant vertices are included in every maximum
critical independent set. It is known that the problem of finding a critical
independent set is polynomially solvable  [ 1 ,  7 ] . 
 
 
 Theorem 1.2 
 
 For a graph  G = ( V , E ) G=(V,E) , the following assertions are true: 
 
 
 (i)   [ 5 ]  the function  d d  is supermodular, i.e., 
 

 
 
 d ⁡ ( A ∪ B ) + d ⁡ ( A ∩ B ) ≥ d ⁡ ( A ) + d ⁡ ( B ) ​  for every  ​ A , B ⊆ V ; d(A\cup B)+d(A\cap B)\geq d(A)+d(B)\text{ for every }A,B\subseteq V; 
 
 
 
 
 (ii)   [ 5 ]   G G  has a unique minimal critical independent
set, namely,  ker ⁡ ( G ) \mathrm{\ker}(G) . 
 
 
 (iii)   [ 3 ]  there is a matching from  N ⁡ ( S ) N(S)  into  S S , for every
critical independent set  S S . 
 
 
 
 In this paper we characterize  ker ⁡ ( G ) \mathrm{\ker}(G) . In addition, a number of
properties of  ker ⁡ ( G ) \mathrm{\ker}(G)  are presented as well.

critical difference. For instance,  d c ​ ( G − v 1 ) = d c ​ ( G ) − 1 d_{c}\left(G-v_{1}\right)=d_{c}\left(G\right)-1 ,  d c ​ ( G − v 13 ) = d c ​ ( G ) d_{c}\left(G-v_{13}\right)=d_{c}\left(G\right) , while
 d c ​ ( G − v 3 ) = d c ​ ( G ) + 1 d_{c}\left(G-v_{3}\right)=d_{c}\left(G\right)+1 , where  G G  is
depicted in Figure  1 .

 Proof.   (i)  Let  v ∈ V v\in V  and  H = G − v H=G-v .
