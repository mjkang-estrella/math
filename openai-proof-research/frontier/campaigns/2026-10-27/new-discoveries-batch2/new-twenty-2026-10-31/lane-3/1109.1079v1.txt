 Abstract 
    
 To study how balanced or unbalanced a maximal intersecting family  ℱ ⊆ ( [ n ] r ) {\mathcal{F}}\subseteq\binom{[n]}{r}  is we consider the ratio  ℛ ⁡ ( ℱ ) = Δ ⁡ ( ℱ ) δ ⁡ ( ℱ ) {\mathcal{R}}({\mathcal{F}})=\frac{\Delta({\mathcal{F}})}{\delta({\mathcal{F}})}  of its maximum and minimum degree. We determine the order of magnitude of the function  m ⁡ ( n , r ) m(n,r) , the minimum possible value of  ℛ ⁡ ( ℱ ) {\mathcal{R}}({\mathcal{F}}) , and establish some lower and upper bounds on the function  M ⁡ ( n , r ) M(n,r) , the maximum possible value of  ℛ ⁡ ( ℱ ) {\mathcal{R}}({\mathcal{F}}) . To obtain constructions that show the bounds on  m ⁡ ( n , r ) m(n,r)  we use a theorem of Blokhuis on the minimum size of a non-trivial blocking set in projective planes. 
  
 
 
 Keywords : Intersecting families, maximum and minimum degree, blocking sets 
 
 
 AMS subject classification : 05D05, 05B25 
 
 
 1  Introduction 

 
 A family  ℱ {\mathcal{F}}  of sets is said to be intersecting if  F 1 ∩ F 2 ≠ ∅ F_{1}\cap F_{2}\neq\emptyset  holds for any  F 1 , F 2 ∈ ℱ F_{1},F_{2}\in{\mathcal{F}} . In their
seminal paper, Erdős, Ko and Rado showed  [ 3 ]  that if  ℱ {\mathcal{F}}  is an intersecting family of  r r -subsets of an  n n -element set  X X  (we denote this by  ℱ ⊆ ( X r ) {\mathcal{F}}\subseteq\binom{X}{r} ), then  | ℱ | ≤ ( n − 1 r − 1 ) |{\mathcal{F}}|\leq\binom{n-1}{r-1}  provided that  2 ​ r ≤ n 2r\leq n . Lots of generalizations of the above theorem have been considered ever since and lots of researchers have been interested in describing how intersecting families may look like. One of the quantities concerning intersecting families that has been studied  [ 2 ,  4 ]  is the unbalance  𝒰 ⁡ ( ℱ ) = | ℱ | − Δ ⁡ ( ℱ ) {\mathcal{U}}({\mathcal{F}})=|{\mathcal{F}}|-\Delta({\mathcal{F}})  where  Δ ⁡ ( ℱ ) \Delta({\mathcal{F}})  denotes the maximum degree in  ℱ {\mathcal{F}} . In this paper we define another notion to measure the balancedness or unbalancedness of  ℱ {\mathcal{F}} : if  δ ⁡ ( ℱ ) \delta({\mathcal{F}})  denotes the minimum degree in  ℱ {\mathcal{F}} , then our aim is to determine how small and how large  ℛ ⁡ ( ℱ ) = Δ ⁡ ( ℱ ) δ ⁡ ( ℱ ) {\mathcal{R}}({\mathcal{F}})=\frac{\Delta({\mathcal{F}})}{\delta({\mathcal{F}})}  can be. To avoid  δ ⁡ ( ℱ ) = 0 \delta({\mathcal{F}})=0  we will always assume that  ∪ ℱ = X \cup{\mathcal{F}}=X . Also, as by considering appropriate subfamilies one could modify the value  ℛ ⁡ ( ℱ ) {\mathcal{R}}({\mathcal{F}})  easily, we will restrict our attention to  maximal  intersecting families, i.e. families with the property  G ∈ ( X r ) ∖ ℱ ⇒ ∃ F ∈ ℱ ​ F ∩ G = ∅ G\in\binom{X}{r}\setminus{\mathcal{F}}\Rightarrow\exists F\in{\mathcal{F}}\hskip 5.69046ptF\cap G=\emptyset . For sake of simplicity we will also assume that the underlying set  X X  of our families is  [ n ] = { 1 , 2 , … , n } [n]=\{1,2,...,n\} . 
 
 
 With the above notation and motivation we define our two main functions as follows: 
 

 
 
 M ⁡ ( n , r ) = max ⁡ { ℛ ⁡ ( ℱ ) : ℱ ⊆ ( [ n ] r ) ​ is maximal intersecting with ∪ ℱ = [ n ] } , M(n,r)=\max\left\{{\mathcal{R}}({\mathcal{F}}):\hskip 5.69046pt{\mathcal{F}}\subseteq\binom{[n]}{r}\text{is maximal intersecting with}\ \cup{\mathcal{F}}=[n]\right\}, 
 
 
 

 
 
 m ⁡ ( n , r ) = min ⁡ { ℛ ⁡ ( ℱ ) : ℱ ⊆ ( [ n ] r ) ​ is maximal intersecting with ∪ ℱ = [ n ] } . m(n,r)=\min\left\{{\mathcal{R}}({\mathcal{F}}):\hskip 5.69046pt{\mathcal{F}}\subseteq\binom{[n]}{r}\text{is maximal intersecting with}\ \cup{\mathcal{F}}=[n]\right\}. 
 
 
 The family giving the extremal size in the theorem of Erdős, Ko and Rado seems to be a natural candidate for
achieving the value of  M ⁡ ( n , r ) M(n,r) . In fact, most families  ℱ {\mathcal{F}}  that occur in the literature have  ℛ ⁡ ( ℱ ) = Θ ⁡ ( n r ) {\mathcal{R}}({\mathcal{F}})=\Theta(\frac{n}{r}) . In Section  2  we will prove the following theorems showing that both  M ⁡ ( n , r ) M(n,r)  and  m ⁡ ( n , r ) m(n,r)  have different order of magnitude. 
 
 
 Theorem 1.1 . 
 
 (i)  For any values of  n n  and  r r , we have  M ⁡ ( n , r ) ≤ n + r r M(n,r)\leq n+r^{r} . In particular, if  r < log ⁡ n log ⁡ log ⁡ n r<\frac{\log n}{\log\log n} , then  M ⁡ ( n , r ) ≤ ( 1 − o ⁡ ( 1 ) ) ​ n M(n,r)\leq(1-o(1))n  holds, 
 
 
 (ii)  if  2 ​ r + 2 < n 2r+2<n , then 
 

 
 
 M ⁡ ( n , r ) ≥ n − 2 ​ r + 3 − n − 2 ​ r + 2 ( 2 ​ r − 3 r − 2 ) M(n,r)\geq n-2r+3-\frac{n-2r+2}{\binom{2r-3}{r-2}} 
 
 
 holds, in particular if  ω ⁡ ( 1 ) = r < log ⁡ n log ⁡ log ⁡ n \omega(1)=r<\frac{\log n}{\log\log n} , then
we obtain  M ⁡ ( n , r ) ∼ n M(n,r)\sim n . 
 
 
 
 At first sight, the bound  r r r^{r}  seems to be very weak, but we will show in Section  3  that it cannot be strengthened too much in general. 
 
 
 A trivial lower bound on  m ⁡ ( n , r ) m(n,r)  is 1. The next theorem states that  n r 2 \frac{n}{r^{2}}  is another general lower and we construct families showing that this is the order of magnitude of  m ⁡ ( n , r ) m(n,r)  as long as  r = O ⁡ ( n 1 / 2 ) r=O(n^{1/2}) . For larger values of  r r  we obtain regular maximal families showing the tightness of the trivial lower bound. 
 
 
 Theorem 1.2 . 
 
 (i)  For any  n n  and  r r , the inequality  m ⁡ ( n , r ) ≥ n r 2 m(n,r)\geq\frac{n}{r^{2}}  holds, 
 
 
 (ii)  if  r ≤ n 1 / 2 r\leq n^{1/2} , then  m ⁡ ( n , r ) = Θ ⁡ ( n r 2 ) m(n,r)=\Theta(\frac{n}{r^{2}})  holds, 
 
 
 (iii)  if  ω ⁡ ( n 1 / 2 ) = r = o ⁡ ( n ) \omega(n^{1/2})=r=o(n)  and  r ⁡ ( n ) / n r(n)/n  is monotone, then there exist infinitely many values  n ′ n^{\prime}  and  r ′ = r ′ ​ ( n ′ ) r^{\prime}=r^{\prime}(n^{\prime})  such that  m ⁡ ( n ′ , r ′ ​ ( n ′ ) ) = 1 m(n^{\prime},r^{\prime}(n^{\prime}))=1  and  r ∼ r ′ r\sim r^{\prime}  holds. 
 
 
 
 
 2  Proofs 

 
 In this section we prove Theorem  1.1  and Theorem  1.2 . 
 
 
 Proof of Theorem  1.1 . 
 
 To prove  (i) , let us consider a maximal intersecting family  ℱ ⊆ ( [ n ] r ) {\mathcal{F}}\subseteq\binom{[n]}{r} . Let us partition  ℱ {\mathcal{F}}  into two subfamilies  ℱ 1 {\mathcal{F}}_{1}  and  ℱ 2 {\mathcal{F}}_{2}  where  ℱ 1 := { F ∈ ℱ : ∃ x ∈ F ​ such that ​ F ∖ { x } ∩ F ′ ≠ ∅ ​ for all ​ F ′ ∈ ℱ } {\mathcal{F}}_{1}:=\{F\in{\mathcal{F}}:\exists x\in F\hskip 5.69046pt\text{such that}\ F\setminus\{x\}\cap F^{\prime}\neq\emptyset\hskip 5.69046pt\text{for all}\ F^{\prime}\in{\mathcal{F}}\}  and  ℱ 2 = ℱ ∖ ℱ 1 {\mathcal{F}}_{2}={\mathcal{F}}\setminus{\mathcal{F}}_{1} . 
 
 
 Claim 2.1 . 
 
 | ℱ 2 | ≤ r r |{\mathcal{F}}_{2}|\leq r^{r} . 
 
 
 
 Proof of Claim.

Thus  d j ≤ r ​ d j + 1 d_{j}\leq rd_{j+1}  holds. Since  d r = 1 d_{r}=1  and  | ℱ 2 | ≤ r ​ d 1 |{\mathcal{F}}_{2}|\leq rd_{1} , the claim follows.
∎ 
 
 
 
 Let  τ \tau  denote the covering number of  ℱ {\mathcal{F}} , i.e. the minimum size of a set meeting all sets of  ℱ {\mathcal{F}} . Clearly, if  τ = r \tau=r , then  ℱ 1 = ∅ {\mathcal{F}}_{1}=\emptyset  and thus by Claim  2.1   | ℱ | ≤ r r |{\mathcal{F}}|\leq r^{r}  and  ℛ ⁡ ( ℱ ) ≤ r r {\mathcal{R}}({\mathcal{F}})\leq r^{r} . 
 
 
 Assume  τ < r \tau<r . We will show a roughly  n n  to 1 mapping  f f  from  ℱ 1 {\mathcal{F}}_{1}  to  ℱ m ​ i ​ n {\mathcal{F}}_{min} , the subfamily containing one fixed vertex  y y  of minimum degree. For any  F ∈ ℱ 1 F\in{\mathcal{F}}_{1}  let  g ⁡ ( F ) g(F)  be an element of  F F  so that  F ∖ { g ⁡ ( F ) } ∩ F ′ ≠ ∅ F\setminus\{g(F)\}\cap F^{\prime}\neq\emptyset  for all  F ′ ∈ ℱ F^{\prime}\in{\mathcal{F}}  (such an element exists by definition of  ℱ 1 {\mathcal{F}}_{1} ). Let us define  f ⁡ ( F ) = F f(F)=F  if  y ∈ F y\in F  and  f ⁡ ( F ) = F ∖ { g ⁡ ( F ) } ∪ y f(F)=F\setminus\{g(F)\}\cup y  if  y ∉ F y\notin F . Note that  f ⁡ ( F ) ∈ ℱ f(F)\in{\mathcal{F}}  as already  F ∖ { g ⁡ ( F ) } F\setminus\{g(F)\}  meets all sets in  ℱ {\mathcal{F}}  and by assumption  ℱ {\mathcal{F}}  is a maximal intersecting family. Observe that at most  n − r + 1 n-r+1  sets can be mapped to the same set  G G  as all such sets should contain  G ∖ { y } G\setminus\{y\} . This concludes the proof of  (i)  as  ℛ ⁡ ( ℱ ) ≤ ℛ ⁡ ( ℱ 1 ) + | ℱ 2 | {\mathcal{R}}({\mathcal{F}})\leq{\mathcal{R}}({\mathcal{F}}_{1})+|{\mathcal{F}}_{2}| . 
 
 
 To prove  (ii)  we need to show a construction. Let us write  S = [ 2 , 2 ​ r − 2 ] S=[2,2r-2]  and  S 0 = [ 2 , r − 1 ] S_{0}=[2,r-1]  and define 
 

 
 
 ℱ 1 = { { 1 } ∪ G : G ∈ ( S r − 1 ) } , ℱ 2 = { { 1 , i } ∪ H : 2 r − 1 ≤ i ≤ n , H ∈ ( S r − 2 ) ∖ S 0 } , {\mathcal{F}}_{1}=\left\{\{1\}\cup G:G\in\binom{S}{r-1}\right\},\hskip 8.5359pt{\mathcal{F}}_{2}=\left\{\{1,i\}\cup H:2r-1\leq i\leq n,H\in\binom{S}{r-2}\setminus S_{0}\right\}, 
 
 
 

 
 
 ℱ 3 = ( S r ) , ℱ 4 = { ( S ∖ S 0 ) ∪ { i } : 2 r − 1 ≤ i ≤ n } , ℱ = ∪ j = 1 4 ℱ j . {\mathcal{F}}_{3}=\binom{S}{r},\hskip 8.5359pt{\mathcal{F}}_{4}=\{(S\setminus S_{0})\cup\{i\}:2r-1\leq i\leq n\},\hskip 8.5359pt{\mathcal{F}}=\cup_{j=1}^{4}{\mathcal{F}}_{j}. 
 
 
 
 
 Claim 2.2 . 
 
 The family  ℱ {\mathcal{F}}  is maximal intersecting. 
 
 
 
 Proof of Claim. 
 
 ℱ {\mathcal{F}}  is clearly intersecting as all of its sets, except those coming from  ℱ 2 {\mathcal{F}}_{2} , meet  S S  in at least  r − 1 r-1  elements. A set  F 2 F_{2}  from  ℱ 2 {\mathcal{F}}_{2}  meets any other from  ℱ 1 ∪ ℱ 2 {\mathcal{F}}_{1}\cup{\mathcal{F}}_{2}  as they both contain  1 1 , a set from  ℱ 3 {\mathcal{F}}_{3}  because of the pigeon-hole principle, and a set from  ℱ 4 {\mathcal{F}}_{4}  as by definition  F 2 ∩ S ≠ S 0 F_{2}\cap S\neq S_{0} . 
 
 
 To prove the maximality of  ℱ {\mathcal{F}}  let us consider a set  T ∉ ℱ T\notin{\mathcal{F}} . If  | T ∩ S | < r − 2 |T\cap S|<r-2 , then any  r r -subset of  S ∖ T S\setminus T  is in  ℱ {\mathcal{F}}  and thus  T T  cannot be added to  ℱ {\mathcal{F}} . ∎ 
 
 
 
 All we have to observe is that in  ℱ {\mathcal{F}}  the degree of 1 is  ( 2 ​ r − 3 r − 1 ) + ( ( 2 ​ r − 3 r − 2 ) − 1 ) ​ ( n − 2 ​ r + 2 ) \binom{2r-3}{r-1}+(\binom{2r-3}{r-2}-1)(n-2r+2)  and the degree of  i i  for any  2 ​ r − 1 ≤ i ≤ n 2r-1\leq i\leq n  is  ( 2 ​ r − 3 r − 2 ) \binom{2r-3}{r-2} .
∎ 
 
 
 
 Note that the proof of Theorem  1.1   (i)  gives an upper bound  M ⁡ ( n , r ) ≤ n + r r M(n,r)\leq n+r^{r}  for any value of  r r  and  n n . 
 
 
 Conjecture 2.3 . 
 
 If  r = o ⁡ ( n ) r=o(n)  holds, then the order of magnitude of  M ⁡ ( n , r ) M(n,r)  is  Θ ⁡ ( n ) \Theta(n) . 
 
 
 
 Now we turn our attention to the function  m ⁡ ( n , r ) m(n,r) . In the proof of Theorem  1.2  we will use the following theorem by Blokhuis on blocking sets of projective planes (for a short survey on the topic see  [ 6 ] ). 
 
 
 Theorem 2.4   (Blokhuis,  [ 1 ] ) . 
 
 Let  Q Q  be a projective plane of order  q q  and  B B  be a blocking set (a set that meets all lines of the projective plane) of size less than  3 2 ​ ( q + 1 ) \frac{3}{2}(q+1) . If  q q  is prime, then  B B  contains a line of the projective plane. 
 
 
 
 We will also need the following strengthening of Chebyshev’s theorem. 
 
 
 Theorem 2.5   (Nagura,  [ 5 ] ) . 
 
 For every integer  n ≥ 25 n\geq 25  there exists a prime  p p  with  n ≤ p ≤ ( 1 + 1 / 5 ) ​ n n\leq p\leq(1+1/5)n . 
 
 
 
 Proof of Theorem  1.2 . 
 
 To prove  (i)  we make the following two easy observations: for any intersecting family  ℱ {\mathcal{F}}  we have  Δ ⁡ ( ℱ ) ≥ | ℱ | / r \Delta({\mathcal{F}})\geq|{\mathcal{F}}|/r  as for any set  F ∈ ℱ F\in{\mathcal{F}}  the inequality  ∑ x ∈ F d ⁡ ( x ) ≥ | ℱ | \sum_{x\in F}d(x)\geq|{\mathcal{F}}|  holds. Also, the average degree in  ℱ {\mathcal{F}}  equals  r ​ | ℱ | n \frac{r|{\mathcal{F}}|}{n} . As the average degree is at least as large as the minimum degree, we obtain 
 

 
 
 ℛ ⁡ ( ℱ ) = Δ ⁡ ( ℱ ) δ ⁡ ( ℱ ) ≥ | ℱ | r r ​ | ℱ | n = n r 2 . {\mathcal{R}}({\mathcal{F}})=\frac{\Delta({\mathcal{F}})}{\delta({\mathcal{F}})}\geq\frac{\frac{|{\mathcal{F}}|}{r}}{\frac{r|{\mathcal{F}}|}{n}}=\frac{n}{r^{2}}. 
 
 
 Note that the proof does not use the fact that  ℱ {\mathcal{F}}  is maximal. 
 
 
 To prove  (ii)  and  (iii)  we need constructions. Suppose first that  r ≤ n 1 / 2 r\leq n^{1/2}  holds. By Theorem  2.5  we can pick a prime  p p  such that  2 3 ​ r < p < 2 3 ​ ( 1 + 1 5 ) ​ r = 4 5 ​ r \frac{2}{3}r<p<\frac{2}{3}(1+\frac{1}{5})r=\frac{4}{5}r . Let  P P  denote a projective plane of order  p p  with vertex set  [ p 2 + p + 1 ] [p^{2}+p+1] . Let us define the following maximal intersecting family

 Note that  ℱ n , r , p {\mathcal{F}}_{n,r,p}  is intersecting as any two of its sets intersect as they both contain lines of a projective plane and

 F l ⊃ l F_{l}\supset l  such that  F l ∩ G = ∅ F_{l}\cap G=\emptyset  holds. As every vertex is contained in  p + 1 p+1  lines of  P P  we have that  d ⁡ ( x ) = ( p + 1 ) ​ ( n − p − 1 r − p − 1 ) + p 2 ​ ( n − p − 2 r − p − 2 ) d(x)=(p+1)\binom{n-p-1}{r-p-1}+p^{2}\binom{n-p-2}{r-p-2}  if  x ∈ [ p 2 + p + 1 ] x\in[p^{2}+p+1] , while for any  y ∈ [ p 2 + p + 2 , n ] y\in[p^{2}+p+2,n]  we have  d ⁡ ( y ) = ( p 2 + p + 1 ) ​ ( n − p − 2 r − p − 2 ) d(y)=(p^{2}+p+1)\binom{n-p-2}{r-p-2} . Therefore we obtain 
 

 
 
 ℛ ⁡ ( ℱ n , p , r ) = p 2 ​ ( n − p − 2 r − p − 2 ) + ( p + 1 ) ​ ( n − p − 1 r − p − 1 ) ( p 2 + p + 1 ) ​ ( n − p − 2 r − p − 2 ) ≤ 1 + 1 p + 1 ⋅ n − p − 1 r − p − 1 ≤ 25 4 ⋅ n r 2 {\mathcal{R}}({\mathcal{F}}_{n,p,r})=\frac{p^{2}\binom{n-p-2}{r-p-2}+(p+1)\binom{n-p-1}{r-p-1}}{(p^{2}+p+1)\binom{n-p-2}{r-p-2}}\leq 1+\frac{1}{p+1}\cdot\frac{n-p-1}{r-p-1}\leq\frac{25}{4}\cdot\frac{n}{r^{2}}

 3  Concluding remarks 

 
 As we mentioned in the Introduction, the bound of Theorem  1.1   (i)  cannot be strengthened in general as the following example shows. If  n = 2 ​ r n=2r , then a maximal intersecting family  ℱ {\mathcal{F}}  contains one set from every pair of complement sets. Thus the family  ℱ ∗ = { F ∈ ( [ n ] r ) : 1 ∉ F , F ≠ [ r + 1 , n ] } ∪ { [ r ] } {\mathcal{F}}^{*}=\{F\in\binom{[n]}{r}:1\notin F,F\neq[r+1,n]\}\cup\{[r]\}  is maximal intersecting and  ℛ ⁡ ( ℱ ∗ ) = Θ ⁡ ( ( n r ) ) = e Θ ⁡ ( n ) {\mathcal{R}}({\mathcal{F}}^{*})=\Theta(\binom{n}{r})=e^{\Theta(n)}  holds while  r r = e Θ ⁡ ( n ​ log ⁡ n ) r^{r}=e^{\Theta(n\log n)} . 
 
 
 In Theorem  1.2   (iii) , we could show regular maximal intersecting families only for special values of  n n  and  r r . There are two ways to generalize our construction. First, one needs not insist that all projective planes should be of the same order, but for the maximality one still needs that they should be of the same asymptotic order (one will have to choose  s s  a bit more carefully). This will ruin the regularity, but for families  ℱ {\mathcal{F}}  obtained this way  ℛ ⁡ ( ℱ ) = 1 + o ⁡ ( 1 ) {\mathcal{R}}({\mathcal{F}})=1+o(1)  would still hold. The other possibility is to add extra vertices that do not belong to  ∪ P i \cup P_{i} , similarly to the construction used for Theorem  1.2   (iii) . This will enable us to obtain constructions for arbitrary values of  n n  and  r r  (provided  n n  is large enough) but for these families  ℱ ′ {\mathcal{F}}^{\prime}  we will have  ℛ ⁡ ( ℱ ′ ) = Θ ⁡ ( r 2 n ) {\mathcal{R}}({\mathcal{F}}^{\prime})=\Theta(\frac{r^{2}}{n}) . 
 
 
 It remains open whether one can construct maximal intersecting families with  ℛ {\mathcal{R}} -value  1 + o ⁡ ( 1 ) 1+o(1)  for any  r ⁡ ( n ) r(n) .
