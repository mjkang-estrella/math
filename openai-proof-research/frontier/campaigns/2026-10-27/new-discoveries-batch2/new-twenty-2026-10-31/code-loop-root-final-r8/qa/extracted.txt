Statement and source scope
    Pires, Grishkov and Rasskazova [1], Conjecture 1, assert that two representations of one code loop with
equal degree and type are isomorphic codes. A representation is a doubly even binary subspace with a factor set
whose associated multiplication gives that loop. Coordinate isomorphism means an arbitrary coordinate permu-
tation carrying the entire code to the other. Coordinate classes consist of positions agreeing on EVERY code-
word; a representation is reduced when every such class has size less than eight. Its type is the sorted list of
class sizes. Rank means vector-space dimension.
     We give two full-support, reduced, doubly even subspaces of F2ˆ50, each of rank seven and type ﬁfteen
ones followed by seven ﬁves. They represent the SAME explicitly nonassociative Moufang loop, but no permu-
tation of the ﬁfty positions carries one code to the other. Thus the printed universal assertion is false. Minimal-
ity is a separate source deﬁnition. No minimal-only, center-order-two or rank-three/four uniqueness claim is re-
futed here. No new underlying Moufang loop is claimed; the result concerns simultaneous constraints on repre-
sentations.


The two codes and their actual type
     Write W=F2ˆ4 and X=F2ˆ3, with coordinates numbered from zero. Let H1 be the nonzero part of a3=0. Let
H2 be the union of the afﬁne plane a3=1,a2=0 and the nonzero part of the plane a1=a3=0. Each has seven
nonzero vectors and vector sum zero. For H1 this follows by counting each free coordinate four times. For H2,
the four afﬁne-plane vectors and three punctured-plane vectors each sum to zero; their last coordinates separate
the two blocks. H2 contains the third and fourth standard unit vectors (one-based unit names), while differences
of its afﬁne-plane vectors supply the ﬁrst two. It therefore spans W.
   For H equal to H1 or H2, use every nonzero a in W as a column, ﬁve times if a is in H and once otherwise.
This gives 43 positions. Add the seven nonzero columns b in X on disjoint positions. Deﬁne the evaluation
word by the entries w dot a on the W positions and x dot b on the X positions. Let D0 use H1 and D1 use H2.
Each code is the actual linear-map range, not a list of prescribed words or invariants. All unit columns occur,
proving injectivity; hence each range has dimension 4+3=7. Every column is nonzero, so every position is used.
    Positions with the same label agree on every word. Distinct W labels, or distinct X labels, are separated by a
unit input. Labels on different summands are separated by an input supported on just one summand. Thus
agreement on every codeword is EXACTLY equality of labels. Seven classes have size ﬁve; the remaining ﬁf-
teen have size one. All sizes are below eight. The actual quotient classes therefore give the required reduced
type. The formal quotient-to-label and ﬁber-to-copy equivalences prove this statement, and coordinate transport
gives actual submodules D50(0), D50(1) of F2ˆ(Fin 50).

  All arithmetic in the following factor formulas is in F2. For x,y in X, set
   f(x,y) = sum_(i=0..2) x_i y_i + x0 y1 + x0 y2 + x1 y2
         + x0 x1 y2 + x0 x2 y1 + x1 x2 y0.

   The diagonal is
   q(x) = 1 + (1+x0)(1+x1)(1+x2).
     It is zero at zero and one at every nonzero x. The complete polynomial gives f(0,y)=f(x,0)=0 and
f(x,x)=q(x). Its symmetric polarization is q(x+y)+q(x)+q(y). Each bilinear term has zero coboundary; the three
cubic terms yield the six distinct-coordinate monomials, the alternating triple form. These statements hold for
all inputs, not only a basis.
   On F2 x W x X deﬁne
   (s,w,x) * (t,v,y) = (s+t+f(x,y), w+v, x+y).
    Zero is the identity. To solve a*b=c, the W and X components give b_W=c_W-a_W and b_X=c_X-a_X;
then b_s=c_s-a_s-f(a_X,b_X). To solve b*a=c use the same vector components and b_s=c_s-a_s-f(b_X,a_X).
These explicit formulas prove existence and uniqueness of both divisions.
   Expanding the displayed factor gives
   f(x,y)+f(z,x)+f(x+y,z+x)
   = f(y,z)+f(y+z,x)+f(x,y+z+x).

    This proves (ab)(ca)=a((bc)a); the other components are additive. Consequently the multiplication is Mo-
ufang. At the three unit simplex inputs, with zero W and sign components, the associator signs differ. The loop
is therefore genuinely nonassociative. CodeLoopLoop proves the identity, unique divisions, this Moufang law
and the actual nonassociative witness directly; no factor-set-to-Moufang theorem is assumed.

   For arbitrary binary words on any ﬁnite coordinate set, the checked identities are
   wt(u+v) + 2 pair(u,v) = wt(u) + wt(v),
   wt(u+v+z) + wt(u) + wt(v) + wt(z)
   = wt(u+v) + wt(u+z) + wt(v+z) + 4 triple(u,v,z).

Arbitrary permutation obstruction and exact endpoint
    The fourth W unit vector annihilates H1, giving a word of weight eight in D0. Since H2 spans W, every
nonzero functional has a positive even count on H2. Its W word therefore has weight at least sixteen. The X
summand adds zero or four, so D1 has no weight-eight word. Every arbitrary coordinate permutation preserves
Hamming weight. Hence no permutation carries the entire ﬁrst code to the second. This is not merely an ob-
struction to generator, label-preserving or chosen-coordinate maps.
