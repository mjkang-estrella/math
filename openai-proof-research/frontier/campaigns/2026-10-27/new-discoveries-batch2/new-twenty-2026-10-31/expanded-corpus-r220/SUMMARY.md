## Sustained finite investigations

**366794, king game.** Recovered the literal Young diagram `((kr)^r, ((k-1)r)^r, ..., r^r)` and the east/south/southeast move recurrence with terminal-cell value zero. The initial repeated-board implementation completed `r=1,3,5,7,9`, `1 <= k <= 200`, then hit its 120-second CPU cap. The revised implementation reuses the smaller diagram as the bottom portion of the next diagram. It completed every odd `1 <= r <= 33`, `1 <= k <= 300`, with all 5,100 cases agreeing with Conjecture 5.1, before the same cap. Only completed rows in `king-fast-data.json` count as coverage. No counterexample or uniform proof emerged. A full proof would need a uniform invariant for the entire boundary row, not extrapolation of the top-left value.

**366989, basis maximization.** Exhaustively checked every subset of the required size in `F_2^4`: 12,870 at c=1, 1,820 at c=2, and 120 at c=3. The maxima were 56, 312, and 616 bases. At rank 5, checked all 496 subsets for c=4 and all 35,960 for c=3; maxima 69,888 and 48,384. Also checked 20,000 random c=2 subsets (seed 220), finding none above the proposed value 21,504. At rank 6, ran ten random restarts with 500 one-exchange proposals each for each c=2,3,4,5; no proposal exceeded the proposed values 5,203,968; 13,447,168; 20,643,840; 25,331,712. These are exact integer diagnostic scores. The general extremal inequality remains unproved. The c=1 theorem is already cited in the source.

**367191, expansion.** Recovered ancestor avoidance, cut-graph definitions, singleton equivalence, and Appendix B's singleton-extension proof. Exhaustively tested all loopless directed graphs through order 5, filtering for strong connectivity: 1, 18, 1,606, and 565,080 strongly connected graphs at orders 2–5 respectively, with no expansion failure. The order-5 pass enumerated all 1,048,576 directed graphs. Also sampled 3,000 graphs at each order 5–10; all strongly connected samples passed. Every nonempty subset pair in distinct cut-graph components is checked, including vacuous graphs with no antecedent. The report does not count each graph as a nonvacuous test. Contraction of one target set to invoke the source singleton theorem is not justified because cut-graph components can change.

**366899, terminal sets.** The cited work already verified all graphs through order 11. Tested 1,000 seeded cycle-plus-chord graphs at each order 12,14,16,18,20. Four had diameter at most 3, within a known theorem; the other 4,996 had a terminal set found by exact general-position subset search with the required endpoint coverage. This is sampled family coverage, not all graphs of these orders. No candidate arose.
