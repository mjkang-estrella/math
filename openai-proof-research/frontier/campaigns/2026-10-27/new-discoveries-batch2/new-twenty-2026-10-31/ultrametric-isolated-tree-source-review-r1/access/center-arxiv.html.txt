The center of distances of a metric space ( X , d ) (X,d) is the set C ⁡ ( X ) C(X) of all t ∈ ℝ + t\in\mathbb{R}^{+} for which the equation d ⁡ ( x , p ) = t d(x,p)=t has a solution for each p ∈ X p\in X . We prove that the equalities C ⁡ ( X ) = { 0 } C(X)=\{0\} or C ⁡ ( X ) = { 0 , diam ⁡ X } C(X)=\{0,\operatorname{diam}X\} hold if ( X , d ) (X,d) is an ultrametric space generated by labeled trees. The necessary and sufficient conditions under which diam ⁡ X ∈ C ⁡ ( X ) \operatorname{diam}X\in C(X) are found. Keywords: center of distances; diametrical graph; labeled tree; ultrametric space. MSC (2020): 54E35. 1 Introduction Ultrametric spaces generated by non-negative vertex labelings on arbitrary trees were introduced in [ 1 ] and subsequently studied in [ 2 , 3 ] . A characterization of totally bounded ultrametric spaces generated by labeled almost rays was provided in [ 4 ] . Furthermore, [ 5 ] contains a metric characterization of ultrametric spaces generated by labeled star graphs. It was shown in [ 6 ] that the compact ultrametric spaces generated by labeled star graphs are the completions of totally bounded ultrametric space generated by decreasingly labeled rays. In the present paper we investigate the class 𝐔𝐓 {\bf UT} of all ultrametric spaces which are isometric to spaces generated by labeled trees. The main goal of the paper is the characterization of the center of distances of 𝐔𝐓 {\bf UT} -spaces ( X , d ) (X,d) . The notion of center of distances was introduced in paper [ 7 ] and used for a generalization of John von Neumann Theorem on permutations of two sequences with the same set of cluster points [ 8 ] . At the moment the authors are not aware of any results describing the structure of the center of distances in the case of ultrametric spaces. The paper is organized as follows. The next section contains some definitions and facts from the theory of ultrametric spaces and graph theory. The main results of the paper are proved in Sections 3 – 5 . Theorem 4 of Section 3 shows that the center of distances C ⁡ ( X ) C(X) of an arbitrary 𝐔𝐓 {\bf UT} -space ( X , d ) (X,d) satisfies either the equality C ⁡ ( X ) = { 0 , diam ⁡ X } C(X)=\{0,\operatorname{diam}X\} (1) or the equality C ⁡ ( X ) = { 0 } . C(X)=\{0\}. (2) In Section 4 we introduce the concept of centered spheres and use it in Theorem 5 to describe the geometry of 𝐔𝐓 {\bf UT} -spaces ( X , d ) (X,d) which satisfy ( 1 ). Theorem 6 of this section gives a necessary and sufficient condition under which each open ball of a given 𝐔𝐓 {\bf UT} -space is a centered sphere in this space. Theorem 7 of Section 4 shows that an ultrametric space ( X , d ) (X,d) is equidistant if and only if each centered sphere of ( X , d ) (X,d) is an open ball of ( X , d ) (X,d) . Theorem 8 of Section 5 shows that equality ( 1 ) holds for 𝐔𝐓 {\bf UT} -space ( X , d ) (X,d) if and only if the diametrical graph of ( X , d ) (X,d) has a spanning star subgraph. Corollary 4 of Theorem 1 shows that equality ( 2 ) holds for 𝐔𝐓 {\bf UT} -space ( X , d ) (X,d) with | X | ≥ 2 |X|\geq 2 if and only if ( X , d ) (X,d) is weakly similar to an unbounded ultrametric space.
