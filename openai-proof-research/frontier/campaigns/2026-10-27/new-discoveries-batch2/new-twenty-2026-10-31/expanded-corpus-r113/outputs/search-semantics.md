The scripts in this lane are diagnostics, not Lean certificates.

Stamp counts use a recursively inserted layer order. Inserting new face n at a gap updates all positions. The new crease (n-1,n) is tested for alternating endpoints against every earlier crease of the same parity; this is precisely the source's same-side no-crossing condition. Its direction determines the next MV bit by Definition 2.1, with even faces facing right. Removing the last face preserves legality (source Lemma 2.1), so the recursion enumerates every legal layer order once. It accumulates every assignment's count at each size. All maximizing assignments through 18 match the source v2 table up to reflection and exchanging M,V. The targeted counter uses the same checker, fixing the bit beforehand and restricting gaps to the corresponding side. It records every assignment evaluated. The final_local_optimum label in the n=30 diagnostic log denotes the best visited assignment only: the time exit interrupted its final neighborhood, so no complete local optimality claim is made. No global maximum is certified for n > 18.

Pinwheel states contain each task's elapsed age, initially all zero. Servicing task j resets its age to zero and increments all other ages. A transition is allowed only if all incremented ages stay strictly below their periods. A reachable directed cycle gives a periodic schedule satisfying every period-window constraint. Conversely a feasible schedule, begun with optimistic zero ages, produces an infinite path; finite state space forces a repeated state. DFS grey-edge detection therefore decides existence. All instances actually counted in the log have completed this decision. The time-limit check before an instance does not count the printed last tuple. The symmetry reduction sorts periods; no reduction merges tasks of equal period. No sampled trajectories substitute for DFS acyclicity.

Johnson tests evaluate the exact rational polynomial in Theorem 1.4 at every integer of its permitted root interval. Finding s distinct zero values is necessary for a tight code. Finding none only excludes these bounded parameters, already excluded by the source's much stronger theorem.

Cylindric tests enumerate all pairs of integer partitions of each total weight up to 18, each with at most n nonzero entries. Missing entries are zero. They impose both inequalities of Definition 2.1. The Gaussian-binomial recurrence and truncated division by (q;q)_(2n) yield the proposed coefficient lists. This checks full coefficients only through the stated truncation.

The equal-partition sweep treats the author's finite coefficient file as input. It constructs initial polynomial values from H_d(t)=h_d(t)/(1-t)^d and uses exact finite differences. Finite differences have degree d-1, so no floating point interpolation is involved. A hash table compares all different d in 4..30 at n=2..50000. The mismatch of p30(666) with the printed example remains material. Numerical collisions or their absence are conditional on this data input until reconciled.

The partition-repulsion sweep uses Euler's pentagonal recurrence for p(n), exact integer kth roots, and nearest-power distances. Its finite cut-off cannot decide a maximum over unbounded n or eventual stabilization over unbounded k.

The stack-sorting sweep uses the usual stack map (pop while top < next input), appends zero to every permutation, and counts passes until zero is first. The source auxiliary depth counts precisely the time to move zero to the left; the output is not the ordinary sorting depth of rho. Every permutation through n=9 was visited; this does not extend the source mean computation through n=37.

Digit checkpoints store the full integer state in hexadecimal and the exact one-count. Integer parity selects the appended digit. No floating point recurrence is used. Asymptotic balance does not follow from any of these prefixes.
