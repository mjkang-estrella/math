# Round 6 proof architecture and limitations

This is a partial throughput experiment, not an unconditional refutation. Root decides acceptance. The inherited round 5 prefix is not extended by this packet.

MaskRUP.lean represents each clause and falsifying assignment by a pair of natural-number bitmasks. The first mask stores positive literals (forbidden value false), and the second stores negative literals (forbidden value true). The `bits` function selects the mask for a forbidden value. Holds asserts that some set bit represents a literal satisfied by the valuation. FalseUnder asserts that every stored literal is false.

`cover c f` checks two bitwise intersection equalities. `cover_bit` proves that every bit of c is then a bit of f. A satisfied clause cannot be covered by a falsifying assignment (`conflict`). If c is covered after adding one supplied literal (n,b), satisfaction forces v n = !b (`force`). This choice is not trusted: the coverage equation is checked. `insert_false` extends the invariant with the forced complement. Each propagation hint contains a mask and `some (n,b)`; the terminal conflict hint contains `none`. The checker tests one coverage condition per hint. List.rec implements recursion without local compiler-generated unsafe recursion helpers. Induction proves check_sound_aux and classical contradiction proves check_sound.

`encode` folds insertion over a literal list. `encode_bit` proves exactly that a bit is set iff the corresponding literal belongs to the list. `encode_holds` proves the exact semantic equivalence. MaskCNF.lean instantiates this equivalence with the inherited literal-list CNF.Holds semantics. No bit-width restriction or finite-variable bound is needed in these general theorems.

The pilot selects zero-based normalized certificate steps [13561,18561). Every stored mask is independently computed from its literal clause. Each module contains 100 checks, each proved by kernel `decide`, and a corresponding soundness theorem conditional on satisfaction of the actual hint masks. The 1,000-step pilot is the first ten modules, and the 5,000-step pilot is all fifty modules; these overlap and must not be added together. These are local RUP checks and conditional semantic theorems. They are NOT a closed normalized-CNF prefix: no named dependency chain to earlier derived clauses and no concrete input-mask membership bridge have been assembled. The Python generator is data preparation only; the general theorem and concrete equations are kernel checked. The concrete literal-to-mask equality for every pilot clause is not yet a delivered theorem.

The delivered conditional endpoint is Percolation.not_conjecture20_mask_conditional : NormalizedCNFUnsat5 → ¬ Conjecture20. Its single explicit hypothesis is nonexistence of a valuation satisfying every clause of normalizedCNF5. All 129,671 normalized additions remain to be connected in round 6. The independently verified round 5 frontier remains 13,561, but its list replay is intentionally not rebuilt in this new experimental packet. No new closed certificate steps are claimed.

The endpoint uses the unchanged normalization proof and all its geometry, literal definitions, finite system equivalence and semantic generator bridge. The original controls and their deletion-separator modules are retained. Retained source files are byte-identical to the round 5 archive, with hashes in retained-source-comparison.json. dropped-modules.json lists every omitted inherited module, including the old input/replay/audit infrastructure. They are unnecessary for the new conditional endpoint, which assumes normalized formula unsatisfiability directly. Their omission does not assert that the new checker has re-proved their closed prefix. A future complete packet must build the named dependency graph and discharge that hypothesis.

Throughput redesign: MaskBuild.lean constructs concrete Lean expressions directly from frozen numeric data. Each rawCheck theorem is an ordinary Eq.refl proof whose expected type is `check c hs = true`. Lean.addDecl kernel-checks it. Each rawSound theorem applies the general check_sound theorem; Meta.inferType supplies its explicit conditional type, and addDecl checks that proof too. The independent leanchecker checks all resulting declarations. This reduces elaboration overhead; it does not replace reduction with a native decision oracle. The final pilots use MaskRaw modules, while the first 1,000 ordinary-elaboration checks are retained as a comparison. The standalone metadata audit checks the elaborator itself as well as all emitted declarations.

Preservation clarification: `dropped-modules.json` means omitted from the small checker-development packet only. Every original module is preserved unchanged in inherited.zip and its safely extracted inherited/src tree. None is declared redundant or re-proved by this experiment. The conditional inherited frontier endpoint continues to require exactly the original 116,110-addition suffix. The new packet does not claim that it is a complete replacement of the round 5 formalization.
