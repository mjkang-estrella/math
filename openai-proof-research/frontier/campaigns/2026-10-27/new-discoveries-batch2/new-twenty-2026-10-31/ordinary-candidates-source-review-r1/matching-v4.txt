                               2. Definitions & notation
   Throughout, we denote by G = (V, E) a finite graph with vertex set V and edge set E.
A matching in G is a set of edges such that no two are adjacent. In particular, we will
consider the following specific types of matchings.
      • A maximum matching is a matching M of maximum size, i.e., for all matchings
         M 0 , |M 0 | ≤ |M |. We let ν(G) denote the size of a maximum matching.
      • A perfect matching is a matching M such that for every vertex v in G, there exists
         an e ∈ M such that v is incident to e.
      • A near perfect matching is a matching M such that for every vertex v in G except
         for one, there exists an e ∈ M such that v is incident to e.
   In addition to sizes of maximum matchings, we will also pay special attention to the size
of the union of two disjoint matchings whose union is of maximum size. More formally,
we define λ(G) := max{|H| + |H 0 | : (H, H 0 ) are disjoint matchings on G}. Furthermore,
define:
      • Λ(G) is the set of pairs (H, H 0 ) of disjoint matchings satisfying |H| + |H 0 | = λ(G).
      • µ(G) := max{|H| : ∃H 0 such that (H, H 0 ) ∈ Λ(G)}.
   ν, λ, and µ are the main concern of this paper. We present an example with the spanner
graph to illustrate our key parameters. The left spanner of Fig. 2 has the unique maximum
matching, M , highlighted. It has size 5, and so ν(G) = 5 for the spanner. The largest
matching disjoint from M has size 2, for combined size of 7. However, if we choose a
separate set of disjoint matchings, we can achieve λ(G) = 8. On the right of the same
figure, our maximal disjoint matchings H and H 0 are highlighted. They each have size 4, so
µ(G) = 4 for the spanner. Most graphs with µ(G)   ν(G)

the spanner, as we will make clear in Section 5.

                                3. PEC decompositions
   Now, we present a type of decomposition for graphs that highlights matching structure
and gives an alternative way to compute the parameters ν(G), λ(G), and µ(G). Several
of the following lemmas will be used in the proof of our main theorems. Throughout this
section, let G := (V, E) be a graph and n := |V |.
      • A subgraph of G is a graph G0 := (V 0 , E 0 ) with V 0 ⊆ V and E 0 ⊆ E. A subgraph
        G0 := (V 0 , E 0 ) of G is spanning if V 0 = V .
      • A pec decomposition of G is a spanning subgraph G0 := (V, E 0 ), each of whose
        (connected) components is a path or an even cycle. (Isolated vertices are treated as
        even paths.)
For a pec decomposition G0 of G, let
      • p(G0 ) (resp., e(G0 )) denote the number of components of G0 that are paths (resp.,
        even paths).
      • p(G) := min{p(G0 ) : G0 is a pec decomposition of G}.
      • e(G) := min{e(G0 ) : G0 is a pec decomposition of G}.
These last three parameters describe structural properties of the graph that can be assessed
with matchings and alternating paths. They are a direct parallel to our original ν, µ, and λ.

                                       4. Basics tools
In this section we will state and prove several structural lemmas about alternating chains
(i.e., paths or cycles) that will be used to prove our main theorems. Let G ..= (V, E) be a
finite connected graph. Among the maximum matchings and maximum disjoint matchings
in G, there are some that have maximal intersection, and this condition allows for sharper
restrictions on the possible edge configurations. More specifically, we define maximally in-
tersecting matchings:
Definition 13. Matchings M , H, and H 0 are called maximally intersecting if they satisfy
the following:
(i)     M is a maximum matching.
(ii)    (H, H 0 ) ∈ Λµ (G) with |H| = µ(G).
(iii)   |M ∩ (H ∪ H 0 )| is maximum among all M, H, H 0 satisfying (i)–(ii).
(iv)    |M ∩ H| is maximum among all M, H, H 0 satisfying (i)–(iii).
                                                7
   Throughout this section, let M , H, H 0 be maximally intersecting matchings. Here are a
few basic facts about M -H alternating chains. Define an end-edge of a path to be an edge
in the path incident to one of the path’s terminal vertices.
Lemma 14.
(14.a) The maximal M -H alternating chains are odd paths with end-edges in M .
(14.b) The end-edges of M -H alternating paths are in H 0 .
(14.c) All vertices on maximal M -H alternating paths are incident to H 0 .
Proof. (14.a) Let P be such a chain. Since these chains are alternating, P cannot be an odd
cycle. If P is an even cycle, define M 0 ..= (M \P ) ∪ (P \M ). This set of edges is a matching
since M is and since P is alternating. Furthermore, |M 0 | = |M |, and so M 0 is a maximum
matching. However, |M 0 ∩ H| > |M ∩ H|, a contradiction. Now suppose that some end-edge
of P is not in M . This edge, e0 , is in H\M , and is adjacent to exactly one M edge e1 in
P . But then if e1 is removed from M and e0 is added to M , |M ∩ H| is again increased, a
contradiction. This implies that the length of P is odd.

(14.b) Consider an end-edge e0 in M \H. Again note that e0 can be incident to H on only
one side. If e0 is not in H 0 , then we can remove e1 , the preceding edge, from H, add e0 to
H, and again increase |M ∩ (H ∪ H 0 )|.

(14.c) Suppose instead some interior vertex is not incident to H 0 , and note that this vertex
is incident to no end-edges. This vertex is incident to exactly one edge in M , which we call
eM . eM is incident to H 0 at most once. Via a similar argument to above, if we take eM to
be in H 0 instead of this adjacent edge, we increase |M ∩ (H ∪ H 0 )|.                      
  We now present similar structural lemmas about maximal H-H 0 alternating paths.
Lemma 15.
(15.a) If a maximal H-H 0 alternating path is odd, then its end-edges are in H.
(15.b) The end-edges of maximal M -H alternating paths (which we know are in H 0 ) are
       end-edges of even H-H 0 alternating paths.
(15.c) All inner (not end) vertices of maximal M -H alternating paths are inner vertices of
       H-H 0 alternating paths. In other words, each end-vertex of an H-H 0 alternating path
       is either an end-vertex of a maximal M -H alternating path or is not on any M -H
       alternating path.
(15.d) On every even maximal H-H 0 alternating chain, the edges in H ∩ M are at least as
       many as those in H 0 ∩ M .
(15.e) Each end-edge of a maximal H-H 0 alternating path that is in H is also in M .
Proof. (15.a): Otherwise, we would switch H and H 0 on that path, keeping |H ∪ H 0 | the
same, but increasing H.
(15.b): Each such edge is adjacent to H exactly on one side, so it is an end-edge of a maximal
H-H 0 alternating path, which hence must be even by (15.a).
(15.c) This is just because each inner vertex of a maximal M -H alternating path is incident
to H by definition and is also incident to H 0 by (14.c).
(15.d) Otherwise, swapping H and H 0 contradicts condition (iv).

   We are now prepared to state and prove our main theorems. For d ∈ N, we call a vertex
in a graph a d-vertex if its degree is d, and we say that a graph has degree d if the degree of
each vertex is at most d. An edge incident to a leaf (a 1-vertex) is called a leaf-edge.
   A path in a graph whose end-vertices are leaves is called leaf-to-leaf. Call an edge e on
an odd path p odd (resp. even) if its edge-distance from either end-edge of p is even (resp.
odd). Similarly, call a vertex v on an even path p odd (resp. even) if its edge-distance from
either end-edge of p is odd (resp. even).
   Our main theorems, Theorem 19 and Theorem 20, establish that the core structural prop-
erties of graphs with µ(G)
                       ν(G)
                            < 1 are due to a graph’s skeleton structure.
Definition 16. A connected nonempty graph G is called a skeleton if it is of degree 3
and admits a (not necessarily spanning) subgraph G0 ..= (V 0 , E 0 ) satisfying the following
conditions:
(16.i) G0 consists of vertex-disjoint odd leaf-to-leaf paths of length at least 5.

Call this matching M .

perfect matching M 0 . Observe that if M = M 0 on each of the paths in G0 then this forces
M = M 0 on all of G. Thus, some path of G0 must contain an M \M 0 edge. Take the leftmost
