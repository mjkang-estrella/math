 Abstract 
 
 We show that if G G is a n n -vertex connected chordal graph, then it admits a longest path transversal of size O ⁡ ( log 2 ⁡ n ) O(\log^{2}n) . Under the stronger assumption of 2-connectivity, we show G G admits a longest cycle transversal of size O ⁡ ( log ⁡ n ) O(\log n) . We also provide longest path and longest cycle transversals which are bounded by the leafage of the chordal graph. 
 
 
 
 1 Introduction 

 
 Gallai [ 7 ] asked whether the intersection of all longest paths in a connected graph is nonempty. Motivated by this question, a Gallai vertex in a graph is a vertex belonging to every longest path. The question was resolved in the negative by Walther  [ 29 ] , who constructed a connected graph with no Gallai vertices. Smaller examples of connected graphs with no Gallai vertices were found by both Walther and Voss  [ 30 ] and
Zamfirescu  [ 33 ] . One such counterexample is the Petersen fragment, which is obtained from splitting an arbitrary vertex of the Petersen graph into three degree one vertices, see Figure   1 . There has been much work understanding how longest paths intersect, with some surveys being available  [ 28 , 34 ] . 
 
 
 A family of graphs 𝒢 \mathcal{G} is Gallai if each connected G ∈ 𝒢 G\in\mathcal{G} has at least one Gallai vertex. There is an ongoing line of research to determine which graph families are Gallai, see for example [ 1 , 4 , 5 , 6 , 15 , 16 , 19 ] . Given a set of graphs ℱ \mathcal{F} , a graph G G is ℱ \mathcal{F} -free of it does not contain any member of ℱ \mathcal{F} as an induced subgraph. There has been some work toward a characterization of the families ℱ \mathcal{F} for which the ℱ \mathcal{F} -free graphs are Gallai when ℱ \mathcal{F} is very small, see [ 10 , 20 , 23 ] , with the full characterization remaining an open question. 
 
 
 Given a family of sets ℱ \mathcal{F} , the intersection graph on ℱ \mathcal{F} is the graph with vertex set ℱ \mathcal{F} with vertices u u and v v adjacent if and only if u u and v v have non-empty intersection. A graph G G is an interval graph if G G is the intersection graph of a family of closed intervals in ℝ \mathbb{R} . A chord of a cycle C C in a graph G G is an edge e ∈ E ⁡ ( G ) − E ⁡ ( C ) e\in E(G)-E(C) with both endpoints on C C . A graph G G is chordal if each cycle on at least 4 4 vertices has a chord. In 2004, Balister, Győri, Lehel, and Schelp  [ 1 ] showed that the interval graphs form a Gallai family, and suggested that the same might be true for the larger family of chordal graphs. The question remains open. 
 
 
 There is some partial evidence that the family of chordal graphs are Gallai. A graph G G is a split graph if V ⁡ ( G ) V(G) can be partitioned into a clique and an independent set. All split graphs are chordal. Bender, Richmond, and Wormald [ 2 ] proved that a uniformly sampled labeled chordal graph almost surely splits. As Klavžar and Petkovšek  [ 19 ] showed split graphs are Gallai, we may conclude almost all (labeled) chordal graphs are also Gallai. 
 
 
 A longest path transversal in G G is a set of vertices that intersects every longest path in G G . The longest path transversal number of G G , denoted lpt ⁡ ( G ) \mathrm{lpt}(G) , is the minimum size of a longest path transversal. Showing that 𝒢 \mathcal{G} is a Gallai family amounts to proving lpt ⁡ ( G ) = 1 \mathrm{lpt}(G)=1 for each connected G ∈ 𝒢 G\in\mathcal{G} . Kierstead and Ren  [ 18 ] proved that lpt ⁡ ( G ) ≤ 5 ​ n 2 / 3 \mathrm{lpt}(G)\leq 5n^{2/3} when G G is a connected n n -vertex graph, improving on an earlier bound of lpt ⁡ ( G ) ≤ 8 ​ n 3 / 4 \mathrm{lpt}(G)\leq 8n^{3/4} due to Long, Milans, and Munaro  [ 22 ] . From below, Grünbaum  [ 12 ] constructed a connected graph G G with lpt ⁡ ( G ) = 3 \mathrm{lpt}(G)=3 . There is no known connected graph G G with lpt ⁡ ( G ) ≥ 4 \mathrm{lpt}(G)\geq 4 . We state our first main result, where lg ⁡ x \lg x denotes log 2 ⁡ x \log_{2}x . 
 
 
 Theorem (See Theorem   4.7 ) . 
 
 If G G is a connected n n -vertex chordal graph, then lpt ⁡ ( G ) ≤ 4 ​ lg 2 ​ n + O ⁡ ( log ⁡ n ) \mathrm{lpt}(G)\leq 4\lg^{2}n+O(\log n) . 
 
 
 
 A tree is a connected acyclic graph. In 1974, Gavril  [ 9 ] showed that a graph G G is chordal if and only if G G is the intersection graph of subtrees of a tree T T . In this case, we say T T is a host tree for the chordal graph G G . The subtrees of a tree are well known to have the Helly property (e.g., see [ 11 ] ), meaning that if ℱ \mathcal{F} is a set of subtrees of T T and every pair of trees in ℱ \mathcal{F} has nonempty intersection, then some vertex in T T is common to each subtree in ℱ \mathcal{F} . Since the longest paths in a connected graph are pairwise intersecting, showing that 𝒢 \mathcal{G} is Gallai is equivalent to showing that for each connected G ∈ 𝒢 G\in\mathcal{G} , the longest paths in G G have the Helly property. As the longest paths in a connected graph are pairwise intersecting, the longest paths in a tree are pairwise intersecting subtrees, and it follows from the Helly property that the trees form a Gallai family. 
 
 
 The treewidth of a graph is a fundamental graph parameter introduced in the graph minors project of Robertson and Seymour [ 26 ] . In nonrigorous terms, treewidth is a measure of how far a graph is from being a tree. Treewidth has received significant attention due to its applications in fixed parameter tractable algorithms; many problems which are NP-hard in general have polynomial algorithms when restricted to graphs with bounded treewidth. The treewidth of a graph G G , denoted tw ⁡ ( G ) \mathrm{tw}(G) , can be defined as tw ⁡ ( G ) = min ⁡ { ω ⁡ ( H ) − 1 : G ⊆ H ​  and  ​ H ​  is chordal } \mathrm{tw}(G)=\min\{\omega(H)-1:G\subseteq H\text{ and }H\text{ is chordal}\} where ω ⁡ ( H ) \omega(H) denotes the size of the largest clique in H H . In particular for a chordal graph G G , we have that tw ⁡ ( G ) = ω ⁡ ( G ) − 1 \mathrm{tw}(G)=\omega(G)-1 . For a reference on treewidth, see [ 25 ] . 
 
 
 Figure 1: Petersen fragment 
 
 
 A bramble of a graph is a set of connected subgraphs which pairwise intersect or are joined by an edge. The order of a bramble B B is the minimum size of a set of vertices intersecting each subgraph in B B . It is well known  [ 27 ] that tw ⁡ ( G ) + 1 \mathrm{tw}(G)+1 is equal to the maximum order of a bramble in G G . As observed by Rautenbach and Sereni [ 24 ] , as the family of longest paths in a connected graph form a bramble, it follows that lpt ⁡ ( G ) ≤ tw ⁡ ( G ) + 1 \mathrm{lpt}(G)\leq\mathrm{tw}(G)+1 when G G is connected. If G G is connected and chordal, then lpt ⁡ ( G ) ≤ tw ⁡ ( G ) + 1 = ω ⁡ ( G ) \mathrm{lpt}(G)\leq\mathrm{tw}(G)+1=\omega(G) . Later, Harvey and Payne  [ 14 ] improved this to lpt ⁡ ( G ) ≤ 4 ​ ⌈ ( ω ⁡ ( G ) ) / 5 ⌉ \mathrm{lpt}(G)\leq 4\left\lceil(\omega(G))/5\right\rceil when G G is a connected chordal graph. 
 
 
 A closely related problem is finding a small set of vertices intersecting every longest cycle, called a longest cycle transversal . The longest cycle transversal number of a graph G G , denoted lct ⁡ ( G ) \mathrm{lct}(G) , is the minimum size of a longest cycle transversal. Unlike for longest paths, connectivity alone is not sufficient for the family of longest cycles in a graph to be pairwise intersecting, and lct ⁡ ( G ) \mathrm{lct}(G) can be as large as | V ⁡ ( G ) | / 3 |V(G)|/3 even when G G is connected. However, if G G is 2 2 -connected, then the longest cycles in G G are pairwise intersecting (see, for example, Lemma   3.1 ). In many cases, bounds on lpt ⁡ ( G ) \mathrm{lpt}(G) for connected G G have analogous bounds on lct ⁡ ( G ) \mathrm{lct}(G) for 2 2 -connected G G . Harvey and Payne  [ 14 ] proved that lct ⁡ ( G ) ≤ 2 ​ ⌈ ω ⁡ ( G ) / 3 ⌉ \mathrm{lct}(G)\leq 2\left\lceil\omega(G)/3\right\rceil when G G is a 2 2 -connected chordal graph. Our second main result is the following. 
 
 
 Theorem (See Theorem   3.9 ) . 
 
 If G G is an n n -vertex 2 2 -connected chordal graph with minimal tree representation T T , then lct ⁡ ( G ) ≤ 4 ​ ( 1 + ⌊ lg ⁡ n ⌋ ) \mathrm{lct}(G)\leq 4(1+\left\lfloor\lg n\right\rfloor) . 
 
 
 
 In Section  2 , we cover the necessary preliminaries to our results. In Section  3 , we prove Theorem  3.9 by an iterative divide-and-conquer strategy on the tree representation of G G . Building on these techniques, in Section  4 we prove Theorem  4.7 . In Section  5 , we provide upper bounds for lpt ⁡ ( G ) \mathrm{lpt}(G) and lct ⁡ ( G ) \mathrm{lct}(G) in terms of the leafage of G G , a parameter introduced by Lin, McKee, and West [ 21 ] . As an application, we show the family of connected chordal graphs admitting a subdivided star tree representation is Gallai. In Section  6 , we conclude with some open questions. 
 
 
 
 2 Preliminaries 

 
 A tree representation for a chordal graph G G is a host tree T T along with a collection of subtrees ℱ {\cal F} of T T such that the intersection graph on ℱ {\cal F} is isomorphic to G G . Recall that Gavril  [ 9 ] characterized the chordal graphs as the graphs which admit a tree representation. Although formally a tree representation is the intersection graph of subtrees of a host tree T T , we also use T T to denote the tree representation. For a vertex u u in a chordal graph G G and a tree representation T T , we use S ⁡ ( u ) S(u) to denote the subtree of T T corresponding to u u . When H H is a subgraph of G G , we define S ⁡ ( H ) S(H) to be the union, over all u ∈ V ⁡ ( H ) u\in V(H) , of S ⁡ ( u ) S(u) . Note that if H H is connected, then S ⁡ ( H ) S(H) is a (connected) subtree of T T . For each x ∈ V ⁡ ( T ) x\in V(T) , we define the bag corresponding to x x , denoted B ⁡ ( x ) B(x) , to be the set { u ∈ V ⁡ ( G ) : x ∈ V ⁡ ( S ⁡ ( u ) ) } \{u\in V(G)\colon\,x\in V(S(u))\} . Note that for each x ∈ V ⁡ ( T ) x\in V(T) , the bag B ⁡ ( x ) B(x) is a clique in G G . Also, if A A is a clique in G G , then the set { S ⁡ ( u ) : u ∈ A } \{S(u)\colon\,u\in A\} is a family of pairwise intersecting subtrees of T T . Since subtrees of a tree have the Helly property, there is a vertex x x belonging to all of these subtrees, yielding A ⊆ B ⁡ ( x ) A\subseteq B(x) . Since B ⁡ ( x ) B(x) is always clique in G G , it follows that if A A is a maximal clique in G G , then A = B ⁡ ( x ) A=B(x) for some x ∈ V ⁡ ( T ) x\in V(T) . In fact, as we note below, when T T is a minimal tree representation, the converse also holds and the bags in T T are exactly the maximal cliques in G G . 
 
 
 A rooted tree is a tree with a distinguished vertex r r , called the root of T T . If T T is a rooted tree with root r r and u ∈ V ⁡ ( T ) u\in V(T) , then the subtree of T T rooted at u u is the tree induced by the set of all vertices w ∈ V ⁡ ( T ) w\in V(T) such that the r ​ w rw -path in T T contains u u . Our convention is to use X X to name a rooted subtree of T T with root vertex x x . Often, our arguments produce a sequence of rooted subtrees X 0 , X 1 , … , X t X_{0},X_{1},\ldots,X_{t} where X 0 X_{0} is a tree representation of a chordal graph, each X i X_{i} is a smaller rooted subtree of X i − 1 X_{i-1} for i ≥ 1 i\geq 1 , and the sequence ends with X t X_{t} empty. 
 
 
 Let T T be a rooted tree, let X X be the subtree rooted at a vertex x ∈ V ⁡ ( T ) x\in V(T) , and let Q Q be a subpath of X X with endpoint x x . For each y ∈ V ⁡ ( Q ) y\in V(Q) , we define the descendants of y y in X X relative to Q Q , denoted D X ​ ( y , Q ) D_{X}(y,Q) , to be the component of X − E ⁡ ( Q ) X-E(Q) containing y y . For a subpath Q 0 Q_{0} of Q Q , we define D X ​ ( Q 0 , Q ) D_{X}(Q_{0},Q) to be the union, over y ∈ V ⁡ ( Q 0 ) y\in V(Q_{0}) , of D X ​ ( y , Q ) D_{X}(y,Q) . 
 
 
 A tree representation T T for a chordal graph G G is minimal if there is no tree representation of G G with a host tree on fewer than | V ⁡ ( T ) | |V(T)| vertices. If T T is a minimal tree representation for G G , then for all distinct x x and y y in V ⁡ ( T ) V(T) , we have B ⁡ ( x ) ⊈ B ⁡ ( y ) B(x)\not\subseteq B(y) , as otherwise contracting the edge e e incident to x x along the x ​ y xy -path simultaneously in T T and each subtree S ⁡ ( v ) S(v) with v ∈ V ⁡ ( G ) v\in V(G) and e ∈ E ⁡ ( S ⁡ ( v ) ) e\in E(S(v)) yields a tree representation of G G with fewer vertices. Note that if B ⁡ ( x ) B(x) were properly contained in a larger clique A A in G G , then A ⊆ B ⁡ ( y ) A\subseteq B(y) for some y ∈ V ⁡ ( T ) y\in V(T) and we have B ⁡ ( x ) ⊊ A ⊆ B ⁡ ( y ) B(x)\subsetneq A\subseteq B(y) for distinct x , y ∈ V ⁡ ( T ) x,y\in V(T) , contradicting the minimality of T T . Conversely, for each tree representation T T of G G , every clique in G G is contained in some bag of T T by the Helly property, and so the number of maximal cliques in G G is a lower bound on | V ⁡ ( T ) | |V(T)| . It follows that T T is minimal if and only if the bags of T T are the maximal cliques in G G . We often use the following property of minimal tree representations. 
 
 
 Lemma 2.1 . 
 
 Let G G be a connected chordal graph with minimal tree representation T T such that | V ⁡ ( G ) | ≥ 2 |V(G)|\geq 2 . We have | B ⁡ ( y ) | ≥ 2 |B(y)|\geq 2 for all y ∈ V ⁡ ( T ) y\in V(T) . 
 
 
 
 Proof. 
 
 As we have observed, in a minimal tree representation, each bag in T T is a maximal clique in G G . If T T has a bag of size 1 1 , then G G has a maximal clique of size 1 1 , which must be an isolated vertex. Since G G is connected, it follows that | V ⁡ ( G ) | = 1 |V(G)|=1 .
∎ 
 
 
 
 Given a subgraph H H of a chordal graph G G with tree representation T T , the core of H H is the union, over all u ​ v ∈ E ⁡ ( H ) uv\in E(H) , of V ⁡ ( S ⁡ ( u ) ∩ S ⁡ ( v ) ) V(S(u)\cap S(v)) . Note that the core of H H is a subset of V ⁡ ( T ) V(T) . A vertex v ∈ V ⁡ ( T ) v\in V(T) is a core vertex of H H if v v belongs to the core of H H . A set W ⊆ V ⁡ ( T ) W\subseteq V(T) has the core capture property with respect to a family of subgraphs ℋ \mathcal{H} of G G if each H ∈ ℋ H\in\mathcal{H} has a core which intersects W W . For a subgraph X X of T T , we say that X X has the core capture property with respect to ℋ \mathcal{H} if V ⁡ ( X ) V(X) has the core capture property with respect to ℋ \mathcal{H} . 
 
 
 Lemma 2.2 . 
 
 Let G G be a chordal graph with a tree representation T T . Let X X be a rooted subtree of T T with root x x , and let H H be a subgraph of G G such that H H has a core vertex in X X but x x is not a core vertex of H H . There is a vertex w ∈ V ⁡ ( H ) w\in V(H) such that S ⁡ ( w ) ⊆ V ⁡ ( X ) − x S(w)\subseteq V(X)-x . 
 
 
 
 Proof. 
 
 Let y ∈ V ⁡ ( X ) y\in V(X) be a core vertex of H H , and obtain u ​ v ∈ E ⁡ ( H ) uv\in E(H) such that y ∈ V ⁡ ( S ⁡ ( u ) ∩ S ⁡ ( v ) ) y\in V(S(u)\cap S(v)) . Note that for some w ∈ { u , v } w\in\{u,v\} , we have that x ∉ V ⁡ ( S ⁡ ( w ) ) x\not\in V(S(w)) , or else x x would also be a core vertex of H H . Since S ⁡ ( w ) S(w) is a subtree of T T , it must be that S ⁡ ( w ) S(w) is contained in a component of T − x T-x . Since y ∈ V ⁡ ( S ⁡ ( w ) ) y\in V(S(w)) and y y is in a component of X − x X-x , it follows that S ⁡ ( w ) ⊆ X − x S(w)\subseteq X-x .
∎ 
 
 
 
 We frequently make use of Jordan’s tree separator theorem [ 17 ] . 
 
 
 Lemma 2.3 . 
 
 Let T T be a tree. There exists a vertex z ∈ V ⁡ ( T ) z\in V(T) such that each component of T − z T-z has at most | V ⁡ ( T ) | / 2 |V(T)|/2 vertices. 
 
 
 
 A graph G G is k k -connected if | V ⁡ ( G ) | > k |V(G)|>k and G − S G-S is connected for all S ⊆ V ⁡ ( G ) S\subseteq V(G) with | S | < k |S|<k . The vertex connectivity of G G , denoted κ ⁡ ( G ) \kappa(G) , is the maximum k k such that G G is k k -connected. In a path P P , the vertices of degree 2 2 are interior or internal vertices and the vertices of degree less than 2 2 are endpoints . Paths P P and Q Q are internally disjoint if their interior vertices are disjoint. We use Menger’s Theorem (see, e.g. [ 31 ] ). 
 
 
 Theorem 2.4 (Menger’s Theorem) . 
 
 If x x and y y are distinct vertices in G G , then G G has κ ⁡ ( G ) \kappa(G) pairwise internally disjoint x ​ y xy -paths. 
 
 
 
 For subsets S , T ⊆ V ⁡ ( G ) S,T\subseteq V(G) , an ( S , T ) (S,T) -path is a path with one endpoint in S S and the other endpoint in T T with internal vertices outside S ∪ T S\cup T . Adding new vertices s s and t t to G G with N ⁡ ( s ) = S N(s)=S and N ⁡ ( t ) = T N(t)=T produces a new graph G ′ G^{\prime} with connectivity at least min ⁡ { | S | , | T | , κ ⁡ ( G ) } \min\{|S|,|T|,\kappa(G)\} . Applying Theorem   2.4 to G ′ G^{\prime} and s , t s,t , and shortening paths with internal vertices in S ∪ T S\cup T gives the following well known consequence of Menger’s Theorem. 
 
 
 Theorem 2.5 (Menger’s Theorem) . 
 
 Let G G be a graph. For all sets S , T ⊆ V ⁡ ( G ) S,T\subseteq V(G) , there exists min ⁡ { | S | , | T | , κ ⁡ ( G ) } \min\{|S|,|T|,\kappa(G)\} pairwise disjoint ( S , T ) (S,T) -paths. 
 
 
 
 
 3 Longest Cycle Transversals 

 
 In this section, we construct longest cycle transversals of size at most O ⁡ ( log ⁡ n ) O(\log n) in 2 2 -connected chordal graphs. We first prove a folklore lemma. 
 
 
 Lemma 3.1 . 
 
 If G G is 2-connected graph and C 1 C_{1} and C 2 C_{2} are longest cycles in G G , then C 1 ∪ C 2 C_{1}\cup C_{2} is 2 2 -connected. In particular, | V ⁡ ( C 1 ) ∩ V ⁡ ( C 2 ) | ≥ 2 |V(C_{1})\cap V(C_{2})|\geq 2 . 
 
 
 
 Proof. 
 
 Let H = C 1 ∪ C 2 H=C_{1}\cup C_{2} . Note that V ⁡ ( C 1 ) V(C_{1}) and V ⁡ ( C 2 ) V(C_{2}) have nonempty intersection or else applying Theorem   2.5 with ( S , T ) = ( V ⁡ ( C 1 ) , V ⁡ ( C 2 ) ) (S,T)=(V(C_{1}),V(C_{2})) gives two disjoint paths in G G joining C 1 C_{1} and C 2 C_{2} and hence a longer cycle. We show that if V ⁡ ( C 1 ) ∩ V ⁡ ( C 2 ) V(C_{1})\cap V(C_{2}) contains a single vertex z z , then G G has a longer cycle. Since G − z G-z is connected, there is a path P P in G G joining V ⁡ ( C 1 − z ) V(C_{1}-z) and V ⁡ ( C 2 − z ) V(C_{2}-z) . Let x x be the endpoint of P P in C 1 − z C_{1}-z and let y y be the endpoint of P P in C 2 − z C_{2}-z . We obtain a longer cycle by combining P P with the longer x ​ z xz -subpath of C 1 C_{1} and the longer y ​ z yz -subpath of C 2 C_{2} . Therefore | V ⁡ ( C 1 ) ∩ V ⁡ ( C 2 ) | ≥ 2 |V(C_{1})\cap V(C_{2})|\geq 2 . Since C 1 C_{1} and C 2 C_{2} are 2 2 -connected, it follows that H H is also 2 2 -connected.
∎ 
 
 
 
 Let G G be a chordal graph with tree representation T T , and let P P be a path in T T . The components of T − E ⁡ ( P ) T-E(P) containing an endpoint of P P are exterior components , and the components containing an interior vertex of P P are interior components . Note that if P P has no interior vertices, then T − E ⁡ ( P ) T-E(P) has no interior components and either one or two exterior components according to whether | V ⁡ ( P ) | = 1 |V(P)|=1 or | V ⁡ ( P ) | = 2 |V(P)|=2 . 
 
 
 Lemma 3.2 . 
 
 Let G G be a chordal graph with a tree representation T T , let x x and y y be distinct vertices in T T , and let P P be the x ​ y xy -path in T T . If G G has a subgraph H H such that H H has a core vertex in each exterior component of T − E ⁡ ( P ) T-E(P) but no core vertex in any interior component, then H H contains κ ⁡ ( H ) \kappa(H) vertices v v such that S ⁡ ( v ) S(v) contains P P . 
 
 
 
 Proof. 
 
 Let T x T_{x} and T y T_{y} be the exterior components of T − E ⁡ ( P ) T-E(P) containing x x and y y respectively. Let e x e_{x} and e y e_{y} be edges in H H having a core vertex in T x T_{x} and T y T_{y} respectively. Both endpoints of e x e_{x} have subtrees intersecting T x T_{x} , and since H H has no core vertex in an interior component of T − E ⁡ ( P ) T-E(P) , at least one of these endpoints u x u_{x} has a subtree S ⁡ ( u x ) S(u_{x}) that is contained in T x T_{x} . Similarly, let u y u_{y} be an endpoint of e y e_{y} with S ⁡ ( u y ) ⊆ T y S(u_{y})\subseteq T_{y} . Let k = κ ⁡ ( H ) k=\kappa(H) . By Theorem   2.4 , it follows that H H has k k internally disjoint u x ​ u y u_{x}u_{y} -paths Q 1 , … , Q k Q_{1},\ldots,Q_{k} . 
 
 
 We claim that each Q i Q_{i} contains a vertex v i v_{i} with P ⊆ S ⁡ ( v i ) P\subseteq S(v_{i}) . If not, then each vertex v v in Q i Q_{i} has a subtree S ⁡ ( v ) S(v) that is either disjoint from T y T_{y} or disjoint from T x T_{x} . Since Q i Q_{i} has endpoints u x u_{x} and u y u_{y} which are disjoint from T y T_{y} and T x T_{x} respectively, it follows that Q i Q_{i} has adjacent vertices w ​ w ′ ww^{\prime} such that S ⁡ ( w ) S(w) is disjoint from T y T_{y} and S ⁡ ( w ′ ) S(w^{\prime}) is disjoint from T x T_{x} . It follows that S ⁡ ( w ) ∩ S ⁡ ( w ′ ) S(w)\cap S(w^{\prime}) is disjoint from T x ∪ T y T_{x}\cup T_{y} , and so S ⁡ ( w ) ∩ S ⁡ ( w ′ ) S(w)\cap S(w^{\prime}) has all its vertices contained in the interior components of T − E ⁡ ( P ) T-E(P) , contradicting that the core of H H is disjoint from those components.
∎ 
 
 
 
 A rooted tree representation of a chordal graph G G is a tree representation T T such that T T is a rooted tree. Let G G be a chordal graph with a rooted tree representation T T , let X X be the subtree of T T rooted at x x , and suppose that X X has the core capture property for a collection ℋ \mathcal{H} of longest paths or longest cycles in G G . We often make progress by finding a proper subtree X ′ X^{\prime} of X X and a small set of vertices A A in G G such that for each H ∈ ℋ H\in\mathcal{H} , either H H intersects A A or H H has a core vertex in X ′ X^{\prime} . Let z ∈ V ⁡ ( X ) z\in V(X) and let Q Q be the x ​ z xz -path in X X . Recall that D X ​ ( Q , Q ) D_{X}(Q,Q) equals the subgraph X − E ⁡ ( Q ) X-E(Q) , and therefore X X and D X ​ ( Q , Q ) D_{X}(Q,Q) have the same vertex set. It follows that D X ​ ( Q , Q ) D_{X}(Q,Q) also has the core capture property for ℋ \mathcal{H} . It turns out that looking at a minimal subpath Q 0 Q_{0} of Q Q such that D X ​ ( Q 0 , Q ) D_{X}(Q_{0},Q) has the core capture property for ℋ \mathcal{H} is useful in constructing A A . 
 
 
 Lemma 3.3 . 
 
 Let G G be a chordal graph with rooted tree representation T T , let X X be a subtree of T T with root x x , and let Q Q be a subpath of X X such that x x is an endpoint of Q Q .  For a 2 2 -connected chordal graph G G with host tree T T , we give an upper bound on lct ⁡ ( G ) \mathrm{lct}(G) in terms of the value of a 2-player Cutter-Chooser game . In the game, the play by Cutter represents our freedom in constructing the transversal to divide the host tree T T in an advantageous way, and the play by Chooser represents the worst-case scenario for the location of longest cycles not yet covered by our transversal. The name is borrowed from the classic cake-cutting literature, see for example [ 3 ] . The game proceeds in rounds, as follows. 
 
 
 At the start of each round, Cutter is presented with a rooted subtree X X of T T with root vertex x x ; in the initial round, X = T X=T and x x is the root of T T . Cutter selects a vertex z ∈ V ⁡ ( X ) z\in V(X) , and the subtree X X is then cut along the x ​ z xz -path Q Q . The game ends if X = Q X=Q . Otherwise, Chooser responds by selecting a component X ′ X^{\prime} of X − V ⁡ ( Q ) X-V(Q) . Note that X ′ X^{\prime} is a rooted subtree of X X . Let x ′ x^{\prime} be the root of X ′ X^{\prime} . The subtree X ′ X^{\prime} with root x ′ x^{\prime} is presented to Cutter at the start of the next round. Cutter tries to minimize the number of rounds, and Chooser tries to maximize the number of rounds. Let ccg ⁡ ( T , r ) \mathrm{ccg}(T,r) be the number of rounds in the Cutter-Chooser game on T T with root r r under optimal play. For a (non-rooted) tree T T , we define ccg ⁡ ( T ) = min r ∈ V ⁡ ( T ) ⁡ ccg ⁡ ( T , r ) \mathrm{ccg}(T)=\min_{r\in V(T)}\mathrm{ccg}(T,r) . One may view the parameter ccg ⁡ ( T ) \mathrm{ccg}(T) as a slight variant of the Cutter-Chooser game in which Cutter may choose the root vertex r r before the initial round. 
 
 
 In a graph G G , the subdivision of an edge u ​ v uv replaces u ​ v uv with a path of length 2 2 through a new vertex. We say that G ′ G^{\prime} is a subdivision of G G if G ′ G^{\prime} can be obtained from G G by a sequence of zero or more edge subdivisions. Note that ccg ⁡ ( T ) = 1 \mathrm{ccg}(T)=1 if and only if T T is path. A caterpillar is a tree T T containing a spine subpath Q Q such that each leaf in T T has its neighbor on Q Q . If T T is a subdivision of a caterpillar, then Cutter may select the spine path in the first round, forcing Chooser to select some path to start the second round. Cutter then cuts along this path, ending the game. Hence, if T T is a subdivided caterpillar, then ccg ⁡ ( T ) ≤ 2 \mathrm{ccg}(T)\leq 2 . The converse also holds, and so ccg ⁡ ( T ) ≤ 2 \mathrm{ccg}(T)\leq 2 if and only if T T is a subdivided caterpillar. We will need a simple monotonicity property for ccg ⁡ ( T , r ) \mathrm{ccg}(T,r) .

 Suppose that G G is a chordal graph with minimal rooted tree representation T T , let X X be a subtree of T T rooted at x x , and let 𝒫 \mathcal{P} be a family of longest paths such that X X has the core capture property for 𝒫 \mathcal{P} . A u ​ v uv -path P ∈ 𝒫 P\in\mathcal{P} is a round trip path if both S ⁡ ( u ) S(u) and S ⁡ ( v ) S(v) have a vertex outside X X . Although P P may have interior vertices with subtrees contained deep inside X X , we have that P P starts and ends with subtrees that are not contained in X X .  5 Leafage Bounds 

 
 A leaf in a graph is a vertex of degree 1 1 . The leafage of a chordal graph G G , denoted ℓ ⁡ ( G ) \ell(G) , is the minimum number of leaves in a tree representation of G G . Clearly, ℓ ⁡ ( G ) = 0 \ell(G)=0 if and only if G G is complete, and ℓ ⁡ ( G ) ≤ 2 \ell(G)\leq 2 if and only if G G is an interval graph. The notion of leafage was introduced by Lin, McKee, and West  [ 21 ] as a measure on how far a chordal graph is from being an interval graph. Habib and Stacho  [ 13 ] gave a polynomial time algorithm for computing ℓ ⁡ ( G ) \ell(G) . Since each connected interval graph G G satisfies lpt ⁡ ( G ) = 1 \mathrm{lpt}(G)=1 , it is natural to expect that connected chordal graphs with small leafage have small longest path transversals. 
 
 
 Let T T be a tree with root r r . If u ​ v ∈ E ⁡ ( T ) uv\in E(T) and u u is on the r ​ v rv -path in T T , then we say that v v is a child of u u . A vertex with no children is childless . Note that for each vertex u ∈ V ⁡ ( T ) u\in V(T) except r r , we have that u u is a leaf in T T if and only if u u is childless. It follows that the number of leaves and the number of childless vertices differs by at most 1 1 . 
 
 
 Lemma 5.1 . 
 
 Let T T be a tree with root r r and k k childless vertices. There exists a path P P such that r r is an endpoint of P P and every component of T − V ⁡ ( P ) T-V(P) has at most k / 2 k/2 childless vertices. 
 
 
 
 Proof. 
 
 For each vertex v ∈ V ⁡ ( T ) v\in V(T) , let c v c_{v} be the number of childless vertices in T T that belong to the subtree rooted at v v . The set of vertices v v such that c v > k / 2 c_{v}>k/2 induces a path P P with r r as an endpoint, and each component of T − V ⁡ ( P ) T-V(P) has at most k / 2 k/2 childless vertices.
∎ 
 
 
 
 As Cutter can use Lemma  5.1 to select a path in the Cutter-Chooser game, the following is an immediate corollary to Theorem  3.8 and Theorem  4.5 . We omit the details. 
 
 
 Corollary 5.2 . 
 
 Let G G be a chordal graph and let m = ℓ ⁡ ( G ) m=\ell(G) . If G G is connected, then lpt ⁡ ( G ) ≤ O ⁡ ( log 2 ⁡ m ) \mathrm{lpt}(G)\leq O(\log^{2}m) . If G G is 2 2 -connected, then lct ⁡ ( G ) ≤ O ⁡ ( log ⁡ m ) \mathrm{lct}(G)\leq O(\log m) . 
 
 
 
 We now proceed with a slightly more delicate analysis regarding leafage. For a tree T T on at least 2 2 vertices, let f ⁡ ( T ) f(T) be the maximum, over all e ∈ E ⁡ ( T ) e\in E(T) , of the minimum number of leaves of T T contained in a component of T − e T-e . For a connected chordal graph G G with tree representation T T , we show that lpt ⁡ ( G ) ≤ f ⁡ ( T ) \mathrm{lpt}(G)\leq f(T) . Balister, Györi, Lehel, and Schelp [ 1 ] observed that tree representations of connected chordal graphs contain longest path transversal bags; we include a proof for completeness. 
 
 
 Proposition 5.3 (Balister–Györi–Lehel–Schelp [ 1 ] ) .

 Proof. 
 
 Let 𝒫 \mathcal{P} be the family of longest paths in a connected chordal graph G G . As longest paths are pairwise intersecting, for P , Q ∈ 𝒫 P,Q\in\mathcal{P} , there exists w ∈ V ⁡ ( P ) ∩ V ⁡ ( Q ) w\in V(P)\cap V(Q) . It follows that S ⁡ ( P ) S(P) and S ⁡ ( Q ) S(Q) both contain S ⁡ ( w ) S(w) . Therefore the set { S ⁡ ( P ) : P ∈ 𝒫 } \{S(P)\colon\,P\in\mathcal{P}\} is a pairwise intersecting family of subtrees of T T . It follows that B ⁡ ( x ) B(x) is a longest path transversal for G G .
∎

 6 Conclusion 

 
 We close with some open problems on longest path transversals, roughly organized from more difficult questions to easier ones. In each case, there is a natural analogue for longest cycle transversals in 2 2 -connected graphs that is also open. 
 
 
 Problem 6.1 (Walther  [ 29 ] , c.f. Zamfirescu  [ 32 ] ) . 
 
 Is there a constant C C such that every connected graph G G satisfies lpt ⁡ ( G ) ≤ C \mathrm{lpt}(G)\leq C ? 
 
 
 
 Problem 6.2 (Balister–Győri–Lehel–Schelp  [ 1 ] ) . 
 
 Is it true that the family of chordal graphs is Gallai, meaning that lpt ⁡ ( G ) = 1 \mathrm{lpt}(G)=1 for each connected chordal graph G G ? 
 
 
 
 If a positive resolution to Problem   6.2 remains elusive, constant upper bounds for chordal graphs would be very interesting. 
 
 
 Problem 6.3 . 
 
 Is there a constant C C such that every connected chordal graph G G satisfies lpt ⁡ ( G ) ≤ C \mathrm{lpt}(G)\leq C ? 
 
 
 
 By restricting the allowed host trees, we obtain various subfamilies of chordal graphs. When the host tree is restricted to be a path, we obtain the interval graphs. Corollary   5.8 shows that when the host tree is restricted to be a subdivided star, we still obtain a Gallai family. 
 
 
 Conjecture 6.4 . 
 
 If G G is a connected chordal graph admitting a tree representation T T such that T T is a subdivided caterpillar, then lpt ⁡ ( G ) = 1 \mathrm{lpt}(G)=1 . 
 
 
 
 From Corollary   4.6 , we have that lpt ⁡ ( G ) ≤ 26 \mathrm{lpt}(G)\leq 26 when the hypotheses of Conjecture   6.4 apply. Perhaps the easiest interesting special case of Conjecture   6.4 is the case that the host tree T T is a subdivided double star, meaning that T T has at most two vertices with degree at least 3 3 .
