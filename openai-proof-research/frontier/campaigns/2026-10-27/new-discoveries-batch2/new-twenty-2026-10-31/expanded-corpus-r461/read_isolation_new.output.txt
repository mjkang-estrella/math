                                          1        Introduction
                                          The Isolation Lemma, introduced by Mulmuley, Vazirani, and Vazirani [2], is a basic tool in
                                          randomized algorithms. In one common form, one has a hypergraph H whose edges encode the
                                          possible solutions to a search problem. A random weight assignment to the vertices is chosen, and
                                          one hopes there is a unique edge of minimum weight. Such a weight assignment is called isolating.
                                          When this occurs, the original search problem has been reduced to a unique-solution problem.
                                              The classical Isolation Lemma in [2] gives a lower bound of dn (1 − n/d) for the number of
                                          isolating weight assignments. Ta-Shma [4] improved the bound to (d − 1)n via a simple and elegant
                                          argument. This was investigated further by Faber & Harris [1], with a number of improved bounds;
                                          in particular, they conjectured that the minimum is attained by the singleton hypergraph, whose
                                          edges are {1}, . . . , {n}. They showed the conjecture for several special cases as well as an asymptotic
                                          regime.
                                              In this note, we fully prove the conjecture of [1], giving the tight extremal bound on the number
                                          of isolating assignments. We will work in a slightly more general setting. Throughout, H is a
                                          non-empty inclusion-free hypergraph on vertex set [n] = {1, . . . , n}. For a function f : H → R and
                                          weight assignment w : [n] → Z, we define the weight of an edge e by

2    Definitions and basic reductions
We define MH,f (w) to be the set of minimum-weight edges, i.e.

                       MH,f (w) = {e ∈ H : f w(e) ≤ f w(h) for every h ∈ H}.

The weight assignment w is isolating if |MH,f (w)| = 1, that is, there is exactly one minimum-weight
edge. In that case, the unique minimum-weight edge is called the isolated edge. Note that, since H
is inclusion-free, the set family MH,f (w) is necessarily an antichain.
    For a set S ⊆ [n], we define the indicator vector for S by χS , i.e.

    The key insight of [4] was that an arbitrary weight assignment could be transformed into an
isolating assignment by subtracting the indicator of a minimum-weight edge.

Proposition 2 ([4]). Let e ∈ MH,f (w) for a weight assignment w. Then the weight assignment

                                              u = w − χe

is isolating, with isolated edge e.

Proof. Let h ∈ H with h ̸= e. Then

                               f u(h) − f u(e) = f w(h) − f w(e) + |e \ h|

antichain.

    Following [1], we will partition the isolating assignments by layers, and show an extremal bound

of w(i) over i ∈ [n]. Define

                     Z(H, d, f ) = {w ∈ [d]n : w is isolating for H, f }
                    Zj (H, d, f ) = {w ∈ Z(H, d, f ) : w in layer j},               for j ∈ [d]

Theorem 5. Let d, n ≥ 1. For every H, f , we have

Let us fix non-empty inclusion-free H and d, f . For a weight assignment w ∈ [d]n , define

                                     I(w) = {i ∈ [n] : w(i) = 1}.

    We refer to the elements of I(w) as one-coordinates of w. With this notation, define

                X = Z1 (Sn , d, 0) = {w ∈ [d]n : |I(w)| = 1}
                U = Z1 (H, d, f ) = {w ∈ [d]n : w is isolating for H, f and I(w) ̸= ∅}

    Then
                                            |X| = n(d − 1)n−1 .
The goal of this section is to prove that

                                                   |U | ≥ |X|.

     The proof strategy is to construct non-negative charges a(w, u) for w ∈ X and u ∈ U , such that
every w ∈ X sends total charge at least one and every u ∈ U receives total charge at most one. By
a double-counting argument, this will imply that |U | ≥ |X|. It is similar to the proof strategy of
[1], which constructed a bipartite graph between X and U ; the key difference is to allow fractional
weights for each pair a(w, u).

5     Extensions
Note that Theorem 1 requires the hypergraph H to be inclusion-free. An equivalent formulation is
to allow H to be arbitrary and require that f be an inclusion-monotone set function, i.e. f (e) ≤ f (h)
for e ⊆ h. In this case, given nested edges e ⊊ h, the edge h can never be a minimum-weight edge
and can simply be removed. The resulting hypergraph becomes inclusion-free automatically.

   Even more generally, the proof of Theorem 5 uses only two properties of the objective function.
Namely, suppose that H is an arbitrary hypergraph (not necessarily inclusion-free), and for each
w ∈ [d]n , e ∈ H we have an objective value Fw (e) in some fixed totally-ordered set. Define

                     MF (w) = {e ∈ H : Fw (e) ≤ Fw (h) for all h ∈ H}
                   Z(H, d, F ) = {w ∈ [d]n : |MF (w)| = 1}
                  Zj (H, d, F ) = {w ∈ Z(H, d, F ) : w in layer j},     for j ∈ [d]

   If we assume that, for every weight assignment w ∈ [d]n , the two properties hold:
 (A) MF (w) is an antichain

 (B) for every private pair (e, S) of MF (w) with w − χS ∈ [d]n , there holds MF (w − χS ) = {e}.
then the proof of Theorem 5 applies without change and gives

                                   |Z1 (H, d, F )| ≥ n(d − 1)n−1 ,

and, via the shifting argument used in the proof of Theorem 1,
