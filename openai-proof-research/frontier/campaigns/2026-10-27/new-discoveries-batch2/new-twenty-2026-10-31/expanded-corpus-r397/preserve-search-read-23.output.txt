define the Wiener index Wσ (G) of the signed graph (G, σ) by Wσ (G) = 2 u,v∈V (G) dσ (u, v).

Observe that if σ is a constant function, then dσ (u, v) = d(u, v), and hence Wσ (G) = W (G).
In particular, if W (G) = W (G − v) for all v ∈ V (G), then there exists a (constant) signing σ
of G such that Wσ (G) = Wσ (G − v). Thus the problem of finding signed graphs (G, σ) with
Wσ (G) = Wσ (G − v) can be viewed as a relaxation of Šoltés’ problem.
In this paper we give many examples of signed graphs satisfying Wσ (G) = Wσ (G − v) for all
v ∈ V (G), and even with Wσ (G) = Wσ (G − S) for any set S of size less than some value k.
All of these examples rely heavily on the fact that, in the signed setting, it is possible to have
Wσ (G) = 0. More generally, we use the following definition.

Definition 2. We say that a signing σ of a graph G is k-canceling if for any set S ⊆ V (G) of
size less than k, we have Wσ (G − S) = 0. We say that a graph G is k-canceling if there exists
a k-canceling signing σ of G. We will refer to 1-canceling graphs (i.e. those with Wσ (G) = 0
for some σ) simply as canceling graphs.

In Section 4 we construct several families of graphs which are k-canceling for any given value of
k. We postpone describing these results, and instead focus on the nicest cases of k = 1, 2. To
state our main result, we recall that the square of a graph G, denoted G2 , is the graph which
