## 1. Target and literal binding

Corpus literal (MathDB 344875; binding in corpus-bindings.json): with S_n(k) the regular palm with n arms of length k,
for k >= 4, chi_L(S_n(k)) = (1+o(1)) ((k-1)/2) (4n)^{1/k}.

Source: Hafidh and Baskoro, On the Locating Chromatic Number of Trees, arXiv:1912.05775v2 (17 Nov 2020), Conjecture 5.1, p.10.
The corpus literal matches the printed conjecture. Section 5 fixes k and considers chi_L as a function of n, so o(1) is as n -> infinity with k fixed.
Source definition (p.2): vertices a_0 and a_{i,j}, 1<=i<=n, 1<=j<=k; edges a_0 a_{i,1} and a_{i,j} a_{i,j+1}.
Source definition (p.1): c: V -> {1,...,p} is a locating p-coloring if every two vertices are resolved by a color class.
"k-coloring" is read as a proper coloring with nonempty classes, the standard convention (Chartrand et al.), and the one the source's own proofs use: Theorems 5.2 and 5.3 take c(x_i) in A, away from the hub color. An empty class would have undefined distance.

Write kappa_k = ((k-1)/2) 4^{1/k} for the printed constant.

## 2. Result

Put l = floor(k/2), u = ceil(k/2), with 0^0 = 1, and beta_k = (l^l u^u)^{1/k}. So beta_k = k/2 for even k, and beta_k = (r^r (r+1)^{r+1})^{1/k} for k = 2r+1.

THEOREM. For every k >= 2 there are C_k and n_0(k) such that for all n >= n_0(k),
  beta_k n^{1/k} - l + 1 <= chi_L(S_n(k)) <= beta_k n^{1/k} + C_k.
Hence chi_L(S_n(k)) / n^{1/k} -> beta_k.

COROLLARY (negation of the literal). beta_k < kappa_k for every k >= 4. So chi_L(S_n(k)) / (kappa_k n^{1/k}) -> beta_k/kappa_k < 1 for every k >= 4, and the printed conjecture is false at every k >= 4. For k=4: beta_4 = 2 and kappa_4 = (3/2) sqrt 2 = 2.1213...

Consistency with the source's proved cases: beta_1 = 1 (chi_L = n+1), beta_2 = 1 (chi_L = ceil(sqrt n)+1), beta_3 = 4^{1/3} (Theorem 5.3). The printed formula agrees with beta_k exactly at k = 2, 3.

## 3. Lower bound: the level-window count

Let c be a locating p-coloring of S_n(k), h the hub color, m = p-1. For a color t != h let D_t = d(a_0, c^{-1}(t)) in {1,...,k}, and set L_s = {t != h : D_t = s}, a_s = |L_s|, so sum a_s = m. A color at position j has D_t <= j.

LEMMA 1. n <= a_1 * prod_{j=2}^{k} (a_{j-1} + a_j + 1).

Proof. Let x_i = a_{i,1}; by properness c(x_i) in L_1. For any color t and arm i,
  d(x_i, c^{-1}(t)) = min( 1 + D_t , min{ j-1 : c(a_{i,j}) = t } ).
(A t-vertex off arm i, or the hub, is at distance at least 1 + D_t. A t-vertex on arm i at position j is at distance j-1. If the depth-D_t vertex lies on arm i, then 1+D_t is an overestimate, but the second term is then smaller, so the minimum is still correct.)
If c(a_{i,j}) = t with D_t = s and j >= s+2, then j-1 >= 1+D_t and that occurrence does not affect the minimum. So only positions j in {s, s+1} matter.
Define y_j = c(a_{i,j}) if that color lies in L_{j-1} union L_j, and y_j = * otherwise (2<=j<=k). Then the code of x_i is a function of (c(x_i), y_2, ..., y_k). Two arms with the same data would give two same-colored vertices with equal codes, which is forbidden. The number of data values is at most the stated product. QED

LEMMA 2. n <= (m+l)^k / (l^l u^u). Consequently p >= beta_k n^{1/k} - l + 1.

Proof. Let t_1 = a_1 and t_j = a_{j-1}+a_j+1. The u odd-indexed factors have sum a_1+...+a_{(last odd)} + (u-1) <= m+l when k is odd, and <= m+u-1 = m+l-1 when k is even. The l even-indexed factors have sum a_1+...+a_{(last even)} + l <= m+l. AM-GM on each group gives prod t_j <= ((m+l)/u)^u ((m+l)/l)^l. QED

## 4. Upper bound: the construction

LEMMA 3. Let L_1,...,L_k be pairwise disjoint color sets, not containing h, with a_s = |L_s|. Let A be the set of tuples x = (x_1,...,x_k) with x_1 in L_1, x_j in L_{j-1} union L_j for j>=2, and x_j != x_{j+1}. Color the hub h and let n distinct tuples of A be the arms. If every color of union L_s occurs in some chosen tuple, this is a locating (1+sum a_s)-coloring of S_n(k).

Proof. Proper: x_1 != h since h is outside the L_s, and adjacent entries differ. All classes are nonempty.
A color t in L_s can occur in a tuple only at positions s or s+1, and not at both since they are adjacent. So t occurs at most once per arm. Let D_t be its actual depth; then s <= D_t <= s+1.
Let v = a_{i,j} with tuple x. Since h occurs only at the hub, d(v, c^{-1}(h)) = j; this coordinate determines the depth, and the hub is the only vertex with value 0 there.
Fix t in L_s. If t occurs on arm i at position q in {s,s+1}: every other t-vertex is on another arm at depth >= D_t, so at distance >= j+D_t, while |j-q| <= j+q-2 <= j+D_t-1 < j+D_t. Thus d(v,c^{-1}(t)) = |j-q| < j+D_t. If t does not occur on arm i then d(v,c^{-1}(t)) = j+D_t exactly.
So the code of v and the depth j determine which colors occur on arm i and, for each such t in L_s, the value |j-q|. Since |j-s| and |j-s-1| have different parity they are different, so q is determined. Hence the code determines the entire tuple x. Two vertices with equal codes have equal depth and equal tuple, so they are the same vertex. QED

Count. Choosing x_1, x_2, ... in turn gives |A| >= a_1 * prod_{j=2}^k (a_{j-1}+a_j-1).
Coverage. If a_1 >= 2 and a_{j-1}+a_j >= 2 for 2<=j<=k, every color occurs in some tuple of A (fix it at its own position and extend outward step by step, each step having at least two options). So whenever M := sum a_s <= n <= |A|, one may choose n tuples containing a tuple through every color.

Profiles.
* k = 2r: a_{2i-1} = b, a_{2i} = 0, with b = ceil(n^{1/k})+1 >= 2. Then |A| >= b (b-1)^{k-1} >= n, and p = 1+rb <= r n^{1/k} + 2r + 1.
* k = 2r+1 (r>=1): a_{2j+1} = (r-j)w for 0<=j<=r and a_{2j} = jw for 1<=j<=r, with w = ceil(y)+2 and y = (n / (r^{r+1}(r+1)^r))^{1/k}. The window sizes are a_{2i-1}+a_{2i} = (r+1)w and a_{2i}+a_{2i+1} = rw, and a_1 = rw. So |A| >= rw ((r+1)w-1)^r (rw-1)^r >= (ry)^{r+1} ((r+1)y)^r = n, using rw-1 >= ry and (r+1)w-1 >= (r+1)y. Also p = 1 + r(r+1)w <= beta_k n^{1/k} + 3r(r+1) + 1, since r(r+1)y = beta_k n^{1/k}.
In both cases M = O(n^{1/k}) <= n for n >= n_0(k). QED (Theorem)

Proof of the Corollary. beta_k^k = l^l u^u and kappa_k^k = 4((k-1)/2)^k.
For k = 2r, r>=2: kappa^k/beta^k = 4(1-1/(2r))^{2r} >= 4(3/4)^4 = 81/64 > 1.
For k = 2r+1, r>=2: kappa^k/beta^k = 4 r^{2r+1}/(r^r (r+1)^{r+1}) = 4(1-1/(r+1))^{r+1} >= 4(2/3)^3 = 32/27 > 1.
Both use that (1-1/x)^x increases in x > 1. QED

Worked check (k=4, b=2, colors {1,2},{3,4}, hub 0; arms 1234, 1243, 2134, 2143): the position-1 vertex of arm 1234 has code (to colors 0,1,2,3,4) = (1,0,1,2,3), and of arm 1243 has code (1,0,1,3,2); they differ as Lemma 3 predicts. This hand check is illustrative only and is not part of the proof.

## 5. Where the printed constant comes from

The Lemma 1 product at the uniform allocation a_1=...=a_{k-1}=m/(k-1), a_k=0 is 2^{k-2}(m/(k-1))^k = (1/4)(2m/(k-1))^k, which is exactly the count the printed constant kappa_k corresponds to. This reconstruction is mine; the source does not state how it obtained Conjecture 5.1. The true optimum is not uniform: the factors split into odd-indexed and even-indexed groups, each with total at most about m, and for even k the optimum puts weight 2/k on every other level and zero on the rest.

## Proof route for the k=4 endpoint (only the Lemma 3 half is needed)

The negation needs only the upper bound along one subsequence, so Lemmas 1 and 2 are NOT required.
1. Fix b >= 2 and N_b = (b(b-1))^2. Arms are indexed by quadruples (x1,x2,x3,x4), x1 != x2 in Fin b, x3 != x4 in Fin b. Use the full family, which removes the coverage/selection step.
2. Spider distance lemmas: dist(hub,(i,j)) = j+1 (0-indexed j); same-arm distance is |j-j'|; different-arm distance is j+j'+2. Prove with an explicit walk for the upper bound and a depth/arm potential that is 1-Lipschitz for the lower bound.
3. Colors: Fin (2b+1), hub color 0, block one colors 1..b, block two colors b+1..2b. Show properness and surjectivity.
4. Code computation from Lemma 3 specialised to k=4; injectivity by reading the hub coordinate and then each block's two small values, using that |j-s| != |j-s-1|.
5. Conclude chiL (palm N_b 4) <= 2b+1.
6. Real analysis: (2b+1) / ((3/2) * (4 N_b)^(1/4)) = (2b+1) / ((3/2) sqrt 2 sqrt(b(b-1))) tends to 2 sqrt 2 / 3 < 1, and N_b -> infinity; a Tendsto to 1 along n would contradict this. Eventually the ratio is below 19/20, which can be proved by clearing the fourth root.
