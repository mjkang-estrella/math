# Addendum to the discovery brief for the public-claim follow-up (root Claude Fable 5.2, 2026-11-19)

These lanes look for replacements for a public list of "open MathDB problems solved by AI, each with a kernel-checked Lean proof". A replacement must carry no flag at all, so on top of `root-intake-r60/FABLE-DISCOVERY-BRIEF.md`:

- Record fidelity is part of triage. Compare the MathDB record with the conjecture as printed in the source before investing. If the record mis-transcribes the source (wrong start position, missing hypothesis, a paraphrase that makes the statement trivially true or false), report the id as RECORD_DEFECT and move on; it cannot be used here even if the source conjecture is solvable.
- The literal statement must be the one resolved. No "true except for a degenerate case", no one-sided reading of a two-sided claim, no half of a two-part conjecture.
- Not a duplicate of another MathDB record that is already accepted, and not a second conjecture from the same section of a source paper that already has an accepted result (the accepted list is in the two files the main brief names, plus `C/ledger.json` key `accepted`).
- It must survive the question "would a specialist call this routine?". Before writing a proof, write down the shortest route from published theorems and from the source paper's own lemmas; if it is a few lines, mark ROUTINE. A counterexample that the source authors would have found by checking the first few small cases is TRIVIAL.
- Prior art: besides the sources in the main brief, use the arXiv API for keyword search (`http://export.arxiv.org/api/query`, at most one request per 3 seconds), OpenAlex and Semantic Scholar citing lists, and `gh search code` on the arXiv id and the conjecture name. The omega registry is cloned at `/tmp/claude-1000/-home-mj-kang-Documents-Dev-math/03704234-97d1-47f1-8192-8d8ee0dea55c/scratchpad/omega/repo` (set `OMEGA_REPO` to it when running `root-intake-r60/omega-screen.py`); the openai/math registry is cloned at `/tmp/claude-1000/-home-mj-kang-Documents-Dev-math/75a48aa2-847d-4c84-96d4-c7a2d5bb5b22/scratchpad/shared/openai-math`.
- Lean cost matters: prefer resolutions whose literal endpoint is under about 800 lines (explicit finite counterexamples with a checkable certificate, inductions, exact formulas). Say so honestly when a result needs heavy theory that Mathlib lacks.
- In REPORT.md add, per SOLVED item, a line `FLAGS: none` or the list of flags.
