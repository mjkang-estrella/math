## Qualifiers every version needs

1. **"Open" means "no earlier resolution found in a stated search", not "new to the world".** Searched for every result: all arXiv versions and the journal version where open; papers citing the source (OpenAlex, Semantic Scholar); web search; the openai/math registry; the omega registry including its GitHub issues and pull requests; ProbXiv where reachable; GitHub code search; the Principia archive; from 2026-11-20 also the ReuF2F benchmark (github.com/cmu-l3/reuF2F). Not searched: mathdb.com itself, Google Scholar, the arXiv search API (all refuse automated clients), and publisher full texts listed as unread. From 2026-11-23 the public repository github.com/mxym/math is also searched (by source arXiv id), after one candidate was found already proved there.
2. **The search missed things before a later lane caught them.** In round 3 several claims were found public only at review or final check (for example a refutation already posted in an omega issue; proofs published by the same authors days after the source). Expect a specialist to find prior work for a few rows.
