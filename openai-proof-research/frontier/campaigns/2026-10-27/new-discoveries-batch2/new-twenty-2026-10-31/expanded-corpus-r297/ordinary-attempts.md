## 365923: every binary graphical description

Read Definition 4.1 (exact orthogonality graphs), Definitions 4.4 and 4.6 (orthogonal vector coloring and validity), Proposition 4.12, Conjecture 4.13, Table 1, and Propositions 4.14–4.18 with proofs. Both arXiv versions and the February 19, 2026 SIAM version retain the conjecture. Isolated vertices count as components. Each pair must be an edge in at least two of the d graphs; arbitrary tuples of biclique unions are not valid automatically.

Write M=2^(d-1). The full endpoint is r+sum c_j<=M+d, with equality implying r=M. The source proves r<=M and that at r=M every graph is the balanced complete bipartite graph. Those are public results. When r<M the remaining target is the strict inequality sum(c_j-1)<M-r.

Route 1: choose a bipartition of each component. After deleting coordinate j, the binary labels of the r vertices are distinct: equal labels would allow an edge only in G_j, violating double coverage. Two occupied labels at Hamming distance one must be adjacent in G_j. On a Hamiltonian cycle of the punctured cube, start with a missing label. For each component of G_j, take its first occupied label; its predecessor is missing, since an occupied predecessor would be adjacent and belong to the same component. Distinct components give distinct predecessors. Thus c_j<=M-r. This reproduces the actual proof of source Proposition 4.18, not a new result.

Summing only yields r+sum c_j<=r+d(M-r). Its excess over M+d is (d-1)(M-r)-d, which may be positive. The same absent label can be charged separately in several punctured coordinate systems. If all but one graph are connected the desired strict bound follows immediately, as in source Corollary 4.19. Multiple disconnected coordinates remain unresolved. A successful continuation needs compatible labelings and disjoint charges for all excess components with strict slack. Neither independently orienting components nor separately choosing Hamiltonian cycles provides that compatibility.

Route 2: delete a summand v. Let t_j(v) count components replacing its old component in G_j-v. Then c'_j=c_j-1+t_j(v), so the parameter P=r+sum c_j satisfies P-P'=d+1-sum t_j(v). A singleton has t=0; a biclique with both shores still nonempty has t=1; deleting the sole vertex on one shore produces as many isolated components as vertices in the other shore. Deletion can therefore increase P. Restriction preserves validity but loses information about how v connected those components. Induction on r with only the source bound r<=M does not control the component gains. A next lemma must choose a structurally suitable v and track shore sizes or coordinate mergers in a stronger potential. No such potential is proved. Small d<=4 checks are already in the source and would not give the universal endpoint.

Route 3: realize the description by normalized vectors. Removing one tensor factor leaves r orthogonal nonzero product vectors in an M-dimensional space, proving only r<=M. Independent rotations of biclique components explain the source expected parameter dimension. It is tempting to put each component rotation beyond the d global rotations into the orthogonal complement, dimension M-r. But orthonormal frames have derivatives inside their own span (skew infinitesimal rotations), and derivatives from different coordinates may be dependent. Orthogonality does not supply the required injection. A full proof needs an injective map from excess component parameters into that complement and a strictness argument. This bridge is unproved. HOLD, no Pi plan. Citing works, orthogonal-product-basis literature and corrections are not exhaustively qualified.

## 349583: prime-power domination without divisibility

Read Racicot–Rosso Definition 1.1, Theorem 2.6 and its constructive proof, Section 4 and Conjecture 4.2. All four arXiv versions retain the conjecture. The journal landing page identifies v4 as its PDF. All logarithms are base two. The graph has even n>=6, vertices Z_n, and edge sums 2^t-1 modulo n for 1<=t<=floor(log_2 n). Put q=p^k. The strict phi(q)<ceil(log_2 n) ensures the primitive-root exponent range is available. Tiny undefined n are not significant counterexamples.

Route 1: when q divides n, source Theorem 2.6 uses residues 0,-1 modulo q. At least one of x,x+1 is a unit modulo q. Choose i with 2^i congruent to that unit. The neighbor 2^i-1-x, reduced modulo n, lies in the required class. This is the complete routine source bridge, with zero credit. When n=Lq+r, 0<r<q, reduction modulo n changes the residue modulo q by a multiple of r. The step of adding n while remaining in the q-class is false. Translating and truncating two residue classes does not control which representatives wrap. A cardinality bound on that set does not establish domination. Missing lemma: a phase choice that covers every seam vertex while staying within ceil(2n/q), including its at-most-one rounding allowance.

Route 2: translate averaging. The source sum graph is not generally invariant under translation: shifting both endpoints by a changes the edge-sum by 2a, which need not preserve the set of permitted sums. One cannot invoke vertex transitivity to obtain a dominating translate of a truncated residue pattern. Averaging uncovered vertices would still require adding vertices in an alteration step. The claimed size budget allows no positive additive error at divisible orders, and at most one rounding unit generally. An O(log n) seam bound is insufficient. A complete argument needs zero uncovered vertices for an admissible phase or a replacement exchange preserving all previously covered vertices. Neither is proved.

Route 3: a nearby divisible order n'=q*ceil(n/q) is a different modular graph. Reduction Z_(n') to Z_n is not a group homomorphism unless n divides n', and the logarithmic degree cutoff may change. Restricting its known dominating set supplies neither an edge-preserving map nor the desired cardinal control. A comparison theorem including seams and cutoffs is missing. HOLD. The cited fixed-degree Knödel papers do not automatically cover this variable-degree endpoint; their bodies and all citing works remain qualification gaps.
