Source conventions (Section 2 of the source):
- R⁺ = [0, ∞).
- A labeled tree T(l) has a labeling l : V(T) → R⁺. It defines d_l(u,u) = 0 and, for u ≠ v, d_l(u,v) = max{l(w) : w on the path from u to v}, endpoints included.
- d_l is an ultrametric exactly when max{l(u), l(v)} > 0 for every edge uv (source Theorem 2.12).
- "(X,d) is generated by T(l)" means X = V(T) and d = d_l.
- A ray is a one-way infinite path (x₁, x₂, …).
- A tree is starlike if exactly one vertex has degree greater than 2. It is rayless if it contains no ray.

**Conjecture 6.2.** Let (X,d) be an infinite ultrametric space. The following are equivalent:
- (i) (X,d) is the completion of a totally bounded X₀ ⊊ X generated by a labeled ray;
- (ii) there is a starlike rayless tree T with a labeling l : V(T) → R⁺ such that (X,d) is a compact ultrametric space generated by T(l).

In (i), "X is the completion of X₀ ⊆ X" means that X is complete and X₀ is dense in X. The metric on X₀ is the restriction of d, and it equals the ray metric. The source's Theorem 5.6 is the special case of decreasing ray labels against star graphs.

## 2. Two elementary facts

**Fact 1 (isolated points).** Let T(l) generate an ultrametric. Let y be a vertex of finite degree with at least one neighbour. Then y is isolated in (V(T), d_l).
- Put η_y = min over neighbours w of y of max{l(y), l(w)}. This is positive by the edge condition.
- For z ≠ y, the path from y to z contains y and one neighbour of y. So d_l(y,z) ≥ η_y.

**Fact 2.** In a compact metric space, a closed set that consists only of isolated points is finite.

## 3. (i) ⇒ (ii)

Let X₀ = {x₁, x₂, …} be generated by the ray R = (x₁, x₂, …) with labels λ_n = l(x_n) ≥ 0. No two consecutive labels are zero. Assume X₀ is totally bounded, X₀ ⊊ X, X is complete and X₀ is dense in X.

**Step 1: λ_n → 0.**
- Fix ε > 0. Every point x_n with λ_n ≥ ε satisfies d(x_n, z) ≥ λ_n ≥ ε for every other z ∈ X₀.
- So any two such points are at distance at least ε.
- Total boundedness at radius ε/2 therefore allows only finitely many such n.

**Step 2: the limit point and its distances.** Define M_n = sup_{k≥n} λ_k.
- The supremum is a maximum. Some label at an index k ≥ n is positive, because there are no two consecutive zeros. Since λ → 0, only finitely many later labels can be at least that large. Hence M_n > 0.
- Every x_n is isolated in X₀ by Fact 1 (R has degrees at most 2). By density it is also isolated in X: if d(y, x_n) < η/2, the approximants z ∈ X₀ of y within η/2 all equal x_n, so y = x_n.
- Take y ∈ X ∖ X₀. It is a limit of points x_{n_j} ∈ X₀. Every index occurs only finitely often in (n_j), since a constant subsequence would give y ∈ X₀. Hence n_j → ∞.
- For fixed m and n_j ≥ m, d(x_m, x_{n_j}) = max_{m≤k≤n_j} λ_k. This equals M_m once n_j passes the last index where the maximum M_m is attained. So d(y, x_m) = M_m.
- If y' is another point of X ∖ X₀, then d(y, y') = lim d(x_{n_j}, x_{n'_j}) ≤ lim sup_{k ≥ min(n_j, n'_j)} λ_k = 0.
- So X = X₀ ∪ {p} with d(p, x_m) = M_m.

**Step 3: records.** Call r a record if λ_r ≥ λ_k for all k > r.
- Fix n and let K be the largest index k ≥ n with λ_k = M_n. K exists because the set is finite and nonempty. K is a record.
- Hence the records r₁ < r₂ < … form an infinite set.
- Let r(n) be the least record ≥ n. Then λ_{r(n)} ≥ λ_K = M_n ≥ λ_{r(n)}, so λ_{r(n)} = M_n.

**Step 4: the tree.** Put r₀ = 0. The legs are L_i = (x_{r_{i−1}+1}, …, x_{r_i}) for i ≥ 1.
- Vertex set of T: X.
- Edges of T: x_k x_{k+1} whenever both lie in the same leg, and p x_{r_i} for every i.
- Labels: l(x_k) = λ_k and l(p) = 0.

T is a tree whose legs are finite paths, each joined to p at its last vertex.
- p has infinite degree. Every other vertex has degree at most 2. So T is starlike.
- A ray visits p at most once and would then have to stay inside a finite leg. So T is rayless.
- Edge condition. Inside a leg it is inherited from R. On the edge p x_{r_i}, λ_{r_i} = M_{r_i} > 0.

**Step 5: d_l = d.** Take x_n ∈ L_i, so r_{i−1} < n ≤ r_i, and note r(n) = r_i.
- (a) For x_n, x_m in the same leg, the tree path is the ray segment, so the distances agree.
- (b) The tree path from x_n to p runs through x_n, …, x_{r_i}, p. The labels on x_n, …, x_{r_i} are at most M_n, and λ_{r_i} = M_n. So d_l(x_n, p) = M_n = d(x_n, p).
- (c) Take x_n ∈ L_i and x_m ∈ L_j with i < j, so n < m.
  - The tree distance is max(M_n, 0, M_m) = M_n.
  - The ray distance max_{n≤k≤m} λ_k includes index r_i, because n ≤ r_i < m. So it is at least λ_{r_i} = M_n. It is also at most M_n. Hence the two agree.

**Step 6: compactness.** X is complete. It is totally bounded because the closure of the totally bounded set X₀ is totally bounded. So X is compact, and (ii) holds.

## 4. (ii) ⇒ (i)

Let X be infinite and compact, generated by T(l), with T starlike and rayless.

**Step 1: shape of T.**
- Let c be the unique vertex of degree greater than 2. Every other vertex has degree at most 2.
- Each component P of T − c is a connected acyclic graph of maximum degree at most 2 with no ray. So P is a finite path.
- c has exactly one neighbour in P. Two neighbours would create a cycle.
- That neighbour is an end of P. Otherwise it would have degree 3.
- If c had finite degree, T would be finite, contradicting the assumption that X is infinite.
- So T consists of c and infinitely many legs c – y₁ – … – y_r, each a finite path.

**Step 2: l(c) = 0.** Choose the first vertices y₁ of infinitely many distinct legs. Any two of them are at distance at least l(c), since their path passes through c. If l(c) > 0, this would be an infinite l(c)-separated set in a compact space, which is impossible.

**Step 3: heights.** For y ≠ c, put h(y) = d(c,y). On a leg, h(y_a) = max{l(y₁), …, l(y_a)}.
- h(y) > 0: the edge c y₁ forces l(y₁) > 0.
- Every y ≠ c is isolated by Fact 1.
- Hence, by Fact 2, the closed set {y : h(y) ≥ ε} = X ∖ B(c, ε) is finite for every ε > 0.

**Step 4: groups.** On each leg, call index s a strict prefix record if l(y_s) > max{l(y₁), …, l(y_{s−1})}, taking the maximum of the empty set to be 0. Index 1 is always such a record.
- Group of s: G_s = {y_s, y_{s+1}, …, y_e}, where e is the index before the next record (or the end of the leg).
- h is constant on G_s and equal to h_G := l(y_s).
- Every label in G_s is at most h_G.
- Two different groups of the same leg have different h. Groups further from c have larger h.

**Step 5: the ray.**
- Order the groups by decreasing h_G, breaking ties arbitrarily. By Step 3, each group is preceded by only finitely many groups. There are infinitely many groups because X₀ := X ∖ {c} is infinite and each group is finite. So this ordering has order type ω.
- Write each group in the order y_{s+1}, y_{s+2}, …, y_e, y_s. Concatenating the groups gives an enumeration x₁, x₂, … of X₀.
- Ray labels: l*(x_k) := l(x_k), the original tree labels.
- Edge condition for consecutive pairs:
  - y_i, y_{i+1} inside a group were adjacent in T;
  - (y_e, y_s) and the pair across a group boundary contain the record y_s(G), whose label h_G > 0.

**Step 6: the ray metric equals d on X₀.** Let u precede v in the enumeration.
- (a) u, v in the same group, both different from y_s. The ray segment is the tree path between them, so the distances agree.
- (b) u in G, v = y_s(G). The ray distance is h_G, since y_s is in the segment and every label in G is at most h_G. On the tree, the path between u and y_s consists of vertices of G, with maximum label l(y_s) = h_G.
- (c) u in group G, v in a later group G′, so h_G ≥ h_{G′}.
  - The ray segment from u to v passes through y_s(G), which ends G. Every label in the segment is at most h_G. So the ray distance is h_G.
  - On the tree: if u and v lie on different legs, the path passes through c and the distance is max(h(u), h(v)) = h_G.
  - If they lie on the same leg, then h_G > h_{G′}, so G lies further from c. The tree path between them contains y_s(G), and all its labels are at most h(u) = h_G. So the distance is h_G again.

**Step 7: completion.**
- X₀ is dense: by Step 3 there are points y with h(y) = d(c, y) arbitrarily small.
- X is compact, hence complete, and X₀ is totally bounded.
- X₀ ⊊ X, and X₀ is generated by the labeled ray (x₁, x₂, …) with labels l*.
- So (i) holds. ∎
