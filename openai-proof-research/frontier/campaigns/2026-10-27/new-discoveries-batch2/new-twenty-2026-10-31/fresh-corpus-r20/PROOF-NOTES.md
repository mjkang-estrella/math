## 339710 — full ordinary reduction; excluded as classical corollary

Primary source: Albrecht1807.00588v2,27June2020, Definitions1.1/1.2/2.3/3.1, Theorem2.4 proof, Lemma3.2 proof and Section4 Conjecture4.1 all read. A path is a nonempty nonrepeating vertex sequence, including a one-vertex path. A routing consists of vertex-disjoint directed paths covering the starting set and ending in targets. A standard representation has T contained in E, every target an actual sink, and every E-minus-T vertex an actual source. Arc complexity minimizes over **all** standard representations, allowing auxiliary vertices. Thus a mere reachability hub is insufficient: simultaneous vertex-disjoint routing, including avoidance of selected target-elements, is essential.

An initial hub shortcut fails: two selected inputs cannot simultaneously use its single vertex. A second, fully constructive route uses a rearrangeable network, and survives that obstruction. Define B2 with disjoint input and output sets of size2 and all four input-output arcs. For even n>2, take two vertex-disjoint copies of B(n/2), called0 and1, plus new inputs x0,...,x(n-1) and outputs y0,...,y(n-1). For each i and c in{0,1}, add x_i to input floor(i/2) in copy c, and output floor(i/2) in copy c to y_i. No other arcs are added. The endpoints are sources/sinks. The graph is finite, simple and acyclic. Arc recurrence a2=4, a(n)=2a(n/2)+4n gives a4=24,a8=80,a16=224. Vertex recurrence v2=4,v(n)=2v(n/2)+2n gives v16=128.

Here is a full inductive routing proof, not a numerical inference. For a permutation pi on n inputs, form the bipartite multigraph with left vertices input pairs, right vertices output pairs and an edge i from floor(i/2) to floor(pi(i)/2). Every vertex has degree2. Each component is an even cycle (including a parallel-edge2-cycle), so alternating its edges colors them0/1, one of each at every pair. For color c, these edges define a permutation from the n/2 input pairs to the n/2 output pairs. Inductively route that permutation in copy c. Prepend x_i and append y_pi(i) to the path for edge i of color c. Each new input/output appears once, paths within a copy are vertex-disjoint, and the copies are disjoint, so these are n vertex-disjoint paths routing pi. Base n2 is immediate. This proves the routing assertion for **all** permutations, not only tested permutations.

Set E=X disjoint-union Y and T=Y in B16. For any Q subset E with |Q|<=16, put A=Q intersect X and C=Q intersect Y. Choose |A| distinct outputs in Y-minus-C, possible because |A|+|C|<=16, choose any bijection from A to those outputs, and extend it to a permutation X->Y. Retain only the paths starting at A and add the one-vertex paths at C. Because Y consists of sinks, none of the retained paths passes through any other output; thus they avoid C, and all paths are disjoint. Hence Q is independent. Conversely a routing for Q has distinct target endpoints and therefore |Q|<=|Y|=16 (select one path for each distinct starting vertex; two starts cannot use one path since their designated path must start at that vertex). Thus the actual represented gammoid is U16,32, and CA(U16,32)<=224<256. All source semantic bridges are present in this ordinary argument; no minimum arc complexity is asserted.

`benes.py` constructs the actual directed graph, gives the recursive cycle-color routing algorithm and directly validates path endpoints, arcs, simplicity and vertex disjointness for all24 permutations at n4 and256 seeded permutations at n16. All graphs and every tested path are retained in `benes.json`. These are implementation diagnostics; the induction supplies the all-permutation ordinary proof. There is no Lean theorem.

Why exclude: this is a direct standard-representation corollary of classical vertex-disjoint permutation-network/superconcentrator results. Alon–Capalbo2004, *Smaller Explicit Superconcentrators*, actual Sections1,3 and4 Theorem3.1 and full proof read, already gives arbitrarily large N-superconcentrators with44N+O(1) arcs. Exactly the same Q=A union C argument gives CA(U(N,2N))=O(N), contradicting the quadratic conjecture for large N. Section4 uses the recursive edge-count relation, compatible matchings, expansion, Menger and Hall; no new superconcentrator theorem is being supplied here.
