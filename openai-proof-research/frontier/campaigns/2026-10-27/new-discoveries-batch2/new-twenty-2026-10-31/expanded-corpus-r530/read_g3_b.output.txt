0 (mod p) for all n ≥ 0.

Mordell [11] established that the function τ (n) is multiplicative and that for primes p, the sequence
of values τ (pm ) for m ≥ 0 satisfy the recurrence relation
                                        τ (pm+1 ) = τ (p)τ (pm ) − p11 τ (pm−1 ).
Note that this recurrence relation is itself a useful tool for proving certain kinds of congruence prop-
erties. For example, from the fact that τ (2) = 24 we may deduce from the recursive formula above
that τ (2k ) ≡ 0 (mod 8) for all k ≥ 1. In fact, once it is also known that τ (p) is even for all primes p,
these recurrences show that τ (n) is odd only when n is an odd square.
   We may therefore in principle use Theorem 1.1 to study congruences for τ (n). The situation is
complicated somewhat by the fact that Lehmer’s conjecture [7] that τ (n) never vanishes remains
open, so it is not yet possible to guarantee in full generality that Vp (A, B; τ ) is finite. Furthermore,
writing down the values of τ (p) is not nearly as simple as with many other arithmetic functions,
and so the direct application of Theorem 1.1 to τ (n) is not as fruitful. However, τ (n) satisfies many
exceptional congruences [15] related to divisor sums σk (n) with various odd values of k, and as we

   We note briefly that Ramanujan’s tau function is special   in its direct connection to divisor sums,
but not in multiplicativity. More generally, if f (q) = n≥0 af (n)q n is any Hecke eigenform, then the

coefficients af (n) are a multiplicative function of n with the additional nice property that for each
prime p, the values af (pm ) for m ≥ 2 are determined by the value of af (p) via a two-term linear
recurrence relation analogous to the classical Fibonacci sequence. The philosophy which arises from
Theorem 1.1 says that all Ramanujan-type congruences of af (n) are induced by the values af (p). As
much is known about the multiplicative structure of these types of recurrence relations, it would be
interesting to pursue a classification of Ramanujan-type congruenes for the coefficients of eigenforms
along these lines.
