130: In the binary strength 2 case we will frequently make use of Hadamard matrices. A
131: Hadamard matrix H(n) is a square matrix of order n, having entries from the set {1, −1}
132: such that any two rows are orthogonal, i.e., it satisfies the equation: H(n)H(n)T = nIn .
133: If a Hadamard matrix H(n) exists, then either n = 2 or n is divisible by 4. However, the
134: converse is an open problem known as the Hadamard conjecture; the smallest value for
135: which it is not known whether a Hadamard matrix exists or not is 668 [6].
136: The following lemma gives a relationship between binary orthogonal arrays of strength 2
137: and 3 and the Hadamard matrices of order 4m.
138: 
139: Lemma 2. [8, p. 148] Let m ≥ 4. Orthogonal arrays OA(4m, 4m−1, 2, 2) and OA(8m, 4m, 2, 3)
140: exist if and only if there exists a Hadamard matrix order 4m.
