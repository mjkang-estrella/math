# Reproduction without network or Lean

All commands must be run from this extracted dossier directory. Python is always invoked with `-I -B`; keep all outputs, caches and temporary files here. Dependencies already used on the task host: Python 3 with pycairo, Cairo, Liberation Serif and STIX Two Math fonts, Poppler (`pdftoppm`, `pdftotext`, `pdfinfo`), bash, timeout, taskset and ps. No package download is needed or authorized by this runbook.

1. Verify manifest.json against member bytes using scripts/check_manifest.py. The external archive receipt separately binds the complete ZIP. The archive contains only lane-relative paths; inspect before extraction.
2. Run `bash scripts/cap.sh python3 -I -B scripts/verify.py`. It reconstructs the two graphs and labellings, performs bounded deterministic heuristic searches and safely extracts the unchanged packet. It does not execute any packet source. The script can run standalone using the bundled sources, raw line and packet, or in the original campaign layout using the frozen input siblings.
3. Run `bash scripts/cap.sh python3 -I -B scripts/render.py`. The source is paper.md plus the generated verification.json tables and the Cairo layout script. It produces the five-page paper.pdf. Creation-time metadata may differ; compare content and tables rather than expecting the regenerated PDF hash to be identical.
4. Run `bash scripts/cap.sh pdftoppm -scale-to 1400 -png paper.pdf qa/page` and inspect all five images. Run `bash scripts/cap.sh pdftotext paper.pdf qa/extracted.txt` for text checking. Original inspection is recorded in qa/receipt.json. A new render requires a new visual inspection.
5. Numerical source checks and a complete inventory of numerical tokens in the paper are in numeric-audit.json. Identifiers, bibliographic years, theorem numbers and dates are source metadata, not arithmetic outputs. Arithmetic quantities are recomputed; the metadata is checked against the frozen source bodies and receipts.

Resource driver scripts/cap.sh uses two CPU affinities, CPU limit 120 seconds, wall limit 140 seconds, aggregate sampled process-group RSS ceiling 6 GiB, and MALLOC_ARENA_MAX=2. Its watchdog is terminated and waited for before return. Runs are serial. If CPU numbers 0 and 1 are unavailable on a different host, select two available CPUs. Do not run Lean, lake, leanchecker, SAT or ILP solvers for this reproduction.

The Lean packet is byte-identical to the supplied final packet: SHA256 ffa01d95d108d91cc5f90638a1ef46fd9f76ac2cc743487a2c0b9644e2f7a2ea. No formal replay is performed by this runbook. Inherited successful root replay and registry-refresh receipts are in evidence/mobius-parent-final-r1/. The exact raw MathDB line and its hash are in 339235.jsonl and verification.json.

Network was confined to STEP 0. Do not rerun scripts/fetch.py as part of offline reproduction. Its unmodified receipts and response bodies, including failures and wrong-person/wrong-paper hits that were discarded, remain in downloads/. Inherited primary-source bodies and receipts are in sources/. prior-art-completion.json distinguishes newly read bodies, inherited body reviews and title/abstract exclusions. HTTP 403/429 or challenge hosts are blocked; verified TLS was never disabled. No denied service API was used.

Initial setup/read commands preceded creation of the copied resource driver; subsequent research, arithmetic, rendering and packaging commands used it. No initial uncapped command ran a heavy calculation. There are no child agents, git operations, shared-ledger edits or writes outside this lane by these scripts. No campaign acceptance is asserted.
