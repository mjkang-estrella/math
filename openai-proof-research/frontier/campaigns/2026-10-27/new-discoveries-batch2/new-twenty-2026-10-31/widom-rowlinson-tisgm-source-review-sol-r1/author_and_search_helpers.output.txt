Claim: for every fixed integer k>=2, sample independent pairs (U_i,V_i)
uniformly in (0,1)^2, and let L_i=min(U_i,V_i), R_i=max(U_i,V_i).
For the sequence of intervals I_i=[L_i,R_i], let D_n be its minimum number
of chronological k-ary heapable classes, exactly as in the source. Then
 lim_{n->infinity} E[D_n]/n=1/(k+1).

Step1, finite exact combinatorial identity. Make a bipartite graph with
one demand vertex for each i and k supply copies of each j. A supply copy
of j is adjacent to demand i iff j<i and R_j<=L_i. Matchings give forests:
each matched i has its unique parent j, each j has at most k children,
and strict time increase forbids cycles. Each component is a rooted tree
and a valid heapable class. Conversely the edges of any partition into
such rooted trees give a matching by distinct supply copies. Therefore
D_n=n-maximumMatching. In particular, by the deficiency form of Hall,
 D_n=max_{S subset [n]} (|S|-k|N(S)|),                       (C)
where N uses the underlying supply labels, before cloning. To recall the
finite deficiency proof: every matching leaves at least the displayed
quantity unmatched. For a maximum matching, start alternating paths from
all unmatched demands. There is no reachable unmatched supply (otherwise
augment). The reachable demand set S has all its neighbor supply copies
matched into S, and all matched members of S arise this way. Thus its
deficiency is exactly the total number of unmatched demands, proving (C).
This independently pays the finite bridge; the source theorem is consistent
with it. Its claimed bijections need not literally be unique when supply
copies are relabelled; only optimum cardinalities are used.

Step2, lower bound. For any x in [0,1] take S={i:L_i<=x}.
Every neighbor has R_j<=x. Thus (C) gives
 D_n>=#{i:L_i<=x}-k#{j:R_j<=x}.
The marginal CDFs are F_L(x)=2x-x^2 and F_R(x)=x^2. Hence
 E[D_n]/n>=2x-(k+1)x^2.
At x=1/(k+1) this gives c=1/(k+1), for every n>0.

Step3, simultaneous upper bound for every Hall cut. Fix an integer m>=1,
and for n>=m partition the arrival indices into m consecutive blocks B_q,
each of size N_q in {a,a+1}, a=floor(n/m). Given ANY S, let h_q be the
largest left endpoint of an element of S in blocks q,...,m, or zero if
that set is empty. Set h_{m+1}=0. For i in S intersect B_q, L_i<=h_q.
For j in B_q with R_j<=h_{q+1}, a selected interval in a strictly later
block attains h_{q+1}, so j is a neighbor. If there is no such selected
interval then h_{q+1}=0 and there is no such j, since all R_j>0.
Therefore
 |S|-k|N(S)| <= sum_q (#{i in B_q:L_i<=h_q}
                            -k#{j in B_q:R_j<=h_{q+1}}).   (D)
Let delta_q^L,delta_q^R be the sup errors of the two block empirical CDFs.
The right side is at most
 sum_q N_q[F_L(h_q)-kF_R(h_{q+1})]
              +sum_q N_q(delta_q^L+k delta_q^R).
Replace each N_q by a; the absolute error is at most (k+1)m.
The remaining sum telescopes exactly:
 sum_q [F_L(h_q)-kF_R(h_{q+1})]
 =sum_q [F_L(h_q)-kF_R(h_q)] +k[F_R(h_1)-F_R(h_{m+1})]
 <=m c+k,
because 2x-(k+1)x^2<=c on [0,1], F_R(h_1)<=1 and F_R(0)=0.
The bound is independent of S, so by (C)
 D_n/n<=c+k/m+(k+1)m/n

The CLI has no batch/list traversal or retry mode. Every redirect is precharged.
This guards this client only, not other tools or arbitrary Python networking.
"""

import datetime

import hashlib
import ipaddress
import json
from pathlib import Path
import re
import sys
import urllib.error
import urllib.parse
import urllib.request

ROOTS = frozenset([
    "https://github.com/openai/math",
    "https://github.com/LeanPool/lean-pool",
    "https://github.com/TauCetiProject/TauCeti",
    "https://github.com/google-deepmind/formal-conjectures",
])
PER_ID_CAP = 12
GLOBAL_CAP = 48
MAX_BYTES = 24 * 1024 * 1024


class PolicyError(RuntimeError):
    pass


def key(url):
    p = urllib.parse.urlsplit(url)
    if p.scheme != "https" or not p.hostname or p.username or p.password:
        raise PolicyError("Only explicit credential-free HTTPS URLs are allowed")
    host = p.hostname.lower()
    if p.port not in (None, 443) or host in ("localhost", "api.github.com") or host.endswith((".local", ".internal", ".localhost")):
        raise PolicyError("Disallowed host/port")
    try:
        if not ipaddress.ip_address(host).is_global:
            raise PolicyError("Nonpublic IP address")
    except ValueError:
        pass
    return host + urllib.parse.unquote(p.path).rstrip("/")


def artifacts(url):
    s = urllib.parse.unquote(url).lower()
    found = set(re.findall(r"(?<!\d)\d{4}\.\d{4,5}(?!\d)", s))
    for doi in re.findall(r"10\.\d{4,9}/[-._;()/:a-z0-9]+", s):
        while any(doi.endswith(t) for t in (".full", ".pdf", ".abstract", ".html", ".xml")):
            doi = doi.rsplit(".", 1)[0]
        found.add(doi)
    return found


class Guard:
    def __init__(self, lane, opener=None):
        self.lane = Path(lane).resolve()
        self.ids = set(map(str, json.loads((self.lane / "reservation.json").read_text())["ids"]))
        self.denied = json.loads((self.lane / "inherited-denials.json").read_text())
        self.opener = opener  # Tests inject a local fake; CLI always uses urllib.
        self.ledger = self.lane / "guard-ledger.jsonl"

    @contextlib.contextmanager
    def locked(self):
        with (self.lane / "guard.lock").open("a") as lock:
            fcntl.flock(lock, fcntl.LOCK_EX)
            records, previous = [], "0" * 64
            if self.ledger.exists():
                for raw in self.ledger.read_bytes().splitlines(keepends=True):
                    record = json.loads(raw)
                    if record.get("seq") != len(records) or record.get("previous") != previous:
                        raise PolicyError("Broken guard ledger chain; no request permitted")
                    records.append(record)
                    previous = hashlib.sha256(raw).hexdigest()
            yield records, previous

    def append(self, records, previous, event):
        record = dict(event, seq=len(records), previous=previous,
                      utc=datetime.datetime.now(datetime.timezone.utc).isoformat())
        raw = (json.dumps(record, sort_keys=True) + "\n").encode()
        with self.ledger.open("ab") as f:
            f.write(raw)
            f.flush()
        return record

    def note(self, event):
        with self.locked() as (records, previous):
            return self.append(records, previous, event)

    def reserve(self, url, routes, plan_sha):

        if url in ROOTS or k in {key(x) for x in ROOTS}:
            routes = sorted(self.ids)  # Shared roots can never be undercharged.
        if not routes or not set(routes) <= self.ids or len(routes) != len(set(routes)):
            raise PolicyError("Routes must be exact unique reserved IDs")
        with self.locked() as (records, previous):
            attempts = [r for r in records if r["event"] == "attempt"]
            failures = [r for r in records if r["event"] == "unavailable"]
            denied_keys = set(self.denied["blocked_keys"]) | {r["url_key"] for r in failures}
            denied_artifacts = set(self.denied["blocked_artifacts"])
            for r in failures:
                denied_artifacts.update(r.get("artifacts", []))
            if k in denied_keys or artifacts(url) & denied_artifacts:
                raise PolicyError("Inherited/current unavailable route or artifact: no retry")
            if any(r["url_key"] == k for r in attempts):
                raise PolicyError("Already attempted URL; use saved bytes/outcome, no refetch/query variant")
            if len(attempts) >= GLOBAL_CAP:
                raise PolicyError("Global GET-hop cap48 exhausted")
            for route in routes:
                if sum(route in r["routes"] for r in attempts) >= PER_ID_CAP:
                    raise PolicyError("Per-ID GET-hop cap12 exhausted: " + route)
            return self.append(records, previous, {
                "event": "attempt", "url": url, "url_key": k,
                "routes": routes, "plan_sha256": plan_sha,
                "ordinal": len(attempts) + 1,
            })
