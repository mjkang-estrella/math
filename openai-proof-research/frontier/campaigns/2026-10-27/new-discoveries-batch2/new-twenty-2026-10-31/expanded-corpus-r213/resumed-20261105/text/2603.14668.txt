                                                                                             Abstract
                                                       Let ir(G) and γ(G) be the irredundance number and the domination number of a
                                                   graph G, respectively. A graph G is called irredundance perfect if ir(H) = γ(H) for
                                                   every induced subgraph H of G. The subclass of P6 -free irredundance perfect graphs
                                                   has been studied extensively. In this paper, we present a characterization of this graph
                                                   class in terms of eleven forbidden induced subgraphs.

                                                   Keywords: irredundance perfect graphs, irredundance number, domination number, P6 -free
                                                   graphs

                                               All graphs considered in this paper are finite, simple, and undirected. For a graph G,
                                           let V (G) denote its vertex set; for X ⊆ V (G), let ⟨X⟩ be the subgraph of G induced by X.
                                           For X, Y ⊆ V (G), we write X ∼ Y if every vertex of X is adjacent to every vertex of Y ,
                                           and X ≁ Y if no vertex of X is adjacent to any vertex of Y . In particular, x ∼ y means that
                                           the vertices x and y are adjacent. For a vertex x ∈ V (G), let N (x) and N [x] = N (x) ∪ {x}
                                           denote its open and closed neighborhoods,
                                                                              S         respectively. This notation extends to subsets
                                           X ⊆ V (G) by defining N (X) = x∈X N (x) and N [X] = N (X) ∪ X.
                                               A set X ⊆ V (G) dominates a set Y ⊆ V (G) if Y ⊆ N [X]. In particular, if X dominates
                                           V (G), then X is called a dominating set. The domination number γ(G) is the cardinality
                                           of a minimum dominating set of G. Domination in graphs has been extensively studied
                                           and has numerous real-life applications [16].
                                               For x ∈ X, the set
                                                                         P N (x, X) = N [x] − N [X − {x}]
                                           is called the private neighborhood of x; the shorter notation P N (x) is used when X is
                                           clear from the context. If P N (x, X) = ∅, then x is said to be redundant in X. A set
                                           X containing no redundant vertex is called irredundant. The minimum cardinality of a
                                           maximal irredundant set of G is the irredundance number ir(G). The following proposition
                                           provides the necessary and sufficient condition for an irredundant set to be maximal.

                                           Proposition 1 ([11]) Let X be an irredundant set of G, and U = V (G) − N [X]. The set
                                           X is a maximal irredundant set if and only if for any v ∈ N [U ], the vertex v dominates
                                           P N (x, X) for some vertex x ∈ X.

    It is well known that for any graph G, ir(G) ≤ γ(G). A graph G is irredundance perfect
if ir(H) = γ(H) for every induced subgraph H of G. There are numerous interesting
results and conjectures concerning irredundance perfect graphs [1–4, 6–13]; some of them
are discussed below. Related classes of graphs, such as domination perfect graphs, upper
domination perfect graphs, and upper irredundance perfect graphs, have also been studied
(see, e.g., [5, 14, 15]).
    One line of research on irredundance perfect graphs has focused on their characteriza-
tion by forbidden induced subgraphs. Below we outline some milestones in this direction.
The earliest result was obtained by Bollobás and Cockayne:

Theorem 1 (Bollobás and Cockayne [1]) If a graph G contains no pair of induced
subgraphs isomorphic to P4 with vertex sequences (ai , bi , ci , di ), i = 1, 2, such that b1 , b2 , c1 ,
c2 , d1 , d2 are pairwise distinct and a1 , a2 ̸∈ {c1 , c2 , d1 , d2 }, then G is irredundance perfect.

   The following result of Favaron strengthens Theorem 1, as the graphs forbidden in
Theorem 2 are included among those forbidden in Theorem 1.

Theorem 2 (Favaron [4]) If a graph G does not contain the graphs P6 , C6 , 2P4 and
G1 − G3 (see Figure 1) as induced subgraphs, then G is an irredundance perfect graph.

   Favaron conjectured that only three of the six graphs in Theorem 2 suffice as forbidden
induced subgraphs to characterize irredundance perfect graphs.

Conjecture 1 (Favaron [4], see also [2]) If a graph G does not contain the graphs P6
and G1 , G2 (Figure 1) as induced subgraphs, then G is irredundance perfect.

    Henning [7] proved Conjecture 1 for graphs G with ir(H) ≤ 4 for every induced
subgraph H of G; it was later completely proved in [10, 12]. In fact, [12] provides the
stronger result: a graph is irredundance perfect if it does not contain P6 , G1 and G5
(Figure 1) as induced subgraphs.
    Another conjecture on irredundance perfect graphs, independent from Conjecture 1,
has been posed in [3]:

Conjecture 2 (Faudree, Favaron and Li [3]) Any P5 -free graph is irredundance per-
fect.

   The validity of Conjecture 2 follows from a result of Puech [10], who showed that a
graph is irredundance perfect if it contains neither P6 nor H as an induced subgraph,
where H is the graph obtained from G4 by deleting one of its pendant vertices. In the
same paper, Puech proposed Conjecture 3 that generalizes Conjectures 1 and 2:

Conjecture 3 (Puech [10]) If a graph G does not contain the graphs P6 and G4 , G5
(Figure 1) as induced subgraphs, then G is irredundance perfect.

    Volkmann and Zverovich proved Conjecture 3 in [13].
    The main result of this paper is the complete characterization of P6 -free irredundance
perfect graphs in terms of forbidden induced subgraphs given in Theorem 3. All results
discussed above follow from Theorem 3.

   The proof of Theorem 3 is based on the next lemmas.
Lemma 1 The graph ⟨X⟩ has no vertex of degree 0.
Proof: Let v be an isolated vertex in ⟨X⟩. Denote H ′ = H − N [v] and X ′ = X − {v}.
Clearly, for any vertex x ∈ X ′ ,
                               P NH ′ (x, X ′ ) = P NH (x, X) ̸= ∅.
Therefore, X ′ is an irredundant set in H ′ . Suppose that there is a vertex u ∈ V (H ′ ) − X ′
such that the set X ′ ∪ {u} is irredundant in H ′ , i.e., P NH ′ (x, X ′ ∪ {u}) ̸= ∅ for any vertex
x ∈ X ′ ∪ {u}. It is not difficult to see that
                         P NH (x, X ∪ {u}) = P NH ′ (x, X ′ ∪ {u}) ̸= ∅
for any x ∈ X ′ ∪ {u}. Moreover, P NH (v, X ∪ {u}) ̸= ∅, since v ∈ P NH (v, X ∪ {u}).
We conclude that X ∪ {u} is an irredundant set in H, contrary to the fact that X is
maximal irredundant. Consequently, X ′ is a maximal irredundant set in H ′ and hence
ir(H ′ ) ≤ |X ′ | = ir(H) − 1. If D is a minimum dominating set of H ′ , then D ∪ {v} is a
dominating set of H. Therefore, γ(H) ≤ |D| + 1 = γ(H ′ ) + 1. We obtain
                          ir(H ′ ) ≤ ir(H) − 1 < γ(H) − 1 ≤ γ(H ′ ).
Thus, ir(H ′ ) < γ(H ′ ), contrary to the minimality of the graph H.
