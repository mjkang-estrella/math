A split digraph is a digraph whose underlying undirected graph is a split graph, meaning that its vertices can be partioned into a clique and an independent set. Equivalently, a split digraph is any digraph which can be obtained from a semicomplete digraph $D=(V,A)$ by adding a new set $V^{\prime}$ of vertices and some arcs between $V^{\prime}$ and $V$ . 1 Introduction
Notation follows [4] so we only repeat a few definitions here (see also Section 2). A digraph is not allowed to have parallel arcs or loops. A directed multigraph can have parallel arcs but no loops. A directed multigraph is semicomplete if it has no pair of non-adjacent vertices.
A directed multigraph $D$ is strong if there exists a path from $x$ to $y$ in $D$ for every ordered pair of distinct vertices $x$ , $y$ of $D$ and $D$ is $k$ -arc-strong if $D\setminus{}A^{\prime}$ is strong for every subset $A^{\prime}\subseteq A(D)$ of size at most $k-1$ . For every fixed integer $k$ there exists a polynomial algorithm for deciding if there is a hamiltonian cycle in a given digraph which is obtained from a semicomplete digraph by adding $k$ new vertices and some arcs.

Conjecture 1.4
For every fixed integer $k$ the hamiltonian cycle problem is polynomial for the class of split digraphs $D=(V_{1},V_{2};A)$ where the independent set $V_{1}$ has size at most $k$ .
