Abstract
A generator matrix of a linear code C over GF(q) is also a matrix of the same rank k over
any extension field GF(q  ) and generates a linear code of the same length, same dimension
and same minimum distance over GF(q  ), denoted by C (q|q  ) and called a lifted code of
C . Although C and their lifted codes C (q|q  ) have the same parameters, they have different
weight distributions and different applications. Few results about lifted linear codes are
known in the literature. This paper proves some fundamental theory for lifted linear codes,
and studies the 2-designs of the lifted projective Reed–Muller codes, lifted Hamming codes
and lifted Simplex codes. In addition, this paper settles the weight distributions of the lifted
Reed–Muller codes of certain orders, and investigates the 3-designs supported by these lifted
codes. As a by-product, an infinite family of three-weight projective codes over GF(4) is
obtained.

1 Introduction

1.1 The support designs of linear codes

Let v and k be positive integers with 1 ≤ k ≤ v. Let t be a positive integer with t ≤ k. Let
P be a set of v elements and let B be a set of k-subsets of P . The pair D := (P , B) is an
incidence structure, where the incidence relation is the set membership. The pair D = (P , B)
is called a t-(v, k, λ) design, or simply t-design, if every t-subset of P is contained in exactly
λ elements of B. The elements of the set P are referred to as points, and those of the set B are
called blocks. The set B is called the block set. The number of blocks in B is usually
                                                                                     denoted
                                                                                          
by b. Let Pk denote the set of all k-subsets of P . Then the incidence structure P , Pk is a
k-(v, k, 1) design, which is called a complete design. A t-design is said to be simple if B does
not contain any repeated blocks. This paper considers only simple t-designs. A t-(v, k, λ)
design is called a Steiner system if t ≥ 2 and λ = 1, and is denoted by S(t, k, v).
    There are several approaches to constructing t-designs with linear codes. One of the
coding-theoretic constructions of t-designs is the following. Let C be a [v, κ, d] linear code
over GF(q), which is a κ-dimensional subspace of the vector space GF(q)v with minimum
Hamming distance d [18, 21] and is also called a [v, κ, d]q linear code. We sometimes
use d(C ) to denote the minimum Hamming distance of a linear code C . Let Ai or Ai (C )
denote the number of codewords with Hamming weight i in C for 0 ≤ i ≤ v. The sequence
(A0 , A1 , . . . , Av ) is called the weight distribution of C . The support of a codeword c =
(c1 , c2 , . . . , cv ) of a linear code C is defined by
                               suppt(c) = {1 ≤ i ≤ v : ci  = 0}.
For each k with Ak (C )  = 0, let Bk (C ) denote the set of the supports of all codewords with
Hamming weight k in C , where Bk (C ) is not allowed to have repeated blocks. Suppose that the
coordinates of the codewords in C are indexed by ( p1 , . . . , pv ). Let P (C ) = { p1 , . . . , pv }.
The incidence structure (P (C ), Bk (C )) may be a t-(v, k, λ) simple design for some positive
integer λ, which is called a support design of the code C , and is denoted by Dk (C ). In this
case, we say that the codewords of weight k in C support or hold a t − (v, k, λ) design, and
for simplicity, we say that C supports or holds a t-(v, k, λ) design.
   The following theorem, which was established by Assmus and Mattson and called the
Assmus–Mattson Theorem, says that the incidence structure Dk (C ) := (P (C ), Bk (C )) defined
by a linear code C is a simple t-design under certain conditions [2].

   The second sufficient condition for the incidence structure (P (C ), Bk (C )) to be a t-design is
via the automorphism group of the linear code C . Before introducing this sufficient condition,
we have to recall several different automorphism groups of a linear code.
   The set of coordinate permutations that map a code C to itself forms a group, where the
binary operation for this group is the function composition. This group is referred to as the
permutation automorphism group of C and denoted by PAut(C ). If the length of C is n and
the coordinates of the codewords in C are indexed with the elements in the set {1, 2, . . . , n},
then PAut(C ) is a subgroup of the symmetric group Symn .
   A monomial matrix over GF(q) is a square matrix that has exactly one nonzero element
of GF(q) in each row and column. It is easily seen that a monomial matrix M can be written
either in the form D P or the form P D1 , where D and D1 are both diagonal matrices and
P is a permutation matrix. Clearly, the set of monomial matrices that map C to itself forms
a group denoted by MAut(C ), which is called the monomial automorphism group of C . By
definition, we have PAut(C ) ⊆ MAut(C ). By definition, every element in MAut(C ) is of the
form D P, where D is a diagonal matrix and P is a permutation matrix. An element of this
group acts on a codeword c as (D P)(c) = cD P −1 . For two elements (Di , Pi ) := Di Pi in
MAut(C ) for i ∈ {1, 2}, the corresponding binary operation of the group MAut(C ) is defined
by

                           (D2 , P2 ) ◦ (D1 , P1 ) = (D1 P1−1 D2 P1 , P2 P1 ).

   The automorphism group of C , denoted by Aut(C ), is the set of maps of the form Mγ ,
where M is a monomial matrix and γ is a field automorphism, that map C to itself. For binary
codes C , PAut(C ), MAut(C ) and Aut(C ) are the same. If q is a prime, MAut(C ) and Aut(C )
are identical. According to their definitions, we have the following relations:

                                    PAut(C ) ⊆ MAut(C ) ⊆ Aut(C ).

By definition, every element in Aut(C ) is of the form D Pγ , where D is a diagonal matrix, P
is a permutation matrix, and γ is an automorphism of GF(q). An element of this group acts
on a codeword c as (D Pγ )(c) = γ ((cD)P −1 ). For any two elements (Di , Pi , γi ) := Di Pi γi
in Aut(C ) for i ∈ {1, 2}, the corresponding binary operation of the group Aut(C ) is defined
by

             (D2 , P2 , γ2 ) ◦ (D1 , P1 , γ1 ) = (D1 P1−1 γ1−1 (D2 )P1 , P2 P1 , γ2 ◦ γ1 ).

   The automorphism group Aut(C ) of a linear code C is said to be t-transitive if for every
pair of t-element ordered sets of coordinates, there is an element D Pγ of the automorphism
group Aut(C ) such that its permutation part P sends the first set to the second set. The
automorphism group Aut(C ) is said to be t-homogeneous if for every pair of t-element sets
of coordinates, there is an element D Pγ of the automorphism group Aut(C ) such that its
permutation part P sends the first set to the second set.
   With the help of the automorphism group of a linear code C , the following theorem gives
another sufficient condition for the code C to hold t-designs.

Theorem 2 [18, p. 308] Let C be a linear code of length n over GF(q) such that Aut(C ) is
t-transitive or t-homogeneous. Then the codewords of any weight i ≥ t of C hold a t-design,
i.e., Di (C ) is a t-design for each i ≥ t with Ai (C ) > 0.

   It is in general very hard to determine the full automorphism group of a linear code. As
long as a t-transitive or t-homogeneous subgroup of Aut(C ) is found, one could make use of
Theorem 2 to prove the t-design property of Di (C ).
   The third way for proving the t-design property of an incidence structure Di (C ) is the direct
approach [10, 26, 32], where the t-design property of an incidence structure (P (C ), Bi (C )) is
proved by verifying the conditions in the definition of t-designs directly. This direct approach
may work only when the block size is very small.

1.2 Lifted linear codes

Let q be a power of a prime and let C be an [n, k, d]q linear code with generator matrix G.
For a positive integer , G is also a matrix of rank k over GF(q  ). Let C (q|q  ) denote the
linear code over GF(q  ) generated by G, which is called the lifted code over GF(q  ) of C .
It is known that C (q|q  ) and C have the same length, dimension and minimum distance [11,
Theorem 7], but they have different weight distributions for  > 1 (see the examples and
some general results in later sections). Even if the weight distribution of C is known, it may
be very hard to determine the weight distribution of a lifted code C (q|q  ) for  > 1. By
definition, C is the subfield subcode over GF(q) of the lifted code C (q|q  ) [18, 21].

1.3 The idea of constructing new designs with lifted codes of a linear code

Suppose that C supports some nontrivial t-designs. One or both of the following cases may
happen:
 • Di (C (q|q  )) is a t -(n, i, λi ) design with (t , λi )  = (t, λi ), while Di (C ) is a t-(n, i, λi )
   design for some i with Ai (C )  = 0.
 • Di (C (q|q  )) is a t -(n, i, λi ) design with Ai (C (q|q  ))  = 0, while Ai (C ) = 0.
If any of the two cases above happens, a new design could be obtained. This idea of obtaining
new support designs from lifted linear codes was considered in [8], where some 5-designs
were found.
    The following theoretical result will be needed in subsequent sections and is a theoretical
foundation of this paper.
Theorem 3 [8] Let C be a linear code of length n over GF(q). Let E be a subgroup of the
monomial automorphism group MAut(C ). Assume that E is t-transitive or t-homogeneous.
Then the following hold:
1. For each e ∈ E, e(C (q|q  )) = C (q|q  ).
2. Di (C (q|q  )) is a t-(n, i, λi ) design with Ai (C (q|q  ))  = 0 for any i ≥ t, where λi is an
   integer.

1.4 Motivations and objectives of this paper

Many infinite families of 2-designs and 3-designs supported by linear codes are available in
the literature [12, 28, 29]. Recently, several infinite families of 4-designs from linear codes
were reported in [26, 32]. No infinite family of linear codes supporting an infinite family of
nontrivial simple 5-designs is known. It is not easy to construct 5-designs from linear codes.
A very small number of 5-designs from some linear codes were reported in [2, 22], [12,
Appendix A], and [8]. Until now no linear code supporting a nontrivial 6-design is known

in the literature. Of course, there are algebraic, geometric and combinatorial approaches to
constructing t-designs [1, 6].
    Combinatorists are in general interested only in the following types of t-designs:

 • t-(v, k, λ) designs with large strength t.
 • t-(v, k, λ) designs with small value λ, in particular, λ = 1.
 • Symmetric and quasi-symmetric t-designs.

However, coding theorists are also interested in t − (v, k, λ) designs with small strength t and
large λ, as some 2-designs could be used to construct linear codes with very good parameters
[11]. This is the main motivation of obtaining new 2-designs by studying the lifted Hamming
and Simplex codes as well as the projective Reed–Muller codes in this paper. The second
motivation of this paper is that two-weight and three-weight linear codes have interesting
applications in association schemes, cryptography and graph theory.
   As a follow-up of [8], we will do the following in this paper:

 • Add some new fundamental results for lifted linear codes.
 • Study the 2-designs supported by lifted projective Reed–Muller codes.
 • Study the 2-designs supported by lifted Hamming codes and lifted Simplex codes.
 • Settle the weight distributions of the lifted codes of the Reed–Muller codes of some
   orders.
 • Present many infinite families of 3-designs supported by lifted Reed–Muller codes.

The contributions of this paper are summarised in Sect. 6. The results of this paper
complement the literatures of coding theory and combinatorics.

3 The support 2-designs of the lifted projective Reed–Muller codes

In this section, we will introduce the projective Reed–Muller codes and study the 2-designs
supported by the lifted projective Reed–Muller codes.
   Let m ≥ 2 be an integer. A point of the projective geometry PG(m − 1, GF(q)) is given in
homogeneous coordinates by (x1 , x2 , . . . , xm ) where all xi are in GF(q) and are not all zero.
Every point of PG(m−1, GF(q)) has q−1 coordinate representations, as (ax 1 , ax2 , . . . , axm )
and (x1 , x2 , . . . , xm ) generate the same 1-dimensional subspace of GF(q)m for any nonzero
a ∈ GF(q).

GF(q), which is a linear space over GF(q). Let A(q, m, h) denote the subspace of

(q m − 1)/(q − 1) and let {x1 , x2 , . . . , xn } be a set of projective points in PG(m − 1, GF(q)).
Then the h-th order projective Reed–Muller code PRM(q, m, h) of length n is defined by

6 Summary and concluding remarks

The main contributions of this paper are summarized as follows.
 • Certain fundamental results for lifted linear codes were proved in Theorems 4 and 5.
 • The support 2-designs of the lifted projective Reed–Muller codes were studied in Theo-
   rem 10. New infinite families of 2-designs were obtained by studying the lifted projective
   Reed–Muller codes.
 • The support 2-designs of the lifted Simplex codes S(q,m) (q|q  ) were characterised in
   Theorem 23. New infinite families of 2-designs were obtained by studying the lifted
   Simplex codes.
 • The support 2-designs of the lifted Hamming codes H(q,m) (q|q  ) were characterised
   in Theorem 27. New infinite families of 2-designs were obtained by studying the lifted
   Hamming codes.
 • An infinite family of three-weight projective codes over GF(4) was obtained in Corollary
   39.
 • The weight distributions of the lifted codes RM2 (1, m)(2|2 ) were settled in Theorem
   33.
 • The weight distributions of the lifted codes RM2 (m−2, m)(2|2 ) were settled in Theorem
   42.
 • It was proved in Theorem 31 and Corollary 34 that many infinite families of 3-designs
   are supported by the lifted codes RM2 (r , m)(2|2 ). New infinite families of 3-designs
   were obtained by studying these lifted codes.
    The determination of the weight enumerator of a linear code is quite difficult in general.
The settlement of the weight enumerator of a lifted code C (q|q  ) could be very difficult, even
if the weight enumerator of the given code C is known. It is much harder to determine the
parameters of the designs studied in this paper. The reader is cordially invited to attack the
open problems presented in this paper.
    It is known that the permutation automorphism group PAut(H(2,m) ) is the general linear
group GLm (GF(2)) [17]. It would be infeasible to characterise the permutation automorphism
group PAut(H(q,m) ) for q > 2, as it varies from a Hamming code to another Hamming code
of the same parameters, although all Hamming codes H(q,m) are monomially-equivalent. In
a special case, the permutation automorphism group PAut(H(q,m) ) for q > 2 was settled
[14].
