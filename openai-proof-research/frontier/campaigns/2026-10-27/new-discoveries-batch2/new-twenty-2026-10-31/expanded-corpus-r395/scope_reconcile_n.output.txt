                                                                                            Abstract
                                                      Let S be a set of n points in the plane in general position. Two line segments connecting
                                                  pairs of points of S cross if they have an interior point in common. Two vertex disjoint
                                                  geometric graphs with vertices in S cross if there are two edges, one from each graph, which
                                                  cross. A set of vertex disjoint geometric graphs with vertices in S is called mutually crossing
                                                  if any two of them cross.
                                                      We show that there exists a constant c such that from any family of n mutually crossing
                                                  triangles, one can always obtain a family of at least nc mutually crossing 2-paths (each of
                                                  which is the result of deleting an edge from one of the triangles) and then provide an example
                                                  that implies that c cannot be taken to be larger than 2/3. For every n we determine the
                                                  maximum number of crossings that a Hamiltonian cycle on a set of n points might have.
                                                  Next, we construct a point set whose longest perfect matching contains no crossings. We also
                                                  consider edges consisting of a horizontal and a vertical line segment joining pairs of points
                                                  of S, which we call elbows, and prove that in any point set S there exists a family of bn/4c
                                                  vertex disjoint mutually crossing elbows. Additionally, we show a point set that admits no
                                                  more than n/3 mutually crossing elbows.
                                                      Finally we study intersecting families of graphs, which are not necessarily vertex disjoint.
                                                  A set of edge disjoint graphs with vertices in S is called an intersecting family if for any two
                                                  graphs in the set we can choose an edge in each of them such that they cross. We prove a
                                                  conjecture by Lara and Rubio-Montiel [10], namely, that any set S of n points in general
                                                  position admits a family of intersecting triangles with a quadratic number of elements.
                                                      Some other results are obtained throughout this work.

    In the study of geometric graphs, we have been mainly interested in studying geometric
graphs containing no edges that cross, e.g., triangulations, non-crossing matchings in bicolored
point sets, alternating paths, etc. In this paper we will be interested in finding geometric graphs
on point sets such that their edges cross many times, e.g., Hamiltonian cycles whose edges cross
as many times as possible.
    We say that a set of points S admits (or contains) a crossing family of k-paths (respectively
of k-cycles) if there is a set of vertex disjoint paths (cycles) of length k with vertices in S, such
that any two of them cross. Perhaps the first result on crossing families was obtained by Aronov
p al. [4]; they proved that any set of n points in general position has a crossing matching with
et
   n/12 edges, i.e. a matching such that any two of its edges cross. Pach and Solymoshi [12]
proved that if a point set with n = 2m points has exactly m halving lines, then it has a crossing
perfect matching. Aronov et al. conjectured in [4] that there is always a crossing matching with
a linear number of elements; this conjecture remains open. Significant progress on this problem
was recently achieved by Pach et al. [11], they proved that any point set has a mutually crossing
matching with at least n1−o(1) edges.
    In [4] the authors also show an example of a point set S such that any crossing matching
with vertices in S has at most n/4 elements. This bound was improved by Evans et al. [7] to
5dn/24e, and by Aichholzer et al. [1] to 8dn/41e.
    Álvarez-Rebollar et al. [3] proved that any point set admits a crossing family of 3-paths with
bn/4c elements, and that for k ≥ 3, any point set admits a crossing family of k-paths with
bn/(k + 1)c elements; these bounds are tight.
    An interesting problem on 2-paths remains open: Is it true that any set of n points contains
a crossing set of 2-paths of linear size? Using the result of Pach et al. [11] on mutually crossing
matchings, it follows easily that any point set S admits a mutually crossing set of 2-paths with
at least n1−o(1) .
    Using our result on crossing families of k-paths it follows easily that any point set has a
crossing family of k-cycles, k ≥ 3, with at least bn/kc elements, since each k-path can be
completed to a k-cycle.
    In [3], it was proved that any point set with n elements admits a set of bn/6c vertex disjoint
crossing triangles; this result was improved by Fulek et al. [9], who proved that any point set
admits a crossing family of triangles with bn/3c elements, which is evidently optimal.
    An orthogonal geometric graph with vertices on S is a graph whose vertices are points of S
and its edges are represented by chains of horizontal and vertical line segments joining pairs of
points in S; an edge of an orthogonal geometric graph is called an elbow if it has one horizontal
and one vertical line segment. The interested reader can find more on this topic in a survey by
Tamassia in [14].

Lemma 3.3. Let a, b ∈ {1, 2, . . . , n−1} be distinct. Then the permutation (0, a, b)·τn is an n-cycle
if and only if a < b.
