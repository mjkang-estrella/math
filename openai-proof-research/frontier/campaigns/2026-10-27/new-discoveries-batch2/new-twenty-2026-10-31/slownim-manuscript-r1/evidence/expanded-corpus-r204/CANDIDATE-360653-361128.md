# CANDIDATE 360653 / 361128: the GM strategies are not a Nash equilibrium of ℓ-player exact slow NIM(n, n−1), for every n ≥ 3 and ℓ ≥ 3

Status: ordinary proof complete, covering the general family and two explicit small certificates; Lean draft UNCOMPILED. No credit claimed.

The two MathDB records state the same conjecture, from two papers by the same authors. Root decides whether one record or both are resolved.

## 1. Sources and exact statement

* MathDB 360653: Gurvich–Naumova, *GM-rule and its applications to impartial games*, arXiv:2311.03257, v1 only. Conjecture 1, TeX line 1139, section "Game NIM(n,n−1) for ℓ players".
* MathDB 361128: Gurvich–Naumova, *Screw discrete dynamical systems and their applications to exact slow NIM*, arXiv:2312.08382, v1 only. Conjecture 1, TeX line 1777, with identical wording. Its version of record is Discrete Applied Math. (Dec 2024), DOI 10.1016/j.dam.2024.07.018 (Crossref receipt `sources/cr-screw.json`). **The VoR body was not read** (ScienceDirect is known to deny access, so it was not tried). Whether the VoR keeps the conjecture is an open source gap.
* Rules (source text):
  * a position is a non-negative n-vector;
  * ℓ players move in a fixed cyclic order;
  * a move keeps one entry and reduces the other n−1 entries by 1, which is legal only if they are positive;
  * a position with at least two non-positive entries is terminal, and the player to move there loses;
  * C exceeds the length of every play from x⁰, the loser pays C − L(P), and each of the ℓ−1 winners receives (C − L(P))/(ℓ−1).
* GM strategy:
  * keep the minimal entry that is a multiple of ℓ (rightmost among equal values; the resulting multiset does not depend on the tie-break);
  * if no entry is a multiple of ℓ, keep the largest entry, a clause stated explicitly in both conjecture paragraphs.
* Conjecture: the ℓ GM strategies form a (uniform) Nash equilibrium. The source notes that ℓ = 2 follows from GMMV23 (arXiv:2304.06498).

## 2. Results

**Theorem 1 (literal refutation, all n ≥ 3, ℓ ≥ 3).** Let a = (n−2)ℓ + 1, b = (n−1)ℓ − 1 and x⁰ = (a, …, a, b), with n−1 copies of a. Player P0 moves first.

1. If all players use GM, the play has length exactly (n−1)ℓ, so P0 loses.
2. If P0 keeps an entry a at the first move and otherwise plays GM, while the others play GM, the play has length (n−1)ℓ − 1. Its loser is P_{ℓ−1} ≠ P0.

Hence P0's payoff rises from −(C − (n−1)ℓ) < 0 to (C − (n−1)ℓ + 1)/(ℓ−1) > 0 for every admissible C, and GM is not a Nash equilibrium. This holds even for positional (memoryless) deviations and for any payoff in which winning beats losing.

Together with GMMV23 (ℓ = 2) and the trivial cases n ≤ 2, the answer is that the GM profile is a uniform Nash equilibrium **iff ℓ = 2** (for n ≥ 3).

**Smallest instance.** n = 3, ℓ = 3, x⁰ = (4,4,5), checked by `scripts/nim_certificate.py` → `outputs/nim/certificate.json`:
* GM play (4,4,5) → (3,3,5) → (2,3,4) → (1,3,3) → (0,2,3) → (0,1,2) → (0,0,1): length 6, so P0 is to move at the terminal position and loses;
* deviation (4,4,5) –keep 4→ (3,4,4) → (3,3,3) → (2,2,3) → (1,1,3) → (0,0,3): length 5, so P2 loses.

All moves after the first are GM moves, including P0's own move at (2,2,3).

**Theorem 2 (convention-free refutation, by certificate).** n = 3, ℓ = 3, x⁰ = (5,5,6).
* The all-GM play never meets a position without a multiple of 3. It has length 8 and P2 loses, so P0 wins with payoff (C − 8)/2.
* Against **every** completion of the GM rule at multiple-free positions (adversarial min–max, `scripts/nim_certificate.py` part B), P0 can force a win with a play of length 7, i.e. payoff (C − 7)/2 > (C − 8)/2.

So the refutation does not depend on the "keep the largest entry" clause. It uses only the authors' length-dependent payoff.

Computational coverage:
* exhaustive best-response checks over all initial positions with entries ≤ 20 (n = 3, ℓ = 3) and ≤ 14 (n = 3, 4; ℓ = 3..7) (`outputs/nim/scan-lit-*.jsonl`, `classify-*.json`);
* the same checks for ℓ = 2 (n = 3, entries ≤ 30; n = 4, entries ≤ 14) find **no** violation, which agrees with GMMV23 and validates the implementation;
* the family of Theorem 1 was verified by direct simulation for 3 ≤ n ≤ 9 and 3 ≤ ℓ ≤ 12 (`outputs/nim/family-L2W.jsonl`).

## 3. Proof of Theorem 1

Positions are treated as multisets, since GM outcomes are permutation-invariant. Let A = (n−2)ℓ.

**GM play.**
* Move 1: x⁰ has entries ≡ 1 and ≡ −1 (mod ℓ), and ℓ ≥ 3, so there is no multiple of ℓ. GM keeps b, giving y¹ = (A^{n−1}, B) with B = (n−1)ℓ − 1.
* Invariant (I_i), for i = 1, …, n−1, at time 1 + (i−1)ℓ: n−i "fresh" piles at (n−1−i)ℓ, i−1 "kept" piles at (n−i)ℓ, and B at (n−i)ℓ − 1. Note that y¹ = (I_1).
* Block i ≤ n−2: GM keeps a fresh pile at value q = (n−1−i)ℓ.
  * During the next ℓ moves (s = 1..ℓ−1 steps into the block), the other values are q − s (fresh), q + ℓ − s (kept) and q + ℓ − 1 − s (B). None is a multiple of ℓ, except that B = q at s = ℓ−1, where it ties with the kept value. A tie gives the same multiset whichever pile is kept, so GM keeps value q throughout.
  * All reduced piles stay positive, because fresh piles are ≥ q − ℓ + 1 ≥ 1 before each reduction.
  * After ℓ moves the state is (I_{i+1}).
* Final phase: (I_{n−1}) = (0, ℓ^{n−2}, ℓ−1). Only the 0 can be kept. The play ends when ℓ−1 reaches 0, after ℓ−1 moves.
* Total length 1 + (n−2)ℓ + (ℓ−1) = (n−1)ℓ ≡ 0 (mod ℓ), so P0 is to move at the terminal position.

**Deviation play.**
* P0 keeps an a, giving z¹ = (a, A^{n−2}, B − 1).
* Invariant (J_i) at time 1 + (i−1)ℓ: n−1−i fresh piles at q = (n−1−i)ℓ, one pile D = q + 1, one pile B′ = q + ℓ − 2, and i−1 kept piles at q + ℓ. Note that z¹ = (J_1).
* Block i ≤ n−2: GM keeps a fresh pile at q.
  * Within the block, D − s is a multiple only at s = 1, where it equals q (a tie); B′ − s is a multiple only at s = ℓ−2 ≥ 1, again equal to q (a tie; for ℓ = 3 both ties occur at s = 1). The other values are as before.
  * Hence (J_{i+1}) holds after ℓ moves.
* After block n−2, at time 1 + (n−2)ℓ, the state is (1, ℓ−2, ℓ^{n−2}).
  * GM keeps an ℓ, giving (0, ℓ−3, ℓ−1, …, ℓ).
  * If ℓ = 3 this is terminal.
  * Otherwise 0 is kept until ℓ−3 reaches 0, after ℓ−3 more moves.
* Total length 1 + (n−2)ℓ + 1 + (ℓ−3) = (n−1)ℓ − 1, so P_{ℓ−1} is to move at the terminal position. P0's own later moves are GM moves, so the deviation is the positional strategy "GM except at x⁰" (x⁰ never recurs, since the sum strictly decreases). ∎

Traces for (n, ℓ) = (4,4) and (5,4) are in the lane log (`scripts/nim_trace.py`).

## 6. Lean plan (UNCOMPILED)

Lean cost is very low. The endpoint needs only two explicit finite plays, computed by `decide` or `rfl` on a fuel-bounded play function.

```lean
-- UNCOMPILED DRAFT (Claude lane; not run).
import Mathlib

/-- position of exact slow NIM(n, n-1) -/
abbrev Pos (n : ℕ) := Fin n → ℕ
def terminal {n} (x : Pos n) : Prop := 2 ≤ (Finset.univ.filter fun i => x i = 0).card
instance {n} (x : Pos n) : Decidable (terminal x) := by unfold terminal; infer_instance
def legal {n} (x : Pos n) (i : Fin n) : Prop := ∀ j, j ≠ i → 0 < x j
def move {n} (x : Pos n) (i : Fin n) : Pos n := fun j => if j = i then x j else x j - 1
/-- a (positional) strategy picks the kept index -/
abbrev Strategy (n : ℕ) := Pos n → Fin n
/-- GM as a relation: `IsGM l x i` holds iff keeping index `i` is a GM move at `x`
    (i carries the minimal value among entries divisible by l, or, if none is divisible by l, a maximal entry).
    Ties are allowed; the formal claim quantifies over every GM selection. -/
def IsGM {n} (l : ℕ) (x : Pos n) (i : Fin n) : Prop :=
  if ∃ j, x j % l = 0 then x i % l = 0 ∧ ∀ j, x j % l = 0 → x i ≤ x j
  else ∀ j, x j ≤ x i
/-- a GM selection is a strategy all of whose choices are GM moves -/
def GMSel {n} (l : ℕ) (σ : Strategy n) : Prop := ∀ x, IsGM l x (σ x)
/-- play with fuel; returns (length, loser index mod l) -/
def play (n l : ℕ) (σ : Fin l → Strategy n) : ℕ → Pos n → ℕ → Option (ℕ × ℕ)
  | 0, _, _ => none
  | fuel+1, x, t => if terminal x then some (t, t % l)
      else let p : Fin l := ⟨t % l, Nat.mod_lt _ (by omega)⟩
           play n l σ fuel (move x (σ p x)) (t+1)
-- payoff as in the source (ℚ), C > max play length; NE := ∀ i σ', payoff i (update σGM i σ') ≤ payoff i σGM.
-- Endpoint: ¬ (∀ n l, 2 ≤ l → ∀ σGM, (∀ p, GMSel l (σGM p)) → ∀ x0 C, admissible C x0 → IsNash n l x0 C σGM),
-- witnessed by n = 3, l = 3, x0 = ![4,4,5], deviator 0, σ' = fun x => if x = ![4,4,5] then 0 else σGM 0 x
-- (keeping entry index 0, value 4).  Both plays are evaluated by `decide`/`rfl` (6 and 5 moves).
```

Notes for the formal worker:

1. GM is defined relationally (`IsGM`/`GMSel`), so the statement quantifies over every tie-break. Statement fidelity requires that **any** tie-break choice be allowed. Either prove outcome invariance under permutations, or define GM as a relation (any index attaining the rule) and quantify the equilibrium claim over all such selections. The refutation must then show that every GM selection yields the losing play from (4,4,5). This is easy here, since ties occur only between equal values.
2. Nash equilibrium is defined over positional strategies. Mention in the statement-fidelity review that history-dependent strategies make the negation only easier, because the deviation is positional.
3. Use payoffs in ℚ: loser −(C − L), winners (C − L)/(ℓ − 1). Show the strict improvement for all C > 6. "Admissible" means C exceeds every play length from x⁰, and every play from (4,4,5) has length ≤ 6, since the entry sum 13 drops by 2 per move.
4. The general Theorem 1 can optionally be formalised from the invariants (I_i) and (J_i). The single instance already negates the conjecture as stated (∀ n, ℓ).
