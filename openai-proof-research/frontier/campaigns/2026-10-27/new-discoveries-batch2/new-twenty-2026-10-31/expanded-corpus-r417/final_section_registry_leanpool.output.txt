Theorem 3.2 [3]. For any connected graph G.
(1) If diam(G) ≤ 2, then V and V 0 are both convex dominating sets of πG for

Theorem 3.3. Every connected graph G has the following properties.
(1) If diam(G) ≤ 3, then V and V 0 are weakly convex dominating sets of πG for
    every permutation π.
(2) If diam(G) > 3, then there exist permutations π1 and π2 such that V is
    not a weakly convex dominating set of π1 G and V 0 is not a weakly convex
    dominating set of π2 G.

Proof. Obviously, for any permutation π, V and V 0 are dominating sets of πG.
For any pair of vertices u, v ∈ V, the shortest u–v path containing at least one
vertex from V 0 has length at least 3. Thus, if diam(G) ≤ 3, then dG (u, v) =
dπG (u, v) and V contains at least one shortest u–v path in πG. Similarly, if
diam(G) ≤ 3, then V 0 must contain a shortest u0 –v 0 path in πG for every u0 , v 0 ∈
V 0.

that dG (u, v) ≥ 4. If π1 is a permutation such that π1 (u) and π1 (v) are adjacent,
then dπG (u, v) = 3 < dG (u, v). Thus, V is not a weakly convex dominating set
in π1 G. Similarly, for π2 = π1−1 , the set V 0 is not weakly convex.

G with diameter at most 3.

Lemma 3.8. Let G be a connected graph in which diam(G) ≤ 2. Let D be a

(1) If π(D1 ) ⊆ D2 , then D2 is a weakly convex dominating set of G.

We now consider the special case where the permutation is π = Id. A graph G
is called a prism fixer if γ(IdG) = γ(G) and a prism doubler if γ(IdG) = 2γ(G).
A graph G is called a universal fixer if γ(πG) = γ(G) for every permutation
π of VG and a universal doubler if γ(πG) = 2γ(G) for every π. Prism fixers
are characterized in [4] and universal fixers in [5] and [6]. Prism doublers and
universal doublers are studied in [1].

universal γcon -fixer is a graph such that for every π γcon (πG) = γcon (G) and a
universal γcon -doubler is a graph such that γcon (πG) = 2γcon (G) for every π.
