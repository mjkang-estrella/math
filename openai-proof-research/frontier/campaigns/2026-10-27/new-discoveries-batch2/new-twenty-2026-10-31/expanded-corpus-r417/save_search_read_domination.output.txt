                                                   prism πG of G is defined as follows: V (πG) = V (G) ∪ V (G0 ), where G0 is
                                                   a copy of G, and E(πG) = E(G) ∪ E(G0 ) ∪ Mπ , where Mπ = {uv 0 : u ∈

                                                                               1. Introduction
                                               Let G = (VG , EG ) be an undirected graph, let π : VG 7→ VG be a permutation
                                           of its vertex set and let G0 be a vertex-disjoint copy of G. We denote the copy
                                           of a vertex v ∈ VG in G0 by v 0 . If S is a set of vertices of G, then S 0 denotes
                                           the copy of S in G0 , i.e. the set {v 0 : v ∈ S}. By V and V 0 we denote the vertex
                                           sets of G and G0 , respectively. The prism graph πG is a graph with the vertex set
                                           V ∪ V 0 and the edge set EG ∪ EG0 ∪ Mπ , where Mπ = {uπ(u)0 : u ∈ VG }.
                                               We say that a set A ∈ VG dominates B ∈ VG if B ∈ NG [A]. We denote this by
                                           A  B. A set A ∈ VG is called a dominating set of the graph G if it dominates VG ,
                                           i.e. if NG [A] = VG . The minimum cardinality of a dominating set in G is called the
                                           domination number of G and denoted γ(G). A minimum dominating set of a graph
                                           is sometimes called a γ-set.
                                               Prism graphs were first defined in [2] and the problem of domination in prism
                                           graphs was first studied by Burger, Mynhardt and Weakley [1].
                                               In a connected graph G a set of vertices A ⊆ VG is said to be convex if for
                                           every pair of vertices u, v ∈ A the set A contains all vertices of every shortest u–v
                                           path. A convex dominating set of G is a dominating set of G which is convex.
                                           The minimum cardinality of a convex dominating set of G is called the convex
                                           domination number of G and denoted as γcon (G). A γcon -set of G is a convex
                                           dominating set of cardinality γcon (G).
                                               A set A of vertices in a connected graph G is said to be weakly convex if for
                                           every pair of vertices u, v ∈ A it contains all vertices of at least one shortest u–v. A
                                           weakly convex dominating set G is a dominating set of G which is weakly convex.
                                           The minimum cardinality of a weakly convex dominating set of G is called the
                                           weakly convex domination number and denoted as γwcon (G). A γwcon -set of G is a
                                           minimum weakly convex dominating set.
                                               A set A ⊆ VG is said to be connected if it induces a connected subgraph, i.e.,
                                           if for every pair of vertices u, v ∈ A there exists a u–v path contained entirely in
                                           A. A connected dominating set of G is a dominating set which is connected. The

          2. Connected, convex and weakly convex domination
   It is clear that the notions of convex, weakly convex and connected domination
are closely related. Since every convex set is weakly convex and every weakly convex
set is connected, it is easy to see that γ(G) ≤ γc (G) ≤ γwcon (G) ≤ γcon (G). Many,
but not all, properties of connected sets can be extended to both convex and weakly
convex sets.

γc (πG) ≥ γ(G) + 1.
Proof. Obviously, if γ(πG) ≥ γ(G) + 1, then γc (πG) ≥ γ(G) + 1.
  If γ(πG) = γ(G) and D is a γ-set of πG, we denote D1 = D ∩ V and D20 =
D ∩ V 0 . Since the only vertices in V 0 dominated by D1 are in π(D1 ), it follows that
B = π(D1 ) ∪ D2  V and therefore |B| = |D| = γ(G). Thus, π(D1 ) ∩ D2 = ∅. Since
NV 0 (D1 ) = π(D1 )0 , it follows that E(D1 , D20 ) = ∅ and therefore D is not connected.

         3. Generalizing some properties of convex domination
  Convex domination in prism graphs was studied by Lemańska and Zuazua in [3],
where they prove the following theorem.
Theorem 4 ([3]). Let G be a connected graph. If
γcon (G) = |VG | and diam G ≤ 2, then γcon (G) = γcon (πG) for every permutation π
of VG .
   The proof of Theorem 4 relies some properties of convex dominating sets, which
they prove in the same paper. We will now compare these properties with those of
weakly convex dominating sets.
Theorem 5 ([3]). For any connected graph G:
    (1) If diam (G) ≤ 2, then V and V 0 are both convex dominating sets of πG for
        any permutation π.
    (2) If diam (G) ≥ 3, then there exist permutations π1 and π2 such that V is not
        a convex dominating set of π1 G and V 0 is not a convex dominating set of
        π2 G.
  It follows that if diam (G) ≤ 2, then γcon (πG) ≤ |VG | for any π. The weakly
convex domination number has a similar property.
Theorem 6. Every connected graph G has the following properties:
    (1) If diam (G) ≤ 3, then V and V 0 are weakly convex dominating sets of πG
        for every permutation π;
4                                 MONIKA ROSICKA


     (2) If diam (G) > 3, then there exist permutations π1 and π2 such that V is
         not a weakly convex dominating set of π1 G and V 0 is not a weakly convex
         dominating set of π2 G.
Proof. Obviously, for any permutation π, V and V 0 are dominating sets of πG. For
any pair of vertices u, v ∈ V, the shortest u–v path containing at least one vertex
from V 0 has length at least 3. Thus, if diam (G) ≤ 3, then dG (u, v) = dπG (u, v) and
V contains at least one shortest u–v path in πG. Similarly, if diam (G) ≤ 3, then
V 0 must contain a shortest u0 –v 0 path in πG for every u0 , v 0 ∈ V 0 .
   Now, let diam (G) be at least 4 and let u, v ∈ V be a pair of vertices such that
dG (u, v) ≥ 4. If π1 is a permutation such that π1 (u) and π1 (v) are adjacent, then
dπG (u, v) = 3 < dG (u, v). Thus, V is not a weakly convex dominating set in π1 G.
Similarly, for π2 = π1−1 , the set V 0 is not weakly convex.                         

   The first part of Theorem 6 implies that γwcon (πG) ≤ |VG | for any graph G with
diameter at most 3.
Proposition 7 ([3]). For a connected graph G and permutation π of VG , let D be
a convex dominating set of πG and let D1 = D ∩ V and D20 = D ∩ V 0 . Then D has
the following properties:
     (1) If |D| < |VG |, then D1 6= ∅ and D20 6= ∅;
     (2) If D1 6= ∅ and D20 6= ∅, then there exists at least one x ∈ D1 such that
         π(x) ∈ D2 .
    The above can be generalized to weakly convex and connected domination.
Proposition 8. For a connected graph G and permutation π of VG , let D be a
connected dominating set of πG and let D1 = D ∩ V and D20 = D ∩ V 0 . Then D
has the following properties:
     (1) If |D| < |VG |, then D1 6= ∅ and D20 6= ∅;
     (2) If D1 6= ∅ and D20 6= ∅, then there exists at least one x ∈ D1 such that
         π(x) ∈ D2 .
Proof. If D1 = ∅, then D = D20 . But every vertex in D20 only dominates one vertex
in V. It follows that if D is a dominating, then D1 = ∅ implies |D| = |V |. The same
reasoning applies if D20 = ∅. Thus, if |D| < |V | , then ∅ ∈
                                                           / {D1 , D20 }.
   If both sets D1 and D2 are nonempty, then D contains a pair of vertices v1 ∈
D1 , v20 ∈ D20 . Since the set D is connected, there exists a v1 -v20 path contained
entirely in D. Each vertex v ∈ V has only one neighbor in V 0 , namely π(v)0 . Hence,
every path connecting v1 ∈ D1 with v20 ∈ D20 contains a pair of vertices x ∈ V and

Lemma 10 ([3]). Let G be a connected graph in which diam (G) ≤ 2. Let D be a
convex dominating set of πG and let D1 = D ∩ V and D20 = D ∩ V 0 . Then the set
D has the following properties:
   (1) If π(D1 ) ⊆ D2 , then D2 is a convex dominating set of G;
   (2) If π −1 (D2 ) ⊆ D1 , then D1 is a convex dominating set of G.
  Again, we can prove a similar property for weakly convex domination.
Lemma 11. Let G be a connected graph in which diam (G) ≤ 2. Let D be a weakly
convex dominating set of πG and let D1 = D ∩ V and D20 = D ∩ V 0 . Then the set
D has the following properties:
   (1) If π(D1 ) ⊆ D2 , then D2 is a weakly convex dominating set of G;
   (2) If π −1 (D2 ) ⊆ D1 , then D1 is a weakly convex dominating set of G.
Proof. If π(D1 ) ∈ D2 , then clearly D20 dominates V 0 , as D1 does not dominate any
part of V 0 − D20 . It follows that D2 is a dominating set of G. For any two vertices
u0 , v 0 ∈ D20 the shortest possible u0 -v 0 -path in πG containing a vertex from V has
length at least 3. If diam (G) ≤ 2, then any shortest u0 -v 0 -path must be contained
in D20 . Thus, for every u, v ∈ D2 the set D2 contains a shortest u-v-path. Hence,
D2 is a weakly convex dominating set of G.
    Similarly, if π −1 (D2 ) ⊆ D1 , then D1 is a dominating set of G because D20 does
not dominate any part of V − D1 . D1 is also convex, because for any u, v ∈ D1 no
shortest u-v-path passes through D20 .                                               
   Note that, unlike Theorem 6, the above is does not hold for every G such that
diam (G) ≤ 3. For example, if G = P4 = ({1, 2, 3, 4}, {12, 23, 34}) and π = (12)(34),
the set D = {10 , 2, 3, 40 } is a weakly convex dominating set of πG. The set {1, 4}
contains π({2, 3}) and it is not a weakly convex set.
   Since so many of the results in [3] can be generalized to weakly convex domina-
tion, one could expect a weakly convex analogue of Theorem 4 to be true as well.
However, Lemańska and Zuazua’s proof relies on showing that if G is a conncected
graph with diam(G) ≤ 2, then a dominating set of πG with less than |VG | vertices
cannot be convex. This is based on properties of convex sets which weakly convex
sets do not have. Thus there appears to be no reason why such a set cannot be
weakly convex and therefore the following conjecture seems more likely.
Conjecture 1. There exists a connected graph G with diam(G) = 2 and permuta-
tion π of VG such that γwcon (G) = |VG | and γwcon (πG) < γwcon (G).

             4. Convex and weakly convex domination in Id G
   We now consider the special case where the permutation π = Id . A graph G
is called a prism fixer if γ(Id G) = γ(G) and a prism doubler if γ(Id G) = 2γ(G).
A graph G is called a universal fixer if γ(πG) = γ(G) for every permutation π of VG
and a universal doubler if γ(πG) = 2γ(G) for every π. Prism fixers are characterized
in [4] and universal fixers in [5] and [6]. Prism doublers and universal doublers are
studied in [1].
   Similarly, a graph G such that γcon (Id G) = γcon (G) is called a prism γcon -fixer
and a graph with γcon (Id G) = 2γcon (G) is called a prism γcon -doubler. A universal
γcon -fixer is a graph such that for every π γcon (πG) = γcon (G) and a universal
γcon -doubler is a graph such that γcon (πG) = 2γcon (G) for every π.

Theorem 15. If G is any connected graph, then γcon (Id G) = min{2γcon (G), |VG |}.
Proof. Let A be a γcon -set of G. Obviously, A ∪ A0 dominates Id G. By Lemma 13,
A ∪ A0 is a convex set in Id G. Hence, A ∪ A0 is clearly a convex dominating set of
πG. The set V is also a convex dominating set of πG.
   Let D be a γcon -set in πG. If D ∩ V 0 = ∅, then obviously D = V. Similarly, if
D ∩ V = ∅, then D = V 0 . If D contains vertices u ∈ V and v 0 ∈ V 0 , it must also
contain every shortest u-v 0 path in πG. Thus, D contains u0 , v and all shortest u-v
and u0 -v 0 paths. Therefore, in this case, D = A ∪ A0 for some A ⊆ V and A is a
γcon -set of G.                                                                    

                                 5. Upper and lower bounds
    It is well known that the inequalities


(1)                                      γ(G) ≤ γ(πG) ≤ 2γ(G)
            CONVEX AND WEAKLY CONVEX DOMINATION IN PRISM GRAPHS                                    9


hold for any graph G and any permutation π of its vertex set. At the confer-
ence Colorings Inependence and Domination in 2015 Rita Zuazua conjectured that
similar inequalities hold for convex and weakly convex domination, i.e.




(2)                         γwcon (G) ≤ γwcon (πG) ≤ 2γwcon (G)




                                                and




(3)                           γcon (G) ≤ γcon (πG) ≤ 2γcon (G)




However, this is not true in general. The smallest counterexample is the path P3
with VP3 = {1, 2, 3}, EP3 = {12, 23} and the permutation π = (12). In this case
γcon (P3 ) = γwcon (P3 ) = 1 while γcon (πP3 ) = γwcon (P3 ) = 3.
   For a star K1,k with k ≥ 2 and the permutation π = (01), where 0 is the central
vertex and 1 is one of the other vertices, we have γcon (K1,k ) = γwcon (K1,k ) = 1
and γcon (πK1,k ) = 4 while γwcon (K1,k ) = 3. Thus, the upper bounds in (2) and
(3) not hold for K1,k .
   Furthermore, for every k ∈ N there is a graph G and permutation π such that
γwcon (πG) − 2γwcon (G) ≥ k.
   Let us begin with the cycle C7 = ({0, 1, 2, 3, 4, 5, 6}, {01, 12, 23, 34, 45, 56, 60})
and the permutation π = (13)(46). The weakly convex domination number of C7 is
7, but the graph πC7 can be dominated by a weakly convex set with only 6 vertices:
{0, 00 , 1, 10 , 6, 60 }.
   In fact, the difference can be arbitrarily large. For any k ∈ N we can construct
a graph Gk as follows (see Fig. 2).


      (1) Take k copies of C7 . Denote the i-th copy of the vertex j by (i, j),
      (2) Replace the vertices (1, 0), ..., (k, 0) with a single vertex (0, 0).


   The permutation πk is defined as πk (i, j) = (i, π(j)). Then γwcon (Gk ) = 6k + 1
and γwcon (πk Gk ) = 4k + 2 (The set {(0, 0), (0, 0)0 , (1, 1), ..., (k, 1), (1, 1)0 , ..., (k, 1)0 ,
(1, 6), ..., (k, 6), (1, 6)0 , ..., (k, 6)0 } is a weakly convex domiating set of πk Gk ). Hence
γwcon (Gk ) − γwcon (πk Gk ) = 2k − 1.

Remark 20. The convex domination number of πG cannot be bounded in terms of
γcon (G).
Proof. Notice that for the graphs Gk defined above γcon (πk Gk ) is constant, while
γcon (Gk ) grows with the increase of k. This shows that there is no upper bound on
γcon (πG) depending only on γcon (G).
   Similarly, if k is constant and l increases, γcon (πk,l Tk,l ) for the tree Tk,l increases,
while γcon (Tk,l ) remains constant. Thus there is no lower bound on γcon (G) de-
pending solely on γcon (G).                                                                 
