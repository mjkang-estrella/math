 Abstract.

 
 For a positive integer h h , let R A , h ​ ( n ) R_{A,h}(n) denote the number of ordered representations
 n = s 1 + ⋯ + s h n=s_{1}+\cdots+s_{h} with all s i ∈ A s_{i}\in A . Let

 
 

 
 
 ℬ = { 0 } ∪ { m ≥ 1 :  the base-4 expansion of  ​ m ​  begins with  ​ 1 ​  or  ​ 2 } . \mathcal{B}=\{0\}\cup\{m\geq 1:\text{ the base-4 expansion of }m\text{ begins with }1\text{ or }2\}. 
 
 
 
 
 Shallit proved that R ℬ , 3 ​ ( n ) R_{\mathcal{B},3}(n) is strictly increasing, thereby disproving a 2002 conjecture of Dombi. In this paper, by using linear bounds for

 1. Introduction


 
 Let ℕ = { 0 , 1 , 2 , … } \mathbb{N}=\{0,1,2,\ldots\} . For a set A ⊆ ℕ A\subseteq\mathbb{N} and an integer h ≥ 1 h\geq 1 , define the ordered h h -fold representation function by

 

 
 
 R A , h ​ ( n ) = # ⁡ { ( a 1 , … , a h ) ∈ A h : a 1 + ⋯ + a h = n } . R_{A,h}(n)=\#\{(a_{1},\ldots,a_{h})\in A^{h}:\ a_{1}+\cdots+a_{h}=n\}. 
 
 
 
 Equivalently, if

 

 
 
 G A ​ ( x ) = ∑ a ∈ A x a , G_{A}(x)=\sum_{a\in A}x^{a}, 
 
 
 
 then

 

 
 
 ∑ n ≥ 0 R A , h ​ ( n ) ​ x n = G A ​ ( x ) h . \sum_{n\geq 0}R_{A,h}(n)x^{n}=G_{A}(x)^{h}. 
 
 
 
 We also write

 

 
 
 A ⁡ ( n ) = # ⁡ { a ∈ A : a ≤ n } A(n)=\#\{a\in A:\ a\leq n\} 
 
 
 
 for the counting function of A A . The problem considered here is when R A , h ​ ( n ) R_{A,h}(n) can be eventually increasing, or strictly increasing, when the complement ℕ ∖ A \mathbb{N}\setminus A is infinite.



 
 The following theorem, due to Erdős, Sárközy and Sós (see [ 4 , 5 ] ), shows that for the ordered representation function no genuinely co-infinite example is possible.



 
 Theorem A (Erdős–Sárközy–Sós) . 

 
 Let A ⊆ ℕ A\subseteq\mathbb{N} . The function R A , 2 ​ ( n ) R_{A,2}(n) is eventually increasing if and only if A A is cofinite; that is, there exists an integer n 0 n_{0} such that 

 

 
 
 { n ∈ ℕ : n ≥ n 0 } ⊆ A . \{n\in\mathbb{N}:n\geq n_{0}\}\subseteq A. 
 
 
 




 
 Related versions for unordered and restricted unordered two-fold representation functions were also studied by Erdős, Sárközy and Sós.



 
 For h ≥ 3 h\geq 3 , based on the Rudin–Shapiro sequence, Dombi [ 3 ] gave a set of density 1 / 2 1/2 whose higher representation functions are eventually increasing.



 
 Theorem B (Dombi) . 

 
 There exists a set A ⊆ ℕ A\subseteq\mathbb{N} of asymptotic density 1 / 2 1/2 such that, for every fixed integer h > 4 h>4 , the function R A , h ​ ( n ) R_{A,h}(n) is eventually increasing. 





 
 Dombi [ 3 ] also proposed the following conjectural obstruction to strict monotonicity in the co-infinite case.



 
 Dombi’s Conjecture . 

 
 If ℕ ∖ A \mathbb{N}\setminus A is infinite, then R A , h ​ ( n ) R_{A,h}(n) cannot be eventually strictly increasing. 





 
 This conjecture is now known to be false. Shallit [ 8 ] constructed co-infinite sets with strictly increasing three-fold representation functions by methods from automata theory and logic.



 
 Theorem C (Shallit) . 

 
 There exists a co-infinite set A ⊆ ℕ A\subseteq\mathbb{N} such that R A , 3 ​ ( n ) R_{A,3}(n) is eventually strictly increasing. 





 
 Let

 

 
 
 ℬ = { 0 } ∪ { m ≥ 1 :  the base-4 expansion of  ​ m ​  begins with  ​ 1 ​  or  ​ 2 } . \mathcal{B}=\{0\}\cup\{m\geq 1:\text{ the base-4 expansion of }m\text{ begins with }1\text{ or }2\}. 
 
 
 
 For Shallit’s result one may take A = ℬ A=\mathcal{B} ; in fact R ℬ , 3 ​ ( n ) R_{\mathcal{B},3}(n) is strictly increasing.
Shallit also remarked that R ℬ , h ​ ( n ) R_{\mathcal{B},h}(n) is eventually strictly increasing for every fixed integer h ≥ 3 h\geq 3 .
In this paper, we improve this result by giving a polynomial order of
 R ℬ , h ​ ( n + 1 ) − R ℬ , h ​ ( n ) R_{\mathcal{B},h}(n+1)-R_{\mathcal{B},h}(n) for every integer h ≥ 3 h\geq 3 .



 
 Theorem 1.1 . 

 
 For every fixed integer h ≥ 3 h\geq 3 , there exist constants c h , C h > 0 c_{h},C_{h}>0 , depending only on h h , such that for every integer n ≥ 1 n\geq 1 , 

 

 
 
 c h ​ n h − 2 ≤ R ℬ , h ​ ( n + 1 ) − R ℬ , h ​ ( n ) ≤ C h ​ n h − 2 . c_{h}n^{h-2}\leq R_{\mathcal{B},h}(n+1)-R_{\mathcal{B},h}(n)\leq C_{h}n^{h-2}. 
 
 
 
 Moreover, 

 

 
 
 R ℬ , h ​ ( n + 1 ) − R ℬ , h ​ ( n ) > 0 R_{\mathcal{B},h}(n+1)-R_{\mathcal{B},h}(n)>0 
 
 
 
 for every n ≥ 0 n\geq 0 . 





 
 Remark . 

 
 The exponent h − 2 h-2 is the natural scale. For the full set ℕ \mathbb{N} , 

 

 
 
 R ℕ , h ​ ( n ) = ( n + h − 1 h − 1 ) , R_{\mathbb{N},h}(n)=\binom{n+h-1}{h-1}, 
 
 
 
 and hence 

 

 
 
 R ℕ , h ( n + 1 ) − R ℕ , h ( n ) = ( n + h − 1 h − 2 ) ≍ h n h − 2 . R_{\mathbb{N},h}(n+1)-R_{\mathbb{N},h}(n)=\binom{n+h-1}{h-2}\asymp_{h}n^{h-2}. 
 
 
 
 Thus Theorem  1.1 says that the base- 4 4 set ℬ \mathcal{B} has the same first-difference order as ℕ \mathbb{N} , despite having an infinite complement with long gaps. 





 
 In Dombi’s paper, the following problem is also posed.



 
 Dombi’s Problem . 

 
 Let h ≥ 3 h\geq 3 . Is there any set A ⊂ ℕ A\subset\mathbb{N} with R A , h ​ ( n ) R_{A,h}(n) eventually increasing and satisfying 



 
 

 
 
 lim n → ∞ A ⁡ ( n ) n = α  with  ​ α ≠ 1 2 ​ ? \lim_{n\rightarrow\infty}\frac{A(n)}{n}=\alpha\quad\text{ with }\alpha\neq\frac{1}{2}? 
 
 
 




 
 For the set ℬ \mathcal{B} one has

 

 
 
 lim inf n → ∞ ℬ ⁡ ( n ) n = 2 3 , lim sup n → ∞ ℬ ⁡ ( n ) n = 8 9 . \liminf_{n\to\infty}\frac{\mathcal{B}(n)}{n}=\frac{2}{3},\qquad\limsup_{n\to\infty}\frac{\mathcal{B}(n)}{n}=\frac{8}{9}. 
 
 
 
 Hence lim n → ∞ ℬ ⁡ ( n ) / n \lim_{n\to\infty}\mathcal{B}(n)/n does not exist.



 
 In the following theorem, we give a new set 𝒞 \mathcal{C} such that lim n → ∞ 𝒞 ⁡ ( n ) / n \lim_{n\to\infty}\mathcal{C}(n)/n exists and is not equal to 1 / 2 1/2 , and such that R 𝒞 , h ​ ( n ) R_{\mathcal{C},h}(n) is strictly increasing for every fixed integer h ≥ 3 h\geq 3 . This answers Dombi’s problem in the form stated above. The more delicate case of prescribed density d ∈ [ 0 , 1 ) d\in[0,1) remains open and is formulated in Problem  1.4 below.



 
 Theorem 1.2 . 

 
 There exists a co-infinite set 𝒞 ⊂ ℕ \mathcal{C}\subset\mathbb{N} such that 

 

 
 
 lim n → ∞ 𝒞 ⁡ ( n ) n = 1 \lim_{n\rightarrow\infty}\frac{\mathcal{C}(n)}{n}=1 
 
 
 
 and, for every integer h ≥ 3 h\geq 3 , 

 

 
 
 R 𝒞 , h ​ ( n + 1 ) > R 𝒞 , h ​ ( n ) ( n ≥ 0 ) . R_{\mathcal{C},h}(n+1)>R_{\mathcal{C},h}(n)\qquad(n\geq 0). 
 
 
 




 
 Remark 1.3 . 

 
 In the above theorem, we construct 𝒞 = ℕ ∖ { 2 j : j ≥ 10 } \mathcal{C}=\mathbb{N}\setminus\{2^{j}:\ j\geq 10\} . It would be interesting to determine whether the set ℕ ∖ { 4 n + 2 : n ≥ 0 } \mathbb{N}\setminus\{4^{n+2}:\ n\geq 0\} from Bell and Shallit [ 2 ] also has this property. 





 
 By numerical computations, we can see that the set A A in Theorem B by Dombi does not satisfy
 R A , 3 ​ ( n ) R_{A,3}(n) strictly increasing, since R A , 3 ​ ( 22 ) = 78 R_{A,3}(22)=78 and R A , 3 ​ ( 23 ) = 75 R_{A,3}(23)=75 . Motivated by this,
we pose the following problems for further research.



 
 Problem 1.4 . 

 
 For which d ∈ [ 0 , 1 ) d\in[0,1) does there exist a set A ⊆ ℕ A\subseteq\mathbb{N} with 

 

 
 
 lim n → ∞ A ⁡ ( n ) n = d \lim_{n\to\infty}\frac{A(n)}{n}=d 
 
 
 
 such that R A , h ​ ( n ) R_{A,h}(n) is strictly increasing for every integer h ≥ 3 h\geq 3 ? 





 
 Problem 1.5 . 

 
 Given two real numbers α \alpha and β \beta with 0 ≤ α < β ≤ 1 0\leq\alpha<\beta\leq 1 , does there exist A ⊆ ℕ A\subseteq\mathbb{N} with lim inf n → + ∞ A ⁡ ( n ) n = α \liminf\limits_{n\rightarrow+\infty}\frac{A(n)}{n}=\alpha and
 lim sup n → + ∞ A ⁡ ( n ) n = β \limsup\limits_{n\rightarrow+\infty}\frac{A(n)}{n}=\beta such that R A , h ​ ( n ) R_{A,h}(n) is strictly increasing for every h ≥ 3 h\geq 3 ? 





 
 In the other direction, some results further characterize the obstruction caused by sparsity: if a set A A is sparse, then the corresponding unordered, restricted unordered two-fold representation functions and R A , h ​ ( n ) R_{A,h}(n) cannot be monotonically increasing. For these results, one may refer to [ 1 , 4 , 5 , 6 , 7 , 9 ] .

 3. Bounds for the two-fold and three-fold differences


 
 We first prove the two-sided bound for β n \beta_{n} . The upper bound will be used for the lower estimate on α n \alpha_{n} ; the lower bound is the key input for the upper estimate on α n \alpha_{n} .

 For every n ≥ 0 n\geq 0 ,
