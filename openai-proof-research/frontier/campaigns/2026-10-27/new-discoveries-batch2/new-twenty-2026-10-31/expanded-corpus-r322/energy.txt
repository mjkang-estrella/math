 Abstract.

 
 We derive several applications of the path-minimality theorem for adjacency
 p p -energy proved in the companion paper. First, we prove the sharp inequality

 
 

 
 
 ℰ p + ​ ( G ) ≥ ℰ p + ​ ( P n ) , \mathcal{E}_{p}^{+}(G)\geq\mathcal{E}_{p}^{+}(P_{n}), 
 
 
 
 
 where P n P_{n} is the path on n n vertices, in three settings: connected bipartite graphs for every real p ≥ 2 p\geq 2 , all connected graphs for every odd integer p ≥ 3 p\geq 3 , and all connected graphs for p = 4 p=4 . Second, using subdivision graphs, we prove path-minimality for Laplacian and signless Laplacian-type spectral sums, including power sums, Estrada-type quantities, resolvent energies, and thresholded tails. Third, we prove an edge-count second-order stop-loss comparison for the signless Laplacian above the threshold 2 2 . This yields the sharp line-graph inequality

 
 

 
 
 ℰ p + ​ ( ℒ ⁡ ( G ) ) ≥ ℰ p + ​ ( P m ) \mathcal{E}_{p}^{+}(\mathcal{L}(G))\geq\mathcal{E}_{p}^{+}(P_{m}) 
 
 
 
 
 for every connected graph G G with m m edges and every real p ≥ 2 p\geq 2 .

 


 
 Key words and phrases: 
graph energy, Laplacian spectrum, signless Laplacian, line graph

 1. Introduction


 
 Throughout this paper, all graphs are finite, simple, undirected, and unweighted. Let G G be a graph with vertex set V ⁡ ( G ) = { v 1 , … , v n } V(G)=\{v_{1},\ldots,v_{n}\} , and let A ⁡ ( G ) A(G) be its n × n n\times n adjacency matrix, whose ( i , j ) (i,j) -entry is 1 1 if v i ​ v j ∈ E ⁡ ( G ) v_{i}v_{j}\in E(G) and is 0 0 otherwise. We write

 

 
 
 λ 1 ​ ( G ) , λ 2 ​ ( G ) , … , λ n ​ ( G ) \lambda_{1}(G),\lambda_{2}(G),\ldots,\lambda_{n}(G) 
 
 
 
 for the eigenvalues of A ⁡ ( G ) A(G) , counted with multiplicity. For a real number x x , we write x + := max ⁡ { x , 0 } x_{+}:=\max\{x,0\} for its positive part. For p > 0 p>0 we define the adjacency p p -energy of G G by

 

 
 
 ℰ p ​ ( G ) := ∑ i = 1 n | λ i ​ ( G ) | p . \mathcal{E}_{p}(G):=\sum_{i=1}^{n}|\lambda_{i}(G)|^{p}. 
 
 
 
 We write P n P_{n} for the path on n n vertices. The companion paper  [ 12 ] proves that, for every connected graph
 G G on n n vertices and every real p ≥ 2 p\geq 2 ,

 

 
 
 ℰ p ​ ( G ) ≥ ℰ p ​ ( P n ) , \mathcal{E}_{p}(G)\geq\mathcal{E}_{p}(P_{n}), 
 
 
 
 with equality for fixed p > 2 p>2 only when G ≅ P n G\cong P_{n} . The proof also
establishes a stronger second-order stop-loss comparison for the squared
singular values of connected bipartite graphs. The purpose of the present
paper is to turn these comparison principles into sharp extremal results for
several related spectral quantities.



 
 The first application concerns positive adjacency p p -energy. If

 

 
 
 ℰ p + ​ ( G ) := ∑ λ i ​ ( G ) > 0 λ i ​ ( G ) p , \mathcal{E}_{p}^{+}(G):=\sum_{\lambda_{i}(G)>0}\lambda_{i}(G)^{p}, 
 
 
 
 then the conjecture of Tang, Liu and Wang  [ 19 , Conjecture 4.6] asks whether

 

 
 
 ℰ p + ​ ( G ) ≥ ℰ p + ​ ( P n ) \mathcal{E}_{p}^{+}(G)\geq\mathcal{E}_{p}^{+}(P_{n}) 
 
 
 
 holds for every connected n n -vertex graph G G and every p ≥ 2 p\geq 2 . We verify this sharp path lower bound
in three cases. It holds for all connected bipartite graphs and all real
 p ≥ 2 p\geq 2 , for all connected graphs when p ≥ 3 p\geq 3 is an odd integer, and for
all connected graphs when p = 4 p=4 . The first two statements are short
consequences of the total p p -energy theorem, while the p = 4 p=4 case uses a
vertex-addition estimate for positive p p -energy.



 
 The second application is to Laplacian-type spectra. For a graph G G , let D ⁡ ( G ) D(G) denote the diagonal matrix of vertex degrees and let A ⁡ ( G ) A(G) denote the adjacency matrix. The Laplacian matrix and the signless Laplacian matrix of G G are

 

 
 
 L ⁡ ( G ) := D ⁡ ( G ) − A ⁡ ( G ) , Q ⁡ ( G ) := D ⁡ ( G ) + A ⁡ ( G ) , L(G):=D(G)-A(G),\qquad Q(G):=D(G)+A(G), 
 
 
 
 respectively. Both matrices are real symmetric and positive semidefinite. For a real symmetric matrix M M , we write λ 1 ​ ( M ) ≥ λ 2 ​ ( M ) ≥ ⋯ \lambda_{1}(M)\geq\lambda_{2}(M)\geq\cdots for its eigenvalues in nonincreasing order, repeated with multiplicity. Using the subdivision graph and the unsigned incidence matrix, we convert the bipartite comparison
from the companion paper  [ 12 ] into path-minimality statements for L ⁡ ( G ) L(G) and
 Q ⁡ ( G ) Q(G) . In particular, for every connected G G on n n vertices and every
 α ≥ 1 \alpha\geq 1 , we prove

 

 
 
 ∑ i = 1 n λ i ​ ( L ⁡ ( G ) ) α ≥ ∑ i = 1 n λ i ​ ( L ⁡ ( P n ) ) α , ∑ i = 1 n λ i ​ ( Q ⁡ ( G ) ) α ≥ ∑ i = 1 n λ i ​ ( Q ⁡ ( P n ) ) α . \sum_{i=1}^{n}\lambda_{i}(L(G))^{\alpha}\geq\sum_{i=1}^{n}\lambda_{i}(L(P_{n}))^{\alpha},\qquad\sum_{i=1}^{n}\lambda_{i}(Q(G))^{\alpha}\geq\sum_{i=1}^{n}\lambda_{i}(Q(P_{n}))^{\alpha}. 
 
 
 
 More generally, the same method gives comparisons for Estrada-type sums, resolvent energies,
and thresholded tails.



 
 The third application concerns line graphs. We use the standard spectral
relation

 

 
 
 ℰ p + ​ ( ℒ ⁡ ( G ) ) = ∑ i ( λ i ​ ( Q ⁡ ( G ) ) − 2 ) + p . \mathcal{E}_{p}^{+}(\mathcal{L}(G))=\sum_{i}\bigl(\lambda_{i}(Q(G))-2\bigr)_{+}^{p}. 
 
 
 
 To prove the desired
line-graph inequality, we establish the following edge-count second-order
stop-loss comparison:

 

 
 
 ∑ i ( λ i ​ ( Q ⁡ ( G ) ) − t ) + 2 ≥ ∑ i ( λ i ​ ( Q ⁡ ( P m + 1 ) ) − t ) + 2 ( t ≥ 2 ) , \sum_{i}\bigl(\lambda_{i}(Q(G))-t\bigr)_{+}^{2}\geq\sum_{i}\bigl(\lambda_{i}(Q(P_{m+1}))-t\bigr)_{+}^{2}\qquad(t\geq 2), 
 
 
 
 for every connected graph G G with m m edges. Integrating this comparison
over the threshold gives

 

 
 
 ℰ p + ​ ( ℒ ⁡ ( G ) ) ≥ ℰ p + ​ ( P m ) ( p ≥ 2 ) . \mathcal{E}_{p}^{+}(\mathcal{L}(G))\geq\mathcal{E}_{p}^{+}(P_{m})\qquad(p\geq 2). 
 
 
 
 This is the technically most independent part of the paper; its proof uses
rank-one spectral-shift estimates, a deletion-minimal counterexample argument,
and exact finite checks.



 
 The paper is organized as follows. Section  2 recalls the
comparison inputs from the companion paper and collects the spectral-shift
notation used later. Section  3 proves the applications
to positive p p -energies, Laplacian-type spectra, and line graphs.
Appendix  A records the exact rational
certificate checks used in the line-graph argument.

 3. Applications to positive p p -energies, Laplacian-type spectra, and line graphs


 
 We now prove the announced applications. The first two subsections use the
path-minimality and bipartite stop-loss comparisons from the companion paper
rather directly. The final subsection proves an additional edge-count
comparison for the signless Laplacian, which is then converted into a sharp
positive p p -energy bound for line graphs.



 
 3.1. Applications to positive p p -energies


 
 Positive and negative p p -energies appear naturally in several spectral graph-theoretic problems. For example, Elphick, Tang and Zhang used positive and negative p p -energies to obtain lower bounds for the chromatic number, fractional chromatic number, quantum chromatic number, orthogonal rank, and projective rank; their results show that non-integer values of p p can sometimes give sharper spectral coloring bounds than the classical choices  [ 7 ] .



 
 For a graph G G , let

 

 
 
 ℰ p + ​ ( G ) = ∑ λ i ​ ( G ) > 0 λ i ​ ( G ) p , ℰ p − ​ ( G ) = ∑ λ i ​ ( G ) < 0 | λ i ​ ( G ) | p \mathcal{E}_{p}^{+}(G)=\sum_{\lambda_{i}(G)>0}\lambda_{i}(G)^{p},\qquad\mathcal{E}_{p}^{-}(G)=\sum_{\lambda_{i}(G)<0}|\lambda_{i}(G)|^{p} 
 
 
 
 be its positive and negative adjacency p p -energies . When p = 2 p=2 , these quantities are the positive and negative square energies of G G . The positive and negative square energies had appeared earlier in the literature, but they were first studied systematically by Elphick, Farber, Goldberg and Wocjan, who formulated influential conjectural lower bounds for the sums of squares of positive and negative eigenvalues  [ 6 ] . For recent progress on these square-energy problems, see the works of Zhang  [ 20 ] , Akbari, Kumar, Mohar and Pragada  [ 2 ] , and Akbari, Kumar, Mohar, Pragada and Zhang  [ 4 ] .



 
 Tang, Liu and Wang introduced positive and negative p p -energies in their study of edge addition and proposed the following positive p p -energy conjecture  [ 19 ] .



 
 Conjecture 3.1 ( [ 19 , Conjecture 4.6] ) . 

 
 Let p ≥ 2 p\geq 2 be a real number, and let G G be a connected graph with n n vertices. Then 

 

 
 
 ℰ p + ​ ( G ) ≥ ℰ p + ​ ( P n ) . \mathcal{E}_{p}^{+}(G)\geq\mathcal{E}_{p}^{+}(P_{n}). 
 
 
 




 
 Conjecture  3.1 , together with the related problems
for positive and negative p p -energies, has attracted recent attention.
Akbari, Kumar, Mohar and Pragada proved a general superadditivity theorem for
the positive and negative p p -energies of Hermitian block matrices for every
 p ≥ 1 p\geq 1   [ 3 ] . They also proposed the corresponding negative
 p p -energy conjecture, asserting that

 

 
 
 ℰ p − ​ ( G ) ≥ ℰ p − ​ ( K n ) \mathcal{E}_{p}^{-}(G)\geq\mathcal{E}_{p}^{-}(K_{n}) 
 
 
 
 for every connected graph G G on n n vertices and every p ≥ 2 p\geq 2 , and
proved this conjecture for p ≥ 4 p\geq 4   [ 3 ] . In the positive direction, they obtained a linear lower bound for
 ℰ p + ​ ( G ) \mathcal{E}_{p}^{+}(G) when p ≥ 4 p\geq 4   [ 3 , Theorem 2] . Recently, Chen, Wang and Zhang proved the negative
 p p -energy conjecture for every integer p ≥ 3 p\geq 3 and obtained a linear lower
bound for the positive 3 3 -energy  [ 5 ] .



 
 For clarity, none of the preceding positive-energy results gives the exact
path lower bound asserted in Conjecture  3.1 . The
positive-energy lower bound of Akbari, Kumar, Mohar and Pragada has the correct
linear order of magnitude for p ≥ 4 p\geq 4 , but it is not the sharp quantity
 ℰ p + ​ ( P n ) \mathcal{E}_{p}^{+}(P_{n}) . Similarly, the positive-energy result of Chen, Wang
and Zhang gives a linear lower bound for ℰ 3 + ​ ( G ) \mathcal{E}_{3}^{+}(G) , rather than the
exact path-minimality inequality ℰ 3 + ​ ( G ) ≥ ℰ 3 + ​ ( P n ) \mathcal{E}_{3}^{+}(G)\geq\mathcal{E}_{3}^{+}(P_{n}) . Thus the exact positive p p -energy path bound remains separate from these
known linear lower bounds, even in the cases p = 3 p=3 and p ≥ 4 p\geq 4 .



 
 Our main theorem settles Conjecture  3.1 for connected bipartite graphs.



 
 Theorem 3.2 . 

 
 Let G G be a connected bipartite graph on n n vertices. Then, for every real number p ≥ 2 p\geq 2 , 

 

 
 
 ℰ p + ​ ( G ) ≥ ℰ p + ​ ( P n ) . \mathcal{E}_{p}^{+}(G)\geq\mathcal{E}_{p}^{+}(P_{n}). 
 
 
 




 
 Proof.

 
 Since G G is bipartite, its nonzero adjacency eigenvalues occur in pairs ± λ \pm\lambda . Hence 

 

 
 
 ℰ p + ​ ( G ) = ℰ p − ​ ( G ) = 1 2 ​ ℰ p ​ ( G ) . \mathcal{E}_{p}^{+}(G)=\mathcal{E}_{p}^{-}(G)=\frac{1}{2}\mathcal{E}_{p}(G). 
 
 
 
 The path P n P_{n} is also bipartite, so ℰ p + ​ ( P n ) = 1 2 ​ ℰ p ​ ( P n ) \mathcal{E}_{p}^{+}(P_{n})=\frac{1}{2}\mathcal{E}_{p}(P_{n}) . By Theorem  2.1 , we have ℰ p ​ ( G ) ≥ ℰ p ​ ( P n ) \mathcal{E}_{p}(G)\geq\mathcal{E}_{p}(P_{n}) . Therefore 

 

 
 
 ℰ p + ​ ( G ) = 1 2 ​ ℰ p ​ ( G ) ≥ 1 2 ​ ℰ p ​ ( P n ) = ℰ p + ​ ( P n ) . ∎ \mathcal{E}_{p}^{+}(G)=\frac{1}{2}\mathcal{E}_{p}(G)\geq\frac{1}{2}\mathcal{E}_{p}(P_{n})=\mathcal{E}_{p}^{+}(P_{n}).\qed 
 
 
 




 
 The same theorem also verifies Conjecture  3.1 for every odd integer p ≥ 3 p\geq 3 . In particular, when p = 3 p=3 , it gives the sharp path lower bound predicted by the conjecture,

 

 
 
 ℰ 3 + ​ ( G ) ≥ ℰ 3 + ​ ( P n ) , \mathcal{E}_{3}^{+}(G)\geq\mathcal{E}_{3}^{+}(P_{n}),

∎

 This theorem has the following square-energy interpretation.



 
 Remark 3.19 . 

 
 Recall that s + ​ ( H ) = ℰ 2 + ​ ( H ) s^{+}(H)=\mathcal{E}_{2}^{+}(H) denotes the positive square energy of a graph H H . Taking p = 2 p=2 in Theorem  3.18 gives

 Thus Theorem  3.18 gives the line-graph case of the positive square-energy lower bound. This should be compared with the recent theorem of Akbari, Kumar, Mohar, Pragada and Zhang, who prove a stronger p = 2 p=2 refinement for connected claw-free graphs with maximum degree at least 3 3   [ 4 , Theorem 1.1] . Since line graphs are claw-free, their result applies to line graphs satisfying this maximum-degree hypothesis in a broader graph class. The point of Theorem  3.18 is different: within the class of line graphs, it gives the same sharp path lower bound for every real exponent p ≥ 2 p\geq 2 .
