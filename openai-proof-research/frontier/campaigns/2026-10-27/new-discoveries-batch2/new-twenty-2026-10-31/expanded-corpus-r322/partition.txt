 Abstract.

 
 Ballantine–Beck–Feigon–Maurischat introduced the subsum polynomial

 
 

 
 
 sp ⁡ ( λ , x ) := ∏ i ( 1 + x λ i ) \operatorname{sp}(\lambda,x):=\prod_{i}(1+x^{\lambda_{i}}) 
 
 
 
 
 attached to an integer partition λ \lambda , and studied rational functions obtained by
summing reciprocals of these polynomials over natural classes of partitions. They posed ten
conjectures which naturally divide into coprimality and divisibility questions, special-value and
recurrence formulas, and coefficient-shape problems.
We prove all of the
conjectures in the first two families: the ordinary and binary coprimality/divisibility
conjectures, and the odd and ternary special-value/recurrence conjectures.
AxiomProver autonomously produced Lean/mathlib formalizations and
machine-checkable proofs of these six conjectures, and
also discovered a counterexample to the statement as printed; the corrected form remains open.

11R09, 11P81, 05A17, 11A05


 
 1. Introduction


 
 1.1. Background


 
 The study of integer partitions is a classical subject in number theory and
combinatorics; we follow the standard notation and terminology described, for
example, in Andrews’ book [ 1 ] . A partition of a nonnegative
integer n n is a finite nonincreasing sequence

 

 
 
 λ = ( λ 1 , λ 2 , … , λ k ) \lambda=(\lambda_{1},\lambda_{2},\ldots,\lambda_{k}) 
 
 
 
 of positive integers whose sum is n n . We write λ ⊢ n \lambda\vdash n . The
empty sequence is the unique partition of 0 0 . The length of λ \lambda is
 ℓ ⁡ ( λ ) ≔ k \ell(\lambda)\coloneq k , and m λ ​ ( i ) m_{\lambda}(i) denotes the multiplicity of the part
 i i in λ \lambda . In particular, we have

 

 
 
 ∑ i ≥ 1 i ​ m λ ​ ( i ) = n and ℓ ⁡ ( λ ) = ∑ i ≥ 1 m λ ​ ( i ) . \sum_{i\geq 1}i\,m_{\lambda}(i)=n\qquad{\text{\rm and}}\qquad\ell(\lambda)=\sum_{i\geq 1}m_{\lambda}(i). 
 
 
 
 Ballantine–Beck–Feigon–Maurischat recently introduced [ 2 ] a family of interesting rational functions attached
to partitions. We now recall their construction in the notation used
throughout this paper. For a partition λ \lambda , its subsum polynomial 
is

 

 
 
 sp ⁡ ( λ , x ) ≔ ∏ j = 1 k ( 1 + x λ j ) . \spol(\lambda,x)\coloneq\prod_{j=1}^{k}(1+x^{\lambda_{j}}). 
 
 
 
 Equivalently, we have

 

 
 
 sp ⁡ ( λ , x ) = ∏ i ≥ 1 ( 1 + x i ) m λ ​ ( i ) . \spol(\lambda,x)=\prod_{i\geq 1}(1+x^{i})^{m_{\lambda}(i)}. 
 
 
 
 This polynomial is the generating function for submultisets of the multiset of
parts of λ \lambda . The reciprocal sum over ordinary partitions is

 

 
 (1) 
 
 sr ⁡ ( n , x ) ≔ ∑ λ ⊢ n 1 sp ⁡ ( λ , x ) . \sr(n,x)\coloneq\sum_{\lambda\vdash n}\frac{1}{\spol(\lambda,x)}. 
 
 
 


 
 1.1.1. The numerator and denominator of sr ⁡ ( n , x ) \sr(n,x) 


 
 A common denominator for ( 1 )
is

 

 
 
 den ∗ ⁡ ( n , x ) ≔ ∏ i ≥ 1 ( 1 + x i ) ⌊ n / i ⌋ , \den^{*}(n,x)\coloneq\prod_{i\geq 1}(1+x^{i})^{\left\lfloor n/i\right\rfloor}, 
 
 
 
 and the corresponding numerator is

 

 
 
 num ∗ ⁡ ( n , x ) ≔ ∑ λ ⊢ n h λ ​ ( x ) , \num^{*}(n,x)\coloneq\sum_{\lambda\vdash n}h_{\lambda}(x), 
 
 
 
 where

 

 
 
 h λ ​ ( x ) ≔ ∏ i ≥ 1 ( 1 + x i ) ⌊ n / i ⌋ − m λ ​ ( i ) . h_{\lambda}(x)\coloneq\prod_{i\geq 1}(1+x^{i})^{\left\lfloor n/i\right\rfloor-m_{\lambda}(i)}. 
 
 
 
 (The products are finite in effect,
since ⌊ n / i ⌋ = 0 \left\lfloor n/i\right\rfloor=0 for i > n i>n .
The exponents of h λ ​ ( x ) h_{\lambda}(x) are nonnegative
because a partition of n n can contain at most ⌊ n / i ⌋ \left\lfloor n/i\right\rfloor parts equal to i i .)
In other words,

 

 
 (2) 
 
 sr ⁡ ( n , x ) = num ∗ ⁡ ( n , x ) den ∗ ⁡ ( n , x ) . \sr(n,x)=\frac{\num^{*}(n,x)}{\den^{*}(n,x)}. 
 
 
 


 
 However the quotient ( 2 ) need not be in lowest terms.
The first cancellation considered by Ballantine–Beck–Feigon–Maurischat removes the common divisor of the
individual summands.
Define

 

 
 
 G ( n , x ) ≔ gcd { h λ ( x ) : λ ⊢ n } , G(n,x)\coloneq\gcd\{h_{\lambda}(x):\lambda\vdash n\}, 
 
 
 
 and then define

 

 
 (3) 
 
 num ⁡ ( n , x ) ≔ num ∗ ⁡ ( n , x ) G ⁡ ( n , x ) and den ⁡ ( n , x ) ≔ den ∗ ⁡ ( n , x ) G ⁡ ( n , x ) . \num(n,x)\coloneq\frac{\num^{*}(n,x)}{G(n,x)}\qquad{\text{\rm and}}\qquad\den(n,x)\coloneq\frac{\den^{*}(n,x)}{G(n,x)}. 
 
 
 
 Therefore, we have

 

 
 (4) 
 
 sr ⁡ ( n , x ) = num ⁡ ( n , x ) den ⁡ ( n , x ) . \sr(n,x)=\frac{\num(n,x)}{\den(n,x)}. 
 
 
 
 We use the empty-partition conventions
 G ⁡ ( 0 , x ) = 1 G(0,x)=1 , h ∅ ​ ( x ) = 1 h_{\emptyset}(x)=1 , num ⁡ ( 0 , x ) = 1 \num(0,x)=1 .



 
 We stress that G ⁡ ( n , x ) G(n,x) is not defined to be
 gcd ⁡ ( num ∗ ⁡ ( n , x ) , den ∗ ⁡ ( n , x ) ) \gcd(\num^{*}(n,x),\den^{*}(n,x)) .
It is the common factor of the summands h λ ​ ( x ) h_{\lambda}(x) .
Therefore, it is conceivable a priori that
 num ⁡ ( n , x ) \num(n,x) and den ⁡ ( n , x ) \den(n,x) are not relatively prime as polynomials in ℤ ⁡ [ x ] \mathbb{Z}[x] .

 1.1.3. Restricted classes of partitions


 
 We refer to the partitions of n n as ordinary partitions .
We also use the following special classes:
 𝒪 ⁡ ( n ) \mathcal{O}(n) is the set of odd partitions of n n , meaning
partitions all of whose parts are odd; ℬ ⁡ ( n ) \mathcal{B}(n) is the set of binary
partitions of n n , meaning partitions all of whose parts are powers of 2 2 ;
and 𝒯 ⁡ ( n ) \mathcal{T}(n) is the set of ternary partitions of n n , meaning partitions all
of whose parts are powers of 3 3 .



 
 The same notation will be used for the restricted classes of partitions. If
 𝒞 \mathcal{C} is one of 𝒪 , ℬ , 𝒯 \mathcal{O},\mathcal{B},\mathcal{T} , let A 𝒞 A_{\mathcal{C}} be its set of
allowed parts:

 ≔ ∏ i ∈ A 𝒞 ( 1 + x i ) ⌊ n / i ⌋ − m λ ​ ( i ) \displaystyle\coloneq\prod_{i\in A_{\mathcal{C}}}(1+x^{i})^{\left\lfloor n/i\right\rfloor-m_{\lambda}(i)}

 1.2. Ballantine–Beck–Feigon–Maurischat’s Ten Conjectures


 
 In the recent paper [ 2 ] ,
Ballantine–Beck–Feigon–Maurischat make ten explicit conjectures about these reciprocals
of partition polynomials. We list them here in the notation fixed above, so
that the statements proved later can be compared directly with the original
conjectures.



 
 1.2.1. Ordinary partitions


 
 The first two conjectures concern the ordinary numerator and
ask whether it is irreducible, and then whether ( 4 ) is already
in lowest terms.



 
 Conjecture 1 . 

 
 For n ≥ 1 n\geq 1 , the polynomial num ⁡ ( n , x ) \num(n,x) is irreducible over ℤ \mathbb{Z} . 





 
 Conjecture 2 . 

 
 For n ≥ 1 n\geq 1 , we have gcd ⁡ ( num ⁡ ( n , x ) , den ⁡ ( n , x ) ) = 1 \gcd(\num(n,x),\den(n,x))=1 . 





 
 The following two conjectures concern coefficient-shape properties of the
ordinary numerator and denominator.
Recall that a finite sequence is unimodal if it weakly increases up to some point
and then weakly decreases;
and a finite sequence ( a i ) (a_{i}) of nonnegative numbers is
 log-concave if a i 2 ≥ a i − 1 ​ a i + 1 a_{i}^{2}\geq a_{i-1}a_{i+1} for every internal index i i .



 
 Conjecture 3 . 

 
 Write num ⁡ ( n , x ) = num 0 ⁡ ( n , x ) + num 1 ⁡ ( n , x ) \num(n,x)=\num_{0}(n,x)+\num_{1}(n,x) , where num 0 \num_{0} contains the even
powers of x x and num 1 \num_{1} contains the odd powers of x x . Then
 num 0 ⁡ ( n , x ) \num_{0}(n,x) is unimodal. 





 
 Conjecture 4 . 

 
 The sequence of coefficients of den ⁡ ( n , x ) \den(n,x) is log-concave except for
 n = 3 , 5 , 6 , 7 n=3,5,6,7 . 







 
 1.2.2. Binary partitions


 
 The next three conjectures concern binary partitions.



 
 Conjecture 5 . 

 
 For the binary numerator and denominator, we have 

 

 
 
 gcd ⁡ ( num ℬ ⁡ ( n , x ) , den ℬ ⁡ ( n , x ) ) = 1 ( n ≥ 1 ) . \gcd(\num_{\mathcal{B}}(n,x),\den_{\mathcal{B}}(n,x))=1\qquad(n\geq 1). 
 
 
 




 
 Conjecture 6 . 

 
 For n > 5 n>5 , the binary numerator num ℬ ⁡ ( n , x ) \num_{\mathcal{B}}(n,x) is unimodal.

asserted that num ℬ ⁡ ( n , x ) \num_{\mathcal{B}}(n,x) is log-concave for n ≥ 2 . n\geq 2. 
This fails for n = 4 n=4 , where

 1.3. Results


 
 In this note we prove six of the ten conjectures
using elementary number theory and facts about cyclotomic polynomials.
The precise results are as follows.



 
 Theorem 1 ( Conjecture   2 ) . 

 
 For every n ≥ 1 n\geq 1 , we have

 gcd ⁡ ( num ℬ ⁡ ( n , x ) , den ℬ ⁡ ( n , x ) ) = 1 . \gcd(\num_{\mathcal{B}}(n,x),\den_{\mathcal{B}}(n,x))=1.

 For every n ≥ 1 n\geq 1 , we have

 where o ⁡ ( M ) o(M) denotes the largest odd divisor of M M .

 The results above resolve the conjectures of Ballantine–Beck–Feigon–Maurischat that concern
coprimality, divisibility, and special values. For clarity, we summarize below the status of all
ten conjectures in their paper. The remaining unresolved cases are the conjectures concerning
irreducibility and coefficient-shape phenomena; in the binary case, the log-concavity assertion is
false as stated.



 
 We note that several of the reductions used below build directly on the
structural analysis in [ 2 ] . In particular, the exponent calculation
for the common divisor, the reduction of evaluations at roots of unity to
a remainder problem, and the corresponding binary reduction were already
developed in [ 2 , Lemmas 3.1 and 3.14] and indicated in
 [ 2 , Section 4] . Our contribution in Sections 3 and 4 is to combine
these reductions with a same-ray noncancellation argument, which rules out
the remaining possible cyclotomic factors and proves the corresponding
coprimality and divisibility conjectures.

 The paper is organized as follows.
In Section   2 we record the
elementary cyclotomic facts that will be used throughout the proofs. In Section   3 , we prove Conjecture   2 
for ordinary partitions by showing that the reduced numerator
does not vanish at any root of unity that can occur as a zero of the reduced denominator.
The key step is a reduction to a smaller remainder problem in which all surviving summands
lie on a single open ray in the complex plane.
In Section   4 , we adapt the same idea to

hence the equivalent coprimality statement of Conjecture   5 .
In Section   5 ,

where only the all-ones partition survives after cancellation.
In Section   6 , we treat ternary
partitions: the specialization at x = − 1 x=-1 gives Conjecture   9 , while the
specialization at x = 1 x=1 leads to a simple generating-function identity and
proves the natural finite-difference form of Conjecture   10 .

 7. Appendix: Autonomous proof production and formalization


 
 At Axiom Math, we are developing AxiomProver,
an AI system for mathematical research based on autoformalization.
As a test case, we gave AxiomProver
ten tasks: to autonomously formalize and prove Conjectures  1 - 10 ,
offering examples of AI assistance as well as limitations in mathematical research.
This appendix is separate from the rest of the manuscript.



 
 7.1. Division of labor


 
 The prose exposition of this paper, including this appendix, was written without the use of AI.
AxiomProver runs Lean,
an interactive theorem prover and a functional programming language built on dependent type theory,
designed to provide a rigorous computational framework for validating mathematical proofs [ 4 ] .
This appendix is included not only to record that formal proofs were produced,
but also to clarify the division of labor between the human-written
mathematics and the AI-generated formalizations. The
mathematical statements supplied to AxiomProver were written in natural
language and can be found in [ 2 ] .



 
 The role of AxiomProver was to convert the non-formal statements
into Lean and to construct machine-checkable formal proofs. Thus, in the tasks
described below, AxiomProver was neither being asked to make any of the conjectures,
nor to decide the final organization of the paper; it was being asked to
produce complete formal proofs of the supplied statements.



 
 Autoformalization involves automatically and autonomously converting
natural-language mathematics into machine-verifiable formal language.
Lean files are created to pass type checkers,
while the natural language papers aim to communicate ideas to readers.





 
 7.2. Task specification and results


 
 Given problems in natural or formal language,
AxiomProver attempts to generate a complete formal proof.
When it succeeds, the system outputs two files:

 
 • 
 
 problem.lean , which formalizes the problem statement;




 • 
 
 solution.lean , which represents a complete proof in a formal language.




 
 The ten tasks share a uniform layout — for i ∈ { 1 , … , 10 } i\in\{1,\dots,10\} ,
we gave the following files as input for the i i -th task:

 
 • 
 
 Conj_ i i _Statement.tex 




 • 
 
 task.md contains a single line

 
 Please read ‘ Conj_ i i _Statement.tex ’ and formalize
Conjecture  \ref{conj:conj_ i i } .

 



 • 
 
 .environment specifies the Lean version used is 4.28.0.




 


 
 Out of the 10 10 tasks, AxiomProver was able to autonomously formalize and prove
Conjecture j j for j ∈ { 2 , 5 , 7 , 8 , 9 , 10 } j\in\{2,5,7,8,9,10\} .
It also found the counterexample n = 4 n=4 to the part of [ 2 , Conjecture 6] 
asserting that num ℬ ⁡ ( n , x ) \num_{\mathcal{B}}(n,x) has log-concave coefficients
(see the remark at the end of Section   1.2.2 ).
Here “autonomously” means that, after receiving the
specified input files, AxiomProver generated the corresponding
 problem.lean and solution.lean files without further
mathematical intervention in the proof script. The authors did not hand-write
or repair the Lean proofs line by line. The resulting formal proofs were then
used as machine-checkable certificates for the proved conjectures.





 
 7.3. Artifacts


 
 The relevant files are posted in the following repository:

 https://github.com/AxiomMath/PartitionPolynomial 

 The version of Lean used is 4.28.0.
Compatibility with other versions is not guaranteed due to the evolving
nature of the Lean 4 compiler and its core libraries.



 
 At first glance, the proofs generated by AxiomProver do not resemble the narrative outlined in this paper.
Converting a Lean file into a proof understandable by humans is challenging
because Lean is designed as code for a type-checker, not as a reader-friendly explanation.
It makes all the “obvious” bookkeeping explicit, such as rewrite steps, coercions, side conditions,
and case splits, and tends to follow the most convenient lemmas and tactics for the library,
rather than the most clear conceptual route.
A mathematician can usually condense this significantly by relying on shared historical context,
standard arguments, and informal identifications that Lean cannot assume.
As a result, writing a paper from Lean files is not just about reformatting.
The authors must understand the formal script, reconstruct the underlying ideas,
and then translate the code into a narrative that emphasizes the key insights
while safely omitting routine details.
