 Abstract.

 
 In this paper, we establish that the maximum edit distance of an n n -vertex graph from the hereditary property of word-representable graphs is n 2 / 8 − o ⁡ ( n 2 ) n^{2}/8-o(n^{2}) . In addition, we establish that the maximum edit distance of an n n -vertex graph from the hereditary property of poset comparability graphs is 5 ​ n 2 / 32 − o ⁡ ( n 2 ) 5n^{2}/32-o(n^{2}) .

 
 In fact, we determine the edit distance function over all edge densities p ∈ [ 0 , 1 ] p\in[0,1] for the property of word-representable graphs, for the property of k k -word-representable graphs for each k ≥ 2 k\geq 2 , and for the property comparability graphs. The latter has a peculiar structure that requires an infinite sequence of colored regularity graphs.

 


 
 Key words and phrases: 
word-representable graphs; comparability graphs; edit distance

 1. Introduction


 
 1.1. Word representation of graphs


 
 Word representations of graphs enable one to encode a graph as a string and were introduced by Pyatkin and the first author  [ 14 ] . A word-representation of a graph G = ( V , E ) G=(V,E) is a word over the alphabet V V such that vertices v 1 v_{1} and v 2 v_{2} are adjacent in G G if and only if they alternate in the word. A graph G G is said to be k k -word-representable if there exists a word representing G G that contains exactly k k copies of each letter, that is, a k k -uniform word. It was shown in  [ 14 ] that a graph is word-representable if and only if it is k k -word-representable for some positive integer k k . This allows one to define the representation number of a word-representable graph G G , denoted by ℛ ⁡ ( G ) {\mathcal{R}}(G) , as the smallest positive integer k k such that G G is k k -word-representable. By definition, ℛ ⁡ ( G ) = ∞ {\mathcal{R}}(G)=\infty for any non-word-representable graph.





 
 1.2. Comparability graphs


 
 The comparability digraph of a finite poset P P , denoted D P D_{P} is a directed graph where the vertex set is the elements of P P and x → D P y x\rightarrow_{D_{P}}y is a directed edge if and only if x < P y x<_{P}y .
The comparability graph of a finite poset P P is simply the underlying graph of its comparability digraph.



 
 There is a strong connection between comparability graphs and word-representable graphs, as indicated in  [ 14 ] . Namely, if a graph is word-representable, then the neighbourhood of any vertex in it must be a comparability graph. The converse of this statement is not true [ 16 ] . It is known  [ 15 ] that every comparability graph can be represented by a concatenation of permutations.





 
 1.3. Hereditary properties of graphs


 
 A property of graphs is hereditary if it is closed under isomorphism and deleting vertices.
That is, if H H is in a hereditary property ℋ {\mathcal{H}} , then every induced subgraph of H H is also in ℋ {\mathcal{H}} .



 
 For a graph F F , let Forb ⁡ ( F ) {\rm Forb}(F) denote the hereditary property of graphs with no induced copy of F F .
For a set of graphs ℱ {\mathcal{F}} , let Forb ⁡ ( ℱ ) {\rm Forb}({\mathcal{F}}) denote the hereditary property of graphs with no induced copy of F F for any F ∈ ℱ F\in{\mathcal{F}} .
That is, Forb ⁡ ( ℱ ) = ⋂ F ∈ ℱ Forb ⁡ ( F ) {\rm Forb}({\mathcal{F}})=\bigcap_{F\in{\mathcal{F}}}{\rm Forb}(F) .
In fact, for every hereditary property ℋ {\mathcal{H}} , there exists a (possibly infinite) set ℱ ⁡ ( ℋ ) {\mathcal{F}}({\mathcal{H}}) such that ℋ = ⋂ F ∈ ℱ ⁡ ( ℋ ) Forb ⁡ ( F ) {\mathcal{H}}=\bigcap_{F\in{\mathcal{F}}({\mathcal{H}})}{\rm Forb}(F) .



 
 A hereditary property is trivial if it is finite, otherwise it is nontrivial .
By Ramsey theory, a hereditary property ℋ {\mathcal{H}} is trivial if and only if there are positive integers a a and b b such that ℋ ⊆ Forb ⁡ ( K a ) ∩ Forb ⁡ ( K b ¯ ) {\mathcal{H}}\subseteq{\rm Forb}\bigl(K_{a}\bigr)\cap{\rm Forb}\bigl(\overline{K_{b}}\bigr) .

 2. Techniques for computing the edit distance function


 
 The key objects in computing the edit distance function were called colored regularity graphs (CRGs) by Alon and Stav  [ 2 ] .



 
 Definition 7 . 

 
 A colored regularity graph (CRG) K K is a simple complete graph together with a partition of its vertices into white and black vertices and a partition of its edges into white, black, and gray edges.
We will use K = ( VW , VB , EW , EB , EG ) K=\bigl({\rm VW},{\rm VB};{\rm EW},{\rm EB},{\rm EG}\bigr) to denote that K K is a CRG with white vertex set VW {\rm VW} , black vertex set VB {\rm VB} , white edge set EW {\rm EW} , black edge set EB {\rm EB} and gray edge set EG {\rm EG} . 



 
 As far as notation, the dependence on K K is usually suppressed if the CRG is understood. 





 
 Colored regularity graphs come from the analysis of graphs using Szemerédi’s regularity lemma.
In particular, one can apply the regularity lemma a second time, inside each of the clusters given by the first iteration and then Ramsey’s theorem.
A convenient form of the regularity lemma for these purposes is given by Alon, Fischer, Krivelevich, and Szegedy  [ 1 ] .



 
 CRGs are used to represent a graph after the editing is finished.
As such, we need to demonstrate how forbidden graphs are not in the edited graph.
This yields the idea of a colored homomorphism.
If G G is a graph, then G ¯ \overline{G} denotes the graph complement.
The notation ⊔ \sqcup denotes the disjoint union of sets.

 A colored homomorphism from a graph G G to a CRG K = ( VW , VB 𝐶𝐿𝑂𝑆𝐸 ; K=({\rm VW},{\rm VB}; 𝑂𝑃𝐸𝑁 EW , EB , EG ) {\rm EW},{\rm EB},{\rm EG}) is a map φ : V ⁡ ( G ) → V ⁡ ( K ) \varphi:V(G)\rightarrow V(K) such that 

 
 •

 • 
 
 If u ​ v ∈ E ⁡ ( G ) uv\in E(G) , then either φ ⁡ ( u ) = φ ⁡ ( v ) ∈ VB \varphi(u)=\varphi(v)\in{\rm VB} or φ ⁡ ( u ) ≠ φ ⁡ ( v ) \varphi(u)\neq\varphi(v) and φ ⁡ ( u ) ​ φ ​ ( v ) ∈ EB ⊔ EG \varphi(u)\varphi(v)\in{\rm EB}\sqcup{\rm EG} . 




 
 If there is a colored homomorphism from G G to K K , then we write G ↦ K G\mapsto K .
If there is no colored homomorphism from G G to K K , then we write G ↦̸ K G\not\mapsto K .

 6.6. Edit distance for oriented graphs


 
 An orientation of a graph is semi-transitive if it is acyclic (i.e., contains no directed cycles), and for any directed path v 0 → v 1 → ⋯ → v k v_{0}\rightarrow v_{1}\rightarrow\cdots\rightarrow v_{k} , either there is no edge between v 0 v_{0} and v k v_{k} , or v i → v j v_{i}\rightarrow v_{j} is an edge for all 0 ≤ i < j ≤ k 0\leq i<j\leq k . A fundamental result in the theory of word-representable graphs by Halldórsson, Pyatkin, and the first author  [ 11 ] states that a graph is word-representable if and only if it admits a semi-transitive orientation.



 
 In the case of ℋ word {\mathcal{H}}_{\rm word} , one may ask about the maximum edit distance of an oriented graph from one admitting a semi-transitive orientation or, in the case of ℋ comp {\mathcal{H}}_{\rm comp} , the maximum edit distance of an oriented graph from one admitting a transitive orientation. This was addressed to some extent by Axenovich and the second author  [ 4 ] , although there is little other literature on the edit distance of oriented graphs, and the interested reader may wish to consider alternative measures of edit distance.
