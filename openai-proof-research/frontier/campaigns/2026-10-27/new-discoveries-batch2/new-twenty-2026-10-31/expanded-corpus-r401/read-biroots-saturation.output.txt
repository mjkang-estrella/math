40:                                              The notion of rank plays an important role in combinatorics on words. Given a subset X of the free
41:                                          monoid A∗ over a finite alphabet A, the rank of X, in symbols r(X), is defined as the smallest number
42:                                          of words needed to express all words of X, i.e., as the minimal cardinality of a set F such that X ⊆ F ∗ .
43:                                          Notice that this minimal set F may not be unique. For instance, the set X = {aabca, aa, bcaaa} has rank
44:                                          2 and there exist two distinct sets F1 = {aa, bca} and F2 = {a, bc} such that X ⊆ F1∗ and X ⊆ F2∗ . It is
45:                                          worth noticing that r(X) ≤ min{|X|, |A|}, hence r(X) is always finite even if X is an infinite set. A set
46:                                          X is said to be elementary if r(X) = |X|. The notion of rank – and the related notion of elementary set –
65: given a word w ∈ A∗ , the set {w} is primitive if and only if the word w is primitive. For instance, the set
66: {abab, abababab} is not elementary; the set {abab} is elementary but not primitive; the set {ab} is primitive.
67:     We have from that definition that for every set X, there exists a primitive set Y such that X ⊆ Y ∗ .
68: The set Y is therefore called a primitive root of X. However, the primitive root of a set is not, in general,
69: unique. Consider for instance the set X = {abcbab, abcdcbab, abcdcdcbab}. It has rank 3, hence it is
70: elementary, yet it is not primitive. Indeed, X ⊆ {ab, cb, cd}∗ . The set {ab, cb, cd} is primitive, and it is
71: a primitive root of X. However, it is not the only primitive root of X: the set {abc, dc, bab} is primitive
72: and X ⊆ {abc, dc, bab}∗ , hence {abc, dc, bab} is another primitive root of X. In the special case of sets
73: of rank 1, clearly these always have a unique primitive root. For instance, the primitive root of the set
74: {abab, abababab} is the set {ab}.
75:     As a main result, we prove that if a set has rank 2, then it has a unique primitive root. This is equivalent
76: to say that for every pair of nonempty words {x, y} such that xy 6= yx there exists a unique primitive set
77: {u, v} such that x and y can be written as concatenations of copies of u and v. The proof is based on the
78: algebraic properties of k-maximal submonoids of a free monoid.

362: 4. Primitive Sets
363:     We now show how the previous results can be interpreted in the terminology of combinatorics on words.
364: Let us start with the remark that a word x ∈ A+ is primitive if and only if, for every u ∈ A+ ,
365:                                              x∗ ⊆ u∗ ⇒ x = u.
366: With our definition of maximality, we have that a word x ∈ A+ is primitive if and only if the monoid x∗ is
367: 1-maximal. Inspired by this observation, we give the following definition.
368: Definition 2. A finite set X ⊆ A∗ is primitive if it is the basis of a |X|-maximal submonoid.
369:     The following proposition is an easy consequence of the definition of primitive set.
370: Proposition 8. Any subset of a primitive set is primitive.
371: 
372: Proof. Let X ⊆ A∗ be a primitive set and let Y be a subset of X. If Y is not primitive then there exists a
373: set Z 6= Y such that |Z| ≤ |Y | and Y ⊆ Z ∗ . It follows that the set F = X \ Y ∪ Z is such that |F | ≤ |X|
374: and X ⊆ F ∗ contradicting the primitiveness of X.
375: 
376:     In particular, any element of a primitive set is a primitive word.
377: Remark 3. The definition of primitive set does not coincide with that of elementary set. A set X is said
378: to be elementary if r(X) = |X|. If X is primitive, then r(X) = |X|, i.e., it is elementary. But there exist
379: elementary sets that are not primitive. For instance, the set {aa, bca} is elementary, but it is not primitive
380: since {aa, bca}∗ ⊆ {a, bc}∗ .
381:     From the definition of primitive set, we have that for every set X there exists a primitive set Y such
382: that X ⊆ Y ∗ . The set Y is therefore called a primitive root of X. However, the primitive root of a set is
383: not, in general, unique. Consider for instance the set X = {abcbab, abcdcbab, abcdcdcbab}. It has rank 3,
384: hence it is elementary, yet it is not primitive. Indeed, X ⊆ {ab, cb, cd}∗ . The set {ab, cb, cd} is primitive,
385: and it is a primitive root of X. However, it is not the only primitive root of X: the set {abc, dc, bab} is
386: primitive and X ⊆ {abc, dc, bab}∗ , hence {abc, dc, bab} is another primitive root of X. In the special case
387: of sets of rank 1, clearly these always have a unique primitive root. For instance, the primitive root of the
388: set {abab, abababab} is the set {ab}.
389:     However, as a consequence of Theorem 6 we have the following result.

393: Proof. If {u1 , u2 } and {v1 , v2 } are two primitive roots of X then X ∗ ⊆ {u1 , u2 }∗ ∩ {v1 , v2 }∗ . Hence, by
394: Theorem 6, X ⊆ {z}∗ , for some primitive word z, i.e., r(X) = 1, a contradiction.

513: 5. Bi-root of a Single Primitive Word
514:      In this section, we derive some consequences on the combinatorics of a single word. In particular, we
515: introduce the notion of bi-root of a primitive word, and we show how this notion may be useful to reveal
516: some hidden repetitive structure in the word.
517:      Let w be a nonempty word. If w is not primitive, then it can be written in a unique way as a concatenation
518: of copies of a primitive word r, called the root of w. However, if w is primitive, one can ask whether it can
519: be written as a concatenation of copies of two words x and y. If we further require that {x, y} is a primitive
520: set, then we call {x, y} a bi-root of the word w. Note that the bi-root of a single word is not, in general,
521: unique. For instance, for w = abcbac we have w = ab · cbac = abcb · ac and {ab, cbac} and {abcb, ac}
522: are both primitive pairs, i.e., they are both bi-roots of w. However, if we additionally require that the size
523: |x| + |y| of the bi-root {x, y} is “short” with respect to the length of w, then we obtain again the uniqueness.
524: This is shown in the next theorem.

550: repetitive at all, and it has |w| − 1 different bi-roots {x, y}, all of size |w|, corresponding to the trivial
551: factorizations w = xy. Thus, the absence of repetitions in a word is related to the large size of its bi-roots.

554: considered notions of hidden repetitions (cf. [20, 21, 22]), as we further discuss in the next section.
555:     We think that the notion of bi-root can be further explored and may have applications, e.g., in the area
556: of string algorithms.

558: example, if w is a square-free word, then w cannot have a bi-root {x, y} such that |x| + |y| < |w|/4, since
559: otherwise w would contain a square (xx, yy, xyxy or yxyx). The previous remark suggests a possible link
560: between the notion of a bi-root and the classical notion of binary pattern, which has been deeply investigated
561: in combinatorics on words and fully classified by J. Cassaigne [23] (see also [11, Chap. 3] for a survey).
