340109 terminal filtration: source pp2–3 maximizes the sorted positive multiplicity list successively and terminates when all entries are exhausted (the source's next undefined-entry/empty-set convention must be represented explicitly, rather than inventing a maximum of empty data). Equivalently terminal survivors are exactly bijections whose sorted multiplicity partition is lexicographically maximal, with zeros appended for comparison. There is no strict-prefix ambiguity between distinct positive partitions of the same total: a proper prefix has smaller sum. All matchings are all bijections by disjointness.

Full ordinary lemma: in any complete bipartite finite set of bijections, with a color on each edge such that every color class is a partial matching (group addition has this property by cancellation in BOTH coordinates), every lexicographically maximal sorted-multiplicity bijection is uniquely determined by its labelled multiplicities. Proof by induction on number of vertices. Fix such f and a color c whose count M is maximal in f. Let k be the number of all c-edges. These edges are pairwise disjoint and extend to a full bijection, so if k>M the extension has maximum count at least k and beats f lexicographically. Therefore k=M, and f uses ALL c-edges. If g has the same labelled multiplicities, g must use exactly those same c-edges. Delete their endpoints. Restriction of f is lexicographically maximal for the residual complete bipartite problem: any improved residual sorted sequence, merged with the fixed block of M copies of color c, improves the full sequence. More formally, lex ordering of equal-total sorted partitions is preserved upon adding the same singleton count M; this follows by cancelling equal leading sorted entries until the first unequal count, or by comparing counts of entries≥each threshold from largest downward. Removed c has no residual edges, so its count does not merge with another occurrence of c. Apply induction to restrictions of f,g, which have the same labelled residual multiplicities. They agree on residual and removed endpoints, so g=f. Base size0 is unique empty bijection. This proves every terminal survivor acyclic, the full quantifier of340109.
