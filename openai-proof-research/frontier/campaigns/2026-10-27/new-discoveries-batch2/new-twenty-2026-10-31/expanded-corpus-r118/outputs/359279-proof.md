# MathDB 359279: the linear-bound multiset reconstruction conjecture for tableau minors is false

Status: candidate for root review. Zero credit until root accepts. Lane: expanded-corpus-r118, 2026-11-02.

## 1. Exact source statement

Source: W. Q. Erickson, D. Herden, J. Meddaugh, M. R. Sepanski, C. Hammon, *Young tableau reconstruction via minors*, arXiv:2307.13161 v1 (e-print sha256 ecf89e9c70f9416e4c2639b9f0cdf29b9edd89f18521e0159abcca6cd8a4b1dd, fetched 2026-11-02). In the Concluding Remarks the source states:

> We have been able to verify the following conjecture by computer for k ≤ 5:
> **Conjecture (conj:k+4).** Let k ≥ 1. Let T ∈ YT(n), where n ≥ k + 4. Then mM_k(T) determines T.

The MathDB record 359279 (corpus chunk line preserved in raw/359279.jsonl) restates it literally.

Definitions (source Section 2):

* YT(n) is the set of standard Young tableaux of size n, with entries 1, …, n increasing along rows and down columns.
* T − m: delete the cell with entry m. While the empty space has a cell directly to the right or directly below, slide the cell with the smaller entry into the empty space. The process ends at an outer corner. Then subtract 1 from every entry larger than m.
* A k-minor is a tableau obtained by iteratively deleting k cells. M_k(T) is the set and mM_k(T) the multiset of all k-minors. The multiset counts all deletion sequences: the proof of the source's Theorem `thm: exp lower bound` says "there are n(n−1)⋯(n−k+1) minors in total".

"mM_k(T) determines T" means that T ↦ mM_k(T) is injective on YT(n).

## 2. Counterexample (k = 8, n = 12 = k + 4)

T₁ (shape (5,1⁷)) has first row 1 5 7 8 12 and first column 1 2 3 4 6 9 10 11.
T₂ (shape (6,1⁶)) has first row 1 2 3 7 10 11 and first column 1 4 5 6 8 9 12.

Both are standard Young tableaux of size 12, and they are distinct, with different shapes. Each multiset mM₈(Tᵢ) contains 12!/4! = 19,958,400 minors. The two multisets coincide, with the following counts over the ten size-4 standard tableaux (the two non-hooks have count 0):

| size-4 minor (rows) | count |
|---|---|
| 1 / 2 / 3 / 4 | 3,064,320 |
| 1 2 / 3 / 4 | 2,540,160 |
| 1 3 / 2 / 4 | 3,628,800 |
| 1 4 / 2 / 3 | 3,709,440 |
| 1 2 3 / 4 | 1,693,440 |
| 1 2 4 / 3 | 2,540,160 |
| 1 3 4 / 2 | 2,056,320 |
| 1 2 3 4 | 725,760 |

So mM₈ does not determine T on YT(12), and Conjecture conj:k+4 fails at k = 8.

At n = 12, k = 8 there is a second pair, rows {1,5,6,8,12} and {1,2,3,6,10,11}, and the transposes of both pairs; these are the only collisions (4 colliding rows out of 140,152 tableaux).

## 3. Verification

1. **Exhaustive C sweep** (`scripts/minors.c`). Over all of YT(n), the multiset row of every T is propagated exactly with h_s(T) = Σ_m h_{s−1}(T − m) under two independent random 64-bit linear hashes. Results:
   * n = k + 4 is injective for k = 1, …, 7.
   * n = k + 4 is not injective for k = 8 (n = 12; 4 collisions), k = 9 (16), k = 10 (60) and k = 11 (190).
   * n = k + 5 is injective for k = 8, 9, 10.
   * Logs: `logs/minM-n*.log`.
2. **Dense Python cross-check** (`scripts/minors.py`, n ≤ 10). It agrees exactly with the C sweep. It also reproduces the source's own facts: M₁ determines T for n ≥ 5 (Cain–Lehtonen); M₂ determines T exactly for n ≥ 8 (source Thm `k = 2 sharp`); mM₂ is injective at n = 6, 7 and not at n = 5 (source remark).
3. **Independent exact check** (`scripts/verify_minors.py`). This is memoised exact multiset arithmetic in Python with its own jeu-de-taquin routine. It confirms equality for both pairs and their transposes (`logs/verify-n12k8.log`).

## 4. Why hooks fail, and a strengthening (ordinary proof, not formalised)

For a hook tableau H(w), encode it by the word w ∈ {A, L}^N with N = n − 1, where letter t records whether entry t+1 lies in the arm or the leg.

**Lemma 1 (deletion on hooks).** Deleting entry 1 or entry 2 both remove the first letter of w; deleting entry m ≥ 3 removes letter m − 1.

*Proof.* When 1 is deleted, the smaller neighbour of the corner is 2, which slides into the corner. The gap then runs to the end of 2's line (arm or leg) and the cell is removed. Relabelling gives the same hook as deleting 2 directly. Any other entry slides along its own line only.

**Lemma 2 (weight formula).** For 1 ≤ k ≤ N − 1,
mM_k(H(w)) = k! · Σ_{P ⊆ [N], |P| = N − k} min(P) · {H(w|_P)}.

*Proof.* A deletion sequence deletes the letters of Q = [N] \ P in some order. It has multiplicity 2 at each step where the deleted letter is the current first letter, and 1 otherwise. A letter q > min P is never first. A letter q < min P is first exactly when all smaller letters are already gone, i.e. when it is a right-to-left minimum in the deletion order of {1, …, j}, where j = min P − 1. Since Σ_{σ ∈ S_j} 2^{rlmin(σ)} = 2·3⋯(j+1) = (j+1)!, the total weight is C(k,j)·(k−j)!·(j+1)! = k!·min P. (Checked against the exact dynamic programme on 420 random cases: `scripts/hookcheck.py`.)

**Theorem 3.** For every constant c ≥ 2 and all sufficiently large N, with n = N + 1 and k = n − c, the map mM_k is not injective on YT(n). Hence no bound of the form n ≥ k + c makes mM_k(T) determine T, and the true threshold f(k) satisfies f(k) − k → ∞.

*Proof.* Put r = c − 1. By Lemma 2, mM_k(H(w)) = k! Σ_τ V_τ(w)·{H(τ)}, where τ ranges over {A, L}^r and V_τ(w) = Σ_{P : w|_P = τ} min P ≤ N·C(N, r). There are at most (N·C(N,r) + 1)^{2^r} possible vectors V, which is less than 2^N for large N. By pigeonhole two distinct words w ≠ w′ have the same V, so the distinct hooks H(w) ≠ H(w′) have the same mM_k.

The explicit first hook failures are c = 4 at n = 12 (the counterexample above) and c = 5 at n = 16, k = 11. For c = 5 one pair is first row {1,2,3,4,5,9,10,11,12,13,16} with legs 6, 7, 8, 14, 15, versus first row {1,4,5,6,7,8,12,13,14,15} with legs 2, 3, 9, 10, 11, 16; it was checked exactly (`logs/verify-c5.log`). For c = 6 there is no hook collision up to n = 26 (all 2^25 words, `logs/hook-r5.log`). Non-hook collisions first appear at n = 13.

## 5. Prior-art and qualification checks

* **Source's own results.** The source proves k = 2 (sets, sharp n ≥ 8) and a cubic sufficient bound for multisets. Nothing in it implies failure at n = k + 4, and the conjecture does not contradict any source data, since the authors verified only k ≤ 5. Our computation confirms k ≤ 7.
* **Cited works.** Monks 2009 (shape reconstruction, n ≥ k² + 2k) and Cain–Lehtonen 2022 (k = 1) contain no k ≥ 8 multiset collision. This was a bounded check from the source citations; those bodies were not read beyond what the source quotes.
* **Generic failure of an underlying rule.** The hook reduction yields a start-position-weighted subword deck (Lemma 2), not the classical k-deck. The counterexample is a direct computation, and Theorem 3 is our own pigeonhole argument.
* **Later literature.** Web searches on 2026-11-02 for follow-ups (tableau reconstruction minors, multiset, k+4) found no resolution. The 2025 Herden slides and DIMACS abstract, and the 2024 Sepanski abstracts, report only the k = 2 result and the cubic bound. No arXiv listing search was done (search API 429 since r90).

* **Classical-example check.** Hooks are not an extremal example sitting on an order or density convention. The failing case lies strictly inside the conjecture's domain (n = k + 4 is included), and failure persists at n = k + 5 (k = 11).
