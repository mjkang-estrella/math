I didn't find a source proving a matching Θ(√n) bound for τ(K_{2,n}). The results give a √n lower bound and a linear upper bound, so the exact order is not settled in what I found.

- **Lower bound (√n):** In "On the List Color Function Threshold," the authors show that there exists a positive constant C such that τ(K_{2,l}) − χ_ℓ(K_{2,l}) ≥ C√l for l ≥ 16.
- **Best upper bound found (linear):** In "Bounding the List Color Function Threshold from Above," the authors show that for any n ≥ 2, τ(K_{2,n}) ≤ ⌈(n+2.05)/1.24⌉, which gives an improvement on the general upper bound for τ(G) when G = K_{2,n}. The general bound for any graph is τ(G) ≤ (|E(G)|−1)/ln(1+√2) + 1.
- **Open questions:** The same paper proposes Conjecture 8: If P_ℓ(K_{2,n+1}, m) = P(K_{2,n+1}, m), then P_ℓ(K_{2,n}, m) = P(K_{2,n}, m). It also notes that it is unknown whether P_ℓ(K_{2,11},3) = P(K_{2,11},3).

So the √n lower bound and the linear upper bound leave a gap. If a Θ(√n) result exists, it wasn't in these results, and I'd check the more recent literature on the list color function threshold before relying on it.
