All commands use actual script paths and Python -I -B. Work from this lane or use its absolute path; scripts resolve their own lane.

1. `python -I -B /absolute/path/to/expanded-corpus-r252/cap.py intake-check python -I -B /absolute/path/to/expanded-corpus-r252/intake.py` re-extracts the fixed reservation from the pinned local corpus. It overwrites records.json, so run prepare.py afterward to restore statement hashes. Existing original intake artifacts are retained in this delivery.
2. prepare.py supplies source/registry fetch-plan.json and adds literal statement hashes. fetch.py consumes plan files, skips existing receipts, preserves failures and blocks inherited denied hosts. Do not remove failure receipts to retry denied routes. Network content is time dependent; current receipts are the reproducible evidence, not a promise of identical future HTTP responses.
3. versions.py inventories arXiv versions from saved abstract pages. texts.py invokes pdftotext only for files actually starting with the PDF magic header. A .pdf filename alone is not source-body evidence.
4. registry.py, subtrees.py, follow.py, registry-more.py and screen-final.py document discovery of complete relevant registry subtrees and raw indexes. Their fresh HTTP receipts pin commits; root-tree truncation is recorded. Follow-up matched files are in http/matched-*. No Lean tool is invoked.
5. report.py writes the exact 20 dispositions and validates raw/statement hashes. final-check.py verifies original chunk/line bindings, source-receipt hashes, final key set, process receipts and creates HASHES.json. HASHES.json excludes itself. Run it through cap.py with a new log name to avoid overwriting exclusive logs.

RESEARCH-NOTES.md contains ordinary proofs and precise Pi certificate plans. There is no executable Lean proof, SAT/matching search, certificate witness, paper or acceptance packet in this lane. For the proposed future tasks, the root must route execution/formalization to Pi; these scripts perform only extraction, HTTP, text conversion and provenance checks.
