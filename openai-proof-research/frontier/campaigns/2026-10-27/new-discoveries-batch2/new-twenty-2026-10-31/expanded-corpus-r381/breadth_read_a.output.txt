25:                                            1.1. Background. Let Sn denote the set of permutations of the set [n] := {1, . . . , n}, which we
26:                                            write as words in one-line notation. The investigation of pattern avoidance in permutations began
27:                                            in 1968, when Knuth [28] introduced a stack-sorting machine and showed that a permutation can
28:                                            be sorted to the identity permutation using this machine if and only if it avoids the pattern 231 (we
29:                                            define pattern containment and avoidance formally below). In his 1990 Ph.D. dissertation, West [37]
30:                                            introduced a deterministic variant of Knuth’s machine; this variant is a function s : Sn → Sn . As
31:                                            in Knuth’s case, a permutation π ∈ Sn satisfies s(π) = 123 · · · n if and only if it avoids 231. More
32:                                            recently, Albert, Homberger, Pantone, Shar, and Vatter [2] introduced a vast generalization of
33:                                            Knuth’s stack-sorting machine by considering C-machines. Roughly speaking, a C-machine is a
34:                                            sorting machine that uses a stack whose entries, when read from top to bottom, must have the
35:                                            same relative order as an element of the permutation class C. Even more recently, Cerbai, Claesson,
36:                                            and Ferrari [11] generalized West’s stack-sorting map in a similar manner. For each permutation
37:                                            pattern σ, they defined a map sσ : Sn → Sn that sends each permutation through a stack in a

208: 1.3. Terminology and Notation. Recall that in this article, a permutation is an ordering of the
209: elements of the set [n] for some n. If π is a sequence of n distinct integers, then the standardization
210: of π is the permutation in Sn obtained by replacing the ith-smallest entry in π with i for all i.
211: For example, the standardization of 4829 is 2314. We say two sequences have the same relative
212: order if their standardizations are equal. We say a permutation σ contains a permutation τ as a
213: pattern if there is a (not necessarily consecutive) subsequence of σ that has the same relative order
214: as τ ; otherwise, σ avoids τ . We say σ contains τ consecutively if σ has a consecutive subsequence
215: with the same relative order as τ ; otherwise, σ avoids the consecutive pattern τ . When we wish to
216: stress that pattern containment (or avoidance) is nonconsecutive, we will sometimes call it classical
217: pattern containment (or avoidance). We refer to the standard references [6, 20, 27, 30] for more
218: information about classical and consecutive permutation patterns.
