## B. Ordinary mathematics — PASS

Here is my independent check of the delicate wrap step. Each representative is between 0 and h. The integer second difference lies in [-2h, 2h]; 2h = p + 3 < 2p. Hence its possible multiples of p are -p, 0 and p.

If a - 2b + c = p, then a + c = p + 2b <= p + 3, so b is 0 or 1. For b = 1 the sum is 4k + 3: two interval digits sum to at most 4k, one h plus an interval digit to at most 4k + 2, and two h's to 4k + 4. None works. For b = 0, the interval alone cannot reach p, and two h's do not work, so {a,c} = {h,h-3}. If (a,c) = (h,h-3), then d = p-3 modulo p, whose representative is above h for k >= 3. The other ordering gives exactly (h-3,0,h,3).

If a - 2b + c = -p, then 2b = p+a+c forces b = h, since all other allowed digits are at most 2k. Consequently a+c=3. For c=0,1,2,3 the respective representatives of d=2c-h modulo p are h-3, h-1, h+1, h+3. Only the first is allowed: h-1 is the missing digit and the last two exceed h. This gives (3,h,0,h-3).

Apply that analysis to the reversed quadruple if only b - 2c + d is assumed to wrap. It would have to be one of the same two exceptional quadruples. Both have nonzero first second difference in the original orientation as well. Thus there is no missed case with first second difference zero and second nonzero. Neither primality nor cancellation modulo a composite was used.

For an ordinary integer progression (a,a+s,a+2s,a+3s), the square contribution to E(a)+E(d)-E(b)-E(c) is 16s^2. The parities of a,c agree and those of b,d agree, so the parity contribution is zero even for negative s. In each exceptional quadruple the outer digits h-3,3 are odd and the inner digits 0,h are even. The unscaled square difference is (h-3)^2+9-h^2 = 18-6h = 9-3p; the parity difference is -4. The full gap is 4(9-3p)+4(3p-5)=16. Every nonconstant local progression therefore has a strictly positive integer gap.

For each vector v in SourceSet, the potential sum is (n/h) times the sum of E over D. All four vector sums agree. Their linear combination with coefficients +1,-1,-1,+1 is zero. This is the sum of nonnegative coordinate gaps. Finiteness forces each gap to be zero, and the local strictness forces each coordinate constant. No averaging approximation or cancellation of positive and negative gaps is hidden here. The same argument in fact works whenever all four histograms agree, even if their common digit multiplicities are unequal.
