# Independent proof for 338806
Recorded before opening FULLCANDIDATE.md or the supplied dormant author plan. The task disclosed the mechanism; independence here means personal verification, not independent invention. No mathematical computation or enumeration was used.

For every positive integer g we construct a finite simple bipartite graph H of maximum degree at most 100 and girth at least g with nu_ur(H) < (3/4)nu(H). Thus epsilon=1/4 and Delta=100 negate the literal, including its intended arbitrarily large girth regime.

First let M={x_i y_i:1<=i<=m} be any uniquely restricted matching in a bipartite graph with fixed sides X,Y. On its indices put i->j exactly when i!=j and x_i y_j is an edge. A directed cycle with distinct indices i_1,...,i_k (k>=2) replaces the k diagonal edges by x_i_t y_i_(t+1), cyclically. These edges form a different matching covering exactly the same vertices. Hence this digraph has no directed cycle. A finite directed graph without directed cycles has a topological ordering: if every vertex had an incoming arc, following predecessors would repeat a vertex and give a directed cycle; remove a vertex with no incoming arc and induct. Every arc goes from earlier to later. With t=floor(m/2), the last t X endpoints and first t Y endpoints are disjoint in index and have no edges between them. Off-diagonal edges would point backwards; diagonal edges would require a common index. This uses no perfect matching assumption and says nothing about acyclicity of the underlying undirected graph.

Fix g, put h=max(1,ceil(g/2)), d=100. Choose an integer N divisible by four, N>=4h, N>400 B_h where B_h=sum_{l=1}^h 2l (2d)^(2l), and N sufficiently large that exp((log 4-d/16)N)<1/4. Such N exists: log 4<2<100/16, B_h is a finite constant independent of N. These are existence inequalities, not numerical experiments.

Take disjoint labelled sets X,Y of size N and d independent uniform bijections pi_c:X->Y. Retain each colored edge (x,pi_c(x),c), initially a multigraph. Each color is a perfect matching. For fixed A subset X, B subset Y of size a=N/4, one color avoids A x B with probability (N-a)_a/(N)_a: expose the distinct images of A uniformly without replacement. Each factor (N-a-j)/(N-j)=1-a/(N-j) <=1-a/N, for 0<=j<a, so the probability is at most (1-a/N)^a <=exp(-a^2/N)=exp(-N/16). Independence gives exp(-dN/16) for all colors. There are binom(N,a)^2 <=4^N pairs, so the probability of any empty a-by-a rectangle is at most exp((log4-d/16)N)<1/4.

Define colored witnesses explicitly. For l>=2 take ordered distinct x_1,...,x_l in X and ordered distinct y_1,...,y_l in Y, with colored edges x_i y_i and x_(i+1) y_i (indices cyclic). Every witness has 2l distinct colored edges. For l=1 take a pair x,y and two distinct colors, both assigned the same pair. Let W_l count all these ordered descriptions that occur. Multiple descriptions of a single cycle are allowed and only overcount. There are at most N^(2l)d^(2l) descriptions (also for l=1). In a given description, a color's prescribed pairs either conflict with being a bijection, giving probability zero, or specify r_c distinct domain and image pairs. In the latter case the probability is (N-r_c)!/N!=1/(N)_(r_c). Colors are independent and sum_c r_c=2l. Since r_c<=2l<=2h and N>=4h, every factor N-j in these falling factorials is at least N/2. Hence the probability is at most (2/N)^(2l). Consequently E W_l <=(2d)^(2l), including the two-color parallel witnesses at l=1. This is finite counting and linearity of expectation, with no independence assumed between witnesses.

Set S=sum_{l=1}^h 2l W_l. Then ES<=B_h. Markov's inequality gives P(S>=N/100)<=100B_h/N<1/4 (because S>=t implies ES>=t P(S>=t)). The union bound shows probability less than 1/2 that either a hole exists or S>=N/100. The finite product probability space therefore contains a tuple having no a-by-a empty rectangle and S<N/100, simultaneously, without conditioning on high girth.

Delete all vertices lying on any occurring witness. A length-2l witness uses at most 2l vertices; overlaps and multiple descriptions only decrease the union size, so the number q deleted is at most S<N/100. Keep the induced colored graph on surviving vertices. No parallel pair survives, since any parallel pair in the original was an l=1 witness. There are no loops because the sides are disjoint. Thus forgetting colors gives a simple bipartite graph H of maximum degree <=d. Any ordinary cycle of length <=2h in H is even, with distinct vertices on each side, and its surviving edges have colors. It was one of the witnesses for l>=2 and its vertices would have been deleted: contradiction. No odd cycle exists. Thus all cycles have length >2h>=g, and forests also satisfy the required no-short-cycle convention. For g=1 or 2, h=1 removes parallel pairs and simplicity suffices; the same argument applies. The graph is finite.

The induced deletion cannot create a hole among surviving sets: edges between surviving vertices are retained. Hence H has no empty a-by-a rectangle. The first color's N matching edges lose at most q edges, since each lost edge contains a deleted vertex and those edges were disjoint. Thus nu(H)>=N-q>99N/100. This proves nonvacuity even though the two surviving sides need not have equal size or a perfect matching.

If a uniquely restricted matching in H had m>=N/2 edges, then t=floor(m/2)>=N/4 because N/4 is an integer. Its topological-order rectangle contains subsets of size a on both sides, contradicting the absence of holes. Thus nu_ur(H)<N/2. Since (3/4)(99/100)>1/2, we have nu_ur(H)<N/2<(3/4)nu(H). All maxima exist because H is finite. This strict counterexample exists for every g at the same d and epsilon, negating exists g forall G. It is neither a degree-growing construction nor a domain/endpoint correction.

Dependencies: only finite bijection counting, elementary exponential inequality, finite DAG ordering, linearity of expectation, Markov and the union bound. Their needed forms are proved above or explicitly reduced to finite counting. No imported expander/high-girth existence theorem is needed.

Additional source-girth safeguard. The construction can also be taken to have an ordinary cycle, so it does not depend on assigning a minimum to the empty set of cycle lengths. In each of the 100 colors, at most q matching edges are lost. The surviving colored edge count is therefore at least 100(N-q)>99N. No parallel edges survive, so these are distinct ordinary edges of H. Its vertex count is at most 2N. A finite forest has fewer edges than vertices when nonempty, by removing leaves inductively. Thus H is not a forest, its girth is defined by an actual cycle, and that girth is greater than 2h. This is a handwritten counting argument, not a computational experiment.

public import URMatchingPrescriptions
@[expose] public section
namespace URMatching
open scoped Classical
/-- Ordered cycle descriptions with two distinct vertex lists and arbitrary colours.
Index k encodes half-length k+1; at k=0 valid descriptions require distinct colours. -/
abbrev CycleDescription (N k : ℕ) :=
  (Fin (k+1) ↪ Fin N) × (Fin (k+1) ↪ Fin N) ×
    (Fin (k+1) → Fin 100) × (Fin (k+1) → Fin 100)

def ValidDescription {N k : ℕ} (w : CycleDescription N k) : Prop :=
  k = 0 → w.2.2.1 0 ≠ w.2.2.2 0

/-- The two edges at each Y vertex, with cyclically consecutive X vertices. -/
def DescriptionOccurs {N k : ℕ} (w : CycleDescription N k)
    (σ : PermutationTuples N 100) : Prop :=
  ∀ i : Fin (k+1), σ (w.2.2.1 i) (w.1 i) = w.2.1 i ∧
    σ (w.2.2.2 i) (w.1 (i+1)) = w.2.1 i

noncomputable def descriptionEncoding (N k : ℕ) : CycleDescription N k →
    (Fin (k+1) → Fin N) × (Fin (k+1) → Fin N) ×
      (Fin (k+1) → Fin 100) × (Fin (k+1) → Fin 100) :=
  fun w => (w.1, w.2.1, w.2.2.1, w.2.2.2)

theorem descriptionEncoding_injective (N k : ℕ) :
    Function.Injective (descriptionEncoding N k) := by
  intro a b h
  obtain ⟨a₁,a₂,a₃,a₄⟩ := a
  obtain ⟨b₁,b₂,b₃,b₄⟩ := b
  simp only [descriptionEncoding, Prod.mk.injEq] at h
  obtain ⟨h₁,h₂,h₃,h₄⟩ := h
  have e₁ : a₁ = b₁ := DFunLike.coe_injective h₁
  have e₂ : a₂ = b₂ := DFunLike.coe_injective h₂
  exact e₁ ▸ e₂ ▸ h₃ ▸ h₄ ▸ rfl

/-- Ordered witness enumeration bound. The validity restriction only reduces it. -/
theorem description_count_bound (N k : ℕ) :
    Fintype.card {w : CycleDescription N k // ValidDescription w} ≤
      N ^ (k+1) * (N ^ (k+1) * (100 ^ (k+1) * 100 ^ (k+1))) := by
  classical
  calc
    _ ≤ Fintype.card (CycleDescription N k) := Fintype.card_subtype_le _
    _ ≤ Fintype.card ((Fin (k+1) → Fin N) × (Fin (k+1) → Fin N) ×
        (Fin (k+1) → Fin 100) × (Fin (k+1) → Fin 100)) :=
      Fintype.card_le_of_injective _ (descriptionEncoding_injective N k)
    _ = _ := by simp
end URMatching

module
public import URMatchingAvoidanceCount
@[expose] public section
namespace URMatching
open scoped Classical
/-- Exact finite independent prescription count, with a different prescribed
injective partial map in every colour. No consistency assumption is hidden. -/
noncomputable def prescriptionEventEquiv (N d : ℕ) (A : Fin d → Finset (Fin N))
    (f : ∀ c, A c ↪ Fin N) :
    {σ : PermutationTuples N d // ∀ c, restriction (A c) (σ c) = f c} ≃
      (∀ c, {τ : Equiv.Perm (Fin N) // restriction (A c) τ = f c}) where
  toFun σ c := ⟨σ.val c, σ.property c⟩
  invFun τ := ⟨fun c => (τ c).val, fun c => (τ c).property⟩
  left_inv _ := rfl
  right_inv _ := rfl

theorem independent_prescription_count (N d : ℕ) (A : Fin d → Finset (Fin N))
    (f : ∀ c, A c ↪ Fin N) :
    Fintype.card {σ : PermutationTuples N d // ∀ c, restriction (A c) (σ c) = f c} =
      ∏ c, (N - (A c).card).factorial := by
  classical
  rw [Fintype.card_congr (prescriptionEventEquiv N d A f), Fintype.card_pi]
  simp only [restriction_fiber_card]

/-- A repeated input with different outputs is impossible, in the full space. -/
theorem inconsistent_input_count (N d : ℕ) (c : Fin d) (x y z : Fin N) (h : y ≠ z) :
    Fintype.card {σ : PermutationTuples N d // σ c x = y ∧ σ c x = z} = 0 := by
  classical
  let : IsEmpty {σ : PermutationTuples N d // σ c x = y ∧ σ c x = z} :=
    ⟨fun σ => h (σ.property.1.symm.trans σ.property.2)⟩
  exact Fintype.card_eq_zero

/-- A repeated output at different inputs is equally impossible. -/
theorem inconsistent_output_count (N d : ℕ) (c : Fin d) (x y z : Fin N) (h : x ≠ y) :
    Fintype.card {σ : PermutationTuples N d // σ c x = z ∧ σ c y = z} = 0 := by
  classical
  let : IsEmpty {σ : PermutationTuples N d // σ c x = z ∧ σ c y = z} :=
    ⟨fun σ => h ((σ.val c).injective (σ.property.1.trans σ.property.2.symm))⟩
  exact Fintype.card_eq_zero
end URMatching
