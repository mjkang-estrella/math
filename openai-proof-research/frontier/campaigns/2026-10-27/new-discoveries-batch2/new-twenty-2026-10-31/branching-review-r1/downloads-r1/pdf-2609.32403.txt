                                                                  Acyclic orientations of mixed graphs
                                                                          Jørgen Bang-Jensen∗and Anders Yeo†
                                                                                      September 29, 2026




arXiv:2609.32403v1 [math.CO] 26 Sep 2026
                                                                                             Abstract
                                                    A mixed graph M = (V, E ∪A) is acyclic if its directed part (V, A) is an acyclic digraph. In this
                                                 note we study the so-called orientation completion problem for the class of acyclic mixed graphs.
                                                 That is, given an acyclic mixed graph M and a property P; can we orient the edges of M so that
                                                 the resulting digraph is acyclic and has property P. We prove that one can decide in polynomial
                                                 time whether M can be completed to an acyclic digraph with an out-branching from a prescibed
                                                 vertex s, while it is NP-complete to decide whether M has an acyclic orientation which has both
                                                 an out-branching and an in-branching (a bipolar orientation). We show that it is NP-complete
                                                 to decide whether M can be oriented so that it contains a directed path between two prescribed
                                                 vertices. Finally we describe a polynomial algorithm for deciding whether an acyclic digraph D
                                                 has an out-branching Bs+ such that the digraph D −A(Bs+ ) is connected (in the underlying sense).
                                                 Based on this we pose as an open problem the complexity of deciding whether the edges of an
                                                 acyclic mixed graph can be oriented so that the result is an acyclic digraph with a non-separating
                                                 out-branching.


                                           1     Introduction
                                           All notation and terminology used is consistent with [4]. Orientations of mixed graphs so as to sat-
                                           isfy prescribed reachability conditions or connectivity properties has been studied many times in the
                                           literature, see e.g. [2, 9, 13, 14, 16, 17]. Several of those problems fit the framework which is called
                                           the orientation completion problem introduced by Bang-Jensen, Huang and Zhu in [5]. This is
                                           defined as follows: given a mixed graph M = (V, E ∪ A) (which can be seen as a partially oriented
                                           graph) and a graph property P; can we orient the edges of E as an arc set A′ so that the resulting
                                           directed graph D = (V, A ∪ A′ ) has property P? The orientation completion problem framework
                                           generalizes many problems dealing with either orientations of undirected graphs or finding prescribed
                                           structures in digraphs. Thus the orientation completion problem for a given property P is at least as
                                           hard as both the orientation problem where one seeks an orientation of an undirected graph so that
                                           the resulting digraph has property P and the already oriented version where we wish to know whether
                                           a given digraph has property P.

                                                The purpose of this note is to study some natural orientation completion problems when the
                                           property P includes that the resulting digraph D must be acyclic. In Section 2 we first study whether
                                           it is possible to obtain a completion to an acyclic digraph so that a prescribed vertex s has a directed
                                           path to all other vertices in D. Then we show in Section 3 that it is NP-complete to decide whether
                                           there is a completion to an acyclic digraph which has both a vertex that can reach other vertices by
                                           directed paths and another vertex that can be reached from all other vertices. In Section 4 we show
                                           that when we just want to ensure reachability between a specific pair of vertices (rather than having an
                                           out-branching), then the orientation completion problem to an acyclic digraph becomes NP-complete.
                                           Finally, we show in Section 5 that one can decide in polynomial time whether an acyclic digraph has a
                                           non-separating out-branching and we, as an interesting open problem, suggest to study the complexity
                                           of the orientation completion version of the problem.

2      Completing an acyclic mixed graph to an acyclic digraph
       with an out-branching
Let M = (V, A, E) be an acyclic mixed graph and let s ∈ V be given. A 3-partition (Y, B, X) of V is
an s-obstruction if
    (i) s ∈ Y ∪ X.
 (ii) There are no edges or arcs with one end in Y and the other in B.
 (iii) Every vertex in X is reachable by a directed path from some vertex in B.

Lemma 2.1 Let M = (V, A, E) be an acyclic mixed graph and let s ∈ V be given. If M has an
s-obstruction, then M has no completion to an acyclic digraph with an out-branching rooted at s.

Proof: Let (Y, B, X) be an s-obstruction and let B ′ ⊆ B denote the set of vertices from B that
can reach a vertex in X. Recall that, by (iii), every vertex in X is reachable from B ′ . Let D be an
arbitrary acyclic completion of M and let O = v1 , v2 , . . . , vn be any acyclic ordering of D. Then O
induces an ordering b1 , b2 , . . . , bk , k = |B ′ | of the vertices in B ′ . Since every vertex of X is reachable
from B ′ in M , all vertices of X must occur after vi = b1 in O. This implies that there is no path from
s to b1 in D so D has no out-branching from s.                                                                    ⋄


Lemma 2.2 If the directed part of an acyclic mixed graph M = (V, A, E) has an out-branching Bs+
rooted at s, then M has a completion to an acyclic digraph containing Bs+ .

Proof: Let O = v1 , v2 , . . . , vn be an acyclic ordering of Bs+ . For every edge vi vj of E we orient the
edge from vi to vj if i < j and from vj to vi if i > j. Clearly the resulting digraph is acyclic and it
contains Bs+ .                                                                                            ⋄


Theorem 2.3 Let M = (V, A, E) be an acyclic mixed graph and let s ∈ V be given. M can be oriented
as an acyclic digraph with an out-branching rooted at s if and only if M has no s-obstruction.

    Proof: By Lemma 2.1 we may assume that M has no s-obstruction. This implies that no arc of
A enters s, as otherwise (∅, V − s, {s}) would be an s-obstruction. The following algorithm constructs
a completion of M to an acyclic digraph with an out-branching from s.
    Let Z denote the set of vertices that are reachable from s via directed paths in M . If Z = V we
are done by Lemma 2.2. So assume Z ̸= V . Let Z ′ ⊆ Z denote the set of vertices in Z which are
adjacent to a vertex in V − Z (by either an arc or an edge). Note that by the definition of Z there
are no arcs from Z ′ to V − Z. If every vertex of Z ′ is reachable from V − Z then (Z − Z ′ , V − Z, Z ′ )
is an s-obstacle, contradicting the assumption. Hence some vertex z ∈ Z ′ cannot be reached from
V − Z. Let zv be an arbitrary edge from z to V − Z and orient this edge from z to v. Since z was
not reachable from V − Z, the directed part of the current mixed graph is acyclic. Now update Z to
include v and all other vertices of V − Z that became reachable when we oriented zv from z to v and
repeat the argument above.
    Let Z1 denote the updated Z and Z1′ be the updated Z ′ and let M1 be the updated M (where the
edge zv has been oriented). Note that if there is a directed path, in M1 , from a vertex in V − Z1 to
a vertex in Z1′ , then this is also a directed path in M as if the arc zv is on the path in M1 then there
is a path from V − Z1 to z implying that z ̸∈ Z ′ , a contradiction. Therefore, if every vertex of Z ′ is
reachable from V − Z then (Z − Z ′ , V − Z, Z ′ ) is an s-obstacle also in later iterations of the algorithm.
    As at least one new vertex is added in each round, after at most n − 1 steps, this results in an
acyclic mixed graph M ′ with an out-branching rooted at s and then we can complete the orientation
by Lemma 2.2.                                                                                               ⋄

   We note that the proof of Theorem 2.3 implies a polynomial algorithm for deciding if a mixed
graph has an acyclic completion containing an out-branching rooted at s.

3     Completing to a bipolar orientation
A vertex ordering v1 , v2 , . . . , vn of a graph G = (V, E) with two distinct vertices s, t is called an
st-ordering of V if it satisfies that v1 = s, vn = t and for every 1 < j < n there are indices
s ≤ i < j < k ≤ n such that vi vj ∈ E and vj vk ∈ E.

Theorem 3.1 [1]

    • Every 2-connected graph G has an st-ordering for every choice of distinct vertices s, t of G.
    • A graph G = (V, E) has an st-ordering if and only if the graph G + st is 2-edge-connected.

    A bipolar orientation of a graph G = (V, E) is an acyclic orientation D = (V, A) of G which has
exactly one source s and one sink t. Thus, for every acyclic ordering s = v1 , v2 , . . . , vn = t of D each
vi with 1 < i < n has an in-neighbour vj (which will have j < i) and an out-neighbour vk (which will
have k > i). From this it is easy to see that G = (V, E) has a bipolar orientation with source s and
sink t if and only if G has an st-ordering.

Theorem 3.2 It is NP-complete to decide whether an acyclic mixed graph M = (V, E ∪ A) can be
completed to a bipolar orientation with source s and sink t for prescribed vertices s, t.

    Proof: We will reduce the so-called betweenness problem to our problem. The betweenness
problem is as follows: given a collection C of tripels (vi1 , vj1 , vk1 ), . . . , (vip , vjp , vkp ) so that all elements
of the tripels are from the set W ; is it possible to order the elements of W as O = v1 , v2 , . . . , vn so
that for every tripel (viq , vjq , vkq ), q ∈ [p], the elements occur in O either in the order viq , vjq , vkq or
in the order vkq , vjq , viq ? This problem, listed as problem [MS1] in [15], is NP-complete.
    Given an instance (W, C) of betweenness where W = {v1 , v2 , . . . , vn } we construct a mixed acyclic
graph M = (V ∗ , E ∪ A) where E and A where we construct V ∗ , E, A as follows starting from V ∗ =
W ∪ {s, t}, E = ∅ and A = ∅.
    • for every vi ∈ W add the arcs svi and vi t to A
    • for every triple (viq , vjq , vkq ) of C we add two new vertices xq , yq to V ∗ , add the four edges
      viq xq , viq yq , xq vkq , yq vkq to E and the arcs xq vjq , vjq yq to A. Let Mq denote the mixed subgraph
      of M induced by the vertices xq , yq , viq , vjq , vkq .

    It is easy to check that the resulting mixed graph M has no directed cycle. Clearly s will be a
source and t a sink in every orientation of M (as an acyclic digraph). It remains to show that M
can be completed to an acyclic digraph with exactly one source and one sink if and only if (W, C) is
a ’yes’-instance of betweenness. Suppose first that M has a bipolar orientation D. Since M contains
the directed path xq vjq yq for every triple (viq , vjq , vkq ) of C and xq , yq are private to Mq , the only
possible acyclic orientations of Mq are obtained by orienting the 4 edges as viq xq , viq yq , xq vkq , yq vkq or
as vkq xq , vkq yq , xq viq , yq viq . In the first case the vertices will occur in the order viq , xq , vjq , yq , vkq in
every acyclic ordering of V ∗ and in the second case they will appear in the order vkq , xq , vjq , yq , viq in
every acyclic ordering of V ∗ . Hence if D has a bipolar orientation, then we obtain the desired ordering
O of W by taking any acyclic order of V ∗ and deleting all the vertices of {xq |q ∈ [p]} ∪ {yq |q ∈ [p]}.
    Suppose now that O is an ordering of W that certifies that (W, C) is a ’yes’-instance of betweenness,
then we obtain a bipolar orientation of M by orienting the four edges of Mq as viq xq , viq yq , xq vkq , yq vkq
if the vertices of (viq , vjq , vkq ) occur in the order viq < vjq < vkq in O and as vkq xq , vkq yq , xq viq , yq viq
if they occur in the order vkq < vjq < viq in O.                                                                         ⋄




4     Orienting a acyclic mixed graph as an acyclic digraph with
      an (s, t)-path
We consider the following problem.

Problem 4.1 (Completion to an acyclic digraph with an (s, t)-path) Given a mixed graph
M and two vertices s, t. Can M be completed to an acyclic digraph D with an (s, t)-path?


Theorem 4.2 Completion to an acyclic digraph with an (s, t)-path. is NP-complete.

    Proof: Let L be the mixed graph on 4 vertices u, v, w, z, two edges uv, wz and two arcs (v, w),
(z, u). There are 4 possible completions of L as an oriented graph and all except the one where we
orient as (u, v), (w, z) is acyclic. Let W denote the mixed graph on 8 vertices p, q, a1 , b1 , a2 , b2 , a3 , b3 ,
three edges a1 b1 , a2 b2 , a3 b3 and six arcs (p, a1 ), (p, a2 ), (p, a3 ), (b1 , q), (b2 , q), (b3 , q).
    Let F be an instance of 3-SAT with variables x1 , x2 , . . . , xn and clauses C1 , C2 , . . . , Cm , where
each clause is of the form (ℓ1 ∨ ℓ2 ∨ ℓ3 ) and each ℓi is either one of the variables xj or the negation x̄j
of such a variable.
    Let pi (qi ) be the number of times variable xi (x̄i ) occurs as a literal in F. The enumeration of the
clauses C1 , . . . , Cm induces an ordering on the occurrences of the same literal in the formula. Guided by
this ordering we now construct a mixed graph H ′ = H ′ (F) as follows: For each variable xi , i ∈ [n] let

    The mixed graph that we construct will never have a (t, s)-path as all arcs are directed into t. So
this implies:

Corollary 4.3 It is NP-complete to decide whether a mixed graph can be completed to be acyclic and
have either an (s, t)-path or a (t, s)-path.

    Even if the input acyclic mixed graph has both a (mixed) (s, t)-path and a (mixed) (t, s)-path the
problem above is still NP-complete. To see this take two copies M1 , M2 of the mixed graph H ′ from
the proof of Theorem 4.2 and denote the copies of s, t in these s1 , t1 , respectively s2 , t2 . Now add two
new vertices s∗ , t∗ , and the arcs s∗ s1 , t1 t∗ , t∗ s2 , t2 s∗ . It is easy to check that the new mixed graph H ′′
is acyclic and has a completion to an acyclic digraph with an (s∗ , t∗ )-path or a (t∗ , s∗ )-path if and
only if H ′ has an acyclic orientation with an (s, t)-path.


5     Non-separating branchings in acyclic digraphs
A subdigraph D′ = (V, A′ ) of a digraph D = (V, A) is non-separating if the digraph D∗ = (V, A \ A′ )
is connected. It is well-known that one can decide in polynomial time whether an undirected graph
G has a pair of edge-disjoint spanning trees. This follows from matroid theory or the short direct
proof in [18] of Tutte’s tree-packing theorem. By Edmonds’s branching theorem [12] one can also
decide in polynomial time whether a digraph contains two arc-disjoint out-branchings. In a personal
communication Thomassé asked the following problem around 2008.
Problem 5.1 What is the complexity of deciding whether a digraph has a non-separating out-branching?

    This was answered by the authors of the present paper as follows.
Theorem 5.2 [8] It is NP-complete to decide whether a digraph D = (V, A) has a non-separating
out-branching.
    We now show that Thomassé’s problem can be solved in polynomial time when D is acyclic.

Theorem 5.3 There exists a polynomial algorithm A which given an acyclic digraph D = (V, A)
either finds a non-separating out-branching or a certificate that D has no such out-branching.

    Proof: First observe that if D has more than one vertex of in-degree zero then it has no out-
branching and A can just out-put a certificate consisting of two vertices of in-degree zero. Hence we
can assume that D has a unique vertex s of in-degree zero. Now let O = s = v1 , v2 , . . . , vn be an
arbitrary acyclic ordering of D and note that every vertex vi with i ≥ 2 has all its in-neighbours before
it in O. Furthermore, if we fix one arc entering each vi , i ≥ 2, then these arcs form an out-branching


                                                          5
from s in D. This implies that D has a non-separating out-branching if and only if U G(D) has a
spanning tree which uses at most d− (vi ) − 1 of the arcs entering vi for each i ≥ 2. Let M1 = (A, I1 )
be the matroid where a set X of arcs is independent if and only if X contains no more than d− (vi ) − 1
of the arcs entering vi for each i ≥ 2 and let M2 be the circuit matroid on U G(D) (a set Y of arcs is
independent if and only if there is no cycle of U G(D) all of whose arcs are contained in Y ). Then it
is easy to check that a set Z of arcs is independent in both M1 and M2 if and only if D − Z has an
out-branching from s and Z induces a forrest in U G(D). Hence D has a non-separating out-branching
if and only if the maximum size of a common independent set of M1 and M2 has size n − 1. This
can be checked by any polynomial algorithm for matroid intersection and in the case when the answer
is no that algorithm can also deliver a certificate (based on Edmonds’s matroid intersection theorem
[11]) for the non-existence of a non-separating out-branching.                                        ⋄

   By Theorem 5.3 and the easy fact that an undirected graph G has an acyclic orientation with a
non-separating out-branching if and only if G has a pair of edge-disjoint spanning trees the following
problem is natural to ask.

Problem 5.4 What is the complexity of deciding whether a mixed graph P has an acyclic completion
which contains a non-separating out-branching?

    We also know that deciding the existence of an out-branching Bs+ which is arc-disjoint from some
in-branching Bt− is polynomial for acyclic digraphs [7, 10]. Hence it is tempting to ask about the com-
plexity of deciding whether a mixed graph M has an acyclic completion which contains a pair Bs+ , Bt−
of respectively an out- and an in-branching. However, already the case when M has no arcs (is an
undirected graph) seems very challenging and even the case when M is the union of two edge-disjoint
spanning trees is open and the problem is closely related to so-called rigidity matroids, see [3, 6].
