198: Abstract.
199:     
200: 
201: We investigate the properties of binary linear codes of even length whose permutation
202: automorphism group is a cyclic group generated by an involution. Up to dimension or co-dimension 4,
203: we show that there is no quasi group code
204: whose permutation automorphism group is isomorphic to C_{2}. By generalizing the method
205: we use to prove this result, we obtain results on the structure of putative extremal self-dual [72,36,16]
206: and [96,48,20] codes in the presence of an involutory permutation automorphism.
207:   
208: 
209: 
210: 
211: Key words and phrases: Group code, Quasi group code, permutation automorphism of a code
212: 
213: 
214: 2010 Mathematics Subject Classification94B05, 11T71, 20B05
215: 
216: 
217: 
218: 
219: 1. Introduction
220: 
221: 
222: 
223: 
224: A binary linear code C of length n is a subspace of {\mathbb{F}}_{2}^{n}. The symmetric group S_{n}
225: acts on {\mathbb{F}}_{2}^{n} by permuting the set of its coordinates. The group of permutations which sends C onto itself
226: is called the permutation automorphism group of C and is denoted by \mathrm{PAut}(C). The
227: permutation automorphism group of a code carries a lot of information about the algebraic structure of
228: the code. For instance,
229: if there is a non-trivial G\leq\mathrm{PAut}(C) for a binary linear code C,
230: the problem of determining C by the help of G is a well-known and difficult problem in coding theory
231: (see for example [4]).
232: 
233: 
234: 
235: 
236: Our intention to attack this problem is to investigate the structure of binary linear codes in the
237: presence of an involutory permutation automorphism. In [1], a method for constructing self-dual
238: codes with an involutory permutation automorphism group is given. Later in [2],
239: extremal doubly even self-dual binary codes of length 24m with an involutory permutation automorphism
240: are considered. It is shown in [2, Theorem 5.3] that a putative self-dual [72,36,16] code
241: can not have an involutory automorphism with some fixed points.
242: Moreover, there are five candidates for the permutation automorphism group of
243: a putative self-dual [72,36,16] code and two of the cantidates are C_{2} and C_{2}\times C_{2} (see [4, Theorem 6.3]).
244: Inspired by all of these,
245: our aim is to deduce some structural results on binary linear codes having an involutory permutation
246: automorphism.
247: We first discuss linear codes with an arbitrary involutory permutation automorphism, then we focus
248: on the ones with involutory fixed point free permutation automorphisms. The fixed subcode associated to
249: a permutation automorphism gives a lot of information about the code itself, as we can see in [1, 2, 5]
250: In particular, the fixed subcode of an involutory permutation automorphism plays a central role in our arguments.
251: 
252: 
253: 
254: 
255: Borello and Willems, in [7], give an intrinsic
256: description of linear codes of length n whose permutation automorphism group contains a free subgroup of S_{n}. These
257: codes are called quasi group codes. Abelian codes, group codes, quasi-cyclic
258: and quasi-abelian codes belong to the class of quasi group codes. Hence, this approach gives a
259: unified way to consider these different class of codes. In this paper, we show that there is no quasi group
260: code C of even length n>2 and dimension k or n-k where 1\leq k\leq 4 where \mathrm{PAut}(C)\cong C_{2} (see Corollary
261: 4.6). On the other hand, by the methods we develop to prove this result, we obtain some results on
262: the structures of putative extremal self-dual [72,36,16] and [96,48,20] codes.
263: 
264: 
265: 
266: 
267: The organization of the paper is as follows. In Section 2, we give the background and some lemmas
268: concerning the dimension of the fixed subspace of an involutory permutation automorphism.
269: In Section 3, we show that if a binary linear code C of even length
270: with dimension or co-dimension 2 satisfies \mathrm{PAut}(C)\cong C_{2}, then its length is 2 or 4. We also
271: determine all binary linear codes C of length 4 with \mathrm{PAut}(C)\cong C_{2} up to permutation equivalence.
272: Section 4 deals with binary linear codes of even length with involutory fixed point free permutation automorphisms
273: with dimension 3 and dimension 4. Also, there are some important corollaries together with a conjecture
274: in this section. In Section 5,
275: we give a generalization of our idea that is used in the proof of Theorem 4.4 and we present the applications on
276: putative extremal self-dual [72,36,16] and [96,48,20] codes.
277: 
278: 
279: 
280: 
281: 
282: 2. Background and lemmas
283: 
284: 
285: 
286: 
287: In this paper, we deal with binary linear codes. Recall that a binary linear code C of length
288: n is a subspace of {\mathbb{F}}_{2}^{n}. An element c=c_{1}c_{2}\ldots c_{n}\in C is called a codeword of C
289: and its Hamming weight is defined to be
290: 
291: 
292: 
293: 
294: \mathrm{wt}(c)=|\{i\in\{1,\ldots,n\}\ |\ c_{i}\neq 0\}|.
295: 
296: 
297: 
298: The minimum weight of C is defined by \mathrm{wt}(C)=\mathrm{min}\{\mathrm{wt}(c)\ |\ c\in C\backslash\{0\}\}. If C is
299: a binary linear code with length n, dimension k and minimum weight d, then C is called
300: a binary [n,k,d] code. For a code C\subseteq{\mathbb{F}}_{2}^{n} and a non-negative integer i, let A_{i}(C) denote
301: the number of codewords in C of weight i. The sequence (A_{0}(C),A_{1}(C),\ldots,A_{n}(C)) is
302: called the weight distribution of C. 
303: 
304: 
305: 
306: 
307: There is a natural action of S_{n} on {\mathbb{F}}_{2}^{n} induced by the action of S_{n} on the set \{1,\ldots,n\}. More precisely,
308: for c=c_{1}c_{2}\ldots c_{n}\in{\mathbb{F}}_{2}^{n} and \beta\in S_{n},
309: 
310: 
311: 
312: 
313: c^{\beta}=c_{\beta^{-1}(1)}c_{\beta^{-1}(2)}\ldots c_{\beta^{-1}(n)}.
314: 
315: 
316: 
317: For a linear code C, set C^{\beta}=\{c^{\beta}\ |\ c\in C\}. It is easy to see that
318: C^{\beta} is also a linear code. A permutation \beta\in S_{n} is called a permutation automorphism
319: or simply an automorphism of C if C^{\beta}=C. The stabilizer
320: 
321: 
322: 
323: 
324: \mathrm{PAut}(C)=\{\beta\in S_{n}\ |\ C^{\beta}=C\}
325: 
326: 
327: 
328: is called the permutation automorphism group of C.
329: 
330: 
331: 
332: 
333: For a linear code C of length n, if there exists a subgroup G of \mathrm{PAut}(C) which is transitive
334: and free, then C is called a group code or a G-code. This characterization is given
335: first in [6] then in [7]. where a weaker notion is introduced. C is called a quasi group code or a quasi-G code if
336: there is a free subgroup G inside \mathrm{PAut}(C).
337: 
338: 
339: 
340: 
341: Two linear codes C_{1} and C_{2} of length n
342: are called permutation equivalent if there is a \beta\in S_{n} such that C_{1}^{\beta}=C_{2}. In this case,
343: note that \mathrm{PAut}(C_{2})=\mathrm{PAut}(C_{1})^{\beta}. So if two linear codes are permutation equivalent, then their
344: permutation automorphism groups are conjugate in S_{n}. In this paper, we denote the k-cycles in S_{n}
345: as (a_{1},a_{2},\ldots,a_{k}) where a_{1},a_{2},\ldots,a_{k}\in\{1,2,\ldots,n\}.
346: 
347: 
348: 
349: 
350: For a permutation automorphism \beta of a binary linear code C,
351: the
352: fixed point set of \beta, which we denote by F_{\beta}(C), is defined as
353: 
354: 
355: 
356: 
357: F_{\beta}(C)=\{c\in C\ |\ c^{\beta}=c\}.
358: 
359: 
360: 
361: Note that, this set is closed under addition, so F_{\beta}(C) is a subspace of C. This
362: is called the fixed subcode of C under \beta.
363: 
364: 
365: 
366: 
367: We begin with an observation that holds for any permutation automorphism of a binary linear code which is
368: an involution. It turns out that there is a relationship between the dimension of the code and its fixed subcode
369: under that involulion.
370: The notation \lceil x\rceil denotes the smallest integer greater or equal to x.
371: 
372: 
373: 
374: Lemma 2.1.
375: 
376: 
377: 
378: Let C be a binary linear code of length n and dimension k. Let \beta\in\mathrm{PAut}(C) be an involution and
379: f=\mathrm{dim}(F_{\beta}(C)). We have that f\geq(k-f) or equivalently f\geq\lceil k/2\rceil.
380: 
381: 
382: 
383: 
384: Proof.
385: 
386: 
387: 
388: If C=F_{\beta}(C), the claim holds trivially. So assume that C\neq F_{\beta}(C).
389: Let’s start with a basis {\mathcal{B}}_{1} of F_{\beta}(C) and then extend it to a basis {\mathcal{B}} of C.
390: Let
391: 
392: 
393: 
394: 
395: {\mathcal{B}}\backslash{\mathcal{B}}_{1}=\{w_{(1)},\ldots,w_{(k-f)}\}
396: 
397: 
398: 
399: and for any i=1,\ldots,k-f define x_{(i)}=w_{(i)}+w_{(i)}{}^{\beta}. Then since w_{(i)}\not\in F_{\beta}(C), we have that
400: x_{(i)}\neq 0. Also x_{(i)}=x_{(i)}{}^{\beta}, so that
401: x_{(i)}\in F_{\beta}(C). If for some \lambda_{i}\in{\mathbb{F}}_{2}, \sum_{i=1}^{k-f}\lambda_{i}x_{(i)}=0, it follows that
402: 
403: 
404: 
405: 
406: \sum_{i=1}^{k-f}\lambda_{i}w_{(i)}=(\sum_{i=1}^{k-f}\lambda_{i}w_{(i)})^{\beta}
407: 
408: 
409: 
410: and so \sum_{i=1}^{k-f}\lambda_{i}w_{(i)}\in F_{\beta}(C)\cap\langle{\mathcal{B}}\backslash{\mathcal{B}}_{1}\rangle.
411: However, F_{\beta}(C)\cap\langle{\mathcal{B}}\backslash{\mathcal{B}}_{1}\rangle=\{0\}, which implies that
412: \sum_{i=1}^{k-f}\lambda_{i}w_{(i)}=0. Hence by the linear independence of the set {\mathcal{B}}\backslash{\mathcal{B}}_{1}, it
413: follows that \lambda_{i}=0 for i=1,\ldots,k-f. Therefore, \{x_{(1)},\ldots,x_{(k-f)}\} is a linearly
414: independent subset of F_{\beta}(C), which yields that f\geq(k-f).
415: ∎
416: 
417: 
418: 
419: 
420: Lemma 2.2.
421: 
422: 
423: 
424: Suppose that C is a binary linear code of dimension k and length n\geq 4. If \mathrm{PAut}(C)=\langle\beta\rangle,
425: for \beta=(1,2)(3,4)\ldots(t,t+1) where t is an odd integer such that
426: 3\leq t\leq(n-1) is an arbitrary odd integer, then \mathrm{dim}(F_{\beta}(C))\leq(k-1). In particular,
427: if k\geq 2 we have that \lceil k/2\rceil\leq\mathrm{dim}(F_{\beta}(C))\leq(k-1).
428: 
429: 
430: 
431: 
432: Proof.
433: 
434: 
435: 
436: Let f=\mathrm{dim}(F_{\beta}(C)). If f=k, it follows that F_{\beta}(C)=C. Then every element c of C satisfy
437: c_{i}=c_{i+1} for all odd i\in\{1,2,\ldots,t\}. But then the transposition (i,i+1)\in\mathrm{PAut}(C) for any
438: odd i\in\{1,2,\ldots,t\}. This implies that \mathrm{PAut}(C)\neq\langle\beta\rangle, a contradiction, so
439: f\neq k and the result follows from Lemma 2.1.
440: 
441: 
442: 
443: 
444: ∎
445: 
446: 
447: 
448: 
449: 
450: 
451: 3. Codes of even length with lower dimensions or co-dimensions
452: 
453: 
454: 
455: 
456: We begin with observations on permutation automorphisms of binary linear codes of even length
457: whose dimension or co-dimension is equal to 1.
458: 
459: 
460: 
461: Proposition 3.1.
462: 
463: 
464: 
465: Let C be a binary linear code of length n=2m where m\geq 2. Assume
466: that \mathrm{dim}(C)=1 or \mathrm{dim}(C)=n-1. Then the following hold.
467: 
468: (i) 
469: 
470: 
471: 
472: We have that \mathrm{PAut}(C)\ncong C_{2}.
473: 
474: (ii) 
475: 
476: 
477: 
478: If \mathrm{wt}(C) is even and \mathrm{wt}(C)\neq n, then C is a quasi group code which is not a group code.
479: 
480: (iii) 
481: 
482: 
483: 
484: Assume that n=2^{r} (or equivalently m=2^{r-1}) and \mathrm{wt}(C)\neq n. Then C is a quasi group code
485: which is not a group code if and only if \mathrm{wt}(C) is even.
486: 
487: 
488: 
489: 
490: 
491: 
492: Proof.
493: 
494: 
495: 
496: If \mathrm{dim}(C)=n-1, then \mathrm{dim}(C^{\perp})=1 and \mathrm{PAut}(C)=\mathrm{PAut}(C^{\perp}). Hence it is enough to
497: prove all assertions for 1-dimensional linear codes.
498: Assume that \mathrm{dim}(C)=1 and the weight of C is equal to d. It follows that
499: C is generated by v where v has exactly d number of 1’s. Then since \mathrm{PAut}(C)=\mathrm{stab}_{S_{n}}(v),
500: we have that
501: 
502: 
503: 
504: 
505: \mathrm{PAut}(C)\cong S_{d}\times S_{n-d}.
506: 
507: 
508: 
509: Hence we have that |\mathrm{PAut}(C)|>2.
510: So the assertion (i) is proved.
511: 
512: 
513: 
514: 
515: If \mathrm{wt}(C)=d is even, there is a fixed point free involution \gamma in S_{d}, and
516: since n-d is also even, there is a fixed point free involution \delta in S_{n-d}.
517: Then we have that \langle\gamma\delta\rangle\leq\mathrm{PAut}(C)
518: and it follows that C is a quasi-\langle\gamma\delta\rangle code. From the structure of \mathrm{PAut}(C), it is easy to see
519: that we can not find a transitive subgroup, hence C is not a group code which finishes the proof of (ii).
520: 
521: 
522: 
523: 
524: Now let us prove the third assertion. Suppose that C is a quasi-H code for H\leq\mathrm{PAut}(C).
525: Then it follows that the order of H is a divisor of n=2^{r} and H is a free
526: subgroup of S_{n}. So there is a fixed point free involution \gamma\in H. It
527: follows that \gamma fixes v and so the number of 1’s
528: in v should be even since \gamma is an involution. The converse direction
529: follows from (ii).
530: ∎
531: 
532: 
533: 
534: 
535: 
536: Now let us investigate linear codes with dimension or co-dimension equal to 2.
537: 
538: 
539: 
540: Theorem 3.2.
541: 
542: 
543: 
544: Let C be a binary linear code of length n=2m where m\geq 3.
545: If \mathrm{dim}(C)=2 or \mathrm{dim}(C)=n-2, then \mathrm{PAut}(C)\ncong C_{2}.
546: 
547: 
548: 
549: 
550: Proof.
551: 
552: 
553: 
554: Suppose to the contrary that C is a binary linear code of length n\geq 6
555: and \mathrm{PAut}(C)=\langle\beta\rangle where \beta is an involution in S_{n}.
556: It is enough to prove the theorem when \mathrm{dim}(C)=2 since \mathrm{PAut}(C)=\mathrm{PAut}(C^{\perp})
557: and \mathrm{dim}(C^{\perp})=n-\mathrm{dim}(C).
558: 
559: 
560: 
561: 
562: Since any conjugate of a permutation automorphism of C is a permutation automorphism
563: of the permutation equivalent code of C, it is enough to prove the result by considering all possible
564: involutions \beta\in S_{n} with different cycle structures. Thus we can assume without loss of generality that \beta=(1,2)(3,4)\ldots(t,t+1) where
565: 1\leq t\leq(n-1) is an arbitrary odd integer. Let us first assume that
566: 3\leq t\leq(n-1). Then by Lemma 2.2, the dimension f of F_{\beta}(C) is
567: equal to 1.
568: So
569: 
570: 
571: 
572: 
573: C=\{0,x,w,w^{\beta}\}
574: 
575: 
576: 
577: where x\in F_{\beta}(C) and w\not\in F_{\beta}(C) and w^{\beta}=w+x.
578: Since x\in F_{\beta}(C), we know that x_{i}=x_{i+1} for all odd i where i\leq t. If there is an
579: odd integer j\leq t such that x_{j}=x_{j+1}=0, then since w^{\beta}=w+x, it implies
580: that w_{j}=w_{j+1}. Hence the transposition (j,j+1) fixes all elements on C, so it lies in \mathrm{PAut}(C),
581: which is a contradiction. If for any odd integer i\leq t we have x_{i}=x_{i+1}=1, then since w^{\beta}=w+x, it implies
582: that w_{i}\neq w_{i+1} for any odd integer i\leq t. Then since t\geq 3, there exist two different integers k,l\leq t+1
583: such that w_{k}=w_{l} so that (w^{\beta})_{k}=(w^{\beta})_{l}. Then it follows that the transposition (k,l) fixes all
584: elements in C, so (k,l)\in\mathrm{PAut}(C). But since (k,l) is different from \beta this is a contradiction.
585: 
586: 
587: 
588: 
589: Now suppose t=1, then \beta=(1,2). Suppose that m\geq 4.
590: Let u and w be two non-zero elements of C. We claim
591: that there exist at least two integers k,l\in\{3,4,\ldots,n\} such that u_{k}=u_{l} and w_{k}=w_{l}. If this
592: is not true, since n\geq 8, there exist at least three elements k,t,l\in\{3,4,\ldots,n\} such that
593: 
594: 
595: 
596: 
597: u_{k}=u_{t}\text{ and }w_{k}\neq w_{t},\ u_{t}=u_{l}\text{ and }w_{t}\neq w_{l}
598: 
599: 
600: 
601: But since these elements take only the values of 0 and 1, it would imply that u_{k}=u_{l}\text{ and }w_{k}=w_{l}.
602: It follows that the transposition (k,l) which is different from \beta=(1,2) fixes u,w and u+w hence is
603: in \mathrm{PAut}(C), which is a contradiction.
604: 
605: 
606: 
607: 
608: Suppose that t=1 and m=3, that is \beta=(1,2).
609: Let u and w be two non-zero elements of C.
610: If we can find k,l\in\{3,4,5,6\} such that u_{k}=u_{l} and w_{k}=w_{l} as in the previous paragraph then we are done.
611: So let us assume that such k and l do not exist. Then it follows that there exist exactly two integers k,l\in\{3,4,5,6\}
612: with the property that u_{k}=u_{l}=1 and that k^{\prime},l^{\prime}\in\{3,4,5,6\}
613: with the property that u_{k^{\prime}}=u_{l^{\prime}}=0. This implies that w_{k}\neq w_{l} and w_{k^{\prime}}\neq w_{l^{\prime}}.
614: If u_{1}=1, then (1,k) and (1,l) fixes u.
615: Since w_{k}\neq w_{l}, we have that either w_{1}=w_{k} or w_{1}=w_{l}. If w_{1}=w_{k}, then the transposition (1,k) fixes
616: w and if w_{1}=w_{l} then (1,l) fixes w.
617: If u_{1}=0. then both (1,k^{\prime}) and (1,l^{\prime}) fixes u.
618: Since w_{k^{\prime}}\neq w_{l^{\prime}}, we have that either w_{1}=w_{k^{\prime}} or w_{1}=w_{l^{\prime}}, similarly
619: choose either of the transposition (1,k^{\prime}) or (1,l^{\prime}) which fixes w in this case. Since in either case we find
620: a transposition in \mathrm{PAut}(C) which is different from \beta, we arrive to a contradiction. This finishes the proof.
621:

630: Remark 3.3.
631: 
632: 
633: 
634: The lower bound for m in Theorem 3.2 is sharp. Indeed, we show that there exists a linear code of length 4 whose
635: permutation automorphism group is isomorphic to C_{2} in the proof of the following result. When the length is
636: equal to 2, then C={\mathbb{F}}_{2}^{2} and \mathrm{PAut}(C)=C_{2} in this case.
637: 
638: 
639: 
640: 
641: Proposition 3.4.
642: 
643: 
644: 
645: Let C be a binary linear code of length
646: 4 and \mathrm{dim}(C)=2. Let \beta\in S_{4} be a transposition. Then \mathrm{PAut}(C)=<\beta> if
647: and only if for every c\in C we have c^{\beta}=c and A_{i}(C)=1 for i=0,1,2,3 and A_{4}(C)=0.
648: 
649: 
650: 
651: 
652: Proof.
653: 
654: 
655: 
656: Without loss of generality we can assume that \beta=(1,2).
657: 
658: 
659: 
660: 
661: Suppose that \mathrm{PAut}(C)=<\beta>. We first claim that F_{\beta}(C)=C. If F_{\beta}(C)\neq C, then
662: the dimension of F_{\beta}(C) is equal to 1. Let x be the non-zero element of F_{\beta}(C), then
663: 
664: 
665: 
666: 
667: C=\{0,x,w,w^{\beta}\}
668: 
669: 
670: 
671: where w\not\in F_{\beta}(C) and x=w+w^{\beta}. Since w\not\in F_{\beta}(C), we have that w_{1}\neq w_{2},
672: so that x_{1}=x_{2}=1. Moreover, since x=w+w^{\beta} we have that x_{3}=x_{4}=0. Hence, x=1100. If w_{3}=w_{4} then
673: the transposition (3,4) fixes w and w^{\beta}, as well as x. So we get a contradiction. So w_{3}\neq w_{4}. Since
674: we also have that w_{1}\neq w_{2}, we have that either w_{1}=w_{3} or w_{1}=w_{4}. Assume without loss of generality that
675: w_{1}=1. Then if w_{1}=w_{3} or w_{1}=w_{4}, then (1,3) or (1,4) fixes w respectively. In the first case (w^{\beta})_{2}=(w^{\beta})_{3}=1,
676: so that (w^{\beta})^{(1,3)}=1100=x and x^{(1,3)}=w^{\beta}. In the second case (w^{\beta})_{2}=(w^{\beta})_{4}=1,
677: so that (w^{\beta})^{(1,4)}=1100=x and x^{(1,4)}=w^{\beta}. In both of the cases, we obtain a transposition in \mathrm{PAut}(C)
678: which is different from \beta. So we have that F_{\beta}(C)=C, or equivalently for all c\in C,c^{\beta}=c.
679: 
680: 
681: 
682: 
683: Our next claim is 1111\not\in C. Assume to the contrary that 1111\in C. Then there are non-zero elements
684: u,w\in C such that u+w=1111. There are k,l\in\{2,3,4\} such that u_{k}=u_{l}. But since
685: u+w=1111, we have that w_{k}=w_{l}. Thus (k,l) which is different from \beta lies in \mathrm{PAut}(C), a contradiction. So
686: A_{4}(C)=0.
687: 
688: 
689: 
690: 
691: Since c^{\beta}=c for all c\in C, we have that c_{1}=c_{2} for all c\in C. If c_{1}=c_{2}=0 for all
692: c\in C, then there is an element v\in C such that v_{3}\neq v_{4} (because otherwise there are less than 4 elements). But this
693: implies that there is u\in C such that u\neq v with u_{3}\neq u_{4}. Then the involution (3,4) flips u and v and it fixes u+v.
694: So (3,4)\in\mathrm{PAut}(C), a contradiction. So there is at least one element w\in C such that w_{1}=w_{2}=1. Then it follows that w=1110 or w=1101 since
695: 1111\not\in C. If w=1110, then the other elements of C are 1100 and 0010. If w=1101, then the other elements of C are 1100 and 0001.
696: Hence, A_{i}(C)=1 for i=0,1,2,3.
697: 
698: 
699: 
700: 
701: Suppose that for any c\in C we have c^{\beta}=c and A_{i}(C)=1 for i=0,1,2,3 and A_{4}(C)=0.
702: Then we have that c_{1}=c_{2} for any c\in C and 1111\not\in C. Then since there exists a unique element with
703: weight 1, there is an element u\in C such that u=0010 or u=0001. Moreover, since there is a unique element with
704: weight equal to 3, we have that either 1110 or 1101 is in C. Then we have that C=\{0000,0010,1100,1110\} or
705: C=\{0000,0001,1100,1101\}. Now it is not difficult to see that \mathrm{PAut}(C)=\langle\beta\rangle.
706: ∎

713: 4. Fixed point free automorphisms
714: 
715: 
716: 
717: 
718: Throughout this section let C be a binary linear code of length n=2m and let
719: \sigma\in\mathrm{PAut}(C) be a fixed point free involutory permutation. Then without
720: loss of generality we can assume
721: 
722: 
723: 
724: 
725: 
726: 
727: 
728: \sigma=\prod_{1\leq i\leq n,i\text{ odd}}(i,i+1)=(1,2)(3,4)\ldots(n-1,n).
729: 
730: 
731: 
732: Then it is easy to see that c=c_{1}c_{2}\ldots c_{n}\in F_{\sigma}(C) if and only if
733: c_{i}=c_{i+1} for all odd i\in\{1,2,\ldots,n\}. For an element c\in F_{\sigma}(C)
734: let us define the set of all odd integers in the support of c as T_{c}, that is
735: 
736: 
737: 
738: 
739: T_{c}:=\{1\leq i\leq n\ |\ i\text{ is odd and }c_{i}c_{i+1}=11\}.
740: 
741: 
742: 
743: 
744: 
745: Lemma 4.1.
746: 
747: 
748: 
749: Let C be a binary linear code of length n=2m with \sigma=(1,2)(3,4)\ldots(n-1,n)\in\mathrm{PAut}(C). Let w\in C\backslash F_{\sigma}(C) and
750: y:=w+w^{\sigma}\in F_{\sigma}(C). Assume that x is a non-zero element in F_{\sigma}(C) such that T_{x}\subseteq T_{y},
751: then the involution \alpha_{x}=\Pi_{i\in T_{x}}(i,i+1) in S_{n} satisfies w^{\alpha_{x}}=w+x.
752: 
753: 
754: 
755: 
756: Proof.
757: 
758: 
759: 
760: Since w^{\sigma}=w+y and T_{x}\subseteq T_{y}, it is easy to see that if i\in T_{x} then x_{i}x_{i+1}=11 and w_{i}\neq w_{i+1}.
761: So (w+x)_{i}(w+x)_{i+1}=w_{i+1}w_{i} when i\in T_{x}.
762: Moreover, if i\not\in T_{x} then x_{i}x_{i+1}=00, so that (w+x)_{i}(w+x)_{i+1}=w_{i}w_{i+1}. As a result, for
763: any odd i, we have that
764: 
765: 
766: 
767: 
768: (w+x)_{i}(w+x)_{i+1}=\begin{cases}w_{i+1}w_{i}&\text{ if }i\in T_{x}\\
769: w_{i}w_{i+1}&\text{ if }i\not\in T_{x}\end{cases}.
770: 
771: 
772: 
773: On the other hand, by the definition of \alpha_{x},
774: for any odd i we have that
775: 
776: 
777: 
778: 
779: (w^{\alpha_{x}})_{i}(w^{\alpha_{x}})_{i+1}=\begin{cases}w_{i+1}w_{i}&\text{ if }i\in T_{x}\\
780: w_{i}w_{i+1}&\text{ if }i\not\in T_{x}\end{cases}.
781: 
782: 
783: 
784: These altogether imply that w^{\alpha_{x}}=w+x.
785: ∎
786: 
787: 
788: 
789: 
790: Remark 4.2.
791: 
792: 
793: 
794: Note that if x=11\ldots 11, then \alpha_{x}=\sigma in the lemma above.
795: 
796: 
797: 
798: 
799: 
800: The following result is a kind of generalization of Lemma 2.2 in the presence of an involutory fixed point free
801: permutation automorphism. By
802: Proposition 3.1, there is no binary linear code with length 4 and dimension 3
803: whose permutation automorphism group is isomorphic to C_{2}. Note also
804: that \mathrm{PAut}({\mathbb{F}}_{2}^{4})=S_{4}. As a consequence of these, the result below
805: is concerned with codes of length at least 6.
806: 
807: 
808: 
809: Theorem 4.3.
810: 
811: 
812: 
813: Suppose that C is a binary linear code of dimension k\geq 3 and length n=2m with m\geq 3
814: such that \mathrm{PAut}(C)=\langle\sigma\rangle for \sigma=(1,2)(3,4)\ldots(n-1,n),
815: then \mathrm{dim}(F_{\sigma}(C))\neq k-1 so that \lceil k/2\rceil\leq\mathrm{dim}(F_{\sigma}(C))\leq k-2. In particular,
816: k\neq 3 or equivalently there is no 3-dimensional linear code C of even length with the
817: property that \mathrm{PAut}(C)=\langle\sigma\rangle.
818: 
819: 
820: 
821: 
822: Proof.
823: 
824: 
825: 
826: By Lemma 2.2, it is enough to show that F_{\sigma}(C) can not be (k-1)-dimensional. Suppose to the contrary that
827: F_{\sigma}(C) is (k-1)-dimensional. Let w\in C\backslash F_{\sigma}(C), then w^{\sigma}\neq w and
828: w+w^{\sigma}\in F_{\sigma}(C).
829: 
830: 
831: 
832: 
833: If for some odd i, w_{i}=w_{i+1} then the transposition (i,i+1) fixes w as well as any element of F_{\sigma}(C).
834: Moreover, since F_{\sigma}(C) is
835: (k-1)-dimensional any element of C can be written as \lambda_{1}w+\lambda_{2}c where c\in F_{\sigma}(C)
836: and \lambda_{1},\lambda_{2}\in{\mathbb{F}}_{2}.
837: Hence, (i,i+1) fixes every element of C, that is \mathrm{PAut}(C)\neq\langle\sigma\rangle, a contradiction.
838: 
839: 
840: 
841: 
842: Hence, for all odd i\in\{1,2,\ldots,n\}, w_{i}\neq w_{i+1}, and it follows that
843: 
844: 
845: 
846: 
847: (w+w^{\sigma})_{i}=(w+w^{\sigma})_{i+1}=w_{i}+w_{i+1}=1,
848: 
849: 
850: 
851: that is w+w^{\sigma}=y=(11\ldots 11).
852: Now, since \mathrm{dim}(F_{\sigma}(C))=k-1\geq 2, there is a non-zero element x\in F_{\sigma}(C)
853: such that x\neq y, so x\neq(11\ldots 11). Then T_{x} is non-empty, since x is a non-zero
854: element of F_{\sigma}(C).
855: Also since x\neq(11\ldots 11), we have that T_{x} is strictly contained T_{y} and hence the permutation
856: 
857: 
858: 
859: 
860: \alpha_{x}=\Pi_{i\in T_{x}}(i,i+1)
861: 
862: 
863: 
864: is an involution in S_{n} which is different from \sigma. Hence, from Lemma 4.1, we
865: have that w^{\alpha_{x}}=w+x. Since any element of C
866: can be written as \lambda_{1}w+\lambda_{2}c where
867: c\in F_{\sigma}(C) and \lambda_{1},\lambda_{2}\in{\mathbb{F}}_{2} and
868: that \alpha_{x} fixes any element of F_{\sigma}(C), we deduce
869: that \alpha_{x}\in\mathrm{PAut}(C), which contradicts with the fact that \mathrm{PAut}(C)=\langle\sigma\rangle.
870: This finishes the proof.
871: ∎

877: 
878: 
879: 
880: There is no 4-dimensional binary linear code C of length n=2m with the property that \mathrm{PAut}(C)=\langle\sigma\rangle where \sigma=(1,2)(3,4)\ldots(n-1,n).
881:

890: If n=4, we have that C={\mathbb{F}}_{2}^{4} and \mathrm{PAut}(C)=S_{4}, so we have that n=2m\geq 6.
891: Furthermore, by Theorem 4.3, we have that \mathrm{dim}(F_{\sigma}(C))=2. Let \{x,y\} be a basis for F_{\sigma}(C) and extend it to a basis
892: 
893:

895: 
896: {\mathcal{B}}=\{x,y,w,u\}
897: 
898: 
899: 
900: of C. Then w+w^{\sigma} and u+u^{\sigma} lie in F_{\sigma}(C). If w+w^{\sigma}=u+u^{\sigma}, then we have that
901: w+u\in F_{\sigma}(C)\cap\langle w,u\rangle=\{0\}, which implies that w=u. So we have that w+w^{\sigma}\neq u+u^{\sigma}.
902: Hence without loss of generality, assume that w+w^{\sigma}=x and u+u^{\sigma}=y. Then
903: i\in T_{x} if and only if w_{i}\neq w_{i+1}. Similarly, i\in T_{y} if and only if u_{i}\neq u_{i+1}.
904: 
905: 
906:

915: 
916: 
917: 
918: \alpha=\Pi_{i\in T}(i,i+1).
919: 
920: 
921: 
922: Since T is non-empty and not equal to the set of all odd integers inside \{1,2,\ldots,n\},
923: \alpha is an involution different from \sigma and it fixes both x and y. Moreover,
924: 
925: 
926: 
927: 
928: (w^{\alpha})_{i}(w^{\alpha})_{i+1}=\begin{cases}w_{i+1}w_{i}&\text{ if }i\in T\\
929: w_{i}w_{i+1}&\text{ if }i\not\in T\end{cases}.

931: 
932:

935: 
936: 
937:

940: w_{i}w_{i+1}&\text{ if }i\not\in T\end{cases}.

942: 
943:

950: Case 2: Assume that T is equal to the set of all odd integers inside \{1,2,\ldots,n\}.

953:

957: sets are empty then T_{x}=T_{y} which is not possible). Without loss

959:

972: 
973:

975:

979:

1110: \alpha=\big(\prod_{i\in T_{y}\backslash T_{x}}(i,i+1)\big)(k_{1},l_{1})(\sigma(k_{1}),\sigma(l_{1})).
1111: 
1112: 
1113: 
1114: It is easy to see that \alpha is a non-trivial involution which is different from \sigma.
1115: Moreover, \alpha fixes x and y.
1116: Since w_{i}=w_{i+1} for all i\in T_{y}\backslash T_{x}, it is easy to see that \alpha fixes w.
1117: For any odd r, we have that
1118: 
1119: 
1120: 
1121: 
1122: (u^{\alpha})_{r}(u^{\alpha})_{r+1}=\begin{cases}u_{r+1}u_{r}&\text{ if }r\in T_{y}\backslash T_{x}\\
1123: u_{r}u_{r+1}&\text{ if }r\in T_{x}\cap T_{y}\\
1124: u_{l}u_{l+1}=u_{l+1}u_{l}&\text{ if }r=k\\
1125: u_{k}u_{k+1}=u_{k+1}u_{k}&\text{ if }r=l\end{cases}.
1126: 
1127: 
1128: 
1129: Note that for odd r, we have that (x+y)_{r}(x+y)_{r+1}=00 if and only if r\in T_{x}\cap T_{y}. Also
1130: for r\in T_{y}\backslash T_{x}, we have that u_{r}\neq u_{r+1} and u_{k}u_{k+1}+11=u_{l}u_{l+1}
1131: since u_{k}u_{k+1}\neq u_{l}u_{l+1}. As a result, we have that
1132: 
1133: 
1134: 
1135: 
1136: (u+x+y)_{r}(u+x+y)_{r+1}=\begin{cases}u_{r+1}u_{r}&\text{ if }r\in T_{y}\backslash T_{x}\\
1137: u_{r}u_{r+1}&\text{ if }r\in T_{x}\cap T_{y}\\
1138: u_{l}u_{l+1}&\text{ if }r=k\\
1139: u_{k}u_{k+1}&\text{ if }r=l\end{cases}.
1140: 
1141: 
1142: 
1143: Hence, we deduce that u^{\alpha}=u+x+y and it follows that \alpha\in\mathrm{PAut}(C). However,
1144: \alpha is an involution different from \sigma so we have a contradiction. 
1145: 
1146: 
1147: 
1148: 
1149: 
1150: Since we get a contradiction in all possible cases, the proof is finished.
1151: ∎

1157: 
1158: 
1159: 
1160: There is no binary linear code C of dimension k and length n=2m with m\geq 2
1161: such that \mathrm{PAut}(C)=\langle\sigma\rangle where
1162: k=i or k=n-i for i\in\{1,2,3,4\} and \sigma=(1,2)(3,4)\ldots(n-1,n).
1163: 
1164: 
1165: 
1166: 
1167: Proof.
1168: 
1169: 
1170: 
1171: Follows from Proposition 3.1, Theorem 3.2, Theorem 4.3 and
1172: Theorem 4.4 since \mathrm{PAut}(C)=\mathrm{PAut}(C^{\perp}) and \mathrm{dim}(C)=n-\mathrm{dim}(C^{\perp}).
1173: ∎

1179: 
1180: 
1181:

1189: Proof.
1190: 
1191: 
1192: 
1193: Suppose that C is a binary quasi group code such that \mathrm{PAut}(C)\cong C_{2}.
1194: Then \mathrm{PAut}(C)=\langle\gamma\rangle where \gamma is a fixed point free involution in S_{n}.
1195: Then \gamma and \sigma are conjugate elements of S_{n}, that is \sigma=\beta^{-1}\gamma\beta for some \beta\in S_{n}.
1196: Let C_{1}=C^{\beta}, then \mathrm{PAut}(C_{1})=\langle\sigma\rangle. But then Corollary 4.5 gives us a contradiction.
1197: ∎

1258: 5. A generalization and an application to some putative extremal self-dual binary codes
1259: 
1260: 
1261: 
1262: 
1263: In this section, we present a generalization of the ideas that are used in the proof of Theorem 4.4. By applying
1264: this generalization to the putative extremal self-dual binary [72,36,16] code and putative extremal self-dual binary
1265: [96,48,20] code, we obtain results concerning the structure of these codes.
1266: 
1267: 
1268: 
1269: 
1270: Let C be a binary linear code of length n=2m and \sigma=(1,2)(3,4)\ldots(n-1,n)\in\mathrm{PAut}(C). We
1271: have that the fixed subcode F_{\sigma}(C) is a subcode of C. So there
1272: is a subcode N_{\sigma}(C) such that
1273: 
1274: 
1275: 
1276: 
1277: C=F_{\sigma}(C)\oplus N_{\sigma}(C).
1278: 
1279: 
1280: 
1281: Let \{w_{(1)},\ldots,w_{(k-f)}\} be a basis of N_{\sigma}(C) where k=\mathrm{dim}(C) and f=\mathrm{dim}(F_{\sigma}(C)).
1282: Then by Lemma 2.1, we have that f\geq(k-f). On the other hand, by the proof of Lemma 2.1,
1283: there is a linearly independent subset \{x_{(1)},\ldots,x_{(k-f)}\} of F_{\sigma}(C) where x_{(j)}=w_{(j)}+w_{(j)}^{\sigma}
1284: for j=1,\ldots,k-f. Now extend \{x_{(1)},\ldots,x_{(k-f)}\} to a basis \{x_{(1)},\ldots,x_{(f)}\} of F_{\sigma}(C).
1285: Set
1286: 
1287: 
1288: 
1289: 
1290: T(\sigma):=T_{x_{(1)}}\cup T_{x_{(2)}}\cup\ldots\cup T_{x_{(k-f)}}
1291: 
1292: 
1293: 
1294: where T_{x_{(j)}} is defined as in Section 4.
1295: Then note that if i\not\in T(\sigma) then (x_{(j)})_{i}(x_{(j)})_{i+1}=00 for any j=1,\ldots,k-f. So if i\not\in T(\sigma)
1296: the equation x_{(j)}=w_{(j)}+w_{(j)}^{\sigma} implies that (w_{(j)})_{i}=(w_{(j)})_{i+1} for any j=1,\ldots,k-f.
1297: 
1298: 
1299: 
1300: Theorem 5.1.
1301: 
1302: 
1303: 
1304: Let C be a binary linear code of length n=2m where m\geq 2
1305: such that \sigma=(1,2)(3,4)\ldots(n-1,n)\in\mathrm{PAut}(C). Suppose that T(\sigma)\neq\{1,3,\ldots,n-1\}.
1306: Then we have that \mathrm{PAut}(C)\neq\langle\sigma\rangle. In particular, \mathrm{PAut}(C) has automorphisms which have some fixed points and
1307: that C_{2}\times C_{2}\leq\mathrm{PAut}(C).
1308: 
1309: 
1310: 
1311: 
1312: Proof.
1313: 
1314: 
1315: 
1316: Let C be a binary linear code of dimension k. Let \beta=\Pi_{i\not\in T_{\sigma}}(i,i+1).
1317: Since T(\sigma)\neq\{1,3,\ldots,n-1\}, the permutation \beta is a non-trivial involution.
1318: Also if i\not\in T_{\beta} then (x_{(j)})_{i}(x_{(j)})_{i+1}=00 and
1319: (w_{(j)})_{i}=(w_{(j)})_{i+1}for any j=1,\ldots,k-f . Hence \beta
1320: fixes all elements in F_{\sigma}(C) and N_{\sigma}(C) so it lies inside
1321: \mathrm{PAut}(C). It is clear that \beta has some fixed points and \langle\sigma,\beta\rangle\cong C_{2}\times C_{2}
1322: ∎

1327: Corollary 5.2.
1328: 
1329: 
1330: 
1331: Let C be a binary self-dual [72,36,16] code. If \sigma=(1,2)(3,4)\ldots(71,72)\in\mathrm{PAut}(C), then T(\sigma) is
1332: equal to the set of all odd integers between 1 and 71.
1333: 
1334: 
1335: 
1336: 
1337: Proof.
1338: 
1339: 
1340:

1342: in \mathrm{PAut}(C) which is not fixed point free. But this contradicts with [2, Theorem 5.3]. So T_{\sigma}=\{1,3,\ldots,71\}.
