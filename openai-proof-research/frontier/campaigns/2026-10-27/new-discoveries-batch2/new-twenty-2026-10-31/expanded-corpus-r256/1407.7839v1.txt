Definition 2.4. Let Q be a cyclic quadratic form in m variables.
   (1) We say that Q is balanced if Condition (r) holds for every r (mod m).
   (2) We say that Q is weakly balanced if when restricted to xi ∈ {0, 1} Condi-
       tion (r ) holds for all r = 1, . . . , m − 1.
          Equivalently, Q is weakly balanced if and only if for all r = 1, . . . , m −
       1, the leading principal r × r minor of Q has the minimal sum of entries
       among all principal r × r minors.
   (3) We say that Q is `-balanced if when restricted to 0 ≤ xi ≤ ` Condition (r )
       holds for all r (mod m). Thus, 1-balanced forms are weakly balanced
       and ∞-balanced forms are balanced.
Remark 2.5. Suppose Q is a positive definite cyclic quadratic form. Then bal-
ancedness of Q can be algorithmically verified by:
  (1) Finding all vectors v such that Q(v) ≤ max{ Q(vr ) | r = 0, . . . , m − 1}.
  (2) Testing whether the found vectors violate Conditions (n).
  For an arbitrary quadratic form Q in m variables, it is possible to determine
whether Q is `-balanced by a direct evaluation of Q at all integer points of the
hypercube [0, `]m .

Definition 3.1. Let G be a finite abelian group (with addition). We say that a
symmetric function f : G → Q is F-nef if for any a, b, c ∈ G we have
(3.1)      f ( a ) + f ( b ) + f ( c ) + f ( a + b + c ) ≥ f ( a + b ) + f ( a + c ) + f ( b + c ).
3.1. First properties. For an arbitrary f : G → Q, we define d f : G × G → Q by
d f ( a, b) = f ( a) + f (b) − f ( a + b). Then (3.1) is equivalent to subadditivity of d f
in each variable:
(3.2)                         d f ( a, b) + d f ( a, c) ≥ d f ( a, b + c).
Lemma 3.2. Suppose f : G → Q is F-nef. Then d f is non-negative, and hence f is
subadditive. Namely, for any a, b ∈ G, we have
                                    f ( a ) + f ( b ) ≥ f ( a + b ).
Proof. Take a positive integer N so that Nb = 0. Applying (3.2), we obtain

Definition 4.2. We say that an F-nef function f : G → Q is effective with respect
to the degree function d : Pn → G if there exists a Q-weighting on Pn such that:
    (1) The flow through the vertex i ∈ Pn is f (d(i )).
    (2) The flow across each proper partition I t J = Pn is at least f (d( I )).
We say that f : G → Z is strongly effective with respect to the degree function
d : Pn → G if there exists a Z-weighting on Pn satisfying (1–2) and
    (3) The flow across each contiguous partition I t J = Pn is exactly f (d( I )).
An F-nef function f : G → Q (resp., f : G → Z) that is effective (resp., strongly
effective) with respect to all degree functions d : Pn → G, for all possible n, is
called effective (resp., strongly effective).

Remark 4.3. Suppose f is an F-nef function with f (0) = 0. Then by subadditiv-
ity of f (Lemma 3.2), to check effectivity of f , it suffices to consider only degree
functions d : Pn → G for which there is no S ( Pn satisfying ∑i∈S d(i ) = 0 ∈ G.
In this case, for a given group G, there are only finitely many n and degree
functions to check. However, because edge weights are allowed to be arbitrary
rational numbers, we do not know an algorithm for checking effectivity of f
even with respect to a fixed degree function d : Pn → G.

Proposition 6.1 (char = 0). Suppose D is a non-zero F-nef divisor on M0,n which can
be written as D = L + N, where L is log terminal (resp., log canonical) and N is a nef

D is nef by [KM13, Theorem 1.2.2]. Recalling that a non-zero symmetric nef
divisor on M0,n is necessarily big (see [KM13, Theorem 1.3.2]), we apply the

D is semiample. This establishes the first part of the proposition.
   Let C be the open convex cone in NS( M0,n )Sn generated by divisors of the

F be the (closed and convex) symmetric F-nef cone of M0,n . We have already
established that C ∩ F ⊂ Nef( M0,n )Sn . Since C ∩ F is a full-dimensional convex
cone inside NS( M0,n )Sn , we conclude that C ∩ F = C ∩ F ⊂ Nef( M0,n )Sn . The
remaining part of the proposition follows.
