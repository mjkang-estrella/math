# Third investigated route: 330708

The actual2015v1 Definition8 uses rightmost representatives of embeddings modulo adjacency shifts. EZ consists of sets of such embeddings whose zero sets have empty intersection. These are not merely the normal embeddings, despite the MathDB shorthand. Source v1 Proposition33 claims a general context-extension formula, and v1 Conjecture35 states the multi-run product. Its proof tries to restrict each embedding to a selected component run and sign-sum over extension fibers. The revised2017v3 Proposition32 proves only the pure repeated-component case; Proposition33 imposes the extra single-interval hypothesis for prepending an indecomposable component, Proposition34 uses noncontainment, and Conjecture35 is now a different assertion. Those actual revised proof bodies are a specific limitation, not metadata-only evidence.

Route1: replace each run by a truncated Boolean lattice and take a product. For embeddings choosing whole equal indecomposable components without crossing run boundaries, a crosscut argument suggests the displayed binomial product with the global sign. This does not cover all pattern embeddings: an indecomposable component may occur inside a different larger component, and smaller component groups may share a larger target component. No source definition forbids this.

Route2: use signed fibers to cancel every noncanonical placement. If an embedding has r possible extensions, choosing a nonempty subset has alternating sum -1, so multiplicative cancellation works only after proving every EZ-cover has a restriction in the claimed base EZ family and that extension fibers partition it. This is precisely the unpaid surjectivity assertion, not a binomial identity. The v3 proof obtains a forced covered letter from the 'single' hypothesis. The full literal omits this hypothesis. We cannot drop it by assuming whole-component embeddings.

Route3: restrict to equal-size incomparable component types. Then cross-type occurrences may be ruled out, potentially yielding a product subfamily proof; however the original literal allows arbitrary runs and these special hypotheses would only solve an instance/helper. Boundary ell_i=0 or lambda=pi issues could also produce convention disputes rather than meaningful resolution. None is credited. Figure3 truncated Boolean diagrams were not visually inspected; no conclusion depends on them. Exact full-scope cancellation lemma remains unpaid; no formal dispatch.
