## 344084: duality of strongly pigeonhole classes

Exact endpoint: for every class C of finite matroids satisfying Definition 2.10 of Funk–Mayhew–Newman I, the class {M*: M in C} satisfies the same definition. This is Conjecture 5.4 (also 7.12), retained in the acquired Algorithmica 2022 final body (sources/matroid-final.pdf.txt, 908–913 and 1952–1957). The cached MathDB statement is preserved literally in raw-provenance.json.

Fix finite M on E=U disjoint-union V. Write r=r(M), a=r_M(U), b=r_M(V), k=a+b-r. Let q be the number of independence-extension equivalence classes of subsets of U: X~X' iff for every Y subset V, X union Y independent iff X' union Y independent. We may retain just the classes containing independent sets; there are at most q. Each such class consists entirely of independent sets by testing Y=empty.

For A subset U define its profile at independent class j as follows. Consider all independent X subset A in class j. Take the smallest deficit a-|X| among them, but replace it by the single symbol infinity if no such X exists or if all such deficits exceed k. Each profile coordinate has at most k+2 values (0,...,k,infinity). All minima exist when the relevant set is nonempty, since E is finite. The number of profiles is at most (k+2)^q.

Claim: equal profiles of A,A' imply that A union B spans M iff A' union B spans M, for EVERY B subset V. Suppose A union B spans and take a basis D contained in it. Put X=D intersection U and Y=D intersection V. Then |X|+|Y|=r and |Y|<=b, so a-|X|<=a+b-r=k. Let j be the class of X. A minimal-deficit X' subset A' in class j has |X'|>=|X|, since profiles agree. X' union Y is independent by the definition of j. Its size is >=r, hence exactly r (an independent subset cannot exceed r). It is a basis contained in A' union B, proving spanning. Reverse A,A' for the converse. No assumption on representability, connectivity, simplicity, loops, coloops, or positive rank was made.

A subset S of E is independent in M* iff E minus S spans M. Indeed, a dual independent set extends to a dual basis, whose complement is a primal basis disjoint from S; conversely a primal basis in E minus S has complementary dual basis containing S. For S subset U and Z subset V, put A=U minus S and B=V minus Z. Thus equal profiles for U minus S and U minus S' imply S~_{M*,U}S'. Consequently q(M*,U)<=(k+2)^q(M,U).

Duality preserves the cut connectivity k: using r_{M*}(W)=|W|-r+r_M(E minus W) on U and V, subtract r(M*)=|E|-r to obtain a+b-r. If C has bound pi(lambda) and k<=lambda, therefore q(M*,U)<=(lambda+2)^pi(lambda). This positive integer function witnesses the strongly pigeonhole property, including k=0 and empty cuts. Dependent subsets of M* are automatically accommodated by the complement profile argument. This pays the exact full class quantifier.

A weaker first shortcut was inadequate: independence in M* is NOT the negation of independence in M. Likewise the source's Corollary 5.3 only controls cuts in selected bounded-width decomposition trees. The profile proof works at every prescribed cut and controls the formerly unbounded cardinality information by the interval [a-k,a].

## 343790: explicit reduced code counterexample

Literal 2019 Conjecture 1 (sources/1909.05143.pdf.txt 689–690): representations V1,V2 of a single code loop L with equal degree and type must be isomorphic as binary codes under a coordinate permutation. Definitions at lines 84–85,168–186 require doubly even codes, reduced coordinate equivalence classes of size <8, and type equal to the sorted list of those class sizes. They do NOT require minimal degree in the conjecture itself. A minimal-only reading is a different endpoint.

Let W=F2^4 with basis e1,e2,e3,e4. Define seven-element sets
H1=span(e1,e2,e3) minus {0};
H2={e4,e4+e1,e4+e2,e4+e1+e2,e1,e3,e1+e3}.
The first four elements of H2 form an affine plane, the last three a disjoint line minus zero. Each block sums to zero, so sum(H1)=sum(H2)=0. H1 spans a hyperplane; H2 spans all W, since its first four elements span e1,e2,e4 and its last three include e3. All seven elements in each set are distinct and nonzero.

For i=1,2 form the coordinate set Omega_i={(a,t):0!=a in W,1<=t<=1+4*1_{a in H_i}}. Define the linear evaluation code C_i={c_i(x):x in W}, with c_i(x)_(a,t)=x dot a. This is a complete constructive specification of each generator matrix: its four rows are the coordinate functions of a, with each nonzero column a repeated once or five times. No generator search or enumeration is needed. Length=15+4*7=43. Evaluation is injective since all four unit columns occur, so dimension=4. Distinct a give distinct coordinate functionals on the whole code; hence coordinate equivalence classes are precisely the column blocks. Type is eight 1s and seven 5s; both are reduced and have no unused coordinates.

For nonzero x, exactly eight nonzero a have x dot a=1. Put h_i(x)=#{a in H_i:x dot a=1}. Because sum H_i=0, h_i(x) is even. Thus wt(c_i(x))=8+4h_i(x) is divisible by 8. All codewords are triply even, in particular doubly even. The identity wt(u+v)=wt(u)+wt(v)-2|u intersection v| implies intersections are divisible by 4. Triple intersections are even: in the unreplicated simplex coordinates, simultaneous three linear equations equal to 1 have either 0 or 2^(4-d) solutions with d<=3, hence even; each replicated contribution adds four copies. Therefore the constant factor set phi=1 satisfies ALL four source factor-set identities. L(C_i) is explicitly the common elementary abelian group {+1,-1} times W. The map (epsilon,c_1(x)) -> (epsilon,c_2(x)) is a multiplicative bijection; no unproved classification inference is used.

C1 and C2 are not permutation equivalent. The nonzero normal functional x=e4 annihilates H1, producing a word of weight 8 in C1. Every nonzero functional is nonzero on some element of H2 since H2 spans W; its h_2(x) is positive even, so every nonzero C2 word has weight at least 16. Coordinate permutations preserve weights.

To pay even a nonassociative interpretation, take a common disjoint summand S, the rank-three binary simplex code with seven coordinates indexed by nonzero a in F2^3, and nonzero words of weight 4. Set D_i=C_i direct-sum S, length 50, dimension 7, type fifteen 1s and seven 5s, again reduced with no unused coordinates. The source's rank-three minimal C_1^3 representation is exactly this simplex code (2019 Theorem 3). An entirely explicit factor set for S is (-1)^f, where over F2
f(x,y)=sum_i x_i*y_i + sum_{i<j} x_i*y_j
       + x1*x2*y3 + x1*x3*y2 + x2*x3*y1.
Its diagonal is q(x)=x1+x2+x3+x1x2+x1x3+x2x3+x1x2x3, equal to 1 for x!=0 and 0 for x=0: q=1+(1+x1)(1+x2)(1+x3). Expanding f(x,y)+f(y,x) gives q(x+y)+q(x)+q(y), the intersection-half parity from the weight identity. Expanding its coboundary gives the sum of the six permutations x_i*y_j*z_k, which is exactly parity of triple intersections of the simplex words: summing (x dot a)(y dot a)(z dot a) over all a, only the monomial a1*a2*a3 survives. Hence this factor set obeys the source identities. It is nonassociative since that determinant is 1 for x=e1,y=e2,z=e3.

Use this same factor set on S and the constant factor set on C_i, with product factor set independent of the C_i inputs. Disjoint supports split weights and intersections, so every source identity is paid. The map (epsilon,c_1(x),s)->(epsilon,c_2(x),s) is an explicit isomorphism of the common nonassociative code loops. D1 has a weight-8 word from C1; D2 has none, since its word weights are 0 or 4 on S plus either 0 or >=16 on C2. Thus even these nonassociative representations are not permutation equivalent. The witness is nonminimal, but the literal conjecture does not assume minimality; it is not a zero-coordinate, non-reduced, or associative-only defect.
