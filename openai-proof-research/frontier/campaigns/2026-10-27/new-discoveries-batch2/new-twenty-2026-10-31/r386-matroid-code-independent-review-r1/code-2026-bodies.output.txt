5:                                                  Abstract. Code loops are Moufang loops constructed from doubly even binary codes.
6:                                                  Then, given a code loop L, we ask which doubly even binary code V produces L. In
7:                                                  this sense, V is called a representation of L. In this article we define and show how
8:                                                  to determine all minimal and reduced representations of nonassociative code loops of
9:                                                  rank 3 and 4.

15:                                                                                  1. Introduction
16:                                              Code loops were introduced by Robert Griess [2] from doubly even binary codes as
17:                                           follows.
18:                                              Let K = F2 = {0, 1} be a field with two elements and K n be an n-dimensional
19:                                           vector space over K. Let u = (u1 , . . . , un ) and v = (v1 , . . . , vn ) in K n and define
20:                                           |v| = |{i | vi = 1}| (the Hamming weight) and |u ∩ v| = |{i | ui = vi = 1}|. A doubly
21:                                           even binary code is a subspace V ⊆ K n such that |v| ≡ 0 (mod 4).
22:                                              Let V be a doubly even binary code and the function ϕ : V × V → {1, −1}, called
23:                                           factor set, defined by:

29:                                                                    ϕ(0, v) = ϕ(v, 0) = 1,
30:                                                               ϕ(v + w, u) = ϕ(v, w + u)ϕ(v, w)ϕ(w, u)(−1)|v∩w∩u| .
31:                                             In order to define a code loop, let V be a doubly even binary code and
32:                                           ϕ : V × V → {1, −1} be a factor set. Consider the set L(V ) = {1, −1} × V and
33:                                           define a product ‘·’ in L(V ) in the following way
34:                                                                            v.w = ϕ(v, w)(v + w),
35:                                                                            v.(−w) = (−v).w = −(v.w).
36:                                              With this product, we obtain a Moufang loop called code loop. Equivalently, a Mo-
37:                                           ufang loop L such that L/A is an elementary abelian 2-group for some central subgroup
38:                                           A of order 2 is called a code loop. We say that L(V ) has rank m if the dimension of
39:                                           the K-vector space V is equal to m. Note that v ∈ L(V ) and −v ∈ L(V ) mean the
40:                                           elements (1, v) and (−1, v), respectively.

64:    So far, we’ve shown how to construct code loops from doubly even binary codes, but
65: we would like to investigate the other direction. In other words, given a certain code
66: loop L, we would like to determine the doubly even codes V such that L ≃ L(V ).
67:    A representation of a given code loop L is a doubly even binary code V ⊆ K m such
68: that L ≃ L(V ) and the number m is called the degree of the representation. So the
69: degree of the representation is the length of the code. We notice that there are many
70: different representations for the same code loop. When necessary, we denote the degree
71: of V by deg(V ).
72:    In this article we determine all minimal representations of nonassociative code loops
73: of rank 3 and 4 (Sections 3 and 4). We will also show how to determine reduced rep-
74: resentations. In order to do this, first, it is necessary to know all these code loops, up
75: to isomorphism. In [3], these code loops were classified using the concept of charac-
76: teristic vector associated with them. We recall the main theorems of classification of
77: nonassociative code loops of rank 3 and 4 in Section 2.
78:                      2. Nonassociative Code Loops of Rank 3 and 4
79:   Let L be a code loop with generator set X = {x1 , . . . , xn } and center {1, −1}. Then
80: we define the characteristic vector of L, denoted by λX (L) or λ(L), by
81:         λ(L) = (λ1 , . . . , λn ; λ12 , . . . , λ1n , . . . , λ(n−1)n ; λ123 , . . . , λ12n , . . . , λ(n−2)(n−1)n ),
82: where λi , λij , λijk ∈ F2 , (−1)λi = x2i , (−1)λij = [xi , xj ] and (−1)λijk = (xi , xj , xk ).
83:    Here, [x, y] denotes the commutator of x and y, and (x, y, z) denotes the associator
84: of x, y and z. The center of a loop L, denoted by Z(L), is the set
85:                           Z(L) = {x ∈ L | [x, y] = (x, y, z) = 1, ∀y, z ∈ L}.
86:    Once a generating set X is fixed, we obtain a unique characteristic vector λX (L),
87: which depends on the choice of the elements in X and on the order of its elements.
88: Different minimal generating sets may produce different characteristic vectors for the
89: same code loop, as illustrated by the following example:
90:    Let L = Z2 × Z4 = {0, 1} × {0, 1, 2, 3} and let Z = {(0, 0), (0, 2)}. Then Z ≤ Z(L)
91: (since L is an abelian group), and L/Z is the Klein group, so L is a code loop of
92: rank 2. We can consider various (ordered) minimal generating subsets of L. With
93: X = (a, b) = ((0, 1), (1, 0)) we obtain a + a = (0, 2) and b + b = (0, 0), while with
94: X ′ = (a′ , b′ ) = ((0, 1), (1, 1)) we obtain a′ + a′ = (0, 2) and b′ + b′ = (0, 2). Note that
95: b has order 2, while b′ has order 4, so the characteristic vectors associated with each
96: generating set are different.
