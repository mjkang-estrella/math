20:                                           Abstract
21:                                           Code loops are Moufang loops constructed from doubly even binary codes.
22:                                           Then, given a code loop L, we ask which doubly even binary code V produces
23:                                           L. In this sense, V is called a representation of L. In this article we define
24:                                           and determine all minimal and reduced representations of nonassociative
25:                                           code loops of rank 3 and 4.
26:                                           Keywords: binary codes, code loops, characteristic vectors, representations.
27: 
28: 
29:                                           1. Introduction
30:                                               Code loops were introduced by Robert Griess (1986, [2]) from doubly
31:                                           even binary codes as follows.
32:                                               Let K = F2 = {0, 1} be a field with two elements and K n be an n-
33:                                           dimensional vector space over K. Let u = (u1 , . . . , un ) and v = (v1 , . . . , vn )
34:                                           in K n and define |v| = |{i | vi = 1}| (the Hamming weight) and |u ∩ v| =
35:                                           |{i | ui = vi = 1}|. A doubly even binary code is a subspace V ⊆ K n such
36:                                           that |v| ≡ 0 (mod 4).

56:     In order to define a code loop, let V be a doubly even code and φ :
57: V × V → {1, −1} be a factor set. Consider the cartesian product L(V ) =
58: {1, −1} × V and define a product ‘·′ in L(V ) in the following way
59: 
60:                         v.w = φ(v, w)(v + w),
61:                         v.(−w) = (−v).w = −(v.w),
62:                         (−v).(−w) = v.w.
63: 
64:    With this product, we obtain a Moufang loop called code loop. We say
65: that L(V ) has rank m, if the dimension of the K-vector space V is igual
66: to m. Note that v ∈ L(V ) and −v ∈ L(V ) means the elements (1, v) and
67: (−1, v), respectively.
68:    It’s important to recall that code loops have some useful properties related
69: to the commutator, associator, and square associated with their elements
70: that we will use to get the main results presented in this article. Chein and
71: Goodaire (1990, [1]) proved that code loops have a unique nonidentity square,
72: a unique nonidentity commutator, and a unique nonidentity associator. In
73: other words, for any u, v, w ∈ V :

80:     So far we’ve shown how to build code loops from doubly even binary
81: codes, but we would like to investigate to the other side. In other words,
82: given a certain code loop L, we would like to determine the doubly even
83: codes V such that L ≃ L(V ).
84:     A representation of a given code loop L is a doubly even code V ⊆ K m
85: such that L ≃ L(V ) and the number m is called degree of the representation.
86: We notice that there are many different representations for a same code loop.

91: nonassociative code loops of rank 3 and 4 (Sections 3 and 4). In order to do
92: this, first, it is necessary to know all these code loops, up to isomorphism.
93: In [3], these code loops were classified using the concept of a characteristic
94: vector associated with them. We recall the main theorems of classification
95: of nonassociative code loops of rank 3 and 4 in Section 2.

97: 2. Nonassociative Code Loops of Rank 3 and 4
98:     Let L be a code loop with generator set X = {x1 , . . . , xn } and center
99: {1, −1}. Then we define the characteristic vector of L, denoted by λX (L) or
100: λ(L), by
101: 
102: λ(L) = (λ1 , . . . , λn ; λ12 , . . . , λ1n , . . . , λ(n−1)n ; λ123 , . . . , λ12n , . . . , λ(n−2)(n−1)n ),
103: 
104: where λi , λij , λijk ∈ F2 , (−1)λi = x2i , (−1)λij = [xi , xj ] and (−1)λijk =
105: (xi , xj , xk ).
106:      Here, [x, y] denotes the commutator of x and y, and (x, y, z) denotes the
107: associator of x, y and z.
108:      Let L be a nonassociative code loop of rank 3 with generators a, b, c.
109: Then the associator (a, b, c) is equal to −1. The characteristic vector associ-
110: ated to L is given by λ(L) = (λ1 , ..., λ6 ) (or simply λ(L) = (λ1 ...λ6 )) where
111: a2 = (−1)λ1 , b2 = (−1)λ2 , c2 = (−1)λ3 , [a, b] = (−1)λ4 , [a, c] = (−1)λ5 and
112: [b, c] = (−1)λ6 .

162: 3. Representations of Code Loops
163:     We proved by Theorems 3 and 4 below that, there are representations
164: of nonassociatives code loops of rank 3 and 4 such that the degree of each
165: representation is the smallest possible.
166: Definition 1. A representation V is called minimal if the degree of V is
167: minimal.
168:     We identify the F2 -space Fm  2 as the set of all subsets of Im = {1, . . . , m}
169: and we define a relation of equivalence ∼ on Im : i ∼ j if and only if {i, j}∩v =
170: {i, j} or {i, j} ∩ v = ∅, for all v ∈ V .
171:     Note that this definition is equivalent to: i ∼ j if and only if {i, j} ∩ vk =
172: {i, j} or {i, j} ∩ vk = ∅, k = 1, . . . , s and {v1 , . . . , vs } is a basis of V .
173:     We will consider only representations such that, for any equivalence class
174: X, we have |X| < 8. We call these representations by reduced represen-
175: tations.
