23:                                                  Abstract. Hliněný’s Theorem shows that any sentence in the monadic
24:                                                  second-order logic of matroids can be tested in polynomial time, when
25:                                                  the input is limited to a class of F-representable matroids with bounded
26:                                                  branch-width (where F is a finite field). If each matroid in a class can
27:                                                  be decomposed by a subcubic tree in such a way that only a bounded
28:                                                  amount of information flows across displayed separations, then the class
29:                                                  has bounded decomposition-width. We introduce the pigeonhole prop-
30:                                                  erty for classes of matroids: if every subclass with bounded branch-
31:                                                  width also has bounded decomposition-width, then the class is pigeon-
32:                                                  hole. An efficiently pigeonhole class has a stronger property, involving an
33:                                                  efficiently-computable equivalence relation on subsets of the ground set.
34:                                                  We show that Hliněný’s Theorem extends to any efficiently pigeonhole
35:                                                  class. In a sequel paper, we use these ideas to extend Hliněný’s The-
36:                                                  orem to the classes of fundamental transversal matroids, lattice path
37:                                                  matroids, bicircular matroids, and H-gain-graphic matroids, where H is
38:                                                  any finite group. We also give a characterisation of the families of hy-
39:                                                  pergraphs that can be described via tree automata: a family is defined
40:                                                  by a tree automaton if and only if it has bounded decomposition-width.
41:                                                  Furthermore, we show that if a class of matroids has the pigeonhole
42:                                                  property, and can be defined in monadic second-order logic, then any
43:                                                  subclass with bounded branch-width has a decidable monadic second-
44:                                                  order theory.

53:                              1. Introduction
54:    The model-checking problem involves a class of structures and a logical
55: language capable of expressing statements about those structures. We con-
56: sider a sentence from the language. The goal is a procedure which will
57: decide whether or not the sentence is satisfied by a given structure from
58: the class. Our starting points are the model-checking meta-theorems due to
59: Courcelle [4] and Hliněný [15]. Courcelle’s Theorem proves that there is an
60: efficient model-testing procedure for any sentence in monadic second-order
61: logic, when the input class consists of graphs with bounded structural com-
62: plexity. Hliněný proves an analogue for matroids representable over finite
63: fields.
64:    Both theorems provide algorithms that are not only polynomial-time,
65: but fixed-parameter tractable (see [7]). This means that the input contains a
66: numerical parameter, λ. The notion of fixed-parameter tractability captures
67: the distinction between running times of order nf (λ) and those of order
68: f (λ)nc , where n is the size of the input, f (λ) is a value depending only on
69: λ, and c is a constant. When we restrict to a fixed value of λ, both running
70: times are polynomial with respect to n, but algorithms of the latter type

151: branch-width also has bounded decomposition-width, then M is pigeon-

153: property ([10, Theorem 7.2]). Other natural classes have an even stronger
154: property. Let M be a class of matroids. Assume there is a value, π(λ), for
155: every positive integer λ, such that the following holds: We let M be a ma-
156: troid in M, and we let U be a subset of E(M ). If λM (U ), the connectivity
157: of U , is at most λ, then ∼U has at most π(λ) equivalence classes. Un-

159: The matroids representable over a finite field ([10, Theorem 5.1]) and fun-
160: damental transversal matroids ([10, Theorem 6.3]) are strongly pigeonhole
161: classes. An efficiently pigeonhole class is strongly pigeonhole, and has the
162: additional property that we can efficiently compute a relation that refines
163: ∼U (Definition 6.4).
164:    Now we describe the structure of this article. Section 2 discusses
165: decomposition-width, pigeonhole classes, and strongly pigeonhole classes.
166: In Section 3 we describe the monadic logic CMS 0 . Section 4 develops the
167: necessary tree automaton ideas. Section 5 is dedicated to the proof of Theo-
168: rem 1.4. In Section 6 we prove Theorem 1.3. We also show that Theorem 1.3
169: holds under the weaker condition that the 3-connected matroids in M form
170: an efficiently pigeonhole class (Theorem 6.11). (However, we require that
171: we can efficiently compute a description of any minor of the input matroid,
172: so this is not a true strengthening of Theorem 1.3.) Theorem 6.11 is nec-
173: essary because we do not know that bicircular matroids or H-gain-graphic
174: matroids (with H finite) form efficiently pigeonhole classes. (Although we
175: conjecture this is the case [10, Conjecture 9.3].) However, we do know that
176: the subclasses consisting of 3-connected matroids are efficiently pigeonhole
177: ([10, Theorem 8.4]).
178:    In the final section (Section 7), we consider the question of decidability.
179: A class of set-systems has a decidable monadic second-order theory if there
180: is a Turing Machine (not time-constrained) which will take any sentence as
181: input, and decide whether it is satisfied by all systems in the class. The
182: main result of this section says that if a class of matroids has the pigeon-
183: hole property and can be defined by a sentence in monadic second-order
184: logic, then any subclass with bounded branch-width has a decidable theory
185: (Corollary 7.5). The special case of F-representable matroids (F finite) has
186: been noted by Hliněný and Seese [16, Corollary 5.3]. On the other hand, the
187: class of K-representable rank-3 matroids has an undecidable theory when K
188: is an infinite field (Corollary 7.7).

200:    Now we introduce one of our principal definitions. A class of set-systems
201: has bounded decomposition-width if those set-systems can be decomposed
202: by subcubic trees in such a way that only a bounded amount of information
203: flows across any of the displayed separations. This section is dedicated to
204: formalising these ideas.
205: Definition 2.1. A set-system is a pair (E, I) where E is a finite set and I is
206: a family of subsets of E. We refer to E as the ground set, and the members
207: of I as independent sets.
208:    In some circumstances, a set-system might be called a hypergraph and
209: the independent sets might be called hyperedges. We prefer more matroid-
210: oriented language.
211: Definition 2.2. Let (E, I) be a set-system, and let U be a subset of E. Let
212: X and X 0 be subsets of U . We say X and X 0 are equivalent (relative to U ),
213: written X ∼U X 0 , if for every subset Z ⊆ E − U , the set X ∪ Z is in I if
214: and only if X 0 ∪ Z is in I.
215:    Informally, we think of X ∼U X 0 as meaning that no subset of E − U
216: can ‘distinguish’ between X and X 0 . It is clear that ∼U is an equivalence
217: relation on subsets of U . Note that by taking Z to be the empty set, we
218: can see that no member of I is equivalent to a subset not in I. Assuming
219: that I is closed under subset containment (as would be the case if I were
220: the family of independent sets in a matroid), then all subsets of U that are
221: not in I are equivalent.
222: Proposition 2.3. Let (E, I) be a set-system and let U and V be disjoint
223: subsets of E. If X ∼U X 0 and Y ∼V Y 0 , then (X ∪ Y ) ∼(U ∪V ) (X 0 ∪ Y 0 ).
224: In particular, X ∪ Y belongs to I if and only if X 0 ∪ Y 0 does.

251:    A subcubic tree is one in which every vertex has degree three or one. A
252: degree-one vertex is a leaf. Let M = (E, I) be a set-system. A decomposition
253: of M is a pair (T, ϕ), where T is a subcubic tree, and ϕ is a bijection from
254: E into the set of leaves of T . Let e be an edge joining vertices u and v in
255: T . Then e partitions E into sets (Ue , Ve ) in the following way: an element
256: x ∈ E belongs to Ue if and only if the path in T from ϕ(x) to u does not
257: contain v. We say that the partition (Ue , Ve ) and the sets Ue and Ve are
258: displayed by the edge e. Define dw(M ; T, ϕ) to be the maximum number
259: of equivalence classes in ∼U , where the maximum is taken over all subsets,
260: U , displayed by an edge in T . Define dw(M ) to be the minimum value of
261: dw(M ; T, ϕ), where the minimum is taken over all decompositions (T, ϕ)
262: of M . This minimum is the decomposition-width of M . The notion of
263: decomposition-width specialises to matroids in the obvious way.
264: Definition 2.5. Let M be a matroid.               Then dw(M ) is equal to
265: dw(E(M ), I(M )).

860:   In this section, we discuss complexity theoretical applications of tree au-
861: tomata. We start with a simple observation.
862: Proposition 6.1. Let ψ be any sentence in CMS 0 . Let M be an automatic
863: class of set-systems. There exists a Turing Machine which will take as input
864: a parse tree for any set system M = (E, I) ∈ M and then test whether or
865: not M satisfies ψ. The running time is O(n), where n = |E|.
866: Proof. Since M is automatic, we can assume that A0 is an {i}-ary tree au-
867: tomaton with alphabet Σ, and for any M = (E, I) ∈ M there is a parse
868: tree (TM , σM ) of M relative to A0 . So there is a bijection ϕM : E → L(TM )
869: such that A0 accepts enc(TM , σM , ϕM , {Yi }) if and only if Yi ∈ I. The proof
870: of Lemma 4.7 is constructive, and shows us how to build an automaton, A,
871: which will accept enc(TM , σM , ϕM , ∅) if and only if M satisfies ψ. This con-
872: struction is done during pre-processing, so it has no impact on the running
873: time. While A processes enc(TM , σM , ϕM , ∅), the computation that occurs
874: at each node takes a constant amount of time. So the running time of A is
875: proportional to the number of nodes. This number is 2n − 1, so the result
876: follows.                                                                     

13:                                                    (BDDs) and zero-suppressed binary decision diagrams (ZDDs) as relatively compact data
