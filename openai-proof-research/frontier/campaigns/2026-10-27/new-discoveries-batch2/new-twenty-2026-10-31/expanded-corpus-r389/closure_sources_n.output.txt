55: Definition 1.1 (Determined directions). For a set of points S ⊆ Fnq , the set of directions DS
56: determined by S is the set of points at infinity corresponding to the lines passing through at
57: least two points of S. The complementary set with respect to H∞ is the set of non-determined
58: directions, denoted by NS .
59: 
60: The direction problem seeks to determine, for a given size |S|, the smallest possible number
61: of directions defined by a point set S under certain conditions, and to describe the sets that
62: achieve this minimum. Observe first that if |S| > q n−1 , then S determines all directions; that
63: is, DS = H∞ . Hence, the most interesting case arises when |S| = q n−1 .
64: With its roots in the work of Rédei [27], this problem has led to many deep results and challenging
65: open questions. Most of the known results concern the planar case (n = 2), see for instance
66: [1, 3, 4, 8, 10, 11, 12, 15, 24, 30, 32]. In higher dimensions, one of the most notable open problems
67: is the cylinder conjecture of Ball [2].
68: 
69: The Cylinder Conjecture. Simeon Ball proposed the following conjectures, in both a weak
70: and a strong form, restricted to prime fields Fp . Let us first define cylinders.
71: 
72: Definition 1.2 (Cylinder). A set S ⊆ F3p is called a cylinder if it is the union of p pairwise
73: disjoint parallel lines so it is a set of size p2 .

76: prime. If the number of non-determined directions of S satisfies |NS | ≥ p, then S is a cylinder.
77:

79: of the Rédei–Lovász–Schrijver theorem [24], proven by Sziklai [33].
