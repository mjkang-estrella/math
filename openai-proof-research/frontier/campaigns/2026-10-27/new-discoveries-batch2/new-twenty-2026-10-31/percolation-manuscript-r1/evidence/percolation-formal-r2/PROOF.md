# Closed proof components and remaining work

The original literal Plane, step, rounds, Percolates, TimeIs, Minimal and Conjecture20 are re-exported unchanged from Definitions.lean. Structure.lean, Plane5.lean, Endpoint.lean and both positive controls are unchanged as well. The source-only round-1 zip receipt and byte comparisons are in provenance/.

Closure.lean proves stabilization at size q = q²+q+1 for every plane and threshold. Inflationarity and monotonicity imply nondecreasing infected counts. Equality of these counts for an inclusion forces equality pointwise, using a list induction. Therefore every nonfixed round strictly increases the count. A fixed round stays fixed at every later round. If there were no fixed round through size q, round size q+1 would have at least size q+1 infected points, contradicting the length of the finite point enumeration. This proof uses no bounded computation over infection masks.

For an initially infected v, take B_v = rounds P r (erase a v) (size q). Stabilization makes it closed, and inflationarity makes it contain a minus v. If B_v contained v, it would contain all of a. Monotonicity and closedness, together with percolation of a, would then make B_v full. Thus the deletion percolates, violating Minimal against that proper subset. This proves the requested canonical separator, specifically at round 31 in PG5.

FiniteSystem.lean records A, X, I, J and B as finite Boolean arrays. I and J are exactly the threshold-5 line activations of A and X. X is A union all I-lines. X union all J-lines is full, while X is nonfull. Each initially infected point has a closed separator containing its deletion and omitting it. witness_to_finite5 supplies these arrays from a literal witness; finite5_to_witness proves the converse. The reverse direction uses minimal_from_separators against every proper subset and every natural percolation time, rather than testing only short deletion runs. It excludes time zero using inflationarity into nonfull X. Thus finite5_iff_target is a genuine equivalence.

TruthTableCNF.lean represents a literal by (variable, forbidden-bit): (z,true) is negative and (z,false) is positive. Holds means some variable differs from its forbidden bit. The bits enumerator uses Nat.rec, avoiding generated recursive compiler helpers. A local gate's CNF contains the blocking clause for every false local truth-table row. gate_sound proves that every such clause holds whenever the gate does. Its key lemma shows that a falsified blocking clause, with matching vector lengths, agrees with the assignment on every support entry. Neither native evaluation nor a SAT checker is trusted.

PG5CNF.lean defines variable types A, X, I, J and B_v,p (31+31+31+31+961 = 1,085 Boolean variables). It constructs support lists by filtering PG5 incidence, rather than reading a DIMACS file. The families are:

- Activation equivalences: I_l iff A has at least five points on l, and J_l iff X does.
- First-round equations: X_p iff A_p or an incident I-line activates.
- Second-round fullness: X_p or an incident J-line activates, for each p.
- Separator closedness: on each of the 31 lines, each B_v has a count different from five. For six-point lines at threshold five this is exactly the closedness obstruction. The soundness proof derives the prohibition from step B_v = B_v and line_degree; it does not assume it.
- One negative clause containing every X_p to exclude fullness at round one.
- Omission clauses: not A_v or not B_v,v.
- Containment clauses, for p distinct from v: not A_v or not A_p or B_v,p.

witness_satisfies_inputCNF5 proves satisfaction of every clause generated by every family, from a minimal two-round witness and its canonical assignment. Therefore GeneratedCNFUnsat5 implies NoMinimalTwoRound5 and the negation of Conjecture20. The endpoint has exactly the GeneratedCNFUnsat5 hypothesis. FiniteSystemUnsat5 is an alternative endpoint hypothesis in a separate theorem, not an additional assumption of not_conjecture20_generated.

No normalization is used, so no collineation assertion is assumed or silently imported. No external proof trace is used. No equality between this new truth-table generator and either prior DIMACS is claimed. In particular the old normalized 82,646-addition LRAT cannot be fed directly to this generator: normalization and clause correspondence would still need proofs. The unnormalized encoding avoids a symmetry obligation, but its UNSAT theorem is still missing. The requested general RUP theorem, pilot 500/2000-step measurements, replay modules and unconditional endpoint remain outstanding. Certificate throughput is zero implemented additions, with no projected timing estimate.
