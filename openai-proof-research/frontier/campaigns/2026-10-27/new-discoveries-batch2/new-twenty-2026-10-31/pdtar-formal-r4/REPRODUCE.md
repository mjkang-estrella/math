# Reproduce r4

Use the pinned Lean 4.34.1 and read-only mathlib cache named in TASK.txt and manifest.json. No downloads, lake operations, or sibling writes are needed.

From this lane, `python3 -I scripts/replay.py --init` creates a fresh empty replay/extracted directory and safely extracts pdtar-source.zip. It refuses existing replay state or extraction. The delivered replay is already complete; to independently reproduce, copy the source zip and scripts/replay.py into a new directory **inside this lane**, keeping scripts/replay.py under its scripts directory, then initialize there.

Run `python3 -I scripts/replay.py --resume --steps 10` repeatedly until REPLAY COMPLETE. Do not start concurrent replay/build processes. Each invocation resumes only after checking source and pinned binary hashes, prior log hashes and the complete build-object inventory. No build objects are archived. All 34 modules are built in module-order.json order with -j1 -M3500 -DwarningAsError=true -DElab.async=false, then all 34 run through leanchecker. The audit and seven expected-failure controls follow: 76 steps total.

scripts/limited.py wraps each heavy child separately with two-CPU affinity, CPU 120 seconds, wall 140 seconds, sampled RSS 6 GiB and MALLOC_ARENA_MAX=2. TMPDIR and XDG_CACHE_HOME are local. Unique log names use time_ns; exclusive creation prevents overwrites. Each child is waited for and cap violations kill its process group. Build drivers themselves do not elaborate Lean. Leanchecker has no Lean elaborator -j/-M flags; its enclosing runner applies the same process caps.

scripts/Audit.lean enumerates all constants belonging to the explicit PDTAR module set, including generated declarations. It verifies that this set equals FinalComplete's PDTAR import closure, rejects unsafe/partial declarations, recursion companions, implemented_by and extern, and checks every declaration's transitive axioms against the three permitted names. Its complete declaration listing is retained in the replay audit log.

All seven negative controls must exit nonzero with substantive unsolved goals or type mismatch. In particular NegStarTwo rejects K(1,2) uniqueness using the actual witness theorem; NegK33Added rejects rigidity of K(3,3) with one internal edge using a triangle obstruction. Their auxiliary graph definitions and obstruction proofs must compile before the intended false endpoint fails.

The source-only zip is regenerated by scripts/package.py; manifest.json records every packaged file hash and the toolchain pins. frozen-before.json and frozen-after.json record all 27 inherited module hashes. report.py rebuilds results.json from the final replay and rechecks frozen and archive bytes.
