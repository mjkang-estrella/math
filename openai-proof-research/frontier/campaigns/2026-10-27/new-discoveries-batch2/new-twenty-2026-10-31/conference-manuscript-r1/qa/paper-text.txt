 Abstract. Etzion, Vardy and Yaakobi conjectured that for every prime p, the code of length p + 1 over ℤp generated
 by the rows of a conference matrix of order p + 1 is an MDS code of dimension (p + 1)/2 and minimum Hamming
 distance (p + 3)/2 (arXiv:1210.5725, Conjecture 5; IEEE Trans. Inform. Theory 59 (2013), Conjecture 1). We give an
 explicit skew conference matrix W of order 20 whose row code C over ᵓ19 has dimension 10, as the authors' Theorem
 4 predicts, but contains a nonzero codeword of Hamming weight 9. Since 9 < 11 = 20 − 10 + 1 = (19 + 3)/2, the code
 C is not MDS and does not have the conjectured minimum distance, so the conjecture is false at p = 19. Every step
 can be checked by hand or with a few lines of code. The refutation is also formalized in Lean 4 with Mathlib as the
 theorem ConferenceMDS.conjecture5_false; the formal proof establishes d(C) ≤ 9, not the exact value. An
 ordinary, unformalized enumeration gives d(C) = 9.

 1. Introduction
 Etzion, Vardy and Yaakobi [1, 2, 3] studied lattices and codes whose generator matrices are weighing matrices,
 mainly for the Lee and Manhattan metrics. A conference matrix of order p + 1, with p prime, generates a code over ℤp
 = ᵓp. The authors proved that this code has dimension (p + 1)/2 (their Theorem 4) and is self-dual (their Theorem 2),
 and they conjectured that it is always MDS. They report that the conjecture "was verified to be true up to n = 23,
 where the conference matrices are based on the Paley's construction", and they list it again as open problem 2 of the
 journal version [2, p. 6722].
 The universal statement fails. Section 3 gives a skew conference matrix W of order 20, a hand proof that its row code
 over ᵓ19 has dimension 10, and an explicit row combination of Hamming weight 9. An MDS code of length 20 and
 dimension 10 must have minimum distance 11, so this one word refutes both the MDS clause and the distance clause.
 The dimension clause is the source's Theorem 4 and remains true.
 Paley conference matrices are not counterexamples: their row codes are doubly extended Reed–Solomon codes
 (Remark 4.2, which is background and not claimed as new). This is consistent with the authors' Paley-only checks.
 The matrix W is not of Paley type. It comes from the Goethals–Seidel array [9].
 The contribution is narrow: one explicit matrix whose row code over ᵓ19 contains a nonzero word of weight at most 9,
 which refutes the conjecture in its exact universal scope. We do not claim the exact minimum distance, any codeword
 counts, the Paley fact, a classification of all order-20 conference matrices, or that p = 19 is the smallest
 counterexample.

 2. Definitions and the conjecture
 Source definitions. We quote the arXiv v2 text [1, p. 4]; the journal text [2, p. 6713] agrees in substance. "A
 weighing matrix Wn,w of order n and weight w is an n × n matrix over the alphabet {0, 1, −1} such that each row and
 column has exactly w nonzero entries; and W · WT = wIn." The conference matrices are "the conference matrices in
 which w = n − 1". The source does not ask for a zero diagonal or for symmetry or skewness. The lattice Λ(W) is the
 lattice with generator matrix W, that is, the set of integer combinations of its rows. Theorem 1 of the source says that
 "Λ(W) can be reduced to a code C of length n ... over the alphabet ℤw", and Theorem 2 says that this code is self-dual.
 The source defines rank as follows: "The rank of A over ℤk is defined to be the maximum number of linearly
 independent rows of A over ℤk" [2, p. 6715].
 The code. Let W be a conference matrix of order n = p + 1, with p prime, so that w = p. Write C(W) for the reduction
 of Λ(W) modulo p, that is, the image of Λ(W) under coordinatewise reduction ℤn → ᵓpn. Reduction is additive and
 maps ℤ onto ᵓp, so C(W) is exactly the ᵓp-span of the reduced rows of W. The Lean theorem
 latticeCode_eq_rowCode proves this equality for every p, n and W. The dimension of C(W) is the rank of W over

 Distance and MDS. The Hamming distance of two words is the number of coordinates in which they differ, and the
 weight of a word is its number of nonzero coordinates. The minimum distance d(C) of a code is the least distance
 between two distinct codewords; for a linear code it is the least weight of a nonzero codeword. A linear [n, k, d] code
 satisfies the Singleton bound d ≤ n − k + 1 and is MDS if equality holds. For n = p + 1 and k = (p + 1)/2 the Singleton
 value is n − k + 1 = (p + 3)/2. So, given Theorem 4, the MDS clause and the distance clause of the conjecture say the
 same thing.
 The source results and the conjecture. The journal text [2, p. 6715] reads as follows; arXiv v2 [1, p. 6] has the same
 wording, with label Conjecture 5.
       Theorem 4: If ᵋ is a conference matrix of order n = p + 1, where p is a prime, then its rank over ℤp (also ᵓp) is
       (p+1)/2. … We have examined the code ℂ reduced from Λ(ᵋ) over the alphabet ℤw for the minimum distance in
       the Lee metric, which is the topic of this paper. We believe that a surprising result will be derived if we will
       examine the Hamming distance of these codes.
       Conjecture 1: If ℂ is a code of length p + 1 constructed from a generator matrix which is a conference matrix
       then ℂ is a maximum distance separable (MDS) code of dimension (p+1)/2 and minimum Hamming distance
       (p+3)/2.
       Conjecture 1 was verified to be true up to n = 23, where the conference matrices are based on the Paley's
       construction from quadratic residues modulo p. Codes with these parameters (self-dual MDS of length q + 1, q

 Proposition 3.1. W is a skew conference matrix of order 20: it has zero diagonal and entries ±1 off the diagonal, WT
 = −W, and W WT = 19 I20. In particular every row and every column has exactly 19 nonzero entries, so W is a
 weighing matrix W20,19, that is, a conference matrix in the source's sense, and also in the textbook sense.
 Proof. All of this is a finite check on the displayed matrix. The Lean file and the stdlib script in the dossier both do it
 entry by entry. Here is the structural reason. The periodic autocorrelations Ps(t) = Σi si si+t at t = 1, 2 are 1, −3 for a; 1,
 1 for b and for c; and −3, 1 for d. Since Ps(t) = Ps(5 − t), the four sum to 0 at every shift t ≠ 0, so AAT + BBT + CCT +
 DDT = 20 I5. Circulants commute, and XR = RXT is symmetric for every circulant X, because both have (i, j) entry
 x4−i−j mod 5. With these two facts, block multiplication gives HHT = 20 I20; this is the classical Goethals–Seidel
 argument [9]. For example, the product of block rows 1 and 2 is −ABR + BAR + CD − DC = 0. Next, a0 = 1 and a5−i
 = −ai for i = 1, …, 4, so A + AT = 2 I5. Each off-diagonal block of H is symmetric, and it is the negative of its mirror
 block. Hence H + HT = 2 I20. Therefore W = H − I has zero diagonal and ±1 entries elsewhere, WT = I − H = −W, and
 W WT = HHT − H − HT + I = 19 I. ∎
 Let C ⊆ ᵓ1920 be the ᵓ19-span of the rows of W reduced mod 19. By Section 2, this is the code the conjecture is about.

 Theorem 3.4. The conjecture of [1, Conjecture 5] and [2, Conjecture 1] is false. For p = 19 and the conference
 matrix W above, the code C is a [20, 10] code with d(C) ≤ 9 < 11 = (p + 3)/2 = n − k + 1, so C is not MDS and its
 minimum distance is not (p + 3)/2.
 Proof. By Proposition 3.1, W is a conference matrix of order p + 1 = 20, with p = 19 prime. By Proposition 3.2, dim C
 = 10. By Proposition 3.3, C contains a nonzero word of weight 9, and its distance from the zero codeword is 9, so
 d(C) ≤ 9. The Singleton value is 20 − 10 + 1 = 11. Therefore both the MDS clause and the distance clause fail. Only
 the dimension clause, the source's Theorem 4, holds. ∎
 Remark 3.5 (normal form). The source writes weighing matrices in a normal form, with the first row consisting of
 zeroes followed by +1's, obtained by negating and permuting columns [1, p. 5]. Negating columns 3, 4, 5, 10, 15 and
 17 puts row 0 of W in this form. Column negation maps C to an equivalent code with the same weight distribution,
 and the image of c still has weight 9. So the normal-form convention does not rescue the conjecture. The Lean
 statement quantifies over all conference matrices and needs no such convention.

 4. Supporting computation and background (not claimed)
 4.1 Exact distance (ordinary computation only). A nonzero word of weight at most 10 vanishes on some set of 10
 coordinates. Enumerating all C(20, 10) = 184,756 such sets and computing the subcode vanishing on each gives d(C)
 = 9 exactly, with 180 weight-9 words up to scalar multiples. This was done by an earlier pipeline stage and
 recomputed independently by a reviewer. We report it as supporting computation only. It is not formalized and is not
 part of the claimed result. Another reviewer diagnostic found that every nonzero combination of at most three rows
 has weight at least 11, for W and for the order-20 Paley matrix alike. The word c uses nine rows.
 4.2 The Paley case (known background). For an odd prime p, let χ be the quadratic character and let W be the
 bordered Paley conference matrix, whose entry in row i + 1 and column j + 1 is χ(j − i) for i, j ∈ ᵓp. By Euler's
 criterion, χ(j − i) ≡ (j − i)(p−1)/2 (mod p). So row i + 1 evaluates on ᵓp the polynomial (x − i)(p−1)/2, which has degree k
 − 1 for k = (p + 1)/2 and leading coefficient 1, and the border column supplies that leading coefficient up to one fixed
 sign. Row 0 is the constant 1, with 0 in the border column. Hence the Paley code is contained in, and by Theorem 4
 equal to, the doubly extended Reed–Solomon code of length p + 1 and dimension k, which is MDS. This routine fact
 explains why the authors' Paley-only checks succeeded. We do not claim it as new. By Ball's theorem [7, Corollary
 9.2], every MDS code over ᵓp of length p + 1 and dimension k ≤ p is, up to equivalence, a Reed–Solomon code.
 Together with Theorem 4, the conjecture was therefore equivalent to asking that every conference matrix of order p +
 1 have a Reed–Solomon row code. The matrix W shows that this fails. Ball's theorem is not used in any proof here.
 4.3 What is not established. We do not claim that p = 19 is the least counterexample; conference matrices of the
 orders p + 1 with p < 19 prime were not audited here. A reviewer combined a secondary classification table [10] (two
 classes of skew Hadamard matrices of order 20 under the equivalence Y = PTXP) with a normalization statement
 quoted in [6]. From these the reviewer inferred that every conference row code of order 20 over ᵓ19 is equivalent
 either to the Paley code or to C. That inference rests on primary sources that were not read, and it is not part of this
 paper's claims.

 6. Related work and the limits of the prior-art search
 The conjecture appears in all four versions of [1, 2, 3], and none of them resolves it. Grassl and Gulliver [5] are cited
 by the source only for the existence of self-dual MDS codes of length q + 1. Their body was not read; we consider this
 a low risk.
 Arasu and Gulliver. The nearest prior work is Arasu and Gulliver [4]. That paper is closed access. Its Section 2
 remarks and its tables were not read. We know its constructions only through the description by Armario and Frau [6,
 Section 1.2, Propositions 1.3–1.4, Table 1]. There a weighing matrix W(n, k) gives the generator matrix [αI, W],
 which needs α2 + k ≡ 0 (mod p), or a skew one gives [αI, βI + W], which needs α2 + β2 + k ≡ 0 (mod p), with α, β
 nonzero. The resulting self-dual codes have length 2n. For p = k = 19 the conditions become α2 ≡ 0 or α2 + β2 ≡ 0
 (mod 19). Both are impossible, because −1 is not a square mod 19: the nonzero squares are 1, 4, 5, 6, 7, 9, 11, 16 and
 17. The constructions would also give length 40, not 20. So, as described, they cannot produce the length-20 witness.
 A remark about length-n row codes in the unread sections or tables of [4] is not excluded.

 7. Significance and limitations
 The result is a finite refutation of a conjecture stated in a peer-reviewed journal and still listed there as open. An
 independent adjudication within the project judged its significance a qualified pass at the minimum threshold of the
 project's credit standard. No known theorem, bound or generic reduction was found that already yields the
 counterexample. The new datum is still a single invariant of a single object, found by computer search and checked
 by standard means. There is no structural explanation and no infinite family. The credited content is only the explicit
 order-20 conference matrix whose ᵓ19 row code has a nonzero word of weight at most 9. The exact distance, the
 counts, the Paley fact, the order-20 dichotomy and the question of minimality are excluded.
