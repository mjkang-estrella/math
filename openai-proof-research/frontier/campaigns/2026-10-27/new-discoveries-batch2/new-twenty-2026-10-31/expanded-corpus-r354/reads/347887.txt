11:                                                                                                    Abstract
12:                                                         A frequency square is a square matrix in which each row and column is a permutation of the same
13:                                                     multiset of symbols. A frequency square is of type (n; λ) if it contains n/λ symbols, each of which
14:                                                     occurs λ times per row and λ times per column. In the case when λ = n/2 we refer to the frequency
15:                                                     square as binary. A set of k-MOFS(n; λ) is a set of k frequency squares of type (n; λ) such that when
16:                                                     any two of the frequency squares are superimposed, each possible ordered pair occurs equally often.
17:                                                         A set of k-maxMOFS(n; λ) is a set of k-MOFS(n; λ) that is not contained in any set of (k + 1)-
18:                                                     MOFS(n; λ). For even n, let µ(n) be the smallest k such that there exists a set of k-maxMOFS(n; n/2).
19:                                                     It was shown in [1] that µ(n) = 1 if n/2 is odd and µ(n) > 1 if n/2 is even. Extending this result, we
20:                                                     show that if n/2 is even, then µ(n) > 2. Also, we show that whenever n is divisible by a particular
21:                                                     function of k, there does not exist a set of k′ -maxMOFS(n; n/2) for any k′ ⩽ k. In particular, this
22:                                                     means that lim sup µ(n) is unbounded. Nevertheless we can construct infinite families of maximal
