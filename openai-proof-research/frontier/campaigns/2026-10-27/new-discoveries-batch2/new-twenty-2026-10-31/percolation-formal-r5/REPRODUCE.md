# Strict bounded replay and continuation

Work only inside this round 5 lane. Lean 4.34.1 is pinned at /home/mj-kang/Documents/Dev/math/dlp-research/.tools/lean-4.34.1-linux/bin. Only bundled Lean/Std and local modules are imported. Network access and mathlib compilation are unnecessary.

Extract source-only.zip into a new lane-local directory after rejecting absolute paths and .. components. Run sha256sum -c source-manifest.sha256 there. Then run RESUME=1 BUDGET=600 bash replay.sh repeatedly until complete. module-order.txt gives the serial dependency order. Each module gets one strict lean -M3500 -DwarningAsError=true process and one leanchecker MODULE process. The driver stops immediately on any failure and checks BUDGET between modules. A started module may finish beyond the budget.

Every Lean, checker and Python process must use guard.sh LABEL COMMAND. It sets MALLOC_ARENA_MAX=2, lane-local TMPDIR and caches, taskset CPUs 0,1, 120 CPU seconds, 140 wall seconds and a 6 GiB process-group RSS watchdog. Processes run serially and the guard waits for its child. No limit is increased after failure. Python invocations use python3 -I -B and a real script path.

Resume stamps contain a rolling digest of all source files through that module and the current compiled output hash. A changed source or compiled output invalidates its stamp; later source changes invalidate downstream stamps. Only compiler-and-checker success writes a stamp and updates replay-progress.json. After each replay chunk, replay-frontiers.tsv updates normalized-progress.json in the extraction and the parent lane. Each source has a manifest hash. The archive contains no compiled files.

AuditR5 imports the full endpoint chain and rejects local assumptions, unsafe or partial declarations, extern declarations, implementation overrides, and generated unsafe recursion helpers. The endpoint prints its transitive axioms. The independent scan.py removes nested comments and strings before checking forbidden executable tokens; run it through guard.sh. Logs and module-times.json record observed replay results, not estimates.

For continuation, read normalized-progress.json, start at next_index_zero_based in normalized-trimmed.json, and preserve every delivered source byte. The new generator is generate.py in this lane (it takes the lane path and target index); its initial start is 12500 and must be adjusted for any later continuation. Module sizing uses hint counts and referenced clause lengths. The delivered next index and LRAT ID govern, not the generator's requested target. Root alone decides acceptance.
