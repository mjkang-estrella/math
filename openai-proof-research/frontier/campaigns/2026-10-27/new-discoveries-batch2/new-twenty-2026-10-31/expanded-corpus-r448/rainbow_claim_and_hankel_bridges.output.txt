                                                                                Abstract
                                                     DeVos et al conjectured that if M is a simple, regular matroid
                                                 and c is a colouring of the elements of M with r(M ) + 1 colours,
                                                 where each colour class has at least two elements, then M contains
                                                 a rainbow circuit of size at most ⌈ r(M2)+1 ⌉. We prove this conjecture
                                                 by showing that for all such regular  P matroids there are four rainbow
                                                 circuits Ci , i = 1, 2, 3, 4 for which i |Ci | ≤ 2r(M ) + 4 and for which
                                                 no element of M belongs to more than two of the circuits.

    The problem dealt with in this paper has its origins in the well-known
Caccetta-Häggkvist conjecture [4]:

1.1 Conjecture ( Cacetta, Häggkvist )
Every simple directed graph on n vertices with minimum out-degree r con-
tains a directed cycle of length at most ⌈ nr ⌉.

    The authors in [1] observed that if for the directed graph G in the above
conjecture, one assigns n colours to the edges whereby the out-directed edges
at each vertex receive the same colour, then the conjecture asserts that
there exists a rainbow cycle of length at most ⌈ nr ⌉. As such, they posed the
following more general conjecture:

1.2 Conjecture ( Aharoni, Devos, Holzman )
Let G be a graph and let c be a ν(G)-colouring of G where each colour class
has size at least r. Then the coloured graph (G, c) contains a rainbow cycle
of length at most ⌈ ν(G)
                      r ⌉.

constant. That is, for all r ≥ 2 there is a constant αr such Conjecture 1.2 is
true if one replaces ⌈ ν(G)         ν(G)

    In [6], the authors considered an extension of rainbow colourings to ma-
troids. A colouring of a matroid M is defined to be a function c : E(M ) →
S for some set S. We call the pair (M, c) a coloured matroid. If S = [k],
then we refer to c as a k- colouring of M. As with graphs, for each s ∈ S,
we define c−1 (s) = {e ∈ E(M ) c(e) = s} to be the colour class for the
colour s. For a subset A ⊂ E(M ), we define c(A) := {c(e) e ∈ A} and we
define c(M ) := c(E(M )), the set of distinct colours appearing in M. We say
that an element e in a coloured matroid is colour-singular if e is the only
element in the colour class containing it. A colouring of matroid (or graph)
is said to be k-bounded (resp. k-uniform) if each colour class has at most
(resp. exactly) k elements. If a colour class X contains two elements and
e ∈ X, we shall denote by e′ the other element in X.
    For a coloured matroid (M, c), a subset A ⊆ E(M ) is said to be a
rainbow subset if c restricted to A is injective. In particular, a rainbow

     We shall make frequent use of the following observation whose easy proof
is left to the reader.

1.3 Observation
Suppose (M, c) is a simple, circuit-achromatic coloured matroid where ε(M ) =
2r(M ) − 1 and c is 2-bounded. Then (M, c) has exactly one colour-singular
element.

    Extending Conjecture 1.2 for the case r = 2 to matroids, the authors in
[6] posed the following conjecture:

1.4 Conjecture
Let M be a simple, regular matroid and let c be a (r(M ) + 1)-colouring of
M . If (M, c) has no colour-singular elements, then M has a short rainbow
circuit.

In [6], the conjecture is shown to be true for graphic and cographic matroids.
In this paper, we prove the above conjecture by proving the existence of four
rainbow circuits the sum of whose cardinalities is at most 2r(M ) + 4.
    A cycle in a matroid is a disjoint union of circuits. For a coloured
matroid (M, c), a pair of circuits (resp. cycles) {C1 , C2 } is said to be a
rainbow circuit pair (RCP) (resp. rainbow cycle pair (RCyP)) if C1
and C2 are disjoint rainbow circuits (resp. cycles). Generally, a disjoint pair
of rainbow subsets {X1 , X2 } is said to be a rainbow pair. A RCP (resp.
RCyP) {C1 , C2 } is said to be short if |C1 | + |C2 | ≤ r(M ) + 2. In shorthand,
we write SRCP (resp. SRCyP) for a short circuit (resp, cycle) pair.
    A family of circuits {C1 , C2 , C3 , C4 } is said to be a short rainbow
circuit 4-tuple (SRC P      4-tuple) if the circuits Ci , i ∈ [4] are rainbow
circuits for which      i |Ci | ≤ 2r(M ) + 4 and for which no element of M
belongs to more than two of the circuits. We can define the same for cycles
where a SRCy 4-tuple denotes a short rainbow cycle 4-tuple. Note that
if {C1 , C2 } is a SRCP (resp. SRCyP), then {C1 , C1 , C2 , C2 } is a SRC 4-
tuple (resp. SRCy 4-tuple). By averaging, one sees that at least one of the
circuits in an SRC 4-tuple is short. We prove Conjecture 1.4 by proving the

2.1. Partially ordered commutative rings and total positivity

  In this paper all rings will be assumed to have an identity element 1 and to be
nontrivial (1 = 0).
  A partially ordered commutative ring is a pair (R, P) where R is a commutative ring
and P is a subset of R satisfying

(a) 0, 1 ∈ P.
(b) If a, b ∈ P, then a + b ∈ P and ab ∈ P.
(c) P ∩ (−P) = {0}.

We call P the nonnegative elements of R, and we deﬁne a partial order on R (compatible
with the ring structure) by writing a ≤ b as a synonym for b − a ∈ P. Please note
that, unlike the practice in real algebraic geometry [4,28,30,35], we do not assume here
that squares are nonnegative; indeed, this property fails completely for our prototypical
example, the ring of polynomials with the coeﬃcientwise order, since (1 − x)2 = 1 − 2x +
x2  0.
