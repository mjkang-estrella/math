# Strict capped replay

The source-only archive contains seven Lean modules, this documentation and the resource/replay/audit scripts. It contains no oleans or downloaded PDFs. Unzip into a fresh empty directory inside this lane. From that directory run `scripts/replay-all`. Every module is built by a separate `lean -j2 -M3500 -DwarningAsError=true` process, then checked by a separate explicit `leanchecker Module` process. The driver stops on any failure. For an interrupted replay, use `RESUME=1 scripts/replay-all` in the same extracted directory: success markers allow resumption after the last completed operation. Clear markers for changed modules and their dependents before resuming after edits; fresh replay is the evidence here.

Manual single-step commands are `scripts/replay build Endpoint` and `scripts/replay check Endpoint`, after dependencies. Module order: AntimagicBasics, AntimagicIso, Antimagic, LauShiu, Counts, Endpoint, Audit. Audit imports all proof modules and emits outputs/audit.tsv. The final Python validation checks its transitive axiom list and local unsafe/partial/implemented-by/extern flags, scans every Lean source and writes results.json. Read logs/Endpoint.build.log for #print axioms not_conjecture41.

All Python, Lean and leanchecker invocations must go through scripts/run. This sets lane-local TMPDIR/TEMP/TMP and cache variables, MALLOC_ARENA_MAX=2, taskset CPUs 0 and 1, CPU 120 seconds and wall 140 seconds. A process-group watchdog sums RSS every 0.1 seconds and kills above 6 GiB. Processes run sequentially; the watchdog is terminated and reaped after each call. Core dumps are disabled. No limit is raised following failure.
