# Every k-gonal prism is B-factorizable

*A proof of Conjecture 17 of Kashiwabara (Electron. J. Combin. 16 (2009) #R55; arXiv:0809.3682), with a complete Lean 4 formalization*

Claude Opus 5.5 produced the mathematical proof (`PROOF-317750.md`), the first review (`REVIEW-317750.md`) and the Lean formalization (`prism-b-factorizable-317750-formal-paper-opus55-20261121-r1`). GPT-6.2 Sol conducted the cross-model review and revised this manuscript. The manuscript presents the arguments in the form used in Lean. The Lean development proves the statement of Definition 4 and uses only `propext`, `Classical.choice` and `Quot.sound`.

## Abstract

Kashiwabara introduced B-factorizable regular graphs to study Briskorn's conjecture on schedules compatible with home–away pattern (HAP) sets. He showed that the 3-cube and the pentagonal prism are B-factorizable by Hilbert-basis computations and conjectured that every k-gonal prism is (Conjecture 17). We prove this for every k ≥ 3. The source's Lemmas 7 and 8 reduce the problem to a statement about a polytope, and only their easy halves are needed. The polytope statement is then reduced to a layered digraph on the colours of a periodic "ladder", where a winding-number argument, an F₂ cut-parity argument and a propagation argument give an integral point. All steps are formalized in Lean 4 with Mathlib (1,891 lines in 8 modules).

## 1. The conjecture and the source definitions

The MathDB record 317750 reads: "For a regular graph $G=(V,E)$, call $G$ **B-factorizable** if every saturated monoid element with edge component equal to the graph's characteristic vector belongs to the monoid generated by compatible perfect matchings. A $k$-gonal prism is the graph formed by two $k$-cycles together with corresponding matching edges. **Prism B-factorizability conjecture.** The graph of every $k$-gonal prism is B-factorizable."

The source (EJC version, §4.4, p. 14) states:

> We may conjecture the following.
> **Conjecture 17.** The graph of every k-gonal prism is B-factorizable.
> This conjecture seems to be easier than Conjecture 5 because we have only to consider an HAP set for three days. But we have not solved it yet.

The definitions below follow Sections 2 and 3 of the journal article. The corresponding Lean definitions are in `PrismDefs.lean`.

**Equal partitions.** "Let V be the finite set of vertices of a graph that we consider. … |V| is always assumed to be even. A partition of a set that consists of two sets of the same size is called an equal partition in this paper. The set of all the equal partitions on V is denoted by C = C(V). … An equal partition can be identified with a complete bipartite graph which has two partite sets of the same size. We denote the complete bipartite graph corresponding to c ∈ C by B_c."

```lean
def IsEqualPartition (c : Finset (Finset V)) : Prop :=
  ∃ H A : Finset V, Disjoint H A ∧ H ∪ A = Finset.univ ∧ H.card = A.card ∧ c = {H, A}
abbrev EqPart := {c : Finset (Finset V) // IsEqualPartition V c}
def Bc (c : EqPart V) : SimpleGraph V where
  Adj a b := ∃ X ∈ c.1, ∃ Y ∈ c.1, X ≠ Y ∧ a ∈ X ∧ b ∈ Y
```

**The space ℕ^{K∪C}.** "Let K := (V choose 2), which is identified with the edges of the complete graph on V. We consider the linear space R^{K∪C} … For v ∈ R^{K∪C}, the components of v in K are called the edge components and the components of v in C are called the HA components. For v ∈ R^{K∪C}, v|_K is defined to be the vector restricted to the edge components." "χ_E means … the characteristic function of edges E."

```lean
abbrev K := {e : Sym2 V // ¬ e.IsDiag}          -- 2-subsets of V; vectors are K V ⊕ EqPart V → ℕ
noncomputable def chiE (G : SimpleGraph V) : K V → ℕ := fun e => if e.1 ∈ G.edgeSet then 1 else 0
```

**PM(V).** "For graph G = (V, E) and c ∈ C, we introduce a vector χ_{E,c} ∈ N^{K∪C} defined as follows … For e ∈ K, χ_{E,c}(e) = 1 if e ∈ E(G), 0 if e ∉ E(G). For f ∈ C, χ_{E,c}(f) = 1 if f = c, 0 if f ≠ c. … Let PM(V) = {χ_{q,c} | q is a perfect matching of B_c for some c ∈ C}."

```lean
noncomputable def chi (c : EqPart V) (q : (Bc c).Subgraph) : K V ⊕ EqPart V → ℕ
  | Sum.inl e => if e.1 ∈ q.edgeSet then 1 else 0
  | Sum.inr c' => if c' = c then 1 else 0
def PM : Set (K V ⊕ EqPart V → ℕ) :=
  {v | ∃ (c : EqPart V) (q : (Bc c).Subgraph), q.IsPerfectMatching ∧ v = chi c q}
```

**The two monoids.** "For M ⊂ N^{K∪C}, N(M) denotes the set of all nonnegative integral combinations of M. That is, N(M) = {Σ k_i p_i | k_i ∈ N, p_i ∈ M} … Let N̄(M) be defined as N̄(M) = {v ∈ N^{K∪C} | kv ∈ N(M) for some k ≥ 1}."

```lean
def N (M : Set (K V ⊕ EqPart V → ℕ)) : AddSubmonoid (K V ⊕ EqPart V → ℕ) := AddSubmonoid.closure M
def Nbar (M : Set (K V ⊕ EqPart V → ℕ)) : Set (K V ⊕ EqPart V → ℕ) :=
  {v | ∃ m : ℕ, 1 ≤ m ∧ m • v ∈ N M}
```

The Lean file also proves `mem_N_iff`: `v ∈ N M` holds iff `v = Σ_{p ∈ s} c_p • p` for a finite set `s ⊆ M` and coefficients `c_p ∈ ℕ`. This is the source's description of N(M).

**Definition 4.** "A regular graph G = (V, E) is called B-factorizable if any v ∈ N̄(PM(V)) with v|_K = χ_E satisfies v ∈ N(PM(V))."

```lean
def BFactorizable (G : SimpleGraph V) : Prop :=
  ∀ v ∈ Nbar (PM V), (fun e => v (Sum.inl e)) = chiE G → v ∈ N (PM V)
```

**The k-gonal prism.** The prism C_k □ K_2 has vertices u_i = (i, false) and w_i = (i, true) for i ∈ ℤ_k, two k-cycles and the k matching edges u_i w_i:

```lean
def prism (k : ℕ) (hk : 3 ≤ k) : SimpleGraph (Fin k × Bool) where
  Adj x y := (x.2 = y.2 ∧ (y.1.val = (x.1.val + 1) % k ∨ x.1.val = (y.1.val + 1) % k)) ∨
    (x.1 = y.1 ∧ x.2 ≠ y.2)
def Conjecture17 : Prop := ∀ (k : ℕ) (hk : 3 ≤ k), BFactorizable (prism k hk)
```

**HAP sets and the polytope P(G, HA)** (§3.1). "A HAP set for r days is given in the form of the following pair of functions H and A. (H, A) : {1, …, r} → C (d ↦ {H(d), A(d)}). … We consider x_{{a,b},d} as a variable for pair {a, b} ∈ K of teams and date d ∈ {1, …, r}. … 1. For any {a, b} ∈ E, Σ_{d∈{1,…,r}} x_{{a,b},d} = 1. For any {a, b} ∉ E, x_{{a,b},d} = 0. 2. For any d ∈ {1, …, r} and any a ∈ V, Σ_{b∈V: b≠a} x_{{a,b},d} = 1. 3. For any d ∈ {1, …, r} and any {a, b} ∈ E, 0 ≤ x_{{a,b},d} ≤ 1. 4. For any d ∈ {1, …, r} and any {a, b} ∈ E, (a, b) ∈ (H(d) × H(d)) ∪ (A(d) × A(d)) implies x_{{a,b},d} = 0. … This polytope is determined by a graph and an HAP set, so we write this polytope as P(G, HA)."

```lean
structure HAP (r : ℕ) where
  H : Fin r → Finset V
  A : Fin r → Finset V
  eq : ∀ d, IsEqualPartition V {H d, A d}
def InP (G : SimpleGraph V) {r : ℕ} (HA : HAP r) (x : K V → Fin r → ℝ) : Prop :=
  (∀ e : K V, e.1 ∈ G.edgeSet → ∑ d, x e d = 1) ∧ (∀ e : K V, e.1 ∉ G.edgeSet → ∀ d, x e d = 0) ∧
  (∀ (d : Fin r) (a : V), ∑ b : {b : V // b ≠ a}, x (pair a b.1 b.2.symm) d = 1) ∧
  (∀ (d : Fin r) (e : K V), e.1 ∈ G.edgeSet → 0 ≤ x e d ∧ x e d ≤ 1) ∧
  (∀ (d : Fin r) (a b : V) (h : a ≠ b), s(a, b) ∈ G.edgeSet →
    ((a ∈ HA.H d ∧ b ∈ HA.H d) ∨ (a ∈ HA.A d ∧ b ∈ HA.A d)) → x (pair a b h) d = 0)
def PolytopeIntegral (G : SimpleGraph V) (r : ℕ) : Prop :=
  ∀ HA : HAP r, (∃ x, InP G HA x) → ∃ x, InP G HA x ∧ IsIntegral x
```

Days are indexed by `Fin r = {0, …, r−1}` instead of {1, …, r}. **Corollary 9** of the source: "An r-regular graph is B-factorizable if and only if, for any HAP set, P(G, HA) contains an integral point whenever P(G, HA) is non-empty." We use only the "if" direction, and we prove it in Lean (§3).

## 2. Results

**Theorem 1 (Conjecture 17).** For every k ≥ 3, the k-gonal prism is B-factorizable (Definition 4). In Lean: `mathdb317750 : Conjecture17`.

**Theorem 2 (polytope form).** For every k ≥ 3 and every HAP set of three days, if P(C_k □ K_2, HA) is non-empty, then it contains an integral point. In Lean: `mathdb317750_polytope (k) (hk) : PolytopeIntegral (prism k hk) 3`.

Theorem 1 follows from Theorem 2 by the bridge of §3. The rounding argument applies to arbitrary day labels. If the day labels admit a feasible point, summing the vertex equations on each side of that day's cut counts the same crossing-edge weight on each side. Thus both sides have the same size.

## 3. From the polytope to Definition 4 (the easy halves of Lemmas 7 and 8)

Let G be a graph on a finite non-empty set V, and suppose every vertex has exactly r neighbours.

**Lemma 3.1 (structure of N(PM(V))).** For every w ∈ N(PM(V)) there is z : C × K → ℕ with
(i) Σ_{c∈C} z(c, e) = w(e) for every e ∈ K;
(ii) Σ_{b≠a} z(c, {a,b}) = w(c) for every c ∈ C and a ∈ V;
(iii) z(c, {a,b}) ≠ 0 implies that a and b lie in different blocks of c.

*Proof.* By induction over the submonoid generated by PM(V). For w = 0 take z = 0. If z₁, z₂ work for w₁, w₂, then z₁ + z₂ works for w₁ + w₂. For a generator χ_{q,c₀} take z(c, e) = 1 if c = c₀ and e ∈ q, and 0 otherwise. Then (i) is the definition of χ_{q,c₀} on K, and (iii) holds because q ⊆ B_{c₀}. For (ii): when c ≠ c₀ both sides are 0; when c = c₀ the left side counts the edges of q at a, which is 1 because q is a perfect matching. ∎

(For an explicit representation w = Σ k_p p one has z(c, e) = Σ_{p=(q,c), e∈q} k_p. This is the quantity used in the source's proof of Lemma 7. The induction avoids choosing a representation.)

**Lemma 3.2 (converse half of Lemma 7).** Let v ∈ N̄(PM(V)) with v|_K = χ_E. Then Σ_{c∈C} v(c) = r. There is a map f : {days} → C, with r days, that takes each value c exactly v(c) times. For the HAP set d ↦ f(d), P(G, HA) is non-empty.

*Proof.* Take m ≥ 1 with m v ∈ N(PM(V)), and z as in Lemma 3.1 for w = m v. Fix a vertex a₀. Then m Σ_c v(c) = Σ_c Σ_{b≠a₀} z(c,{a₀,b}) = Σ_{b≠a₀} Σ_c z(c,{a₀,b}) = Σ_{b≠a₀} m χ_E({a₀,b}) = m r, so Σ_c v(c) = r. The map f exists because Σ_c v(c) = r: number the pairs (c, j) with j < v(c). If v(c) = 0, then (ii) forces z(c, ·) = 0. Each c = f(d) has positive v(c). Put
  x_{e,d} = z(f(d), e) / (m v(f(d))).
Condition 1: for e ∈ E, Σ_d x_{e,d} = Σ_{c: v(c)>0} v(c) · z(c,e)/(m v(c)) = Σ_c z(c,e)/m = m v(e)/m = 1. For e ∉ E, v(e) = 0, so every z(c, e) = 0 by (i). Condition 2: Σ_{b≠a} x_{{a,b},d} = m v(f(d))/(m v(f(d))) = 1. Condition 3: x ≥ 0, and x_{e,d} ≤ Σ_{d'} x_{e,d'} = 1. Condition 4: if a and b are on the same side on day d, they lie in the same block of f(d), so z(f(d), {a,b}) = 0 by (iii). ∎

**Lemma 3.3 (forward half of Lemma 8).** If x is an integral point of P(G, HA), then w := Σ_d χ_{q_d, c_d} ∈ N(PM(V)), where c_d = {H(d), A(d)} and q_d = {{a,b} : x_{{a,b},d} = 1}. Moreover w|_K = χ_E and w(c) = #{d : c_d = c}.

*Proof.* By Conditions 1 and 3, x takes values in {0, 1}. By Condition 4, an edge of q_d joins H(d) to A(d), so q_d ⊆ B_{c_d}. By Condition 2, every vertex lies on exactly one edge of q_d. So χ_{q_d,c_d} ∈ PM(V). On K, w(e) = #{d : x_{e,d} = 1} = Σ_d x_{e,d}, which is 1 on E by Condition 1 and 0 off E. On C the value is the number of days with c_d = c. ∎

**Theorem 3.4 (bridge).** If P(G, HA) contains an integral point whenever it is non-empty, for every HAP set of r days, then G is B-factorizable.

*Proof.* Let v ∈ N̄(PM(V)) with v|_K = χ_E. Lemma 3.2 gives days f and a point of P(G, HA). The hypothesis gives an integral point. Lemma 3.3 gives w ∈ N(PM(V)) with w|_K = χ_E = v|_K and w(c) = #{d : f(d) = c} = v(c). So v = w ∈ N(PM(V)). ∎

The prism is 3-regular (§6), so Theorem 1 follows from Theorem 2 and Theorem 3.4 with r = 3. No Birkhoff–von Neumann or bipartite-matching-polytope argument is needed.

## 4. Proof of Theorem 2

### 4.1 The ladder encoding

Index the vertices by ℕ, read modulo k: u_n = (n mod k, false) and w_n = (n mod k, true). The edges are a_n = u_n u_{n+1}, b_n = w_n w_{n+1} and r_n = u_n w_n. Fix an HAP set and write P_n(b)(d) ∈ {0,1} for the indicator that vertex (n, b) lies in H(d). Since {H(d), A(d)} is a partition, a and b are on the same side on day d iff their labels agree. Colour (day) d is *allowed* on an edge iff the labels of its endpoints differ at d. Write A(a_n), A(b_n), A(r_n) for the allowed sets.

A point x of P(G, HA) gives k-periodic probability vectors x_{a_n}, x_{b_n}, x_{r_n} ∈ ℝ^3 (Condition 1). Each is supported in the allowed set of its edge (Condition 4). Condition 2 at u_{n+1} and w_{n+1}, whose neighbours are u_n, u_{n+2}, w_{n+1} and w_n, w_{n+2}, u_{n+1} respectively (k ≥ 3), gives

  (V)  x_{a_n} + x_{r_{n+1}} + x_{a_{n+1}} = (1,1,1) = x_{b_n} + x_{r_{n+1}} + x_{b_{n+1}}.

An integral point is the same as k-periodic colourings c_a, c_b, c_r : ℕ → {0,1,2} that are allowed on every edge and proper at every vertex: {c_a(n), c_r(n+1), c_a(n+1)} and {c_b(n), c_r(n+1), c_b(n+1)} are three distinct colours. For distinct colours c, c' let t(c, c') be the third colour.

Two parity facts. Let s_n(c) = P_n(false)(c) + P_n(true)(c) (mod 2), so c ∈ A(r_n) iff s_n(c) = 1, and let L_n = A(a_n) ∩ A(b_n).
- **(P1)** If c ∈ A(a_n) for all 0 ≤ n < k, then k is even. (The label P_n(false)(c) flips at each step and returns to itself after k steps.)
- **(P2)** If c ∈ L_n, then s_n(c) = s_{n+1}(c). (Four bits whose two "horizontal" sums are 1 have equal "vertical" sums.)

### 4.2 Step 1: lateral alternation

Subtracting the two sides of (V) gives x_{a_{n+1}} − x_{b_{n+1}} = −(x_{a_n} − x_{b_n}), so x_{a_n} − x_{b_n} = (−1)^n δ with δ = x_{a_0} − x_{b_0}. Periodicity gives δ = (−1)^k δ, so δ = 0 when k is odd. If δ = 0 we use Step 2. Otherwise k is even and we use Step 3.

### 4.3 Step 2: δ = 0 (type-E colourings)

Write y_n = x_{a_n} = x_{b_n} and ρ_n = x_{r_n}. Let Γ be the layered digraph with an arc from (n, c) to (n+1, c') iff c ∈ L_n, c' ∈ L_{n+1}, c ≠ c' and t(c, c') ∈ A(r_{n+1}). Arcs depend on n only modulo k. A *path* is a sequence p_0, …, p_k of colours with an arc from (i, p_i) to (i+1, p_{i+1}) for each i < k. Write T(c, c') if some path has p_0 = c and p_k = c'. A closed walk that winds j times around the prism is a cycle of length j of the relation T.

*Closing.* If T(c, c), the path extended periodically gives the type-E colouring c_a = c_b = p and c_r(n+1) = t(p_n, p_{n+1}). It is allowed and proper by the definition of the arcs.

*Splicing.* Let p and q be paths. If n < k and there is an arc from (n, p_n) to (n+1, q_{n+1}), then the sequence equal to p up to n and to q after n is a path, so T(p_0, q_k). The same holds when p_n = q_n for some n ≤ k.

*Successor lemma (2a).* If y_n(c) > 0, then some c' ≠ c has y_{n+1}(c') > 0 and ρ_{n+1}(t(c,c')) > 0. In particular there is an arc from (n, c) to (n+1, c') (positivity implies allowedness). *Proof.* Let d, e be the other two colours, so t(c,d) = e and t(c,e) = d. Suppose the claim fails for both c' = d and c' = e. There are four cases. If y_{n+1}(d) = y_{n+1}(e) = 0, then y_{n+1}(c) = 1, and (V) at colour c gives y_n(c) = 0. If y_{n+1}(d) = ρ_{n+1}(d) = 0, then (V) at colour d gives y_n(d) = 1, so y_n(c) = 0. The case y_{n+1}(e) = ρ_{n+1}(e) = 0 is symmetric. If ρ_{n+1}(d) = ρ_{n+1}(e) = 0, then ρ_{n+1}(c) = 1 and (V) gives y_n(c) = 0. ∎

Iterating the successor lemma k times shows that every c with y_0(c) > 0 has T(c, c') for some c' with y_0(c') = y_k(c') > 0. Choose c₀ with y_0(c₀) > 0 and successors c₁, c₂, c₃ in this sense. Suppose, for contradiction, that T has no loop T(c, c).

*No 2-cycles (2d).* Suppose T(c, c') via p and T(c', c) via q. Then:
1. p_n ≠ q_n for all n ≤ k (else splicing gives T(c, c));
2. there is no arc from (n, p_n) to (n+1, q_{n+1}), or from (n, q_n) to (n+1, p_{n+1}) (else T(c, c) or T(c', c')).

Write A_n = p_n, B_n = q_n, and call x *present* at layer n if x ∈ {A_n, B_n}. Present colours lie in L_n.
- *Leaving and entering.* If x is present at n but not at n+1, or at n+1 but not at n, then x is the third colour of one of the two arcs at that step, so s_{n+1}(x) = 1.
- *Run lemma.* If x is present at layers n₀ and n₀+1 and s_{n₀+1}(x) = 0, then x is present at every layer 0, …, k. Forward: if x is present at n with s_n(x) = 0, then (P2) gives s_{n+1}(x) = 0, so x cannot leave. Backward: if x is present at n with s_{n+1}(x) = 0, then (P2) gives s_n(x) = 0, so x cannot have entered at n. This is an induction on the linear range of layers; no cyclic run is needed.
- *An always-present colour.* If every step is a swap (A_{n+1} = B_n, B_{n+1} = A_n), the set {A_n, B_n} is constant, so A_0 is always present. Otherwise take a step n₀ that is not a swap. If A_{n₀+1} = B_{n₀}, then x = B_{n₀} is present at n₀ and n₀+1. Also A_{n₀} ≠ B_{n₀+1} and t(A_{n₀}, B_{n₀+1}) = x, so by 2 there is no arc from (n₀, A_{n₀}) to (n₀+1, B_{n₀+1}), which forces s_{n₀+1}(x) = 0. If A_{n₀+1} ≠ B_{n₀}, then B_{n₀+1} = A_{n₀}, and the symmetric argument applies to x = A_{n₀}. The run lemma makes x present at every layer.
- *Contradiction.* x ∈ L_n ⊆ A(a_n) for every n < k, so k is even by (P1). At every step x changes lap: if x = A_n, then x ≠ A_{n+1}, so x = B_{n+1}, and symmetrically. After an even number k of steps x is on its starting lap. But A_k = c' = B_0 and B_k = c = A_0, and c ≠ c'. Contradiction.

*No 3-cycles (2c).* Suppose T(c₀,c₁), T(c₁,c₂), T(c₂,c₀) via paths p⁰, p¹, p² with c₀, c₁, c₂ distinct, and suppose there are no loops and no 2-cycles. At layer 1 the three values p^X_1 are distinct. Otherwise splicing gives T(c_X, c_{Y+1}) with Y ≠ X, which is a loop or, together with the third path, a 2-cycle. So the arcs from layer 0 to layer 1 form a derangement of the three colours, whose three thirds are all colours, and A(r_1) = {0,1,2}. Exactly one of p¹_1, p²_1 equals c₀. Take the other one, p^Y_1. There is an arc from (0, c₀) to (1, p^Y_1), and splicing gives T(c₀, c_{Y+1}). For Y = 1 this is T(c₀, c₂), a 2-cycle with T(c₂, c₀). For Y = 2 it is a loop. Contradiction.

*Conclusion.* With no loops and no 2-cycles, adjacent colours in c₀, c₁, c₂, c₃ differ, and c₀ ≠ c₂ and c₁ ≠ c₃. In three colours this forces c₃ = c₀, which gives a 3-cycle with distinct colours, contradicting (2c). So a loop T(c, c) exists, and closing it gives an integral point.

*Comparison with PROOF-317750.md.* The proof lane extracts a simple cycle of winding j ∈ {1,2,3} and splices. Here we work with the relation T on the at most three colours of layer 0, and splicing is concatenation of index ranges, as the review suggested. The proof lane's run lemma uses maximal cyclic runs. Here it is a forward and backward induction on the layers 0, …, k of the two-turn walk.

### 4.4 Step 3: δ ≠ 0, k even (type-S colourings)

Since Σ_c δ(c) = 0 and δ ≠ 0, there are colours α, β with δ(α) > 0 > δ(β). Let γ = t(α, β). If δ(γ) < 0, exchange the two cycles (u ↔ w). This replaces δ by −δ, and the roles of α, β become those of β, α with third colour γ. So assume δ(γ) ≥ 0. From x_{a_n} − x_{b_n} = ±δ and nonnegativity:

  (F) for even n: x_{a_n}(c) ≥ δ(c) and x_{b_n}(c) ≥ −δ(c); for odd n: x_{a_n}(c) ≥ −δ(c) and x_{b_n}(c) ≥ δ(c).

*Type-S colourings.* For distinct colours p, q, let c_a(n) = p for even n and q for odd n, c_b(n) = q for even n and p for odd n, and c_r ≡ t(p, q). This is proper and k-periodic (k even). It is allowed if x_{a_n}(p), x_{b_n}(q) > 0 for even n, x_{a_n}(q), x_{b_n}(p) > 0 for odd n, and t(p, q) ∈ A(r_n) for all n.

*Propagation.* If, for a colour c, c ∉ A(r_{m+1}) implies c ∈ L_{m+1} for every m, then excluding c from one rung excludes it from all rungs. This follows from (P2) by forward induction from that rung, and periodicity covers the rungs before it.

If γ ∈ A(r_n) for all n, the type-S colouring with (p, q) = (α, β) is allowed by (F). Otherwise γ is excluded from some rung.

- *Case δ(γ) = 0.* Then x_{a_n}(γ) = x_{b_n}(γ), and x_{a_n}(γ) < 1 for all n, because by (F) colour α (n even) or β (n odd) has positive weight on a_n. If γ ∉ A(r_{m+1}), then ρ_{m+1}(γ) = 0, and (V) gives x_{a_m}(γ) + x_{a_{m+1}}(γ) = 1, so x_{a_{m+1}}(γ) = x_{b_{m+1}}(γ) > 0 and γ ∈ L_{m+1}. By propagation γ is excluded from every rung, and then x_{a_n}(γ) > 0 for all n. Next, β ∈ A(r_n) for all n. If β is excluded from a rung, take a positive index n for it by periodicity. Then ρ_n = e_α, and (V) gives x_{a_{n−1}}(α) = x_{a_n}(α) = 0, contradicting (F) at the even one of n−1 and n. The type-S colouring with (p, q) = (α, γ) and rungs t(α, γ) = β is then allowed.
- *Case δ(γ) > 0.* For c ∈ {α, γ} with c' the other one: if c ∉ A(r_{m+1}), then (V) gives x_{a_m}(c) + x_{a_{m+1}}(c) = 1 = x_{b_m}(c) + x_{b_{m+1}}(c). If m+1 is even, x_{a_{m+1}}(c) ≥ δ(c) > 0, and x_{b_m}(c') ≥ δ(c') > 0 gives x_{b_m}(c) < 1, so x_{b_{m+1}}(c) > 0. The odd case is symmetric. So c ∈ L_{m+1}, and propagation applies to c. If α ∈ A(r_n) for all n, the type-S colouring with (p, q) = (γ, β) and rungs t(γ, β) = α is allowed. Otherwise both α and γ are excluded from every rung, so ρ_1 = e_β, and (V) gives x_{a_1}(β) = 0, contradicting (F) at n = 1.

This completes the proof of Theorem 2. ∎

## 5. Translation between the prism and the ladder (Lean: `PrismPolytope.lean`)

Every vertex of `Fin k × Bool` is `vtx (m+1) b = ((m+1) mod k, b)` for some m. Its neighbours are exactly `vtx (m+2) b`, `vtx m b` and `vtx (m+1) (!b)`, and these are distinct for k ≥ 3 (`adj_iff`, `neighborFinset_eq`). Condition 2 therefore reduces to the three-term equation (V) (`sum_ne_nbr`). In the other direction, an edge colouring of the ladder defines the colour of an edge {a, b} of the prism symmetrically (`colOf`, `colOf_symm`, using k ≥ 3). Its indicator satisfies Conditions 1–4 (`prism_polytope`).

## 6. Vacuity checks (Lean: `PrismMain.lean`)

- `prism_regular : (prism k hk).IsRegularOfDegree 3` and `prism_edges : (prism k hk).edgeFinset.card = 3 * k`. So `prism k hk` is the cubic prism with 3k edges and not a degenerate graph.
- `cube_good_point`: for k = 4 and the HAP set with H(0) = {u₀, u₂, w₀, w₂}, H(1) = {u₁, u₃, w₁, w₃}, H(2) = {u₀, u₁, u₂, u₃} (A(d) the complement), P(G, HA) contains an explicit integral point. So the polytope hypothesis can hold.
- `cube_hyp_satisfiable`: for k = 4 some v ∈ N̄(PM(V)) has v|_K = χ_E. So the hypothesis of Definition 4 is satisfiable and Theorem 1 is not vacuous.
- `cube_bad_empty`: for k = 4 and the HAP set with H(0) = {u₀, u₁, u₃, w₀} (days 1 and 2 as above), P(G, HA) = ∅. So the polytope condition is not trivially true.

## 8. Significance

The theorem settles Kashiwabara's conjecture for all prisms by using the alternation between the two cycles and the parity of the allowed day cuts. The scope is one family of cubic graphs. Kashiwabara's Example 24 gives a cubic bipartite graph for which the implication fails, and his Theorem 19 gives a separate obstruction for 4-regular antiprisms. The proof gives a compatible integral schedule whenever a fractional one exists. It leaves Briskorn's complete-graph conjecture outside its scope.

## 9. Prior art

Kashiwabara verified the cube and pentagonal prism by Hilbert-basis computations in Section 4.4. Both arXiv versions and the journal version leave the general prism conjecture open. Corollary 9 gives the equivalent feasibility formulation. The bibliography and archive searches for the cross-model review found no earlier solution. The public search and its access limits are recorded in `CROSS-REVIEW-317750.md`.

## 10. Computations

The cross-model review used exact rational feasibility checks and direct enumeration of proper edge colourings on all balanced three-day HAP tables for the triangular prism and cube. Both methods found 63 feasible tables out of 220 for the triangular prism and 1,339 out of 7,770 for the cube, taking the days up to permutation and each partition up to exchanging its blocks. The script `check_prism.py` reproduces the counts. The Lean proof treats every k ≥ 3 symbolically.
