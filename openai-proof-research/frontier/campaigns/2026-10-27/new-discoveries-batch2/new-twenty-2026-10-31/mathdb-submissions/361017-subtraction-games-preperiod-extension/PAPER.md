# Seeded subtraction games with at most three moves: the converse of the extension criterion

*A proof of Conjecture 2 of Miklós and Post, with a Lean 4 formalization*

Claude Opus 5.5 produced the proof, Lean code and first review in separate sessions. GPT-6.2 Sol performed the
cross-model review and revised this manuscript. The campaign's root replay rebuilt and kernel-checked the six
Lean modules from the source appendix.

## Abstract

Let A ⊂ ℕ⁺ be a finite set with |A| ≤ 3 and let S be a seed. Miklós and Post conjectured that if every number
kp + x (k ≥ 1, x ∈ A, p the period) is an extension of the game (A, S), then the outcome sequence has no
preperiod. We prove this, in a stronger form: the hypothesis for k = 1 is enough, p may be any eventual period,
and p + x ∈ A is allowed. The key step is a counting lemma: for |A| ≤ 3, a periodic solution of the subtraction
recurrence on ℤ never has a 1 at m with 1's at all of m + A (Lemma K). A four-move example shows the lemma is sharp. The Lean 4 development with Mathlib includes the definitions,
eventual periodicity,
the conjecture as stated, the stronger form, and kernel-checked examples. The examples show that the hypothesis
can be satisfied and that the bound 3 is needed.

## 1. The conjecture and the source's definitions

István Miklós and Logan Post state Conjecture 2 in Section 7 of both versions of *Superpolynomial period
lengths of the winning positions in the subtraction game*. The journal version appeared in *International
Journal of Game Theory* **53** (2024), 1275–1313. [arXiv:2312.02426v1](https://arxiv.org/abs/2312.02426)
and [journal version](https://doi.org/10.1007/s00182-024-00911-5).

**Conjecture 2.** For a finite nonempty subtraction set A of positive integers with |A| ≤ 3, put α = max A.
For every seed S ∈ {0,1}^α let p = Per(A,S). If kp + x is an extension of (A,S) for every positive integer k
and every x ∈ A, then PrePer(A,S) = 0.

The definitions below follow Sections 2, 2.1 and 2.2 of the source. In Lean, `true` encodes 1, a win for the
player to move, and `false` encodes 0.

| Source | Lean |
|---|---|
| A finite nonempty set A of positive integers with α = max A. | `A : Finset ℕ` with `0 ∉ A` and `hne : A.Nonempty`. In `Conjecture2`, the seed has type `Fin (A.max' hne) → Bool`. |
| Equation (1). At n ≥ 0, w(n) is winning if some predecessor n − x, for x ∈ A, is losing. | `w A S j` for `j ≥ 0` is `!(decide (∀ x ∈ A, (if _ : 0 < x then w A S (j - x) else true) = true))`. Every x in the endpoint is positive, so the recursive branch applies, as stated in `w_rec`. |
| Definition 3 and Equation (2). The seed is w(−α), …, w(−1). | `seedVal S j` uses the index `j + α` for `−α ≤ j < 0`, so `S i = w(i − α)`. |
| A short seed is left-padded with 1's. | `seedVal S j = true` for `j < −α`. For `j < 0`, `w A S j = seedVal S j`. |
| The outcome sequence generated by the seed starts at n = 0. | `seq A S n = w A S n` for `n : ℕ`. |
| Definition 2. The period is the least positive p for which w(n) = w(n + p) for all n ≥ N for some N ≥ 0. The preperiod is the least such N. | `PeriodicOver f p := ∃ N, ∀ n, N ≤ n → f n = f (n + p)`. `Per A S := Nat.find (exists_period A S)` minimizes over positive p. `PrePer A S := Nat.find (exists_preper A S)` minimizes N at that period. |
| Lemma 2.2 in the preprint, Lemma 2 in the journal. The finite windows force eventual periodicity. | `exists_period` proves the required positive-period existence by pigeonhole. |
| Definition 4. An extension is a move b outside A whose insertion leaves the entire outcome sequence unchanged for the same seed. | `IsExt A S b := b ∉ A ∧ seq (insert b A) S = seq A S`. The same `S` is used after insertion, with any additional padding supplied by `seedVal`. |

The Lean statement of the conjecture is

```lean
def Conjecture2 : Prop :=
  ∀ (A : Finset ℕ) (_h0 : 0 ∉ A) (hne : A.Nonempty), A.card ≤ 3 →
    ∀ S : Fin (A.max' hne) → Bool,
      (∀ k : ℕ, 0 < k → ∀ x ∈ A, IsExt A S (k * Per A S + x)) → PrePer A S = 0

theorem conjecture2 : Conjecture2
```

Fidelity remarks.
1. The period is the least *positive* p. The source leaves "p ≥ 1" implicit; with p = 0 the definition would be
   trivial.
2. `A.Nonempty` is needed so that α = max A exists. For A = ∅ the source's α is undefined.
3. Per and PrePer are `Nat.find` over existence statements proved in Lean (`exists_period` is Lemma 2.2), so
   neither has a default value.
4. The definitions accept a seed of any length α. A shorter seed is padded on the left with 1's, as the source
   specifies. The conjecture uses exactly α = max A. The examples use the source's seed 0110 of length 4 for
   A = {3,5}, which is padded to 10110.
5. "Extension" requires b ∉ A, as in Definition 4. It compares the two sequences at every n ≥ 0.

## 2. Results

**Theorem A (stronger form; Lean `pure_of_period`).** Let A ⊂ ℕ⁺ be finite with |A| ≤ 3, let S be any seed, and
let p ≥ 1 be such that {w_{A,S}} is periodic over p. Suppose that for every x ∈ A, either p + x ∈ A or p + x is an
extension of (A, S). Then w(n) = w(n + p) for every n ≥ 0.

**Corollary B (Lean `conjecture2_k1`, `conjecture2`).** Under |A| ≤ 3, if p + x is an extension for every x ∈ A,
where p = Per(A,S), then PrePer(A,S) = 0. In particular Conjecture 2 holds.

Proof of the corollary: apply Theorem A with p = Per(A,S); then N = 0 satisfies Definition 2, so the least such N
is 0. The hypothesis of Conjecture 2 for k = 1 is the hypothesis of Corollary B. ∎

**Theorem C (Lemma K; Lean `lemmaK`).** Let |A| ≤ 3, p ≥ 1, and let P : ℤ → {0,1} satisfy P(m + p) = P(m) and the
recurrence at every m ∈ ℤ: P(m) = 0 ⇔ P(m − x) = 1 for all x ∈ A. If P(m) = 1, then P(m + y) = 0 for some y ∈ A.

**Sharpness and non-vacuity (all kernel-checked, module `SubtractionExamples`).**
* A = {1,5,6}, seed 011011 (w(−6), …, w(−1) = 0,1,1,0,1,1): Per = 7, PrePer = 0, and every 7k + x (k ≥ 1,
  x ∈ A) is an extension. The no-seed game has period 11, so this seed changes the period.
  `conjecture2_hypothesis_satisfiable`: the hypothesis of `Conjecture2` holds for this A with a seed of the
  literal type `Fin (A.max' hne) → Bool` that is not all ones.
* The source's examples: Per({2,4,7}) = 3 and PrePer({2,4,7}) = 4 (`ex247`). For A = {3,5} and S = 0110:
  Per = 8, PrePer = 0, and 11 = 8 + 3 is not an extension (`ex35`, `ex35_not_ext`). The game {3,5,11} with the
  same seed has the word 0·1⁵·0·1·0·1³·(01)^∞ and period 2 (`ex35_11`). The source says this "caused a preperiod of length
  12". That is the length of the printed prefix. By Definition 2 the preperiod is 11, because w(11) = w(13) = 1.
  Lean proves 11.
* |A| = 4: for A = {1,2,6,11} with no seed (the source's counterexample), Per = 12, PrePer = 1, and every 12k + x
  is an extension (`ex4`, `ex4_hyp`). Hence the statement with |A| ≤ 4 is false (`conjecture2_fails_card4`).
  Lemma K also fails for {2,5,6,7}. The 12-periodic solution 110111111100 has P(1) = 1 and P(1 + y) = 1 for all
  y ∈ A (`not_lemmaK_2567`).

## 3. Proof

Throughout, w = w_{A,S} on ℤ. Its values at negative positions are the padded seed. Choose M ≥ x for every x ∈ A. For example, take max A when A is nonempty and take 0 otherwise. Write "w(j) = 1" for `true`.

**Recurrence and blocks.** For j ≥ 0, w(j) = 0 iff w(j − x) = 1 for all x ∈ A (`w_rec`). Block lemma
(`shift_of_block`): if a ≥ 0, p ≥ 0 and w(j) = w(j + p) for all j ∈ [a − M, a), then w(j) = w(j + p) for all j ≥ a − M.
Proof by induction on j. For j ≥ a ≥ 0, both w(j) and w(j + p) are determined by the values at j − x and
j + p − x (x ∈ A). Each j − x lies in [a − M, j), where the induction hypothesis gives equality with its p-shift.

**Eventual periodicity (Lemma 2.2).** The windows (w(n − M), …, w(n − 1)) for n = 0, …, 2^M take at most 2^M
values, so two of them coincide, at N < N′. The block lemma with a = N and p = N′ − N gives periodicity over p
from N.

**Step 0 (extension ⇒ backward condition; `cond_of_isExt`).** Let b > 0 be an extension and B = A ∪ {b}. The
sequences w_B and w_A agree at negative positions (same padded seed) and at n ≥ 0 (by assumption). If n ≥ 0 and
w(n) = 0, then w_B(n) = 0, so by the B-recurrence w_B(n − b) = 1, that is, w(n − b) = 1. If instead p + x ∈ A,
the same conclusion is the A-recurrence. So under the hypothesis of Theorem A:

 (C) for all x ∈ A and n ≥ 0: w(n) = 0 ⇒ w(n − p − x) = 1.

**Step 1 (zeros translate backwards).** For n ≥ 0: w(n + p) = 0 ⇒ w(n) = 0. Indeed (C) at n + p gives
w(n − x) = 1 for all x ∈ A, and the recurrence at n gives w(n) = 0.

**Step 2 (periodic part).** Let N be such that w(n) = w(n + p) for n ≥ N. For m ∈ ℤ put
P(m) = w(m + K(m)p), where K(m) = max(0, N + M − m). Then m + K(m)p ≥ N + M. Since w is p-periodic beyond N,
P(m) = w(m + kp) for every integer k ≥ 0 with m + kp ≥ N. Hence:
* P(m + p) = P(m);
* P satisfies the recurrence at every m ∈ ℤ. The recurrence of w at m + K(m)p ≥ 0 involves the positions
  m − x + K(m)p ≥ N, where w equals P(m − x);
* (B) for n ≥ 0, P(n) = 0 ⇒ w(n) = 0. We have w(n + K(n)p) = P(n) = 0, and Step 1 steps back K(n) times.

**Step 3 (Lemma K, Theorem C).** First a version on a finite abelian group. Let G be a finite abelian group, let
D ⊆ G with |D| ≤ 3, and let f : G → {0,1} satisfy f(m) = 0 ⇔ f(m − y) = 1 for all y ∈ D. Let Q = f⁻¹(0) and
T = f⁻¹(1).
* (i) Independence: z ∈ Q, y ∈ D ⇒ z + y ∉ Q (otherwise the recurrence at z + y would force f(z) = 1).
* If D = ∅, the recurrence forces f ≡ 0 and there is nothing to prove. Otherwise D = {a, b, c} as a set,
  with repetitions allowed.
* Put X_y = {m : m − y ∈ Q} and Y_y = {m : m + y ∈ Q}. By the recurrence, X_a ∪ X_b ∪ X_c = T. By (i),
  Y_a ∪ Y_b ∪ Y_c ⊆ T.
* Singles: |X_y| = |Y_y| by the bijection m ↦ m − 2y from X_y to Y_y.
* Pairs: |X_y ∩ X_z| = |Y_y ∩ Y_z|. Translating by −(y + z) maps {m : m − y, m − z ∈ Q} bijectively onto
  {m : m + z, m + y ∈ Q}.
* Triple: X_a ∩ X_b ∩ X_c ⊆ Y_a ∩ Y_b ∩ Y_c. Suppose m − a, m − b, m − c ∈ Q, and let y ∈ D. For every y′ ∈ D,
  m − y′ ∈ Q, so f((m − y′) + y) = 1 by (i). That is, every predecessor m + y − y′ of m + y is a 1, so the
  recurrence gives m + y ∈ Q.
* By inclusion–exclusion for three sets, |⋃Y| − |⋃X| = |⋂Y| − |⋂X| ≥ 0. So |⋃Y| ≥ |⋃X| = |T|. Together with
  ⋃Y ⊆ T this gives ⋃Y = T: every m with f(m) = 1 has some y ∈ D with f(m + y) = 0.

For P on ℤ, take G = ℤ/p, f(z) = P(z̃) with z̃ ∈ [0, p) a representative of z, and D the image of A in ℤ/p.
Then |D| ≤ |A| ≤ 3, and elements of A that coincide mod p are merged in D. Periodicity gives P(m) = f(m mod p),
and the recurrence transfers. ∎

**Step 4 (conclusion of Theorem A).** Suppose w(n) ≠ w(n + p) for some n ≥ 0. Let L be the least number with
w(n) = w(n + p) for all n ≥ L. Then L ≥ 1. Put n₀ = L − 1, so w(n₀) ≠ w(n₀ + p), and w(j) = w(j + p) for
j > n₀. For j > n₀ this gives w(j) = P(j). In particular w(n₀ + p) = P(n₀ + p) = P(n₀).
* If w(n₀) = 1, then P(n₀) = 0, and (B) gives w(n₀) = 0, a contradiction.
* If w(n₀) = 0, then P(n₀) = 1. For each y ∈ A the recurrence at n₀ + y gives w(n₀ + y) = 1, since its
  predecessor n₀ is a 0. Since n₀ + y > n₀, P(n₀ + y) = w(n₀ + y) = 1. This contradicts Lemma K.

Hence w(n) = w(n + p) for all n ≥ 0. ∎

**Where the Lean proof differs from the earlier written proof.** The pair terms are matched by one translation of
a single set, instead of the counting identity N(d) = N(−d). The periodic part uses the explicit shift K(m). The
eventual period comes from pigeonhole on windows of length max A. In all other respects the argument is the same.

**Certificates for the examples.** The examples use four proved criteria (module `SubtractionCompute`):
* the converse of the source's Proposition 2.8, that b ∉ A, b > 0 and w(n) = 0 ⇒ w(n − b) = 1 make b an
  extension (`isExt_of_cond`);
* a structurally recursive table of the first values of w, proved equal to w (`wc_eq`, `w_eq_look`);
* the block lemma, for Per and PrePer (`per_preper_of_check`);
* for "every kp + x is an extension": periodicity over p ≥ N₀ + M from N₀, with M bounding the moves and the seed length, plus a finite check on [−M, N₀)
  (`allExt_of_check`).

The finite checks are closed by `decide +kernel`, which is plain kernel evaluation and uses no extra axioms.

## 4. Scope and significance

In Section 2.2 the authors describe the conjecture as an observed pattern and give four-move counterexamples
to the unrestricted converse. Proposition 2.8 (journal Proposition 6) gives the criterion for an individual
extension. Lemma 2.12 (journal Lemma 9) tests pure periodicity in the unseeded game via translations near the
initial boundary. Under the extension hypothesis, losing positions of the periodic tail already occur in the
original sequence. Lemma K rules out extra early losing positions by showing that the losing classes cover
the winning classes in both directions. For up to three translates, inclusion–exclusion reduces the comparison
of the two covers to a single triple intersection.

The conclusion concerns binary outcomes, arbitrary seeds, and sets of at most three moves. It settles
Conjecture 2. The period bounds and the arithmetic classification of three-move games form separate questions.

Two distinctions matter for the seeded wording. The one-move conclusion also follows directly from the
source's Proposition 3.1. The source's Theorem 3.3 (journal Theorem 13) claims pure periodicity for all
two-move seeds, but under Equation (1), A = {1,3} and S = 000 give the outcome word 11·(10)^∞, with period 2
and preperiod 2. This seed fails the extension hypothesis. Also, the k = 1 hypothesis suffices for the
conclusion of Conjecture 2. It can be strictly weaker than the all-k hypothesis for a seeded game. For
A = {1,5} and S = 00110, the outcome word is (110)^∞. The moves 4 and 8 are extensions, while 7 = 2p + 1
connects the losing index 2 to the seed zero at −5, so 7 fails the extension criterion.

## 5. Related work

Manabe uses the source's translating-zeros criterion to study arithmetic conditions for pure periodicity in
unseeded three-move subtraction games. His main results concern specific period families and recover
Sprague–Grundy values. His Remark 58 discusses the separate Conjecture 3. [Manabe, arXiv:2609.05358v2](https://arxiv.org/abs/2609.05358v2).

Larsson and Saha survey the seeded problem and recount Austin's forward extension theorem for purely
periodic nim-sequences. The other citing works examined concern additive games, the sink convention, or the
complexity of evaluating the recurrence. The review found no prior resolution of Conjecture 2 in these
sources. [Larsson–Saha](https://arxiv.org/abs/2405.20054v2), [Larsson–Manabe](https://arxiv.org/abs/2603.10414v2),
[Bhagat et al.](https://arxiv.org/abs/2601.18715v3), [Parfenov–Vyalyi](https://arxiv.org/abs/2606.01175v1).

Ho gives a finite expansion test for unseeded nim-sequences. Flammenkamp proves backward determinacy
on collision-free windows when the move set with 0 adjoined is closed under x ↦ max(A)−x. He also studies seeded
orbits. The move-set symmetry in that result is a separate hypothesis from the cardinality bound in Lemma K.
[Ho, arXiv:1202.2986v3](https://arxiv.org/abs/1202.2986), [Flammenkamp, 1997, Satz 12](https://wwwhomes.uni-bielefeld.de/cgi-bin/cgiwrap/achim/index.cgi).

## 6. Computational corroboration

The cross-model review script `check_review.py` enumerates the 192,506 pairs (A,S) with
1 ≤ |A| ≤ 3, max A ≤ 11, and full-length seeds. It computes periods from the repeated windows, checks the
least period of each outcome cycle, and measures preperiods in outcomes from n = 0. It independently
transcribes the Lean recurrence on integer indices and compares the outcome values for each pair. Of these
pairs, 27,920 satisfy the all-k extension hypothesis, 29,803 satisfy the
literal k = 1 hypothesis, and 32,698 satisfy the stronger k = 1 hypothesis allowing moves already
in A. Every qualifying pair has preperiod zero. All-k tests reduce to finitely many k because once the added
move is large enough, only its residue modulo p matters. The script also checks Lemma K on
917 periodic orbits in the same range, counting an orbit once per move set, and
recomputes the named examples in Section 2.
