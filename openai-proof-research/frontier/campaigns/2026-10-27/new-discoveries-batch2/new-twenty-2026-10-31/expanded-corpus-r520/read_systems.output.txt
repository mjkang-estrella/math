                                                  of maximally independent sets. They are interesting in their own right.


                                           1      Introduction
                                           Given a graph H, we say that a graph G is H-saturated if it is maximally H-free, meaning G contains no copy
                                           of H but every graph G + e obtained by adding a new edge e to G contains H. The saturation problem is to
                                           determine, or at least estimate, the saturation number sat(n, H), defined (for graphs H with at least one edge
                                           and integers n ≥ 0) to be the minimum number of edges in an H-saturated graph G on n vertices. We are
                                           usually interested in fixed H and large n. The saturation problem is dual to the Turán forbidden subgraph
                                           problem of determining the extremal number ex(n, H), defined to be the maximum number of edges in an
                                           H-saturated graph G on n vertices. However, much less is known for the saturation problem than for the Turán
                                           problem. See [2] for a survey of the saturation problem.

                                           For certain H the saturation number is known exactly. In particular, Erdős, Hajnal and Moon showed (Theorem
                                           1 in [4]) that for r ≥ 2 and n ≥ r − 2, sat(n, Kr ) = (r − 2)n − r−1
                                                                                                             2  and that the unique extremal graph consists
                                           of a Kr−2 fully connected to an independent set of size n − (r − 2) (for n < r, Kn is the unique Kr -saturated
                                           graph on n vertices). Note that for large n this graph contains many vertices of degree r − 2. Moreover, this
                                           is the smallest possible degree of a vertex in a Kr -saturated graph on n ≥ r − 1 vertices. One might therefore
                                           ask what happens if we forbid vertices of degree r − 2, and more generally, vertices of small degree. In [1] (see
                                           the second paragraph of the introduction), this led us to define sat(n, Kr , t) for integers r ≥ 3, t ≥ r − 2 and
                                           large enough integers n to be the minimum number of edges in a Kr -saturated graph G on n vertices with
                                           δ(G) ≥ t (more precisely, such graphs exist if and only if n ≥ (r − 1)t/(r − 2)). This quantity (or rather the
                                           one obtained by replacing the condition δ(G) ≥ t with δ(G) = t) was first considered by Duffus and Hanson
                                           (second paragraph of the Introduction in [3]).

                                           One could also note that the extremal graph has r − 2 conical vertices (vertices adjacent to all other vertices),
                                           leading one to define sat∆ (n, Kr ) to be the minimum number of edges in a Kr -saturated graph G on n vertices
                                           with ∆(G) ≤ ∆, and indeed this quantity has been studied (see section 2.1 in [2]). In this paper, we instead note
                                           that for large n the extremal graph has many pairs of twins (vertices with the same neighbourhood), leading us
                                           to define tsat(n, Kr ) for integers r ≥ 3 and large enough integers n to be the minimum number of edges in a
                                           twin-free Kr -saturated graph G on n vertices. It is not immediately clear whether such graphs even exist, but
                                           we show that they do for fixed r and large n. In fact, we completely determine for which r and n such graphs
                                           exist.
                                           Theorem 1. Let r ≥ 3 and n ≥ 0 be integers. Then there exists a twin-free Kr -saturated graph on n vertices
                                           unless n = r, n = r + 1, r = 3 and n = 6, or r = 3 and n = 7.

One can also combine the twin-free and minimum degree conditions. The naive approach would be to define
tsat(n, Kr , t) for integers r ≥ 3, t ≥ r − 2 and large enough integers n to be the minimum number of edges
in a twin-free Kr -saturated graph G on n vertices with δ(G) ≥ t. We now explain why a more complicated
definition is in fact more natural.

A blow-up of a graph H is a graph G obtained by replacing each vertex of H with some positive number of
copies. Two copies in G are adjacent if and only if the vertices in H they are copies of are adjacent (in particular
copies of the same vertex are non-adjacent). Note that any two copies in G of a vertex in H are twins. It is
easy to check that G is Kr -saturated if and only if H is Kr -saturated, unless H is a clique on at most r − 2
vertices and G is a proper blow-up of H. An equivalent definition of tsat(n, Kr ) is the minimum number of
edges in a Kr -saturated graph G on n vertices that is minimal in the sense that it cannot be obtained from a
smaller Kr -saturated graph H in this way.

Note that δ(G) ≥ δ(H). Hence, given integers r ≥ 3 and t ≥ r − 2 and a Kr -saturated graph H with
δ(H) ≥ t, we can generate other Kr -saturated graphs G with δ(G) ≥ t by taking blow-ups of H (the conditions
δ(H) ≥ t ≥ r − 2 rule out the trivial exceptions). In [1], we saw that sat(n, Kr , t) = tn + O(1) (see page 1) and
that all approximately extremal graphs are obtained in this way (see Theorem 2). More precisely, Theorem 2 is
equivalent to the statement that every Kr -saturated graph G on n vertices with δ(G) ≥ t and e(G) = tn + O(1)
is a blow-up of a Kr -saturated graph H with δ(H) ≥ t and |H| = O(1).

This leads us to define tsat(n, Kr , t) for integers r ≥ 3, t ≥ r − 2 and large enough integers n to be the minimum
number of edges in a Kr -saturated graph G on n vertices with δ(G) ≥ t that is minimal in the sense that it
cannot be obtained by blowing up a smaller Kr -saturated graph H with δ(H) ≥ t. Equivalently, tsat(n, Kr , t)
is the minimum number of edges in a Kr -saturated graph G on n vertices with δ(G) ≥ t in which every pair of
twins is adjacent to a vertex of degree t. It is again not immediately clear whether such graphs even exist, but
we will see later that they do for large enough n.

Note that Theorem 2 in [1] is equivalent to the statement that tsat(n, Kr , t) = tn + ω(1). We show that for t
large enough relative to r, the ω(1) term tends to infinity like a sublinear power of n. While we do not determine
the exact power, we show that is is roughly 1/(t − r).

2     Systems
In this section we first sketch the proof of the lower bound in part 2 of Theorem 2. This then motivates the
definition of r-systems and variants thereof, which are certain structures that arise naturally in the sketch proof.
We then define certain extremal quantities in terms of these r-systems. Finally, we state several results providing
estimates for these quantities and establishing relationships between them and between them and tsat(n, Kr , t).

We first sketch the proof of the lower bound in part 2 of Theorem 2. Let G be a twin-free K3 -saturated graph
on n vertices. We need to show that e(G) ≥ (5 + 2/3) n + o(n). If e(G) = ω(n), there is nothing to prove, so we
may assume e(G) = O(n). Then by Theorem 4 in [1], G has a vertex cover (a set of vertices intersecting every
edge) C of size m = O(n/ log n). Let H = G[C] be the subgraph induced by C and F = {Γ(v) : v 6∈ C} be the
family of neighbourhoods of the vertices outside C. Note that the elements of F are sets of vertices in H and
that every vertex v 6∈ C gives a different element of F , since G is twin-free.

Since G is K3 -free, H is K3 -free and the sets in F are independent. Since G is K3 -saturated, the sets in F are
in fact maximally independent. Finally, since the vertices outside C are non-adjacent and G is K3 -saturated,
F is an intersecting family.

For each integer t ≥ 0, let Ft = {S ∈ F : |S| = t}. We will show that for all integers 0 ≤ t ≤ 4, K3 -free graphs
H with |H| = m and intersecting families F of maximally independent sets of vertices in H of size t, we have
|F | = O(m). We will also show that for all K3 -free graphs H with |H| = m and intersecting families F of
maximally independent sets of vertices in H of size 5, we have e(H) ≥ 2|F |/3+o (|F |). Hence |Ft | = O(n/ log n)
for every integer 0 ≤ t ≤ 4 and e(H) ≥ 2|F5 |/3+o(n), from which it easily follows that e(G) ≥ (5 + 2/3) n+o(n).

We now define r-systems and variants thereof, which are generalisations to all integers r ≥ 3 of the structures
that arose naturally in our sketch proof. Suppose we have a graph G and a vertex cover C of G. Let H = G[C]
be the subgraph induced by C and F = {Γ(v) : v 6∈ C} be the family of neighbourhoods of the vertices outside
C, as in the sketch proof. We no longer require G to be twin-free, so we think of F as a family with ‘multi-
plicities’ in the sense that for twins v and w outside C we consider Γ(v) and Γ(w) to be distinct elements of F
even though they are the same set. Note that the elements of F are again sets of vertices in H and that G is
completely determined by H and F . Let us write G(H, F ) for this graph G. It is then easy to work out the
conditions on H and F for G(H, F ) to be Kr -saturated, which leads to the following definitions and observation.


Definition 1. For an integer r ≥ 3, an r-system is a pair (H, F ), where H is a graph and F is a family of sets
of vertices in H with multiplicities, with the following properties.

    1. H is Kr -free.
    2. Every set S ∈ F is maximally Kr−1 -free, meaning H[S] is Kr−1 -free but H[S ∪ {v}] contains Kr−1 for
       every vertex v 6∈ S.
    3. H[S ∩ T ] contains Kr−2 for all S 6= T ∈ F .

Definition 2. For an integer r ≥ 3, a maximal r-system is an r-system (H, F ) such that for every missing edge
e in H, either H + e contains Kr or (H + e)[S] contains Kr−1 for some S ∈ F .

5    Open problems
The obvious open problems are to improve the estimates for the extremal quantities we defined.
Problem 1. Improve the estimates for tsat(n, Kr ) in Theorem 2.
Problem 2. Improve the estimates for tsat(n, Kr , t) in Theorem 3.
Problem 3. Improve the estimates for sr,t (m) in Theorem 4.
Problem 4. Improve the estimates for er,t (s) and e′r,t (s) in Theorem 6.


In light of Theorem 1, one might ask the following.
Question 1. For which r, t and n does there exist a Kr -saturated graph G on n vertices with δ(G) ≥ t that
cannot be obtained by blowing up a smaller Kr -saturated graph H with δ(H) ≥ t?


Though in some sense the Kr case is the most natural one, one could also define tsat(n, H) to be the minimum
number of edges in a twin-free H-saturated graph on n vertices for other graphs H. As in the case H = Kr , it
is not immediately clear whether such graphs even exist. By Theorem 1, in the case H = Kr , such graphs do
exist for fixed r and large n.
Question 2. For which graphs H do there exist twin-free H-saturated graphs on n vertices for large enough n?
The answer to Question 2 is not “All graphs”. Indeed, it is easy to show that when H is a matching, all H-free
graphs are blow-ups of a graph with O(1) vertices. Indeed, let G be an H-free graph. Let S be the set of
matched vertices in a maximal matching in G. Then, since G is H-free, |S| = O(1), and since the matching is
maximal, V (G)\S is an independent set. Together, these imply that G is a blow-up of a graph with O(1) vertices.

Kászonyi and Tuza showed that sat(n, H) = O(n) for all graphs H (see Theorem 1 in [7]). It is not at all clear
whether the same should hold for tsat(n, H), when it is well-defined.
Question 3. Do we have tsat(n, H) = O(n) for every graph H for which there exist twin-free H-saturated
graphs on n vertices for large enough n?

                                                          24
Tuza conjectured that the ratio sat(n, H)/n converges for all graphs H (see Conjecture 10 in [9]). Tuza’s
Conjecture is still wide open. It is again not at all clear whether the same should hold for tsat(n, H) when
tsat(n, H) = O(n).
Question 4. Does tsat(n, H)/n converge for all graphs H for which tsat(n, H) = O(n)?
