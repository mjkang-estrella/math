## Independent ordinary proof

Use finite undirected edge-indexed multigraphs, spanning subgraphs retaining every vertex, and connected components including isolated vertices. A connected component is a tree when its edge count is its vertex count minus one, and unicyclic when the counts agree, provided it is a pseudoforest. A loop contributes one edge and one cycle. For a rooted connected G containing a cycle let U(G) count spanning edge subsets with every component unicyclic. Let T(G,r) count those with the root component a tree and all other components unicyclic. These are actual graph families, not numbers defined by an arithmetic recurrence.

Basis bridge. The independent sets of B(G) are precisely pseudoforests. Every all-unicyclic spanning subset has |V| edges. An independent set has at most |V| edges, hence this subset is maximal independent. Conversely let an independent subset have a tree component C. If C is not all vertices, connectedness of ambient G gives an edge from C to a different subset-component. That edge is unused; adding it merges a tree with a tree or unicyclic component and still leaves at most one cycle. If C is all vertices, the subset is a spanning tree. Since G has a cycle, some edge is outside the tree; adding that edge makes exactly one cycle (also for a graph loop). Thus such a subset is not maximal. This proves both directions for bases, not just maximal cardinality candidates. In particular every basis has rank |V|; existence follows as well by extending a spanning tree with any extra edge. A basis may have several unicyclic components. No argument substitutes spanning trees for bases.

Seed. One vertex r with exactly one labeled loop has one U state (the loop) and one T state (the empty subset). Thus (U,T)=(1,1), with |V|+|E|=2.

X. Add a new labeled loop l at the current root. The U states omitting l correspond by identity to old U states. In a U state containing l, deletion of l turns exactly the root's unicyclic component into a tree and leaves all other components unicyclic: an old T state. Conversely adding l to any old T state creates exactly one cycle at the root. These are inverse maps. An old root-unicyclic component cannot accept l, because that gives two cycles. In a new T state l must be absent, and identity gives exactly the old T states. These disjoint exhaustive alternatives establish (U,T)->(U+T,T).

Y. Add a fresh vertex s, a single labeled edge e=rs, and designate s the new root. In a U state, e must be present: otherwise s is isolated and is a tree. Deleting the pendant vertex s and e leaves an old U state; adjoining them is its inverse and does not change a component's cycle count. For new T states with e absent, s is the isolated root-tree component, so the old restriction must be an old U state. For new T states with e present, s is a leaf in the root-tree component; deleting it gives exactly an old T state. Both converses hold and the two cases are disjoint. Hence (U,T)->(U,U+T). This checks the omitted-edge case rather than silently requiring all bridges in every basis.

Connectedness and existence of the seed cycle persist through X and Y. X adds one edge; Y adds one vertex and one edge. Edge identities persist even when several loops have the same endpoint. No spanning-subset multiplicity is lost.

Arithmetic. Let N>1 and choose 1<=a<N with gcd(N,a)=1. Repeatedly subtract the smaller coordinate of (N,a) from the larger. Positivity and gcd are preserved and the sum strictly decreases. Termination is at equal coordinates, hence at (1,1). Reverse each subtraction: subtraction in the first coordinate reverses as X; in the second as Y. Thus the graph word realizes exactly (N,a), with U=N. This does not need an operation that swaps the graph states. For canonical a/N=[0;q1,...,qr] with qr>1, Euclidean division groups these single subtractions into the qi, with the last block shortened by one to stop at (1,1) rather than (1,0). Length is S(a/N)-1. The one-quotient case a=1 gives N-1 subtractions as required. All qi are positive, so no zero-quotient orientation ambiguity occurs.

All N size bound. Aistleitner–Borda–Hauke, arXiv:2210.14095, introduction, defines Z_N^*={1<=a<=N:gcd(a,N)=1}, canonical last quotient >1, and S as the sum of all partial quotients. Corollary 2 states for ALL N>=3 there is a reduced fraction a/N with S(a/N)<=12/pi^2 log N log log N+O(log N). For N>1 the unit condition excludes a=N; hence this is precisely a numerator in [1,N-1]. This is not an average-over-denominators conclusion or a prime-only theorem. Theorem 1 is a uniform fixed-denominator concentration estimate; the corollary is expressly its consequence. The implied constant in Corollary 2 is uniform in N. A larger positive constant absorbs any finite initial range. No analytic proof of that published theorem has been rederived here.

For L=S-1, graph size s=|V|+|E|<=2+2L<=2S. Since log log N<=log N for N>=3, a single constant gives s<=C(1+log N)^2. N=1 is the seed; N=2 is one X, giving exactly two bases. Number vertices consecutively, number edges in creation order, and list both endpoint labels for each edge, including equal endpoints for loops. An explicit self-delimiting edge-list encoding uses O(s log(s+1)) bits, bounded by C'(1+log N)^3 after enlarging uniform constants. Thus the exact requested polylogarithmic presentation bound holds for EVERY positive N, including primes and small integers.

## Actual source bridge, prior art, and objections

Chan–Pak Proposition 5.20 is specifically a theorem about matching counts of forests. It uses rooted trees with (a,b)=(ma(H),ma(H-x)). Attaching a leaf and retaining the root yields (a+b,b); attaching it and choosing the new leaf as root yields (a+b,a). The complete proof then uses Calkin–Wilf/Euclidean arithmetic, first for prime targets and then disjoint union and prime factorization. This proof appears in both v1 and v2 and the author PDF. It does not mention pseudoforests, the root-tree defect state, or a parsimonious map into bicircular bases.

The dictionary at the level of arithmetic is complete: X is the first-coordinate shear, Y the second-coordinate shear. The matching retain-root step is the first shear; its new-root step is the second shear followed by swapping coordinates. One can track an orientation bit: when bicircular (U,T)=(a,b), matching retain-root uses X and keeps orientation, and matching new-root uses Y and reverses orientation. In reversed orientation (U,T)=(b,a), retain-root uses Y and preserves orientation, and new-root uses X and reverses orientation. Seed (1,1) agrees. If a translated word ends reversed, exchanging every X and Y exchanges its final coordinates by induction from the symmetric seed, recovering the desired first coordinate. This is a count/word dictionary. It is not a source-provided bijection of matching objects and bicircular bases. The graph-level meaning of the shears and U=b(B(G)) requires the independent lemmas proved above. Proposition 5.20 alone supplies none of these lemmas.
