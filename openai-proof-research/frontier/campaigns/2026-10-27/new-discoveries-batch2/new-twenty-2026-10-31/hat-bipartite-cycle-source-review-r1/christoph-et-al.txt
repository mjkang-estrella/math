                                                           The Hamilton space of pseudorandom graphs
                                                           Micha Christoph∗               Rajko Nenadov†                Kalina Petrova‡


                                                                                             Abstract
                                                   We show that if n is odd and p ≥ C log n/n, then with high probability Hamilton cycles in G(n, p)
                                                span its cycle space. More generally, we show this holds for a class of graphs satisfying certain
                                                natural pseudorandom properties. The proof is based on a novel idea of parity-switchers, which can




arXiv:2402.01447v1 [math.CO] 2 Feb 2024
                                                be thought of as analogues of absorbers in the context of cycle spaces. As another application of
                                                our method, we show that Hamilton cycles in a near-Dirac graph G, that is, a graph G with odd n
                                                vertices and minimum degree n/2 + C for sufficiently large constant C, span its cycle space.


                                          1     Introduction
                                          Given a graph G = (V, E), let E(G) denote the vector space of subsets of E over F2 , also known as
                                          the edge space. The elements of this vector space correspond to subsets of E, with addition defined
                                          as the symmetric difference. The cycle space C(G) ⊆ E(G) is defined as the subspace spanned by all
                                          (not necessarily induced) cycles in G, and Ck (G) ⊆ C(G) — by cycles of length exactly k. Determining
                                          conditions under which Ck (G) = C(G), for some k, is a well-studied problem in graph theory [3, 4, 5, 9,
                                          15, 16].
                                              Here we are interested in the case where Cn (G) = C(G), that is, in the case where Hamilton cycles
                                          span the cycle space. Note that if G contains an odd cycle, a necessary condition for Cn (G) = C(G) is
                                          that G has an odd number of vertices. Alspach, Locke, and Witte [2] showed that if Γ is a finite abelian
                                          group of odd order, then Cn (G) = C(G) for any connected Cayley graph G over Γ. Heinig [11] showed
                                          that the same holds if G is a graph with odd n vertices and minimum degree δ(G) ≥ (1 + ε)n/2, for
                                          any ε > 0 and n sufficiently large, and in [12] he obtained Cn (Gn,p ) = C(Gn,p ) with high probability for
                                          p ≥ n−1/2+o(1) . We improve both of these results. In the case of dense graphs, we improve the minimum
                                          degree to the one which is optimal up to an additive constant term.
                                          Theorem 1.1. There exists C > 1 such that the following holds for sufficiently large odd n. Let G be a
                                          graph with n vertices such that δ(G) ≥ n/2 + C. Then Cn (G) = C(G).
                                             In the case of random graphs, we improve the bound on p to p ≥ C log n/n, which is best possible
                                          up to the (multiplicative) constant C. More generally, we show an analogous statement for a class of
                                          pseudorandom graphs.

2     Proof Strategy
The following lemma is our starting point. A similar statement is also used as a starting point in [3, 5],
however after it the two approaches diverge.
Lemma 2.1. Let G be a Hamiltonian graph with odd n vertices, such that Cn (G) 6= C(G). Then there
exists a subgraph R ⊆ G for which the following holds:
(C1) R 6= G,
(C2) every Hamilton cycle in G contains an even number of edges from R, and

(C3) for every partition V (G) = A ∪ B we have

                                                eR (A, B) ≥ eG (A, B)/2

      and R 6= G[A, B].
Proof. Given a subspace S ⊆ E(G), we write S ⊥ for its orthogonal complement,

                                S ⊥ = {D ∈ E(G) : hD, Si = 0 for all S ∈ S},

where                                                 X
                                          hD, Si =            D(e)S(e)
                                                     e∈E(G)

with addition being done in F2 and, for any X ∈ E(G), X(e) is the indicator for e ∈ X. It is well known
that C ⊥ (G) is precisely the cut space of G, that is, it consists of all edge subsets corresponding to induced
bipartite graphs G[A, B], including ∅, for all partitions V (G) = A ∪ B.
   From Cn (G) ⊆ C(G) and the assumption of the lemma, we conclude Cn⊥ (G) \ C ⊥ (G) is non-empty. Let
R ⊆ G be a largest (in terms of edges) element of Cn⊥ (G) \ C ⊥ (G). Since R ∈ Cn⊥ (G), every Hamilton cycle
in G has an even number of edges in R (by the definition). Note that R + C ⊥ (G) ⊆ Cn⊥ (G) is disjoint
from C ⊥ (G) since it is a coset of C ⊥ (G). Therefore, R is not a cut of G but contains at least half the
edges over every cut (A, B), as otherwise R + G[A, B] ∈ Cn⊥ (G) \ C ⊥ (G) contradicts the maximality of
R. Finally, we have R 6= G, as otherwise R contains a Hamilton cycle, contradicting the fact that every
Hamilton cycle has an even number of edges in R. It is worth noting that this is the only place where
we use the fact that n is odd.
    Central to our proof is the notion of a parity-switcher.
Definition 2.2 (Parity-switcher). Given a graph G and a subgraph R ⊆ G, a subgraph W ⊆ G is called
an R-parity-switcher if it consists of an even cycle C = (v1 , v2 , . . . , v2k ) with an odd number of edges in
R, and vertex-disjoint paths Pi between vi and v2k−i+2 for 2 ≤ i ≤ k.
    A parity-switcher contains two Hamilton paths (that is, paths containing each vertex in V (W )):
               P                P           P
    • v1 → v2 →2 v2k → v2k−1 →3 v3 → v4 →4 v2k−2 → . . . → vk+1 , and
                P           P                    P
    • v1 → v2k →2 v2 → v3 →3 v2k−1 → v2k−2 →4 v4 → . . . → vk+1 .
Importantly, the two paths have a different parity of edges from R, since each Pi for 2 ≤ i ≤ k appears
fully in both paths and each edge of C is contained in exactly one of the paths (see Figure 1).

Proof strategy.     We use the following recipe for showing Cn (G) = C(G):
(S1) Suppose Cn (G) 6= C(G), and take R ⊆ G to be a subgraph given by Lemma 2.1.
(S2) Find a (small) R-parity-switcher W :
   (S2.a) Find an even cycle C = (v1 , . . . , v2k ) with an odd number of edges in R.
   (S2.b) Find edge-disjoint (short) paths Pi between vi and v2k−i+2 , for each 2 ≤ i ≤ k.
(S3) Find a Hamilton path H ′ from v1 to vk+1 in G \ (V (W ) \ {v1 , vk+1 }).
(S4) If H ′ contains an odd (even) number of edges in R, then choose a Hamilton path H ′′ in W from v1
     to vk+1 with an even (odd) number of edges in R.
(S5) Conclude that the concatenation of H ′ and H ′′ gives a Hamilton cycle H ⊆ G with an odd number
     of edges in R, contradicting (C2).
    A reader familiar with the concept of absorbers will notice their similarity to parity-switchers. Indeed,
the main goal of the parity-switcher is to reduce the problem to the one where we just aim to find a
Hamilton cycle, without any further restrictions (technically, the goal of absorbers is to reduce a problem
to the one about almost-spanning structures; morally, its goal is to change the problem in a way which
provides us more flexibility).
    To implement the strategy, we only need to take care of steps (S2) and (S3). In particular, as only
(S2.a) is concerned with R, this is the most difficult step (that being said, (S2.b) and (S3) are not simple,
however there is already an existing machinery which we make use of). The following lemma takes care
of Step (S2.a), and is the crux of our proof.

    To demonstrate the overall strategy, we give a short proof of Theorem 1.1.
Proof of Theorem 1.1. Suppose Cn (G) 6= C(G). Let R ⊆ G be a subgraph given by Lemma 2.1, which
we can apply since G is Hamiltonian by Dirac’s theorem [6]. Note that we only need to implement steps
(S2) and (S3).

Step (S2.a). Let ℓ = 10. We use Lemma 2.3 to obtain a cycle C = (v1 , . . . , v2k ) in G, of even length
at most 2ℓ, which contains an odd number of edges from R. Condition (L2) follows from (C1) and the
second part of (C3). To see that (L1) holds, first note that (C3) implies R has minimum degree at least
n/4 + C/2 and it is connected. Choosing C > 4ℓ, we have that for any S ⊆ V (G) of size |S| ≤ 2ℓ < C/2,
the minimum degree of R \ S is strictly larger than n/4. If a shortest path between some x and y in R \ S
is of length at least 10, then the neighbourhoods of the first, fourth, seventh, and tenth vertex on such a
path are disjoint – which cannot be given the minimum degree of R \ S.

Step (S2.b). Next, we need to connect vi to v2k−i+2 for every 2 ≤ i ≤ k. This can be done by
sequentially applying the fact that as long as the set S consisting of the vertices on the cycle and all the
obtained paths so far is of size less than C, any two vertices x, y ∈ V (G) are at distance at most two
in G \ (S \ {x, y}). As the set S is always of size at most 3ℓ (2ℓ vertices on the cycle, and at most one
additional vertex for each pair of vertices we are aiming to connect), this is indeed the case for C > 3ℓ.
This concludes the construction of an R-parity-switcher W .

Step (S3). Finally, G′ := G \ (V (W ) \ {v1 , vk+1 }) has minimum degree δ(G′ ) > n/2, thus by Dirac’s
theorem it contains a Hamilton path between any two prescribed vertices.

5     Concluding remarks
    • Heinig [12] showed that if Cn (Gn,p ) = C(Gn,p ) and G(n, p) is not a forest, then necessarily δ(Gn,p ) ≥
      3. This prompts the following hitting time problem, which would further refine Corollary 1.6:
       Problem 5.1. Suppose n is odd, and consider the random graph process {Gm }m∈(n) . Is it true
                                                                                                2
       that, with high probability, δ(Gm ) ≥ 3 implies Cn (Gm ) = C(Gm )?

    • We reiterate the question asked by Heinig [11]:
       Problem 5.2. Suppose n is odd and sufficiently large, and let G be a graph with δ(G) > n/2. Is it
       true that Cn (G) = C(G)?

       Theorem 1.1 answers this if δ(G) is just a bit larger, namely δ(G) ≥ n/2+C (taking C = 41 suffices).
       It would be interesting to see if the strategy outlined in Section 2, together with a stability-type
       case analysis akin to the one in [13], for example, can be used to resolve Problem 5.2. We leave this
       for future work.
