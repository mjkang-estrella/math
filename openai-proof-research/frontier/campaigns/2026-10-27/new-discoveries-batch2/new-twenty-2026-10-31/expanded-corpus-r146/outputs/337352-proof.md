## 1. Exact source statement and readings

MathDB 337352 (raw line: corpus chunk 0005, see `extracted.json`) copies Conjecture 2 of
Cheon, Jung, Kitaev and Mojallal, *Riordan graphs I: Structural properties*, arXiv:1710.04604
(v1, 12 Oct 2017, and still posed in v2, 13 Apr 2019 = Linear Algebra Appl. 579 (2019) 89-135):

> **Conjecture 2.** We have that diam(CG_{2^k}) = k and there are no io-decomposable Riordan graphs
> G_{2^k} ≇ CG_{2^k} of the Bell type satisfying diam(G_{2^k}) = k for all k ≥ 1.

v2 states, just before Conjecture 2, that Conjecture 1 was refuted in [26] = J.-H. Jung,
*Diameter of io-decomposable Riordan graphs of the Bell type*, arXiv:1901.11156, published in
Graphs and Combinatorics 38 (2022), article 7. Jung proves diam(CG_{2^k}) = k (Theorem 2.4) and proves
the uniqueness part only "for some special io-decomposable Riordan graphs" (Theorems 3.2 and 3.3: for
k ≥ 4, any G_{2^k} whose binary A-sequence differs from all-ones within its first 16 entries has
diameter < k). The published abstract (Springer page, receipt in `sources/receipts.jsonl`) has the
same scope.

The trailing quantifier "for all k ≥ 1" admits two readings.

* **(R1) per-k reading:** for every k ≥ 1, every io-decomposable Bell-type G_{2^k} with
  diam(G_{2^k}) = k is isomorphic to CG_{2^k}.
* **(R2) family reading:** the Catalan family is the only io-decomposable Bell-type family
  (one fixed g, all orders) with diam(G_{2^k}(g, zg)) = k for every k ≥ 1.

(R1) is false at k = 2 and k = 3 (Section 4). The k = 3 exception, A-sequence (1,1,1,1,1,1,0), is
printed with diameter 3 in Jung's own Table 1, so a literal (R1) refutation is a zero-credit,
source-data correction. (R2) is the reading consistent with the authors' tables and Theorem 3.3.

**Theorem (this lane).** For every k ≥ 4, if G = G_{2^k}(g, zg) is an io-decomposable Riordan graph
of the Bell type with diam(G) = k, then the first 2^k − 1 entries of its binary A-sequence are all 1,
so G = CG_{2^k} as labelled graphs.

**Corollaries.**
(a) (R2) holds: Conjecture 2 is true in the family reading. If g ≢ C (mod 2), its A-sequence has a
first zero at some index p. Choose k ≥ 4 with 2^k − 2 ≥ p. Then diam(G_{2^k}(g, zg)) ≠ k, and
diam(CG_{2^k}) = k by Jung's Theorem 2.4.
(b) (R1) holds exactly for k = 1 and k ≥ 4, and fails exactly for k = 2 and k = 3. This is a
complete per-k characterization.

## 2. Definitions used (source-literal)

* Binary Bell matrix B = B(g, zg) = [b_{i,j}] with g(0) = 1, determined by its binary A-sequence
  (1, a_1, a_2, ...). The recurrence (Jung eq. (9), CJKM Thm 2.2) is
  b_{0,0} = 1,
  b_{i+1,0} = a_1 b_{i,0} + ... + a_{i+1} b_{i,i},
  b_{i+1,j+1} = b_{i,j} + a_1 b_{i,j+1} + ... + a_{i−j} b_{i,i} (mod 2).
  Equivalently f = zg satisfies f = zA(f), and b_{i,j} = [z^i] g f^j = [z^{i−j}] g^{j+1}.
* Riordan graph G_n(g, f) (CJKM Def. 2.4 and eq. (4)): vertex set [n]; for i > j ≥ 1, i ~ j iff
  b_{i−2, j−1} = 1, i.e. iff [z^{i−1}] f^j ≡ 1.
* io-decomposable Bell type (CJKM Thm 4.6 = Jung Lemma 2.1): the binary A-sequence has the form
  (1, 1, a_2, a_2, a_4, a_4, ...), i.e. a_0 = a_1 = 1 and a_{2m+1} = a_{2m}. G_n depends only on
  a_0, ..., a_{n−2}.
* Catalan graph CG_n = G_n(C, zC), with A-sequence all ones (C = 1/(1 − zC), so A = 1/(1 − z)).
* diam: the usual graph diameter (CJKM Def. 4.21).

Throughout, K ≥ 4, N = 2^K and h = N/2.

## 3. Proof

**Published facts used** (all for io-decomposable Bell-type graphs):

* (P1) CJKM Thm 4.13 / Jung Lemma 1.3(i): in G_{2^s+1}, vertex 2^s + 1 is universal.
* (P2) Jung Lemma 2.5(ii) (from CJKM Thm 3.7): ⟨{2^s+1, ..., 2^{s+1}}⟩ ≅ G_{2^s} via i ↦ i − 2^s.
* (P3) Jung Thm 2.6 with Thm 2.4: in CG_{2^s}, the pairs at distance s are exactly (i, 2^s) with
  i ≤ 2^{s−1}, and every other pair is at distance ≤ s − 1. In particular d(1, v) ≤ s − 1 for
  v < 2^s.
* (P4) CJKM Thm 4.22 / Jung Lemma 1.3(iv): diam(G_n) ≤ ⌊log₂ n⌋.
* (P5) Jung eq. (8) (proof of Lemma 3.1), which follows from (P1) and (P2):
  diam(G_{2^{s+1}}) ≤ max(2, diam(G_{2^s}) + 1).
* (F) For m ≤ n, the induced subgraph of G_n on [m] is G_m (leading principal submatrix).

**Lemma A (neighbours of the last vertex; new).** Let G_N be any Bell-type Riordan graph with
binary A-sequence A, and N = 2^K. For 1 ≤ j < N, N ~ j iff j is odd and [w^{N−1−j}] A(w)^{−1} ≡ 1
(mod 2).

*Proof.* Lift A to Z[[w]] with 0/1 coefficients. By CJKM Thm 2.2 the integer Riordan array (g, zg)
with this A-sequence reduces mod 2 to B. Lagrange inversion for f = zA(f) gives the identity
n[z^n] f^j = j[w^{n−j}] A^n in Z, for n, j ≥ 1. Take n = N − 1, which is odd. Then
[z^{N−1}] f^j ≡ j [w^{N−1−j}] A^{N−1} (mod 2). Mod 2, A^N = A(w^N) ≡ 1 (mod w^N). Hence
A^{N−1} ≡ A^{−1} (mod 2, w^N), and N − 1 − j < N. Finally, N ~ j iff [z^{N−1}] f^j is odd. ∎

Machine check of Lemma A against the recurrence: 800 random Bell-type A-sequences with N = 8, ..., 64
(`scripts/riordan_tables.py`).

**Lemma B (a zero creates a low neighbour; new).** Let G_N be io-decomposable of Bell type with
a_i = 1 for all i ≤ h − 1. Suppose some a_p = 0 with h ≤ p ≤ N − 2, and take the least such p.
Then p is even, p = 2q with h/2 ≤ q ≤ h − 1, and N is adjacent to j = N − 1 − p, where
1 ≤ j ≤ h − 1.

*Proof.* If p were odd, then a_{p−1} = a_p = 0 with p − 1 ≥ h, contradicting minimality.
Write A ≡ (1 + w) H(w²) with H(x) = Σ_m a_{2m} x^m. Then H_m = 1 for m < q and H_q = 0, so
(1 + x)H(x) ≡ 1 + x^q + O(x^{q+1}). Hence U(x) := 1/((1 + x)H(x)) ≡ 1 + x^q + O(x^{q+1}). Also
A^{−1} ≡ (1 + w)/((1 + w)² H(w²)) = (1 + w) U(w²), so [w^{2q}] A^{−1} = [x^q] U = 1. Now
j = N − 1 − 2q is odd, and h/2 ≤ q ≤ h − 1 gives 1 ≤ j ≤ h − 1. By Lemma A, N ~ j. ∎

**Lemma C (one zero lowers the diameter).** Under the hypotheses of Lemma B with K ≥ 4,
diam(G_N) ≤ K − 1.

*Proof.* Let V1 = [1, h+1] and V2 = [h+1, N].
By (F) and (P1), ⟨V1⟩ = G_{h+1} has the universal vertex h + 1, so d(x, y) ≤ 2 on V1.
By (P2), ⟨V2⟩ ≅ G_h via i ↦ i − h. G_h depends only on a_0, ..., a_{h−2}, all of which are 1, so
⟨V2⟩ ≅ CG_h.
Upper bounds in induced subgraphs remain upper bounds in G:
* x, y ∈ V1: d ≤ 2 ≤ K − 1.
* x, y ∈ V2: d ≤ diam(CG_h) = K − 1 (Jung Thm 2.4).
* x ∈ [1, h], y ∈ [h+2, N−1]: d ≤ 1 + d_{⟨V2⟩}(h+1, y) = 1 + d_{CG_h}(1, y − h) ≤ 1 + (K − 2), by
  (P3) since y − h ≠ h.
* x ∈ [1, h], y = N: with j from Lemma B, d(x, N) ≤ d_{⟨V1⟩}(x, j) + 1 ≤ 3 ≤ K − 1, since K ≥ 4.
Every pair is covered, so diam(G_N) ≤ K − 1. ∎

**Proof of the Theorem.** Induction on k ≥ 4.

*Base k = 4.* There are 2^7 = 128 io-decomposable Bell-type A-prefixes (a_0, ..., a_14). Exhaustive
computation finds exactly one with diameter 4, the all-ones prefix (CG_16). The diameter
distribution is {2: 61, 3: 66, 4: 1} (`logs/riordan_all_k4.log`). The k = 5 case was also checked
exhaustively over all 2^15 = 32,768 prefixes: {2: 10881, 3: 21748, 4: 138, 5: 1}
(`logs/riordan_all_k5.log`).

*Step k → k+1 (k ≥ 4).* Let G = G_{2^{k+1}} have diameter k + 1. By (P5),
k + 1 ≤ max(2, diam(G_{2^k}) + 1), so diam(G_{2^k}) ≥ k. By (P4), diam(G_{2^k}) ≤ k. Hence
diam(G_{2^k}) = k, and by the induction hypothesis a_0 = ... = a_{2^k−2} = 1. Then
a_{2^k−1} = a_{2^k−2} = 1 by io-decomposability. If some a_p = 0 with 2^k ≤ p ≤ 2^{k+1} − 2,
Lemma C (with K = k + 1 ≥ 5) gives diam(G) ≤ k, a contradiction. ∎

Independent exhaustive confirmation of the k = 6 step: all 2^16 = 65,536 sequences with the first 32
entries equal to 1 were checked. Only the all-ones sequence has diameter 6; the others have diameter
4 (65,532) or 5 (3) (`logs/riordan_fast_K6_c*.log`). Lemma B's j = N − 1 − p was confirmed for all of
these, and for 3,000 random K = 7 samples (`logs/riordan_nbr_K*.log`, `logs/riordan_sanity.log`).

**Why k = 3 fails, and why K ≥ 4 is sharp.** At k = 3 (N = 8), A = 1111110 has its zero at p = 6.
Lemma B gives the extra edge {1, 8}, so the graph is CG_8 plus the edge {1, 8}. Lemma C's last bound
is then d ≤ 3, which is not < K = 3, and indeed the diameter stays 3. This is exactly the
(R1)-counterexample printed in Jung's Table 1.

## 4. Small cases (R1)

* k = 1: N = 2, a single graph (K_2), diameter 1. (R1) holds.
* k = 2: A = (1,1,0) gives edges {12, 13, 14, 23, 34} with diameter 2. It has 5 edges, while CG_4 has
  4 edges ({12, 13, 23, 34}), so it is not ≅ CG_4. (R1) fails.
* k = 3: A = 1111110 is CG_8 plus the edge {1, 8}. It has diameter 3 and 14 edges, versus 13 for
  CG_8. (R1) fails. Jung's Table 1 lists this sequence with diameter 3 (that table also has a typo:
  its 9th row duplicates 1111110 and should read 1111001, diameter 2; recomputed in
  `logs/riordan_tables.log`).

`theorem catalan_unique (k : ℕ) (hk : 4 ≤ k) (a : ℕ → ZMod 2) (hio : IoBell a) :
   diam (riordanGraph a (2^k)) = k → ∀ i, i ≤ 2^k - 2 → a i = 1`,
plus the family corollary `conjecture2_family`. Definitions are source-literal:
* the Bell matrix comes from the A-sequence recurrence (Jung (9)) as a recursive function on ℕ;
* adjacency is (4);
* IoBell is `a 0 = 1 ∧ a 1 = 1 ∧ ∀ m, a (2m+1) = a (2m)`;
* diam is `SimpleGraph.diam` on `Fin n`, or an explicit BFS eccentricity with a proved-sound bridge.

1. Generating-function bridge: b_{i,j} = coeff (g^{j+1}) (i − j) over `PowerSeries (ZMod 2)`, with
   g = A(zg). Medium.

   inversion, so this is HIGH; a direct coefficient-extraction proof is a possible alternative.
3. (P1), (P2), (P3), (P4) are published, but each needs a full general-k formalization: fractal
   self-similarity, the universal vertex, and the distance structure of CG_{2^s}. HIGH.
4. Base case k = 4: 128 graphs on 16 vertices. A kernel `decide` should work with an efficient
   checker, or a certificate of a short path for each pair. Low to medium.
5. Lemmas B and C and the induction: low to medium once 1–3 exist.
Overall Lean cost: HIGH (general-k structural formalization). There is no finite-certificate
shortcut, because the statement is for all k.
