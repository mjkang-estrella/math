# 344302: proof of Zhu's down-up-down-up conjecture for all n (candidate; ordinary proof, Lean not done)

Status: candidate full-scope proof. Not self-accepted. The ordinary proof combines exact finite computation (n ≤ 200) with an interval-certified analytic argument (n > 200). Lean formalization is not done, and the obstacles are listed in Section 6.

## 1. Statement

Source: C. Zhu, *Enumerating permutations and rim hooks characterized by double descent sets*, arXiv:1910.12818 (v1 and v2 both contain it; checked both e-prints). It is Conjecture 6.2 (`Paper_v2.tex` line 424):

> Given a fixed n ∈ ℕ, the numbers dd({i}; n) for 2 ≤ i < ⌈n/2⌉ follow a "down up down up" pattern: dd({i}; n) > dd({i+1}; n) if i is even, and dd({i}; n) < dd({i+1}; n) if i is odd.

Here dd(I; n) is the number of w ∈ S_n whose double-descent set {p ∈ [2, n−1] : w_{p−1} > w_p > w_{p+1}} equals I. The MathDB record 344302 (chunk 0006, line 3682) matches.

**Prior status.** Hänni, *Asymptotics of descent functions*, arXiv:2011.14360 (§ "Finitely many cases of asymptotic down-up-down-up"), proves only the first three inequalities, and only for all sufficiently large n. There, d_3({j}, n) = dd({j+1}; n). No later resolution was found (searches dated 2026-11-03), and there is no Omega or OpenAI registry entry.

**Theorem.** The conjecture holds for every n.

Write p = i − 2 ≥ 0 and q = n − i − 1. The range 2 ≤ i < ⌈n/2⌉ is exactly q − p ≥ 2. The claim is (−1)^p Δ(p, q) > 0, where Δ(p, q) := D(p, q) − D(p+1, q−1) and D(p, q) := dd({p+2}; p+q+3) / (p+q+3)!.

## 2. Exact convolution formula

Let c_m be the coefficients of 1/(1+z+z²), so (c_m) = (1, −1, 0, 1, −1, 0, …). Let f(z) = Σ_{m≥0} c_m z^m / m!, and let a_L = [z^L] 1/f(z). Then

**(★)** D(p, q) = Σ_{s≤p} Σ_{t≤q} c_s c_t / (s+t+3)! · a_{p−s} a_{q−t}.

Taking the empty set in place of {i} in the same argument gives a_L = dd(∅; L) / L!, which is David and Barton's EGF.

**Proof of (★).**

1. *Run structure.* DDes(w) = {i} holds exactly when every maximal decreasing run of w has length at most 2, except one run of length exactly 3 occupying positions i−1, i, i+1.
2. *Block counts.* For a composition b of n, the number of w that decrease on every block of b is n!/∏ b_j!. Moreover, w decreases on every block of b exactly when b refines the run composition c(w).
3. *Möbius inversion.* Inverting over the refinement order gives #{w : c(w) = c} = Σ_{b coarsening c} (−1)^{ℓ(c)−ℓ(b)} n!/∏ b_j!.
4. *Factorization over blocks.* Sum over all admissible c and exchange the order of summation. The signed sum over refinements factors over the blocks of b:
   - an ordinary block of size m contributes Σ over {1,2}-compositions of (−1)^{parts−1} = −c_m;
   - the block containing the 3-run, with s positions before it and t after it inside the block, contributes c_s c_t.
5. *Assembly.* Summing over the blocks to the left of the special block gives [z^L] 1/(1 − Σ_{m≥1} (−c_m) z^m/m!) = a_L, and likewise on the right. This yields (★).

(★) was also checked against direct DP enumeration for all 3 ≤ n < 22 (`scripts/dd_formula_check.py`, `logs/dd-formula.log`).

**Analytic data.**

- By the ODE f'' + f' + f = 0 with f(0) = 1 and f'(0) = −1, we have f(z) = (2/√3) e^{−z/2} sin(π/3 − √3 z/2).
- Its zeros are z_k = x0(1 + 3k), k ∈ ℤ, with x0 = 2π/(3√3) ≈ 1.2092. They are simple, and Res_{z_k} 1/f = −(−1)^k e^{z_k/2}.
- Set e_j = (−1)^j e^{z_j/2}/z_j. Then e0 ≈ 1.5138 and e_{−1} ≈ 0.12340.
- Let P(x) = e0/(1 − x/x0) + e_{−1}/(1 + x/(2x0)) and H = 1/f − P. Then H is analytic for |x| < 4x0, because the next zeros of f are 4x0 and −5x0.
- Define T(x, y) = Σ_{s,t} c_s c_t x^s y^t / (s+t+3)!, which is entire. Its coefficients are symmetric in s and t.

## 3. Main term

Let W_p(y) := Σ_{s≤p} a_{p−s} Σ_t c_s c_t y^t / (s+t+3)!, so that D(p, q) = [y^q] (1/f)(y) W_p(y). Expanding 1/f = P + H in y gives exactly

D(p, q) = Σ_{l∈{0,−1}} e_l z_l^{−q} (W_p(z_l) − tail_l) + [y^q] H(y) W_p(y).

Put U_p(z) := W_p(z) − z W_{p+1}(z). Then

x0^{p+q} Δ(p, q) = e0 x0^p U_p(x0) + e_{−1} (−1/2)^q x0^p U_p(−2x0) + E_R + E_tail,

where E_R comes from the y-side H terms and E_tail from the truncations in y. Now expand the x-side the same way, writing W_p(z) = [x^p] (1/f)(x) T(x, z):

- the pole at x0 cancels exactly in U_p(x0) up to superexponentially small truncation terms, because of the factor (1 − x0/x0);
- the pole at −2x0 contributes (3/2) τ (−1/2)^p, where τ := e0 e_{−1} T(−2x0, x0);
- in the mirror term, the pole at x0 contributes 3τ (−1/2)^q.

Hence

x0^{p+q} Δ(p, q) = (3/2) τ (−1/2)^p [1 + 2(−1/2)^{q−p}] + E,

with E the explicit error terms bounded in Section 4. Two consistency checks:

- At q − p = 1 the bracket vanishes, matching the symmetry dd({n/2}; n) = dd({n/2 + 1}; n) for even n.
- For q − p ≥ 2 the bracket lies in [1/2, 3/2], so the sign of the main term is (−1)^p sign(τ).

## 4. Rigorous bounds

All bounds are computed with mpmath interval arithmetic and outward rounding (`scripts/dd_rigorous.py`, output `outputs/dd-rigorous-output.txt`).

1. **τ.** τ ∈ [0.03249579939136517464618, 0.03249579939136517464619], so τ > 0.
2. **Remainder on a circle.** On |x| = r = 3x0, subdividing θ ∈ [0, π] into 2000 interval arcs (with conjugate symmetry) gives max |1/f| ≤ 6.134 and max |H| ≤ 7.138. By the Cauchy estimate, |[x^m] H(x) g(x)| ≤ max|Hg| / r^m.
3. **Error constants.**
   - x-side H error: |E1(p)| ≤ C1 3^{−p} with C1 ≤ 20.18.
   - Coefficient bound: sup_m a_m x0^m ≤ K0 ≤ 8.775.
   - Mirror term: |x0^p U_p(−2x0)| ≤ C2 ≤ 16.97.
   - y-side H term: |E_R| ≤ C3 3^{−q} with C3 ≤ 350.9.
   - Mirror x-side error: ≤ 2.06 · 2^{−q} 3^{−p}.
   - All x- and y-side truncation errors are bounded explicitly and are superexponentially small.
4. **Case B (p ≥ 20, any q ≥ p+2).** The main term is at least (3/4) τ 2^{−p}. It strictly exceeds the sum of all error bounds for every p ≥ 20 (`caseB_threshold_p: 20`, computed by interval comparison).
5. **Case A (p ≤ 40, n > 200, hence q ≥ 158).** The exact values (−1)^p e0 x0^p U_p(x0) are enclosed rigorously for p ≤ 40, and all are positive. At p = 0 the value is about 0.0209, and for large p it is about (3/2) τ 2^{−p}; the lower endpoints are listed in the output. The remaining terms are at most e_{−1} C2 2^{−158} + C3 3^{−158} plus truncations, which is far smaller (`caseA_ok: true`).
6. **Finite range n ≤ 200.** Exact dynamic programming over permutations by last rank and descent flag verifies the conjecture for every 4 ≤ n ≤ 200 and every i in range, using big integers (`scripts/dd344302.py`, `logs/dd-sweep-*.log`). The DP was brute-force checked against permutation enumeration for n ≤ 8, and it reproduces the source values dd({2}; 4) = 3 and dd({6}; 9) = 22419.

Since every n > 200 with q − p ≥ 2 falls under Case A or Case B, this proves the theorem. ∎

## 5. Remaining review points

- **Möbius step.** An independent reviewer should re-derive the Möbius/composition identity (★) in full. It was numerically confirmed only for n < 22.
- **Arc enclosure.** The circle bound relies on mpmath `iv` enclosures over 2000 arcs. A reviewer should re-run it with a different subdivision or an independent interval library.
- **Novelty and significance.** The conjecture comes from a high-school PRIMES paper. Hänni's 2020 partial progress shows the problem had been treated as open. The method (meromorphic generating function with explicit real poles) is standard analytic combinatorics. Root decides significance.

## 6. Lean feasibility

The finite part is formalizable: a DP checker for n ≤ 200 with a proved-sound Boolean checker. The analytic part needs:

- the meromorphic factorization of 1/f;
- Cauchy coefficient estimates on a circle (available in Mathlib through `HasFPowerSeriesOnBall` and Cauchy integral bounds);
- rigorous enclosures of transcendental constants and of a supremum over a circle.

This is a large formalization project, and no draft endpoint is supplied. A possible route is to replace the circle supremum by an explicit real-variable bound on |sin w|, proved by elementary inequalities on arcs.
