                   2. Preliminaries and general notation
   We refer to [11] for standard notation and terminology from additive [semi]group
theory (note that, in this paper, “additive” does not imply “commutative”).
   We denote by N the set of non-negative integers, endowed with its usual op-
erations and order, which we extend as customary to N ∪ {∞} by adjoining an
element ∞ ∈  / N and taking, in particular, 0 · ∞ := ∞ · 0 := 0.
   At several points, we will use without explicit mention that if A ⊆ B ⊆ N ∪
{∞} then inf(B) ≤ inf(A) and sup(A) ≤ sup(B), with the convention that the
supremum of ∅ is 0 and the infimum of ∅ is ∞.
   Unless differently stated, i and n shall denote positive integers. Given a set X,
we write |X| for the size of X if X is finite, and let |X| := ∞ otherwise.
   Here, a semigroup is a pair A = (A, +) consisting of a set A and an associative
binary operation + on A (we refer to [6] for basic aspects of semigroup theory).
   We let A× be the set of units of A, so A× = ∅ if A is not a monoid (or unital
semigroup). In this respect, we recall that, if A is unital with identity 0, a unit
of A is an element z ∈ A for which there exists a (provably unique) z̃ ∈ A, called
the inverse of z (in A), such that z + z̃ = z̃ + z = 0 (we usually denote z̃ by −z).
   For Z ⊆ A we write Z × instead of Z ∩ A× (if there is no likelihood of confusion)
and hZiA for the smallest subsemigroup of A containing Z. Then given z ∈ A, we
use ordA (z) for the order of z (in A), i.e. we let ordA (z) := |h{z}iA |, so generalizing
the common notion of order for the elements of a group.
   An element z ∈ A is said to be cancellable (in A) if x+z = y +z or z +x = z +y
for x, y ∈ A imply x = y, and A is cancellative if each z ∈ A is cancellable.
   Building on these premises, we assume for the remainder that A = (A, +) is
a fixed, arbitrary semigroup (unless differently noted), and let 0 be the identity
of a unitization, A(0) , of A: If A is unital, then A(0) := A; otherwise, A(0) :=

(A ∪ {0}, +), where 0 is some element ∈  / A and, by an abuse of notation, + is the

x̃ + x = y + ỹ = 0. This implies that z ∈ X × + Y × , and so we are done.             

                                6. Closing remarks
   While every commutative cancellative semigroup embeds as a subsemigroup
into a group (through the standard construction of the group of fractions of a
commutative monoid), nothing similar is true in the non-commutative setting, no
matter if the ambient semigroup is finitely generated or not. This is related to
an old question in the theory of semigroups first answered by A. I. Mal’cev in [9],
and serves as a “precondition” for the present paper, as it shows that the study
of sumsets in cancellative semigroups cannot be systematically reduced, in the
absence of commutativity, to the case of groups, at least not in an obvious way
(note that the semigroup considered by Mal’cev is also finitely generated).
   On the other hand, every semigroup embeds into a monoid (e.g., through the
unitization process of Section 2), with the result that, for the specific purposes
of the manuscript, we could have assumed almost everywhere that the “ambient”
is a monoid (rather than just a semigroup), but we did differently because, first,
the assumption is not really necessary (insofar as Theorem 7 is vacuously true if
A× = ∅), and second, it seems more appropriate to develop as much as possible
of the material with no regard to the presence of an identity (e.g., since this is
better suited for further generalizations).

necessary assumption for anything in the lines of Conjecture 6 to be true:
