li ). For example, decorated ordered set partition ({1, 2, 7}2, {3, 5}3, {4, 6}1) is same
as ({3, 5}3, {4, 6}1, {1, 2, 7}2). A decorated ordered set partition is called hypersimpli-
cial if it satisfies 1 ≤ li ≤ |Li | − 1 for all i. For the motivation and more background
on decorated ordered set partitions, see [6].

                                 5. Compatible A-Orders
   In this section we introduce our main tool: a linear order of A that is com-
patible with c ∈ G. This concept is an algebraic generalization of the compatible
reflection order introduced in [2], and it also appeared in [31] in the context of
complex reflection groups. We recall Assumption 4.1: Red A (c) is assumed finite.
5.1. Definition and Properties of Compatible Orders. Recall that Ac = { a ∈ A |
a ≤ A c}. Observe that we trivially have Red A (c) = Red Ac (c).
   Let ≺ be any linear order on Ac . We say that a factorization ( a1 , a2 , . . . , aℓ A (c) ) ∈
Red A (c) is ≺-rising if ai  ai+1 for all i ∈ [ℓ A (c) − 1]. We denote by Rise(c; ≺)
the number of ≺-rising reduced A-factorizations of c for a given linear order ≺
on Ac .
5.1.1. Hurwitz Orbits and Rising Factorizations. The next statement relates these
rising factorizations to the Hurwitz orbits of Red A (c), in the specific case when
ℓ A (c) = 2.
Proposition 5.1. Let c ∈ G have ℓ A (c) = 2. Let Orb(c) denote the number of Hurwitz
orbits of Red A (c). Then:
