                                                                                      Abstract
                                                  Let G = (V, E) be a connected simple graph, with n vertices such that S is its
                                                  homogeneous monomial subring. We prove that if S is normal and Gorenstein,
                                                  then G is unmixed with cover number ⌈ n2 ⌉ and G has a strong ⌈ n2 ⌉-τ -reduction.
                                                  Furthermore, if n is even, then we show that G is bipartite. Finally, if S is normal
                                                  and G is unmixed whose cover number is ⌈ n2 ⌉, we give sufficient conditions for S to
                                                  be Gorenstein.
                                           Keywords: Gorenstein; τ -reduction; cover number; unmixed.

                                           A vertex cover is a subset C of V (G) such that C ∩ e 6= ∅ for each e ∈ E(G). The cover

                                           if every minimal vertex cover has τ (G) elements.
                                           A monomial algebra A is Gorenstein if A is Cohen-Macaulay and its canonical module
                                           ωA is a principal ideal. Hochsther ([6]) proved that if A is normal, then A is Cohen-

                                           with τ (G) = ⌈ n2 ⌉, we give sufficient conditions for S to be Gorenstein.

A subset F of V (G) is a stable set if y * F for each y ∈ E(G). The cardinality of
a maximum stable set is denoted by α(G). G is called well-covered if every maximal
stable set has α(G) elements. Also, F is a (maximal) stable set if and only if V (G) \ F
is a (minimal) vertex cover. Hence, τ (G) + α(G) = |V (G)| and G is unmixed if and
only if G is well-covered. G is very well-covered if G is well-covered and α(G) = n2
(equivalently, τ (G) = n2 ).
