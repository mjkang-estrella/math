James Tuite Email: james.t.tuite@open.ac.uk Abstract In this paper we consider a colouring version of the general position problem. The gp \gp -chromatic number is the smallest number of colours needed to colour the vertices of the graph such that each colour class has the no-three-in-line property. We determine bounds on this colouring number in terms of the diameter, general position number, size, chromatic number, cochromatic number and total domination number and prove realisation results. We also determine the gp \gp -chromatic number of several graph classes, including Kneser graphs K ⁡ ( n , 2 ) K(n,2) , line graphs of complete graphs, complete multipartite graphs, block graphs and Cartesian products. Finally, we show that the gp \gp -colouring problem is NP-complete. The authors would like to dedicate this paper to the memory of the eminent Indian graph theorist Prof. E. (2020) : 05C12, 05C15, 05C69 1 Introduction For any special property of a vertex subset of a graph G G , it is interesting to consider partitions of the vertex set of G G such that each part of the partition has that property, or, equivalently, colourings of V ⁡ ( G ) V(G) such that each colour class has the given property. The most basic example is the property of being an independent set, in which case the associated colourings are proper and the smallest possible number of colours in such a colouring is the chromatic number of the graph. A dual concept is clique partitions , which is equivalent to a proper colouring of the complement of the graph. Combining both concepts, a colouring is cochromatic if each colour class induces either an independent set or a clique; see [ 12 ] for a discussion of this problem. Another example comes from domination theory; the domatic number of G G , introduced in [ 5 ] , is the largest possible number of colours in a colouring of V ⁡ ( G ) V(G) such that each colour class is a dominating set. Other variations involve stronger distance conditions on the colour classes than independence; a 2-distance colouring requires two vertices in the same colour class to be at distance at least two (see [ 22 , 23 ] ), whilst injective colourings are colourings in which each colour class is an open packing , i.e. if u , v u,v are vertices with the same colour, then u u and v v have no common neighbours (see [ 1 , 15 ] ). In this paper we consider a related colouring problem inspired by the general position problem for graphs. This problem originated in a chessboard no-three-in-line puzzle of Dudeney [ 9 ] : how many pawns can be placed on an n × n n\times n chessboard such that no three pawns lie on a straight line in the plane? This question was generalised to graphs independently in [ 2 ] and [ 26 ] as follows: given a graph G G , what is the largest number of vertices in a subset S ⊆ V ⁡ ( G ) S\subseteq V(G) such that no three vertices in S S lie on a common shortest path of G G ? Colourings and partitions related to no-three-in-line problems have been studied in the literature before. In [ 34 ] Wood considers colourings of the n × n n\times n grid in which each colour class has Dudeney’s geometrical no-three-in-line property. In finite geometry, a capset is a set of points, no three of which lie on the same line; one problem of interest is to partition the vertices of a geometry into disjoint capsets, see for example [ 11 ] . A very recent paper [ 18 ] treats a colouring problem for a related position parameter, the mutual-visibility number, which was introduced in [ 7 ] . In this article we explore colouring problems for graphs in which each colour class is required to be in general position. The plan of this paper is as follows. Section 2 defines basic graph theory terminology and poses the colouring problems that we will be investigating. Section 3 provides some elementary bounds on our position colouring numbers and compares colouring numbers for different types of position sets, whilst Section 4 explores connections with other well-known types of colourings and graph domination. In Section 5 we obtain the gp \gp -colouring numbers of some common graph classes that are of interest in the general position problem and Section 6 discusses graphs with very large or small position colouring numbers. In Section 7 we investigate gp \gp -colourings of Cartesian products and strong grids. It is proven in Section 8 that the decision version of the gp \gp -colouring problem is NP-complete. We close in Section 9 with some open problems. 2 Preliminaries All graphs considered in this paper are finite, simple and undirected. We now define the vertex subsets that will form the focus of this paper. Definition 2.1 . A subset S ⊆ V ⁡ ( G ) S\subseteq V(G) is in general position , or is a general position set , if no shortest path of G G contains more than two vertices of S S . The general position number gp ⁡ ( G ) \gp(G) is the number of vertices in a largest general position set of G G . Several variants of the general position number have been considered in the literature (see [ 4 ] for a survey), some of which will be needed in our study. The monophonic position problem is defined by replacing ‘shortest path’ in Definition 2.1 by ‘induced path’ and was first investigated in [ 32 ] . A set M M of vertices of a graph G G is in monophonic position or is a monophonic position set if no induced path of G G contains more than two vertices of M M . The monophonic position number mp ⁡ ( G ) \mono(G) (or mp \mono -number for short) is the number of vertices in a largest monophonic position set of G G . The mutual-visibility problem , defined in [ 7 ] , is a relaxation of the no-three-in-line property: a set S ⊆ V ⁡ ( G ) S\subseteq V(G) is mutually-visible if for any pair u , v ∈ S u,v\in S there exists at least one shortest u , v u,v -path in G G that does not pass through a vertex of S − { u , v } S-\{u,v\} . The largest number of vertices in a mutual-visibility set is the mutual-visibility number μ ⁡ ( G ) \mu(G) . An independent general position set is a general position set that is also an independent set. Such sets were considered in [ 31 ] . The independent general position number is the number of vertices in a largest independent general position set and we will denote this by gp_i ⁡ ( G ) \igp(G) . Similarly, an independent monophonic position set is a monophonic position set that is also an independent set, and the number of vertices in a largest independent monophonic position set of G G is the independent monophonic position number mp_i ⁡ ( G ) \imp(G) . Since we will frequently wish to discuss several types of position set at the same time, we adopt the following convention. Convention 2.2 . If π \pi stands for a position type invariant (in this context μ ⁡ ( G ) \mu(G) , gp ⁡ ( G ) \gp(G) or mp ⁡ ( G ) \mono(G) ), then we call a subset of that type a π \pi -set . The corresponding independent π \pi -number will be denoted by π i ​ ( G ) \pi_{i}(G) . It is easy to see that for any connected graph we have mp ⁡ ( G ) ≤ gp ⁡ ( G ) ≤ μ ⁡ ( G ) \mono(G)\leq\gp(G)\leq\mu(G) . The graphs that we consider will not necessarily be connected; in this case, for any of the position type invariants π \pi described above, we will adopt the convention that a vertex subset S S of a disconnected graph G G is a π \pi -set of G G if and only if S ∩ V ⁡ ( H ) S\cap V(H) is a π \pi -set of H H for each component H H of G G . We may now formally define the colouring problems introduced in this article. Definition 2.3 . Let π ⁡ ( G ) \pi(G) be one of gp ⁡ ( G ) , mp ⁡ ( G ) \gp(G),\mono(G) or μ ⁡ ( G ) \mu(G) . A π \pi -colouring of a graph G G is a colouring of G G such that each colour class is a π \pi -set. The π \pi -chromatic number χ π ​ ( G ) \chi_{\pi}(G) is the smallest number of colours needed for a π \pi -colouring of G G . For independent position sets we define π i \pi_{i} -colourings and χ π i \chi_{\pi_{i}} -chromatic numbers analogously. In particular, the gp \gp -chromatic number χ gp ​ ( G ) \chi_{\gp}(G) is the smallest number of colours needed to colour V ⁡ ( G ) V(G) such that each colour class is a general position set of G G . Observe that for disconnected graphs, the π \pi -chromatic number will be the maximum of the π \pi -chromatic numbers of the components.
