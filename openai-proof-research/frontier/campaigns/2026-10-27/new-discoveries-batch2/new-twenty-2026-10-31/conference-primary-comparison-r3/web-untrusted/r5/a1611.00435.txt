2 Preliminaries

In this Section we summarize the main concepts and results to be used in the next
sections. We may quote [3] and [21] as general references.
     A q-ary linear code C of length n over the ring Zq is a Zq -submodule of Zn    q , that
is, an additive subgroup of Zn    q . We denote by C = hb1 , ..., bk i the code generated
by the vectors b1 , ..., bk ∈ Znq . A set {b1 , ..., bk } is a basis for C when the vectors
b1 , ..., bk are linearly independent and generate C. In this case, any element v ∈ C
can be written in a unique way as a linear combination of the vectors b1 , ..., bk .
In opposition to codes over fields there are q-ary linear codes (if q is not a prime)
that have no basis, for example, the code C = h(2, 4)i = {(0, 0), (2, 4), (4, 2)} ⊆ Z26
does not have a basis because every nonempty subset of C is linearly dependent
(3(a, b) = (0, 0)). Every q-ary linear code C is characterized by a minimal set
of generators. A generator matrix for a q-ary linear code C is any matrix whose
rows form a minimal set of generators for the code C. For each pair of vectors
x = (x1 , ..., xn ) and y = (y1 , ..., yn ) in Zn
                                                q , the inner product between x and y is
defined, as usual, as x · y = x1 y1 + · · · + xn yn . O set C ⊥ = {y ∈ Zn       q; x · y =
0, ∀x ∈ C} is a q-ary linear code, called the dual code of C. If C1 and C2 are q-ary
linear codes such that C1 ⊇ C2 , then C1⊥ ⊆ C2⊥ .
     A lattice Λ is a discrete additive subgroup of Rn . Equivalently, Λ ⊆ Rn is a
lattice if and only if there are linearly independent vectors v1 , ..., vm ∈ Rn such
that Λ is the set of all integer linear combinations of vi , i = 1, ..., m, i.e.,

                     Λ = {α1 v1 + · · · + αm vm ; α1 , ..., αm ∈ Z}.

In the above description, the set {v1 , ..., vm } is called a basis of Λ and the number
m is called the rank of Λ. When m = n we say that Λ has full rank. The matrix M
whose rows are the vectors v1 , ..., vm is called a generator matrix of Λ. M1 and M2
are generator matrices of the same lattice if and only if there is a unimodular matrix
U (with integer entries and det(U ) = ±1) such that M2 = U M1 . The determinant
of Λ is defined as det Λ = det(M M t ) and√this is an invariant under change of basis.
The volume of Λ is defined as vol(Λ)

Λ. We denote by span(M ) = {uM ; u ∈ Rn } the vector space generated by the

    A sphere packing in Rn is a collection of spheres/balls of equal size which do
not overlap (except for touching). A lattice packing in Rn is a sphere packing in
Rn such that the set formed by the centers of the spheres is a lattice. The packing
radius ρ of a lattice Λ relative to a distance d is the largest real number r such
that Λ + Bd [0, r] is a lattice packing, where Bd [0, r] is the closed ball with center
0 and radius r relative to distance d. If translations by v ∈ Λ are isometries under
d, it can be shown that ρ = λ/2, where λ is the value of the minimum distance of
Λ relative to distance d, i.e.,

              λ = min{d(x, y); x, y ∈ Λ and x 6= y} = min d(x, 0).

of a lattice Λ of rank n relative to distance d is the number δd (Λ) = ρn /vol(Λ).
Given a distance d in Rn , a problem of interest is the search for a lattice with
greatest possible density and such lattices are known only for a very few dimen-
sions. For example, for the Euclidean distance, the densest lattices are known in
the dimensions from 1 to 8 [3] and 24 [2]. For the l1 -distance, densest lattices are
only known in dimensions 1, 2 and 3 [5].

5 Conclusion

The minimum l1 -distance of lattices ΛD , ΛD0 and ΛD obtained via Constructions
D, D0 e D is investigated here. We provide upper bounds for the minimum l1 -
distance at these lattices. When the chain of codes used is closed under the zero-
one addition, we derive explicit expressions for the minimum l1 -distances of the
lattices ΛD and ΛD depending on the Lee-distances of the codes used in these
constructions. In addition, we also show connections between Constructions D
and D0 and obtain under certain conditions the minimum l1 -distance of the dual
lattice Λ∗D0 . Further work in the directions presented here is the discussion of the
minimum distance of these lattices regarding the lp -norm.
