## 367672: sustained binary linear rank route

Use finite simple binary matroids, allowing a loop, as in the primary source. A homomorphism is the restriction of a linear map of point spans, with each ground element mapped into the target ground set. Adjacent maps differ by cχ_C for a source cocircuit C (Facts 2.1–2.3). Write χ_C=ℓ restricted to the ground set for a nonzero binary linear functional. A self-map adjacent to identity has linear extension T=I+cℓ. If ℓ(c)=1 then T²=I+2cℓ+cℓ(c)ℓ=I+cℓ=T in characteristic two, and T(c)=0. Thus it is an idempotent with proper image, fixes its image, and defines a proper dismantling retraction. If ℓ(c)=0, T²=I, so T is invertible. A self-map of a finite ground set which is injective is a permutation of that set, hence an automorphism. This dichotomy explains exactly where a rank decrease would yield a dismantling step.

First failed shortcut: connectedness of Col(N,N) alone does not force such a rank decrease. A path can move through automorphisms/transvections; a loopless N need not admit a constant homomorphism (a circuit of odd size obstructs constant nonzero images). Nor can one map to zero if the ground set excludes zero. Passing to a minimal image in the identity component only helps after proving a proper-image map is in that component; assuming it is circular.

Second route: choose an arbitrary source matroid M whose homomorphisms encode two prescribed copies of N. Triviality means every given pair of homomorphisms is connected, not merely that the decision problem has a simple complexity bound. A valid gadget must force the connecting path to induce a noninvertible self-map of N. The graph proof uses vertex folds; its one-vertex support is generally not a cocircuit, and its nonlinear folds are generally not binary linear maps. Source Lemma3.1 gives composition paths but no such rigidity gadget. Exact missing lemma: every finite binary matroid with no proper adjacent-to-identity retraction and more than the loop/edge endpoint admits M and homomorphisms M→N in different reconfiguration components. No proof of that lemma or counterexample to it was found. Full converse remains parked; source sufficiency is already Corollary3.5.
