# Reproduce the dossier

Safely extract kirchhoff-source-only.zip into a NEW empty directory. Reject absolute paths, parent traversal, symlinks, duplicate member names and compiled artifacts. scripts/safe_extract.py implements these checks. Run it as `python3 -I scripts/safe_extract.py kirchhoff-source-only.zip fresh-replay` from the dossier directory. All writes must remain in this lane during the assigned run.

Set LEAN_BIN to the **executable**, for this machine `/home/mj-kang/Documents/Dev/math/dlp-research/.tools/lean-4.34.1-linux/bin/lean`. Set LEAN_PACKAGES to `/home/mj-kang/Documents/Dev/math/openai-proof-research/frontier/campaigns/2026-10-14/formal/.lake/packages`, or an equivalent read-only package cache. Required pins: Lean 4.34.1 commit 5045d0056413266e57c625dcd7c365b10e377c52; mathlib d13f23b723b8a846827a245b89c10fc7d3f11612. sources/lake-manifest.json records all package revisions. Provision these outside the driver; it neither downloads nor mutates dependencies. The cached package contents are an external trust input, not independently rebuilt here.

Inside the extraction, run `python3 -I replay.py`. Existing oleans anywhere inside the extraction cause refusal. The driver verifies source-hashes.json, checks the exact Lean version through its watchdog, strictly builds Basic, Certificates, Graph, RealBridge, and Audit with `-j1 -DwarningAsError=true`, and runs leanchecker for each. Audit is command-only tooling; its audit selects all 176 declarations in the four proof modules, by module identity, with full type and body ASTs including opaque bodies, safety and partiality flags, and transitive axiom lists. Only propext, Classical.choice, Quot.sound are allowed. No local axiom is allowed.

It then checks the reviewer's three positive proofs of control negations, plus three expected-failure false-claim attempts. Expected failures alone can be elaboration failures, so use the positive semantic controls as substantive evidence. No killed process counts as rejection. Every invocation, including `--version` and leanchecker, passes through scripts/run.py: at most two CPU affinities; 120-second CPU limit; 140-second wall limit; MALLOC_ARENA_MAX=2; 6 GiB sampled aggregate process-group RSS cap at 50 ms intervals. Shared pages may be counted twice across processes, conservatively. This is a sampled cap, not a hard virtual-address-space limit. The runner waits for its process and kills its process group on limit violation. Calls run sequentially, with no parallel heavy processes.

Receipts are written under receipts/, full logs under logs/, temporary files under outputs/ inside the extraction. `receipts/replay.json` appears only after every stage passes. This source packet is self-contained for local proof source and harness, not for Lean/mathlib binaries. No network access is needed for replay.

Manuscript: paper/manuscript.json contains the prose source; paper/render.py renders it with ReportLab and Liberation Serif fonts. Install ReportLab in a lane-local directory (this run used outputs/python-libs), or provide it through Python. The six-page PDF is paper/kirchhoff-draft.pdf. The QA PNGs and receipt record inspection of every final page. The full dossier retains exact copied source bodies and historical HTTP receipts; these are frozen evidence, not newly fetched sources. PROOF.md contains the ordinary proof.

The source-only ZIP carries text/Lean proof source, exact matrices and evidence, the manuscript source, and replay harness, with no compiled modules, PDF, or environment. The full ZIP additionally carries the PDF, final QA images, replay logs/receipts, summary/results and manifests. It omits fresh-replay compiled oleans and the lane-local Python installation. Source ZIP integrity is external in manifests/archives.json; full ZIP integrity is in manifests/delivery.json, outside the ZIP to avoid a circular hash.
