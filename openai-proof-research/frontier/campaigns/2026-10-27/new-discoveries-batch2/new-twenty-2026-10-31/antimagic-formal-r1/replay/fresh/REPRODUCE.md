# Reproduction

Run `bash scripts/replay.sh` from this directory or a fresh extraction of source.zip. No network, lake build or upstream writes are used. The fixed dependencies are Lean 4.34.1 and the prebuilt mathlib packages at the read-only path in scripts/env.sh, pinned to d13f23b723b8a846827a245b89c10fc7d3f11612. The source zip is a resumable partial certificate, not an accepted solution.

The driver strictly builds each module serially with `lean -j1 -M3500 -DwarningAsError=true` and invokes leanchecker with an explicit module argument immediately afterward. A PATH shim also supplies -j1 and -M3500 to Lean subprocesses invoked by leanchecker. Every Lean, leanchecker and Python process is run inside the capped process group: two CPUs, CPU 120 s, wall 140 s, MALLOC_ARENA_MAX=2, an aggregate process-group RSS watchdog at 6 GiB. Temporary directories and Python caches are beneath the extraction. Logs have nanosecond names and include return codes. Processes are waited on; the watchdog is stopped after each run.

Audit.lean is audit tooling, not an import of the endpoint. It enumerates all declarations of all six Antimagic modules as seeds, so generated/private declarations are included. It follows every declaration type and value with allowOpaque := true, inductive constructors, mutual groups, and existing _unsafe_rec companions to a fixed point. Every discovered dependency is processed, and closure membership is checked again for each type and value. The 200-round fuel bound must terminate with an empty frontier or the audit fails. Implemented_by and extern attributes and unsafe/partial flags are recorded; implementation targets are metadata and are not followed as proof-body edges. audit.tsv records one row for every member of this expanded closure; report.py separates local and upstream metadata and checks the axiom allowlist and local zero flags. This is a dependency-closure audit, not an enumeration of every unrelated declaration in imported libraries.

AntimagicRegression uses kernel decide, never native_decide or ofReduceBool. It checks row incidence and the explicit formula, NOT the literal graph weight or graph edge-equivalence bijection; that regression bridge remains unproved. Python is diagnostics only and checks explicit edge incidence independently of the row-weight summation routine in Lean. Negative controls reject a repeated label, the claimed leaf-only colour count for Figure 5, and odd t = 3 as a member of the even hypothesis. They are sensitivity tests, not conjecture counterexamples.

For a new extraction, inspect `zipinfo -1 source.zip`, require relative paths without parent components, extract into an empty directory under the assigned lane, and execute the replay there. Source archives contain only Lean source, prose, and scripts; no olean, caches, logs, or upstream packages. The original TASK.txt and launch metadata remain outside the archive.
