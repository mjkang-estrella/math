We formulate a geometric version of the Erdős-Hajnal conjecture that applies to finite projective geometries rather than graphs, in both its usual ‘induced’ form and the multicoloured form. The multicoloured conjecture states, roughly, that a colouring c of the points of PG ⁡ ( n − 1 , q ) containing no copy of a fixed colouring c 0 of PG ⁡ ( k − 1 , q ) for small k must contain a subspace of dimension polynomial in n that avoids some colour. If ( k , q ) = ( 2 , 2 ) , then c 0 is a colouring of a three-element ‘triangle’, and there are three essentially different cases, all of which we resolve. We derive both the cases where c 0 assigns the same colour to two different elements from a recent breakthrough result in additive combinatorics due to Kelley and Meka. We handle the case that c 0 is a ‘rainbow’ colouring by proving that rainbow-triangle-free colourings of projective geometries are exactly those that admit a certain decomposition into two-coloured pieces. This is closely analogous to a theorem of Gallai on rainbow-triangle-free coloured complete graphs. We also show that existing structure theorems resolve certain two-coloured cases where ( k , q ) = ( 2 , 3 ) , and ( k , q ) = ( 3 , 2 ) . Introduction The Erdős-Hajnal conjecture [ 9 ] states that for every graph H , there is a constant β = β ⁡ ( H ) > 0 such that, if G is a graph on n vertices with no induced H -subgraph, then G has a clique or stable set of size at least n β . This problem is known for some particular graphs H (notably the 5 -cycle) as well as when H belongs to one of a few infinite classes such as the cographs, but is wide open in general. See [ 8 ] for a survey. Erdős and Hajnal [ 10 ] in fact stated a multicoloured generalization of the same conjecture. To state this, we introduce some terminology. A colouring of a finite set X is any function c whose domain is X , and, for s ∈ ℕ , an s -colouring is a function c : X → { 1 , … , s } . Given a colouring c , we write [ c ] for the range of c (the set of colours used by c ), and | c | for the number of colours used by c . For a graph G , a colouring of G means a colouring of E ⁡ ( G ) . The conjecture is stated in terms of colourings of complete graphs ‘containing’ other colourings. If c and d are colourings of complete graphs H and G respectively, then we say that d contains c if there is an injection ψ : V ⁡ ( H ) → V ⁡ ( G ) such that c ⁡ ( x ​ y ) = d ⁡ ( ψ ⁡ ( x ) ​ ψ ​ ( y ) ) for all distinct x , y ∈ V ⁡ ( H ) . A colouring not containing c is c -free. Conjecture 1.1 (Multicoloured Erdős-Hajnal conjecture for graphs) . For all 1 ≤ s 0 ≤ s and k ≥ 1 , and every s 0 -colouring c 0 of K k , there exist δ , C > 0 such that, for all n ∈ ℕ and every c 0 -free s -colouring c of K n , there is a colour i ∈ { 1 , … , s } and a set X of at least C ​ n δ vertices of K n such that c ⁡ ( e ) ≠ i for every edge e with both ends in X . The set X is referred to as homogeneous . The case where s 0 = s = 2 is the classical Erdős-Hajnal conjecture. We make an analogous conjecture about colourings of projective geometries. In this context, we write G ≅ PG ⁡ ( n − 1 , q ) to denote the projective space associated with some generic n -dimensional vector space V over GF ⁡ ( q ) ; the points of G are the one-dimensional subspaces of V . Going forward, we often identify this object with the corresponding simple rank- n GF ⁡ ( q ) -representable matroid on q n − 1 q − 1 elements. A colouring of G is a colouring of the q n − 1 q − 1 points of G . If c and d are colourings of H ≅ PG ⁡ ( m − 1 , q ) and G ≅ PG ⁡ ( n − 1 , q ) respectively, then we say that d contains c if there is an injective homomorphism ψ : H → G such that c ⁡ ( x ) = d ⁡ ( ψ ⁡ ( x ) ) for every point x of H . If d does not contain c , then d is c -free . We are primarily interested in the binary case, where one can think of n -dimensional binary projective space more concretely as the set of nonzero vectors in 𝔽 2 n , and homomorphisms as linear maps. Given s ∈ ℕ , and an s -colouring c of G ≅ PG ⁡ ( n − 1 , 2 ) , we say that a subspace V of G is ( c , s ) -homogeneous if there is some i ∈ { 1 , … , s } for which i ∉ c ⁡ ( V ) . That is, the colouring c avoids some colour on V . Conjecture 1.2 (Multicoloured geometric Erdős-Hajnal conjecture) . For every prime power q , all k , s 0 , s ∈ ℕ with s 0 ≤ s , and every s 0 -colouring c 0 of PG ⁡ ( k − 1 , q ) , there exists δ , C > 0 such that, for all n ∈ ℕ and every c 0 -free s -colouring c of G ≅ PG ⁡ ( n − 1 , q ) , there is a ( c , s ) -homogeneous subspace of G with dimension at least C ​ n δ . Induced restrictions The classical Erdős-Hajnal conjecture on induced subgraphs is precisely the case of Conjecture 1.1 where both the colourings use only two colours. Specializing Conjecture 1.2 in the same way gives the following conjecture, phrased in terms of induced restrictions . In what follows, we slightly abuse notation by identifying a projective geometry PG ⁡ ( n − 1 , q ) with its set of points. If H and X are sets of points in PG ⁡ ( k − 1 , q ) and PG ⁡ ( n − 1 , q ) respectively, then we say that X contains H as an induced restriction if there is an injective homomorphism ψ : PG ⁡ ( k − 1 , q ) → PG ⁡ ( n − 1 , q ) such that, for each point x of PG ⁡ ( k − 1 , q ) , we have ψ ⁡ ( x ) ∈ X if and only if x ∈ H . Conjecture 1.3 (Geometric Erdős-Hajnal conjecture) . For every prime power q and all k ∈ ℕ and H ⊆ PG ⁡ ( k − 1 , q ) , there exists δ , C > 0 such that, for all n ∈ ℕ and X ⊆ PG ⁡ ( n − 1 , q ) not containing H as an induced restriction, there is a subspace W of PG ⁡ ( n − 1 , q ) such that dim ( W ) > C ​ n δ , and either W ⊆ X or W ∩ X = ∅ . Finally, we state a strengthening of the last two conjectures, suggested by Jacob Fox, which asserts that in fact they hold for linear functions rather than polynomial. This may seem quite strong, but we know of no construction that refutes it. Conjecture 1.4 . Conjectures 1.2 and 1.3 hold with δ = 1 . Results Our first few main results concern the binary case, where the object being excluded is a colouring of the rank-two binary projective geometry T ≅ PG ⁡ ( 2 − 1 , 2 ) , known in matroid parlance as a ‘triangle’. This geometry T has just three elements; when thinking of a larger host geometry G ≅ PG ⁡ ( n − 1 , 2 ) as a set of vectors in 𝔽 2 n \ { 0 } , a copy of T in G is simply a triple of distinct vectors that sum to zero. The analogous problem for triangles in edge-coloured complete graphs is especially well-studied [ 1 , 11 , 12 , 18 ]. To prove Conjecture 1.2 , it suffices to consider the case where the colouring c 0 is surjective: that is, where s 0 = | c 0 | . Thus, by symmetry, there are only three essentially different colourings c 0 of T = { x 1 , x 2 , x 3 } : the 1 -colouring c 0 with [ c 0 ] = { 1 } , the 2 -colouring c 0 where c 0 ​ ( x 1 ) = c 0 ​ ( x 2 ) = 1 and c 0 ​ ( x 3 ) = 2 , and the ‘rainbow’ 3 -colouring with c 0 ​ ( x i ) = i for all i . Our first result handles the first two cases, for arbitrary s ≥ s 0 . Theorem 1.5 . Let s 0 ∈ [ 2 ] and s ≥ s 0 , and c 0 be an s 0 -colouring of T . Then Conjecture 1.2 holds for c 0 and s , with δ = 1 7 . The proof of this theorem is via a reduction to a recent breakthrough result in additive combinatorics due to Kelley and Meka [ 16 ], formulated by Hunter and Pohoata [ 15 ] in our setting. Our next result handles the rainbow colouring of T , when s 0 = s = 3 . Theorem 1.6 . Let c 0 be the rainbow 3 -colouring of T . Then Conjecture 1.2 holds for c 0 and s = 3 , with C = 1 3 and δ = 1 . Moreover, the values of δ and C are best-possible. The proof is via very different techniques. Following a route analogous to results due to Gallai [ 12 , 18 ] and Fox, Grinshpun and Pach [ 11 ], we prove an exact structure theorem, Theorem 6.7 , which describes the 3 -colourings of PG ⁡ ( n − 1 , 2 ) with no rainbow triangle, and derive Theorem 1.6 as an easy consequence. Theorem 6.7 is a little too technical to state precisely here, but it roughly states that, if c is a colouring of the points of a projective geometry having no three colinear points of different colours, then c can be constructed from two-coloured subspaces using a certain ‘join’ operation. The following weakening will be enough to imply Theorem 1.6 . Theorem 1.7 . Let n ∈ ℕ , let q be a prime power, and c be a colouring of the points of G ≅ PG ⁡ ( n − 1 , q ) so that | c ⁡ ( L ) | ≤ 2 for each two-dimensional subspace L of G . Then there are subspaces ∅ = W 0 ⊆ W 1 ⊆ … ⊆ W k = G of G such that | c ⁡ ( W i + 1 − W i ) | ≤ 2 for all 0 ≤ i < k . Note that this applies to all finite projective geometries, not just those over 𝔽 2 ; this is also the case for Theorem 6.7 . Sadly, for larger fields, Theorem 6.7 has no direct applications to Conjecture 1.2 , because the notion of a ‘line’ diverges from that of a ‘triangle’. In the case where the number of colours is equal to the dimension, our structure theorem has an especially nice consequence, stating that there is a unique n -colouring of PG ⁡ ( n − 1 , q ) with no rainbow triangle, up to automorphisms and permutations of the colour set. In the case where q = 2 , this follows from a much more general result of Bérczi and Schwarcz [ 2 , Theorem 4], who call these colourings ‘standard’. (Their result has an apparently stronger assumption that omits rainbow circuits rather than triangles, but we will see in Theorem 5.2 that this hypothesis is equivalent to ours in the case of projective geometries.) Theorem 1.8 . Let q be a prime power, and c be an n -colouring of PG ⁡ ( n − 1 , q ) that uses all n colours, such that each line contains at most two colours. Then there is a maximal chain of subspaces ∅ = F 0 ⊂ … ⊂ F n = PG ⁡ ( n − 1 , q ) such that the sets F i − F i − 1 are monochromatic with different colours. Conjecture 1.3 is equivalent to the case of Conjecture 1.2 where s = s 0 = 2 , so is resolved in the case where q = k = 2 by Theorem 1.5 . We can resolve two more cases of Conjecture 1.5 (up to complementation) using known exact structure theorems. The first is in the case where q = 3 and k = 2 , and H is a set of two distinct elements in PG ⁡ ( 1 , 3 ) . Viewed as a two-colouring, this object H is self-complementary, since PG ⁡ ( 1 , 3 ) has four elements and symmetric automorphism group. Conjecture 1.3 will follow for H from a characterization of the H -free matroids due to Mizell and Oxley [ 20 ], which we prove separately and in more generality as Theorem 7.9 . Theorem 1.9 . Let H ⊆ PG ⁡ ( 1 , 3 ) with | H | = 2 . Then Conjecture 1.3 holds for H , with δ = 1 and C = 1 2 . These values are best-possible. The second case we can settle is that of the claw , which is defined as a basis of the seven-point Fano plane PG ⁡ ( 2 , 2 ) . This will follow from the main theorem of [ 21 ], which allows us to reduce the problem to Theorem 1.5 . Theorem 1.10 . Let H ⊆ PG ⁡ ( 2 , 2 ) consist of either a (three-element) basis of PG ⁡ ( 2 , 2 ) or its four-element complement. Then Conjecture 1.3 holds for H , with δ = 1 7 . 2. Preliminaries We write ℕ for the set { 0 , 1 , … } , and [ n ] = { 1 , … , n } for each n ∈ ℕ . When discussing matroids, we usually use the notation and terminology of Oxley [ 22 ]. For sets X , Y in a matroid M , we write ⊓ M ( X , Y ) for the ‘local connectivity’ evaluated as r M ​ ( X ) + r M ​ ( Y ) − r M ​ ( X ∪ Y ) . A rank-one flat is a point , and a rank-two flat is a line . Two flats F , F ′ of a matroid M are complementary if ⊓ M ( F , F ′ ) = 0 and F ∪ F ′ is spanning in M ; such an F ′ is a complement of F , and satisfies r ⁡ ( M ) = r M ​ ( F ) + r M ​ ( F ′ ) . Note that if B is any basis for M containing a basis I for the flat F , then cl M ⁡ ( B − I ) is an example of a complement of F , so every flat has at least one complement. Our first tool is due to Bose and Burton [ 3 ]. A projective subspace of 𝔽 2 n is a linear subspace with the zero vector removed. Theorem 2.1 . Let t ∈ ℕ . If X ⊆ 𝔽 2 n \ { 0 } contains no ( t + 1 ) -dimensional projective subspace, then | X | ≤ ( 1 − 2 − t ) ​ 2 n . Given a set X ⊆ 𝔽 2 n , write ω ⁡ ( X ) for the largest dimension of a projective subspace contained in X , and α ⁡ ( X ) = ω ⁡ ( 𝔽 2 n \ X ) for the largest dimension of a projective subspace contained in the complement of X . By applying Theorem 2.1 to set ( 𝔽 2 n \ { 0 } ) \ X with t = α ⁡ ( X ) , we obtain the following corollary. Corollary 2.2 . Each X ⊆ 𝔽 2 n satisfies | X | ≥ 2 n − α ⁡ ( X ) − 1 . Finally, the qualitative Ramsey result that facilitates the discussion ahead is due to Graham, Leeb and Rothschild [ 13 ]. Theorem 2.3 . There is a function R q ​ ( s , t ) so that, for each prime power q and all s , t ∈ ℕ , for all n ∈ ℕ with n ≥ R q ​ ( s , t ) and each colouring c of G ≅ PG ⁡ ( n − 1 , q ) with [ c ] ⊆ { 𝖱𝖾𝖽 , 𝖡𝗅𝗎𝖾 } , there is either an s -dimensional subspace of G coloured 𝖱𝖾𝖽 , or a t -dimensional subspace of G coloured 𝖡𝗅𝗎𝖾 . 3. Modularity Our main results will be applied to projective geometries over finite fields, but it is convenient to work at the more abstract level of modular matroids. The consequence is that our proofs are co-ordinate free, and apply to a slightly larger class of objects. A matroid M is modular if every pair F , F ′ of flats of M satisfies r M ​ ( F ) + r M ​ ( F ′ ) = r M ​ ( F ∪ F ′ ) + r M ​ ( F ∩ F ′ ) , or equivalently if r M ( cl M ( A ) ∩ cl M ( B ) ) = ⊓ M ( A , B ) for all A , B ⊆ E ⁡ ( M ) . Canonical examples include matroids of rank at most two, free matroids, projective planes in rank three (including non-Desarguesian ones), and projective geometries over finite fields. Indeed, the simple connected modular matroids of rank at least four are precisely those of the form PG ⁡ ( n − 1 , q ) for a prime power q (See [ 22 , Proposition 6.9.1]). Even though Theorem 1.6 only applies to binary projective geometries, Theorem 6.7 applies to all connected modular matroids, which by the aforementioned classification comprise precisely the loopless matroids whose simplification is either a rank- 2 uniform matroid, a projective plane, or PG ⁡ ( n − 1 , q ) for n ≥ 4 . The first four lemmas in this section follow easily from the classification just discussed, but for completeness, we include self-contained proofs that use the definition of modularity directly. Lemma 4.1 . If M is a loopless modular matroid, then flats F , F ′ of M are complementary if and only if they are disjoint and their union spans M . Proof. It suffices to show that two flats F 1 , F 2 have local connectivity zero if and only if they are disjoint. But r M ( F 1 ∩ F 2 ) = ⊓ M ( F 1 , F 2 ) , and since M is loopless, we have r M ​ ( F 1 ∩ F 2 ) = 0 if and only if | F 1 ∩ F 2 | = 0 . The equivalence holds. ∎ Lemma 4.2 . If M is a modular matroid, then M / C is modular for each set C ⊆ E ⁡ ( M ) , and M | F is modular for each flat F of M . Proof. The fact that M | F is modular follows immediately from the definition, since the flats of M | F are the flats of M that are contained in F . To see that M / C is modular for all C , let X , Y ⊆ E ⁡ ( M / C ) . By the modularity of M and the fact that C ⊆ cl M ⁡ ( X ∪ C ) ∩ cl M ⁡ ( Y ∪ C ) , ⊓ M / C ( X , Y ) = ⊓ M ( X ∪ C , Y ∪ C ) − r M ( C ) = r M ​ ( cl M ⁡ ( X ∪ C ) ∩ cl M ⁡ ( Y ∪ C ) ) − r M ​ ( C ) = r M / C ​ ( cl M / C ⁡ ( X ) ∩ cl M / C ⁡ ( Y ) ) , so M / C is modular. ∎ Lemma 4.3 . If F is a nonempty proper flat of a connected modular matroid M , then M | F and M / F are both connected and modular. Proof. We know both are modular from the previous lemma, so it suffices to show that both are connected. To show that M | F is connected, let x , y ∈ F . By the connectedness of M , there is a circuit C of M containing x and y . If C = { x , y } , then C is a circuit of M | F containing x and y , as required. Otherwise, both { x , y } and C − { x , y } are independent in M , so r M ​ ( cl M ⁡ ( { x , y } ) ∩ cl M ⁡ ( C − { x , y } ) ) = ⊓ M ( C − { x , y } , { x , y } ) = ( | C | − 2 ) + 2 − ( | C | − 1 ) = 1 . Therefore M has a nonloop e spanned by both { x , y } and C − { x , y } . Since F is a flat, e ∈ F . If e is parallel to some f ∈ { x , y } , then the independent set ( C − { x , y } ) ∪ { f } is spanned by its proper subset C − { x , y } , a contradiction. Therefore e is parallel to neither x nor y but is spanned by { x , y } , so { e , x , y } is a circuit contained in F . Therefore M | F is connected. To see that M / F is connected, let F 0 be a complement of F , so F 0 is spanning in M / F . Since F is a flat, the matroid M / F is loopless and has a connected spanning restriction M | F 0 , so is connected. ∎ The next lemma is a well-known result about finite projective planes, stated in matroidal language. Lemma 4.4 . If M is a connected, modular rank-three matroid, then there is an integer q ≥ 2 such that every line of M has length q + 1 , every point is contained in exactly q + 1 lines, and the number of points and the number of lines are both equal to q 2 + q + 1 . Proof. We may assume that M is simple. By modularity, any two distinct lines intersect in a single element. Let ℒ be the set of lines of M , and L , L ′ ∈ ℒ be distinct lines intersecting in a point e . Let f ∈ L − e and f ′ ∈ L ′ − e , noting that f ≠ f ′ . If E ⁡ ( M ) = L ∪ L ′ , then since M is coloopless, there are distinct x , x ′ ∈ L − L ′ and distinct y , y ′ ∈ L ′ − L . Then cl M ⁡ ( { x , y } ) and cl M ⁡ ( { x ′ , y ′ } ) intersect in some element z , and it is easy to argue that z ∉ L ∪ L ′ , a contradiction. Therefore there exists g ∈ E ⁡ ( M ) − ( L ∪ L ′ ) . Define φ : L → L ′ by, for each x ∈ L , setting φ ⁡ ( x ) to be the unique point in L ′ ∩ cl M ⁡ ( { x , g } ) . Since x is the only element of L ∩ cl M ⁡ ( { φ ⁡ ( x ) , g ′ } ) , the function φ is injective. It follows that | L ′ | ≥ | L | . Lemma 4.5 . If M is a connected modular matroid, then every cocircuit of M is spanning. Proof. Let K be a cocircuit of M , and let x ∈ K . When discussing matroid properties such as connectedness, modularity, or independence of a set, we identify ( M ; c ) with the matroid M . The colouring c is simple (with respect to M ) if M has no loop, and c ⁡ ( e ) = c ⁡ ( f ) for all e , f that are parallel in M . Note that M itself need not be simple for this to hold, but simplicity of M implies simplicity of c . A set X is c -monochromatic if c is constant on X , is c -polychromatic otherwise, and is c -rainbow if c is injective on X . We omit the reference to c if it is clear from context. The following lemma shows that the existence of a rainbow triangle is equivalent to the existence of a larger rainbow circuit. Lemma 5.1 . A modular coloured matroid ( M ; c ) has a rainbow triangle if and only if ( M ; c ) has a rainbow circuit of size at least 3 . Proof. One direction is immediate. For the other direction, let C be a minimal rainbow circuit of ( M ; c ) for which | C | ≥ 3 . Towards a contradiction, suppose that | C | ≥ 4 . Let ( X 1 , X 2 ) be a partition of C with | X 1 | , | X 2 | ≥ 2 . Since each X i is a proper subset of C , it is independent in M , which implies that r M ( cl M ( X 1 ) ∩ cl M ( X 2 ) ) = ⊓ M ( X 1 , X 2 ) = | X 1 | + | X 2 | − r M ( C ) = 1 , Let e be a nonloop in cl M ⁡ ( X 1 ) ∩ cl M ⁡ ( X 2 ) . For each i , the set X i ∪ { e } is dependent, so contains a circuit C i with e ∈ C i . Note that | C i | ≥ 3 for each i ; otherwise, applying circuit elimination to C 1 and C 2 yields a circuit properly contained in C (since | X 1 | , | X 2 | ≥ 2 ). Now, since C i − { e } ⊆ X i and X 1 ∪ X 2 is rainbow, one of the circuits C 1 , C 2 must be rainbow. But both are clearly smaller than C , which contradicts minimality. ∎ We now present several equivalent characterizations of modular coloured matroids without rainbow triangles. Theorem 5.2 . Let ( M ; c ) be a modular coloured matroid for which c is simple. The following are equivalent: (i) ( M ; c ) has no rainbow triangle; (ii) ( M ; c ) has no rainbow circuit; (iii) | c ⁡ ( X ) | ≤ r M ​ ( X ) for all X ⊆ E ⁡ ( M ) ; (iv) | c ⁡ ( F ) | ≤ r M ​ ( F ) for every flat F of M . Proof. By the simplicity of c , every rainbow circuit of M has size at least 3 , so the equivalence of ( i ) and ( ii ) follows from Lemma 5.1 . It is clear that ( iii ) implies ( iv ). Moreover, if ( iv ) holds and X ⊆ E ⁡ ( M ) , then | c ⁡ ( X ) | ≤ | c ⁡ ( cl M ⁡ ( X ) ) | ≤ r M ​ ( cl M ⁡ ( X ) ) = r M ​ ( X ) , so ( iv ) implies ( iii ). Since a rainbow triangle T satisfies | c ⁡ ( T ) | > r M ​ ( T ) , we also know that ( iii ) implies ( i ). It is thus sufficient to show that ( ii ) implies ( iii ). Suppose that ( ii ) holds and ( iii ) does not, and let X be a minimal set for which | c ⁡ ( X ) | > r M ​ ( X ) . For each e ∈ X , the minimality of X implies that | c ⁡ ( X − e ) | ≤ r M ​ ( X − e ) ≤ r M ​ ( X ) ≤ | c ⁡ ( X ) | − 1 ≤ | c ⁡ ( X − e ) | , so equality holds throughout, meaning that r M ​ ( X ) = | c ⁡ ( X ) | − 1 and that e is the only element of X with colour c ⁡ ( e ) . This holds for all e ∈ X , so X is rainbow, and r M ​ ( X ) = | c ⁡ ( X ) | − 1 = | X | − 1 . Therefore X contains a rainbow circuit C , contradicting ( ii ). ∎ A rainbow-triangle-free coloured matroid is essentially the same as one where every line contains at most two colours. A natural generalization is the class of matroids where all rank- k flats contain at most k colours for some fixed k . However, we can see by way of the following easy result that this does not make the classification problem any more interesting. Theorem 5.3 . Let ( M ; c ) be a coloured matroid, and k ≥ 2 be an integer. If r ⁡ ( M ) ≥ k and | c ⁡ ( F ) | ≤ k for every rank- k flat F of M , then either | c | ≤ k , or ( M ; c ) has no rainbow triangle. Proof. Suppose for a contradiction that ( M ; c ) has a rainbow triangle T , but also that | c | > k . Then there is a ( k − 2 ) -element set S ⊆ E ⁡ ( M ) − T such that S ∪ T is rainbow. Since r M ​ ( S ∪ T ) ≤ r M ​ ( T ) + | S | = 2 + ( k − 2 ) = k , S ∪ T is contained in a rank- k flat of M using at least | S ∪ T | = k + 1 colours, a contradiction. ∎ Our main structural result, Theorem 6.8 , adds a nontrivial fifth condition to the list in Theorem 5.2 . To be able to state and prove this condition, we need a notion of decomposition for coloured matroids. A decomposer of a coloured matroid ( M ; c ) is a proper flat F of M such that, for all e ∈ E ⁡ ( M ) − F , the set cl M ⁡ ( F ∪ { e } ) − F is c -monochromatic. It is easy to see that, if M has no loop, the flat ∅ is a decomposer if and only if c is simple. A decomposer of rank at least one is nontrivial . For nearly all of our theorems, the matroids addressed are connected and have rank at least one. This means they are loopless, that points are the same as parallel classes, and that nontrivial decomposers are precisely nonempty decomposers. However, our inductive strategy involves contractions that create parallel pairs; to facilitate this, we work at a level of generality that includes non-simple matroids. The reader should bear in mind the possibility that two distinct elements are parallel (and therefore not in a rainbow triangle), which can affect the course of our arguments. Lift-Joins To turn Theorem 5.9 into a structure theorem, we need an operation that can be used to glue two rainbow-triangle-free colourings together into a larger one. We now describe this operation, then use Theorem 5.9 to derive Theorem 6.7 . Theorem 5.9 is the hard part of the actual proof; the work in this section amounts to straightforward manipulation of definitions in order that Theorem 6.7 can be carefully stated and proved. We call the gluing operation a lift-join . This was first defined in a slightly different (two-coloured) context in [ 6 ]. The definition uses the fact that, if F 1 and F 2 are skew flats of a modular matroid M and e ∈ cl M ⁡ ( F 1 ∪ F 2 ) − F 1 , then the flats cl M ⁡ ( F 1 ∪ { e } ) and F 2 intersect in a point. A lift-join combines colourings of F 1 and F 2 to obtain a colouring of the closure of their union. Definition 6.1 . Let F 1 and F 2 be skew flats of a modular matroid M , and let c 1 , c 2 be colourings of F 1 , F 2 respectively with c 2 simple in M . The lift-join c 1 ⊗ c 2 is the colouring c of cl M ⁡ ( F 1 ∪ F 2 ) such that c ​ ( e ) = c 1 ​ ( e ) for all e ∈ F 1 , and for each e ∈ cl M ⁡ ( F 1 ∪ F 2 ) − F 1 , we have { c ⁡ ( e ) } = c 2 ​ ( cl M ⁡ ( F 1 ∪ { e } ) ∩ F 2 ) . Kemperman’s theorem In the case where M is a Desarguesian projective geometry and | c | = 3 , Theorem 6.8 can almost certainly be derived from Kemperman’s theorem on small sumsets in abelian groups. Though the original version of the theorem in [ 17 ] does not use this terminology, we phrase our discussion in terms of the shorter proof in [ 4 ], which uses the convenient concept of a critical trio , defined to be a triple ( A , B , C ) of subsets of an additive abelian group G for which | A | + | B | + | C | > | G | and 0 ∉ A + B + C . To apply this to Theorem 6.8 with | c | = 3 and M = PG ⁡ ( n − 1 , q ) , let A 1 , A 2 , A 3 be the colour classes of a rainbow-triangle-free 3 -colouring of PG ⁡ ( n − 1 , q ) . Each element e of M is by definition a 1 -dimensional subspace of 𝔽 q n . For each i ∈ [ 3 ] , let X i = ⋃ e ∈ A i e ⊆ 𝔽 q n . By construction, the sets X i pairwise intersect only in the zero vector, and satisfy | X 1 | + | X 2 | + | X 3 | = q n + 2 . If there exist vectors x 1 , x 2 , x 3 with x i ∈ X i and x 3 ≠ 0 while x 1 + x 2 + x 3 = 0 , then either some x i is zero and the other two are parallel and nonzero (which does not occur by the construction of the X i ) or all three are nonzero, which does not occur since the original colouring is rainbow-triangle-free. It follows, therefore, that 0 ∉ X 1 + X 2 + ( X 3 \ { 0 } ) and | X 1 | + | X 2 | + | X 3 \ { 0 } | = q n + 1 . Therefore ( X 1 , X 2 , X 3 \ { 0 } ) is a critical trio in the additive group 𝔽 q n . Kemperman’s theorem as formulated in [ 4 , Theorem 4.5] gives an exact characterization of all critical trios, in terms of so-called ‘beats’, ‘chords’, ‘continuations’ and a chain of subgroups. We do not state the result here, since its statement requires a plethora of definitions, but the correspondence with Theorem 6.8 is clear – ‘impure beats’ correspond to lift-joins, and the chain of subgroups correspond to the subspaces spanned by unions of initial segments of the F i . Deriving the three-coloured case of Theorem 6.8 from Kemperman’s theorem is likely a matter of little more than reconciling distinct sets of terminologies. With more than three colours, the simplicity of the correspondence breaks down. While one could possibly use an inductive strategy where distinct colours are merged to find a proof of Theorem 6.8 using Kemperman’s theorem, such a proof could easily be longer than ours. 7. Targets Before applying Theorem 6.8 to derive our main results on the geometric Erdős-Hajnal conjecture, we define a special type of colouring. This is a version of a definition originally given in [ 21 ] in the language of induced submatroids, which is essentially the two-coloured case. Call a coloured matroid ( M ; c ) a target if there are flats cl M ⁡ ( ∅ ) = F 0 ⊆ F 1 ⊆ … ⊆ F k = E ⁡ ( M ) of M such that every nonempty set of the form F 0 or F i + 1 − F i is monochromatic. Given a target ( M ; c ) with r ⁡ ( M ) ≥ 1 , it can be convenient to choose the flats F 0 ⊆ … ⊆ F k with k minimal. Given such a choice, F i + 1 − F i − 1 must contain at least two colours for all 1 ≤ i < k , since otherwise we could remove F i from the list. It follows that there is always a choice of the F i so that the containments F i ⊆ F i + 1 are all strict, and for all i , the sets F i − F i − 1 and F i + 1 − F i are monochromatic with different colours. This section will establish some basic properties of targets, as well as prove two theorems that classify targets in terms of excluded subconfigurations. Infinite Fields Matroids are traditionally defined to have finite ground sets, but this is certainly not necessary. Infinite matroids of finite rank can easily be defined from the usual matroid rank axioms by simply dropping the requirement that the ground set is finite while maintaining the stipulation that rank is integer-valued. With the notable exception of matroid duality, most matroid theory works exactly as expected for these objects – see [ 5 ] for a discussion. It is natural to ask whether Theorem 6.8 holds in this expanded setting, since it would then apply to colourings of finite-dimensional projective space over fields such as ℚ , ℝ and ℂ . Indeed, every component of the proof of Theorem 6.8 easily adapts to finite-rank infinite matroids, except Lemma 5.7 , whose proof involves counting points in lines. Unfortunately, this issue is fundamental, because the generalization of Theorem 6.8 to projective geometries over infinite fields turns out to be false. We show via an algebraic construction that for many infinite fields 𝔽 (including ℚ , ℝ and ℂ ), there is a rainbow-triangle-free n -colouring of PG ⁡ ( n − 1 , 𝔽 ) that cannot be decomposed via lift-joins. The construction is a higher-dimensional version of one discovered for projective planes by Carter and Vogt [ 7 ] and, independently, Hales and Straus [ 14 ]. To explain the construction, we need some algebra. A non-Archimedean valuation on a field 𝔽 is a function v : 𝔽 → ℝ ∪ { ∞ } so that v − 1 ​ ( ∞ ) = { 0 } , and v ⁡ ( a ​ b ) = v ⁡ ( a ) + v ⁡ ( b ) and v ⁡ ( a + b ) ≥ min ⁡ ( v ⁡ ( a ) , v ⁡ ( b ) ) for all a , b ∈ 𝔽 . Note that v ⁡ ( a − 1 ) = − v ⁡ ( a ) for all a and therefore that v ⁡ ( 1 ) = v ⁡ ( − 1 ) = 0 ; if there is some a ≠ 0 for which v ⁡ ( a ) ≠ 0 , then v is nontrivial . It is routine to show that finite fields do not admit nontrivial non-Archimedean valuations, and it is known that the same is true for any algebraic extension of a finite field. Many other fields do have such valuations, however. For example, if p is a prime, then the p -adic valuation on ℚ , defined by v ⁡ ( p t ​ r s ) = t for all r , s relatively prime to p , is non-Archimedean. Nontrivial valuations on ℝ and ℂ are harder to construct, but their existence follows from the axiom of choice. Given a non-Archimedean valuation v on a field 𝔽 , an integer n ≥ 1 , and a vector ( u 1 , … , u n ) ∈ 𝔽 n , write c v ​ ( u ) for the smallest index s such that v ⁡ ( u s ) = min i ⁡ v ⁡ ( u i ) ; this is an n -colouring of 𝔽 n \ { 0 } . It is easy to check using the definition of a non-Archimedean valuation that c v ​ ( λ ​ u ) = c v ​ ( u ) for all λ ∈ 𝔽 × , so c v can also be viewed as an n -colouring defined on the projective space PG ⁡ ( n − 1 , 𝔽 ) whose points are the one-dimensional subspaces of 𝔽 n . (For p -adic valuations on the field of rationals, we can view c v very concretely: to colour a point x = ( r 1 , … , r n ) , simply scale the r i to be integers with no common factor, and colour x with the first index whose entry is not a multiple of p .) For the remainder of the section, write PG ⁡ ( n − 1 , 𝔽 ) for the projective geometry whose points are explicitly the 1 -dimensional subspaces of 𝔽 q n , and let [ x ] be the element of PG ⁡ ( n − 1 , 𝔽 ) corresponding to the vector x ∈ 𝔽 n \ { 0 } . We first show that the colouring c v is rainbow-triangle-free – in fact it is just as easy to show the equivalent statement that it has no rainbow circuit. (Showing this for all circuits has the tiny advantage of not exploiting the equivalence in Lemma 5.1 , which does hold for finite-rank infinite matroids, but we technically did not prove in this setting.) Theorem 12.1 . Let n ≥ 1 , and let v be a non-Archimedean valuation on a field 𝔽 . Then every c v -rainbow set in PG ⁡ ( n − 1 , 𝔽 ) is independent. Proof. Let I = { x 1 , … , x t } be a c v -rainbow set, where c v ​ ( x 1 ) < c v ​ ( x 2 ) < … < c v ​ ( x t ) . Let x i = [ ( x 1 i , … , x n i ) ] and c v ​ ( x i ) = k i for each i . Write | x | for v ⁡ ( x ) . Since c v ​ ( x 1 i , … , x n i ) = k i for each i , we have | x k i i | ≤ | x j i | for all j , and the inequality is strict if j < k i . To show that I is independent, it suffices to show that the t × t matrix A defined by A i ​ j = x k j i is nonsingular. Suppose, therefore, that the determinant | A | of A is zero. Write s ⁡ ( π ) = ± 1 for the sign of a permutation π ∈ S n . For each π ∈ S n , using | s ⁡ ( π ) | = 0 , we have | s ⁡ ( π ) ​ ∏ i = 1 t x k π ⁡ ( i ) i | = ∑ i = 1 t | x k π ⁡ ( i ) i | ≥ ∑ i = 1 t | x k i i | . Moreover, if π is not the identity permutation, there is some s such that π ⁡ ( s ) < s , which implies that k π ⁡ ( s ) < k s , so | x k π ⁡ ( s ) s | > | x k s s | , and the inequality above is strict. Therefore ∑ i = 1 t | x k i i | < min π ≠ 1 ⁡ | s ⁡ ( π ) ​ ∏ i = 1 t x k π ⁡ ( i ) i | ≤ | ∑ π ≠ 1 s ⁡ ( π ) ​ ∏ i = 1 t x k π ⁡ ( i ) i | = | | A | − ∏ i = 1 t x k i i | . But | A | = 0 and | − ∏ i = 1 t x i k i | = ∑ i = 1 t | x i k i | , giving a contradiction. ∎ If F is a nontrivial decomposer of a coloured projective geometry ( G ; c ) with | c | ≥ 2 , there clearly exist x ∈ F and y ≠ F with c ⁡ ( x ) ≠ c ⁡ ( y ) , and x is the only point of the line cl M ⁡ ( { x , y } ) with colour c ⁡ ( x ) . The next theorem, on the other hand, shows that colourings c v arising from nontrivial non-Archimedean valuations contain no lines that intersect a colour class in exactly one point, and hence they cannot be decomposed via lift-joins. This in turn implies that the statement of Theorem 6.8 must fail for projective geometries over general infinite fields, even when it is adjusted to allow for infinite matroids. Theorem 12.2 . Let n ≥ 1 , and v be a nontrivial non-Archimedean valuation on a field 𝔽 . Then no line L of PG ⁡ ( n − 1 , 𝔽 ) intersects a colour class of c v in exactly one point. Proof. Suppose that x = [ ( x 1 , … , x n ) ] is the unique point of a line L having colour k ∈ [ n ] . Since L contains no linearly independent triple, it contains no rainbow triple by Theorem 12.1 , so there is some colour ℓ ≠ k so that c ⁡ ( L − { x } ) = { k } . Since v is nontrivial, there exists d ∈ 𝔽 with v ⁡ ( d ) < 0 . Define hyperplanes W 1 = { a ∈ 𝔽 n : a k = 0 } and W 2 = { a ∈ 𝔽 n : a ℓ = d ​ a k } of 𝔽 n , and let H 1 , H 2 be the corresponding hyperplanes of PG ⁡ ( n − 1 , 𝔽 ) . For each a ∈ W 1 , we have a k = 0 and so v ⁡ ( a k ) = ∞ and hence c v ​ ( a ) ≠ k by the definition of c v . Similarly, for each a ∈ W 2 , we have v ⁡ ( a ℓ ) = v ⁡ ( d ) + v ⁡ ( a k ) < v ⁡ ( a k ) , so c v ​ ( a ) ≠ k . But since L is a line, there are points f 1 ∈ L ∩ H 1 and f 2 ∈ L ∩ H 2 . As just observed, we have c v ​ ( f 1 ) ≠ k and c v ​ ( f 2 ) ≠ k ; since f 1 , f 2 ∈ L we must have f 1 = f 2 = x . Therefore x ∈ H 1 ∩ H 2 , which by the definitions of H 1 and H 2 implies that x k = x ℓ = 0 . This contradicts the fact that c v ​ ( x ) = k . ∎ On the other hand, algebraic extensions of finite fields do not have nontrivial non-Archimedean valuations, and Theorem 1 of [ 14 ] will imply Lemma 5.7 for projective planes over all such fields. Using this fact, one could routinely extend Theorem 6.8 to apply to all finite-dimensional coloured projective geometries over algebraic extensions of finite fields.
