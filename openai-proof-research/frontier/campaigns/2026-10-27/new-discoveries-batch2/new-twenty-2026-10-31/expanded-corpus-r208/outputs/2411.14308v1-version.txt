In this paper we establish some new results similar to Lagrange’s four-square theorem. For example, we prove that any integer n > 1 n>1 can be written w ⁡ ( 5 ​ w + 1 ) / 2 + x ⁡ ( 5 ​ x + 1 ) / 2 + y ⁡ ( 5 ​ y + 1 ) / 2 + z ⁡ ( 5 ​ z + 1 ) / 2 w(5w+1)/2+x(5x+1)/2+y(5y+1)/2+z(5z+1)/2 with w , x , y , z ∈ ℤ w,x,y,z\in\mathbb{Z} . Here we state two general results: (1) If a a and b b are odd integers with a > 0 a>0 , b > − a b>-a and gcd ⁡ ( a , b ) = 1 \gcd(a,b)=1 , then all sufficient large integers can be written as w ⁡ ( a ​ w + b ) 2 + x ⁡ ( a ​ x + b ) 2 + y ⁡ ( a ​ y + b ) 2 + z ⁡ ( a ​ z + b ) 2 \frac{w(aw+b)}{2}+\frac{x(ax+b)}{2}+\frac{y(ay+b)}{2}+\frac{z(az+b)}{2} with w , x , y , z w,x,y,z nonnegative integers. (2) If a a and b b are integers with a > 0 a>0 , b > − a b>-a , 2 | a 2\mid a and gcd ⁡ ( a , b ) = 1 \gcd(a,b)=1 , then all sufficient large integers can be written as w ⁡ ( a ​ w + b ) + x ⁡ ( a ​ x + b ) + y ⁡ ( a ​ y + b ) + z ⁡ ( a ​ z + b ) w(aw+b)+x(ax+b)+y(ay+b)+z(az+b) with w , x , y , z w,x,y,z nonnegative integers. Introduction Lagrange’s four-square theorem states that any n ∈ ℕ = { 0 , 1 , 2 , … } n\in\mathbb{N}=\{0,1,2,\ldots\} can be written as w 2 + x 2 + y 2 + z 2 w^{2}+x^{2}+y^{2}+z^{2} with w , x , y , z ∈ ℤ w,x,y,z\in\mathbb{Z} . For any integer m ⩾ 3 m\geqslant 3 , the polygonal numbers of order m m (or m m -gonal numbers) are those nonnegative integers p m ​ ( n ) = ( m − 2 ) ​ ( n 2 ) + n = n ⁡ ( ( m − 2 ) ​ n − ( m − 4 ) ) 2 ( n = 0 , 1 , 2 , … ) . p_{m}(n)=(m-2)\binom{n}{2}+n=\frac{n((m-2)n-(m-4))}{2}\ \ (n=0,1,2,\ldots). Note that p 3 ​ ( x ) = x ⁡ ( x + 1 ) 2 , p 4 ​ ( x ) = x 2 , p 5 ​ ( x ) = x ⁡ ( 3 ​ x − 1 ) 2 ​ and ​ p 8 ​ ( x ) = x ⁡ ( 3 ​ x − 2 ) . p_{3}(x)=\frac{x(x+1)}{2},\ p_{4}(x)=x^{2},\ p_{5}(x)=\frac{x(3x-1)}{2}\ \text{and}\ p_{8}(x)=x(3x-2). Fermat claimed that each n ∈ ℕ n\in\mathbb{N} is a sum of m m m m -gonal numbers; this was confirmed by Lagrange, Gauss and Cauchy for the cases m = 4 m=4 , m = 3 m=3 , and m ⩾ 5 m\geqslant 5 , respectively (cf. [ 3 , 4 ] ). In 2016 the author [ 6 ] proved that each n ∈ ℤ + = { 1 , 2 , 3 , … } n\in\mathbb{Z}^{+}=\{1,2,3,\ldots\} can be written a sum of four generalized octagonal numbers one of which is odd. This is quite similar to Lagrange’s four-square theorem.
