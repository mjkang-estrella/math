# Polynomial failure of the universal boundary Korn estimate

Status: COMPLETE ORDINARY PROOF; candidate for independent mathematical and significance review. No novelty acceptance, Lean verification, or public submission is asserted.

## Exact source and scope

Feng–Lorton, arXiv:1501.05340v1 (21 January 2015), printed p4, Conjecture 2.2, equation (2.5), asserts the existence of a positive constant K such that for **every** vector field u in H²(Ω),

    ||∇u||²_{L²(Γ)} ≤ K (||u||²_{L²(Γ)} + ||ε(u)||²_{L²(Γ)}).

Here ε(u)=(∇u+(∇u)^T)/2 and the matrix norm is Frobenius. The setup on p2 allows d=2 or 3 and an open bounded domain; p3 assumes strict star-shapedness. The open unit disk D in R² is smooth, convex, and strictly star-shaped: x·n=1 on ∂D. The displayed universal conjecture is not restricted to homogeneous elasticity solutions. We refute exactly that universal estimate. No claim is made about theorems conditional on that estimate or estimates on restricted PDE solution spaces.

## Theorem

For every real C>0 there is a real polynomial vector field u:R²→R² for which

    ||∇u||²_{L²(∂D)} > C (||u||²_{L²(∂D)} + ||ε(u)||²_{L²(∂D)}).

In fact, there is an explicit sequence u_k, k any positive integer, with the three squared norms respectively π(2k²+1), π, π. Consequently their quotient is k²+1/2, and there is no finite domain-dependent constant even on the fixed unit disk.

## Construction and proof

Identify R² with C and write z=x+iy and s=z\bar z=x²+y². For every integer k≥1 define the complex polynomial

    U_k(z,\bar z) = [(3-s)z^(k+1) + s((2k+3)-(2k+1)s)\bar z^(k-1)]/4,

and set u_k=(Re U_k, Im U_k). Every real component is a polynomial in x,y, including when k=1. Hence u_k is smooth on a neighborhood of the closed disk and belongs to H²(D;R²).

For r>0 write z=r exp(iθ), e_r=(cosθ,sinθ), e_θ=(-sinθ,cosθ). Algebraically the same field is

    u_k(r,θ)=a_k(r)cos(kθ)e_r + b_k(r)sin(kθ)e_θ,
    a_k(r) = r^(k+1)((k+3)-(k+1)r²)/2,
    b_k(r) = (k/2)r^(k+1)(r²-1).

Indeed, after multiplication by exp(iθ), a cos(kθ)+i b sin(kθ) equals [(a+b)exp(i(k+1)θ)+(a-b)exp(i(1-k)θ)]/2, and substituting a,b gives U_k. The apparent polar singularity at zero is irrelevant because the Cartesian expression is polynomial.

Direct differentiation yields

    a_k(1)=1, a'_k(1)=0, b_k(1)=0, b'_k(1)=k.

For any smooth u=u_r e_r+u_θ e_θ the gradient, using the orthonormal frame (e_r,e_θ) for both input and output, is

    [ ∂_r u_r     (∂_θ u_r-u_θ)/r ]
    [ ∂_r u_θ     (∂_θ u_θ+u_r)/r ].

This follows by differentiating ∂_θ e_r=e_θ, ∂_θ e_θ=-e_r, with the unit tangential derivative r^(-1)∂_θ. Thus on r=1,

    u_k = cos(kθ)e_r,
    ∇u_k = [ 0           -k sin(kθ) ]
           [ k sin(kθ)    cos(kθ)   ],
    ε(u_k)=diag(0, cos(kθ)).

Changing the same orthonormal frame on input and output preserves Frobenius norms and symmetric parts. These identities therefore calculate exactly the Cartesian gradient and strain norms. Unit-circle arclength is dθ. Since for each positive integer k,

    ∫₀^{2π}cos²(kθ)dθ = ∫₀^{2π}sin²(kθ)dθ = π,

we obtain

    ||u_k||² = π,
    ||ε(u_k)||² = π,
    ||∇u_k||² = π(2k²+1).

The integral identities follow immediately by integrating cos²t=(1+cos2t)/2 and sin²t=(1-cos2t)/2. Given C>0 choose a positive integer k>C+1, using the Archimedean property. Then k²+1/2>C, so π(2k²+1)>2πC. This proves the stated strict inequality and refutes the source's universal constant. QED.

## Lean feasibility

A meaningful endpoint is the literal negation of a uniform boundary inequality on D for polynomial real vector fields, with actual derivatives and actual integrals on the unit circle. Prove the polynomial's smoothness and H² membership, its derivative identities on the parametrized circle, the arclength integration equivalence, and the three exact norms, then use k²+1/2 unbounded. Algebra can use complex monomials or real polynomial expansions; the proof requires no decision procedure over transcendental approximations. The main engineering burden is the honest bridge from parameterized circle integrals to Sobolev trace norms and from the polar derivative formula to the Cartesian Frechet derivative. A theorem only about a hand-assigned boundary matrix would not be an acceptable endpoint.
