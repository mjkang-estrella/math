                                                A weighted bilateral shift with cyclic square is supercyclic
                                                                                       Stanislav Shkarin


                                                                                             Abstract




arXiv:1209.1458v1 [math.FA] 7 Sep 2012
                                                  It is shown that for a bounded weighted bilateral shift T acting on ℓp (Z) for 1 ⩽ p ⩽ 2
                                               supercyclicity of T , weak supercyclicity of T , cyclicity of T ⊕T and cyclicity of T 2 are equivalent.
                                               A new sufficient condition for cyclicity of a weighted bilateral shift is proved, which implies, in
                                               particular, that any compact weighted bilateral shift is cyclic.

    On the other hand, cyclicity of a weighted bilateral shift turns out to be a much more subtle
issue, see, for instance, [10, 11, 14, 18]. It is worth noting that unlike for hypercyclicity or super-
cyclicity, cyclicity of a weighted bilateral shift depends on p. For instance, the unweighted bilateral
shift is cyclic on ℓ2 (Z) and non-cyclic on ℓ1 (Z). There exist several necessary and several sufficient
conditions of cyclicity of a weighted bilateral shift, see for instance, the works of Herrero [10, 11].
Prominent among these conditions is the observation that if the adjoint of a weighted bilateral shift
T on ℓp (Z) for 1 ⩽ p < ∞ has non-empty point spectrum then T is non-cyclic. This implies, in
particular, that the weighted bilateral shift Tw,p with the weight sequence wn = a for n ⩽ 0 and
wn = b for n > 0 with 0 < |b| < |a| is non-cyclic for any p ∈ [1, ∞]. This is precisely the shape of
the first example of a non-cyclic weighted bilateral shift, obtained by Beauzamy [5].
    Recall that a bounded linear operator T on a Banach space B is said to satisfy the Supercyclicity
Criterion [12] if there exist a strictly increasing sequence {nk }k∈Z+ of positive integers, dense subsets
E and F of B and a map S : F → F such that T Sy = y for each y ∈ F and kT nk xkkS nk yk → 0 as
k → ∞ for any x ∈ E and y ∈ F . The following two results are proved in [12].
Theorem SC. Any operator satisfying the Supercyclicity Criterion is supercyclic.
Theorem MS. A weighted bilateral shift on ℓp (Z) for 1 ⩽ p < ∞ or on c0 (Z) is supercyclic if and
only if it satisfies the Supercyclicity Criterion.
    There is no great mystery about the last theorem. One just has to take E = F being the space
of sequences with finite support, S being the inverse of the restriction of T to F and use Theorem S
to find an appropriate sequence {nk }. Note also that weak hypercyclicity and weak supercyclicity
of weighted bilateral shifts were studied in [3, 6, 17, 19]. In [19] it is shown that for p ⩽ 2 any
weighted bilateral shift on ℓp (Z) is either supercyclic or is not weakly supercyclic. We extend this
dichotomy.
Theorem 1.1. Let 1 ⩽ p ⩽ 2 and T be a weighted bilateral shift on ℓp (Z). Then the following
statements are equivalent:
(C1) T satisfies the Supercyclicity Criterion;
(C2) T is supercyclic;
(C3) T is weakly supercyclic;
(C4) T ⊕ T is cyclic;
(C5) there is n ⩾ 2 for which T n is cyclic;
(C6) for any n ∈ N, T n is cyclic.
    We would like to stress that, as it is shown in [19], for each p > 2 there is a weakly supercyclic
non-supercyclic weighted bilateral shift T on ℓp (Z). Since powers of a weakly supercyclic operators
are cyclic, we see that (C6) does not imply (C2) when p > 2. From this observation and equivalence
of (C5), (C6) and (C2) for p ⩽ 2, we immediately obtain the following corollary.
Corollary 1.2. A weighted bilateral shift T acting on ℓp (Z) with 1 ⩽ p ⩽ 2 is supercyclic if and
only if T 2 is cyclic. On the other hand for each p > 2 there exists a non-supercyclic weighted
bilateral shift on ℓp (Z) whose powers are all cyclic.

2    Proof of Theorem 1.1
We start with the following three easy and known but nice observations.

Lemma 2.1. Let B1 and B2 be Banach spaces and T1 ∈ L(B1 ), T2 ∈ L(B2 ) be such that there exists
a bounded linear operator J : B1 → B2 with dense range satisfying T2 J = JT1 . Then cyclicity of
T1 implies cyclicity of T2 .
                                                                      
Proof. Observe that span {T2n Jx : n ∈ Z+ } = J span {T1n x : n ∈ Z+ } for each x ∈ B1 . Hence Jx
is a cyclic vector for T2 for each cyclic vector x for T1 .

Remark. The same argument shows that Lemma 2.1 remains true if cyclicity is replaced by
hypercyclicity, supercyclicity, weak hypercyclicity or weak supercyclicity.

Lemma 2.2. Let B be a Banach space and T ∈ L(B). Then the operator T ⊕ T ∗ acting on B × B ∗
is non-cyclic.

Proof. Let (x, f ) ∈ B × B ∗ be different from zero. Then the continuous linear functional F on
B ⊕ B ∗ defined by F (y, g) = f (y) − g(x) is non-zero. We have,

          F (T n x, T ∗n f ) = f (T n x) − T ∗n f (x) = f (T n x) − f (T n x) = 0   for any   n ∈ Z+ .

Thus, the orbit of any non-zero vector under T ⊕ T ∗ is contained in the kernel of a non-zero
continuous linear functional. Therefore, T ⊕ T ∗ is not cyclic.

Corollary 2.3. Let B be a Banach space and T ∈ L(B) be such that there exists a bounded linear
operator J : B → B ∗ with dense range satisfying T ∗ J = JT . Then the operator T ⊕ T acting on
B ⊕ B is non-cyclic.

Proof. Since T ∗ J = JT , we have (T ⊕ T ∗ )(I ⊕ J) = (I ⊕ J)(T ⊕ T ). Assume that T ⊕ T is cyclic.
Since I ⊕ J : B × B → B × B ∗ is bounded and has dense range, Lemma 2.1 implies that T ⊕ T ∗ is
cyclic, which is impossible according to Lemma 2.2.

4    Concluding remarks
It is worth mentioning another dichotomy for weighted bilateral shifts, provided in [20]. Namely if
T is a weighted bilateral shift on ℓp (Z) with 1 < p < ∞ then either T is supercyclic or T n x/kT n xk
is weakly convergent to zero as n → ∞ for each non-zero x ∈ ℓp (Z). The same holds true for
weighted bilateral shifts on c0 (Z) and fails for weighted bilateral shifts on ℓ1 (Z). We would like to
stress that the following problem remains open.
Problem 4.1. Characterize cyclic weighted bilateral shifts on ℓp (Z) for 1 ⩽ p < ∞ and on c0 (Z).
   As mentioned in [1], it is not known whether certain specific weighted bilateral shifts are cyclic.
For instance, let 0 < α ⩽ 1, wn = 1 if n ⩽ 1 and wn = 1 − n−α if n ⩾ 2. It is easy to see that the

when α > 1/2.

   We conjecture that the answer to the following question must be affirmative.

Problem 4.3. Let 2 < p ⩽ ∞. Does there exist a weighted bilateral shift T = Tw,p such that T n is
cyclic for any n ∈ N and T is not weakly supercyclic?

    Note that Salas [15] proved that I + T is hypercyclic for any (unilateral) backward weighted
shift T . We would like to raise the following problem.

Problem 4.4. Characterize weighted bilateral shifts Tw,p for which I + T is hypercyclic. What
about supercyclicity?

   What the author has been able to observe so far is that for 1 ⩽ p ⩽ 2, supercyclicity of I + T
implies supercyclicity of T for any weighted bilateral shift T on ℓp (Z).
   Finally, we would like to raise the following problem.

Problem 4.5. Does there exists a bounded linear operator T on a separable Banach space such
that T ⊕ T is cyclic and T 2 is non-cyclic?
