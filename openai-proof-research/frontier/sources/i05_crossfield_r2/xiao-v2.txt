                                                                              1. Introduction

                                            Throughout the paper, let (X, B, µ) be a Lebesgue space. Let Z[n] denote all
                                          polynomials with integer coefficients.
                                            Let G be an infinte, countable, discrete group. A tuple (X, B, µ, G) is a measure-
                                          preserving system if there exists a group homomorphism Π : G → MPT(X, B, µ)
                                          where MPT(X, B, µ) denotes the group of invertible measure-preserving transfor-
                                          mations of (X, B, µ). We write g for the measure-preserving transformation Π(g).
                                          When G = Z, we write (X, B, µ, T ) for measure-preserving system (X, B, µ, G) where
                                          T denotes the measure-preserving transformation Π(1).
                                            In 1977, H. Furstenberg provided an ergodic theoretic proof for Szemerédi’s theo-
                                          rem in [13]. From then on, convergence of polynomial ergodic averages of measure-

2.3. Algebraic past. Given group G with identity element eG , an algebraic past
of G is a subset Φ with properties (1)-(3): (1) Φ∩Φ−1 is empty; (2) Φ∪Φ−1 ∪{eG } =
G; (3) Φ · Φ ⊂ Φ. The group G is left-orderable if there exists a linear ordering
in G which is invariant under left translation. The group G is left-orderable if and
only if there exists an algebraic past Φ in G. Indeed, one can obtain the desired
linear-order based on Φ as follows: g1 is less than g2 (write g1 <Φ g2 or g1 < g2 ) if
g2 −1 g1 ∈ Φ.
Example 2.3. When G = Z, let Φ be {n ∈ Z : n < 0}. Then we can get the natural
linear order of Z.
