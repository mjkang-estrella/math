Abstract.
In the paper we develop a new method of proving non-speciality
of a linear system with base fat points in general position.
Using this method we
show that the Hirschowitz-Harbourne Conjecture holds
for systems with base points of equal multiplicity bounded by 4242.
Key words and phrases: Multivariate interpolation, linear systems, Hirschowitz–Harbourne conjecture.
1991 Mathematics Subject Classification14H50; 13P10

2. The Hirschowitz–Harbourne Conjecture
For systems of the form ℒd​(m1,…,mr):=ℒD​(m1,…,mr)\mathcal{L}_{d}(m_{1},\dots,m_{r}):=\mathcal{L}_{D}(m_{1},\dots,m_{r}), D={α∈ℕ2∣|α|≤d}D=\{\alpha\in\mathbb{N}^{2}\mid|\alpha|\leq d\}
the well-known
Hirschowitz–Harbourne Conjecture giving geometrical
description of the speciality of a system was formulated in [9].
To formulate this conjecture consider the blowing-up
π:ℙ~2→ℙ2\pi:\widetilde{\mathbb{P}}^{2}\to\mathbb{P}^{2} in rr general points with
exceptional divisors E1,…,ErE_{1},\dots,E_{r}.
Definition 5.
A curve C⊂ℙ2C\subset\mathbb{P}^{2} is said to be a −1-1-curve
if it is irreducible and the self-intersection C~2\widetilde{C}^{2} of its proper
transform C~⊂ℙ~2\widetilde{C}\subset\widetilde{\mathbb{P}}^{2} is equal to −1-1.
Conjecture 6 (Hirschowitz–Harbourne).
A system L=ℒd​(m1,…,mr)L=\mathcal{L}_{d}(m_{1},\dots,m_{r}) is special if and only if
there exists a −1-1-curve C⊂ℙ2C\subset\mathbb{P}^{2} such that
L~.C~≤−2,\widetilde{L}.\widetilde{C}\leq-2,
where L~:=|d​π∗​(𝒪ℙ2​(1))−∑j=1rmj​Ej|\widetilde{L}:=|d\pi^{*}(\mathcal{O}_{\mathbb{P}^{2}}(1))-\sum_{j=1}^{r}m_{j}E_{j}|.
This conjecture was studied by many authors, we refer only to the recent
results. For homogenous systems (m1=m2=m3=⋯=mr=:mm_{1}=m_{2}=m_{3}=\dots=m_{r}=:m),
the above conjecture holds for m≤20m\leq 20 (see [4, 5]).
In the general case the Conjecture holds for multiplicities bounded by 1111
(see [8]). Both these results were obtained with the help of computers.
For further information about the above conjecture see for example
[3].
In this paper we develop a new method (called ’’diagram cutting‘‘) based
on some properties of matrices assigned to systems of curves.
This method allows providing easy proofs
of non-speciality for large family of systems. Moreover, these proofs
can often be found argorithmically with a computer program.
Sometimes this needs a lot of computations, but then it can easily be checked
’’by hand‘‘.
As a result of the method we show that in order to check non-speciality
of all homogeneous systems of bounded multiplicity mm it is enough to
check a finite number of cases. This result was obtained in purely theoretical way.
The second result is Theorem 31 stating that
Conjecture 6 holds for homogeneous multiplicities bounded by 4242.
This result was obtained using a computer program.
3. Diagram cutting method
Before introducing the method we must establish the notation and
say when a system is non-special in the language of matrices.

Lemma 20.

5. Homogeneous systems with bounded multiplicity
Theorem 31.
The Hirschowitz-Harbourne Conjecture holds for homogeneous systems with multiplicities
bounded by 4242.
Proof.
For m<20m<20 the result can be found in [5].
For m=20,…,42m=20,\dots,42 we choose d0​(m)=3​md_{0}(m)=3m.
In order to
check the conjecture we have to do the following:
(1)
Find all non-special systems among ℒd​(m×r)\mathcal{L}_{d}(m^{\times r}) for
d≤d0​(m)d\leq d_{0}(m) (there are only finitely many of them). Next, for every such system
we must show that it satisfies the Hirschowitz-Harbourne conjecture. This was done
with the help of computer programs. By the proof of Theorem 29
the maximal size of matrix (for m=42m=42) can be 8128×116568128\times 11656, but
in most cases the combination of reduction method and Cremona transformation
gives an immediate answer.
(2)
For every system from the set S​(m,d0​(m))S(m,d_{0}(m)) we must prove its
non-speciality.
As the set S​(m,d0​(m))S(m,d_{0}(m)) contains systems with big size of diagrams, this
cannot be done without preparations.
For a system L=ℒD​(m×r)∈EoLS⁡(m)L=\mathcal{L}_{D}(m^{\times r})\in\EoLS(m) we use reduction method described in
[8] to reduce the problem to the question about non-speciality
of L′=ℒD′​(m×5)L^{\prime}=\mathcal{L}_{D^{\prime}}(m^{\times 5}) for some diagram D′D^{\prime}.
For m=42m=42 this forces us to compute the determinant
of 4515×45154515\times 4515 matrix 4343 times — this can be done.
For the rest of the systems from S​(m,d0​(m))S(m,d_{0}(m)) we use the following fact
(see Proposition 28 in [8]).
Theorem 32.
Let m1,…,mr∈ℕ∗m_{1},\dots,m_{r}\in\mathbb{N}^{*}. There exists a diagram DD with
the property: if ℒD​(m1,…,mr)\mathcal{L}_{D}(m_{1},\dots,m_{r}) is non-special then for all d∈ℕd\in\mathbb{N}
the system ℒd​(m1,…,mr)\mathcal{L}_{d}(m_{1},\dots,m_{r}) is non-special.
So for each rr such that ℒd​(m×r)∈S⁡(m,d0​(m))\mathcal{L}_{d}(m^{\times r})\in S(m,d_{0}(m)) we have to check
only one system ℒD​(m×r)\mathcal{L}_{D}(m^{\times r}) for some diagram DD depending on rr.
We also reduce this system to ℒD′​(m×9)\mathcal{L}_{D^{\prime}}(m^{\times 9}).
In [6] the reader can find the table with the actual number of cases to be checked,
as well as all necessary software with instructions, on how to perform the tests.
∎
Remark 33.
The test decribed above can also be performed for greater values of mm,
but for each m≥43m\geq 43 this will take at least several days of computation.
It seems that now it would be better to reorganize the method.
6. Closing remarks
Remark 34.
There exists another method of proving non-speciality of given system
(or for a family of systems) based on blowing-up the projective space
introduced by C. Ciliberto and R. Miranda ([5]). It seems
that diagram cutting method is different and sometimes works better.
Moreover, all definitions and results of section 3 can
be easily carried over to the higher-dimensional case of the
systems of polynomials in nn variables vanishing (with multiplicities)
at points in general position. This is not known for the method
of C. Ciliberto and R. Miranda.
Remark 35.
Observe that Theorem 27 can be reformulated to the following.
Theorem 36.
If the set EoLS⁡(m)\EoLS(m) contains only non-special systems and
ℒd​(m1,…,mr)\mathcal{L}_{d}(m_{1},\dots,m_{r}) is non-special then
ℒd+m⁡(m+1)​(m1,…,mr,m×p)\mathcal{L}_{d+m(m+1)}(m_{1},\dots,m_{r},m^{\times p})
is non-special, where p=2​d+m⁡(m+1)+1p=2d+m(m+1)+1.
This shows that in order to find all non-special systems of the form
ℒd​(m1,…,mr)\mathcal{L}_{d}(m_{1},\dots,m_{r}) with mi≤Mm_{i}\leq M, i=1,…,ri=1,\dots,r it
is sufficient to check a finite number of cases.
