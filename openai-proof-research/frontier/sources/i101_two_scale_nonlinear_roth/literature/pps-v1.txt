Abstract.
A nonlinear version of Roth’s theorem states that dense sets of integers contain configurations of the form x, x+d, x+d^{2}. We obtain a multidimensional version of this result, which can be regarded as a first step towards effectivising those cases of the multidimensional polynomial Szemerédi theorem involving polynomials with distinct degrees. In addition, we prove an effective “popular” version of this result, showing that every dense set has some non-zero d such that the number of configurations with difference parameter d is almost optimal. Perhaps surprisingly, the quantitative dependence in this result is exponential, compared to the tower-type bounds encountered in the popular linear Roth theorem.

1. Introduction
A long-standing programme in additive combinatorics concerns obtaining effective
versions of the multidimensional Szemerédi theorem [FK78]
and the polynomial Szemerédi theorem [BL96], as well as their
common generalisation (also found in [BL96]); see for instance
[Gow98, Gow22]. In this paper, we take a first step towards effectivising those cases of the multidimensional polynomial Szemerédi theorem involving polynomials of distinct degrees.
Theorem 1.1 (Density bound).
If A\subset\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\}\times\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\} does not contain a triple of the form
(1.1)
(x,y),\ (x+d,y),\ (x,y+d^{2})\quad\text{with}\quad d\neq 0,
then
|A|=O\mathopen{}\left({N^{2}}/{(\log N)^{c}}\mathclose{}\right).
Here c>0 is an absolute constant11
1
We expect that c=2^{-300} is permissible..
Simultaneous to our work, Kravitz, Kuca and Leng [KKL] have obtained a result of this type for configurations of the form (x,y), (x+P(d),y), (x,y+P(d)), where P\in\mathbb{Z}[d] has an integer root of multiplicity one. Together, these constitute the first effective cases of the multidimensional polynomial Szemerédi theorem
involving both a genuinely multidimensional configuration and a genuinely nonlinear
polynomial.
We derive our density bound on taking \varepsilon=\delta^{3}/2 in the following stronger result, which proves the existence of a “popular” difference (with effective bounds).
Theorem 1.2 (Popular difference in two dimensions).
Let A\subset\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\}\times\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\} with |A|\geqslant\delta N^{2} and let 0<\varepsilon\leqslant 1/2.
Either N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exists d\neq 0 such that
\#\mathopen{}\left\{(x,y)\in A:(x+d,y),(x,y+d^{2})\in A\mathclose{}\right\}\geqslant\mathopen{}\left(\delta^{3}-\varepsilon\mathclose{}\right)N^{2}.
Theorem 1.2 is a consequence of our more general Theorem 7.1, which we also use (in §7) to derive the existence of a popular difference in the one-dimensional context:
Theorem 1.3 (Popular difference in one dimension).
Let A\subset\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\} with |A|\geqslant\delta N and let 0<\varepsilon\leqslant 1/2.
Either N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exists d\neq 0 such that
\#\mathopen{}\left\{x\in A:x+d,x+d^{2}\in A\mathclose{}\right\}\geqslant\mathopen{}\left(\delta^{3}-\varepsilon\mathclose{}\right)N.
We remark that the above exponential bound N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) is in sharp contrast to the tower-type bound necessary for linear three-term progressions, see [FPZ22].
As a corollary to Theorem 1.3, we obtain a new proof that subsets of
\mathopen{}\left\{1,2,\dots,N\mathclose{}\right\} lacking the nonlinear Roth configuration have at most polylogarithmic
density, which is the main result of [PP22]. As
in [PP22], our argument crucially relies on the advances
made in [PP19].

Remark 1.5 (The obstructions in our inverse theorem are necessary).
By removing the absolute value in (1.3), at the cost of introducing signs, one can re-phrase our inverse theorem as saying that if the counting operator for our configuration is large, as in (1.2), then the function weighting the (x+d,y) term correlates with a function of the form
(x,y)\mapsto e(\alpha x)\phi(y),
where \alpha is “major arc at scale N” and \phi:\mathbb{Z}\to\mathbb{C} is 1-bounded. Similarly, the function weighting the (x,y+d^{2}) term correlates with a function of the form
(x,y)\mapsto\psi(x)e(\beta y),
where \beta is major arc at scale N^{2} and \psi:\mathbb{Z}\to\mathbb{C} is 1-bounded.
Notice that the above formulation does not posit any structure for the 1-bounded functions \phi and \psi. There is no hope in being able to extract further structure regarding these functions: their arbitrariness is necessary. This is exhibited in the following example.
Let \phi:[N^{2}]\to\mathopen{}\left\{\pm 1\mathclose{}\right\} be a random function that takes the value 1 with probability 1/2, independently as the argument ranges over [N^{2}]. For (x,y)\in[N]\times[N^{2}] set
f_{0}(x,y):=\phi(x)\phi(y)(-1)^{x+y},\quad f_{1}(x,y):=(-1)^{x}\phi(y)\quad\text{and}\quad f_{2}(x,y):=\phi(x)(-1)^{y}.
Then
\sum_{x,y,d}f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2})=\sum_{x,y,d}1_{[N]}(x)1_{[N^{2}]}(y)1_{[N]}(x+d)1_{[N^{2}]}(y+d^{2})\gg N^{4}.
Yet for any “reasonable” notion of structured function \psi, the randomness of \phi means that the fibre maps y\mapsto f_{1}(x,y) and x\mapsto f_{2}(x,y) almost surely do not correlate with \psi.
1.1. Previous work
1.1.1. Density bounds for higher-dimensional configurations
Let us first put our density bound (Theorem 1.1) in context.
Given any two-point polynomial configuration (without congruence obstructions), it is
likely that one can show that subsets of [N]^{n} lacking this configuration have at most
polylogarithmic density. One way to prove this is to generalise Sárközy’s argument
[Sár78] for the configuration x,x+d^{2}; see Lyall and Magyar’s
[LM09] treatment of \underline{x},\underline{x}+(d,d^{2},\dots,d^{n}) for an instance
of this approach. It is also plausible that even stronger bounds could be obtained by
adapting the argument of Bloom and Maynard [BM22], who have proved the current best
known bounds in Sárközy’s theorem.
Longer linear configurations in \mathbb{Z}^{n} can be encoded as matrix progressions
\underline{x},\ \underline{x}+T_{1}\underline{d},\ \dots\ \underline{x}+T_{s}\underline{d},
where T_{i} are n\times n matrices with integer entries. As was demonstrated in
[Pre15], provided that the T_{i} and their differences T_{i}-T_{j}
(i\neq j) are all non-singular, one can extract density bounds for sets lacking these
configurations by adapting the higher-order Fourier analysis techniques of Gowers [Gow01]. One may be able to synthesise this approach with that of [Pre17] in order to bound the density of sets lacking nonlinear matrix progressions of the form
\underline{x},\ \underline{x}+T_{1}(d_{1}^{k},\dots,d_{n}^{k}),\ \dots\ \underline{x}+T_{s}(d_{1}^{k},\dots,d_{n}^{k}),
again provided that the T_{i} and their differences T_{i}-T_{j} (i\neq j) are all non-singular.
It is much harder to obtain quantitative bounds for sets lacking singular matrix progressions. Preceding this article and that of Kravitz-Kuca-Leng [KKL], there are only two results in this direction (for progressions of length greater than two). The first is due to Shkredov [Shk06] and obtains double-logarithmic bounds for sets lacking any three-point matrix progression, regardless of the singularity of the matrices and their differences. This very general result is deduced in [Pre15, Theorem B.2] from Shkredov’s much more concrete result which bounds the density of sets lacking two-dimensional corners:
(1.4)
(x,y),\ (x+d,y),\ (x,y+d)\quad\text{with}\quad d\neq 0.
Very recently, the first author [Pel24] obtained the first reasonable bounds for sets lacking a specific four-point singular matrix progression, namely L-shapes:
(1.5)
(x,y),\ (x+d,y),\ (x,y+d),\ (x,y+2d)\quad\text{with}\quad d\neq 0.
Although this argument was carried out over the finite field model \mathbb{F}_{p}^{n}\times\mathbb{F}_{p}^{n}, those conversant with the appropriate machinery will see that adapting the argument to the integer setting is now within reach, albeit technically demanding.
We believe the arguments of this paper open up the possibility of obtaining bounds for sets lacking polynomial progressions of the form
(1.6)
\underline{x},\ \underline{x}+P_{1}(d)\underline{v}_{1},\ \dots\ ,\ \underline{x}+P_{s}(d)\underline{v}_{s}\quad\text{with}\quad d\neq 0,
where \underline{v}_{1},\dots,\underline{v}_{s} are fixed integer vectors and the polynomials P_{i} have
integer coefficients, zero constant term and (importantly) distinct degrees. Our
configuration (1.1) corresponds to taking P_{1}=d, P_{2}=d^{2}, \underline{v}_{1}=(1,0) and \underline{v}_{2}=(0,1). For the analogous problem over the finite field \mathbb{F}_{p}, our
paper corresponds to work of Han-Lacey-Yang [HLY21], and we posit that it
is possible to obtain the analogue of Kuca’s more general result [Kuc24] in the integers. In this paper we make heavy use of the one-dimensional machinery developed in [PP19] for x,x+d,x+d^{2}, and for (1.6) we expect that the appropriate one-dimensional machinery is available in [Pel20].
1.1.2. Existence of a popular difference
We now turn to the context surrounding our popular difference results (Theorem 1.2 and Theorem 1.3). To our knowledge, the first results in this direction concern three-term and four-term arithmetic progressions [BHK05]. These results were obtained via ergodic methods and as a result concern the weaker notion of upper Banach density, rather than the lower density we deal with in Theorem 1.2 and Theorem 1.3. There have since been a number of ergodic works dealing with other configurations, see for instance [Fra08, Chu11, DLMS21]. In particular, Chu, Frantzikinakis and Host [CFH11] have proved the ergodic (and hence qualitative) analogue of Theorem 1.2.
Green [Gre05b] pioneered the use of arithmetic regularity to study these problems, proving the existence of a popular difference for three-term arithmetic progressions and thereby strengthening [BHK05] from upper Banach density to lower density. Green’s theorem states that for any \varepsilon>0 and any A\subset[N] with |A|\geqslant\delta N, either N\leqslant C(\varepsilon) or there exists d\neq 0 such that
(1.7)
\#\mathopen{}\left\{x\in A:x+d,\ x+2d\in A\mathclose{}\right\}\geqslant(\delta^{3}-\varepsilon)N.
Green and Tao [GT10] used higher-order Fourier analysis to obtain the analogous result for four-term arithmetic progressions. The result is false for longer progressions; see Ruzsa’s appendix to [BHK05].
In Green’s argument for (1.7), the constant C(\varepsilon) is bounded in terms of a tower of twos of height \varepsilon^{-O(1)}. This tower height was reduced to O(\log(1/\varepsilon)) by Fox, Pham and Zhao [FP21, FP19, FPZ22], who went on to demonstrate (remarkably) that this bound is best possible.
In higher dimensions, existence of a popular common difference for certain non-singular matrix progressions of length 3 and 4 was established in [BSST22]. For corners (1.4), the ergodic version of a popular difference was studied by Chu [Chu11], with combinatorial analogues obtained by Mandache [Man21]. Both of these authors establish that the naive conjecture is not correct for the popular difference version of the corners theorem. The “correct” conjecture was emphatically addressed in [FSS+20]. In [SSZ21], linear configurations were classified according to when the naive conjecture is correct.
All of the above results concerning popular differences have either been qualitative or
the bounds obtained have been tower-type. The only result we are aware of with reasonable
bounds is due to Lyall and Magyar [LM13], and concerns two-point
polynomial progressions in one dimension. Lyall and Magyar show that if P is a
polynomial with integer coefficients and zero constant term, then for any \varepsilon>0 and
A\subset[N] with |A|\geqslant\delta N, either there exists d\in\mathbb{Z}\setminus\mathopen{}\left\{0\mathclose{}\right\}
such that
\#\mathopen{}\left\{x\in A:x+P(d)\in A\mathclose{}\right\}\geqslant(\delta^{2}-\varepsilon)N,
or N\leqslant\exp\exp\mathopen{}\left(O\mathopen{}\left(\varepsilon^{-1}\log(\varepsilon^{-1}\mathclose{}\right)\mathclose{}\right). We believe that by suitably adapting the methods of this paper, one should be able to replace this double exponential bound with N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right). Determining the correct bound on N seems an interesting problem, even in the simplest situation of x, x+d^{2}. In forthcoming work by the second author, the third author and Mengdi Wang, we generalize Lyall and Magyar’s result to certain multi-point polynomial progressions, proving that if P_{1},\cdots,P_{m} are polynomials with integer coefficients and zero constant terms with distinct degrees, then for any \varepsilon>0 and
A\subset[N] with |A|\geqslant\delta N, either there exists d\in\mathbb{Z}\setminus\mathopen{}\left\{0\mathclose{}\right\}
such that
\#\mathopen{}\left\{x\in A:x+P_{1}(d),\cdots,x+P_{m}(d)\in A\mathclose{}\right\}\geqslant(\delta^{m+1}-\varepsilon)N,
or N\leqslant\exp\exp\mathopen{}\left(O\mathopen{}\left(\varepsilon^{-1}\mathclose{}\right)\mathclose{}\right).
2. An outline of our argument
All statements in this section are of a heuristic and informal nature, in particular much of what we write is, strictly speaking, false. To avoid obfuscating our sketch by tracking ranges of summation, we simply write \mathbb{E}_{x}f(x) to indicate a normalised sum, with the range of summation to be inferred from the context.
Given a set A\subset[N]^{2} of density \delta:=|A|/N^{2}, our starting point is to study the count
(2.1)
\mathbb{E}_{x,y,d}1_{A}(x,y)1_{A}(x+d,y)1_{A}(x,y+d^{2}).
Traditionally in additive combinatorics, one compares this with the count of configurations lying in a random set of density \delta, which (after normalisation) is of order \delta^{3}. If these counts are close, then one has a profusion of configurations in the set A. If not, then we hope to show that A has some exploitable structure. In a density increment argument, we typically exploit this by passing to a substructure where the density is larger. Iterating this argument eventually yields a substructure where the count of configurations is close to the random count, finishing our proof.
For many multidimensional configurations, we contend that the random count \delta^{3} is
not a useful comparison to make. One reason for this is that there are very unstructured
sets that do not have the random number of configurations: taking an example from
[Gre05a, §5], consider a product of random sets B_{1}\times B_{2} where each
B_{i}\subset[N] has density \sqrt{\delta}. In the corners problem (1.4),
one is forced to deal with these very loosely structured objects - they only possess the
structure of a Cartesian product. However, the inverse theorem for our configuration
(Theorem 1.4) says that the sets we need to deal with have more structure:
they take the form B\times P where P\subset[N] is a dense arithmetic
progression (i.e., of length proportional to N and with small common difference) and B\subset[N] is arbitrary. After moving to a grid with slightly larger step size, this purported “bad” set can be thought of as taking the form B^{\prime}\times[N^{\prime}], where B^{\prime} has no exploitable structure.
With the above discussion in mind, and following [HLY21, Kuc24], we contend that it is more sensible to compare (2.1) with the following count, where we have essentially replaced the third indicator function 1_{A}(x,y+d^{2}) with its average \mathbb{E}_{y^{\prime}}1_{A}(x,y^{\prime}) on vertical fibres:
(2.2)
\mathbb{E}_{x,y,d}1_{A}(x,y)1_{A}(x+d,y)\mathbb{E}_{d^{\prime}}1_{A}(x,y+d^{\prime}+d^{2})\\
\approx\mathbb{E}_{x,y,d,d^{\prime}}1_{A}(x,y)1_{A}(x+d,y)1_{A}(x,y+d^{\prime})\\
\approx\mathbb{E}_{x,y,x^{\prime},y^{\prime}}1_{A}(x,y)1_{A}(x^{\prime},y)1_{A}(x,y^{\prime}).
A (non-obvious55
5
See https://mathoverflow.net/questions/189222.) application of Hölder’s inequality gives that
\mathbb{E}_{x,y,x^{\prime},y^{\prime}}1_{A}(x,y)1_{A}(x^{\prime},y)1_{A}(x,y^{\prime})\geqslant\mathopen{}\left(\mathbb{E}_{x,y}1_{A}(x,y)\mathclose{}\right)^{3}.
Hence, we have a profusion of configurations, and, in particular, the existence of a popular difference, if (2.1) is \varepsilon-close to (2.2).
If (2.1) is not \varepsilon-close to (2.2), then, on setting
(2.3)
f_{2}(x,y):=1_{A}(x,y)-\mathbb{E}_{d^{\prime}}1_{A}(x,y+d^{\prime}),
we have
\mathopen{}\left|\mathbb{E}_{x,y,d}1_{A}(x,y)1_{A}(x+d,y)f_{2}(x,y+d^{2})\mathclose{}\right|\geqslant\varepsilon.
At this point, we apply our inverse theorem (Theorem 1.4) to deduce the existence of \alpha\approx a/q with q\leqslant\varepsilon^{-O(1)} such that
\mathbb{E}_{x}\mathopen{}\left|\mathbb{E}_{y}f_{2}(x,y)e(\alpha y)\mathclose{}\right|\geqslant\varepsilon^{O(1)}.
The function y\mapsto e(\alpha y) is approximately invariant under small shifts of the form y\mapsto y+q^{2}d^{\prime}, so by a little averaging, there exists N^{\prime}\geqslant\varepsilon^{O(1)}N such that
(2.4)
\mathbb{E}_{x,y}\mathopen{}\left|\mathbb{E}_{|d^{\prime}|<N^{\prime}}f_{2}(x,y+q^{2}d^{\prime})\mathclose{}\right|\geqslant\varepsilon^{O(1)}.
Equation (2.4) is saying that we can convolve f_{2} in the second coordinate with a long arithmetic progression of small common difference, in order to yield a function with large L^{1}-norm. Recall from (2.3) that f_{2} is, essentially, 1_{A} minus the convolution of 1_{A} in the second coordinate with the interval (-N,N). We can, therefore, use (2.4), together with approximate orthogonality properties of convolution, in order to obtain an energy increment:
\mathbb{E}_{x,y}\mathopen{}\left|\mathbb{E}_{|d^{\prime}|<N^{\prime}}1_{A}(x,y+q^{2}d^{\prime})\mathclose{}\right|^{2}\geqslant\mathbb{E}_{x,y}\mathopen{}\left|\mathbb{E}_{|d|<N}1_{A}(x,y+d)\mathclose{}\right|^{2}+\varepsilon^{O(1)}.
We now repeat the above argument, this time focusing on the restricted counting operator
\mathbb{E}_{x,y}\mathbb{E}_{|d|<N^{\prime}}1_{A}(x,y)1_{A}(x+qd,y)1_{A}(x,y+q^{2}d^{2}),
which counts configurations where the difference parameter is divisible by q and ranges over a shorter interval. We compare this restricted counting operator with the restricted analogue of (2.2), namely
\mathbb{E}_{x,y}\mathbb{E}_{|d|,|d^{\prime}|<N^{\prime}}1_{A}(x,y)1_{A}(x+qd,y)1_{A}(x,y+q^{2}d^{\prime}).
Again, this comparison either yields a profusion of configurations in our set A, or alternatively we have an energy increment of the form
\mathbb{E}_{x,y}\Bigl|\mathbb{E}_{|\tilde{d}|<\tilde{N}}1_{A}(x,y+q^{2}\tilde{q}^{2}\tilde{d})\Bigr|^{2}\geqslant\mathbb{E}_{x,y}\Bigl|\mathbb{E}_{|d^{\prime}|<N^{\prime}}1_{A}(x,y+q^{2}d^{\prime})\Bigr|^{2}+\varepsilon^{O(1)},
for some \tilde{q}\ll\varepsilon^{-O(1)} and some \tilde{N}\gg\varepsilon^{O(1)}N^{\prime}.
Iterating the energy increment n times, we obtain a convolution whose energy is at least n\varepsilon^{O(1)}. Since the energy is bounded above by 1, the energy increment must terminate after at most n\leqslant\varepsilon^{-O(1)} steps. Setting q_{1}:=q, q_{2}:=q\tilde{q} and so on, the iteration yields some common difference q_{n} of size
q_{n}\leqslant\underbrace{\varepsilon^{-O(1)}\dotsm\varepsilon^{-O(1)}}_{\varepsilon^{-O(1)}\text{ times}}=\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right)
and an interval length N_{n} satisfying
N_{n}\geqslant\underbrace{\varepsilon^{O(1)}\dotsm\varepsilon^{O(1)}}_{\varepsilon^{-O(1)}\text{ times}}N=N/\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right),
such that we have the comparison
|\mathbb{E}_{x,y}\mathbb{E}_{|d|<N_{n}}1_{A}(x,y)1_{A}(x+q_{n}d,y)1_{A}(x,y+q_{n}^{2}d^{2})\\
-\mathbb{E}_{x,y}\mathbb{E}_{|d|,|d^{\prime}|<N_{n}}1_{A}(x,y)1_{A}(x+q_{n}d,y)1_{A}(x,y+q_{n}^{2}d^{\prime})|\leqslant\varepsilon.
This delivers a popular difference, since an argument using Hölder’s inequality again gives something of the form
\mathbb{E}_{x,y}\mathbb{E}_{|d|,|d^{\prime}|<N_{n}}1_{A}(x,y)1_{A}(x+q_{n}d,y)1_{A}(x,y+q_{n}^{2}d^{\prime})\gtrapprox\delta^{3}.
2.1. Paper organisation
Proving our inverse theorem (Theorem 1.4) occupies
§§3-5. The first part of this argument (§3)
shows that our configuration is controlled by a Gowers U^{5}-norm in the vertical
direction. This uses the PET induction scheme of Bergelson-Leibman
[BL96] together with the “quantitative concatenation”
machinery developed in [PP19]. In §4, we
use the degree lowering technique as developed in [PP19] to reduce the U^{5}-norm to a U^{1}-norm (after passing to a long progression with small common difference). In §5, we combine the results of the previous sections in order to derive our inverse theorem. Our energy increment argument is carried out in §6 and we deduce the existence of a popular common difference in §7. Notation that is used repeatedly is collected in Appendix A.
3. PET induction and U^{5}-control in the vertical direction
We begin by showing that our counting operator is controlled by a Gowers U^{5}-norm in the vertical direction. In order to establish the existence of a popular common difference (Theorem 1.2), it is convenient to work with a counting operator that incorporates a nicer weight than the sharp cut-off d\in[-N,N] used in the inverse theorem stated in our introduction (Theorem 1.4).
Theorem 3.1 (U^{5}-control in the vertical direction).
Let f_{0},f_{1},g:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions and let \mu_{N} denote the probability measure66

\Lambda_{N}(f_{0},f_{1},g):=\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}f_{0}(x,y)\sum_{d}\mu_{N}(d)f_{1}(x+d,y)g(x,y+d^{2}).

\mathbb{E}_{x\in[N]}\mathopen{}\left\|g_{x}1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}}\gg\delta^{O(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}},

Proof.
Rather than summing x and y over intervals, it is convenient to be able to sum over \mathbb{Z}, as this allows us to change variables in a clean manner, without having to keep track of how this affects the range of summation. We may therefore assume that
\mathrm{supp}(f_{0})\subset[N]\times[N^{2}],\quad\mathrm{supp}(f_{1})\subset[-N,2N]\times[N^{2}],\quad\mathrm{supp}(g)\subset[N]\times[2N^{2}].
Notice that this affects neither the hypothesis nor the conclusion of the theorem.
Following the procedure of [PP19, Lemma 3.3], we repeatedly
apply the Cauchy–Schwarz inequality and a change of variables. It is convenient to renormalise by writing \tilde{\mu}_{N}:=N\mu_{N}, to give a 1-bounded function with support contained in [-N,N].
Averaging the d parameter by shifts d\mapsto d+a with a\in[N], and taking into account the support of \tilde{\mu}_{N}, we have that
\Lambda_{N}(f_{0},f_{1},g)=\frac{1}{N^{4}}\sum_{x,y}f_{0}(x,y)\sum_{|d|\leqslant N}\mathbb{E}_{a\in[N]}\tilde{\mu}_{N}(d+a)f_{1}(x+d+a,y)g(x,y+(d+a)^{2}).
We apply the Cauchy–Schwarz inequality to double the a variable in the above sum. After a further change of variables, recalling that \Delta_{(a,0)}f_{1}(x,y)=f_{1}(x,y)\overline{f_{1}(x+a,y)} as in (A.4) and \mu_{N}(a):=N^{-2}\sum_{a_{1}-a_{2}=a}1_{[N]}(a_{1})1_{[N]}(a_{2}) as in (A.7), this gives that
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|\leqslant\mathopen{}\left(\frac{1}{N^{4}}\sum_{x,y}|f_{0}(x,y)|^{2}\sum_{|d|\leqslant N}1\mathclose{}\right)^{1/2}\\
\mathopen{}\left(\frac{1}{N^{4}}\sum_{x,y,d,a}\mu_{N}(a)\Delta_{a}\tilde{\mu}_{N}(d)\Delta_{(a,0)}f_{1}(x,y)g(x-d,y+d^{2})\overline{g(x-d,y+(d+a)^{2})}\mathclose{}\right)^{1/2}.
We now repeat the above process, averaging d by shifts d\mapsto d+b with b\in[N], then applying Cauchy–Schwarz to double the b variable. After further change of variables, this gives
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{4}\ll\frac{1}{N^{4}}\sum_{a,b,x,y,d}\mu_{N}(a)\mu_{N}(b)\Delta_{a,b}\tilde{\mu}_{N}(d)g(x,y)\overline{g\bigl(x,y+2ad+a^{2}\bigr)}\\
\overline{g\bigl(x-b,y+2bd+b^{2}\bigr)}g\bigl(x-b,y+2(a+b)d+(a+b)^{2}\bigr).
We continue to iterate this procedure, this time averaging d by shifts d\mapsto d+h_{1} with h_{1}\in[H], where 1\leqslant H\leqslant N. Doing so gives
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{8}\ll\frac{1}{N^{4}}\sum_{a,b,h_{1},x,y,d}\mu_{N}(a,b)\mu_{H}(h_{1})\Delta_{a,b,h_{1}}\tilde{\mu}_{N}(d)\overline{\Delta_{(0,2ah_{1})}g\bigl(x,y+a^{2}\bigr)}\\
\overline{\Delta_{(0,2bh_{1})}g\bigl(x-b,y+2(b-a)d+b^{2}\bigr)}\Delta_{(0,2(a+b)h_{1})}g\bigl(x-b,y+2bd+(a+b)^{2}\bigr),
using the notation in (A.8). Another iteration yields
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{16}\ll\frac{1}{N^{4}}\sum_{a,b,h_{1},h_{2},x,y,d}\mu_{N}(a,b)\mu_{H}(h_{1},h_{2})\Delta_{a,b,h_{1},h_{2}}\tilde{\mu}_{N}(d)\\
\overline{\Delta_{2bh_{1},2(b-a)h_{2}}g_{x}\bigl(y+b^{2}\bigr)}\Delta_{2(a+b)h_{1},2bh_{2}}g_{x}\bigl(y+2ad+(a+b)^{2}\bigr).
Introducing an additional average over h_{3}\in[N] and changing variables, we have
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{16}\ll\frac{1}{N^{4}}\sum_{a,b,\underline{h},x,y,d}\mu_{N}(a,b)\mu_{H}(\underline{h})\mathbb{E}_{h_{3}\in[H]}\Delta_{a,b,\underline{h}}\tilde{\mu}_{N}(d+h_{3})\\
\overline{\Delta_{2bh_{1},2(b-a)h_{2}}g_{x}\bigl(y-2ad+b^{2}\bigr)}\Delta_{2(a+b)h_{1},2bh_{2}}g_{x}\bigl(y+2ah_{3}+(a+b)^{2}\bigr)
We next observe that, for 1\leqslant h_{3}\leqslant H\leqslant N, we have
\Delta_{a,b,\underline{h}}\tilde{\mu}_{N}(d+h_{3})=\Delta_{a,b,\underline{h}}\tilde{\mu}_{N}(d)+O\mathopen{}\left(1_{[-2N,2N]}(d)H/N\mathclose{}\right).
Hence,
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{16}\ll\frac{H}{N}+\frac{1}{N^{4}}\biggl|\sum_{a,b,\underline{h},x,y,d}\mu_{N}(a,b)\mu_{H}(\underline{h})\sum_{d}\Delta_{a,b,\underline{h}}\tilde{\mu}_{N}(d)\\
\overline{\Delta_{2bh_{1},2(b-a)h_{2}}g_{x}\bigl(y-2ad+b^{2}\bigr)}\mathbb{E}_{h_{3}\in[H]}\Delta_{2(a+b)h_{1},2bh_{2}}g_{x}\bigl(y+2ah_{3}+(a+b)^{2}\bigr)\biggr|.
So, a final application of the Cauchy–Schwarz inequality gives
\mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|^{32}\ll\frac{H^{2}}{N^{2}}+\mathopen{}\left|\frac{1}{N^{3}}\sum_{a,b,\underline{h},x,y}\mu_{N}(a,b)\mu_{H}(\underline{h})\Delta_{2(a+b)h_{1},2bh_{2},2ah_{3}}g_{x}\bigl(y\bigr)\mathclose{}\right|.
It follows that if |\Lambda_{N}(f_{0},f_{1},g)|\geqslant\delta, then either H\gg\delta^{16}N, or there exists a set S\subset[N] of size |S|\gg\delta^{32}N such that, for each x\in S, we have
\sum_{a,b\in(-2N,2N)}\mathopen{}\left|\sum_{h}\mu_{H}(h)\sum_{y}\Delta_{(a+b)h_{1},\,bh_{2},\,ah_{3}}g_{x}(y)\mathclose{}\right|\gg\delta^{32}N^{4}.
For each such x\in S, the above gives the same conclusion as the first displayed equation in the proof of [PP19, Theorem 5.6]. We note that, in the notation of [PP19, Theorem 5.6], we are replacing N with 2N^{2}, and taking M:=N, q:=1 and f:=g_{x} (which is a 1-bounded function with support contained in [2N^{2}]). Applying the proof of [PP19, Theorem 5.6], for each x\in S we deduce that either N\ll 1 or
\mathopen{}\left\|g_{x}\mathclose{}\right\|_{U^{5}}^{32}\gg\delta^{O(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}}^{32}.
The conclusion of our theorem being trivial in the case that N\ll 1, the result follows on summing over x\in S.
∎
As is exploited repeatedly in [PP19, PP22, Pel20], it is often more convenient to replace arbitrary bounded functions with dual functions, as these functions possess more structure. The next result shows that this is possible in Theorem 3.1. We eventually use this in §5.
Corollary 3.2 (Vertical U^{5}-control of the dual).
Let f_{0},f_{1},g:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions and let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Write
\Lambda_{N}(f_{0},f_{1},g):=\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\sum_{d}\mu_{N}(d)f_{0}(x,y)f_{1}(x+d,y)g(x,y+d^{2}).
If \mathopen{}\left|\Lambda_{N}(f_{0},f_{1},g)\mathclose{}\right|\geqslant\delta then, on defining the dual
(3.1)
F_{x}(y)=F(x,y):=\sum_{d}\mu_{N}(d)f_{0}(x,y-d^{2})f_{1}(x+d,y-d^{2}),
we have
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}}\gg\delta^{O(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}},
where the U^{5}-norm is defined via (A.5).
Proof.
We may assume that
\mathrm{supp}(f_{0})\subset[N]\times[N^{2}],\quad\mathrm{supp}(f_{1})\subset[-2N,2N]\times[N^{2}],\quad\mathrm{supp}(g)\subset[N]\times[2N^{2}],
so that \mathrm{supp}(F)\subset[N]\times[2N^{2}]. With these assumptions on the support, we may remove the restriction that (x,y)\in[N]\times[N^{2}] in our counting operator, instead summing over \mathbb{Z}^{2}. Thus
\delta\leqslant|\Lambda_{N}(f_{0},f_{1},g)|=\frac{1}{N^{3}}\mathopen{}\left|\sum_{x,y}F(x,y)g(x,y)\mathclose{}\right|.
The Cauchy–Schwarz inequality then gives
\delta^{2}\ll\frac{1}{N^{3}}\sum_{x,y}\overline{F(x,y)}F(x,y)=\Lambda_{N}\mathopen{}\left(\overline{f}_{0},\overline{f}_{1},F\mathclose{}\right).
By Theorem 3.1, we deduce that
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}}\gg\delta^{O(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}}.
∎
4. Degree lowering
The key result of this section is Lemma 4.5, which shows that we can replace the U^{5}-norm in Corollary 3.2 with the U^{1}-norm, after passing to a long subprogression of small common difference. Before proving this, we begin with a number of technical lemmas that underlie the argument.
Lemma 4.1 (Weyl bound).
Let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
For any \alpha,\beta\in\mathbb{T} we have the implication
(4.1)
\mathopen{}\left|\sum_{d}\mu_{N}(d)e(\alpha d^{2}+\beta d)\mathclose{}\right|\geqslant\delta\\
\implies\mathopen{}\left(\exists q\ll\delta^{-O(1)}\mathclose{}\right)\mathopen{}\left[\mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2}\text{ and }\mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N\mathclose{}\right].
Furthermore, for any integers a,b\in\mathbb{Z} we have
(4.2)
\mathopen{}\left|\sum_{d}\mu_{N}(d+a)\mu_{N}(d+b)e(\alpha d^{2}+\beta d)\mathclose{}\right|\geqslant\delta/N\implies\mathopen{}\left(\exists q\ll\delta^{-O(1)}\mathclose{}\right)\mathopen{}\left[\mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2}\mathclose{}\right].
Proof.
Let us prove (4.2), the remaining assertions being similar and simpler.
Expanding the definition of the Fejér kernel (A.7), we have
\sum_{d}\mu_{N}(d+a)\mu_{N}(d+b)e(\alpha d^{2}+\beta d)\\
=N^{-4}\sum_{d_{1},d_{2},d_{3}}1_{[N]}(d_{1})1_{[N]}(d_{2})1_{[N]}(d_{3})1_{[N]}(a-b-d_{1}+d_{2}+d_{3})\\
e\mathopen{}\left(\alpha\mathopen{}\left(d_{1}-d_{2}-a\mathclose{}\right)^{2}+\beta\mathopen{}\left(d_{1}-d_{2}-a\mathclose{}\right)\mathclose{}\right)\\
\leqslant N^{-2}\max_{c_{1},c_{2}}\mathopen{}\left|\sum_{d_{1}}1_{[N]}(d_{1})1_{[N]}(c_{1}-d_{1})e\mathopen{}\left(\alpha d_{1}^{2}+(\beta-c_{2}\alpha)d_{1}\mathclose{}\right)\mathclose{}\right|.
Since the final summation in d_{1} is over a subinterval of [N], the claimed conclusion follows from Weyl’s inequality, as formulated in [Tao12, Lemma 1.1.16].
∎
Lemma 4.2 (Shifted quadratic correlations are major arc).
Let f:\mathbb{Z}\to\mathbb{C} be a 1-bounded function and let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Suppose that for some \alpha\in\mathbb{T} we have
(4.3)
\mathbb{E}_{x\in[N]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f(x+d)e\mathopen{}\left(\alpha d^{2}\mathclose{}\right)\mathclose{}\right|\geqslant\delta.
Then there exists q\ll\delta^{-O(1)} such that \mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2}. Furthermore there exists \beta\in\mathbb{T} such that \mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N and
\mathopen{}\left|\sum_{x\in[-N,2N]}f(x)e(\beta x)\mathclose{}\right|\gg\delta^{2}N.
Similarly, if for some \beta\in\mathbb{T} we have
(4.4)
\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f(y+d^{2})e\mathopen{}\left(\beta d\mathclose{}\right)\mathclose{}\right|\geqslant\delta,
then there exists q\ll\delta^{-O(1)} such that
\mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N and there exists \alpha\in\mathbb{T} with
\mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} such that
\mathopen{}\left|\sum_{y\in[2N^{2}]}f(y)e(\alpha y)\mathclose{}\right|\gg\delta^{O(1)}N^{2}.
Proof.
Write h(d):=\mu_{N}(d)e(\alpha d^{2}). Our assumption (4.3) implies that
there exists a phase function g:\mathbb{Z}\to\mathopen{}\left\{z\in\mathbb{C}:|z|=1\mathclose{}\right\} such that
\sum_{x,d}g(x)1_{[N]}(x)f(x+d)1_{[-N,2N]}(x+d)h(d)\geqslant\delta N.
By orthogonality and Hölder’s inequality, we have
\delta N\leqslant\int_{\mathbb{T}}\widehat{g1}_{[N]}(\beta)\widehat{f1}_{[-N,2N]}(-\beta)\hat{h}(\beta)\mathrm{d}\beta\\
\leqslant\big\|\widehat{g1}_{[N]}\big\|_{2}\big\|\widehat{f1}_{[-N,2N]}\big\|_{2}^{1/2}\big\|\hat{h}\big\|_{2}^{1/2}\big\|\widehat{f1}_{[-N,2N]}\hat{h}\big\|_{\infty}^{1/2}\\
\leqslant\mathopen{}\left\|1_{[N]}\mathclose{}\right\|_{2}\mathopen{}\left\|1_{[-N,2N]}\mathclose{}\right\|_{2}^{1/2}\mathopen{}\left\|\mu_{N}\mathclose{}\right\|_{2}^{1/2}\big\|\widehat{f1}_{[-N,2N]}\hat{h}\big\|_{\infty}^{1/2}.
Hence there exists \beta\in\mathbb{T} such that
\biggl|\sum_{d}\mu_{N}(d)e(\alpha d^{2}+\beta d)\biggr|\gg\delta^{2}\quad\text{and}\quad\mathopen{}\left|\sum_{x\in[-N,2N]}f(x)e(\beta x)\mathclose{}\right|\gg\delta^{2}N.
The result now follows from the Weyl bound (Lemma 4.1).
Next we turn to (4.4). This implies that there exists a phase function g:\mathbb{Z}\to\mathopen{}\left\{z\in\mathbb{C}:|z|=1\mathclose{}\right\} such that
\sum_{y,d}g(y)1_{[N^{2}]}(y)f(y+d^{2})1_{[2N^{2}]}(y+d^{2})\mu_{N}(d)e(\beta d)\geqslant\delta N^{2}.
Write S_{N}(\alpha,\beta):=\sum_{d}\mu_{N}(d)e(\alpha d^{2}+\beta d). By orthogonality and Hölder’s inequality, we have
\delta N^{2}\leqslant\int_{\mathbb{T}}\widehat{g1}_{[N^{2}]}(\alpha)\widehat{f1}_{[2N^{2}]}(-\alpha)S_{N}(\alpha,\beta)\mathrm{d}\alpha\\
\leqslant\big\|\widehat{g1}_{[N^{2}]}\big\|_{2}\big\|\widehat{f1}_{[2N^{2}]}\big\|_{2}^{5/7}\mathopen{}\left\|S(\cdot,\beta)\mathclose{}\right\|_{6}^{6/7}\big\|\bigl|\widehat{f1}_{[2N^{2}]}\bigr|^{2/7}\mathopen{}\left|S(\cdot,\beta)\mathclose{}\right|^{1/7}\big\|_{\infty}.
Employing a standard estimate for the sixth moment of a quadratic exponential sum (see, for instance, [PP22, Lemma 6.4]), there exists \alpha\in\mathbb{T} such that
\biggl|\sum_{d}\mu_{N}(d)e(\alpha d^{2}+\beta d)\biggr|\gg\delta^{7}\quad\text{and}\quad\mathopen{}\left|\sum_{x\in[2N^{2}]}f(x)e(\alpha x)\mathclose{}\right|\gg\delta^{7/2}N^{2}.
The result now follows from the Weyl bound (Lemma 4.1).
∎
The following simple observation is used repeatedly in the remainder of the paper, and can be regarded as the key “reason” why Theorem 1.3 has exponential bounds, rather than the tower-type bounds encountered in the popular version of the linear Roth theorem [FPZ22]. It essentially allows us to show that we can pass from many “major arc” correlations to a single correlation: the major arcs line up. The reason underlying this is that the major arcs form a tiny fraction of all possible frequencies.
Lemma 4.3 (Pigeon-holing major arcs).
Let f_{1},\dots,f_{M}:[-N,N]\to\mathbb{C} be 1-bounded functions. For a fixed positive integer k, let \alpha,\alpha_{1},\dots,\alpha_{M}\in\mathbb{T} be frequencies for which there are positive integers q_{1},\dots,q_{M}\leqslant Q such that \mathopen{}\left\|q_{m}(\alpha_{m}-\alpha)\mathclose{}\right\|_{\mathbb{T}}\leqslant Q/N^{k} for each m. Suppose that
\mathbb{E}_{m\in[M]}\mathopen{}\left|\mathbb{E}_{|x|\leqslant N}f_{m}(x)e(\alpha_{m}x^{k})\mathclose{}\right|\geqslant 1/Q.
Then there exists m_{0}\in[M] such that
\mathbb{E}_{m\in[M]}\mathopen{}\left|\mathbb{E}_{|x|\leqslant N}f_{m}(x)e(\alpha_{m_{0}}x^{k})\mathclose{}\right|\gg 1/Q^{O(1)}.
Moreover, if \alpha_{1},\dots,\alpha_{M} are \frac{1}{QN^{k}}-separated77
7
By which we mean that, for each i and j, either \alpha_{i}=\alpha_{j} or \mathopen{}\left\|\alpha_{i}-\alpha_{j}\mathclose{}\right\|\geqslant\frac{1}{QN^{k}}., then we can ensure that the m_{0}\in[M] found above satisfies
\#\mathopen{}\left\{m\in[M]:\alpha_{m}=\alpha_{m_{0}}\mathclose{}\right\}\gg MQ^{-O(1)}.
Proof.
By the popularity principle, there exists a set \mathcal{M}\subset[M] with |\mathcal{M}|\geqslant\frac{M}{2Q} such that for each m\in\mathcal{M} we have
(4.5)
\mathopen{}\left|\mathbb{E}_{|x|\leqslant N}f_{m}(x)e(\alpha_{m}x^{k})\mathclose{}\right|\geqslant\tfrac{1}{2Q}.
Set T:=100QN^{k}. If \alpha_{1},\dots,\alpha_{M} are 1/(QN^{k})-separated, then set \tilde{\alpha}_{m}:=\alpha_{m}; otherwise, we round each \alpha_{m} to the nearest fraction of the form t/T. In either case, we obtain a 1/T-separated set \tilde{\alpha}_{1},\dots,\tilde{\alpha}_{M} contained in the shifted union
\alpha+\bigcup_{1\leqslant a\leqslant q\leqslant Q}\mathopen{}\left[\tfrac{a}{q}-\tfrac{2Q}{qN^{k}},\tfrac{a}{q}+\tfrac{2Q}{qN^{k}}\mathclose{}\right].
Write D for the number of distinct \tilde{\alpha}_{m} lying in the above set. Since the \tilde{\alpha}_{m} are 1/T-separated, a volume packing argument gives
D\leqslant\sum_{q\leqslant Q}q(1+\tfrac{4QT}{qN^{k}})\ll Q^{2}\mathopen{}\left(1+\tfrac{T}{N^{k}}\mathclose{}\right)\ll Q^{3}.
Hence, by the pigeon-hole principle, there exists \tilde{\alpha}_{m_{0}} such that
\#\mathopen{}\left\{m\in\mathcal{M}:\tilde{\alpha}_{m}=\tilde{\alpha}_{m_{0}}\mathclose{}\right\}\gg|\mathcal{M}|Q^{-3}\gg MQ^{-4}.
Our choice of T ensures that, for each m with \tilde{\alpha}_{m}=\tilde{\alpha}_{m_{0}}, the frequencies \alpha_{m} and \alpha_{m_{0}} are sufficiently close to ensure that
(4.6)
\mathopen{}\left|\mathbb{E}_{|x|\leqslant N}f_{m}(x)e(\alpha_{m_{0}}x^{k})\mathclose{}\right|\gg 1/Q.
Summing over m\in[M] with \tilde{\alpha}_{m}=\tilde{\alpha}_{m_{0}}, we deduce that
\mathbb{E}_{m\in[M]}\mathopen{}\left|\mathbb{E}_{|x|\leqslant N}f_{m}(x)e(\alpha_{m_{0}}x^{k})\mathclose{}\right|\gg 1/Q^{5}.
∎
Our penultimate technical lemma before proving Lemma 4.5 is essentially the main argument underlying Lemma 4.5, but carried out in a notationally simpler context.
Lemma 4.4 (Shifted quadratic correlations conspire).
Let f_{1},\dots,f_{M}:\mathbb{Z}\to\mathbb{C} be 1-bounded functions and let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Let T be a positive integer satisfying T\leqslant\delta^{-1}N^{2}. Suppose that there are functions \phi_{1},\dots,\phi_{M}:\mathbb{Z}\to\mathopen{}\left\{t/T:t\in[T]\mathclose{}\right\} and a set \mathcal{N}\subset[M]\times[N] of size at least \delta MN such that for each (m,x)\in\mathcal{N} we have
(4.7)
\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{m}(x+d)e\mathopen{}\left(\phi_{m}(x)d^{2}\mathclose{}\right)\mathclose{}\right|\geqslant\delta.
Then there exists q\ll\delta^{-O(1)} and \phi\in\mathbb{T} with \mathopen{}\left\|q\phi\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} such that
\#\mathopen{}\left\{(m,x)\in\mathcal{N}:\phi_{m}(x)=\phi\mathclose{}\right\}\gg\delta^{O(1)}MN.
Proof.
We first show that, for fixed m, many of the \phi_{m}(x) lie in the same shift of the major arcs.
By the popularity principle, there exists a set \mathcal{M}\subset[M] with |\mathcal{M}|\gg\delta M such that for each m\in\mathcal{M} the fibre \mathcal{N}_{m}:=\mathopen{}\left\{x\in[N]:(m,x)\in\mathcal{N}\mathclose{}\right\} satisfies |\mathcal{N}_{m}|\gg\delta N. Summing over \mathcal{N}_{m}, we deduce that
\mathbb{E}_{x\in\mathcal{N}_{m}}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{m}(x+d)e\mathopen{}\left(\phi_{m}(x)d^{2}\mathclose{}\right)\mathclose{}\right|\geqslant\delta.
Applying the Cauchy–Schwarz inequality to double the d variable and then
re-parametrising gives
\delta^{2}\leqslant\mathbb{E}_{x\in\mathcal{N}_{m}}\sum_{d,\tilde{d}}\mu_{N}(d)\mu_{N}(\tilde{d})f_{m}(x+d)\overline{f_{m}(x+\tilde{d})}e\mathopen{}\left(\phi_{m}(x)\mathopen{}\left[d^{2}-\tilde{d}^{2}\mathclose{}\right]\mathclose{}\right)\\
\ll\frac{1}{\delta N}\sum_{|x|<2N}\sum_{|h|<2N}f_{m}(x)\overline{f_{m}(x+h)}\sum_{d}\Delta_{h}\mu_{N}(d)1_{\mathcal{N}_{m}}(x-d)e\mathopen{}\left(-\phi_{m}(x-d)\mathopen{}\left[2hd+h^{2}\mathclose{}\right]\mathclose{}\right).
We again apply the Cauchy–Schwarz inequality to double the d variable, yielding
\displaystyle\delta^{6}
\displaystyle\ll\sum_{x,h,d,\tilde{d}}\Delta_{h}\mu_{N}(d)\Delta_{h}\mu_{N}(\tilde{d})1_{\mathcal{N}_{m}}\bigl(x-d\bigr)1_{\mathcal{N}_{m}}\bigl(x-\tilde{d}\,\bigr)
\displaystyle\qquad\times e\Bigl(\mathopen{}\left[\phi_{m}(x-d)-\phi_{m}\bigl(x-\tilde{d}\,\bigr)\mathclose{}\right]h^{2}+\phi_{m}(x-d)2hd-\phi_{m}\bigl(x-\tilde{d}\,\bigr)2h\tilde{d}\Bigr)
\displaystyle\leqslant\sum_{x,d,\tilde{d}}\mu_{N}(d)\mu_{N}(\tilde{d})1_{\mathcal{N}_{m}}\bigl(x-d\bigr)1_{\mathcal{N}_{m}}\bigl(x-\tilde{d}\,\bigr)\biggl|\sum_{h}\mu_{N}(d+h)\mu_{N}(\tilde{d}+h)
\displaystyle\qquad\times e\Bigl(\mathopen{}\left[\phi_{m}(x-d)-\phi_{m}\bigl(x-\tilde{d}\,\bigr)\mathclose{}\right]h^{2}+\phi_{m}(x-d)2hd-\phi_{m}\bigl(x-\tilde{d}\,\bigr)2h\tilde{d}\Bigr)\biggr|.
Next, we change variables in the above sum, substituting d=x-n and \tilde{d}=x-\tilde{n}. We also use the pointwise bound \mu_{N}\leqslant 1/N, together with the fact that the only values of x that contribute to the above sum lie in the interval [-2N,2N]. Thus taking a maximum over x gives some x_{0} such that
\displaystyle\delta^{6}N
\displaystyle\ll\sum_{n,\tilde{n}}1_{\mathcal{N}_{m}}(n)1_{\mathcal{N}_{m}}(\tilde{n})\biggl|\sum_{h}\mu_{N}(x_{0}-n+h)\mu_{N}(x_{0}-\tilde{n}+h)
\displaystyle\qquad\times e\Bigl(\mathopen{}\left[\phi_{m}(n)-\phi_{m}(\tilde{n})\mathclose{}\right]h^{2}+\phi_{m}(n)2h(x_{0}-n)-\phi_{m}(\tilde{n})2h(x_{0}-\tilde{n})\Bigr)\biggr|.
Taking a maximum over \tilde{n} and using the popularity principle in n, there exists \mathcal{N}_{m}^{\prime}\subset\mathcal{N}_{m} with |\mathcal{N}_{m}^{\prime}|\gg\delta^{6}N and there exists an integer y_{0} along with a frequency \alpha_{m} such that for each n\in\mathcal{N}_{m}^{\prime} there exists an integer y_{n} and a frequency \beta_{m}(n)\in\mathbb{T} satisfying
\frac{\delta^{6}}{N}\ll\biggl|\sum_{h}\mu_{N}(y_{n}+h)\mu_{N}(y_{0}+h)e\Bigl(\mathopen{}\left[\phi_{m}(n)-\alpha_{m}\mathclose{}\right]h^{2}+\beta_{m}(n)h\Bigr)\biggr|.
By the Weyl bound (Lemma 4.1), for each n\in\mathcal{N}_{m}^{\prime} there exists q_{m,n}\ll\delta^{-O(1)} with
\mathopen{}\left\|q_{m,n}\mathopen{}\left[\phi_{m}(n)-\alpha_{m}\mathclose{}\right]\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2}.
Whilst summing (4.7) over n\in\mathcal{N}_{m}^{\prime} gives
\sum_{n\in[N]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{m}(n+d)e\mathopen{}\left(\phi_{m}(n)d^{2}\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}N.
Applying Lemma 4.3, for each m\in\mathcal{M} there exists n_{m}\in\mathcal{N}^{\prime}_{m} such that on setting \phi_{m}:=\phi_{m}(n_{m}) we have
\#\mathopen{}\left\{n\in\mathcal{N}_{m}:\phi_{m}(n)=\phi_{m}\mathclose{}\right\}\gg\delta^{O(1)}N.
In particular
\mathbb{E}_{x\in[N]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{m}(x+d)e\mathopen{}\left(\phi_{m}d^{2}\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}.
Applying Lemma 4.2, there exists q\ll\delta^{-O(1)} such that \mathopen{}\left\|q\phi_{m}\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2}. Re-applying Lemma 4.3 gives some \phi=\phi_{m_{0}} such that
\#\mathopen{}\left\{m\in\mathcal{M}:\phi_{m}=\phi\mathclose{}\right\}\gg\delta^{O(1)}M
Hence
\#\mathopen{}\left\{(m,x)\in\mathcal{N}:\phi_{m}(x)=\phi\mathclose{}\right\}\geqslant\sum_{m\in\mathcal{M}:\phi_{m}=\phi}\#\mathopen{}\left\{x\in\mathcal{N}_{m}:\phi_{m}(x)=\phi_{m}\mathclose{}\right\}\gg\delta^{O(1)}MN.
∎
We are now in a position to prove our degree lowering lemma.
Lemma 4.5 (Degree lowering).
Let f_{0},f_{1}:\mathbb{Z}\to\mathbb{C} be 1-bounded functions with
\mathrm{supp}(f_{0})\subset[N]\times[N^{2}]\quad\text{and}\quad\mathrm{supp}(f_{1})\subset[-N,2N]\times[N^{2}]
Let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Define the dual function
F_{x}(y)=F(x,y):=\sum_{d}\mu_{N}(d)f_{0}(x,y-d^{2})f_{1}(x+d,y-d^{2}),
a 1-bounded function supported on [N]\times[2N^{2}]. Suppose that for some s\geqslant 2 we have
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}\mathclose{}\right\|_{U^{s}(\mathbb{Z})}^{2^{s}}\geqslant\delta\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{s}(\mathbb{Z})}^{2^{s}},
where the U^{s}-norm is given by (A.5). Then, either N\ll_{s}\delta^{-O_{s}(1)}, or there exists \alpha\in\mathbb{T} and q\ll_{s}\delta^{-O_{s}(1)} such that \mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll_{s}\delta^{-O_{s}(1)}/N^{2} and
(4.8)
\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{1}(x+d,y)e\mathopen{}\left(\alpha d^{2}\mathclose{}\right)\mathclose{}\right|\gg_{s}\delta^{O_{s}(1)}.
Proof.
Let us first assume that s\geqslant 3. In this case, we claim that our assumptions imply that
(4.9)
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}\mathclose{}\right\|_{U^{s-1}(\mathbb{Z})}^{2^{s-1}}\gg_{s}\delta^{O_{s}(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{s-1}(\mathbb{Z})}^{2^{s-1}}.
Given this claim, we intend to iterate in order to arrive at the case in which s=2, so that
(4.10)
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}\mathclose{}\right\|_{U^{2}(\mathbb{Z})}^{4}\gg_{s}\delta^{O_{s}(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{2}(\mathbb{Z})}^{4}.
Returning to the proof of (4.9), since we may assume that N\ll_{s}1 does not hold, we have
\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{s}(\mathbb{Z})}^{2^{s}}\gg_{s}N^{2s+2}.
Expanding the definition of the U^{s}-norm (A.5), and using the fact that F_{x} is supported on [2N^{2}], gives
\mathbb{E}_{|h_{1}|<2N^{2}}\dotsm\mathbb{E}_{|h_{s-2}|<2N^{2}}\mathbb{E}_{x\in[N]}\mathopen{}\left\|\Delta_{h_{1},\dots,h_{s-2}}F_{x}\mathclose{}\right\|_{U^{2}}^{4}\gg_{s}\delta N^{6}.
Applying the U^{2}-inverse theorem [PP19, Lemma A.1], there exists
\mathcal{N}\subset\left((-2N^{2},2N^{2})^{s-2}\cap\mathbb{Z}^{s-2}\right)\times[N]
of size |\mathcal{N}|\gg_{s}\delta N^{2s-3} and a function \phi:\mathbb{Z}^{s-1}\to\mathbb{T} such that for every (\underline{h},x)\in\mathcal{N} we have
(4.11)
\biggl|\sum_{y}\Delta_{\underline{h}}F_{x}(y)e\bigl(\phi(\underline{h};x)y\bigr)\biggr|\gg_{s}\delta N^{2}.
Set T:=\mathopen{}\left\lceil C_{s}\delta^{-1}N^{2}\mathclose{}\right\rceil, with C_{s} an absolute constant taken sufficiently large to ensure that, on rounding \phi(\underline{h};x) to the nearest fraction of the form t/T, the inequality (4.11) remains valid.
Summing over \mathcal{N} and applying the dual-difference interchange inequality [PP19, Lemma 6.3], we deduce that
\sum_{(\underline{h}^{0},x),(\underline{h}^{1},x)\in\mathcal{N}}\biggl|\sum_{y,d}\mu_{N}(d)\Delta_{(0,\underline{h}^{0}-\underline{h}^{1})}f_{0}(x,y-d^{2})\\
\Delta_{(0,\underline{h}^{0}-\underline{h}^{1})}f_{1}(x+d,y-d^{2})e\bigl(\phi(\underline{h}^{0};\underline{h}^{1};x)y\bigr)\biggr|\gg_{s}\delta^{O_{s}(1)}N^{4s-5},
where
\phi(\underline{h}^{0};\underline{h}^{1};x):=\sum_{\omega\in\mathopen{}\left\{0,1\mathclose{}\right\}^{s}}(-1)^{|\omega|}\phi(\underline{h}^{\omega};x)\qquad\text{and}\qquad\underline{h}^{\omega}:=(h_{1}^{\omega_{1}},\dots,h_{s}^{\omega_{s}}).
Changing variables from y to y+d^{2} and taking maxima, there exist y and \underline{h}^{1} such that
\sum_{(\underline{h}^{0},x)\in\mathcal{N}}\mathopen{}\left|\sum_{d}\mu_{N}(d)\Delta_{(0,\underline{h}^{0}-\underline{h}^{1})}f_{1}(x+d,y)e\bigl(\phi(\underline{h}^{0};\underline{h}^{1};x)d^{2}\bigr)\mathclose{}\right|\gg_{s}\delta^{O_{s}(1)}N^{2s-3}.
Thus, there exists \mathcal{N}^{\prime}\subset\mathcal{N} of size \mathcal{N}^{\prime}\gg_{s}\delta^{O_{s}(1)}N^{2s-3} such that for each (\underline{h}^{0},x)\in\mathcal{N}^{\prime} we have
\mathopen{}\left|\sum_{d}\mu_{N}(d)\Delta_{(0,\underline{h}^{0}-\underline{h}^{1})}f_{1}(x+d,y)e\bigl(\phi(\underline{h}^{0};\underline{h}^{1};x)d^{2}\bigr)\mathclose{}\right|\gg_{s}\delta^{O_{s}(1)}.
By Lemma 4.4, there exists \mathcal{N}^{\prime\prime}\subset\mathcal{N}^{\prime} of size \gg_{s}\delta^{O_{s}(1)}N^{2s-3} and \phi\in\mathbb{T} such that for any (\underline{h}^{0},x)\in\mathcal{N}^{\prime\prime} we have \phi(\underline{h}^{0};\underline{h}^{1};x)=\phi. In particular, when restricted to the set \mathcal{N}^{\prime\prime}, the function \phi satisfies
\phi(\underline{h}^{0};x)=\phi-\sum_{\omega\in\mathopen{}\left\{0,1\mathclose{}\right\}^{s-2}\setminus\mathopen{}\left\{0\mathclose{}\right\}}(-1)^{|\omega|}\phi(\underline{h}^{\omega};x).
For fixed x, the right-hand side of this identity is low rank in \underline{h}^{0} according to the terminology preceding [PP19, Lemma 6.4].
Summing over \underline{h} such that (\underline{h},x)\in\mathcal{N}^{\prime\prime} in (4.11), we deduce the existence of low-rank functions \psi_{x}:\mathbb{Z}^{s-2}\to\mathbb{T} such that
(4.12)
\mathbb{E}_{x\in[N]}\mathbb{E}_{|h_{1}|<N^{2}}\dotsm\mathbb{E}_{|h_{s-2}|<N^{2}}\mathopen{}\left|\sum_{y}\Delta_{\underline{h}}F_{x}(y)e\bigl(\psi_{x}(\underline{h})y\bigr)\mathclose{}\right|\gg_{s}\delta^{O_{s}(1)}N^{2}.
Employing the inequality stated in [PP19, Lemma 6.4] then gives
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}\mathclose{}\right\|_{U^{s-1}}^{2^{s-1}}\gg_{s}\delta^{O_{s}(1)}N^{2s}.
This proves the claim (4.9).
By iterating (4.9), our initial assumption of large U^{s}-norm yields a large U^{2}-norm, as in (4.10). Moreover, we note that when running the argument with s=3, the inequality (4.12) becomes
\mathbb{E}_{x\in[N]}\mathopen{}\left|\mathbb{E}_{|y|\leqslant 2N^{2}}F_{x}(y)e\bigl(\psi_{x}y\bigr)\mathclose{}\right|\gg_{s}\delta^{O_{s}(1)},
where for each x, our application of Lemma 4.4 gives some q_{x}\ll_{s}\delta^{-O_{s}(1)} with \mathopen{}\left\|q_{x}\psi_{x}\mathclose{}\right\|_{\mathbb{T}}\ll_{s}\delta^{-O_{s}(1)}/N^{2}. Once more applying Lemma 4.3, we may assume that \psi_{x}=\psi is constant in x, so that
\mathbb{E}_{x\in[N]}\biggl|\sum_{y}F_{x}(y)e\bigl(\psi y\bigr)\biggr|\gg_{s}\delta^{O_{s}(1)}N^{2}.
Expanding the dual function F_{x}, changing variables in y and employing the triangle inequality to bring the sum over y outside the absolute value, we derive (4.8).
∎
5. Inverse theorems for our counting operator
Degree lowering (Lemma 4.5) can be combined with vertical U^{5}-control of
the dual function (Corollary 3.2), and a little Fourier analysis, in order to prove an inverse theorem for the function weighting the (x+d,y) term in our counting operator.
Theorem 5.1 (Counting operator inverse theorem, I).
Let f_{0},f_{1},f_{2}:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions and let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Write
\Lambda_{N}(f_{0},f_{1},f_{2}):=\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\sum_{d}\mu_{N}(d)f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2}).
If \mathopen{}\left|\Lambda_{N}(f_{0},f_{1},f_{2})\mathclose{}\right|\geqslant\delta, then either N\ll\delta^{-O(1)} or there exists \beta\in\mathbb{T} and q\ll\delta^{-O(1)} such that \mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N and
(5.1)
\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\mathbb{E}_{x\in[-N,2N]}f_{1}(x,y)e\mathopen{}\left(\beta x\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}.
Proof.
In order to avoid tracking the range of summation, we assume that
\mathrm{supp}(f_{0})\subset[N]\times[N^{2}]\quad\text{and}\quad\mathrm{supp}(f_{1})\subset[-N,2N]\times[N^{2}]
Notice that this affects neither the hypothesis nor the conclusion of the theorem.
By vertical U^{5}-control of the dual function (Corollary 3.2), our assumptions give that
\mathbb{E}_{x\in[N]}\mathopen{}\left\|F_{x}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}}\gg\delta^{O(1)}\mathopen{}\left\|1_{[2N^{2}]}\mathclose{}\right\|_{U^{5}(\mathbb{Z})}^{2^{5}},
where
F_{x}(y)=F(x,y):=\sum_{d}\mu_{N}(d)f_{0}(x,y-d^{2})f_{1}(x+d,y-d^{2}).
By degree lowering (Lemma 4.5), either N\ll\delta^{-O(1)} or there exists \alpha\in\mathbb{T} and q\ll\delta^{-O(1)} with \mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} such that
\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{1}(x+d,y)e(\alpha d^{2})\mathclose{}\right|\gg\delta^{O(1)}.
By the popularity principle and Lemma 4.2, for each y\in[N^{2}] there exist q_{y}\ll\delta^{-O(1)} and \beta_{y}\in\mathbb{T} with \mathopen{}\left\|q_{y}\beta_{y}\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N such that
\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\mathbb{E}_{x\in[-N,2N]}f_{1}(x,y)e(\beta_{y}x)\mathclose{}\right|\gg\delta^{O(1)}.
Pigeon-holing in the major arcs (Lemma 4.3), there exists \beta\in\mathbb{T} and q\ll\delta^{-O(1)} with \mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N such that
\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\mathbb{E}_{x\in[-N,2N]}f_{1}(x,y)e(\beta x)\mathclose{}\right|\gg\delta^{O(1)}.
The result follows.
∎
We now use the inverse theorem for the function weighting the (x+d,y) term to obtain an inverse theorem for the function weighting the (x,y+d^{2}) term.
Theorem 5.2 (Counting operator inverse theorem, II).
Let f_{0},f_{1},f_{2}:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions and let \mu_{N} denote the probability measure
\mu_{N}:=\tfrac{1}{N^{2}}1_{[N]}*1_{-[N]}=\tfrac{1}{N}\mathopen{}\left(1-\tfrac{|\cdot|}{N}\mathclose{}\right)_{+}.
Write
\Lambda_{N}(f_{0},f_{1},f_{2}):=\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\sum_{d}\mu_{N}(d)f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2}).
If \mathopen{}\left|\Lambda_{N}(f_{0},f_{1},f_{2})\mathclose{}\right|\geqslant\delta, then either N\ll\delta^{-O(1)} or there exists \alpha\in\mathbb{T} and q\ll\delta^{-O(1)} such that \mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} and
\mathbb{E}_{x\in[N]}\mathopen{}\left|\mathbb{E}_{y\in[2N^{2}]}f_{2}(x,y)e\mathopen{}\left(\alpha y\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}.
Proof.
We may assume that
\mathrm{supp}(f_{0})\subset[N]\times[N^{2}],\quad\mathrm{supp}(f_{1})\subset[-N,2N]\times[N^{2}],\quad\mathrm{supp}(f_{2})\subset[N]\times[2N^{2}].
Define the dual function
G(x,y):=\sum_{d}\mu_{N}(d)f_{0}(x-d,y)f_{2}(x-d,y+d^{2}).
Then, by the Cauchy–Schwarz inequality:
\delta\leqslant\mathopen{}\left|\frac{1}{N^{3}}\sum_{x,y}f_{1}(x,y)G(x,y)\mathclose{}\right|\ll\mathopen{}\left(\frac{1}{N^{3}}\sum_{x,y}G(x,y)\overline{G(x,y)}\mathclose{}\right)^{1/2}=\Lambda_{N}\mathopen{}\left(\overline{f}_{0},G,\overline{f}_{2}\mathclose{}\right)^{1/2}.
Hence, by our first inverse theorem (Theorem 5.1), either N\ll\delta^{-O(1)} or there exists \beta\in\mathbb{T} and q\ll\delta^{-O(1)} such that \mathopen{}\left\|q\beta\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N and
\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\mathbb{E}_{x\in[-N,2N]}G(x,y)e\mathopen{}\left(\beta x\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}.
Expanding the dual function, changing variables and employing the triangle inequality, we have
\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\mathopen{}\left|\sum_{d}\mu_{N}(d)f_{2}(x,y+d^{2})e(\beta d)\mathclose{}\right|\gg\delta^{O(1)}.
By the popularity principle and Lemma 4.2, for each x\in[N] there exist q_{x}\ll\delta^{-O(1)} and \alpha_{x}\in\mathbb{T} with \mathopen{}\left\|q_{x}\alpha_{x}\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} such that
\mathbb{E}_{x\in[N]}\mathopen{}\left|\mathbb{E}_{y\in[2N^{2}]}f_{2}(x,y)e(\alpha_{x}y)\mathclose{}\right|\gg\delta^{O(1)}.
Pigeon-holing in the major arcs (Lemma 4.3), there exists \alpha\in\mathbb{T} and q\ll\delta^{-O(1)} with \mathopen{}\left\|q\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/N^{2} such that
\mathbb{E}_{x\in[N]}\mathopen{}\left|\mathbb{E}_{y\in[2N^{2}]}f_{2}(x,y)e(\alpha y)\mathclose{}\right|\gg\delta^{O(1)}.
The result follows.
∎
The previous two inverse theorems concern the global count of configurations. As indicated in §2, our strategy for proving Theorem 1.2 is to focus on counting configurations where the difference parameter is divisible by a small positive integer q and is localised to an interval shorter than N. We therefore require an inverse theorem for this localised counting operator. We also take this opportunity to replace correlation with major arcs by convolution with a Fejér kernel, which facilitates the energy increment argument in Theorem 6.1. Making these adjustments to our inverse theorem is the purpose of the next result.
Theorem 5.3 (Large localised count gives a large convolution).
Let f_{0},f_{1},f_{2}:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions with support contained in [-N_{1},N_{1}]\times[-N_{2},N_{2}] where N_{1}\geqslant N_{2}^{1/2}. Suppose that for some positive integers q,M with qM\leqslant N_{2}^{1/2} we have
\mathopen{}\left|\sum_{x,y,d}\mu_{M}(d)f_{0}(x,y)f_{1}(x+qd,y)f_{2}(x,y+q^{2}d^{2})\mathclose{}\right|\geqslant\delta N_{1}N_{2}.
Then there exists a positive integer \tilde{q} with \tilde{q}\ll\delta^{-O(1)} such that for any positive integer \widetilde{M}, either \widetilde{M}\gg\delta^{O(1)}M or
(5.2)
\sum_{x,y}\mathopen{}\left|\sum_{\tilde{d}}\mu_{\widetilde{M}^{2}}(\tilde{d})f_{2}(x,y+q^{2}\tilde{q}^{2}\tilde{d})\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
Here \mu_{M} and \mu_{\widetilde{M}^{2}} denote the Fejér kernels defined in (A.7).
Proof.
By a change of variables, we may average our operator over additional shifts, to deduce that
\Bigl|\sum_{x,y}\mathbb{E}_{x^{\prime}\in[M]}\mathbb{E}_{y^{\prime}\in[M^{2}]}\sum_{d}\mu_{M}(d)f_{0}(x+qx^{\prime},y+q^{2}y^{\prime})f_{1}(x+q(x^{\prime}+d),y+q^{2}y^{\prime})\\
f_{2}(x+qx^{\prime},y+q^{2}(y^{\prime}+d^{2}))\Bigr|\geqslant\delta N_{1}N_{2}.
Hence, on setting
f_{i}^{x,y,q}(x^{\prime},y^{\prime}):=f_{i}(x+qx^{\prime},y+q^{2}y^{\prime}),
we have that
(5.3)
\Bigl|\sum_{x,y}\Lambda_{M}\mathopen{}\left(f_{0}^{x,y,q},f_{1}^{x,y,q},f_{2}^{x,y,q}\mathclose{}\right)\Bigr|\geqslant\delta N_{1}N_{2}.
We note that, since qM\leqslant N_{2}^{1/2}\leqslant N_{1} and each f_{i} is supported on [-N_{1},N_{1}]\times[-N_{2},N_{2}], the set of pairs (x,y)\in\mathbb{Z}^{2} that contribute to (5.3) is contained in [-2N_{1},2N_{1}]\times[-2N_{2},2N_{2}]. Thus, by the popularity principle, there exists a set \mathcal{P}\subset[-2N_{1},2N_{1}]\times[-2N_{2},2N_{2}] of size \gg\delta N_{1}N_{2} such that
\mathopen{}\left|\Lambda_{M}\mathopen{}\left(f_{0}^{x,y,q},f_{1}^{x,y,q},f_{2}^{x,y,q}\mathclose{}\right)\mathclose{}\right|\gg\delta\quad\text{for all }(x,y)\in\mathcal{P}.
By our second counting operator inverse theorem (Theorem 5.2), either M\ll\delta^{-O(1)} or, for each pair (x,y)\in\mathcal{P}, there exists \alpha_{x,y}\in\mathbb{T} and q_{x,y}\ll\delta^{-O(1)} with \mathopen{}\left\|q_{x,y}\alpha_{x,y}\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/M^{2} and such that
\mathbb{E}_{x^{\prime}\in[M]}\mathopen{}\left|\mathbb{E}_{y^{\prime}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime})e\mathopen{}\left(\alpha_{x,y}y^{\prime}\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}.
Notice that we can ignore the possibility that M\ll\delta^{-O(1)}, since in this case all positive integers \widetilde{M} satisfy \widetilde{M}\gg\delta^{O(1)}M. Pigeon-holing in the major arcs, as in Lemma 4.3, we obtain \alpha\in\mathbb{T} and \tilde{q}\ll\delta^{-O(1)} with \mathopen{}\left\|\tilde{q}\alpha\mathclose{}\right\|_{\mathbb{T}}\ll\delta^{-O(1)}/M^{2} and such that
(5.4)
\sum_{x,y}\mathbb{E}_{x^{\prime}\in[M]}\mathopen{}\left|\mathbb{E}_{y^{\prime}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime})e\mathopen{}\left(\alpha y^{\prime}\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
We note that
\mathopen{}\left|e\mathopen{}\left(\alpha y^{\prime}\mathclose{}\right)-e\mathopen{}\left(\alpha(y^{\prime}+\tilde{q}^{2}\tilde{d})\mathclose{}\right)\mathclose{}\right|\ll\delta^{-O(1)}|\tilde{d}|/M^{2}.
Combining this with the fact that the set of pairs (x,y) that contribute to (5.4) is contained in [-2N_{1},2N_{1}]\times[-2N_{2},2N_{2}], we deduce that for any positive integer \widetilde{M}, we either have \widetilde{M}\gg\delta^{O(1)}M or
(5.5)
\sum_{x,y}\mathbb{E}_{x^{\prime}\in[M]}\mathopen{}\left|\mathbb{E}_{y^{\prime}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime})\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}e\mathopen{}\left(\alpha(y^{\prime}+\tilde{q}^{2}\tilde{d})\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
Instead of averaging the phase in (5.5) over shifts of the form \tilde{q}^{2}\tilde{d}, we would like to change variables and average f_{2}^{x,y,q}(x^{\prime},\cdot) over these shifts. We have the identity
\mathbb{E}_{y^{\prime}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime})\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}e\mathopen{}\left(\alpha(y^{\prime}+\tilde{q}^{2}\tilde{d})\mathclose{}\right)\\
=\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}\mathbb{E}_{y^{\prime}-\tilde{q}^{2}\tilde{d}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime}-\tilde{q}^{2}\tilde{d})e\mathopen{}\left(\alpha y^{\prime}\mathclose{}\right).
Hence, estimating the symmetric difference of the sets of summands gives that
\mathbb{E}_{y^{\prime}\in[2M^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime})\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}e\mathopen{}\left(\alpha(y^{\prime}+\tilde{q}^{2}\tilde{d})\mathclose{}\right)\\
=\mathbb{E}_{y^{\prime}\in[2M^{2}]}\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime}-\tilde{q}^{2}\tilde{d})e\mathopen{}\left(\alpha y^{\prime}\mathclose{}\right)+O\mathopen{}\left(\frac{\tilde{q}^{2}\widetilde{M}^{2}}{M^{2}}\mathclose{}\right).
It follows that either \widetilde{M}\gg\delta^{O(1)}M or we have
\sum_{x,y}\mathbb{E}_{x^{\prime}\in[M]}\mathopen{}\left|\mathbb{E}_{y^{\prime}\in[2M^{2}]}\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime}-\tilde{q}^{2}\tilde{d})e\mathopen{}\left(\alpha y^{\prime}\mathclose{}\right)\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
Applying the triangle inequality gives
\mathbb{E}_{x^{\prime}\in[M]}\mathbb{E}_{y^{\prime}\in[2M^{2}]}\sum_{x,y}\mathopen{}\left|\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}f^{x,y,q}_{2}(x^{\prime},y^{\prime}-\tilde{q}^{2}\tilde{d})\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
Taking a maximum over x^{\prime} and y^{\prime}, then expanding the definition of each f_{2}^{x,y,q} and changing variables, we have
\sum_{x,y}\mathopen{}\left|\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}f_{2}(x,y-q^{2}\tilde{q}^{2}\tilde{d})\mathclose{}\right|\gg\delta^{O(1)}N_{1}N_{2}.
An application of Cauchy–Schwarz to double the \tilde{d} variables then yields
\delta^{O(1)}N_{1}N_{2}\ll\sum_{x,y}\mathbb{E}_{\tilde{d}_{1},\tilde{d}_{2}\in[\widetilde{M}^{2}]}f_{2}(x,y-q^{2}\tilde{q}^{2}\tilde{d}_{1})\overline{f_{2}(x,y-q^{2}\tilde{q}^{2}\tilde{d}_{2})}\\
\leqslant\sum_{x,y}\mathopen{}\left|\mathbb{E}_{\tilde{d}_{1},\tilde{d}_{2}\in[\widetilde{M}^{2}]}f_{2}\mathopen{}\left(x,y+q^{2}\tilde{q}^{2}(\tilde{d}_{1}-\tilde{d}_{2})\mathclose{}\right)\mathclose{}\right|
This gives (5.2), on recalling the definition (A.7) of the Fejér kernel \mu_{H}.
∎
We end this section by deriving the inverse theorem claimed in our introduction (Theorem 1.4), where there is no occurrence of the Fejér kernel \mu_{N} in the counting operator.
Proof of Theorem 1.4.
Set M:=\mathopen{}\left\lceil 2\delta^{-1}N\mathclose{}\right\rceil. Due to the support of the f_{i}, if
f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2})\neq 0
then x\in[N], y\in[N^{2}] and |d|<N. It follows that
\mathopen{}\left|f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2})-f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2})M\mu_{M}(d)\mathclose{}\right|\\
\leqslant\tfrac{\delta}{2}1_{[N]}(x)1_{[N^{2}]}(y).
Thus the hypothesis (1.2) implies that
\mathopen{}\left|\Lambda_{M}(f_{0},f_{1},f_{2})\mathclose{}\right|\gg\delta\tfrac{N^{4}}{M^{4}}\gg\delta^{O(1)}.
Applying Theorem 5.1 and Theorem 5.2, either N\ll\delta^{-O(1)} or there exist \alpha,\beta\in\mathbb{T} and q_{1},q_{2}\ll\delta^{-O(1)} such that \mathopen{}\left\|q_{1}\alpha\mathclose{}\right\|\ll\delta^{-O(1)}/N and \mathopen{}\left\|q_{2}\beta\mathclose{}\right\|\ll\delta^{-O(1)}/N^{2}, as well as (1.3) holds. The theorem follows on taking q:=q_{1}q_{2}.
∎
6. Energy increment
We are now in a position to run an energy increment argument in order to obtain a modified counting operator that is close to our original count: see our outline in §2 for more on this. Green and Tao [GT12] call the argument underlying the following result a local Koopman-von Neuman theorem.
Theorem 6.1 (Energy increment to a subprogression).
Let 0<\varepsilon\leqslant 1/2 and let f_{0},f_{1},f_{2}:\mathbb{Z}^{2}\to\mathbb{C} be 1-bounded functions, each with support contained in [N_{1}]\times[N_{2}] where N_{1}\geqslant N_{2}^{1/2}.
Then either N_{2}\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right), or there exist q\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) and M\geqslant N_{2}^{1/2}/\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) such that
(6.1)
\biggl|\sum_{x,y,d}\mu_{\varepsilon M}(d)f_{0}(x,y)f_{1}(x+qd,y)\Bigl[f_{2}\mathopen{}\left(x,y+q^{2}d^{2}\mathclose{}\right)-\sum_{\tilde{d}}\mu_{M^{2}}(\tilde{d})f_{2}\mathopen{}\left(x,y+q^{2}\mathopen{}\left(\tilde{d}+d^{2}\mathclose{}\right)\mathclose{}\right)\Bigr]\biggr|\\
\leqslant\varepsilon N_{1}N_{2}.
Moreover, we may choose M sufficiently small to ensure that qM\leqslant\varepsilon N_{2}^{1/2}. Here \mu_{\varepsilon M} and \mu_{M^{2}} denote Fejér kernels, as defined in (A.7).
Proof.
We perform an iterative procedure. At stage 0, we take q=q_{0}:=1 and M=M_{0}:=\lfloor\varepsilon N_{2}^{1/2}\rfloor. Suppose that at stage n of our iteration we have a positive integers q=q_{n}\leqslant\varepsilon^{-O(n)} and M=M_{n}\in[\varepsilon^{O(n+1)}N_{2}^{1/2},\varepsilon N_{2}^{1/2}/q] that satisfy the energy lower bound
(6.2)
\sum_{x,y}\biggl|\sum_{\tilde{d}}f_{2}(x,y+q^{2}\tilde{d})\mu_{M^{2}}(\tilde{d})\biggr|^{2}\gg n\varepsilon^{O(1)}N_{1}N_{2}.
Given this, we query whether (6.1) holds or not. If (6.1) holds, then the process terminates. Therefore suppose that (6.1) does not hold.
Write
g_{2}(x,y):=f_{2}\mathopen{}\left(x,y\mathclose{}\right)-\sum_{\tilde{d}}\mu_{M^{2}}(\tilde{d})f_{2}\mathopen{}\left(x,y+q^{2}\tilde{d}\mathclose{}\right),
which is a function with support contained in [-N_{1},N_{1}]\times[-N_{2},N_{2}], since q^{2}M^{2}\leqslant N_{2}. Applying the inverse theorem for our asymmetric counting operator (Theorem 5.3), there exists a positive integer \tilde{q} with \tilde{q}\leqslant\varepsilon^{-O(1)} such that for any positive integer \widetilde{M}, either \widetilde{M}\geqslant\varepsilon^{O(1)}M or
(6.3)
\sum_{x,y}\mathopen{}\left|\sum_{\tilde{d}}\mu_{\widetilde{M}^{2}}(\tilde{d})g_{2}(x,y+q^{2}\tilde{q}^{2}\tilde{d})\mathclose{}\right|\gg\varepsilon^{O(1)}N_{1}N_{2}.
Provided that it is not the case that M\ll\varepsilon^{-O(1)}, we can find a positive integer \widetilde{M}\geqslant\varepsilon^{O(1)}M sufficiently small to guarantee (6.3). If M\ll\varepsilon^{-O(1)} then the process terminates.
On writing f_{2}^{x}(y):=f_{2}(x,y) and \mu_{q,H}(y):=1_{q\cdot\mathbb{Z}}(y)\mu_{H}(y/q), we may expand the definition of g_{2} to re-formulate (6.3) as88
8
Here we have normalised the L^{1}(\mathbb{Z}) norm as in (A.1).
\sum_{x}\mathopen{}\left\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}-f_{2}^{x}*\mu_{q^{2},M^{2}}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\mathclose{}\right\|_{1}\gg\varepsilon^{O(1)}N_{1}N_{2}.
One can check that we have the bound
\mathopen{}\left\|\mu_{q^{2},M^{2}}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}-\mu_{q^{2},M^{2}}\mathclose{}\right\|_{1}\ll\frac{\tilde{q}^{2}\widetilde{M}^{2}}{M^{2}}+\frac{\tilde{q}^{4}\widetilde{M}^{4}}{M^{4}}.
Decreasing \widetilde{M} if necessary, but still retaining a lower bound of the form \widetilde{M}\geqslant\varepsilon^{O(1)}M, we have
\sum_{x}\mathopen{}\left\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}-f_{2}^{x}*\mu_{q^{2},M^{2}}\mathclose{}\right\|_{1}\gg\varepsilon^{O(1)}N_{1}N_{2}.
Applying the Cauchy–Schwarz inequality then gives
\sum_{x}\mathopen{}\left\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}-f_{2}^{x}*\mu_{q^{2},M^{2}}\mathclose{}\right\|_{2}^{2}\gg\varepsilon^{O(1)}N_{1}N_{2}.
We wish to replace the above, which measures the energy of a difference of two functions f-g, with the difference of their energies \mathopen{}\left\|f\mathclose{}\right\|_{2}^{2}-\mathopen{}\left\|g\mathclose{}\right\|_{2}^{2}. From Pythagoreans’ theorem, we know that to make this substitution we must show that f-g and g are (approximately) orthogonal. More concretely, writing L^{2}-norms in terms of inner products, we have
(6.4)
\big\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\big\|_{2}^{2}-\big\|f_{2}^{x}*\mu_{q^{2},M^{2}}\big\|_{2}^{2}=\big\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}-f_{2}^{x}*\mu_{q^{2},M^{2}}\big\|_{2}^{2}\\
-2\operatorname{Re}\bigl\langle f_{2}^{x}*\mu_{q^{2},M^{2}},f_{2}^{x}*\bigl(\mu_{q^{2},M^{2}}-\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\bigr)\bigr\rangle.
So we wish to show that the latter inner product is small.
Suppose otherwise, so that the inner product in (6.4) is at least
\delta\mathopen{}\left\|f_{2}^{x}\mathclose{}\right\|_{2}^{2}. Then Parseval’s identity and the convolution identity give
\delta\mathopen{}\left\|f_{2}^{x}\mathclose{}\right\|_{2}^{2}\leqslant\operatorname{Re}\bigl\langle f_{2}^{x}*\mu_{q^{2},M^{2}},f_{2}^{x}*\bigl(\mu_{q^{2},M^{2}}-\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\bigr)\bigr\rangle\\
=\int_{\mathbb{T}}\bigl|\widehat{f}^{x}_{2}(\alpha)\bigr|^{2}\widehat{\mu}_{q^{2},M^{2}}(\alpha)\mathopen{}\left[\widehat{\mu}_{q^{2},M^{2}}(\alpha)-\widehat{\mu}_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}(\alpha)\mathclose{}\right]\mathrm{d}\alpha\\
\leqslant\mathopen{}\left\|f_{2}^{x}\mathclose{}\right\|_{2}^{2}\sup_{\alpha}\mathopen{}\left(\widehat{\mu}_{q^{2},M^{2}}(\alpha)\mathopen{}\left[\widehat{\mu}_{q^{2},M^{2}}(\alpha)-\widehat{\mu}_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}(\alpha)\mathclose{}\right]\mathclose{}\right).
By non-negativity of \widehat{\mu}_{q^{2},M^{2}}, there exists \alpha\in\mathbb{T} such that both of the following hold
\widehat{\mu}_{q^{2},M^{2}}(\alpha)\geqslant\delta\quad\text{and}\quad\widehat{\mu}_{q^{2},M^{2}}(\alpha)-\widehat{\mu}_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}(\alpha)\geqslant\delta.
Yet, we know from summing the geometric series that if
M^{-4}\mathopen{}\left|\hat{1}_{[M^{2}]}(q^{2}\alpha)\mathclose{}\right|^{2}=\widehat{\mu}_{q^{2},M^{2}}(\alpha)\geqslant\delta,
then \mathopen{}\left\|q^{2}\alpha\mathclose{}\right\|_{\mathbb{T}}\leqslant\delta^{-1/2}/M^{2}. Yet, for such values of \alpha, we have
\widehat{\mu}_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}(\alpha)=\bigl|\mathbb{E}_{\tilde{d}\in[\widetilde{M}^{2}]}e(\alpha q^{2}\tilde{q}^{2}\tilde{d})\bigr|^{2}\geqslant\bigl(1-\frac{2\pi\tilde{q}^{2}\widetilde{M}^{2}}{\delta^{1/2}M^{2}}\bigr)^{2}\geqslant 1-\frac{4\pi\tilde{q}^{2}\widetilde{M}^{2}}{\delta^{1/2}M^{2}}.
Thus, taking \delta=(5\pi\tilde{q}^{2}\widetilde{M}^{2}/M^{2})^{2/3} gives the contradiction that such values of \alpha satisfy \widehat{\mu}_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}(\alpha)>1-\delta and \widehat{\mu}_{q^{2},M^{2}}(\alpha)>1.
We have therefore deduced that
\operatorname{Re}\mathopen{}\left\langle f_{2}^{x}*\mu_{q^{2},M^{2}},f_{2}^{x}*\mathopen{}\left(\mu_{q^{2},M^{2}}-\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\mathclose{}\right)\mathclose{}\right\rangle\ll\mathopen{}\left(\tfrac{\tilde{q}\widetilde{M}}{M}\mathclose{}\right)^{4/3}\mathopen{}\left\|f_{2}^{x}\mathclose{}\right\|_{2}^{2}.
Putting all of the above together, we have that
\sum_{x}\mathopen{}\left(\big\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\big\|_{2}^{2}-\mathopen{}\left\|f_{2}^{x}*\mu_{q^{2},M^{2}}\mathclose{}\right\|_{2}^{2}\mathclose{}\right)\geqslant\Omega\mathopen{}\left(\varepsilon^{O(1)}N_{1}N_{2}\mathclose{}\right)-O\mathopen{}\left(\mathopen{}\left(\tfrac{\tilde{q}\widetilde{M}}{M}\mathclose{}\right)^{4/3}N_{1}N_{2}\mathclose{}\right).
Decreasing \widetilde{M} if necessary, but still retaining a lower bound of the form \widetilde{M}\geqslant\varepsilon^{O(1)}M, we obtain the energy increment
\sum_{x}\big\|f_{2}^{x}*\mu_{q^{2}\tilde{q}^{2},\widetilde{M}^{2}}\big\|_{2}^{2}\geqslant\sum_{x}\big\|f_{2}^{x}*\mu_{q^{2},M^{2}}\big\|_{2}^{2}+\Omega\mathopen{}\left(\varepsilon^{O(1)}N_{1}N_{2}\mathclose{}\right).
With this bound in hand, our inductive hypotheses are satisfied (see (6.2)), and our procedure iterates to the next stage.
Since the energy (6.2) is bounded above by N_{1}N_{2}, our procedure must terminate at some stage n\ll\varepsilon^{O(1)}, yielding either M=M_{n}\ll\varepsilon^{-O(1)} or (6.1). Unpacking the rate at which q=q_{n} and M=M_{n} change, the former possibility leads to N\leqslant\exp(\varepsilon^{-O(1)}), whilst the latter gives our other desired outcome.
∎
7. Obtaining a popular difference
Finally we prove the remaining results claimed in our introduction §1.
Theorem 7.1 (Existence of a popular difference).
Let A\subset[N_{1}]\times[N_{2}] with |A|\geqslant\delta N_{1}N_{2} and N_{1}\geqslant N_{2}^{1/2}. Given 0<\varepsilon\leqslant 1/2, either N_{2}\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exist q\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) and M\geqslant N_{2}^{1/2}/\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) such that
\sum_{x,y,d}\mu_{M}(d)1_{A}(x,y)1_{A}(x+qd,y)1_{A}(x,y+q^{2}d^{2})\geqslant\mathopen{}\left(\delta^{3}-\varepsilon\mathclose{}\right)N_{1}N_{2}.
Proof.
Let us apply our energy increment argument to 1_{A}, so we take f_{0}=f_{1}=f_{2}=1_{A} in Theorem 6.1. This tells us that we either have N_{2}\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exist q\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) and M\geqslant N_{2}^{1/2}/\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) such that qM\leqslant\varepsilon N_{2}^{1/2} and
\biggl|\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\\
\biggl[1_{A}\mathopen{}\left(x,y+q^{2}d^{2}\mathclose{}\right)-\sum_{\tilde{d}}\mu_{M^{2}}(\tilde{d})1_{A}\mathopen{}\left(x,y+q^{2}\mathopen{}\left(d^{2}+\tilde{d}\mathclose{}\right)\mathclose{}\right)\biggr]\biggr|\leqslant\varepsilon N_{1}N_{2}.
Focusing on the second counting operator, we have
\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\sum_{\tilde{d}}\mu_{M^{2}}\bigl(\tilde{d}\bigr)1_{A}\mathopen{}\left(x,y+q^{2}\mathopen{}\left(d^{2}+\tilde{d}\mathclose{}\right)\mathclose{}\right)\\
=\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\sum_{\tilde{d}}\mu_{M^{2}}\mathopen{}\left(\tilde{d}-d^{2}\mathclose{}\right)1_{A}\mathopen{}\left(x,y+q^{2}\tilde{d}\mathclose{}\right).
The Lipschitz properties of \mu_{M^{2}} give that
\mathopen{}\left|\mu_{M^{2}}\mathopen{}\left(\tilde{d}-d^{2}\mathclose{}\right)-\mu_{M^{2}}\bigl(\tilde{d}\bigr)\mathclose{}\right|\ll d^{2}M^{-4}.
Hence our restriction to |d|<\varepsilon M gives
\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\sum_{\tilde{d}}\mu_{M^{2}}\bigl(\tilde{d}\bigr)1_{A}\mathopen{}\left(x,y+q^{2}\mathopen{}\left(d^{2}+\tilde{d}\mathclose{}\right)\mathclose{}\right)\\
\geqslant\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\sum_{\tilde{d}}\mu_{M^{2}}\bigl(\tilde{d}\bigr)1_{A}\mathopen{}\left(x,y+q^{2}\tilde{d}\mathclose{}\right)-O\mathopen{}\left(\varepsilon N_{1}N_{2}\mathclose{}\right).
Expanding the definition (A.7) of the Fejér kernel, then changing variables, we have
\sum_{x,y,d}\mu_{\varepsilon M}(d)1_{A}(x,y)1_{A}(x+qd,y)\sum_{\tilde{d}}\mu_{M^{2}}\bigl(\tilde{d}\bigr)1_{A}\mathopen{}\left(x,y+q^{2}\tilde{d}\mathclose{}\right)\\
\geqslant\sum_{x,y}\mathbb{E}_{d_{1},d_{2}\in[\varepsilon M]}\mathbb{E}_{\tilde{d}_{1},\tilde{d}_{2}\in[M^{2}]}1_{A}\bigl(x+qd_{1},y+q^{2}\tilde{d}_{1}\bigr)\\
1_{A}\bigl(x+qd_{2},y+q^{2}\tilde{d}_{1}\bigr)1_{A}\bigl(x+qd_{1},y+q^{2}\tilde{d}_{2}\bigr).
By an application of Hölder’s inequality, sometimes termed the Blakley-Roy inequality99

Taking N_{1}=N_{2} in Theorem 7.1 yields Theorem 1.2. Taking N_{2}=N_{1}^{2} yields the following, which is perhaps more natural.
Corollary 7.2.
Let A\subset[N]\times[N^{2}] with |A|\geqslant\delta N^{3} and let 0<\varepsilon\leqslant 1/2.
Either N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exists d\neq 0 such that
\#\mathopen{}\left\{(x,y)\in A:(x+d,y),(x,y+d^{2})\in A\mathclose{}\right\}\geqslant\mathopen{}\left(\delta^{3}-\varepsilon\mathclose{}\right)N^{3}.
From this we derive the existence of a one-dimensional popular common difference, which is claimed in Theorem 1.3.
Corollary 7.3 (Theorem 1.3, re-stated).
Let A\subset[N] with |A|\geqslant\delta N and let 0<\varepsilon\leqslant 1/2.
Either N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exists d\neq 0 such that
\#\mathopen{}\left\{x\in A:x+d,x+d^{2}\in A\mathclose{}\right\}\geqslant\mathopen{}\left(\delta^{3}-\varepsilon\mathclose{}\right)N.
Proof.
Define
\tilde{A}:=\mathopen{}\left\{(x,y)\in[N^{1/2}]\times[N]:x+y\in A\mathclose{}\right\}.
Let us bound the size of \tilde{A}. We have:
|\tilde{A}|\geqslant\sum_{a\in A\cap(N^{1/2},N]}\sum_{x\in[N^{1/2}]}1_{[N]}(a-x)\geqslant\mathopen{}\left(\delta N-N^{1/2}\mathclose{}\right)N^{1/2}\geqslant(\delta-\varepsilon)N^{3/2},
or else N\ll\varepsilon^{-O(1)}.
Applying Theorem 7.1, either N\leqslant\exp\mathopen{}\left(\varepsilon^{-O(1)}\mathclose{}\right) or there exists an integer d\neq 0 such that
\#\mathopen{}\left\{(x,y)\in[N^{1/2}]\times[N]:x+y,\ x+y+d,\ x+y+d^{2}\in A\mathclose{}\right\}\geqslant\mathopen{}\left((\delta-\varepsilon)^{3}-\varepsilon\mathclose{}\right)N^{3/2}.
Taking a maximum over x\in[N^{1/2}], we obtain some x_{0} such that
\#\mathopen{}\left\{y\in[N]:x_{0}+y,\ x_{0}+y+d,\ x_{0}+y+d^{2}\in A\mathclose{}\right\}\geqslant\mathopen{}\left((\delta-\varepsilon)^{3}-\varepsilon\mathclose{}\right)N.
The result follows on observing that (by the binomial theorem) (\delta-\varepsilon)^{3}\geqslant\delta^{3}-4\varepsilon.
∎
Appendix A Notation
A.1. Standard conventions
We use \mathbb{N} to denote the positive integers. For real X\geqslant 1, write [X]=\{1,2,\ldots,\mathopen{}\left\lfloor X\right\rfloor\}. A complex-valued function is 1-bounded if the modulus of the function does not exceed 1.
We use counting measure on \mathbb{Z}^{d}, so that for f,g:\mathbb{Z}^{d}\to\mathbb{C} we have
(A.1)
\mathopen{}\left\langle f,g\mathclose{}\right\rangle:=\sum_{x}f(x)\overline{g(x)}\qquad\text{and}\qquad\mathopen{}\left\|f\mathclose{}\right\|_{L^{p}}:=\biggl(\sum_{x}|f(x)|^{p}\biggr)^{\frac{1}{p}}.
Any sum of the form \sum_{x} is to be interpreted as a sum over \mathbb{Z}^{d}.
We use Haar probability measure on \mathbb{T}^{d}:=\mathbb{R}^{d}/\mathbb{Z}^{d}, so that for measurable F:\mathbb{T}^{d}\to\mathbb{C} we have
\mathopen{}\left\|F\mathclose{}\right\|_{L^{p}}:=\biggl(\int_{\mathbb{T}^{d}}|F(\alpha)|^{p}\mathrm{d}\alpha\biggr)^{\frac{1}{p}}=\biggl(\int_{[0,1)^{d}}|F(\alpha)|^{p}\mathrm{d}\alpha\biggr)^{\frac{1}{p}}
For \alpha\in\mathbb{T} we write \mathopen{}\left\|\alpha\mathclose{}\right\|_{\mathbb{T}} for the distance to the nearest integer.
For a finite set S and function f:S\to\mathbb{C}, denote the average of f over S by
\mathbb{E}_{s\in S}f(s):=\frac{1}{|S|}\sum_{s\in S}f(s).
Given functions f,g:G\to\mathbb{C} on an additive group with measure \mu_{G} we define their convolution by
(A.2)
f*g(x):=\int_{G}f(x-y)g(y)\mathrm{d}\mu_{G},
when this makes sense. On the integers G=\mathbb{Z}, we take \mu_{G} to be counting measure.
We define the Fourier transform of f:\mathbb{Z}^{d}\to\mathbb{C} by
(A.3)
\hat{f}(\alpha):=\sum_{x}f(x)e(\alpha\cdot x)\qquad(\alpha\in\mathbb{T}^{d}),
again, when this makes sense. Here e(\beta) stands for e^{2\pi i\beta}.
The difference function of f:\mathbb{Z}^{d}\to\mathbb{C} with respect to h\in\mathbb{Z}^{d} is the function \Delta_{h}f:\mathbb{Z}^{d}\to\mathbb{C} given by
(A.4)
\Delta_{h}f(x)=f(x)\overline{f(x+h)}.
Iterating, we set
\Delta_{h_{1},\dots,h_{s}}f:=\Delta_{h_{1}}\dots\Delta_{h_{s}}f.
This allows us to define the Gowers U^{s}-norm
(A.5)
\mathopen{}\left\|f\mathclose{}\right\|_{U^{s}(\mathbb{Z}^{d})}:=\mathopen{}\left(\sum_{x,h_{1},\dots,h_{s}\in\mathbb{Z}^{d}}\Delta_{h_{1},\dots,h_{s}}f(x)\mathclose{}\right)^{1/2^{s}}.
When S\subset\mathbb{Z}^{d} we define the localised Gowers U^{s}-norm
(A.6)
\mathopen{}\left\|f\mathclose{}\right\|_{U^{s}(S)}:=\mathopen{}\left\|f1_{S}\mathclose{}\right\|_{U^{s}}.
For a function f and positive-valued function g, write f\ll g or f=O(g) if there exists a constant C such that |f(x)|\leq Cg(x) for all x. We write f=\Omega(g) if f\gg g. We sometimes opt for a more explicit approach, using C to denote a large absolute constant, and c to denote a small positive absolute constant. The values of C and c may change from line to line.
A.2. Local conventions
Up to normalisation, all of the above are well-used in the literature. Next we list notation specific to our paper. We have tried to minimise this in order to aid the casual reader.
For a real parameter H\geqslant 1, we use \mu_{H}:\mathbb{Z}\to[0,1] to represent the following normalised Fejér kernel
(A.7)
\mu_{H}(h):=\frac{1}{\mathopen{}\left\lfloor H\right\rfloor}\mathopen{}\left(1-\frac{|h|}{\mathopen{}\left\lfloor H\right\rfloor}\mathclose{}\right)_{+}=\frac{(1_{[H]}*1_{-[H]})(h)}{\mathopen{}\left\lfloor H\right\rfloor^{2}}.
Strictly speaking, “Fejér kernel” usually refers to the Fourier transform of this function, which is a function on the torus \mathbb{T}. We adhere to our unconventional nomenclature since most of our arguments take place in \mathbb{Z}.
For a multidimensional vector h\in\mathbb{Z}^{d} we write
(A.8)
\mu_{H}(h)=\mu_{H}(h_{1},\dots,h_{d}):=\mu_{H}(h_{1})\dotsm\mu_{H}(h_{d}).
We observe that this is a probability measure on \mathbb{Z}^{d} with support in the box (-H,H)^{d}.
Define a counting operator on the functions f_{0},f_{1},f_{2}:\mathbb{Z}^{2}\to\mathbb{C} by
(A.9)
\Lambda_{N}(f_{0},f_{1},f_{2}):=\mathbb{E}_{x\in[N]}\mathbb{E}_{y\in[N^{2}]}\sum_{d}\mu_{N}(d)f_{0}(x,y)f_{1}(x+d,y)f_{2}(x,y+d^{2}).
When the f_{i} are all equal to f we simply write \Lambda_{N}(f).
