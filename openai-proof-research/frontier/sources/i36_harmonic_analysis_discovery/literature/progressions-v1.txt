                                                                                    1. Introduction


                                           In 1974 Pál Erdős [3] posed the question if for any inﬁnite set 𝐴 ⊂ R there exists a set
                                           𝐸 ⊂ R with positive Lebesgue measure such that 𝐸 contains no similar copies of 𝐴
                                           (here by a similar copy of a set 𝑆 ⊂ R we mean a set of the form 𝑎𝑆 + 𝑏 = {𝑎𝑥 + 𝑏 : 𝑥 ∈ 𝑆},
                                           where 𝑎, 𝑏 ∈ R and 𝑎 ≠ 0). The statement that the answer is positive is called the Erdős
                                           similarity conjecture, although it is not clear if Erdős himself expected an aﬃrmative
                                           answer. There are a lot of partial results (see e.g. [4–8]), but none so far that
                                           conclusively answer the question.

                                           It is easy to see that it is enough to check the conjecture for 𝐴 = {𝑎1 , 𝑎2 , . . .}, where
                                           (𝑎 𝑛 ) is a sequence converging to zero. In 1984 Falconer [4] showed the conjecture for
                                           all slowly converging sequences (in the sense that 𝑎 𝑛+1 /𝑎 𝑛 → 1). Surprisingly, there
                                           is no single exponentially quickly convergent sequence (𝑎 𝑛 ) for which it is known
                                           if the Erdős similarity conjecture holds. In particular it is not known if there exists
                                           a 𝑞 ∈ (0, 1) such that every measurable set 𝐸 ⊂ R with positive Lebesgue measure
                                           contains a similar copy of the sequence (𝑞 𝑛 ). Clearly, the Erdős similarity conjecture
                                           would imply that such 𝑞 cannot exist. Here we pose the following possibly easier
                                           question:
                                           Question 1. Does every measurable set 𝐸 ⊂ R of positive Lebesgue measure contain
                                           a sequence of the form (𝑎𝑞 𝑛 + 𝑏)∞
                                                                            𝑛=1
                                                                                for some 𝑎, 𝑏, 𝑞 ∈ R, 𝑎 ≠ 0, 𝑞 ∈ (0, 1)?


                                           We do not know the answer to Question 1. A natural attempt to prove an aﬃrmative
                                           answer could be taking a Lebesgue density point 𝑏 of 𝐸 and showing that for such
                                           a 𝑏 we can ﬁnd 𝑎 ∈ R \ {0} and 𝑞 ∈ (0, 1) such that (𝑎𝑞 𝑛 + 𝑏)∞
                                                                                                         𝑛=1
                                                                                                             ⊂ 𝐸. One of the main
                                           results of this paper is the following result, which shows that this approach does not
                                           work.

In [6] Kolountzakis proved that for any inﬁnite set 𝐴 ⊂ R there exists a measurable
set 𝐸 ⊂ [0, 1] of measure arbitrarily close to 1 such that almost every similar copy of 𝐴
