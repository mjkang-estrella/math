                                                                                      1. Introduction
                                             Let X be a complex Banach space, and B(X) the algebra of bounded linear operators on
                                          X. For T ∈ B(X), let σ(T ) be the spectrum of T . Say T is quasinilpotent if σ(T ) = {0}.

                                          dimensional separable Hilbert space have a non-trivial closed hyperinvariant (i.e., invariant
                                          for all the operators commuting with T ) subspace? This question is still open, especially for
                                          quasinilpotent operators (see [3, 8, 11, 12]).

  In fact, Mτ is not always closed. In [7], Ji and Liu constructed a quasinilpotent operator
T with power set [0, 1], for which Mτ is not closed for each τ ∈ [0, 1). But they proved
that there exists a subset N of Lat T , which is order isomorphic to Λ(T ). So, the following
question was raised in [7].
Question 1. For any quasinilpotent operator T ∈ B(X), can one find a subset N of Lat T
which is order isomorphic to Λ(T )?
   From the reference [5, 7], we observe that the subsets {1} and [0, 1] can be the power set of
some quasinilpotent operators. Can we find other subsets of [0, 1] that correspond to power
set of a quasinilpotent operator? Thus, we may naturally consider the following question.
Question 2. Which subsets of [0, 1] could be the power set of a quasinilpotent operator
T ∈ B(X)?
  Given a Banach space X, we let X ′ denote its dual space. Suppose that T ∈ B(X), we
denote by T ′ the adjoint of acting on X ′ . Comparing with the fact that σ(T ) = σ(T ′ ), one
may naturally consider the following question.
Question 3. Are Λ(T ) and Λ(T ′ ) intrinsically linked?
   In light of these questions, this paper is devoted to the calculations of the power set of
quasinilpotent weighted shifts on lp . To proceed, we recall some terminology and notation.
