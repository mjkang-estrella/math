                                             THE ERDŐS SIMILARITY PROBLEM FOR NULL SEQUENCES WITH
                                                        ADJACENT RATIOS BOUNDED BELOW

                                                                                   KAN JIANG AND LIFENG XI


                                                   Abstract. Let (an ) be a positive null sequence with lim inf n→∞ an+1 /an > 0. For every
                                                   η > 0, we construct a compact set E ⊂ [0, 1] with Lebesgue measure greater than 1 − η
                                                   containing no nontrivial affine copy of {an : n ≥ 1}. No monotonicity is assumed. The proof

                                                   adapts a finite-tree construction for geometric sequences to grids chosen from a subsequence
                                                   with two-sided ratio bounds. We also obtain one such set for any prescribed countable family
                                                   of sequences, with infinitely many distinct points omitted from every affine copy.

   Bourgain [1] proved that the sum of three infinite sets is not measure universal. More recently,

they proved that {an : n ≥ 1} + A and {an : n ≥ 1} − A are not measure universal for every
infinite set A. These results do not imply nonuniversality of the sequence itself.
   The bi-Lipschitz version has a different answer. Feng, Lai and Xiong [7, Theorem 1.1] proved,
in particular, that if a positive strictly decreasing null sequence satisfies

not imply measure universality in the sense used here.
   There are also results in which Hausdorff dimension replaces Lebesgue measure. Keleti [12]
constructed a compact set of Hausdorff dimension one that avoids similar copies of any prescribed
countable collection of three-point sets. Cruz, Lai and Pramanik [3] constructed Borel sets of
Hausdorff dimension one and Lebesgue measure zero avoiding affine copies of {0} ∪ {an : n ≥ 1}
under suitable decay assumptions. Their result includes geometric sequences. These dimension
statements do not give a positive-measure avoiding set.
   Gallagher, Lai and Weber [8] studied the corresponding question for dense Gδ sets. They
proved that Cantor sets are not topologically universal, whereas every countable set is topo-
logically universal. Jung and Lai [10] characterized topological universality by strong measure
zero. For the measure problem on Cantor sets, Kolountzakis [14] constructed full-measure sets
avoiding certain thin Cantor sets. A different question concerns unbounded sequences and sets
having large measure in every unit interval; see Kolountzakis and Papageorgiou [15].

1.1. Outline of the proof. We construct small open 1-periodic sets meeting x + t{bn : n ≥ 1}
for every x ∈ R and t ∈ [1, 2]. Dilations and reflections then cover all nonzero scales.
   We assign an interval of indices, called a window, to each edge of a finite tree. A local test
uses only the tables on that edge and in its child subtree. By choosing the window lengths,
we bound the number of representative dilations exponentially in the length. The number of

children is chosen so that the failure probability decreases faster. Using the finest grid of the
whole tree would not give this estimate.
   After enlarging the random set to an open set, the exceptional centers form a small closed
set. An open neighborhood of this set meets every remaining copy, since x + tbn → x. Thus no
center is left out.
