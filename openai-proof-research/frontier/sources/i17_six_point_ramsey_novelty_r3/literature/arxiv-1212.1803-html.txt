Almost all sets of d+2d+2 points on the (d−1)(d-1)-sphere are not subtransitive
Sean Eberhard
Address: Centre for Mathematical Sciences, Wilberforce Road, Cambridge CB3 0WA
Email address: s.eberhard@dpmms.cam.ac.uk
Abstract.
We generalise an argument of Leader, Russell, and Walters to show that almost all sets of d+2d+2 points on the (d−1)(d-1)-sphere Sd−1S^{d-1} are not contained in a transitive set in some 𝐑n\mathbf{R}^{n}.
A finite subset of 𝐑d\mathbf{R}^{d} is called transitive if it has a transitive group of symmetries, and subtransitive if it is a subset of a transitive set in some 𝐑n\mathbf{R}^{n}, where possibly n>dn>d. Clearly every subtransitive set lies on a sphere. The converse was answered negatively by Leader, Russell, and Walters [3, 4] in connection to some conjectures in Euclidean Ramsey theory. Their key idea in [3] was to show more strongly that almost all cyclic quadrilaterals are not even affinely subtransitive; that is, they do not embed into a transitive set even by a (nonconstant) affine map x↦A​x+bx\mapsto Ax+b.
The purpose of this note is to point out that both the result and the argument in [3] generalise straightforwardly: almost all sets of d+2d+2 points on the (d−1)(d-1)-sphere are not affinely subtransitive. On the other hand, it is not hard to see that every affinely independent set of d+1d+1 points, in other words a nondegenerate simplex, is subtransitive (see, e.g., [1] or [4]), so this result is best possible.
Theorem.
Almost every set of d+2d+2 points on the (d−1)(d-1)-sphere Sd−1⊂𝐑dS^{d-1}\subset\mathbf{R}^{d} is not affinely subtransitive.
Proof.
Let x0,…,xd+1x_{0},\ldots,x_{d+1} be chosen uniformly at random from Sd−1S^{d-1}. Since there are only countably many finite groups, each of which has only countably many orthogonal representations up to orthogonal conjugacy, it suffices to fix a finite subgroup GG of O⁡(n)O(n), and elements g1,…,gd+1∈Gg_{1},\ldots,g_{d+1}\in G, and show that almost surely there is no nonconstant affine f:𝐑d→𝐑nf:\mathbf{R}^{d}\to\mathbf{R}^{n} such that
f⁡(xk)=gk​f​(x0)for all k=1,…,d+1.f(x_{k})=g_{k}f(x_{0})\quad\text{for all $k=1,\ldots,d+1$}.
(1)
If x0,…,xdx_{0},\ldots,x_{d} are affinely independent then they may be affinely mapped to the standard affine basis 0,e1,…,ed0,e_{1},\ldots,e_{d} of 𝐑d\mathbf{R}^{d}. The image α=(α1,…,αd)∈𝐑d\alpha=(\alpha_{1},\ldots,\alpha_{d})\in\mathbf{R}^{d} of xd+1x_{d+1} is then uniquely determined. The
function ϕ:(x0,…,xd+1)↦α\phi:(x_{0},\ldots,x_{d+1})\mapsto\alpha thus defined is a rational map, and moreover the image of ϕ\phi is ‘‘large”11
1
For instance, image​(ϕ)⊃(0,1)d−1×(1,∞)\text{image}(\phi)\supset(0,1)^{d-1}\times(1,\infty). In the language of algebraic geometry, ϕ\phi is a dominant rational map: its image is not contained in any proper subvariety..
If ϕ⁡(x0,…,xd+1)=α\phi(x_{0},\ldots,x_{d+1})=\alpha, then (1) has a nonconstant affine solution if and only if it does when (x0,…,xd+1)(x_{0},\ldots,x_{d+1}) is replaced by (0,e1,…,ed,α)(0,e_{1},\ldots,e_{d},\alpha); call this condition (1)′. Writing f⁡(x)=A​x+bf(x)=Ax+b with A∈𝐑n×dA\in\mathbf{R}^{n\times d} and b∈𝐑nb\in\mathbf{R}^{n}, the conditions k=1,…,dk=1,\ldots,d of (1)′ are equivalent to
A=(g1​b−b,…,gd​b−b),A=(g_{1}b-b,\ldots,g_{d}b-b),
while the final condition states that
∑k=1dαk​(gk​b−b)+b=gd+1​b.\sum_{k=1}^{d}\alpha_{k}(g_{k}b-b)+b=g_{d+1}b.
(2)
Note that (2) is an n×nn\times n linear condition on bb. If the only solutions are fixed points of {g1,…,gd+1}\{g_{1},\ldots,g_{d+1}\}, then AA must be 00, so ff must be constant. Quotienting by the subspace of fixed points of {g1,…,gd+1}\{g_{1},\ldots,g_{d+1}\}, we therefore obtain an n×n′n\times n^{\prime} (where n′⩽nn^{\prime}\leqslant n) linear system which has a nonzero solution if and only if (1)′ has a nonconstant affine solution. Since each n′×n′n^{\prime}\times n^{\prime} minor of this system is a polynomial in α1,…,αd\alpha_{1},\ldots,\alpha_{d}, it follows, unless each such polynomial is identically zero, that the set of α\alpha such that (1)′ has a nonconstant affine solution is contained in a proper subvariety of 𝐑d\mathbf{R}^{d}. Since ϕ\phi has large image, it then follows that the set of (x0,…,xd+1)(x_{0},\ldots,x_{d+1}) such that (1) has a nonconstant affine solution is contained in a proper subvariety of (Sd−1)d+2(S^{d-1})^{d+2}.
Thus it remains only to show that some n′×n′n^{\prime}\times n^{\prime} minor of this system is not identically zero, or equivalently that (1)′ does not always have a nonconstant affine solution. That is, we must rule out the possibility that {0,e1,…,ed,α}\{0,e_{1},\ldots,e_{d},\alpha\} is affinely subtransitive for every α∈𝐑d\alpha\in\mathbf{R}^{d}. But if α=(1/(2​d),…,1/(2​d))\alpha=(1/(2d),\ldots,1/(2d)) then {0,e1,…,ed,α}\{0,e_{1},\ldots,e_{d},\alpha\} is not even convex, so it cannot even be mapped onto a sphere with a nonconstant affine map.
∎
