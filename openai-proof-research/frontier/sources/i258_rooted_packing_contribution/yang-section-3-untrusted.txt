3    Deterministic embeddings of spread lists
We turn a spread empirical law into fixed neighborhood partitions that embed after the
roots have been placed. The hypotheses concern only the given list and its subpatterns,
independently of the graph applications.

                                                     6

3.1   Patterns and Hall functions
Let S be a finite set of roots. In the random bipartite graph G(S, [N ], ρ), every edge between
S and a disjoint set [N ] is present independently with probability ρ. Thus the neighborhoods
Zy ⊆ S, y ∈ [N ], are independent with law µρ . A list A1 , . . . , Ab ⊆ S has a root-preserving
embedding if there is an injection ϕ : [b] → [N ] such that Ai ⊆ Zϕ(i) for every i. The roots
themselves are not relabeled.
   A pattern family is a collection P ⊆ 2S . It is downward closed if A ∈ P and B ⊆ A imply
B ∈ P. This condition ensures that splitting a pattern never leaves the permitted family.
Associated with P is the class

                  F(P) = {fA : A ⊆ P} ,         fA (z) = 1{∃A ∈ A : A ⊆ z}.               (3.1)

We call these Hall functions. The empty subfamily represents zero, whereas a subfamily
containing the empty pattern represents one. If every pattern has size at most r, these
functions are monotone DNFs (disjunctive normal forms) of width at most r: each term
asks that all coordinates in one pattern be present, and the terms are joined by “or.” In
particular,
                          f ∈ F (P), f ̸≡ 0 =⇒ µρ (f ) ≥ ρr .                        (3.2)
   The terminology in (3.1) comes from Hall’s theorem [3]. For a nonempty set of indices
B ⊆ [b], define
                              fB (z) = 1{∃i ∈ B : Ai ⊆ z}.
Its candidate union is Γ(B) = {y ∈ [N ] : fB (Zy ) = 1}. A root-preserving embedding exists
exactly when |Γ(B)| ≥ |B| for every B ⊆ [b]. Thus one must control the entire class of
candidate-union functions, not just the candidate count for each individual pattern.

Definition 3.1 (Brackets). A finite family G of increasing {0, 1}-valued functions on 2S
provides brackets of error ε for F (P) under µρ if every f ∈ F(P) has f − , f + ∈ G such that

                  f − ≤ f ≤ f +,      µρ (f − f − ) ≤ ε,    µρ (f + − f ) ≤ ε.

All pointwise inequalities are required on the whole of 2S .

   An upper bracket controls demand on the target side; a lower bracket controls supply in
the host. The brackets need not themselves belong to F(P), but they must be increasing.
The error is measured in the same biased product measure as the host.

3.2   A relative-error embedding theorem
We use the following external coupling input.

Theorem 3.2 (Li, [6, Theorem 3.3]). If ν is a ρ-spread probability measure on 2S , where
0 < ρ < 1, there are jointly distributed random sets I, R1 , R2 such that

              I ∼ ν,      Rj ∼ µρ (j = 1, 2),       I ⊆ R1 ∪ R2   almost surely.

   The two Bernoulli sets are not required to be independent. This coupling will be used
only to choose the target decomposition, not to sample the host.

3.3   Finite pattern families
When the family of possible subpatterns is small, no approximation is needed. The following
form is the input for Sections 5 and 6.
