2. On the topological classiﬁcation of 4-manifolds

   The main result (2.4) of this section is an upper bound on the number of S 2 × S 2 connected summands
suﬃcient for a stable homeomorphism, where the fundamental group of X lies in a certain class of good
groups. By using Freedman–Quinn surgery [10, §11], if X is also suﬃciently large (2.3 for example), each
nonzero element ϑ of the UNil-group and simple DIFF homotopy structure (Y, h : Y → X) pair to form a
distinct TOP homotopy structure (Yϑ , hϑ ) that represents the DIFF homotopy structure ϑ · (Y, h) obtained
from (1).
