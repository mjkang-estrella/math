                                                     INEQUALITIES ON SIX POINTS IN A CAT(0) SPACE

                                                                                    TETSU TOYODA

                                                  Abstract. We establish a family of inequalities that hold true on any 6 points in any
                                                  CAT(0) space. We prove that the validity of these inequalities does not follow from
                                                  any properties of 5-point subsets of CAT(0) spaces. In particular, the validity of these
                                                  inequalities does not follow from the CAT(0) 4-point condition.

                                                                                  1. Introduction
                                             Many simple necessary and sufficient conditions for a geodesic metric space to be a
                                           CAT(0) space have been known. However, to find a characterization of those metric
                                           spaces that admit a distance-preserving embedding into a CAT(0) space is an open
                                           problem posed by Gromov (see [7, Section 1.19+], [8, §15], [1, Section 7], [2, Chapter
                                           10, E], [3, Section 1.4], [4, Section 2.2] and [16, Section 1]).
                                             A condition for points x1 , . . . , xn in a metric space (X, dX ) is called a quadratic metric
                                           inequality on n points if it can be written in the form

1.2. Graph comparison. Gromov [8, §7] introduced the following notion.
Definition 1.6 (Gromov [8]). Let n be an integer at least 4, and let Cn = (V, E) be
the n-vertex cycle graph with vertex set V and edge set E. A metric space (X, dX )
is said to satisfy the Cycln (0) condition if for any map f : V → X, there exists a map
g : V → H to a Hilbert space H such that
                   (
                     ∥g(u) − g(v)∥ ≤ dX (f (u), f (v)), if {u, v} ∈ E,
                     ∥g(u) − g(v)∥ ≥ dX (f (u), f (v)), if {u, v} ̸∈ E
for any u, v ∈ V .
   By Reshetnyak’s majorization theorem [14], every CAT(0) space satisfies the Cycln (0)
condition for any integer n ≥ 4. Gromov [8] proved that a geodesic metric space is
CAT(0) if and only if it satisfies the Cycl4 (0) condition. He also proved that a metric
space satisfies the Cycl4 (0) condition if and only if it satisfies the ⊠-inequalities. Thus,
by Theorem 1.2, a metric space X with |X| ≤ 5 admits a distance-preserving embedding
into a CAT(0) space if and only if X satisfies the Cycl4 (0) condition. Furthermore, the
present author [17] proved that if a metric space satisfies the Cycl4 (0) condition, then
it also satisfies the Cycln (0) condition for any integer n ≥ 4. On the other hand, the
existence of Lebedeva’s 6-point metric spaces that we have mentioned before shows that
the Cycl4 (0) condition is not a sufficient condition for a 6-point metric space to admit
a distance-preserving embedding into a CAT(0) space.

  A geodesic in a metric space X is a distance-preserving embedding of an interval of
the real line into X. For any x, y ∈ X, the image of a geodesic γ : [0, dX (x, y)] → X
with γ(0) = x and γ(dX (x, y)) = y is called a geodesic segment with endpoints x and y.
A metric space X is called geodesic if for any x, y ∈ X, there exists a geodesic segment
with endpoints x and y. We recall the definition of CAT(0) spaces.

Definition 2.1. A complete geodesic metric space (X, dX ) is called a CAT(0) space if for
any x, y ∈ X, and any geodesic γ : [0, dX (x, y)] → X with γ(0) = x and γ(dX (x, y)) = y,
the inequality

      dX (z, γ(tdX (x, y)))2 ≤ (1 − t)dX (z, x)2 + tdX (z, y)2 − (1 − t)tdX (x, y)2   (2.1)

holds true for any z ∈ X and any t ∈ [0, 1].

  In a CAT(0) space X, for any x, y ∈ X, a geodesic segment with endpoints x and y
exists uniquely. It is straightforward to see that (2.1) holds with equality when X is a
Hilbert space. In particular, Hilbert spaces are CAT(0).

Remark 2.2. Let (X, dX ) be a CAT(0) space, and let x, y, z ∈ X. Suppose that
γ : [0, dX (x, y)] → X is the geodesic such that γ(0) = x and γ(dX (x, y)) = y. Then
Definition 2.1 implies that

                  0 ≤ (1 − t)dX (z, x)2 + tdX (z, y)2 − (1 − t)tdX (x, y)2            (2.2)

for any t ∈ [0, 1], and equality holds in (2.2) if and only if z = γ(tdX (x, y)). Although
not necessary for our purposes, we note that (2.2) actually follows only from the triangle
inequality
                              dX (x, y) ≤ dX (z, x) + dX (z, y)
and the nonnegativity of dX . Therefore, (2.2) holds in every metric space.
