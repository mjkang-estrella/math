Summary. Stated improvement; optimal complexity open

Question
How many independently deleted copies of an unknown binary string suffice to recon-
struct every length-n string?

Result
For retention probability 𝑝, an upper bound exp(𝑂(𝑝−1 (log 𝑛)3 (1 + log log(2𝑛))6 )) on
the number of traces. The report also gives a polynomial sample bound when deletion
probability is at most 𝑛−𝜀 for fixed 𝜀 > 0.

Scope and remaining questions
Provides the requested improved sample upper bound. It does not prove matching
optimality or polynomial reconstruction running time.

                                                Abstract
        We give an improved worst-case sample bound for reconstructing a string from indepen-
     dent deletion traces, with its length and retention probability known. For each fixed retention
     probability, the number of traces is quasipolynomial: the logarithm of the sample budget is
     O((log n)3 (1 + log log(2n))6 ). If the deletion probability is at most n−ε for fixed ε > 0, poly-
     nomially many traces suffice. These bounds apply to binary strings and to strings of general
     symbols observed exactly. They concern sample complexity and do not assert an efficient re-
     construction algorithm or matching optimality.


Bound and comparison
Consider the i.i.d. deletion channel on an unknown string x of length n: a trace consists of the
symbols retained, in order with no labels on their original positions, when each position is retained
independently with probability p. Different traces are independent. The length and retention prob-
ability (and the channel model) are known to the reconstructor. All logarithms without specified
base are natural. The standard worst-case reconstruction task is to recover the entire string with
success probability at least 2/3 for each possible x.

Theorem 1. For integer n ≥ 2 and 0 < p ≤ 1, worst-case trace reconstruction of binary strings is
possible in this channel with at most

Gap probes with level masks
We first work with binary strings. Throughout assume the original length sufficiently large by an
absolute constant. Smaller n ≥ 2 can be handled by collecting ⌈p−n log 3⌉ traces to see one of full
length with probability at least 2/3; for bounded n ≥ 2 use log(1/p) ≤ 1/p to absorb this budget.
For n = 1 separately O(p−1 ) suffice. If n ≥ 2 and p < 1/n the full-length-trace strategy costs at
most exp(O(p−1 log n)), since with s = np ≤ 1, n log(1/p) = p−1 s(log n + log(1/s)). Also if n ≥ 2
and q = 1 − p < 1/n, then pn ≥ (1 − 1/n)n ≥ 1/4, so a constant number of traces suffices via the
same strategy. Hence for the rest write q = 1 − p and suppose p, q ≥ 1/n. Prepend a known block
of zeros of length equal to the original length to both candidates when comparing. Traces of the
extended inputs can be simulated by prepending independently sampled deletion traces of the zero
block. In the binary-case proof from here, n will now denote this doubled length so still p, q ≥ 1/n.

Separated-word base
Say a positive integer is a period of a word if symbols agree at all pairs of positions whose difference
equals it. By the padding we have d ≥ 2P0 for all sufficiently large n. Let w′ = xd−2P0 +1 · · · xd−1 =
yd−2P0 +1 · · · yd−1 . At least one of w′ 0, w′ 1 has no period of length < P0 . Indeed if both had
such periods p1 , p2 , then w′ would have both periods, hence period gcd(p1 , p2 ) (by the Fine–Wilf
phenomenon [4]). Indeed |w′ | ≥ p1 +p2 ; on positions 1, . . . , p1 +p2 , cyclic addition of p1 preserves the
symbol by either period p1 or (when wrapping around, moving by −p2 ) period p2 . This operation
connects all positions in each residue class mod gcd(p1 , p2 ) there. Positions beyond this range can
be related to ones within it by repeatedly subtracting p1 . Positions 2P0 − p1 and 2P0 − p2 in w′ –
numbered from 1 – would agree, contradicting opposite required final bits. Choose such a period-
avoiding extension w ∈ {w′ 0, w′ 1} and take the tuple with 2P0 slots, all edges exact, no masks,
and predicates testing the bits of w. The indicators of occurrences ending at d differ. Occurrence
endings in each individual string are P0 -separated, by the period condition. Hence up to sign,

Extension to general symbols
For clarity use n here for the original length. Collect ⌈p−1 log(12n)⌉ preliminary samples; except
with probability at most 1/12 by a union bound, every source symbol is in the observed set S,
and |S| ≤ n always. Given success, on independent fresh traces run tests for pairs in S n , mapping
symbols for each pair to bits by the indicator of one of the distinct symbols at its first differing
position, then using the binary pair argument (including padding as needed) for the two projected
candidates. For large n, p, 1 − p ≥ 1/n the Hoeffding sample size can be multiplied by O(log n)
for tail ≤ e−3n log n per pair and a union bound over rivals. Output a candidate winning all its
comparisons or declare failure if there is none. The increase does not affect the stated asymptotic
budget. The bounded-size or min(p, 1 − p) < 1/n cases can again directly use the whole-trace
strategy instead. This extension also concerns sample complexity only.
