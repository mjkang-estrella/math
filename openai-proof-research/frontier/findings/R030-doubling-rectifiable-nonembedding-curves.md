# R030 — Doubling rectifiable curves with no finite-dimensional bi-Lipschitz embedding

**Accepted as the eighth substantial result of the 2026-10-14 campaign: 8/10.** This is internal acceptance under the stipulated source contract and bounded contribution comparison, not external peer review or worldwide priority certification.

One fixed compact path-connected set of finite one-dimensional Hausdorff measure works before choosing the target dimension or distortion. The pinned OpenAI Hilbert nonembedding theorem is an explicit external premise. No simple arc, injective parametrization, quasiconvexity, Ahlfors regularity, or quantitative witness-size bound is claimed.

The additional operation is a finite height-separated polygonal thickening preserving witness distances and controlling ambient balls at every scale, including edge interiors. Finite witnesses, Dvoretzky placement and shrinking clusters are credited antecedents. Summable abstract-tree tours produce the curve. The contribution comparison distinguishes the ambient norm metric from intrinsic or weighted path metrics in the examined earlier constructions.
