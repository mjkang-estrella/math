# Parent optional route: exact order in a black-box finite group

2026-10-13. Unreviewed research suggestion sent to active I327. This is not a finding, not a completed proof and not a substitute for primitive-element search. It may be an extension of I322 rather than a separate substantial contribution.

Given an element g in a finite black-box group and an explicitly known upper bound N on its order, choose a dyadic Q >= 1024 * 2^(2 ceil(log2 N)). Use one exponent register and the pinned flagged polygonal transform. Accept a frequency only when its reduced continued-fraction approximant j/r satisfies 1 <= r <= N, gcd(j,r)=1, k=round(jQ/r), and an exact order verifier accepts r. The verifier factors r with the stipulated exact fixed-gate factoring algorithm, checks g^r=e and g^(r/ell)!=e for every prime ell dividing r. These conditions uniquely certify the order. The r=1 case is immediate.

The anticipated one-transform character estimate is p_j >= c/r for every coprime j. An exact fixed-dimensional probability calculation uses x-x'=rz, two phase-floor variables and a degree-two weight. This needs a complete proof and precise treatment of all continued-fraction choices; none is presumed here.

If those steps pass, per-label completion could set tau_r=2^(-ceil(log2 r)-c0), with total P0(r)=phi(r)tau_r. The elementary product bound phi(r)/r >= 1/(k+1), where k is the number of distinct prime factors, follows from ordered primes p_i>=i+1 and gives P0(r)>=1/poly(log N). A fixed polynomial number of trials raises success uniformly. The final unique-output quarter-success completion need not compute P(r) before the trial: after a valid r is obtained its P(r) is computed, and the complementary uniform guess of the unique r computes the same value after validation. This is a proposed deferred computation of a probability, not permission for an input-dependent rotation. Every actual coin still must be dyadic and every history retained.

Quantum exact factoring inside the verifier, invalid branches, the common circuit clock, gate control, selected-event normalization and resource accounting all require audit. The group representation must supply reversible multiplication, identity and equality with charged oracle costs and polynomial-length encodings. Do not assert a result for an unspecified infinite encoding model. Even if valid, the route does not find a primitive element and may belong in the single I322 algorithmic package.
