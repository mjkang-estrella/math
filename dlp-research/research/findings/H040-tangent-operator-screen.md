# H040 tangent multiplier: missing public map

2026-10-08. Independent initial native Astra `/root/h007_additive_relations`
proposal; root checked the narrow argument. No new source/novelty claim,
numerical run or Lean claim. This is not a general coordinate lower bound.

Mechanism considered: recover k from the differential of the unknown
multiplication map [k]. Its action on the one-dimensional tangent space at
infinity is multiplication by k in Fp: the differential of group addition is
addition of tangent vectors, so induction gives this for [k]. If that scalar
were available, k modp plus the canonical range could leave only a few scalar
candidates when q is comparable to p. This is the prospective gain, not an
implemented operation.

Missing primitive: construct that unknown map or its differential from G,Q.
For full E(Fp) of order q with q!=p prime, [k] and [k+q] agree on every rational
input but have different tangent multipliers, since q is nonzero in Fp.
Therefore evaluation on rational endpoints does not define the differential of
the unknown map. Differentiating a known scalar circuit returns the known
scalar. Public translation by Q has tangent multiplier1 after the usual
translation identification. Choosing the canonical multiplication map requires
the very missing scalar-sensitive construction; it is not done by naming it.

This rejects only the proposed endpoint-to-unknown-derivative shortcut. A
canonical scalar is uniquely determined by G,Q, so the observation does not
prove that no algorithm can compute it or a useful feature. No expensive
test or refinement is warranted without an explicit construction.
