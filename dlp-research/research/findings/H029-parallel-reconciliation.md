## Corrections to the proposer

The claimed exact rejection of all three cards is not accepted. Coalescence
requires deterministic evolution on relevant state (possibly including phase),
not necessarily the point alone. Equal stored points may yield useful relations
without future coalescence. This does not prove inversion is the only arithmetic
that can be shared. Storage, queries, labels and successful detection must be paid.

A: twin branching shares a denominator to create X+J and X-J, then retires a
walker to limit population. An unreported retired suffix can lose immediate
detection value without a retained descriptor. However dark fraction rho/theta
and its conversion to a rho/(2theta) birthday penalty are unproved heuristics.
Later traversal or paid descriptors can preserve some value. If every branch
uses a distinct DP retirement, branch count is bounded by actual retirements;
expected theta*T needs a visitation model. Population growth is births minus
retirements, but record size and memory allocation must be specified to convert
that into a work bound. Status: unvalidated. Cheapest next falsifier needs a
frozen retirement/ancestry/replay/query contract, not an imported rho constant.

B: adaptive reporting rates. Under independent tests with successive hazards
theta_j, expected number of tests to report is

    sum_(t>=0) product_(j=1)^t (1-theta_j).

It is not generally an average of reciprocal rates. Alternating hazards1,0 and
a uniform initial phase take1.5 tests on average; constant1/2 takes2. This refutes
the proposed probability lemma, NOT a working point-based coalescent detector.
AM–HM only applies to classes with a fixed geometric hazard within each class,
and consistent class weights and budget. Actual merge targets need not be uniform.
Querying earlier stored points remains a separate cost. No universal optimality
of constant density has been established here.

C: fully store a fraction phi of trails. In the proposer's uniform-hit model,
weighted delay (1-phi)*T/(M-phi*T) cannot beat T/M when T>=M. But if remaining
DPs cover only the remaining (1-phi)*T points, weighted delay is instead

    (1-phi)^2*T/(M-phi*T),  0<=phi<M/T.

For phi>0 it is no better than T/M iff T-2M+M*phi>=0; in particular M<=T/2
suffices. This is a restricted low-memory screen, not all-budget exclusion.
Full-trail immediate detection also needs incoming-walker queries, not just
insertions. Uniform hit fraction phi is an assumption, not a curve theorem.

## Research decision

Retain the three mechanisms and their missing premises. Do not promote the
proposer's global10% overhead ceiling, sole reopening inequality, remembered2.5
tail constant or assertion that population changes affect only wall time.
No matched complete-work saving was supplied. Existing known batching/replay/DP
benefits belong in the comparator, but do not form a universal lower bound.
No implementation or generic formal machinery authorized by these incomplete
cards. The next meaningful test requires one concrete detector with a paid ledger.
