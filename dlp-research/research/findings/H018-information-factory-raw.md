### Rank 1: A-ALG, an exact test for low-degree algebraic relations between the scalar and a feature

**Why this class.** The structure classes generated by the scalar action of Aff(F_q) are already covered (see pruning result N3 below):
- dilation eigenfunctions over F_q: the BM card;
- low-degree polynomials over F_q: RS and BM;
- additive characters over ℂ: AGS/H003;
- multiplicative characters over ℂ: MCL.

The natural next class that can be tested exactly is **algebraic relations**, which are not closed under those actions. Rational functions of n have dense monomial expansions on F_q^*, so BM reports linear complexity near q for them and misses them.

**Hypothesis H_A(d,e).** There is a nonzero R ∈ F_q[n,z] with deg_n ≤ d and deg_z ≤ e such that R(n, z(nG)) = 0 for all n ∈ F_q^*. Candidate features:
- z = x̄, the integer x reinterpreted mod q (even under negation);
- the centered formal parameter −x/y mod q (odd under negation);
- optionally a multiview vector (z(P), z(2P)).

This class contains rational functions of n (e=1), algebraic functions, and the inverse "n is a polynomial in z" slice (d=1).

**Recovery path.**
1. Compute z0 = z(Q). If r(n) = R(n, z0) is identically zero (at most e bad values of z0), rerandomize Q ← Q+uG.
2. Find the roots of r by computing gcd(r, n^q − n), at a cost of O(M(d) log q) field operations.
3. This gives at most d candidates. Verify each with nG = Q.

**Complete cost.**
- Setup: N = D+s samples, where D = (d+1)(e+1). Sampling takes two scalar multiplications plus N additions. Building the monomial matrix costs N·D, and the kernel computation costs O(N·D²) (or D^ω). Memory is O(N·D).
- Per target: one feature evaluation, a root-finding step, and at most d verification scalar multiplications.
- It beats square-root work only if setup plus d·log q is much smaller than q^{1/2} in matched units. That needs roughly D ≲ q^{0.2}.
- Across many targets the setup amortizes completely, which is why a positive result would be dramatic.

**Possible source of gain.** None beyond closure. A relation would make the log an algebraic function of a cheap feature.

**Unsupported assumption.** That such a low-bidegree relation exists. A counting heuristic says a random function has no relation unless D is close to q.

**Prior-art distinction.**
- Coppersmith–Shparlinski (J. Cryptology 13, 2000) prove degree lower bounds, exponential in lg p, for polynomials **and algebraic functions** that agree with the F_p^* discrete log on ≥ p^{1/2+ε} points. So the analogous expectation is strongly negative.
- Lange–Winterhof (COCOON 2002) give degree lower bounds for polynomials interpolating the EC discrete log.
- I could not verify whether either paper covers the general (d,e) bidegree with F_q-valued, mixed-modulus EC features. That is exactly where character-sum methods may not transfer, because integer reinterpretation is not algebraic.
- The H017 BM card covers sparse explicit polynomials; this card covers implicit and rational relations. They overlap only on dense polynomials of degree ≤ d.

**Cheapest falsifier (paper estimate, unmeasured).**
- **Outcome logic.** If the sample matrix has full rank, H_A(d,e) is false on that curve and feature. That conclusion is deterministic, with no false negatives. A rank deficiency is only a candidate; validate it on ≥ 64 fresh samples.
- **Test (i), rational slice e=1.** Use Cauchy rational interpolation with d up to about 191: N = 2d+2 points, roughly 1.5e5 F_q operations, then 64 fresh checks.
- **Test (ii).** Run a (7,7) kernel test with D=64, N=96, roughly 4e5 operations.
- **Controls.** A planted rational table (αn+β)/(γn+δ) must return degree 1. A random table must fail.
- **Budget.** The total is under about 1M F_q operations before the root's unit conversion.
- **Piggyback option.** The rank test accepts any set of distinct sample points. If the root **predeclares it before the BM run**, the BM probe's 128 geometric samples could be reused, so the only extra cost would be about 5e5 of linear algebra.
- **Scope.** Any result covers one tiny instance only. It says nothing asymptotic.

Variants I deliberately did not count as separate cards: multiview vectors, relations restricted to a cheaply recognizable subset, and an F_p-valued version with the scalar reinterpreted into F_p.

### Pruning results (derived here; they need independent checking)

**N1. Composing with a homomorphism does not escape degree bounds.** For any isogeny or endomorphism φ, f∘φ(nG) = f(n·φ(G)). Isogeny-chain features cost polylog time and have degree ℓ^h·deg f, which looks like it escapes Weil-type bounds. It does not: their correlation with any function of n equals that of f on the codomain curve, so they inherit the bound for deg f.

**N2. A useful cheap operation must be non-algebraic or CDH-hard.**
- Morphisms E→E are translations composed with endomorphisms (Silverman, AEC III.4.7, cited from memory). Correspondences induce homomorphisms. So every algebraic operation acts on logs as n ↦ λn + c.
- Small orbit order arises only from Aut(E), which is already in the baseline.
- A cheap operation acting on logs as a polynomial of degree ≥ 2 gives a CDH-type oracle by finite differences. den Boer and Maurer–Wolf then reduce DLP to it, assuming auxiliary groups with smooth order exist. These are known results, not new ones.
- So the "missing cheap public operation" must either depend on integer representations (rho-type walks) or be as strong as CDH.

**N3. Spectral and rank probes add no new structure class.**
- In characteristic q, (T−1)^q = T^q − 1 = 0 for the shift operator T. So the finite-dimensional translation-invariant F_q-spaces are exactly polynomials of degree ≤ L, and dilation eigenfunctions are monomials.
- Over ℂ, the corresponding objects are additive and multiplicative characters.
- Additive and multiplicative Hankel ranks therefore reproduce the RS, BM, AGS and MCL classes exactly.
- For a ±1 coordinate feature, Parseval plus the Kohel–Shparlinski-type bound gives Fourier sparsity ≥ q/(C log p)². Constants are unverified.

**N4. Structure below the Weil scale is just a landmark dictionary.** A box {n ∈ I, x ∈ J} with |I||J| < p contains O(1) points. Any "bias" there is effectively a stored dictionary entry, which reduces to the H013 landmark tradeoff L + q/L.

**N5. EDS quasi-periodic power-equivariant features are constant.**
- Use the identity ψ_{mN} = ψ_m^{N²}·ψ_N∘[m]. Take N ≡ 1 (mod q) and N² ≡ 1 (mod p−1); such an N exists by CRT because gcd(q, p−1) = 1.
- Then ψ_N(mR) = ψ_N(R)^{m²} whenever q ∤ m.
- Comparing m with m+q forces ψ_N(R)^{q²} = 1. Since q ∤ p−1, this gives ψ_N ≡ 1.
- This closes the EDS-based compact evaluation route that the H003 orbit gate asked for, in this power-equivariant form. It is the same phenomenon as the trivial reduced Tate pairing.
