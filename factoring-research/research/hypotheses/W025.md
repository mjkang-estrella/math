## 1. Replace independent coefficient representatives by one small multiplier

Fix a W022 chart with Q=ell^L (L>=1), ell odd, and an integer polynomial
R(x)=sum_nu d_nu*x^nu representing its chosen root. The number of monomials
is fixed. On the ordinary integer box, let w_nu>=1 bound |x^nu|. Let |S|<=W
and S=sign*R(x) modulo Q be the covered weighted sum. The old implementation
uses individual representatives d_nu mod Q, whose weighted height can be
large. We instead COMPUTE c and a polynomial P for a scaled root c*S.

For an integer target T>=1, set

    J={nu: w_nu>T}, K_nu=ceil(w_nu/T) for nu in J,
    B=product_(nu in J) K_nu.

The empty product is 1. Seek integers 1<=c<=B and k_nu such that

    |c*d_nu-Q*k_nu| <= floor((Q-1)/K_nu),  nu in J.       (1)

Existence is elementary: partition the fractional residue cube of the
vectors j*(d_nu/Q) for j=0,...,B into product K_nu=B half-open boxes. Two
points share a box. Their positive index difference is c, and every integer
error has magnitude strictly below Q/K_nu, exactly the bound in (1).
No random-coefficient or generic-lattice assumption is made.

Acquisition need NOT enumerate B points. Equation (1), together with
1<=c<=B, is an integer linear feasibility problem in |J|+1 variables
(c and the k_nu). The dimension is fixed, and every coefficient is binary
encoded. Invoke the explicit fixed-dimension integer-programming algorithm
of Lenstra; for fixed degree its bit cost is polynomial in the input length.
The parent retrieved the original paper from the author's publication page
and read its statement and algorithm setup, PDF pp.1-3 / text lines26-110:
[Lenstra, 1983](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1983i/art.pdf).
The complete proof was not re-audited. The use here is a fixed-dimensional
constructive subroutine with stated inputs, not a shortest-vector oracle.
No package has been installed and no fast implementation is claimed.

The positive constraint on c matters. An unconstrained short-vector search
could return c=0 and a multiple of Q in one coefficient; that is not a
useful scaling. The pigeonhole argument plus integer feasibility avoids it.

## 2. Normalize a nonunit multiplier without losing the carry saving

Require the public check B<Q. Then 1<=c<Q and v=valuation_ell(c)<L. Put

    r=ell^v, c'=c/r, Q'=Q/r >= ell.

For nu in J, e_nu=c*d_nu-Q*k_nu is divisible by r; use e'_nu=e_nu/r.
For nu outside J, use a centered representative e'_nu of c'*d_nu modulo Q'.
Define P=sum e'_nu*x^nu. It satisfies P=c'*R modulo Q'. For active terms,

    |e'_nu|*w_nu / Q' = |e_nu|*w_nu/Q < w_nu/K_nu <= T.

For inactive terms, |e'_nu|*w_nu <= Q'*T/2. If there are D monomials in
total, then |P(x)|<=D*Q'*T everywhere on the original box. Also

    c'*W/Q' = c*W/Q <= B*W/Q.

Thus every true c'*S is represented by sign*P(x)+Q'*tau with

    |tau| <= ceil(B*W/Q + D*T).                            (2)

Dividing c and Q by the SAME ell-power preserves the normalized carry cost.
Q' need not be a square: it is a precision for the already established
scaled-root congruence, not a fresh square-root acquisition modulus.

The represented exponent is now

    E'=c'*(u+N*vweight)-sign*P(x)-Q'*tau.

At the true leaf E'=c'*(p-1)*(vweight*q-u). The multiplier is acquired only
from public chart coefficients and bounds, independently of alpha.

W024's SIGN filter survives: P modulo ell equals c'*r0, and c' is an ell-unit.
The new exponent's constant residue is c' times the old nonzero epsilon.
Every retained integer exponent is nonzero, and a true good-base witness
survives. This is why normalization, rather than assuming c coprime to ell,
is essential. All old chart subdivisions remain ordinary boxes. A child
restriction can retain the same c',P,Q' and carry interval; recomputing them
is not necessary for representation correctness and would need to be paid.

If B>=Q, use the old representation and its W024 filter instead. In the
general construction choose T by binary search on the monotone condition
B(T)*W/Q <= C*T for a fixed constant C. The finite monomial count and
binary bounds make this polylogarithmic setup. The branch with B<Q must
be checked explicitly, not inferred from a volume estimate.

## 3. Concrete one-long-coordinate quartic

Suppose a signed v chart is a singleton and x varies over |x|<=Z, Z>=2.
After substituting that y coordinate and reducing coefficients modulo Q,
write R(x)=d0+d1*x+d2*x^2+d3*x^3+d4*x^4. Set

    A=max(1,ceil(W/Q)),   1<=A<=Z^2,
    T=ceil_cuberoot(A*Z^7),
    K3=ceil(Z^3/T), K4=ceil(Z^4/T), B=K3*K4.

The integer cube root is computed with outward rounding. Here
Z^2<=T<=Z^3 and B<=4Z^7/T^2, so B*W/Q<=B*A<=4T.
Apply the THREE-VARIABLE integer program only to d3,d4. The lower three
coefficient representatives have total height at most Q'*Z^2 for Z>=2;
the two shortened terms contribute at most 2Q'*T. Hence

    |P(x)|<=3Q'*T,
    every covered carry lies in [-7T,7T].                 (3)

This gives a paid carry length O(A^(1/3)*Z^(7/3)), replacing the previously
chosen O(A+Z^4) envelope in this regime. It is an upper-bound improvement
to that specific conservative representation, not a lower bound on every
old representation or a claim that all leading coefficients were large.
Take the cheaper of old and new bounds on any supplied chart.

The exact feasible point can be checked using integer arithmetic after the
fixed-dimensional solver returns it. Scaling, valuation stripping and all
coefficient reductions have polynomial-logarithmic bit cost. There are
only O(log Q) possible new strides Q' for one old Q, but per-chart multipliers
and coefficient arrays vary. A future shared evaluator must handle them and
pay setup; this construction does not inherit a shared-coefficient theorem
whose hypotheses no longer hold.

## 4. Explicit comparison within a root-cover regime

In the thin top-stratum regime U~M,V~1, fixed ell, H~M^(2/5), the signed
v charts are singleton once H>2V. With W~sqrt(MN),

    Z~M^(3/5), A~sqrt(N)/M^(3/2).

When 1<=A<=Z^2 and B<Q, the new target is

    T=O(N^(1/6)*M^(9/10)), B=O(N^(-1/3)*M^(12/5)).

For M~N^(1/4), A~N^(1/8), Z~N^(3/20), and

    old carry envelope: N^(3/5),
    new carry envelope: N^(47/120),
    multiplier bound:   N^(4/15) < Q~N^(1/2).

There are O(M) pairs, so the enlarged occurrence envelope changes from
O(N^(17/20)) to O(N^(77/120)) in this particular supplied-range composition,
with polylogarithmic acquisition per chart. Neither exponent beats a
factoring baseline; indeed small factors at this extreme thin boundary are
already susceptible to cheaper preprocessing. This is an intermediate
carry-bound improvement, not a full algorithmic comparison.

More generally if V grows but 2V<H, Z~M^(3/5)/V and the same one-coordinate
construction gives T=O(N^(1/6)*M^(9/10)/V^(7/3)), under the displayed A and
B conditions. All strata, dyadic ranges, prime scheduling, small-factor
preprocessing and final product/localization remain obligations of a complete
splitter. For several varying coordinates, section1 uses their actual
anisotropic monomial weights and a fixed-dimensional feasibility problem;
no favorable aggregate exponent is asserted without working it out.
