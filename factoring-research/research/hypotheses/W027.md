# W027: optimize the complete coefficient carry envelope directly

Parent construction, 2026-10-08 local. Pending independent validation.
No numerical experiment. Verified complete factoring improvement: **NONE**.

## The new computation

W025's sufficient pigeonhole bound ignores special coefficient divisibility.
Its Opus review supplied stronger truncation and hybrid baselines. Instead of
choosing between those formulas heuristically, solve ONE precise optimization
problem covering all their positive constant multipliers at once.

Given Q=ell^L, L>=1, a fixed-support polynomial

    R(x)=sum_(nu=1)^D d_nu*x^nu modulo Q,

integer bounds w_nu>=1 for |x^nu| on the supplied ordinary box, and integer
W>=0 bounding |S|, let centered_Q(z) be either minimum-absolute integer
representative of z modulo Q. Ell is odd, so the representative is unique.
Reduce all input d_nu to [0,Q). Define

    F(c) = c*W + sum_nu w_nu*|centered_Q(c*d_nu)|,
    1 <= c <= Q-1.                                      (1)

Compute c_star minimizing (1), EXACTLY for this stated envelope, by
fixed-dimensional integer linear feasibility and binary search. Variables
are c, k_nu, t_nu (2D+1 integer variables); for a proposed objective B impose

    1 <= c <= Q-1,
    t_nu >= c*d_nu-Q*k_nu,
    t_nu >= -(c*d_nu-Q*k_nu),
    t_nu >= 0,
    c*W + sum_nu w_nu*t_nu <= B.                         (2)

Optional explicit bounds 0<=k_nu<=Q and 0<=t_nu<=Q make the domain bounded
without removing a minimum. For c,d_nu in their displayed ranges, a nearest
integer k_nu to c*d_nu/Q lies in [0,Q], and its error has magnitude <=Q/2.
At an optimum, replacing any other k_nu by that nearest one only helps.

There is a feasible point at c=1 with objective at most

    F0 = W + Q*sum_nu w_nu.

Binary-search B in [0,F0]. Feasibility is monotone in B. With fixed D,
Lenstra's constructive fixed-dimensional algorithm supplies a feasible point
in polynomial bit time; use the last feasible B to recover c_star and the
coefficient errors. Every input in (2) has polynomial logarithmic width when
Q,W,w_nu have that width, and there are O(log(F0+1)) feasibility calls.
This is a fully specified theoretical primitive, not a claim that it has a
practical implementation in the current stdlib environment.

The primary source already checked for the prior construction is
[Lenstra, 1983](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1983i/art.pdf):
fixed-dimensional binary integer feasibility, including producing a witness.
No novelty for this optimization technique is claimed. The new application
is to the complete public carry envelope rather than a sufficient box-volume
bound or independent choices of precision and coefficient representatives.

## Normalize once, and keep the exact bound

Let r be the largest ell-power dividing c_star, and put

    c'=c_star/r, Q'=Q/r>=ell,
    e_nu=centered_Q(c_star*d_nu), P=sum_nu(e_nu/r)*x^nu.

Every e_nu is divisible by r because c_star and Q are. Thus P has integer
coefficients and P=c'R modulo Q'. The normalization preserves the objective:

    (c'*W + sum_nu w_nu*|e_nu/r|)/Q' = F(c_star)/Q.

Every true c'*S is represented by sigma*P(x)+Q'*tau with

    |tau| <= floor(F(c_star)/Q).                         (3)

Do not round this up to at least 1: when the right side is 0, the singleton
carry {0} is the correct interval. The floor is valid because tau is an
integer; a conservative implementation may still use the ceiling.

As in W025, the W024 sign residue is multiplied by the ell-unit c'. Every
retained exponent is a nonzero integer, and the actual good-base leaf has
E'=c'*(p-1)*(vq-u). The coefficient bounds, optimization and normalization
are all alpha-independent. Ordinary child boxes may retain the same c',P,Q'
and interval; tightening them is optional and must be priced separately.

## Why this subsumes the stronger baselines

For any lower precision Q_j=ell^j, 1<=j<=L, choose c=Q/Q_j in (1).
Then, exactly,

    centered_Q(c*d_nu) = c*centered_(Q_j)(d_nu),
    F(c)/Q = W/Q_j + sum_nu w_nu*|centered_(Q_j)(d_nu)|/Q_j.

This is the complete centered-coefficient envelope for that truncation.
Coefficients with sufficient H-adic divisibility vanish automatically.
The optimizer therefore includes all legal lower precisions without needing
an asymptotic generic-coefficient assumption or a separate chart root.

For a hybrid, first lower to Q_j and then choose 1<=a<Q_j. The combined
multiplier c=(Q/Q_j)*a still lies in [1,Q-1], and its objective is exactly
the hybrid's normalized weighted coefficient envelope. Centering any
nonminimal representatives can only improve it. Thus the optimizer is at
least as good as every such truncation/constant-multiplier hybrid for the
same supplied R, box weights, W and monomial basis.

Restricting positive constants to c<Q loses no better option in this family.
If c>=Q is not a multiple of Q, its positive remainder c0 has identical
coefficient residues and c0*W<=c*W. Multiples of Q normalize to precision 1
or less, outside this prime-residue-filter family. Negative constants have
the same absolute-height objective as their positives, with a sign change.
This is not a restriction on other algorithms, only this optimization class.

## Exact scope and next bottleneck

"Optimal" here means only (1). It does not minimize the actual maximum of
P on the box, exploit cancellation between monomials, change coordinates,
allow variable multipliers, or minimize a product evaluator's total cost.
In particular, the best carry width can come with a lower modulus or altered
coefficients that cost more to evaluate jointly. The supplied chart acquisition
and all pairs/strata/prime bases still need payment. A minimum coefficient
envelope is neither a factoring oracle nor a complete complexity theorem.

The concrete saved work is searching a numerically large set of c or guessing
among weak carry formulas: it is replaced by polynomial-logarithmic work per
fixed-dimensional chart, and it incorporates the structural truncation found
by the review. It also prevents a misleading comparison to an inferior
representation when the known divisibility already supplies a better one.

Audit (2)'s witness/optimization semantics, all bit lengths, zero W, Q=ell,
normalization, floor bound, exact hybrid inclusion and the filter/localization
interface. Symbolic validation is sufficient; a numerical scan would only
certify small optima and would NOT implement Lenstra. No new numerical run
is requested absent a specific ambiguity. No faster factoring bound is claimed.

The next constructive problem is to optimize representation and evaluator
together, or compute a separating invariant without the anchor family.
The main thread keeps the single-coefficient branch separate and active.
