# W017 Batched character filters for class-order estimates

Parent constructive wave, 2026-10-08. Verified new end-to-end factoring
improvement: NONE. This branch bypasses norm-relation collection: obtain many
class-order estimates with shared arithmetic, then seek factor-revealing
ambiguous forms. The batching primitive below is explicit; a faster complete
factoring algorithm is not supplied.

## Known starting point, with primary-source boundaries

Schnorr--Lenstra's 1984 paper, *A Monte Carlo factoring algorithm with linear
storage*, discusses using approximations to quadratic class numbers to shorten
order searches, including the older 1/5-scale route. This basic proposal is
not new. Primary source: https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1984c/artc.pdf
The parent has opened the paper and inspected its introductory extracted
passage; it has not audited that algorithm or all its analytic assumptions.

Hiary's *A fast amortized algorithm for computing quadratic Dirichlet
L-functions*, arXiv:1608.06614v2, Theorem 1.1 and sections 1,4,5, supplies
a different batch method with conductor-scale preprocessing. The theorem's
polylogarithmic per-value work must not be detached from that setup cost.
Its introduction permits s=1. Composite-conductor inclusion/exclusion is a
separate explicit part of its algorithm. Primary source:
https://arxiv.org/pdf/1608.06614
No single-input factoring improvement is imported from this result.

The construction below computes ONLY finite Euler products for a specified
multiplier family; it does not use an unevaluated L-function oracle.

## A concrete shared finite-product computation

Fix an integer discriminant candidate D<0 derived from N, an integer prime
cutoff B, and request multipliers 1<=k<=K. For each odd prime ell<=B, compute
c_ell=(D/ell) by a Kronecker/Legendre test. If ell reveals a proper factor
of N, return it; character zeros caused by known auxiliary factors are simply
handled as zeros. Sieve the primes and construct the period

    l_ell(a)=(a/ell), 0<=a<ell.

For example mark the nonzero square residues by squaring each residue and set
the remaining nonzero entries to -1. All O(ell) work is charged. The character
of D*k at ell is c_ell*l_ell(k), regardless of whether k is squarefree. For
use as fundamental discriminants later, filter the multiplier list separately.
The ell=2 local factor is one bounded-period sequence handled independently.

For chi in {-1,0,1}, there is the exact real identity

    -log(1-chi/ell) = A_ell*chi + C_ell*chi^2,
    A_ell = (1/2)*log((ell+1)/(ell-1)),
    C_ell = -(1/2)*log(1-ell^(-2)).                       (1)

When c_ell!=0, chi^2 is the indicator ell does not divide k. Thus the C terms
are a constant minus a sieve over multiples of ell. That part costs
O~(B+K) elementary work, including constructing and outputting the K values.

The nontrivial A part is the coefficient sequence of the rational series

    F(z) = sum_(odd prime ell<=B)
      w_ell * (sum_(a=0)^(ell-1) l_ell(a)*z^a)/(1-z^ell),
    w_ell=c_ell*A_ell.                                   (2)

Combine the rational functions by a binary product/sum tree. If

    D_B = sum_(odd prime ell<=B) ell,

the numerator and denominator degrees are O(D_B). Invert the denominator
as a power series through degree K and multiply to recover every coefficient
1,...,K. All denominators have constant term 1, so Newton series inversion
works over a composite coefficient ring. No interpolation inverses or integer
factorization of N is used. Using fast polynomial arithmetic, the proposed
arithmetic cost is

    O~(D_B+K),       D_B<=B^2,                            (3)

plus precision costs below. A separate computation for each k costs roughly
K*pi(B) character terms. This is an actual sharing operation when K is large
relative to B, not an assertion that small K benefits.

## Finite precision without exponential integer coefficients

Choose a common dyadic scale 2^b and approximate each A_ell,C_ell to absolute
error at most 2^(-b), with b large enough that the sum of all rounding errors
is <=epsilon/2. Compute (2) with the scaled INTEGER weights modulo 2^W.
Choose W so that twice the bound on the absolute final weighted sum is below
2^W. A loose bound pi(B)*max|scaled weight| suffices. Thus W is
O(b+log(B+1)), not the bit length of an expanded exact integer denominator.
Intermediate polynomial coefficients stay reduced modulo 2^W. The true final
weighted sums are recovered by their signed representatives. The C-term sieve
is treated with the same fixed-point convention. Logs and, if requested,
exponentiation to obtain the positive finite Euler products need certified
rounding at the stated precision; their costs are included.

This prevents exponential intermediate coefficients in product_(ell)(1-z^ell)
from being silently represented as unit-cost integers. The primitive promises
approximations to log product_(ell<=B)(1-chi_(D*k)(ell)/ell)^(-1), with a
chosen ABSOLUTE log error epsilon. It does not promise that this finite
product approximates the infinite L-value within epsilon.

## What it would save, and what it does not save

For fundamental negative discriminants Delta=D*k, class number estimates scale
as sqrt(|Delta|)*L(1,chi_Delta)/pi (apart from the exceptional small unit cases).
Filtering squarefree/congruence conditions and gcd(k,N), constructing forms,
sampling sufficiently useful classes and all order/torsion extraction must be
paid. One can sieve k<=K for its small factorization at O~K cost; this does NOT
factor N or certify that D was fundamental. The semiprime/squarefree-N scope is
an analysis promise until an explicit general reduction is supplied.

An analytic tail guarantee is a separate premise. If it supplied a class-order
interval of width Delta_h(B,k), ordinary interval collision work is on the
scale sqrt(Delta_h), plus generation and a proof of useful extraction. The
batch finite-product cost (3) does not let baby steps in distinct class groups
share a table. Nor does finding an exponent annihilating one sampled class
automatically identify the full class number or a useful ambiguous form.

In a deliberately simplified CONDITIONAL model, suppose width is
O~(sqrt(N*k)/sqrt(B)). A single estimate followed by an interval search has
cost B+N^(1/4)*B^(-1/4), optimized at the familiar N^(1/5) scale. This is a
model comparison, not a claimed uniform analytic error theorem.
If every k<=K then needs its own full interval search, their total search work
is O~(N^(1/4)*K^(5/4)*B^(-1/4)); batching estimates alone need not improve
factoring. An improvement requires a priced selection or extraction mechanism
that actually uses the cheaper family. Smooth-order success probabilities or
unusually accurate estimates cannot be asserted independently across k without
justification. The finite product filter is not evidence for those hypotheses.

## A second exact check: square multipliers do not supply independent tails

For a quadratic character chi_D and positive f, the imprimitive character
chi_(D*f^2)(n) equals chi_D(n) when gcd(n,f)=1 and is zero otherwise.
Consequently its Euler product removes just the factors at primes dividing f.
If all those primes are <=B, both the infinite L-value and the finite product
change by the SAME known factor. The relative truncation error is identical.
Averaging normalized estimates over such square multipliers cannot reduce it.
This is exact correlation, not a heuristic variance objection.

For nonsquare multipliers, the characters really change, but so do the class
groups. That is the precise tradeoff: related groups give correlated analytic
errors; independent-looking character estimates do not give free shared order
search. A computation crossing this divide must be explicitly constructed.
