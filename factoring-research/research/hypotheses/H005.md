# H005 — Quadratic inverse-patch pruning screen

Status: preregistered diagnostic, parent-owned; no complexity gain accepted.

Original proposal: Card 1 of research/hypotheses/W001-lifting.md. For odd N,
write p=a+2^s t and expand N/p modulo B=2^K as a finite geometric polynomial.
With s=ceil(K/3), the degree-two expansion is exact. Relax z=t² to the integer
interval between both endpoint tangents and the secant of t². A feasible relaxed
point need not be a factor; an infeasible relaxation can soundly prune a node.
The speculative improvement requires very small *total* search trees. No such
bound has been demonstrated; the quadratic screen cannot by itself beat the
known deterministic exponent. Its purpose is to decide whether higher-degree
work merits consideration.

## Frozen diagnostic

Use K=10,12,14,16; s=ceil(K/3); B=2^K; I=J=[2^(K/2−1),2^(K/2)−1]. Generate all
products of two distinct primes in I whose bitlength is K−1; shuffle their sorted
deduplicated list with Python Random(1001), using the same RNG in increasing K
order, and take at most eight N per K. Report actual sample sizes. The probe
receives only N and the public size-derived interval. This is a balanced-family
diagnostic, not an all-input benchmark or an N-only production factorer.

For every odd a modulo 2^s with a nonempty t interval, search the whole bisection
tree after any factor is found. Decide relaxed feasibility by exact reference
enumeration of t and q, solving c2*z = q−c0−c1*t mod B and checking intersection
of the z progression with the tangent/secant bounds. This enumerator is a charged
diagnostic, not an implementation of fast integer programming. Count its tested
(t,q) pairs and time. Compute ground-truth feasibility separately; never use it
to prune. Record visited nodes, false feasible nodes, rejection depths, operand
width diagnostics, and ratio to the complete unpruned tree.

Controls: verify the proposed N=115, K=8, s=3, a=1, t in [1,3], q in [3,5]
false feasible example; ensure every exact Taylor value equals N/p modulo B on
the tested patches; compare all returned factors with direct enumeration.

Reject the cheap-relaxation route at this screen if the median visited-node
fraction is >=0.8 on completed instances at the largest completed K. Any pruned
true solution is a soundness failure. Passing warrants a scaling follow-up, not
a speedup claim. Degree-five behavior and a proved search-tree bound remain open.

Command: `timeout 60s .venv/bin/python research/experiments/H005/quadratic_screen.py`.
Internal wave deadline 55 seconds, including generation; all partial and unstarted
instances are recorded. Output result.json includes source/protocol hashes.
No external solver, model, new library, or Lean infrastructure is required.
