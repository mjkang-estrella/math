# H012 — Exact reciprocal-certificate reuse

Status: preregistered diagnostic, parent-owned.

## Candidate and scope

W001-deterministic Card A asks whether a certificate (u,v,t) can cover many
factor-size intervals, reducing giant steps. This diagnostic constructs a
concrete valid pool via exact two-dimensional Gauss reduction, eliminating the
trivial constant-quotient direction before reduction. It does not implement a
factorer or assert the proposed asymptotic logarithmic gain.

For public unit j modulo m, the certificate conditions are

    v+2u*j = 0 mod m,
    N*t+u*j²+v*j = 0 mod m².

Equivalently, choose u*j²=N*t mod m, then choose
v=-u*j-N*t*j^(-1) mod m². Thus (u,t) has the basis (m,0),(c,1),
where c=N*(j²)^(-1) mod m. For a cell [P,Q], set C=floor((P+Q)/2) and
Gauss-reduce the integer basis (m*C²,0),(c*C²,N). Decode u and t by exact
division of these coordinates. Try b1,b2,b1+b2,b1-b2, normalizing sign.
Choose v in its residue class nearest to -u*C-N*t/C, with exact rational
rounding and ties upward. Reject u=t=0. Check both congruences exactly.

A certificate covers a closed real interval [P,Q] only if
|u*z+v+N*t/z|<=H throughout it. Check endpoints and, when u*t>0 and it is
inside the interval, the stationary point z²=N*t/u. Decide the stationary
value v+sign(u)*2*sqrt(u*N*t) against +/-H by integer sign/square comparisons.
No float or sampled-point approximation establishes coverage.

For each residue, deduplicate its pool, find all runs of whole covered cells,
and select a minimum-cardinality cover of the cells by the furthest-right greedy
rule. Count disconnected runs separately and record distinct certificates too.
This grid cover is conservative: it can miss savings from endpoints inside a
cell. Every selected covered cell is certified, not merely observed.

## Frozen inputs, budgets and criterion

- Random(1212), two public odd N at each exact bit length 64,128,256. Draw
  uniformly with the high and low bits set. Keep only gcd(N,m)=1 under the
  following deterministic m rule; record rejected generation counts. Do not
  assert these controls are semiprimes or primes. No hidden factor is generated.
- Let target=floor(N^(1/5)), computed exactly. Build the largest initial
  primorial not exceeding target, then multiply by 2 until doubling would
  exceed target. Its prime factors are public and generated with exact trial
  primality. Record m and its known distinct primes. No factoring of N is used.
- For each N choose 16 distinct unit residues uniformly by rejection sampling
  from 1,...,m-1 using the same RNG. Record every chosen residue and rejection
  count. Conditioned sampling is a finite diagnostic, not a proof for all j.
- Start at ceil(N^(1/3)) and make successive doubled cells, clipping the last
  endpoint to floor(sqrt(N)). Shared boundaries are harmless. These endpoints
  cover every integer factor in the intended size interval.
- Set K=16*ceil(sqrt(N/m³)) by exact integer comparisons, then H=K*m².
  Never increase K to repair a failed cell. Use exactly the four vectors above.
- Record all pool certificates, source cells and their exact whole-cell coverage,
  incomplete covers, selected covers, cell count, coverage ratio, generation
  work, Gauss steps, envelope checks and operand-width diagnostics. Preserve
  all completed, partial and unstarted residue cases.
- One invocation; internal deadline 55 seconds, external timeout 60 seconds.
  No budget or parameter enlargement after results. Save source/protocol hashes
  and complete evidence in experiments/H012/result.json, refusing overwrite.
- Finite continuation criterion: every attempted residue at the largest fully
  completed bit length has a complete cover, and the median ratio of original
  cell count to selected interval count is at least 2, without changing K.
  Otherwise reject this pool as the immediate lead (or inconclusive if no size
  completes). Any invalid congruence or accepted false envelope is a soundness
  failure. Passing does NOT establish C(n)=O(n/log n), a gain against a matched
  implementation, or a general factoring result. A constant reuse factor can
  pass this deliberately modest screen while giving no asymptotic improvement.

## Costs that remain relevant

All pool generation and cross-cell certification are real work. The small script
uses schoolbook Python integers and exact Gauss reduction; its timings do not
certify the faster reduction bounds used by the mathematical proposal. A surviving
pool still needs a uniform compressed-cover bound, full generation/selection cost,
the charged high-order preparation, collision extraction and all-input reduction.
The target is a possible logarithmic improvement to deterministic N^(1/5), not
a new N exponent, a GNFS speedup, or polynomial-time classical factoring.
