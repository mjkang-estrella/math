# H006 — Degree-five relaxation: certified subtree lower bound

Status: preregistered diagnostic, parent-owned.

## Question

Card 1 of W001-lifting.md speculates that inverse Taylor patches with degree five
could have total node count 2^(n/6)*poly(n). H005 was inconclusive because its
degree-two intervals had at most two integers. Test the actual degree-five
relaxation for a large cheaply certified feasible subtree, without assuming an
efficient IP solver or using hidden factors to choose branches.

## Constructive feasibility certificate

Let K=6s, R=2^s, B=R^6. A patch p=a+R*t has exact inverse polynomial
P(t)=sum(j=0..5)c_j*t^j mod B, where c_j=N*(-1)^j*a^(-j-1)*R^j mod B.
For t in [L,U], relax every z_j=t^j for j>=2 to the two tangent lower bounds
and secant upper bound (rounded inward to integer bounds); set z_0=1,z_1=t.

Choose an interior integer t and z_2=t². Set q to a residue of
c_0+c_1*t+c_2*t² modulo R³ inside the public cofactor interval J. If none exists,
try the next declared t. For j=3,4,5 sequentially, c_j/R^j is odd, so invert it
mod R and choose z_j in its tangent/secant interval that cancels the next
base-R digit of q−sum(c_i*z_i). Failure to find such z_j is inconclusive.
On success check every inequality and the complete congruence exactly.

Any accepted certificate proves the full relaxation feasible. Its nonexistence
in this limited construction does NOT prove infeasibility. Recursively bisect
only certified nodes; count uncertified visited boundary nodes but do not expand
them. This subtree is contained in the whole-tree search specified by the
proposal, so its node count lower-bounds that search's work. Root processing for
every patch is included. The comparison is with exhaustive traversal after any
factor, matching the proposed uniform V screen, not a claim about early-stop
factoring runtime. Later analysis must address ordering/early success separately.

## Frozen experiment and outcomes

K=12,18,24,30,36. At each K generate four distinct semiprimes from distinct
K/2-bit primes with N.bit_length()=K−1. Generator Random(6006), at most 10000
attempts per size. Test-data factors never enter the certificate routine. Use
the public I=J=[2^(K/2−1),2^(K/2)−1], all odd residues a mod R, and t trials
in deterministic order midpoint, L+1, U−1 (deduplicated and clipped strictly
inside). If L=U, test the exact leaf. Non-singleton nodes without an interior
integer produce no certificate and are not expanded in this lower-bound probe.

Record every completed/partial/unstarted instance, certified nodes, all visited
nodes, exact-factor certificates versus spurious ones, width diagnostics and
ratio to the complete unpruned tree. Use a 55-second internal deadline inside a
60-second subprocess timeout. Preserve partial counters and sample shortfalls.

If median visited-node fraction at largest completed K is >=0.5, classify the
current full-tree small-V hypothesis as empirically unsupported and investigate
a general lower bound from the certificate construction before investing in an IP
implementation. This is not an asymptotic disproof. If the fraction is smaller,
report inconclusive; it could be our weak certificate search. Any invalid
certificate or pruned true claim is a soundness failure. No factorization
complexity improvement can be claimed from this diagnostic.

Run `timeout 60s .venv/bin/python research/experiments/H006/certified_subtree.py`.
Output result.json includes exact input values, counters, source/protocol hashes.
