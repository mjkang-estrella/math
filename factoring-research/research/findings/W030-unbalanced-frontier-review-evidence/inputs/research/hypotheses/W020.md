# W020 — try to replace class-order searches by halving a known square class

2026-10-08 local. Parent constructive attempt and exact scoped diagnosis.
No improved complete factoring bound. No numerical candidate run or sampling
claim is planned; verify the load-bearing algebra with pinned Lean instead.

## Computation that would be saved

W017 requires expensive class annihilators. A different route is to start
from a known square class H^2, compute a second half K, and inspect K/H in
the 2-torsion subgroup. A useful nontrivial ambiguous class can split the
discriminant. This would replace the annihilator search if independent
halving were cheap. Independence and the actual halving computation are
requirements, not supplied oracles.

For a binary form Q=(a,2b,c), put N=ac-b^2. A known square representation
Q(u,v)=w^2 gives a rational point on a conic:

    X=a*u+b*v, Y=v, Z=w,
    X^2+N*Y^2=a*Z^2.                                  (H1)

When gcd(Z,N)=1, X/Z modulo N is a square root of a. Could the ordinary
rational parametrization of this conic cheaply give a different root,
and thereby a different half, without factoring N?

The concrete attempt uses the line through (X/Z,Y/Z) with slope A/B.
After clearing denominators the second intersection is

    X1=(N*A^2-B^2)*X - 2*N*A*B*Y,
    Y1=(B^2-N*A^2)*Y - 2*A*B*X,
    Z1=(B^2+N*A^2)*Z.                                 (H2)

All coordinates have polynomial bit length for polynomial-width A,B.
Normalize gcd(A,B)=1 first, and gcd-test Z and any parameter denominator.

## Exact result: this parametrization keeps the global root sign

The following identities hold over the integers, with no factorization,
group-order assumption, random model or conic-point assumption for H3/H4:

    X1^2+N*Y1^2 = (B^2+N*A^2)^2*(X^2+N*Y^2),          (H3)
    X1*Z + X*Z1 = 2*N*A*Z*(A*X-B*Y).                  (H4)

If gcd(B,N)=1 and gcd(Z,N)=1, then Z1 is a unit modulo N, and (H4) says
X1/Z1=-X/Z modulo N. No independent CRT sign is produced. Further primitive
normalization divides only by units modulo N, since Z1 is already a unit.

If 1<gcd(B,N)<N, the parameter B has already supplied a proper factor.
If gcd(B,N)=N, write B=N*k. Coprimality of A,B implies gcd(A,N)=1. Divide
the three coordinates in (H2) by the common N, giving

    X2=(A^2-N*k^2)*X-2*N*A*k*Y,
    Y2=(N*k^2-A^2)*Y-2*A*k*X,
    Z2=(A^2+N*k^2)*Z.

Now Z2 is a unit, and the corresponding exact identity is

    X2*Z-X*Z2 = -2*N*k*Z*(k*X+A*Y).                  (H5)

Thus this branch returns +X/Z modulo N. Any further common factor of the
coordinates is a unit modulo N. The vertical line B=0 is included after
normalizing A to a unit (coprime A,B forces A=+/-1).

These three gcd cases exhaust integer B. Therefore repeatedly making
rational line moves of this kind from a known unit-denominator conic point
only returns the original modular root or its global negative, unless a
parameter gcd already factors N. This is a statement about the explicit
parametrization, not all conic algorithms, class-group halving algorithms,
or arbitrary arithmetic circuits. It is not a factoring lower bound.

## Exact place the standard halving route needs missing input

Bosma--Stevenhagen, *On the computation of quadratic 2-class groups* (1996),
[primary paper](https://jtnb.centre-mersenne.org/item/10.5802/jtnb.170.pdf),
section 6, especially lemma 6.1 and the paragraph on printed page 307,
construct a ternary completion by extracting roots modulo the prime-power
factors of the discriminant. Those prime powers are part of its input.
The later ternary reduction does not eliminate their acquisition cost.
The parent read the abstract and sections around 5.8 and 6.1--6.7, not
the entire proof/dependency chain. The [publisher's erratum](https://jtnb.centre-mersenne.org/item/10.5802/jtnb.200.pdf)
was read in full: it concerns incorrect/incomplete reference numbering in
the printed paper, not a correction to the root-acquisition dependency.

The proposal to factor only the smaller leading coefficient a and recurse
does not discharge the paper's discriminant-root step. A known conic point
does provide one such root, but H4/H5 show that rational line randomization
does not make it independent. This is the failed assumption, identified as
an explicit algebraic computation rather than a generic claim of difficulty.

## Constructive next question and evidence plan

An alternative must change the root branch without smuggling in a new root
of a modulo N. One precise interface is a ternary completion whose local
choices are not fixed by the known point, with acquisition and nontrivial
branch probability proved. A claim that mere random unimodular or conic
line changes accomplish this must be tested against H4/H5 first. No such
completion is currently supplied, so this candidate is not promoted.

Formalize only H1, H3, H4, the exact B=N*k cancellation and H5. These
integer identities are useful guards against a false improvement; they
do not formalize modular inversion, gcd extraction, class groups, random
sampling or complete complexity. Run the existing shared checks and axiom
audit after adding the module. No new theorem-count metric is used.
