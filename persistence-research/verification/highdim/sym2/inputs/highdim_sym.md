# Symmetric high-dimensional certificates

## Scope and claim labels

**PROVED** means a mathematical implication or a complete certificate/coverage replay. **COMPUTED** means an executed finite experiment or a count of its outputs. **CONJECTURAL** means an unproved interpretation. This work changes only `verification/highdim/sym/` and this note; it makes no claim to settle multiplicative persistence.

## Method and certificate format

**PROVED.** For each distinct coefficient c, store the multiset of the position residues belonging to c. The class key is `(L mod M, sorted residues for c_1, ..., sorted residues for c_g)`. A coefficient with multiplicity one is an ordinary coordinate. Equal residues are allowed: distinct actual positions can have equal residues, and dropping actual distinctness during congruence sieving enlarges the domain safely.

**PROVED.** These classes partition all labelled position tuples: the key is a unique function of a tuple. Within an equal-coefficient group, permutations have identical X, so a single orbit representative suffices. Canonical *actual* solutions have increasing positions within each coefficient group. Every permutation of each recorded group is implicitly a solution; mixed coefficient orderings remain distinct and are all covered.

**PROVED.** To refine M to fM, a parent residue b occurring h times is distributed among `b, b+M, ..., b+(f-1)M`. The number of choices is `binomial(f+h-1,h)`. Choices for different parent residues and coefficient groups, together with the f choices for L, are independent. Sorting the resulting group yields each child exactly once. The generator uses combinations with replacement; the checker independently uses weak compositions of h into f bins. In particular, simply reducing the *sorted tuple* coordinatewise would be wrong: the checker reduces, re-sorts, and checks multiplicities.

**COMPUTED.** `gen_sym.py` emits JSONL `format="nd-sym", version=1`. Metadata contains `groups=[[coefficient,multiplicity],...]`, K, qmin, dimension, domain `unordered`, a root, and `scope`. Node residues are `[L_residue,[group_1_residues],...]`. An internal node has its refinement modulus, explicit children, and a list of rest primes. Leaves have either `{"prime":p}` or `{"sz":[a,w],"sol":[...]}`. `scope="full"` requires the all-zero root modulo 1. `scope="class"` is used only for positive controls and proves only that specified residue class.

## Independent checker and soundness

**PROVED.** `check_sym.py` imports only the Python standard library and imports no generator, projection, legacy checker, or arithmetic helper. It checks canonical group shapes, unique coefficients, dimensions, residues, root coverage, parent links, child multiplicities, duplicate children/IDs, cycles, reachability, and every child refinement. Every child not stored explicitly must pass a listed prime kill recomputed from scratch.

**PROVED.** Write `t0=v2(K)` and require qmin > t0, including the L floor. Thus `v2(X)=t0`. For j=v3(M), X modulo `3^(j+2)` has decimal period `3^j`, so the class determines either an exact exponent a or the lower bound a >= j+2. When 6 divides M, the analogous computation modulo `7^(i+1)`, with i=v7(M) and decimal period `6*7^i`, determines an exact w or its lower bound. Otherwise w >= 0 is the only constraint. The checker verifies every claimed decimal period.

**PROVED.** At an aligned prime p > 7, the checker independently proves primality by trial division and recomputes the orders of 10, 3 and 7. After normalization by `2^t0 3^a_lo 7^w_lo`, the necessary target is a coset of the cyclic subgroup generated by the remaining free powers. Membership is checked by exponentiation to its subgroup order. No supply-cache assertion is trusted.

**PROVED.** Optional `pin2=true` is valid only when qmin >= t0+3. In that case `X/2^t0 = K/2^t0 (mod 8)`. The four pairs `(a mod 2,w mod 2)` map bijectively to the four odd residues via `3^a 7^w`; the checker enumerates that map independently. An exact exponent of the wrong parity is impossible; a free exponent advances by two and the auxiliary subgroup is generated by 9 and/or 49. This strengthens ordinary prime kills without assuming an exponent bound.

**PROVED.** The optional decimal-tail constraint uses k=`pin_digits` <= min(3,qmin) and `D = 5^k * 2^max(k-t0,0)`. Every candidate satisfies `3^a 7^w = K/2^t0 (mod D)`. Independently enumerated decimal periods A and W of 3 and 7 give all admissible pairs `(a mod A,w mod W)`. Exact signatures filter those pairs. At an auxiliary prime, each surviving pair gives a coset of the subgroup generated by `3^A` when a is free and `7^W` when w is free. The checker recomputes those orders and the union of cosets. Lower bounds on free exponents do not remove residues from the image of an infinite arithmetic progression in a finite group. The mod-8 constraint can also filter these representatives; A and W are even because D contains 5.

**PROVED.** An unaligned-prime test computes all possible contributions of each residue occurrence modulo p. If d=ord_p(10), a coordinate fixed modulo M ranges over precisely one residue modulo gcd(d,M) in its decimal period. Finite-set convolution adds these contribution sets, starting at K. Allowing independent choices and collisions contains every domain tuple. A whole class is killed only when **every** resulting X residue misses the necessary target cosets. The checker computes this convolution independently, using the original class signature. It does not silently assume the stronger signatures of unenumerated refinements.

**PROVED.** A size leaf is accepted only with exact a and w, fixing the integer `N=2^t0*3^a*7^w`. All solutions have `10^L <= N-K`. The checker enumerates every such L and uses independent meet-in-the-middle enumeration of distinct positions below L, comparing the complete class-filtered solution set to the declared list. The generator instead uses recursive subtraction. Neither assumes absence of decimal carries. A separate canonical-position brute box independently requires every smooth X to occur in a checked size leaf and compares the entire solution set inside the box.

## Legacy-tree projection and configuration coverage

**PROVED.** `project_nd.py` treats a legacy tree only as an untrusted search hint. For a symmetric child it assigns its residues to source-labelled slots with the correct parent residue and coefficient, then follows that one source branch. Equal-coefficient permutation invariance makes that branch valid for the entire orbit. Legacy size lists are never copied: new unordered size solutions are enumerated. The emitted tree is verified by the fresh checker, including every omitted lift. This is a projection cross-check, not a from-scratch search timing comparison.

**PROVED.** `audit_coverage.py` independently follows the canonical coefficient elimination order used to name the legacy slices. Whenever a free coordinate lies below a certificate floor, it splits into each exact low position and the remaining high tail. Fixing a position moves its contribution into K. Dropping mixed floors and fixed/free collision restrictions only enlarges the emitted domain. Every terminal branch must have a checked full-domain certificate. Points with L below a terminal floor are covered by a separate exact smooth-lattice scan through the maximum floor minus one. Choosing a different elimination order yields a different valid slice cover whose constants need not match the supplied legacy files.

## Reproduction

**COMPUTED.** All Python entry commands use the prescribed 8,000,000 KiB virtual-memory limit, isolated Python, and only the standard library. Commands are bounded to less than 30 minutes. These are representative replay commands (working directory: repository root):

```sh
bash -c 'ulimit -v 8000000; python3 -I verification/highdim/sym/test_sym.py'
bash -c 'ulimit -v 8000000; python3 -I verification/highdim/sym/check_sym.py verification/highdim/sym/smoke.jsonl 10'
timeout 1500 bash -c 'ulimit -v 8000000; python3 -I verification/highdim/sym/run_experiments.py cross --stage all --seconds 120 --workers 6'
timeout 900 bash -c 'ulimit -v 8000000; python3 -I verification/highdim/sym/run_experiments.py cross --stage all --retry-budget --seconds 600 --workers 3'
bash -c 'ulimit -v 8000000; python3 -I verification/highdim/sym/audit_coverage.py'
```

**COMPUTED.** An early period-36 launch briefly overlapped two existing pools, exceeding the aggregate worker limit; it was stopped immediately and produced no retained result. Retained experiments have pool sizes at most 12; subsequent concurrent pools were kept within 12 workers total. No git commit was made.
